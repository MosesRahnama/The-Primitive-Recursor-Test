# ttt2

This folder is the public TTT2 artifact index.

Only the answer-related subtrees are included:

- `schema/`
- `schema-new-system/`
- `schema-b-new-system/`
- `ko7/`

Each child folder contains its own README with the local command and
certificate details. The parent folder exists so paths cited from
`../../scoring/answer-key/answer_key.json` have a stable public root.
