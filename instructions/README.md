# Instructions

Operator and agent instructions for every manual stage of the data pipeline.

| Subfolder | Stage |
|-----------|-------|
| `extraction\` | Round-by-round extraction prompts, one folder per test surface |
| `normalization\` | Normalization stage rules and operator steps |
| `scoring\` | Scoring-stage instructions (the override-audit package) |

The end-to-end pipeline map is `results\data_pipeline_overview.md`.
