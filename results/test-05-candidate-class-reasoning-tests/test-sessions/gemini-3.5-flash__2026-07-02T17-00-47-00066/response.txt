To assess whether `mu1`, `mu2`, and `mu3` are valid termination measures for the rewrite relation `Step`, we need to determine if they strictly decrease for every possible rewrite step. That is, for each candidate measure $\mu$, we require that if `Step t1 t2` holds, then $\mu(t1) > \mu(t2)$.

None of the three proposed candidates are valid termination measures. They all fail to strictly decrease on the rule `R_rec_succ`:
$$\text{Step } (\text{recDelta } b\ s\ (\text{delta } n)) \ (\text{app } s\ (\text{recDelta } b\ s\ n))$$

Below is a detailed analysis of each candidate.

---

### Analysis of `mu1`

We test `mu1` against the rule `R_rec_succ`:
* **LHS measure:**
  $$\mu_1(\text{recDelta } b\ s\ (\text{delta } n)) = 1 + \mu_1(b) + \mu_1(s) + \mu_1(\text{delta } n)$$
  Since $\mu_1(\text{delta } n) = 1 + \mu_1(n)$, we have:
  $$\mu_1(\text{LHS}) = 2 + \mu_1(b) + \mu_1(s) + \mu_1(n)$$

* **RHS measure:**
  $$\mu_1(\text{app } s\ (\text{recDelta } b\ s\ n)) = 1 + \mu_1(s) + \mu_1(\text{recDelta } b\ s\ n)$$
  Substituting $\mu_1(\text{recDelta } b\ s\ n) = 1 + \mu_1(b) + \mu_1(s) + \mu_1(n)$ gives:
  $$\mu_1(\text{RHS}) = 2 + \mu_1(b) + 2\mu_1(s) + \mu_1(n)$$

* **Comparison:**
  For strict termination, we require $\mu_1(\text{LHS}) > \mu_1(\text{RHS})$:
  $$2 + \mu_1(b) + \mu_1(s) + \mu_1(n) > 2 + \mu_1(b) + 2\mu_1(s) + \mu_1(n) \iff 0 > \mu_1(s)$$
  
  Since $\mu_1(s) \ge 0$ for all terms $s$, this condition is never satisfied. 
  * If $s = \text{void}$ (so $\mu_1(s) = 0$), the measure remains equal ($\text{LHS} = \text{RHS}$).
  * If $\mu_1(s) > 0$, the measure strictly increases ($\text{LHS} < \text{RHS}$).

**Conclusion:** `mu1` is **invalid**.

---

### Analysis of `mu2`

We test `mu2` against the rule `R_rec_succ`:
* **LHS measure:**
  $$\mu_2(\text{recDelta } b\ s\ (\text{delta } n)) = 5 + \mu_2(b) + \mu_2(s) + (1 + \mu_2(n)) = 6 + \mu_2(b) + \mu_2(s) + \mu_2(n)$$

* **RHS measure:**
  $$\mu_2(\text{app } s\ (\text{recDelta } b\ s\ n)) = 1 + \mu_2(s) + (5 + \mu_2(b) + \mu_2(s) + \mu_2(n)) = 6 + \mu_2(b) + 2\mu_2(s) + \mu_2(n)$$

* **Comparison:**
  We require $\mu_2(\text{LHS}) > \mu_2(\text{RHS})$:
  $$6 + \mu_2(b) + \mu_2(s) + \mu_2(n) > 6 + \mu_2(b) + 2\mu_2(s) + \mu_2(n) \iff 0 > \mu_2(s)$$

  Just like `mu1`, because $\mu_2(s) \ge 0$, this inequality is never satisfied.

**Conclusion:** `mu2` is **invalid**.

---

### Analysis of `mu3`

We test `mu3` against the rule `R_rec_succ`:
* **LHS measure:**
  $$\mu_3(\text{recDelta } b\ s\ (\text{delta } n)) = 1 + \mu_3(b) + \mu_3(s) + (1 + \mu_3(n)) = 2 + \mu_3(b) + \mu_3(s) + \mu_3(n)$$

* **RHS measure:**
  $$\mu_3(\text{app } s\ (\text{recDelta } b\ s\ n)) = 2 + \mu_3(s) + (1 + \mu_3(b) + \mu_3(s) + \mu_3(n)) = 3 + \mu_3(b) + 2\mu_3(s) + \mu_3(n)$$

* **Comparison:**
  We require $\mu_3(\text{LHS}) > \mu_3(\text{RHS})$:
  $$2 + \mu_3(b) + \mu_3(s) + \mu_3(n) > 3 + \mu_3(b) + 2\mu_3(s) + \mu_3(n) \iff 0 > 1 + \mu_3(s)$$

  Since $1 + \mu_3(s) \ge 1$ for all $s$, this is always false. The measure strictly increases on every application of this rewrite rule.

**Conclusion:** `mu3` is **invalid**.

---

### Summary
All three candidates fail to prove the termination of the relation because they cannot handle the duplication of the subterm $s$ in the right-hand side of the recursion step `R_rec_succ`.
