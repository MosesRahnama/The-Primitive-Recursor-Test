**Short answer:**  
None of the three measures is a correct termination‑measuring function for the rewrite system.  Each of them fails to decrease on the *rec‑succ* rule

```
recDelta b s (delta n)  →  app s (recDelta b s n)
```

and therefore cannot guarantee termination.

Below is a detailed walk‑through of the three candidates and why they break down.

---

## 1.  The rewrite rules

| # | Rule (LHS → RHS) |
|---|-------------------|
| 1 | `integrate (delta t) → void` |
| 2 | `merge void t → t` |
| 3 | `merge t void → t` |
| 4 | `merge t t → t` |
| 5 | `recDelta b s void → b` |
| 6 | `recDelta b s (delta n) → app s (recDelta b s n)` |
| 7 | `eqW a a → void` |
| 8 | `eqW a b → integrate (merge a b)` |

A termination measure `μ` must satisfy **μ(RHS) < μ(LHS)** for every rule.

---

## 2.  Candidate μ₁

```
μ₁(void)            = 0
μ₁(delta t)        = 1 + μ₁(t)
μ₁(integrate t)    = 1 + μ₁(t)
μ₁(merge a b)      = 1 + μ₁(a) + μ₁(b)
μ₁(app a b)        = 1 + μ₁(a) + μ₁(b)
μ₁(recDelta b s n) = 1 + μ₁(b) + μ₁(s) + μ₁(n)
μ₁(eqW a b)        = 3 + μ₁(a) + μ₁(b)
```

### Check the rules

| Rule | μ₁(LHS) – μ₁(RHS) |
|------|-------------------|
| 1 | `(1+(1+μ₁(t))) – 0 = 2+μ₁(t) > 0` |
| 2,3 | `(1+μ₁(t)) – μ₁(t) = 1 > 0` |
| 4 | `(1+2·μ₁(t)) – μ₁(t) = 1+μ₁(t) > 0` |
| 5 | `(1+μ₁(b)+μ₁(s)) – μ₁(b) = 1+μ₁(s) ≥ 1` |
| 7 | `(3+2·μ₁(a)) – 0 > 0` |
| 8 | `(3+μ₁(a)+μ₁(b)) – (1+(1+μ₁(a)+μ₁(b))) = 1 > 0` |

**Problem – rule 6**

```
LHS = recDelta b s (delta n)
μ₁(LHS) = 1 + μ₁(b) + μ₁(s) + (1+μ₁(n))
        = 2 + μ₁(b) + μ₁(s) + μ₁(n)

RHS = app s (recDelta b s n)
μ₁(RHS) = 1 + μ₁(s) + (1+μ₁(b)+μ₁(s)+μ₁(n))
        = 2 + μ₁(b) + 2·μ₁(s) + μ₁(n)

μ₁(LHS) – μ₁(RHS) = – μ₁(s) ≤ 0
```

When `μ₁(s) > 0` the measure **increases**; when `s = void` it stays equal.  Hence μ₁ does **not** guarantee a strict decrease.

---

## 3.  Candidate μ₂

```
μ₂(void)            = 0
μ₂(delta t)        = 1 + μ₂(t)
μ₂(integrate t)    = 2 + μ₂(t)
μ₂(merge a b)      = 2 + μ₂(a) + μ₂(b)
μ₂(app a b)        = 1 + μ₂(a) + μ₂(b)
μ₂(recDelta b s n) = 5 + μ₂(b) + μ₂(s) + μ₂(n)
μ₂(eqW a b)        = 5 + μ₂(a) + μ₂(b)
```

### Check the rules

All rules 1–5, 7, 8 give a strict decrease (the same kind of calculation as for μ₁, with the constants changed).  

**Problem – rule 6**

```
μ₂(LHS) = 5 + μ₂(b) + μ₂(s) + (1+μ₂(n))
        = 6 + μ₂(b) + μ₂(s) + μ₂(n)

μ₂(RHS) = 1 + μ₂(s) + (5 + μ₂(b) + μ₂(s) + μ₂(n))
        = 6 + μ₂(b) + 2·μ₂(s) + μ₂(n)

μ₂(LHS) – μ₂(RHS) = – μ₂(s) ≤ 0
```

Again the measure does **not** go down (it stays equal only when `s = void`).

---

## 4.  Candidate μ₃

```
μ₃(void)            = 0
μ₃(delta t)        = 1 + μ₃(t)
μ₃(integrate t)    = 2 + μ₃(t)
μ₃(merge a b)      = 1 + μ₃(a) + μ₃(b)
μ₃(app a b)        = 2 + μ₃(a) + μ₃(b)
μ₃(recDelta b s n) = 1 + μ₃(b) + μ₃(s) + μ₃(n)
μ₃(eqW a b)        = 4 + μ₃(a) + μ₃(b)
```

### Check the rules

All rules except 6 decrease strictly.

**Problem – rule 6**

```
μ₃(LHS) = 1 + μ₃(b) + μ₃(s) + (1+μ₃(n))
        = 2 + μ₃(b) + μ₃(s) + μ₃(n)

μ₃(RHS) = 2 + μ₃(s) + (1 + μ₃(b) + μ₃(s) + μ₃(n))
        = 3 + μ₃(b) + 2·μ₃(s) + μ₃(n)

μ₃(LHS) – μ₃(RHS) = – (1 + μ₃(s)) < 0
```

Here the RHS is **larger** by at least 1, regardless of `s`.  So μ₃ also fails.

---

## 5.  Why the rec‑succ rule is the hard case

The step

```
recDelta b s (delta n) → app s (recDelta b s n)
```

reduces the *depth* of the `delta`‑chain in the third argument (from `delta n` to `n`).  All three measures add the weight of the newly introduced `app` constructor, which exactly cancels (or outweighs) the loss of the outer `delta`.  Consequently an additive weighting of the syntax tree cannot enforce a strict decrease.

A termination proof for this system therefore requires a **lexicographic** or **nested** measure, e.g.

```
μ(t) = ( number of delta‑constructors in the outermost “recursion‑argument”,
         total size of the term )
```

or any other measure that isolates the recursion‑argument’s size from the “app” prefix.

---

## 6.  Bottom line

| Candidate | Fails on rule | Reason |
|-----------|---------------|--------|
| μ₁ | 6 (rec‑succ) | increase = μ₁(s) (zero only when `s = void`) |
| μ₂ | 6 (rec‑succ) | increase = μ₂(s) (zero only when `s = void`) |
| μ₃ | 6 (rec‑succ) | increase = 1 + μ₃(s)  (always > 0) |

All three **do not** satisfy the required strict decrease for every rewrite step, so none of them is a valid termination measure for the given first‑order rewrite calculus.
