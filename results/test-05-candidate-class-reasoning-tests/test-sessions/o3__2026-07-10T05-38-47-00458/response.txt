Assessment criterion  
For a function μ : Trace → ℕ to be a genuine termination measure for the relation
         t ⟶ t′   (i.e.  Step t t′),
we must have

   μ t  >  μ t′

for every constructor of  Step.  The critical point is therefore to check the
seven rules of ‑/ Step /- against each of the three proposals μ₁, μ₂, μ₃.

------------------------------------------------------------
1.  Rules that are automatically satisfied by all three μᵢ
------------------------------------------------------------

For the following rules the left hand side is always assigned a strictly
greater value than the right hand side by every candidate, because the left
hand side contains an extra constructor that the right hand side lacks.

• R_int_delta        integrate (delta t)      ⟶  void
• R_merge_void_left  merge void t             ⟶  t
• R_merge_void_right merge t void             ⟶  t
• R_merge_cancel     merge t t                ⟶  t
• R_rec_zero         recDelta b s void        ⟶  b
• R_eq_refl          eqW a a                  ⟶  void
• R_eq_diff          eqW a b                  ⟶  integrate (merge a b)

Hence any incompatibility must come from rule R_rec_succ.

------------------------------------------------------------
2.  The critical rule  R_rec_succ
------------------------------------------------------------

Rule:
      recDelta b s (delta n)     ⟶     app s (recDelta b s n)

Let the common part “contrib” be μ(b)+μ(s)+μ(n).  Then

   μ (recDelta b s (delta n)) = wr + wd + contrib        (LHS)
   μ (app s (recDelta b s n)) = wa + wr + contrib        (RHS)

where
   wr : constant used for recDelta
   wd : extra constant paid for the outer delta
   wa : constant used for app.

The rule will decrease μ  iff   wd  >  wa.

Below are the constants chosen by the three proposals:

        wr    wd    wa
   μ₁   1     1     1
   μ₂   5     1     1
   μ₃   1     1     2

• μ₁ and μ₂:  wd = wa  ⇒  LHS = RHS whenever s = void (μ s = 0).
              Hence the measure is *not strictly decreasing*.

• μ₃:         wd < wa  ⇒  LHS < RHS  for every s.
              So the measure is *increasing* – the worst possible case.

Therefore none of the three proposals is a valid termination measure.

------------------------------------------------------------
3.  How to repair the situation
------------------------------------------------------------

Keep every weight as in μ₁ (the simplest of the three) but make the weight of
delta strictly larger than the weight of app.  One perfectly adequate choice
is

   μ₄ void               = 0
   μ₄ (delta t)          = 2 + μ₄ t          -- raised from 1 to 2
   μ₄ (integrate t)      = 3 + μ₄ t          -- any number ≥ 1 works
   μ₄ (merge a b)        = 1 + μ₄ a + μ₄ b
   μ₄ (app a b)          = 1 + μ₄ a + μ₄ b
   μ₄ (recDelta b s n)   = 1 + μ₄ b + μ₄ s + μ₄ n
   μ₄ (eqW a b)          = 4 + μ₄ a + μ₄ b

Now for R_rec_succ we have

   μ₄ LHS = 1 + 2 + contrib = 3 + contrib
   μ₄ RHS = 1 + 1 + contrib = 2 + contrib

so μ₄ LHS > μ₄ RHS by exactly 1, even when s = void.  All other rules still
decrease because they already did in μ₁.  Hence μ₄ is a correct termination
measure.

------------------------------------------------------------
Conclusion
------------------------------------------------------------

• μ₁ : fails – not strictly decreasing for R_rec_succ (equality if s = void).  
• μ₂ : fails – same problem as μ₁.  
• μ₃ : fails – actually increases for R_rec_succ (wd < wa).  

None of the three candidates can be accepted.  Increasing the weight of the
δ-constructor so that  weight(δ) > weight(app)  (for instance the μ₄ above)
fixes the problem and yields a valid, strictly descending measure.
