None of the three candidates are valid termination measures because they all fail to be strictly decreasing on the `R_rec_succ` rule. For all `b`, `s`, `n`, the measure of the left-hand side `recDelta b s (delta n)` is **less than or equal** to the measure of the right-hand side `app s (recDelta b s n)`. Concretely, let `x = μ(b)`, `y = μ(s)`, `z = μ(n)`:

- **μ₁**: LHS = `2 + x + y + z` ; RHS = `2 + x + 2y + z` → LHS ≤ RHS (equal when `y=0`, otherwise smaller).
- **μ₂**: LHS = `6 + x + y + z` ; RHS = `6 + x + 2y + z` → same issue.
- **μ₃**: LHS = `2 + x + y + z` ; RHS = `3 + x + 2y + z` → LHS < RHS for all `y ≥ 0`.

All other rewrite rules are handled successfully by each candidate (the measure strictly decreases), but the failure on `R_rec_succ` alone disqualifies them as global termination measures.
