# Audit of Candidate Termination Measures

I need to verify that each candidate measure strictly decreases across every rewrite rule. That is, for each rule `Step t1 t2`, I need `mu(t1) > mu(t2)`.

Let me use the notation `|t|` for the measure of a subterm, and analyze each rule under each candidate.

## Rule-by-rule analysis

### R_int_delta: `integrate (delta t) → void`

| Measure | LHS | RHS | Decreases? |
|---------|-----|-----|------------|
| mu1 | 1 + (1 + \|t\|) = 2 + \|t\| | 0 | ✅ |
| mu2 | 2 + (1 + \|t\|) = 3 + \|t\| | 0 | ✅ |
| mu3 | 2 + (1 + \|t\|) = 3 + \|t\| | 0 | ✅ |

### R_merge_void_left: `merge void t → t`

| Measure | LHS | RHS | Decreases? |
|---------|-----|-----|------------|
| mu1 | 1 + 0 + \|t\| = 1 + \|t\| | \|t\| | ✅ |
| mu2 | 2 + 0 + \|t\| = 2 + \|t\| | \|t\| | ✅ |
| mu3 | 1 + 0 + \|t\| = 1 + \|t\| | \|t\| | ✅ |

### R_merge_void_right: `merge t void → t`

Same analysis — all ✅.

### R_merge_cancel: `merge t t → t`

| Measure | LHS | RHS | Decreases? |
|---------|-----|-----|------------|
| mu1 | 1 + \|t\| + \|t\| = 1 + 2\|t\| | \|t\| | ✅ |
| mu2 | 2 + 2\|t\| | \|t\| | ✅ |
| mu3 | 1 + 2\|t\| | \|t\| | ✅ |

### R_rec_zero: `recDelta b s void → b`

| Measure | LHS | RHS | Decreases? |
|---------|-----|-----|------------|
| mu1 | 1 + \|b\| + \|s\| + 0 | \|b\| | ✅ |
| mu2 | 5 + \|b\| + \|s\| | \|b\| | ✅ |
| mu3 | 1 + \|b\| + \|s\| | \|b\| | ✅ |

### R_rec_succ: `recDelta b s (delta n) → app s (recDelta b s n)`

| Measure | LHS | RHS |
|---------|-----|-----|
| mu1 | 1 + \|b\| + \|s\| + (1 + \|n\|) = 2 + \|b\| + \|s\| + \|n\| | 1 + \|s\| + (1 + \|b\| + \|s\| + \|n\|) = 2 + \|b\| + 2\|s\| + \|n\| |

**mu1: LHS − RHS = −|s|. ❌ FAILS** (LHS < RHS when |s| > 0).

| mu2 | 5 + \|b\| + \|s\| + 1 + \|n\| = 6 + \|b\| + \|s\| + \|n\| | 1 + \|s\| + (5 + \|b\| + \|s\| + \|n\|) = 6 + \|b\| + 2\|s\| + \|n\| |

**mu2: LHS − RHS = −|s|. ❌ FAILS.**

| mu3 | 1 + \|b\| + \|s\| + 1 + \|n\| = 2 + \|b\| + \|s\| + \|n\| | 2 + \|s\| + (1 + \|b\| + \|s\| + \|n\|) = 3 + \|b\| + 2\|s\| + \|n\| |

**mu3: LHS − RHS = −1 − |s|. ❌ FAILS.**

### R_eq_refl / R_eq_diff

All three candidates handle these straightforwardly (I verified they decrease), but the details are moot.

## Verdict

**All three candidates fail** on rule `R_rec_succ`. The fundamental problem is that the RHS `app s (recDelta b s n)` duplicates `s`, so any additive measure satisfying `mu(app a b) ≥ mu(a) + mu(b)` cannot absorb the extra copy of `|s|` just by removing one `delta` wrapper. None of the three measures is a valid termination measure for this rewrite system.
