## Setting up the audit

For any candidate `mu : Trace -> Nat` to certify termination of `Step` by well-founded recursion on `Nat`, it must satisfy

```
Step t t' -> mu t > mu t'
```

for **every** constructor of `Step`, for **all** instantiations of the universally quantified variables. I checked this rule‑by‑rule for `mu1`, `mu2`, `mu3`.

## Rules 1–5, 7, 8: all three candidates are fine

For each of `R_int_delta`, `R_merge_void_left`, `R_merge_void_right`, `R_merge_cancel`, `R_rec_zero`, `R_eq_refl`, `R_eq_diff`, the LHS–RHS difference collapses to a **fixed positive constant** (independent of the size of the subterms), because the subterm sizes on both sides match up one‑for‑one. E.g. for `R_eq_diff`:

- `mu1`: `(3+a+b) - (1+(1+a+b)) = 1 > 0`
- `mu2`: `(5+a+b) - (2+(2+a+b)) = 1 > 0`
- `mu3`: `(4+a+b) - (2+(1+a+b)) = 1 > 0`

and similarly for the others. So all three measures pass all rules **except one**.

## The fatal rule: `R_rec_succ`

```
Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

Here `s` occurs **twice** on the right (once directly, once inside the recursive call), but only once on the left. For any measure of the additive shape

```
mu (delta t)          = A + mu t
mu (app a b)          = B + mu a + mu b
mu (recDelta b s n)   = C + mu b + mu s + mu n
```

a direct computation gives

```
mu (recDelta b s (delta n))          = C + A + mu b + mu s + mu n
mu (app s (recDelta b s n))          = B + C + mu b + 2·mu s + mu n
```

so

```
LHS - RHS = A - B - mu s.
```

This is exactly the pattern behind all three candidates:

| candidate | A (delta) | B (app) | `LHS - RHS` |
|---|---|---|---|
| `mu1` | 1 | 1 | `-mu1 s` |
| `mu2` | 1 | 1 | `-mu2 s` |
| `mu3` | 1 | 2 | `-1 - mu3 s` |

**None of these is ever positive.**

- For `mu1`/`mu2`: the difference is `≤ 0`, with equality only when `s = void`. So the required strict decrease **never holds** — it's a tie when `s` is trivial and an actual *increase* whenever `mu(s) > 0`.
- For `mu3`: the difference is `-1 - mu3 s < 0` **unconditionally**, so `mu3` strictly *increases* on every instance of this rule, even when `s = void`.

### Concrete witnesses

Take `b = void`, `s = delta void`, `n = void`:

- `mu1`: source `recDelta(void, delta void, delta void) = 3`, target `app(delta void, recDelta(void, delta void, void)) = 4`. **3 < 4** (increase).
- `mu2`: source `= 7`, target `= 8`. **7 < 8** (increase).
- `mu3`: source `= 3`, target `= 5`. **3 < 5** (larger increase).

Even with `s = void`, `b = void`, `n = void`:

- `mu1`: source `= 2`, target `= 2` (tie, no strict decrease).
- `mu2`: source `= 6`, target `= 6` (tie).
- `mu3`: source `= 2`, target `= 3` (still increases).

## Verdict

- **`mu1`**: Fails as a termination measure. It correctly decreases on all rules except `R_rec_succ`, where it is non‑increasing (constant or strictly increasing depending on `s`). Never strictly decreasing there.
- **`mu2`**: Same defect as `mu1` (identical `A - B = 0` imbalance); merely rescaled constants elsewhere, no structural fix.
- **`mu3`**: Also fails, and worse than the other two: on `R_rec_succ` it *strictly increases* the measure in **every** instance (no tie case at all), since its `app`-constant `B=2` exceeds the `delta`-constant `A=1` by more than the others.

All three fail for the same structural reason: they are simple **additive (subterm-linear)** measures, each subterm contributing its size exactly once with fixed weights. The rule `R_rec_succ` duplicates the occurrence of `s` on the reduct side, so any such linear measure necessarily assigns `s` a total weight of 2 on the target vs. 1 on the source, making a genuine decrease impossible for unbounded `s`, and even producing a tie/increase for small `s` because the constants can't compensate a variable-dependent deficit.

**Conclusion:** none of `mu1`, `mu2`, `mu3` is a valid termination measure for this `Step` relation. To fix this, one needs a measure that is *not* linear in `s` for the `recDelta`/`app` pair — e.g. something like `mu(recDelta b s n) := mu(b) + (mu(n)+1) * (mu(s)+k)` (multiplicative in `s` and `n`) or a lexicographic measure that decreases primarily on `n` while treating `s` as a fixed "parameter" not recounted at each unfolding.
