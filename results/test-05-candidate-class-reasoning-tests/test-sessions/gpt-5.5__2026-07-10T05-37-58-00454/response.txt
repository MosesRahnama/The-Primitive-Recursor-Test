All three candidates fail as strict termination measures for `Step`.

For a measure `mu` into `Nat` to prove termination directly, every rewrite

```lean
Step lhs rhs
```

would need to satisfy:

```lean
mu rhs < mu lhs
```

Most rules decrease for all three measures, but the problematic rule is:

```lean
R_rec_succ :
  Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

## `mu1`

Compute:

```lean
mu1 (recDelta b s (delta n))
= 1 + mu1 b + mu1 s + mu1 (delta n)
= 2 + mu1 b + mu1 s + mu1 n
```

and

```lean
mu1 (app s (recDelta b s n))
= 1 + mu1 s + mu1 (recDelta b s n)
= 1 + mu1 s + (1 + mu1 b + mu1 s + mu1 n)
= 2 + mu1 b + 2 * mu1 s + mu1 n
```

So the right-hand side exceeds the left-hand side by `mu1 s`.

- If `s = void`, the measure is unchanged.
- If `s` is non-void, the measure increases.

Example with `b = void`, `s = void`, `n = void`:

```lean
mu1 (recDelta void void (delta void)) = 2
mu1 (app void (recDelta void void void)) = 2
```

So `mu1` is not a strict decreasing measure.

## `mu2`

Similarly:

```lean
mu2 (recDelta b s (delta n))
= 5 + mu2 b + mu2 s + (1 + mu2 n)
= 6 + mu2 b + mu2 s + mu2 n
```

and

```lean
mu2 (app s (recDelta b s n))
= 1 + mu2 s + (5 + mu2 b + mu2 s + mu2 n)
= 6 + mu2 b + 2 * mu2 s + mu2 n
```

Again, the right-hand side exceeds the left-hand side by `mu2 s`.

Example with `b = void`, `s = void`, `n = void`:

```lean
mu2 (recDelta void void (delta void)) = 6
mu2 (app void (recDelta void void void)) = 6
```

So `mu2` is also not a strict decreasing measure.

## `mu3`

For `mu3`:

```lean
mu3 (recDelta b s (delta n))
= 1 + mu3 b + mu3 s + (1 + mu3 n)
= 2 + mu3 b + mu3 s + mu3 n
```

while

```lean
mu3 (app s (recDelta b s n))
= 2 + mu3 s + (1 + mu3 b + mu3 s + mu3 n)
= 3 + mu3 b + 2 * mu3 s + mu3 n
```

The right-hand side exceeds the left-hand side by:

```lean
1 + mu3 s
```

So `mu3` strictly increases on `R_rec_succ`, even when `s = void`.

Example:

```lean
mu3 (recDelta void void (delta void)) = 2
mu3 (app void (recDelta void void void)) = 3
```

Thus `mu3` is not a termination measure either.

## Summary

| Measure | Valid strict decreasing measure? | Failing rule |
|---|---:|---|
| `mu1` | No | `R_rec_succ` |
| `mu2` | No | `R_rec_succ` |
| `mu3` | No | `R_rec_succ` |

The other rewrite rules appear to decrease under these measures, but because `R_rec_succ` does not, none of `mu1`, `mu2`, or `mu3` proves termination of `Step` by simple descent into `Nat`.
