All three proposed measures **fail** as strict termination measures for `Step`.

A valid Nat-valued termination measure `mu` would need:

```lean
Step x y → mu y < mu x
```

for every rewrite rule. Most rules decrease for all three candidates, but the rule

```lean
R_rec_succ :
  Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

is problematic.

## `mu1`

For `R_rec_succ`:

```lean
mu1 (recDelta b s (delta n))
= 1 + mu1 b + mu1 s + (1 + mu1 n)
= 2 + mu1 b + mu1 s + mu1 n
```

while

```lean
mu1 (app s (recDelta b s n))
= 1 + mu1 s + (1 + mu1 b + mu1 s + mu1 n)
= 2 + mu1 b + 2 * mu1 s + mu1 n
```

So the right-hand side is larger by `mu1 s`.

- If `s = void`, the measure is unchanged.
- If `s ≠ void`, the measure increases.

Example with `b = s = n = void`:

```lean
mu1 (recDelta void void (delta void)) = 2
mu1 (app void (recDelta void void void)) = 2
```

So `mu1` is not strictly decreasing.

## `mu2`

The same issue occurs.

```lean
mu2 (recDelta b s (delta n))
= 5 + mu2 b + mu2 s + (1 + mu2 n)
= 6 + mu2 b + mu2 s + mu2 n
```

and

```lean
mu2 (app s (recDelta b s n))
= 1 + mu2 s + (5 + mu2 b + mu2 s + mu2 n)
= 6 + mu2 b + 2 * mu2 s + mu2 n
```

Again, the right-hand side is larger by `mu2 s`.

Example:

```lean
mu2 (recDelta void void (delta void)) = 6
mu2 (app void (recDelta void void void)) = 6
```

So `mu2` is also not strictly decreasing.

## `mu3`

For `mu3` the failure is even stronger.

```lean
mu3 (recDelta b s (delta n))
= 1 + mu3 b + mu3 s + (1 + mu3 n)
= 2 + mu3 b + mu3 s + mu3 n
```

but

```lean
mu3 (app s (recDelta b s n))
= 2 + mu3 s + (1 + mu3 b + mu3 s + mu3 n)
= 3 + mu3 b + 2 * mu3 s + mu3 n
```

The right-hand side exceeds the left-hand side by `1 + mu3 s`, so it always increases.

Example:

```lean
mu3 (recDelta void void (delta void)) = 2
mu3 (app void (recDelta void void void)) = 3
```

So `mu3` is not a termination measure either.

## Other rules

The other rewrite rules do decrease under all three measures. In particular, the `eqW` case was weighted high enough:

```lean
eqW a b ↦ integrate (merge a b)
```

For example:

- `mu1`: `3 + A + B > 1 + (1 + A + B)`
- `mu2`: `5 + A + B > 2 + (2 + A + B)`
- `mu3`: `4 + A + B > 2 + (1 + A + B)`

So the only obstruction is `R_rec_succ`.

## Verdict

| Measure | Valid termination measure? | Reason |
|---|---:|---|
| `mu1` | No | `R_rec_succ` is non-decreasing / increasing |
| `mu2` | No | `R_rec_succ` is non-decreasing / increasing |
| `mu3` | No | `R_rec_succ` strictly increases |

Therefore, **none of the three candidates establishes termination of `Step` by strict decrease into `Nat`**.
