# Assessment of Termination Measures

I need to check whether each measure strictly decreases on every `Step` rule.

## Rule Analysis

For each measure `μ` and rule `Step L R`, I compute `μ(L) − μ(R)` and verify it is **strictly positive** for *every* instance.

The rules are:
1. `R_int_delta`: `integrate (delta t) → void`
2. `R_merge_void_left`: `merge void t → t`
3. `R_merge_void_right`: `merge t void → t`
4. `R_merge_cancel`: `merge t t → t`
5. `R_rec_zero`: `recDelta b s void → b`
6. `R_rec_succ`: `recDelta b s (delta n) → app s (recDelta b s n)`
7. `R_eq_refl`: `eqW a a → void`
8. `R_eq_diff`: `eqW a b → integrate (merge a b)`

## μ₁

| Rule | μ₁(L) | μ₁(R) | Δ |
|------|-------|-------|---|
| 1 | 2+μ₁(t) | 0 | ≥2 ✓ |
| 2 | 1+μ₁(t) | μ₁(t) | 1 ✓ |
| 3 | 1+μ₁(t) | μ₁(t) | 1 ✓ |
| 4 | 1+2μ₁(t) | μ₁(t) | 1+μ₁(t) ✓ |
| 5 | 1+μ₁(b)+μ₁(s) | μ₁(b) | 1+μ₁(s) ≥ 1 ✓ |
| 6 | 2+μ₁(b)+μ₁(s)+μ₁(n) | 2+μ₁(b)+2μ₁(s)+μ₁(n) | **−μ₁(s)** |
| 7 | 3+2μ₁(a) | 0 | ≥3 ✓ |
| 8 | 3+μ₁(a)+μ₁(b) | 3+μ₁(a)+μ₁(b) | **0** |

**μ₁ fails**:
- **Rule 6**: counterexample `s = void` gives LHS = RHS = 2 (taking `b = n = void`).
- **Rule 8**: with `merge` and `integrate` both adding 1, the LHS and RHS have identical cost — non-strict.

## μ₂

| Rule | μ₂(L) | μ₂(R) | Δ |
|------|-------|-------|---|
| 1 | 3+μ₂(t) | 0 | ≥3 ✓ |
| 2 | 2+μ₂(t) | μ₂(t) | 2 ✓ |
| 3 | 2+μ₂(t) | μ₂(t) | 2 ✓ |
| 4 | 2+2μ₂(t) | μ₂(t) | 2+μ₂(t) ✓ |
| 5 | 5+μ₂(b)+μ₂(s) | μ₂(b) | 5+μ₂(s) ≥ 5 ✓ |
| 6 | 6+μ₂(b)+μ₂(s)+μ₂(n) | 6+μ₂(b)+2μ₂(s)+μ₂(n) | **−μ₂(s)** |
| 7 | 5+2μ₂(a) | 0 | ≥5 ✓ |
| 8 | 5+μ₂(a)+μ₂(b) | 4+2μ₂(a)+2μ₂(b) | 1−μ₂(a)−μ₂(b) |

**μ₂ fails**:
- **Rule 6**: with `s = void`, μ₂(LHS) = μ₂(RHS) (e.g., `b = n = void` gives 6 on both sides).
- **Rule 8**: with `a = b = void`, μ₂(LHS) = 5 but μ₂(RHS) = 4, so the measure **increases** by 1.

## μ₃

| Rule | μ₃(L) | μ₃(R) | Δ |
|------|-------|-------|---|
| 1 | 3+μ₃(t) | 0 | ≥3 ✓ |
| 2 | 1+μ₃(t) | μ₃(t) | 1 ✓ |
| 3 | 1+μ₃(t) | μ₃(t) | 1 ✓ |
| 4 | 1+2μ₃(t) | μ₃(t) | 1+μ₃(t) ≥ 1 ✓ |
| 5 | 1+μ₃(b)+μ₃(s) | μ₃(b) | 1+μ₃(s) ≥ 1 ✓ |
| 6 | 2+μ₃(b)+μ₃(s)+μ₃(n) | 3+μ₃(b)+2μ₃(s)+μ₃(n) | 1+μ₃(s) ≥ 1 ✓ |
| 7 | 4+2μ₃(a) | 0 | ≥4 ✓ |
| 8 | 4+μ₃(a)+μ₃(b) | 3+μ₃(a)+μ₃(b) | **1** ✓ |

**μ₃ works** for every rule: the difference is always at least 1, regardless of subterm choice. The key engineering choices are:
- `merge` contributes 1 (so the void/cancel rules strictly drop it), `integrate` contributes 2 (so `eqW` strictly beats `integrate (merge _ _)`), and `app` contributes 2 (so `recDelta` at weight 1 cannot be "absorbed" by the app wrapper in `R_rec_succ`).

## Verdict

| Measure | Status |
|---------|--------|
| **μ₁** | ❌ **Not** a termination measure. Fails on `R_rec_succ` (e.g. `s = void`) and ties on `R_eq_diff`. |
| **μ₂** | ❌ **Not** a termination measure. Fails on `R_rec_succ` (e.g. `s = void`) and on `R_eq_diff` where it actually *increases* (e.g. `a = b = void`). |
| **μ₃** | ✅ **Valid** termination measure. Strictly decreases on all eight rules. |
