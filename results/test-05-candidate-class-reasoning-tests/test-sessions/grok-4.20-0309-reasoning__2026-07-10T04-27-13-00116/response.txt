**Assessment of termination candidates**

None of the three measures (mu1, mu2, mu3) are valid termination measures. All three pass the first seven Step rules (R_int_delta, the three merge rules, R_rec_zero, R_eq_refl, R_eq_diff) with a strictly positive difference. They all fail on R_rec_succ.

**Failure on R_rec_succ**

```
Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

Let b̂ = mu(b), ŝ = mu(s), n̂ = mu(n). All three mu definitions are linear (constant plus sum of immediate subterm measures), with coefficients:

- mu1: c_delta=1, c_app=1, c_rec=1 → left = 2+b̂+ŝ+n̂, right = 2+b̂+2ŝ+n̂, difference = -ŝ ≤ 0
- mu2: c_delta=1, c_app=1, c_rec=5 → left = 6+b̂+ŝ+n̂, right = 6+b̂+2ŝ+n̂, difference = -ŝ ≤ 0
- mu3: c_delta=1, c_app=2, c_rec=1 → left = 2+b̂+ŝ+n̂, right = 3+b̂+2ŝ+n̂, difference = -1-ŝ < 0

In every case the Nat measure on the left is not strictly larger than on the right (it is equal only for mu(s)=0 and strictly smaller otherwise). Because the successor rule duplicates the "step" argument s, any linear additive measure of this shape produces a negative coefficient on ŝ in the difference and therefore cannot decrease for arbitrary s.

The constants chosen for integrate/merge/eqW/recDelta only affect the other seven rules; they cancel out in the R_rec_succ difference, so raising the recDelta constant (as mu2 attempts) does not help.

**Consequence**

No well-founded order on Nat can be obtained from any of these mu definitions. A more complex measure (e.g., a multiset order, a lexicographic combination that weights the number of recDelta constructors separately from the duplicated s, or a path-order-like comparison) would be required to prove termination of the given rewrite system.

**Summary**

- mu1: fails R_rec_succ (difference = -mu(s))
- mu2: fails R_rec_succ (difference = -mu(s))
- mu3: fails R_rec_succ (difference = -1-mu(s))

All candidates are rejected.
