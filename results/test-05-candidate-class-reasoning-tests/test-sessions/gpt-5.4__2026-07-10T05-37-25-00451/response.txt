Here’s the audit of the three proposed measures as termination measures for the one-step rewrite relation `Step`.

A valid candidate should strictly decrease on every rewrite rule:
if `Step t u`, then `μ u < μ t`.

---

## Rule-by-rule check

The rewrite rules are:

1. `integrate (delta t) -> void`
2. `merge void t -> t`
3. `merge t void -> t`
4. `merge t t -> t`
5. `recDelta b s void -> b`
6. `recDelta b s (delta n) -> app s (recDelta b s n)`
7. `eqW a a -> void`
8. `eqW a b -> integrate (merge a b)`

---

# Candidate `mu1`

```lean
def mu1 : Trace -> Nat
| .void => 0
| .delta t => 1 + mu1 t
| .integrate t => 1 + mu1 t
| .merge a b => 1 + mu1 a + mu1 b
| .app a b => 1 + mu1 a + mu1 b
| .recDelta b s n => 1 + mu1 b + mu1 s + mu1 n
| .eqW a b => 3 + mu1 a + mu1 b
```

## Checks

- `integrate (delta t)`:
  - LHS = `1 + (1 + mu1 t) = 2 + mu1 t`
  - RHS = `0`
  - decreases

- `merge void t -> t`:
  - LHS = `1 + 0 + mu1 t = 1 + mu1 t`
  - RHS = `mu1 t`
  - decreases

- `merge t void -> t`: same, decreases

- `merge t t -> t`:
  - LHS = `1 + 2 * mu1 t`
  - RHS = `mu1 t`
  - decreases

- `recDelta b s void -> b`:
  - LHS = `1 + mu1 b + mu1 s`
  - RHS = `mu1 b`
  - decreases

- `recDelta b s (delta n) -> app s (recDelta b s n)`:
  - LHS = `1 + mu1 b + mu1 s + (1 + mu1 n) = 2 + mu1 b + mu1 s + mu1 n`
  - RHS = `1 + mu1 s + (1 + mu1 b + mu1 s + mu1 n)`
    = `2 + mu1 b + 2*mu1 s + mu1 n`

This is **not** smaller in general. In fact RHS exceeds LHS by `mu1 s`.

- If `s = void`, they are equal.
- If `mu1 s > 0`, RHS is larger.

So `mu1` fails on `R_rec_succ`.

- `eqW a a -> void`:
  - LHS = `3 + 2 * mu1 a`
  - RHS = `0`
  - decreases

- `eqW a b -> integrate (merge a b)`:
  - LHS = `3 + mu1 a + mu1 b`
  - RHS = `1 + (1 + mu1 a + mu1 b) = 2 + mu1 a + mu1 b`
  - decreases by 1

## Verdict on `mu1`
**Invalid termination measure.**  
Fails because `R_rec_succ` is not strictly decreasing.

# Overall conclusion

All three candidates are **invalid** as global termination measures for `Step`.

The common problem is the recursive-step rule:

```lean
recDelta b s (delta n) -> app s (recDelta b s n)
```

Any additive size measure of the form used here counts the occurrence of `s`:

- once on the left, inside `recDelta b s (delta n)`
- twice on the right, once as the function in `app s ...` and once still inside `recDelta b s n`

So the right-hand side is not smaller; it is equal or larger.
