**Assessment of the Three Termination Measures**

All three candidates (`mu1`, `mu2`, `mu3`) fail to be valid termination measures for the given rewrite system. While they successfully decrease for most rewrite rules, **all three fail on the rule `R_rec_succ`**, which unrolls a recursive call. Here is the detailed breakdown:

### The Critical Failure: `R_rec_succ`

The rule is:
```
recDelta b s (delta n)  →  app s (recDelta b s n)
```

In this step, the argument `s` (the "step" term) is duplicated: it appears once on the left-hand side (inside `recDelta`) but twice on the right-hand side (once as the first argument to `app`, and once inside the nested `recDelta`). 

For a measure `mu` to decrease, we would need:
```
mu(recDelta b s (delta n))  >  mu(app s (recDelta b s n))
```

However, with the additive structure of all three measures, the right-hand side accumulates `mu(s)` twice while the left-hand side accumulates it only once. The constants in the definitions are insufficient to compensate for this duplication.

#### Detailed calculation for each measure:

Let `mu(s)` denote the measure of `s`, `mu(b)` for `b`, and `mu(n)` for `n`.

**For `mu1`:**
- LHS: `mu1(recDelta b s (delta n))` = `1 + mu1(b) + mu1(s) + (1 + mu1(n))` = `2 + mu1(b) + mu1(s) + mu1(n)`
- RHS: `mu1(app s (recDelta b s n))` = `1 + mu1(s) + (1 + mu1(b) + mu1(s) + mu1(n))` = `2 + mu1(b) + 2*mu1(s) + mu1(n)`
- **Result:** LHS − RHS = `−mu1(s)`. 
  - If `s` is `void`, LHS = RHS (no decrease).
  - If `s` is non-void, RHS > LHS (measure increases).

**For `mu2`:**
- LHS: `5 + mu2(b) + mu2(s) + (1 + mu2(n))` = `6 + mu2(b) + mu2(s) + mu2(n)`
- RHS: `1 + mu2(s) + (5 + mu2(b) + mu2(s) + mu2(n))` = `6 + mu2(b) + 2*mu2(s) + mu2(n)`
- **Result:** LHS − RHS = `−mu2(s)`.
  - If `s` is `void`, LHS = RHS (no decrease).
  - If `s` is non-void, RHS > LHS (measure increases).

**For `mu3`:**
- LHS: `1 + mu3(b) + mu3(s) + (1 + mu3(n))` = `2 + mu3(b) + mu3(s) + mu3(n)`
- RHS: `2 + mu3(s) + (1 + mu3(b) + mu3(s) + mu3(n))` = `3 + mu3(b) + 2*mu3(s) + mu3(n)`
- **Result:** LHS − RHS = `−1 − mu3(s)` < 0 **always**.
  - The measure strictly increases for any `s`, including `void`.

### Summary of Other Rules

For completeness, all three measures correctly decrease (or are undefined for) the other rules:
- **`R_int_delta`**, **`R_merge_*`**, **`R_rec_zero`**, **`R_eq_refl`**, **`R_eq_diff`**: All satisfy `mu(LHS) > mu(RHS)` with the given constants.
- The constants in `mu2` and `mu3` for `integrate`, `merge`, `eqW`, and `recDelta` are larger than in `mu1`, but this does not resolve the duplication issue in `R_rec_succ`.

### Conclusion

**None of the three candidates are valid termination measures.** The fundamental issue is that `R_rec_succ` duplicates the subterm `s`, and additive measures with positive coefficients cannot decrease when a subterm is copied. To handle this rule, a measure would need to either:
- Assign a coefficient of at least 2 to `mu(s)` in the LHS (i.e., weight `recDelta` such that `s` counts double), or
- Use a non-linear measure or lexicographic ordering that strictly distinguishes the recursive structure in a way that overcomes the duplication.

As written, `mu1` and `mu2` fail to strictly decrease when `s = void` (they remain equal), while `mu3` strictly increases in all cases for `R_rec_succ`.
