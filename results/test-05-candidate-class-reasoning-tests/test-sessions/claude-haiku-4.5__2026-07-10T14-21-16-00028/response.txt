# Assessment of Termination Measures

I'll analyze each measure by checking critical rewrite rules to see if the measure strictly decreases.

## Critical Rules to Check

The most problematic rules are:
- **R_rec_succ**: `recDelta b s (delta n)` → `app s (recDelta b s n)`
- **R_eq_diff**: `eqW a b` → `integrate (merge a b)`

These introduce new structure that could potentially increase the measure.

---

## mu1 Analysis

**R_rec_succ**: `recDelta b s (delta n)` → `app s (recDelta b s n)`
- LHS: `1 + mu1 b + mu1 s + mu1(delta n)` = `1 + mu1 b + mu1 s + 1 + mu1 n` = `2 + mu1 b + mu1 s + mu1 n`
- RHS: `1 + mu1 s + (1 + mu1 b + mu1 s + mu1 n)` = `2 + mu1 b + 2·mu1 s + mu1 n`

❌ **FAILS**: RHS > LHS when `mu1 s > 0`

---

## mu2 Analysis

**R_rec_succ**: `recDelta b s (delta n)` → `app s (recDelta b s n)`
- LHS: `5 + mu2 b + mu2 s + 1 + mu2 n` = `6 + mu2 b + mu2 s + mu2 n`
- RHS: `1 + mu2 s + (5 + mu2 b + mu2 s + mu2 n)` = `6 + mu2 b + 2·mu2 s + mu2 n`

❌ **FAILS**: RHS > LHS when `mu2 s > 0`

---

## mu3 Analysis

**R_rec_succ**: `recDelta b s (delta n)` → `app s (recDelta b s n)`
- LHS: `1 + mu3 b + mu3 s + 1 + mu3 n` = `2 + mu3 b + mu3 s + mu3 n`
- RHS: `2 + mu3 s + (1 + mu3 b + mu3 s + mu3 n)` = `3 + mu3 b + 2·mu3 s + mu3 n`

❌ **FAILS**: RHS > LHS when `mu3 s > 0`

---

## Conclusion

**All three candidates fail as termination measures.** The fundamental issue is that all three assign the same relative weights to `recDelta` and `app`, which is insufficient to handle the R_rec_succ rule. This rule requires that the cost of applying `s` be offset by a decrease in the argument structure, which none of these measures achieve.

To succeed, a measure would need either:
1. Much higher weight on `recDelta` relative to `app`, or
2. A lexicographic approach combining structural depth with weighted costs
