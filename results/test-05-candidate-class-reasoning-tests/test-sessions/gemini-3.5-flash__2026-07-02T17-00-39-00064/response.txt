To assess the three proposed termination measures ($\mu_1$, $\mu_2$, and $\mu_3$), we must check whether they strictly decrease for every possible transition in the rewrite relation `Step`. 

That is, a candidate $\mu$ is a valid termination measure if and only if:
$$\forall t_1\ t_2 : \text{Trace},\quad \text{Step}\ t_1\ t_2 \implies \mu(t_1) > \mu(t_2)$$

Since `Step` is defined by 8 non-recursive rewrite rules (with no congruence rules), we only need to verify this inequality for each of the 8 rules.

---

### Executive Summary

**None of the three candidates ($\mu_1$, $\mu_2$, or $\mu_3$) are valid termination measures.** 

While all three candidates successfully satisfy 7 out of the 8 rewrite rules, **they all fail on the recursive step rule `R_rec_succ`**:
$$\text{Step}\ (\text{recDelta}\ b\ s\ (\text{delta}\ n))\ (\text{app}\ s\ (\text{recDelta}\ b\ s\ n))$$

Below is a detailed assessment of each candidate.

---

### Detailed Analysis of `R_rec_succ`

The rule is:
$$\text{recDelta}\ b\ s\ (\text{delta}\ n) \implies \text{app}\ s\ (\text{recDelta}\ b\ s\ n)$$

#### 1. Candidate $\mu_1$
For $\mu_1$, the values of the LHS and RHS are:
*   $\mu_1(\text{LHS}) = 1 + \mu_1(b) + \mu_1(s) + \mu_1(\text{delta}\ n) = 2 + \mu_1(b) + \mu_1(s) + \mu_1(n)$
*   $\mu_1(\text{RHS}) = 1 + \mu_1(s) + \mu_1(\text{recDelta}\ b\ s\ n) = 2 + \mu_1(b) + 2\mu_1(s) + \mu_1(n)$

Comparing them:
*   $\mu_1(\text{LHS}) > \mu_1(\text{RHS}) \iff 2 + \mu_1(b) + \mu_1(s) + \mu_1(n) > 2 + \mu_1(b) + 2\mu_1(s) + \mu_1(n)$
*   This simplifies to $0 > \mu_1(s)$, which is **always false** since $\mu_1(s) \ge 0$.
*   **Concrete Counterexample:** Let $b = \text{void}$, $s = \text{void}$, and $n = \text{void}$.
    $$\mu_1(\text{recDelta void void (delta void)}) = 2$$
    $$\mu_1(\text{app void (recDelta void void void)}) = 2$$
    Since $2 \ngtr 2$, $\mu_1$ is invalid.

#### 2. Candidate $\mu_2$
For $\mu_2$, the values of the LHS and RHS are:
*   $\mu_2(\text{LHS}) = 5 + \mu_2(b) + \mu_2(s) + \mu_2(\text{delta}\ n) = 6 + \mu_2(b) + \mu_2(s) + \mu_2(n)$
*   $\mu_2(\text{RHS}) = 1 + \mu_2(s) + \mu_2(\text{recDelta}\ b\ s\ n) = 6 + \mu_2(b) + 2\mu_2(s) + \mu_2(n)$

Comparing them:
*   This simplifies to $0 > \mu_2(s)$, which is **always false**.
*   **Concrete Counterexample:** Let $b = \text{void}$, $s = \text{void}$, and $n = \text{void}$.
    $$\mu_2(\text{recDelta void void (delta void)}) = 6$$
    $$\mu_2(\text{app void (recDelta void void void)}) = 6$$
    Since $6 \ngtr 6$, $\mu_2$ is invalid.

#### 3. Candidate $\mu_3$
For $\mu_3$, the values of the LHS and RHS are:
*   $\mu_3(\text{LHS}) = 1 + \mu_3(b) + \mu_3(s) + \mu_3(\text{delta}\ n) = 2 + \mu_3(b) + \mu_3(s) + \mu_3(n)$
*   $\mu_3(\text{RHS}) = 2 + \mu_3(s) + \mu_3(\text{recDelta}\ b\ s\ n) = 3 + \mu_3(b) + 2\mu_3(s) + \mu_3(n)$

Comparing them:
*   This simplifies to $0 > 1 + \mu_3(s)$, which is **always false**.
*   **Concrete Counterexample:** Let $b = \text{void}$, $s = \text{void}$, and $n = \text{void}$.
    $$\mu_3(\text{recDelta void void (delta void)}) = 2$$
    $$\mu_3(\text{app void (recDelta void void void)}) = 3$$
    Here, the measure actually *increases* ($2 < 3$). Thus, $\mu_3$ is invalid.

### Why the Candidates Fail (Structural Reason)

In the rule `R_rec_succ`, the parameter $s$ is embedded inside the recursive instantiation of `recDelta` on the RHS, but is *also* pulled out as a direct child of the outer `app` constructor:
$$\text{recDelta}\ b\ s\ (\text{delta}\ n) \implies \text{app}\ \mathbf{s}\ (\text{recDelta}\ b\ \mathbf{s}\ n)$$

Any standard linear additive size measure $\mu$ where:
*   $\mu(\text{recDelta}\ b\ s\ n) = C_{\text{rec}} + c_b\mu(b) + c_s\mu(s) + c_n\mu(n)$
*   $\mu(\text{app}\ x\ y) = C_{\text{app}} + c_x\mu(x) + c_y\mu(y)$

will yield a coefficient for $\mu(s)$ on the RHS of at least $c_x + c_y \cdot c_s$. For a strictly decreasing measure, we require the LHS coefficient to be strictly greater than or equal to the RHS coefficient of any unbound subterm, meaning:
$$c_s \ge c_x + c_y \cdot c_s$$

Since all coefficients are natural numbers and $c_y \ge 1$ (as the recursive call must be weighted), this forces $c_x = 0$, meaning `app` cannot weight its left child $s$ at all. In all three proposed candidates, $c_x \ge 1$, which is why they all fail.
