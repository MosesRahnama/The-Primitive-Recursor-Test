None of the three candidates is a valid strict termination measure for `Step`. The problematic rule is always `R_rec_succ`.

Let \(m_s = \mu_i(s)\). The strict-decrease differences for that rule are:

| Measure | \(\mu_i(\text{LHS})-\mu_i(\text{RHS})\) |
|---|---:|
| `mu1` | \(-m_s\) |
| `mu2` | \(-m_s\) |
| `mu3` | \(-(1+m_s)\) |

Thus:

- `mu1` and `mu2` are unchanged when `s = void`, and increase when `s` has positive measure.
- `mu3` always increases.

A common concrete counterexample is:
```lean
Step
  (recDelta void void (delta void))
  (app void (recDelta void void void))
```

Its measures are:

| Measure | Source | Target |
|---|---:|---:|
| `mu1` | 2 | 2 |
| `mu2` | 6 | 6 |
| `mu3` | 2 | 3 |

So strict decrease fails for all three.

All other rewrite rules strictly decrease under each candidate. In particular, for `R_eq_diff`, the decreases are exactly one:
- `mu1`: `3 + μ(a) + μ(b)` to `2 + μ(a) + μ(b)`
- `mu2`: `5 + μ(a) + μ(b)` to `4 + μ(a) + μ(b)`
- `mu3`: `4 + μ(a) + μ(b)` to `3 + μ(a) + μ(b)`

The underlying issue is that `R_rec_succ` duplicates `s`:
```text
recDelta b s (delta n)
  ↦ app s (recDelta b s n)
```
Any simple additive size assigning positive cost to `s` must account for an extra copy on the right. Therefore:

- **`mu1`: invalid**
- **`mu2`: invalid**
- **`mu3`: invalid**

This only shows that these proposed measures do not prove termination; it does not by itself show that `Step` is nonterminating.
