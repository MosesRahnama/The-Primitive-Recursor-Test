All three candidates fail to be valid termination measures because they do not strictly decrease on the rule `R_rec_succ`.

**Rule under consideration**  
`R_rec_succ : forall b s n, Step (recDelta b s (delta n)) (app s (recDelta b s n))`

For a measure `mu` to work, we must have  
`mu (app s (recDelta b s n)) < mu (recDelta b s (delta n))` for all `b, s, n`.

**Analysis**

- **mu1**  
  Source: `1 + mu1 b + mu1 s + (1 + mu1 n) = 2 + mu1 b + mu1 s + mu1 n`  
  Result: `1 + mu1 s + (1 + mu1 b + mu1 s + mu1 n) = 2 + mu1 b + 2·mu1 s + mu1 n`  
  Comparison requires `2·mu1 s < mu1 s`, impossible for `mu1 s ≥ 0`.

- **mu2**  
  Source: `5 + mu2 b + mu2 s + (1 + mu2 n) = 6 + mu2 b + mu2 s + mu2 n`  
  Result: `1 + mu2 s + (5 + mu2 b + mu2 s + mu2 n) = 6 + mu2 b + 2·mu2 s + mu2 n`  
  Comparison again requires `2·mu2 s < mu2 s`, impossible.

- **mu3**  
  Source: `1 + mu3 b + mu3 s + (1 + mu3 n) = 2 + mu3 b + mu3 s + mu3 n`  
  Result: `2 + mu3 s + (1 + mu3 b + mu3 s + mu3 n) = 3 + mu3 b + 2·mu3 s + mu3 n`  
  Comparison requires `1 + 2·mu3 s < mu3 s`, i.e. `1 + mu3 s < 0`, impossible.

All other rules are strictly decreasing for each measure, but the failure on `R_rec_succ` renders every candidate invalid as a termination measure for the whole rewrite system.
