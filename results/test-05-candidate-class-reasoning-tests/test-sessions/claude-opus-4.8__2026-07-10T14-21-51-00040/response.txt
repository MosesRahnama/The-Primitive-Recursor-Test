# Assessment of the Three Termination Measures

I'll check each measure against all 8 rewrite rules, requiring **strict decrease** (μ(lhs) > μ(rhs)) for a valid termination measure.

## The 8 rules and their LHS/RHS structure

1. `R_int_delta`: `integrate (delta t)` → `void`
2. `R_merge_void_left`: `merge void t` → `t`
3. `R_merge_void_right`: `merge t void` → `t`
4. `R_merge_cancel`: `merge t t` → `t`
5. `R_rec_zero`: `recDelta b s void` → `b`
6. `R_rec_succ`: `recDelta b s (delta n)` → `app s (recDelta b s n)`
7. `R_eq_refl`: `eqW a a` → `void`
8. `R_eq_diff`: `eqW a b` → `integrate (merge a b)`

The critical rules are **R_rec_succ** and **R_eq_diff**, since these can *grow* the term.

---

## μ1

- R1: `2 + mu1 t` > `0` ✓
- R2: `1 + mu1 t` > `mu1 t` ✓
- R3: `1 + mu1 t` > `mu1 t` ✓
- R4: `1 + 2·mu1 t` > `mu1 t` ✓
- R5: `1 + mu1 b + mu1 s` > `mu1 b` ✓
- R6: LHS `= 1 + b + s + (1 + n) = 2 + b + s + n`; RHS `app s (recDelta b s n) = 1 + s + (1 + b + s + n) = 2 + b + 2s + n`. Need `2+b+s+n > 2+b+2s+n`, i.e. `0 > s`. **FAILS** (when `s>0`).
- R8: LHS `= 3 + a + b`; RHS `integrate(merge a b) = 1 + (1 + a + b) = 2 + a + b`. `3+a+b > 2+a+b` ✓

**μ1 is INVALID** — fails on R_rec_succ (the copy of `s` in `app` isn't compensated).

---

## μ2

- R1: `3 + mu2 t` > `0` ✓
- R2: `2 + mu2 t` > `mu2 t` ✓
- R3: `2 + mu2 t` > `mu2 t` ✓
- R4: `2 + 2·mu2 t` > `mu2 t` ✓
- R5: `5 + b + s + n` > `b` ✓
- R6: LHS `= 5 + b + s + (1 + n) = 6 + b + s + n`; RHS `= 1 + s + (5 + b + s + n) = 6 + b + 2s + n`. Need `6+b+s+n > 6+b+2s+n` → `0 > s`. **FAILS**.
- R7: `5 + 2a` > `0` ✓
- R8: LHS `= 5 + a + b`; RHS `integrate(merge a b) = 2 + (2 + a + b) = 4 + a + b`. `5+a+b > 4+a+b` ✓

**μ2 is INVALID** — same failure on R_rec_succ. Increasing constants doesn't help because the extra `s` term scales with the (unbounded) size of `s`.

---

## μ3

- R1: `integrate(delta t) = 2 + (1 + mu3 t) = 3 + mu3 t` > `0` ✓
- R2: `merge void t = 1 + 0 + mu3 t = 1 + mu3 t` > `mu3 t` ✓
- R3: `1 + mu3 t` > `mu3 t` ✓
- R4: `merge t t = 1 + 2·mu3 t` > `mu3 t` ✓
- R5: `1 + b + s + 0` > `b` ✓ (`1 + b + s > b`)
- R6: LHS `= 1 + b + s + (1 + n) = 2 + b + s + n`; RHS `app s (recDelta b s n) = 2 + s + (1 + b + s + n) = 3 + b + 2s + n`. Need `2+b+s+n > 3+b+2s+n` → `-1 > s`. **FAILS** (even worse: fails for all `s ≥ 0`).
- R7: `4 + 2a` > `0` ✓
- R8: LHS `= 4 + a + b`; RHS `integrate(merge a b) = 2 + (1 + a + b) = 3 + a + b`. `4+a+b > 3+a+b` ✓

**μ3 is INVALID** — fails on R_rec_succ, and here the `app` weight of 2 makes it fail even when `s = void`.

## Summary

| Rule | μ1 | μ2 | μ3 |
|------|----|----|----|
| R_int_delta | ✓ | ✓ | ✓ |
| R_merge_void_left | ✓ | ✓ | ✓ |
| R_merge_void_right | ✓ | ✓ | ✓ |
| R_merge_cancel | ✓ | ✓ | ✓ |
| R_rec_zero | ✓ | ✓ | ✓ |
| **R_rec_succ** | **✗** | **✗** | **✗** |
| R_eq_refl | ✓ | ✓ | ✓ |
| R_eq_diff | ✓ | ✓ | ✓ |

**All three candidates are invalid.** Every one fails on `R_rec_succ`.

### Root cause
`R_rec_succ` rewrites `recDelta b s (delta n)` to `app s (recDelta b s n)`, which **duplicates** the subterm `s` (it appears both in the new `app` and in the recursive `recDelta`). With any purely additive linear measure of the form used here, the RHS contains `mu(s)` *twice* while the LHS contains it *once*. The measure difference is
$$\Delta = \text{const}_{\text{delta}} - \text{const}_{\text{app}} - \mu(s),$$
and since `μ(s)` is unbounded, no fixed choice of constants can guarantee `Δ > 0`.

### What would be needed
A working measure must dominate this duplication of `s`. Simple additive weights over subterm sizes cannot do it. One needs either:
- a measure where `recDelta`'s dependence on `n` **multiplies** the cost of `s` (e.g. a term like `mu(n) * (1 + mu(s))`), so peeling one `delta` off `n` frees up more than one copy's worth of `s`; or
- a lexicographic / multiset ordering treating `n`'s structure as the primary component.

The three given candidates only differ in constant weights, so none can succeed regardless of how the constants are tuned.
