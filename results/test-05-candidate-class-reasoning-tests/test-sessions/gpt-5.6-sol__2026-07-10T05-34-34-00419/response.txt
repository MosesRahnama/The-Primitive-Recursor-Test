A valid termination measure into `Nat` must satisfy `μ lhs > μ rhs` for every `Step lhs rhs`.

For an additive measure with constructor costs `d` for `delta` and `a` for `app`, rule `R_rec_succ` requires

\[
d > a + μ(s),
\]

because:

\[
\begin{aligned}
μ(\mathrm{recDelta}\ b\ s\ (\mathrm{delta}\ n))
  &= r + μ(b)+μ(s)+d+μ(n),\\
μ(\mathrm{app}\ s\ (\mathrm{recDelta}\ b\ s\ n))
  &= a+r+μ(b)+2μ(s)+μ(n).
\end{aligned}
\]

Thus the rule duplicates the contribution of `s`, and none of the candidates can decrease on it.

### Candidate `mu1`

Here `d = 1` and `a = 1`, so decrease would require `1 > 1 + mu1 s`, which is impossible.

With `b = s = n = void`:

- source measure: `2`
- target measure: `2`

Hence it is not strictly decreasing. For non-`void` `s`, it actually increases; for example, with `s = delta void`, the measures are `3 → 4`.

All other rules strictly decrease under `mu1`.

### Candidate `mu2`

Again `d = 1` and `a = 1`, giving the same failure.

With `b = s = n = void`:

- source measure: `6`
- target measure: `6`

For `s = delta void`, the measures are `7 → 8`.

All other rules strictly decrease under `mu2`.

### Candidate `mu3`

Here `d = 1` and `a = 2`, so `R_rec_succ` increases even when `s = void`.

With `b = s = n = void`:

- source measure: `2`
- target measure: `3`

All other rules strictly decrease under `mu3`.

### Verdict

| Candidate | Result |
|---|---|
| `mu1` | Invalid: `R_rec_succ` can preserve or increase the measure |
| `mu2` | Invalid: `R_rec_succ` can preserve or increase the measure |
| `mu3` | Invalid: `R_rec_succ` always increases by at least `1 + mu3 s` |

Therefore, **none of the three candidates is a valid strict termination measure for `Step`**. The core problem is that `R_rec_succ` duplicates `s`, which a simple additive size measure cannot compensate for with fixed constructor weights.
