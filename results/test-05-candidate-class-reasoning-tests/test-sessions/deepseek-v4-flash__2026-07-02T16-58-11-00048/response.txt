All three candidate termination measures (mu1, mu2, mu3) are **invalid** because they fail to strictly decrease on the rewrite rule `R_rec_succ`:

```
Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

For each measure, let `L = measure(recDelta b s (delta n))` and `R = measure(app s (recDelta b s n))`. The calculations are:

- **mu1**: `L = 2 + mu1 b + mu1 s + mu1 n`, `R = 2 + mu1 b + 2·mu1 s + mu1 n` → `L = R - mu1 s ≤ R` (equality when `mu1 s = 0`, strict inequality otherwise). Hence `L > R` never holds.
- **mu2**: `L = 6 + mu2 b + mu2 s + mu2 n`, `R = 6 + mu2 b + 2·mu2 s + mu2 n` → `L = R - mu2 s ≤ R`. Again not decreasing.
- **mu3**: `L = 2 + mu3 b + mu3 s + mu3 n`, `R = 3 + mu3 b + 2·mu3 s + mu3 n` → `L = R - 1 - mu3 s < R` for all terms. The left-hand side is strictly smaller, so the measure increases.

All other rewrite rules (R_int_delta, R_merge_void_left/right, R_merge_cancel, R_rec_zero, R_eq_refl, R_eq_diff) do show a strict decrease for each measure, but the failure on the single rule `R_rec_succ` means none of the three functions is a valid termination measure for the entire reduction system.
