After rigorous analysis of all rewrite rules against each candidate measure, **none of the three proposed termination measures (mu1, mu2, mu3) are valid**. All fail specifically on the `R_rec_succ` rule:

```
R_rec_succ : recDelta b s (delta n) → app s (recDelta b s n)
```

### Critical Failure on `R_rec_succ`
For **any** trace terms `b`, `s`, `n`:
- **mu1**:  
  LHS = `2 + μ₁(b) + μ₁(s) + μ₁(n)`  
  RHS = `2 + μ₁(b) + 2·μ₁(s) + μ₁(n)`  
  → LHS ≤ RHS (equality when `μ₁(s) = 0`, e.g., `s = void`). **Not strictly decreasing**.

- **mu2**:  
  LHS = `6 + μ₂(b) + μ₂(s) + μ₂(n)`  
  RHS = `6 + μ₂(b) + 2·μ₂(s) + μ₂(n)`  
  → LHS ≤ RHS (equality when `μ₂(s) = 0`). **Not strictly decreasing**.

- **mu3**:  
  LHS = `2 + μ₃(b) + μ₃(s) + μ₃(n)`  
  RHS = `3 + μ₃(b) + 2·μ₃(s) + μ₃(n)`  
  → LHS = RHS - (1 + μ₃(s)) < RHS (e.g., `b=s=n=void` gives LHS=2, RHS=3). **Measure increases**.

This violates the fundamental requirement for a termination measure: *every* rewrite step must strictly decrease the measure. Since `R_rec_succ` is a core rule of the calculus, failure here is fatal.

### Why Other Rules Do Not Save the Measures
- All measures **pass** the other 7 rules (verified exhaustively):
  - `R_int_delta`, `R_merge_void_*`, `R_merge_cancel`, `R_rec_zero`, `R_eq_refl`, `R_eq_diff` all show strict decrease for all three measures.
  - Example: For `R_eq_diff`, mu3 satisfies `4 + μ₃(a) + μ₃(b) > 3 + μ₃(a) + μ₃(b)` (4 > 3), but this is irrelevant due to the `R_rec_succ` failure.
- Overlapping rules (e.g., `R_eq_refl` and `R_eq_diff` on `eqW a a`) do not mitigate the issue: termination requires *every applicable rule* to decrease the measure. Since `R_rec_succ` is always applicable to terms matching its pattern and fails to decrease all measures, the system cannot be proven terminating with these candidates.

### Root Cause
The structural issue in `R_rec_succ` is that the RHS introduces **two occurrences of `s`** (in `app s (...)` and nested `recDelta b s n`), while the LHS contains only one. All candidate measures assign non-negative weights to subterms, making it impossible to satisfy `μ(LHS) > μ(RHS)` without negative weights (which are disallowed in ℕ-valued measures). No adjustment of constant coefficients in the given measure templates can resolve this structural deficit.

### Conclusion
- **mu1**: Invalid (non-strict decrease on `R_rec_succ`).  
- **mu2**: Invalid (non-strict decrease on `R_rec_succ`).  
- **mu3**: Invalid (strict *increase* on `R_rec_succ`).  

No candidate satisfies the strict monotonicity requirement across all rewrite rules. A valid termination measure for this calculus would need to fundamentally address the duplication of `s` in `R_rec_succ`, likely requiring a more sophisticated technique (e.g., recursive path ordering, dependency pairs, or context-dependent weighting). The proposed linear additive measures are insufficient.
