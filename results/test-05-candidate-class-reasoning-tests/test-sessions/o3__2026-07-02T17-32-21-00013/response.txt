Summary of the check

For every candidate µᵢ (i = 1,2,3) we have to show, for every reduction rule
    L ⟶ R,
that µᵢ (L) > µᵢ (R).  
All the rules except

      recDelta-succ :  
         recDelta b s (delta n)  ⟶  app s (recDelta b s n)

behave well for the three proposals: the measure drops by at least 1 for all
of

 • integrate (delta t) ⟶ void  
 • merge void t ⟶ t  
 • merge t void ⟶ t  
 • merge t t  ⟶ t  
 • recDelta b s void ⟶ b  
 • eqW a a ⟶ void  
 • eqW a b ⟶ integrate (merge a b)

The failing rule

Let wΔ, wℛ, wₐₚₚ be the constants contributed by
    delta,  recDelta,  app
in the chosen measure.  In every of the three proposals

        wΔ = 1      wℛ = 1 (µ₁,µ₃)  or 5 (µ₂)     wₐₚₚ = 1 (µ₁) 2 (µ₂,µ₃)

For the problematic rule we get, uniformly for all three measures,

      µ(L) = wℛ + wΔ + µ b + µ s + µ n
      µ(R) = wₐₚₚ + wℛ + µ b + 2 µ s + µ n

hence

      µ(R) – µ(L) = (wₐₚₚ – wΔ) + µ s   ≥   (wₐₚₚ – wΔ).

Because wₐₚₚ ≥ 1 and wΔ = 1, the right-hand side is non-negative and is
strictly positive whenever s ≠ void.  Consequently µ does not decrease on this
rule:

• µ₁ :  µ increases by   µ s             (≥ 0).
• µ₂ :  µ increases by   1 + µ s        (≥ 1 unless s = void).
• µ₃ :  µ increases by   1 + µ s        (≥ 1 unless s = void).

Therefore

Candidate-1 (µ₁)   –– fails, counter-example recDelta-succ.  
Candidate-2 (µ₂)   –– fails, same counter-example.  
Candidate-3 (µ₃)   –– fails, same counter-example.

Conclusion

None of the three proposed measures is a valid termination measure for the
given rewrite system.  Any additive size measure that simply sums the sizes of
sub-traces cannot work, because in the recDelta-succ rule the redex appears
nested inside an additional app on the right-hand side, inevitably making the
sum grow.  A successful proof of termination will have to use a different kind
of ordering (for instance a multiset or lexicographic combination that treats
the recursion argument separately).
