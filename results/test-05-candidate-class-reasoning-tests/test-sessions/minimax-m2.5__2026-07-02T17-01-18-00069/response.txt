**Short answer:**  
- **mu₁** – *not* a termination measure.  
- **mu₂** – *not* a termination measure.  
- **mu₃** – *is* a valid termination measure.

---

### Why the first two measures fail

All rewrite rules are listed in the `Step` inductive family.  
A termination measure `μ : Trace → ℕ` must satisfy

```
∀ (s ⇒ t)  :  μ(s) > μ(t)
```

where “s ⇒ t” is any constructor of `Step`.

We examine every rule:

| Rule | μ₁(left) – μ₁(right) | μ₂(left) – μ₂(right) | μ₃(left) – μ₃(right) |
|------|----------------------|----------------------|----------------------|
| `R_int_delta`  (integrate (delta t) ⇒ void) | 2+μ(t) > 0 | 3+μ(t) > 0 | 3+μ(t) > 0 |
| `R_merge_void_left/right` (merge void t ⇒ t) | 1+μ(t) > μ(t) | 2+μ(t) > μ(t) | 1+μ(t) > μ(t) |
| `R_merge_cancel` (merge t t ⇒ t) | 1+2·μ(t) > μ(t) | 2+2·μ(t) > μ(t) | 1+2·μ(t) > μ(t) |
| `R_rec_zero` (recDelta b s void ⇒ b) | 1+μ(b)+μ(s) > μ(b) | 5+μ(b)+μ(s) > μ(b) | 1+μ(b)+μ(s) > μ(b) |
| `R_eq_refl` (eqW a a ⇒ void) | 3+2·μ(a) > 0 | 5+2·μ(a) > 0 | 4+2·μ(a) > 0 |
| `R_eq_diff` (eqW a b ⇒ integrate (merge a b)) | 1 > 0 | 1 > 0 | 1 > 0 |

All the above are strictly positive for **μ₁**, **μ₂**, and **μ₃**.

The only problematic rule is `R_rec_succ`:

```
recDelta b s (delta n)  ⇒  app s (recDelta b s n)
```

Computing the difference for each candidate:

* **μ₁**  

```
μ₁(left) = 2 + μ₁(b) + μ₁(s) + μ₁(n)
μ₁(right)= 2 + μ₁(b) + 2·μ₁(s) + μ₁(n)
Δ = μ₁(left) – μ₁(right) = – μ₁(s) ≤ 0
```

If `s = void` we get equality; otherwise the measure *increases*. Hence μ₁ does **not** guarantee termination.

* **μ₂**  

```
μ₂(left) = 6 + μ₂(b) + μ₂(s) + μ₂(n)
μ₂(right)= 6 + μ₂(b) + 2·μ₂(s) + μ₂(n)
Δ = – μ₂(s) ≤ 0
```

Same problem: μ₂ fails for the same reason.

* **μ₃**  

```
μ₃(left) = 2 + μ₃(b) + μ₃(s) + μ₃(n)
μ₃(right)= 3 + μ₃(b) + 2·μ₃(s) + μ₃(n)
Δ = –1 – μ₃(s) ≤ –1  < 0
```

Here the measure **always** strictly decreases (by at least 1), regardless of the size of `s`. All other rules also keep Δ > 0, so μ₃ satisfies the required property.

---

### Summary

- **μ₁** and **μ₂** are not suitable termination measures because the `recDelta`‑succesor rule does not lower their value (it either stays the same or grows).
- **μ₃** works: by giving the `app` constructor a larger weight (2) than `recDelta` (1) and a modest weight to `merge` (1) and `integrate` (2), every rewrite step reduces the numeric value, yielding a well‑founded measure.

Therefore, among the three candidates, **only μ₃ is a correct termination measure** for the given rewrite system.
