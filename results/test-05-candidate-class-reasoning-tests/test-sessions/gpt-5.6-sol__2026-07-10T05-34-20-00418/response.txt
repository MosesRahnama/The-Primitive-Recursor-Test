A valid `Nat`-valued termination measure must strictly decrease for every `Step t u`, i.e. `μ u < μ t`.

All three candidates fail on `R_rec_succ`.

Let \(B = μ(b)\), \(S = μ(s)\), and \(N = μ(n)\).

| Measure | Source: `recDelta b s (delta n)` | Target: `app s (recDelta b s n)` | Source − target |
|---|---:|---:|---:|
| `mu1` | `2 + B + S + N` | `2 + B + 2*S + N` | `-S` |
| `mu2` | `6 + B + S + N` | `6 + B + 2*S + N` | `-S` |
| `mu3` | `2 + B + S + N` | `3 + B + 2*S + N` | `-(1 + S)` |

Thus:

- **`mu1` is invalid.** It is unchanged when `s = void` and increases when `mu1 s > 0`.
- **`mu2` is invalid.** It has the same problem: unchanged when `s = void` and increases for nontrivial `s`.
- **`mu3` is invalid.** It always increases on `R_rec_succ`, even when `s = void`.

A single concrete step demonstrates all three failures:

```lean
Step
  (recDelta void void (delta void))
  (app void (recDelta void void void))
```

The values are:

- `mu1`: `2 → 2`
- `mu2`: `6 → 6`
- `mu3`: `2 → 3`

All the other rewrite rules strictly decrease under each candidate. In particular, `R_eq_diff` decreases by exactly `1` for all three. The sole obstruction is that `R_rec_succ` duplicates `s`; none of these additive measures accounts for that duplication with a sufficiently decreasing component.

**Conclusion: none of `mu1`, `mu2`, or `mu3` is a valid strict termination measure for `Step`.**
