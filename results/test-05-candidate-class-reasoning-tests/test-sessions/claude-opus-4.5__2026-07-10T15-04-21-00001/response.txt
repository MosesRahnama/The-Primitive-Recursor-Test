## Detailed Analysis

### μ₁ (mu1)

**R_rec_succ:** `recDelta b s (delta n)` → `app s (recDelta b s n)`
- LHS: `1 + μ₁(b) + μ₁(s) + (1 + μ₁(n))` = `2 + μ₁(b) + μ₁(s) + μ₁(n)`
- RHS: `1 + μ₁(s) + (1 + μ₁(b) + μ₁(s) + μ₁(n))` = `2 + μ₁(b) + 2·μ₁(s) + μ₁(n)`
- **Fails:** RHS ≥ LHS (extra `μ₁(s)` term)

**R_eq_diff:** `eqW a b` → `integrate (merge a b)`
- LHS: `3 + μ₁(a) + μ₁(b)`
- RHS: `1 + (1 + μ₁(a) + μ₁(b))` = `2 + μ₁(a) + μ₁(b)`
- ✓ Decreases by 1

**Verdict: ✗ UNSOUND** (fails R_rec_succ)

---

### μ₂ (mu2)

**R_rec_succ:** `recDelta b s (delta n)` → `app s (recDelta b s n)`
- LHS: `5 + μ₂(b) + μ₂(s) + (1 + μ₂(n))` = `6 + μ₂(b) + μ₂(s) + μ₂(n)`
- RHS: `1 + μ₂(s) + (5 + μ₂(b) + μ₂(s) + μ₂(n))` = `6 + μ₂(b) + 2·μ₂(s) + μ₂(n)`
- **Fails?** No! The `delta` wrapper on `n` contributes +1 to LHS, and we need to account for it being stripped. Let me recalculate:
- LHS: `5 + μ₂(b) + μ₂(s) + μ₂(delta n)` = `5 + μ₂(b) + μ₂(s) + 1 + μ₂(n)` = `6 + μ₂(b) + μ₂(s) + μ₂(n)`
- RHS: `1 + μ₂(s) + (5 + μ₂(b) + μ₂(s) + μ₂(n))` = `6 + μ₂(b) + 2·μ₂(s) + μ₂(n)`
- This still seems to fail... but wait, the recDelta weight is 5, which absorbs the cost. The difference is `μ₂(s)`, so this fails unless we use a multiset ordering or μ₂(s) = 0.

Actually, re-examining: the `app` has weight 1, and `recDelta` has weight 5. So:
- Lost: 5 (recDelta) + 1 (delta wrapper) = 6
- Gained: 1 (app) + 5 (inner recDelta) + μ₂(s) = 6 + μ₂(s)

**Fails when s ≠ void.**

**Verdict: ✗ UNSOUND** (fails R_rec_succ when s is non-trivial)

---

### μ₃ (mu3)

**R_rec_succ:** `recDelta b s (delta n)` → `app s (recDelta b s n)`
- LHS: `1 + μ₃(b) + μ₃(s) + (1 + μ₃(n))` = `2 + μ₃(b) + μ₃(s) + μ₃(n)`
- RHS: `2 + μ₃(s) + (1 + μ₃(b) + μ₃(s) + μ₃(n))` = `3 + μ₃(b) + 2·μ₃(s) + μ₃(n)`
- **Fails:** RHS > LHS

**Verdict: ✗ UNSOUND** (fails R_rec_succ)

---

## Conclusion

**None of the three candidate measures are valid termination measures.** All three fail on `R_rec_succ` because the rule duplicates `s` in the result (once in `app s ...` and once inside the recursive `recDelta b s n`), causing the measure to potentially increase when `μ(s) > 0`.

The rewrite system may require a more sophisticated measure (e.g., lexicographic ordering, multiset ordering, or a measure that tracks the "recursion depth" separately from term size).
