**Assessment:** none of the three candidates is a valid termination measure.  
All of them fail on the rule `R_rec_succ`, and no choice of positive constant offsets can repair this because the rule duplicates the step argument `s`.

---

### What is required

A function `μ : Trace → Nat` proves termination of `Step` only if for **every** rule instance `l → r` we have `μ(l) > μ(r)`.

---

### Rules that all three candidates satisfy

For the following rules, every `μᵢ` strictly decreases (the checks are straightforward arithmetic with natural numbers):

| Rule | Condition on `μᵢ` |
|------|-------------------|
| `R_int_delta` | `integrate (delta t) → void` |
| `R_merge_void_left` / `R_merge_void_right` | `merge void t → t` and symmetric |
| `R_merge_cancel` | `merge t t → t` |
| `R_rec_zero` | `recDelta b s void → b` |
| `R_eq_refl` | `eqW a a → void` |
| `R_eq_diff` | `eqW a b → integrate (merge a b)` |

So the *only* rule that disqualifies the candidates is **`R_rec_succ`**:

```
recDelta b s (delta n)  →  app s (recDelta b s n)
```

---

### Failure on `R_rec_succ`

Write `|x|` for the corresponding measure `μ(x)`.  
For any measure of the linear shape used here,

* `|delta n| = c_δ + |n|`
* `|app a b| = c_app + |a| + |b|`
* `|recDelta b s n| = c_rec + |b| + |s| + |n|`

the left- and right-hand sides of `R_rec_succ` evaluate to:

* LHS = `c_rec + c_δ + |b| + |s| + |n|`
* RHS = `c_app + c_rec + |b| + 2|s| + |n|`

Hence  
**RHS − LHS = (c_app − c_δ) + |s|**.

Because `|s|` can be any natural number (traces can be arbitrarily deep), the difference is non‑negative for all `s` and, for most choices, positive. Strict decrease is impossible.

---

#### `mu1`

*Constants:* `c_δ = 1`, `c_app = 1`, `c_rec = 1`.

RHS − LHS = `1 − 1 + |s| = |s|`.

* If `s = void` then `|s| = 0` and **LHS = RHS** (the measure does not decrease).  
* If `s` is non‑void then RHS is strictly larger than LHS.

**Counterexample:** `b = void, s = void, n = void`  
`mu1(recDelta void void (delta void)) = 2 = mu1(app void (recDelta void void void))`.

→ `mu1` is **invalid**.

---

#### `mu2`

*Constants:* `c_δ = 1`, `c_app = 1`, `c_rec = 5`.

The extra `+4` inside `recDelta` cancels out on both sides:

RHS − LHS = `1 − 1 + |s| = |s|`.

* If `s = void` the measure is unchanged.  
* If `s` is non‑void the measure increases.

**Counterexample:** `b = void, s = void, n = void`  
`mu2(recDelta void void (delta void)) = 6 = mu2(app void (recDelta void void void))`.

→ `mu2` is **invalid**.

---

#### `mu3`

*Constants:* `c_δ = 1`, `c_app = 2`, `c_rec = 1`.

RHS − LHS = `2 − 1 + |s| = 1 + |s|`.

This is **strictly positive for every possible `s`**.  
Thus `mu3` does not merely stay flat—it *increases* on every instance of `R_rec_succ`.

**Counterexample:** `b = void, s = void, n = void`  
`mu3(LHS) = 2 < 3 = mu3(RHS)`.

→ `mu3` is **invalid** (and in fact moves in the wrong direction).

---

### Summary

| Measure | Verdict | Why |
|---------|---------|-----|
| `mu1` | **Invalid** | Fails on `R_rec_succ`; equal when `s = void`, larger when `s` is non‑void. |
| `mu2` | **Invalid** | Fails on `R_rec_succ`; equal when `s = void`, larger when `s` is non‑void. The big constant `5` in `recDelta` is irrelevant because it appears on both sides. |
| `mu3` | **Invalid** | Fails on `R_rec_succ`; strictly **increases** for every `s` because the duplicated `s` on the right outweighs the constants. |

**Root cause:** `R_rec_succ` places the subterm `s` in *two* positions on the right (`app s …` and inside the recursive `recDelta`) but only *one* position on the left. Any additive measure with positive coefficients for the subterms of `app` and `recDelta` will assign at least as much weight to the two occurrences on the right as to the single occurrence on the left, so no linear measure of this form can be strictly decreasing. A genuine termination measure for this calculus would need a non‑linear weighting (e.g., giving `s` a smaller coefficient in recursive contexts, or using a lexicographic ordering).
