None of `mu1`, `mu2`, or `mu3` is a valid strict decreasing measure for every `Step`.

The obstruction is `R_rec_succ`:

```lean
Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

Writing `B = muᵢ b`, `S = muᵢ s`, and `N = muᵢ n`:

| Measure | Source measure | Target measure | Target − source |
|---|---:|---:|---:|
| `mu1` | `2 + B + S + N` | `2 + B + 2*S + N` | `S` |
| `mu2` | `6 + B + S + N` | `6 + B + 2*S + N` | `S` |
| `mu3` | `2 + B + S + N` | `3 + B + 2*S + N` | `1 + S` |

Thus:

- `mu1` is unchanged when `mu1 s = 0`, and increases when `mu1 s > 0`.
- `mu2` is unchanged when `mu2 s = 0`, and increases when `mu2 s > 0`.
- `mu3` always increases on `R_rec_succ`.

For a concrete counterexample applicable to all three, take:

```lean
b = void
s = delta void
n = void
```

Then the step is:

```lean
recDelta void (delta void) (delta void)
  -->
app (delta void) (recDelta void (delta void) void)
```

with values:

| Measure | Before | After |
|---|---:|---:|
| `mu1` | `3` | `4` |
| `mu2` | `7` | `8` |
| `mu3` | `3` | `5` |

All the other rule families do strictly decrease under each respective measure:

- `R_int_delta`
- both `R_merge_void_*` rules
- `R_merge_cancel`
- `R_rec_zero`
- `R_eq_refl`
- `R_eq_diff`

In particular, the `eqW` weights are sufficient for `R_eq_diff`:

- `mu1`: source exceeds target by `1`;
- `mu2`: source exceeds target by `1`;
- `mu3`: source exceeds target by `1`.

The issue is specifically that `R_rec_succ` retains `s` inside the recursive call while also placing another copy of `s` as the left child of `app`. These additive measures therefore pay for `s` twice on the right but only once on the left. The constructor constants cannot compensate for an arbitrarily large `s`.

So the assessment is:

- `mu1`: invalid as a global strict termination measure;
- `mu2`: invalid as a global strict termination measure;
- `mu3`: invalid as a global strict termination measure, and fails more strongly than the first two on `R_rec_succ`.

This only rejects these proposed one-dimensional measures; it does not by itself establish nontermination of the rewrite calculus.
