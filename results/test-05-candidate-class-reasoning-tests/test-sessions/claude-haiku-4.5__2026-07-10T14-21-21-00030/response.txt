# Assessment of Termination Measures

I'll analyze each candidate measure by checking whether `mu(t) > mu(t')` for every rewrite rule `Step t t'`.

## Candidate mu1

**FAILS** on rule `R_rec_succ`:
- Rewrite: `recDelta b s (delta n) → app s (recDelta b s n)`
- LHS: `mu1(recDelta b s (delta n)) = 1 + mu1(b) + mu1(s) + (1 + mu1(n))`
- RHS: `mu1(app s (recDelta b s n)) = 1 + mu1(s) + (1 + mu1(b) + mu1(s) + mu1(n))`
- Simplifying: LHS = `2 + mu1(b) + mu1(s) + mu1(n)` vs RHS = `2 + mu1(b) + 2·mu1(s) + mu1(n)`
- We need `mu1(s) > mu1(s)`, which is false.

**Verdict: ❌ Not a valid termination measure**

## Candidate mu2

**FAILS** on rule `R_eq_diff`:
- Rewrite: `eqW a b → integrate (merge a b)`
- LHS: `mu2(eqW a b) = 5 + mu2(a) + mu2(b)`
- RHS: `mu2(integrate (merge a b)) = 2 + (2 + mu2(a) + mu2(b)) = 4 + mu2(a) + mu2(b)`
- We need `5 + mu2(a) + mu2(b) > 4 + mu2(a) + mu2(b)`, which simplifies to `5 > 4` ✓

Checking `R_rec_succ`:
- LHS: `mu2(recDelta b s (delta n)) = 5 + mu2(b) + mu2(s) + (1 + mu2(n)) = 6 + mu2(b) + mu2(s) + mu2(n)`
- RHS: `mu2(app s (recDelta b s n)) = 1 + mu2(s) + (5 + mu2(b) + mu2(s) + mu2(n)) = 6 + mu2(b) + 2·mu2(s) + mu2(n)`
- We need `mu2(s) > mu2(s)`, which is false.

**Verdict: ❌ Not a valid termination measure**
