Assessment criterion: for a candidate `μ`, every rewrite rule `Step l r` should strictly decrease the measure, i.e. `μ l > μ r`.

## Candidate `mu1`

`mu1` is **not** a valid termination measure.

Check the problematic rules:

- `R_rec_succ`:
  - LHS: `mu1 (recDelta b s (delta n)) = 1 + mu1 b + mu1 s + (1 + mu1 n) = 2 + mu1 b + mu1 s + mu1 n`
  - RHS: `mu1 (app s (recDelta b s n))`
    = `1 + mu1 s + (1 + mu1 b + mu1 s + mu1 n)`
    = `2 + mu1 b + 2*mu1 s + mu1 n`
  - So RHS exceeds LHS by `mu1 s`. If `s ≠ void`, it increases; if `s = void`, it is equal. In no case is it strictly smaller in general.

- `R_eq_diff`:
  - LHS: `mu1 (eqW a b) = 3 + mu1 a + mu1 b`
  - RHS: `mu1 (integrate (merge a b)) = 1 + (1 + mu1 a + mu1 b) = 2 + mu1 a + mu1 b`
  - This one decreases by 1, so it is fine.

- All the simpler rules decrease:
  - `integrate (delta t) -> void`: `2 + mu1 t > 0`
  - `merge void t -> t`: `1 + mu1 t > mu1 t`
  - `merge t void -> t`: same
  - `merge t t -> t`: `1 + 2*mu1 t > mu1 t`
  - `recDelta b s void -> b`: `1 + mu1 b + mu1 s > 0`
  - `eqW a a -> void`: `3 + 2*mu1 a > 0`

Conclusion: **`mu1` fails because of `R_rec_succ`.**

## Candidate `mu2`

`mu2` is a **valid** termination measure.

Check each rule:

- `R_int_delta`:
  - LHS: `mu2 (integrate (delta t)) = 2 + (1 + mu2 t) = 3 + mu2 t`
  - RHS: `0`
  - Strict decrease.

- `R_merge_void_left`:
  - `mu2 (merge void t) = 2 + 0 + mu2 t = 2 + mu2 t > mu2 t`

- `R_merge_void_right`:
  - same.

- `R_merge_cancel`:
  - `mu2 (merge t t) = 2 + 2*mu2 t > mu2 t`

- `R_rec_zero`:
  - LHS: `mu2 (recDelta b s void) = 5 + mu2 b + mu2 s`
  - RHS: `mu2 b`
  - Strict decrease.

- `R_rec_succ`:
  - LHS:
    `mu2 (recDelta b s (delta n))
      = 5 + mu2 b + mu2 s + (1 + mu2 n)
      = 6 + mu2 b + mu2 s + mu2 n`
  - RHS:
    `mu2 (app s (recDelta b s n))
      = 1 + mu2 s + (5 + mu2 b + mu2 s + mu2 n)
      = 6 + mu2 b + 2*mu2 s + mu2 n`
  - Difference:
    `LHS - RHS = - mu2 s`
  - So this is **not** decreasing unless `mu2 s = 0`, and equal when `s = void`.

So `mu2` actually **fails** as well.

- `R_eq_refl` and `R_eq_diff` both decrease:
  - `eqW a a -> void`: `5 + 2*mu2 a > 0`
  - `eqW a b -> integrate (merge a b)`:
    - LHS: `5 + mu2 a + mu2 b`
    - RHS: `2 + (2 + mu2 a + mu2 b) = 4 + mu2 a + mu2 b`
    - decreases by 1.

Conclusion: **`mu2` fails because of `R_rec_succ`.**

## Candidate `mu3`

`mu3` is **not** a valid termination measure.

Check the critical rules:

- `R_rec_succ`:
  - LHS:
    `mu3 (recDelta b s (delta n))
      = 1 + mu3 b + mu3 s + (1 + mu3 n)
      = 2 + mu3 b + mu3 s + mu3 n`
  - RHS:
    `mu3 (app s (recDelta b s n))
      = 2 + mu3 s + (1 + mu3 b + mu3 s + mu3 n)
      = 3 + mu3 b + 2*mu3 s + mu3 n`
  - RHS is larger by `1 + mu3 s`, so this definitely increases.

- `R_eq_diff`:
  - LHS: `mu3 (eqW a b) = 4 + mu3 a + mu3 b`
  - RHS:
    `mu3 (integrate (merge a b))
      = 2 + (1 + mu3 a + mu3 b)
      = 3 + mu3 a + mu3 b`
  - decreases by 1, so fine.

Other rules also decrease:
- `integrate (delta t) -> void`: `3 + mu3 t > 0`
- `merge void t -> t`: `1 + mu3 t > mu3 t`
- `merge t void -> t`: same
- `merge t t -> t`: `1 + 2*mu3 t > mu3 t`
- `recDelta b s void -> b`: `1 + mu3 b + mu3 s > mu3 b`
- `eqW a a -> void`: `4 + 2*mu3 a > 0`

Conclusion: **`mu3` fails because of `R_rec_succ`.**

---

## Overall verdict

None of the three candidates works.

The common obstruction is the rule

- `recDelta b s (delta n) -> app s (recDelta b s n)`

For any additive measure of the form

- `μ(recDelta b s n) = c_r + μ(b) + μ(s) + μ(n)`
- `μ(app a b) = c_a + μ(a) + μ(b)`

the right-hand side contains an extra copy of `s`, so
`μ(app s (recDelta b s n))`
adds another `μ(s)`. Thus the rule cannot strictly decrease unless `s` has weight 0 always, which is impossible for a natural-valued structural size measure of this shape.

## Concise summary

- `mu1`: invalid
- `mu2`: invalid
- `mu3`: invalid

All three fail on `R_rec_succ`.
