For a Nat-valued termination measure, every rewrite rule must satisfy:

\[
\mu(\text{lhs}) > \mu(\text{rhs})
\]

All three candidates fail because of `R_rec_succ`.

Let \(m_s = \mu(s)\), \(m_b = \mu(b)\), \(m_n = \mu(n)\).

## `mu1`

For

```lean
Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

we get:

\[
\mu_1(\text{lhs})
= 1 + \mu_1(b) + \mu_1(s) + \mu_1(\delta n)
= 2 + m_b + m_s + m_n
\]

\[
\mu_1(\text{rhs})
= \mu_1(app s (recDelta b s n))
= 1 + m_s + (1 + m_b + m_s + m_n)
= 2 + m_b + 2m_s + m_n
\]

So:

\[
\mu_1(\text{lhs}) - \mu_1(\text{rhs}) = -m_s
\]

Thus `mu1` is equal when `s = void`, and increases on the rewrite whenever `s` has positive measure.

Example counterexample:

```lean
b = void, s = delta void, n = void
```

Then:

```lean
mu1 (recDelta void (delta void) (delta void)) = 3
mu1 (app (delta void) (recDelta void (delta void) void)) = 4
```

So `mu1` is not a valid strict termination measure.

## `mu2`

Again for `R_rec_succ`:

\[
\mu_2(\text{lhs})
= 5 + m_b + m_s + (1 + m_n)
= 6 + m_b + m_s + m_n
\]

\[
\mu_2(\text{rhs})
= 1 + m_s + (5 + m_b + m_s + m_n)
= 6 + m_b + 2m_s + m_n
\]

So:

\[
\mu_2(\text{lhs}) - \mu_2(\text{rhs}) = -m_s
\]

Same failure as `mu1`.

Example with equality:

```lean
b = void, s = void, n = void
```

Both sides have measure `6`, so there is no strict decrease.

Example with increase:

```lean
b = void, s = delta void, n = void
```

The left side has measure `7`, the right side has measure `8`.

So `mu2` is also not a valid strict termination measure.

## `mu3`

For `R_rec_succ`:

\[
\mu_3(\text{lhs})
= 1 + m_b + m_s + (1 + m_n)
= 2 + m_b + m_s + m_n
\]

\[
\mu_3(\text{rhs})
= 2 + m_s + (1 + m_b + m_s + m_n)
= 3 + m_b + 2m_s + m_n
\]

So:

\[
\mu_3(\text{lhs}) - \mu_3(\text{rhs}) = -(1 + m_s)
\]

This is always negative. The measure strictly increases for every instance of `R_rec_succ`.

Example:

```lean
b = void, s = void, n = void
```

Then:

```lean
mu3 (recDelta void void (delta void)) = 2
mu3 (app void (recDelta void void void)) = 3
```

So `mu3` is not a valid termination measure either.

## Other rules

For all three candidates, the other rules do strictly decrease. The sole obstruction is:

```lean
R_rec_succ :
  Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

## Verdict

None of the three proposed measures is a valid strict termination measure for `Step`.

- `mu1`: fails on `R_rec_succ`; equality if `s = void`, increase otherwise.
- `mu2`: fails on `R_rec_succ`; equality if `s = void`, increase otherwise.
- `mu3`: fails on `R_rec_succ`; always increases.
