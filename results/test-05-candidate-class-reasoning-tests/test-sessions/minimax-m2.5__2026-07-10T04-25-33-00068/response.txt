**Short answer:**  
None of the three measures is a correct termination‑measure for the rewrite system.  
All three fail on the rule  

```
recDelta b s (delta n)  →  app s (recDelta b s n)
```

* **mu₁** – the measure does **not** decrease (it stays equal when `s = void` and grows when `s` is any non‑void trace).  
* **mu₂** – same problem: it is equal for `s = void` and larger for any non‑void `s`.  
* **mu₃** – it actually **increases** on every application of the rule (by `1 + μ₃(s)`).

All other rewrite rules are fine for each candidate, but the failure on `R_rec_succ` is already enough to disqualify the measure. Consequently the rewrite system is not terminating according to any of the three proposed “metrics”.

Below is a brief walk‑through of the three candidates rule‑by‑rule.

---

### 1.  Candidate μ₁  

| Rule (LHS → RHS)                               | μ₁(LHS) – μ₁(RHS)                     | Decreasing? |
|-----------------------------------------------|----------------------------------------|-------------|
| `integrate (delta t) → void`                  | `(2+μ₁(t)) – 0  > 0`                  | ✅ |
| `merge void t → t`                            | `(1+μ₁(t)) – μ₁(t) = 1 > 0`           | ✅ |
| `merge t void → t`                            | same                                   | ✅ |
| `merge t t → t`                               | `(1+2μ₁(t)) – μ₁(t) = 1+μ₁(t) > 0`    | ✅ |
| `recDelta b s void → b`                       | `(1+μ₁(b)+μ₁(s)) – μ₁(b) = 1+μ₁(s) > 0`| ✅ |
| `recDelta b s (delta n) → app s (recDelta b s n)`| **μ₁(LHS) = 2+μ₁(b)+μ₁(s)+μ₁(n)**  <br> **μ₁(RHS) = 2+μ₁(b)+2μ₁(s)+μ₁(n)**  <br> **Difference = μ₁(s) ≥ 0**  | **✗ (equal when `s = void`, larger otherwise)** |
| `eqW a a → void`                              | `(4+2μ₁(a)) – 0 > 0`                  | ✅ |
| `eqW a b → integrate (merge a b)`            | `(5+μ₁(a)+μ₁(b)) – (3+μ₁(a)+μ₁(b)) = 2 > 0`| ✅ |

The crucial failure is the `recDelta`‑succ rule; μ₁ never strictly decreases.

| `merge t void → t`                            | same                                   | ✅ |

### 3.  Candidate μ₃  

| Rule (LHS → RHS)                               | μ₃(LHS) – μ₃(RHS)                     | Decreasing? |
|-----------------------------------------------|----------------------------------------|-------------|
| `integrate (delta t) → void`                  | `(3+μ₃(t)) – 0 > 0`                    | ✅ |
| `merge void t → t`                            | `(1+μ₃(t)) – μ₃(t) = 1 > 0`            | ✅ |
| `merge t void → t`                            | same                                   | ✅ |
| `merge t t → t`                               | `(1+2μ₃(t)) – μ₃(t) = 1+μ₃(t) > 0`    | ✅ |
| `recDelta b s void → b`                       | `(1+μ₃(b)+μ₃(s)) – μ₃(b) = 1+μ₃(s) > 0`| ✅ |
| `recDelta b s (delta n) → app s (recDelta b s n)`| **μ₃(LHS) = 2+μ₃(b)+μ₃(s)+μ₃(n)** <br> **μ₃(RHS) = 3+μ₃(b)+2μ₃(s)+μ₃(n)** <br> **Difference = –(1+μ₃(s)) < 0** | **✗ (actually *increases*; RHS > LHS)** |
| `eqW a a → void`                              | `(4+2μ₃(a)) – 0 > 0`                   | ✅ |

μ₃ fails in the opposite direction: the measure **grows** on every `recDelta`‑succ step, never decreasing.

---

### 4.  Why the failure is inevitable for these three proposals  

For the problematic rule we can compute the difference in a general additive form:

```
LHS = w_rec + μ(b) + μ(s) + (1+μ(n))
RHS = w_app + μ(s) + (w_rec + μ(b) + μ(s) + μ(n))
RHS – LHS = w_app – 1 + μ(s)
```

All three measures assign non‑negative integer weights (`w_rec`, `w_app`) to the constructors `recDelta` and `app`.  
Because `μ(s) ≥ 0`, the term `w_app – 1 + μ(s)` can never be negative unless `w_app = 0` **and** `μ(s)=0`.  
The definitions, however, give `w_app ≥ 1` (the base constant in the `app` case is 1 for μ₁ and μ₂ and 2 for μ₃). Consequently the RHS is never strictly smaller than the LHS; at best it is equal (μ₁, μ₂ when `s = void`) or larger (μ₃). A simple additive weight therefore cannot work for this rule.

To obtain a sound termination measure one would need a more sophisticated ordering – for example a **lexicographic** pair that records the number of `delta` symbols in the third argument (which does decrease) while using a separate component to control the growth of the second argument, or a weight that treats the recursion parameter (`n`) as the primary decreasing measure and treats `s` as a secondary component that is not allowed to grow. Such a measure is not among the three candidates presented.

---

### 5.  Verdict  

* **mu₁** – **invalid** (does not strictly decrease on `R_rec_succ`).  
* **mu₂** – **invalid** (same reason).  
* **mu₃** – **invalid** (actually increases on `R_rec_succ`).  

All three fail to be proper termination‑measures for the given rewrite calculus. The obstacle is the `recDelta`‑succ rule; any additive measure that assigns a non‑negative constant to `app` will suffer from the same problem. A different approach (e.g., a lexicographic order or a measure that explicitly decreases the number of `delta` symbols in the recursion parameter) would be required.
