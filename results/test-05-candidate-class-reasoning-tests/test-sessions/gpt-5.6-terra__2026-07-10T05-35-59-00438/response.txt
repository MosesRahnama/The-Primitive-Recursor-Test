None of the three candidates is a valid strict termination measure for `Step`.

Let \(B = \mu(b)\), \(S = \mu(s)\), and \(N = \mu(n)\). The problematic rule is:

```lean
R_rec_succ :
  Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

For this rule:

| Measure | LHS | RHS | LHS − RHS |
|---|---:|---:|---:|
| `mu1` | `2 + B + S + N` | `2 + B + 2*S + N` | `-S` |
| `mu2` | `6 + B + S + N` | `6 + B + 2*S + N` | `-S` |
| `mu3` | `2 + B + S + N` | `3 + B + 2*S + N` | `-1 - S` |

Consequences:

- **`mu1` fails.**
  - If `s = void`, then `mu1 s = 0`, so the measure is unchanged.
  - For example:
    ```lean
    recDelta void void (delta void)
    ```
    and
    ```lean
    app void (recDelta void void void)
    ```
    both have `mu1 = 2`.
  - If `s` has positive measure, the RHS is larger.

- **`mu2` fails** for the same reason.
  - With `s = void`, both sides have `mu2 = 6`.
  - With positive `mu2 s`, the measure increases.

- **`mu3` fails more strongly.**
  - The RHS is always larger by `1 + mu3 s`.
  - Even at `s = void`, the rule changes the measure from `2 + B + N` to `3 + B + N`.

All other rules strictly decrease under all three measures. Their decreases are:

| Rule | `mu1` decrease | `mu2` decrease | `mu3` decrease |
|---|---:|---:|---:|
| `R_int_delta` | `2` | `3` | `3` |
| `R_merge_void_left/right` | `1` | `2` | `1` |
| `R_merge_cancel` | `1 + μ(t)` | `2 + μ(t)` | `1 + μ(t)` |
| `R_rec_zero` | `1 + μ(s)` | `5 + μ(s)` | `1 + μ(s)` |
| `R_eq_refl` | `3 + 2μ(a)` | `5 + 2μ(a)` | `4 + 2μ(a)` |
| `R_eq_diff` | `1` | `1` | `1` |

Thus the assessment is:

- `mu1`: invalid, because `R_rec_succ` is non-increasing only when `s` is `void`-sized and increasing otherwise.
- `mu2`: invalid for the same reason.
- `mu3`: invalid, because `R_rec_succ` always increases it.
