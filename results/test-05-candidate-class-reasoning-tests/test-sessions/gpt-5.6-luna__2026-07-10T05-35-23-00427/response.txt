All three candidates fail to provide a strictly decreasing measure for every rewrite rule. The problematic rule is `R_rec_succ`.

For
```lean
Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

the measure differences are:

### `mu1`

\[
\mu_1(\text{source}) = 2+\mu_1(b)+\mu_1(s)+\mu_1(n)
\]

\[
\mu_1(\text{target}) = 2+\mu_1(b)+2\mu_1(s)+\mu_1(n)
\]

Thus the target exceeds the source by `mu1 s`. In particular, if `s = void`, the measure is unchanged.

Concrete counterexample:
```lean
recDelta void void (delta void)
  ↦ app void (recDelta void void void)
```

Both sides have `mu1 = 2`.

### `mu2`

Similarly,

\[
\mu_2(\text{source}) = 6+\mu_2(b)+\mu_2(s)+\mu_2(n)
\]

\[
\mu_2(\text{target}) = 6+\mu_2(b)+2\mu_2(s)+\mu_2(n)
\]

Again, the target exceeds the source by `mu2 s`; with `s = void`, the measure is unchanged. Therefore `mu2` also fails.

### `mu3`

Here,

\[
\mu_3(\text{source}) = 2+\mu_3(b)+\mu_3(s)+\mu_3(n)
\]

\[
\mu_3(\text{target}) = 3+\mu_3(b)+2\mu_3(s)+\mu_3(n)
\]

The target exceeds the source by `1 + mu3 s`, so `mu3` actually increases on every `R_rec_succ` step.

### Conclusion

- `mu1`: invalid — non-strict for `s = void`, increasing otherwise.
- `mu2`: invalid — non-strict for `s = void`, increasing otherwise.
- `mu3`: invalid — strictly increases on `R_rec_succ`.

The other rewrite rules do decrease these measures, but failure on even one rule is enough to disqualify each candidate as a global termination measure.
