Here’s the audit of the three proposed measures as **strict one-step decrease candidates** for `Step`.

A valid termination measure `μ` for this rewrite system should satisfy:

\[
\forall t\,u,\; Step\ t\ u \rightarrow \mu(t) > \mu(u).
\]

---

### Candidate `mu1`: **fails**

Most rules decrease, but `R_eq_diff` does not.

- Rule: `eqW a b → integrate (merge a b)`
- LHS:
  \[
  \mu_1(eqW\,a\,b)=3+\mu_1(a)+\mu_1(b)
  \]
- RHS:
  \[
  \mu_1(integrate(merge\,a\,b))
  =1+\mu_1(merge\,a\,b)
  =1+(1+\mu_1(a)+\mu_1(b))
  =2+\mu_1(a)+\mu_1(b)
  \]
So this one is fine (drops by 1).

But `R_rec_succ` fails:

- Rule: `recDelta b s (delta n) → app s (recDelta b s n)`
- LHS:
  \[
  1+\mu_1(b)+\mu_1(s)+\mu_1(delta\,n)
  =1+\mu_1(b)+\mu_1(s)+(1+\mu_1(n))
  =2+\mu_1(b)+\mu_1(s)+\mu_1(n)
  \]
- RHS:
  \[
  1+\mu_1(s)+\mu_1(recDelta\,b\,s\,n)
  =1+\mu_1(s)+(1+\mu_1(b)+\mu_1(s)+\mu_1(n))
  =2+\mu_1(b)+2\mu_1(s)+\mu_1(n)
  \]
Difference:
\[
\mu_1(\text{LHS})-\mu_1(\text{RHS})=-\mu_1(s)\le 0.
\]
If `s ≠ void`, RHS is larger. So not decreasing.

✅ Conclusion: **`mu1` is not a valid strict decrease measure.**

---

### Candidate `mu2`: **fails**

Check problematic rule `R_rec_succ`:

- LHS:
  \[
  \mu_2(recDelta\,b\,s\,(delta\,n))
  =5+\mu_2(b)+\mu_2(s)+(1+\mu_2(n))
  =6+\mu_2(b)+\mu_2(s)+\mu_2(n)
  \]
- RHS:
  \[
  \mu_2(app\,s\,(recDelta\,b\,s\,n))
  =1+\mu_2(s)+(5+\mu_2(b)+\mu_2(s)+\mu_2(n))
  =6+\mu_2(b)+2\mu_2(s)+\mu_2(n)
  \]
Again:
\[
\mu_2(\text{LHS})-\mu_2(\text{RHS})=-\mu_2(s)\le 0.
\]
So fails whenever `s` non-void.

Also `R_eq_diff` is only weakly decreasing:
- LHS `=5+...`
- RHS `=2 + (2+...) =4+...`
drops by 1, fine.
Main blocker remains `R_rec_succ`.

✅ Conclusion: **`mu2` is not valid.**

---

### Candidate `mu3`: **fails**

Same critical rule:

- LHS:
  \[
  \mu_3(recDelta\,b\,s\,(delta\,n))
  =1+\mu_3(b)+\mu_3(s)+(1+\mu_3(n))
  =2+\mu_3(b)+\mu_3(s)+\mu_3(n)
  \]
- RHS:
  \[
  \mu_3(app\,s\,(recDelta\,b\,s\,n))
  =2+\mu_3(s)+(1+\mu_3(b)+\mu_3(s)+\mu_3(n))
  =3+\mu_3(b)+2\mu_3(s)+\mu_3(n)
  \]
Difference:
\[
\mu_3(\text{LHS})-\mu_3(\text{RHS})=-1-\mu_3(s)<0.
\]
RHS is strictly larger always. So definite failure.

(Also `R_eq_diff` would be equal here:
LHS `4+...`, RHS `2 + (1+...) = 3+...`, actually drops by 1, so okay. Still fails on recursion step.)

✅ Conclusion: **`mu3` is not valid.**

---

## Final verdict

All three candidates **fail** as global strict termination measures for `Step`, for the same structural reason:  
`R_rec_succ` duplicates the contribution of `s` on the RHS (`app s (...)` while `recDelta` already contains `s`), so any simple additive size measure with positive weight for `s` in both `app` and `recDelta` cannot strictly decrease there.

So: **mu1 ✗, mu2 ✗, mu3 ✗**.
