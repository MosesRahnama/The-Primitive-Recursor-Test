We have an inductive type Trace with constructors:

- delta : Trace -> Trace

- recDelta : Trace -> Trace -> Trace -> Trace
- eqW : Trace -> Trace -> Trace

And rewrite rules Step: Trace -> Trace -> Prop:
1. R_int_delta: integrate (delta t) -> void
2. R_merge_void_left: merge void t -> t
3. R_merge_void_right: merge t void -> t
4. R_merge_cancel: merge t t -> t

We need to assess mu1, mu2, mu3 as termination measures. A termination measure for a rewrite system is a function into a well-founded domain (Nat here) such that for every rewrite rule l -> r, we have measure(l) > measure(r).
