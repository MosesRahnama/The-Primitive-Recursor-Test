Summary of the eight rewrite rules (Step)

1.  integrate (delta t)                   →  void
2.  merge void t                          →  t
3.  merge t void                          →  t
4.  merge t t                             →  t
5.  recDelta b s void                     →  b
6.  recDelta b s (delta n)                →  app s (recDelta b s n)
7.  eqW a a                               →  void
8.  eqW a b                               →  integrate (merge a b)

For a function μ to prove termination it must be strictly
decreasing along every rule instance, in particular along rule 6.
Only that rule duplicates the term s, so it is the critical one.

Notation:  R = μ(recDelta b s n) = c + μ b + μ s + μ n,
           where c is the constant that the concrete μ assigns to
           recDelta (1 for μ₁ and μ₃, 5 for μ₂).

With that,
   μ(lhs) = μ(recDelta b s (delta n))
          = c + μ b + μ s + μ(delta n)
          = c + μ b + μ s + (d + μ n)      (d = μ-weight of delta)

   μ(rhs) = μ(app s (recDelta b s n))
          = e + μ s + R                    (e = μ-weight of app)
          = e + μ s + c + μ b + μ s + μ n
          = (e-d) + c + μ b + (μ s + μ s) + μ n + d

Hence
   μ(rhs) – μ(lhs) = (e-d) + μ s.

The different candidates just choose different constants c,d,e.

• Candidate μ₁  
    c = 1,  d = 1,  e = 1  
    μ(rhs) – μ(lhs) = (1-1) + μ s = μ s ≥ 0.  
    – If s = void the difference is 0 (no strict decrease).  
    – If s ≠ void the difference is positive (measure even grows).  
    ⇒ μ₁ is not a termination measure.

• Candidate μ₂  
    c = 5,  d = 1,  e = 1  
    μ(rhs) – μ(lhs) = (1-1) + μ s = μ s ≥ 0 (same calculation).  
    The measure again stays the same when s = void and grows
    otherwise.  
    ⇒ μ₂ fails as well.

• Candidate μ₃  
    c = 1,  d = 1,  e = 2  
    μ(rhs) – μ(lhs) = (2-1) + μ s = 1 + μ s > 0.  
    The measure increases for every instance of rule 6, even when
    s = void (difference = 1).  
    ⇒ μ₃ is strictly increasing on the critical rule and therefore
    unsuitable.

All three candidates work on the seven “easy” rules (1-5,7-8), but
they all break down on rule 6. Consequently,

  • μ₁ does NOT prove termination,
  • μ₂ does NOT prove termination,
  • μ₃ does NOT prove termination.

A successful measure must give recDelta a weight that is at least
one full copy of μ s higher than the weight assigned to app, or it
must otherwise compensate for the duplication of s that rule 6
performs.
