All three proposed `Nat` measures fail as termination measures for `Step`, because each must strictly decrease on every rewrite rule, and all three fail on `R_rec_succ`.

Let `B = μ b`, `S = μ s`, and `N = μ n`.

## `mu1`

For the problematic rule:

```lean
Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

Compute:

```text
mu1 (recDelta b s (delta n))
= 1 + B + S + (1 + N)
= 2 + B + S + N

mu1 (app s (recDelta b s n))
= 1 + S + (1 + B + S + N)
= 2 + B + 2*S + N
```

So the RHS is larger by `S`:

```text
RHS - LHS = S
```

If `s = void`, then `S = 0`, so the measure is equal, not strictly decreasing. If `s` is non-void, the measure increases.

Therefore `mu1` is not a valid termination measure.

All other rules decrease under `mu1`, including:

```text
eqW a b        : 3 + A + B
integrate (...) : 2 + A + B
```

so `R_eq_diff` decreases by `1`.

## `mu2`

Again for `R_rec_succ`:

```text
mu2 (recDelta b s (delta n))
= 5 + B + S + (1 + N)
= 6 + B + S + N

mu2 (app s (recDelta b s n))
= 1 + S + (5 + B + S + N)
= 6 + B + 2*S + N
```

So again:

```text
RHS - LHS = S
```

If `s = void`, the measure is equal. Otherwise it increases.

Therefore `mu2` is not a valid termination measure.

The other rules do strictly decrease under `mu2`; for example:

```text
mu2 (eqW a b) = 5 + A + B
mu2 (integrate (merge a b)) = 2 + (2 + A + B) = 4 + A + B
```

so `R_eq_diff` decreases by `1`.

## `mu3`

For `R_rec_succ`:

```text
mu3 (recDelta b s (delta n))
= 1 + B + S + (1 + N)
= 2 + B + S + N

mu3 (app s (recDelta b s n))
= 2 + S + (1 + B + S + N)
= 3 + B + 2*S + N
```

Here:

```text
RHS - LHS = 1 + S
```

So the RHS is always strictly larger, even when `s = void`.

Therefore `mu3` is not a valid termination measure.

Again, the other rules decrease under `mu3`; for instance:

```text
mu3 (eqW a b) = 4 + A + B
mu3 (integrate (merge a b)) = 2 + (1 + A + B) = 3 + A + B
```

so `R_eq_diff` decreases by `1`.

## Summary

| Measure | Valid termination measure? | Reason |
|---|---:|---|
| `mu1` | No | `R_rec_succ` is non-decreasing; equal when `s = void`, increasing otherwise |
| `mu2` | No | Same failure as `mu1` |
| `mu3` | No | `R_rec_succ` strictly increases the measure for every `s` |

The obstruction is always the rule:

```lean
R_rec_succ :
  Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

because the recursive unfolding duplicates/counts `s` on the RHS. None of the three measures weights the decreasing `n` argument strongly enough to compensate for the extra occurrence of `s`.
