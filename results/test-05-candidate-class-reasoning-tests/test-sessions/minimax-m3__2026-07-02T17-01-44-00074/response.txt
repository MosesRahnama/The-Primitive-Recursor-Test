## Assessment of Termination Measures

For each measure we check the eight rules. A measure is a valid (single) termination measure iff it strictly decreases on **every** rule.

### Rule 6 — `R_rec_succ`
`Step (recDelta b s (delta n)) (app s (recDelta b s n))`

- **mu1**
  LHS: `1 + μ₁(b) + μ₁(s) + 1 + μ₁(n) = 2 + μ₁(b) + μ₁(s) + μ₁(n)`
  RHS: `1 + μ₁(s) + (1 + μ₁(b) + μ₁(s) + μ₁(n)) = 2 + μ₁(b) + 2·μ₁(s) + μ₁(n)`
  LHS − RHS = `−μ₁(s) ≤ 0`. ❌

- **mu2**
  LHS: `5 + μ₂(b) + μ₂(s) + 1 + μ₂(n) = 6 + μ₂(b) + μ₂(s) + μ₂(n)`
  RHS: `1 + μ₂(s) + (5 + μ₂(b) + μ₂(s) + μ₂(n)) = 6 + μ₂(b) + 2·μ₂(s) + μ₂(n)`
  LHS − RHS = `−μ₂(s) ≤ 0`. ❌

- **mu3**
  LHS: `1 + μ₃(b) + μ₃(s) + 1 + μ₃(n) = 2 + μ₃(b) + μ₃(s) + μ₃(n)`
  RHS: `2 + μ₃(s) + (1 + μ₃(b) + μ₃(s) + μ₃(n)) = 3 + μ₃(b) + 2·μ₃(s) + μ₃(n)`
  LHS − RHS = `−(1 + μ₃(s)) < 0`. ✓

### Rule 8 — `R_eq_diff`
`Step (eqW a b) (integrate (merge a b))`

- **mu1**
  LHS: `3 + μ₁(a) + μ₁(b)`
  RHS: `1 + 1 + 1 + μ₁(a) + μ₁(b) = 3 + μ₁(a) + μ₁(b)`
  LHS − RHS = `0`. ❌ (not a strict decrease)

- **mu2**
  LHS: `5 + μ₂(a) + μ₂(b)`
  RHS: `1 + 2 + 2 + μ₂(a) + μ₂(b) = 5 + μ₂(a) + μ₂(b)`
  LHS − RHS = `0`. ❌

- **mu3**
  LHS: `4 + μ₃(a) + μ₃(b)`
  RHS: `2 + 2 + 1 + μ₃(a) + μ₃(b) = 5 + μ₃(a) + μ₃(b)`
  LHS − RHS = `−1 < 0`. ✓

### Verdict

| Measure | All rules strictly decrease? |
|---|---|
| **mu1** | No — fails on `R_rec_succ` and `R_eq_diff` |
| **mu2** | No — fails on `R_rec_succ` and `R_eq_diff` |
| **mu3** | **Yes** — strictly decreases on all eight rules |

**Conclusion.** Only `mu3` is a valid termination measure for this rewrite system. `mu1` and `mu2` each fail on two rules: the recursive unrolling `R_rec_succ` (because they don't penalize `app`/`recDelta` enough to compensate for the duplicated `s`) and the equality-bridge `R_eq_diff` (because their coefficients on `eqW`, `integrate`, and `merge` are not tuned so that the wrap `integrate ∘ merge` strictly dominates `eqW`). The constants in `mu3` (`integrate` weight 2, `app` weight 2, `eqW` weight 4) are exactly what is needed to make the desired inequalities strict.
