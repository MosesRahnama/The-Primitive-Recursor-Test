We need to assess three termination measures (mu1, mu2, mu3) for the rewrite system defined by `Step`. A termination measure is a function from traces to natural numbers such that for every rewrite rule `Step t t'`, we have `mu t' < mu t` (strict decrease). If it holds for all rules, the measure is a valid termination measure (lexicographic/recursive path orderings are more sophisticated, but typically a single measure to Nat just needs to decrease).
