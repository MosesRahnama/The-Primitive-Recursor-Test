All three candidates **fail** to be valid termination measures. The rewrite rule `R_rec_succ` rewrites `recDelta b s (delta n)` to `app s (recDelta b s n)`. For each measure, the left‑hand side (LHS) is not strictly greater than the right‑hand side (RHS):

* **`mu1`**: LHS = \(2 + \mu_1(b) + \mu_1(s) + \mu_1(n)\), RHS = \(2 + \mu_1(b) + 2\mu_1(s) + \mu_1(n)\). LHS ≤ RHS (equal when \(s=0\), otherwise smaller).  
* **`mu2`**: LHS = \(6 + \mu_2(b) + \mu_2(s) + \mu_2(n)\), RHS = \(6 + \mu_2(b) + 2\mu_2(s) + \mu_2(n)\). LHS ≤ RHS.  
* **`mu3`**: LHS = \(2 + \mu_3(b) + \mu_3(s) + \mu_3(n)\), RHS = \(3 + \mu_3(b) + 2\mu_3(s) + \mu_3(n)\). LHS < RHS for all values.

Because the measure does not strictly decrease on every `Step`, none of `mu1`, `mu2`, `mu3` can serve as a termination measure for the given rewrite system (with the usual well‑founded order on `Nat`).
