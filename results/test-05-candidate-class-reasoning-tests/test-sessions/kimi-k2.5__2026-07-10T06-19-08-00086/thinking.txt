rec(b, s, 0) = b
rec(b, s, succ(n)) = s(rec(b, s, n))

Here, delta represents succ, and void represents 0.

In a typical termination measure for primitive recursion, we would use the third argument (n) as the decreasing component.

If we define mu(recDelta b s n) = mu(n), then:
LHS: mu(delta n) = 1 + mu(n)
RHS: mu(app s (recDelta b s n)) 

If we define mu(app a b) = mu(b) (i.e., the "result" of the application), then RHS = mu(recDelta b s n) = mu(n).
Then 1 + mu(n) > mu(n), which works.
