# Assessment of Termination Measures

I'll analyze each candidate by checking whether `mu(t') < mu(t)` for every rewrite rule `Step t t'`.

## **Candidate mu1: FAILS**

**Counterexample: Rule R_rec_succ**
```
Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

- `mu1 (recDelta b s (delta n))` = `1 + mu1 b + mu1 s + (1 + mu1 n)` = `2 + mu1 b + mu1 s + mu1 n`
- `mu1 (app s (recDelta b s n))` = `1 + mu1 s + (1 + mu1 b + mu1 s + mu1 n)` = `2 + mu1 b + 2·mu1 s + mu1 n`

Since `mu1 s ≥ 0`, we have `mu1(result) ≥ mu1(source)`. **Not strictly decreasing.**

## **Candidate mu2: FAILS**

**Counterexample: Rule R_eq_diff**
```
Step (eqW a b) (integrate (merge a b))
```

- `mu2 (eqW a b)` = `5 + mu2 a + mu2 b`
- `mu2 (integrate (merge a b))` = `(2 + (2 + mu2 a + mu2 b))` = `4 + mu2 a + mu2 b`

We get `mu2(result) = 4 + mu2 a + mu2 b < 5 + mu2 a + mu2 b = mu2(source)`. ✓

**But check Rule R_rec_succ:**
```
Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

- `mu2 (recDelta b s (delta n))` = `5 + mu2 b + mu2 s + (1 + mu2 n)` = `6 + mu2 b + mu2 s + mu2 n`
- `mu2 (app s (recDelta b s n))` = `1 + mu2 s + (5 + mu2 b + mu2 s + mu2 n)` = `6 + mu2 b + 2·mu2 s + mu2 n`

Again, `mu2(result) ≥ mu2(source)`. **Not strictly decreasing.**
