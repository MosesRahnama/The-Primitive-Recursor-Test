All three candidates fail to be valid termination measures for the given rewrite system. The problem lies with the `R_rec_succ` rule:

```
Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

For each measure µ, computing the values shows that µ(LHS) is not strictly greater than µ(RHS) for all possible `b`, `s`, `n`.

- **mu1**:  
  LHS = `2 + mu1 b + mu1 s + mu1 n`  
  RHS = `2 + mu1 b + 2·mu1 s + mu1 n`  
  If `s = void` (`mu1 s = 0`) then LHS = RHS, violating the strict decrease. If `s ≠ void`, RHS > LHS.

- **mu2**:  
  LHS = `6 + mu2 b + mu2 s + mu2 n`  
  RHS = `6 + mu2 b + 2·mu2 s + mu2 n`  
  Again, when `s = void` (`mu2 s = 0`) we have LHS = RHS; otherwise RHS > LHS.

- **mu3**:  
  LHS = `2 + mu3 b + mu3 s + mu3 n`  
  RHS = `3 + mu3 b + 2·mu3 s + mu3 n`  
  Here RHS > LHS for any `s` (since `mu3 s ≥ 0`), so the measure increases.

The remaining rewrite rules do decrease under each of these measures, but the failure on `R_rec_succ` alone disqualifies all three candidates. A successful termination measure would need a more sophisticated ordering (e.g., lexicographic or polynomial) to handle the duplication of `s` in this rule.
