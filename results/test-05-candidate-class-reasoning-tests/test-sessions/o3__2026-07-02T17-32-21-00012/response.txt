We test each candidate μ against every rewrite rule of

 integrate (delta t)          →  void                      (R_int_delta)
 merge void t                 →  t                         (R_merge_void_left)
 merge t void                 →  t                         (R_merge_void_right)
 merge t t                    →  t                         (R_merge_cancel)
 recDelta b s void            →  b                         (R_rec_zero)
 recDelta b s (delta n)       →  app s (recDelta b s n)    (R_rec_succ)
 eqW a a                      →  void                      (R_eq_refl)
 eqW a b                      →  integrate (merge a b)     (R_eq_diff)

For the first five and the last two rules all three measures do
strictly decrease; the critical point is the recursion rule
R_rec_succ.  We therefore compute  

  L = μ (recDelta b s (delta n))
  R = μ (app s (recDelta b s n))

for each candidate.

──────────────────────────────────────────────────────────────────────────────
μ₁ :

 L  = 1 + μ₁ b + μ₁ s + μ₁ (delta n)
    = 1 + μ₁ b + μ₁ s + (1 + μ₁ n)
    = 2 + μ₁ b + μ₁ s + μ₁ n

 R  = 1 + μ₁ s + μ₁ (recDelta b s n)
    = 1 + μ₁ s + (1 + μ₁ b + μ₁ s + μ₁ n)
    = 2 + μ₁ b + 2·μ₁ s + μ₁ n

 R – L = μ₁ s ≥ 0 (and it is  > 0 whenever s ≠ void).

Hence μ₁ grows (or stays the same when s = void) instead of decreasing.
μ₁ therefore fails.

──────────────────────────────────────────────────────────────────────────────
μ₂ :

 L  = 5 + μ₂ b + μ₂ s + μ₂ (delta n)
    = 5 + μ₂ b + μ₂ s + (1 + μ₂ n)
    = 6 + μ₂ b + μ₂ s + μ₂ n

 R  = 1 + μ₂ s + μ₂ (recDelta b s n)
    = 1 + μ₂ s + (5 + μ₂ b + μ₂ s + μ₂ n)
    = 6 + μ₂ b + 2·μ₂ s + μ₂ n

 R – L = μ₂ s ≥ 0 (strictly positive unless s = void).

So μ₂ also increases in general; it is not a valid descent
function.

──────────────────────────────────────────────────────────────────────────────
μ₃ :

 L  = 1 + μ₃ b + μ₃ s + μ₃ (delta n)
    = 1 + μ₃ b + μ₃ s + (1 + μ₃ n)
    = 2 + μ₃ b + μ₃ s + μ₃ n

 R  = 2 + μ₃ s + μ₃ (recDelta b s n)
    = 2 + μ₃ s + (1 + μ₃ b + μ₃ s + μ₃ n)
    = 3 + μ₃ b + 2·μ₃ s + μ₃ n

 R – L = 1 + μ₃ s > 0.

Again the measure grows, so μ₃ also fails.

──────────────────────────────────────────────────────────────────────────────
Conclusion

• μ₁, μ₂ and μ₃ all strictly decrease on every rule except
  R_rec_succ.

• On R_rec_succ the right-hand side contains an extra copy of s,
  whereas the left-hand side merely loses one outer delta.  
  Because the weight given to a Δ (delta) node is a fixed constant
  while the weight of the sub-trace s can be arbitrarily large, the
  three single-number measures cannot dominate this duplication.
  
Therefore none of the three proposed measures is a valid global
termination measure for the rewrite system.  A successful proof of
termination will require either

  – a different weighting that scales with the size of s, or  
  – a multicomponent/lexicographic measure that counts the remaining
    nesting of Δ’s separately from the overall size of the term.
