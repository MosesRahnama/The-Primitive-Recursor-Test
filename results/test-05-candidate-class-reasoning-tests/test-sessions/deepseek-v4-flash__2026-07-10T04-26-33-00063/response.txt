All three candidates fail to be valid termination measures for the rewrite system.  

- **mu1**, **mu2**, and **mu3** satisfy the strict decrease condition for rules 1–5, 7, and 8.  
- However, for the critical rule **R_rec_succ** ( `recDelta b s (delta n) → app s (recDelta b s n)` ), each measure assigns a value to the right‑hand side that is **greater than or equal** to the value of the left‑hand side.  
  - For mu1: LHS = `2 + mu1(b) + mu1(s) + mu1(n)`, RHS = `2 + mu1(b) + 2·mu1(s) + mu1(n)` → RHS ≥ LHS, equal only when `mu1(s) = 0`.  
  - For mu2: LHS = `6 + mu2(b) + mu2(s) + mu2(n)`, RHS = `6 + mu2(b) + 2·mu2(s) + mu2(n)` → same pattern.  
  - For mu3: LHS = `2 + mu3(b) + mu3(s) + mu3(n)`, RHS = `3 + mu3(b) + 2·mu3(s) + mu3(n)` → RHS is strictly larger by `1 + mu3(s)`.  

Since a termination measure must strictly decrease on **every** rewrite step, none of the proposed measures works.
