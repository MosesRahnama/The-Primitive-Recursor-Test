## Checking mu1

**R_int_delta**: `integrate(delta t)` → `void`
- LHS: 1 + (1 + μ(t)) = 2 + μ(t) > 0 ✓

**R_merge_void_left**: `merge void t` → `t`
- LHS: 1 + 0 + μ(t) = 1 + μ(t) > μ(t) ✓

**R_merge_void_right**: similarly ✓

**R_merge_cancel**: `merge t t` → `t`
- LHS: 1 + μ(t) + μ(t) = 1 + 2μ(t) > μ(t) ✓

**R_rec_zero**: `recDelta b s void` → `b`
- LHS: 1 + β + σ + 0 = 1 + β + σ > β ✓

**R_rec_succ**: `recDelta b s (delta n)` → `app s (recDelta b s n)`
- LHS: 1 + β + σ + (1 + ν) = 2 + β + σ + ν
- RHS: 1 + σ + (1 + β + σ + ν) = 2 + β + 2σ + ν
- Need LHS > RHS: 2 + β + σ + ν > 2 + β + 2σ + ν → 0 > σ. **FAILS** when σ > 0. ✗

**mu1 fails** on R_rec_succ.
