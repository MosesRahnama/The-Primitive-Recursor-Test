Great, let’s audit each proposed measure against all rewrite rules.

A valid termination measure `μ` for this one-step relation should satisfy, for every rule `Step l r`:
\[
\mu(l) > \mu(r).
\]

### Rules to check

1. `integrate (delta t) → void`
2. `merge void t → t`
3. `merge t void → t`
4. `merge t t → t`
5. `recDelta b s void → b`
6. `recDelta b s (delta n) → app s (recDelta b s n)`
7. `eqW a a → void`
8. `eqW a b → integrate (merge a b)`

## Candidate `mu1`

`mu1`:
- `integrate`: `1 + ...`
- `merge`: `1 + ... + ...`
- `app`: `1 + ... + ...`
- `recDelta`: `1 + ... + ... + ...`
- `eqW`: `3 + ... + ...`

Most rules strictly decrease, but check rule 6:

- LHS:
  \[
  \mu_1(recDelta\, b\, s\, (delta\, n)) = 1 + \mu_1 b + \mu_1 s + (1 + \mu_1 n) = 2 + \mu_1 b + \mu_1 s + \mu_1 n
  \]
- RHS:
  \[
  \mu_1(app\, s\, (recDelta\, b\, s\, n)) = 1 + \mu_1 s + (1 + \mu_1 b + \mu_1 s + \mu_1 n)
  = 2 + \mu_1 b + 2\mu_1 s + \mu_1 n
  \]

Difference:
\[
\mu_1(\text{LHS}) - \mu_1(\text{RHS}) = -\mu_1 s.
\]

So it is **not decreasing in general** (equal if `s=void`, increasing RHS otherwise).  
❌ `mu1` is **not** a termination measure.

## Candidate `mu2`

`mu2`:
- `integrate`: weight 2
- `merge`: weight 2
- `app`: weight 1
- `recDelta`: weight 5
- `eqW`: weight 5

Critical checks:

- Rule 6:
  \[
  \mu_2(recDelta\, b\, s\, (delta\, n)) = 5+\mu_2 b+\mu_2 s+(1+\mu_2 n)=6+\mu_2 b+\mu_2 s+\mu_2 n
  \]
  \[
  \mu_2(app\, s\, (recDelta\, b\, s\, n)) = 1+\mu_2 s+(5+\mu_2 b+\mu_2 s+\mu_2 n)=6+\mu_2 b+2\mu_2 s+\mu_2 n
  \]
  Difference = `- mu2 s`, so fails whenever `s ≠ void`.

- Rule 8:
  \[
  \mu_2(eqW\, a\, b)=5+\mu_2 a+\mu_2 b
  \]
  \[
  \mu_2(integrate(merge\, a\, b))=2+(2+\mu_2 a+\mu_2 b)=4+\mu_2 a+\mu_2 b
  \]
  This one decreases by 1, fine.

But because of rule 6, overall invalid.  
❌ `mu2` is **not** a termination measure.

## Candidate `mu3`

`mu3`:
- `integrate`: 2
- `merge`: 1
- `app`: 2
- `recDelta`: 1
- `eqW`: 4

Check rule 6 again:

- LHS:
  \[
  \mu_3(recDelta\, b\, s\, (delta\, n)) = 1+\mu_3 b+\mu_3 s+(1+\mu_3 n)=2+\mu_3 b+\mu_3 s+\mu_3 n
  \]
- RHS:
  \[
  \mu_3(app\, s\, (recDelta\, b\, s\, n)) = 2+\mu_3 s+(1+\mu_3 b+\mu_3 s+\mu_3 n)
  =3+\mu_3 b+2\mu_3 s+\mu_3 n
  \]

Difference:
\[
\mu_3(\text{LHS})-\mu_3(\text{RHS}) = -1-\mu_3 s < 0.
\]
RHS is always strictly larger, so definitely fails.

Also rule 8:
\[
\mu_3(eqW\, a\, b)=4+\mu_3 a+\mu_3 b,\quad
\mu_3(integrate(merge\, a\, b))=2+(1+\mu_3 a+\mu_3 b)=3+\mu_3 a+\mu_3 b
\]
This one decreases, but rule 6 kills it.  
❌ `mu3` is **not** a termination measure.

## Final assessment

- `mu1`: **invalid**
- `mu2`: **invalid**
- `mu3`: **invalid**

All three fail on the recursive-step rule
\[
recDelta\, b\, s\, (delta\, n) \to app\, s\, (recDelta\, b\, s\, n),
\]
because `s` is duplicated on the right (once as function in `app`, once inside recursive call), and each candidate gives nonnegative size to `s`, making strict decrease impossible with a plain additive scalar measure of this form.
