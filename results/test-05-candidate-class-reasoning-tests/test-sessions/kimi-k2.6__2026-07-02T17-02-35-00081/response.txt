To be a valid termination measure, a function `μ : Trace → Nat` must **strictly decrease** on every rewrite step: if `Step l r`, then `μ l > μ r`.

All three candidates handle the “easy” rules comfortably:

- **`R_int_delta`**, **`R_merge_void_left/right`**, **`R_merge_cancel`**, **`R_rec_zero`**, **`R_eq_refl`**, and **`R_eq_diff`** all strictly decrease under `mu1`, `mu2`, and `mu3` because the positive constants assigned to the left-hand-side constructors outweigh the right-hand-side expressions.

The single rule that defeats all three candidates is **`R_rec_succ`**:

```
recDelta b s (delta n)  →  app s (recDelta b s n)
```

This rule **duplicates** the step argument `s`. Because the measures are additive over subterms, that duplication introduces an extra copy of `μ(s)` on the right-hand side that cannot be compensated by the fixed constants.

---

### Candidate 1: `mu1`

For `R_rec_succ`:
- LHS: `mu1 (recDelta b s (delta n)) = 1 + mu1 b + mu1 s + (1 + mu1 n) = 2 + mu1 b + mu1 s + mu1 n`
- RHS: `mu1 (app s (recDelta b s n)) = 1 + mu1 s + (1 + mu1 b + mu1 s + mu1 n) = 2 + mu1 b + 2·mu1 s + mu1 n`

Difference: `RHS − LHS = mu1 s`.

*Verdict:* **Invalid.**  
If `s = void` (so `mu1 s = 0`), the measure is unchanged (`2 + mu1 b + mu1 n` on both sides). If `s` is larger, the measure **increases**. It never strictly decreases.

---

### Candidate 2: `mu2`

For `R_rec_succ`:
- LHS: `mu2 (recDelta b s (delta n)) = 5 + mu2 b + mu2 s + (1 + mu2 n) = 6 + mu2 b + mu2 s + mu2 n`
- RHS: `mu2 (app s (recDelta b s n)) = 1 + mu2 s + (5 + mu2 b + mu2 s + mu2 n) = 6 + mu2 b + 2·mu2 s + mu2 n`

Difference: `RHS − LHS = mu2 s`.

*Verdict:* **Invalid.**  
Same structural failure as `mu1`: when `s = void` the two sides are equal, and for any non-void `s` the measure grows.

---

### Candidate 3: `mu3`

For `R_rec_succ`:
- LHS: `mu3 (recDelta b s (delta n)) = 1 + mu3 b + mu3 s + (1 + mu3 n) = 2 + mu3 b + mu3 s + mu3 n`
- RHS: `mu3 (app s (recDelta b s n)) = 2 + mu3 s + (1 + mu3 b + mu3 s + mu3 n) = 3 + mu3 b + 2·mu3 s + mu3 n`

Difference: `RHS − LHS = 1 + mu3 s`.

*Verdict:* **Invalid.**  
Here the RHS is **strictly larger** than the LHS for *every* possible `s` (even when `s = void`). The measure not only fails to decrease, it strictly increases on this step.

---

### Summary

| Candidate | Fails on `R_rec_succ`? | Behavior on `R_rec_succ` |
|-----------|------------------------|--------------------------|
| `mu1`     | Yes                    | Unchanged if `s = void`, increases otherwise |
| `mu2`     | Yes                    | Unchanged if `s = void`, increases otherwise |
| `mu3`     | Yes                    | Strictly increases always |

**None of the three candidates is a valid termination measure.** The fundamental obstacle is the duplication of `s` in `R_rec_succ`: any purely additive structural measure inevitably picks up an extra `μ(s)` on the right-hand side, and because `s` can be an arbitrarily large trace, no fixed choice of positive constants can force a strict decrease on this rule.
