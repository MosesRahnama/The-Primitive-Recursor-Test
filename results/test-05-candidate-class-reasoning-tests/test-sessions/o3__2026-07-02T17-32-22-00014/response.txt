Goal of a termination/​complexity measure μ  
For every constructor  

    Step  lhs  rhs

we must have μ lhs  >  μ rhs (strict descent in ℕ).

Below N₁, N₂, N₃ denote μ1 , μ2 , μ3 respectively.



1.  Rules that all three candidates satisfy
    • integrate (δ t) → void  
      N₁=2+N₁ t , N₂=3+N₂ t , N₃=3+N₃ t  >0  
    • merge-void-left / merge-void-right  
      N₁=1+…, N₂=2+…, N₃=1+… > rhs  
    • merge-cancel  
      1+2·N*>N*  (holds for all three)  
    • recDelta-zero  
      N₁=1+N b+N s, N₂=5+…, N₃=1+…  > N b  
    • eqW-refl  
      obvious (extra constant)  
    • eqW-diff  
      lhs−rhs = 1  for the three measures

   Up to this point the candidates look fine.



2.  The critical rule:  recDelta-succ  

       recDelta b s (δ n)   →   app s (recDelta b s n)


   Compute the three measures.

   μ1
   lhs :  2 + N₁ b + N₁ s + N₁ n  
   rhs :  2 + N₁ b + 2·N₁ s + N₁ n  
   rhs − lhs = N₁ s  ≥ 0.  
   Descent fails whenever N₁ s ≠ 0 (and is even equal when N₁ s = 0).

   μ2
   lhs :  6 + N₂ b + N₂ s + N₂ n  
   rhs :  6 + N₂ b + 2·N₂ s + N₂ n  
   rhs − lhs = N₂ s  ≥ 0.  Same problem.

   μ3
   lhs :  2 + N₃ b + N₃ s + N₃ n  
   rhs :  3 + N₃ b + 2·N₃ s + N₃ n  
   rhs − lhs = 1 + N₃ s  ≥ 1.  Even worse.

   Therefore none of the three proposed measures is strictly
   decreasing on the recDelta-succ rule, so none of them can serve as
   a global termination measure for the calculus.



3.  Verdict

   • μ1  passes all rules except recDelta-succ ⇒ not a termination
     measure.

   • μ2  behaves exactly like μ1 on the offending rule ⇒ also not a
     termination measure.

   • μ3  is strictly larger on the right-hand side of recDelta-succ
     (by 1+μ3 s) ⇒ fails even more clearly.

In short, all three candidates are inadequate; the system still needs
a different weight assignment (or a multicomponent measure) that
penalises the application constructor more heavily than the recursion
constructor so that

    μ (recDelta b s (δ n))  >  μ (app s (recDelta b s n))

holds unconditionally.
