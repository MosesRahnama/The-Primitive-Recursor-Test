Outcome of the audit

• μ₁ is NOT a termination measure  
• μ₂ is NOT a termination measure  
• μ₃ is NOT a termination measure  

Why they all fail

For every candidate the only troublesome rule is

  R_rec_succ :
        recDelta b s (delta n)  ⟶  app s (recDelta b s n)

Because the constants and weights are additive, each measure gives  

    μ (recDelta b s (delta n))  =  C₁ + μ b + μ s + μ n
    μ (app s (recDelta b s n))  =  C₂ + μ b + 2·μ s + μ n

with C₂ = C₁ + 1 for μ₃,  C₂ = C₁ for μ₁,  and  C₂ = C₁ for μ₂.  
Hence

    μ (rhs) − μ (lhs) = μ s        (μ₁, μ₂)
    μ (rhs) − μ (lhs) = 1 + μ s    (μ₃)

So the value of the measure either stays the same (if μ s = 0) or
increases (if μ s > 0).  It never decreases, which is required for a
termination metric.

All other rules do strictly decrease every candidate measure, but that is
not enough: a single non-decreasing step breaks global well-foundedness.

Conclusion

None of the three proposals is suitable.  A successful measure has to
give the sub-term s a negative weight in the right–hand side of
R_rec_succ, or employ a different (e.g. lexicographic or multiset-based)
ordering instead of a simple additive size.
