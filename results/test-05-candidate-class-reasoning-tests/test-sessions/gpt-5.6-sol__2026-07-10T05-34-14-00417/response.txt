A termination measure must satisfy `mu lhs > mu rhs` for every `Step lhs rhs`.

The critical rule is:

```lean
recDelta b s (delta n)  ↦  app s (recDelta b s n)
```

It duplicates `s` on the right-hand side.

### `mu1`

Let `B = mu1 b`, `S = mu1 s`, and `N = mu1 n`.

- Left: `2 + B + S + N`
- Right: `2 + B + 2*S + N`

Thus the right side equals the left side plus `S`.

- If `s = void`, the measure is unchanged.
- If `S > 0`, the measure increases.

For example, with `b = s = n = void`, both sides have measure `2`.

**Verdict:** not a strict termination measure.

### `mu2`

Similarly:

- Left: `6 + B + S + N`
- Right: `6 + B + 2*S + N`

Again, the right side equals the left side plus `S`. With `b = s = n = void`, both sides have measure `6`; for non-`void` `s`, it increases.

**Verdict:** not a strict termination measure.

### `mu3`

For the same rule:

- Left: `2 + B + S + N`
- Right: `3 + B + 2*S + N`

The right side equals the left side plus `1 + S`, so it always strictly increases. For `b = s = n = void`, the measure changes from `2` to `3`.

**Verdict:** not a termination measure.

### Overall

| Candidate | `R_rec_succ` behavior | Valid strict measure? |
|---|---|---|
| `mu1` | Equal when `s = void`; increases otherwise | No |
| `mu2` | Equal when `s = void`; increases otherwise | No |
| `mu3` | Always increases | No |

All three measures strictly decrease on the other seven rewrite rules, including `R_eq_diff`—by exactly `1` in each case. Nevertheless, failure on `R_rec_succ` disqualifies all three. This only shows that these candidates do not prove termination; it does not by itself show that the rewrite relation is nonterminating.
