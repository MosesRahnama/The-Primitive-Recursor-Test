**Assessment**

All three candidate measures fail to be valid termination measures for the rewrite system. Each satisfies most of the rewrite rules, but all fail on the crucial rule **`R_rec_succ`**, which duplicates the step argument `s`.

Below is the detailed analysis. For a measure `μ` to prove termination, we require `μ(t) > μ(t')` for every step `t → t'`.

---

### 1. Analysis of `R_rec_succ`

The rule is:
```
recDelta b s (delta n)  →  app s (recDelta b s n)
```

Let `μ` be any of the three measures. All define `μ(recDelta b s n)` as a constant plus `μ(b) + μ(s) + μ(n)`, and `μ(app a b)` as a constant plus `μ(a) + μ(b)`. All assign `delta` a positive weight (1 for `mu1`, 1 for `mu2`, 1 for `mu3`).

**Left-hand side:**
```
μ(recDelta b s (delta n)) = w_rec + μ(b) + μ(s) + (w_delta + μ(n))
                         = (w_rec + w_delta) + μ(b) + μ(s) + μ(n)
```

**Right-hand side:**
```
μ(app s (recDelta b s n)) = w_app + μ(s) + (w_rec + μ(b) + μ(s) + μ(n))
                         = (w_app + w_rec) + μ(b) + 2·μ(s) + μ(n)
```

**Comparison:**
For a strict decrease, we need:
```
(w_rec + w_delta) + μ(s)  >  (w_app + w_rec) + 2·μ(s)
w_delta  >  w_app + μ(s)
```

Since `μ(s)` can be any natural number (arbitrarily large), no choice of constant weights `w_delta` and `w_app` can satisfy this inequality for all traces `s`.

**Concrete failure for each candidate:**

| Measure | LHS (`recDelta b s (delta n)`) | RHS (`app s (recDelta b s n)`) | Difference (RHS − LHS) |
|---------|-------------------------------|-------------------------------|------------------------|
| **mu1** | `2 + mu1(b) + mu1(s) + mu1(n)` | `2 + mu1(b) + 2·mu1(s) + mu1(n)` | `mu1(s)` |
| **mu2** | `6 + mu2(b) + mu2(s) + mu2(n)` | `6 + mu2(b) + 2·mu2(s) + mu2(n)` | `mu2(s)` |
| **mu3** | `2 + mu3(b) + mu3(s) + mu3(n)` | `3 + mu3(b) + 2·mu3(s) + mu3(n)` | `1 + mu3(s)` |

In all cases, when `μ(s) > 0`, the measure strictly **increases** across the rewrite step, violating the termination requirement. When `s = void` (so `μ(s) = 0`), `mu1` and `mu2` produce equal measures (no decrease), while `mu3` still increases.

---

### 2. Analysis of Other Rules (for completeness)

All three measures successfully handle the other rules:

*   **`R_int_delta`**: `integrate (delta t) → void`  
    All assign positive weight to `integrate` and `delta`, so LHS ≥ 2 + μ(t) > 0 = μ(void).

*   **`R_merge_void_left/right`**: `merge void t → t` and `merge t void → t`  
    LHS = `w_merge + μ(t)` > `μ(t)` since `w_merge` is 1 (mu1/mu3) or 2 (mu2).

*   **`R_merge_cancel`**: `merge t t → t`  
    LHS = `w_merge + 2·μ(t)` > `μ(t)`.

*   **`R_rec_zero`**: `recDelta b s void → b`  
    LHS = `w_rec + μ(b) + μ(s)` > `μ(b)`.

*   **`R_eq_refl`**: `eqW a a → void`  
    LHS = `w_eq + 2·μ(a)` > 0.

*   **`R_eq_diff`**: `eqW a b → integrate (merge a b)`  
    *   **mu1**: `3 + a + b` vs `1 + (1 + a + b) = 2 + a + b`. (3 > 2, OK)
    *   **mu2**: `5 + a + b` vs `2 + (2 + a + b) = 4 + a + b`. (5 > 4, OK)
    *   **mu3**: `4 + a + b` vs `2 + (1 + a + b) = 3 + a + b`. (4 > 3, OK)

---

### Conclusion

- **mu1**: Invalid. Fails `R_rec_succ` (measure increases by `mu1(s)`).
- **mu2**: Invalid. Fails `R_rec_succ` (measure increases by `mu2(s)`).
- **mu3**: Invalid. Fails `R_rec_succ` (measure increases by `1 + mu3(s)`).

No linear measure of the given form (constant weight plus sum of recursive measures) can prove termination for this system because `R_rec_succ` duplicates the subterm `s`. A valid termination measure would require a non-linear weighting (e.g., making the cost of `recDelta` quadratic in `μ(s)`, or using a lexicographic ordering) to account for the duplication.
