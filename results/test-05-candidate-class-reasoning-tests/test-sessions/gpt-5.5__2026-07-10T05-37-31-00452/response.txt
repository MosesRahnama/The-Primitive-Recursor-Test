All three proposed measures fail as strict termination measures for `Step`.

A valid Nat-valued termination measure would need, for every rule,

```lean
Step lhs rhs → μ lhs > μ rhs
```

The only problematic rule is `R_rec_succ`:

```lean
Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

## `mu1`

For `R_rec_succ`:

```text
mu1 (recDelta b s (delta n))
= 1 + mu1 b + mu1 s + (1 + mu1 n)
= 2 + mu1 b + mu1 s + mu1 n
```

but

```text
mu1 (app s (recDelta b s n))
= 1 + mu1 s + (1 + mu1 b + mu1 s + mu1 n)
= 2 + mu1 b + 2 * mu1 s + mu1 n
```

So the RHS is larger by `mu1 s`, or equal when `s = void`.

Example equality:

```text
mu1 (recDelta void void (delta void)) = 2
mu1 (app void (recDelta void void void)) = 2
```

So `mu1` is not strictly decreasing.

## `mu2`

Similarly:

```text
mu2 (recDelta b s (delta n))
= 5 + mu2 b + mu2 s + (1 + mu2 n)
= 6 + mu2 b + mu2 s + mu2 n
```

while

```text
mu2 (app s (recDelta b s n))
= 1 + mu2 s + (5 + mu2 b + mu2 s + mu2 n)
= 6 + mu2 b + 2 * mu2 s + mu2 n
```

Again the RHS is larger by `mu2 s`, or equal when `s = void`.

Example equality:

```text
mu2 (recDelta void void (delta void)) = 6
mu2 (app void (recDelta void void void)) = 6
```

So `mu2` also fails.

## `mu3`

For `mu3`:

```text
mu3 (recDelta b s (delta n))
= 1 + mu3 b + mu3 s + (1 + mu3 n)
= 2 + mu3 b + mu3 s + mu3 n
```

but

```text
mu3 (app s (recDelta b s n))
= 2 + mu3 s + (1 + mu3 b + mu3 s + mu3 n)
= 3 + mu3 b + 2 * mu3 s + mu3 n
```

Here the RHS is always larger by `1 + mu3 s`.

Example:

```text
mu3 (recDelta void void (delta void)) = 2
mu3 (app void (recDelta void void void)) = 3
```

So `mu3` fails even more directly.

## Other rules

The remaining rules decrease under all three measures, including:

```lean
integrate (delta t)       ↦ void
merge void t              ↦ t
merge t void              ↦ t
merge t t                 ↦ t
recDelta b s void         ↦ b
eqW a a                   ↦ void
eqW a b                   ↦ integrate (merge a b)
```

In particular, the `eqW`/`integrate`/`merge` weights were chosen so that `R_eq_diff` decreases by exactly `1` for all three measures.

## Verdict

| Measure | Valid strict termination measure? | Reason |
|---|---:|---|
| `mu1` | No | `R_rec_succ` is non-decreasing; equal when `s = void`, increasing otherwise |
| `mu2` | No | same failure as `mu1` |
| `mu3` | No | `R_rec_succ` strictly increases |

Thus none of the three candidates proves termination of `Step` by simple strict descent on `Nat`.
