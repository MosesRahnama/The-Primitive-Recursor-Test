**Short answer:** none of the three measures is a valid termination measure for the given rewrite system. All of them fail on the rule `R_rec_succ`, because that rule duplicates the subterm `s` and the constants chosen in `mu1`, `mu2` and `mu3` cannot compensate for an extra copy of an arbitrarily large term.

---

### What is required
A function `μ : Trace → Nat` is a termination measure iff **for every step** `Step t₁ t₂` we have `μ t₁ > μ t₂`.

All three candidates are *homomorphic* (or *size-like*) measures: each constructor contributes a fixed non‑negative weight plus the sum of the measures of its children.  
Let us write `|t|` for `μᵢ t`. For `R_rec_succ`

```
recDelta b s (delta n)  →  app s (recDelta b s n)
```

the left- and right-hand side sizes are

* LHS: `W_rec + |b| + |s| + W_delta + |n|`
* RHS: `W_app + |s| + W_rec + |b| + |s| + |n|`

so the difference is

```
|LHS| – |RHS| = (W_delta – W_app) – |s|
```

Because `|s|` can be any natural number (e.g. a tall tower of `delta`s), a fixed choice of `W_delta` and `W_app` can never make this difference strictly positive for **all** `s`. This single rule dooms every additive measure of the given shape.

Below is the exact failure for each candidate.

---

### Candidate `mu1`

Weights: `delta` = 1, `app` = 1, `recDelta` = 1.

For `R_rec_succ`:

```
mu1(recDelta b s (delta n)) = 2 + mu1 b + mu1 s + mu1 n
mu1(app s (recDelta b s n)) = 2 + mu1 b + 2·mu1 s + mu1 n
```

The RHS is larger by `mu1 s`.

*Counterexample:* `b = void`, `s = void`, `n = void`.  
LHS = `recDelta void void (delta void)` has measure **2**.  
RHS = `app void (recDelta void void void)` also has measure **2**.  
No strict decrease. If `s` is larger (e.g. `delta void`) the measure actually **increases**.

**Verdict:** `mu1` is **not** a termination measure.

---

### Candidate `mu2`

Weights: `delta` = 1, `app` = 1, `recDelta` = 5.

For `R_rec_succ`:

```
mu2(recDelta b s (delta n)) = 6 + mu2 b + mu2 s + mu2 n
mu2(app s (recDelta b s n)) = 6 + mu2 b + 2·mu2 s + mu2 n
```

Again the RHS exceeds the LHS by `mu2 s`.

*Counterexample:* `b = void`, `s = void`, `n = void`.  
Both sides have measure **6**; equality, not a strict decrease.  
For any non‑void `s` the measure goes up.

**Verdict:** `mu2` is **not** a termination measure.

---

### Candidate `mu3`

Weights: `delta` = 1, `app` = 2, `recDelta` = 1.

For `R_rec_succ`:

```
mu3(recDelta b s (delta n)) = 2 + mu3 b + mu3 s + mu3 n
mu3(app s (recDelta b s n)) = 3 + mu3 b + 2·mu3 s + mu3 n
```

The RHS is larger by `1 + mu3 s`. Even in the smallest case `s = void` the measure **strictly increases**.

*Counterexample:* `b = void`, `s = void`, `n = void`.  
LHS measure = **2**, RHS measure = **3**.

**Verdict:** `mu3` is **not** a termination measure; in fact it always grows on this rule.

---

### Summary of the other rules
For completeness, all three measures *do* strictly decrease on the remaining seven rules:

| Rule | `mu1` | `mu2` | `mu3` |
|------|-------|-------|-------|
| `R_int_delta` | 2+|t| → 0 | 3+|t| → 0 | 3+|t| → 0 |
| `R_merge_void_left/right` | 1+|t| → |t| | 2+|t| → |t| | 1+|t| → |t| |
| `R_merge_cancel` | 1+2|t| → |t| | 2+2|t| → |t| | 1+2|t| → |t| |
| `R_rec_zero` | 1+|b|+|s| → |b| | 5+|b|+|s| → |b| | 1+|b|+|s| → |b| |
| `R_eq_refl` | 3+2|a| → 0 | 5+2|a| → 0 | 4+2|a| → 0 |
| `R_eq_diff` | 3+|a|+|b| → 2+|a|+|b| | 5+|a|+|b| → 4+|a|+|b| | 4+|a|+|b| → 3+|a|+|b| |

The only obstacle is `R_rec_succ`.

---

### Conclusion
- **`mu1`** fails because `R_rec_succ` yields equality when `s = void` and an increase otherwise.  
- **`mu2`** fails for the identical reason (equality at `s = void`, increase otherwise).  
- **`mu3`** fails more dramatically: `R_rec_succ` strictly increases `mu3` for **every** choice of `s`.

**None of the three candidates is a valid termination measure for the `Step` relation.** The fundamental problem is that `R_rec_succ` duplicates the subterm `s`, and a simple additive weighting cannot offset an arbitrarily large duplicated term.
