All three candidates fail as global termination measures because none strictly decreases on every `Step`, specifically on `R_rec_succ`.

For a rule instance

```lean
Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

the measures behave as follows.

### `mu1`

The left-hand side has measure

```text
1 + mu1 b + mu1 s + (1 + mu1 n)
= 2 + mu1 b + mu1 s + mu1 n
```

The right-hand side has measure

```text
1 + mu1 s + (1 + mu1 b + mu1 s + mu1 n)
= 2 + mu1 b + 2 * mu1 s + mu1 n
```

Thus the right-hand side exceeds the left-hand side by `mu1 s`. It is strictly larger whenever `s` is non-`void`.

For example, taking `b = void`, `s = delta void`, and `n = void`, the measures are `3` and `4`.

Therefore, **`mu1` is invalid**.

### `mu2`

Similarly, the left-hand side has measure

```text
6 + mu2 b + mu2 s + mu2 n
```

while the right-hand side has measure

```text
6 + mu2 b + 2 * mu2 s + mu2 n
```

Again, the right-hand side exceeds the left-hand side by `mu2 s`, so any non-`void` `s` gives a counterexample.

Therefore, **`mu2` is invalid**.

### `mu3`

Here the left-hand side has measure

```text
2 + mu3 b + mu3 s + mu3 n
```

and the right-hand side has measure

```text
3 + mu3 b + 2 * mu3 s + mu3 n
```

The right-hand side is always larger by `1 + mu3 s`, even when `s = void`.

Therefore, **`mu3` is invalid**.

The other rewrite rules decrease each candidate, but failure on `R_rec_succ` is enough to reject all three.
