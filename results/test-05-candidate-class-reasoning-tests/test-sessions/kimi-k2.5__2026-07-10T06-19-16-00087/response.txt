**Assessment of Termination Measures**

All three candidate measures fail to prove termination of the rewrite system. They handle most rules correctly but all break on the **`R_rec_succ`** rule.

### The Critical Issue: Rule `R_rec_succ`

The rule `recDelta b s (delta n) → app s (recDelta b s n)` duplicates the step argument `s`: it appears once in the left-hand side but twice in the right-hand side (once in the `app` and once in the recursive `recDelta` call).

For a linear measure `μ` of the form used here, we have:
- Left: `μ(recDelta b s (delta n)) = c_rec + |b| + |s| + (c_delta + |n|)`
- Right: `μ(app s (recDelta b s n)) = c_app + |s| + (c_rec + |b| + |s| + |n|)`

For strict decrease, we need: `c_delta > c_app + |s|`

Since `|s|` can be arbitrarily large (as `s` is an arbitrary trace), **no constant coefficients can satisfy this inequality**. Consequently, any measure where `s` has a positive coefficient in `recDelta` will fail.

### Analysis by Candidate

**`mu1`**:
- **Coefficient on `s`**: 1 in `recDelta`, 1 in `app` (total 2 on RHS).
- **Behavior on `R_rec_succ`**: 
  - If `s = void`: `mu1` stays unchanged (stagnation: `2 + |b| + |n|` → `2 + |b| + |n|`).
  - If `s ≠ void`: `mu1` **increases** (since `|s| > 0` implies LHS has `|s|` while RHS has `2|s|`).
- **Verdict**: Invalid. Does not strictly decrease.

**`mu2`**:
- **Coefficient on `s`**: 1 in `recDelta`, 1 in `app` (total 2 on RHS).
- **Behavior on `R_rec_succ`**:
  - If `s = void`: `mu2` stays unchanged (stagnation: `6 + |b| + |n|` → `6 + |b| + |n|`).
  - If `s ≠ void`: `mu2` **increases**.
- **Verdict**: Invalid. Does not strictly decrease.

**`mu3`**:
- **Coefficient on `s`**: 1 in `recDelta`, 1 in `app` (total 2 on RHS), with higher constant overhead on `app`.
- **Behavior on `R_rec_succ`**: 
  - Always **increases**: LHS is `2 + |b| + |s| + |n|`, RHS is `3 + |b| + 2|s| + |n|`, giving a net increase of `1 + |s| ≥ 1`.
- **Verdict**: Invalid. Strictly increases on this step.

### Other Rules

All three measures correctly handle the other seven rules:
- **`R_int_delta`**, **`R_merge_void_left/right`**, **`R_merge_cancel`**, **`R_rec_zero`**, **`R_eq_refl`**, **`R_eq_diff`**: All show strict decrease for `mu1`, `mu2`, and `mu3`.

### Conclusion

None of the three candidates are valid termination measures. They all fail on the primitive recursion step `R_rec_succ` because they cannot account for the duplication of the step argument `s`. To prove termination, a measure would need to assign a weight to `recDelta` that grows with `s` (e.g., a non-linear measure or a lexicographic ordering), or the system would need a different encoding of recursion that doesn't duplicate `s`.
