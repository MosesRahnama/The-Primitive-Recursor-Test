**Short answer:**  
None of the three measures is a correct termination‑measure for the rewrite system.  
All three fail on the rule  

```
R_rec_succ :  recDelta b s (delta n)  →  app s (recDelta b s n)
```

and they fail in slightly different ways:

| measure | what happens on `R_rec_succ` | verdict |
|---------|------------------------------|---------|
| **μ₁**  | `μ₁(recDelta b s (delta n)) = 2 + μ₁(b) + μ₁(s) + μ₁(n)`<br>`μ₁(app s (recDelta b s n)) = 2 + μ₁(b) + 2·μ₁(s) + μ₁(n)`<br>Difference = `‑μ₁(s)` → ≤ 0 (equality when `s = void`) | **not strictly decreasing** |
| **μ₂**  | `μ₂(recDelta b s (delta n)) = 6 + μ₂(b) + μ₂(s) + μ₂(n)`<br>`μ₂(app s (recDelta b s n)) = 6 + μ₂(b) + 2·μ₂(s) + μ₂(n)`<br>Difference = `‑μ₂(s)` → ≤ 0 (equality when `s = void`) | **not strictly decreasing** |
| **μ₃**  | `μ₃(recDelta b s (delta n)) = 2 + μ₃(b) + μ₃(s) + μ₃(n)`<br>`μ₃(app s (recDelta b s n)) = 3 + μ₃(b) + 2·μ₃(s) + μ₃(n)`<br>Difference = `‑1 ‑ μ₃(s) < 0` → the left‑hand side is **smaller** than the right‑hand side, i.e. the measure would *increase* on this step | **wrong direction** |

All other rewrite rules are satisfied by each measure:

* `R_int_delta`                                                                        `μ_i(integrate (delta t)) > 0`
* `R_merge_void_left/right`                                  `μ_i(merge void t) > μ_i(t)` etc.
* `R_merge_cancel`                                     `μ_i(merge t t) > μ_i(t)`
* `R_rec_zero`                                     `μ_i(recDelta b s void) > μ_i(b)`
* `R_eq_refl`                                     `μ_i(eqW a a) > 0`
* `R_eq_diff`                                    `μ_i(eqW a b) > μ_i(integrate (merge a b))`

Because the recursion rule is not (strictly) decreasing for any of the three definitions, **none of them can serve as a termination‑measure for the given rewrite system**. (If a non‑strictly decreasing measure were acceptable, μ₁ and μ₂ would be non‑increasing, but the standard definition requires a strict decrease.)
