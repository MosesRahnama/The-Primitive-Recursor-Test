# Assessment of Termination Measures for the Rewrite Calculus

I'll analyze each proposed measure (mu1, mu2, mu3) by checking whether it strictly decreases for every rewrite rule in the `Step` relation.

## Summary Table

| Rule | LHS → RHS | mu1 | mu2 | mu3 |
|------|-----------|-----|-----|-----|
| R_int_delta | `integrate (delta t)` → `void` | ✓ | ✓ | ✓ |
| R_merge_void_left | `merge void t` → `t` | ✓ | ✓ | ✓ |

## Detailed Analysis

### R_rec_succ (Critical Rule)

**LHS:** `recDelta b s (delta n)` → **RHS:** `app s (recDelta b s n)`

- **mu1:**
  - LHS = `1 + μ(b) + μ(s) + (1 + μ(n))` = `2 + μ(b) + μ(s) + μ(n)`
  - RHS = `1 + μ(s) + (1 + μ(b) + μ(s) + μ(n))` = `2 + μ(b) + 2μ(s) + μ(n)`
  - **Fails:** RHS ≥ LHS (the `s` term is duplicated)

- **mu2:**
  - LHS = `5 + μ(b) + μ(s) + (1 + μ(n))` = `6 + μ(b) + μ(s) + μ(n)`
  - RHS = `1 + μ(s) + (5 + μ(b) + μ(s) + μ(n))` = `6 + μ(b) + 2μ(s) + μ(n)`
  - Wait, let me recalculate: RHS = `1 + μ(s) + (5 + μ(b) + μ(s) + μ(n))`
  - Actually: The `delta` wrapper on `n` contributes 1 to LHS, and RHS loses the `delta` but gains an `app`. With mu2's weights: `recDelta` costs 5, `app` costs 1, `delta` costs 1.
  - LHS = 5 + μ(b) + μ(s) + 1 + μ(n) = 6 + μ(b) + μ(s) + μ(n)
  - RHS = 1 + μ(s) + 5 + μ(b) + μ(s) + μ(n) = 6 + μ(b) + 2μ(s) + μ(n)
  - **This also fails!** Let me re-examine...
  
  Actually, the key insight: in RHS, the inner `recDelta b s n` uses `n`, not `delta n`. So we lose the `delta` cost of 1 from `n`. The balance is: we trade `recDelta(5) + delta(1)` for `app(1) + recDelta(5)`, which is 6 → 6, but we also duplicate `s`. **mu2 fails here too.**

- **mu3:**
  - LHS = 1 + μ(b) + μ(s) + 1 + μ(n) = 2 + μ(b) + μ(s) + μ(n)
  - RHS = 2 + μ(s) + 1 + μ(b) + μ(s) + μ(n) = 3 + μ(b) + 2μ(s) + μ(n)
  - **Fails:** RHS > LHS

### R_eq_diff

**LHS:** `eqW a b` → **RHS:** `integrate (merge a b)`

- **mu1:** LHS = 3 + μ(a) + μ(b), RHS = 1 + 1 + μ(a) + μ(b) = 2 + μ(a) + μ(b). **Passes** ✓
- **mu2:** LHS = 5 + μ(a) + μ(b), RHS = 2 + 2 + μ(a) + μ(b) = 4 + μ(a) + μ(b). **Passes** ✓
- **mu3:** LHS = 4 + μ(a) + μ(b), RHS = 2 + 1 + μ(a) + μ(b) = 3 + μ(a) + μ(b). **Passes** ✓

## Conclusion

**None of the three measures are valid termination measures** for this rewrite system. All three fail on **R_rec_succ** because the rule duplicates the subterm `s`, causing any additive measure to increase (or at best stay constant) rather than strictly decrease.

To prove termination, one would need either:
1. A more sophisticated measure (e.g., multiset ordering, polynomial interpretation with multiplicative components)
2. Additional restrictions on the calculus
3. A proof that the system is not strongly normalizing (if that's the case)
