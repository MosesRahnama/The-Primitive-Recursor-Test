**Short answer:** None of the three candidates is a valid termination measure.  
All of them satisfy the decrease condition for every rule **except** `R_rec_succ`, where every candidate fails. The obstruction is structural: in `R_rec_succ` the variable `s` is duplicated on the right‑hand side, so any purely additive “size” measure counts `s` twice on the right but only once on the left.

---

### Detailed audit

A function `μ : Trace → Nat` is a termination measure iff for every rule instance `l → r` we have `μ(l) > μ(r)`.  
Below we write `B = μ(b)`, `S = μ(s)`, `N = μ(n)`, `A = μ(a)`, `T = μ(t)` and compare the two sides for each rule.

| Rule | LHS measure | RHS measure | Condition needed |
|------|-------------|-------------|------------------|
| `R_int_delta` | `c_int + c_delta + T` | `0` | constant > 0 |
| `R_merge_void_left` | `c_merge + T` | `T` | `c_merge > 0` |
| `R_merge_void_right` | `c_merge + T` | `T` | `c_merge > 0` |
| `R_merge_cancel` | `c_merge + 2T` | `T` | `c_merge + T > 0` |
| `R_rec_zero` | `c_rec + B + S` | `B` | `c_rec + S > 0` |
| `R_rec_succ` | `c_rec + c_delta + B + S + N` | `c_app + c_rec + B + 2S + N` | `c_delta > c_app + S` |
| `R_eq_refl` | `c_eq + 2A` | `0` | `c_eq + 2A > 0` |
| `R_eq_diff` | `c_eq + A + B` | `c_int + c_merge + A + B` | `c_eq > c_int + c_merge` |

For the three candidates the constants are:

| | `c_delta` | `c_int` | `c_merge` | `c_app` | `c_rec` | `c_eq` |
|---|----------|---------|-----------|---------|---------|--------|
| **mu1** | 1 | 1 | 1 | 1 | 1 | 3 |
| **mu2** | 1 | 2 | 2 | 1 | 5 | 5 |
| **mu3** | 1 | 2 | 1 | 2 | 1 | 4 |

#### Rules that all three pass
Rules 1–5, 7 and 8 are strictly decreasing for **all** candidates:

* `R_int_delta`, `R_merge_*`, `R_rec_zero`, `R_eq_refl`: the positive constant offsets on the left guarantee strict decrease.
* `R_eq_diff`:  
  - mu1: `3 > 1+1` ✓  
  - mu2: `5 > 2+2` ✓  
  - mu3: `4 > 2+1` ✓

#### The fatal rule: `R_rec_succ`
`R_rec_succ : recDelta b s (delta n) → app s (recDelta b s n)`

Because `s` appears **once** on the left and **twice** on the right (as an argument to `app` and again inside the nested `recDelta`), the coefficient of `S = μ(s)` is `1` on the LHS and `2` on the RHS. The constant terms cancel partially, leaving:

| Measure | `μ(LHS)` | `μ(RHS)` | Difference `μ(LHS) − μ(RHS)` |
|---------|----------|----------|------------------------------|
| **mu1** | `2 + B + S + N` | `2 + B + 2S + N` | `−S` |
| **mu2** | `6 + B + S + N` | `6 + B + 2S + N` | `−S` |
| **mu3** | `2 + B + S + N` | `3 + B + 2S + N` | `−1 − S` |

* **mu1** and **mu2**: the difference is `−S ≤ 0`.  
  - If `s = void` (`S = 0`) the two sides are **equal**, so the measure does not strictly decrease.  
  - If `s` is larger, the RHS is **strictly bigger** than the LHS; the rewrite actually *increases* the measure.

* **mu3**: the difference is `−1 − S < 0` for **every** `s`. This measure always grows on `R_rec_succ`.

Because `S` can be arbitrarily large (e.g. `s = delta^k void`), no choice of positive constant offsets can compensate for the `−S` term. Thus **no** additive measure of this linear shape can handle `R_rec_succ`.

---

### Verdict

| Candidate | Verdict | Reason |
|-----------|---------|--------|
| **mu1** | **Invalid** | Fails on `R_rec_succ`: non‑decreasing (equal when `s = void`, increasing otherwise). |
| **mu2** | **Invalid** | Fails on `R_rec_succ`: same defect as mu1; the larger constants for `recDelta` and `eqW` do not help because they cancel out. |
| **mu3** | **Invalid** | Fails on `R_rec_succ`: strictly increases on every instance of the rule. |

**Bottom line:** All three candidates are eliminated by the recursor step `R_rec_succ`. A valid termination measure for this system would need to treat the third argument of `recDelta` non‑uniformly (e.g. a lexicographic measure or a weight that depends on the number of `delta` constructors in that position) rather than a simple additive tree size.
