None of mu1/mu2/mu3 strictly decrease on all Step rules (all fail on R_rec_succ, as mu increases or stays equal). No single Nat measure of this form can prove termination.

**Reasoning**

The Step relation has 8 rules (only top-level contractions; no congruences). A valid termination measure mu: Trace → Nat must satisfy ∀t1 t2, Step t1 t2 → mu(t1) > mu(t2). All 3 candidates were checked exhaustively on all 8 rules (computations below use the obvious unfolding of each mu definition). The first 7 rules are abbreviated by name; only the critical rule is expanded in full.

- R_int_delta: holds for mu1 (2 + μ(t) > 0), mu2 (3 + μ(t) > 0), mu3 (3 + μ(t) > 0).
- R_merge_void_left/right: holds for mu1 (1 + μ(t) > μ(t)), mu2 (2 + μ(t) > μ(t)), mu3 (1 + μ(t) > μ(t)).
- R_merge_cancel: holds for mu1 (1 + 2μ(t) > μ(t)), mu2 (2 + 2μ(t) > μ(t)), mu3 (1 + 2μ(t) > μ(t)).
- R_rec_zero: holds for mu1 (1 + μ(b) + μ(s) > μ(b)), mu2 (5 + μ(b) + μ(s) > μ(b)), mu3 (1 + μ(b) + μ(s) > μ(b)).
- R_eq_refl: holds for mu1 (3 + 2μ(a) > 0), mu2 (5 + 2μ(a) > 0), mu3 (4 + 2μ(a) > 0).
- R_eq_diff: holds for mu1 (3 + μ(a) + μ(b) > 2 + μ(a) + μ(b)), mu2 (5 + μ(a) + μ(b) > 4 + μ(a) + μ(b)), mu3 (4 + μ(a) + μ(b) > 3 + μ(a) + μ(b)).

Only R_rec_succ fails for all 3 (let b' = μ(b), s = μ(s), n = μ(n); all other subterms cancel):

- mu1: LHS = 2 + b' + s + n; RHS = 2 + b' + 2s + n. Thus LHS - RHS = -s. Fails (LHS ≤ RHS always; strict increase if s > 0).
- mu2: LHS = 6 + b' + s + n; RHS = 6 + b' + 2s + n. Thus LHS - RHS = -s. Fails (same as mu1).
- mu3: LHS = 2 + b' + s + n; RHS = 3 + b' + 2s + n. Thus LHS - RHS = -1 - s. Fails (strict increase always).

Since R_rec_succ can increase mu, none of the candidates can be used in a termination proof (even though the relation is terminating for other reasons: chains are finite, as app terms are irreducible and rec arguments decrease). No linear additive measure over subterms can succeed on R_rec_succ either, due to duplication of the s argument (coeff. of s is +1 on LHS but +2 on RHS).
