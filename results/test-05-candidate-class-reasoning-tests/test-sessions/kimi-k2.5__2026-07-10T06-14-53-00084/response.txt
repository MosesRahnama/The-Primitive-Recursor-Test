Assessment of the three termination measures for the rewrite calculus defined in the file.

### Criterion for Validity
A function `μ : Trace → Nat` is a valid termination measure (or reduction order) if for every rewrite step `t → u` (i.e., `Step t u`), we have `μ(t) > μ(u)` with the standard ordering on natural numbers.

### The Critical Rule: `R_rec_succ`
The rule `recDelta b s (delta n) → app s (recDelta b s n)` is the primary obstacle for all three candidates. Let us analyze the measure change for this rule.

For a generic linear measure of the form used in the candidates:
- `μ(recDelta b s n) = c_r + μ(b) + μ(s) + μ(n)`
- `μ(app x y) = c_a + μ(x) + μ(y)`
- `μ(delta t) = c_d + μ(t)`

The left-hand side (LHS) and right-hand side (RHS) measures are:
- **LHS**: `μ(recDelta b s (delta n)) = c_r + μ(b) + μ(s) + c_d + μ(n)`
- **RHS**: `μ(app s (recDelta b s n)) = c_a + μ(s) + [c_r + μ(b) + μ(s) + μ(n)] = c_a + c_r + μ(b) + 2·μ(s) + μ(n)`

For strict decrease (`LHS > RHS`), we require:
$$c_d > c_a + \mu(s)$$

Since `s` can be an arbitrary `Trace`, `μ(s)` can be arbitrarily large. **No choice of positive constants $c_d$ and $c_a$ can satisfy this inequality for all `s`.** Consequently, any linear measure of this structural form will fail on this rule.

### Detailed Analysis of Each Candidate

**Candidate 1 (`mu1`)**
- Constants: `c_recDelta = 1`, `c_app = 1`, `c_delta = 1`, `c_integrate = 1`, `c_merge = 1`, `c_eqW = 3`
- **R_rec_succ check**:
  - LHS: `1 + μ(b) + μ(s) + (1 + μ(n)) = 2 + μ(b) + μ(s) + μ(n)`
  - RHS: `1 + μ(s) + (1 + μ(b) + μ(s) + μ(n)) = 2 + μ(b) + 2·μ(s) + μ(n)`
  - **Verdict**: The RHS exceeds the LHS by exactly `μ(s)`. 
    - If `s = void` (where `μ(s) = 0`), the measure is unchanged (not strictly decreasing).
    - If `s` is any non-void term, the measure **increases**.
  - **Conclusion**: Invalid.

**Candidate 2 (`mu2`)**
- Constants: `c_recDelta = 5`, `c_app = 1`, `c_delta = 1`, `c_integrate = 2`, `c_merge = 2`, `c_eqW = 5`
- **R_rec_succ check**:
  - LHS: `5 + μ(b) + μ(s) + (1 + μ(n)) = 6 + μ(b) + μ(s) + μ(n)`
  - RHS: `1 + μ(s) + (5 + μ(b) + μ(s) + μ(n)) = 6 + μ(b) + 2·μ(s) + μ(n)`
  - **Verdict**: Identical to `mu1`, the RHS exceeds the LHS by `μ(s)`. The larger constants (5 vs 1) do not remedy the structural problem of the duplicated `s` on the RHS.
    - If `s = void`, measure is unchanged.
    - If `s` is non-void, measure increases.
  - **Conclusion**: Invalid.

**Candidate 3 (`mu3`)**
- Constants: `c_recDelta = 1`, `c_app = 2`, `c_delta = 1`, `c_integrate = 2`, `c_merge = 1`, `c_eqW = 4`
- **R_rec_succ check**:
  - LHS: `1 + μ(b) + μ(s) + (1 + μ(n)) = 2 + μ(b) + μ(s) + μ(n)`
  - RHS: `2 + μ(s) + (1 + μ(b) + μ(s) + μ(n)) = 3 + μ(b) + 2·μ(s) + μ(n)`
  - **Verdict**: The RHS exceeds the LHS by `1 + μ(s)`. Even when `s = void` (μ(s)=0), the measure **increases by 1**. For non-void `s`, it increases even more.
  - **Conclusion**: Invalid (and strictly worse than the others as it never decreases on this rule).

### Summary
- **`mu1`**: Fails on `R_rec_succ` (measure non-decreasing; increases if `s` is non-void).
- **`mu2`**: Fails on `R_rec_succ` (measure non-decreasing; increases if `s` is non-void). The larger constants do not help because they appear on both sides of the inequality.
- **`mu3`**: Fails on `R_rec_succ` (measure strictly increases even when `s = void`).

**Final Verdict**: None of the three candidates are valid termination measures for the given rewrite system. The structural issue with `R_rec_succ`—where the step function `s` appears once in the source but twice in the target (once directly and once inside the recursive call)—cannot be handled by any simple linear structural measure into `Nat`.
