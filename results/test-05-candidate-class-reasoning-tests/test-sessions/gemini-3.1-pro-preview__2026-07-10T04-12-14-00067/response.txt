To assess the three candidate termination measures (`mu1`, `mu2`, and `mu3`), we must verify if they strictly decrease across every step of the defined rewrite calculus. That is, for every rule `Step L R`, a valid termination measure `mu` must satisfy `mu L > mu R`. 

All three candidates define linear structural weights where the measure of a term is the sum of the measures of its arguments plus some constant defined by the constructor.

Let's evaluate how these measures hold up against the rewrite rules.

### 1. The Non-Duplicating Rules
For most of the rules, all three candidates successfully show a strict decrease:
* **`R_int_delta`** (`integrate (delta t) -> void`): 
  LHS measures are $\ge 2 + \mu(t)$, while the RHS is $0$. All candidates pass.
* **`R_merge_void_left` / `R_merge_void_right`** (`merge void t -> t`): 
  LHS adds a positive constant (1 or 2) to $\mu(t)$. All candidates pass.
* **`R_merge_cancel`** (`merge t t -> t`): 
  LHS evaluates to $C + 2\mu(t)$, which is strictly greater than $\mu(t)$. All candidates pass.
* **`R_rec_zero`** (`recDelta b s void -> b`): 
  LHS evaluates to $C + \mu(b) + \mu(s) + 0$, strictly greater than $\mu(b)$. All candidates pass.
* **`R_eq_refl`** (`eqW a a -> void`):
  LHS measures $\ge 3 + 2\mu(a)$, while the RHS is $0$. All candidates pass.
* **`R_eq_diff`** (`eqW a b -> integrate (merge a b)`):
  * For `mu1`: LHS = $3 + a + b$. RHS = $1 + (1 + a + b) = 2 + a + b$. ($3 > 2$, **Pass**)
  * For `mu2`: LHS = $5 + a + b$. RHS = $2 + (2 + a + b) = 4 + a + b$. ($5 > 4$, **Pass**)
  * For `mu3`: LHS = $4 + a + b$. RHS = $2 + (1 + a + b) = 3 + a + b$. ($4 > 3$, **Pass**)

### 2. The Failing Rule: `R_rec_succ`
The rule `R_rec_succ` dictates that:
`Step (recDelta b s (delta n)) (app s (recDelta b s n))`

Notice that the variable **`s` is duplicated** on the right-hand side. Because all three measures are strictly linear polynomials with a coefficient of $1$ for each recursive argument, the duplication of `s` severely breaks the strict decrease. 

Let's do the exact math for LHS and RHS on each candidate:

**For `mu1`**:
* $\mu_1(\text{LHS}) = 1 + b + s + (1 + n) = 2 + b + s + n$
* $\mu_1(\text{RHS}) = 1 + s + (1 + b + s + n) = 2 + b + 2s + n$
* Requirement: $2 + b + s + n > 2 + b + 2s + n \implies \mathbf{0 > \mu_1(s)}$
* **Result**: Fails (since $\mu_1(s) \ge 0$).

**For `mu2`**:
* $\mu_2(\text{LHS}) = 5 + b + s + (1 + n) = 6 + b + s + n$
* $\mu_2(\text{RHS}) = 1 + s + (5 + b + s + n) = 6 + b + 2s + n$
* Requirement: $6 + b + s + n > 6 + b + 2s + n \implies \mathbf{0 > \mu_2(s)}$
* **Result**: Fails.

**For `mu3`**:
* $\mu_3(\text{LHS}) = 1 + b + s + (1 + n) = 2 + b + s + n$
* $\mu_3(\text{RHS}) = 2 + s + (1 + b + s + n) = 3 + b + 2s + n$
* Requirement: $2 + b + s + n > 3 + b + 2s + n \implies \mathbf{0 > 1 + \mu_3(s)}$
* **Result**: Fails.

### Conclusion
**None of the three candidates are valid termination measures.** 

While they cleanly cover rules matching standard structural consumption, they fundamentally fail to account for the duplication of the `s` variable in `R_rec_succ`. A rewrite rule that duplicates a variable can never be proven to terminate using a purely linear additive measure where the variable has a coefficient of $1$ on both sides. Proving termination for this calculus would require a non-linear interpretation (e.g., multiset path ordering or a polynomial interpretation where `recDelta` is defined with multiplication over its arguments).
