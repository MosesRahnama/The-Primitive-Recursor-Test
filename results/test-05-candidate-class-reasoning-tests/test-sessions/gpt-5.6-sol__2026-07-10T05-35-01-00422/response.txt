A termination measure must satisfy `μ target < μ source` for every `Step source target`.

All three candidates fail on `R_rec_succ`:

| Candidate | Source measure | Target measure | Result |
|---|---:|---:|---|
| `mu1` | `2 + μ(b) + μ(s) + μ(n)` | `2 + μ(b) + 2·μ(s) + μ(n)` | Equal if `μ(s)=0`; increases otherwise |
| `mu2` | `6 + μ(b) + μ(s) + μ(n)` | `6 + μ(b) + 2·μ(s) + μ(n)` | Equal if `μ(s)=0`; increases otherwise |
| `mu3` | `2 + μ(b) + μ(s) + μ(n)` | `3 + μ(b) + 2·μ(s) + μ(n)` | Always increases |

Here the rule is
```lean
recDelta b s (delta n) ↦ app s (recDelta b s n)
```
and the extra occurrence of `s` on the right defeats these additive measures.

A common explicit counterexample is:
```lean
recDelta void void (delta void)
  ↦ app void (recDelta void void void)
```

Its measures are:

- `mu1`: `2 ↦ 2` — not strict.
- `mu2`: `6 ↦ 6` — not strict.
- `mu3`: `2 ↦ 3` — increases.

For `mu1` and `mu2`, choosing a nonempty `s`, such as `delta void`, makes the measure increase as well.

All three measures strictly decrease for every other listed rule, including `R_eq_diff`:

- `mu1`: decreases from `3 + μ(a) + μ(b)` to `2 + μ(a) + μ(b)`.
- `mu2`: decreases from `5 + μ(a) + μ(b)` to `4 + μ(a) + μ(b)`.
- `mu3`: decreases from `4 + μ(a) + μ(b)` to `3 + μ(a) + μ(b)`.

**Conclusion:** none of `mu1`, `mu2`, or `mu3` is a valid strict termination measure for the full `Step` relation. The sole obstructing rule schema is `R_rec_succ`.
