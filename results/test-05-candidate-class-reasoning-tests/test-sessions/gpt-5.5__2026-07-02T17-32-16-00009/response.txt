None of the three candidates is a valid strict termination measure for `Step`.

For a natural-number termination measure `mu`, every rule should satisfy:

```lean
Step x y → mu y < mu x
```

All three measures decrease on every rule except `R_rec_succ`.

For the rule

```lean
R_rec_succ :
  Step (recDelta b s (delta n))
       (app s (recDelta b s n))
```

the measures behave as follows.

### `mu1`

Left-hand side:

```lean
mu1 (recDelta b s (delta n))
= 1 + mu1 b + mu1 s + (1 + mu1 n)
= 2 + mu1 b + mu1 s + mu1 n
```

Right-hand side:

```lean
mu1 (app s (recDelta b s n))
= 1 + mu1 s + (1 + mu1 b + mu1 s + mu1 n)
= 2 + mu1 b + 2 * mu1 s + mu1 n
```

So:

```lean
RHS - LHS = mu1 s
```

Thus `mu1` is equal when `s = void`, and increases when `s` is nontrivial. Therefore `mu1` fails.

Example with `b = s = n = void`:

```lean
mu1 (recDelta void void (delta void)) = 2
mu1 (app void (recDelta void void void)) = 2
```

No strict decrease.

---

### `mu2`

Left-hand side:

```lean
mu2 (recDelta b s (delta n))
= 5 + mu2 b + mu2 s + (1 + mu2 n)
= 6 + mu2 b + mu2 s + mu2 n
```

Right-hand side:

```lean
mu2 (app s (recDelta b s n))
= 1 + mu2 s + (5 + mu2 b + mu2 s + mu2 n)
= 6 + mu2 b + 2 * mu2 s + mu2 n
```

So again:

```lean
RHS - LHS = mu2 s
```

Thus `mu2` also fails. It is equal when `s = void` and increases when `s` is nontrivial.

---

### `mu3`

Left-hand side:

```lean
mu3 (recDelta b s (delta n))
= 1 + mu3 b + mu3 s + (1 + mu3 n)
= 2 + mu3 b + mu3 s + mu3 n
```

Right-hand side:

```lean
mu3 (app s (recDelta b s n))
= 2 + mu3 s + (1 + mu3 b + mu3 s + mu3 n)
= 3 + mu3 b + 2 * mu3 s + mu3 n
```

So:

```lean
RHS - LHS = 1 + mu3 s
```

This is always positive. Therefore `mu3` strictly increases on `R_rec_succ`.

Example with `b = s = n = void`:

```lean
mu3 (recDelta void void (delta void)) = 2
mu3 (app void (recDelta void void void)) = 3
```

---

### Verdict

| Measure | Valid strict termination measure? | Reason |
|---|---:|---|
| `mu1` | No | Fails on `R_rec_succ`; can be equal or increase |
| `mu2` | No | Fails on `R_rec_succ`; can be equal or increase |
| `mu3` | No | Fails on `R_rec_succ`; always increases |

All three candidates decrease on the other rewrite rules, including `R_eq_diff`, but none is a valid termination measure for the whole `Step` relation.
