# Audit of Candidate Termination Measures

I need to verify that for each rewrite rule `Step t1 t2`, the candidate measure strictly decreases: `mu(t1) > mu(t2)`.

## Systematic Analysis of Each Rule

Let me analyze each rule against all three measures.

### R_rec_zero: `recDelta b s void → b`

| Measure | LHS | RHS | Decreases? |
|---------|-----|-----|------------|
| mu1 | 1 + mu1 b + mu1 s + 0 | mu1 b | ✅ |
| mu2 | 5 + mu2 b + mu2 s | mu2 b | ✅ |
| mu3 | 1 + mu3 b + mu3 s | mu3 b | ✅ |

### R_rec_succ: `recDelta b s (delta n) → app s (recDelta b s n)`

| Measure | LHS | RHS |
|---------|-----|-----|
| mu1 | 1 + mu1 b + mu1 s + (1 + mu1 n) = 2 + mu1 b + mu1 s + mu1 n | 1 + mu1 s + (1 + mu1 b + mu1 s + mu1 n) = **2 + mu1 b + 2·mu1 s + mu1 n** |

**mu1**: LHS = 2 + B + S + N, RHS = 2 + B + 2S + N. We need LHS > RHS, i.e., 0 > S. **❌ FAILS** when `mu1 s ≥ 1`.

**mu2**: LHS = 5 + B + S + (1 + N) = 6 + B + S + N. RHS = 1 + S + (5 + B + S + N) = 6 + B + 2S + N. Need 6+B+S+N > 6+B+2S+N, i.e., 0 > S. **❌ FAILS**.

**mu3**: LHS = 1 + B + S + (1 + N) = 2 + B + S + N. RHS = 2 + S + (1 + B + S + N) = 3 + B + 2S + N. Need 2+B+S+N > 3+B+2S+N, i.e., -1 > S. **❌ FAILS**.

### R_eq_refl: `eqW a a → void` — ✅ all three (trivially).

### R_eq_diff: `eqW a b → integrate (merge a b)`

| Measure | LHS | RHS | Decreases? |
|---------|-----|-----|------------|
| mu1 | 3 + A + B | 1 + (1 + A + B) = 2 + A + B | ✅ |
| mu2 | 5 + A + B | 2 + (2 + A + B) = 4 + A + B | ✅ |
| mu3 | 4 + A + B | 2 + (1 + A + B) = 3 + A + B | ✅ |

## Verdict

**All three candidates fail** on rule `R_rec_succ`. This rule duplicates `s` in the output (it appears both directly and inside the recursive `recDelta` call), so any additive measure over term size cannot decrease—the duplicated subterm causes the RHS to grow. A valid termination argument for this system would likely require a more sophisticated measure (e.g., a multiset ordering, a lexicographic measure incorporating the "fuel" `n`, or a measure that accounts for the bounded recursion depth).
