# Audit of Candidate Termination Measures

I need to verify that each candidate measure strictly decreases across every rewrite rule. That is, for each rule `Step t1 t2`, I need to check `mu(t1) > mu(t2)`.

Let me systematically check each rule against each measure. I'll use shorthand: for a term `t`, I write `|t|` for the measure of `t`.

## Rule-by-rule analysis

### R_int_delta: `integrate (delta t) → void`

| Measure | LHS | RHS | Decreases? |
|---------|-----|-----|------------|
| mu1 | 1 + (1 + \|t\|) = 2 + \|t\| | 0 | ✅ |
| mu2 | 2 + (1 + \|t\|) = 3 + \|t\| | 0 | ✅ |
| mu3 | 2 + (1 + \|t\|) = 3 + \|t\| | 0 | ✅ |

### R_merge_void_left: `merge void t → t`

### R_merge_void_right: `merge t void → t`

### R_rec_succ: `recDelta b s (delta n) → app s (recDelta b s n)`

This is the critical rule. The RHS contains `recDelta b s n` nested inside `app`.

| Measure | LHS | RHS | Decreases? |
|---------|-----|-----|------------|
| mu1 | 1 + \|b\| + \|s\| + (1 + \|n\|) = 2 + \|b\| + \|s\| + \|n\| | 1 + \|s\| + (1 + \|b\| + \|s\| + \|n\|) = 2 + \|b\| + 2\|s\| + \|n\| | ❌ (RHS ≥ LHS whenever \|s\| > 0) |
| mu2 | 5 + \|b\| + \|s\| + (1 + \|n\|) = 6 + \|b\| + \|s\| + \|n\| | 1 + \|s\| + (5 + \|b\| + \|s\| + \|n\|) = 6 + \|b\| + 2\|s\| + \|n\| | ❌ (same issue) |
| mu3 | 1 + \|b\| + \|s\| + (1 + \|n\|) = 2 + \|b\| + \|s\| + \|n\| | 2 + \|s\| + (1 + \|b\| + \|s\| + \|n\|) = 3 + \|b\| + 2\|s\| + \|n\| | ❌ (RHS > LHS always) |

### R_eq_refl: `eqW a a → void` — all ✅ trivially.

### R_eq_diff: `eqW a b → integrate (merge a b)`

| Measure | LHS | RHS | Decreases? |
|---------|-----|-----|------------|
| mu1 | 3 + \|a\| + \|b\| | 1 + (1 + \|a\| + \|b\|) = 2 + \|a\| + \|b\| | ✅ |
| mu2 | 5 + \|a\| + \|b\| | 2 + (2 + \|a\| + \|b\|) = 4 + \|a\| + \|b\| | ✅ |
| mu3 | 4 + \|a\| + \|b\| | 2 + (1 + \|a\| + \|b\|) = 3 + \|a\| + \|b\| | ✅ |

## Conclusion

**All three candidates fail** on rule `R_rec_succ`. This rule duplicates `s` in the output (it appears both directly and inside the recursive call), causing any additive measure to increase. No simple first-order size measure of this form can handle the non-size-decreasing recursion unfolding. A valid termination argument would require a lexicographic or multiset ordering, or a measure that accounts for the structural depth of `n` independently.
