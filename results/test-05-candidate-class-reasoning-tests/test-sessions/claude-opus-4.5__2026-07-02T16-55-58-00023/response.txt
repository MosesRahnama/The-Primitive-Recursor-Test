# Assessment of Termination Measures for the Rewrite Calculus

I'll analyze each candidate measure against all rewrite rules to determine if they establish `Step t₁ t₂ → μ(t₁) > μ(t₂)`.

## Rule-by-Rule Analysis

### R_int_delta: `integrate (delta t) → void`

| Measure | LHS | RHS | Decreases? |
|---------|-----|-----|------------|
| μ₁ | 1 + (1 + μ₁(t)) = 2 + μ₁(t) | 0 | ✓ |
| μ₂ | 2 + (1 + μ₂(t)) = 3 + μ₂(t) | 0 | ✓ |
| μ₃ | 2 + (1 + μ₃(t)) = 3 + μ₃(t) | 0 | ✓ |

### R_merge_void_left: `merge void t → t`

| Measure | LHS | RHS | Decreases? |
|---------|-----|-----|------------|
| μ₁ | 1 + 0 + μ₁(t) = 1 + μ₁(t) | μ₁(t) | ✓ |
| μ₂ | 2 + 0 + μ₂(t) = 2 + μ₂(t) | μ₂(t) | ✓ |
| μ₃ | 1 + 0 + μ₃(t) = 1 + μ₃(t) | μ₃(t) | ✓ |

### R_merge_void_right: `merge t void → t` — Same analysis as above. ✓ for all.

### R_merge_cancel: `merge t t → t`

| Measure | LHS | RHS | Decreases? |
|---------|-----|-----|------------|
| μ₁ | 1 + 2·μ₁(t) | μ₁(t) | ✓ (need 1 + μ₁(t) > 0) |
| μ₂ | 2 + 2·μ₂(t) | μ₂(t) | ✓ |
| μ₃ | 1 + 2·μ₃(t) | μ₃(t) | ✓ |

### R_rec_zero: `recDelta b s void → b`

| Measure | LHS | RHS | Decreases? |
|---------|-----|-----|------------|
| μ₁ | 1 + μ₁(b) + μ₁(s) + 0 | μ₁(b) | ✓ |
| μ₂ | 5 + μ₂(b) + μ₂(s) + 0 | μ₂(b) | ✓ |
| μ₃ | 1 + μ₃(b) + μ₃(s) + 0 | μ₃(b) | ✓ |

### R_rec_succ: `recDelta b s (delta n) → app s (recDelta b s n)`

| Measure | LHS | RHS | Decreases? |
|---------|-----|-----|------------|
| μ₁ | 1 + μ₁(b) + μ₁(s) + (1 + μ₁(n)) | 1 + μ₁(s) + (1 + μ₁(b) + μ₁(s) + μ₁(n)) | **✗** |
| | = 2 + μ₁(b) + μ₁(s) + μ₁(n) | = 2 + μ₁(b) + 2·μ₁(s) + μ₁(n) | |
| μ₂ | 5 + μ₂(b) + μ₂(s) + (1 + μ₂(n)) | 1 + μ₂(s) + (5 + μ₂(b) + μ₂(s) + μ₂(n)) | **✗** |
| | = 6 + μ₂(b) + μ₂(s) + μ₂(n) | = 6 + μ₂(b) + 2·μ₂(s) + μ₂(n) | |
| μ₃ | 1 + μ₃(b) + μ₃(s) + (1 + μ₃(n)) | 2 + μ₃(s) + (1 + μ₃(b) + μ₃(s) + μ₃(n)) | **✗** |
| | = 2 + μ₃(b) + μ₃(s) + μ₃(n) | = 3 + μ₃(b) + 2·μ₃(s) + μ₃(n) | |

### R_eq_refl: `eqW a a → void` — All measures decrease. ✓

### R_eq_diff: `eqW a b → integrate (merge a b)`

| Measure | LHS | RHS | Decreases? |
|---------|-----|-----|------------|
| μ₁ | 3 + μ₁(a) + μ₁(b) | 1 + (1 + μ₁(a) + μ₁(b)) = 2 + μ₁(a) + μ₁(b) | ✓ |
| μ₂ | 5 + μ₂(a) + μ₂(b) | 2 + (2 + μ₂(a) + μ₂(b)) = 4 + μ₂(a) + μ₂(b) | ✓ |
| μ₃ | 4 + μ₃(a) + μ₃(b) | 2 + (1 + μ₃(a) + μ₃(b)) = 3 + μ₃(a) + μ₃(b) | ✓ |

## Conclusion

**All three measures fail** on rule **R_rec_succ**. The RHS duplicates `s` and preserves the recursive structure, causing the measure to increase (or stay equal when `s = void`). 

This rule is inherently non-size-decreasing under any additive measure because the right-hand side contains two copies of `s`. A valid termination argument would require either:
- A lexicographic measure prioritizing the "depth" of the `delta` chain in `n`
- A multiset ordering
- Restricting the calculus
