Great, let’s audit each proposed measure against the rewrite rules.

A valid termination measure `μ` for this one-step relation should satisfy:

\[
\forall t u,\; Step\ t\ u \Rightarrow \mu(t) > \mu(u).
\]

---

### Candidate `mu1`: **fails**

Most rules decrease, but `R_rec_succ` breaks it.

- Rule:
  \[
  recDelta\ b\ s\ (\delta n) \to app\ s\ (recDelta\ b\ s\ n)
  \]
- Under `mu1`:
  - LHS:
    \[
    1 + \mu_1 b + \mu_1 s + \mu_1(\delta n)
    = 1 + \mu_1 b + \mu_1 s + (1+\mu_1 n)
    = 2 + \mu_1 b + \mu_1 s + \mu_1 n
    \]
  - RHS:
    \[
    \mu_1(app\ s\ (recDelta\ b\ s\ n))
    = 1 + \mu_1 s + \mu_1(recDelta\ b\ s\ n)
    = 1 + \mu_1 s + (1+\mu_1 b+\mu_1 s+\mu_1 n)
    = 2 + \mu_1 b + 2\mu_1 s + \mu_1 n
    \]
  RHS exceeds LHS by `mu1 s`, so not decreasing in general (equal only if `s = void`-like size 0).

So `mu1` is **not** a strict descent measure.

---

### Candidate `mu2`: **fails**

Again `R_rec_succ` fails (even worse due to larger recDelta/app constants).

- LHS:
  \[
  \mu_2(recDelta\ b\ s\ (\delta n))
  = 5 + \mu_2 b + \mu_2 s + (1+\mu_2 n)
  = 6 + \mu_2 b + \mu_2 s + \mu_2 n
  \]
- RHS:
  \[
  \mu_2(app\ s\ (recDelta\ b\ s\ n))
  = 1 + \mu_2 s + (5+\mu_2 b+\mu_2 s+\mu_2 n)
  = 6 + \mu_2 b + 2\mu_2 s + \mu_2 n
  \]
Again RHS = LHS + `mu2 s`, so not strictly smaller.

Hence `mu2` is **not** a valid termination measure.

---

### Candidate `mu3`: **fails**

Same critical rule still fails.

- LHS:
  \[
  \mu_3(recDelta\ b\ s\ (\delta n))
  = 1 + \mu_3 b + \mu_3 s + (1+\mu_3 n)
  = 2 + \mu_3 b + \mu_3 s + \mu_3 n
  \]
- RHS:
  \[
  \mu_3(app\ s\ (recDelta\ b\ s\ n))
  = 2 + \mu_3 s + (1+\mu_3 b+\mu_3 s+\mu_3 n)
  = 3 + \mu_3 b + 2\mu_3 s + \mu_3 n
  \]
RHS is larger by `1 + mu3 s`.

So `mu3` is also **not** a strict descent measure.

---

## Bottom line

All three candidates **fail** as global one-step decreasing measures for `Step`, and they all fail for the same reason: rule `R_rec_succ` duplicates the contribution of `s` on the RHS (`app s (...)` while `s` also remains inside `recDelta ...`), which additive size measures cannot strictly decrease through.
