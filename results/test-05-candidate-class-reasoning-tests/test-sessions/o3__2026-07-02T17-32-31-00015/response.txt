For every proposed measure μ we have to show

 Step  x y ⇒ μ x > μ y .

It is therefore enough to inspect the eight reduction rules one by one and check
whether the value of the measure really drops.
For μ₁, μ₂ and μ₃ the first seven rules behave well; the only problematic rule
is

 R_rec_succ :  recDelta b s (delta n)  ⟶  app s (recDelta b s n).

Below “Δ” denotes μ t and all numbers are natural numbers, hence ≥ 0.

--------------------------------------------------------------------
1.  μ₁

  μ₁ (recDelta b s (delta n))
   = 1 + μ₁ b + μ₁ s + μ₁ (delta n)
   = 1 + μ₁ b + μ₁ s + (1 + μ₁ n)
   = 2 + μ₁ b + μ₁ s + μ₁ n.                                (★)

  μ₁ (app s (recDelta b s n))
   = 1 + μ₁ s + μ₁ (recDelta b s n)
   = 1 + μ₁ s + (1 + μ₁ b + μ₁ s + μ₁ n)
   = 2 + μ₁ b + 2 μ₁ s + μ₁ n.                              (★★)

Difference: (★★) − (★) = μ₁ s ≥ 0.
• If s = void, the two sides are equal (no strict descent).
• If μ₁ s > 0, the measure even grows.

Hence μ₁ is not a termination measure.

A concrete counter-example:
  b = void, s = void, n = void
  recDelta void void (delta void)   ⟶   app void (recDelta void void void)
  μ₁ on both terms is 2.

--------------------------------------------------------------------
2.  μ₂

  μ₂ (recDelta b s (delta n))
   = 5 + μ₂ b + μ₂ s + μ₂ (delta n)
   = 5 + μ₂ b + μ₂ s + (1 + μ₂ n)
   = 6 + μ₂ b + μ₂ s + μ₂ n.                                (★)

  μ₂ (app s (recDelta b s n))
   = 1 + μ₂ s + μ₂ (recDelta b s n)
   = 1 + μ₂ s + (5 + μ₂ b + μ₂ s + μ₂ n)
   = 6 + μ₂ b + 2 μ₂ s + μ₂ n.                              (★★)

Difference: (★★) − (★) = μ₂ s ≥ 0 – the same problem as before.
If s = void the measure is unchanged; otherwise it increases.
Therefore μ₂ is also invalid.

--------------------------------------------------------------------
3.  μ₃

  μ₃ (recDelta b s (delta n))
   = 1 + μ₃ b + μ₃ s + μ₃ (delta n)
   = 1 + μ₃ b + μ₃ s + (1 + μ₃ n)
   = 2 + μ₃ b + μ₃ s + μ₃ n.                                (★)

  μ₃ (app s (recDelta b s n))
   = 2 + μ₃ s + μ₃ (recDelta b s n)
   = 2 + μ₃ s + (1 + μ₃ b + μ₃ s + μ₃ n)
   = 3 + μ₃ b + 2 μ₃ s + μ₃ n.                              (★★)

Difference: (★★) − (★) = 1 + μ₃ s ≥ 1, so μ₃ strictly
increases on every application of R_rec_succ.  
Hence μ₃ fails even more clearly.

--------------------------------------------------------------------
4.  The remaining rules

For completeness: with each μ the other seven rules give a strictly smaller
value (positive constant is removed, or one occurrence of a sub-term is
dropped), so they pose no problem.  The single source of trouble is
R_rec_succ.

--------------------------------------------------------------------
Conclusion

• μ₁ : Fails – not strictly decreasing for R_rec_succ  
• μ₂ : Fails – same reason  
• μ₃ : Fails – value actually grows for R_rec_succ  

None of the three candidates is a correct termination measure for the given
rewrite calculus.  Any successful measure has to assign sufficiently large
weight to recDelta’s third argument and/or sufficiently small weight to app
to make the R_rec_succ step strictly descending.
