# Assessment of Termination Measures for the Rewrite Calculus

I'll analyze each of the three candidate measures (mu1, mu2, mu3) by checking whether they strictly decrease across all rewrite rules.

## Methodology

For each rule `Step t1 t2`, I need to verify that `mu(t1) > mu(t2)`.

---

## Analysis of mu1

| Rule | LHS measure | RHS measure | Decreases? |
|------|-------------|-------------|------------|
| **R_int_delta** | `mu1(integrate (delta t)) = 1 + (1 + mu1 t) = 2 + mu1 t` | `mu1(void) = 0` | ✓ |
| **R_merge_void_left** | `mu1(merge void t) = 1 + 0 + mu1 t = 1 + mu1 t` | `mu1(t)` | ✓ |
| **R_merge_void_right** | `mu1(merge t void) = 1 + mu1 t + 0 = 1 + mu1 t` | `mu1(t)` | ✓ |
| **R_merge_cancel** | `mu1(merge t t) = 1 + 2*mu1 t` | `mu1(t)` | ✓ |
| **R_rec_zero** | `mu1(recDelta b s void) = 1 + mu1 b + mu1 s + 0` | `mu1(b)` | ✓ |
| **R_rec_succ** | `mu1(recDelta b s (delta n)) = 1 + mu1 b + mu1 s + (1 + mu1 n)` | `mu1(app s (recDelta b s n)) = 1 + mu1 s + (1 + mu1 b + mu1 s + mu1 n)` | **✗** |

For R_rec_succ:
- LHS: `2 + mu1 b + mu1 s + mu1 n`
- RHS: `2 + 2*mu1 s + mu1 b + mu1 n`

This **fails** when `mu1 s > 0` (i.e., when `s ≠ void`).

| **R_eq_refl** | `mu1(eqW a a) = 3 + 2*mu1 a` | `mu1(void) = 0` | ✓ |
| **R_eq_diff** | `mu1(eqW a b) = 3 + mu1 a + mu1 b` | `mu1(integrate (merge a b)) = 1 + (1 + mu1 a + mu1 b) = 2 + mu1 a + mu1 b` | ✓ |

**mu1 is NOT a valid termination measure.**

---

## Analysis of mu2

| Rule | LHS measure | RHS measure | Decreases? |
|------|-------------|-------------|------------|
| **R_int_delta** | `2 + (1 + mu2 t) = 3 + mu2 t` | `0` | ✓ |
| **R_merge_void_left** | `2 + 0 + mu2 t = 2 + mu2 t` | `mu2 t` | ✓ |
| **R_merge_void_right** | `2 + mu2 t + 0 = 2 + mu2 t` | `mu2 t` | ✓ |
| **R_merge_cancel** | `2 + 2*mu2 t` | `mu2 t` | ✓ |
| **R_rec_zero** | `5 + mu2 b + mu2 s + 0` | `mu2 b` | ✓ |
| **R_rec_succ** | `5 + mu2 b + mu2 s + (1 + mu2 n) = 6 + mu2 b + mu2 s + mu2 n` | `1 + mu2 s + (5 + mu2 b + mu2 s + mu2 n) = 6 + mu2 b + 2*mu2 s + mu2 n` | **✗** |

For R_rec_succ, same issue: fails when `mu2 s > 0`.

**mu2 is NOT a valid termination measure.**

---

## Analysis of mu3

| Rule | LHS measure | RHS measure | Decreases? |
|------|-------------|-------------|------------|
| **R_int_delta** | `2 + (1 + mu3 t) = 3 + mu3 t` | `0` | ✓ |
| **R_merge_void_left** | `1 + 0 + mu3 t = 1 + mu3 t` | `mu3 t` | ✓ |
| **R_merge_void_right** | `1 + mu3 t + 0 = 1 + mu3 t` | `mu3 t` | ✓ |
| **R_merge_cancel** | `1 + 2*mu3 t` | `mu3 t` | ✓ |
| **R_rec_zero** | `1 + mu3 b + mu3 s + 0` | `mu3 b` | ✓ |
| **R_rec_succ** | `1 + mu3 b + mu3 s + (1 + mu3 n) = 2 + mu3 b + mu3 s + mu3 n` | `2 + mu3 s + (1 + mu3 b + mu3 s + mu3 n) = 3 + mu3 b + 2*mu3 s + mu3 n` | **✗** |

Again fails for R_rec_succ when `mu3 s > 0`.

**mu3 is NOT a valid termination measure.**

---

## Conclusion

**None of the three candidates (mu1, mu2, mu3) are valid termination measures.** All three fail on rule **R_rec_succ**, where the recursive call duplicates the step function `s` in the output. A simple additive measure cannot account for this duplication—a more sophisticated approach (e.g., multiset orderings or a measure that accounts for the recursion depth differently) would be required.
