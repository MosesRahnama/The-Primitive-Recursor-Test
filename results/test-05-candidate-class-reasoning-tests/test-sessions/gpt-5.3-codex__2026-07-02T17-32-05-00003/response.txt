Here’s the audit of the three measures as **strict one-step decreasing interpretations** for `Step`:

### Criterion
A candidate `μ` works for termination via measure descent if for every rule `Step l r`, we have:
\[
\mu(l) > \mu(r).
\]

---

### `mu1`
Fails.

Counterexample: `R_rec_succ`
- LHS: `recDelta b s (delta n)`
  \[
  \mu1 = 1+\mu1 b+\mu1 s+(1+\mu1 n)=2+\mu1 b+\mu1 s+\mu1 n
  \]
- RHS: `app s (recDelta b s n)`
  \[
  \mu1 = 1+\mu1 s+(1+\mu1 b+\mu1 s+\mu1 n)=2+\mu1 b+2\mu1 s+\mu1 n
  \]
Difference:
\[
\mu1(\text{RHS})-\mu1(\text{LHS})=\mu1 s.
\]
So if `s ≠ void` (i.e. `mu1 s > 0`), the measure increases; if `s = void`, it is equal. Never strictly decreases in general.

So `mu1` is **not valid**.

---

### `mu2`
Fails.

Again `R_rec_succ`:
- LHS:
  \[
  \mu2(recDelta\, b\, s\, (delta\, n))
  =5+\mu2 b+\mu2 s+(1+\mu2 n)
  =6+\mu2 b+\mu2 s+\mu2 n
  \]
- RHS:
  \[
  \mu2(app\, s\, (recDelta\, b\, s\, n))
  =1+\mu2 s+(5+\mu2 b+\mu2 s+\mu2 n)
  =6+\mu2 b+2\mu2 s+\mu2 n
  \]
Difference:
\[
\mu2(\text{RHS})-\mu2(\text{LHS})=\mu2 s.
\]
Same issue: nondecreasing (equal when `s=void`, increasing otherwise).

So `mu2` is **not valid**.

---

### `mu3`
Fails.

`R_rec_succ`:
- LHS:
  \[
  \mu3(recDelta\, b\, s\, (delta\, n))
  =1+\mu3 b+\mu3 s+(1+\mu3 n)
  =2+\mu3 b+\mu3 s+\mu3 n
  \]
- RHS:
  \[
  \mu3(app\, s\, (recDelta\, b\, s\, n))
  =2+\mu3 s+(1+\mu3 b+\mu3 s+\mu3 n)
  =3+\mu3 b+2\mu3 s+\mu3 n
  \]
Difference:
\[
\mu3(\text{RHS})-\mu3(\text{LHS})=1+\mu3 s>0.
\]
Always increases.

So `mu3` is **not valid**.

---

## Final verdict
All three candidates **fail** as global strictly decreasing termination measures for `Step`, each due to rule `R_rec_succ`.  
(Separately, note `R_eq_diff` and `R_eq_refl` overlap on `eqW a a`, but that does not affect the above failure.)
