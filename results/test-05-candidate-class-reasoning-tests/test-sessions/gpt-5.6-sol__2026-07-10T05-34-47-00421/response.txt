A valid `Nat`-valued termination measure must satisfy `μ lhs > μ rhs` for every `Step lhs rhs`.

All three candidates fail on `R_rec_succ`. Let

- `B = μ b`
- `S = μ s`
- `N = μ n`.

| Measure | Source: `recDelta b s (delta n)` | Target: `app s (recDelta b s n)` | Result |
|---|---:|---:|---|
| `mu1` | `2 + B + S + N` | `2 + B + 2*S + N` | Equal if `S = 0`; otherwise increases |
| `mu2` | `6 + B + S + N` | `6 + B + 2*S + N` | Equal if `S = 0`; otherwise increases |
| `mu3` | `2 + B + S + N` | `3 + B + 2*S + N` | Always increases |

A common concrete counterexample is:

```lean
Step
  (recDelta void void (delta void))
  (app void (recDelta void void void))
```

The corresponding values are:

- `mu1`: `2 → 2`
- `mu2`: `6 → 6`
- `mu3`: `2 → 3`

Thus:

- **`mu1` is not a strict termination measure.**
- **`mu2` is not a strict termination measure.**
- **`mu3` is not a strict termination measure.**

All the other listed rewrite rules strictly decrease under each candidate. The sole obstruction is `R_rec_succ`, whose right-hand side duplicates `s`; the additive measures count that duplication, while the reduction of `delta n` to `n` does not compensate for it.
