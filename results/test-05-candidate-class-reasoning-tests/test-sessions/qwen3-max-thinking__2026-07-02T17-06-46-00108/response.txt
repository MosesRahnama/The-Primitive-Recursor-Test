### Assessment of Termination Measures for the Rewrite Calculus

All three proposed measures (**`mu1`**, **`mu2`**, **`mu3`**) **fail** to serve as valid termination measures for the given rewrite system. A valid termination measure must satisfy **strict decrease** (`μ(t₁) > μ(t₂)`) for **every** rewrite step `Step t₁ t₂`, across **all** instantiations of rule variables. Below is the precise failure analysis.

---

#### 🔴 Critical Failure: Rule `R_rec_succ`
This rule is the universal point of failure:
```lean
R_rec_succ : ∀ b s n, Step (recDelta b s (delta n)) (app s (recDelta b s n))
```
For **any** additive structural measure of the form used here (linear combination of subterm measures with non-negative coefficients), the right-hand side (`app s (recDelta b s n)`) contains **two occurrences of `s`** (once as `app`'s first argument, once inside `recDelta`), while the left-hand side contains only **one occurrence of `s`**. Since `μ(s) ≥ 0` and unbounded (e.g., `s = delta^k void` yields arbitrarily large `μ(s)`), the measure of the RHS **cannot** be strictly less than the LHS for all `s`.

Concrete evaluation per candidate:
- **`mu1`**:  
  `μ(LHS) = 2 + b + s + n`  
  `μ(RHS) = 2 + b + 2s + n`  
  → `μ(LHS) − μ(RHS) = −s ≤ 0`.  
  **Fails**: Equal when `s = void` (`μ(s)=0`); *increases* when `μ(s) > 0` (e.g., `s = delta void`).
  
- **`mu2`**:  
  `μ(LHS) = 6 + b + s + n`  
  `μ(RHS) = 6 + b + 2s + n`  
  → `μ(LHS) − μ(RHS) = −s ≤ 0`.  
  **Fails**: Same structural flaw as `mu1`; equality at `s = void`, increase otherwise.
  
- **`mu3`**:  
  `μ(LHS) = 2 + b + s + n`  
  `μ(RHS) = 3 + b + 2s + n`  
  → `μ(LHS) − μ(RHS) = −1 − s < 0` for all `s`.  
  **Fails catastrophically**: Measure *strictly increases* on every instance of this rule.

This failure is **irremediable** for any measure of this additive form. No choice of constant coefficients can overcome the structural duplication of `s` in the RHS. Termination (if it holds) would require a non-additive measure (e.g., lexicographic, multiset, or context-sensitive), which these candidates are not.

---

#### ✅ Other Rules Are Satisfied (But Irrelevant)
All three measures **do** strictly decrease on every other rule:
- `R_int_delta`, `R_merge_void_{left,right}`, `R_merge_cancel`, `R_rec_zero`, `R_eq_refl`, `R_eq_diff` all satisfy `μ(t₁) > μ(t₂)` universally under all candidates.  
  *(Example: For `R_eq_diff`, `mu3(eqW a b) = 4+a+b > 3+a+b = mu3(integrate (merge a b))`.)*  
- Even the dual rewrites for `eqW a a` (`R_eq_refl` to `void` and `R_eq_diff` to `integrate (merge a a)`) both decrease under all measures.

However, **a single failing rule invalidates the entire measure**. Since `R_rec_succ` fails for all candidates, satisfaction of other rules is immaterial.

---

#### 📌 Conclusion
| Candidate | Valid Termination Measure? | Primary Reason |
|-----------|----------------------------|----------------|
| `mu1`     | ❌ No                      | Non-strict (equal/increasing) on `R_rec_succ` |
| `mu2`     | ❌ No                      | Non-strict (equal/increasing) on `R_rec_succ` |
| `mu3`     | ❌ No                      | Strictly *increasing* on `R_rec_succ` |

**All three candidates are invalid.** The rewrite system’s `R_rec_succ` rule inherently duplicates the subterm `s` in the reduct, making it impossible for any additive structural measure with non-negative coefficients to guarantee strict decrease. This is a fundamental limitation of the proposed measure *forms*, not merely poor coefficient choices. To prove termination (if achievable), a more sophisticated measure—e.g., lexicographic combination, dependency pairs, or a recursive path order—would be required.
