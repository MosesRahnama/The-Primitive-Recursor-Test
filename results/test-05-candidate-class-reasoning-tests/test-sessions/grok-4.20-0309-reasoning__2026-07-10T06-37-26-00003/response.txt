**Assessment:** None of the three candidates (mu1, mu2, mu3) are valid termination measures. All strictly decrease on rules R_int_delta, R_merge_void_left, R_merge_void_right, R_merge_cancel, R_rec_zero, R_eq_refl, and R_eq_diff. However, all fail on R_rec_succ:

- mu1(recDelta b s (delta n)) = 2 + μb + μs + μn  
  mu1(app s (recDelta b s n)) = 2 + μb + 2⋅μs + μn  
  → RHS = LHS + μs (equal if μs=0; strictly increases otherwise)

- mu2(recDelta b s (delta n)) = 6 + μb + μs + μn  
  mu2(app s (recDelta b s n)) = 6 + μb + 2⋅μs + μn  
  → RHS = LHS + μs (equal if μs=0; strictly increases otherwise)

- mu3(recDelta b s (delta n)) = 2 + μb + μs + μn  
  mu3(app s (recDelta b s n)) = 3 + μb + 2⋅μs + μn  
  → RHS = LHS + (1 + μs) (always strictly increases)

These are purely additive structural sizes; the recursor rule duplicates its step argument s while adding an app wrapper, so no linear measure of this form can be strictly decreasing. (A non-structural measure interpreting the successor depth of the third argument would be needed instead.)

**Final answer:** none valid (all fail on R_rec_succ)
