All three candidates fail as strict `Nat` termination measures for `Step`.

A valid measure `mu` would need, for every rule

```lean
Step lhs rhs
```

to satisfy

```lean
mu rhs < mu lhs
```

Most rules decrease for all three measures, but the problematic rule is always:

```lean
| R_rec_succ : forall b s n,
    Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

## `mu1`

For `R_rec_succ`:

```lean
mu1 (recDelta b s (delta n))
= 1 + mu1 b + mu1 s + mu1 (delta n)
= 2 + mu1 b + mu1 s + mu1 n
```

while

```lean
mu1 (app s (recDelta b s n))
= 1 + mu1 s + mu1 (recDelta b s n)
= 1 + mu1 s + (1 + mu1 b + mu1 s + mu1 n)
= 2 + mu1 b + 2 * mu1 s + mu1 n
```

So the target is larger by `mu1 s`:

```lean
mu1 rhs = mu1 lhs + mu1 s
```

Thus it is equal when `s = void`, and increases whenever `s` is nontrivial.

Example:

```lean
b = void
s = delta void
n = void
```

Then

```lean
mu1 lhs = 3
mu1 rhs = 4
```

So `mu1` is not a valid strict termination measure.

## `mu2`

For `R_rec_succ`:

```lean
mu2 (recDelta b s (delta n))
= 5 + mu2 b + mu2 s + (1 + mu2 n)
= 6 + mu2 b + mu2 s + mu2 n
```

and

```lean
mu2 (app s (recDelta b s n))
= 1 + mu2 s + (5 + mu2 b + mu2 s + mu2 n)
= 6 + mu2 b + 2 * mu2 s + mu2 n
```

Again:

```lean
mu2 rhs = mu2 lhs + mu2 s
```

So `mu2` also fails. It is non-decreasing for `s = void` and increasing for non-`void` `s`.

## `mu3`

For `R_rec_succ`:

```lean
mu3 (recDelta b s (delta n))
= 1 + mu3 b + mu3 s + (1 + mu3 n)
= 2 + mu3 b + mu3 s + mu3 n
```

and

```lean
mu3 (app s (recDelta b s n))
= 2 + mu3 s + (1 + mu3 b + mu3 s + mu3 n)
= 3 + mu3 b + 2 * mu3 s + mu3 n
```

So:

```lean
mu3 rhs = mu3 lhs + 1 + mu3 s
```

This is strictly larger for every `s`.

Therefore `mu3` fails even more decisively.

## Summary

| Measure | Status | Reason |
|---|---:|---|
| `mu1` | Fails | `R_rec_succ` is non-decreasing/even increasing |
| `mu2` | Fails | `R_rec_succ` is non-decreasing/even increasing |
| `mu3` | Fails | `R_rec_succ` always increases |

All three measures decrease on the other rewrite rules, including `R_eq_diff`, but none is a valid strict termination measure for the whole `Step` relation because of `R_rec_succ`.
