**Short answer:**  
None of the three functions `mu1`, `mu2` or `mu3` is a correct termination‑measure for the rewrite system.

---

### Why each candidate fails

| Rule | What the measure must satisfy | `mu1` | `mu2` | `mu3` |
|------|-------------------------------|-------|-------|-------|
| **R_int_delta** `integrate (delta t) → void` | \(\mu(\text{void}) < \mu(\text{integrate (delta t)})\) | \(0 < 2+\mu(t)\) ✔ | \(0 < 3+\mu(t)\) ✔ | \(0 < 3+\mu(t)\) ✔ |
| **R_merge_void_left/right** `merge void t → t` , `merge t void → t` | \(\mu(t) < \mu(\text{merge …})\) | \(\mu(t) < 1+\mu(t)\) ✔ | \(\mu(t) < 2+\mu(t)\) ✔ | \(\mu(t) < 1+\mu(t)\) ✔ |
| **R_merge_cancel** `merge t t → t` | \(\mu(t) < \mu(\text{merge t t})\) | \(\mu(t) < 1+2\mu(t)\) ✔ | \(\mu(t) < 2+2\mu(t)\) ✔ | \(\mu(t) < 1+2\mu(t)\) ✔ |
| **R_rec_zero** `recDelta b s void → b` | \(\mu(b) < \mu(\text{recDelta b s void})\) | \(\mu(b) < 1+\mu(b)+\mu(s)\) ✔ | \(\mu(b) < 5+\mu(b)+\mu(s)\) ✔ | \(\mu(b) < 1+\mu(b)+\mu(s)\) ✔ |
| **R_eq_refl** `eqW a a → void` | \(\mu(void) < \mu(\text{eqW a a})\) | \(0 < 3+2\mu(a)\) ✔ | \(0 < 5+2\mu(a)\) ✔ | \(0 < 4+2\mu(a)\) ✔ |
| **R_eq_diff** `eqW a b → integrate (merge a b)` | \(\mu(\text{integrate (merge a b)}) < \mu(\text{eqW a b})\) | \(2+\mu(a)+\mu(b) < 3+\mu(a)+\mu(b)\) ✔ | \(4+\mu(a)+\mu(b) < 5+\mu(a)+\mu(b)\) ✔ | \(3+\mu(a)+\mu(b) < 4+\mu(a)+\mu(b)\) ✔ |
| **R_rec_succ** `recDelta b s (delta n) → app s (recDelta b s n)` | \(\mu(\text{app s (recDelta …)}) < \mu(\text{recDelta b s (delta n)})\) | **fails** – when `s = void` the two measures are equal ( \(2+\mu(b)+\mu(n)\) = \(2+\mu(b)+\mu(n)\) ). In all other cases the RHS is larger. | **fails** – the RHS is larger by \(\mu_2(s)\) (or equal when `s = void`). | **fails** – the RHS is larger by \(1+\mu_3(s)\) (always >). |

The only problematic rule is **R_rec_succ**.  
All three candidates break the required strict decrease on this rule:

* **mu1** – equality when the “function” argument `s` is `void`.  
* **mu2** – the RHS is never smaller; it is either equal (`s = void`) or strictly larger.  
* **mu3** – the RHS is always strictly larger.

Consequently none of the three functions is a termination measure for the given rewrite system.
