# Audit of Candidate Termination Measures

I need to verify that for each rewrite rule `Step t1 t2`, the candidate measure strictly decreases: `mu(t1) > mu(t2)`.

## Analysis of Each Rule

Let me compute `mu(lhs)` and `mu(rhs)` for each rule under all three measures.

### R_rec_succ: `recDelta b s (delta n) → app s (recDelta b s n)`

This is the critical rule. The RHS contains a recursive `recDelta` call.

| Measure | LHS | RHS |
|---------|-----|-----|
| mu1 | `1 + mu1 b + mu1 s + (1 + mu1 n)` = `2 + mu1 b + mu1 s + mu1 n` | `1 + mu1 s + (1 + mu1 b + mu1 s + mu1 n)` = `2 + mu1 b + 2·mu1 s + mu1 n` |

**mu1**: LHS = `2 + B + S + N`, RHS = `2 + B + 2S + N`. RHS ≥ LHS. **❌ FAILS** (RHS is larger by `S`).

| mu2 | `5 + B + S + (1+N)` = `6 + B + S + N` | `1 + S + (5 + B + S + N)` = `6 + B + 2S + N` |

**mu2**: LHS = `6 + B + S + N`, RHS = `6 + B + 2S + N`. **❌ FAILS** (same issue).

| mu3 | `1 + B + S + (1+N)` = `2 + B + S + N` | `2 + S + (1 + B + S + N)` = `3 + B + 2S + N` |

**mu3**: LHS = `2 + B + S + N`, RHS = `3 + B + 2S + N`. **❌ FAILS** (even worse).

### R_eq_refl / R_eq_diff

These pass easily for all three under the given constants (the `eqW` constants are large enough).

## Conclusion

**All three candidates fail** on the `R_rec_succ` rule. The fundamental problem is that `app s (recDelta b s n)` duplicates `s` — it appears both as the first argument of `app` and inside the recursive `recDelta`. Since every measure assigns `app` a cost of `1 + mu(s) + mu(recDelta b s n)`, the `s` contribution appears twice in the RHS but only once in the LHS. No constant-offset adjustment to the constructors' base weights can overcome this duplication. A valid termination argument for this system would require a non-additive measure (e.g., a multiset ordering or a lexicographic measure incorporating term structure).
