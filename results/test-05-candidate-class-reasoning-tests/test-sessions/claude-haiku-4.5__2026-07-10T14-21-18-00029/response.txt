# Assessment of Termination Measures

I will analyze whether each measure strictly decreases under all rewrite rules.

## Analysis by Rule

### R_int_delta: `integrate (delta t) → void`
- **mu1**: `1 + (1 + mu1 t)` → `0` ✓ (decreases by 2 + mu1 t)
- **mu2**: `2 + (1 + mu2 t)` → `0` ✓ (decreases by 3 + mu2 t)
- **mu3**: `2 + (1 + mu3 t)` → `0` ✓ (decreases by 3 + mu3 t)

### R_merge_void_left: `merge void t → t`
- **mu1**: `1 + 0 + mu1 t` → `mu1 t` ✓ (decreases by 1)
- **mu2**: `2 + 0 + mu2 t` → `mu2 t` ✓ (decreases by 2)
- **mu3**: `1 + 0 + mu3 t` → `mu3 t` ✓ (decreases by 1)

### R_merge_void_right: `merge t void → t`
- **mu1**: `1 + mu1 t + 0` → `mu1 t` ✓
- **mu2**: `2 + mu2 t + 0` → `mu2 t` ✓
- **mu3**: `1 + mu3 t + 0` → `mu3 t` ✓

### R_merge_cancel: `merge t t → t`
- **mu1**: `1 + mu1 t + mu1 t` → `mu1 t` ✓ (decreases by 1 + mu1 t)
- **mu2**: `2 + mu2 t + mu2 t` → `mu2 t` ✓ (decreases by 2 + mu2 t)
- **mu3**: `1 + mu3 t + mu3 t` → `mu3 t` ✓ (decreases by 1 + mu3 t)

### R_rec_zero: `recDelta b s void → b`
- **mu1**: `1 + mu1 b + mu1 s + 0` → `mu1 b` ✓ (decreases by 1 + mu1 s)
- **mu2**: `5 + mu2 b + mu2 s + 0` → `mu2 b` ✓ (decreases by 5 + mu2 s)
- **mu3**: `1 + mu3 b + mu3 s + 0` → `mu3 b` ✓ (decreases by 1 + mu3 s)

### R_rec_succ: `recDelta b s (delta n) → app s (recDelta b s n)`
- **mu1**: `1 + mu1 b + mu1 s + (1 + mu1 n)` → `1 + mu1 s + (1 + mu1 b + mu1 s + mu1 n)`
  - LHS: `2 + mu1 b + mu1 s + mu1 n`
  - RHS: `2 + 2·mu1 s + mu1 b + mu1 n`
  - **FAILS** ✗ (increases by mu1 s)

- **mu2**: `5 + mu2 b + mu2 s + (1 + mu2 n)` → `1 + mu2 s + (5 + mu2 b + mu2 s + mu2 n)`
  - LHS: `6 + mu2 b + mu2 s + mu2 n`
  - RHS: `6 + 2·mu2 s + mu2 b + mu2 n`
  - **FAILS** ✗ (increases by mu2 s)

- **mu3**: `1 + mu3 b + mu3 s + (1 + mu3 n)` → `2 + mu3 s + (1 + mu3 b + mu3 s + mu3 n)`
  - LHS: `2 + mu3 b + mu3 s + mu3 n`
  - RHS: `3 + 2·mu3 s + mu3 b + mu3 n`
  - **FAILS** ✗ (increases by 1 + mu3 s)

### R_eq_refl & R_eq_diff
All three measures decrease on these rules.

## Conclusion

**All three candidates fail to be valid termination measures** because none of them strictly decrease under `R_rec_succ`. The rule `recDelta b s (delta n) → app s (recDelta b s n)` duplicates the `s` subterm in the recursive call, causing the measure to increase for all three proposals.

To fix this, the measures would need to assign much higher weights to the `recDelta` constructor relative to `app`, or employ a lexicographic ordering that prioritizes reducing the structure differently.
