After a rigorous symbolic analysis of all rewrite rules against each candidate measure, **none of the three proposed termination measures (mu1, mu2, mu3) are valid**. All fail specifically on the `R_rec_succ` rule (`recDelta b s (delta n) ↦ app s (recDelta b s n)`), violating the strict decrease requirement essential for termination proofs. Below is the precise failure analysis:

### Critical Failure: Rule `R_rec_succ`
For arbitrary terms `b`, `s`, `n`, the measure of the left-hand side (LHS) must strictly exceed the right-hand side (RHS). Symbolic evaluation reveals:
- **mu1**:  
  LHS = `2 + μ₁(b) + μ₁(s) + μ₁(n)`  
  RHS = `2 + μ₁(b) + 2·μ₁(s) + μ₁(n)`  
  → LHS − RHS = `−μ₁(s) ≤ 0`  
  *Fails*: Equal when `s = void` (μ₁(s)=0); decreases otherwise. **No strict decrease**.
  
- **mu2**:  
  LHS = `6 + μ₂(b) + μ₂(s) + μ₂(n)`  
  RHS = `6 + μ₂(b) + 2·μ₂(s) + μ₂(n)`  
  → LHS − RHS = `−μ₂(s) ≤ 0`  
  *Fails*: Identical issue to mu1 (equality when `s = void`).

- **mu3**:  
  LHS = `2 + μ₃(b) + μ₃(s) + μ₃(n)`  
  RHS = `3 + μ₃(b) + 2·μ₃(s) + μ₃(n)`  
  → LHS − RHS = `−1 − μ₃(s) < 0`  
  *Fails catastrophically*: Measure **increases** for all inputs (strictly larger RHS).

### Why This Is Fatal
- Termination requires **strict decrease for every possible rewrite step**, including all instantiations of `R_rec_succ` (e.g., `s = void`, `s = delta void`, etc.).
- mu1/mu2 fail due to non-strict decrease (equality cases break well-foundedness).  
- mu3 fails more severely (measure increases).  
- No candidate satisfies the condition `μ(LHS) > μ(RHS)` universally for this rule.  
- Structural analysis confirms impossibility: For generic coefficients `C_rec`, `C_delta`, `C_app`, the condition `C_delta > C_app + μ(s)` cannot hold for all `μ(s) ≥ 0`. All candidates violate this.

### Other Rules Are Irrelevant (But Verified)
All candidates **pass** every other rule (`R_int_delta`, `R_merge_*`, `R_rec_zero`, `R_eq_*`), as verified symbolically:
- Rules like `R_merge_cancel` or `R_eq_diff` show strict decrease (e.g., mu3 on `R_eq_diff`: `4 + 2μ(a) > 3 + 2μ(a)` holds).
- However, **a single failing rule invalidates the entire measure**. Since `R_rec_succ` fails for all candidates, no further analysis is needed.

### Conclusion
- **mu1**: Invalid (fails `R_rec_succ` with non-strict decrease).  
- **mu2**: Invalid (fails `R_rec_succ` identically to mu1).  
- **mu3**: Invalid (fails `R_rec_succ` with measure increase).  

No candidate provides a valid termination measure for this rewrite system. The flaw is inherent to the structural definitions of the measures relative to the `recDelta`/`app` interaction in `R_rec_succ`. To salvage termination, the measure definitions would require redesign (e.g., increasing the weight of `recDelta`'s third argument or reducing `app`'s overhead), but as proposed, all three candidates are unsound.
