A termination measure into `Nat` must strictly decrease for every constructor of `Step`.

All three candidates succeed on every rule except `R_rec_succ`.

Let \(B = \mu_i(b)\), \(S = \mu_i(s)\), and \(N = \mu_i(n)\).

| Candidate | Source: `recDelta b s (delta n)` | Target: `app s (recDelta b s n)` | Result |
|---|---:|---:|---|
| `mu1` | \(2+B+S+N\) | \(2+B+2S+N\) | target − source = \(S\) |
| `mu2` | \(6+B+S+N\) | \(6+B+2S+N\) | target − source = \(S\) |
| `mu3` | \(2+B+S+N\) | \(3+B+2S+N\) | target − source = \(1+S\) |

Thus:

- **`mu1` is not a valid strict termination measure.**
  - It is unchanged when `s = void`.
  - It increases whenever `mu1 s > 0`.

- **`mu2` is not a valid strict termination measure.**
  - It is unchanged when `s = void`.
  - It increases whenever `mu2 s > 0`.

- **`mu3` is not a valid strict termination measure.**
  - It increases on every `R_rec_succ` step, including when `s = void`.

A common concrete counterexample is:

```lean
Step
  (recDelta void void (delta void))
  (app void (recDelta void void void))
```

The source and target measures are:

- `mu1`: source `2`, target `2`
- `mu2`: source `6`, target `6`
- `mu3`: source `2`, target `3`

The other rewrite rules do strictly decrease all three measures, including `R_eq_diff` by exactly `1`. Therefore, the sole obstruction for each candidate is `R_rec_succ`, and **none of the three candidates proves termination by strict descent**.
