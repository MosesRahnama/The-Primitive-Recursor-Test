None of the three candidate measures is a valid termination measure for the given rewrite system.  

All three fail on the rule `R_rec_succ`:  
- `mu1(lhs) = 2 + mu1(b) + mu1(s) + mu1(n)`  
  `mu1(rhs) = 2 + mu1(b) + 2·mu1(s) + mu1(n)`  
  → `mu1(rhs) ≥ mu1(lhs)` (strictly greater when `mu1(s) > 0`).  
- `mu2(lhs) = 6 + mu2(b) + mu2(s) + mu2(n)`  
  `mu2(rhs) = 6 + mu2(b) + 2·mu2(s) + mu2(n)`  
  → same issue.  
- `mu3(lhs) = 2 + mu3(b) + mu3(s) + mu3(n)`  
  `mu3(rhs) = 3 + mu3(b) + 2·mu3(s) + mu3(n)`  
  → `mu3(rhs) > mu3(lhs)` for all `s`.  

Since a termination measure must strictly decrease on every rewrite step, and none of the three does so for `R_rec_succ`, they are all invalid.
