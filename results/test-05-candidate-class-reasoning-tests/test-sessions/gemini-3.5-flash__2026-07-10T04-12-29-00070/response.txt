An assessment of the three proposed termination measures (`mu1`, `mu2`, and `mu3`) for the given first-order rewrite calculus reveals that **none of the candidates are valid termination measures**. 

All three candidates fail to strictly decrease on the rewrite rule **`R_rec_succ`**, while successfully decreasing on all other seven rules.

---

### Detailed Assessment of Candidates on `R_rec_succ`

The rewrite rule `R_rec_succ` is defined as:
$$\text{recDelta } b\ s\ (\text{delta } n) \longrightarrow \text{app } s\ (\text{recDelta } b\ s\ n)$$

#### 1. Assessment of `mu1`
* **Definition of `mu1`:**
  * $\mu_1(\text{void}) = 0$
  * $\mu_1(\text{delta } t) = 1 + \mu_1(t)$
  * $\mu_1(\text{app } a\ b) = 1 + \mu_1(a) + \mu_1(b)$
  * $\mu_1(\text{recDelta } b\ s\ n) = 1 + \mu_1(b) + \mu_1(s) + \mu_1(n)$

* **Evaluation on `R_rec_succ`:**
  $$\begin{aligned}
  \text{LHS} &= \mu_1(\text{recDelta } b\ s\ (\text{delta } n)) \\
  &= 1 + \mu_1(b) + \mu_1(s) + (1 + \mu_1(n)) \\
  &= 2 + \mu_1(b) + \mu_1(s) + \mu_1(n)
  \end{aligned}$$
  
  $$\begin{aligned}
  \text{RHS} &= \mu_1(\text{app } s\ (\text{recDelta } b\ s\ n)) \\
  &= 1 + \mu_1(s) + (1 + \mu_1(b) + \mu_1(s) + \mu_1(n)) \\
  &= 2 + \mu_1(b) + 2\mu_1(s) + \mu_1(n)
  \end{aligned}$$

* **Conclusion for `mu1`:** 
  Comparing LHS and RHS: 
  $$\text{LHS} \le \text{RHS}$$
  If $\mu_1(s) > 0$ (for example, if $s = \text{delta void}$), then $\text{LHS} < \text{RHS}$ (the measure strictly increases). Thus, **`mu1` fails**.

---

#### 2. Assessment of `mu2`
* **Definition of `mu2`:**
  * $\mu_2(\text{void}) = 0$
  * $\mu_2(\text{delta } t) = 1 + \mu_2(t)$
  * $\mu_2(\text{app } a\ b) = 1 + \mu_2(a) + \mu_2(b)$
  * $\mu_2(\text{recDelta } b\ s\ n) = 5 + \mu_2(b) + \mu_2(s) + \mu_2(n)$

* **Evaluation on `R_rec_succ`:**
  $$\begin{aligned}
  \text{LHS} &= \mu_2(\text{recDelta } b\ s\ (\text{delta } n)) \\
  &= 5 + \mu_2(b) + \mu_2(s) + (1 + \mu_2(n)) \\
  &= 6 + \mu_2(b) + \mu_2(s) + \mu_2(n)
  \end{aligned}$$

  $$\begin{aligned}
  \text{RHS} &= \mu_2(\text{app } s\ (\text{recDelta } b\ s\ n)) \\
  &= 1 + \mu_2(s) + (5 + \mu_2(b) + \mu_2(s) + \mu_2(n)) \\
  &= 6 + \mu_2(b) + 2\mu_2(s) + \mu_2(n)
  \end{aligned}$$

* **Conclusion for `mu2`:** 
  Similarly, $\text{LHS} \le \text{RHS}$. Whenever $\mu_2(s) > 0$, the measure strictly increases. Thus, **`mu2` fails**.

---

#### 3. Assessment of `mu3`
* **Definition of `mu3`:**
  * $\mu_3(\text{void}) = 0$
  * $\mu_3(\text{delta } t) = 1 + \mu_3(t)$
  * $\mu_3(\text{app } a\ b) = 2 + \mu_3(a) + \mu_3(b)$
  * $\mu_3(\text{recDelta } b\ s\ n) = 1 + \mu_3(b) + \mu_3(s) + \mu_3(n)$

* **Evaluation on `R_rec_succ`:**
  $$\begin{aligned}
  \text{LHS} &= \mu_3(\text{recDelta } b\ s\ (\text{delta } n)) \\
  &= 1 + \mu_3(b) + \mu_3(s) + (1 + \mu_3(n)) \\
  &= 2 + \mu_3(b) + \mu_3(s) + \mu_3(n)
  \end{aligned}$$

  $$\begin{aligned}
  \text{RHS} &= \mu_3(\text{app } s\ (\text{recDelta } b\ s\ n)) \\
  &= 2 + \mu_3(s) + (1 + \mu_3(b) + \mu_3(s) + \mu_3(n)) \\
  &= 3 + \mu_3(b) + 2\mu_3(s) + \mu_3(n)
  \end{aligned}$$

* **Conclusion for `mu3`:** 
  In this case, because of the higher constant cost associated with `app`, $\text{LHS} < \text{RHS}$ always holds. The measure strictly increases even if $s = \text{void}$. Thus, **`mu3` fails**.

### Behavior on Other Rules (For Completeness)

All other rewrite rules strictly decrease under all three measures:

* **`R_int_delta`:** $\text{integrate (delta } t) \to \text{void}$
  * `mu1`: $2 + \mu_1(t) > 0$ (OK)
  * `mu2`: $3 + \mu_2(t) > 0$ (OK)
  * `mu3`: $3 + \mu_3(t) > 0$ (OK)

* **`R_merge_void_left` / `right` / `cancel`**:
  * For all three measures, $\mu(\text{merge } a\ b) > \mu(a)$ and $\mu(\text{merge } a\ b) > \mu(b)$ strictly holds. (OK)

* **`R_rec_zero`:** $\text{recDelta } b\ s\ \text{void} \to b$
  * `mu1`: $1 + \mu_1(b) + \mu_1(s) > \mu_1(b)$ (OK)
  * `mu2`: $5 + \mu_2(b) + \mu_2(s) > \mu_2(b)$ (OK)
  * `mu3`: $1 + \mu_3(b) + \mu_3(s) > \mu_3(b)$ (OK)

* **`R_eq_refl`:** $\text{eqW } a\ a \to \text{void}$
  * Decreases because $\mu(\text{eqW } a\ a) > 0$ for all candidates. (OK)

* **`R_eq_diff`:** $\text{eqW } a\ b \to \text{integrate (merge } a\ b)$
  * `mu1`: $3 + \mu_1(a) + \mu_1(b) > 2 + \mu_1(a) + \mu_1(b)$ (OK)
  * `mu2`: $5 + \mu_2(a) + \mu_2(b) > 4 + \mu_2(a) + \mu_2(b)$ (OK)
  * `mu3`: $4 + \mu_3(a) + \mu_3(b) > 3 + \mu_3(a) + \mu_3(b)$ (OK)

### Why Linear Measures Fail
To make a rule like `R_rec_succ` terminate, the measure of `recDelta` needs to scale non-linearly. Specifically, since `recDelta` acts as a recursion operator over the structure of its third argument (the "recursion counter" `n`), the weight of the step parameter `s` must be multiplied by the size of `n` (e.g., using a product such as $\mu(s) \cdot \mu(n)$ in the definition of $\mu(\text{recDelta } b\ s\ n)$). Standard linear size metrics like `mu1`, `mu2`, and `mu3` are mathematically incapable of proving termination for this system.
