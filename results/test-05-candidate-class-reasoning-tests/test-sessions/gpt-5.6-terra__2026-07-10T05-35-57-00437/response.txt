None of the three candidates is a valid strict termination measure for all `Step` rules.

The common failure is `R_rec_succ`:

```lean
Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

Let `B = μ b`, `S = μ s`, and `N = μ n`.

| Measure | Source | Target | Source − Target |
|---|---:|---:|---:|
| `mu1` | `2 + B + S + N` | `2 + B + 2*S + N` | `-S` |
| `mu2` | `6 + B + S + N` | `6 + B + 2*S + N` | `-S` |
| `mu3` | `2 + B + S + N` | `3 + B + 2*S + N` | `-1 - S` |

Consequences:

- `mu1` does not strictly decrease when `s = void` (`S = 0`), and increases when `s` is non-void.
- `mu2` has the same problem.
- `mu3` strictly increases even when `s = void`.

A concrete instance for all three is:

```lean
R_rec_succ void void void
```

namely:

```lean
recDelta void void (delta void)
  -->
app void (recDelta void void void)
```

Its values are:

| Measure | Left | Right |
|---|---:|---:|
| `mu1` | `2` | `2` |
| `mu2` | `6` | `6` |
| `mu3` | `2` | `3` |

Thus `mu1` and `mu2` fail strictness by equality here; `mu3` fails by an outright increase.

For completeness, every other rewrite rule does strictly decrease under each respective candidate:

- `R_int_delta`: decrease by at least `2`, `3`, `3` for `mu1`, `mu2`, `mu3`.
- `R_merge_void_left` and `R_merge_void_right`: decrease by `1`, `2`, `1`.
- `R_merge_cancel`: decrease by `1 + μ t`, `2 + μ t`, `1 + μ t`.
- `R_rec_zero`: decrease by `1 + μ s`, `5 + μ s`, `1 + μ s`.
- `R_eq_refl`: decreases to `0`.
- `R_eq_diff`: decreases by exactly `1` for all three.

So the assessment is:

- `mu1`: invalid due to `R_rec_succ`.
- `mu2`: invalid due to `R_rec_succ`.
- `mu3`: invalid due to `R_rec_succ`, more strongly than the first two.
