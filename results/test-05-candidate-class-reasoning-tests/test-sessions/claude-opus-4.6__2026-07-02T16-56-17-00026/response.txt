# Audit of Candidate Termination Measures

I need to verify that each candidate measure strictly decreases across every rewrite rule. That is, for each rule `Step t1 t2`, I need `mu(t1) > mu(t2)`.

Let me systematically check each rule against each measure. I'll use shorthand: `m(t)` for the measure applied to `t`.

## Rule-by-rule analysis

### Rule R_int_delta: `integrate (delta t) → void`

| Measure | LHS | RHS | Decrease? |
|---------|-----|-----|-----------|
| mu1 | `1 + (1 + m(t)) = 2 + m(t)` | `0` | ✅ |
| mu2 | `2 + (1 + m(t)) = 3 + m(t)` | `0` | ✅ |
| mu3 | `2 + (1 + m(t)) = 3 + m(t)` | `0` | ✅ |

### Rule R_merge_void_left: `merge void t → t`

| Measure | LHS | RHS | Decrease? |
|---------|-----|-----|-----------|
| mu1 | `1 + 0 + m(t) = 1 + m(t)` | `m(t)` | ✅ |
| mu2 | `2 + 0 + m(t) = 2 + m(t)` | `m(t)` | ✅ |
| mu3 | `1 + 0 + m(t) = 1 + m(t)` | `m(t)` | ✅ |

### Rule R_merge_void_right: `merge t void → t`

Same structure, symmetric. ✅ for all three.

### Rule R_merge_cancel: `merge t t → t`

| Measure | LHS | RHS | Decrease? |
|---------|-----|-----|-----------|
| mu1 | `1 + m(t) + m(t) = 1 + 2·m(t)` | `m(t)` | ✅ (since `1 + m(t) > 0`) |
| mu2 | `2 + 2·m(t)` | `m(t)` | ✅ |
| mu3 | `1 + 2·m(t)` | `m(t)` | ✅ |

### Rule R_rec_zero: `recDelta b s void → b`

| Measure | LHS | RHS | Decrease? |
|---------|-----|-----|-----------|
| mu1 | `1 + m(b) + m(s) + 0` | `m(b)` | ✅ |
| mu2 | `5 + m(b) + m(s) + 0` | `m(b)` | ✅ |
| mu3 | `1 + m(b) + m(s) + 0` | `m(b)` | ✅ |

### Rule R_rec_succ: `recDelta b s (delta n) → app s (recDelta b s n)`

| Measure | LHS | RHS |
|---------|-----|-----|
| mu1 | `1 + m(b) + m(s) + (1 + m(n))` = `2 + m(b) + m(s) + m(n)` | `1 + m(s) + (1 + m(b) + m(s) + m(n))` = `2 + m(b) + 2·m(s) + m(n)` |

**mu1**: LHS − RHS = `−m(s)`. This is **≤ 0**, so **mu1 fails** ❌ (whenever `m(s) > 0`).

| mu2 | `5 + m(b) + m(s) + 1 + m(n)` = `6 + m(b) + m(s) + m(n)` | `1 + m(s) + (5 + m(b) + m(s) + m(n))` = `6 + m(b) + 2·m(s) + m(n)` |

**mu2**: LHS − RHS = `−m(s)`. **mu2 fails** ❌.

| mu3 | `1 + m(b) + m(s) + 1 + m(n)` = `2 + m(b) + m(s) + m(n)` | `2 + m(s) + (1 + m(b) + m(s) + m(n))` = `3 + m(b) + 2·m(s) + m(n)` |

**mu3**: LHS − RHS = `−1 − m(s)`. **mu3 fails** ❌.

### Rules R_eq_refl and R_eq_diff

These are easily checked but moot given the above.

Notably, **R_eq_diff** (`eqW a b → integrate (merge a b)`) requires the eqW constant to exceed integrate + merge costs: mu1 needs `3 > 1 + 1 = 2` ✅; mu2 needs `5 > 2 + 2 = 4` ✅; mu3 needs `4 > 2 + 1 = 3` ✅.

## Verdict

**All three candidates fail** on rule **R_rec_succ**. The right-hand side `app s (recDelta b s n)` duplicates `s`, adding an extra copy of `m(s)` that none of the measures can absorb. No simple additive measure over subterms can handle this rule without accounting for the duplication (e.g., via a multiplicative or exponential component in the measure).
