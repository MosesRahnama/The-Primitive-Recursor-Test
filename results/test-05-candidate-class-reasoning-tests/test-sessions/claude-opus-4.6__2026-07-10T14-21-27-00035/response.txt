# Audit of Candidate Termination Measures

I need to verify that for each rewrite rule `Step t1 t2`, the candidate measure strictly decreases: `mu(t1) > mu(t2)`.

## Systematic Analysis of Each Rule

Let me work through each rule for all three measures.

| Measure | LHS | RHS | Decreases? |
|---------|-----|-----|------------|
| mu1 | 1 + (1 + mu1 t) = 2 + mu1 t | 0 | ✅ |
| mu2 | 2 + (1 + mu2 t) = 3 + mu2 t | 0 | ✅ |
| mu3 | 2 + (1 + mu3 t) = 3 + mu3 t | 0 | ✅ |

### R_merge_cancel: `merge t t → t`

| Measure | LHS | RHS | Decreases? |

### R_rec_zero: `recDelta b s void → b`

| Measure | LHS | RHS | Decreases? |
|---------|-----|-----|------------|
| mu1 | 1 + mu1 b + mu1 s + 0 | mu1 b | ✅ |

| mu3 | 1 + mu3 b + mu3 s + 0 | mu3 b | ✅ |

### R_rec_succ: `recDelta b s (delta n) → app s (recDelta b s n)`

| Measure | LHS | RHS |
|---------|-----|-----|
| mu1 | 1 + mu1 b + mu1 s + (1 + mu1 n) = **2 + mu1 b + mu1 s + mu1 n** | 1 + mu1 s + (1 + mu1 b + mu1 s + mu1 n) = **2 + mu1 b + 2·mu1 s + mu1 n** |
| mu2 | 5 + mu2 b + mu2 s + 1 + mu2 n = **6 + mu2 b + mu2 s + mu2 n** | 1 + mu2 s + (5 + mu2 b + mu2 s + mu2 n) = **6 + mu2 b + 2·mu2 s + mu2 n** |
| mu3 | 1 + mu3 b + mu3 s + 1 + mu3 n = **2 + mu3 b + mu3 s + mu3 n** | 2 + mu3 s + (1 + mu3 b + mu3 s + mu3 n) = **3 + mu3 b + 2·mu3 s + mu3 n** |

- **mu1**: LHS − RHS = −mu1 s. Fails when mu1 s > 0. **❌ UNSOUND**
- **mu2**: LHS − RHS = −mu2 s. Fails when mu2 s > 0. **❌ UNSOUND**
- **mu3**: LHS − RHS = −1 − mu3 s. Always fails. **❌ UNSOUND**

### R_eq_refl and R_eq_diff

These would need checking too, but the `R_rec_succ` rule already sinks all three.

## Verdict

**All three candidates are unsound.** The critical failure is rule `R_rec_succ`, where `recDelta b s (delta n)` rewrites to `app s (recDelta b s n)`. The right-hand side duplicates `s` (once directly in `app`, once inside the recursive `recDelta`), so the measure of the RHS includes `2·mu(s)` versus only `1·mu(s)` on the left. No additive constant on the `recDelta` constructor can compensate for this duplication when `s` is arbitrarily large. None of the three measures assigns a sufficiently large overhead to `delta` relative to `app` + the duplication of `s` to make this work.
