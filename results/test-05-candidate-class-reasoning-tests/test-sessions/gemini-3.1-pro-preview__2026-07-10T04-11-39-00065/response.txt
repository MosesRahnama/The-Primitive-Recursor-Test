To determine whether `mu1`, `mu2`, or `mu3` are valid termination measures for the rewrite calculus defined by `Step`, we must check if the measure strictly decreases for every rule—that is, `mu(LHS) > mu(RHS)` for all possible terms. 

All three candidate measures successfully prove a strict decrease for most of the rewrite rules (such as `R_int_delta`, `R_merge_*`, `R_rec_zero`, and `R_eq_*`), but **all three candidates completely fail on `R_rec_succ`**.

### The Problematic Rule: `R_rec_succ`
```lean
R_rec_succ : forall b s n, Step (recDelta b s (delta n)) (app s (recDelta b s n))
```
Notice that the variable `s` is **duplicated**. It appears once on the left-hand side (LHS) but twice on the right-hand side (RHS). Because all three proposed measures are linear, additive polynomials, they cannot compensate for the fact that `s` could be an arbitrarily large term. 

Let's evaluate the LHS and RHS for each candidate mathematically:

#### Candidate 1 (`mu1`)
* **LHS:** `mu1(recDelta b s (delta n)) = 1 + b + s + (1 + n) = 2 + b + s + n`
* **RHS:** `mu1(app s (recDelta b s n)) = 1 + s + (1 + b + s + n) = 2 + b + 2s + n`
* **Decrease (`LHS > RHS`):** `2 + b + s + n > 2 + b + 2s + n  =>  0 > s`
Because `s` can be any term (e.g., if `s = delta void`, its measure is `1`), `0 > s` is inherently **false**.

#### Candidate 2 (`mu2`)
* **LHS:** `mu2(recDelta b s (delta n)) = 5 + b + s + (1 + n) = 6 + b + s + n`
* **RHS:** `mu2(app s (recDelta b s n)) = 1 + s + (5 + b + s + n) = 6 + b + 2s + n`
* **Decrease (`LHS > RHS`):** `6 + b + s + n > 6 + b + 2s + n  =>  0 > s`
Just like `mu1`, this requires `0 > s`, which is **false**.

#### Candidate 3 (`mu3`)
* **LHS:** `mu3(recDelta b s (delta n)) = 1 + b + s + (1 + n) = 2 + b + s + n`
* **RHS:** `mu3(app s (recDelta b s n)) = 2 + s + (1 + b + s + n) = 3 + b + 2s + n`
* **Decrease (`LHS > RHS`):** `2 + b + s + n > 3 + b + 2s + n  =>  -1 > s`
This candidate actually *increases* in measure unconditionally, rendering it completely **false**.

### Conclusion
**None of the three candidates are valid termination measures.** 

Because `recDelta` is essentially a recursor that duplicates `s` exactly `n` times, a purely additive/linear polynomial interpretation can never prove termination for this calculus. To successfully capture the termination of this system, you would need an interpretation that handles duplication—either through an exponential measure, a multiplicative polynomial (e.g., weighing `recDelta` proportionally to `mu(s) * mu(n)`), or a Lexicographic Path Ordering (LPO).
