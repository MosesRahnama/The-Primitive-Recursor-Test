### Assessment of Termination Measure Candidates

All three candidates (**`mu1`**, **`mu2`**, **`mu3`**) **fail** to be valid termination measures for the given rewrite calculus. The failure occurs exclusively on the rule **`R_rec_succ`** (rule 6):  
`recDelta b s (delta n) ⟶ app s (recDelta b s n)`.  

No candidate satisfies the strict decrease requirement (`μ(LHS) > μ(RHS)`) for this rule under all valid term instantiations. Below is the precise failure analysis:

---

#### 🔴 Critical Failure: Rule `R_rec_succ` (Rule 6)
For **any** additive structural measure of the form used in the candidates (where subterm measures sum positively), the RHS contains **two occurrences of `s`** (once in `app s ...`, once inside `recDelta b s n`), while the LHS contains **only one occurrence of `s`**. This structural imbalance makes strict decrease impossible for non-negative measures. Concrete verification:

| Candidate | `μ(LHS)` = `μ(recDelta b s (delta n))` | `μ(RHS)` = `μ(app s (recDelta b s n))` | Failure Mode |
|-----------|------------------------------------------|------------------------------------------|--------------|
| **`mu1`** | `2 + μ(b) + μ(s) + μ(n)` | `2 + μ(b) + 2·μ(s) + μ(n)` | `μ(LHS) - μ(RHS) = -μ(s) ≤ 0`<br>→ **Equality** when `s = void` (e.g., `μ(LHS)=μ(RHS)=2`). Violates *strict* decrease. |
| **`mu2`** | `6 + μ(b) + μ(s) + μ(n)` | `6 + μ(b) + 2·μ(s) + μ(n)` | `μ(LHS) - μ(RHS) = -μ(s) ≤ 0`<br>→ **Equality** when `s = void` (e.g., `μ(LHS)=μ(RHS)=6`). Violates *strict* decrease. |
| **`mu3`** | `2 + μ(b) + μ(s) + μ(n)` | `3 + μ(b) + 2·μ(s) + μ(n)` | `μ(LHS) - μ(RHS) = -1 - μ(s) < 0`<br>→ **Strict increase** even for `s = void` (`μ(LHS)=2`, `μ(RHS)=3`). Catastrophic failure. |

**Why this is fatal**:  
- Termination requires **strict decrease for every applicable rewrite step**, regardless of term structure.  
- `s = void` is a valid ground term (per `Trace.void`), making equality (for `mu1`/`mu2`) or increase (for `mu3`) unavoidable.  
- The structural duplication of `s` in the RHS cannot be compensated by constant offsets in additive measures. No candidate resolves this.

---

#### ✅ Other Rules Pass (But Irrelevant Due to Rule 6 Failure)
All candidates **correctly decrease** on the remaining 7 rules (`R_int_delta`, `R_merge_*`, `R_rec_zero`, `R_eq_*`):  
- Rules 1–5, 7: Constants ensure `μ(LHS) > μ(RHS)` (e.g., `merge t t ⟶ t` has `1 + 2μ(t) > μ(t)`).  
- Rule 8 (`eqW a b ⟶ integrate (merge a b)`): Constants satisfy `μ(eqW) > μ(integrate ∘ merge)` (e.g., `mu3`: `4 + ... > 3 + ...`).  
- Rule 7 (`eqW a a ⟶ void`) holds trivially (`μ(eqW a a) ≥ 3 > 0`).  

However, **a single failing rule invalidates the entire measure**. Passing other rules does not salvage the candidates.

---

#### 📌 Conclusion
- **`mu1`**: Fails due to non-strict decrease (equality) on `R_rec_succ` when `s` is minimal (e.g., `void`).  
- **`mu2`**: Same failure mode as `mu1` (equality on minimal `s`). Higher constants elsewhere are irrelevant.  
- **`mu3`**: Worst failure—measure **increases** on `R_rec_succ` even for trivial terms.  

**No candidate is a valid termination measure**. The rewrite rule `R_rec_succ` inherently duplicates the subterm `s`, which cannot be handled by simple additive structural measures with non-negative weights. A valid measure would require:  
- Non-additive structure (e.g., lexicographic tuples, dependency pairs),  
- Context-sensitive weighting (e.g., discounting duplicated subterms),  
- Or a fundamentally different approach (e.g., interpreting terms in a well-founded domain where duplication is controlled).  

The candidates, as defined, are **provably insufficient** for termination of this calculus. Rule `R_rec_succ` is the definitive counterexample for all three.
