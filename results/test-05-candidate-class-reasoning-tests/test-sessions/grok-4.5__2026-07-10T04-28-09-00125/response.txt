### Assessment of the three candidates

The rewrite system is given by the inductive relation `Step`. A function \(\mu : \mathrm{Trace} \to \mathbb{N}\) is a valid (strict) termination measure if \(\mu(t) > \mu(t')\) holds for every instance of every rule \(t \mathrel{\mathrm{Step}} t'\). (Because each \(\mu_i\) is defined by a strictly positive linear combination of the measures of immediate subterms, any such decrease on a redex automatically lifts to an arbitrary context; it is therefore enough to examine the eight rules themselves.)

All three candidates fail this test. The failure is concentrated on a single rule; the other seven rules are unproblematic for every candidate. The detailed case analysis follows.

#### Common notation
Write \(m_x\) for \(\mu_i(x)\) (the particular \(\mu_i\) being clear from context) and let \(c_C\) be the constant appearing in the clause of \(\mu_i\) for constructor \(C\).

#### Rules that decrease for every \(\mu_i\)
- \(\mathrm{R\_int\_delta}\).  
  \(\mu(\mathrm{integrate}\,(\mathrm{delta}\,t)) = c_{\mathrm{integrate}} + c_{\mathrm{delta}} + m_t > 0 = \mu(\mathrm{void})\).

- \(\mathrm{R\_merge\_void\_left/right}\).  
  \(\mu(\mathrm{merge}\,\mathrm{void}\,t) = c_{\mathrm{merge}} + m_t > m_t\).

- \(\mathrm{R\_merge\_cancel}\).  
  \(\mu(\mathrm{merge}\,t\,t) = c_{\mathrm{merge}} + 2m_t > m_t\).

- \(\mathrm{R\_rec\_zero}\).  
  \(\mu(\mathrm{recDelta}\,b\,s\,\mathrm{void}) = c_{\mathrm{rec}} + m_b + m_s > m_b\).

- \(\mathrm{R\_eq\_refl}\).  
  \(\mu(\mathrm{eqW}\,a\,a) = c_{\mathrm{eq}} + 2m_a > 0\).

- \(\mathrm{R\_eq\_diff}\).  
  The constants satisfy \(c_{\mathrm{eq}} > c_{\mathrm{integrate}} + c_{\mathrm{merge}}\) for each of the three definitions, therefore  
  \(\mu(\mathrm{eqW}\,a\,b) = c_{\mathrm{eq}} + m_a + m_b > c_{\mathrm{integrate}} + c_{\mathrm{merge}} + m_a + m_b = \mu(\mathrm{integrate}\,(\mathrm{merge}\,a\,b))\).

#### The failing rule \(\mathrm{R\_rec\_succ}\)
\[
\mathrm{recDelta}\,b\,s\,(\mathrm{delta}\,n)
\quad\mathrel{\mathrm{Step}}\quad
\mathrm{app}\,s\,(\mathrm{recDelta}\,b\,s\,n).
\]
A short calculation yields the difference of measures:
\[
\mu(\mathrm{lhs}) - \mu(\mathrm{rhs})
\;=\;
(c_{\mathrm{delta}} - c_{\mathrm{app}}) - m_s.
\]
- For \(\mu_1\) one has \(c_{\mathrm{delta}}=c_{\mathrm{app}}=1\), so the difference equals \(-m_s\le 0\).  
  Equality holds precisely when \(s=\mathrm{void}\); the measure *increases* as soon as \(m_s>0\).
- For \(\mu_2\) the constants are again \(c_{\mathrm{delta}}=c_{\mathrm{app}}=1\), producing the identical non-positive difference.
- For \(\mu_3\) one has \(c_{\mathrm{delta}}=1\) and \(c_{\mathrm{app}}=2\), so the difference equals \(-1-m_s<0\); the measure *strictly increases* on every instance of the rule.

Consequently none of the three functions is a strict ranking function for \(\mathrm{Step}\).

#### Why a linear measure cannot work
The rule duplicates the subterm \(s\). Any measure that simply adds \(m_s\) (with a fixed coefficient) therefore receives an extra positive contribution \(m_s\) on the right-hand side. The only “fuel” available on the left-hand side is the constant \(c_{\mathrm{delta}}\) coming from the destroyed \(\mathrm{delta}\)-constructor; that constant cannot dominate an arbitrarily large \(m_s\). Hence no function of the shape proposed by the three candidates can be a termination measure for the given calculus.

(The rewrite system is nevertheless terminating—the recursor simply unfolds a finite numeral—but a proof of that fact requires a measure that grows at least exponentially with the height of the numeral, e.g. an interpretation of \(\mathrm{recDelta}\) that multiplies by a factor depending on \(s\).)

**Summary.**  
\(\mu_1\), \(\mu_2\) and \(\mu_3\) are all invalid termination measures.
