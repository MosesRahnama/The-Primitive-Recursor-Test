The three candidate termination measures **all fail** to be valid for the given rewrite system `Step`. A measure `mu : Trace → Nat` is a termination measure if for each rule `Step s t` we have `mu(s) > mu(t)`. The failure occurs on the rule `R_rec_succ`:

```
R_rec_succ: Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

Below are the computations for each candidate:

**1. `mu1`**
```
mu1(recDelta b s (delta n)) = 2 + mu1 b + mu1 s + mu1 n
mu1(app s (recDelta b s n)) = 2 + mu1 b + 2*mu1 s + mu1 n
```
The difference is `- mu1 s`. Since `mu1 s ≥ 0`, the measure does not decrease; it actually increases when `mu1 s > 0` and stays equal when `mu1 s = 0`. **Not a termination measure.**

**2. `mu2`**
```
mu2(recDelta b s (delta n)) = 6 + mu2 b + mu2 s + mu2 n
mu2(app s (recDelta b s n)) = 6 + mu2 b + 2*mu2 s + mu2 n
```
Difference is again `- mu2 s ≤ 0`. **Not a termination measure.**

**3. `mu3`**
```
mu3(recDelta b s (delta n)) = 2 + mu3 b + mu3 s + mu3 n
mu3(app s (recDelta b s n)) = 3 + mu3 b + 2*mu3 s + mu3 n
```
Difference is `-1 - mu3 s < 0`. **Not a termination measure.**

All three candidates fail because the right-hand side of `R_rec_succ` duplicates the argument `s`, and each measure is a linear combination of the measures of its subterms. No linear weighting can make the measure strictly decrease under duplication.
