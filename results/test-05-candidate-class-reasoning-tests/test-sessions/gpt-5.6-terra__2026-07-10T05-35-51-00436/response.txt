None of the three candidates is a valid strict termination measure for all `Step` rules.

For each measure, all rules decrease except `R_rec_succ`.

### `mu1`

For

```lean
Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

write `B = mu1 b`, `S = mu1 s`, `N = mu1 n`.

```text
mu1 (recDelta b s (delta n))
= 1 + B + S + (1 + N)
= 2 + B + S + N

mu1 (app s (recDelta b s n))
= 1 + S + (1 + B + S + N)
= 2 + B + 2*S + N
```

Thus the right-hand side exceeds the left-hand side by `S`.

- If `s = void`, the measure is unchanged.
- If `s` has positive measure, the rewrite increases the measure.

For example, with `b = void`, `s = delta void`, and `n = void`:

```text
mu1 (recDelta void (delta void) (delta void)) = 3
mu1 (app (delta void) (recDelta void (delta void) void)) = 4
```

So `mu1` fails.

---

### `mu2`

Similarly, with `B = mu2 b`, `S = mu2 s`, and `N = mu2 n`:

```text
mu2 (recDelta b s (delta n))
= 5 + B + S + (1 + N)
= 6 + B + S + N

mu2 (app s (recDelta b s n))
= 1 + S + (5 + B + S + N)
= 6 + B + 2*S + N
```

Again, the result is larger by `S`.

- `s = void` gives equality rather than a strict decrease.
- Any non-`void` step term causes an increase.

For the same concrete substitution:

```text
mu2 (recDelta void (delta void) (delta void)) = 7
mu2 (app (delta void) (recDelta void (delta void) void)) = 8
```

So `mu2` also fails.

---

### `mu3`

For `mu3`:

```text
mu3 (recDelta b s (delta n))
= 1 + B + S + (1 + N)
= 2 + B + S + N

mu3 (app s (recDelta b s n))
= 2 + S + (1 + B + S + N)
= 3 + B + 2*S + N
```

The right-hand side exceeds the left-hand side by `1 + S`.

Therefore `R_rec_succ` strictly increases `mu3` for every possible `s`, including `void`.

For example:

```text
mu3 (recDelta void void (delta void)) = 2
mu3 (app void (recDelta void void void)) = 3
```

So `mu3` fails even more directly.

---

### Other rules

For all three candidates, the other seven rules are strictly decreasing:

- `R_int_delta`
- `R_merge_void_left`
- `R_merge_void_right`
- `R_merge_cancel`
- `R_rec_zero`
- `R_eq_refl`
- `R_eq_diff`

The sole obstruction in each case is `R_rec_succ`, whose right-hand side duplicates `s`: once as the left argument of `app`, and once inside the recursive call. A simple additive size measure cannot decrease across that duplication unless the recursive-call contribution is weighted or ordered differently.
