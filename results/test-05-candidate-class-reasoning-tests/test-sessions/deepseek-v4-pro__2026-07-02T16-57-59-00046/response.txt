All three candidates fail to serve as strict termination measures for the given rewrite relation `Step`. The problematic rule is `R_rec_succ`:

```
R_rec_succ : forall b s n, Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

For any measure `mu` of the form used here—where `mu (recDelta b s n) = C₁ + mu b + mu s + mu n` and `mu (app a b) = C₂ + mu a + mu b`—the values compare as follows:

- LHS: `mu (recDelta b s (delta n)) = C₁ + mu b + mu s + (1 + mu n) = (C₁ + 1) + mu b + mu s + mu n`
- RHS: `mu (app s (recDelta b s n)) = C₂ + mu s + (C₁ + mu b + mu s + mu n) = (C₁ + C₂) + mu b + 2·mu s + mu n`

The difference is  
`RHS - LHS = (C₂ - 1) + mu s`.

Since `mu s ≥ 0` and in each candidate `C₂ ≥ 1` (for `mu1`, `C₂ = 1`; for `mu2`, `C₂ = 1`; for `mu3`, `C₂ = 2`), we always have `RHS - LHS ≥ mu s ≥ 0`. Thus `mu(LHS) ≤ mu(RHS)`, so the measure does not strictly decrease. In fact, unless `s` is `void` (making `mu s = 0`) and `C₂ = 1`, it strictly increases. This violates the requirement that every step must lower the measure.

**Specific failures:**

- **`mu1`**: `C₁ = 1`, `C₂ = 1`.  
  LHS = `2 + mu1 b + mu1 s + mu1 n`, RHS = `2 + mu1 b + 2·mu1 s + mu1 n`.  
  RHS = LHS + `mu1 s` ≥ LHS. Not decreasing.

- **`mu2`**: `C₁ = 5`, `C₂ = 1`.  
  LHS = `6 + mu2 b + mu2 s + mu2 n`, RHS = `6 + mu2 b + 2·mu2 s + mu2 n`.  
  RHS = LHS + `mu2 s` ≥ LHS. Not decreasing.

- **`mu3`**: `C₁ = 1`, `C₂ = 2`.  
  LHS = `2 + mu3 b + mu3 s + mu3 n`, RHS = `3 + mu3 b + 2·mu3 s + mu3 n`.  
  RHS = LHS + `1 + mu3 s` > LHS. Not decreasing.

All other rules do produce a strict decrease under each candidate, but the single counterexample `R_rec_succ` makes each candidate invalid as a termination measure.
