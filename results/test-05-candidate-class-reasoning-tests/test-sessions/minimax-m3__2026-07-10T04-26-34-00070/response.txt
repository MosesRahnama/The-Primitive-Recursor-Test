# Termination Measure Assessment

I need to verify that for every rewrite rule `Step L R`, the measure satisfies `μ(L) > μ(R)` (strict decrease).

## Per-rule check

Let me write `μ(t)` succinctly using variable names as measure values (e.g. `a` for `μ(a)`).

| Rule | LHS | RHS |
|------|-----|-----|
| R_int_delta | integrate(delta t) | void |
| R_merge_void_left | merge(void, t) | t |
| R_merge_void_right | merge(t, void) | t |
| R_merge_cancel | merge(t, t) | t |
| R_rec_zero | recDelta b s void | b |
| **R_rec_succ** | **recDelta b s (delta n)** | **app s (recDelta b s n)** |
| R_eq_refl | eqW a a | void |
| R_eq_diff | eqW a b | integrate (merge a b) |

## Verdict — all three fail

Every candidate breaks on **R_rec_succ**. Computing the LHS vs RHS for that rule:

| Measure | LHS = μ(recDelta b s (delta n)) | RHS = μ(app s (recDelta b s n)) | LHS − RHS |
|---------|---|---|---|
| μ1 | `1 + b + s + (1+n) = 2 + b + s + n` | `1 + s + (1 + b + s + n) = 2 + b + 2s + n` | **−s** |
| μ2 | `5 + b + s + (1+n) = 6 + b + s + n` | `1 + s + (5 + b + s + n) = 6 + b + 2s + n` | **−s** |
| μ3 | `1 + b + s + (1+n) = 2 + b + s + n` | `2 + s + (1 + b + s + n) = 3 + b + 2s + n` | **−s − 1** |

For every measure the difference is **negative** whenever `s ≠ 0` (and zero when `s = 0`). So the LHS is *not strictly greater* than the RHS — in fact, the measures all **increase** through the unfold when the step argument `s` is non-zero. None of the three weight the recursion counter `n` heavily enough to be drained by a single unfolding: each one treats `recDelta` as a sum of its three sub-terms, and the `app` constructor in the RHS reintroduces an extra `1 + s` that is not paid for by consuming the `delta n` head.

All other rules are fine (the most delicate of them, R_eq_diff, decreases by exactly 1 in each measure because `3 + a + b > 1 + (1 + a + b)` for μ1, `5 + a + b > 2 + (2 + a + b)` for μ2, and `4 + a + b > 2 + (1 + a + b)` for μ3). But that doesn't save the candidates.

## Conclusion

**μ1, μ2, and μ3 are all invalid termination measures.** Each of them is *not* strictly decreasing on `R_rec_succ` — they all increase by an amount proportional to the size of the step term `s`. To obtain a valid measure one would need to weight the recursion counter `n` in `recDelta` significantly more heavily than the other components (e.g. give `n` a coefficient ≥ 2 in `recDelta`) so that the single `delta`-unfolding in `R_rec_succ` produces a genuine drop.
