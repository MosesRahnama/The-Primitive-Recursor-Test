# Audit of Candidate Termination Measures

I need to verify that for each rewrite rule `Step t t'`, the candidate measure strictly decreases: `mu(t) > mu(t')`. Let me check each measure against every rule.

## Notation

For each rule, I'll compute `mu(lhs)` and `mu(rhs)` and check strict decrease.

## mu1

| Rule | LHS measure | RHS measure | Decrease? |
|------|------------|-------------|-----------|
| `R_int_delta`: `integrate (delta t) → void` | `1 + (1 + mu1 t) = 2 + mu1 t` | `0` | ✅ |
| `R_merge_void_left`: `merge void t → t` | `1 + 0 + mu1 t = 1 + mu1 t` | `mu1 t` | ✅ |
| `R_merge_void_right`: `merge t void → t` | `1 + mu1 t + 0 = 1 + mu1 t` | `mu1 t` | ✅ |
| `R_merge_cancel`: `merge t t → t` | `1 + mu1 t + mu1 t = 1 + 2·mu1 t` | `mu1 t` | ✅ |
| `R_rec_zero`: `recDelta b s void → b` | `1 + mu1 b + mu1 s + 0` | `mu1 b` | ✅ |
| `R_rec_succ`: `recDelta b s (delta n) → app s (recDelta b s n)` | `1 + mu1 b + mu1 s + (1 + mu1 n) = 2 + mu1 b + mu1 s + mu1 n` | `1 + mu1 s + (1 + mu1 b + mu1 s + mu1 n) = 2 + mu1 b + 2·mu1 s + mu1 n` | ❌ Need `2 + mu1 b + mu1 s + mu1 n > 2 + mu1 b + 2·mu1 s + mu1 n`, i.e. `0 > mu1 s`. **Fails** unless `s = void`. |
| `R_eq_refl`: `eqW a a → void` | `3 + 2·mu1 a` | `0` | ✅ |
| `R_eq_diff`: `eqW a b → integrate (merge a b)` | `3 + mu1 a + mu1 b` | `1 + (1 + mu1 a + mu1 b) = 2 + mu1 a + mu1 b` | ✅ |

**mu1 is UNSOUND.** It fails on `R_rec_succ` because the recursive unfolding duplicates `s` in the result (once in `app` and once inside the recursive `recDelta`), and `mu1` doesn't give `recDelta` enough overhead to absorb the extra copy of `s`.

## Summary

**All three candidates fail** on the `R_rec_succ` rule:

```
recDelta b s (delta n)  →  app s (recDelta b s n)
```

The right-hand side contains both `s` standalone and `s` embedded inside the recursive `recDelta b s n` call. Any additive measure of the form `c + mu(b) + mu(s) + mu(n)` for `recDelta` will produce LHS measure `c + mu(b) + mu(s) + (1 + mu(n))` while the RHS measure is at least `mu(s) + (c + mu(b) + mu(s) + mu(n))`, which includes **two copies** of `mu(s)`. For strict decrease we would need `1 > mu(s)`, which fails for non-trivial `s`.

A correct termination measure for this system would likely require either:
- A **multiplicative** component (e.g., involving `mu(s) * mu(n)`)
- A **lexicographic/multiset ordering**
- Restricting `s` to a class with bounded measure

None of `mu1`, `mu2`, or `mu3` is a valid termination measure for this rewrite system.
