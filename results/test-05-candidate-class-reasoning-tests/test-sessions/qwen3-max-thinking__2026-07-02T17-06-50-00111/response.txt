### Assessment of Termination Measures for the Rewrite Calculus

All three candidate measures (**`mu1`**, **`mu2`**, **`mu3`**) **fail** to be valid termination measures for the given rewrite system. Each violates the strict-decrease requirement on the **`R_rec_succ`** rule. Below is a precise, rule-by-rule analysis.

---

#### 🔴 Critical Failure: Rule `R_rec_succ`
`Step (recDelta b s (delta n)) (app s (recDelta b s n))`  
For termination, we require:  
`mu(recDelta b s (delta n)) > mu(app s (recDelta b s n))` for **all** traces `b, s, n`.

| Measure | LHS (`recDelta b s (delta n)`) | RHS (`app s (recDelta b s n)`) | Comparison | Verdict |
|--------|--------------------------------|--------------------------------|------------|---------|
| **`mu1`** | `2 + μb + μs + μn` | `2 + μb + 2·μs + μn` | LHS − RHS = `−μs` ≤ 0 | ❌ Fails: **non-strict** (equal when `μs = 0`, e.g., `s = void`) |
| **`mu2`** | `6 + μb + μs + μn` | `6 + μb + 2·μs + μn` | LHS − RHS = `−μs` ≤ 0 | ❌ Fails: **non-strict** (equal when `μs = 0`) |
| **`mu3`** | `2 + μb + μs + μn` | `3 + μb + 2·μs + μn` | LHS − RHS = `−1 − μs` < 0 | ❌ Fails: **strict increase** (always larger RHS) |

- **Concrete counterexample** (valid for `mu1`, `mu2`):  
  Let `b = void`, `s = void`, `n = void`.  
  - LHS: `recDelta void void (delta void)`  
    `mu1 = 1 + 0 + 0 + (1 + 0) = 2`  
  - RHS: `app void (recDelta void void void)`  
    `mu1 = 1 + 0 + (1 + 0 + 0 + 0) = 2`  
  → **No decrease** (violates strictness).  
- For `mu3`, the RHS is **always larger** (e.g., same inputs yield LHS=2, RHS=3).

This single failure invalidates all three candidates. Termination measures must decrease **strictly** on **every** possible rewrite step; equality or increase is unacceptable.

---

#### ✅ Other Rules Are Satisfied by All Candidates
All candidates **correctly decrease** on the remaining 7 rules:
- `R_int_delta`, `R_merge_void_left/right`, `R_merge_cancel`, `R_rec_zero`, `R_eq_refl`, `R_eq_diff`  
  → Verified algebraically: LHS measure > RHS measure holds universally (e.g., constants ensure strict decrease even when subterm measures are zero).
- **Critical note on `eqW` rules**:  
  Both `R_eq_refl` (for `eqW a a`) and `R_eq_diff` (for any `eqW a b`, including `a = b`) must be checked. All candidates satisfy **both**:
  - `R_eq_refl`: `mu(eqW a a) ≥ 3 (mu1), 5 (mu2), 4 (mu3) > 0 = mu(void)`
  - `R_eq_diff`: `mu(eqW a b) − mu(integrate (merge a b)) = 1` for all candidates (e.g., `mu1`: `3+μa+μb > 2+μa+μb`).

No other rule exposes flaws. The **sole and decisive failure** is `R_rec_succ`.

---

#### 📌 Conclusion
- **`mu1`**: Invalid — non-strict decrease on `R_rec_succ` (equality possible).  
- **`mu2`**: Invalid — non-strict decrease on `R_rec_succ` (equality possible).  
- **`mu3`**: Invalid — **increases** on `R_rec_succ` (strict violation).  

**None of the proposed measures are valid termination measures.**  
The flaw stems from structural mismatch in `R_rec_succ`: the RHS (`app s (recDelta b s n)`) introduces an **extra occurrence of `s`** in the measure computation compared to the LHS. All candidates assign non-negative weights to subterms, making strict decrease impossible under the current rule formulation. A valid measure would need to:  
- Assign negative weight to `s` (impossible in `ℕ`),  
- Or use a lexicographic/multiset order,  
- Or modify the rule/measures to break the `μs` duplication.  

As defined, **no candidate succeeds**.
