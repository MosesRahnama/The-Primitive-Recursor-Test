All three proposed measures are intended to be “descending‐size” functions
μ : Trace → ℕ that strictly drop along every rewrite step

    lhs –– Step ––> rhs  implies  μ lhs > μ rhs .

The critical rule is the successor clause of the iterator:

    R_rec_succ :  recDelta b s (delta n)   →   app s (recDelta b s n)

On that single rule every candidate breaks down.

--------------------------------------------------------------
1.  μ₁

lhs : μ₁ (recDelta b s (delta n))
     = 1 + μ₁ b + μ₁ s + μ₁ (delta n)
     = 2 + μ₁ b + μ₁ s + μ₁ n

rhs : μ₁ (app s (recDelta b s n))
     = 1 + μ₁ s + μ₁ (recDelta b s n)
     = 1 + μ₁ s + (1 + μ₁ b + μ₁ s + μ₁ n)
     = 2 + μ₁ b + 2 μ₁ s + μ₁ n

Difference lhs – rhs = − μ₁ s

•  If s ≠ void the quantity is negative (the measure rises).
•  If s  = void it is 0 (no strict decrease).

Example counter-step  
b := void, s := delta void, n := void  

lhs = 2 + 0 + 1 + 0 = 3  
rhs = 1 + 1 + 2 = 4  ⇒ μ₁ increases.

Therefore μ₁ is NOT a termination measure.

--------------------------------------------------------------
2.  μ₂

lhs : μ₂ = 6 + μ₂ b + μ₂ s + μ₂ n
rhs : μ₂ = 6 + μ₂ b + 2 μ₂ s + μ₂ n
lhs – rhs = − μ₂ s  (same phenomenon)

Same counterexample gives lhs = 7, rhs = 8.  
μ₂ also fails.

--------------------------------------------------------------
3.  μ₃

Because .app is given a heavier constant (2) while .recDelta keeps a light
constant (1), the inequality is even worse:

lhs : μ₃ = 2 + μ₃ b + μ₃ s + μ₃ n
rhs : μ₃ = 3 + μ₃ b + 2 μ₃ s + μ₃ n
lhs – rhs = −1 − μ₃ s ≤ −1

Even with s = void the measure rises by one, so μ₃ never decreases on this
rule.  Example with the same data as above:

lhs = 2 + 0 + 1 + 0 = 3  
rhs = 3 + 0 + 2 + 0 = 5.

Thus μ₃ also fails.

--------------------------------------------------------------
Conclusion

• μ₁ : Fails on rule R_rec_succ (sometimes equal, usually increases).

• μ₂ : Same failure, always rises when s ≠ void.

• μ₃ : Always rises by at least one on R_rec_succ.

None of the three candidates is a valid termination measure for the given
rewrite system; the weights assigned to recDelta and/or app must be changed
(or an additional lexicographic component introduced) to compensate for the
duplication of s in the right-hand side of R_rec_succ.
