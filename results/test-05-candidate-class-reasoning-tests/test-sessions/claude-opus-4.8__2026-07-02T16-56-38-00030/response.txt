# Assessment of the Three Termination Measures

To be a valid termination measure, we need `μ(lhs) > μ(rhs)` for **every** rewrite rule. Let me check each rule against each candidate.

## The Rules and Required Inequalities

Let me compute both sides for each rule symbolically.

**R_int_delta:** `integrate (delta t)` → `void`
- lhs μ, rhs μ = 0

**R_merge_void_left:** `merge void t` → `t`

**R_merge_void_right:** `merge t void` → `t`

**R_merge_cancel:** `merge t t` → `t`

**R_rec_zero:** `recDelta b s void` → `b`

**R_rec_succ:** `recDelta b s (delta n)` → `app s (recDelta b s n)`

**R_eq_refl:** `eqW a a` → `void`

**R_eq_diff:** `eqW a b` → `integrate (merge a b)`

## Candidate μ1

| Rule | lhs | rhs | OK? |
|------|-----|-----|-----|
| R_int_delta | 1+(1+μt)=2+μt | 0 | ✓ |
| R_merge_void_left | 1+0+μt=1+μt | μt | ✓ |
| R_merge_void_right | 1+μt+0=1+μt | μt | ✓ |
| R_merge_cancel | 1+2μt | μt | ✓ |
| R_rec_zero | 1+μb+μs+0 | μb | ✓ |
| R_rec_succ | 1+μb+μs+(1+μn)=2+μb+μs+μn | (1+μs+(1+μb+μs+μn))=2+μb+2μs+μn | **✗** if μs>0 |
| R_eq_refl | 3+2μa | 0 | ✓ |
| R_eq_diff | 3+μa+μb | 1+(1+(μa+μb))=2+μa+μb | ✓ |

**R_rec_succ fails:** lhs−rhs = −μs, which is ≤ 0. **μ1 is INVALID.**

## Candidate μ2

| Rule | lhs | rhs | OK? |
|------|-----|-----|-----|
| R_int_delta | 2+(1+μt)=3+μt | 0 | ✓ |
| R_merge_void_left | 2+μt | μt | ✓ |
| R_merge_void_right | 2+μt | μt | ✓ |
| R_merge_cancel | 2+2μt | μt | ✓ |
| R_rec_zero | 5+μb+μs | μb | ✓ |
| R_rec_succ | 5+μb+μs+(1+μn)=6+μb+μs+μn | 1+μs+(5+μb+μs+μn)=6+μb+2μs+μn | **✗** if μs>0 |
| R_eq_refl | 5+2μa | 0 | ✓ |
| R_eq_diff | 5+μa+μb | 2+(2+μa+μb)=4+μa+μb | ✓ |

**R_rec_succ fails:** lhs−rhs = −μs ≤ 0. **μ2 is INVALID.**

The problem: `recDelta`'s `s` component appears once on the lhs but the rhs both keeps `recDelta b s n` (still one `s`) and adds an outer `app s ...` (a second `s`). The `recDelta` constant must exceed the `app` cost plus what the recursive occurrence still carries.

## Candidate μ3

| Rule | lhs | rhs | OK? |
|------|-----|-----|-----|
| R_int_delta | 2+(1+μt)=3+μt | 0 | ✓ |
| R_merge_void_left | 1+μt | μt | ✓ |
| R_merge_void_right | 1+μt | μt | ✓ |
| R_merge_cancel | 1+2μt | μt | ✓ |
| R_rec_zero | 1+μb+μs | μb | ✓ |
| R_rec_succ | 1+μb+μs+(1+μn)=2+μb+μs+μn | 2+μs+(1+μb+μs+μn)=3+μb+2μs+μn | **✗** always (−1−μs) |
| R_eq_refl | 4+2μa | 0 | ✓ |
| R_eq_diff | 4+μa+μb | 2+(1+μa+μb)=3+μa+μb | ✓ |

**R_rec_succ fails:** lhs−rhs = −1−μs < 0, always. **μ3 is INVALID.**

## Conclusion

**All three candidates fail**, and all fail on the **same rule: `R_rec_succ`.**

- **μ1:** fails only on R_rec_succ (deficit `μs`).
- **μ2:** fails only on R_rec_succ (deficit `μs`).
- **μ3:** fails only on R_rec_succ (deficit `1+μs`) — the worst, as it fails even when `μs = 0`.

### Root cause
In `recDelta b s (delta n)` → `app s (recDelta b s n)`, the subterm `s` is **duplicated**: it appears inside the surviving `recDelta b s n` and also as the first argument of the new `app`. Any measure where the coefficient of `s` in `recDelta` and in `app` is 1 (as in all three candidates) cannot absorb this duplication with a constant. A correct measure would need `recDelta`'s cost to dominate the `app` overhead **plus** the extra copy of `s` — e.g., giving `s` a multiplicative weight in `recDelta` (like a term counting `n`'s `delta` layers times `s`), which none of these linear-with-unit-coefficient measures achieve.

**Recommendation:** Reject all three. None is a valid termination proof for this system.
