To assess the three candidate termination measures (`mu1`, `mu2`, and `mu3`), we must evaluate whether they prove strict termination for the calculus. A valid termination measure over natural numbers must strictly decrease across every reduction rule—meaning that for every rule `LHS -> RHS`, it must be universally true that `mu(LHS) > mu(RHS)`.

Here is the assessment of the three candidates:

### Executive Summary
**All three candidates fail to prove termination.** 
While all three measures successfully prove strict decrease for 7 out of the 8 rules (such as `R_eq_diff` and `R_merge_cancel`), they **all fail** on the recursive rule `R_rec_succ`. 

Because `mu1`, `mu2`, and `mu3` are strictly linear combinations of their subterms, none of them can mathematically account for the structural duplication of the arbitrary variable `s` in the rule:
`Step (recDelta b s (delta n)) (app s (recDelta b s n))`

### 1. Assessment of `mu1`
* **Successes**: `mu1` works perfectly for the non-duplicating rules. For instance, in `R_eq_diff` (`eqW a b -> integrate (merge a b)`):
  * LHS: `3 + mu1 a + mu1 b`
  * RHS: `1 + (1 + mu1 a + mu1 b) = 2 + mu1 a + mu1 b`
  * `3 > 2`, so it strictly decreases.
* **Failure on `R_rec_succ`**:
  * LHS: `mu1 (recDelta b s (delta n)) = 1 + b + s + (1 + n) = 2 + b + s + n`
  * RHS: `mu1 (app s (recDelta b s n)) = 1 + s + (1 + b + s + n) = 2 + b + 2s + n`
  * For termination, we need `2 + b + s + n > 2 + b + 2s + n`, which simplifies to `0 > s`. Since `mu1 s` can be arbitrarily large (e.g., `mu1 (delta void) = 1`), this is false. Even if `s = void` (where `mu1 s = 0`), the inequality evaluates to `2 > 2`, which is not strictly decreasing.

### 2. Assessment of `mu2`
* **Successes**: `mu2` also works for the rest of the calculus. For `R_eq_diff`:
  * LHS: `5 + mu2 a + mu2 b`
  * RHS: `2 + (2 + mu2 a + mu2 b) = 4 + mu2 a + mu2 b`
  * `5 > 4`, strictly decreasing.
* **Failure on `R_rec_succ`**:
  * LHS: `mu2 (recDelta b s (delta n)) = 5 + b + s + (1 + n) = 6 + b + s + n`
  * RHS: `mu2 (app s (recDelta b s n)) = 1 + s + (5 + b + s + n) = 6 + b + 2s + n`
  * Like `mu1`, the requirement simplifies to `0 > s`. Thus, it fails to prove strict decrease for exactly the same reason.

### 3. Assessment of `mu3`
* **Successes**: Works for non-duplicating rules. For `R_eq_diff`: 
  * LHS: `4 + mu3 a + mu3 b`
  * RHS: `2 + (1 + mu3 a + mu3 b) = 3 + mu3 a + mu3 b`
  * `4 > 3`, strictly decreasing.
* **Failure on `R_rec_succ`**: `mu3` fails even more obviously than the previous two.
  * LHS: `mu3 (recDelta b s (delta n)) = 1 + b + s + (1 + n) = 2 + b + s + n`
  * RHS: `mu3 (app s (recDelta b s n)) = 2 + s + (1 + b + s + n) = 3 + b + 2s + n`
  * The requirement simplifies to `0 > 1 + s`. Because natural numbers are `>= 0`, the RHS is actually **strictly greater** than the LHS in all contexts, meaning `mu3` implies the system is actively growing.

### Conclusion
A linear measure to `Nat` (using only `+` constants) cannot solve this specific termination problem. Because `R_rec_succ` introduces a second copy of an arbitrary term `s` into the trace, measuring it requires a non-linear bounding strategy. A successful termination measure would need structural multiplication (e.g. `mu(recDelta b s n) = C + b + (s * n)`) to pay for the duplication of `s` relative to the reduction of `n`.
