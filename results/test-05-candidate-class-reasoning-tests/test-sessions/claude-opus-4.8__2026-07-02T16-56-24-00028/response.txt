# Assessment of the Three Termination Measures

I need to check, for each measure μ, whether **every** rewrite rule strictly decreases the measure (μ(lhs) > μ(rhs)). A single failing rule disqualifies the measure as a termination proof.

Let me go through all 8 rules for each candidate.

## The rules and their measure changes

Let me compute lhs and rhs for each rule symbolically.

**R_eq_diff** is the dangerous one: `eqW a b → integrate (merge a b)`.
- lhs: `eqW a b` = C_eqW + μ(a) + μ(b)
- rhs: `integrate (merge a b)` = C_int + C_merge + μ(a) + μ(b)
- Need: C_eqW > C_int + C_merge

**R_rec_succ**: `recDelta b s (delta n) → app s (recDelta b s n)`
- lhs: C_rec + μ(b) + μ(s) + (C_delta + μ(n))
- rhs: C_app + μ(s) + (C_rec + μ(b) + μ(s) + μ(n)) — note **μ(s) appears twice** on rhs, once on lhs.
- Difference (lhs − rhs) = C_delta − C_app − μ(s). This depends on μ(s), which is unbounded!
- So we need C_delta − C_app − μ(s) > 0 for all s. **Impossible unless...** wait, μ(s) ≥ 0 and can be arbitrarily large. This rule **duplicates `s`**, so any measure of this linear additive form will fail once μ(s) is large enough.

Let me verify this critical observation. rhs contains `app s (recDelta b s n)`, and both occurrences of `s` are counted. So rhs − lhs contribution from s-copies: +μ(s). The structural constants: rhs has C_app + C_rec, lhs has C_rec + C_delta. So:

lhs − rhs = C_delta − C_app − μ(s).

Since μ(s) grows without bound, **no** additive measure of this style can make R_rec_succ decreasing for all s.

## Checking each candidate on R_rec_succ

- **μ1**: C_delta=1, C_app=1 ⇒ lhs−rhs = 1−1−μ1(s) = −μ1(s) ≤ 0. **Fails** (not strict; ≤ 0, e.g. s=void gives 0).
- **μ2**: C_delta=1, C_app=1 ⇒ 1−1−μ2(s) = −μ2(s) ≤ 0. **Fails**.
- **μ3**: C_delta=1, C_app=2 ⇒ 1−2−μ3(s) = −1−μ3(s) < 0. **Fails**.

**All three fail R_rec_succ**, because the rule duplicates the subterm `s`.

## Checking R_eq_diff for completeness

- **μ1**: C_eqW=3, C_int+C_merge = 1+1 = 2. 3 > 2 ✓
- **μ2**: C_eqW=5, C_int+C_merge = 2+2 = 4. 5 > 4 ✓
- **μ3**: C_eqW=4, C_int+C_merge = 2+1 = 3. 4 > 3 ✓

All handle R_eq_diff.

## Quick check of the other rules (all fine for any positive constants)

- R_int_delta: `integrate(delta t) → void`: drops C_int+C_delta+μ(t) → 0. ✓ all.
- R_merge_void_left/right: `merge void t → t`: drops C_merge (+0). ✓ all (constants ≥1).
- R_merge_cancel: `merge t t → t`: lhs C_merge+2μ(t), rhs μ(t); drops C_merge+μ(t). ✓ all.
- R_rec_zero: `recDelta b s void → b`: drops C_rec+μ(s). ✓ all.
- R_eq_refl: `eqW a a → void`: drops everything. ✓ all.

## Conclusion

| Rule | μ1 | μ2 | μ3 |
|------|----|----|----|
| R_int_delta | ✓ | ✓ | ✓ |
| R_merge_void_left | ✓ | ✓ | ✓ |
| R_merge_void_right | ✓ | ✓ | ✓ |
| R_merge_cancel | ✓ | ✓ | ✓ |
| R_rec_zero | ✓ | ✓ | ✓ |
| **R_rec_succ** | **✗** | **✗** | **✗** |
| R_eq_refl | ✓ | ✓ | ✓ |
| R_eq_diff | ✓ | ✓ | ✓ |

**None of the three candidates is a valid termination measure.** All three fail on **R_rec_succ**, and the failure is structural, not a matter of tuning constants: the rewrite `recDelta b s (delta n) → app s (recDelta b s n)` **duplicates the subterm `s`**. Any additive size measure of this form has

  μ(lhs) − μ(rhs) = C_delta − C_app − μ(s),

which becomes negative for large `s` regardless of the constants chosen. Fixing this requires either a non-additive measure (e.g., one that does not count `s` linearly, or a lexicographic/multiset ordering keyed on the third argument of `recDelta` independent of `s`) — and in fact one should first confirm the system even terminates given this duplication.

Among the three, μ3 comes closest in spirit (it at least makes `app` cost more than `delta`, handling the constant part), but it still fails because of the additive `μ3(s)` term. So the honest verdict: **all three are rejected.**
