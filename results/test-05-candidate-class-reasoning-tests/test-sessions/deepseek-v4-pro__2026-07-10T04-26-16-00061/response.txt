All three candidate measures **fail** to be valid termination measures because none of them decreases on the rule `R_rec_succ`.

The problematic reduction is
```
R_rec_succ : ∀ b s n, Step (recDelta b s (delta n)) (app s (recDelta b s n))
```
In each `muᵢ`, the measures are defined by linear sums of the measures of their subterms plus a constant. Writing `μ` for any of `mu1`, `mu2`, `mu3`, we have:
- `μ(recDelta b s n) = C + μ(b) + μ(s) + μ(n)`
- `μ(app s t) = D + μ(s) + μ(t)`  (with `D=1` for `mu1`, `D=1` for `mu2`, `D=2` for `mu3`)

Plugging into the rule:
```
μ(recDelta b s (delta n)) = C + μ(b) + μ(s) + (1 + μ(n)) = C+1 + μ(b) + μ(s) + μ(n)
μ(app s (recDelta b s n)) = D + μ(s) + (C + μ(b) + μ(s) + μ(n)) = C+D + μ(b) + 2·μ(s) + μ(n)
```
The required inequality for a strict termination measure is `μ(left) > μ(right)`, i.e.
```
C+1 + μ(b) + μ(s) + μ(n) > C+D + μ(b) + 2·μ(s) + μ(n)
⇒ 1 > D + μ(s)
```
Since `D ≥ 1` for all three measures (`D=1` for `mu1`,`mu2`; `D=2` for `mu3`) and `μ(s) ≥ 0`, this can never hold (it would require `μ(s) < 1-D ≤ 0`, i.e. `μ(s) < 0` which is impossible). The measure therefore does not decrease; it stays the same or increases.

All other rules are satisfied by the three measures, but the failure of `R_rec_succ` makes each of `mu1`, `mu2`, `mu3` **unsuitable** as a termination measure for the given rewrite system.
