Here’s the quick audit of the three measures as **strictly decreasing termination measures** for every `Step` rule.

A valid measure `μ` must satisfy: for every rule `Step l r`, we have `μ l > μ r`.

---

### `mu1` ❌ not valid

Most rules decrease, but `R_eq_diff` fails:

- LHS: `eqW a b`  
  `mu1 = 3 + mu1 a + mu1 b`
- RHS: `integrate (merge a b)`  
  `mu1 = 1 + (1 + mu1 a + mu1 b) = 2 + mu1 a + mu1 b`

So this one actually decreases by 1 — that part is fine.

The real failure is `R_rec_succ`:

- LHS: `recDelta b s (delta n)`  
  `mu1 = 1 + mu1 b + mu1 s + (1 + mu1 n) = 2 + mu1 b + mu1 s + mu1 n`
- RHS: `app s (recDelta b s n)`  
  `mu1 = 1 + mu1 s + (1 + mu1 b + mu1 s + mu1 n) = 2 + mu1 b + 2*mu1 s + mu1 n`

Need `LHS > RHS`, i.e.  
`2 + b + s + n > 2 + b + 2s + n`, impossible unless negative numbers.  
So `mu1` is **not** a ranking function.

---

### `mu2` ❌ not valid

Again `R_rec_succ` fails:

- LHS: `recDelta b s (delta n)`  
  `mu2 = 5 + b + s + (1 + n) = 6 + b + s + n`
- RHS: `app s (recDelta b s n)`  
  `mu2 = 1 + s + (5 + b + s + n) = 6 + b + 2s + n`

Need `6 + b + s + n > 6 + b + 2s + n`, false in general.

So `mu2` is also **not** valid.

(Other problematic spot check: `R_eq_diff` gives equality, not strict decrease:
`eqW` has 5+…, RHS `integrate(merge…)` is `2 + (2 + …) = 4 + …`, so that one is okay actually; strict decrease by 1. Main blocker remains `rec_succ`.)

---

### `mu3` ❌ not valid

Two failures:

1. `R_rec_succ`:
   - LHS: `1 + b + s + (1+n) = 2 + b + s + n`
   - RHS: `2 + s + (1 + b + s + n) = 3 + b + 2s + n`
   RHS is larger, so not decreasing.

2. `R_eq_diff`:
   - LHS: `4 + a + b`
   - RHS: `integrate (merge a b)` = `2 + (1 + a + b) = 3 + a + b`
   This one decreases, so fine.

But since `rec_succ` fails, `mu3` is **not** valid.

---

## Final verdict

- `mu1`: **invalid**
- `mu2`: **invalid**
- `mu3`: **invalid**

All three are rejected due to the `R_rec_succ` rule, where the recursive-call term is placed under `app s (...)`, causing duplication/extra weight of `s` that these additive measures can’t absorb.
