**Why it terminates from the rules alone**

The signature exhibits a clean structural recursion that any of the standard methods (polynomial/(matrix) interpretation, recursive path order, or dependency-pair framework) can certify:

- `plus(x, s(y)) → s(plus(x, y))` — the `s` layer on the second argument is peeled off in each recursive call.
- `times(s(x), y) → plus(times(x, y), y)` — the `s` layer on the first argument is peeled off in each recursive call; the `plus` redex then resolves to a smaller sum.
- `p(s(s(x))) → s(p(s(x)))`, `p(s(0)) → 0` — these strictly reduce the number of leading `s`'s in the argument (a well-founded measure that is definable syntactically, e.g., via a polynomial/lexicographic interpretation that maps `s(x) ↦ x+1`, `p(x) ↦ 2x`).
- `fac(s(x)) → times(fac(p(s(x))), s(x))` — the recursive call to `fac` is on `p(s(x))`, which the `p` rules reduce (one rule-application at a time) from `s(x)` to `x`, i.e., a strictly smaller argument. Combined with the decrease in `times`, this gives a quasi-decreasing/lexicographic ordering that is provable purely by induction on the rewrite structure.

For example, a polynomial interpretation over ℕ with
`0↦0, s(x)↦x+1, p(x)↦2x, plus(x,y)↦2x+2y+1, times(x,y)↦4xy+2x+2y+2` (and a bounded `fac` interpretation)
yields `[l] > [r]` for every rule after checking the finitely many algebraic inequalities on arguments — a syntactic/meta-theoretic check, not an object-level commitment.

There are no variable-binding constructs, no rules whose right-hand side introduces fresh structure not present on the left, no "duplicating" rules (every `x`/`y` on the right is a subterm of the left, except in `times(s(x),y) → plus(times(x,y),y)` where the size growth is bounded and offset by the `s`-decrease on the first argument), and no "self-embedding" rules. So the rewrite system is *syntactically* terminating, and a proof can be given that depends only on the rules shown.
