The user asks about a first-order term rewriting system and whether termination can be established from the presented rules alone.
Yes, termination can be established from the given rules alone. The system is terminating because every rewrite step strictly decreases a suitable measure on terms (the sum of the sizes of the arguments to the top-level function symbol, with a small adjustment for the successor constructor).

Define the size of a term recursively:  
- size( 0 ) = 1  
- size( s(t) ) = size(t) + 1  
- size( plus(t,u) ) = size(t) + size(u) + 1  
- size( times(t,u) ) = size(t) + size(u) + 1  

This measure is 1 for every constant and increases by at least 1 for every constructor application.
