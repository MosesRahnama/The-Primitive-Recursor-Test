Yes, termination can be established from the given rules alone.

The argument uses a lexicographic path order (LPO) with a suitable status and precedence. Define the precedence ≻ by  
plus ≻ times ≻ p ≻ s ≻ 0.  
Assign to every variable the status “mult” ( 0 is a constant).  

We verify that every rule is strictly decreasing under this LPO.

- plus(x,0) → x  
  Root of left is plus, root of right is variable (no root). The variable x occurs as an argument of plus, so the left side is greater than its subterm 0 and than x.

- plus(x,s(y)) → s(plus(x,y))  
  Root plus ≻ s, so it suffices to show plus(x,s(y)) ≻ plus(x,y).
