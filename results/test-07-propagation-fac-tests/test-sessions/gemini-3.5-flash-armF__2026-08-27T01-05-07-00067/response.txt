### Termination Argument

We prove termination using the **Lexicographic Path Ordering (LPO)**, which is a well-founded simplification order. Any term rewriting system whose rules strictly decrease under LPO is guaranteed to terminate.

$$\text{times} \succ \text{plus} \succ s \succ 0$$

We assign a **left-to-right lexicographic status** to all function symbols.

* Because the root of the LHS is strictly greater than the RHS constant, and the RHS contains no variables not present in the LHS, we have:
  $$\text{times}(x, 0) \succ_{lpo} 0$$

  1. $\text{times}(x, s(y)) \succ_{lpo} \text{times}(x, y)$
