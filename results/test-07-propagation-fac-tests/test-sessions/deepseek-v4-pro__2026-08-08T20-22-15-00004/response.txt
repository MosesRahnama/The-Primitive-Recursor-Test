**Termination argument**

**1. Dependency pairs (DPs)**

```
plus(x,0)   → x                           (no defined symbol in rhs)
plus(x,s(y)) → s(plus(x,y))                DP: PLUS(x,s(y)) → PLUS(x,y)

times(0,y)  → 0
times(x,0)  → 0
times(s(x),y) → plus(times(x,y), y)        DPs: TIMES(s(x),y) → TIMES(x,y)

p(s(s(x)))  → s(p(s(x)))                   DP: P(s(s(x))) → P(s(x))
p(s(0))     → 0

fac(s(x))   → times(fac(p(s(x))), s(x))    DPs: FAC(s(x)) → FAC(p(s(x)))
                                             FAC(s(x)) → TIMES(fac(p(s(x))), s(x))
```

**2. Dependency graph and SCCs**
The dependency graph has edges:
- PLUS(x,s(y)) → PLUS(x,y)
- TIMES(s(x),y) → TIMES(x,y) and TIMES(s(x),y) → PLUS(...)
- P(s(s(x))) → P(s(x))
- FAC(s(x)) → FAC(p(s(x))) and FAC(s(x)) → TIMES(...)

Since TIMES depends on PLUS but not vice versa, and FAC depends on TIMES but not vice versa, the strongly connected components (SCCs) are {PLUS}, {TIMES}, {P}, and {FAC}. We can prove termination of each SCC independently with a reduction pair that makes its DP(s) strictly decreasing and all original rules weakly decreasing.

**3. Algebraic interpretation for the whole system**
Choose the carrier ℕ with the usual well-founded order >. Interpret the constructors and function symbols as weakly monotone functions over ℕ:

- \([0] = 0\)
- \([s](x) = x+1\)
- \([p](x) = \max(x-1, 0)\)
- \([plus](x,y) = x+y\)
- \([times](x,y) = x\cdot y\)
- \([fac](x) = x!\)  (factorial: \(0!=1\), \((n+1)!=(n+1)\,n!\))
- For the marked DP symbols we use simple projections:
  - \([PLUS^\#](x,y) = y\)
  - \([TIMES^\#](x,y) = x\)
  - \([P^\#](x) = x\)
  - \([FAC^\#](x) = x\)

All these functions are weakly monotone on ℕ.

**4. Checking the DPs (strict decrease)**

We need a reduction pair that makes this weakly decreasing when proving {TIMES}. Giving \([PLUS^\#]\) a suitable interpretation, e.g., constant 0, and keeping \([TIMES^\#](x,y)=x\) works. **5. Checking the original rules (weak decrease ≧)**
- `plus(x,0) → x`  
  \(x+0 = x\) (equality).
- `plus(x,s(y)) → s(plus(x,y))`  
  \(x+(y+1) = (x+y)+1\) (equality).

- `p(s(s(x))) → s(p(s(x)))`

Every original rule evaluates to an equality, hence ≧ holds trivially.

**6. Conclusion**
By the dependency pair theorem, the strict decrease of the DPs together with the weak decrease of all original rules in a monotone ℕ-interpretation imply termination of the whole TRS. Each rule is addressed, no extra axioms are assumed, and the proof stays entirely within the given syntactic rules and standard metatheoretic constructions.
