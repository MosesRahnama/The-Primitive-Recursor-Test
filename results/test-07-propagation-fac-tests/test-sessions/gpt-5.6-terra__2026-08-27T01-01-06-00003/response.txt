**Verdict: yes.** Termination can be established from the displayed rules alone. No associativity, commutativity, arithmetic semantics, constructor freeness beyond ordinary first-order syntax, or extra rewrite rules are needed.

A standard dependency-pair argument with a natural-number interpretation suffices.

## Dependency pairs

Mark defined symbols by `#`. The dependency pairs are:

```text
plus#(x, s(y)) -> plus#(x, y)

times#(s(x), y) -> times#(x, y)
times#(s(x), y) -> plus#(times(x, y), y)

p#(s(s(x))) -> p#(s(x))

fac#(s(x)) -> times#(fac(p(s(x))), s(x))
fac#(s(x)) -> fac#(p(s(x)))
```

The remaining rules must be weakly decreasing under the interpretation below.

## Interpretation of unmarked symbols

Interpret terms over the natural numbers:

```text
[0]       = 0
[s(t)]    = [t] + 1
[p(t)]    = max([t] - 1, 0)

[plus(t,u)]  = [t] + 2[u] + 1
[times(t,u)] = 2([t] + 1)([u] + 1)
[fac(t)]     = F([t])
```

where \(F\) is the strictly increasing function defined by:

```text
F(0)     = 0
F(n + 1) = 2(F(n) + 1)(n + 2) + 1.
```

All these interpretations are monotone.

### Orientation of the original rewrite rules

For `plus`:

```text
plus(x, 0) -> x
```

has value

```text
[x] + 1 > [x].
```

And

```text
plus(x, s(y)) -> s(plus(x, y))
```

has left side

```text
[x] + 2[y] + 3
```

and right side

```text
[x] + 2[y] + 2.
```

So it strictly decreases.

For `times`:

```text
times(0, y) -> 0
times(x, 0) -> 0
```

strictly decrease because their left sides are respectively \(2([y]+1)\) and \(2([x]+1)\), both positive.

For

```text
times(s(x), y) -> plus(times(x, y), y)
```

the left side is

```text
2([x] + 2)([y] + 1),
```

whereas the right side is

```text
2([x] + 1)([y] + 1) + 2[y] + 1.
```

The difference is exactly \(1\), hence the rule strictly decreases.

For the `p` rules:

```text
p(s(s(x))) -> s(p(s(x)))
p(s(0)) -> 0
```

both are weakly decreasing:

```text
max(([x]+2)-1,0) = [x]+1
```

and

```text
[s(p(s(x)))] = max(([x]+1)-1,0)+1 = [x]+1,
```

so the first is an equality. The second is also an equality:

```text
[p(s(0))] = max(1-1,0) = 0.
```

Weak decrease is sufficient for ordinary rules in the dependency-pair criterion.

Finally, for

```text
fac(s(x)) -> times(fac(p(s(x))), s(x)),
```

the left side is

```text
F([x]+1)
 = 2(F([x])+1)([x]+2)+1,
```

while the right side is

```text
2(F([x])+1)([x]+2).
```

Thus this rule strictly decreases.

Therefore every original rule is weakly decreasing, and all except the two `p` rules are strictly decreasing, under the unmarked interpretation.

## Interpretation of marked symbols

Use:

```text
[plus#(t,u)]  = [u]
[times#(t,u)] = [t] + 2[u]
[p#(t)]       = [t]
[fac#(t)]     = F([t]) + 2[t].
```

These are monotone. Every dependency pair is now strictly decreasing.

### `plus`

```text
plus#(x, s(y)) -> plus#(x, y)
```

becomes:

```text
[y] + 1 > [y].
```

### `times`

```text
times#(s(x), y) -> times#(x, y)
```

becomes:

```text
[x] + 1 + 2[y] > [x] + 2[y].
```

And

```text
times#(s(x), y) -> plus#(times(x, y), y)
```

becomes:

```text
[x] + 1 + 2[y] > [y].
```

### `p`

```text
p#(s(s(x))) -> p#(s(x))
```

becomes:

```text
[x] + 2 > [x] + 1.
```

### `fac`

For the recursive `fac` dependency pair:

```text
fac#(s(x)) -> fac#(p(s(x)))
```

the left value is

```text
F([x]+1) + 2([x]+1),
```

and the right value is

```text
F([x]) + 2[x].
```

This is strict because \(F\) is strictly increasing.

For the call through `times`:

```text
fac#(s(x)) -> times#(fac(p(s(x))), s(x)),
```

the right side is

```text
F([x]) + 2([x]+1).
```

The left side is

```text
F([x]+1) + 2([x]+1),
```

which is strictly larger because \(F([x]+1) > F([x])\).

## Conclusion

All rewrite rules are weakly decreasing under a monotone natural-number interpretation, and every dependency pair is strictly decreasing under the same reduction-pair framework. Since strict descent on natural numbers is well-founded, there can be no infinite dependency-pair chain. By the standard dependency-pair termination criterion, the presented TRS terminates.

Thus, **termination is provable from the given syntax and rewrite rules alone.**
