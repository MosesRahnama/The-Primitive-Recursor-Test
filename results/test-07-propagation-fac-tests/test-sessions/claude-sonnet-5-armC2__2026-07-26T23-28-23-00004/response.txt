This system is a fairly standard combination of natural-number arithmetic operations (`plus`, `times`, `p` for predecessor, `fac` for factorial), and it can be shown terminating by standard, purely syntactic/semantic termination techniques that only use the rules themselves — no external axioms about the intended semantics of numbers are needed.

**Reasoning:**

1. **No mutual recursion / cyclic dependency:** Each function's rules only call previously "simpler" or auxiliary functions:
   - `plus` reduces via structural recursion on its second argument.
   - `times(s(x), y) -> plus(times(x,y), y)` recurses on the first argument of `times`, calling `plus`.
   - `p(s(s(x))) -> s(p(s(x)))` decreases the argument depth of `p`.
   - `fac(s(x)) -> times(fac(p(s(x))), s(x))` calls `p` (which strictly decreases: `p(s(x))` will eventually reduce to a term smaller than `s(x)`), and recursion on `fac` occurs only on this smaller term.

2. **A polynomial/argument-size interpretation works:** Assign to each symbol a weight function, e.g. interpret `0 ↦ 0`, `s(x) ↦ x+1`, and interpret defined symbols compatibly:
   - `[plus](x,y) = x+y`
   - `[times](x,y) = x*y` (or a polynomial majorizing multiplication)
   - `[p](x) = x-1` (natural subtraction, i.e. bounded below by 0)
   - `[fac](x)` interpreted by a rapidly growing polynomial/exponential bound.

   Checking each rule, the left-hand side's interpretation is strictly greater than the right-hand side's under a suitable well-founded polynomial (or PORPO/LPO-based) ordering. In particular:
   - `plus(x,0) -> x`: trivially decreasing.
   - `plus(x,s(y)) -> s(plus(x,y))`: recursive argument `y` strictly smaller than `s(y)`.
   - `times` rules: recursive call on `x` (smaller than `s(x)`), with `y` unchanged — standard for such recursive multiplication definitions.
   - `p(s(s(x))) -> s(p(s(x)))`: recursive argument `s(x)` is strictly smaller than `s(s(x))`.
   - `p(s(0)) -> 0`: base case, trivially decreasing.
   - `fac(s(x)) -> times(fac(p(s(x))), s(x))`: Since `p(s(x))` rewrites (via the `p`-rules, which terminate independently and reduce term size) to a term no larger than `x`, the recursive call to `fac` is on a strictly smaller argument than `s(x)`.

   This kind of layered/recursive structure is exactly what recursive path orderings (RPO/LPO) with an appropriate precedence (`fac > times > p, s`; `times > plus > s`; `p > s`) are designed to handle, and the system can be verified terminating by LPO or a simple polynomial interpretation, both of which are derived purely from the syntactic shape of the rules — no external structural or semantic axioms about natural numbers are required.
