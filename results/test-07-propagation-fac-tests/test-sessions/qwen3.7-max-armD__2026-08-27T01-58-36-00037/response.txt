# Verdict: **Terminating**

## Termination Argument: Lexicographic Path Ordering (LPO)

Termination is established by orienting every rule strictly with the **Lexicographic Path Ordering** using the precedence:

$$\texttt{times} > \texttt{plus} > \texttt{p} > \texttt{s} > \texttt{0}$$

with lexicographic status (left-to-right) on all function symbols.

---

### Rule-by-rule verification

**Rule 1:** `plus(x, 0) -> x`
`x` is a direct subterm of the LHS. By the LPO subterm condition (condition 4), `plus(x, 0) > x`. ✓

**Rule 2:** `plus(x, s(y)) -> s(plus(x, y))`
Root `plus` > root `s`, so by LPO condition 2 we need `plus(x, s(y))` to dominate every argument of `s`, i.e., `plus(x, s(y)) > plus(x, y)`. Since the roots are equal (`plus`), we compare arguments lexicographically: `(x, s(y))` vs `(x, y)`. The first components are equal; the second requires `s(y) > y`, which holds by the subterm condition. ✓

**Rule 3:** `times(0, y) -> 0`
`0` is a direct subterm (first argument) of the LHS. By the subterm condition, `times(0, y) > 0`. ✓

**Rule 4:** `times(x, 0) -> 0`
`0` is a direct subterm (second argument) of the LHS. By the subterm condition, `times(x, 0) > 0`. ✓

**Rule 5:** `times(s(x), y) -> plus(times(x, y), y)`
Root `times` > root `plus`, so we need the LHS to dominate both arguments of `plus`:
- `times(s(x), y) > y`: `y` is a direct subterm. ✓
- `times(s(x), y) > times(x, y)`: same root `times`, compare arguments lexicographically: `(s(x), y)` vs `(x, y)`. First component requires `s(x) > x`, which holds by the subterm condition. ✓

**Rule 6:** `p(s(s(x))) -> s(p(s(x)))`
Root `p` > root `s`, so we need `p(s(s(x))) > p(s(x))` (the sole argument of `s` on the RHS). Same root `p`, so compare arguments: `s(s(x))` vs `s(x)`. Same root `s`, so compare arguments: `s(x)` vs `x`. This holds by the subterm condition (`x` is a subterm of `s(x)`). Unwinding back up, `s(s(x)) > s(x)` and therefore `p(s(s(x))) > p(s(x))`. ✓

**Rule 7:** `p(s(0)) -> 0`
By the subterm condition applied twice: `s(0) > 0` (since `0` is a subterm of `s(0)`), and then `p(s(0)) > 0` (since `s(0) > 0` implies `s(0) ≥ 0`, satisfying condition 4). ✓

---

### Why this suffices

LPO is a **well-founded reduction ordering**: it is closed under contexts and substitutions, and it is strictly well-founded (no infinite descending chains). Since every rewrite rule `l -> r` satisfies `l >_{lpo} r`, any rewrite sequence

$$t_0 \to t_1 \to t_2 \to \cdots$$

would produce a strictly descending chain

$$t_0 >_{lpo} t_1 >_{lpo} t_2 >_{lpo} \cdots$$

which must be finite. No additional axioms, side conditions, or structural assumptions were needed — only the syntax of the terms and the rules as given.
