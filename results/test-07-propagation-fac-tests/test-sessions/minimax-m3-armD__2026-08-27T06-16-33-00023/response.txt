## Verdict: **Yes**, termination can be established from the rules alone.

The system is a standard first-order definition of three primitive-recursive functions (addition, multiplication, predecessor) on the Peano-style naturals, and the rules never introduce a recursive cycle that escapes a primitive-recursive decrease.

## Termination Argument (Polynomial Interpretation)

I exhibit a well-founded monotone ℕ-algebra — i.e. an assignment of monotone, weakly positive polynomials to each function symbol — under which the left side of every rule strictly exceeds the right side. This is a standard, fully self-contained technique that uses no axioms beyond the rules' own syntax.

**Interpretation** (over ℕ with the usual order):

| Symbol   | Polynomial                          |
|----------|-------------------------------------|
| `0`      | `0`                                 |
| `s(x)`   | `x + 1`                             |
| `p(x)`   | `2x`                                |
| `plus(x,y)` | `x + 2y + 1`                      |
| `times(x,y)` | `2xy + 2x + 2y + 1`              |

Every polynomial is monotone in each argument and positive (≥ 1 for the binary symbols; ≥ 0 for `0` and `p`). So this is a valid weakly monotone, weakly positive ℕ-algebra.

**Verification of every rule** (let `⟦t⟧` denote the value of a closed instance `t`):

1. **`plus(x, 0) → x`** ⟹ `⟦plus(x,0)⟧ = ⟦x⟧ + 1  >  ⟦x⟧`. ✓
2. **`plus(x, s(y)) → s(plus(x, y))`** ⟹
   - LHS = `⟦x⟧ + 2(⟦y⟧+1) + 1 = ⟦x⟧ + 2⟦y⟧ + 3`
   - RHS = `(⟦x⟧ + 2⟦y⟧ + 1) + 1 = ⟦x⟧ + 2⟦y⟧ + 2`
   - LHS − RHS = 1 > 0. ✓
3. **`times(0, y) → 0`** ⟹ `⟦times(0,y)⟧ = 0 + 0 + 2⟦y⟧ + 1 = 2⟦y⟧ + 1  >  0`. ✓
4. **`times(x, 0) → 0`** ⟹ `⟦times(x,0)⟧ = 0 + 2⟦x⟧ + 0 + 1 = 2⟦x⟧ + 1  >  0`. ✓
5. **`times(s(x), y) → plus(times(x, y), y)`** ⟹
   - LHS = `2(⟦x⟧+1)⟦y⟧ + 2(⟦x⟧+1) + 2⟦y⟧ + 1 = 2⟦x⟦y⟧ + 2⟦x⟧ + 4⟦y⟧ + 3`
   - RHS = `(2⟦x⟦y⟧ + 2⟦x⟧ + 2⟦y⟧ + 1) + 2⟦y⟧ + 1 = 2⟦x⟦y⟧ + 2⟦x⟧ + 4⟦y⟧ + 2`
   - LHS − RHS = 1 > 0. ✓
6. **`p(s(s(x))) → s(p(s(x)))`** ⟹
   - LHS = `2(⟦x⟧ + 2) = 2⟦x⟧ + 4`
   - RHS = `2(⟦x⟧ + 1) + 1 = 2⟦x⟧ + 3`
   - LHS − RHS = 1 > 0. ✓
7. **`p(s(0)) → 0`** ⟹ `⟦p(s(0))⟧ = 2(0 + 1) = 2  >  0`. ✓

Every rule strictly decreases the polynomial weight. By the standard theorem on polynomial interpretations (a reduction order on ground terms is induced by any well-founded monotone ℕ-algebra in which `l ⟦>⟧ r` holds for every rule `l → r`), the system is **terminating**.

## Why nothing extra is needed

- The interpretation only uses the carrier ℕ and its standard order, plus the syntactic recursion of the rules — no structural axioms about the constructors `0`/`s`, no induction principle, and no additional rewrite rules are invoked.
- Each of the three "components" (`plus`, `times`, `p`) is handled uniformly by the same interpretation, and the only inter-rule dependency (`times` produces `plus(...)`) is harmless because the `plus` weight is also strictly decreased by the `times` rule (rule 5).
- The peculiar-looking `p` rule `p(s(s(x))) → s(p(s(x)))` is the trickiest one: it preserves the semantic value but is captured by the multiplicative factor `2` in `⟦p⟧(x) = 2x`, which "taxes" the extra `s` constructor enough that stripping it from the left of the argument outweighs the `s` added on the right of the result.

**Conclusion:** Termination is provable directly from the seven rules via the polynomial interpretation above; no external or structural assumptions are required.
