The dependency pair method with polynomial interpretations over ℕ was chosen because the system contains a rule defining predecessor (`p(s(s(x))) -> s(p(s(x)))`) that is not structurally size‑decreasing, and a factorial rule (`fac(s(x)) -> times(fac(p(s(x))), s(x))`) where the recursive call hides behind that predecessor. Simple syntactic orders like the lexicographic path order (LPO) struggle with these rules because they rely on the pure term structure, whereas `p` needs to be interpreted semantically as the predecessor function to show its output is “smaller.” The polynomial interpretation approach is a standard, flexible technique that lets us assign arithmetic meanings (e.g., `p(x)` as `max(0, x-1)`) directly capturing the intended semantics, making it easy to orient the tricky rules and to separate the mutually recursive functions (`plus`, `times`, `p`, `fac`) into independent, decreasing dependency pairs. It provides a clean, self‑contained termination proof without strengthening the system or adding external assumptions.
