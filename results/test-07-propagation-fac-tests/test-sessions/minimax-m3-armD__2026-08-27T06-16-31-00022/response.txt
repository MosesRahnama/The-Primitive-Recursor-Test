# Termination Analysis

## Verdict: **Yes, the system terminates**, provable from the rewrite rules alone using a standard lexicographic-argument measure.

## Termination Argument

I exhibit an explicit well-founded measure on terms and verify that every rule strictly decreases it. No extra rules, guards, or object-level assumptions are needed.

### The Measure

For any term `t`, let `|t|` denote its symbol count (each constant and function application counts 1; variables count 0). Define a 4-tuple

$$\mu(t) = (\mu_{\times}(t),\ \mu_{+}(t),\ \mu_{p}(t),\ |t|)$$

where the first three components capture the "size of the recursive argument" of each defined function when that function sits at the root:

- $\mu_{\times}(t) = |a|$ if $t = \texttt{times}(a,b)$, else $0$
- $\mu_{+}(t)  = |b|$ if $t = \texttt{plus}(a,b)$,  else $0$
- $\mu_{p}(t)  = |a|$ if $t = \texttt{p}(a)$,       else $0$

Tuples are compared in the **lexicographic order** on $\mathbb{N}^4$, which is well-founded.

### Rule-by-Rule Verification

I write each rule as `LHS → RHS` and check $\mu(\text{LHS}) >_{\text{lex}} \mu(\text{RHS})$.

| # | Rule | $\mu(\text{LHS})$ | $\mu(\text{RHS})$ | Strict in component |
|---|------|-------------------|-------------------|---------------------|
| 1 | `plus(x,0) → x` | $(0,\,1,\,0,\,|x|+2)$ | $(0,\,0,\,0,\,|x|)$ | 2nd (1>0) |
| 2 | `plus(x,s(y)) → s(plus(x,y))` | $(0,\,|y|+1,\,0,\,|x|+|y|+2)$ | $(0,\,0,\,0,\,|x|+|y|+2)$ | 2nd ($|y|+1>0$) |
| 3 | `times(0,y) → 0` | $(1,\,0,\,0,\,|y|+2)$ | $(0,\,0,\,0,\,1)$ | 1st (1>0) |
| 4 | `times(x,0) → 0` | $(|x|,\,0,\,0,\,|x|+2)$ | $(0,\,0,\,0,\,1)$ | 1st if $|x|>0$, else 4th ($|x|+2>1$) |
| 5 | `times(s(x),y) → plus(times(x,y),y)` | $(|x|+1,\,0,\,0,\,|x|+|y|+2)$ | $(0,\,|y|,\,0,\,|x|+2|y|+2)$ | 1st ($|x|+1>0$ always) |
| 6 | `p(s(s(x))) → s(p(s(x)))` | $(0,\,0,\,|x|+2,\,|x|+2)$ | $(0,\,0,\,0,\,|x|+3)$ | 3rd ($|x|+2>0$) |
| 7 | `p(s(0)) → 0` | $(0,\,0,\,2,\,2)$ | $(0,\,0,\,0,\,1)$ | 3rd (2>0) |

In every rule, $\mu(\text{LHS}) >_{\text{lex}} \mu(\text{RHS})$ for **every** ground instance, because the strict component depends only on $|x|$ or $|y|$, both non-negative, and the inequalities in the table are unconditional.

### Why Each Rule is Covered

- **Rules 1, 2, 5, 6, 7** each transfer control to a term whose root is *not* the recursive function on the LHS (or whose recursive argument has collapsed). The "primary" component ($\mu_+, \mu_\times$, or $\mu_p$) of the LHS is therefore positive while that of the RHS is zero — strict decrease.
- **Rules 3, 4** are the base cases; they move from a defined-function root to a constructor/term, and the size component finishes the strict inequality even when the first components tie at zero.
- The four "clusters" (`plus`, `times`, `p`, plus the constructor `s`/`0`) **do not mutually recurse**: the LHS of each rule for one defined function never contains another defined function as a root. The lex tuple is the standard way of encoding this independence.

### Conclusion

Since lex on $\mathbb{N}^4$ is well-founded and every rule strictly decreases $\mu$, the rewrite system is terminating. The proof is fully self-contained: it uses only the seven given rules and the well-foundedness of the standard order on natural numbers.
