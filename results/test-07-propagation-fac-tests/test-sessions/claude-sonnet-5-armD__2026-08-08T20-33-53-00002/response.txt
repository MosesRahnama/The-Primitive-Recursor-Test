## Method: Lexicographic Path Order (LPO)

Use the precedence
$$
\text{times} \;>\; \text{plus} \;>\; \text{p} \;>\; \text{s} \;>\; 0,
$$
with the standard (left‑to‑right lexicographic, or equivalently multiset) status on argument tuples, and the usual LPO comparison rules:

- $f(\vec s) >_{lpo} t$ if some $s_i \ge_{lpo} t$ (subterm case), or
- $f(\vec s) >_{lpo} g(\vec t)$ if $f>g$ in the precedence and $f(\vec s) >_{lpo} t_j$ for every $t_j$, or
- $f(\vec s) >_{lpo} f(\vec t)$ if $f=g$ and $\vec s$ is lexicographically/multiset‑greater than $\vec t$ (with each comparison recursively via $>_{lpo}$), together with the subterm property $f(\vec s) >_{lpo} s_i$ for each $s_i$.

LPO is a simplification order: it is well‑founded, monotonic (closed under contexts) and stable (closed under substitutions), so compatibility of every rule with $>_{lpo}$ suffices for termination.

### Rule‑by‑rule check

**1. `plus(x,0) -> x`**
$x$ is a proper subterm of $\text{plus}(x,0)$. By the subterm property, $\text{plus}(x,0) >_{lpo} x$. ✔ (holds regardless of precedence)

**2. `plus(x,s(y)) -> s(plus(x,y))`**
Heads: $\text{plus} > \text{s}$. Need $\text{plus}(x,s(y)) >_{lpo} \text{plus}(x,y)$ (the sole argument of the RHS's head).
Same head `plus`: compare argument tuples $(x,s(y))$ vs $(x,y)$: first components equal, second component $s(y) >_{lpo} y$ by the subterm property. Hence $\text{plus}(x,s(y)) >_{lpo}\text{plus}(x,y)$. ✔

**3. `times(0,y) -> 0`**
$0$ is a (sub)term occurring as the first argument of $\text{times}(0,y)$, so by the subterm property $\text{times}(0,y) >_{lpo} 0$. ✔

**4. `times(x,0) -> 0`**
Same argument: $0$ is the second argument, a strict subterm, so $\text{times}(x,0) >_{lpo} 0$. ✔

**5. `times(s(x),y) -> plus(times(x,y), y)`**
Heads: $\text{times} > \text{plus}$. Need $\text{times}(s(x),y) >_{lpo} \text{times}(x,y)$ and $\text{times}(s(x),y) >_{lpo} y$.

- Same head `times`: compare $(s(x),y)$ vs $(x,y)$: first component $s(x) >_{lpo} x$ (subterm property), rest equal ⇒ $\text{times}(s(x),y) >_{lpo}\text{times}(x,y)$.
- $y$ is a proper subterm of $\text{times}(s(x),y)$, so $\text{times}(s(x),y) >_{lpo} y$ by the subterm property.

Both required inequalities hold. ✔

**6. `p(s(s(x))) -> s(p(s(x)))`**
Heads: $\text{p} > \text{s}$. Need $\text{p}(s(s(x))) >_{lpo} \text{p}(s(x))$ (the single argument of the RHS's head).
Same head `p`: compare $s(s(x))$ vs $s(x)$: $s(s(x)) >_{lpo} s(x)$ by the subterm property. Hence $\text{p}(s(s(x))) >_{lpo}\text{p}(s(x))$. ✔

**7. `p(s(0)) -> 0`**
$0$ occurs as a subterm of $s(0)$, which itself is a subterm of $\text{p}(s(0))$; by transitivity of the strict subterm relation, $\text{p}(s(0)) >_{lpo} 0$. ✔
