**Verdict: yes.** Termination can be established from these rules alone. No arithmetic axioms about naturals, injectivity of `s`, or extra predecessor rules are needed. The argument is syntactic.

Let \(B\) be the subsystem consisting of all rules except the `fac` rule:

```text
plus(x, 0) -> x
plus(x, s(y)) -> s(plus(x, y))
times(0, y) -> 0
times(x, 0) -> 0
times(s(x), y) -> plus(times(x, y), y)
p(s(s(x))) -> s(p(s(x)))
p(s(0)) -> 0
```

## 1. The `plus`/`times`/`p` subsystem terminates

Use lexicographic LPO/RPO with, for example, precedence

```text
times > plus > p > s > 0
```

with lexicographic status for `plus`, `times`, and `p`.

Each rule strictly decreases:

- `plus(x, 0) -> x`  
  The right side is a proper subterm.

- `plus(x, s(y)) -> s(plus(x, y))`  
  `plus > s`, and
  ```text
  plus(x, s(y)) > plus(x, y)
  ```
  because the second argument decreases from `s(y)` to `y`.

- `times(0, y) -> 0` and `times(x, 0) -> 0`  
  The right side is smaller.

- `times(s(x), y) -> plus(times(x, y), y)`  
  Since `times > plus`, it suffices to compare the left side with both arguments of the right-hand `plus`:
  ```text
  times(s(x), y) > times(x, y)
  ```
  because `s(x) > x`, and
  ```text
  times(s(x), y) > y
  ```
  because `y` is a subterm of the left side.

- `p(s(s(x))) -> s(p(s(x)))`  
  Since `p > s`, it suffices that
  ```text
  p(s(s(x))) > p(s(x)),
  ```
  which follows from `s(s(x)) > s(x)`.

- `p(s(0)) -> 0`  
  Immediate.

Thus \(B\) terminates.

It is also confluent: the rules are left-linear, and the only overlap is

```text
times(0, 0)
```

between the two `times`-zero rules; both results are `0`. Therefore every term has a unique \(B\)-normal form.

## 2. What the `p` rules do syntactically

No external interpretation of `p` as arithmetic predecessor is needed. The following purely syntactic fact follows from the two `p` rules.

For a \(B\)-normal term \(u\), write it as

```text
u = s^k(v)
```

where \(v\) is not headed by `s`; \(k\) is the number of leading `s` symbols in \(u\).

Then:

```text
s(u)
```

has \(k+1\) leading `s` symbols, while the \(B\)-normal form of

```text
p(s(u))
```

has at most \(k\) leading `s` symbols.

Indeed:

- If \(u\) is not headed by `s`, then `p(s(u))` is either stuck at its root or, in the special case `u = 0`, reduces to `0`. In either event it has no leading `s`.
- If \(u = s(w)\), then
  ```text
  p(s(s(w))) -> s(p(s(w))).
  ```
  Repeating this strips one leading successor from the argument of the outer `p`. Eventually either `p(s(0)) -> 0` applies or a stuck term of the form `p(s(v))` remains, with one fewer exposed `s` than the original `s(u)`.

So, relative to the syntactic leading-`s` depth of a \(B\)-normal argument,

```text
s(u)  >  p(s(u)).
```

The strictness here means “one fewer leading `s` after \(B\)-normalization,” not any imported numerical fact.

## 3. The `fac` rule has a strictly descending recursive call

The remaining rule is:

```text
fac(s(x)) -> times(fac(p(s(x))), s(x))
```

Its only newly created `fac` call is:

```text
fac(p(s(x))).
```

Compared with the original call:

```text
fac(s(x)),
```

the argument of the recursive `fac` call has strictly fewer leading `s` symbols after normalization by the terminating subsystem \(B\), by the fact proved above.

All other work on the right-hand side is carried out by `times` and `plus`, which belong to the already terminating subsystem \(B\).

In particular:

- `fac(0)` has no rewrite rule and is therefore a normal form.
- If an argument eventually ceases to have the form `s(...)`, then no further `fac` rule applies at that position.
- The `p` rules can expose successors while reducing `p(s(x))`, but they cannot restore the lost successor count: their net effect is exactly the syntactic descent described above.
- `times` may copy its second argument through
  ```text
  times(s(x), y) -> plus(times(x, y), y),
  ```
  but this does not create a new recursive `fac` call with a larger `fac` argument. It only duplicates already existing finite subterms while the terminating \(B\)-computation proceeds.

Formally, one may use the standard termination-by-extension argument for a terminating confluent base TRS \(B\): extend it with a defined symbol `fac` whose recursive calls are on arguments strictly descending in a well-founded measure computed modulo \(B\). Here that measure is the number of leading `s` symbols in the \(B\)-normal form of the `fac` argument. The recursive call of the only `fac` rule decreases that measure strictly.

This argument covers arbitrary rewriting order, not merely an eager or innermost strategy: reductions in arguments belong either to the terminating base system \(B\), or to proper/nested `fac` calls subject to the same strictly descending call measure.

## 4. Rule-by-rule conclusion

All rules are covered:

```text
plus(x, 0) -> x                         terminating by RPO
plus(x, s(y)) -> s(plus(x, y))          terminating by RPO

times(0, y) -> 0                        terminating by RPO
times(x, 0) -> 0                        terminating by RPO
times(s(x), y) -> plus(times(x, y), y)  terminating by RPO

p(s(s(x))) -> s(p(s(x)))                terminating by RPO
p(s(0)) -> 0                            terminating by RPO

fac(s(x)) -> times(fac(p(s(x))), s(x))  recursive fac argument
                                         loses one leading s modulo B
```

Therefore the full rewrite system is terminating on all first-order terms generated by the displayed syntax.
