## 2. The two real problems with my first answer

### Problem 1: an unnecessary and unjustified derived fact

I wrote: *"the only step needed is that on the original rules $p(s(t)) \to^* t$."*

This is **unnecessary**. For DP (f) — $\mathrm{FAC}(s(x)) \to \mathrm{FAC}(p(s(x)))$ — the strict decrease I need is between the *first argument* of the FAC node, which on the LHS is $s(x)$ (s-depth $1+d(x)$) and on the RHS is $p(s(x))$ (s-depth $0$, because the head symbol of $p(s(x))$ is $p$, not $s$). So

$$1 + d(x) \;\ge\; 1 \;>\; 0,$$

with no need to invoke anything about $p$. The "p-stripping" claim I made was a leftover from an earlier draft where I was using a different (and worse) measure. **Drop it.** This was a presentation error, not a logic error.

### Problem 2: the simple "s-depth of the recursive argument" measure is not a valid reduction pair

This is the substantive issue. In the DP framework, the reduction pair $(\succ, \succcurlyeq)$ must be **closed under substitutions** — if $l \succ r$ then $\sigma(l) \succ \sigma(r)$ for every substitution $\sigma$ — and $\succcurlyeq$ must be **closed under contexts**.

Take the simple measure $\delta(t)$ = "s-depth of the recursive argument of the outermost defined symbol of $t$," and consider rule (1):

$$\mathsf{plus}(x, 0) \to x.$$

Here $\delta(\mathrm{LHS}) = 0$ (the recursive arg is $0$) and $\delta(\mathrm{RHS}) = 0$ (variable). So the rule is in $\succcurlyeq$. Now apply the substitution $\sigma = \{x \mapsto \mathsf{plus}(0, s(s(0)))\}$:

- $\sigma(\mathrm{LHS}) = \mathsf{plus}(\mathsf{plus}(0, s(s(0))), 0)$, so $\delta = 0$.
- $\sigma(\mathrm{RHS}) = \mathsf{plus}(0, s(s(0)))$, so $\delta = 2$.

So $\sigma(\mathrm{LHS}) \not\succcurlyeq \sigma(\mathrm{RHS})$: the measure **increased** on the RHS under substitution. Closure under substitutions fails. The simple $\delta$ is therefore **not a legitimate reduction pair** for the DP framework, and my claim that "every original rule is in $\succcurlyeq$" was wrong as stated.

This is a real hole, not a cosmetic one.

## 3. The fix: a lexicographic measure that *is* a valid reduction pair

The fix is to use a **lexicographic pair** $(\mathrm{rank}(t), d(t))$, where:

- $\mathrm{rank}(t)$ = the head symbol of $t$ if it is a defined symbol, ordered by $\mathsf{fac} > \mathsf{times} > \mathsf{plus} > \mathsf{p} > \mathsf{none}$ (where "none" means the term has no defined symbol at the head, e.g. $0$, $s(\cdots)$, or a variable);
- $d(t)$ = s-depth of the *recursive* argument of that head symbol (2nd arg for $\mathsf{plus}$, 1st arg for everything else), or $0$ if the head is "none."

Order lexicographically, with rank first. Call the resulting strict order $\succ$ and its reflexive closure $\succcurlyeq$.

### Why this is a valid reduction pair

- **Well-founded**: the rank takes values in a finite chain, the second component in $\mathbb{N}$. Standard.
- **Closed under substitutions**: the head symbol of $\sigma(t)$ is the head symbol of $t$ (substitution does not move the root), so $\mathrm{rank}(\sigma(t)) = \mathrm{rank}(t)$ exactly. The lex order is therefore preserved. ✓
- **Closed under contexts** for $\succcurlyeq$: any context $C[\cdot]$ fixes the head symbol of $C[t]$ independently of what sits in the hole, and the relevant-argument position is either inside the hole (in which case the lex comparison is unchanged) or determined by $C$ alone (in which case both sides agree). ✓

### Rule-by-rule verification (every rule, as required)

| Rule | $\mathrm{rank}(L)$ | $d(L)$ | $\mathrm{rank}(R)$ | $d(R)$ | lex verdict |
|---|---|---|---|---|---|
| (1) $\mathsf{plus}(x,0)\to x$ | $\mathsf{plus}$ | $0$ | none | $0$ | $L \succ R$ (rank drops) |
| (2) $\mathsf{plus}(x,s(y))\to s(\mathsf{plus}(x,y))$ | $\mathsf{plus}$ | $1+d(y)$ | $\mathsf{plus}$ (inside $s$) | $d(y)$ | $L \succ R$ (same rank, $d$ drops) |
| (3) $\mathsf{times}(0,y)\to 0$ | $\mathsf{times}$ | $0$ | none | $0$ | $L \succ R$ (rank drops) |
| (4) $\mathsf{times}(x,0)\to 0$ | $\mathsf{times}$ | $d(x)$ | none | $0$ | $L \succ R$ (rank drops) |
| (5) $\mathsf{times}(s(x),y)\to \mathsf{plus}(\mathsf{times}(x,y),y)$ | $\mathsf{times}$ | $1+d(x)$ | $\mathsf{plus}$ | $d(y)$ | $L \succ R$ ($\mathsf{times}>\mathsf{plus}$ in rank) |
| (6) $\mathsf{p}(s(s(x)))\to s(\mathsf{p}(s(x)))$ | $\mathsf{p}$ | $2+d(x)$ | $\mathsf{p}$ (inside $s$) | $1+d(x)$ | $L \succ R$ (same rank, $d$ drops) |
| (7) $\mathsf{p}(s(0))\to 0$ | $\mathsf{p}$ | $1$ | none | $0$ | $L \succ R$ (rank drops) |
| (8) $\mathsf{fac}(s(x))\to \mathsf{times}(\mathsf{fac}(\mathsf{p}(s(x))),s(x))$ | $\mathsf{fac}$ | $1+d(x)$ | $\mathsf{times}$ | $0$ | $L \succ R$ ($\mathsf{fac}>\mathsf{times}$ in rank) |

Every rule is in $\succ$ (hence also in $\succcurlyeq$). No rule needed a "but trust me, $p$ strips an $s$" patch; the decreases are direct from the head symbol and the s-depth of the relevant argument.

### DP-by-DP verification (every DP, as required)

| DP | rank change | $d$ change | in $\succ$? |
|---|---|---|---|
| (a) $\mathrm{PLUS}(x,s(y))\to \mathrm{PLUS}(x,y)$ | same | $1+d(y)\to d(y)$ | ✓ |
| (b) $\mathrm{TIMES}(s(x),y)\to \mathrm{PLUS}(\cdots,y)$ | $\mathsf{times}\to\mathsf{plus}$ | — | ✓ |

| (d) $\mathrm{P}(s(s(x)))\to \mathrm{P}(s(x))$ | same | $2+d(x)\to 1+d(x)$ | ✓ |
| (e) $\mathrm{FAC}(s(x))\to \mathrm{TIMES}(\cdots)$ | $\mathsf{fac}\to\mathsf{times}$ | — | ✓ |
| (f) $\mathrm{FAC}(s(x))\to \mathrm{FAC}(p(s(x)))$ | same | $1+d(x)\to 0$ | ✓ |

Every DP is in $\succ$.

### DP-graph analysis

- (a), (c), (d) are the only self-loops.
- (b) can be followed by (a), then the chain leaves $\mathrm{PLUS}$ — no cycle through (b).
- (e) and (f) are leaves: the RHS of (e) has head $\mathsf{times}$ with first argument headed by $\mathsf{fac}$ (no DP matches); the RHS of (f) has head $\mathsf{fac}$ with first argument $p(s(x))$ headed by $\mathsf{p}$ (no DP matches).

So every cycle in the DP graph is a self-loop on a DP that is in $\succ$. The DP framework's termination criterion is satisfied.

## 5. Why I picked this method in the first place (recap, with the benefit of hindsight)

I picked the DP framework because the obvious alternatives provably fail on this specific system:

- **Polynomial interpretations over $\mathbb{N}$**: rule (8) forces $[\!s\!]$ to be expanding ($c\ge 2$), which then forces $[\!\mathsf{fac}\!]$ to dominate $[\!\mathsf{times}\!]\circ[\!\mathsf{fac}\!]$ applied to an *expanded* argument, requiring super-polynomial growth. The obstruction is real.
- **A flat numeric measure**: the wrapper $\mathsf{times}(\cdots)$ in rule (8) hides the recursion of $\mathsf{fac}$, so a single integer on the whole term cannot see both decreases.
- **RPO/LPO**: rule (6) needs $\mathsf{p} > \mathsf{s}$ in the precedence, but rule (8) needs $\mathsf{s} > \mathsf{p}$ (so that $\mathsf{fac}(s(\cdot)) >_{\mathrm{RPO}} \mathsf{fac}(p(\cdot))$). The precedences are in conflict.

The DP framework is the right tool because the mutual recursion is **shallow and well-typed by argument position**: every defined symbol recurses on exactly one of its arguments, and the relevant argument's s-depth strictly decreases at every recursive call. The cross-symbol edges (FAC→TIMES, TIMES→PLUS) only ever go from a "higher" symbol in the rank to a "lower" one, which is exactly what the lex-order reduction pair captures.
