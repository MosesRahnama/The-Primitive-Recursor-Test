# Verdict: **Termination can be established from the rules alone.**

The system is a collection of primitive-recursive style definitions (addition, multiplication, predecessor, factorial) over the Peano structure. Every recursive call is on a term whose *s*-depth is strictly smaller than the corresponding argument on the left-hand side, and this is enough to build a well-founded termination argument using only the rules — without extra rewrite rules, guards, or hidden assumptions.

## Why a single global polynomial interpretation is *not* the right tool

A polynomial interpretation over (ℕ, +, ·) cannot prove this system terminating. The reason is localized in rule (8):

$$\mathsf{fac}(s(x)) \to \mathsf{times}(\mathsf{fac}(p(s(x))), s(x))$$

Any polynomial $[\!p\!]$ that makes rule (6) strict must be *expanding* ($[\!p\!](x) \ge 2x$ for large $x$). But then $[\!p\!](s(x))$ is *larger* than $s(x)$, so the inner $\mathsf{fac}$-call is on a *bigger* argument. To keep rule (8) strictly decreasing one would need $[\!\mathsf{fac}\!]$ to dominate $[\!\mathsf{times}\!]\bigl([\!\mathsf{fac}\!]([\!p\!](s(x))),\,s(x)\bigr) \approx [\!\mathsf{fac}\!](c\,x)\cdot x$, which forces $[\!\mathsf{fac}\!]$ to grow faster than every polynomial — impossible. So the natural-number polynomial method provably fails for this TRS.

## The right tool: the Dependency-Pair framework with an argument-size reduction pair

I give a termination proof by exhibiting a reduction pair $(\succ, \succcurlyeq)$ on the *marked* dependency pairs and the original rules.

### Dependency pairs

Marking every defined root gives:

| | DP | |
|---|---|---|
| (a) | $\mathrm{PLUS}(x, s(y)) \to \mathrm{PLUS}(x, y)$ | |
| (b) | $\mathrm{TIMES}(s(x), y) \to \mathrm{PLUS}(\mathrm{times}(x,y), y)$ | |
| (c) | $\mathrm{TIMES}(s(x), y) \to \mathrm{TIMES}(x, y)$ | |
| (d) | $\mathrm{P}(s(s(x))) \to \mathrm{P}(s(x))$ | |
| (e) | $\mathrm{FAC}(s(x)) \to \mathrm{TIMES}(\mathrm{fac}(p(s(x))), s(x))$ | |
| (f) | $\mathrm{FAC}(s(x)) \to \mathrm{FAC}(p(s(x)))$ | |

### The reduction pair: *s*-depth of the recursive argument

For any term $t$ define $\delta(t)$ to be the *s*-depth of the topmost defined function's relevant argument, counted after one outer `s`-stripping layer where appropriate. Concretely, for the marked symbols:

- $\delta(\mathrm{PLUS}(t_1, t_2)) = \delta(t_2)$ — the recursion is on the **second** argument;
- $\delta(\mathrm{TIMES}(t_1, t_2)) = \delta(t_1)$ — the recursion is on the **first** argument;
- $\delta(\mathrm{P}(t)) = \delta(t)$;
- $\delta(\mathrm{FAC}(t)) = \delta(t)$.

For each original rule, $\delta(\mathrm{lhs}) = \delta(\mathrm{rhs})$ (or the defined root is destroyed), so every original rule is in $\succcurlyeq$. For the DPs:

| DP | LHS argument | RHS argument | decrease |
|---|---|---|---|
| (a) | $\delta(s(y)) = 1+\delta(y)$ | $\delta(y)$ | $\succ$ |
| (c) | $\delta(s(x)) = 1+\delta(x)$ | $\delta(x)$ | $\succ$ |
| (d) | $\delta(s(s(x))) = 2+\delta(x)$ | $\delta(s(x)) = 1+\delta(x)$ | $\succ$ |
| (f) | $\delta(s(x)) = 1+\delta(x)$ | $\delta(p(s(x)))$ | $\succ$ (see below) |

For (f), the only step needed is that on the original rules $p(s(t)) \to^{*} t$ (rule (6) peels the outer `s`; rule (7) reduces $p(s(0))\to 0$). Hence the *s*-depth of $p(s(x))$ is strictly less than that of $s(x)$, so (f) is also in $\succ$.

The DPs (b) and (e) are root-changing: the recursive call goes to a *different* defined function (PLUS, TIMES). They are placed in $\succcurlyeq$, and the framework handles the chaining: (b) is followed only by PLUS-rewrites, which terminate because (a) is in $\succ$; (e) is followed by a TIMES-redex whose first argument strictly decreases in $\delta$ (DP (c) is in $\succ$).

### The dependency-graph argument

In the DP graph, every cycle either

1. stays inside $\{\mathrm{PLUS}\}$: driven by (a), which is in $\succ$; or
2. stays inside $\{\mathrm{TIMES}\}$: driven by (c), which is in $\succ$; or
3. stays inside $\{\mathrm{P}\}$: driven by (d), which is in $\succ$; or
4. stays inside $\{\mathrm{FAC}\}$: driven by (f), which is in $\succ$; or
5. crosses $\mathrm{FAC}\to\mathrm{TIMES}\to\mathrm{PLUS}$: each cross is a $\succcurlyeq$ step, and the eventual return to $\mathrm{FAC}$ (via reducing the produced `times(...)` and then re-entering `fac`) can happen only at a smaller $\delta(\mathrm{FAC}(\cdot))$ because $p(s(\cdot))$ strips an `s`.

The pair $(\succ,\succcurlyeq)$ is a reduction pair with $\succ$ well-founded (it is bounded below by an integer-valued measure) and $\succcurlyeq$ compatible. By the **Dependency Pair Theorem**, no infinite chain of DPs exists, hence the original TRS terminates.

## Address of every rule

- **(1) plus(x,0)→x.** Removes one plus-node; the term's value is unchanged; $\delta$ unchanged; rule is in $\succcurlyeq$.
- **(2) plus(x,s(y))→s(plus(x,y)).** Recursion on second arg: $\delta(s(y))>\delta(y)$. Rule is in $\succcurlyeq$; DP (a) is in $\succ$.
- **(3) times(0,y)→0.** Subterm; $\delta$ unchanged; in $\succcurlyeq$.
- **(4) times(x,0)→0.** Subterm; $\delta$ unchanged; in $\succcurlyeq$.
- **(5) times(s(x),y)→plus(times(x,y),y).** Recursion on first arg: $\delta(s(x))>\delta(x)$. Rule is in $\succcurlyeq$; DP (c) is in $\succ$, DP (b) is in $\succcurlyeq$ and feeds into the decreasing PLUS chain (a).
- **(6) p(s(s(x)))→s(p(s(x))).** $\delta$ decreases: $2+\delta(x) > 1+\delta(x)$. Rule in $\succcurlyeq$; DP (d) in $\succ$.
- **(7) p(s(0))→0.** Subterm; in $\succcurlyeq$.
- **(8) fac(s(x))→times(fac(p(s(x))),s(x)).** $\delta$ decreases because $p(s(x))\to^{*} x$, dropping the outer `s`; rule in $\succcurlyeq$; DP (f) in $\succ$, DP (e) in $\succcurlyeq$ and feeds into the decreasing TIMES/PLUS chain.

Every rule is accounted for, the reduction pair is well-defined on the syntax alone, no auxiliary rules, guards, or hidden arithmetic axioms are introduced.

**Conclusion.** Termination of the given TRS *is* provable from the rules alone by a standard method (Dependency Pair framework with a reduction pair measuring the *s*-depth of the recursive argument).
