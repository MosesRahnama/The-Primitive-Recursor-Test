The system defines addition, multiplication, predecessor (`p`), and factorial (`fac`) over Peano-style natural numbers. Although `p(s(x))` is not syntactically a subterm of `s(x)` (which defeats simple structural orderings like RPO/LPO), termination can be proven using a semantic value function combined with dependency pair analysis.

**Define a value interpretation** `val` on ground terms:
- `val(0) = 0`, `val(s(t)) = val(t) + 1`
- `val(plus(a,b)) = val(a) + val(b)`
- `val(times(a,b)) = val(a) × val(b)`
- `val(p(t)) = max(val(t) − 1, 0)`
- `val(fac(t)) = (val(t))!`

**Step 1 — All rules preserve `val`.** Checking each rule confirms `val(LHS) = val(RHS)`:
- Rules 1–2: standard addition identities.
- Rules 3–5: `0·y = 0`, `x·0 = 0`, `(x+1)·y = x·y + y`.
- Rule 6: `max(v+2−1, 0) = v+1 = max(v+1−1, 0)+1`.
- Rule 7: `max(1−1, 0) = 0`.
- Rule 8: `(v+1)! = v! × (v+1)`.

**Step 2 — Dependency pair analysis.** The four SCCs in the dependency graph are:
- `{PLUS(x, s(y)) → PLUS(x, y)}` — second argument structurally decreases.
- `{TIMES(s(x), y) → TIMES(x, y)}` — first argument structurally decreases.
- `{P(s(s(x))) → P(s(x))}` — argument structurally decreases.
- `{FAC(s(x)) → FAC(p(s(x)))}` — structural size does **not** decrease, but:

**Step 3 — The FAC cycle terminates by value decrease.** In any chain:
`FAC(s(x₁)) → FAC(p(s(x₁))) →* FAC(s(x₂)) → …`

Since all rules preserve `val`, the intermediate reduction `p(s(x₁)) →* s(x₂)` gives:
`val(s(x₂)) = val(p(s(x₁))) = max(val(x₁)+1−1, 0) = val(x₁) = val(s(x₁)) − 1`

The value of the argument drops by exactly 1 per cycle step. Since values are non-negative integers (well-founded), the chain terminates in at most `val(s(x₁))` steps.

**Conclusion:** No external axioms are needed — only the rewrite rules themselves (to verify `val`-invariance) and the well-foundedness of ℕ. The system is terminating.
