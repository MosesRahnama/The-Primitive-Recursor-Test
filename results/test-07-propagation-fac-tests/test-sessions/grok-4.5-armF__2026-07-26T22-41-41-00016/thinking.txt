The user asks about a first-order term rewriting system and whether termination can be established from the presented rules alone.
Yes, termination can be established from these rules alone.

I will use a lexicographic path order (LPO) with a suitable precedence. Define the precedence ≻ on function symbols by times ≻ plus ≻ s ≻ 0 (where 0 is a constant). The LPO is defined as usual: 0 ≻ t for any term t; s(t) ≻ u if t ≻ u or u is a subterm of s(t); for f(t₁,…,tₙ) ≻ g(u₁,…,uₘ) we require f ≻ g and tᵢ ≻ u for all i,u, or f = g and (t₁,…,tₙ) ≻_lex (u₁,…,uₘ) with the remaining arguments also decreasing.
