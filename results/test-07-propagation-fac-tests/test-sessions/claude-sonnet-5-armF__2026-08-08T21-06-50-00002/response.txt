## Verdict: **Yes** — termination is provable directly from the rules using the **Recursive Path Order (RPO)**.

## Setup

Use RPO with

* **Precedence:** `times ≻ plus ≻ s ≻ 0`
* **Status:** lexicographic (left‑to‑right) for `plus` and `times`; `s` and `0` have no argument-order issues (arity ≤ 1).

Recall the two basic facts about RPO that will be used repeatedly:

* **(Subterm property):** `t ≻ t'` for every proper subterm `t'` of `t`.
* **(Precedence step):** if `root(t) = f ≻ g = root(u)` and `t ≻ uᵢ` for every argument `uᵢ` of `u`, then `t ≻ u`.
* **(Same‑head step):** if `root(t) = root(u) = f`, and the argument tuples of `t`,`u` compare favorably under the lexicographic extension of `≻` (and `t ≻ uᵢ` for the relevant arguments), then `t ≻ u`.

## Checking every rule

**1. `times(x,0) → 0`**
`0` is a direct (proper) subterm of `times(x,0)`. By the subterm property, `times(x,0) ≻ 0`. ✔

**2. `times(x,s(y)) → plus(times(x,y), x)`**
`root = times ≻ plus = root(RHS)`. Need `times(x,s(y)) ≻ times(x,y)` and `times(x,s(y)) ≻ x`.
- `times(x,s(y)) ≻ x`: `x` is a direct subterm — subterm property. ✔
- `times(x,s(y)) ≻ times(x,y)`: same head `times`; compare tuples `(x,s(y))` vs `(x,y)` lexicographically: first components equal, second components compare as `s(y) ≻ y` (subterm property). Hence `times(x,s(y)) ≻ times(x,y)`. ✔
By the precedence step, `times(x,s(y)) ≻ plus(times(x,y),x)`. ✔

**3. `plus(x,0) → x`**
`x` is a direct subterm of `plus(x,0)` — subterm property gives `plus(x,0) ≻ x`. ✔

**4. `plus(0,x) → x`**
Same argument: `x` is a direct subterm — `plus(0,x) ≻ x`. ✔

**5. `plus(x,s(y)) → s(plus(x,y))`**
`root = plus ≻ s = root(RHS)`. Need `plus(x,s(y)) ≻ plus(x,y)` (the sole argument of `s(...)`).
Same head `plus`; compare tuples `(x,s(y))` vs `(x,y)`: first components equal, second components `s(y) ≻ y` (subterm property) ⇒ `plus(x,s(y)) ≻ plus(x,y)`.
By the precedence step, `plus(x,s(y)) ≻ s(plus(x,y))`. ✔

**6. `plus(s(x),y) → s(plus(x,y))`**
`root = plus ≻ s`. Need `plus(s(x),y) ≻ plus(x,y)`.
Same head `plus`; compare tuples `(s(x),y)` vs `(x,y)`: first components differ with `s(x) ≻ x` (subterm property), which already decides the lexicographic comparison ⇒ `plus(s(x),y) ≻ plus(x,y)`.
By the precedence step, `plus(s(x),y) ≻ s(plus(x,y))`. ✔
