The standard LPO definition (e.g., from Baader & Nipkow or Dershowitz):

Given a precedence > on function symbols (a well-founded strict partial order), the LPO > is defined as:

s = f(s1, ..., sn) > t if and only if one of the following holds:
(LPO1) t is a variable and t occurs in s (as a proper subterm, i.e., t != s, which is guaranteed since s has a root symbol f and t is a variable)
(LPO2) t = g(t1, ..., tm) and:
  (LPO2a) f > g and s > tj for all j = 1, ..., m
  (LPO2b) f = g and (s1, ..., sn) >_lex (t1, ..., tm) and s > tj for all j = 1, ..., m
  (LPO2c) si >= t for some i = 1, ..., n (where >= means > or syntactic equality)

Note: In (LPO2a) and (LPO2b), the condition "s > tj for all j" means that the LHS must be strictly greater than each argument of the RHS.
