# Verdict: **Terminating**

Termination can be established directly from the given rules using the **Lexicographic Path Ordering (LPO)** with the precedence:

$$\text{times} > \text{plus} > s > 0$$

and left-to-right lexicographic status for all function symbols.

---

## Termination Argument

Recall that in LPO, $s = f(s_1,\dots,s_n) >_{\text{lpo}} t$ holds if one of the following is satisfied:

- **(Var)** $t$ is a variable occurring in $s$
- **(Prec)** $t = g(t_1,\dots,t_m)$, $f > g$ in the precedence, and $s >_{\text{lpo}} t_j$ for all $j$
- **(Same)** $t = g(t_1,\dots,t_m)$, $f = g$, $(s_1,\dots,s_n) >_{\text{lpo}}^{\text{lex}} (t_1,\dots,t_m)$, and $s >_{\text{lpo}} t_j$ for all $j$
- **(Sub)** $s_i \geq_{\text{lpo}} t$ for some $i$

Since LPO is a well-founded reduction ordering (closed under contexts and substitutions), orienting all rules strictly ($\text{LHS} >_{\text{lpo}} \text{RHS}$) proves termination.

### Rule-by-rule verification

**Rule 1:** $\text{times}(x, 0) \to 0$
- $\text{times} > 0$ in the precedence, and the RHS has no arguments, so the subterm conditions are vacuously met. ✓ **(Prec)**

**Rule 3:** $\text{plus}(x, 0) \to x$
- $x$ is a variable occurring in the LHS. ✓ **(Var)**

**Rule 4:** $\text{plus}(0, x) \to x$
- $x$ is a variable occurring in the LHS. ✓ **(Var)**

**Rule 5:** $\text{plus}(x, s(y)) \to s(\text{plus}(x, y))$
- $\text{plus} > s$ in the precedence **(Prec)**. We must show the LHS exceeds the sole argument of $s$, i.e., $\text{plus}(x, s(y)) >_{\text{lpo}} \text{plus}(x, y)$.
  - Same root symbol $\text{plus}$, so use **(Same)** with lexicographic comparison of arguments: $(x, s(y))$ vs. $(x, y)$.
  - First components are equal ($x = x$). Second components: $s(y) >_{\text{lpo}} y$ by **(Var)**. So the lex condition holds.
  - Subterm conditions: $\text{plus}(x, s(y)) >_{\text{lpo}} x$ and $\text{plus}(x, s(y)) >_{\text{lpo}} y$ both by **(Var)**. ✓

**Rule 6:** $\text{plus}(s(x), y) \to s(\text{plus}(x, y))$
- $\text{plus} > s$ in the precedence **(Prec)**. We must show $\text{plus}(s(x), y) >_{\text{lpo}} \text{plus}(x, y)$.
  - Same root $\text{plus}$, **(Same)** with lex comparison: $(s(x), y)$ vs. $(x, y)$.
  - First components: $s(x) >_{\text{lpo}} x$ by **(Var)**. Lex condition holds immediately.
  - Subterm conditions: $\text{plus}(s(x), y) >_{\text{lpo}} x$ and $>_{\text{lpo}} y$ both by **(Var)**. ✓

**Rule 2:** $\text{times}(x, s(y)) \to \text{plus}(\text{times}(x, y), x)$
- $\text{times} > \text{plus}$ in the precedence **(Prec)**. We must show the LHS exceeds each argument of $\text{plus}$:
  1. $\text{times}(x, s(y)) >_{\text{lpo}} \text{times}(x, y)$:
     - Same root $\text{times}$, **(Same)** with lex: $(x, s(y))$ vs. $(x, y)$.
     - First components equal. Second: $s(y) >_{\text{lpo}} y$ by **(Var)**. ✓
     - Subterm conditions: $\text{times}(x, s(y)) >_{\text{lpo}} x$ and $>_{\text{lpo}} y$ both by **(Var)**. ✓
  2. $\text{times}(x, s(y)) >_{\text{lpo}} x$: by **(Var)**. ✓

## Conclusion

All six rules are strictly oriented by LPO under the single precedence $\text{times} > \text{plus} > s > 0$ with no extra axioms, guards, or side conditions. Since LPO is a well-founded reduction ordering, **the system is terminating**.
