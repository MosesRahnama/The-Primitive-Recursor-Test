We interpret each symbol as a polynomial over the natural numbers, all strictly monotone in every argument (guaranteeing a well-founded, monotonic, stable ordering compatible with rewriting):

All these functions are strictly monotone in each argument (coefficients of variables are positive), so the interpretation is a valid basis for a reduction order: if `[l] > [r]` for every instance of a rule, that rule is compatible with a well-founded monotone order, and if this holds for **all** rules, the whole system terminates.

### Checking every rule
