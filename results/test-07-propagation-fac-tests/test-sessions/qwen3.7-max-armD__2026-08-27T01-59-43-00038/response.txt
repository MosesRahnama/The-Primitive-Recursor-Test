# Termination Assessment

**Verdict: The system is terminating.**

## Proof via Polynomial Interpretation over ℕ

I assign the following polynomial interpretation over the non-negative integers:

| Symbol | Interpretation |
|--------|---------------|
| `0` | `0` |
| `s(x)` | `x + 1` |
| `plus(x, y)` | `x + 2y + 1` |
| `times(x, y)` | `2xy + 2x + y + 1` |
| `p(x)` | `2x` |

All functions map ℕ → ℕ and are (at least weakly) monotone in every argument, satisfying the requirements for a valid polynomial interpretation.

## Rule-by-Rule Verification

**Rule 1:** `plus(x, 0) → x`
- LHS = `x + 2(0) + 1 = x + 1`
- RHS = `x`
- `x + 1 > x` ✅

**Rule 2:** `plus(x, s(y)) → s(plus(x, y))`
- LHS = `x + 2(y + 1) + 1 = x + 2y + 3`
- RHS = `(x + 2y + 1) + 1 = x + 2y + 2`
- `x + 2y + 3 > x + 2y + 2` ✅

**Rule 3:** `times(0, y) → 0`
- LHS = `2(0)y + 2(0) + y + 1 = y + 1`
- RHS = `0`
- `y + 1 > 0` ✅

**Rule 4:** `times(x, 0) → 0`
- LHS = `2x(0) + 2x + 0 + 1 = 2x + 1`
- RHS = `0`
- `2x + 1 > 0` ✅

**Rule 5:** `times(s(x), y) → plus(times(x, y), y)`
- LHS = `2(x+1)y + 2(x+1) + y + 1 = 2xy + 3y + 2x + 3`
- RHS = `(2xy + 2x + y + 1) + 2y + 1 = 2xy + 3y + 2x + 2`
- `LHS − RHS = 1 > 0` ✅

**Rule 6:** `p(s(s(x))) → s(p(s(x)))`
- LHS = `2(x + 2) = 2x + 4`
- RHS = `2(x + 1) + 1 = 2x + 3`
- `2x + 4 > 2x + 3` ✅

**Rule 7:** `p(s(0)) → 0`
- LHS = `2(0 + 1) = 2`
- RHS = `0`
- `2 > 0` ✅

## Conclusion

Every rewrite rule strictly decreases the polynomial interpretation. Since the interpretation maps into ℕ under the standard well-founded ordering `>`, infinite rewrite sequences are impossible. The system **terminates**, established purely from the given syntax and rules with no external assumptions.
