## Why a polynomial interpretation here

I chose the method because the system has a very specific shape that polynomial interpretations handle cleanly, and the alternatives are awkward or unsafe given the constraints.

**What the system is.** It is a first‑order TRS (no `binder`/lambda, no AC, no `mem`/lookup). The right‑hand sides are all **syntactically smaller** than the left‑hand sides with one important exception: rule 5,
$$\mathsf{times}(\mathsf{s}(x),y)\to\mathsf{plus}(\mathsf{times}(x,y),y)$$
This is the classic Peano‑multiplication rule. A naive "one symbol smaller" measure fails on it (the right‑hand side is *bigger* in symbol count). So a purely structural, symbol‑counting argument does not work and I needed an interpretation that can absorb the structural blow‑up into a numeric decrease.

**Why polynomial and not the others I considered.**

- *Recursive path order / lexicographic / multiset path order.* RPO/LPO needs a precedence where the head symbol of the lhs (here `times`) is greater than the head of the rhs (`plus`). That would require me to enforce a precedence `times > plus`. That is an *object‑level* claim about the symbol ordering that is not in the rewrite system; relying on it smuggles in a meta‑assumption. It is also brittle: I would have to redo it for each rule. With a polynomial interpretation the decrease is numeric and the only "ordering" is $\mathbb{N}$'s built‑in one.
- *Matrix interpretation.* Would work, but it is strictly more machinery than needed; the polynomials above are degree ≤ 2 in the worst case and monotone, which is the simplest setting of the same proof technique.
- *Dependency‑pair framework.* Powerful, but it would require introducing a fresh "dp" signature (new symbols like $F_{\mathsf{times}}, F_{\mathsf{plus}}, F_{\mathsf{p}}$) and additional DP rules. That is effectively *strengthening the system with extra rewrite rules* — which the question explicitly forbids.
- *Manual ad‑hoc measure.* One could try a tuple measure such as $(\text{size},\, \text{second argument of } \mathsf{plus}\text{ in the spine})$ or a count of `plus`/`times` symbols. That is doable, but it is essentially reinventing a polynomial interpretation in disguise, and it is more error‑prone: every rule has to be checked against a hand‑crafted ordering, and rule 5 in particular needs care.
- *Simplification ordering (e.g. a direct semantic path order).* Same issue as RPO: needs a precedence or a status, again an object‑level choice.

A polynomial interpretation gets around all of these:

1. It is **purely numeric**, so the well‑foundedness argument is just "values lie in $\mathbb{N}$ and strictly decrease," which uses only the standard order on the naturals — no extra symbol ordering, no extra rules, no extra axioms about the TRS.
2. It **naturally handles rule 5**, because under $\mathcal{I}(\mathsf{times}(x,y))=(2x+1)(2y+1)$ the substitution $x\mapsto \mathsf{s}(x)$ multiplies the value by $(2x+3)/(2x+1)$, comfortably absorbing the additive $+y$ on the rhs.
3. It is **uniform and verifiable**: the same monotone polynomial is applied to every occurrence of a function symbol, so the seven checks in the table cover all rules, and there is no case analysis hidden in a lexicographic tie‑breaker.
4. It is **standard** (Dershowitz 1979; see also Zantema's `SRS` and the `AProVE`/termination handbooks), so I am not invoking a bespoke technique.

## Could I have done it without a polynomial interpretation?

Yes — a small ad‑hoc measure works too, e.g. an interpretation into $\mathbb{N}^2$ with lexicographic ordering: first component = syntactic size, second = a small correction term. But that is morally the same argument as a polynomial interpretation, just written more verbosely. I picked the polynomial form because it is the cleanest, most standard, and most transparently checkable instance of the same idea, and it stays strictly within the "no extra rules, no hidden assumptions" boundary the question imposed.
