# Termination Analysis

**Verdict: The system terminates.**

## The Two Rules

```
(1)  F(x, y, Z)     →  x
(2)  F(x, y, S(n))  →  G(y, F(x, y, n))
```

## Termination Argument (Polynomial Interpretation over ℕ)

I use a standard polynomial interpretation into the natural numbers. The order on terms is the natural order on ℕ, which is well-founded. Variables are interpreted as 0 (the minimum); for any substitution σ with non‑negative values, each φᵢ is monotone, so φ(tσ) ≥ φ(t).

| Symbol | Interpretation |
|---|---|
| Z | 0 |
| S(t) | φ(t) + 1 |
| F(t₁, t₂, t₃) | 2·φ(t₃) + 1 |
| G(t₁, t₂) | φ(t₁) + φ(t₂) |

### Check of Rule (1): F(x, y, Z) → x

- φ(F(x, y, Z)) = 2·φ(Z) + 1 = 2·0 + 1 = **1**
- φ(x) = **0**

Strict decrease: 1 > 0. ✓

### Check of Rule (2): F(x, y, S(n)) → G(y, F(x, y, n))

- φ(F(x, y, S(n))) = 2·φ(S(n)) + 1 = 2·(φ(n) + 1) + 1 = **2·φ(n) + 3**
- φ(G(y, F(x, y, n))) = φ(y) + φ(F(x, y, n)) = 0 + (2·φ(n) + 1) = **2·φ(n) + 1**

Strict decrease: 2·φ(n) + 3 > 2·φ(n) + 1. ✓

## Why This Is Sufficient

Both rules strictly decrease the value of φ over the well-founded domain (ℕ, >). Since every rewrite step replaces a redex with a term of strictly smaller φ-value, no infinite rewrite sequence is possible. By the standard polynomial-interpretation termination theorem, the system is terminating.

No additional rules, guards, side conditions, or object-level axioms were introduced — the proof uses only the given syntax and the two rewrite rules.
