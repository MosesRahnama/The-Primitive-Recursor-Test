## Verdict: **YES — the system terminates.**

I establish this from the eight rules alone, using a standard dependency-pair (DP) analysis (Arts & Giesl). No extra rules, guards, or object‑level axioms are imported; every fact used is read off the given syntax and the rewrite relation it generates.

---

### 1. The dependency pairs

For each rule `l → r`, every defined‑function subterm of `r` gives a DP `l → u`. From the system:

| # | Rule source | DP |
|---|---|---|
| DP₁ | rule 2 | `plus(x, s(y)) → plus(x, y)` |
| DP₂ | rule 5 | `times(s(x), y) → times(x, y)` |
| DP₃ | rule 5 | `times(s(x), y) → plus(times(x, y), y)` |
| DP₄ | rule 6 | `p(s(s(x))) → p(s(x))` |
| DP₅ | rule 8 | `fac(s(x)) → times(fac(p(s(x))), s(x))` |
| DP₆ | rule 8 | `fac(s(x)) → fac(p(s(x)))` |

(Rules 1, 3, 4, 7 introduce no defined symbol on the RHS, so no DPs.)

### 2. Key lemma — the times‑term of DP₅ is a *dead redex*

Consider the RHS of DP₅, `times(fac(p(s(x))), s(x))`. I claim no rule 3, 4, or 5 ever applies to it.

- **Rule 3** (`times(0, y) → 0`) needs first arg = `0`. But `fac(p(s(x)))` is never `0`: `fac(·)` is either the normal form `fac(0)` (head symbol `fac`) or reduces by rule 8 to a term whose head is `times`. Neither is `0`.
- **Rule 4** (`times(x, 0) → 0`) needs second arg = `0`. Here the second arg is `s(x)`, not `0`.
- **Rule 5** (`times(s(x), y) → plus(times(x, y), y)`) needs the first arg to have head `s`. But `fac(p(s(x)))` has head `fac`, and any reduct of it has head `fac` (the normal form `fac(0)`) or head `times` (from rule 8). It never acquires head `s`.

So the times‑term produced by rule 8 is a **permanent normal form**; no rule can rewrite it. (This is purely a property of the head symbols derivable from the eight rules — no external assumption.)

### 3. Chain analysis of every DP

I trace the possible DP chains. A chain step rewrites the current RHS by the *original* rules and tries to unify with the LHS of the next DP.

- **DP₁** `plus(x, s(y)) → plus(x, y)`. The RHS `plus(x, y)` is a normal form when `y` is a variable; with `y = 0` rule 1 gives `x` (a variable, normal form); with `y = s(z)` rule 2 gives `s(plus(x, z))` (no DP has `s(·)` as LHS). Chain length ≤ 1.
- **DP₂** `times(s(x), y) → times(x, y)`. RHS `times(x, y)` is in normal form (no times rule applies when the first arg is a variable). Chain length ≤ 1.
- **DP₃** `times(s(x), y) → plus(times(x, y), y)`. The RHS unifies with DP₁’s LHS only if `y = s(y′)`, giving `plus(times(x, s(y′)), s(y′))`, which is a redex of DP₁. So DP₃ → DP₁, and DP₁ is finite.
- **DP₄** `p(s(s(x))) → p(s(x))`. The RHS unifies with DP₄’s own LHS only via `x ↦ s(x′)`, giving `p(s(s(x′))) → p(s(x′))`. The `s`‑depth of the argument strictly decreases; the chain is bounded by the initial `s`‑depth.
- **DP₅** `fac(s(x)) → times(fac(p(s(x))), s(x))`. By the lemma of §2, the RHS is a permanent normal form. No rule (hence no DP) can consume it. **DP₅ is a sink.**
- **DP₆** `fac(s(x)) → fac(p(s(x)))`. 
  - If `x` is a variable, `p(s(x))` matches neither rule 6 (needs `s(s(z))` with the inner `z` being `x`, but `x` is a bare variable, not `s(·)`) nor rule 7 (needs `s(0)`). So `p(s(x))` is a normal form that is not `s(·)`; rule 8 does not match `fac(p(s(x)))`, and DP₆’s RHS is a normal form. Chain length ≤ 1.
  - If `x` is a ground numeral `sⁿ(0)`, then `p(s(sⁿ(0))) →* sⁿ(0) = x`, so `fac(p(s(x))) →* fac(x)`. This matches DP₆’s LHS only when `x = s(x′)`, i.e. `n ≥ 1`, and the new argument has strictly smaller `s`‑depth. After `n` steps we reach `fac(0)`, a normal form. Chain length `≤ n`.

### 4. The DP graph is acyclic; conclusion

The reachable edges between DPs are:

```
DP₃ → DP₁          DP₄ → DP₄      DP₆ → DP₆
DP₁, DP₂, DP₅  :  sinks
```

There is **no cycle** that returns to `fac` from `times`, because the only `fac → times` edge (DP₅) lands in a dead redex, and `times` never produces a `fac` subterm. Every recursive DP (DP₄, DP₆) strictly decreases the `s`‑depth of its argument; every other DP is a sink or feeds a sink in one step.

By the **Dependency Pair Theorem** (the standard sufficient condition: a TRS is terminating iff its DP problem has no infinite chain), the original system is terminating.

---

### 5. Why no “strengthening” was needed

The argument never introduces a new rewrite rule, guard, or external axiom. The “dead redex” claim in §2 is established purely by case analysis of the head symbols of the rules (which functions can appear at the root of a reduct of `fac(·)` and of `p(·)`), and the acyclicity of the DP graph is read off the eight rules. Every measure used (`s`‑depth of the recursive argument, finiteness of the chain) is derived from the rules themselves.
