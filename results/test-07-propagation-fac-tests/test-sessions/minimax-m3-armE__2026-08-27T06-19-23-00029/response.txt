## Termination Argument

**Measure.** For a term `t`, define its *depth* `d(t)` as the size of the third argument of the **outermost** `F`, where size is measured structurally on the Peano numerals:

- `size(Z) = 0`
- `size(S(u)) = 1 + size(u)`

For terms not headed by `F`, set `d(t) = 0`. Since the third argument of every `F` is built only from `Z` and `S`, the natural numbers with the standard ordering form a well-founded domain for `size`.

**Rule-by-rule analysis.**

*Rule 1:  `F(x, y, Z)  →  x`*

- LHS: the third argument is `Z`, so `size = 0`. This is the base case.
- RHS: the term is `x` (no `F`-redex at the head). The depth drops from 0 to 0, but no further reduction of this redex is possible by rule 1 again, since `Z` is not unifiable with `S(n)`.

*Rule 2:  `F(x, y, S(n))  →  G(y, F(x, y, n))`*

- LHS: third argument is `S(n)`, so `size = 1 + size(n)`.
- RHS: contains the subterm `F(x, y, n)` whose third argument is `n`, with `size(n) < 1 + size(n)`. So the depth of the head `F` strictly decreases.
- The freshly introduced term `G(y, …)` has **no applicable rule** (the system provides no rule for `G`), so it acts as a frozen constructor and never spawns further redexes.

**Why this suffices.**

1. Every `F`-redex's third argument is a Peano numeral, hence has a finite size.
2. Rule 2 strictly decreases that size; rule 1 applies only when the size is 0 and produces no new `F`-redex.
3. No rule for `G` exists, so `G`-terms contribute no redexes.
4. The well-foundedness of `(ℕ, <)` gives termination: any rewrite sequence starting from an `F`-redex must hit the base rule in finitely many steps, after which only inert `G`-prefixes remain.

The only object-level fact used is the well-foundedness of the natural numbers as generated by `Z` and `S`—which is directly available from the syntax of the rewrite rules themselves (rule 1 names `Z` as the base, rule 2 names `S(n)` as the step). No external axioms, structural rules, or extra guards are needed.

**Conclusion.** The system is terminating, by structural induction on the size of the third argument of `F`.
