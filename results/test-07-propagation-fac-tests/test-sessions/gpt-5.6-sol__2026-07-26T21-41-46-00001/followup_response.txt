I chose a **two-component semantic interpretation** because the system mixes two different notions:

1. the mathematical value represented by a term, and  
2. the amount of computation still encoded in it.

Most rules preserve mathematical value rather than decrease it. For example,

\[
plus(x,s(y))\to s(plus(x,y))
\]

denotes the same number on both sides. Likewise, the factorial rule preserves factorial value. Thus a simple interpretation by ordinary numerical value cannot prove termination.

At the same time, a purely syntactic order is awkward because of the interaction between `p` and `fac`:

- Orienting  
  \[
  p(s(s(x)))\to s(p(s(x)))
  \]
  naturally suggests that `p` should dominate `s`.
- In the factorial rule, one must justify that the recursive call
  \[
  fac(p(s(x)))
  \]
  is smaller than \(fac(s(x))\), which syntactically suggests treating \(s(x)\) as larger than \(p(s(x))\).

This creates the kind of precedence tension that makes a straightforward recursive path order unattractive. More fundamentally, \(p(s(x))\) is not literally a subterm of \(s(x)\), so one cannot invoke ordinary structural recursion without importing an assumption such as “`p` is predecessor.”

The pair interpretation resolves this directly:

- The first coordinate assigns the intended numerical value.
- The second coordinate is a decreasing potential or computation cost.
- The order compares costs only when values are equal.

That last point is important. Every rewrite rule preserves the first coordinate, while strictly lowering the second. Consequently, the interpretation does not pretend that evaluation changes the represented number; it measures only the disappearance of computational work.

The individual cost formulas were chosen in stages:

- `p`, `plus`, and `times` were given costs that make their recursive rules decrease by a small explicit amount—usually exactly \(1\).
- `fac` required a value-dependent affine cost
  \[
  K_nA+C_n,
  \]
  because duplication and nesting in
  \[
  times(fac(p(s(x))),s(x))
  \]
  make a fixed linear coefficient insufficient. The recurrences for \(K_n\) and \(C_n\) were selected so that this final rule decreases by \(A+1\).

I also chose this method because it proves the strongest relevant claim cleanly: **termination for all terms, including open and non-constructor terms**, without assuming that variables range only over numerals or adding equations such as \(p(s(x))=x\). The familiar arithmetic behavior is used only as a semantic interpretation for orienting the existing rules, which is permitted in a termination proof; it is not added to the rewrite system as an object-level axiom.
