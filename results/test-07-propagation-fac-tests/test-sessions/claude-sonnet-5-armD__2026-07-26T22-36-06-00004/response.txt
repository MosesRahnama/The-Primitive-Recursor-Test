## Verdict: **Terminating** — provable by the Lexicographic Path Order (LPO)

The system can be shown terminating using a standard, well-known technique: the **Lexicographic Path Order (LPO)**, instantiated with a precedence on the function symbols and left‑to‑right lexicographic status for multi‑argument symbols. This is a purely syntactic simplification order; no extra rules, guards, or external axioms are needed — only the subterm property and the precedence/status comparison, both of which are standard components of LPO.

### Precedence and status

Choose the precedence
```
times ≻ plus ≻ p ≻ s ≻ 0
```
with **lexicographic status** (left-to-right) for `times`, `plus`, and `p`, and the trivial status for the unary `s` and the constant `0`.

Recall the two basic LPO clauses used below:

- **Subterm property:** any proper subterm `t` of `f(...)` satisfies `f(...) ≻ t`.
- **Precedence clause:** if `root(l)=f ≻ g=root(r)` (or the roots are equal and lexicographic comparison of argument tuples applies), then `l ≻ r` provided `l ≻ r_i` for every immediate argument `r_i` of `r` (or the lexicographic comparison succeeds, respectively).

### Rule-by-rule verification

**1. `plus(x,0) → x`**
`x` is a proper subterm of `plus(x,0)`. By the subterm property, `plus(x,0) ≻ x`. ✔

**2. `plus(x,s(y)) → s(plus(x,y))`**
Root of LHS is `plus`, root of RHS is `s`, and `plus ≻ s`. It suffices that `plus(x,s(y)) ≻ plus(x,y)` (the only argument of `s(...)`).
Both sides have head `plus`; compare argument tuples `(x,s(y))` vs `(x,y)` lexicographically: first components equal (`x=x`); second components compare as `s(y) ≻ y` (subterm property). Hence `(x,s(y)) ≻_{lex} (x,y)`, giving `plus(x,s(y)) ≻ plus(x,y)`. Thus the precedence clause applies. ✔

**3. `times(0,y) → 0`**
RHS is the minimal constant `0`; LHS is a compound term. By the subterm/precedence property for constants below all function symbols, `times(0,y) ≻ 0`. ✔

**4. `times(x,0) → 0`**
Same reasoning: `times(x,0) ≻ 0`. ✔

**5. `times(s(x),y) → plus(times(x,y), y)`**
Root of LHS is `times`, root of RHS is `plus`, and `times ≻ plus`. Need `times(s(x),y) ≻ times(x,y)` and `times(s(x),y) ≻ y`.

- `times(s(x),y) ≻ y`: `y` is a proper subterm of the LHS — subterm property. ✔
- `times(s(x),y) ≻ times(x,y)`: same head `times`; compare tuples `(s(x),y)` vs `(x,y)` lexicographically: first components `s(x) ≻ x` (subterm property) already decides it. ✔

Both required comparisons hold, so the precedence clause gives `times(s(x),y) ≻ plus(times(x,y),y)`. ✔

**6. `p(s(s(x))) → s(p(s(x)))`**
Root of LHS is `p`, root of RHS is `s`, and `p ≻ s`. Need `p(s(s(x))) ≻ p(s(x))` (the sole argument of the RHS's `s`).
Both have head `p`; compare arguments `s(s(x))` vs `s(x)`: both head `s`; compare `s(x)` vs `x`: `s(x) ≻ x` by subterm property, so `s(s(x)) ≻ s(x)`. Hence `p(s(s(x))) ≻ p(s(x))`, and the precedence clause applies. ✔

**7. `p(s(0)) → 0`**
RHS is the minimal constant `0`; LHS compound. `p(s(0)) ≻ 0`. ✔

### Conclusion

Every rewrite rule is strictly decreasing under this LPO instance (precedence `times ≻ plus ≻ p ≻ s ≻ 0`, left-to-right lexicographic status for `times`, `plus`, `p`). Since LPO is a well-founded order on terms (a classical, self-contained fact about the ordering itself, requiring no extra axioms about the symbols), and rewriting with any rule strictly decreases every term in this order, **no infinite rewrite sequence exists**. Hence the system is terminating, established entirely from the given rules using a standard, non-strengthening proof technique.
