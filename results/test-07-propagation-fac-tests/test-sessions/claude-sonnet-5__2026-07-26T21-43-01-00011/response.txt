## Verdict

**Yes.** Termination of this system can be established from the rules alone, using the **Dependency Pair (DP) Framework** (Arts–Giesl) together with elementary monotone polynomial interpretations for each resulting cycle. No extra rules, guards, or side conditions are needed — only the standard DP machinery (dependency pairs, the CAP‑based dependency graph estimate, usable rules, reduction pairs), applied directly to the eight given rules.

A naive attempt with a single global polynomial interpretation fails: rule `p(s(s(x))) -> s(p(s(x)))` forces the interpretation of `p` to be *expanding* (coefficient > 1) to get strict decrease, while the call `fac(p(s(x)))` in rule 8 would then need `p` to be *contracting*. This conflict is exactly why the DP framework (which lets each cycle be handled by its own tailored order) is the right tool here.

## Dependency pairs

- **D1** self‑loops (`PLUS→PLUS`); no other connections.
- **D3** self‑loops (`TIMES→TIMES`); **D2→D1**, **D3→D2** but nothing returns to D2/D3’s cycle, so D2 is a trivial (acyclic) node.

## Discharging each SCC

- **{D1}:** interpret via projection to 2nd argument, `[s](y)=y+1`. Need `y+1 > y`: trivial. No usable rules (target is a bare variable).
- **{D3}:** projection to 1st argument, `[s](x)=x+1`. Need `x+1 > x`: trivial. No usable rules.
- **{D4}:** identity interpretation on the argument, `[s](x)=x+1`. Need `x+2 > x+1`: trivial. `s` has no defining rules, so no usable‑rule obligation.
- **{D6}** (the crux, covering rule 8's recursive call together with rules 6–7 as usable rules): use
  - `β(0)=0`, `β(s(t))=β(t)+1`, `β(p(t)) = max(β(t)-1, 0)` (a monotone, total N‑valued algebra).

  *Strict decrease of D6:* `β(s(x)) = β(x)+1`, and `β(p(s(x))) = max(β(x)+1-1,0) = β(x)`. Since `β(x)+1 > β(x)` for every natural number `β(x)`, this holds for **every** term `x`, not just numerals.

  *Usable rules (6,7) weakly compatible:*
  - Rule 6: `β(p(s(s(x)))) = β(x)+1 = β(s(p(s(x))))` — equal, hence `≥`.
  - Rule 7: `β(p(s(0))) = 0 = β(0)` — equal, hence `≥`.

  Monotonicity of `s` (`+1`) and `p` (`max(·-1,0)`) is immediate.
