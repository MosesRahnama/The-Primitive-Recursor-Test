The dependency pair framework is a standard, syntax-driven technique that operates entirely within the first-order term rewriting system. It transforms the original rules into a new set of pairs whose termination implies the termination of the original system, without adding any new rewrite rules, guards or side conditions to the original TRS. This verification is an external proof obligation; it does not modify the rewrite system itself and does not rely on any object-level axioms beyond what is already present in the given syntax and rules.

The fact that some constructors (p(0), fac(0)) have no defining rules is immaterial; termination proofs via interpretations only care about the rewrite relation on terms that can actually be rewritten, and the chosen interpretation still strictly decreases on every applicable rule.
