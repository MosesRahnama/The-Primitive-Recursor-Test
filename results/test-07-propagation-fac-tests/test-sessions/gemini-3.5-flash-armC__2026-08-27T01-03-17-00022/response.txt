### Reasoning

The term rewriting system (TRS) defines standard arithmetic operations over Peano natural numbers:
* `plus` defines addition.
* `times` defines multiplication.
* `p` defines the predecessor function (where $p(s(s(x))) \to s(p(s(x)))$ and $p(s(0)) \to 0$).
* `fac` defines the factorial function.

#### Why Simple Path Orderings Fail Directly
A simple Lexicographic Path Ordering (LPO) or Recursive Path Ordering (RPO) cannot prove termination directly due to a conflict in the precedence of the function symbols:
1. The rule `p(s(s(x))) -> s(p(s(x)))` requires $p \succ s$ in the precedence.
2. The rule `fac(s(x)) -> times(fac(p(s(x))), s(x))` requires $s(x) \succ p(s(x))$, which would typically require $s \succ p$.

#### How Termination is Established
Termination can be proved purely from the rules using standard, automated TRS termination techniques, such as the **Dependency Pair (DP) Framework** combined with polynomial interpretations or semantic labeling:

1. **Dependency Pairs:**
   The critical dependency pair loop is:
   $$\text{FAC}(s(x)) \to \text{FAC}(p(s(x)))$$
2. **Reduction Pair / Polynomial Interpretation:**
   By analyzing the dependency graph, we can orient the rules using a reduction pair $(\ge, >)$ where the rewriting rules are weakly decreasing ($\ge$) and the dependency pairs are strictly decreasing ($>$). 
   
   Using an appropriate polynomial interpretation (or matrix interpretation) over the natural numbers, we can assign a measure to the terms such that the argument of `fac` strictly decreases with each recursive call because of the predecessor function `p`. Specifically, we can map:
   * $[0] = 1$
   * $[s](x) = x + 2$
   * $[p](x) = x - 1$ (for $x \ge 2$)

   Under this interpretation, the rules remain well-defined, and the argument of `FAC` strictly decreases from $[s(x)] = x + 2$ to $[p(s(x))] = x + 1$. 

Thus, the system is strongly normalizing (terminating), and this can be established purely through syntactic and structural analysis of the rules themselves without any external assumptions.
