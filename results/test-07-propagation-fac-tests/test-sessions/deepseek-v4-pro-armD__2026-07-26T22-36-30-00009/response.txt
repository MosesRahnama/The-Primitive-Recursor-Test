**Termination argument:**
We use the **recursive path ordering (RPO)** with a partial precedence on the function symbols. Define the precedence as follows:

- `times > plus > s`
- `p > s`
- All function symbols are greater than the constant `0` (i.e., `s > 0`, `p > 0`, `plus > 0`, `times > 0`).

The symbols `plus` and `p` (as well as `times` and `p`) are left incomparable; this does not affect the proof because no rule has a top-level conflict requiring their comparison.

Under RPO, every term is strictly greater than its proper subterms, and the ordering is stable under substitution and well-founded. We check each rule:

1. **`plus(x, 0) -> x`**  
   `x` is a direct subterm of `plus(x, 0)`, so `plus(x, 0) > x` by the subterm property.

2. **`plus(x, s(y)) -> s(plus(x, y))`**  
   The top symbol `plus` is greater than `s`. We must also have `plus(x, s(y))` greater than the argument of `s`, namely `plus(x, y)`. This holds because both have the same top symbol `plus`, the first argument `x` is unchanged, and `s(y) > y` (subterm). Hence `plus(x, s(y)) > s(plus(x, y))`.

3. **`times(0, y) -> 0`**  
   `0` is a direct subterm, so `times(0, y) > 0`.

4. **`times(x, 0) -> 0`**  
   Same reasoning: `0` is a subterm, so `times(x, 0) > 0`.

5. **`times(s(x), y) -> plus(times(x, y), y)`**  
   Top symbol `times > plus`. We check the arguments of `plus`:
   - `times(s(x), y) > times(x, y)` (same top symbol, `s(x) > x` by subterm, second argument equal).
   - `times(s(x), y) > y` (subterm).  
   Thus the strict decrease holds.

6. **`p(s(s(x))) -> s(p(s(x)))`**  
   Top symbol `p > s`. We compare with the argument `p(s(x))`:
   - `p(s(s(x))) > p(s(x))` holds because both have the top symbol `p` and the argument `s(s(x)) > s(x)` (subterm).  
   Hence `p(s(s(x))) > s(p(s(x)))`.

7. **`p(s(0)) -> 0`**  
   Since `p > s > 0`, we have `p > 0`, and therefore `p(s(0)) > 0`.

Every rewrite rule is strictly decreasing in this RPO. Because RPO is a simplification order, the system is terminating. No external axioms, extra rewrite rules, or side conditions are needed.
