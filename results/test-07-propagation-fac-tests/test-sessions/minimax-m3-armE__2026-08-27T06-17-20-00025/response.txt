## Termination Argument

The system is a definitional recursion on the third argument of `F`, which is built from the constructors `Z` and `S` (i.e., a unary encoding of the natural numbers). Rule R2 strips one `S` from the third argument and rebuilds the term around a recursive call on a strictly smaller third argument. Rule R1 is the base case. `G` is a constructor (no rules mention `G`), so it can never re-trigger `F`-reduction on its own.

**Measure.** Let `|t|` denote the syntactic size of a term (each variable counts 1, each function symbol counts 1, plus the sizes of its arguments). The key observation is:

- `|F(x, y, S(n))| = |x| + |y| + |S(n)| + 1 = |x| + |y| + |n| + 2`
- `|F(x, y, n)| = |x| + |y| + |n| + 1`

So the recursive call in R2 is one symbol smaller than the redex. Moreover, every proper subterm of a redex is strictly smaller.

**Proof (strong induction on |t| that every term t terminates).**

*Induction hypothesis:* every term smaller than `t` terminates (i.e., admits no infinite reduction).

*Inductive step, cases on the form of `t`:*

1. **`t` is a normal form** (`Z`, `S(…)`, a variable, or `G(s, u)` — note `G` has no defining rule): then `t` terminates in 0 steps.

2. **`t = F(s, u, Z)`** (rule R1 applies). Then `t → s`. Since `s` is a proper subterm of `t`, `|s| < |t|`, so by IH `s` terminates; hence `t` terminates.

3. **`t = F(s, u, S(w))`** (rule R2 applies). Then `t → G(u, F(s, u, w))`. The subterm `F(s, u, w)` is strictly smaller than `t` (the `S` wrapper is removed, lowering the size by 1), so by IH `F(s, u, w)` reduces to some normal form `nf`. Therefore
   `G(u, F(s, u, w))  →*  G(u, nf)`.
   Since `G` has no rewrite rule, `G(u, nf)` is a normal form, so the right-hand side terminates; hence `t` terminates.

4. **No other redex shapes are possible** (the only defined symbol with rules is `F`, and its only redex positions require the third argument to be `Z` or `S(w)`).

By induction, every term in the system terminates. ∎

**Address of every rule:**
- **R1** decreases the size by passing to a proper subterm (`x` is a subterm of `F(x,y,Z)`).
- **R2** decreases the size of the recursive call (`F(x,y,n)` is one symbol smaller than `F(x,y,S(n))`), and the surrounding `G` is a constructor with no further rules, so it cannot fuel infinite re-expansion.

No additional rewrite rules, guards, side conditions, or hidden assumptions are needed; the argument uses only the syntax of the given terms and the two stated rules.
