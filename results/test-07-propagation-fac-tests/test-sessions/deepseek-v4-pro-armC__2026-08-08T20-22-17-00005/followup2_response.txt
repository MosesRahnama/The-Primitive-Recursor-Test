I chose those methods (polynomial interpretations for dependency pairs or a recursive path ordering) because they work directly on the given rules without importing any extra axioms, weakening the system, or adding hidden assumptions.

- Polynomial interpretations assign a natural-number weight to each term, derived solely from the syntax and rules; no external arithmetic facts are assumed, only the built-in order on natural numbers (which is part of the termination method, not an object-level axiom).
- Recursive path ordering (RPO) uses only the syntactic structure and a precedence on function symbols; it never needs extra rules or equational theories.
- Dependency pairs reduce termination to showing that recursive calls are smaller; the decrease can be proven by a reduction order (like a polynomial or RPO) that treats `plus`, `times`, `p`, and `fac` as ordinary functions with no added semantics.

Since all recursion is structural and the rules define the functions completely, these methods require nothing beyond what is already in the rewrite system. No strengthening or hidden assumptions are introduced.
