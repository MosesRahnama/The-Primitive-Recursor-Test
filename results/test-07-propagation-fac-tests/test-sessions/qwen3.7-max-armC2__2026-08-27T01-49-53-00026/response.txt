## Assessment: **Yes, termination can be established.**

### Reasoning

The system defines predecessor (`p`), addition (`plus`), multiplication (`times`), and factorial (`fac`). Each function's termination can be analyzed via its recursive structure:

**1. `plus` terminates:** Rule 2 decreases the second argument structurally (`s(y) → y`).

**2. `times` terminates:** Rule 5 decreases the first argument structurally (`s(x) → x`). The duplication of `y` in the RHS is bounded because the recursive call `times(x, y)` has a strictly smaller first argument.

**3. `p` terminates:** Rule 6 reduces the argument to `p` from `s(s(x))` to `s(x)` (a proper subterm), so the argument size strictly decreases.

**4. `fac` terminates (the critical case):** Rule 8 makes the recursive call `fac(p(s(x)))`. The key observation is a **bounded chain argument**:

For the `fac` dependency pair `FAC(s(x)) → FAC(p(s(x)))` to chain to another `fac` call, `p(s(x))` must reduce to some `s(x')`. This requires `x = s(y)`, triggering `p(s(s(y))) → s(p(s(y)))`, yielding `x' = p(s(y))`. For the chain to continue *again*, `y` must itself be `s(z)`, and so on.

Each link in a `fac`-chain consumes one `s` from the top of the original argument. Since any term has only finitely many `s`-layers at the top, every `fac`-chain is finite. For non-ground terms (e.g., `fac(s(x))` with `x` a variable), `p(s(x))` is already in normal form and the chain stops immediately.

**No external axioms are needed:** The rules themselves fully define the behavior of all symbols. Terms like `p(0)` or `fac(0)` are simply normal forms—the system is defined for all terms, not just well-formed numerals, and terminates on all of them.

**Proof technique:** A formal proof can be constructed using the **Dependency Pair framework** combined with a **size-change termination** argument (or a well-founded ordering tracking the `s`-depth of `fac`'s argument). Standard polynomial interpretations alone are insufficient (since `p(s(s(x))) = s(p(s(x)))` semantically, making strict decrease impossible under monotone polynomial interpretations of `p`), but the size-change principle or argument filtering with a custom well-founded order handles the `fac` SCC without importing any object-level assumptions.
