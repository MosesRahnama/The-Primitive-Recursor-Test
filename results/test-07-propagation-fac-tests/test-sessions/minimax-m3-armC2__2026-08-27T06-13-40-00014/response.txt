**Reasoning:**

Termination can be established from the rewrite system alone, using only standard termination techniques applied to the given rules — no external axioms (Peano arithmetic, etc.) are required.

The system is essentially a well-founded recursive definition of `plus`, `times`, `p` (predecessor), and `fac` (factorial). One can prove termination as follows:

1. **`plus` and `times`**: Each recursive call operates on a strictly smaller argument in a well-founded position (the second argument for `plus`, the first for `times`). The base cases `plus(x,0)→x`, `times(0,y)→0`, `times(x,0)→0` terminate trivially. A lexicographic path order (LPO) with precedence `times > plus > s > 0` (plus as a strict subterm/lexicographic argument) handles these.

2. **`p`**: Each rule decreases the structural size of the argument. `p(s(0))→0` is immediate. `p(s(s(x)))→s(p(s(x)))` reduces `s(s(x))` to `s(p(s(x)))`, where the recursive call `p(s(x))` is on a smaller term than `s(s(x))`. This is provable via LPO with `p > s`.

3. **`fac`**: The critical rule is `fac(s(x)) → times(fac(p(s(x))), s(x))`. The recursive call is on `p(s(x))`. From the rules for `p` one can derive (by structural induction on the term structure) that `p(s(x))` is strictly smaller than `s(x)` in the well-founded ordering induced by the `p`-rules — equivalently, `p(s(x))` rewrites (in zero or more steps) to a term that is a proper structural subterm of `s(x)`. This is a derivable fact from the rules themselves, not an imported axiom.

   A standard way to formalize this: use the dependency pair method. The only relevant dependency pair is `fac(s(x)) ≫ fac(p(s(x)))`. The constraint `p(s(x)) ≺ s(x)` is discharged by the rules for `p`, which show that `p(s(x))` is reducible to a term strictly smaller than `s(x)` in the LPO/subterm ordering.

No object-level facts (e.g., that `0` denotes zero, that `s` is the Peano successor, that `p(n)=n-1`, etc.) are needed — only the syntactic structure of the rules and a well-founded order compatible with them.
