## Termination Argument (Lexicographic Path Order)

I apply the **Lexicographic Path Order (LPO)** with the following strict precedence on the function symbols:

$$\text{times} > \text{plus} > p > s > 0$$

This precedence defines a well-founded rewrite order on ground terms (and extends to terms with variables by stability under substitution). I verify that every rule is strictly decreasing under LPO.

### Rule-by-Rule Verification

**Rule 1:** `plus(x, 0) → x`
- The RHS `x` is a proper subterm of the LHS, so LPO yields `plus(x, 0) > x`. ✓

**Rule 2:** `plus(x, s(y)) → s(plus(x, y))`
- Top symbols: `plus > s` in the precedence.
- Need LHS `> plus(x, y)` (the argument of the RHS's top symbol).
- Comparing `plus(x, s(y))` vs `plus(x, y)`: same top symbol `plus`, so lexicographic comparison of argument lists: `(x, s(y))` vs `(x, y)`.
- The second components: `s(y) > y` (since `y` is a proper subterm of `s(y)`).
- Also LHS `> x` and LHS `> y` (both are subterms). ✓

**Rule 3:** `times(0, y) → 0`
- The RHS `0` is a subterm. ✓

**Rule 4:** `times(x, 0) → 0`
- The RHS `0` is a subterm. ✓

**Rule 5:** `times(s(x), y) → plus(times(x, y), y)`
- Top symbols: `times > plus`.
- Need LHS `> times(x, y)` and LHS `> y` (the RHS's arguments).
- `times(s(x), y) > y`: `y` is a subterm. ✓
- `times(s(x), y) > times(x, y)`: same top `times`, lexicographic `(s(x), y) >_{lex} (x, y)`, which holds because `s(x) > x` (`x` is a subterm of `s(x)`). The required subterm conditions `> x` and `> y` also hold. ✓

**Rule 6:** `p(s(s(x))) → s(p(s(x)))`
- Top symbols: `p > s`.
- Need LHS `> p(s(x))` (the argument of the RHS's top symbol).
- `p(s(s(x))) > p(s(x))`: same top `p`, lexicographic `(s(s(x))) >_{lex} (s(x))`, which requires `s(s(x)) > s(x)`.
- `s(s(x)) > s(x)`: same top `s`, lexicographic `(s(x)) >_{lex} (x)`, since `s(x) > x` (`x` is a subterm). The required subterm condition `> x` also holds (deep subterm). ✓

**Rule 7:** `p(s(0)) → 0`
- The RHS `0` is a subterm. ✓

### Conclusion

Every rule of the system is strictly oriented by the LPO with the precedence $\text{times} > \text{plus} > p > s > 0$. Since LPO is a well-founded reduction order on the term algebra, the rewrite system is **terminating**. No additional axioms, side conditions, or rewrite rules were introduced — the proof uses only the given syntax and the LPO construction.
