# Termination Assessment: **YES, the system terminates.**

## Termination Argument

The proof proceeds via the **dependency pair framework** combined with a **semantic value interpretation** that is invariant under all rewrite rules.

---

### Step 1: A Value-Preserving Semantic Interpretation

Define an interpretation $V$ on ground terms over the signature (extended with fresh constants $c$ for variables, assigned any $V(c) \in \mathbb{N}$):

| Term | $V$ |
|------|-----|
| $V(0)$ | $= 0$ |
| $V(s(t))$ | $= V(t) + 1$ |
| $V(p(t))$ | $= \max(0,\; V(t) - 1)$ |
| $V(\text{plus}(t_1, t_2))$ | $= V(t_1) + V(t_2)$ |
| $V(\text{times}(t_1, t_2))$ | $= V(t_1) \cdot V(t_2)$ |
| $V(\text{fac}(t))$ | $= V(t)!$ |

**Claim:** Every rewrite rule preserves $V$. Verification:

1. **plus(x, 0) → x:** $V(x)+0 = V(x)$. ✓
2. **plus(x, s(y)) → s(plus(x, y)):** $V(x)+V(y)+1 = V(x)+V(y)+1$. ✓
3. **times(0, y) → 0:** $0\cdot V(y) = 0$. ✓
4. **times(x, 0) → 0:** $V(x)\cdot 0 = 0$. ✓
5. **times(s(x), y) → plus(times(x, y), y):** $(V(x)+1)\cdot V(y) = V(x)\cdot V(y) + V(y)$. ✓
6. **p(s(s(x))) → s(p(s(x))):** $\max(0, V(x)+2-1) = V(x)+1$, and $\max(0, V(x)+1-1)+1 = V(x)+1$. ✓
7. **p(s(0)) → 0:** $\max(0, 1-1) = 0$. ✓
8. **fac(s(x)) → times(fac(p(s(x))), s(x)):** $(V(x)+1)! = V(p(s(x)))! \cdot (V(x)+1) = V(x)! \cdot (V(x)+1) = (V(x)+1)!$. ✓

Since all rules preserve $V$, any rewrite sequence $t \to^* t'$ satisfies $V(t) = V(t')$.

---

### Step 2: Dependency Pairs

The defined symbols are **plus, times, p, fac**. The dependency pairs are:

| DP | Pair |
|----|------|
| DP1 | $\text{PLUS}^\#(x, s(y)) \to \text{PLUS}^\#(x, y)$ |
| DP2 | $\text{TIMES}^\#(s(x), y) \to \text{TIMES}^\#(x, y)$ |
| DP3 | $\text{TIMES}^\#(s(x), y) \to \text{PLUS}^\#(\text{times}(x, y), y)$ |
| DP4 | $\text{P}^\#(s(s(x))) \to \text{P}^\#(s(x))$ |
| DP5 | $\text{FAC}^\#(s(x)) \to \text{FAC}^\#(p(s(x)))$ |
| DP6 | $\text{FAC}^\#(s(x)) \to \text{TIMES}^\#(\text{fac}(p(s(x))), s(x))$ |
| DP7 | $\text{FAC}^\#(s(x)) \to \text{P}^\#(s(x))$ |

---

### Step 3: All DP Chains Are Finite

An infinite chain requires substitutions $\sigma_i$ such that the RHS of one DP rewrites (below the root) to match the LHS of the next. For each possible cycle or path:

**DP1 chains:** $\text{PLUS}^\#(x, s(y)) \to \text{PLUS}^\#(x, y)$. The chain condition requires $y\sigma_i \to^* s(y\sigma_{i+1})$. Since rewriting preserves $V$:
$$V(y\sigma_i) = V(s(y\sigma_{i+1})) = V(y\sigma_{i+1}) + 1$$
Thus $V(y\sigma_{i+1}) = V(y\sigma_i) - 1$. This strictly decreasing sequence of natural numbers must be finite. ✓

**DP2 chains:** $\text{TIMES}^\#(s(x), y) \to \text{TIMES}^\#(x, y)$. Analogously, $V(x\sigma_{i+1}) = V(x\sigma_i) - 1$. Finite. ✓

**DP4 chains:** $\text{P}^\#(s(s(x))) \to \text{P}^\#(s(x))$. Chain condition: $s(x\sigma_i) \to^* s(s(x\sigma_{i+1}))$, so $V(x\sigma_i)+1 = V(x\sigma_{i+1})+2$, giving $V(x\sigma_{i+1}) = V(x\sigma_i) - 1$. Finite. ✓

**DP5 chains (the critical case):** $\text{FAC}^\#(s(x)) \to \text{FAC}^\#(p(s(x)))$. The chain condition requires:
$$p(s(x\sigma_i)) \to^* s(x\sigma_{i+1})$$
Since rewriting preserves $V$:
$$V(p(s(x\sigma_i))) = V(s(x\sigma_{i+1}))$$
For any ground term $t$ with $V(t) \geq 0$:
$$V(p(s(t))) = \max(0,\; V(t)+1-1) = V(t)$$
And $V(s(u)) = V(u) + 1$. Therefore:
$$V(x\sigma_i) = V(x\sigma_{i+1}) + 1 \implies V(x\sigma_{i+1}) = V(x\sigma_i) - 1$$
This strictly decreasing sequence of natural numbers must be finite. ✓

**DP3** transitions to PLUS# (DP1), which is finite. ✓
**DP6** is a dead end: $\text{fac}(\dots)$ never rewrites to a term rooted by $s$ (it produces $\text{times}$, which can produce $\text{plus}$, which can produce $s$, but the chain gets stuck when $\text{fac}(0)$ is reached since $\text{fac}(0)$ is a normal form that matches neither $0$ nor $s(\dots)$). ✓
**DP7** transitions to P# (DP4), which is finite. ✓

---

### Step 4: Conclusion

The dependency graph has the following structure of strongly connected components:

$$\{\text{FAC}^\#\} \longrightarrow \{\text{TIMES}^\#\} \longrightarrow \{\text{PLUS}^\#\}$$
$$\{\text{FAC}^\#\} \longrightarrow \{\text{P}^\#\}$$

Every SCC admits only finite chains (each step strictly decreases a natural number derived from $V$), and all inter-SCC transitions are one-way. Therefore, **no infinite dependency chain exists**, and the term rewriting system **terminates**.
