### Verdict
Yes, termination is established from the rules alone (via the lexicographic path order, a standard simplification order).

### Termination Argument
Consider the lexicographic path order (LPO) induced by the precedence
\[
\texttt{times} > \texttt{plus} > \texttt{s} > 0
\]
on the signature (with lexicographic status for the binary symbols, left-to-right). This is a well-founded simplification order on terms, so it suffices to check that every rule is oriented strictly left-to-right. (Variables are incomparable with everything except themselves; the order is stable under substitution.)

- Rule \(\texttt{times}(x,0)\to 0\): the left-hand side has root \(\texttt{times}\) which is strictly above the constant \(0\), so the inequality holds.
- Rule \(\texttt{times}(x,\texttt{s}(y))\to\texttt{plus}(\texttt{times}(x,y),x)\): the left-hand root \(\texttt{times}\) is strictly above the right-hand root \(\texttt{plus}\). It remains only to verify that the left-hand side strictly exceeds each immediate argument of the right-hand side:
  - \(\texttt{times}(x,\texttt{s}(y))>\texttt{times}(x,y)\) holds by the lexicographic comparison of arguments (first arguments identical, second arguments satisfy \(\texttt{s}(y)>y\));
  - \(\texttt{times}(x,\texttt{s}(y))>x\) holds because \(x\) is an immediate argument of the left-hand side.
- Rule \(\texttt{plus}(x,0)\to x\): the left-hand side has root \(\texttt{plus}\) and \(x\) is one of its immediate arguments, so the inequality holds.
- Rule \(\texttt{plus}(0,x)\to x\): identical reasoning to the previous case.
- Rule \(\texttt{plus}(x,\texttt{s}(y))\to\texttt{s}(\texttt{plus}(x,y))\): the left-hand root \(\texttt{plus}\) is strictly above the right-hand root \(\texttt{s}\). It remains only to verify \(\texttt{plus}(x,\texttt{s}(y))>\texttt{plus}(x,y)\), which holds by the lexicographic comparison of arguments (first arguments identical, second arguments satisfy \(\texttt{s}(y)>y\)).
- Rule \(\texttt{plus}(\texttt{s}(x),y)\to\texttt{s}(\texttt{plus}(x,y))\): the left-hand root \(\texttt{plus}\) is strictly above the right-hand root \(\texttt{s}\). It remains only to verify \(\texttt{plus}(\texttt{s}(x),y)>\texttt{plus}(x,y)\), which holds by the lexicographic comparison of arguments (first arguments satisfy \(\texttt{s}(x)>x\), second arguments identical).

Every rule decreases in the order. Consequently there are no infinite rewrite sequences.
