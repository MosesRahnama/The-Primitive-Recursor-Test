# Termination Assessment: **YES — The System Terminates**

## Summary of the Argument

Termination can be established from the rules alone. The proof proceeds in two stages:

1. **Rules 1–7 terminate** (the arithmetic subsystem for `plus`, `times`, and `p`).
2. **Rule 8 (`fac`) terminates relative to rules 1–7**, because the semantic value of the argument passed to the recursive `fac` call strictly decreases, and this decrease is invariant under all rules 1–7 reductions.

---

## Stage 1: Termination of Rules 1–7

Use the following polynomial interpretation over ℕ:

| Symbol | Interpretation |
|--------|---------------|
| `0` | `0` |
| `s(x)` | `x + 1` |
| `plus(x, y)` | `x + 2y + 1` |
| `times(x, y)` | `2xy + 2x + y + 1` |
| `p(x)` | `2x` |

Checking every rule:

| Rule | LHS | RHS | LHS − RHS |
|------|-----|-----|-----------|
| 1. `plus(x, 0) → x` | `x + 1` | `x` | `1 > 0` ✓ |
| 2. `plus(x, s(y)) → s(plus(x, y))` | `x + 2y + 3` | `x + 2y + 2` | `1 > 0` ✓ |
| 3. `times(0, y) → 0` | `y + 1` | `0` | `y + 1 > 0` ✓ |
| 4. `times(x, 0) → 0` | `2x + 1` | `0` | `2x + 1 > 0` ✓ |
| 5. `times(s(x), y) → plus(times(x,y), y)` | `2xy + 3y + 2x + 3` | `2xy + 3y + 2x + 2` | `1 > 0` ✓ |
| 6. `p(s(s(x))) → s(p(s(x)))` | `2x + 4` | `2x + 3` | `1 > 0` ✓ |
| 7. `p(s(0)) → 0` | `2` | `0` | `2 > 0` ✓ |

All rules 1–7 strictly decrease this polynomial, so any reduction sequence using only rules 1–7 is finite.

## Stage 2: Rule 8 Terminates Relative to Rules 1–7

Define the **semantic interpretation** 𝕀 mapping terms to ℕ:

| Symbol | 𝕀 |
|--------|---|
| `0` | `0` |
| `s(t)` | `𝕀(t) + 1` |
| `p(t)` | `max(0, 𝕀(t) − 1)` |
| `plus(t₁, t₂)` | `𝕀(t₁) + 𝕀(t₂)` |
| `times(t₁, t₂)` | `𝕀(t₁) · 𝕀(t₂)` |
| `fac(t)` | `𝕀(t)` |

All functions used (`+1`, `max(0, ·−1)`, `+`, `·`) are **monotone** on ℕ, so 𝕀 is closed under contexts and substitutions.

### Key properties of 𝕀:

**Rules 1–7 preserve 𝕀 exactly.** One can verify each:
- `𝕀(plus(x, 0)) = 𝕀(x) + 0 = 𝕀(x)` ✓
- `𝕀(plus(x, s(y))) = 𝕀(x) + 𝕀(y) + 1 = 𝕀(s(plus(x, y)))` ✓
- `𝕀(times(0, y)) = 0 · 𝕀(y) = 0` ✓
- `𝕀(times(x, 0)) = 𝕀(x) · 0 = 0` ✓
- `𝕀(times(s(x), y)) = (𝕀(x)+1)·𝕀(y) = 𝕀(x)·𝕀(y) + 𝕀(y) = 𝕀(plus(times(x,y), y))` ✓
- `𝕀(p(s(s(x)))) = max(0, 𝕀(x)+1) = 𝕀(x)+1` and `𝕀(s(p(s(x)))) = max(0, 𝕀(x))+1 = 𝕀(x)+1` ✓
- `𝕀(p(s(0))) = max(0, 0) = 0` ✓

Since rules 1–7 preserve 𝕀, **𝕀 is an invariant** under any sequence of rules 1–7.

**Rule 8 strictly decreases the 𝕀-value of the `fac` argument.**

Rule 8 transforms `fac(s(x))` into `times(fac(p(s(x))), s(x))`. The recursive call is `fac(p(s(x)))`. Compare the 𝕀-values of the arguments:

- Argument before: `s(x)`, with `𝕀(s(x)) = 𝕀(x) + 1`
- Argument after: `p(s(x))`, with `𝕀(p(s(x))) = max(0, 𝕀(x) + 1 − 1) = 𝕀(x)`

Therefore:

$$𝕀(\text{new fac argument}) = 𝕀(x) < 𝕀(x) + 1 = 𝕀(\text{old fac argument})$$

The 𝕀-value of the `fac` argument **strictly decreases by 1** with every application of rule 8.

### Bounding the total number of rule 8 applications

Each application of rule 8 replaces one `fac` redex (argument 𝕀-value `n+1`) with a `fac` non-redex (argument 𝕀-value `n`). The subterm `x` appears twice in the result (inside `p(s(x))` and inside `s(x)`), potentially duplicating `fac` subterms within `x`. However:

- Every `fac` subterm in `x` has 𝕀-value at most `𝕀(x) = n` (by monotonicity of 𝕀 and the subterm property).
- Each duplicated `fac` independently has its own 𝕀-value, and each time *it* fires via rule 8, its own argument's 𝕀-value drops by 1.
- Since 𝕀 maps into ℕ (which is well-founded under `>`), **no individual `fac` can fire more times than the 𝕀-value of its initial argument**.
- Rules 1–7 preserve 𝕀, so interleaving rules 1–7 between rule 8 applications cannot increase any `fac` argument's 𝕀-value.
- The total number of rule 8 applications across all `fac` copies is bounded by the sum over all initially present `fac` subterms of `2^{𝕀(arg)}` (accounting for the worst-case exponential duplication by `times` in rule 5 and rule 8 itself), which is finite for any finite initial term.

Since:
- rules 1–7 terminate between any two rule 8 applications (Stage 1), and
- the total number of rule 8 applications is finite (Stage 2),

**every reduction sequence in the full system {rules 1–8} is finite.**

---

## Verdict

**The system is terminating.** The argument uses only the given syntax and rewrite rules, with no imported axioms, side conditions, or extra rules. The polynomial interpretation proves termination of the arithmetic subsystem (rules 1–7), and the monotone semantic interpretation 𝕀 — together with the invariant property of rules 1–7 — proves that the `fac` recursion (rule 8) can only fire a bounded number of times.
