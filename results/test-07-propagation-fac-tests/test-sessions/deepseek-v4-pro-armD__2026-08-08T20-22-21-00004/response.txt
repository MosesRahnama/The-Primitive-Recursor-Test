**Interpretation:**
\[
\begin{aligned}
\llbracket 0 \rrbracket &= 0\\
\llbracket s(x) \rrbracket &= x + 1\\
\llbracket plus(x, y) \rrbracket &= x + 2y + 1\\
\llbracket times(x, y) \rrbracket &= 2(x+1)(y+1) = 2xy + 2x + 2y + 2\\
\llbracket p(x) \rrbracket &= 2x
\end{aligned}
\]
All interpretation functions are polynomials with non‑negative coefficients, so they are weakly monotone (compatible with contexts) and yield natural numbers for all natural‑number assignments to variables.

**Rule‑by‑rule check for strict decrease (\(\llbracket l \rrbracket > \llbracket r \rrbracket\)):**

1. **plus(x, 0) → x**  
   \(\llbracket plus(x,0) \rrbracket = x + 2\cdot 0 + 1 = x+1 > x = \llbracket x \rrbracket\)

2. **plus(x, s(y)) → s(plus(x, y))**  
   \(\llbracket plus(x,s(y)) \rrbracket = x + 2(y+1) + 1 = x + 2y + 3\)  
   \(\llbracket s(plus(x,y)) \rrbracket = (x + 2y + 1) + 1 = x + 2y + 2\)  
   \(x + 2y + 3 > x + 2y + 2\)

3. **times(0, y) → 0**  
   \(\llbracket times(0,y) \rrbracket = 2(0+1)(y+1) = 2y+2 > 0 = \llbracket 0 \rrbracket\)

4. **times(x, 0) → 0**  
   \(\llbracket times(x,0) \rrbracket = 2(x+1)(0+1) = 2x+2 > 0 = \llbracket 0 \rrbracket\)

5. **times(s(x), y) → plus(times(x, y), y)**  
   \(\llbracket times(s(x),y) \rrbracket = 2((x+1)+1)(y+1) = 2(x+2)(y+1) = 2xy + 2x + 4y + 4\)  
   \(\llbracket plus(times(x,y),\,y) \rrbracket = \llbracket times(x,y) \rrbracket + 2y + 1 = (2xy + 2x + 2y + 2) + 2y + 1 = 2xy + 2x + 4y + 3\)  
   \(2xy + 2x + 4y + 4 > 2xy + 2x + 4y + 3\)

6. **p(s(s(x))) → s(p(s(x)))**  
   \(\llbracket p(s(s(x))) \rrbracket = 2((x+1)+1) = 2x+4\)  
   \(\llbracket s(p(s(x))) \rrbracket = 2(x+1) + 1 = 2x+3\)  
   \(2x+4 > 2x+3\)

7. **p(s(0)) → 0**  
   \(\llbracket p(s(0)) \rrbracket = 2(0+1) = 2 > 0 = \llbracket 0 \rrbracket\)

Every rule strictly decreases the interpretation.  Because the underlying well‑founded order (the natural numbers with `>`) is compatible with the monotone term‑formation operations, every rewrite step decreases the interpretation, forbidding infinite rewrite sequences.  Hence the system is terminating.
