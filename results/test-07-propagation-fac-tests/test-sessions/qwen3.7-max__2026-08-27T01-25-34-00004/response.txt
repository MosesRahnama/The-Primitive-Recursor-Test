# Termination Assessment: **YES — The System Terminates**

## Overview of the Proof Method

I use the **Dependency Pair (DP) framework** (Arts & Giesl). The key insight is that the system correctly implements arithmetic (addition, multiplication, predecessor, factorial), and the semantic value of terms — evaluated with variables set to 0 — provides a strictly decreasing measure for the only non-trivial recursive cycle.

---

## Step 1: Compute Dependency Pairs

The defined symbols are `plus`, `times`, `p`, `fac`. Marking them (with `#`) at the root of each relevant subterm in right-hand sides yields:

| DP | Rule Source | Dependency Pair |
|----|------------|-----------------|
| 1 | Rule 2 | `plus#(x, s(y)) → plus#(x, y)` |
| 2 | Rule 5 | `times#(s(x), y) → plus#(times(x, y), y)` |
| 3 | Rule 5 | `times#(s(x), y) → times#(x, y)` |
| 4 | Rule 6 | `p#(s(s(x))) → p#(s(x))` |
| 5 | Rule 8 | `fac#(s(x)) → times#(fac(p(s(x))), s(x))` |
| 6 | Rule 8 | `fac#(s(x)) → fac#(p(s(x)))` |
| 7 | Rule 8 | `fac#(s(x)) → p#(s(x))` |

---

## Step 2: Dependency Graph and SCCs

Analyzing which DPs can chain to which (i.e., whether the RHS of one DP can rewrite to match the LHS of another):

- **DP1** → DP1 (if `y` has form `s(y')`).
- **DP2** → DP1 only.
- **DP3** → DP2, DP3 (if `x` has form `s(x')`).
- **DP4** → DP4 (if `x` has form `s(x')`).
- **DP5** → **nothing**. The RHS is `times(fac(p(s(x))), s(x))`. For this to chain to any DP, the first argument `fac(p(s(x)))` would need to rewrite to a term rooted at `s` or `0`. By induction on the semantic value (defined below), `fac(t)` only ever rewrites to terms rooted at `fac` or `times` — never `s`, `0`, `plus`, or `p`. Hence no root-level rule (3, 4, or 5) ever fires on `times(fac(…), …)`, so it can never reshape to match any DP left-hand side.
- **DP6** → DP5, DP6, DP7 (if `p(s(x))` rewrites to `s(x')`).
- **DP7** → DP4 only.

The **strongly connected components** (SCCs) are:

| SCC | Members |
|-----|---------|
| A | {DP1} |
| B | {DP3} |
| C | {DP4} |
| D | {DP6} |

All other DPs (2, 5, 7) are acyclic and lead only into these SCCs.

---

## Step 3: Terminate Each SCC

### SCC A: `plus#(x, s(y)) → plus#(x, y)`
The second argument decreases from `s(y)` to `y` (strict subterm). **Terminating.**

### SCC B: `times#(s(x), y) → times#(x, y)`
The first argument decreases from `s(x)` to `x` (strict subterm). **Terminating.**

### SCC C: `p#(s(s(x))) → p#(s(x))`
The argument decreases from `s(s(x))` to `s(x)` (strict subterm). **Terminating.**

### SCC D: `fac#(s(x)) → fac#(p(s(x)))` — the critical case

Define the **evaluation function** `E(t)` into ℕ (natural numbers) by interpreting every variable as 0:

```
E(0)            = 0
E(s(t))         = E(t) + 1
E(p(t))         = max(E(t) − 1, 0)
E(plus(t₁,t₂))  = E(t₁) + E(t₂)
E(times(t₁,t₂)) = E(t₁) × E(t₂)
E(fac(t))       = (E(t))!
E(x)            = 0          for any variable x
```

**E is invariant under all 8 rewrite rules.** This is verified by direct calculation for each rule. For the two most important:

- **Rule 6**: `E(p(s(s(x)))) = max(E(x)+2−1, 0) = E(x)+1`. And `E(s(p(s(x)))) = 1 + max(E(x)+1−1, 0) = 1 + E(x)`. Equal. ✓
- **Rule 8**: `E(fac(s(x))) = (E(x)+1)!`. And `E(times(fac(p(s(x))), s(x))) = (E(p(s(x))))! × (E(x)+1) = (E(x))! × (E(x)+1) = (E(x)+1)!`. Equal. ✓

(All other rules are verified similarly; the rules faithfully implement standard arithmetic.)

**E strictly decreases along every DP6 chain.** An infinite DP6 chain would require:

```
fac#(s(x₀σ₀)) → fac#(p(s(x₀σ₀))) →* fac#(s(x₁σ₁)) → fac#(p(s(x₁σ₁))) →* …
```

Between consecutive DP applications, `p(s(xᵢσᵢ))` must rewrite to `s(xᵢ₊₁σᵢ₊₁). Since E is invariant under rewriting:

```
E(s(xᵢ₊₁σᵢ₊₁)) = E(p(s(xᵢσᵢ))) = max(E(xᵢσᵢ) + 1 − 1, 0) = E(xᵢσᵢ)
```

Therefore:

```
E(xᵢ₊₁σᵢ₊₁) + 1 = E(xᵢσᵢ)    ⟹    E(xᵢ₊₁σᵢ₊₁) = E(xᵢσᵢ) − 1
```

Since `E` always yields a non-negative integer, this sequence must terminate in at most `E(x₀σ₀)` steps. **Terminating.**

---

## Conclusion

All four SCCs in the dependency graph are terminating, and all acyclic DPs lead only into these SCCs. Therefore, **no infinite rewrite sequence exists**, and the system terminates. ∎
