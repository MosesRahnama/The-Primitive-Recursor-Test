## Assessment

The lexicographic measure `measure t = (phase t, cost t)` is **sound**: every rule in `Step` strictly decreases the pair under the standard lexicographic order on `Nat × Nat` (first component decreases, or first stays equal and the second decreases).

**Verification rule by rule:**

| Rule | LHS phase | LHS cost | RHS phase | RHS cost | Decreases? |
|---|---|---|---|---|---|
| `R_int_delta` | 0 | `2 + cost t` | 0 | 0 | phase equal, cost ↓ ✓ |
| `R_merge_void_left/right` | 0 | `1 + cost t` | 0 | `cost t` | phase equal, cost ↓ ✓ |
| `R_merge_cancel` | 0 | `1 + 2·cost t` | 0 | `cost t` | phase equal, cost ↓ ✓ |
| `R_rec_zero` | 0 | `1 + cost b + cost s` | 0 | `cost b` | phase equal, cost ↓ ✓ |
| `R_rec_succ` | **1** | `2 + cost b + cost s + cost n` | **0** | `2 + 2·cost s + cost b + cost n` | phase strictly ↓ ✓ |
| `R_eq_refl` | 0 | `3 + 2·cost a` | 0 | 0 | phase equal, cost ↓ ✓ |
| `R_eq_diff` | 0 | `3 + cost a + cost b` | 0 | `2 + cost a + cost b` | phase equal, cost ↓ ✓ |

**Key design point.** The `phase` function exists precisely to handle the recursive case `R_rec_succ`, which *replicates* the step function `s` in the right-hand side (so `cost` of the RHS is at least as large as that of the LHS). The author assigns a non-zero `phase` to any `recDelta` whose body is a `delta`, and `R_rec_succ` is the only rule that can produce such a term from a `recDelta b s (.delta _)`. After firing, the result is an `app` whose head is not a `recDelta` on a `delta`, so the phase drops to 0 and never comes back — that is exactly what the measure exploits.

**Conclusion.** The measure is well-founded (it ranges over `Nat × Nat`, which is well-founded under the lexicographic order) and every `Step` strictly decreases it, hence the rewrite system is terminating. The measure is sound.
