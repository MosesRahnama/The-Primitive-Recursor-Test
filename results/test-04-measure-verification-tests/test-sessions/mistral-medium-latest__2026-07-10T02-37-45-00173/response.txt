### Assessment of the Lexicographic Termination Measure

The proposed termination measure for the first-order rewrite calculus is a pair `(phase t, cost t)` where:
- `phase t` is 1 if `t` is of the form `recDelta b s (delta n)`, and 0 otherwise.
- `cost t` is a recursive size measure that counts the number of constructors in the term, with some constructors (like `eqW`) having a higher base cost.

The termination measure is **lexicographic**, meaning that `(phase t1, cost t1) > (phase t2, cost t2)` if either:
1. `phase t1 > phase t2`, or
2. `phase t1 = phase t2` and `cost t1 > cost t2`.

### Soundness Check
To assess soundness, we need to verify that for every rewrite rule `Step t1 t2`, the measure strictly decreases: `measure t1 > measure t2`.

Let's check each rule:

1. **`R_int_delta`**: `Step (integrate (delta t)) void`
   - `measure (integrate (delta t)) = (phase (integrate (delta t)), cost (integrate (delta t)))`
     - `phase (integrate (delta t)) = 0` (since it's not `recDelta b s (delta n)`)
     - `cost (integrate (delta t)) = 1 + cost (delta t) = 1 + (1 + cost t) = 2 + cost t`
   - `measure void = (0, 0)`
   - Comparison: `(0, 2 + cost t) > (0, 0)` because `2 + cost t > 0`. ✅

2. **`R_merge_void_left`**: `Step (merge void t) t`
   - `measure (merge void t) = (0, 1 + cost void + cost t) = (0, 1 + 0 + cost t) = (0, 1 + cost t)`
   - `measure t = (phase t, cost t)`
   - Comparison: `(0, 1 + cost t) > (phase t, cost t)`
     - If `phase t = 0`, then `1 + cost t > cost t` ✅
     - If `phase t = 1`, then `0 > 1` is false ❌
   - **Problem**: If `t` is `recDelta b s (delta n)`, then `phase t = 1`, and `(0, 1 + cost t)` is not greater than `(1, cost t)` in the lexicographic order (since `0 < 1`). Thus, this rule does not always decrease the measure.

3. **`R_merge_void_right`**: `Step (merge t void) t`
   - Symmetric to `R_merge_void_left`. Same issue if `t` is `recDelta b s (delta n)`. ❌

4. **`R_merge_cancel`**: `Step (merge t t) t`
   - `measure (merge t t) = (0, 1 + cost t + cost t) = (0, 1 + 2 * cost t)`
   - `measure t = (phase t, cost t)`
   - Comparison: `(0, 1 + 2 * cost t) > (phase t, cost t)`
     - If `phase t = 0`, then `1 + 2 * cost t > cost t` ✅
     - If `phase t = 1`, then `0 > 1` is false ❌
   - **Problem**: Same as above if `t` is `recDelta b s (delta n)`.

5. **`R_rec_zero`**: `Step (recDelta b s void) b`
   - `measure (recDelta b s void) = (0, 1 + cost b + cost s + cost void) = (0, 1 + cost b + cost s)`
   - `measure b = (phase b, cost b)`
   - Comparison: `(0, 1 + cost b + cost s) > (phase b, cost b)`
     - If `phase b = 0`, then `1 + cost b + cost s > cost b` ✅
     - If `phase b = 1`, then `0 > 1` is false ❌
   - **Problem**: If `b` is `recDelta b' s' (delta n)`, then `phase b = 1`, and the measure does not decrease.

6. **`R_rec_succ`**: `Step (recDelta b s (delta n)) (app s (recDelta b s n))`
   - `measure (recDelta b s (delta n)) = (1, 1 + cost b + cost s + cost (delta n)) = (1, 1 + cost b + cost s + 1 + cost n) = (1, 2 + cost b + cost s + cost n)`
   - `measure (app s (recDelta b s n)) = (phase (app s (recDelta b s n)), cost (app s (recDelta b s n)))`
     - `phase (app s (recDelta b s n)) = 0` (since it's not `recDelta b' s' (delta n')`)
     - `cost (app s (recDelta b s n)) = 1 + cost s + cost (recDelta b s n) = 1 + cost s + (1 + cost b + cost s + cost n) = 2 + cost b + 2 * cost s + cost n`
   - Comparison: `(1, 2 + cost b + cost s + cost n) > (0, 2 + cost b + 2 * cost s + cost n)`
     - `1 > 0` is true, so the measure decreases regardless of the cost. ✅

7. **`R_eq_refl`**: `Step (eqW a a) void`
   - `measure (eqW a a) = (0, 3 + cost a + cost a) = (0, 3 + 2 * cost a)`
   - `measure void = (0, 0)`
   - Comparison: `(0, 3 + 2 * cost a) > (0, 0)` because `3 + 2 * cost a > 0`. ✅

8. **`R_eq_diff`**: `Step (eqW a b) (integrate (merge a b))`
   - `measure (eqW a b) = (0, 3 + cost a + cost b)`
   - `measure (integrate (merge a b)) = (0, 1 + cost (merge a b)) = (0, 1 + 1 + cost a + cost b) = (0, 2 + cost a + cost b)`
   - Comparison: `(0, 3 + cost a + cost b) > (0, 2 + cost a + cost b)` because `3 + cost a + cost b > 2 + cost a + cost b`. ✅

### Conclusion
The measure is **not sound** because there exist rules (`R_merge_void_left`, `R_merge_void_right`, `R_merge_cancel`, `R_rec_zero`) where the measure does not strictly decrease when the right-hand side has `phase = 1` and the left-hand side has `phase = 0`. For example:
- If `t = recDelta b s (delta n)`, then `Step (merge void t) t` has:
  - `measure (merge void t) = (0, 1 + cost t)`
  - `measure t = (1, cost t)`
  - `(0, 1 + cost t)` is not greater than `(1, cost t)` in the lexicographic order.

Thus, the proposed lexicographic measure is **not sound** for this rewrite system.
