## Assessment

The measure `measure t = (phase t, cost t)` ordered lexicographically is **sound** — every rule in `Step` strictly decreases it, so the rewrite system terminates.

### Rule-by-rule verification

I'll denote the lex comparison by writing `(phase L, cost L) ↦ (phase R, cost R)` and checking that LHS lex-greater than RHS.

| Rule | LHS → RHS | LHS | RHS | Check |
|---|---|---|---|---|
| `R_int_delta` | `integrate (delta t) → void` | `(0, 2 + cost t)` | `(0, 0)` | phase eq, cost: `0 < 2 + cost t` ✓ |
| `R_merge_void_left` | `merge void t → t` | `(0, 1 + cost t)` | `(phase t, cost t)` | if `phase t = 0`: `cost t < 1 + cost t`; if `phase t = 1`: `0 < 1` ✓ |
| `R_merge_void_right` | symmetric | — | — | ✓ |
| `R_merge_cancel` | `merge t t → t` | `(0, 1 + 2·cost t)` | `(phase t, cost t)` | ✓ (same reasoning) |
| `R_rec_zero` | `recDelta b s void → b` | `(0, 1 + cost b + cost s)` | `(phase b, cost b)` | if `phase b = 0`: `cost b < 1 + cost b + cost s`; if `phase b = 1`: `0 < 1` ✓ |
| `R_rec_succ` | `recDelta b s (delta n) → app s (recDelta b s n)` | `(1, 2 + cost b + cost s + cost n)` | `(0, 2 + cost b + 2·cost s + cost n)` | phase drops `1 → 0` ✓ |
| `R_eq_refl` | `eqW a a → void` | `(0, 3 + 2·cost a)` | `(0, 0)` | phase eq, `0 < 3 + 2·cost a` ✓ |
| `R_eq_diff` | `eqW a b → integrate (merge a b)` | `(0, 3 + cost a + cost b)` | `(0, 2 + cost a + cost b)` | phase eq, cost strictly smaller ✓ |

### Why the design works

- **`phase`** is `1` only on the *active* `recDelta _ _ (delta _)` form, i.e. exactly the LHS of `R_rec_succ`. Because the RHS of `R_rec_succ` is an `app` (and thus `phase 0`), the phase component handles the *unrolling step* of primitive recursion, which would otherwise be hard to dominate using `cost` alone (the recursive call is wrapped under `app s …`, which adds `cost s` to the RHS).
- **`cost`** is a standard "size" measure, positive on every non-`void` constructor. It is a decreasing witness for all other rules, including the cases where the recursion terminates (`R_rec_zero`) and the merge/integrate/eq rules.
- `phase` is `0` for every RHS of every rule, so once phase drops to 0, termination is delegated entirely to `cost`, which is monotone and strictly decreases on the remaining rules.

### Conclusion

**The lexicographic measure `(phase, cost)` is sound.** Each of the 8 rewrite rules strictly decreases the pair in lex order, so the `Step` relation is well-founded and the calculus terminates.
