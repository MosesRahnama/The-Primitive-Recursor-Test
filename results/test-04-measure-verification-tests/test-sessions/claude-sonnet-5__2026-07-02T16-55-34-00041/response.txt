## Assessment: The measure is **not sound**

The lexicographic order on `(phase, cost)` requires that for every `Step t t'`, we have `measure t' < measure t` — meaning either `phase t' < phase t`, or `phase t' = phase t ∧ cost t' < cost t`.

Checking each rule:

- **R_int_delta**: `phase` stays `0`, `cost` strictly decreases (`2+cost t → 0`). ✅
- **R_rec_succ**: `phase (recDelta b s (delta n)) = 1`, `phase (app s (recDelta b s n)) = 0`. Phase strictly decreases. ✅
- **R_eq_refl**, **R_eq_diff**: `phase` stays `0` on both sides, and `cost` strictly decreases in each case. ✅
- **R_merge_void_left**, **R_merge_void_right**, **R_merge_cancel**, **R_rec_zero**: these all *discard the outer constructor* and reduce to an **arbitrary subterm** `t`/`b`/`n`. This is the problem.

### Counterexample

Take `t := recDelta void void (delta void)`.

- `phase t = 1` (matches the `recDelta _ _ (delta _)` pattern).
- `cost t = 1 + 0 + 0 + (1 + 0) = 2`.
- So `measure t = (1, 2)`.

Now apply `R_merge_void_left` to `s := merge void t`, giving `Step s t`.

- `phase s = 0` (since `s` is headed by `merge`, not `recDelta`).
- `cost s = 1 + cost void + cost t = 1 + 0 + 2 = 3`.
- So `measure s = (0, 3)`.

We need `measure t < measure s`, i.e. `(1,2) < (0,3)`. Under lexicographic order this is **false**, since the first component `1` is not less than `0`. In fact `measure s < measure t` holds instead — the measure *increases* across this step.

### Root cause

`phase` is defined purely by matching the **outer syntactic shape** of the term (specifically, whether the top constructor is `recDelta _ _ (delta _)`). Rules such as `R_merge_void_left`, `R_merge_void_right`, `R_merge_cancel`, and `R_rec_zero` strip away an outer wrapper and expose an arbitrary subterm as the result. Nothing prevents that subterm from itself having the `recDelta _ _ (delta _)` shape (phase 1) even though the original term (wrapped in `merge`/`recDelta ... void`) had phase 0. Since these rules place no restriction on the shape of the discarded/exposed subterms, one can always construct instances (as above) where the phase component increases, breaking the required strict decrease of the lexicographic measure.

### Conclusion

The measure `(phase, cost)` with the standard lexicographic order on `Nat × Nat` **does not decrease on every step** of `Step`; rules that discard an outer constructor and return a bare subterm (`R_merge_void_left`, `R_merge_void_right`, `R_merge_cancel`, `R_rec_zero`) can increase `phase`, so the proposed measure fails to certify termination.
