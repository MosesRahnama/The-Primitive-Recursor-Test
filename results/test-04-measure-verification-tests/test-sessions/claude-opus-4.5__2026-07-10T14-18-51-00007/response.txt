# Assessment of the Lexicographic Termination Measure

I need to verify that for every rewrite rule `Step t t'`, we have `measure t > measure t'` in the lexicographic ordering on `Nat × Nat`.

The measure is `(phase t, cost t)` where lexicographic ordering means: `(p₁, c₁) > (p₂, c₂)` iff `p₁ > p₂` or (`p₁ = p₂` and `c₁ > c₂`).

## Analysis of Each Rule

### R_int_delta: `integrate (delta t) → void`
- **LHS:** `phase = 0`, `cost = 1 + (1 + cost t) = 2 + cost t`
- **RHS:** `phase = 0`, `cost = 0`
- **Decreases?** ✓ (phase equal, cost decreases: `2 + cost t > 0`)

### R_merge_void_left: `merge void t → t`
- **LHS:** `phase = 0`, `cost = 1 + 0 + cost t = 1 + cost t`
- **RHS:** `phase = 0`, `cost = cost t`
- **Decreases?** ✓ (phase equal, cost decreases: `1 + cost t > cost t`)

### R_merge_void_right: `merge t void → t`
- **LHS:** `phase = 0`, `cost = 1 + cost t + 0 = 1 + cost t`
- **RHS:** `phase = 0`, `cost = cost t`
- **Decreases?** ✓ (phase equal, cost decreases)

### R_merge_cancel: `merge t t → t`
- **LHS:** `phase = 0`, `cost = 1 + cost t + cost t = 1 + 2·cost t`
- **RHS:** `phase = 0`, `cost = cost t`
- **Decreases?** ✓ (phase equal, cost decreases: `1 + 2·cost t > cost t`)

### R_rec_zero: `recDelta b s void → b`
- **LHS:** `phase = 0` (third arg is `void`, not `delta _`), `cost = 1 + cost b + cost s + 0`
- **RHS:** `phase = 0`, `cost = cost b`
- **Decreases?** ✓ (phase equal, cost decreases: `1 + cost b + cost s > cost b`)

### R_rec_succ: `recDelta b s (delta n) → app s (recDelta b s n)`
- **LHS:** `phase = 1`, `cost = 1 + cost b + cost s + (1 + cost n) = 2 + cost b + cost s + cost n`
- **RHS:** `phase(app s (recDelta b s n)) = 0`, `cost = 1 + cost s + (1 + cost b + cost s + cost n)`
- **Decreases?** ✓ (phase decreases: `1 > 0`)

### R_eq_refl: `eqW a a → void`
- **LHS:** `phase = 0`, `cost = 3 + cost a + cost a = 3 + 2·cost a`
- **RHS:** `phase = 0`, `cost = 0`
- **Decreases?** ✓ (phase equal, cost decreases)

### R_eq_diff: `eqW a b → integrate (merge a b)`
- **LHS:** `phase = 0`, `cost = 3 + cost a + cost b`
- **RHS:** `phase = 0`, `cost = 1 + (1 + cost a + cost b) = 2 + cost a + cost b`
- **Decreases?** ✓ (phase equal, cost decreases: `3 + cost a + cost b > 2 + cost a + cost b`)

## Conclusion

**The measure is SOUND.** Every rewrite rule strictly decreases the lexicographic measure `(phase, cost)`. The key insight is that `R_rec_succ` is the only rule that could potentially increase `cost` (due to duplication of `s`), but this is handled by having it decrease `phase` from 1 to 0 instead. All other rules maintain `phase` at 0 and strictly decrease `cost`.
