# Assessment of the Termination Measure

I need to check whether the lexicographic measure `(phase t, cost t)` strictly decreases for every rewrite rule in `Step`.

Let me analyze each rule systematically.

## Rule-by-rule analysis

### R_int_delta: `integrate (delta t) → void`
- **LHS:** phase = 0, cost = 1 + (1 + cost t) = 2 + cost t
- **RHS:** phase = 0, cost = 0
- ✅ (0, 2 + cost t) > (0, 0)

### R_merge_void_left: `merge void t → t`
- **LHS:** phase = 0, cost = 1 + 0 + cost t = 1 + cost t
- **RHS:** phase(t) ∈ {0, 1}, cost = cost t
- If phase(t) = 0: (0, 1 + cost t) > (0, cost t) ✅
- If phase(t) = 1: (0, 1 + cost t) vs (1, cost t) — here **0 < 1** in the first component, so the measure **increases**. ❌

**Counterexample:** Let `t = recDelta b s (delta n)`. Then:
- LHS = `merge void (recDelta b s (delta n))`, phase = 0, cost = 1 + 0 + cost(recDelta b s (delta n))
- RHS = `recDelta b s (delta n)`, phase = 1, cost = cost(recDelta b s (delta n))
- Measure goes from (0, ...) to (1, ...), which is an **increase**.

### R_merge_void_right: `merge t void → t`
- Same issue as above. If `t = recDelta b s (delta n)`, phase goes from 0 to 1. ❌

### R_merge_cancel: `merge t t → t`
- **LHS:** phase = 0, cost = 1 + 2 · cost t
- **RHS:** phase(t) could be 1 (same counterexample as above). ❌

### R_rec_zero: `recDelta b s void → b`
- **LHS:** phase = 0, cost = 1 + cost b + cost s + 0 = 1 + cost b + cost s
- **RHS:** phase(b) ∈ {0,1}, cost = cost b
- If phase(b) = 1: (0, ...) → (1, ...) — **increases**. ❌

### R_rec_succ: `recDelta b s (delta n) → app s (recDelta b s n)`
- **LHS:** phase = 1, cost = 1 + cost b + cost s + (1 + cost n) = 2 + cost b + cost s + cost n
- **RHS:** `app s (recDelta b s n)`, phase = 0, cost = 1 + cost s + (1 + cost b + cost s + cost n) = 2 + cost b + 2·cost s + cost n
- Measure: (1, 2 + cost b + cost s + cost n) → (0, 2 + cost b + 2·cost s + cost n)
- First component strictly decreases (1 > 0), so this is fine regardless of second component. ✅

### R_eq_refl: `eqW a a → void`
- **LHS:** phase = 0, cost = 3 + 2·cost a
- **RHS:** phase = 0, cost = 0
- ✅

### R_eq_diff: `eqW a b → integrate (merge a b)`
- **LHS:** phase = 0, cost = 3 + cost a + cost b
- **RHS:** phase = 0, cost = 1 + (1 + cost a + cost b) = 2 + cost a + cost b
- ✅ (3 + cost a + cost b > 2 + cost a + cost b)

## Verdict: **The measure is unsound.**

The fundamental problem is that `phase` can **increase** when a rewrite strips away a constructor (like `merge` or `recDelta` in the zero case) to expose a `recDelta _ _ (delta _)` subterm. Specifically, rules **R_merge_void_left**, **R_merge_void_right**, **R_merge_cancel**, and **R_rec_zero** can all produce a right-hand side with `phase = 1` from a left-hand side with `phase = 0`, causing the lexicographic measure to increase rather than decrease.
