## Assessment: The measure is **not sound**

For `(phase, cost)` to serve as a valid termination measure, every step `Step t t'` must satisfy `measure t' < measure t` in the lexicographic order — i.e., either `phase t' < phase t`, or `phase t' = phase t` and `cost t' < cost t`.

The definition of `phase` only inspects the **outermost** constructor pattern (`recDelta _ _ (delta _)`). Several reduction rules replace a term by one of its **arbitrary subterms**, and that subterm's outer shape is not controlled by the rule at all. This lets `phase` *increase* across a step, which breaks the lexicographic order.

### Counterexample

Consider the rule
```
R_merge_void_left : ∀ t, Step (merge void t) t
```
Instantiate `t := recDelta b s (delta n)` for arbitrary `b s n`. Then:

- LHS = `merge void (recDelta b s (delta n))`.
  Its outermost constructor is `merge`, so `phase LHS = 0`.
- RHS = `recDelta b s (delta n)`.
  This exactly matches the pattern `recDelta _ _ (delta _)`, so `phase RHS = 1`.

Thus `phase RHS = 1 > 0 = phase LHS`, so `measure RHS > measure LHS` in the lex order — the measure **increases**, not decreases, on this step. The same problem occurs with:

- `R_merge_void_right` (`merge t void → t`),
- `R_merge_cancel` (`merge t t → t`),
- `R_rec_zero` (`recDelta b s void → b`),

whenever the surviving subterm (`t`, or `b`) happens to be of the shape `recDelta _ _ (delta _)`. In all these cases the rule discards an "outer" constructor (`merge`, `recDelta ... void`) that had `phase = 0`, exposing an inner subterm that can have `phase = 1`.

### Why the rest of the design doesn't rescue it

The only rule that actually *needs* the phase component to decrease is `R_rec_succ`:
```
recDelta b s (delta n)  →  app s (recDelta b s n)
```
Here `phase` correctly drops from 1 to 0, independent of `cost`, which is presumably the intended purpose of `phase` (to handle the fact that `cost` alone doesn't decrease, since `app s (recDelta b s n)` is not obviously "smaller" than `recDelta b s (delta n)` by the naive `cost` sum — actually here cost does drop too, but phase is there to make the decrease robust). However, `phase` as defined is a *global* structural predicate on arbitrary terms, not a property that is monotonically consumed only by the intended `recDelta`-chain; the erasure rules (`merge void _`, `merge _ void`, `merge t t`, `recDelta b s void`) can arbitrarily *expose* a `recDelta _ _ (delta _)` pattern that was "hidden" one level down, causing `phase` to jump from 0 to 1.

### Conclusion

Because `phase` is not preserved or monotonically decreasing under the erasure/projection rules (`merge void t → t`, `merge t void → t`, `merge t t → t`, `recDelta b s void → b`) — these rules can strictly increase `phase` when the retained subterm happens to match the `recDelta _ _ (delta _)` pattern — the proposed lexicographic measure `(phase, cost)` **does not decrease on every step**, and therefore does **not** constitute a valid termination proof for the rewrite system `Step`.
