The proposed lexicographic measure is **not sound** for the given rewrite relation. For a measure `m : Trace → Nat × Nat` with lexicographic order to witness termination, we need `m(right) < m(left)` (or at least `m(right) ≺ m(left)` in the chosen well-founded order) for every step `Step left right`. The definition here aims to decrease the pair `(phase t, cost t)` lexicographically, i.e. either the `phase` strictly decreases, or the `phase` stays the same and `cost` strictly decreases.

The counterexample is rule `R_merge_void_left`:

```
| R_merge_void_left  : ∀ t, Step (merge void t) t
```

Take `t := recDelta b s (delta n)`.  
- `phase t = 1` (by the first clause of `phase`).  
- `phase (merge void t) = 0` (the second, catch‑all clause, because the head is `merge`, not `recDelta`).

Thus we have
```
m(merge void t) = (0, cost(merge void t)) = (0, 1 + cost t)
m(t)            = (1, cost t)
```
In lexicographic order, `(1, cost t)` is **greater** than `(0, 1 + cost t)` because `1 > 0`. Hence `m(right) > m(left)`, violating the required decrease. The measure can increase in the `phase` component when the right‑hand side of `R_merge_void_left` is a `recDelta` whose target is a `delta`. Therefore the measure is unsound.
