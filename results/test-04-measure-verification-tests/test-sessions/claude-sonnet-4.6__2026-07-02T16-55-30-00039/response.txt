## Assessment of the Termination Measure

### The Proposed Measure

The measure is `(phase t, cost t)` under lexicographic order, where:
- `phase t = 1` only for `recDelta _ _ (delta _)`, and `0` otherwise
- `cost t` is a structural size function

For soundness, every rewrite step `Step t t'` must satisfy `measure t' < measure t` lexicographically, i.e., either `phase t' < phase t`, or `phase t' = phase t` and `cost t' < cost t`.

---

### Analysis of Each Rule

**R_int_delta**: `integrate (delta t) → void`
- phase: 0 → 0; cost: 2 + cost t → 0. ✓

**R_merge_void_left**: `merge void t → t`
- phase: 0 → 0; cost: 1 + 0 + cost t → cost t. ✓

**R_merge_void_right**: `merge t void → t`
- phase: 0 → 0; cost: 1 + cost t + 0 → cost t. ✓

**R_merge_cancel**: `merge t t → t`
- phase: 0 → 0; cost: 1 + cost t + cost t → cost t. ✓

**R_rec_zero**: `recDelta b s void → b`
- phase: 0 → 0; cost: 1 + cost b + cost s + 0 → cost b. ✓

**R_rec_succ**: `recDelta b s (delta n) → app s (recDelta b s n)`
- phase: **1** → 0 (since result is `app`, not `recDelta _ _ (delta _)`). So phase strictly decreases. ✓
- (cost need not decrease for this to hold)

**R_eq_refl**: `eqW a a → void`
- phase: 0 → 0; cost: 3 + 2·cost a → 0. ✓

**R_eq_diff**: `eqW a b → integrate (merge a b)`
- phase: 0 → 0; cost: 3 + cost a + cost b → 1 + (1 + cost a + cost b) = 2 + cost a + cost b. ✓

---

### Critical Issue: The Measure is Not Closed Under Context / Not a Global Measure

The measure is defined only on **top-level** redexes. The calculus as written defines `Step` only at the root (no congruence rules), so reduction only fires at the top level. In this restricted system, the measure works locally for each top-level step.

However, there is a deeper problem: **R_rec_succ** produces `app s (recDelta b s n)`, which contains a `recDelta b s n` subterm. If reduction were to continue (e.g., if `n` is itself `delta n'`), the inner `recDelta b s n` would need to be reduced. But without congruence rules, the system **cannot reduce under `app`**, so this inner redex is permanently blocked. The calculus is therefore **not Turing-complete in its reduction strategy**, and the measure never needs to account for subterm reduction.

---

### Verdict

**The measure is sound for the calculus as stated** (top-level steps only, no congruence rules). Every rule strictly decreases `(phase, cost)` lexicographically. However, the calculus itself is significantly incomplete — `recDelta` cannot reduce recursively in practice — so the termination result is somewhat vacuous. The measure would **not** be sound for a version of the calculus extended with congruence (contextual closure) rules.
