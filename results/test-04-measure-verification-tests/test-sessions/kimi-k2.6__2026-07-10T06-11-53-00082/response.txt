**The measure is not sound.**  
The lexicographic pair `(phase, cost)` does **not** strictly decrease on every rewrite step. While it works for several rules, it fails whenever a rule’s left-hand side has `phase = 0` but the right-hand side can be an arbitrary subterm whose `phase` is `1`.

---

### Why it fails

Recall:

```lean
def phase : Trace → Nat
| .recDelta _ _ (.delta _) => 1
| _ => 0
```

Only a `recDelta` whose **third** argument is a `delta` gets phase 1; everything else gets phase 0.

Now consider the rules that simply drop a top-level constructor:

1. **`R_merge_void_left`**: `merge void t → t`  
   The LHS always has `phase = 0`. If `t` happens to be a `recDelta _ _ (delta _)`, then `phase t = 1`.  
   Lexicographically, `(0, …) < (1, …)`, so the measure **increases**.

2. **`R_merge_void_right`**: `merge t void → t`  
   Same problem.

3. **`R_merge_cancel`**: `merge t t → t`  
   Same problem.

4. **`R_rec_zero`**: `recDelta b s void → b`  
   The LHS has third argument `void`, so `phase = 0`. If `b` is a `recDelta _ _ (delta _)`, then `phase b = 1` and the measure again increases.

---

### Concrete counterexample

Let

```lean
t* := recDelta void void (delta void)
```

Compute its components:

- `phase t* = 1` (third argument is `delta void`).
- `cost void = 0`.
- `cost (delta void) = 1`.
- `cost t* = 1 + 0 + 0 + 1 = 2`.

Now apply `R_merge_void_left` with `t := t*`:

- **LHS**: `merge void t*`  
  `phase = 0`  
  `cost = 1 + 0 + 2 = 3`  
  `measure = (0, 3)`

- **RHS**: `t*`  
  `measure = (1, 2)`

Since `(0, 3) < (1, 2)` in the standard lexicographic order, the step **raises** the measure.

The same `t*` also breaks `R_rec_zero`:  
`recDelta t* void void` has measure `(0, 3)` but rewrites to `t*` with measure `(1, 2)`.

---

### Rules that do work

For completeness, the measure **does** decrease on the other rules:

- `R_int_delta`: phase stays `0`, cost drops by at least 2.
- `R_rec_succ`: phase drops from `1` to `0`, which dominates any cost change.
- `R_eq_refl` / `R_eq_diff`: phase stays `0`, cost drops.

But because at least one step can increase the lexicographic pair, the proposed measure is **unsound** as a termination argument for the whole calculus.
