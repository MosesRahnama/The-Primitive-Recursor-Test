# Assessment of the Lexicographic Termination Measure

## Overview

The proposed measure is `(phase t, cost t)` with lexicographic ordering. For this to be sound, every rewrite step must strictly decrease this measure.

## Analysis of Each Rule

### Rules where `phase` stays at 0:

**R_int_delta**: `integrate (delta t) → void`
- Cost: `1 + (1 + cost t) = 2 + cost t` → `0` ✓

**R_merge_void_left**: `merge void t → t`
- Cost: `1 + 0 + cost t = 1 + cost t` → `cost t` ✓

**R_merge_void_right**: `merge t void → t`
- Cost: `1 + cost t + 0 = 1 + cost t` → `cost t` ✓

**R_merge_cancel**: `merge t t → t`
- Cost: `1 + cost t + cost t = 1 + 2*(cost t)` → `cost t` ✓

**R_rec_zero**: `recDelta b s void → b`
- Cost: `1 + cost b + cost s + 0` → `cost b` ✓

### Rule where `phase` decreases from 1 to 0:

**R_rec_succ**: `recDelta b s (delta n) → app s (recDelta b s n)`
- Phase: `1` → `0` ✓ (strictly decreases first component)
- Cost comparison not needed since phase decreased

### Rules involving `eqW`:

**R_eq_refl**: `eqW a a → void`
- Cost: `3 + cost a + cost a` → `0` ✓

**R_eq_diff**: `eqW a b → integrate (merge a b)`
- Cost LHS: `3 + cost a + cost b`
- Cost RHS: `1 + (1 + cost a + cost b) = 2 + cost a + cost b`
- Decrease: `3 + cost a + cost b > 2 + cost a + cost b` ✓

## Critical Problem: The Measure is **UNSOUND**

The measure only proves that **single steps** decrease the measure. However, `R_rec_succ` introduces a fundamental problem:

**R_rec_succ** transforms `recDelta b s (delta n)` into `app s (recDelta b s n)`.

The inner term `recDelta b s n` can itself reduce. If `n` matches `delta m`, then this inner `recDelta` has `phase = 1`, and applying `R_rec_succ` again produces `app s (recDelta b s m)`.

The issue is that after the first `R_rec_succ` fires (phase 1 → 0), we now have `app s (recDelta b s n)` with `phase = 0`. But if `n = delta m`, the subterm `recDelta b s (delta m)` has `phase = 1`. When we reduce this subterm:

- **Before inner reduction**: `app s (recDelta b s (delta m))` has `phase = 0`, `cost = 1 + cost s + (1 + cost b + cost s + (1 + cost m))`
- **After inner reduction**: `app s (app s (recDelta b s m))` has `phase = 0`

The cost actually **increases** here:
- LHS cost: `1 + cost s + 1 + cost b + cost s + 1 + cost m = 3 + 2*cost s + cost b + cost m`
- RHS cost: `1 + cost s + 1 + cost s + 1 + cost b + cost s + cost m = 3 + 3*cost s + cost b + cost m`

When `cost s > 0`, the cost **increases**, and phase stays at 0.

## Conclusion

**The measure is UNSOUND.** The `R_rec_succ` rule, when applied to nested `recDelta` terms, can cause the cost to increase while the phase remains constant. A sound termination argument would require a more sophisticated measure, such as tracking the nesting depth of recursive structures or using multiset orderings.
