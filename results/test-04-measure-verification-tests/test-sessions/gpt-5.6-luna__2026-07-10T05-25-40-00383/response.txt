The measure is **not sound** for the given rewrite rules under the usual lexicographic ordering on `Nat × Nat`, where the `phase` component is compared first.

The problematic rule is:

```lean
R_rec_zero : ∀ b s, Step (recDelta b s void) b
```

For the left-hand side,

```lean
phase (recDelta b s void) = 0
```

because `phase` is `1` only when the third argument is syntactically a `delta`. However, `b` can itself have phase `1`.

For example, take:

```lean
b := recDelta void void (delta void)
s := void
```

Then:

```lean
Step (recDelta b void void) b
```

but

```lean
measure (recDelta b void void) = (0, 3)
measure b                    = (1, 2)
```

Thus the rewrite changes the measure from `(0, 3)` to `(1, 2)`. Although the cost decreases, the phase increases from `0` to `1`, so the lexicographic measure **increases**, rather than decreases.

The other rules do decrease the proposed measure, but `R_rec_zero` is enough to invalidate the termination argument. A sound measure would need to account for the possibility that the base argument `b` contains an active `recDelta` phase, or use a different ordering/measure.
