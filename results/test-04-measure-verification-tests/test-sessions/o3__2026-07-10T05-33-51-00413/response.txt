No – the proposed measure  
  measure t = (phase t , cost t)  
is NOT a sound termination measure for the relation Step.

Why it ought to work  
For every rule  l → r  we would have to prove

 (phase l , cost l) > (phase r , cost r) with the usual lexicographic
 order on Nat × Nat, i.e.
  phase l > phase r  or
  phase l = phase r ∧ cost l > cost r .

Where it fails  
Take any term t with phase t = 1, e.g.

 t₁ := recDelta void void (delta void)

(phase t₁ = 1, cost t₁ = 2).

Apply the rule  

 R_merge_void_left : Step (merge void t) t

to the left-hand side l₁ := merge void t₁:

 phase l₁ = 0  
 cost  l₁ = 1 + cost t₁ = 3

 phase r₁ = phase t₁ = 1  
 cost  r₁ = cost  t₁ = 2

Thus  

 measure l₁ = (0 , 3)  
 measure r₁ = (1 , 2).

Lexicographically, (0,3) is strictly smaller than (1,2) because the first
component has decreased, so the measure has increased along the rewrite
step.  Hence the rule R_merge_void_left is not decreasing the measure, and
the measure is not sound.

Exactly the same counter-argument works for

• R_merge_void_right :  Step (merge t void) t  
• R_merge_cancel     :  Step (merge t t)      t  
• R_rec_zero         :  Step (recDelta b s void) b

whenever their right-hand side happens to have phase = 1.

Conclusion  
Because some rules can raise the first (phase) component of the proposed
lexicographic pair, the pair is not monotonically decreasing along all
rewrite steps, so the suggested measure does not prove termination.
