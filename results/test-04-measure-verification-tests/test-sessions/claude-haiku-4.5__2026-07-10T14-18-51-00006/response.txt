# Assessment of the Termination Measure

## Verdict: **UNSOUND**

The lexicographic measure `(phase t, cost t)` is **not sound** for proving termination of the given rewrite system. Here's why:

### Critical Counterexample: R_rec_succ

Consider the rule:
```lean
R_rec_succ : Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

**Before rewrite:**
- `t = recDelta b s (delta n)`
- `phase t = 1` (matches the pattern `recDelta _ _ (.delta _)`)
- `cost t = 1 + cost b + cost s + (1 + cost n)`

**After rewrite:**
- `t' = app s (recDelta b s n)`
- `phase t' = 0` (doesn't match the recDelta pattern)
- `cost t' = 1 + cost s + (1 + cost b + cost s + cost n) = 2 + cost b + 2·cost s + cost n`

**Comparison:**
```
measure(t)  = (1, 1 + cost b + cost s + 1 + cost n)
measure(t') = (0, 2 + cost b + 2·cost s + cost n)
```

The phase decreases from 1 to 0 ✓, but this only guarantees progress in the first component. Since the rewrite transforms a "phase 1" term into a "phase 0" term, the second component (cost) can increase arbitrarily without violating the lexicographic order.

### Why This Is Problematic

For termination, we need `measure(t') < measure(t)` in the lexicographic order. While the phase decreases here, allowing cost to increase means:

1. A chain of reductions could repeatedly use R_rec_succ to decrease phase while increasing cost
2. Once phase stabilizes at 0, subsequent reductions must decrease cost to continue
3. But **there's no guarantee that a chain of reductions will eventually terminate** if cost can grow unbounded during phase transitions

### What Would Be Needed

To make this sound, the measure would need to ensure that either:
- **Both components decrease** with each step, or
- **Cost is bounded** in terms of phase, preventing unbounded growth, or
- **The cost component is designed** to account for the structural changes in the rewrite rules

The current definition doesn't satisfy any of these conditions.
