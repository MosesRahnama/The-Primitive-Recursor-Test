The proposed lexicographic measure `(phase t, cost t)` is **not sound** for the reduction relation `Step`.

### Why it fails

The measure must strictly decrease (in the lexicographic order on `Nat × Nat`) for every rule of `Step`. The problematic case is `R_rec_zero`:

```lean4
| R_rec_zero : ∀ b s, Step (recDelta b s void) b
```

- **Source:** `recDelta b s void`  
  `phase(source) = 0` because the third argument is `void`, not `.delta _`.
- **Target:** `b` (any `Trace`).  
  If `b` itself is a `recDelta` whose third argument is `.delta _`, then `phase(b) = 1`.

Thus we can have:

```
measure(source) = (0, cost(source))
measure(target) = (1, cost(b))
```

In the lexicographic order, `(1, ...) > (0, ...)`, so the measure **increases**, violating the required decrease condition.

### Example of failure

Take `b = recDelta x y (delta z)`. Then:
```
Step (recDelta (recDelta x y (delta z)) s void) (recDelta x y (delta z))
```
The source has measure `(0, ...)`, the target `(1, ...)`.

All other rules are decreasing, but one counterexample is enough to make the measure unsound for the unrestricted `Step` relation.
