**Conclusion – the measure is sound.**

The pair  

\[
\text{measure}(t)=\bigl(\text{phase}(t),\;\text{cost}(t)\bigr)
\]

is ordered lexicographically on \(\mathbb N\times\mathbb N\).  
Since the lexicographic order on the natural numbers is well‑founded, it is enough to check that every rewrite rule of `Step` makes the pair strictly smaller.

Below is a case‑by‑case verification (the notation “\(>\)” means “greater in the lexicographic order”).

| Rule (LHS → RHS) | \(\text{phase}(LHS)\) | \(\text{cost}(LHS)\) | \(\text{phase}(RHS)\) | \(\text{cost}(RHS)\) | Comparison |
|-----------------|----------------------|----------------------|----------------------|----------------------|------------|
| `R_int_delta` `t` | 0 | \(2+\text{cost}(t)\) | 0 | 0 | \((0,2+\text{cost}t) > (0,0)\) |
| `R_merge_void_left` `t` | 0 | \(1+\text{cost}(t)\) | 0 | \(\text{cost}(t)\) | \((0,1+\text{cost}t) > (0,\text{cost}t)\) |
| `R_merge_void_right` `t` | 0 | \(1+\text{cost}(t)\) | 0 | \(\text{cost}(t)\) | same as above |
| `R_merge_cancel` `t` | 0 | \(1+2\!\cdot\!\text{cost}(t)\) | 0 | \(\text{cost}(t)\) | \((0,1+2c) > (0,c)\) |
| `R_rec_zero` `b,s` | 0 | \(1+\text{cost}(b)+\text{cost}(s)\) | 0 | \(\text{cost}(b)\) | \((0,1+c_b+c_s) > (0,c_b)\) |
| `R_rec_succ` `b,s,n` | **1** | \(2+\text{cost}(b)+\text{cost}(s)+\text{cost}(n)\) | **0** | \(2+\text{cost}(b)+2\text{cost}(s)+\text{cost}(n)\) | \((1,\dots) > (0,\dots)\) (phase drops) |
| `R_eq_refl` `a` | 0 | \(3+2\!\cdot\!\text{cost}(a)\) | 0 | 0 | \((0,3+2c) > (0,0)\) |
| `R_eq_diff` `a,b` | 0 | \(3+\text{cost}(a)+\text{cost}(b)\) | 0 | \(2+\text{cost}(a)+\text{cost}(b)\) | \((0,3+c_a+c_b) > (0,2+c_a+c_b)\) |

In every rule the first component either stays the same (phase = 0) while the second component (the cost) strictly decreases, **or** the first component decreases from 1 to 0, which already guarantees a strict lexicographic drop irrespective of the cost. No rule leaves the measure unchanged or increases it.

Because:

* `phase` only takes values `0` or `1`,
* `cost` is a positive linear combination of the costs of the sub‑terms,
* the lexicographic order on \(\mathbb N\times\mathbb N\) is well‑founded,

the function `measure` is a **well‑founded monotone decrease** for all one‑step rewrites. Consequently any forward chain of `Step`‑reductions must be finite; the measure is a sound termination (weakly decreasing) measure for the rewrite system.

Hence the proposed lexicographic measure is indeed sound for proving termination of the given rewrite calculus.
