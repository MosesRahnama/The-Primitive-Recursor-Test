To assess whether the proposed lexicographic termination measure `(phase t, cost t)` is sound for the given rewrite system, we need to verify that for every rewrite step `Step t t'`, the measure strictly decreases in the lexicographic order. That is, either:

1. `phase t > phase t'`, or
2. `phase t = phase t'` and `cost t > cost t'`.

### 1. `R_int_delta : ∀ t, Step (integrate (delta t)) void`
- `t = integrate (delta t)`
  - `phase t = 0` (since it doesn't match `.recDelta _ _ (.delta _)`)
  - `cost t = 1 + cost (delta t) = 1 + (1 + cost t) = 2 + cost t`
- `t' = void`
  - `phase t' = 0`
  - `cost t' = 0`
- Comparison: `phase t = phase t'` and `cost t = 2 + cost t > 0 = cost t'`. The measure decreases.

### 2. `R_merge_void_left : ∀ t, Step (merge void t) t`
- `t = merge void t`
  - `phase t = 0`
  - `cost t = 1 + cost void + cost t = 1 + 0 + cost t = 1 + cost t`
- `t' = t`
  - `phase t' = phase t` (since `t` is arbitrary)
  - `cost t' = cost t`
- Comparison: `phase t = phase t'` and `cost t = 1 + cost t' > cost t'`. The measure decreases.

### 3. `R_merge_void_right : ∀ t, Step (merge t void) t`
- Symmetric to `R_merge_void_left`. The measure decreases.

### 4. `R_merge_cancel : ∀ t, Step (merge t t) t`

  - `cost t = 1 + cost t + cost t = 1 + 2 * cost t`
- `t' = t`
  - `phase t' = phase t`
  - `cost t' = cost t`
- Comparison: `phase t = phase t'` and `cost t = 1 + 2 * cost t' > cost t'`. The measure decreases.

### 5. `R_rec_zero : ∀ b s, Step (recDelta b s void) b`

  - `cost t' = cost b`
- Comparison:

  - If `phase b = 0`, then `phase t = phase t'` and `cost t = 1 + cost b + cost s > cost b = cost t'`. The measure decreases.

### 6. `R_rec_succ : ∀ b s n, Step (recDelta b s (delta n)) (app s (recDelta b s n))`

### 7. `R_eq_refl : ∀ a, Step (eqW a a) void`
