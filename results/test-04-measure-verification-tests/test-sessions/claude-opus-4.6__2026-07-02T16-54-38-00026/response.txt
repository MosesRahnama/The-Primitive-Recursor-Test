# Assessment of the Lexicographic Termination Measure

I need to check whether for every rule `Step t₁ t₂`, we have `measure t₁ > measure t₂` in the lexicographic order on `Nat × Nat` (i.e., either `phase t₁ > phase t₂`, or `phase t₁ = phase t₂ ∧ cost t₁ > cost t₂`).

Let me check each rule:

## 1. `R_int_delta`: `integrate (delta t) → void`
- **phase**: `integrate (delta t)` doesn't match `.recDelta _ _ (.delta _)`, so phase = 0. `void` → phase = 0. Equal.
- **cost**: `1 + (1 + cost t) = 2 + cost t` vs `0`. ✅ Decreases.

## 2. `R_merge_void_left`: `merge void t → t`
- **phase**: `merge void t` → 0. `t` → 0 (unless `t` is a `recDelta _ _ (delta _)`, in which case phase = 1).
- If `t = recDelta b s (delta n)`: phase goes from 0 to 1. **Phase increases!**
- **cost**: `1 + 0 + cost t = 1 + cost t` vs `cost t`. Cost decreases, but phase increased.
- Lexicographically: `(0, 1 + cost t)` vs `(1, cost t)`. Since `0 < 1`, this is **not** a decrease.

## **This rule is unsound under the proposed measure.**

The problem is concrete: let `t = recDelta b s (delta n)`. Then:
- `measure (merge void t) = (0, 1 + cost t)`
- `measure t = (1, cost t)`

Since `0 < 1` in the first component, the measure actually **increases** lexicographically.

The same issue affects:

## 3. `R_merge_void_right`: `merge t void → t`
- Same problem when `t = recDelta b s (delta n)`.

## 4. `R_merge_cancel`: `merge t t → t`
- Same problem when `t = recDelta b s (delta n)`: phase goes 0 → 1.

## 6. `R_rec_succ`: `recDelta b s (delta n) → app s (recDelta b s n)`
- **phase**: LHS matches `.recDelta _ _ (.delta _)` → phase = 1. RHS is `app ...` → phase = 0. Phase decreases. ✅

## 5. `R_rec_zero`: `recDelta b s void → b`
- **phase**: LHS doesn't match `.recDelta _ _ (.delta _)` (third arg is `void` not `delta _`) → phase = 0. `b` has phase 0 unless it's a recDelta with delta. But cost: `1 + cost b + cost s + 0` vs `cost b`. Cost strictly decreases (as long as we don't have a phase increase). If `b = recDelta _ _ (delta _)`, phase goes 0 → 1. **Unsound.**

## 7–8. `R_eq_refl` and `R_eq_diff`
- `R_eq_refl`: `eqW a a → void`. Phase 0 → 0, cost `3 + 2·cost a` → 0. ✅
- `R_eq_diff`: `eqW a b → integrate (merge a b)`. Phase 0 → 0, cost `3 + cost a + cost b` → `1 + (1 + cost a + cost b) = 2 + cost a + cost b`. ✅

---

## Conclusion

**The measure is unsound.** The fundamental issue is that `phase` can **increase** when a rewrite rule strips away a constructor (like `merge` or the `void` argument position in `recDelta`) and exposes a `recDelta _ _ (delta _)` subterm. Specifically, rules `R_merge_void_left`, `R_merge_void_right`, `R_merge_cancel`, and `R_rec_zero` can all produce a result whose phase is strictly greater than the source's phase, and the cost decrease in the second component cannot compensate because the lexicographic order checks the first component first.
