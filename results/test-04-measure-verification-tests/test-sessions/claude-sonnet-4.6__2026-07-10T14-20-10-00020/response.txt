## Assessment of the Termination Measure

### Overview

The proposed lexicographic measure is `(phase t, cost t)` where:
- `phase t = 1` if `t = recDelta b s (delta n)`, else `0`
- `cost t` is a structural size measure

For the measure to be sound, every rewrite step `Step t t'` must satisfy `measure t' < measure t` lexicographically, i.e., either `phase t' < phase t`, or `phase t' = phase t` and `cost t' < cost t`.

---

### Analysis of Each Rule

**R_int_delta**: `integrate (delta t) → void`
- `phase`: 0 → 0. `cost`: `1 + 1 + cost t` → `0`. ✓

**R_merge_void_left**: `merge void t → t`
- `phase`: 0 → 0. `cost`: `1 + 0 + cost t` → `cost t`. ✓

**R_merge_void_right**: `merge t void → t`
- `phase`: 0 → 0. `cost`: `1 + cost t + 0` → `cost t`. ✓

**R_merge_cancel**: `merge t t → t`
- `phase`: 0 → 0. `cost`: `1 + cost t + cost t` → `cost t`. ✓

**R_rec_zero**: `recDelta b s void → b`
- `phase`: 0 → 0. `cost`: `1 + cost b + cost s + 0` → `cost b`. ✓

**R_rec_succ**: `recDelta b s (delta n) → app s (recDelta b s n)`
- `phase` of LHS: **1** (matches the `recDelta _ _ (delta _)` pattern).
- `phase` of RHS `app s (recDelta b s n)`: **0** (not a `recDelta _ _ (delta _)`).
- So `phase` drops from 1 → 0. ✓ (first component strictly decreases, second need not be checked)

**R_eq_refl**: `eqW a a → void`
- `phase`: 0 → 0. `cost`: `3 + 2·cost a` → `0`. ✓

**R_eq_diff**: `eqW a b → integrate (merge a b)`
- `phase`: 0 → 0. `cost`: `3 + cost a + cost b` → `1 + 1 + cost a + cost b = 2 + cost a + cost b`. ✓ (strictly less)

---

### Critical Gap: No Congruence (Context Closure)

The `Step` relation is defined only at the **top level** — there are no congruence rules allowing reduction inside subterms. This means the calculus as defined **cannot reduce a redex that appears nested inside a larger term**.

For the measure to support a full reduction strategy, one would need rules like:
```
Step t t' → Step (delta t) (delta t')
```
etc. These are absent. Under top-level reduction only, the measure is trivially adequate for the rules given, but **the system cannot normalize arbitrary terms**.

---

### Conclusion

**The measure is sound for the rules as stated**: every top-level step strictly decreases `(phase, cost)` lexicographically. However, the system is **incomplete** — it lacks congruence rules, so the measure's practical utility for proving termination of normalization of arbitrary terms is limited. The soundness of the measure itself holds, but it addresses only a fragment of what a full termination proof would require.
