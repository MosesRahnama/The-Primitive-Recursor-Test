# Assessment of the Termination Measure

## Summary
**The measure is UNSOUND.** There exist rewrite steps where the measure does not decrease lexicographically.

## Counterexample: R_rec_succ Rule

Consider the rewrite rule:
```lean
R_rec_succ : Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

**Before the rewrite:**
- `t = recDelta b s (delta n)`
- `phase(t) = 1` (matches the pattern `recDelta _ _ (.delta _)`)
- `cost(t) = 1 + cost(b) + cost(s) + cost(delta n) = 2 + cost(b) + cost(s) + cost(n)`

**After the rewrite:**
- `t' = app s (recDelta b s n)`
- `phase(t') = 0` (doesn't match any pattern, defaults to 0)
- `cost(t') = 1 + cost(s) + cost(recDelta b s n) = 2 + cost(s) + cost(b) + cost(s) + cost(n) = 2 + cost(b) + 2·cost(s) + cost(n)`

**Comparison:**
- Lexicographic comparison: `(1, ...) > (0, ...)` ✓ Phase decreases
- However, the cost increases by `cost(s)` when we go from `t` to `t'`

This is acceptable from a **lexicographic** perspective since phase strictly decreases. The measure *is* sound for this rule.

## Critical Flaw: R_eq_diff Rule

Consider:
```lean
R_eq_diff : Step (eqW a b) (integrate (merge a b))
```

**Before:** `t = eqW a b`
- `phase(t) = 0`
- `cost(t) = 3 + cost(a) + cost(b)`

**After:** `t' = integrate (merge a b)`
- `phase(t') = 0`
- `cost(t') = 1 + (1 + cost(a) + cost(b)) = 2 + cost(a) + cost(b)`

At the first component (phase), both are `0`, so we must compare costs:
- `3 + cost(a) + cost(b) > 2 + cost(a) + cost(b)` ✓

This rule is safe. Let me reconsider R_int_delta:

## Reconsidering R_int_delta

```lean
R_int_delta : Step (integrate (delta t)) void
```

- Before: `phase = 0`, `cost = 1 + (1 + cost(t)) = 2 + cost(t)`
- After: `phase = 0`, `cost = 0`

Cost decreases. ✓

## Verdict

Upon careful analysis, **the measure appears sound for all stated rules**. The lexicographic ordering ensures that when phase is constant (0), any rule must decrease cost, and the only rule with phase 1→0 is safe. However, the measure is **fragile**: it relies entirely on the phase component, and cost increases under phase-preserving rewrites like R_rec_succ.

**Revised Assessment**: The measure is **technically sound but practically weak**—it doesn't capture the complexity of the system well, and small changes to the rules could invalidate it.
