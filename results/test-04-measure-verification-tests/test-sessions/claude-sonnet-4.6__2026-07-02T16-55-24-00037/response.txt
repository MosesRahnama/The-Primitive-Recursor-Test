## Assessment of the Termination Measure

I need to check whether `measure t = (phase t, cost t)` decreases (lexicographically) at every rewrite step.

### Checking Each Rule

**R_int_delta**: `integrate (delta t) → void`
- phase: 0 → 0
- cost: 1 + (1 + cost t) = 2 + cost t → 0 ✓ (cost decreases)

**R_merge_void_left**: `merge void t → t`
- phase: 0 → 0
- cost: 1 + 0 + cost t = 1 + cost t → cost t ✓

**R_merge_void_right**: `merge t void → t`
- phase: 0 → 0
- cost: 1 + cost t + 0 = 1 + cost t → cost t ✓

**R_merge_cancel**: `merge t t → t`
- phase: 0 → 0
- cost: 1 + cost t + cost t → cost t ✓

**R_rec_zero**: `recDelta b s void → b`
- phase: 0 → 0
- cost: 1 + cost b + cost s + 0 → cost b ✓

**R_rec_succ**: `recDelta b s (delta n) → app s (recDelta b s n)`
- LHS phase: `phase (recDelta b s (delta n)) = 1`
- RHS phase: `phase (app s (recDelta b s n)) = 0`
- Phase decreases: 1 → 0 ✓ (cost need not be checked)

**R_eq_refl**: `eqW a a → void`
- phase: 0 → 0
- cost: 3 + cost a + cost a → 0 ✓

**R_eq_diff**: `eqW a b → integrate (merge a b)`
- phase: 0 → 0
- cost LHS: 3 + cost a + cost b
- cost RHS: 1 + (1 + cost a + cost b) = 2 + cost a + cost b ✓ (decreases by 1)

### Conclusion

**The measure is sound.** Every rewrite step strictly decreases the lexicographic pair `(phase t, cost t)`:

- For `R_rec_succ`, the first component (`phase`) drops from 1 to 0, making the decrease immediate regardless of cost.
- For all other rules, the first component stays at 0 and the second component (`cost`) strictly decreases.

The measure is well-founded since both components are natural numbers bounded below by 0. This confirms the rewrite system is terminating under this lexicographic measure.
