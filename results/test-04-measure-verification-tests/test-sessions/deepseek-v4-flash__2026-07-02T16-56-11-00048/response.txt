The lexicographic measure `(phase, cost)` is **not sound** as a termination measure for the rewrite system defined by `Step`. The measure is intended to strictly decrease under the lexicographic order for every rewrite rule, but several rules can increase the first component (`phase`) while keeping the second component finite, leading to a larger measure.

### Counterexample

Consider the rule `R_merge_void_left`:
```
Step (merge void t) t
```
Take `t = recDelta b s (delta n)` for arbitrary `b, s, n`. Then:
- `phase(merge void t) = 0` (since `merge` is not a `recDelta` with a `delta` third argument).
- `phase(t) = 1` because `t` itself is a `recDelta` with a `delta` third argument.
Thus `phase` increases from 0 to 1. Since the lexicographic order compares the first component first, the measure increases, violating the required strict decrease.

The same problem occurs with:
- `R_merge_void_right` (if `t` is such a term),
- `R_merge_cancel` (if `t` has phase 1),
- `R_rec_zero` (if `b` has phase 1).

Therefore, the measure does not guarantee termination of the rewrite system.
