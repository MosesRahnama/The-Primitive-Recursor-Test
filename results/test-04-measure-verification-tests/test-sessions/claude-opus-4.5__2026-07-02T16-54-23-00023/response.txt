# Assessment of the Lexicographic Termination Measure

I need to verify that for every rewrite rule `Step t t'`, the measure `(phase t, cost t)` strictly decreases lexicographically—meaning either `phase` decreases, or `phase` stays the same and `cost` decreases.

## Analysis of Each Rule

### R_int_delta: `integrate (delta t) → void`
- **Before:** `phase = 0`, `cost = 1 + (1 + cost t) = 2 + cost t`
- **After:** `phase = 0`, `cost = 0`
- ✅ Phase unchanged, cost decreases (2 + cost t > 0)

### R_merge_void_left: `merge void t → t`
- **Before:** `phase = 0`, `cost = 1 + 0 + cost t = 1 + cost t`
- **After:** `phase t` (could be 0 or 1), `cost t`
- ⚠️ If `t = recDelta _ _ (delta _)`, then `phase t = 1 > 0`. **Phase increases!**
- ❌ **UNSOUND** for this case

### R_merge_void_right: `merge t void → t`
- Same analysis as above.
- ❌ **UNSOUND** when `t = recDelta _ _ (delta _)`

### R_merge_cancel: `merge t t → t`
- **Before:** `phase = 0`, `cost = 1 + cost t + cost t = 1 + 2·cost t`
- **After:** `phase t`, `cost t`
- ⚠️ If `t = recDelta _ _ (delta _)`, then `phase t = 1 > 0`. **Phase increases!**
- ❌ **UNSOUND** for this case

### R_rec_zero: `recDelta b s void → b`
- **Before:** `phase = 0` (third arg is `void`, not `delta _`), `cost = 1 + cost b + cost s + 0`
- **After:** `phase b`, `cost b`
- ⚠️ If `b = recDelta _ _ (delta _)`, then `phase b = 1 > 0`. **Phase increases!**
- ❌ **UNSOUND** for this case

### R_rec_succ: `recDelta b s (delta n) → app s (recDelta b s n)`
- **Before:** `phase = 1`, `cost = 1 + cost b + cost s + (1 + cost n)`
- **After:** 
  - `phase (app s (recDelta b s n)) = 0` (app is not a recDelta pattern)
  - `cost = 1 + cost s + (1 + cost b + cost s + cost n)`
- ✅ Phase decreases from 1 to 0

### R_eq_refl: `eqW a a → void`
- **Before:** `phase = 0`, `cost = 3 + cost a + cost a`
- **After:** `phase = 0`, `cost = 0`
- ✅ Phase unchanged, cost decreases

### R_eq_diff: `eqW a b → integrate (merge a b)`
- **Before:** `phase = 0`, `cost = 3 + cost a + cost b`
- **After:** `phase = 0`, `cost = 1 + (1 + cost a + cost b) = 2 + cost a + cost b`
- ✅ Phase unchanged, cost decreases (3 + x > 2 + x)

## Conclusion

**The measure is UNSOUND.**

The fundamental problem is that several rules (`R_merge_void_left`, `R_merge_void_right`, `R_merge_cancel`, `R_rec_zero`) can expose a subterm that has `phase = 1`, while the original term has `phase = 0`. This causes the phase component to *increase*, violating the lexicographic ordering requirement.

**Concrete counterexample:** Let `t = recDelta void void (delta void)`.
- `merge void t` has `phase = 0`, `cost = 1 + 0 + 4 = 5`
- After `R_merge_void_left`: `t` has `phase = 1`, `cost = 4`
- The measure goes from `(0, 5)` to `(1, 4)`, which is an **increase** in lexicographic order.
