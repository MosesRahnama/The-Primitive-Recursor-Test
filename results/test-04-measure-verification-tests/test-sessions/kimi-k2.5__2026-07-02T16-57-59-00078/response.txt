The proposed measure is **not sound**.

The lexicographic measure $\langle\text{phase}(t), \text{cost}(t)\rangle$ fails to decrease on several rewrite rules when the right-hand side is a `recDelta` term with a `delta` in the third position (i.e., a term with phase 1) while the left-hand side has phase 0.

Specifically:

1.  **`R_merge_void_left`** and **`R_merge_void_right`**:  
    If $t = \text{recDelta}\ b\ s\ (\delta\ n)$, then:
    -   LHS: $\text{merge void } t$ (or $\text{merge } t \text{ void}$) has phase 0.
    -   RHS: $t$ has phase 1.
    -   The measure increases from $\langle 0, \dots \rangle$ to $\langle 1, \dots \rangle$.

2.  **`R_merge_cancel`**:  
    If $t = \text{recDelta}\ b\ s\ (\delta\ n)$, then:
    -   LHS: $\text{merge } t\ t$ has phase 0.
    -   RHS: $t$ has phase 1.
    -   Again, the phase increases from 0 to 1.

3.  **`R_rec_zero`**:  
    If the base case $b = \text{recDelta}\ b'\ s'\ (\delta\ n)$, then:
    -   LHS: $\text{recDelta}\ b\ s\ \text{void}$ has phase 0 (since the third argument is `void`, not `delta`).
    -   RHS: $b$ has phase 1.
    -   The measure increases from $\langle 0, \dots \rangle$ to $\langle 1, \dots \rangle$.

While **R_rec_succ** correctly decreases the phase (from 1 to 0), the other rules do not preserve the measure ordering, allowing the first component to increase arbitrarily. Therefore, the calculus is not guaranteed to terminate under this measure.
