# Assessment of the Termination Measure

## Summary
**The measure is UNSOUND.** The lexicographic pair `(phase t, cost t)` does not decrease for all rewrite rules.

## Critical Counterexample

Consider rule **R_rec_succ**:
```
Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

**Before rewriting:**
```
t = recDelta b s (delta n)
phase(t) = 1  (matches the pattern recDelta _ _ (.delta _))
cost(t) = 1 + cost b + cost s + cost (delta n)
        = 1 + cost b + cost s + (1 + cost n)
        = 2 + cost b + cost s + cost n
```

**After rewriting:**
```
t' = app s (recDelta b s n)
phase(t') = 0  (app doesn't match any special case)
cost(t') = 1 + cost s + (1 + cost b + cost s + cost n)
         = 2 + cost s + cost b + cost s + cost n
         = 2 + cost b + 2·cost s + cost n
```

**Comparison:**
- Phase: 1 > 0 ✓ (decreases)
- Cost: (2 + cost b + cost s + cost n) vs (2 + cost b + 2·cost s + cost n)
  - The cost increased by `cost s`! ✗

Since the phase pair `(1, old_cost)` does not lexicographically decrease to `(0, new_cost)` when `new_cost > old_cost`, the measure fails.

## The Problem

The rule R_rec_succ duplicates the subterm `s` in the reductum, increasing the total cost while transitioning to a lower phase. The phase decrease is insufficient to compensate for the cost increase because:
- In lexicographic order, we only move to the second component if phases are equal
- Here the phases differ (1 → 0), so the cost difference becomes irrelevant, but this only works if we're *leaving* the higher phase
- In practice, the trace can grow indefinitely through repeated applications of rules that increase cost

The measure lacks sufficient structure to guarantee that the calculus terminates.
