The proposed measure is not sound. It fails to strictly decrease (in lex order) on several rules, including `R_merge_void_left`, `R_merge_void_right`, `R_merge_cancel`, and `R_rec_zero` (specifically when the RHS has `phase = 1`). 

For a counterexample to decreasingness, let `t := recDelta b s (delta n)` (so `phase(t) = 1` and `cost(t) = 2 + cost(b) + cost(s) + cost(n)`). Then:
- `measure(merge void t) = (0, 3 + cost(b) + cost(s) + cost(n))`
- `measure(t) = (1, 2 + cost(b) + cost(s) + cost(n))`
- These compare as `(0, _)` < `(1, _)` in lex order, so `R_merge_void_left` increases the measure.

(The only rule that starts from `phase = 1` is `R_rec_succ`, which does decrease as expected.)
