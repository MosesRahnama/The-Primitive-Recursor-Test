The measure is **not sound** for all rewrite rules under the usual lexicographic ordering on `Nat × Nat`.

The problematic rule is:

```lean
R_rec_zero : ∀ b s, Step (recDelta b s void) b
```

The source always has phase `0`, because its third argument is `void`:

```lean
phase (recDelta b s void) = 0
```

However, the target `b` may itself be a successor-shaped `recDelta`, and therefore have phase `1`. For example, let

```lean
b := recDelta void void (delta void)
s := void
```

Then:

```lean
measure (recDelta b s void) = (0, 3)
measure b                    = (1, 2)
```

Although the cost decreases, the phase increases from `0` to `1`. Hence the target is larger lexicographically, not smaller.

The other rules appear compatible with the proposed measure, but `R_rec_zero` invalidates the termination argument. To repair it, the phase would need to account for the phase of the embedded base term `b`, or the measure would need to use a different ordering that guarantees this rule decreases.
