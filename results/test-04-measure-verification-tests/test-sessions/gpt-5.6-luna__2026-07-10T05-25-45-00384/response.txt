The measure is **not sound** as a lexicographic termination measure for these rewrite rules, assuming the intended ordering is the usual lexicographic order on `(phase, cost)`, with smaller values decreasing.

For example, let

```lean
x := recDelta void void (delta void)
```

Then:

```lean
phase x = 1
cost x = 2
```

but

```lean
phase (merge void x) = 0
cost (merge void x) = 3
```

The rule

```lean
R_merge_void_left : Step (merge void t) t
```

therefore gives

```lean
measure (merge void x) = (0, 3)
measure x              = (1, 2)
```

The target is not smaller lexicographically, because its first component increases from `0` to `1`.

The same problem occurs for:

```lean
R_merge_void_right
R_merge_cancel
```

whenever the surviving term has phase `1`.

There is also a counterexample for:

```lean
R_rec_zero : Step (recDelta b s void) b
```

by choosing `b = x` above. The source has phase `0`, while the target has phase `1`.

The other rules behave as intended:

- `R_int_delta` decreases cost.
- `R_rec_succ` decreases phase from `1` to `0`.
- `R_eq_refl` decreases cost.
- `R_eq_diff` decreases cost by one.

However, since several rewrite rules increase the phase component, the pair `(phase, cost)` does not strictly decrease on every `Step`. Thus it cannot directly establish termination.
