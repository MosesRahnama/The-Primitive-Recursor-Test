# Assessment of the Lexicographic Termination Measure

I need to verify that for every rewrite rule `Step t t'`, we have `measure t > measure t'` in the lexicographic ordering on `Nat × Nat`.

The measure is `(phase t, cost t)` where lexicographic ordering means either:
1. `phase t > phase t'`, OR
2. `phase t = phase t'` AND `cost t > cost t'`

Let me analyze each rule:

## Rule Analysis

### R_int_delta: `integrate (delta t) → void`
- LHS: `phase = 0`, `cost = 1 + (1 + cost t) = 2 + cost t`
- RHS: `phase = 0`, `cost = 0`
- ✅ `(0, 2 + cost t) > (0, 0)` ✓

### R_merge_void_left: `merge void t → t`
- LHS: `phase = 0`, `cost = 1 + 0 + cost t = 1 + cost t`
- RHS: `phase(t) ∈ {0, 1}`, `cost = cost t`
- If `phase(t) = 0`: `(0, 1 + cost t) > (0, cost t)` ✓
- **If `phase(t) = 1`**: `(0, 1 + cost t)` vs `(1, cost t)` — Here `0 < 1`, so LHS < RHS!
- ❌ **UNSOUND** when `t = recDelta _ _ (delta _)`

### R_merge_void_right: `merge t void → t`
- Same analysis as above.
- ❌ **UNSOUND** when `t = recDelta _ _ (delta _)`

### R_merge_cancel: `merge t t → t`
- LHS: `phase = 0`, `cost = 1 + 2*(cost t)`
- RHS: `phase(t) ∈ {0, 1}`, `cost = cost t`
- **If `phase(t) = 1`**: `(0, 1 + 2*(cost t))` vs `(1, cost t)` — `0 < 1`!
- ❌ **UNSOUND** when `t = recDelta _ _ (delta _)`

### R_rec_zero: `recDelta b s void → b`
- LHS: `phase = 0` (since third arg is `void`, not `delta _`), `cost = 1 + cost b + cost s + 0`
- RHS: `phase(b)`, `cost = cost b`
- **If `phase(b) = 1`**: `(0, ...)` vs `(1, ...)` — fails!
- ❌ **UNSOUND** when `b = recDelta _ _ (delta _)`

### R_rec_succ: `recDelta b s (delta n) → app s (recDelta b s n)`
- LHS: `phase = 1`, `cost = 1 + cost b + cost s + (1 + cost n)`
- RHS: `phase = 0` (it's an `app`), `cost = 1 + cost s + (1 + cost b + cost s + cost n)`
- Since `phase` decreases from 1 to 0: ✅ ✓

### R_eq_refl: `eqW a a → void`
- LHS: `phase = 0`, `cost = 3 + 2*(cost a)`
- RHS: `phase = 0`, `cost = 0`
- ✅ ✓

### R_eq_diff: `eqW a b → integrate (merge a b)`
- LHS: `phase = 0`, `cost = 3 + cost a + cost b`
- RHS: `phase = 0`, `cost = 1 + (1 + cost a + cost b) = 2 + cost a + cost b`
- ✅ `3 + cost a + cost b > 2 + cost a + cost b` ✓

---

## Conclusion

**The measure is UNSOUND.**

The fundamental problem is that `phase` can be 0 on the LHS but 1 on the RHS when the result of a rewrite is a term of the form `recDelta _ _ (delta _)`. This happens in:

- **R_merge_void_left/right**: `merge void (recDelta b s (delta n)) → recDelta b s (delta n)`
- **R_merge_cancel**: `merge t t → t` where `t = recDelta _ _ (delta _)`
- **R_rec_zero**: `recDelta (recDelta b' s' (delta n')) s void → recDelta b' s' (delta n')`

In these cases, the phase *increases* from 0 to 1, which violates the lexicographic ordering requirement.
