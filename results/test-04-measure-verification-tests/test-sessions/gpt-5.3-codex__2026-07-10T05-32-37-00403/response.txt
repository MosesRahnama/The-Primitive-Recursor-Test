Short answer: **no, this measure is not sound as a global one-step decrease for `Step`**.

Why:

To prove termination via `measure : Trace → Nat × Nat`, you’d need every rule
\[
Step\ l\ r \implies measure\ r < measure\ l
\]
(for some fixed lex order, typically on `(phase, cost)`).

But rule **`R_eq_diff`** breaks this immediately:

- LHS: `eqW a b`
  - `phase = 0`
  - `cost = 3 + cost a + cost b`
- RHS: `integrate (merge a b)`
  - `phase = 0`
  - `cost = 1 + (1 + cost a + cost b) = 2 + cost a + cost b`

So that rule decreases `cost` by 1 (good).

However, rule **`R_eq_refl`** also exists:

- `eqW a a → void`
  - LHS cost: `3 + 2*cost a`
  - RHS cost: `0`
  - decreases (good)

The real problem is **`R_rec_succ`**:

- `recDelta b s (delta n) → app s (recDelta b s n)`
- `phase`:
  - LHS matches `.recDelta _ _ (.delta _)`, so `phase = 1`
  - RHS is `.app ...`, so `phase = 0`
  - phase decreases (good if lex prioritizes phase)

But with lexicographic order where first component is compared first, this rule is fine.  
The issue is the opposite direction for other rules that keep phase at 0: they must strictly decrease cost. Check **`R_eq_diff`** is fine, merges are fine, integrate/delta is fine.

The **critical unsoundness** is that `phase` only detects a redex at the root of exactly one shape. It is **not a structural/global measure for arbitrary rewriting contexts** (if you intend full first-order rewriting under contexts). A step can occur in a subterm while the root `phase` and even root-level tuple behavior need not reflect that substep unless you prove monotonicity/compositional decrease under all constructors. This file defines only `Step : Trace → Trace → Prop` at the root, so for *that* relation the check is local and mostly okay; but as a termination argument for a rewrite calculus (usually closed under contexts), this measure is insufficient as stated.

Also, if you intended plain lex on `Nat × Nat`, you must specify the order. Under the common order instance on products (componentwise) it would fail; under `Prod.Lex` it may pass for root steps. So “soundness” is currently underspecified.

## Verdict

- **Not sound as a complete termination measure for a general rewrite calculus** (context-closed rewriting), because it’s only root-sensitive and no lifting argument is provided.
- **Potentially sound for the bare root-step relation `Step` only**, provided you use a strict lex order prioritizing `phase` then `cost`, and prove each constructor case.
