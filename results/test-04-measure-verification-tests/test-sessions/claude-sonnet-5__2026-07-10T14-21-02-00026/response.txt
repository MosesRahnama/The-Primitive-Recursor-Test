## Assessment: **The measure is not sound.**

The lexicographic order on `Nat × Nat` (with the usual lexicographic comparison) requires that for every step `Step s t`, we have `measure t < measure s` lexicographically — i.e. either `phase t < phase s`, or `phase t = phase s` and `cost t < cost s`.

The `phase` function is defined so that it is `1` exactly when the term has the *syntactic* shape `recDelta _ _ (delta _)`, and `0` otherwise. This is meant to capture "one step away from firing `R_rec_succ`", and indeed for `R_rec_succ` itself the phase correctly drops from `1` to `0`.

**Problem:** several other rules can *produce* a term of that special recDelta-with-`delta`-argument shape as their result, even though the phase of the *redex itself* was `0`. This causes the phase component to *increase* from 0 to 1, which is not compatible with a decreasing lexicographic measure regardless of what happens to `cost`.

### Counterexample

Take `t := recDelta void void (delta void)`.

Consider the rule `R_merge_void_left`:
```
Step (merge void t) t
```

- Source `s := merge void t`. Since `s` is not of the form `recDelta _ _ (delta _)`, `phase s = 0`.
- Target `t = recDelta void void (delta void)`, which *does* match `recDelta _ _ (delta _)`, so `phase t = 1`.

Hence
```
measure s = (0, cost s)
measure t = (1, cost t)
```
and since `(1, cost t) >lex (0, cost s)` for **any** natural numbers `cost s, cost t`, we get `measure t > measure s`, i.e. the measure **increases** along this step. This directly contradicts what a termination measure must satisfy.

The same problem occurs for `R_merge_void_right` (`merge t void → t`) and `R_merge_cancel` (`merge t t → t`) whenever `t` has the shape `recDelta _ _ (delta _)`.

### Conclusion

The `phase` component is not monotonically non-increasing across all rewrite rules — it can jump from `0` to `1` in a `merge`-elimination step whose result happens to expose a `recDelta _ _ (delta _)` redex. Since the lexicographic comparison always favors a smaller first component, any such increase in `phase` cannot be compensated by `cost`, so `measure` fails to decrease on these steps. Therefore `measure` as defined is **not a sound termination measure** for `Step`.
