# Assessment of the Lexicographic Termination Measure

I need to verify that for every rewrite rule `Step t t'`, the measure `(phase t, cost t)` decreases lexicographically (i.e., either `phase` strictly decreases, or `phase` stays the same and `cost` strictly decreases).

## Analysis of Each Rule

### R_int_delta: `integrate (delta t) → void`
- **Before:** `phase = 0`, `cost = 1 + (1 + cost t) = 2 + cost t`
- **After:** `phase = 0`, `cost = 0`
- ✅ Phase same, cost decreases (2 + cost t > 0)

### R_merge_void_left: `merge void t → t`
- **Before:** `phase = 0`, `cost = 1 + 0 + cost t = 1 + cost t`
- **After:** `phase t` (could be 0 or 1), `cost t`
- ⚠️ If `t = recDelta _ _ (delta _)`, then `phase t = 1 > 0`
- ❌ **UNSOUND**: Phase can increase from 0 to 1

### R_merge_void_right: `merge t void → t`
- Same issue as above
- ❌ **UNSOUND**: Phase can increase from 0 to 1

### R_merge_cancel: `merge t t → t`
- **Before:** `phase = 0`, `cost = 1 + cost t + cost t = 1 + 2*(cost t)`
- **After:** `phase t` (could be 0 or 1), `cost t`
- ❌ **UNSOUND**: Phase can increase from 0 to 1

### R_rec_zero: `recDelta b s void → b`
- **Before:** `phase = 0` (third arg is `void`, not `delta _`), `cost = 1 + cost b + cost s + 0`
- **After:** `phase b`, `cost b`
- ❌ **UNSOUND**: If `b = recDelta _ _ (delta _)`, phase increases

### R_rec_succ: `recDelta b s (delta n) → app s (recDelta b s n)`
- **Before:** `phase = 1`, `cost = 1 + cost b + cost s + (1 + cost n)`
- **After:** `phase = 0` (it's an `app`), `cost = 1 + cost s + (1 + cost b + cost s + cost n)`
- ✅ Phase strictly decreases (1 → 0)

### R_eq_refl: `eqW a a → void`
- **Before:** `phase = 0`, `cost = 3 + cost a + cost a`
- **After:** `phase = 0`, `cost = 0`
- ✅ Phase same, cost decreases

### R_eq_diff: `eqW a b → integrate (merge a b)`
- **Before:** `phase = 0`, `cost = 3 + cost a + cost b`
- **After:** `phase = 0`, `cost = 1 + (1 + cost a + cost b) = 2 + cost a + cost b`
- ✅ Phase same, cost decreases (3 + x > 2 + x)

## Conclusion

**The measure is UNSOUND.**

The fundamental problem is that the `phase` function only examines the top-level constructor, but several rules (particularly the `merge` rules and `R_rec_zero`) can "expose" a subterm that has higher phase than the original term.

Concrete counterexample for `R_merge_void_left`:
```
t = merge void (recDelta b s (delta n))
t' = recDelta b s (delta n)
```
- `measure t = (0, 1 + 0 + cost(recDelta b s (delta n)))`
- `measure t' = (1, cost(recDelta b s (delta n)))`

The phase increases from 0 to 1, so the measure does not decrease lexicographically.
