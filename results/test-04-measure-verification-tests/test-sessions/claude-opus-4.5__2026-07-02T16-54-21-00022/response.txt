# Assessment of the Lexicographic Termination Measure

I need to verify that for every rewrite rule `Step t₁ t₂`, we have `measure t₁ > measure t₂` in the lexicographic ordering on `Nat × Nat`.

The measure is `(phase t, cost t)` where lexicographic comparison means:
- Either `phase t₁ > phase t₂`, or
- `phase t₁ = phase t₂` and `cost t₁ > cost t₂`

Let me analyze each rule:

## Rule-by-Rule Analysis

### R_int_delta: `integrate (delta t) → void`
- LHS: `phase = 0`, `cost = 1 + (1 + cost t) = 2 + cost t`
- RHS: `phase = 0`, `cost = 0`
- **✓ Decreases**: `(0, 2 + cost t) > (0, 0)`

### R_merge_void_left: `merge void t → t`
- LHS: `phase = 0`, `cost = 1 + 0 + cost t = 1 + cost t`
- RHS: `phase t` (could be 0 or 1), `cost t`
- If RHS has `phase = 1` (i.e., `t = recDelta _ _ (delta _)`), then `(0, _) > (1, _)` is **FALSE**
- **✗ UNSOUND**

### R_merge_void_right: `merge t void → t`
- Same issue as above.
- **✗ UNSOUND**

### R_merge_cancel: `merge t t → t`
- LHS: `phase = 0`, `cost = 1 + 2 * cost t`
- RHS: `phase t`, `cost t`
- Same issue: if `t = recDelta _ _ (delta _)`, phase increases from 0 to 1.
- **✗ UNSOUND**

### R_rec_zero: `recDelta b s void → b`
- LHS: `phase = 0` (third arg is `void`, not `delta _`), `cost = 1 + cost b + cost s + 0`
- RHS: `phase b`, `cost b`
- If `b = recDelta _ _ (delta _)`, phase increases.
- **✗ UNSOUND**

### R_rec_succ: `recDelta b s (delta n) → app s (recDelta b s n)`
- LHS: `phase = 1`, `cost = 1 + cost b + cost s + (1 + cost n) = 2 + cost b + cost s + cost n`
- RHS: `phase(app s (recDelta b s n)) = 0`, `cost = 1 + cost s + (1 + cost b + cost s + cost n) = 2 + cost b + 2*cost s + cost n`
- Phase decreases from 1 to 0: **✓ Decreases** (lexicographically, first component decreases)

### R_eq_refl: `eqW a a → void`
- LHS: `phase = 0`, `cost = 3 + 2 * cost a`
- RHS: `phase = 0`, `cost = 0`
- **✓ Decreases**

### R_eq_diff: `eqW a b → integrate (merge a b)`
- LHS: `phase = 0`, `cost = 3 + cost a + cost b`
- RHS: `phase = 0`, `cost = 1 + (1 + cost a + cost b) = 2 + cost a + cost b`
- **✓ Decreases**: cost goes from 3 + ... to 2 + ...

## Conclusion

**The measure is UNSOUND.**

The fundamental problem is that several rules (`R_merge_void_left`, `R_merge_void_right`, `R_merge_cancel`, `R_rec_zero`) can return a term whose phase is 1 while the LHS has phase 0. Since phase is the primary component of the lexicographic measure, an increase in phase means the measure increases rather than decreases.

For example, `merge void (recDelta b s (delta n))` has measure `(0, _)` but rewrites to `recDelta b s (delta n)` which has measure `(1, _)`.
