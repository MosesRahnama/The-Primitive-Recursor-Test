No.  
The pair (phase t , cost t) does not strictly decrease along every reduction
t → t′ that is generated by the rules in Step, so it cannot serve as a
termination measure for the whole calculus.

Where it fails

1.  Rules that merely remove a «merge void …» wrapper

        merge void t   →   t          (R_merge_void_left)
        merge t void   →   t          (R_merge_void_right)
        merge t t      →   t          (R_merge_cancel)

   have left–hand side phase 0, because merge is never given phase 1.
   The right-hand side is the arbitrary trace t.
   If we pick  

        t = recDelta b s (delta n)

   then phase t = 1, so

        measure (merge void t) = (0 , …) ,
        measure t              = (1 , …) ,

   i.e. the first component of the measure increases from 0 to 1 and the
   lexicographic order goes the wrong way.

2.  The rule

        recDelta b s void → b          (R_rec_zero)

   has left-hand side phase 0.  
   If we again choose

        b = recDelta b₁ s₁ (delta n)

   the right-hand side has phase 1 and the measure grows instead of
   shrinking.

Because at least these two kinds of steps can raise the first component of
the lexicographic pair, (phase , cost) is **not a sound decreasing
measure** for the rewrite system.
