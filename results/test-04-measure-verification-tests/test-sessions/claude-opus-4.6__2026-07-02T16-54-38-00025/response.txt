# Assessment of the Termination Measure

I need to check whether the lexicographic measure `(phase t, cost t)` strictly decreases (in lexicographic order) for every rewrite rule defined by `Step`.

Let me analyze each rule:

## Rule-by-rule analysis

### R_int_delta: `integrate (delta t) → void`
- **LHS:** phase = 0, cost = 1 + (1 + cost t) = 2 + cost t
- **RHS:** phase = 0, cost = 0
- **(0, 2 + cost t) > (0, 0)** ✅

### R_merge_void_left: `merge void t → t`
- **LHS:** phase = 0, cost = 1 + 0 + cost t = 1 + cost t
- **RHS:** phase(t) ≤ 1, cost = cost t
- If phase(t) = 0: **(0, 1 + cost t) > (0, cost t)** ✅
- If phase(t) = 1: **(0, 1 + cost t) vs (1, cost t)** — here 0 < 1 in the first component, so **LHS < RHS**. ❌

This is already a problem. Consider `t = recDelta b s (delta n)`. Then:
- LHS = `merge void (recDelta b s (delta n))`, phase = 0, cost = 1 + cost(recDelta b s (delta n))
- RHS = `recDelta b s (delta n)`, phase = 1, cost = cost(recDelta b s (delta n))

The measure goes from `(0, ...)` to `(1, ...)`, which is an **increase** in the first (most significant) component.

## The measure is **unsound**

The problem is that `phase` assigns a higher value to `recDelta _ _ (delta _)` than to `merge void (recDelta _ _ (delta _))`. When `R_merge_void_left` fires and exposes a `recDelta` with a `delta` argument at the top level, the phase increases from 0 to 1, and the lexicographic measure goes up.

The same issue affects **R_merge_void_right**, **R_merge_cancel**, and **R_eq_diff** (which can produce terms whose subterms might have higher phase). Let me verify R_eq_diff more carefully:

### R_eq_diff: `eqW a b → integrate (merge a b)`
- **LHS:** phase = 0, cost = 3 + cost a + cost b
- **RHS:** phase = 0, cost = 1 + (1 + cost a + cost b) = 2 + cost a + cost b
- **(0, 3 + cost a + cost b) > (0, 2 + cost a + cost b)** ✅ (this one is fine)

### R_rec_succ: `recDelta b s (delta n) → app s (recDelta b s n)`
- **LHS:** phase = 1, cost = 1 + cost b + cost s + (1 + cost n)
- **RHS:** phase = 0, cost = 1 + cost s + (1 + cost b + cost s + cost n)
- First component: 1 > 0 ✅ (decreases regardless of cost)

So `phase` was specifically designed to handle R_rec_succ, but it breaks R_merge_void_left and R_merge_void_right.

## Conclusion

**The measure is not sound.** The rules `R_merge_void_left` and `R_merge_void_right` can increase the `phase` component from 0 to 1 when the surviving subterm is a `recDelta _ _ (delta _)`, causing the lexicographic measure to increase rather than decrease. A concrete counterexample is:

```
merge void (recDelta b s (delta n))  →  recDelta b s (delta n)
measure: (0, _)  →  (1, _)
```
