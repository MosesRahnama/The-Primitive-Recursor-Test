## Assessment: The measure is **not sound**.

A lexicographic termination measure on `Nat × Nat` must strictly decrease on every rewrite rule. Here the measure is unsound because four of the rules can produce a *larger* term in the lex order, not a smaller one.

### Why `phase` is the culprit

`phase t = 1` only when `t = recDelta b s (delta n)` at the **root**, and `0` otherwise. In lex order, anything at phase `0` is below everything at phase `1`, regardless of the cost. So as soon as a rewrite step *exposes* a `recDelta _ _ (delta _)` as the new root, the measure jumps from `(0, _)` up to `(1, _)`, which is an **increase**, not a decrease.

### Concrete counterexamples

For any `b s n`, let `t₀ = recDelta b s (delta n)`. Then `phase t₀ = 1`.

- **R_merge_void_left:**  `merge void t₀  →  t₀`
  - LHS measure: `(0, 1 + cost b + cost s + (1 + cost n))`
  - RHS measure: `(1, 1 + cost b + cost s + (1 + cost n))`
  - In lex order, `(0, _) < (1, _)`, so the measure **increases**.

- **R_merge_void_right:**  `merge t₀ void → t₀` — same problem, phase goes `0 → 1`.

- **R_merge_cancel:**  `merge t₀ t₀ → t₀` — same problem.

- **R_rec_zero:**  `recDelta t₀ s void → t₀`
  - LHS phase `0`, RHS phase `1`. The cost also goes up (the inner `recDelta … delta …` has cost ≥ 2 inside `t₀`). So the measure strictly **increases**.

### Rules that are fine

For completeness, the other four rules do strictly decrease the lex measure:

- `R_int_delta`, `R_eq_refl`, `R_eq_diff`: phase stays `0` and cost drops by ≥ 1.
- `R_rec_succ`: LHS has phase `1` (root is `recDelta _ _ (delta _)`) and RHS is an `app`, so phase is `0` — phase strictly decreases. (Note: cost goes up, but phase drop wins in lex order, so this one is OK.)

### Conclusion

The proposed measure `(phase, cost)` is **unsound** as a termination argument. To fix it, `phase` would need to look at the top-level constructor in a way that is monotone under the rewrite rules — for instance, by tracking something more closely tied to the structural recursion in `recDelta` (e.g., a measure on the spine / a hybrid numeric weight that strictly decreases on every rule). A simple root-based phase flag, as defined here, is insufficient because the merge and `rec_zero` rules can hoist a `recDelta _ _ (delta _)` to the root.
