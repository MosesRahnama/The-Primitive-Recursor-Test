I'll analyze whether the lexicographic measure `(phase t, cost t)` decreases on every rewrite step.

## Key observation about `phase`

`phase` is 1 only when the whole term is `recDelta _ _ (delta _)`, and 0 otherwise. Critically, `phase` only depends on the **top-level** structure of a term.

## Checking each rule

For a lexicographic measure to be sound, for each step `Step s t` we need either `phase t < phase s`, or (`phase t = phase s` and `cost t < cost s`).

Let me check the problematic rule: **R_rec_succ**.

`Step (recDelta b s (delta n)) (app s (recDelta b s n))`

- LHS: `recDelta b s (delta n)`. Top-level is `recDelta _ _ (delta _)`, so `phase = 1`.
- RHS: `app s (recDelta b s n)`. Top-level is `app`, so `phase = 0`.

Here `phase` decreases (1 → 0), so this step is fine regardless of cost. Good.

Now check the other rules — all of these must **not increase phase**, and if phase stays equal, cost must strictly decrease.

**R_int_delta**: `integrate (delta t) → void`. LHS phase 0, RHS phase 0. Cost: LHS = `1 + 1 + cost t`, RHS = 0. Decreases. ✓

**R_merge_void_left**: `merge void t → t`. phase 0 → phase(t). If `t = recDelta _ _ (delta _)`, then RHS phase = 1 while LHS phase = 0. **phase INCREASES!**

Let me verify. LHS `merge void t`: top-level is `merge`, phase = 0. If `t` itself is `recDelta b s (delta n)`, then RHS = `t`, whose phase = 1.

So we'd need phase to go from 0 to 1 — an **increase**. This breaks the lexicographic ordering (first component must not increase).

## Concrete counterexample

Take `t = recDelta void void (delta void)`.

- LHS: `merge void t`. `phase = 0`. 
- RHS: `t`. `phase = 1`.

`measure(LHS) = (0, cost)`, `measure(RHS) = (1, cost')`.

Since `1 > 0`, the measure **increases** lexicographically. The step `R_merge_void_left` here does not decrease the measure.

The same defect affects:
- **R_merge_void_right**: `merge t void → t` — same issue with the same `t`.
- **R_merge_cancel**: `merge t t → t` — with `t = recDelta void void (delta void)`, phase goes 0 → 1.
- **R_eq_diff**: `eqW a b → integrate (merge a b)` — RHS top-level is `integrate`, phase 0; LHS phase 0, so this one is fine on phase and cost decreases (LHS cost `3 + cost a + cost b`, RHS `1 + 1 + cost a + cost b`). ✓ Actually fine.

## Conclusion

**The measure is NOT sound.**

The flaw is that `phase` inspects only the top-level shape of a term, but several rules (`R_merge_void_left`, `R_merge_void_right`, `R_merge_cancel`) can expose a `recDelta _ _ (delta _)` subterm at the top level of the result. When the reduced term happens to be such a `recDelta`, `phase` jumps from 0 to 1, so the lexicographic pair increases rather than decreases.

Concretely, for `t = recDelta void void (delta void)`:
- `Step (merge void t) t` gives `measure (merge void t) = (0, _)` but `measure t = (1, _)`, which is **larger**.

So while the intended trouble-maker `R_rec_succ` is handled correctly by the `phase` component, that same non-compositional `phase` breaks the void/cancel merge rules. A correct measure would need `phase` (or an analogous ranking) to be robust under substitution of arbitrary subterms into the top position — e.g., by counting occurrences of the `recDelta _ _ (delta _)` pattern throughout the whole term rather than only at the root.
