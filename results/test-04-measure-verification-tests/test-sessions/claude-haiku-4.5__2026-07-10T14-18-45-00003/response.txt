# Assessment of the Lexicographic Termination Measure

## Summary
**The measure is UNSOUND.** It fails to prove termination for rule `R_rec_succ`.

## Detailed Analysis

### The Problematic Rule
```lean
| R_rec_succ : ∀ b s n, Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

This rule rewrites `recDelta b s (delta n)` to `app s (recDelta b s n)`.

### Why the Measure Fails

**Before the rewrite:**
- `phase(recDelta b s (delta n))` = 1 (matches the pattern `recDelta _ _ (.delta _)`)
- `cost(recDelta b s (delta n))` = 1 + cost(b) + cost(s) + cost(delta n)
                                  = 1 + cost(b) + cost(s) + (1 + cost(n))

**After the rewrite:**
- `phase(app s (recDelta b s n))` = 0 (doesn't match any phase pattern)
- `cost(app s (recDelta b s n))` = 1 + cost(s) + cost(recDelta b s n)
                                 = 1 + cost(s) + (1 + cost(b) + cost(s) + cost(n))
                                 = 2 + cost(b) + 2·cost(s) + cost(n)

### The Comparison

| Component | Before | After |
|-----------|--------|-------|
| **Phase** | 1 | 0 |
| **Cost** | 2 + cost(b) + cost(s) + cost(n) | 2 + cost(b) + 2·cost(s) + cost(n) |

The phase *does* decrease (1 → 0), which is good. However, the cost increases by `cost(s)` (unless `cost(s) = 0`, i.e., `s` is `void`). This creates a potential infinite rewrite sequence if `s` has positive cost.

**Counter-example rewrite sequence:**
```
recDelta void (delta void) (delta void)
→ (R_rec_succ) app (delta void) (recDelta void (delta void) void)
→ (R_rec_zero) app (delta void) void
```

While this particular sequence terminates, a measure that only decreases lexicographically on *some* rewrite paths (phase decreases once, then costs increase) is problematic. The phase component cannot compensate for unbounded cost growth on longer derivations.

## Conclusion

The measure lacks soundness because it doesn't establish a genuine well-founded ordering for all rewrite sequences. The phase component only decreases when `R_rec_succ` applies, but afterwards, the cost can grow without bound relative to the phase.
