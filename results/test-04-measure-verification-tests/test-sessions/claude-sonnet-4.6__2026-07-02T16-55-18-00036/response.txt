## Assessment of the Termination Measure

### The Proposed Measure

The measure is `(phase t, cost t)` ordered lexicographically, where:
- `phase t = 1` if `t = recDelta b s (delta n)`, else `0`
- `cost t` is a structural size measure

For soundness, each rewrite step must **strictly decrease** this lexicographic measure.

---

### Analysis of Each Rule

**R_int_delta**: `integrate (delta t) → void`
- Both have phase 0. Cost: `1 + 1 + cost t` → `0`. ✓ Decreases.

**R_merge_void_left**: `merge void t → t`
- Both phase 0. Cost: `1 + 0 + cost t` → `cost t`. ✓ Decreases.

**R_merge_void_right**: `merge t void → t`
- Both phase 0. Cost: `1 + cost t + 0` → `cost t`. ✓ Decreases.

**R_merge_cancel**: `merge t t → t`
- Both phase 0. Cost: `1 + cost t + cost t` → `cost t`. ✓ Decreases.

**R_rec_zero**: `recDelta b s void → b`
- Both phase 0. Cost: `1 + cost b + cost s + 0` → `cost b`. ✓ Decreases (assuming `cost s ≥ 0`).

**R_rec_succ**: `recDelta b s (delta n) → app s (recDelta b s n)`
- LHS phase = **1**. RHS = `app s (recDelta b s n)`, which is not of the form `recDelta _ _ (delta _)`, so RHS phase = **0**.
- Since `1 > 0`, the phase strictly decreases. ✓ (cost comparison irrelevant)

**R_eq_refl**: `eqW a a → void`
- Both phase 0. Cost: `3 + cost a + cost a` → `0`. ✓ Decreases.

**R_eq_diff**: `eqW a b → integrate (merge a b)`
- Both phase 0. Cost: `3 + cost a + cost b` → `1 + (1 + cost a + cost b)` = `2 + cost a + cost b`. ✓ Decreases (3 > 2).

---

### Critical Gap: The Measure is Not Closed Under Context

The measure only applies to the **root redex**. The calculus as defined has `Step` as a flat relation on whole terms — there are no congruence rules allowing reduction under binders or inside subterms. Therefore, **no contextual closure is defined**, and the measure only needs to handle the seven listed rules, which it does correctly.

**However**, if one intended this to model a full rewriting system with contextual closure, the measure would be **unsound**: after `R_rec_succ` fires, the result `app s (recDelta b s n)` contains a `recDelta` subterm that could itself match `recDelta b s (delta n')`, but the phase/cost of the *whole* term is not tracked structurally.

---

### Conclusion

**Within the literal definition given** (no congruence rules, reduction only at the root), the measure is **sound**: every step in `Step` strictly decreases `(phase t, cost t)` lexicographically. But the system is incomplete as a rewrite calculus, and the measure would **not extend soundly** to a contextually closed version without significant redesign.
