The proposed lexicographic termination measure `measure(t) = (phase t, cost t)` is **not sound**. A counterexample exists for the rewrite rule `R_merge_void_left`:

- Consider `t = recDelta b s (delta n)` for arbitrary `b, s, n`.  
  By definition of `phase`:  
  `phase t = 1` (matches `.recDelta _ _ (.delta _)`).  
  `phase (merge void t) = 0` (top-level constructor is `merge`, not `recDelta` with `delta` argument).

- Compute measures:  
  `measure (merge void t) = (0, 1 + cost t)`  
  `measure t = (1, cost t)`

- Lexicographic comparison requires `(1, cost t) < (0, 1 + cost t)`.  
  However:  
  - First components: `1 ≮ 0` (fails the primary comparison),  
  - Since `1 > 0`, `(1, cost t)` is **greater** than `(0, 1 + cost t)` in lexicographic order.  
  Thus, `measure t ≮ measure (merge void t)`.

This violates the strict decrease requirement for termination. The same flaw applies to:
- `R_merge_void_right` (with `merge t void → t` when `t` has phase 1),
- `R_merge_cancel` (with `merge t t → t` when `t` has phase 1),
- `R_rec_zero` (with `recDelta b s void → b` when `b` has phase 1).

While rules like `R_rec_succ` *do* decrease correctly (phase drops from 1 to 0, dominating cost changes), the existence of **any** rewrite step where the measure fails to decrease invalidates the entire termination argument. The measure’s phase component is too coarse—it resets to 0 on non-`recDelta` heads but allows phase-1 terms to emerge unchanged on the RHS of reductions involving `merge` or `recDelta` with non-`delta` arguments.

**Conclusion**: The measure is unsound. Termination cannot be established via this lexicographic pair due to counterexamples where the phase component increases or fails to decrease strictly. A sound measure would need finer-grained phase tracking (e.g., structural phase propagation) or a different well-founded order.
