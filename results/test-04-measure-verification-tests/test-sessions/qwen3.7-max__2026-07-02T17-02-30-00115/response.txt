## Assessment: The Measure is **Not Sound**

The proposed lexicographic measure `(phase t, cost t)` fails to decrease for several rewrite rules. The core problem is that the `phase` function can **increase** from 0 to 1 during a reduction step, which violates the requirement that the measure must strictly decrease in lexicographic order.

### Detailed Counterexamples

The `phase` function assigns `1` to terms of the form `recDelta _ _ (delta _)` and `0` to everything else. Several rules can "expose" or produce such a term from a wrapper that has phase `0`:

#### 1. `R_merge_void_left`: `merge void t → t`

Let `t = recDelta b s (delta n)`.

| | LHS: `merge void t` | RHS: `t` |
|---|---|---|
| **phase** | 0 | **1** |
| **cost** | 1 + 0 + cost t = 1 + cost t | cost t |

We need `(1, cost t) < (0, 1 + cost t)` lexicographically. This requires `1 < 0` in the first component, which is **false**.

#### 2. `R_merge_void_right`: `merge t void → t`

Identical issue when `t = recDelta b s (delta n)`. Phase goes from `0` to `1`. **Fails.**

#### 3. `R_merge_cancel`: `merge t t → t`

Same issue when `t = recDelta b s (delta n)`. Phase goes from `0` to `1`. **Fails.**

#### 4. `R_rec_zero`: `recDelta b s void → b`

Let `b = recDelta b' s' (delta n')`.

| | LHS: `recDelta b s void` | RHS: `b` |
|---|---|---|
| **phase** | 0 (third arg is `void`, not `delta _`) | **1** |
| **cost** | 1 + cost b + cost s | cost b |

We need `(1, cost b) < (0, 1 + cost b + cost s)`. Again requires `1 < 0`. **Fails.**

### Rules That Do Work

- **`R_rec_succ`**: Phase goes from `1` to `0` — the first component decreases, so it succeeds regardless of cost.
- **`R_int_delta`**, **`R_eq_refl`**, **`R_eq_diff`**: Phase stays at `0` and cost strictly decreases.

### Root Cause

The `phase` function is meant to give priority to `recDelta` reductions (presumably to handle the `R_rec_succ` rule, which duplicates `s` and increases `cost`). However, the design is flawed because other rules can **produce** a `recDelta _ _ (delta _)` term as their result, causing the phase to jump from `0` to `1`. A sound measure would need to ensure the phase is **monotonically non-increasing** across all rules, or account for the phase of subterms in the cost function.
