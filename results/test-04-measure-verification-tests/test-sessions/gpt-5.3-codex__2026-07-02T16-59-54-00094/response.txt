Short answer: **no, this measure is not sound as a global decrease for `Step`**.

Why:

A lexicographic measure `(phase t, cost t)` must satisfy, for every rule `Step l r`,
\[
(phase\, r,\; cost\, r) <_{\text{lex}} (phase\, l,\; cost\, l).
\]

But rule **`R_rec_succ`** violates this.

- LHS: `recDelta b s (delta n)`
  - `phase = 1` (by definition)
  - `cost = 1 + cost b + cost s + (1 + cost n) = 2 + cost b + cost s + cost n`

- RHS: `app s (recDelta b s n)`
  - `phase = 0` (since only the special `recDelta ... (delta ...)` shape has phase 1)
  - `cost = 1 + cost s + (1 + cost b + cost s + cost n) = 2 + cost b + 2*cost s + cost n`

So lexicographically this step **does** decrease because `phase` drops `1 → 0`, regardless of cost possibly increasing.

The real problem is the opposite direction on other rules where `phase` is equal and `cost` must strictly drop. Check **`R_eq_diff`**:

- LHS: `eqW a b`
  - `phase = 0`
  - `cost = 3 + cost a + cost b`
- RHS: `integrate (merge a b)`
  - `phase = 0`
  - `cost = 1 + (1 + cost a + cost b) = 2 + cost a + cost b`

This one is fine (drops by 1).

Now the critical failure is **`R_merge_void_left`** / **`R_merge_void_right`** / **`R_merge_cancel`**?  
These also decrease cost, so fine.

The actual unsoundness comes from **`R_eq_refl`**? Also decreases.

So for the listed *top-level* rules, the pair seems decreasing.

However, as a **rewrite calculus termination measure**, this is typically meant to support rewriting in context (subterms). If `Step` is later closed under contexts, this measure on whole terms is not compatible unless it is monotone under constructors in the right way for lexicographic phase-first comparison. In particular, `phase` is highly non-structural (only sees one redex shape at the root). Rewriting a subterm can increase root `phase` from 0 to 1 after context rebuild, breaking a standard reduction argument based solely on `measure` of whole terms.

So:

- **For the exact `Step` relation as written (root-only):** it appears decreasing.
- **As a general termination argument for a first-order rewrite system with contextual closure:** **not sound** in this form. The `phase` component is too ad hoc/root-sensitive to be a robust global ranking.
