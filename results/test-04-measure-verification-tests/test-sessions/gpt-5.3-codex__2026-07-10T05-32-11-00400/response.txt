Short answer: **no, this measure is not sound as a global decreasing rewrite measure for `Step`**.

Why:

For termination via a lexicographic measure `(phase t, cost t)` into `Nat × Nat`, you need for every rule `Step l r`:
\[
(phase\ l,\ cost\ l) >_{lex} (phase\ r,\ cost\ r).
\]

A direct counterexample is rule **`R_eq_diff`**:
- LHS: `eqW a b`
  - `phase = 0`
  - `cost = 3 + cost a + cost b`
- RHS: `integrate (merge a b)`
  - `phase = 0`
  - `cost = 1 + (1 + cost a + cost b) = 2 + cost a + cost b`

So this one does decrease cost by 1 (good).

But rule **`R_int_delta`**:
- LHS: `integrate (delta t)`
  - `phase = 0`
  - `cost = 1 + (1 + cost t) = 2 + cost t`
- RHS: `void`
  - `phase = 0`
  - `cost = 0`
Also decreases (good).

The real issue is **`R_rec_succ`**:
- LHS: `recDelta b s (delta n)`
  - `phase = 1`
  - `cost = 1 + cost b + cost s + (1 + cost n) = 2 + cost b + cost s + cost n`
- RHS: `app s (recDelta b s n)`
  - `phase = 0`
  - `cost = 1 + cost s + (1 + cost b + cost s + cost n)
         = 2 + cost b + 2*cost s + cost n`

Lexicographically, phase drops `1 → 0`, so this step is accepted even if cost increases. That can be okay in lex order.

However, now look at what happens after one `R_rec_succ`: you create a `recDelta b s n` under `app`. If `n` is again `delta ...`, another `R_rec_succ` applies to that subterm (in any compatible closure setting), again dropping phase locally from 1 to 0 but potentially increasing cost by `cost s`. This can repeat as many times as there are deltas in `n`. A simple top-level `(phase t, cost t)` is not stable under context/recursive rewriting unless you prove every one-step rewrite on whole terms strictly decreases the whole-term measure. For subterm rewriting, this `phase` only inspects the root, so it does **not** account for redexes below the root and is therefore not a valid global ranking function for the usual closure of rewriting.

Even at root-step level only, another problem: many rules have `phase=0 → 0`, so they rely purely on cost. That part is okay individually, but the calculus includes **`R_eq_diff : eqW a b → integrate (merge a b)` for all `a b`**, including `a = b`. Then both `R_eq_refl` and `R_eq_diff` apply to `eqW a a`. Although both decrease cost at root, this overlap shows the system is nondeterministic; measure soundness still requires strict decrease for every chosen rule (which happens here), so overlap itself is not fatal.

So the key verdict:

- If `Step` is interpreted **only as root rewriting exactly as declared**, then each listed rule appears decreasing lexicographically with your definitions, so it is plausibly sound for that restricted relation.
- If intended as a **first-order rewrite calculus** in the standard sense (closed under contexts/substitutions), this measure is **not sound** as a termination argument, because `phase` is root-only and does not track nested `recDelta` redexes; `measure` on full terms will not necessarily decrease for contextual steps.

Given your wording (“first-order rewrite calculus”), I would assess it as **unsound for the intended global termination claim**.
