### Assessment of the Proposed Measure

The proposed termination measure is \(\operatorname{measure}(t) = (\operatorname{phase}(t), \operatorname{cost}(t))\), ordered lexicographically (with the usual order on \(\mathbb{N}\)). This is intended to show that the rewrite relation \(\operatorname{Step}\) is well-founded. For the measure to be sound, it is necessary that \(t \mathrel{\operatorname{Step}} u\) always implies \(\operatorname{measure}(t) >_{\mathrm{lex}} \operatorname{measure}(u)\).

This fails. While some rules decrease the measure, others do not (even when \(\operatorname{Step}\) is interpreted purely as root reduction, exactly as defined by the inductive rules). The problematic rules are those whose left-hand side has phase \(0\) but whose right-hand side may have phase \(1\):

- \(\operatorname{merge}\,\mathsf{void}\,t \to t\)
- \(\operatorname{merge}\,t\,\mathsf{void} \to t\)
- \(\operatorname{merge}\,t\,t \to t\)
- \(\operatorname{recDelta}\,b\,s\,\mathsf{void} \to b\)

In each case the left-hand side is never of the form \(\operatorname{recDelta}\_\_{\_}(\mathsf{delta}\_)\), so its phase is \(0\). The right-hand side may be of that form, yielding phase \(1\). Although \(\operatorname{cost}\) strictly decreases, the primary component of the measure *increases*, so the lexicographic pair increases.

#### Concrete counter-example
Let
\[
t \;=\; \operatorname{recDelta}\,\mathsf{void}\,\mathsf{void}\,(\mathsf{delta}\,\mathsf{void}).
\]
Then \(\operatorname{phase}(t)=1\) and \(\operatorname{cost}(t)=2\). The term \(\operatorname{merge}\,\mathsf{void}\,t\) therefore satisfies
\[
\operatorname{measure}(\operatorname{merge}\,\mathsf{void}\,t) = (0,3).
\]
Rule \(\mathrm{R\_merge\_void\_left}\) rewrites it to \(t\), whose measure is \((1,2)\). We have
\[
(0,3) \;<_{\mathrm{lex}}\; (1,2),
\]
so the measure *increases*.

(The same phenomenon occurs for the other three rules listed above.)

#### Rules that *do* decrease the measure
For completeness:

- \(\operatorname{integrate}(\mathsf{delta}\,t)\to\mathsf{void}\): both sides have phase \(0\), cost drops by at least \(2\).
- \(\operatorname{recDelta}\,b\,s\,(\mathsf{delta}\,n)\to\operatorname{app}\,s\,(\operatorname{recDelta}\,b\,s\,n)\): phase drops from \(1\) to \(0\) (the possible increase in cost is therefore irrelevant).
- Both \(\operatorname{eqW}\) rules: both sides have phase \(0\), cost drops by at least \(1\).

These successes do not rescue the measure, because a single increasing rule already renders it unsound for termination.

#### Remarks on contexts
Even if one silently closes \(\operatorname{Step}\) under arbitrary contexts (as is common for a “rewrite calculus”), the same counter-example still works: it is a root reduction. Reductions that occur strictly inside a non-empty context cannot raise the *global* phase (phase inspects only the root constructor), and the strictly monotonic cost function would then guarantee a decrease; the damage is already done by the root cases.

#### Conclusion
The measure is **not sound**: there exist \(\operatorname{Step}\)-steps that increase it. Consequently it cannot establish termination of the calculus.
