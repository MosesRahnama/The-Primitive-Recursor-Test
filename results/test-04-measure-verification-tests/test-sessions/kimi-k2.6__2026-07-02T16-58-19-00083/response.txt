**The measure is not sound.**

For a lexicographic measure `ℕ × ℕ` to prove termination it must *strictly decrease* on **every** rewrite step.  While the proposed `(phase t, cost t)` succeeds on some rules, it fails on others because the first component can increase.

### The problem

`phase t` is `1` only when `t` has the head form `recDelta _ _ (delta _)`.  On all other terms it is `0`.

This works for `R_rec_succ`:
- Source: `recDelta b s (delta n)` → `phase = 1`
- Target: `app s (recDelta b s n)` → `phase = 0`
The first component drops, so the lexicographic order decreases.

But on several rules the left-hand side is **not** of that form, so its phase is `0`, while the right-hand side can be instantiated to a term whose phase is `1`.

### Concrete counterexample

Consider rule `R_merge_void_left`: `merge void t → t`.

Let  
```
t := recDelta void void (delta void)
```

Compute the measure of `t`:
- `phase t = 1` (it matches `recDelta _ _ (delta _)`).
- `cost void = 0`
- `cost (delta void) = 1 + 0 = 1`
- `cost t = 1 + cost void + cost void + cost (delta void) = 1 + 0 + 0 + 1 = 2`
- Hence **`measure t = (1, 2)`**.

Compute the measure of the redex `merge void t`:
- `phase (merge void t) = 0` (head constructor is `merge`).
- `cost (merge void t) = 1 + cost void + cost t = 1 + 0 + 2 = 3`
- Hence **`measure (merge void t) = (0, 3)`**.

Now `Step (merge void t) t` holds by `R_merge_void_left`, but

```
(0, 3) < (1, 2)   in the lexicographic order
```

because `0 < 1`.  The rewrite step **increases** the measure.

### Other failing rules

The same issue arises for:
- `R_merge_void_right` and `R_merge_cancel` (instantiate `t` with `recDelta … (delta …)`).
- `R_rec_zero` (instantiate `b` with `recDelta … (delta …)`; the source has third argument `void`, so its phase is `0`, but the target `b` can have phase `1`).

Since the measure does not decrease on all valid steps, it is **unsound** as a termination measure for this rewrite calculus.
