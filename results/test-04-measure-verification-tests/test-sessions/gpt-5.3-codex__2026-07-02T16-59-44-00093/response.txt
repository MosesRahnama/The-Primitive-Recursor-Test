Short answer: **no, this measure is not sound for proving every `Step` decreases lexicographically**.

Why:

A lexicographic measure `(phase, cost)` decreases on a step `t → u` only if either:

1. `phase t > phase u`, or
2. `phase t = phase u` and `cost t > cost u`.

Your `phase` is only `1` for terms of shape `recDelta _ _ (delta _)`, otherwise `0`.

The problematic rule is:

- `R_eq_diff : Step (eqW a b) (integrate (merge a b))`

For this rule:
- `phase (eqW a b) = 0`
- `phase (integrate (merge a b)) = 0`

So we must compare `cost`:
- `cost (eqW a b) = 3 + cost a + cost b`
- `cost (integrate (merge a b)) = 1 + (1 + cost a + cost b) = 2 + cost a + cost b`

This decreases by 1, so that one is fine.

But the real failure is:

- `R_rec_succ : Step (recDelta b s (delta n)) (app s (recDelta b s n))`

Here:
- LHS phase = `1`
- RHS phase = `0`

So phase decreases: good.

Now check all phase-0 rules by cost. Most decrease, except:

- `R_eq_diff` decreases (fine)
- `R_merge_void_*`, `R_merge_cancel`, `R_int_delta`, `R_rec_zero`, `R_eq_refl` all decrease (fine)

So at first glance this looks okay for **top-level** steps only.

However, there is a deeper issue: `R_eq_diff` is unconditional (`∀ a b`) and overlaps with `R_eq_refl` when `a = b`. You then have both:

- `eqW a a → void` (cost drop large)
- `eqW a a → integrate (merge a a)` (cost drop by 1 only)

Still decreasing, so no contradiction for termination measure itself.

So if we interpret `Step` exactly as one-step root rewrite, the proposed measure actually **does** decrease for every constructor rule.

Hence final judgment:

- **Sound for the given `Step` relation as written (root steps only)**.
- **Not sufficient** if you intended a contextual/closure rewrite relation (rewriting inside subterms), because `measure` of the whole term may then fail to decrease unless you lift the proof carefully with a context-compatible argument.

So the key caveat: as-is, for this exact inductive `Step`, the lexicographic measure is sound.
