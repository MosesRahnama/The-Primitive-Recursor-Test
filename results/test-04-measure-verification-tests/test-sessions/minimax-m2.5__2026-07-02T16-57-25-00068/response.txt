**Short answer:**  
No. The pair `(phase, cost)` does **not** strictly decrease for every rewrite rule, so it cannot be used as a termination‑measure for the calculus as defined.

---

### Why the measure can fail

The measure is  

```
measure t := (phase t, cost t)   -- lexicographic order on Nat × Nat
```

We say a rewrite step `L → R` is *decreasing* if  

```
measure L  >  measure R   (lexicographically)
```

Below we examine each rule.

| Rule | `phase(L)` | `cost(L)` | `phase(R)` | `cost(R)` | Does `measure L > measure R`? |
|------|------------|-----------|------------|-----------|------------------------------|
| `R_int_delta` | 0 | `2 + cost(t)` | 0 | 0 | **Yes** |
| `R_merge_void_left` | 0 | `1 + cost(t)` | **phase(t)** | `cost(t)` | **No** if `phase(t)=1` (i.e. `t = recDelta _ _ (delta _)`) |
| `R_merge_void_right` | 0 | `1 + cost(t)` | **phase(t)** | `cost(t)` | **No** for the same reason |
| `R_merge_cancel` | 0 | `1 + 2·cost(t)` | **phase(t)** | `cost(t)` | **No** when `phase(t)=1` |
| `R_rec_zero` | 0 | `1 + cost(b) + cost(s)` | **phase(b)** | `cost(b)` | **No** when `phase(b)=1` |
| `R_rec_succ` | 1 | `2 + cost(b)+cost(s)+cost(n)` | 0 | `2 + cost(b)+2·cost(s)+cost(n)` | **Yes** (phase drops) |
| `R_eq_refl` | 0 | `3 + 2·cost(a)` | 0 | 0 | **Yes** |
| `R_eq_diff` | 0 | `3 + cost(a)+cost(b)` | 0 | `2 + cost(a)+cost(b)` | **Yes** |

The four rules `R_merge_void_left`, `R_merge_void_right`, `R_merge_cancel`, and `R_rec_zero` can increase the first component of the measure:

* If the right‑hand side happens to be a term of the form `recDelta _ _ (delta _)`, its `phase` is 1 while the left‑hand side has `phase` 0.  
* Because lexicographic order prioritises the first component, the whole pair *decreases* (i.e. `measure L < measure R`) in those cases, violating the required strict descent.

A concrete counter‑example:

```
let t := recDelta b s (delta n)      -- phase(t) = 1, cost(t) = 1 + cost(b) + cost(s) + (1+cost(n))

merge void t  →  t
```

- Left side: `measure(merge void t) = (0, 1 + cost(t))`  
- Right side: `measure(t) = (1, cost(t))`

Since `0 < 1`, the lexicographic order gives `(0, …) < (1, …)`. The measure **increases**, not decreases.

The same problem occurs for `recDelta b s void → b` when `b` itself is a `recDelta` with a `delta` in the third argument.

---

### Conclusion

Because the proposed `measure` is not decreasing for all rewrite steps, it is **not a sound termination measure** for the calculus as presented. In particular, the four rules mentioned above break the required well‑founded descent. To obtain a correct termination proof one would need to either

1. modify the `phase` function so that it decreases (e.g., swap the values 0 and 1), or  
2. add a different ranking component that dominates the possible increase of `phase`, or  
3. restrict the rewrite system to the subset of rules that already reduce `phase`.

But as the file stands, the lexicographic pair `(phase, cost)` does **not** guarantee termination.
