The measure is sound.

**Reasoning:**
We need to verify that for every rewrite rule `Step t u`, the measure strictly decreases in the lexicographic order on `ℕ × ℕ`, i.e., `measure u < measure t`. The measure is `(phase t, cost t)` where:
- `phase t` is `1` if `t` is of the form `recDelta _ _ (delta _)`, else `0`.
- `cost t` is a positive weight that sums the sizes of subterms.

Let's check each rule:

1. **R_int_delta**: `integrate (delta t) → void`  
   Both sides have `phase = 0`.  
   `cost(void) = 0`, `cost(integrate (delta t)) = 2 + cost t`.  
   `0 < 2 + cost t` holds.

2. **R_merge_void_left**: `merge void t → t`  
   `phase` stays `0`.  
   `cost(merge void t) = 1 + cost t`, strict decrease.

3. **R_merge_void_right**: `merge t void → t`  
   Analogous, `cost` drops by at least `1`.

4. **R_merge_cancel**: `merge t t → t`  
   `cost(merge t t) = 1 + 2·cost t > cost t`.

5. **R_rec_zero**: `recDelta b s void → b`  
   `phase = 0` (third argument is `void`, not `delta _`).  
   `cost(LHS) = 1 + cost b + cost s`, `cost(RHS) = cost b`. Decrease holds because `1 + cost s > 0`.

6. **R_rec_succ**: `recDelta b s (delta n) → app s (recDelta b s n)`  
   Here the left‑hand side has `phase = 1` because the third argument is `delta n`.  
   The right‑hand side is an `app` term, so its `phase` is `0`.  
   Lexicographically `(0, _) < (1, _)` irrespective of costs. Strict decrease.

7. **R_eq_refl**: `eqW a a → void`  
   `phase = 0` for both.  
   `cost(LHS) = 3 + 2·cost a > 0 = cost(void)`.

8. **R_eq_diff**: `eqW a b → integrate (merge a b)`  
   `phase = 0` for both.  
   `cost(LHS) = 3 + cost a + cost b`, `cost(RHS) = 2 + cost a + cost b`.  
   `2 < 3` guarantees `cost(RHS) < cost(LHS)`.

Every step strictly reduces `measure`. Therefore the lexicographic measure `(phase, cost)` is a sound termination measure for this rewrite system.
