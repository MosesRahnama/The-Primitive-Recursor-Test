No – the proposed measure

    measure t := (phase t , cost t)      -- ordered lexicographically
                                            -- (first compare phase, then cost)

is not monotonically decreasing along every reduction step of `Step`.  
It already fails for the constructor-free rule

    R_rec_zero :  Step (recDelta b s void)  b

Phase component
---------------

phase (recDelta b s void)      = 0                    -- because the third
                                                      -- argument is *not* a
                                                      -- `delta _`

phase b = 1 is possible whenever `b` itself is of the
form `recDelta _ _ (delta _)`.

Thus we can choose, for example,

    b := recDelta void void (delta void)
    s := void

and obtain the step

    t₀ := recDelta (recDelta void void (delta void)) void void
           ↠   b := recDelta void void (delta void)

with

    phase t₀ = 0
    phase b  = 1 .

Lexicographically we compare first components first, so

    (phase t₀,  cost t₀) = (0, …)
    (phase b,   cost b)  = (1, …)

and (0, …) is **smaller** than (1, …).  
Consequently the measure increases, contradicting the requirement that it
must strictly decrease along every reduction step for a sound termination
argument.

Cost component
--------------

Even though the cost of the right–hand side is smaller than the cost of the
left–hand side, the lexicographic order never consults the second component
once the first components differ, so the increase in `phase` cannot be
compensated.

Conclusion
----------

Because the rule `R_rec_zero` can increase the first (phase) component,
the pair `(phase, cost)` is **not** a well-founded, strictly decreasing
measure for the whole rewrite system.  The termination argument based on
this measure is therefore unsound; at least the treatment of the
`recDelta … void` rule must be changed (e.g. by redefining `phase`,
introducing a third component, or reversing the order on the first
component) to restore soundness.
