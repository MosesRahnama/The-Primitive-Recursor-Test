The proposed measure is not sound, as several rules (e.g. `R_merge_void_left`, `R_rec_zero`) admit steps that increase the first component.

**Explanation**

The measure is intended to decrease on every `Step t t'` (under lexicographic order on `Nat × Nat`, with `phase` primary). This holds for `R_int_delta`, `R_merge_cancel`, `R_rec_succ`, `R_eq_refl`, and `R_eq_diff` (either the primary component strictly drops or the components are equal and the secondary strictly drops).

It fails for `R_merge_void_left`, `R_merge_void_right`, and `R_rec_zero`. For a counterexample to the first, let `t ≔ recDelta b s (delta n)`. Then `phase(merge void t) = 0` but `phase(t) = 1`, so the primary component increases from 0 to 1 (regardless of the secondary components). The same occurs for the other two rules when the right-hand side has `phase = 1`. Since the measure does not decrease on every step, it does not prove termination.
