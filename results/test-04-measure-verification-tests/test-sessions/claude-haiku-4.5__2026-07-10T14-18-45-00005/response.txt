# Assessment of the Termination Measure

## Verdict: **UNSOUND**

The lexicographic measure `(phase t, cost t)` is **not sound** for proving termination of the rewrite system. Here are the critical issues:

### 1. **Phase Does Not Decrease (Critical)**

The `phase` function only assigns a special value to `recDelta b s (delta _)`:
```lean
phase (recDelta b s (delta n)) = 1
phase _ = 0
```

Consider the rewrite rule **R_rec_succ**:
```
recDelta b s (delta n) → app s (recDelta b s n)
```

- **Before**: `phase(recDelta b s (delta n)) = 1`
- **After**: `phase(app s (recDelta b s n)) = 0` (since `app` is not `recDelta` with a `delta` argument)

The phase **increases** (1 → 0 in the second component means we're checking cost), but the cost of the right-hand side depends entirely on `cost(recDelta b s n)`. If this cost is large enough, the second component may not decrease sufficiently.

### 2. **Cost May Not Decrease**

For rule **R_rec_succ** with the measure transitioning to the cost component:
```
recDelta b s (delta n) → app s (recDelta b s n)
```

The cost function gives:
- **LHS cost**: `1 + cost(b) + cost(s) + cost(delta n)` 
  - = `1 + cost(b) + cost(s) + (1 + cost(n))`
  - = `2 + cost(b) + cost(s) + cost(n)`

- **RHS cost**: `1 + cost(s) + cost(recDelta b s n)`
  - = `1 + cost(s) + (1 + cost(b) + cost(s) + cost(n))`
  - = `2 + cost(b) + 2·cost(s) + cost(n)`

The RHS cost is **larger** by `cost(s)`, so cost strictly increases. The measure fails.

### 3. **Other Problematic Rules**

- **R_eq_diff**: `eqW a b → integrate (merge a b)`
  - Cost increases from `3 + cost(a) + cost(b)` to `1 + (1 + cost(a) + cost(b))` = `2 + cost(a) + cost(b)` plus the integrate wrapper
  - This rule itself may not be problematic, but combined with others it breaks termination

The measure cannot prove termination of this rewrite system as designed.
