# Assessment of the Termination Measure

## Verdict: **UNSOUND**

The lexicographic measure `(phase t, cost t)` fails to prove termination. Here's why:

## Critical Counterexample

Consider rule **R_rec_succ**:
```
Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

**Before:** `recDelta b s (delta n)`
- `phase = 1` (matches the pattern in `phase`)
- `cost = 1 + cost b + cost s + cost n + 1` (the inner `delta n` adds 1)

**After:** `app s (recDelta b s n)`
- `phase = 0` (doesn't match `recDelta ... (delta _)`)
- `cost = 1 + cost s + (1 + cost b + cost s + cost n)`

The phase decreases (1 → 0), which is good. However, **the cost can increase** depending on the structure:
- `cost(before) = 1 + cost b + cost s + (1 + cost n)`
- `cost(after) = 1 + cost s + 1 + cost b + cost s + cost n`
- `cost(after) - cost(before) = cost s`

When `cost s > 0`, the second component of the measure increases while the first decreases. Since the measure is lexicographic, a decrease in the first component should make the overall measure decrease regardless of the second component. But this only works if we're guaranteed that once phase decreases, it stays low for future steps.

## The Real Problem

There's no guarantee that subsequent reductions of `app s (recDelta b s n)` will keep `phase = 0`. If `app` or further reductions eventually reconstruct another pattern matching `recDelta ... (delta _)`, the phase could increase again, creating a potential loop.

**The measure lacks sufficient constraints on the interaction between phase and cost to guarantee global termination.**

## Recommendation

A sound measure would need to ensure that phase decreases monotonically across all reductions, or the cost function would need to account for the "potential" that allows phase increases in later steps.
