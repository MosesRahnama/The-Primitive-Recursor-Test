The lexicographic measure `(phase t, cost t)` is **not sound** for the given rewrite system. Several reduction rules allow the right‑hand side to have a larger measure in the first component, violating the required decrease.

In particular, consider the rule:

```lean
| R_merge_void_left  : ∀ t, Step (merge void t) t
```

Take `t := recDelta b s (delta n)`. Then:

- LHS = `merge void (recDelta b s (delta n))` → `phase = 0`  
- RHS = `recDelta b s (delta n)` → `phase = 1` (because the third argument is `.delta _`)

The lexicographic order would require `(1, cost(RHS)) < (0, cost(LHS))`, but `1 > 0`. Hence the measure does not decrease; it actually *increases* in the first component. The same problem occurs with `R_merge_void_right`, `R_merge_cancel`, and `R_rec_zero` when suitably instantiated (e.g., `b` in `R_rec_zero` is a `recDelta` with a `delta`).

Since the measure fails to be strictly decreasing for all possible steps, it is not a valid termination measure for this rewrite relation.
