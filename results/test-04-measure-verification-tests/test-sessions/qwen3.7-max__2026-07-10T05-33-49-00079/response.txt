The proposed lexicographic termination measure is **unsound**. 

In a first-order rewrite calculus, a valid termination measure must not only strictly decrease for every base rewrite rule, but it must also be **monotonic** (compatible with contexts). This means that if a term $s$ rewrites to $t$ (so $\text{measure}(s) > \text{measure}(t)$), then placing both terms in any arbitrary context $C$ must also yield a decrease: $\text{measure}(C[s]) > \text{measure}(C[t])$. 

While the measure strictly decreases for all base rules at the root, it fails the monotonicity requirement due to the `R_rec_succ` rule.

### The Flaw in `R_rec_succ`
Consider the `R_rec_succ` rule:
`Step (recDelta b s (delta n)) (app s (recDelta b s n))`

Let's evaluate the measure for the left-hand side (LHS) and right-hand side (RHS) of this rule:
* **LHS:** `recDelta b s (delta n)`
  * `phase` = 1 (matches the `.recDelta _ _ (.delta _)` pattern)
  * `cost` = $1 + \text{cost}(b) + \text{cost}(s) + (1 + \text{cost}(n)) = 2 + \text{cost}(b) + \text{cost}(s) + \text{cost}(n)$
* **RHS:** `app s (recDelta b s n)`
  * `phase` = 0 (top-level constructor is `app`, not `recDelta`)
  * `cost` = $1 + \text{cost}(s) + (1 + \text{cost}(b) + \text{cost}(s) + \text{cost}(n)) = 2 + \text{cost}(b) + 2 \cdot \text{cost}(s) + \text{cost}(n)$

At the root, the measure decreases lexicographically because the `phase` drops from 1 to 0. However, notice that the `cost` actually **increases** by $\text{cost}(s)$. 

### Counterexample to Monotonicity
Because the `phase` function only inspects the top-level constructor of the term, placing the redex inside *any* context will mask the phase difference, forcing both the LHS and RHS to have a phase of 0. When this happens, the lexicographic comparison falls back to the `cost`, which we just established strictly increases.

Let $s$ be a term with a non-zero cost, for example, $s = \text{delta void}$ (which has $\text{cost} = 1$). 
Now, place the `R_rec_succ` redex inside the context $C = \text{delta } []$:

1. **Contextual LHS:** $C[\text{LHS}] = \text{delta } (\text{recDelta } b \text{ } s \text{ } (\text{delta } n))$
   * `phase` = 0 (top-level is `delta`)
   * `cost` = $1 + \text{cost}(\text{LHS})$

2. **Contextual RHS:** $C[\text{RHS}] = \text{delta } (\text{app } s \text{ } (\text{recDelta } b \text{ } s \text{ } n))$
   * `phase` = 0 (top-level is `delta`)
   * `cost` = $1 + \text{cost}(\text{RHS})$

Because $\text{cost}(\text{RHS}) > \text{cost}(\text{LHS})$, it follows that $\text{cost}(C[\text{RHS}]) > \text{cost}(C[\text{LHS}])$. 

Comparing their measures:
* $\text{measure}(C[\text{LHS}]) = (0, \text{cost}(C[\text{LHS}]))$
* $\text{measure}(C[\text{RHS}]) = (0, \text{cost}(C[\text{RHS}]))$

Since the phases are equal and the cost has strictly increased, $\text{measure}(C[\text{LHS}]) < \text{measure}(C[\text{RHS}])$. 

### Conclusion
The measure increases when the `R_rec_succ` rewrite step is performed under a context (like `delta []`, `merge [] void`, etc.). Because the measure is not monotonic, it is **unsound** for proving the termination of the rewrite calculus.
