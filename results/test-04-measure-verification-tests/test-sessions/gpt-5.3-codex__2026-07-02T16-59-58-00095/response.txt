The proposed measure

\[
\text{measure}(t) = (\text{phase } t,\ \text{cost } t)
\]

with lexicographic order on `Nat × Nat` is **not sound** for all rules in `Step`.

### Why it fails

A sound termination measure for one-step rewriting should strictly decrease on every rule:
\[
\text{Step } l\ r \implies \text{measure}(r) <_{\text{lex}} \text{measure}(l).
\]

Consider rule `R_rec_succ`:

- LHS: `recDelta b s (delta n)`
- RHS: `app s (recDelta b s n)`

Compute phases:

- `phase (recDelta b s (delta n)) = 1`
- `phase (app s (recDelta b s n)) = 0`

So phase decreases (`1 → 0`), which is good lexicographically regardless of cost.

But now check rule `R_int_delta`:

- LHS: `integrate (delta t)` has `phase = 0`
- RHS: `void` has `phase = 0`

So we rely on `cost` decrease:
- `cost (integrate (delta t)) = 1 + (1 + cost t) = 2 + cost t`
- `cost void = 0`
decreases, fine.

Similarly for `merge` and `rec_zero` and `eq_refl`: all phase equal, cost drops.

The critical failure is `R_eq_diff`:
- LHS: `eqW a b`
- RHS: `integrate (merge a b)`

Phases:
- both `0`, so need cost drop.

Costs:
- `cost (eqW a b) = 3 + cost a + cost b`
- `cost (integrate (merge a b)) = 1 + (1 + cost a + cost b) = 2 + cost a + cost b`

This **does** decrease by 1, so still fine.

So all listed rules do decrease under this local check.  
However, there is a deeper issue: because `Step` is only top-level rewriting, this is sufficient for one-step termination of that relation. If your intended calculus is a **rewrite relation closed under contexts** (usual term rewriting), the measure as defined on whole terms is generally **not enough as stated** unless you prove compatibility with contexts (or lift to a recursive/path ordering argument). In particular, `phase` only inspects the root; under contextual closure, redexes inside subterms can fire without changing root phase in a controlled way, and lexicographic decrease of whole-term `(phase, cost)` is not immediate from just root rules.

## Verdict

- For the exact `Step` relation shown (root-only rules): **sound** (each rule strictly decreases `(phase, cost)` lexicographically).
- For a standard context-closed rewrite system (if that is what you meant by “calculus”): **not yet justified**; additional proof obligations are needed.
