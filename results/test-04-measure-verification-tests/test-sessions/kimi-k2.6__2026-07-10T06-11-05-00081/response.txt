**Conclusion: the measure is not sound.**

A lexicographic measure \((\text{phase}, \text{cost})\) is sound only if **every** rewrite step strictly decreases the pair in the standard lexicographic order on \(\mathbb{N} \times \mathbb{N}\). The problem is that several rules can produce a term with \(\text{phase} = 1\) from a term with \(\text{phase} = 0\). Because phase is the most significant component, the measure actually *increases* on those steps.

---

### Why it fails

`phase t = 1` only when the top-level constructor is `recDelta _ _ (delta _)`. Every other term—including `merge …`, `integrate …`, and `recDelta _ _ void`—has phase `0`.

Now consider the following rules:

1. **`R_merge_void_left`** : `merge void t → t`  
   The left-hand side is a `merge`, so its phase is `0`. If we pick `t` to be a term whose top-level constructor is `recDelta _ _ (delta _)`, then the right-hand side has phase `1`. The measure goes from `(0, …)` to `(1, …)`, which is a lexicographic *increase*.

2. **`R_merge_void_right`** : `merge t void → t`  
   Same issue.

3. **`R_merge_cancel`** : `merge t t → t`  
   Same issue.

4. **`R_rec_zero`** : `recDelta b s void → b`  
   The left-hand side is `recDelta` with third argument `void`, so its phase is `0`. If `b` itself is a `recDelta _ _ (delta _)`, the right-hand side has phase `1`. Again the measure increases.

---

### Concrete counterexample

Take the rule `R_merge_void_left` with  

\[
t \;=\; \text{recDelta}\;\text{void}\;\text{void}\;(\delta\;\text{void}).
\]

**Left-hand side:** `merge void t`  
- `phase = 0` (top symbol is `merge`)  
- `cost = 1 + cost(\text{void}) + cost(t) = 1 + 0 + 2 = 3`  
  (since `cost(t) = 1 + 0 + 0 + cost(\delta\;\text{void}) = 1 + 1 = 2`)  
- **Measure:** \((0, 3)\)

**Right-hand side:** `t`  
- `phase = 1` (matches `.recDelta _ _ (.delta _)`)  
- `cost = 2`  
- **Measure:** \((1, 2)\)

We have a valid step  

\[
\text{Step}\;(\text{merge}\;\text{void}\;t)\;t,
\]

yet \((1,2) > (0,3)\) lexicographically. The measure does not decrease.

---

### Another counterexample (for `R_rec_zero`)

Let  

\[
b = \text{recDelta}\;\text{void}\;\text{void}\;(\delta\;\text{void}),\qquad
s = \text{void}.
\]

**Left-hand side:** `recDelta b s void`  
- `phase = 0` (third argument is `void`, not `delta`)  
- `cost = 1 + cost(b) + cost(s) + cost(\text{void}) = 1 + 2 + 0 + 0 = 3\)  
- **Measure:** \((0, 3)\)

**Right-hand side:** `b`  
- `phase = 1`  
- `cost = 2\)  
- **Measure:** \((1, 2)\)

Again the measure increases.

---

### Summary

Because the rewrite system allows “creating” a top-level `recDelta _ _ (delta _)` out of contexts that have phase `0` (merge, or recDelta with a `void` third argument), the first component of the lexicographic pair can rise. A single step that increases the first component is enough to break termination. Therefore, the proposed measure **\((\text{phase}, \text{cost})\) is unsound**.
