**The measure is not sound.**  

The proposed lexicographic ordering is  
\((\text{phase},\ \text{cost})\) with the usual well‑founded lexicographic order on \(\mathbb{N}\times\mathbb{N}\).  
For a termination measure to be sound we need **every** rewrite step to strictly decrease this pair.  
While the second component (`cost`) does decrease on most rules, the first component (`phase`) is **not** monotonic: several rules can strip away an outer constructor and expose a `recDelta _ _ (delta _)` subterm, causing `phase` to jump from `0` to `1`.

---

### Concrete counterexample

Take the rule **`R_merge_void_left`**:
```lean
Step (merge void t) t
```

Let  
\[
t \;=\; \text{recDelta}\ \text{void}\ \text{void}\ (\delta\ \text{void})
\]

**Left‑hand side:** `merge void t`

* `phase (merge void t) = 0` (it is a `merge`, not a `recDelta` with `delta` in the third argument).
* `cost (delta void) = 1 + cost void = 1`.
* `cost t = 1 + cost void + cost void + cost (delta void) = 1 + 0 + 0 + 1 = 2`.
* `cost (merge void t) = 1 + cost void + cost t = 1 + 0 + 2 = 3`.

So  
\[
\text{measure}(\text{merge void t}) = (0,\; 3).
\]

**Right‑hand side:** `t`

* `phase t = 1` (by definition of `phase`, since `t` is exactly `recDelta _ _ (delta _)`).
* `cost t = 2`.

So  
\[
\text{measure}(t) = (1,\; 2).
\]

Now compare the two pairs lexicographically:
\[
(0,3) \;<\; (1,2)
\]
because \(0 < 1\).  
The **measure increases** on this rewrite step, so it does not establish termination.

---

### Why this happens

The function `phase` only looks at the *outermost* shape of a term. Rules such as

* `R_merge_void_left` / `R_merge_void_right` / `R_merge_cancel`
* `R_rec_zero`

can discard the outer constructor and return an arbitrary subterm. If that subterm happens to be a `recDelta _ _ (delta _)`, its phase is `1` while the original term had phase `0`. No amount of decrease in `cost` can compensate for an increase in the first component of a lexicographic pair.

---

### Conclusion

Because `phase` can grow during rewriting, the lexicographic measure `(phase t, cost t)` is **unsound** for proving termination of this calculus. A valid measure would need a first component that never increases (or a more sophisticated ordering that accounts for the nesting of `recDelta`).
