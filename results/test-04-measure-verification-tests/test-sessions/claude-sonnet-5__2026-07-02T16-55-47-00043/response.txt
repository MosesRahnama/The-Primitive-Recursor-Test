## Assessment: **The measure is NOT sound.**

The intended use of `measure : Trace → Nat × Nat` (lexicographic on `Nat × Nat`) as a termination measure requires that **every** `Step t t'` satisfies `measure t' < measure t` in the lexicographic order. This fails for several rules.

### Counterexample: `R_merge_void_left`

Take `t := recDelta b s (delta n)` for arbitrary `b s n`. This `t` has `phase t = 1` (it matches the `recDelta _ _ (.delta _)` pattern).

Consider the step
```
Step (merge void t) t
```
which is a valid instance of `R_merge_void_left`.

- **Source** `merge void t`:
  - `phase (merge void t) = 0` (the top constructor is `merge`, not `recDelta _ _ (delta _)`), regardless of what `t` is.
  - `cost (merge void t) = 1 + cost void + cost t = 1 + cost t`.
  - So `measure (merge void t) = (0, 1 + cost t)`.

- **Target** `t = recDelta b s (delta n)`:
  - `phase t = 1`.
  - `cost t = 1 + cost b + cost s + cost (delta n)`.
  - So `measure t = (1, cost t)`.

Comparing lexicographically:
```
(0, 1 + cost t)  vs  (1, cost t)
```
Since the first components satisfy `0 < 1`, we get
```
measure (merge void t) < measure t
```
i.e. the measure **strictly increases** along this rewrite step, rather than decreasing.

### Why this happens

`phase` is designed to detect the "unblocking" pattern `recDelta _ _ (delta _)` (presumably to justify termination of `R_rec_succ`, which does *not* decrease `cost` in a naive structural sense, since `app s (recDelta b s n)` embeds `s` again). But `phase` is a purely syntactic, non-compositional check on the *top-level* shape of the term. Any rule that can **create** a top-level `recDelta _ _ (delta _)` redex out of a term that did not have this shape at the top (e.g. `merge void t`, `merge t void`, `merge t t`, or even nested occurrences produced by substitution-like rules) will cause `phase` to jump from `0` to `1`, increasing the first (dominant) component of the lexicographic pair — regardless of what happens to `cost`.

Since `R_merge_void_left`, `R_merge_void_right`, and `R_merge_cancel` are all *congruence-free, generic* rules (they apply to arbitrary `t`, including a `t` of the "unblocking" recDelta shape), they can each trigger this phase increase. This directly contradicts the requirement that `measure` strictly decreases at every `Step`.

### Conclusion

The pair `(phase, cost)` is **not** a valid termination measure for `Step`: `phase` is not stable/monotonic under rules that discard the "wrapping" constructor and expose an inner subterm, and there exist concrete step instances (as shown above) where `measure` strictly *increases*. Hence the proposed lexicographic order does not certify termination of the rewrite system as given.
