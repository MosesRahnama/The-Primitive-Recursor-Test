The proposed measure is **not sound**.

**Counterexample:**  
Consider the rewrite step `R_rec_zero` with base case `b := recDelta void void (delta void)`:

- **Left-hand side:** `recDelta (recDelta void void (delta void)) void void`
  - `phase` = 0 (the third argument is `void`, not `delta _`)
  - `cost` = 1 + 2 + 0 + 0 = 3
  - **Measure:** `(0, 3)`

- **Right-hand side:** `recDelta void void (delta void)`
  - `phase` = 1 (matches `.recDelta _ _ (.delta _)`)
  - `cost` = 1 + 0 + 0 + 1 = 2
  - **Measure:** `(1, 2)`

In the lexicographic order on `Nat × Nat`, we have `(0, 3) < (1, 2)` is **false**; rather `(1, 2) > (0, 3)` because the first component increases from 0 to 1. Thus the measure increases along this valid rewrite step.

**Why it fails:**  
The `phase` function distinguishes only terms of the form `recDelta _ _ (delta _)` (giving them phase 1). However, the rules `R_merge_void_left`, `R_merge_void_right`, `R_merge_cancel`, and `R_rec_zero` all rewrite a left-hand side with phase 0 to a right-hand side that may contain an arbitrary subterm (including one with phase 1). Therefore, the first component of the lexicographic measure can increase, breaking well-foundedness.

Only `R_rec_succ` correctly decreases the phase (from 1 to 0), but the other rules do not preserve or decrease the phase, making the overall measure unsound.
