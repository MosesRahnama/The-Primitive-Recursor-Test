The lexicographic termination measure `(phase, cost)` is **not sound**. The problem is that several rewrite rules have a left‑hand side with `phase = 0` but a right‑hand side that may have `phase = 1`. Since the lexicographic order compares the first component first, a step that increases the phase from 0 to 1 makes the measure larger, violating the decreasing requirement.

For example, take `t = recDelta void void (delta void)`. Then `phase(t) = 1`, `cost(t) = 2`. Applying `R_merge_void_left` gives:
- `merge void t` has `phase = 0` and `cost = 1 + cost(void) + cost(t) = 1 + 0 + 2 = 3`, so `measure(merge void t) = (0,3)`.
- `measure(t) = (1,2)`.
We need `(1,2) < (0,3)` lexicographically, but `1 > 0`, so the step **increases** the measure. The same issue affects `R_merge_void_right`, `R_merge_cancel`, and `R_rec_zero`. Therefore the proposed measure does not prove termination.
