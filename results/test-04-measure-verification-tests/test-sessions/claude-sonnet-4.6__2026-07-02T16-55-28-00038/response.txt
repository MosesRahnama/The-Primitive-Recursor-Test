## Assessment of the Termination Measure

### Overview

The proposed measure is a lexicographic pair `(phase t, cost t)` where:
- `phase t = 1` only when `t = recDelta b s (delta n)`, and `0` otherwise
- `cost t` is a structural size measure

The claim is that each rewrite step `Step t t'` satisfies `measure t' < measure t` lexicographically.

---

### Analysis of Each Rule

**R_int_delta**: `integrate (delta t) → void`
- Both have phase 0. Cost: `1 + 1 + cost t` → `0`. ✓ (cost strictly decreases)

**R_merge_void_left**: `merge void t → t`
- Both have phase 0. Cost: `1 + 0 + cost t` → `cost t`. ✓

**R_merge_void_right**: `merge t void → t`
- Same as above. ✓

**R_merge_cancel**: `merge t t → t`
- Phase 0 → 0. Cost: `1 + cost t + cost t` → `cost t`. ✓

**R_rec_zero**: `recDelta b s void → b`
- Phase 0 → 0. Cost: `1 + cost b + cost s + 0` → `cost b`. ✓

**R_eq_refl**: `eqW a a → void`
- Phase 0 → 0. Cost: `3 + cost a + cost a` → `0`. ✓

**R_eq_diff**: `eqW a b → integrate (merge a b)`
- Phase 0 → 0. Cost: `3 + cost a + cost b` → `1 + 1 + cost a + cost b = 2 + cost a + cost b`. ✓ (strictly decreases by 1)

**R_rec_succ**: `recDelta b s (delta n) → app s (recDelta b s n)`
- LHS phase = **1**; RHS = `app s (recDelta b s n)`.
- `recDelta b s n` has `phase = 1` only if `n = delta _`. The outer `app` has phase 0. So RHS phase = **0**.
- Since `1 > 0` lexicographically, the cost of the RHS is **irrelevant** — the measure decreases on the first component alone. ✓

---

### Critical Issue: No Congruence Rules

The calculus only defines top-level rewriting steps. There are **no congruence rules** (no rules of the form "if `Step t t'` then `Step (f t) (f t')`"). This means the calculus as defined only rewrites at the **root** of a term — subterms are never reduced.

For example, `app (eqW a b) c` can never step anywhere under this definition; `eqW a b` is stuck inside `app`.

**Within the scope of the rules as given**, the measure is sound. Every rule listed does strictly decrease `(phase, cost)`.

---

### Verdict

**The measure is sound for the rules as stated.** Every rule strictly decreases the lexicographic measure `(phase t, cost t)`. The phase trick correctly handles `R_rec_succ` by dropping from 1 to 0, making the cost comparison unnecessary for that case.

However, the calculus lacks congruence rules, so the measure only proves termination of **root-level** rewriting. A full confluence/termination proof would require closing under contexts, at which point the measure would need to be lifted to contexts (e.g., via a compatible well-founded order), which this file does not address.
