## Assessment of the Termination Measure

### What the measure proposes

The measure `measure t = (phase t, cost t)` uses a lexicographic ordering where:
- `phase t = 1` only when `t = recDelta b s (delta n)` (the recursive step rule), and `0` otherwise
- `cost t` is a structural size measure

### Checking each rewrite rule

For the measure to be sound, every `Step t t'` must satisfy `measure t' < measure t` lexicographically.

**R_int_delta**: `integrate (delta t) → void`
- `cost (integrate (delta t)) = 1 + 1 + cost t = 2 + cost t`
- `cost void = 0`
- Both have phase 0. Cost strictly decreases. ✓

**R_merge_void_left**: `merge void t → t`
- `cost (merge void t) = 1 + 0 + cost t = 1 + cost t > cost t`
- Both have phase 0. Cost strictly decreases. ✓

**R_merge_void_right**: `merge t void → t` — symmetric to above. ✓

**R_merge_cancel**: `merge t t → t`
- `cost (merge t t) = 1 + 2·cost t ≥ 1 + cost t > cost t`. ✓

**R_rec_zero**: `recDelta b s void → b`
- `cost (recDelta b s void) = 1 + cost b + cost s + 0 > cost b`
- Both have phase 0. ✓

**R_rec_succ**: `recDelta b s (delta n) → app s (recDelta b s n)`
- LHS has phase **1**; RHS is `app s (recDelta b s n)`, which has phase **0** (since `recDelta b s n` is not of the form `recDelta _ _ (delta _)` in general — it depends on `n`).
- Since phase decreases (1 → 0), the lexicographic order is satisfied **regardless of cost**. ✓
- However, note a subtlety: if `n` itself is `delta n'`, then `recDelta b s n` has phase 1 and `app s (recDelta b s n)` still has phase 0. The phase of the *outer* term is what matters, and `app ...` always has phase 0. ✓

**R_eq_refl**: `eqW a a → void`
- `cost (eqW a a) = 3 + 2·cost a ≥ 3 > 0 = cost void`. Both phase 0. ✓

**R_eq_diff**: `eqW a b → integrate (merge a b)`
- `cost (eqW a b) = 3 + cost a + cost b`
- `cost (integrate (merge a b)) = 1 + (1 + cost a + cost b) = 2 + cost a + cost b`
- `3 + cost a + cost b > 2 + cost a + cost b`. Both phase 0. ✓

### Conclusion

**The measure is sound.** Every rewrite step strictly decreases the lexicographic measure `(phase, cost)`:

- `R_rec_succ` decreases the phase component (1 → 0), so the cost need not decrease.
- All other rules have phase 0 on both sides and strictly decrease the cost.

The measure correctly handles the only "expensive" rule (`R_rec_succ`) by assigning it a higher phase, and the `eqW` cost inflation by 3 (vs. 2 for `integrate (merge ...)`) is the critical design choice that makes `R_eq_diff` work.
