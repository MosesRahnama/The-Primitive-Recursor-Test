The proposed lexicographic measure is **not sound**: some rewrite steps increase the first component `phase`.

Let

```lean
u := recDelta void void (delta void)
```

Then:

```lean
phase u = 1
cost u = 1 + 0 + 0 + 1 = 2
measure u = (1, 2)
```

By `R_merge_void_left`:

```lean
Step (merge void u) u
```

For the source:

```lean
phase (merge void u) = 0
cost (merge void u) = 1 + 0 + 2 = 3
measure (merge void u) = (0, 3)
```

Thus the step changes the measure as follows:

```text
(0, 3) → (1, 2)
```

Under lexicographic ordering with `phase` as the primary component, this is an **increase**, not a decrease.

The same issue affects:

- `R_merge_void_right`
- `R_merge_cancel`
- `R_rec_zero`

because these rules can expose an arbitrary subterm whose phase is `1`, while the source’s outer constructor gives it phase `0`.

The `phase` component does correctly handle `R_rec_succ`, whose source has phase `1` and target phase `0`, but it is not stable under rules that remove an outer constructor. Therefore, `measure := (phase, cost)` does not decrease for every `Step` and cannot justify termination.
