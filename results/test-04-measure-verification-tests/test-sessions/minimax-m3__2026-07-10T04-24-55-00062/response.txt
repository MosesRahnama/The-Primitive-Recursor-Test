## Assessment: The lexicographic measure is **not sound**.

The measure `(phase t, cost t)` fails to decrease lexicographically for several rewrite rules. Below is the analysis rule by rule.

### Definition reminder

```lean
def phase : Trace → Nat
| .recDelta _ _ (.delta _) => 1
| _ => 0
```

So `phase t = 1` **iff** `t = recDelta b s (delta n)` for some `b, s, n`; otherwise `phase t = 0`.

### Rule-by-rule check

| Rule | LHS (phase, cost) | RHS (phase, cost) | Lex decrease? |
|------|-------------------|-------------------|---------------|
| `R_int_delta` | (0, 2+cost t) | (0, 0) | ✓ cost drops |
| `R_merge_void_left`  `merge void t → t` | (0, 1+cost t) | (phase t, cost t) | **✗ if `phase t = 1`** |
| `R_merge_void_right` `merge t void → t` | (0, 1+cost t) | (phase t, cost t) | **✗ if `phase t = 1`** |
| `R_merge_cancel`     `merge t t → t` | (0, 1+2·cost t) | (phase t, cost t) | **✗ if `phase t = 1`** |
| `R_rec_zero` `recDelta b s void → b` | (0, 1+cost b+cost s) | (phase b, cost b) | **✗ if `phase b = 1`** |
| `R_rec_succ` `recDelta b s (delta n) → app s (recDelta b s n)` | **(1, 1+cost b+cost s+1+cost n)** | (0, 1+cost s+1+cost b+cost s+cost n) | **✗ phase goes 1 → 0** |
| `R_eq_refl`  `eqW a a → void` | (0, 3+2·cost a) | (0, 0) | ✓ cost drops |
| `R_eq_diff`  `eqW a b → integrate (merge a b)` | (0, 3+cost a+cost b) | (0, 2+cost a+cost b) | ✓ cost drops |

### The decisive counterexample: `R_rec_succ`

The LHS is `recDelta b s (delta n)`, so by the very definition of `phase`, `phase (LHS) = 1`. The RHS is `app s (recDelta b s n)`, which is **not** of the form `recDelta _ _ (delta _)`, so `phase (RHS) = 0`. The first component **increases** from 1 to 0 — the measure goes *up* in the lex order. (The second component also happens to go up: `1+cost b+cost s+1+cost n` vs. `2+2·cost s+cost b+cost n`, so there is no compensating decrease on the second axis either.)

### Cascading failure

Even ignoring `R_rec_succ`, the merge and rec-zero rules all have `phase(LHS) = 0`, so any RHS of the form `recDelta b' s' (delta n')` (i.e. anything with `phase = 1`) would also yield a strict lex *increase*. The phase function is too coarse to be the leading component: it assigns the highest phase to the very term produced by `R_rec_succ`'s predecessor, which is exactly the rule that creates those phase-1 terms from phase-0 antecedents.

### Verdict

The measure is **not sound** for proving termination of this rewrite system. The fix is not a simple tweak of the cost numbers; the `phase` function would need to be redefined so that every rule's RHS has a strictly smaller first component. For example, a common correct choice is to track "structural depth" (e.g. the size of the rightmost spine of `recDelta`s) rather than the mere presence of a `delta` under a `recDelta` — but as stated, the current measure does not justify termination.
