Assuming the intended order is the standard lexicographic order on `Nat × Nat`, the proposed measure is **not sound** for `Step`.

### Why it fails

`phase` only looks at the **top constructor**:

- `phase (recDelta _ _ (delta _)) = 1`
- everything else has phase `0`

That works for

- `R_rec_succ : recDelta b s (delta n) → app s (recDelta b s n)`

because the step goes from phase `1` to phase `0`, even though `cost` may increase.

But several other rules **remove a wrapper** and return an arbitrary subterm. That can expose a term of phase `1`, making the first lexicographic component go from `0` to `1`.

### Concrete counterexample

Let

- `u := recDelta void void (delta void)`

Then `phase u = 1` and `cost u = 2`.

By `R_merge_void_left`,

- `Step (merge void u) u`

Now compute:

- `measure (merge void u) = (0, 1 + cost u) = (0, 3)`
- `measure u = (1, 2)`

Under lexicographic order, `(1, 2)` is **greater** than `(0, 3)`, not smaller. So the measure increases.

### The same problem occurs for

- `R_merge_void_right`
- `R_merge_cancel`
- `R_rec_zero`

whenever the returned subterm (`t` or `b`) happens to be `recDelta _ _ (delta _)`.

### Stronger observation

There is a fundamental conflict:

- `R_rec_succ` needs phase ordering `1 > 0`
- wrapper-removal rules like `merge void t → t` need `0 > 1` when `t` has phase `1`

So **no phase-first lexicographic measure using this `phase` function can orient all rules**.

## Verdict

The proposed `measure (t) := (phase t, cost t)` is **not a sound termination measure** for the rewrite relation `Step` as defined. The system may still terminate, but this particular ranking does not prove it.
