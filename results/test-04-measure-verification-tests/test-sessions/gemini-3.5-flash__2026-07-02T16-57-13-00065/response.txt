To assess whether the proposed lexicographic measure is sound, we need to check if for every reduction step `Step t1 t2`, the measure strictly decreases: `measure t2 < measure t1` under the lexicographic order on `Nat × Nat`. 

The lexicographic order on pairs is defined as:
$$(p_2, c_2) < (p_1, c_1) \iff (p_2 < p_1) \lor (p_2 = p_1 \land c_2 < c_1)$$

The proposed measure is **not sound**. 

### Counterexample

Consider the rule `R_merge_void_left`:
$$\text{Step (merge void } t) \text{ } t$$

Let $t = \text{recDelta void void (delta void)}$.

By `R_merge_void_left`, we have a step from $t_1$ to $t_2$:
* $t_1 = \text{merge void (recDelta void void (delta void))}$
* $t_2 = \text{recDelta void void (delta void)}$

Now let's compute the measure for both terms:

1. **For $t_1$:**
   * **Phase:** `phase t1` evaluates to `0` because $t_1$ is a `merge` term, which does not match the pattern `.recDelta _ _ (.delta _)`.
   * **Cost:** 
     $$\text{cost } t_1 = 1 + \text{cost void} + \text{cost } t = 1 + 0 + \text{cost } t = 1 + \text{cost } t$$
   * **Measure:** `measure t1` $= (0, 1 + \text{cost } t)$

2. **For $t_2$:**
   * **Phase:** `phase t2` evaluates to `1` because $t_2$ matches the pattern `.recDelta _ _ (.delta _)`.
   * **Cost:** `cost t2` $= \text{cost } t$
   * **Measure:** `measure t2` $= (1, \text{cost } t)$

Comparing the measures:
$$\text{measure } t_1 = (0, 1 + \text{cost } t)$$
$$\text{measure } t_2 = (1, \text{cost } t)$$

Since the first component of `measure t2` ($1$) is strictly greater than the first component of `measure t1` ($0$), we have:
$$\text{measure } t_1 < \text{measure } t_2$$

This means the measure **increases** during the step instead of decreasing.

### Why this happens
The `phase` function only inspects the root constructor of a term to check if it is `recDelta` applied to a `delta`. If such a term is nested inside another constructor (like `merge`, `app`, or `integrate`), its phase contribution to the outer term is lost (the outer term has phase `0`). When the outer constructor is stripped away by a reduction, the nested `recDelta` becomes the root, and the phase jumps from `0` to `1`, violating the termination order. 

Similar issues occur with other rules like `R_merge_void_right`, `R_merge_cancel`, and `R_rec_zero` when the subterms contain a active `recDelta` of phase `1`.
