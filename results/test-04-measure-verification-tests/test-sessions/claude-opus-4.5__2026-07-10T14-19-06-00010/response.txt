# Assessment of the Lexicographic Termination Measure

I need to verify whether the measure `(phase t, cost t)` strictly decreases (lexicographically) for every rewrite rule in the `Step` relation.

## Analysis of Each Rule

### R_int_delta: `integrate (delta t) → void`
- **Before:** phase = 0, cost = 1 + (1 + cost t) = 2 + cost t
- **After:** phase = 0, cost = 0
- ✅ **Decreases:** (0, 2 + cost t) > (0, 0)

### R_merge_void_left: `merge void t → t`
- **Before:** phase = 0, cost = 1 + 0 + cost t = 1 + cost t
- **After:** phase t (could be 0 or 1), cost = cost t
- If `t = recDelta _ _ (delta _)`, then phase t = 1, so (0, 1 + cost t) vs (1, cost t)
- ❌ **UNSOUND:** (0, _) < (1, _) lexicographically, so the measure *increases*

### R_merge_void_right: `merge t void → t`
- **Before:** phase = 0, cost = 1 + cost t + 0 = 1 + cost t
- **After:** phase t (could be 0 or 1), cost = cost t
- Same issue as above when `t = recDelta _ _ (delta _)`
- ❌ **UNSOUND**

### R_merge_cancel: `merge t t → t`
- **Before:** phase = 0, cost = 1 + 2*(cost t)
- **After:** phase t (could be 0 or 1), cost = cost t
- Same issue when `t = recDelta _ _ (delta _)`
- ❌ **UNSOUND**

### R_rec_zero: `recDelta b s void → b`
- **Before:** phase = 0 (since third arg is `void`, not `delta _`), cost = 1 + cost b + cost s + 0
- **After:** phase b, cost = cost b
- If `b = recDelta _ _ (delta _)`, phase increases from 0 to 1
- ❌ **UNSOUND**

### R_rec_succ: `recDelta b s (delta n) → app s (recDelta b s n)`
- **Before:** phase = 1, cost = 1 + cost b + cost s + (1 + cost n)
- **After:** phase = 0 (since `app` matches `_ => 0`), cost = 1 + cost s + (1 + cost b + cost s + cost n)
- Measure: (1, 2 + cost b + cost s + cost n) → (0, 2 + cost b + 2*cost s + cost n)
- ✅ **Decreases:** Phase drops from 1 to 0

### R_eq_refl: `eqW a a → void`
- **Before:** phase = 0, cost = 3 + 2*(cost a)
- **After:** phase = 0, cost = 0
- ✅ **Decreases**

### R_eq_diff: `eqW a b → integrate (merge a b)`
- **Before:** phase = 0, cost = 3 + cost a + cost b
- **After:** phase = 0, cost = 1 + (1 + cost a + cost b) = 2 + cost a + cost b
- ✅ **Decreases:** (0, 3 + cost a + cost b) > (0, 2 + cost a + cost b)

## Conclusion

**The measure is UNSOUND.**

The fundamental problem is that several rules (R_merge_void_left, R_merge_void_right, R_merge_cancel, R_rec_zero) can produce a result whose `phase` is 1 while the original term has `phase` 0. In a lexicographic ordering where phase is the primary component, this causes the measure to *increase* rather than decrease.

For example, with `merge void (recDelta b s (delta n))`:
- Before: (0, 1 + 0 + cost(recDelta b s (delta n)))
- After: (1, cost(recDelta b s (delta n)))

Since (0, _) < (1, _), the measure increases, violating the termination requirement.
