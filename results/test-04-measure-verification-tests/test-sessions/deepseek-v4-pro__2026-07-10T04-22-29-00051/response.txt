The lexicographic measure `(phase t, cost t)` is sound for the given rewrite system. Here’s why.

For a lexicographic combination of natural numbers `(p, c)` to show termination, each rewrite step `l → r` must satisfy  
`(phase l, cost l) > (phase r, cost r)` in the lexicographic order (i.e., `phase l > phase r`, or `phase l = phase r` and `cost l > cost r`).  

Let’s check all eight rules of `Step`:

1. **R_int_delta** : `integrate (delta t) → void`  
   - `phase` of both sides is `0` (since neither is `recDelta` with `delta` as third argument).  
   - `cost (integrate (delta t)) = 1 + cost (delta t) = 2 + cost t` > `cost void = 0`.  
   ✅ Decrease.

2. **R_merge_void_left** : `merge void t → t`  
   - `phase = 0` on both sides.  
   - `cost (merge void t) = 1 + cost void + cost t = 1 + cost t` > `cost t`.  
   ✅ Decrease.

3. **R_merge_void_right** : `merge t void → t`  
   - Analogous: `cost = 1 + cost t + 0 > cost t`.  
   ✅ Decrease.

4. **R_merge_cancel** : `merge t t → t`  
   - `cost = 1 + cost t + cost t = 1 + 2·cost t` > `cost t` for any `cost t` (natural).  
   ✅ Decrease.

5. **R_rec_zero** : `recDelta b s void → b`  
   - `recDelta _ _ void` matches the `_ => 0` case → `phase = 0`.  
   - `cost = 1 + cost b + cost s + 0 > cost b`.  
   ✅ Decrease.

6. **R_rec_succ** : `recDelta b s (delta n) → app s (recDelta b s n)`  
   - Left: third argument is `delta n` → `phase = 1`.  
   - Right: `app` has `phase = 0`.  
   - `phase` drops from `1` to `0`, so the measure decreases regardless of costs.  
   ✅ Decrease.

7. **R_eq_refl** : `eqW a a → void`  
   - `phase = 0` both sides.  
   - `cost = 3 + 2·cost a > 0`.  
   ✅ Decrease.

8. **R_eq_diff** : `eqW a b → integrate (merge a b)`  
   - `phase = 0` both sides.  
   - `cost` left = `3 + cost a + cost b`, right = `1 + cost (merge a b) = 2 + cost a + cost b`.  
   - Left cost > right cost.  
   ✅ Decrease.

In every case the lexicographic measure strictly decreases. Therefore **the measure is sound** for proving termination of the rewrite system.
