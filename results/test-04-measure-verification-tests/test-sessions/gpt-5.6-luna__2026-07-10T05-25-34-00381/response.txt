The measure is sound for all constructors of `Step`, assuming the intended order on `Nat × Nat` is lexicographic with the first component compared first.

For each rule:

- `R_int_delta`:  
  `integrate (delta t)` has cost `2 + cost t`, while `void` has cost `0`.

- `R_merge_void_left/right`:  
  The source cost is `1 + cost t`, and the target cost is `cost t`.

- `R_merge_cancel`:  
  `merge t t` has cost `1 + 2 * cost t`, which exceeds `cost t`.

- `R_rec_zero`:  
  `recDelta b s void` has phase `0` and cost  
  `1 + cost b + cost s`, which is strictly greater than the target cost `cost b`.

- `R_rec_succ`:  
  The source `recDelta b s (delta n)` has phase `1`. The target  
  `app s (recDelta b s n)` has phase `0`, so the measure decreases lexicographically even though the target’s cost can be larger.

- `R_eq_refl`:  
  `eqW a a` has cost `3 + 2 * cost a`, while `void` has cost `0`.

- `R_eq_diff`:  
  The source has cost `3 + cost a + cost b`; the target  
  `integrate (merge a b)` has cost `2 + cost a + cost b`.

Thus every rewrite step strictly decreases `(phase t, cost t)` lexicographically. The phase component is specifically needed for `R_rec_succ`, since that rule may increase `cost`. Since lexicographic order on `Nat × Nat` is well-founded, this gives a valid termination measure.
