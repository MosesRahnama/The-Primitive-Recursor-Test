## Assessment of the Termination Measure

### Overview

The proposed lexicographic measure is `(phase t, cost t)` where:
- `phase t = 1` if `t = recDelta b s (delta n)`, else `0`
- `cost t` is a structural size measure

### Checking Each Rule

I'll verify that each step strictly decreases the measure `(phase, cost)` under the lexicographic order.

---

**R_int_delta**: `integrate (delta t) → void`
- Measure: `(0, 2 + cost t) → (0, 0)` ✓

**R_merge_void_left**: `merge void t → t`
- Measure: `(0, 1 + cost t) → (0, cost t)` ✓

**R_merge_void_right**: `merge t void → t`
- Measure: `(0, 1 + cost t) → (0, cost t)` ✓

**R_merge_cancel**: `merge t t → t`
- Measure: `(0, 1 + 2·cost t) → (0, cost t)` ✓

**R_rec_zero**: `recDelta b s void → b`
- Measure: `(0, 1 + cost b + cost s) → (0, cost b)` ✓

**R_rec_succ**: `recDelta b s (delta n) → app s (recDelta b s n)`
- LHS measure: `(1, 1 + cost b + cost s + 1 + cost n)`
- RHS measure: `(0, 1 + cost s + (1 + cost b + cost s + cost n))`
- Since phase decreases from **1 → 0**, this step is valid regardless of cost. ✓

**R_eq_refl**: `eqW a a → void`
- Measure: `(0, 3 + 2·cost a) → (0, 0)` ✓

**R_eq_diff**: `eqW a b → integrate (merge a b)`
- LHS cost: `3 + cost a + cost b`
- RHS cost: `1 + (1 + cost a + cost b) = 2 + cost a + cost b`
- Measure: `(0, 3 + cost a + cost b) → (0, 2 + cost a + cost b)` ✓

---

### Critical Soundness Gap

The measure only applies to **single-step top-level rewrites**. The rules as written are **not congruence rules** — there are no rules of the form "if `s → s'` then `f(s) → f(s')`". So the calculus as defined only rewrites at the root.

However, if the intent is to use this as a rewrite system applied anywhere in a term (i.e., closing under contexts), the measure **would be unsound**: applying a rule under a context can *increase* `cost`. For example, `R_eq_diff` increases cost by `−1` at the root, but this is not monotone — a subterm rewrite of `eqW a b` inside a larger term doesn't guarantee the outer `cost` decreases by enough.

Specifically, `cost(eqW a b) = 3 + cost a + cost b` while `cost(integrate(merge a b)) = 2 + cost a + cost b`. The gap is only **1**, which is not sufficient to guarantee decrease under arbitrary contexts if congruence rules were added (a wrapper of depth 1 would neutralize the gap, but actually any fixed context adds a constant to both sides, so it would still work in that scenario — but `R_rec_succ` is the real concern: `recDelta b s n` appears in the RHS, with the same `b` and `s`, so `cost` of the recursive call is `1 + cost b + cost s + cost n`, less than the original by exactly 1).

### Conclusion

**For the calculus as literally defined (root rewrites only), the measure is sound.** Every rule strictly decreases `(phase, cost)` lexicographically. The `phase` component is a clever device to handle `R_rec_succ`, which increases `cost` but decreases `phase` from 1 to 0. All other rules decrease `cost` at phase 0.

If congruence/contextual closure is intended, the measure requires more careful argument, but as stated the measure is **sound**.
