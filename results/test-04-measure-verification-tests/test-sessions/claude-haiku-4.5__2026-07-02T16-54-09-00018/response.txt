# Assessment of the Termination Measure

## Verdict: **UNSOUND**

The lexicographic measure `(phase t, cost t)` does **not** soundly prove termination for this rewrite system. Here's why:

### Critical Counterexample

Consider the rewrite rule **R_rec_succ**:
```
Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

**Before:** `recDelta b s (delta n)`
- `phase = 1` (matches the pattern in the phase definition)
- `cost = 1 + cost b + cost s + (1 + cost n) = 2 + cost b + cost s + cost n`

**After:** `app s (recDelta b s n)`
- `phase = 0` (doesn't match any special phase pattern)
- `cost = 1 + cost s + (1 + cost b + cost s + cost n) = 2 + cost b + 2·cost s + cost n`

**Problem:** While `phase` decreases (1 → 0) ✓, the `cost` of the resulting term can be **larger** than the original:
- Original cost: `2 + cost b + cost s + cost n`
- Resulting cost: `2 + cost b + 2·cost s + cost n`
- Difference: `+cost s` (net increase)

Since the second component of the lexicographic pair increases, the measure does not decrease overall.

### Additional Issues

1. **Phase definition is incomplete**: The `phase` function returns 1 only for `recDelta b s (delta _)` and 0 for everything else. After applying R_rec_succ, we get a term of the form `app ...` with phase 0, but we've lost the structural advantage that allowed phase reduction in the first place.

2. **No accounting for recursive depth**: The `cost` counts syntactic structure but doesn't track how the recursive structure of nested `recDelta` terms evolves.

### What Would Be Needed

A sound termination proof would require a measure that either:
- Strictly decreases on the problematic case (R_rec_succ), or
- Accounts for the structural properties being simplified (e.g., the size of the third argument to `recDelta` or the number of `delta` constructors it contains)
