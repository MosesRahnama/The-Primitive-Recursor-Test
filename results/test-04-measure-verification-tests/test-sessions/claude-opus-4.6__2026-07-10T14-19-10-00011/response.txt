# Assessment of the Termination Measure

I need to check whether for every rewrite rule `Step l r`, the lexicographic measure `(phase l, cost l) > (phase r, cost r)` holds (using lexicographic ordering on `Nat × Nat`).

Let me analyze each rule:

## Rule-by-rule analysis

### R_int_delta: `integrate (delta t) → void`
- **LHS:** phase = 0, cost = 1 + (1 + cost t) = 2 + cost t
- **RHS:** phase = 0, cost = 0
- **(0, 2 + cost t) > (0, 0)** ✅

### R_merge_void_left: `merge void t → t`
- **LHS:** phase = 0, cost = 1 + 0 + cost t = 1 + cost t
- **RHS:** phase(t) ∈ {0, 1}, cost = cost t
- If phase(t) = 0: **(0, 1 + cost t) > (0, cost t)** ✅
- If phase(t) = 1: **(0, 1 + cost t) vs (1, cost t)** — first component 0 < 1. **❌ FAIL**

This fails when `t = recDelta b s (delta n)`, since then `phase(t) = 1` and the measure increases in the first component.

### R_merge_void_right: `merge t void → t`
- Same issue as above. **❌ FAIL** when `t = recDelta b s (delta n)`.

### R_merge_cancel: `merge t t → t`
- **LHS:** phase = 0, cost = 1 + 2 * cost t
- **RHS:** phase(t) could be 1 (same scenario as above)
- If phase(t) = 1: **(0, ...) vs (1, ...)** **❌ FAIL**

### R_rec_zero: `recDelta b s void → b`
- **LHS:** phase = 0 (third arg is `void`, not `delta _`), cost = 1 + cost b + cost s + 0
- **RHS:** phase(b) could be 1
- If phase(b) = 1: **(0, ...) vs (1, ...)** **❌ FAIL**

### R_rec_succ: `recDelta b s (delta n) → app s (recDelta b s n)`
- **LHS:** phase = 1, cost = 1 + cost b + cost s + (1 + cost n) = 2 + cost b + cost s + cost n
- **RHS:** `app s (recDelta b s n)` — phase = 0, cost = 1 + cost s + (1 + cost b + cost s + cost n) = 2 + cost b + 2·cost s + cost n
- **(1, 2 + cost b + cost s + cost n) > (0, 2 + cost b + 2·cost s + cost n)** ✅ (first component strictly decreases)

### R_eq_refl: `eqW a a → void`
- **LHS:** phase = 0, cost = 3 + 2·cost a
- **RHS:** phase = 0, cost = 0
- **(0, 3+2·cost a) > (0, 0)** ✅

### R_eq_diff: `eqW a b → integrate (merge a b)`
- **LHS:** phase = 0, cost = 3 + cost a + cost b
- **RHS:** phase = 0, cost = 1 + (1 + cost a + cost b) = 2 + cost a + cost b
- **(0, 3 + cost a + cost b) > (0, 2 + cost a + cost b)** ✅

## Conclusion

**The measure is unsound.** The rules `R_merge_void_left`, `R_merge_void_right`, `R_merge_cancel`, and `R_rec_zero` can all produce a right-hand side whose `phase` is 1 while the left-hand side has `phase` 0. Concretely, for example:

```
merge void (recDelta b s (delta n)) → recDelta b s (delta n)
```

has measure `(0, _) → (1, _)`, which is an **increase** in the lexicographic order.

The fundamental problem is that `phase` is defined only on the top-level constructor pattern, and rewrite rules like `merge` and `recDelta`-at-zero can expose a subterm that has a higher phase than the original term. The measure would need to account for the maximum phase of all subterms, or use a different approach entirely (such as a recursive path ordering or a measure that is monotone with respect to subterm exposure).
