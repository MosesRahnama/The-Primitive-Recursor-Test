## Assessment

I checked each rule of the `Step` relation against the lexicographic measure `(phase t, cost t)`. The measure is **sound** — every rule strictly decreases it.

### Rule-by-rule verification

| Rule | LHS measure | RHS measure | Reason |
|---|---|---|---|
| `R_int_delta` | `(0, 2 + cost t)` | `(0, 0)` | Same phase, cost drops by 2+ |
| `R_merge_void_left` | `(0, 1 + cost t)` | `(phase t, cost t)` | Either phase drops (if `t = recDelta _ _ (delta _)`), or phase is 0 and cost drops by 1 |
| `R_merge_void_right` | symmetric to above | | ✓ |
| `R_merge_cancel` | `(0, 1 + 2·cost t)` | `(phase t, cost t)` | Either phase drops from 1→0, or same phase 0 and cost drops |
| `R_rec_zero` | `(0, 1 + cost b + cost s)` | `(phase b, cost b)` | Phase either drops (if `b` is a `recDelta _ _ (delta _)`) or is 0 with cost `≥ 1 + cost b` (since `cost s ≥ 0`) |
| `R_rec_succ` | `(1, _)` | `(0, _)` | Phase drops 1 → 0 (the `app` head is not a `recDelta _ _ (delta _)`) |
| `R_eq_refl` | `(0, 3 + 2·cost a)` | `(0, 0)` | Same phase, cost drops |
| `R_eq_diff` | `(0, 3 + cost a + cost b)` | `(0, 2 + cost a + cost b)` | Same phase, cost drops by exactly 1 |

### Key observations

- **`phase` is well-chosen.** The only rule that could be costly to verify on `cost` alone is `R_rec_succ`, since the rhs `app s (recDelta b s n)` is *larger* in cost than the lhs `recDelta b s (delta n)` (the rhs contains a copy of the recursive call). The `phase` flag cleverly tags the spine of an unrolling `recDelta` (its third argument is a `delta`) so the phase drops the moment we take the `R_rec_succ` step. This is essential for soundness.
- **All other rules decrease `cost`**, so even without the `phase` component the measure would still work for them. The `phase` component is what rescues `R_rec_succ`.

### Conclusion

The lexicographic measure `(phase, cost)` is **sound** for proving termination of `Step`.
