# Assessment of the Lexicographic Termination Measure

I need to verify that for every rewrite rule `Step t t'`, we have `measure t > measure t'` in the lexicographic ordering on `Nat × Nat`.

The measure is `(phase t, cost t)` where lexicographic ordering means either:
1. `phase t > phase t'`, OR
2. `phase t = phase t'` AND `cost t > cost t'`

Let me analyze each rule:

## Rule-by-Rule Analysis

### R_int_delta: `integrate (delta t) → void`
- `phase (integrate (delta t)) = 0`, `phase void = 0`
- `cost (integrate (delta t)) = 1 + (1 + cost t) = 2 + cost t`
- `cost void = 0`
- ✅ `2 + cost t > 0`

### R_merge_void_left: `merge void t → t`
- `phase (merge void t) = 0`, `phase t = 0` (unless t matches recDelta pattern)
- `cost (merge void t) = 1 + 0 + cost t = 1 + cost t`
- `cost t = cost t`
- ✅ `1 + cost t > cost t`

### R_merge_void_right: `merge t void → t`
- Similar analysis: ✅ `1 + cost t > cost t`

### R_merge_cancel: `merge t t → t`
- `cost (merge t t) = 1 + cost t + cost t = 1 + 2·cost t`
- `cost t = cost t`
- ✅ `1 + 2·cost t > cost t`

### R_rec_zero: `recDelta b s void → b`
- `phase (recDelta b s void) = 0` (since `void` doesn't match `delta _`)
- `cost (recDelta b s void) = 1 + cost b + cost s + 0 = 1 + cost b + cost s`
- `cost b = cost b`
- ✅ `1 + cost b + cost s > cost b`

### R_rec_succ: `recDelta b s (delta n) → app s (recDelta b s n)`
- `phase (recDelta b s (delta n)) = 1`
- `phase (app s (recDelta b s n)) = 0`
- ✅ Phase strictly decreases (1 > 0), so this rule is covered.

### R_eq_refl: `eqW a a → void`
- `phase (eqW a a) = 0`, `phase void = 0`
- `cost (eqW a a) = 3 + cost a + cost a = 3 + 2·cost a`
- `cost void = 0`
- ✅ `3 + 2·cost a > 0`

### R_eq_diff: `eqW a b → integrate (merge a b)`
- `phase (eqW a b) = 0`, `phase (integrate (merge a b)) = 0`
- `cost (eqW a b) = 3 + cost a + cost b`
- `cost (integrate (merge a b)) = 1 + (1 + cost a + cost b) = 2 + cost a + cost b`
- ✅ `3 + cost a + cost b > 2 + cost a + cost b`

## Critical Observation on R_rec_succ

While the phase decreases, I should verify the RHS cannot immediately step back to a higher phase. The termination measure only needs to decrease at each step, not account for future steps.

However, note that `app s (recDelta b s n)` has `phase = 0`. If `n = delta m` for some `m`, then `recDelta b s n = recDelta b s (delta m)` which has `phase = 1`. But this is a **subterm**, not the whole term. The `phase` function is applied to the **root** of the term, and `app _ _` always has phase 0.

So the measure on the full term `app s (recDelta b s n)` is `(0, ...)` which is less than `(1, ...)`.

## Conclusion

**The measure is SOUND.** Every rewrite step strictly decreases the lexicographic measure `(phase, cost)`:
- Most rules maintain phase at 0 and strictly decrease cost
- The critical `R_rec_succ` rule strictly decreases phase (from 1 to 0)
- The cost assignment for `eqW` (using 3 instead of 1) correctly ensures `R_eq_diff` decreases cost
