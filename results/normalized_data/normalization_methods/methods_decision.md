# Method Rename Decisions

This file documents the canonical reporting names used by the unified
`method_labels.csv`. Normalization names and classes describe method identity;
they are not correctness judgments.

Canonical standardized method names:

- `dependency_pairs`
- `direct_measure`
- `lexicographic_measure`
- `lpo`
- `multiset_measure`
- `objection_or_non_method`
- `ordinal_interpretation`
- `path_order_generic`
- `polynomial_interpretation`
- `rpo`
- `structural_descent`
- `structural_induction`
- `tait_computability`
- `well_founded_induction`

Historical names are mapped to these canonical names in `method_renames.csv`.
The complete source-by-source reconciliation is recorded in
`method_labels_unification_2026-07-11.csv`.
