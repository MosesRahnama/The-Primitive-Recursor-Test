**Assessment: Yes, strong normalization can be established from the rules alone.**

**Reasoning:**

The system has two rules operating on the `Velk` symbol, dispatched by the structure of its third argument:

```
Velk(x, y, Mek)     -> x
Velk(x, y, Oru(n))  -> Tarn(y, Velk(x, y, n))
```

Key observations:

1. **The third argument strictly controls recursion.** Rule 1 fires when the third argument is `Mek` and produces `x` — a subterm, containing no `Velk` reintroduced by the rule. Rule 2 fires when the third argument is `Oru(n)` and produces a recursive `Velk(x, y, n)` where the third argument has been decremented from `Oru(n)` to `n`.

2. **A simple measure suffices.** Take as measure the size (or number of `Oru`/`Mek` constructor occurrences) of the third argument of each `Velk` redex. Rule 2 replaces a `Velk` on `Oru(n)` with a `Velk` on `n`, strictly reducing this measure. Rule 1 eliminates the `Velk` entirely. Neither rule introduces any new `Velk` with a third argument that isn't a proper subterm of the original.

3. **No copying that grows the controlling argument.** Although `y` is duplicated in rule 2 (it appears in both `Tarn(y, ...)` and inside the recursive `Velk(x, y, n)`), the duplicated material sits in argument positions that do **not** feed back into the third (recursion-controlling) argument of any `Velk`. So duplication cannot regenerate reducible structure in the controlling position.

4. **Standard termination argument.** A polynomial/lexicographic interpretation works cleanly. For instance, interpret with `[Mek] = 0`, `[Oru](n) = n + 1`, `[Tarn](a,b) = a + b + 1`, and `[Velk](x,y,z) = x + z·(y+1) + z + 1` (or similar), and check both rules strictly decrease. More simply, a **recursive path ordering** with any precedence where `Velk > Tarn` and `Velk > Oru` orients both rules, since the recursive `Velk` call is on a strict subterm `n` of `Oru(n)`.

**Conclusion:** This is a structurally primitive-recursive schema (it is essentially iterated application of `Tarn` driven down a unary numeral built from `Oru`/`Mek`). Termination follows directly from the well-foundedness of the subterm relation on the third argument — no external structural axioms or object-level assumptions are needed. The rules themselves supply everything required for a decreasing measure.
