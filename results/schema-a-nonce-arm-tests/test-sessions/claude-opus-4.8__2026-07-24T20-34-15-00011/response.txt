# Assessment: Yes, strong normalization can be established from the system alone.

## Reasoning

The system has two rules:

```
Velk(x, y, Mek)     -> x
Velk(x, y, Oru(n))  -> Tarn(y, Velk(x, y, n))
```

**Key observation:** The recursion is controlled entirely by the third argument of `Velk`. Reduction only occurs when a `Velk` term has a *constructor-headed* third argument (`Mek` or `Oru(...)`), and in the recursive rule the third argument strictly decreases from `Oru(n)` to `n`.

**A simple termination argument via a well-founded measure:**

Define a measure `μ` on terms by summing over all subterms of the form `Velk(x, y, t)` the "size" of the third argument `t`, where size counts the number of `Oru`/`Mek`/other symbol layers in `t`. More directly:

- Assign to each function symbol a polynomial interpretation over the naturals:
  - `Mek = 1`
  - `Oru(n) = n + 1`
  - `Tarn(y, z) = y + z + 1` (or any monotone form)
  - `Velk(x, y, n) = x + n·(y+1) + n`

Check both rules strictly decrease:

**Rule 1:** `Velk(x, y, Mek) -> x`
- LHS = `x + 1·(y+1) + 1 = x + y + 2`
- RHS = `x`
- LHS > RHS ✓

**Rule 2:** `Velk(x, y, Oru(n)) -> Tarn(y, Velk(x, y, n))`
- LHS = `x + (n+1)(y+1) + (n+1)`
- RHS = `y + [x + n(y+1) + n] + 1`
- LHS − RHS = `(n+1)(y+1) + (n+1) − y − n(y+1) − n − 1`
  = `(y+1) + 1 − y − 1 = 1 > 0` ✓

Since all interpretations are monotone and both rules strictly decrease under a well-founded (natural number) ordering, the system is **strongly normalizing**.

## Why nothing external is needed

- There are **no variable-binding constructs**, so no capture/substitution axioms are required.
- There are **no imported equational or structural axioms**; the constructors `Mek`, `Oru`, `Tarn` are free.
- The termination measure is derivable purely from the syntactic shape of the two rules — the strictly decreasing third argument in the recursive rule provides the well-founded descent.

**Conclusion:** Strong normalization follows from the presented rewrite system alone via a standard polynomial (or structural-descent) argument, with no need for external assumptions.
