## Theorem 1: `kappa_rec_delta_step`

**Claim:** `kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1`

**LHS** (by `kappa_rec_delta`):
```
kappa (recDelta b s (delta n)) = max (max (kappa b) (kappa s)) (kappa n) + 1
```

**RHS:** We need `kappa (recDelta b s n) + 1`. But `kappa (recDelta b s n)` depends on the shape of `n`.

The definition of `kappa` for `recDelta` has **two cases**:
- `kappa (recDelta b s (delta n)) = max (max (kappa b) (kappa s)) (kappa n) + 1`
- `kappa (recDelta b s n) = max (max (kappa b) (kappa s)) (kappa n)` — for all other `n`

So `kappa (recDelta b s n) = max (max (kappa b) (kappa s)) (kappa n)` **only when `n` is not of the form `delta _`**. When `n = delta m`, we get `kappa (recDelta b s (delta m)) = max (max (kappa b) (kappa s)) (kappa m) + 1`, which is different.

The claim requires that `kappa (recDelta b s n) = max (max (kappa b) (kappa s)) (kappa n)` for **all** `n`. But this fails when `n = delta m`:
- `kappa (recDelta b s (delta m)) = max (max (kappa b) (kappa s)) (kappa m) + 1`
- whereas `max (max (kappa b) (kappa s)) (kappa (delta m)) = max (max (kappa b) (kappa s)) (kappa m)`

These differ by 1. So **Theorem 1 is false** when `n` is itself a `delta`.

**Counterexample:** Let `b = void`, `s = void`, `n = delta void`.
- LHS: `kappa (recDelta void void (delta (delta void))) = max (max 0 0) (kappa (delta void)) + 1 = max 0 0 + 1 = 1`
- RHS: `kappa (recDelta void void (delta void)) + 1 = (max (max 0 0) (kappa void) + 1) + 1 = (0 + 1) + 1 = 2`
- `1 ≠ 2`. **The theorem is false.**
