# Assessment of the Helper Strategy

## Goal: Prove termination of rewriting via `kappa` decreasing

The two helper theorems are:

1. **`kappa_rec_delta_step`**: `kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1`
2. **`kappa_rec_succ_drop`**: `kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))`

## Analysis of Theorem 1: `kappa_rec_delta_step`

**LHS:** `kappa (recDelta b s (delta n))`

By the pattern match for `recDelta b s (.delta n)`:
```
= Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1
```

**RHS:** `kappa (recDelta b s n) + 1`

Now, `kappa (recDelta b s n)` depends on whether `n` matches `.delta n'` for some `n'`. In general, for arbitrary `n`, we need to consider two cases:

- **If `n` is not of the form `delta n'`**: Then `kappa (recDelta b s n) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)`, and the equation holds: both sides equal `Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1`. ✓

- **If `n = delta n'`**: Then `kappa (recDelta b s n) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n') + 1`, while `kappa n = kappa (delta n') = kappa n'`. So both sides equal `Nat.max (Nat.max (kappa b) (kappa s)) (kappa n') + 1 + 1`. Wait—LHS is `Nat.max (Nat.max (kappa b) (kappa s)) (kappa (delta n')) + 1 = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n') + 1`, while RHS is `(Nat.max (Nat.max (kappa b) (kappa s)) (kappa n') + 1) + 1`. These are **not equal** in general.

**Counterexample:** Let `b = s = void`, `n = delta void`. Then:
- LHS: `kappa (recDelta void void (delta (delta void))) = max (max 0 0) 0 + 1 = 1`
- RHS: `kappa (recDelta void void (delta void)) + 1 = (max (max 0 0) 0 + 1) + 1 = 2`

**Theorem 1 is false.** ✗

## Analysis of Theorem 2: `kappa_rec_succ_drop`

**LHS:** `kappa (app s (recDelta b s n)) = Nat.max (kappa s) (kappa (recDelta b s n))`

**RHS (after rewrite):** `kappa (recDelta b s n) + 1`

We need `Nat.max (kappa s) (kappa (recDelta b s n)) < kappa (recDelta b s n) + 1`.

Since `kappa (recDelta b s n) ≥ Nat.max (kappa b) (kappa s) ≥ kappa s` (for the non-delta-n case), the max equals `kappa (recDelta b s n)`, and `k < k + 1` holds. But when `n = delta n'`, `kappa (recDelta b s n) = max (max (kappa b) (kappa s)) (kappa n') + 1`, which is still `≥ kappa s`, so the inequality still holds.

However, the proof begins with `rw [kappa_rec_delta_step]`, which applies Theorem 1—**which is false**. So while the final inequality is actually **true**, the proof strategy is **unsound** because it depends on a false lemma.

## Conclusion

**The helper strategy is unsound.** Theorem 1 (`kappa_rec_delta_step`) is false when `n` is itself of the form `delta n'`, because `kappa (delta n') = kappa n'` collapses one layer, but the `recDelta` pattern match on `delta n` adds `+1`, creating a discrepancy. Theorem 2's statement is actually true, but the proposed proof strategy of rewriting via Theorem 1 relies on a false intermediate step, making the overall approach invalid.
