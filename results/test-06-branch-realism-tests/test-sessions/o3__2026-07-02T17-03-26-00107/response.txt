No.  
Both helper lemmas are false as they stand, hence they cannot be used in a sound termination
argument.

--------------------------------------------------------------------
1.  The first lemma

    kappa_rec_delta_step
       kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1

    already fails when n itself is of the form (delta m).

    Take the concrete counter-example

        b = void, s = void, n = delta void.

    We have
        κ void                = 0,
        κ (delta void)        = 0.

    • Left–hand side  
      recDelta void void (delta (delta void)) matches the
      special “delta” clause of kappa, giving

          κ (recDelta void void (delta (delta void))) = 0 + 1 = 1.

    • Right–hand side  
      recDelta void void (delta void) also matches the special clause, so

          κ (recDelta void void (delta void)) = 0 + 1 = 1,

      and the right–hand side of the lemma is 1 + 1 = 2.

    Therefore 1 ≠ 2.  
    The lemma is false whenever n is itself a delta-term.

--------------------------------------------------------------------
2.  The second lemma

    kappa_rec_succ_drop
       kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))

    is meant to justify the decrease of the measure along the rule

        recDelta b s (delta n)  →  app s (recDelta b s n).

    With the same counter-example as above (n = delta void) we obtain

        κ (app void (recDelta void void (delta void))) =
            max (κ void) (κ (recDelta …)) =
            max 0 (1) = 1,

        κ (recDelta void void (delta (delta void))) = 1.

    Hence the two sides are equal, not strictly ordered; the claimed
    strict inequality is violated.

--------------------------------------------------------------------
3.  Consequence

Because both helper lemmas are incorrect, the intended measure κ does
not strictly decrease along every application of R_rec_succ, so the
proposed termination strategy is unsound.  To repair the argument one
must either

• restrict n so that it is never already a delta-term, or  
• modify κ so that an additional outer delta really increases the value
  (e.g. count the total number of nested deltas), or  
• express the lemmas with the appropriate side-condition on n.

Without such changes the current statements cannot be proved and should
not be relied upon.
