# Assessment of the Helper Strategy Soundness

## Overview

The file defines a rewrite calculus with a structural measure `kappa` intended to prove termination. I need to assess whether the two helper theorems are sound (i.e., provable).

## Analysis of `kappa_rec_delta_step`

**Claim:** `kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1`

**Left-hand side:**
By the definition of `kappa`:
```
kappa (recDelta b s (delta n)) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1
```
(This matches the specific pattern `recDelta b s (.delta n)`)

**Right-hand side:**
```
kappa (recDelta b s n) + 1
```

For the general case where `n` is an arbitrary `Trace`, the definition falls through to:
```
kappa (recDelta b s n) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)
```

So the RHS becomes:
```
Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1
```

**Comparison:** Both sides equal `Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1`.

**However, there's a subtlety:** When `n` itself matches `.delta m` for some `m`, then `kappa (recDelta b s n)` would use the specific `.delta` case, giving `Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1` instead.

But wait - the LHS has `kappa (... (delta n))` which pattern-matches on `delta n`, extracting `kappa n` (since `kappa (delta t) = kappa t`). So:
- LHS = `Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1`

For RHS with arbitrary `n`:
- If `n = delta m`: `kappa (recDelta b s (delta m)) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1`
- General case: `kappa (recDelta b s n) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)`

**The theorem is NOT universally true.** When `n = delta m`:
- LHS = `Nat.max (Nat.max (kappa b) (kappa s)) (kappa (delta m)) + 1 = Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1`
- RHS = `Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1 + 1`

These differ by 1.

## Analysis of `kappa_rec_succ_drop`

**Claim:** `kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))`

After rewriting with `kappa_rec_delta_step`:
```
kappa (app s (recDelta b s n)) < kappa (recDelta b s n) + 1
```

**LHS:**
```
kappa (app s (recDelta b s n)) = Nat.max (kappa s) (kappa (recDelta b s n))
```

For the general case: `kappa (recDelta b s n) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)`

So LHS = `Nat.max (kappa s) (Nat.max (Nat.max (kappa b) (kappa s)) (kappa n))`
       = `Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)` (since `kappa s ≤ Nat.max (kappa b) (kappa s)`)

**RHS:** `Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1`

So we need: `Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) < Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1`

This is always true since `x < x + 1` for naturals.

**But this depends on `kappa_rec_delta_step` being correct**, which it isn't in general.

## Conclusion

**The helper strategy is UNSOUND.**

The theorem `kappa_rec_delta_step` is false when `n` is of the form `delta m`. For example, with `n = delta void`:
- LHS: `kappa (recDelta b s (delta (delta void))) = max(max(κb, κs), κ(void)) + 1 = max(max(κb, κs), 0) + 1`
- RHS: `kappa (recDelta b s (delta void)) + 1 = (max(max(κb, κs), 0) + 1) + 1`

These are not equal, differing by 1.
