Short answer: **the strategy is not sound as a global “step decreases `kappa`” argument**; it is only sound for the specific `R_rec_succ` helper goal.

Why:

Let  
\[
M := \max(\max(\kappa b,\kappa s),\kappa n).
\]
Then by definition:

- \(\kappa(\text{recDelta } b\, s\, (\delta n)) = M+1\),
- \(\kappa(\text{recDelta } b\, s\, n) = M\) (since `kappa (delta n) = kappa n`, the non-δ branch on `n` gives exactly \(M\)),
- so `kappa_rec_delta_step` is mathematically correct:
  \[
  \kappa(\text{recDelta } b\, s\, (\delta n))=\kappa(\text{recDelta } b\, s\, n)+1.
  \]

For `kappa_rec_succ_drop`:

\[
\kappa(\text{app } s\, (\text{recDelta } b\, s\, n))
= \max(\kappa s,\kappa(\text{recDelta } b\, s\, n))
= \max(\kappa s,M)=M
\]
because \(M\ge \kappa s\). Hence
\[
\kappa(\text{app } s\, (\text{recDelta } b\, s\, n)) = M < M+1
= \kappa(\text{recDelta } b\, s\, (\delta n)).
\]
So this helper theorem is also correct.

---

However, if these helpers are meant to support termination of the **entire** `Step` relation via strict decrease of `kappa`, that fails. Counterexample rule:

- `R_eq_diff : Step (eqW a b) (integrate (merge a b))`

Compute:
\[
\kappa(\text{eqW } a\, b)=\max(\kappa a,\kappa b),
\]
\[
\kappa(\text{integrate }(\text{merge } a\, b))
=\kappa(\text{merge } a\, b)
=\max(\kappa a,\kappa b).
\]
So this step is **measure-preserving**, not decreasing.

Therefore:

- **Local soundness** (for proving decrease in the `recDelta`-successor case): yes.
- **Global soundness** as a termination measure for all rewrite rules using strict `<`: no.
