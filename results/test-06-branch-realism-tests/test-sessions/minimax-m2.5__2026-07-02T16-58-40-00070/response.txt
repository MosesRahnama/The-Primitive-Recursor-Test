The helper theorems `kappa_rec_delta_step` and `kappa_rec_succ_drop` are not sound as written, because they do not hold for all traces `n`. Specifically, both theorems fail when `n` is of the form `delta m` for some trace `m`.

### Analysis of `kappa_rec_delta_step`

The theorem states:
```lean
theorem kappa_rec_delta_step (b s n : Trace) :
  kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1 := by
  sorry
```

- **Left-hand side**: By definition of `kappa`,  
  `kappa (recDelta b s (delta n)) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1`.

- **Right-hand side**: `kappa (recDelta b s n) + 1` depends on whether `n` is a delta:
  - If `n` is **not** a delta, then `kappa (recDelta b s n) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)`, so the right-hand side equals `Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1`, which matches the left-hand side.
  - If `n` **is** a delta (i.e., `n = delta m`), then `kappa (recDelta b s n) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1`. Thus, the right-hand side becomes `Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1 + 1 = Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 2`, while the left-hand side is `Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1` (since `kappa n = kappa m`). These are unequal.

**Counterexample**: Let `b = void`, `s = void`, `n = delta void`. Then:
- LHS: `kappa (recDelta void void (delta (delta void))) = 1`.
- RHS: `kappa (recDelta void void (delta void)) + 1 = 1 + 1 = 2`.
Thus, `1 ≠ 2`, so the theorem is false.

### Analysis of `kappa_rec_succ_drop`

The theorem states:
```lean
theorem kappa_rec_succ_drop (b s n : Trace) :
  kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n)) := by
  rw [kappa_rec_delta_step]
  sorry
```

Even ignoring the use of `kappa_rec_delta_step`, this inequality is false in general. Using the same counterexample `b = void`, `s = void`, `n = delta void`:
- LHS: `kappa (app void (recDelta void void (delta void))) = 1`.
- RHS: `kappa (recDelta void void (delta (delta void))) = 1`.
Thus, `1 < 1` is false.

### Implication for Termination

The rewrite rule `R_rec_succ` applies to terms of the form `recDelta b s (delta n)`, reducing them to `app s (recDelta b s n)`. The theorem `kappa_rec_succ_drop` is intended to prove that `kappa` decreases during this step. However, because the inequality fails when `n` is a delta, the measure `kappa` as defined does not guarantee termination for `R_rec_succ`. The helper strategy is therefore unsound.

### Conclusion

Both theorems are false in general, and the termination argument using `kappa` is flawed as written. The definitions would need to be adjusted (e.g., by restricting `n` to non-delta traces or modifying `kappa`) to ensure soundness.
