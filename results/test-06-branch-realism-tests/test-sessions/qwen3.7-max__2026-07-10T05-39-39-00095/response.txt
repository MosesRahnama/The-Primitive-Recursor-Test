## Assessment: The Helper Strategy is Unsound

Both helper theorems are **false** as stated. They fail when the third argument `n` is itself of the form `delta m`. Below are the detailed calculations.

---

### Theorem 1: `kappa_rec_delta_step` is false

**Claim:** `kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1` for all `n`.

**Counterexample:** Let `b = void`, `s = void`, `n = delta void`.

**LHS:**
```
kappa (recDelta void void (delta (delta void)))
  -- matches the (delta n) branch with n = delta void
= Nat.max (Nat.max (kappa void) (kappa void)) (kappa (delta void)) + 1
= Nat.max (Nat.max 0 0) (kappa void) + 1
= Nat.max 0 0 + 1
= 1
```

**RHS:**
```
kappa (recDelta void void (delta void)) + 1
  -- matches the (delta n) branch with n = void
= (Nat.max (Nat.max (kappa void) (kappa void)) (kappa void) + 1) + 1
= (Nat.max 0 0 + 1) + 1
= 1 + 1
= 2
```

**1 ≠ 2.** The root cause is that `kappa (delta t) = kappa t`, so wrapping `n` in `delta` doesn't increase `kappa n`, yet the `recDelta` pattern-match clause for `delta n` adds only one `+1` regardless of how many `delta` layers are present.

---

### Theorem 2: `kappa_rec_succ_drop` is false

**Claim:** `kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))` for all `n`.

**Counterexample:** Same values: `b = void`, `s = void`, `n = delta void`.

**LHS:**
```
kappa (app void (recDelta void void (delta void)))
= Nat.max (kappa void) (kappa (recDelta void void (delta void)))
= Nat.max 0 (Nat.max (Nat.max 0 0) (kappa void) + 1)   -- delta-branch, n=void
= Nat.max 0 (0 + 1)
= 1
```

**RHS:**
```
kappa (recDelta void void (delta (delta void)))
  -- delta-branch, n = delta void
= Nat.max (Nat.max (kappa void) (kappa void)) (kappa (delta void)) + 1
= Nat.max (Nat.max 0 0) 0 + 1
= 1
```

**1 < 1 is false.** The inequality collapses to equality because `kappa (delta void) = kappa void = 0`, making the `+1` on the RHS insufficient to exceed the LHS.

---

### Root Cause

The measure `kappa` assigns `kappa (delta t) = kappa t`, meaning `delta` is invisible to the measure. However, the `recDelta` definition's `(delta n)` branch adds `+1` on top of `kappa n`. When `n` is itself a `delta m`, `kappa n = kappa m`, so the `+1` premium is the same whether you have one `delta` or two. This makes it impossible for `kappa` to distinguish `recDelta b s (delta (delta m))` from `recDelta b s (delta m)` in terms of measure, breaking both the equality in Theorem 1 and the strict inequality in Theorem 2.

A sound fix would require either:
1. Making `kappa (delta t) > kappa t` (e.g., `kappa (delta t) = kappa t + 1`), or
2. Redefining the `recDelta` branches so the measure accounts for the structural depth of `delta` nesting explicitly.
