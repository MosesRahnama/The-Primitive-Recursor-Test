# Assessment of the Helper Strategy

## Conclusion: **UNSOUND** ❌

The helper strategy contains a critical flaw. Specifically, `kappa_rec_succ_drop` cannot be proven as stated because the inequality does not hold in general.

---

## Detailed Analysis

### Theorem 1: `kappa_rec_delta_step`

This theorem claims:
```
kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1
```

**Analysis:**
- `kappa (recDelta b s (delta n)) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1` (by definition)
- `kappa (recDelta b s n) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)` (by the non-delta case in `kappa`)

Therefore:
```
kappa (recDelta b s (delta n)) 
  = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1
  = kappa (recDelta b s n) + 1
```

✅ **This theorem is provable and correct.**

### Theorem 2: `kappa_rec_succ_drop`

This theorem claims:
```
kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))
```

**Calculation:**
After rewriting with `kappa_rec_delta_step`:
```
Goal: kappa (app s (recDelta b s n)) < kappa (recDelta b s n) + 1
```

Now expand both sides:
```
kappa (app s (recDelta b s n)) 
  = Nat.max (kappa s) (kappa (recDelta b s n))
  = Nat.max (kappa s) (Nat.max (Nat.max (kappa b) (kappa s)) (kappa n))
```

For the inequality to hold:
```
Nat.max (kappa s) (Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)) < 
  Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1
```

**Counterexample:** Let `kappa b = 0`, `kappa s = 5`, `kappa n = 0`.

Then:
- LHS = `Nat.max 5 (Nat.max (Nat.max 0 5) 0) = Nat.max 5 5 = 5`
- RHS = `Nat.max (Nat.max 0 5) 0 + 1 = 5 + 1 = 6`

So `5 < 6` ✓ works in this case.

**Better counterexample:** Let `kappa b = 0`, `kappa s = 5`, `kappa n = 5`.

Then:
- LHS = `Nat.max 5 (Nat.max (Nat.max 0 5) 5) = Nat.max 5 5 = 5`
- RHS = `Nat.max (Nat.max 0 5) 5 + 1 = 5 + 1 = 6`

Again `5 < 6` ✓.

Actually, **the inequality is always true** because for any natural numbers `a`, `b`, `c`:
```
Nat.max a (Nat.max b c) ≤ Nat.max b c < Nat.max b c + 1
```

So `kappa_rec_succ_drop` **is actually provable** despite the `sorry`. The issue is that the proof strategy is left incomplete.

## Summary

| Theorem | Status | Reason |
|---------|--------|--------|
| `kappa_rec_delta_step` | ✅ Provable | Direct unfolding of definitions |
| `kappa_rec_succ_drop` | ✅ Provable | The inequality holds but the proof is incomplete (contains `sorry`) |

**The helper strategy is *semantically sound* in that both theorems are true, but *practically incomplete* since the second proof is left unfinished.**
