No.  
Both auxiliary lemmas are only correct when the third argument of 
recDelta is NOT itself a δ-term.  
As soon as that argument already begins with a δ, each lemma is
violated and the intended “measure drop’’ that should guarantee
termination disappears.

Let  

  B  = κ b, S = κ s, N = κ n,  
  M  = max (max B S) N.  

1.  κ-value of the two kinds of recDelta nodes  

    κ (recDelta b s (δ n))       = M + 1  
    κ (recDelta b s n)           = M         if n is not a δ-term  
                                   M + 1     if n = δ n′.  

2.  Lemma 1 (kappa_rec_delta_step)

    Claim: κ (recDelta b s (δ n)) = κ (recDelta b s n) + 1.

    Take n := δ n′.  
    Then κ (recDelta b s (δ n)) = M + 1, while  
         κ (recDelta b s n) + 1 = (M + 1) + 1 = M + 2.  
    Hence the required equality fails whenever n already has a leading
    δ.  The lemma is therefore false.

3.  Lemma 2 (kappa_rec_succ_drop)

    Claim: κ (app s (recDelta b s n)) < κ (recDelta b s (δ n)).

    With the same choice n := δ n′ we have

        κ (recDelta b s (δ n)) = M + 1,
        κ (recDelta b s n)     = M + 1,
        κ (app s (recDelta …)) = max (S, M+1) = M + 1               (because S ≤ M).

    Thus left– and right–hand sides are equal, not strictly ordered, so
    the strict inequality is violated.

Because the measure κ ignores a leading δ (κ (δ t) = κ t), dropping one
δ from the argument of recDelta does not necessarily lower the overall
measure once that argument already starts with at least one δ.  Hence
the measure does not strictly decrease along the rule  

   recDelta b s (δ n)  →  app s (recDelta b s n),

and the two helper statements as written are unsound.  A correct
termination proof needs either a different measure or a version of the
lemmas that is restricted to the case where n itself is not a δ-term.
