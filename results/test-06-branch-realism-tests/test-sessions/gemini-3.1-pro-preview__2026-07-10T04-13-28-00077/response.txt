The helper strategy is **unsound** as written. Both theorems (`kappa_rec_delta_step` and `kappa_rec_succ_drop`) are false. 

### The Root Cause
The structural measure `kappa` does not count the depth of nested `delta` constructors. By definition, `kappa (.delta t) = kappa t`. 

For `.recDelta b s n`, the pattern match only checks if the third argument *immediately* starts with a `.delta`. If it does, it adds `1` to the result, but then it computes the `kappa` of the inner term. Because nested `delta`s are skipped without adding to the score, `kappa` can at most add `1` regardless of how many `delta` constructors are layered in that position.

### Calculations / Counterexample
We can demonstrate this by setting `b = .void`, `s = .void`, and `n = .delta .void`. 

First, note the base evaluations of `kappa`:
* `kappa .void = 0`
* `kappa (.delta .void) = kappa .void = 0`

Now let's evaluate the `.recDelta` term where the third argument is a single `.delta .void`:
```lean
  kappa (recDelta .void .void (.delta .void))
```
This hits the pattern `| .recDelta b s (.delta n')` with `n' = .void`. 
It evaluates to: `Nat.max (Nat.max (kappa .void) (kappa .void)) (kappa .void) + 1 = 0 + 1 = 1`.

Next, evaluate the `.recDelta` term where the third argument has nested deltas (`.delta (.delta .void)`):
```lean
  kappa (recDelta .void .void (.delta (.delta .void)))
```
This hits the pattern `| .recDelta b s (.delta n')` with `n' = .delta .void`.
It evaluates to: `Nat.max (Nat.max (kappa .void) (kappa .void)) (kappa (.delta .void)) + 1`. 
Because `kappa (.delta .void) = 0`, this also evaluates to `0 + 1 = 1`.

#### 1. Falsifying `kappa_rec_delta_step`
The theorem claims:
```lean
kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1
```
Plugging in our counterexample (`b = .void`, `s = .void`, `n = .delta .void`):
* **LHS:** `kappa (recDelta .void .void (delta (delta .void))) = 1`
* **RHS:** `kappa (recDelta .void .void (delta .void)) + 1 = 1 + 1 = 2`

`1 = 2` is false.

#### 2. Falsifying `kappa_rec_succ_drop`
The theorem claims:
```lean
kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))
```
Plugging in the same counterexample:
* **LHS:** `kappa (app .void (recDelta .void .void (delta .void)))`
  By definition of `kappa` on `.app`, this is: 
  `Nat.max (kappa .void) (kappa (recDelta .void .void (delta .void))) = Nat.max 0 1 = 1`.
* **RHS:** `kappa (recDelta .void .void (delta (delta .void))) = 1`.

`1 < 1` is false.
