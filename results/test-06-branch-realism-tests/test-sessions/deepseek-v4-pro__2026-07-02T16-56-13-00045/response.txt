The helper strategy is **not sound** as written. The first stated theorem, `kappa_rec_delta_step`, is false in general, which breaks the intended termination argument.

### Why `kappa_rec_delta_step` fails

Recall the definition of `kappa`:

```lean
def kappa : Trace → Nat
  | .recDelta b s (.delta n) => Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1
  | .recDelta b s n          => Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)
```

The theorem claims:

```
∀ b s n, kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1
```

Let’s compute both sides for a concrete counterexample:  
Take `b = .void`, `s = .void`, `n = .delta .void`.

- **LHS:** `recDelta .void .void (delta (delta .void))`  
  The third argument is `delta (delta .void)`, which matches the pattern `.delta n` with `n = delta .void`.  
  `kappa` = `max(max(0,0), kappa(delta .void)) + 1`  
  `kappa(delta .void) = kappa .void = 0`.  
  So LHS = `max(0, 0) + 1 = 1`.

- **RHS:** `kappa (recDelta .void .void (delta .void)) + 1`  
  Here the third argument is `delta .void`, again matching the `.delta n` case with `n = .void`.  
  `kappa(recDelta .void .void (delta .void)) = max(max(0,0), kappa .void) + 1 = 0 + 1 = 1`.  
  Then RHS = `1 + 1 = 2`.

We obtain `1 = 2`, a contradiction.  
More generally, whenever `n` itself is a `delta` term, the left side gets exactly one `+1` while the right side gets `+1` from the inner `kappa` and an extra `+1` outside, making the equality fail. The statement only holds when `n` is **not** a `delta` term, but the quantifier requires it to hold for every `n : Trace`. Hence the lemma is false.

### Impact on `kappa_rec_succ_drop`

The second theorem begins with:

```lean
theorem kappa_rec_succ_drop (b s n : Trace) :
  kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n)) := by
  rw [kappa_rec_delta_step]
```

This rewrite replaces the RHS with `kappa (recDelta b s n) + 1`. After that, the goal is

```
kappa (app s (recDelta b s n)) < kappa (recDelta b s n) + 1
```

By definition `kappa (app a b) = max (kappa a) (kappa b)`, the left side becomes `max (kappa s) (kappa (recDelta b s n))`.  
The required inequality `max(Ks, K_rec) < K_rec + 1` is not universally true either: it fails whenever `kappa s > K_rec` (for instance, `K_rec = 3`, `Ks = 5` gives `5 < 4`, false).

Since the very first rewrite relies on an invalid lemma, and the resulting goal is also not provable, the helper strategy is unsound.
