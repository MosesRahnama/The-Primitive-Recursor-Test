# Assessment of the Helper Strategy

## Goal: Determine if the two helper theorems are sound (true) as stated.

---

## Theorem 1: `kappa_rec_delta_step`

**Statement:**
```
kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1
```

**Analysis:**

The LHS is:
```
kappa (recDelta b s (delta n)) = max (max (kappa b) (kappa s)) (kappa n) + 1
```
by the `recDelta`-with-`delta` clause.

The RHS depends on the shape of `n`. We need:
```
kappa (recDelta b s n) + 1
```

**Case 1: `n` is not of the form `delta m`.** Then `kappa (recDelta b s n) = max (max (kappa b) (kappa s)) (kappa n)`, so the RHS is `max (max (kappa b) (kappa s)) (kappa n) + 1`. This matches the LHS. ✓

**Case 2: `n = delta m` for some `m`.** Then:
- LHS = `max (max (kappa b) (kappa s)) (kappa (delta m)) + 1 = max (max (kappa b) (kappa s)) (kappa m) + 1`
- RHS = `kappa (recDelta b s (delta m)) + 1 = (max (max (kappa b) (kappa s)) (kappa m) + 1) + 1`

These are **not equal** in general. For example, take `b = s = void`, `n = delta void`:
- LHS = `max (max 0 0) 0 + 1 = 1`
- RHS = `(max (max 0 0) 0 + 1) + 1 = 2`

**Theorem 1 is FALSE.** ✗

---

## Theorem 2: `kappa_rec_succ_drop`

**Statement:**
```
kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))
```

**Analysis:**

The RHS is `max (max (kappa b) (kappa s)) (kappa n) + 1`.

The LHS is `kappa (app s (recDelta b s n)) = max (kappa s) (kappa (recDelta b s n))`.

**Case: `n` is not `delta m`.** Then:
```
LHS = max (kappa s) (max (max (kappa b) (kappa s)) (kappa n))
     = max (max (kappa b) (kappa s)) (kappa n)
```
RHS = that value + 1. So LHS < RHS. ✓

**Case: `n = delta m`.** Then:
```
kappa (recDelta b s n) = max (max (kappa b) (kappa s)) (kappa m) + 1
LHS = max (kappa s) (max (max (kappa b) (kappa s)) (kappa m) + 1)
    = max (max (kappa b) (kappa s)) (kappa m) + 1
RHS = max (max (kappa b) (kappa s)) (kappa m) + 1
```

So LHS = RHS, meaning LHS < RHS is **false**.

For a concrete counterexample: `b = s = void`, `n = delta void`:
- LHS = `max 0 (0 + 1) = 1`
- RHS = `0 + 1 = 1`
- `1 < 1` is false.

**Theorem 2 is FALSE.** ✗

---

## Conclusion

**The helper strategy is unsound as written.** Both theorems fail when `n` is itself of the form `delta m`, because the pattern-match clause for `recDelta b s (delta n)` in `kappa` adds `+1` based on the *outermost* `delta`, but when `n` is also a `delta`, the recursive call `kappa (recDelta b s n)` triggers the same `+1` clause again. The measure `kappa` adds 1 for each `delta` wrapper on the third argument of `recDelta`, so `kappa (recDelta b s (delta (delta m)))` is `base + 2`, not `base + 1` where `base` is `kappa (recDelta b s (delta m))`.

A correct measure for the termination argument would need to track the structural size of the third argument of `recDelta` (e.g., counting `delta` nesting depth), rather than relying on `kappa` as defined. Alternatively, one could use `sizeOf` or a dedicated structural recursion principle.
