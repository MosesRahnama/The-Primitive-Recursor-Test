## Theorem 1: `kappa_rec_delta_step`

**Claim:** `kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1`

From the definition of `kappa`:
- `kappa (recDelta b s (delta n)) = max (max (kappa b) (kappa s)) (kappa n) + 1`

For `kappa (recDelta b s n)`, we need to consider what `n` is. The definition has two cases:
- If `n = delta n'`: `kappa (recDelta b s (delta n')) = max (max (kappa b) (kappa s)) (kappa n') + 1`
- Otherwise (n is not of the form `delta _`): `kappa (recDelta b s n) = max (max (kappa b) (kappa s)) (kappa n)`

So `kappa (recDelta b s n) + 1`:
- If `n = delta n'`: `max (max (kappa b) (kappa s)) (kappa n') + 2`
- Otherwise: `max (max (kappa b) (kappa s)) (kappa n) + 1`

And `kappa (recDelta b s (delta n)) = max (max (kappa b) (kappa s)) (kappa n) + 1` always.

The equation holds **only when `n` is not of the form `delta _`** (i.e., `void`, `integrate`, `merge`, `app`, `recDelta`, `eqW`). When `n = delta n'`, the left side is `max (max (kappa b) (kappa s)) (kappa n') + 1` while the right side is `max (max (kappa b) (kappa s)) (kappa n') + 2`. These are **not equal**.

**Theorem 1 is false in general.**

## Theorem 2: `kappa_rec_succ_drop`

**Claim:** `kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))`

Left side: `kappa (app s (recDelta b s n)) = max (kappa s) (kappa (recDelta b s n))`

For the non-`delta` case of `n`: `kappa (recDelta b s n) = max (max (kappa b) (kappa s)) (kappa n)`

So LHS = `max (kappa s) (max (max (kappa b) (kappa s)) (kappa n)) = max (max (kappa b) (kappa s)) (kappa n)`

RHS = `max (max (kappa b) (kappa s)) (kappa n) + 1`

So LHS < RHS ✓ in this case.

For `n = delta n'`: `kappa (recDelta b s (delta n')) = max (max (kappa b) (kappa s)) (kappa n') + 1`

LHS = `max (kappa s) (max (max (kappa b) (kappa s)) (kappa n') + 1)`

Let `M = max (max (kappa b) (kappa s)) (kappa n')`. Then RHS = `M + 1`, and LHS = `max (kappa s) (M + 1)`.

If `kappa s > M + 1`, then LHS = `kappa s > M + 1` = RHS, so **LHS ≥ RHS**, violating the strict inequality.

## Conclusion

**The helper strategy is unsound.** Both theorems are false as stated. Theorem 1 fails when `n` is itself a `delta`-headed term (the `+1` is not preserved through the recursive unfolding).
