Short answer: **the strategy is sound** (for these two helper lemmas), and the needed arithmetic checks out.

### Why `kappa_rec_delta_step` is valid

Let
\[
M := \max(\max(\kappa b,\kappa s),\kappa n).
\]
By definition:
- \(\kappa(\mathrm{recDelta}\ b\ s\ (\delta n)) = M + 1\) (special `recDelta ... (delta n)` clause),
- \(\kappa(\mathrm{recDelta}\ b\ s\ n) = M\), because `kappa (delta n) = kappa n`, so even if `n` happens to be `delta _`, both clauses still agree numerically.

Hence
\[
\kappa(\mathrm{recDelta}\ b\ s\ (\delta n))
= M+1
= \kappa(\mathrm{recDelta}\ b\ s\ n)+1.
\]
So theorem 1 is correct.

---

### Why `kappa_rec_succ_drop` is valid

You want:
\[
\kappa(\mathrm{app}\ s\ (\mathrm{recDelta}\ b\ s\ n))
< \kappa(\mathrm{recDelta}\ b\ s\ (\delta n)).
\]

Compute left side:
\[
\kappa(\mathrm{app}\ s\ (\mathrm{recDelta}\ b\ s\ n))
= \max(\kappa s,\kappa(\mathrm{recDelta}\ b\ s\ n)).
\]
Let \(R := \kappa(\mathrm{recDelta}\ b\ s\ n)\).  
Since \(R = \max(\max(\kappa b,\kappa s),\kappa n)\), we have \(\kappa s \le R\), so
\[
\max(\kappa s,R)=R.
\]
Thus LHS \(=R\).

Using theorem 1, RHS:
\[
\kappa(\mathrm{recDelta}\ b\ s\ (\delta n)) = R+1.
\]
So inequality becomes \(R < R+1\), true in `Nat`.

So theorem 2 is also correct.

---

### Caveat (important for bigger termination goal)

These lemmas only justify the `R_rec_succ` decrease. As a global rewrite termination measure, `kappa` is **not** strictly decreasing on every rule (e.g. `R_eq_diff`: `eqW a b -> integrate (merge a b)` preserves `kappa` exactly). So this helper strategy is sound locally, but insufficient by itself for full strict-decrease termination over all `Step` rules.
