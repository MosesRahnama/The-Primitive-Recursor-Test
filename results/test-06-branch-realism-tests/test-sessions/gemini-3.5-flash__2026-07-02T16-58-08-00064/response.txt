The helper strategy is **unsound**. Both proposed theorems are false as written because the structural measure $\kappa$ does not strictly decrease or satisfy the expected recurrence relation when the recursion depth $n$ is itself of the form $\text{delta } n'$. 

We can show this with a concrete counterexample.

### Counterexample
Let:
* $b = \text{void}$
* $s = \text{void}$
* $n = \text{delta void}$

Using the definitions of $\kappa$ from the file:
1. $\kappa(\text{void}) = 0$
2. $\kappa(\text{delta void}) = \kappa(\text{void}) = 0$

---

### Analysis of `kappa_rec_delta_step`

The theorem statement is:
$$\kappa(\text{recDelta } b\ s\ (\text{delta } n)) = \kappa(\text{recDelta } b\ s\ n) + 1$$

Let us evaluate both sides with our counterexample values:

* **Left-Hand Side (LHS):**
  $$\kappa(\text{recDelta } \text{void } \text{void } (\text{delta } (\text{delta void})))$$
  Since the third argument is a $\text{delta}$, this matches the first case of $\kappa$ for `recDelta`:
  $$\max(\max(\kappa(\text{void}), \kappa(\text{void})), \kappa(\text{delta void})) + 1$$
  $$\max(\max(0, 0), 0) + 1 = 1$$

* **Right-Hand Side (RHS):**
  $$\kappa(\text{recDelta } \text{void } \text{void } (\text{delta void})) + 1$$
  Using the first case again since the third argument is a $\text{delta}$:
  $$\left(\max(\max(\kappa(\text{void}), \kappa(\text{void})), \kappa(\text{void})) + 1\right) + 1$$
  $$(0 + 1) + 1 = 2$$

Since $\text{LHS} = 1 \neq 2 = \text{RHS}$, the theorem `kappa_rec_delta_step` is **false**.

---

### Analysis of `kappa_rec_succ_drop`

The theorem statement is:
$$\kappa(\text{app } s\ (\text{recDelta } b\ s\ n)) < \kappa(\text{recDelta } b\ s\ (\text{delta } n))$$

Let us evaluate both sides with our counterexample values:

* **Left-Hand Side (LHS):**
  $$\kappa(\text{app } \text{void } (\text{recDelta } \text{void } \text{void } (\text{delta void})))$$
  Using the definition of $\kappa$ for `app`:
  $$\max(\kappa(\text{void}), \kappa(\text{recDelta } \text{void } \text{void } (\text{delta void})))$$
  $$\max(0, \max(\max(0, 0), 0) + 1) = \max(0, 1) = 1$$

* **Right-Hand Side (RHS):**
  $$\kappa(\text{recDelta } \text{void } \text{void } (\text{delta } (\text{delta void})))$$
  As calculated in the previous step, this evaluates to:
  $$1$$

The inequality becomes $1 < 1$, which is **false**. Therefore, `kappa_rec_succ_drop` is also **false**.

### Conclusion
The helper strategy is **unsound**. Because $\kappa(\text{delta } t) = \kappa(t)$, wrapping terms in $\text{delta}$ does not increase their $\kappa$ value. Consequently, when evaluating nested recursion steps of the form `delta (delta n)`, the measure does not increase, violating the strict decrease required for termination.
