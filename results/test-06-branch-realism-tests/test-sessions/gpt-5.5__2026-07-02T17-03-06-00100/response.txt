The helper strategy is **not sound as written**. Both intended helper theorems are false in general.

Let

\[
C = \max(\kappa b)(\kappa s).
\]

By definition,

\[
\kappa(\mathrm{recDelta}\ b\ s\ (\delta n))
= \max(C, \kappa n) + 1.
\]

But the value of

\[
\kappa(\mathrm{recDelta}\ b\ s\ n)
\]

depends on the shape of `n`.

---

## 1. `kappa_rec_delta_step` is false

The theorem claims:

```lean
kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1
```

This is true only when `n` is not itself a `delta`. If `n = delta m`, then:

\[
\kappa n = \kappa(\delta m) = \kappa m.
\]

So the left-hand side is:

\[
\kappa(\mathrm{recDelta}\ b\ s\ (\delta(\delta m)))
= \max(C, \kappa m) + 1.
\]

But the right-hand side is:

\[
\kappa(\mathrm{recDelta}\ b\ s\ (\delta m)) + 1
= \left(\max(C, \kappa m) + 1\right) + 1.
\]

So the claimed equality becomes:

\[
\max(C, \kappa m) + 1
=
\max(C, \kappa m) + 2,
\]

which is impossible.

Concrete counterexample:

```lean
b = void
s = void
n = delta void
```

Then:

```lean
kappa (recDelta void void (delta (delta void))) = 1
```

but

```lean
kappa (recDelta void void (delta void)) + 1 = 2
```

So the theorem would assert `1 = 2`.

---

## 2. `kappa_rec_succ_drop` is also false

The theorem claims:

```lean
kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))
```

Again take `n = delta m`.

The right-hand side is:

\[
\kappa(\mathrm{recDelta}\ b\ s\ (\delta(\delta m)))
= \max(C, \kappa m) + 1.
\]

The left-hand side is:

\[
\kappa(\mathrm{app}\ s\ (\mathrm{recDelta}\ b\ s\ (\delta m)))
=
\max(\kappa s, \kappa(\mathrm{recDelta}\ b\ s\ (\delta m))).
\]

But

\[
\kappa(\mathrm{recDelta}\ b\ s\ (\delta m))
=
\max(C, \kappa m) + 1.
\]

Since `κ s ≤ C ≤ max(C, κ m) + 1`, the left-hand side simplifies to:

\[
\max(C, \kappa m) + 1.
\]

So both sides are equal, not strictly decreasing.

Concrete counterexample:

```lean
b = void
s = void
n = delta void
```

Then:

```lean
kappa (app void (recDelta void void (delta void))) = 1
```

and

```lean
kappa (recDelta void void (delta (delta void))) = 1
```

So the claimed strict inequality is:

```lean
1 < 1
```

which is false.

---

Therefore the proposed helper strategy cannot justify termination using this `kappa` measure. In particular, the rewrite

```lean
recDelta b s (delta n) ↦ app s (recDelta b s n)
```

does not strictly decrease `kappa` when `n` is itself a `delta`; it preserves it.
