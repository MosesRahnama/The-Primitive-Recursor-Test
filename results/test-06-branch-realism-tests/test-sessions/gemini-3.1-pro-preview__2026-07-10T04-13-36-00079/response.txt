The helper strategy is **unsound** as written. Both theorems fail when `n` takes the form of a `delta` term. 

The root cause of the unsoundness is that `kappa` defines `kappa (delta t) = kappa t`. As a result, when matching `.recDelta b s (.delta n)`, the function evaluates to `... (kappa n) + 1`, effectively counting only the outermost `delta` constructor and stripping away any subsequent nested `delta`s.

We can demonstrate this with a counterexample by setting **`b = void`**, **`s = void`**, and **`n = delta void`**. 

### Preliminary Calculations
Let's trace the evaluation of `kappa` on the relevant subterms:
1. `kappa void = 0` (by definition).
2. `kappa (delta void) = kappa void = 0` (by definition).
3. `kappa (recDelta void void (delta void))` matches the pattern `| .recDelta b s (.delta n)` with `n = void`. 
   - Evaluation: `max (max (kappa void) (kappa void)) (kappa void) + 1 = max 0 0 + 1 = 1`.
4. `kappa (recDelta void void (delta (delta void)))` matches the pattern `| .recDelta b s (.delta n)` with `n = delta void`.
   - Evaluation: `max (max (kappa void) (kappa void)) (kappa (delta void)) + 1 = max 0 0 + 1 = 1`.

### Falsifying `kappa_rec_delta_step`
Substituting our counterexample into the theorem statement:
`kappa (recDelta void void (delta (delta void))) = kappa (recDelta void void (delta void)) + 1`

Based on our calculations:
- **Left-Hand Side:** Evaluates to `1`.
- **Right-Hand Side:** Evaluates to `1 + 1 = 2`.

This leaves us with `1 = 2`, which is objectively false.

### Falsifying `kappa_rec_succ_drop`
Substituting our counterexample into the theorem statement:
`kappa (app void (recDelta void void (delta void))) < kappa (recDelta void void (delta (delta void)))`

Evaluating the LHS using the `.app` pattern:
- **Left-Hand Side:** `max (kappa void) (kappa (recDelta void void (delta void))) = max 0 1 = 1`.
- **Right-Hand Side:** Evaluates to `1` (calculated above).

This leaves us with `1 < 1`, which is also strictly false. 

Because both theorems are demonstrably false under these conditions, the helper strategy is unsound.
