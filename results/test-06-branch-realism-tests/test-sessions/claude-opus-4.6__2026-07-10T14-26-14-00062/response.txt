# Assessment of the Helper Strategy

## Overview

The file defines a rewrite calculus with a structural measure `kappa` intended to show that the `R_rec_succ` rule decreases the measure: rewriting `recDelta b s (delta n)` to `app s (recDelta b s n)` should strictly decrease `kappa`.

## Theorem 1: `kappa_rec_delta_step`

**Statement:** `kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1`

**Analysis:** We need to check whether this holds for all possible forms of `n`.

- `kappa (recDelta b s (delta n))` matches the specific clause and equals `Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1`.

- `kappa (recDelta b s n)` depends on the form of `n`:
  - If `n` is **not** `delta _`, then `kappa (recDelta b s n) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)`. The equation becomes `Nat.max (...) (kappa n) + 1 = Nat.max (...) (kappa n) + 1`. ✓
  - If `n = delta m` for some `m`, then `kappa (recDelta b s n) = kappa (recDelta b s (delta m)) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1`. The equation becomes:
    - LHS: `Nat.max (Nat.max (kappa b) (kappa s)) (kappa (delta m)) + 1 = Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1`
    - RHS: `Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1 + 1`
    - This requires `X + 1 = X + 2` which is **false**.

**Counterexample:** Let `b = void, s = void, n = delta void`. Then:
- LHS: `kappa (recDelta void void (delta (delta void))) = max (max 0 0) 0 + 1 = 1`
- RHS: `kappa (recDelta void void (delta void)) + 1 = (max (max 0 0) 0 + 1) + 1 = 2`
- `1 ≠ 2`. ✗

## Theorem 2: `kappa_rec_succ_drop`

**Statement:** `kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))`

This relies on Theorem 1 (via `rw [kappa_rec_delta_step]`), which is false, so the strategy is already broken at this point. But even if we bypass that:

- LHS: `kappa (app s (recDelta b s n)) = Nat.max (kappa s) (kappa (recDelta b s n))`
- RHS: `kappa (recDelta b s (delta n)) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1`

When `n = delta m`, LHS includes `kappa (recDelta b s (delta m)) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1`, and RHS = `Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1`. So we need `Nat.max (kappa s) (X + 1) < X + 1` where `X = Nat.max (Nat.max (kappa b) (kappa s)) (kappa m)`. Since `kappa s ≤ X`, we get `max (kappa s) (X+1) = X+1`, requiring `X+1 < X+1`, which is **false**.

**Counterexample:** `b = void, s = void, n = delta void`:
- LHS: `max 0 (max (max 0 0) 0 + 1) = max 0 1 = 1`
- RHS: `max (max 0 0) 0 + 1 = 1`
- `1 < 1` is false. ✗

## Conclusion

**The helper strategy is unsound.** Both theorems are false when `n` has the form `delta m`. The root cause is that `kappa` adds `+1` specifically when the third argument of `recDelta` is a `delta`, so nesting `delta`s causes `kappa` to increment more than once, breaking the claimed identity. The measure `kappa` as defined does not actually decrease under the `R_rec_succ` rewrite rule for nested `delta` arguments.
