The helper strategy is **unsound** as written. Both theorems are false when the parameter `n` is itself a `delta` term.

### Counterexample

Take `b = void`, `s = void`, and `n = delta void`.

**Calculating `kappa` values:**

By definition:
- `kappa void = 0`
- `kappa (delta void) = kappa void = 0`

For `recDelta` with a `delta` third argument:
- `kappa (recDelta b s (delta x)) = max (max (kappa b) (kappa s)) (kappa x) + 1`

**For the first theorem** `kappa_rec_delta_step`:
- Left side: `kappa (recDelta void void (delta (delta void)))`
  - This matches the first pattern (third arg is `delta (delta void)`), with inner `n = delta void`.
  - Value: `max (max 0 0) (kappa (delta void)) + 1 = max 0 0 + 1 = 1`

- Right side: `kappa (recDelta void void (delta void)) + 1`
  - This matches the first pattern with inner `n = void`.
  - Value: `(max (max 0 0) (kappa void) + 1) + 1 = (0 + 1) + 1 = 2`

The theorem claims `1 = 2`, which is false.

**For the second theorem** `kappa_rec_succ_drop`:
- Left side: `kappa (app void (recDelta void void (delta void)))`
  - `kappa (recDelta void void (delta void)) = 1` (from above)
  - `kappa (app void ...) = max (kappa void) 1 = max 0 1 = 1`

- Right side: `kappa (recDelta void void (delta (delta void))) = 1` (from above)

The theorem claims `1 < 1`, which is false.

### Root Cause

The definition of `kappa` distinguishes between `recDelta b s (.delta n)` and `recDelta b s n`:
- When the third argument is a `delta`, it adds `+ 1`
- Otherwise, it doesn't

When `n` is already a `delta` (say `n = delta m`):
- `kappa (recDelta b s (delta n))` counts the nested delta (the outer one)
- `kappa (recDelta b s n)` also counts the delta (since `n` is `delta m`)

Specifically:
- `kappa (recDelta b s (delta (delta m))) = max (max (kappa b) (kappa s)) (kappa m) + 1`
- `kappa (recDelta b s (delta m)) = max (max (kappa b) (kappa s)) (kappa m) + 1`

They are **equal**, not differing by 1.

Consequently, the rewrite step `recDelta b s (delta n) → app s (recDelta b s n)` does **not** decrease the measure when `n` is a `delta` (the measure stays the same), making the termination argument invalid as written.
