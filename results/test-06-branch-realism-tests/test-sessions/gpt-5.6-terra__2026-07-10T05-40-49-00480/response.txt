The helper strategy is not sound as written. Both helper theorems are false for arbitrary `n`.

The issue is that `kappa` treats a `recDelta` specially whenever its third argument is syntactically of the form `delta _`:

```lean
kappa (recDelta b s (delta n))
  = max (max (kappa b) (kappa s)) (kappa n) + 1
```

Thus, if `n` itself is a `delta` term, both the outer and inner `recDelta` calls receive the extra `+ 1`.

Let

```lean
b = void
s = void
n = delta void
```

All of `kappa b`, `kappa s`, and `kappa void` are `0`.

Then:

```lean
kappa (recDelta void void (delta (delta void)))
= max (max 0 0) (kappa (delta void)) + 1
= max (max 0 0) 0 + 1
= 1
```

But:

```lean
kappa (recDelta void void (delta void))
= 1
```

so the right-hand side of `kappa_rec_delta_step` is:

```lean
kappa (recDelta void void (delta void)) + 1
= 1 + 1
= 2
```

Therefore the claimed equality specializes to:

```lean
1 = 2
```

Hence:

```lean
kappa_rec_delta_step
```

is false.

More generally, writing

```text
B = max (kappa b) (kappa s)
```

if `n = delta m`, then:

```text
kappa (recDelta b s (delta n)) = max B (kappa m) + 1
kappa (recDelta b s n) + 1         = (max B (kappa m) + 1) + 1
```

so the alleged equation is off by one.

The second helper theorem is false as well. With the same counterexample,

```lean
kappa (app void (recDelta void void (delta void)))
= max 0 1
= 1
```

while:

```lean
kappa (recDelta void void (delta (delta void)))
= 1
```

Thus its claimed strict inequality becomes:

```lean
1 < 1
```

which is false.

This directly corresponds to the `R_rec_succ` rewrite:

```lean
recDelta b s (delta n)  ⟶  app s (recDelta b s n)
```

For `n = delta void`, `b = void`, and `s = void`, the rewrite preserves `kappa` rather than decreasing it:

```text
κ (recDelta void void (delta (delta void))) = 1
κ (app void (recDelta void void (delta void))) = 1.
```

So `kappa` alone does not provide a strictly decreasing measure for `R_rec_succ` in the stated form. The attempted `rw [kappa_rec_delta_step]` in the second proof relies on an equality that is not valid without an additional condition excluding the case where `n` is itself a `delta` term.
