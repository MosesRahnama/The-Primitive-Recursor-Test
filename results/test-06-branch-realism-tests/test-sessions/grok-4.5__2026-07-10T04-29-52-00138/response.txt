The proposed helper lemmas are both false, so the strategy is unsound.

### Analysis of `kappa_rec_delta_step`
By definition of `kappa`,
\[
\kappa(\mathsf{recDelta}\,b\,s\,(\mathsf{delta}\,n))
=
\max(\max(\kappa b,\kappa s),\kappa n)+1.
\]
The right-hand side of the claimed equality is \(\kappa(\mathsf{recDelta}\,b\,s\,n)+1\). The value of \(\kappa(\mathsf{recDelta}\,b\,s\,n)\) itself depends on the shape of \(n\):

- If \(n\) is *not* headed by \(\mathsf{delta}\), the second equation of `kappa` applies and yields exactly \(\max(\max(\kappa b,\kappa s),\kappa n)\). The equality therefore holds.
- If \(n=\mathsf{delta}\,m\), the first equation of `kappa` applies instead:
  \[
  \kappa(\mathsf{recDelta}\,b\,s\,n)
  =
  \max(\max(\kappa b,\kappa s),\kappa m)+1.
  \]
  The claimed equality then becomes
  \[
  \max(\max(\kappa b,\kappa s),\kappa m)+1
  \;=\;
  \bigl(\max(\max(\kappa b,\kappa s),\kappa m)+1\bigr)+1,
  \]
  which is false.

Concrete counter-example: take \(b=s=\mathsf{void}\) and \(n=\mathsf{delta}\,\mathsf{void}\). Then
\[
\kappa(\mathsf{recDelta}\,\mathsf{void}\,\mathsf{void}\,(\mathsf{delta}\,(\mathsf{delta}\,\mathsf{void})))=1
\]
while
\[
\kappa(\mathsf{recDelta}\,\mathsf{void}\,\mathsf{void}\,(\mathsf{delta}\,\mathsf{void}))+1=2.
\]

### Analysis of `kappa_rec_succ_drop`
Even if the first helper were true, the second would still fail. Expanding definitions,
\[
\kappa(\mathsf{app}\,s\,(\mathsf{recDelta}\,b\,s\,n))
=
\max(\kappa s,\kappa(\mathsf{recDelta}\,b\,s\,n))
\]
and
\[
\kappa(\mathsf{recDelta}\,b\,s\,(\mathsf{delta}\,n))
=
\max(\max(\kappa b,\kappa s),\kappa n)+1.
\]
When \(n=\mathsf{delta}\,m\) the same calculation as above shows that both sides evaluate to the identical natural number
\[
\max(\max(\kappa b,\kappa s),\kappa m)+1,
\]
so the strict inequality does not hold.

(The same concrete values \(b=s=\mathsf{void}\), \(n=\mathsf{delta}\,\mathsf{void}\) already give \(1\not<1\).)

### Conclusion
Because both lemmas are false for arbitrary traces (they hold only when the third argument of \(\mathsf{recDelta}\) is not itself headed by \(\mathsf{delta}\)), any termination argument that relies on them is unsound.
