## Assessment: The helper strategy is **unsound**.

Both helper theorems are false. The root cause is that `kappa` is blind to `delta` wrappers (since `kappa (delta t) = kappa t`), which causes the `+1` in the `.recDelta b s (.delta n)` equation to fail to accumulate across nested `delta` constructors.

---

### Theorem 1: `kappa_rec_delta_step` is false

The theorem claims:

$$\kappa(\text{recDelta}\; b\; s\; (\delta\; n)) = \kappa(\text{recDelta}\; b\; s\; n) + 1$$

**Counterexample:** Let $b = \text{void}$, $s = \text{void}$, $n = \delta\;\text{void}$.

Note $\kappa(\text{void}) = 0$ and $\kappa(\delta\;\text{void}) = 0$.

**LHS:** $\kappa(\text{recDelta}\;\text{void}\;\text{void}\;(\delta\;(\delta\;\text{void})))$

The third argument is $\delta(\delta\;\text{void})$, which matches the pattern `.delta n` with $n = \delta\;\text{void}$:

$$\max(\max(0, 0),\; \kappa(\delta\;\text{void})) + 1 = \max(0, 0) + 1 = 1$$

**RHS:** $\kappa(\text{recDelta}\;\text{void}\;\text{void}\;(\delta\;\text{void})) + 1$

The third argument is $\delta\;\text{void}$, matching `.delta n` with $n = \text{void}$:

$$\max(\max(0, 0),\; \kappa(\text{void})) + 1 = 0 + 1 = 1$$

So RHS $= 1 + 1 = 2$.

$$\text{LHS} = 1 \neq 2 = \text{RHS}$$

---

### Theorem 2: `kappa_rec_succ_drop` is false

The theorem claims:

$$\kappa(\text{app}\; s\; (\text{recDelta}\; b\; s\; n)) < \kappa(\text{recDelta}\; b\; s\; (\delta\; n))$$

**Counterexample:** Same values: $b = \text{void}$, $s = \text{void}$, $n = \delta\;\text{void}$.

**LHS:** $\kappa(\text{app}\;\text{void}\;(\text{recDelta}\;\text{void}\;\text{void}\;(\delta\;\text{void})))$

From above, $\kappa(\text{recDelta}\;\text{void}\;\text{void}\;(\delta\;\text{void})) = 1$, so:

$$\max(\kappa(\text{void}),\; 1) = \max(0, 1) = 1$$

**RHS:** $\kappa(\text{recDelta}\;\text{void}\;\text{void}\;(\delta\;(\delta\;\text{void})))$

From above, this equals $1$.

$$1 < 1 \quad \text{is false.}$$

---

### Diagnosis

The `kappa` function satisfies $\kappa(\delta\; t) = \kappa(t)$, so $\delta$ is invisible to the measure. The first equation for `recDelta`:

```
| .recDelta b s (.delta n) => Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1
```

peels exactly one `delta` and adds 1. But when $n$ itself is $\delta\;m$, we get:

$$\kappa(\text{recDelta}\; b\; s\; (\delta\;(\delta\;m))) = \max(\max(\kappa b, \kappa s),\; \kappa m) + 1$$

because $\kappa(\delta\; m) = \kappa(m)$. Meanwhile:

$$\kappa(\text{recDelta}\; b\; s\; (\delta\; m)) = \max(\max(\kappa b, \kappa s),\; \kappa m) + 1$$

These are **equal**, not separated by 1. The measure cannot distinguish $\delta(\delta\;m)$ from $\delta\;m$ at the third argument position, so the `+1` increment does not compound. Any termination argument built on these two lemmas will be unsound.
