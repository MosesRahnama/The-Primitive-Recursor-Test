# Assessment of the Helper Strategy

## Overview

The file defines a rewrite calculus with a structural measure `kappa` intended to decrease across rewrite steps. The two helper theorems target the `R_rec_succ` rule, which rewrites `recDelta b s (delta n)` to `app s (recDelta b s n)`. The goal is to show `kappa` strictly decreases across this step.

## Theorem 1: `kappa_rec_delta_step`

**Statement:** `kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1`

**Analysis:** We need to check this by cases on `n`.

- **LHS** (for any `n`): By `kappa_rec_delta`, `kappa (recDelta b s (delta n)) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1`.

- **RHS** depends on the shape of `n`:
  - If `n = delta m`: `kappa (recDelta b s (delta m)) + 1 = (Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1) + 1`. But `kappa (delta m) = kappa m`, so LHS = `Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1`. These are **equal** ✓ since `kappa n = kappa (delta m) = kappa m` and `kappa (recDelta b s n) = kappa (recDelta b s (delta m)) = max(max(kb, ks), kappa m) + 1`, giving RHS = `max(max(kb, ks), kappa m) + 2` ≠ LHS.

**Wait — this is a problem.** When `n = delta m`:
- LHS = `max(max(kb, ks), kappa(delta m)) + 1 = max(max(kb, ks), kappa m) + 1`
- RHS = `kappa(recDelta b s (delta m)) + 1 = (max(max(kb, ks), kappa m) + 1) + 1`

These are **not equal**. The theorem is **false** when `n` is itself a `delta`.

**Concrete counterexample:** Let `b = s = n = void`. Then `kappa(recDelta void void (delta void)) = max(max(0,0), 0) + 1 = 1`. And `kappa(recDelta void void void) = max(max(0,0), 0) = 0`. So `1 = 0 + 1` ✓. But now let `n = delta void`: `kappa(recDelta void void (delta (delta void))) = max(0, kappa(delta void)) + 1 = max(0,0) + 1 = 1`. And `kappa(recDelta void void (delta void)) = max(0,0) + 1 = 1`. So we need `1 = 1 + 1 = 2`. **False.**

## Theorem 2: `kappa_rec_succ_drop`

**Statement:** `kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))`

The LHS is `max(kappa s, kappa(recDelta b s n))` and the RHS is `max(max(kb, ks), kappa n) + 1`.

Using the same counterexample with `n = delta void`, `b = s = void`:
- LHS = `max(0, kappa(recDelta void void (delta void))) = max(0, 1) = 1`
- RHS = `max(0, 0) + 1 = 1`
- Need `1 < 1`. **False.**

## Conclusion

**The helper strategy is unsound.** The first theorem `kappa_rec_delta_step` is false when `n` has the form `delta m`, because `kappa` on `recDelta` with a `delta`-headed third argument adds `+1`, making the recursion nest non-uniformly. The second theorem also fails for the same reason: the `kappa` measure as defined does not actually strictly decrease across the `R_rec_succ` rewrite in all cases.

The root cause is that the `recDelta` clause in `kappa` pattern-matches specifically on `delta n`, adding `+1` only at one level of `delta`, but the "unwrapped" recursive call `recDelta b s n` when `n` is itself a `delta` still triggers the `+1` clause, so the difference between the two sides is not uniformly 1.
