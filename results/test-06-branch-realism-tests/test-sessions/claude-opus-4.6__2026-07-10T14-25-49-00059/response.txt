# Assessment of the Helper Strategy

## Goal

The two helper theorems are intended to show that the `R_rec_succ` rewrite rule — which rewrites `recDelta b s (delta n)` to `app s (recDelta b s n)` — strictly decreases `kappa`, enabling a termination argument.

## Theorem 1: `kappa_rec_delta_step`

**Statement:**
```
kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1
```

**Analysis:**

The LHS is:
```
kappa (recDelta b s (delta n)) = max (max (kappa b) (kappa s)) (kappa n) + 1
```
by the pattern-matching clause for `recDelta b s (.delta n)`.

The RHS is `kappa (recDelta b s n) + 1`. Now, `kappa (recDelta b s n)` depends on whether `n` matches `.delta n'` for some `n'`:

- **If `n` is not a `delta`:** The catch-all clause gives `kappa (recDelta b s n) = max (max (kappa b) (kappa s)) (kappa n)`, so `RHS = max (max (kappa b) (kappa s)) (kappa n) + 1`. This equals the LHS. ✓

- **If `n = delta n'`:** Then `kappa (recDelta b s n) = max (max (kappa b) (kappa s)) (kappa n') + 1`, and `kappa n = kappa (delta n') = kappa n'`. So LHS = `max (max (kappa b) (kappa s)) (kappa n') + 1` and RHS = `max (max (kappa b) (kappa s)) (kappa n') + 1 + 1`. These are **not equal**.

**Verdict: Theorem 1 is FALSE** when `n` is itself a `delta` term. For example, take `b = void, s = void, n = delta void`:
- LHS: `kappa (recDelta void void (delta (delta void))) = max (max 0 0) 0 + 1 = 1`
- RHS: `kappa (recDelta void void (delta void)) + 1 = (max (max 0 0) 0 + 1) + 1 = 2`

## Theorem 2: `kappa_rec_succ_drop`

**Statement:**
```
kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))
```

**Analysis:**

The LHS is:
```
max (kappa s) (kappa (recDelta b s n))
```

The RHS is:
```
max (max (kappa b) (kappa s)) (kappa n) + 1
```

Consider the case where `n` is not a `delta`: `kappa (recDelta b s n) = max (max (kappa b) (kappa s)) (kappa n)`. Then:
- LHS = `max (kappa s) (max (max (kappa b) (kappa s)) (kappa n))` = `max (max (kappa b) (kappa s)) (kappa n)`
- RHS = `max (max (kappa b) (kappa s)) (kappa n) + 1`

So LHS < RHS holds (x < x + 1). ✓ in this sub-case.

But when `n = delta n'`: `kappa (recDelta b s n) = max (max (kappa b) (kappa s)) (kappa n') + 1`, and `kappa n = kappa n'`. So:
- LHS = `max (kappa s) (max (max (kappa b) (kappa s)) (kappa n') + 1)`
- RHS = `max (max (kappa b) (kappa s)) (kappa n') + 1`

Let `M = max (max (kappa b) (kappa s)) (kappa n')`. Since `kappa s ≤ M`, we have `kappa s ≤ M < M + 1`, so LHS = `M + 1 = RHS`. Thus LHS < RHS fails (we get equality).

**Verdict: Theorem 2 is FALSE** when `n` is a `delta` term.

## Conclusion

**The helper strategy is unsound.** Both theorems are false for nested `delta` arguments. The root cause is that `kappa` adds `+1` only for `recDelta b s (.delta n)` while stripping one `delta` via `kappa (delta t) = kappa t`, so the measure doesn't account for multiple `delta` layers correctly. The first theorem's equation breaks down, and the strict inequality in the second theorem becomes a non-strict equality. A corrected approach would need a measure that properly accounts for the recursive structure (e.g., using `sizeOf` or counting `delta` nesting in the third argument).
