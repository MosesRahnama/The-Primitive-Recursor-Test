The helper strategy is **unsound** as written. Both theorems (`kappa_rec_delta_step` and `kappa_rec_succ_drop`) are false, and the `kappa` measure is not a valid termination measure for the recursion step.

Below is the proof of unsoundness supported by concrete calculations.

---

### 1. Counterexample for `kappa_rec_delta_step`

Let us choose the following terms:
* $b = \text{void}$
* $s = \text{void}$
* $n = \text{delta void}$

We will evaluate both sides of the equation:
$$\kappa(\text{recDelta}\ b\ s\ (\text{delta}\ n)) = \kappa(\text{recDelta}\ b\ s\ n) + 1$$

#### Left-Hand Side (LHS) Calculation:
The term is $\text{recDelta void void (delta (delta void))}$.
According to the definition of `kappa`, the pattern for `.recDelta b s (.delta n)` is matched with $n = \text{delta void}$:
$$\kappa(\text{recDelta void void (delta (delta void))}) = \max(\max(\kappa(\text{void}), \kappa(\text{void})), \kappa(\text{delta void})) + 1$$

Using the definition of `kappa` on the subterms:
* $\kappa(\text{void}) = 0$
* $\kappa(\text{delta void}) = \kappa(\text{void}) = 0$

Plugging these in:
$$\text{LHS} = \max(\max(0, 0), 0) + 1 = 0 + 1 = 1$$

#### Right-Hand Side (RHS) Calculation:
The term is $\kappa(\text{recDelta void void (delta void)}) + 1$.
For the inner term, the pattern for `.recDelta b s (.delta n)` is matched with $n = \text{void}$:
$$\kappa(\text{recDelta void void (delta void)}) = \max(\max(\kappa(\text{void}), \kappa(\text{void})), \kappa(\text{void})) + 1$$
$$\kappa(\text{recDelta void void (delta void)}) = \max(\max(0, 0), 0) + 1 = 1$$

Adding the $+1$ from the theorem statement:
$$\text{RHS} = 1 + 1 = 2$$

Since $\text{LHS} = 1 \neq 2 = \text{RHS}$, the theorem `kappa_rec_delta_step` is false.

---

### 2. Counterexample for `kappa_rec_succ_drop`

This theorem aims to show that the measure strictly decreases during a recursion step:
$$\kappa(\text{app}\ s\ (\text{recDelta}\ b\ s\ n)) < \kappa(\text{recDelta}\ b\ s\ (\text{delta}\ n))$$

Using the exact same counterexample ($b = \text{void}$, $s = \text{void}$, $n = \text{delta void}$):

#### Left-Hand Side (LHS) Calculation:
$$\kappa(\text{app void (recDelta void void (delta void))})$$
By definition of `kappa` on `app`:
$$\max(\kappa(\text{void}), \kappa(\text{recDelta void void (delta void)}))$$
$$\max(0, 1) = 1$$

#### Right-Hand Side (RHS) Calculation:
$$\kappa(\text{recDelta void void (delta (delta void))}) = 1 \quad \text{(calculated in Section 1)}$$

The inequality becomes:
$$1 < 1$$
which is false. Thus, `kappa_rec_succ_drop` is also false.

---

### Conclusion

The underlying issue is that `kappa (delta t)` is defined as `kappa t`. This collapses the nested structure of any tower of `delta`s (i.e., $\kappa(\delta^k(\text{void})) = 0$ for all $k$). As a result, the measure `kappa` cannot detect the decrease in recursion depth when the system peels off a `delta` constructor during a step.
