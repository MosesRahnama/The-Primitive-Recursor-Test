The helper strategy is **unsound**. Both theorems are false as stated, and the measure `kappa` does not strictly decrease on the `R_rec_succ` rewrite step when the trace `n` is itself a `delta`.

Here are the specific failures:

### 1. `kappa_rec_delta_step` is false

The theorem claims:
```lean
kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1
```

**Counterexample:** Let `b = void`, `s = void`, and `n = delta void`.

- **Left-hand side:**  
  `kappa (recDelta void void (delta (delta void)))`  
  By the first clause of `kappa` (matching `.recDelta b s (.delta n)`):  
  = `Nat.max (Nat.max (kappa void) (kappa void)) (kappa (delta void)) + 1`  
  = `Nat.max (Nat.max 0 0) 0 + 1` = `1`

- **Right-hand side:**  
  `kappa (recDelta void void (delta void)) + 1`  
  By the first clause of `kappa`:  
  = `(Nat.max (Nat.max 0 0) 0 + 1) + 1` = `2`

Since `1 ≠ 2`, the equality fails. The equation only holds when `n` is **not** of the form `delta t`.

### 2. `kappa_rec_succ_drop` is false

This theorem claims the measure strictly decreases on the `R_rec_succ` step:
```lean
kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))
```

**Counterexample:** Again, let `b = void`, `s = void`, and `n = delta void`.

- **Left-hand side** (the reduct):  
  `kappa (app void (recDelta void void (delta void)))`  
  = `Nat.max (kappa void) (kappa (recDelta void void (delta void)))`  
  = `Nat.max 0 1` = `1`

- **Right-hand side** (the redex):  
  `kappa (recDelta void void (delta (delta void)))`  
  = `Nat.max (Nat.max 0 0) (kappa (delta void)) + 1`  
  = `0 + 1` = `1`

The inequality `1 < 1` is false. The measures are equal in this case, not decreasing.

### Root Cause

The definition of `kappa` assigns a `+1` to `recDelta b s (delta n)` regardless of whether `n` is itself a delta. This means:
- `kappa (recDelta b s (delta (delta m)))` = `X + 1`
- `kappa (recDelta b s (delta m))` = `X + 1` (where `X = Nat.max (Nat.max (kappa b) (kappa s)) (kappa m)`)

Thus nested deltas do not increase the measure, breaking the inductive argument. The helper theorems implicitly assume `n` is not a `delta`, but the `Step` relation allows `n` to be any trace, including `delta m`.
