## Assessment: The Helper Strategy Is **Unsound**

Both helper theorems are **false** as stated, and the proof of the second depends on the first. The root cause is that `kappa` silently collapses nested `delta` constructors, making the "+1" in the `recDelta`/`delta` clause non-compositional.

---

### 1. `kappa_rec_delta_step` is false

The theorem claims:

$$\kappa(\text{recDelta}\; b\; s\; (\delta\; n)) = \kappa(\text{recDelta}\; b\; s\; n) + 1$$

**Counterexample.** Let $b = \text{void},\; s = \text{void},\; n = \delta\;\text{void}$.

**LHS:** $\kappa(\text{recDelta}\;\text{void}\;\text{void}\;(\delta\;(\delta\;\text{void})))$

The third argument $\delta(\delta\;\text{void})$ matches the `.delta n` clause with $n = \delta\;\text{void}$:

$$= \max(\max(0, 0),\; \kappa(\delta\;\text{void})) + 1 = \max(0,\; \kappa(\text{void})) + 1 = 0 + 1 = \mathbf{1}$$

**RHS:** $\kappa(\text{recDelta}\;\text{void}\;\text{void}\;(\delta\;\text{void})) + 1$

The third argument $\delta\;\text{void}$ matches the `.delta n` clause with $n = \text{void}$:

$$= \bigl(\max(\max(0,0),\; \kappa(\text{void})) + 1\bigr) + 1 = (0 + 1) + 1 = \mathbf{2}$$

Since $1 \neq 2$, the theorem is false.

**Why it fails.** The `kappa` definition for the `.delta n` pattern uses `kappa n`, not `kappa (delta n)`. Because `kappa (delta t) = kappa t`, any tower of nested deltas is collapsed to a single depth count of **+1**, regardless of how many `delta` constructors are stacked. The "+1" does not compound.

---

### 2. `kappa_rec_succ_drop` is false

The theorem claims:

$$\kappa(\text{app}\; s\; (\text{recDelta}\; b\; s\; n)) < \kappa(\text{recDelta}\; b\; s\; (\delta\; n))$$

**Counterexample.** Let $b = \text{void},\; s = \text{void},\; n = \delta\;\text{void}$.

**LHS:** $\kappa(\text{app}\;\text{void}\;(\text{recDelta}\;\text{void}\;\text{void}\;(\delta\;\text{void})))$

$$= \max(\kappa(\text{void}),\; \kappa(\text{recDelta}\;\text{void}\;\text{void}\;(\delta\;\text{void})))$$
$$= \max(0,\; 1) = \mathbf{1}$$

(using $\kappa(\text{recDelta}\;\text{void}\;\text{void}\;(\delta\;\text{void})) = 1$ from above)

**RHS:** $\kappa(\text{recDelta}\;\text{void}\;\text{void}\;(\delta\;(\delta\;\text{void}))) = \mathbf{1}$

(from the LHS calculation in the previous section)

Since $1 < 1$ is false, the theorem is false.

---

### 3. The proof script of `kappa_rec_succ_drop` is unsound

The proof begins with `rw [kappa_rec_delta_step]`, which would rewrite the goal to:

$$\kappa(\text{app}\; s\; (\text{recDelta}\; b\; s\; n)) < \kappa(\text{recDelta}\; b\; s\; n) + 1$$

This rewritten form *would* be provable (since $\kappa(\text{app}\; s\; x) = \max(\kappa(s), \kappa(x))$ and $\kappa(\text{recDelta}\; b\; s\; n) \geq \kappa(s)$, giving $\leq$ and hence $< \cdot + 1$). However, the rewrite itself is invalid because `kappa_rec_delta_step` is false. A proof built on a false lemma is unsound.

---

### Summary

| Theorem | Verdict | Root cause |
|---|---|---|
| `kappa_rec_delta_step` | **False** | `kappa` strips all `delta` layers, so the `+1` doesn't accumulate for nested deltas |
| `kappa_rec_succ_drop` | **False** | Equality (not strict decrease) when $n$ is itself a `delta` |
| Proof of `kappa_rec_succ_drop` | **Unsound** | Depends on the false `kappa_rec_delta_step` via `rw` |

To fix this, `kappa` would need to count `delta` depth explicitly (e.g., `kappa (delta t) = kappa t + 1`) so that nested deltas produce strictly increasing measure values, or the `recDelta` clauses would need a structural size measure that is insensitive to the `delta`-stripping behavior.
