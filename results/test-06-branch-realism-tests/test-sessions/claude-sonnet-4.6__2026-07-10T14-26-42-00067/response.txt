## Theorem 1: `kappa_rec_delta_step`

**Claim:** `kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1`

```
kappa (recDelta b s (delta n)) = max (max (kappa b) (kappa s)) (kappa n) + 1
```

**RHS:** `kappa (recDelta b s n) + 1`. Now I need to evaluate `kappa (recDelta b s n)`. The definition has two cases:
- If `n = delta n'` for some `n'`: `kappa (recDelta b s (delta n')) = max (max (kappa b) (kappa s)) (kappa n') + 1`
- Otherwise (including `void`, `merge`, `app`, etc.): `kappa (recDelta b s n) = max (max (kappa b) (kappa s)) (kappa n)`

So for the **general case** where `n` is not necessarily of the form `delta n'`:

- LHS = `max (max (kappa b) (kappa s)) (kappa n) + 1`
- RHS = `kappa (recDelta b s n) + 1`

When `n` is **not** a `delta`, `kappa (recDelta b s n) = max (max (kappa b) (kappa s)) (kappa n)`, so RHS = `max (max (kappa b) (kappa s)) (kappa n) + 1`. ✓

When `n = delta n'`, `kappa (recDelta b s (delta n')) = max (max (kappa b) (kappa s)) (kappa n') + 1`, so RHS = `max (max (kappa b) (kappa s)) (kappa n') + 1 + 1 = max (max (kappa b) (kappa s)) (kappa (delta n')) + 2`. But LHS = `max (max (kappa b) (kappa s)) (kappa (delta n')) + 1`. **These differ by 1 — the theorem is FALSE when `n = delta n'`.**

## Theorem 2: `kappa_rec_succ_drop`
