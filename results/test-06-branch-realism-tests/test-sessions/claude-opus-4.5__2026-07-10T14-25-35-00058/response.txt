# Assessment of the Helper Strategy Soundness

## Overview

The helper strategy aims to prove that `kappa` decreases when applying the `R_rec_succ` rewrite rule:
```
recDelta b s (delta n)  →  app s (recDelta b s n)
```

I will analyze whether the two helper theorems are sound as stated.

## Analysis of `kappa_rec_delta_step`

**Claim:** `kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1`

**LHS calculation:**
By the definition of `kappa` (the `recDelta b s (.delta n)` case):
```
kappa (recDelta b s (delta n)) = max (max (kappa b) (kappa s)) (kappa n) + 1
```

**RHS calculation:**
For `kappa (recDelta b s n)`, we need to consider what `n` is:
- If `n` matches `.delta m` for some `m`, then: `kappa (recDelta b s n) = max (max (kappa b) (kappa s)) (kappa m) + 1`
- Otherwise (if `n` is `void`, `integrate _`, `merge _ _`, `app _ _`, `recDelta _ _ _`, or `eqW _ _`): `kappa (recDelta b s n) = max (max (kappa b) (kappa s)) (kappa n)`

**Problem:** The theorem is only true when `n` does **not** match the `.delta _` pattern.

**Counterexample:** Let `n = delta void`.
- LHS: `kappa (recDelta b s (delta (delta void))) = max (max (kappa b) (kappa s)) (kappa (delta void)) + 1 = max (max (kappa b) (kappa s)) 0 + 1`
- RHS: `kappa (recDelta b s (delta void)) + 1 = (max (max (kappa b) (kappa s)) (kappa void) + 1) + 1 = max (max (kappa b) (kappa s)) 0 + 2`

These are not equal. **The first theorem is false in general.**

## Analysis of `kappa_rec_succ_drop`

**Claim:** `kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))`

**RHS:** `max (max (kappa b) (kappa s)) (kappa n) + 1`

**LHS:** `kappa (app s (recDelta b s n)) = max (kappa s) (kappa (recDelta b s n))`

For the case where `n` is not of the form `delta _`:
```
LHS = max (kappa s) (max (max (kappa b) (kappa s)) (kappa n))
    = max (max (kappa b) (kappa s)) (kappa n)
```

We need: `max (max (kappa b) (kappa s)) (kappa n) < max (max (kappa b) (kappa s)) (kappa n) + 1`

This is true (for natural numbers, `x < x + 1`).

**However**, if `n = delta m` for some `m`:
```
kappa (recDelta b s n) = max (max (kappa b) (kappa s)) (kappa m) + 1
LHS = max (kappa s) (max (max (kappa b) (kappa s)) (kappa m) + 1)
```

**Counterexample:** Let `b = void`, `s = void`, `n = delta void`.
- RHS: `kappa (recDelta void void (delta (delta void))) = max (max 0 0) 0 + 1 = 1`
- LHS: `kappa (app void (recDelta void void (delta void))) = max 0 (max (max 0 0) 0 + 1) = max 0 1 = 1`

We need `1 < 1`, which is false. **The second theorem is also false in general.**

## Conclusion

**The helper strategy is unsound.** Both theorems have counterexamples when `n` is itself of the form `delta m`. The fundamental issue is that the `kappa` measure adds `+1` specifically when the third argument to `recDelta` matches `.delta _`, but this pattern can be nested, causing the measure to behave inconsistently with the claimed equalities and inequalities.
