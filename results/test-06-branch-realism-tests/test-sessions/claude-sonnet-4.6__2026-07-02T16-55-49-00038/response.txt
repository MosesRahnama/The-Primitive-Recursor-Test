I need to assess whether the helper strategy is sound by checking the two theorems mathematically.

## Theorem 1: `kappa_rec_delta_step`

**Claim:** `kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1`

**Left side:** By `kappa_rec_delta`:
```
kappa (recDelta b s (delta n)) = max (max (kappa b) (kappa s)) (kappa n) + 1
```

**Right side:** We need `kappa (recDelta b s n) + 1`. The definition of `kappa (recDelta b s n)` depends on the shape of `n`:

- If `n = delta n'`: `kappa (recDelta b s (delta n')) = max (max (kappa b) (kappa s)) (kappa n') + 1`
- If `n` is **not** of the form `delta _` (e.g., `n = void`, `n = merge ...`, etc.): `kappa (recDelta b s n) = max (max (kappa b) (kappa s)) (kappa n)`

So the right side is:
- When `n` is not `delta _`: `max (max (kappa b) (kappa s)) (kappa n) + 1` ✓ matches left side
- When `n = delta n'`: `max (max (kappa b) (kappa s)) (kappa n') + 1 + 1 = max (max (kappa b) (kappa s)) (kappa n') + 2`

But the left side when `n = delta n'` is:
`kappa (recDelta b s (delta (delta n'))) = max (max (kappa b) (kappa s)) (kappa (delta n')) + 1 = max (max (kappa b) (kappa s)) (kappa n') + 1`

These are **not equal**: left gives `...+ 1`, right gives `...+ 2`.

**Theorem 1 is FALSE** in general (e.g., take `n = delta void`, `b = void`, `s = void`):
- LHS: `kappa (recDelta void void (delta (delta void))) = max(max(0,0), kappa(delta void)) + 1 = max(0,0) + 1 = 1`
- RHS: `kappa (recDelta void void (delta void)) + 1 = (max(max(0,0), kappa(void)) + 1) + 1 = (0+1)+1 = 2`

`1 ≠ 2`. **Theorem 1 is unsound.**

## Theorem 2: `kappa_rec_succ_drop`

**Claim:** `kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))`

The proof strategy rewrites using `kappa_rec_delta_step` (already shown to be false), so the proof is broken at that step. But let's check the underlying mathematical claim directly.

**LHS:** `kappa (app s (recDelta b s n)) = max (kappa s) (kappa (recDelta b s n))`

**RHS:** `kappa (recDelta b s (delta n)) = max (max (kappa b) (kappa s)) (kappa n) + 1`

We need: `max (kappa s) (kappa (recDelta b s n)) < max (max (kappa b) (kappa s)) (kappa n) + 1`

For `n` not of form `delta _`:
- `kappa (recDelta b s n) = max (max (kappa b) (kappa s)) (kappa n)`
- LHS = `max (kappa s) (max (max (kappa b) (kappa s)) (kappa n)) = max (max (kappa b) (kappa s)) (kappa n)`
- Need: `max (max (kappa b) (kappa s)) (kappa n) < max (max (kappa b) (kappa s)) (kappa n) + 1` ✓ (always true)

For `n = delta n'`:
- `kappa (recDelta b s (delta n')) = max (max (kappa b) (kappa s)) (kappa n') + 1`
- LHS = `max (kappa s) (max (max (kappa b) (kappa s)) (kappa n') + 1)`
- RHS = `max (max (kappa b) (kappa s)) (kappa n') + 1`
- Need: `max (kappa s) (M+1) < M+1` where `M = max(max(kappa b)(kappa s))(kappa n')`
- This requires `kappa s ≤ M` AND `M+1 < M+1` — the second condition is **false**.

**Theorem 2 is also false** in general.

## Conclusion

**The helper strategy is unsound.** Both theorems fail for inputs where `n` is itself of the form `delta n'`. The `kappa` measure as defined does not strictly decrease along `R_rec_succ` steps, making the termination argument invalid as written.
