# Assessment of the Helper Strategy Soundness

## Overview

The helper strategy attempts to prove that `kappa` decreases when applying the `R_rec_succ` rewrite rule:
```
recDelta b s (delta n)  →  app s (recDelta b s n)
```

Let me analyze both theorems.

## Analysis of `kappa_rec_delta_step`

This theorem claims:
```
kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1
```

**Left-hand side:**
By definition (the special case for `recDelta b s (.delta n)`):
```
kappa (recDelta b s (delta n)) = max (max (kappa b) (kappa s)) (kappa n) + 1
```

**Right-hand side:**
```
kappa (recDelta b s n) + 1
```

The value of `kappa (recDelta b s n)` depends on whether `n` matches `.delta n'` for some `n'`:
- If `n = delta n'`: `kappa (recDelta b s n) = max (max (kappa b) (kappa s)) (kappa n') + 1`
- Otherwise: `kappa (recDelta b s n) = max (max (kappa b) (kappa s)) (kappa n)`

**For the general case (n is not a delta):**
```
kappa (recDelta b s n) + 1 = max (max (kappa b) (kappa s)) (kappa n) + 1 ✓
```
This matches the LHS.

**For the case n = delta n':**
```
kappa (recDelta b s (delta n')) + 1 = max (max (kappa b) (kappa s)) (kappa n') + 1 + 1
                                    = max (max (kappa b) (kappa s)) (kappa n') + 2
```
But `kappa (delta n') = kappa n'`, so we need:
```
max (max (kappa b) (kappa s)) (kappa n') + 1 = max (max (kappa b) (kappa s)) (kappa n') + 2
```
This is **false**.

**Conclusion: `kappa_rec_delta_step` is NOT generally true.**

## Analysis of `kappa_rec_succ_drop`

This theorem claims:
```
kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))
```

**RHS:** `max (max (kappa b) (kappa s)) (kappa n) + 1`

**LHS:** 
```
kappa (app s (recDelta b s n)) = max (kappa s) (kappa (recDelta b s n))
```

**Counterexample:** Let `b = void`, `s = void`, `n = void`.
- `kappa b = 0`, `kappa s = 0`, `kappa n = 0`
- RHS: `max (max 0 0) 0 + 1 = 1`
- `kappa (recDelta void void void) = max (max 0 0) 0 = 0` (since `void` doesn't match `.delta _`)
- LHS: `max 0 0 = 0`
- Check: `0 < 1` ✓

**Another case:** Let `b = void`, `s = delta (delta void)`, `n = void`.
- `kappa s = kappa (delta (delta void)) = kappa (delta void) = kappa void = 0`
- RHS: `max (max 0 0) 0 + 1 = 1`
- LHS: `max 0 0 = 0 < 1` ✓

Actually, the key issue is whether `kappa (recDelta b s n) ≤ max (max (kappa b) (kappa s)) (kappa n)`. If `n` is not a delta, equality holds. If `n = delta n'`, we get the `+1` case, but `kappa n = kappa n'`, so it could exceed the bound.

**Critical counterexample:** `b = void`, `s = void`, `n = delta void`.
- RHS: `max (max 0 0) (kappa (delta void)) + 1 = max 0 0 + 1 = 1`
- `kappa (recDelta void void (delta void)) = max (max 0 0) 0 + 1 = 1`
- LHS: `max 0 1 = 1`
- Check: `1 < 1` is **false** ✗

## Conclusion

**The helper strategy is UNSOUND.** Both theorems fail:
1. `kappa_rec_delta_step` fails when `n` is itself a `delta`.
2. `kappa_rec_succ_drop` fails for `b = void, s = void, n = delta void`, where both sides equal 1.
