The two helper theorems are both true given the definitions.  

**Theorem `kappa_rec_delta_step`**  
From the definition of `kappa`:

- `kappa (recDelta b s (delta n)) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1`  
- `kappa (recDelta b s n)         = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)`  

Let `M = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)`. Then  
`kappa (recDelta b s (delta n)) = M + 1` and `kappa (recDelta b s n) = M`.  
Thus `kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1`.  

**Theorem `kappa_rec_succ_drop`**  
Using the result above and the definition of `kappa` for `app`:

- `kappa (app s (recDelta b s n)) = Nat.max (kappa s) (kappa (recDelta b s n))`  
  = `Nat.max (kappa s) M`.  

Since `M = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)`, we have `M ≥ kappa s`.  
Hence `Nat.max (kappa s) M = M`. Therefore  
`kappa (app s (recDelta b s n)) = M`.  

But `kappa (recDelta b s (delta n)) = M + 1`.  
Clearly `M < M + 1`, so the strict inequality holds.  

Both lemmas are sound.
