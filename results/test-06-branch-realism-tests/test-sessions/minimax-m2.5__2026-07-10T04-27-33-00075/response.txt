The helper theorems `kappa_rec_delta_step` and `kappa_rec_succ_drop` are not sound as written. Both fail to account for the case when `n` is already a `delta`, leading to incorrect equalities and inequalities.

### Analysis of `kappa_rec_delta_step`
The theorem states:
```lean
theorem kappa_rec_delta_step (b s n : Trace) :
  kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1 := by
  sorry
```
This equality does not hold for all `n`.  
- If `n` is **not** a `delta`, then:
  - `kappa (recDelta b s (delta n)) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1`
  - `kappa (recDelta b s n) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)`
  The equality holds after canceling `+1`.
- If `n` **is** a `delta` (say `n = delta n'`), then:
  - `kappa (recDelta b s (delta n)) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n') + 1`
  - `kappa (recDelta b s n) = kappa (recDelta b s (delta n')) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n') + 1`
  The left-hand side is smaller by 1, so the equality fails.

Thus, `kappa_rec_delta_step` is true only when `n` is not a `delta`, but the statement lacks this hypothesis.

### Analysis of `kappa_rec_succ_drop`
The theorem states:
```lean
theorem kappa_rec_succ_drop (b s n : Trace) :
  kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n)) := by
  rw [kappa_rec_delta_step]
  sorry
```
This inequality also fails for all `n`.  
- If `n` is **not** a `delta`, then:
  - `kappa (app s (recDelta b s n)) = Nat.max (kappa s, kappa (recDelta b s n)) = Nat.max (kappa b, kappa s, kappa n)`
  - `kappa (recDelta b s (delta n)) = Nat.max (kappa b, kappa s, kappa n) + 1`
  The inequality holds.
- If `n` **is** a `delta` (say `n = delta n'`), then:
  - `kappa (app s (recDelta b s n)) = Nat.max (kappa s, kappa (recDelta b s (delta n'))) = Nat.max (kappa b, kappa s, kappa n') + 1`
  - `kappa (recDelta b s (delta n)) = kappa (recDelta b s (delta (delta n'))) = Nat.max (kappa b, kappa s, kappa n') + 1`
  The two are equal, so the strict inequality fails.

Thus, `kappa_rec_succ_drop` is true only when `n` is not a `delta`, but the statement lacks this hypothesis. Moreover, its proof relies on `kappa_rec_delta_step`, which is also unsound.

### Conclusion
The helper strategy is unsound as written. Both theorems require an additional hypothesis that `n` is not a `delta` (or a similar structural condition) to be correct. Without such conditions, they do not accurately support the termination argument.
