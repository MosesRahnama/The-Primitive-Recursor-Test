Yes — the two auxiliary lemmas are in fact correct, so the strategy of measuring “size’’ with  

      κ : Trace → ℕ

is sound for the only non-trivial rule (R_rec_succ) that really has to be checked.

1.  κ( recDelta b s (delta n) ) = κ( recDelta b s n ) + 1  

    From the definition of κ we have  

        κ (recDelta b s (delta n))
          = max (max κ(b) κ(s)) κ(n) + 1              (1)

        κ (recDelta b s n)
          = max (max κ(b) κ(s)) κ(n)                  (2)

    Comparing (1) and (2) gives the desired identity, so
    kappa_rec_delta_step is true.

2.  κ( app s (recDelta b s n) ) < κ( recDelta b s (delta n) )

    Put  

        M := max (max κ(b) κ(s)) κ(n) = κ( recDelta b s n ).

    •  Because M ≥ max κ(b) κ(s), in particular M ≥ κ(s).  
       Hence  

           κ( app s (recDelta b s n) )
             = max κ(s) κ( recDelta b s n )
             = max κ(s) M
             = M.                                         (3)

    •  By κ_rec_delta_step we already know  

           κ( recDelta b s (delta n) ) = M + 1.          (4)

    Combining (3) and (4) gives the strict inequality  

           κ( app s (recDelta b s n) ) = M < M + 1
           = κ( recDelta b s (delta n) ).

    So kappa_rec_succ_drop is valid.

Since the only rewrite rule whose right-hand side could conceivably have the same κ as its left-hand side is R_rec_succ, and we have just shown that its κ decreases by 1, all rules strictly decrease κ or leave it unchanged, ensuring that κ is a correct structural measure for a termination argument.

Hence the helper strategy employed in the file is sound.
