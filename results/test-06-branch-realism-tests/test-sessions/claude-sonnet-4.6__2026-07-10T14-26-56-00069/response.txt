## Theorem 1: `kappa_rec_delta_step`

**Claim:** `kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1`

**Left side:** By `kappa_rec_delta`:
```
kappa (recDelta b s (delta n)) = max (max (kappa b) (kappa s)) (kappa n) + 1
```

**Right side:** `kappa (recDelta b s n) + 1`

For the right side, I need to evaluate `kappa (recDelta b s n)`. The definition has two cases:
- If `n = delta m` for some `m`: `kappa (recDelta b s (delta m)) = max (max (kappa b) (kappa s)) (kappa m) + 1`
- Otherwise (including `n = void`, `n = merge ...`, etc.): `kappa (recDelta b s n) = max (max (kappa b) (kappa s)) (kappa n)`

So the claim requires:
```
max (max (kappa b) (kappa s)) (kappa n) + 1 = kappa (recDelta b s n) + 1
```
which simplifies to:
```
max (max (kappa b) (kappa s)) (kappa n) = kappa (recDelta b s n)
```

This holds **only when `n` is not of the form `delta m`**. When `n = delta m`, `kappa (recDelta b s n) = max (max (kappa b) (kappa s)) (kappa m) + 1`, which is not generally equal to `max (max (kappa b) (kappa s)) (kappa (delta m)) = max (max (kappa b) (kappa s)) (kappa m)`.

**Theorem 1 is FALSE in general.** Counterexample: let `n = delta void`, `b = void`, `s = void`.
- LHS: `kappa (recDelta void void (delta (delta void))) = max (max 0 0) 0 + 1 = 1`
- RHS: `kappa (recDelta void void (delta void)) + 1 = (max (max 0 0) 0 + 1) + 1 = 2`
- `1 ≠ 2`. ✗

## Theorem 2: `kappa_rec_succ_drop`

**Claim:** `kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))`
