# Assessment of the Helper Strategy Soundness

## Overview

The helper strategy aims to prove that `kappa` decreases under the `R_rec_succ` rewrite rule, which transforms `recDelta b s (delta n)` into `app s (recDelta b s n)`. This would support a termination argument for the rewrite system.

## Analysis of `kappa_rec_delta_step`

**Claim:** `kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1`

**Left-hand side:**
```
kappa (recDelta b s (delta n)) = max (max (kappa b) (kappa s)) (kappa n) + 1
```
(by the special case in `kappa` definition)

**Right-hand side:**
```
kappa (recDelta b s n) + 1 = ?
```

The problem is that `kappa (recDelta b s n)` depends on the structure of `n`:
- If `n = delta m` for some `m`, then `kappa (recDelta b s n) = max (max (kappa b) (kappa s)) (kappa m) + 1`
- Otherwise, `kappa (recDelta b s n) = max (max (kappa b) (kappa s)) (kappa n)`

**For the general case (n is not a delta):**
```
RHS = max (max (kappa b) (kappa s)) (kappa n) + 1
```
This matches the LHS. ✓

**For the case where `n = delta m`:**
```
LHS = max (max (kappa b) (kappa s)) (kappa (delta m)) + 1
    = max (max (kappa b) (kappa s)) (kappa m) + 1

RHS = kappa (recDelta b s (delta m)) + 1
    = (max (max (kappa b) (kappa s)) (kappa m) + 1) + 1
    = max (max (kappa b) (kappa s)) (kappa m) + 2
```

**These are not equal!** The theorem `kappa_rec_delta_step` is **false** when `n` is itself a `delta` term.

## Analysis of `kappa_rec_succ_drop`

**Claim:** `kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))`

**RHS:** `max (max (kappa b) (kappa s)) (kappa n) + 1`

**LHS:** 
```
kappa (app s (recDelta b s n)) = max (kappa s) (kappa (recDelta b s n))
```

**Counterexample:** Let `b = void`, `s = void`, `n = void`.
- `kappa s = 0`
- `kappa (recDelta void void void) = max (max 0 0) 0 = 0`
- LHS = `max 0 0 = 0`
- RHS = `max (max 0 0) 0 + 1 = 1`
- `0 < 1` ✓ (works for this case)

**Counterexample:** Let `b = void`, `s = delta (delta void)`, `n = void`.
- `kappa s = kappa (delta (delta void)) = 0`
- `kappa (recDelta void s void) = max (max 0 0) 0 = 0`
- LHS = `max 0 0 = 0`
- RHS = `0 + 1 = 1` ✓

**Potential problem case:** Let `s` be large. Say `kappa s = 5`, `kappa b = 0`, `kappa n = 0`.
- LHS = `max 5 (max (max 0 5) 0) = max 5 5 = 5`
- RHS = `max (max 0 5) 0 + 1 = 5 + 1 = 6`
- `5 < 6` ✓

This inequality appears to hold because the `+1` on the RHS accounts for the `delta` wrapper.

## Conclusion

**The helper strategy is UNSOUND.**

The theorem `kappa_rec_delta_step` is **false** in general. Specifically, when `n = delta m`:
- LHS = `max (max (kappa b) (kappa s)) (kappa m) + 1`
- RHS = `max (max (kappa b) (kappa s)) (kappa m) + 2`

The second theorem `kappa_rec_succ_drop` may actually be true, but its proof strategy (using `rw [kappa_rec_delta_step]`) relies on the false first lemma, so the overall approach is flawed.
