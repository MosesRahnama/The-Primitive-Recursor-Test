# Assessment of the Helper Strategy

## Overview

The file defines a rewrite calculus with a structural measure `kappa` intended to decrease across rewrite steps. The two helper theorems target the `R_rec_succ` rule, which rewrites `recDelta b s (delta n)` to `app s (recDelta b s n)`. The strategy is to show `kappa` strictly decreases across this step.

## Theorem 1: `kappa_rec_delta_step`

**Statement:** `kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1`

**Analysis:** We need to check whether this holds by examining the definition of `kappa`.

- LHS: `kappa (recDelta b s (delta n))` matches the special clause for `.recDelta b s (.delta n)`, giving `Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1`.

- RHS: `kappa (recDelta b s n) + 1`. This depends on the shape of `n`:
  - If `n` is **not** of the form `.delta m`, then `kappa (recDelta b s n) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)`, and the RHS becomes `Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1`. ✓ Matches LHS.
  - If `n = .delta m` for some `m`, then `kappa (recDelta b s n) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1`, and the RHS becomes `Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 2`. But the LHS is `Nat.max (Nat.max (kappa b) (kappa s)) (kappa (delta n)) + 1 = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1 = Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1`.

  So when `n = delta m`: LHS = `max(max(κ(b), κ(s)), κ(m)) + 1`, but RHS = `max(max(κ(b), κ(s)), κ(m)) + 2`.

**Verdict: Theorem 1 is FALSE** when `n` is of the form `delta m`. Counterexample: `b = void, s = void, n = delta void`. Then LHS = `max(max(0,0),0) + 1 = 1`, RHS = `(max(max(0,0),0) + 1) + 1 = 2`.

## Theorem 2: `kappa_rec_succ_drop`

**Statement:** `kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))`

Since it begins by rewriting with the (false) first theorem, the proof strategy is unsound from the start. But let's also check the statement itself.

- LHS: `kappa (app s (recDelta b s n)) = Nat.max (kappa s) (kappa (recDelta b s n))`.
- RHS: `kappa (recDelta b s (delta n)) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1`.

Consider `b = void, s = void, n = void`:
- LHS = `max(0, max(max(0,0),0)) = 0`
- RHS = `max(max(0,0),0) + 1 = 1`. ✓ (0 < 1)

Consider `b = void, s = delta(delta(void)), n = void`:
- `kappa s = 0`, `kappa b = 0`, `kappa n = 0`.
- LHS = `max(0, max(max(0,0),0)) = 0`
- RHS = `0 + 1 = 1`. ✓

Actually, the statement itself appears to be **true** in general (since `max(κ(s), κ(recDelta b s n)) ≤ max(max(κ(b),κ(s)), κ(n)) < max(max(κ(b),κ(s)), κ(n)) + 1`), but the **proof strategy** relying on theorem 1 is broken.

## Conclusion

**The helper strategy is unsound.** Theorem `kappa_rec_delta_step` is false when `n` has the form `delta m`, because `kappa` pattern-matches on the third argument of `recDelta`, causing a double application of the `+1` bonus. The second theorem's statement appears true, but its proof cannot proceed via the false first lemma. A correct approach would require case-splitting on `n` or restructuring `kappa` to avoid the nested pattern-match issue.
