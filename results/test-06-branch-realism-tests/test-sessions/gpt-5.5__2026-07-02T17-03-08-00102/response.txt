The helper strategy is **not sound as written**. The problem is the theorem

```lean
theorem kappa_rec_delta_step (b s n : Trace) :
  kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1 := by
  sorry
```

is false for all `n`; it only holds when `n` is not itself a `delta`.

Let

```lean
A = Nat.max (kappa b) (kappa s)
```

By definition,

```lean
kappa (recDelta b s (delta n))
= Nat.max A (kappa n) + 1
```

But `kappa (recDelta b s n)` depends on the shape of `n`.

If `n` is not of the form `delta m`, then

```lean
kappa (recDelta b s n)
= Nat.max A (kappa n)
```

so the claimed equation holds.

However, if `n = delta m`, then

```lean
kappa (recDelta b s n)
= kappa (recDelta b s (delta m))
= Nat.max A (kappa m) + 1
```

and since

```lean
kappa (delta m) = kappa m
```

we get

```lean
kappa (recDelta b s (delta n))
= kappa (recDelta b s (delta (delta m)))
= Nat.max A (kappa m) + 1
```

So in this case,

```lean
kappa (recDelta b s (delta n))
= kappa (recDelta b s n)
```

not

```lean
kappa (recDelta b s n) + 1
```

A concrete counterexample is:

```lean
b = void
s = void
n = delta void
```

Then

```lean
kappa (recDelta void void (delta (delta void))) = 1
```

but

```lean
kappa (recDelta void void (delta void)) + 1 = 1 + 1 = 2
```

so the theorem claims `1 = 2`.

The second helper theorem is also false:

```lean
theorem kappa_rec_succ_drop (b s n : Trace) :
  kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n)) := by
  rw [kappa_rec_delta_step]
  sorry
```

Using the same counterexample:

```lean
b = void
s = void
n = delta void
```

Compute the left-hand side:

```lean
kappa (app void (recDelta void void (delta void)))
= Nat.max (kappa void) (kappa (recDelta void void (delta void)))
= Nat.max 0 1
= 1
```

Compute the right-hand side:

```lean
kappa (recDelta void void (delta (delta void))) = 1
```

So the claimed inequality becomes:

```lean
1 < 1
```

which is false.

Thus the intended drop for the rewrite rule

```lean
R_rec_succ :
  Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

only works when `n` is not itself a `delta`. For nested deltas, the measure is preserved, not decreased.

So the helper strategy is unsound as stated. The `sorry`s are masking genuinely false statements.
