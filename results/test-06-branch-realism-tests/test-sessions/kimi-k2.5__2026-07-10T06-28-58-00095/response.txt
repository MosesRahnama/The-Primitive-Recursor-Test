The helper strategy is **unsound**. Both theorems are false as stated.

## Analysis

The measure `kappa` is defined with special handling for `recDelta` when the third argument is a `delta`:

```lean
| .recDelta b s (.delta n) => Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1
| .recDelta b s n => Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)
```

### Counterexample to `kappa_rec_delta_step`

The theorem claims: `kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1`

**When `n` is itself a `delta` term**, say `n = delta m`:
- Left side: `kappa (recDelta b s (delta (delta m)))` = `Nat.max (Nat.max (kappa b) (kappa s)) (kappa (delta m)) + 1` = `Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1`
- Right side: `kappa (recDelta b s (delta m)) + 1` = `(Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1) + 1` = `Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 2`

Let `X = Nat.max (Nat.max (kappa b) (kappa s)) (kappa m)`. The theorem claims `X + 1 = X + 2`, which is false.

**Concrete example**: Take `b = s = m = void` (all with `kappa = 0`):
- `kappa (recDelta void void (delta (delta void)))` = `max(max(0,0), 0) + 1 = 1`
- `kappa (recDelta void void (delta void)) + 1` = `(max(max(0,0), 0) + 1) + 1 = 2`
- `1 ≠ 2`

### Counterexample to `kappa_rec_succ_drop`

The theorem claims: `kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))`

Using the rewrite rule `R_rec_succ`, we step from `recDelta b s (delta n)` to `app s (recDelta b s n)`.

**When `n = delta m`**:
- `kappa (recDelta b s (delta n))` = `kappa (recDelta b s (delta (delta m)))` = `Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1`
- `kappa (app s (recDelta b s n))` = `kappa (app s (recDelta b s (delta m)))` = `Nat.max (kappa s) (kappa (recDelta b s (delta m)))` = `Nat.max (kappa s) (Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1)`

Since `Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) ≥ kappa s`, we have:
`Nat.max (kappa s) (Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1`

Thus both sides equal `Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1`, giving **equality**, not strict inequality.

**Concrete example**: `b = s = void`, `n = delta void`:
- `kappa (recDelta void void (delta (delta void)))` = 1
- `kappa (app void (recDelta void void (delta void)))` = `max(0, 1) = 1`
- `1 < 1` is false.

## Conclusion

The measure `kappa` fails to distinguish between `recDelta b s (delta n)` and `recDelta b s (delta (delta n))`—they receive the same value. Consequently, the rewrite step `R_rec_succ` (which moves from `delta n` to `n`) does not strictly decrease the measure when `n` contains a `delta` constructor. The termination argument is therefore invalid.
