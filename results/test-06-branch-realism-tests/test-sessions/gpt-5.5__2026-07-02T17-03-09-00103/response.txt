The helper strategy is **not sound as written**. Both helper theorems are false for the given definition of `kappa`.

The problem is the special equation:

```lean
| .recDelta b s (.delta n) =>
    Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1
| .recDelta b s n =>
    Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)
```

Because the first clause matches whenever the third argument is syntactically a `delta`, the value of

```lean
kappa (recDelta b s n)
```

depends not only on `kappa n`, but also on whether `n` itself is a `delta`.

Let

```lean
A = Nat.max (kappa b) (kappa s)
```

Then:

```lean
kappa (recDelta b s (delta n)) = Nat.max A (kappa n) + 1
```

But `kappa (recDelta b s n)` is not always `Nat.max A (kappa n)`. If `n = delta m`, then:

```lean
kappa (recDelta b s n)
= kappa (recDelta b s (delta m))
= Nat.max A (kappa m) + 1
```

and since `kappa (delta m) = kappa m`, this is

```lean
Nat.max A (kappa n) + 1
```

So in that case:

```lean
kappa (recDelta b s n) + 1
= Nat.max A (kappa n) + 2
```

while

```lean
kappa (recDelta b s (delta n))
= Nat.max A (kappa n) + 1
```

Therefore the theorem

```lean
theorem kappa_rec_delta_step (b s n : Trace) :
  kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1
```

is false.

A concrete counterexample is:

```lean
b = void
s = void
n = delta void
```

Then:

```lean
kappa (recDelta void void (delta (delta void)))
= Nat.max (Nat.max 0 0) 0 + 1
= 1
```

but

```lean
kappa (recDelta void void (delta void)) + 1
= (Nat.max (Nat.max 0 0) 0 + 1) + 1
= 2
```

So the theorem would assert:

```lean
1 = 2
```

which is impossible.

The second helper theorem is also false:

```lean
theorem kappa_rec_succ_drop (b s n : Trace) :
  kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))
```

Using the same counterexample:

```lean
b = void
s = void
n = delta void
```

Compute the right-hand side:

```lean
kappa (recDelta void void (delta (delta void))) = 1
```

Compute the left-hand side:

```lean
kappa (app void (recDelta void void (delta void)))
= Nat.max (kappa void) (kappa (recDelta void void (delta void)))
= Nat.max 0 1
= 1
```

So the theorem claims:

```lean
1 < 1
```

which is false.

Hence the proposed termination-measure helper strategy is unsound. The measure decreases for `R_rec_succ` only when the recursive argument `n` is not itself a `delta`. For nested deltas, the measure can stay the same rather than strictly decrease.
