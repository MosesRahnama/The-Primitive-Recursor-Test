# Assessment of the Helper Strategy Soundness

## Summary
The helper strategy is **unsound as written**. The first theorem (`kappa_rec_delta_step`) is false, which undermines the entire termination argument.

## Detailed Analysis

### Theorem 1: `kappa_rec_delta_step`
**Claim:** `kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1`

**Verification:**

From the `kappa` definition:
- `kappa (recDelta b s (delta n)) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1` (by the special case for `delta`)
- `kappa (recDelta b s n) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)` (by the general case)

Therefore:
```
kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1 ✓
```

**Verdict:** This theorem is **correct** (though marked `sorry`).

---

### Theorem 2: `kappa_rec_succ_drop`
**Claim:** `kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))`

**Verification:**

After rewriting with `kappa_rec_delta_step`:
```
Goal: kappa (app s (recDelta b s n)) < kappa (recDelta b s n) + 1
```

Expanding `kappa (app s (recDelta b s n))`:
```
kappa (app s (recDelta b s n))
= Nat.max (kappa s) (kappa (recDelta b s n))
```

For the inequality to hold:
```
Nat.max (kappa s) (kappa (recDelta b s n)) < kappa (recDelta b s n) + 1
```

**Counterexample:** Let `kappa s = 100` and `kappa (recDelta b s n) = 5`.

Then:
- LHS: `Nat.max 100 5 = 100`
- RHS: `5 + 1 = 6`
- Inequality: `100 < 6` ✗ **FALSE**

**Verdict:** This theorem is **false** and cannot be proven.

---

## Root Cause

The `kappa` measure for `app` uses `Nat.max`, which does not guarantee a decrease when one argument is strictly larger than the other operand being measured. The rewrite rule:

```
R_rec_succ : Step (recDelta b s (delta n)) (app s (recDelta b s n))
```

produces a term where `kappa s` may be arbitrarily large (even larger than the entire left-hand side), violating the termination property.

## Conclusion

**The helper strategy is unsound.** A corrected termination argument would need either:
1. A different structural measure that accounts for the strict positivity of arguments in `app`, or
2. A proof that `kappa s < kappa (recDelta b s (delta n))` holds under additional constraints
