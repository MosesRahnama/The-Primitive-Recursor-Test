### 1.  `kappa_rec_delta_step`

\[
\text{Statement: }\;\kappa(\operatorname{recDelta}\;b\;s\;(\delta n))

### 2.  `kappa_rec_succ_drop`

\[
\text{Statement: }\;\kappa(\operatorname{app}\;s\;(\operatorname{recDelta}\;b\;s\;n))
   < \kappa(\operatorname{recDelta}\;b\;s\;(\delta n)).
\]

**Rewrite using the first lemma.**  
After `rw [kappa_rec_delta_step]` the right‑hand side becomes

\[
\kappa(\operatorname{recDelta}\;b\;s\;n)+1 .
\]

Now we evaluate the left‑hand side.

* By definition of `kappa` for `app`:

\[
\kappa(\operatorname{app}\;s\;(\operatorname{recDelta}\;b\;s\;n))
   = \operatorname{Nat.max}(\kappa s)\bigl(\kappa(\operatorname{recDelta}\;b\;s\;n)\bigr).
\]

* Using the definition of `kappa` for `recDelta` (the general case):

\[
\kappa(\operatorname{recDelta}\;b\;s\;n)
   = \operatorname{Nat.max}
        (\operatorname{Nat.max}(\kappa b)(\kappa s))
        (\kappa n)
   = \operatorname{max}(\kappa b,\kappa s,\kappa n).
\]

Because the maximum of a set of numbers is always **at least** each element, we have

\[
\kappa s \le \operatorname{max}(\kappa b,\kappa s,\kappa n)
   = \kappa(\operatorname{recDelta}\;b\;s\;n).
\]

Therefore

\[
\kappa(\operatorname{app}\;s\;(\operatorname{recDelta}\;b\;s\;n))
   = \operatorname{max}\bigl(\kappa s,\kappa(\operatorname{recDelta}\;b\;s\;n)\bigr)
   = \kappa(\operatorname{recDelta}\;b\;s\;n).
\]

Putting everything together:

\[
\kappa(\operatorname{app}\;s\;(\operatorname{recDelta}\;b\;s\;n))
   = \kappa(\operatorname{recDelta}\;b\;s\;n)
   < \kappa(\operatorname{recDelta}\;b\;s\;n)+1
   = \kappa(\operatorname{recDelta}\;b\;s\;(\delta n)).
\]

The strict inequality holds because for any natural number `x` we have `x < x+1`.  Hence the lemma is true.
