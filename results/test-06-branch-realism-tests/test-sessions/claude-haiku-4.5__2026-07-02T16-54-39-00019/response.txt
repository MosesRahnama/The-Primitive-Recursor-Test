# Assessment of Helper Strategy Soundness

## Summary
The helper strategy is **unsound as written**. The first theorem (`kappa_rec_delta_step`) makes a claim that is **false**, which cascades into making the second theorem unprovable.

## Detailed Analysis

### Theorem 1: `kappa_rec_delta_step`

**Claim:** `kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1`

**Verification by calculation:**

For `recDelta b s (delta n)`:
```
kappa (recDelta b s (delta n)) 
  = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1    [by definition]
```

For `recDelta b s n`:
```
kappa (recDelta b s n) 
  = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)    [by second clause, since n ≠ delta m in general]
```

Therefore:
```
kappa (recDelta b s n) + 1 
  = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1
```

**This matches!** So `kappa_rec_delta_step` is **correct in principle**.

---

### Theorem 2: `kappa_rec_succ_drop`

**Claim:** `kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))`

**Verification by calculation:**

After rewriting with `kappa_rec_delta_step`:
```
kappa (app s (recDelta b s n)) < kappa (recDelta b s n) + 1
```

Expanding both sides:
```
kappa (app s (recDelta b s n)) 
  = Nat.max (kappa s) (kappa (recDelta b s n))    [by definition of app]
  = Nat.max (kappa s) (Nat.max (Nat.max (kappa b) (kappa s)) (kappa n))
```

For the claim to hold, we need:
```
Nat.max (kappa s) (Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)) < Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1
```

**This is false in general.** Note that:
```
Nat.max (kappa s) (Nat.max (Nat.max (kappa b) (kappa s)) (kappa n))
  = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)    [by associativity/idempotence of max]
```

So we're claiming:
```
Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) < Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1
```

This is **always true** (any natural number is strictly less than itself plus 1).

**Correction:** The second theorem is actually **sound**, but the proof is trivial: the inequality holds because `kappa (app s (recDelta b s n))` equals `kappa (recDelta b s n)`, and anything is strictly less than itself plus 1.

---

## Conclusion

- **`kappa_rec_delta_step`**: Sound ✓
- **`kappa_rec_succ_drop`**: Sound ✓ (though the proof is simpler than might appear)

The helper strategy **is sound**, but the second theorem's conclusion is somewhat weaker than one might initially expect—it relies entirely on the `+1` in the rewrite, with the `app` constructor not actually reducing the measure meaningfully beyond what unwrapping the `delta` provides.
