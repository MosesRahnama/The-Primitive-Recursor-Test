The helper strategy is not sound as written. The first helper theorem is false for arbitrary `n`, and consequently the strict-drop theorem is also false.

The issue is that `kappa` adds `1` whenever the third argument of `recDelta` is *immediately* of the form `delta _`. Thus, if `n` is itself a `delta`, then both sides contain such a `+ 1`.

Take

```lean
b = void
s = void
n = delta void
```

Then:

```lean
kappa (recDelta void void (delta (delta void)))
= Nat.max (Nat.max 0 0) (kappa (delta void)) + 1
= 1
```

whereas

```lean
kappa (recDelta void void (delta void)) + 1
= 1 + 1
= 2.
```

So the asserted equality

```lean
kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1
```

specializes to `1 = 2`, which is false.

More generally, if `n = delta m`, write

```lean
M = Nat.max (Nat.max (kappa b) (kappa s)) (kappa m).
```

Then:

```lean
kappa (recDelta b s (delta (delta m))) = M + 1
```

but

```lean
kappa (recDelta b s (delta m)) + 1 = (M + 1) + 1.
```

The first helper would be valid only in the branch where `n` is not itself syntactically `delta _`; in that case the ordinary `recDelta` clause gives the unincremented value.

The second helper fails on the same example. For `b = s = void` and `n = delta void`:

```lean
kappa (recDelta void void (delta (delta void))) = 1
```

while its rewrite target has:

```lean
kappa (app void (recDelta void void (delta void)))
= Nat.max 0 1
= 1.
```

Hence the proposed strict inequality becomes

```lean
1 < 1,
```

which is false.

This corresponds directly to the `R_rec_succ` instance

```lean
Step
  (recDelta void void (delta (delta void)))
  (app void (recDelta void void (delta void))).
```

The source and target have equal `kappa`, not a strict decrease.

Moreover, independently of the recursive-success issue, `kappa` is not a globally strictly decreasing measure for all the displayed rules. For example:

```lean
kappa (merge void t) = kappa t
```

so `R_merge_void_left` preserves the measure, and similarly `R_eq_diff` preserves the maximum measure:

```lean
kappa (eqW a b)
= Nat.max (kappa a) (kappa b)
= kappa (integrate (merge a b)).
```

Thus `kappa` cannot by itself support a proof that every `Step` strictly decreases it.
