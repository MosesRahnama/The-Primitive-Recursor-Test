# Assessment of the Helper Strategy

## Goal of the Strategy

The two helper theorems aim to show that the `R_rec_succ` rewrite rule — which rewrites `recDelta b s (delta n)` to `app s (recDelta b s n)` — strictly decreases `kappa`, enabling a termination argument.

## Theorem 1: `kappa_rec_delta_step`

**Statement:** `kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1`

**Analysis:** We need to check this by cases on `n`.

- **Case `n = delta m`:**
  - LHS: `kappa (recDelta b s (delta (delta m)))` = `max (max (kappa b) (kappa s)) (kappa (delta m)) + 1` = `max (max (kappa b) (kappa s)) (kappa m) + 1`
  - RHS: `kappa (recDelta b s (delta m)) + 1` = `max (max (kappa b) (kappa s)) (kappa m) + 1`
  - ✅ Equal.

- **Case `n = void`:**
  - LHS: `kappa (recDelta b s (delta void))` = `max (max (kappa b) (kappa s)) (kappa void) + 1` = `max (max (kappa b) (kappa s)) 0 + 1`
  - RHS: `kappa (recDelta b s void) + 1`. Since `void` doesn't match `.delta n`, this falls to the catch-all: `max (max (kappa b) (kappa s)) (kappa void) + 1` = `max (max (kappa b) (kappa s)) 0 + 1`
  - ✅ Equal.

- **Case `n = merge a' b'` (or any non-`delta` constructor):**
  - LHS: `max (max (kappa b) (kappa s)) (kappa n) + 1` (matches the `delta` pattern on the outer call)
  - RHS: `max (max (kappa b) (kappa s)) (kappa n) + 1` (falls to catch-all since `n` is not `delta _`)
  - ✅ Equal.

**Verdict:** This theorem is **sound**. In all cases, wrapping `n` in `delta` adds exactly 1 to the catch-all clause, while the catch-all for `recDelta b s n` (when `n` is not a `delta`) gives the same base value. And when `n` *is* a `delta m`, both sides reduce identically because `kappa (delta m) = kappa m`.

## Theorem 2: `kappa_rec_succ_drop`

**Statement:** `kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))`

After rewriting with theorem 1, the goal becomes:

`kappa (app s (recDelta b s n)) < kappa (recDelta b s n) + 1`

Expanding the LHS:

`max (kappa s) (kappa (recDelta b s n)) < kappa (recDelta b s n) + 1`

Let `K = kappa (recDelta b s n)`. By the definition of `kappa` for `recDelta`, `K ≥ max (kappa b) (kappa s)`, so in particular `K ≥ kappa s`.

Therefore `max (kappa s) K = K`, and the goal becomes:

`K < K + 1`

which is trivially true. ✅

**Verdict:** This theorem is **sound**.

## Overall Conclusion

**The helper strategy is sound.** Both theorems are true:

1. `kappa_rec_delta_step` holds because wrapping the third argument in `delta` adds exactly 1 regardless of `n`'s form, since `kappa (delta n) = kappa n` causes the inner value to be identical in both cases.

2. `kappa_rec_succ_drop` holds because `kappa s ≤ kappa (recDelta b s n)` (by the `max` in `kappa`'s definition), so the `app` node's measure equals `kappa (recDelta b s n)`, which is strictly less than `kappa (recDelta b s n) + 1`.

Together they establish that the `R_rec_succ` rule strictly decreases `kappa`, which is the critical step for any termination proof over this rewrite system.
