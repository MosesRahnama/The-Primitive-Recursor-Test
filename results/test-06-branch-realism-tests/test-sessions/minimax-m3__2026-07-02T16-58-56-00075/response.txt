## Assessment: The helper strategy is **sound**.

### Step 1: Verify `kappa_rec_delta_step`

The claim is `kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1`.

Computing both sides using the definition of `kappa`:

- **LHS**: Since the outer term is `recDelta b s (delta n)`, the `delta` branch fires:
  $$\kappa(\text{recDelta } b\, s\, (\delta n)) = \max\bigl(\max(\kappa b, \kappa s), \kappa(\delta n)\bigr) + 1 = \max\bigl(\max(\kappa b, \kappa s), \kappa n\bigr) + 1$$

- **RHS**: Since `n` is a *bare* `Trace` (not visibly `delta _`), the non-`delta` branch fires:
  $$\kappa(\text{recDelta } b\, s\, n) = \max\bigl(\max(\kappa b, \kappa s), \kappa n\bigr)$$
  So $\kappa(\text{recDelta } b\, s\, n) + 1 = \max\bigl(\max(\kappa b, \kappa s), \kappa n\bigr) + 1$.

Both sides are equal. The lemma is **true**, and `rw [kappa_rec_delta_step]` is a valid rewrite.

### Step 2: Verify `kappa_rec_succ_drop` after rewriting

After `rw [kappa_rec_delta_step]`, the goal becomes:
$$\kappa(\text{app } s\, (\text{recDelta } b\, s\, n)) \;<\; \kappa(\text{recDelta } b\, s\, n) + 1$$

Now compute the LHS. By the `app` clause:
$$\kappa(\text{app } s\, (\text{recDelta } b\, s\, n)) = \max\bigl(\kappa s,\; \kappa(\text{recDelta } b\, s\, n)\bigr)$$

But $\kappa(\text{recDelta } b\, s\, n) = \max(\max(\kappa b, \kappa s), \kappa n) \;\geq\; \max(\kappa b, \kappa s) \;\geq\; \kappa s$.

Therefore:
$$\max\bigl(\kappa s,\; \kappa(\text{recDelta } b\, s\, n)\bigr) = \kappa(\text{recDelta } b\, s\, n)$$

The goal reduces to:
$$\kappa(\text{recDelta } b\, s\, n) \;<\; \kappa(\text{recDelta } b\, s\, n) + 1$$

This holds for every natural number. The `sorry` in `kappa_rec_succ_drop` is in a **provable** context — it can be closed with `Nat.lt_succ_self` after a `simp [kappa_app, kappa_rec_delta]` (or equivalent).

### Conclusion

Both pieces check out:
1. `kappa_rec_delta_step` is a true identity (an equality of `Nat`s, not just an inequality), so using it as a rewrite lemma is legitimate — it cannot loop or rewrite in the wrong direction.
2. The post-rewrite goal is provable by elementary `Nat` arithmetic after simplifying with the `kappa` clauses.

The strategy as written is sound, and the `sorry`s in this file could be discharged mechanically.
