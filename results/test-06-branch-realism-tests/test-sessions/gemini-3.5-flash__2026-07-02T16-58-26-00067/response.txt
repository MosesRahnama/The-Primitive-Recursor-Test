The helper strategy is **unsound** as written. Both theorems, `kappa_rec_delta_step` and `kappa_rec_succ_drop`, are false under the current definition of `kappa`.

Below is the step-by-step evaluation and counterexample calculations supporting this conclusion.

---

### Root Cause of the Unsoundness
In the definition of `kappa`, the constructor `delta` does not contribute to the measure:
$$\kappa(\text{delta}\ t) = \kappa(t)$$
Because nesting the `delta` constructor does not increase the weight of a `Trace`, the recursive step for `recDelta` (which unpacks a `delta` constructor) cannot be shown to decrease the overall measure.

---

### Counterexample for `kappa_rec_delta_step`
We want to check if the following holds for all $b, s, n$:
$$\kappa(\text{recDelta}\ b\ s\ (\text{delta}\ n)) \stackrel{?}{=} \kappa(\text{recDelta}\ b\ s\ n) + 1$$

Let:
* $b = \text{void}$ (so $\kappa(b) = 0$)
* $s = \text{void}$ (so $\kappa(s) = 0$)
* $n = \text{delta void}$ (so $\kappa(n) = \kappa(\text{void}) = 0$)

#### 1. Evaluate the LHS:
$$\kappa(\text{recDelta}\ \text{void}\ \text{void}\ (\text{delta}\ (\text{delta void})))$$
The third argument is of the form `.delta n'` where $n' = \text{delta void}$. This matches the first pattern for `recDelta` in the definition of `kappa`:
$$\kappa(\text{recDelta}\ b\ s\ (\text{delta}\ n')) = \max(\max(\kappa(b), \kappa(s)), \kappa(n')) + 1$$
Substituting our values:
$$\text{LHS} = \max(\max(0, 0), \kappa(\text{delta void})) + 1 = \max(0, 0) + 1 = 1$$

#### 2. Evaluate the RHS:
$$\kappa(\text{recDelta}\ \text{void}\ \text{void}\ (\text{delta void})) + 1$$
The third argument is of the form `.delta n''` where $n'' = \text{void}$. This also matches the first pattern of `recDelta`:
$$\kappa(\text{recDelta}\ \text{void}\ \text{void}\ (\text{delta void})) = \max(\max(0, 0), \kappa(\text{void})) + 1 = \max(0, 0) + 1 = 1$$
Adding the $+1$ from the RHS of the theorem:
$$\text{RHS} = 1 + 1 = 2$$

Since $1 \neq 2$, **`kappa_rec_delta_step` is false.**

### Counterexample for `kappa_rec_succ_drop`
We want to check if the following strict inequality holds:
$$\kappa(\text{app}\ s\ (\text{recDelta}\ b\ s\ n)) \stackrel{?}{<} \kappa(\text{recDelta}\ b\ s\ (\text{delta}\ n))$$

Using the same assignment ($b = \text{void}$, $s = \text{void}$, $n = \text{delta void}$):

#### 1. Evaluate the LHS:
$$\kappa(\text{app}\ \text{void}\ (\text{recDelta}\ \text{void}\ \text{void}\ (\text{delta void})))$$
Using the definition of `kappa` for `app`:
$$\text{LHS} = \max(\kappa(\text{void}), \kappa(\text{recDelta}\ \text{void}\ \text{void}\ (\text{delta void})))$$
$$\text{LHS} = \max(0, 1) = 1$$

#### 2. Evaluate the RHS:
$$\kappa(\text{recDelta}\ \text{void}\ \text{void}\ (\text{delta}\ (\text{delta void})))$$
From our previous calculation, this evaluates to:
$$\text{RHS} = 1$$

Since the inequality simplifies to $1 < 1$ (which is false), **`kappa_rec_succ_drop` is false.**
