The helper theorems are not sound (i.e., they do not hold in general, and thus cannot be used as written for a termination argument).

To see this, instantiate `b = void`, `s = void`, and `n = delta void` (any `void` could be replaced by an arbitrary `Trace` with `kappa = 0` without changing the result).

By definition of `kappa`:
- `kappa(void) = 0`.
- `kappa(delta void) = 0`.
- `kappa(recDelta void void (delta void))` matches the `(.delta _)` case, so equals `Nat.max (Nat.max 0 0) 0 + 1 = 1`.
- `kappa(recDelta void void (delta (delta void)))` matches the `(.delta _)` case, so equals `Nat.max (Nat.max 0 0) 0 + 1 = 1`.
- `kappa(app void (recDelta void void (delta void)))` equals `Nat.max 0 1 = 1`.

Thus:
- `kappa(recDelta void void (delta (delta void))) = 1` but `kappa(recDelta void void (delta void)) + 1 = 2`, so the first theorem fails (`1 ≠ 2`).
- `kappa(app void (recDelta void void (delta void))) = 1` but `kappa(recDelta void void (delta (delta void))) = 1`, so the second theorem fails (`1 ≮ 1`).

(The `rw` in the second theorem cannot salvage it, as it relies on the first.) These are exactly the `LHS` and `RHS` of `R_rec_succ` (with the chosen parameters), so the claimed strict decrease of `kappa` does not hold in general.
