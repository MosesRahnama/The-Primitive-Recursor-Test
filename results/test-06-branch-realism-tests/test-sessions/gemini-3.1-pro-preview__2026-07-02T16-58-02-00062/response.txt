The helper strategy is **unsound** as written. Both of the provided helper theorems are false and can be broken with a simple counterexample. 

The root cause of the problem is the definition of `kappa` for the `.delta` constructor:
```lean
| .delta t => kappa t
```
Because `kappa (delta t) = kappa t`, the measure ignores nested `delta`s. The pattern match for `recDelta` only checks the outermost constructor of its third argument, meaning it will add `1` if the argument is a `delta`, but it will *not* continue to add `1` for any inner `delta`s.

We can prove that the helper theorems are unsound by evaluating them with the counterexample **`b = void`**, **`s = void`**, and **`n = delta void`**. 

### 1. Assessing `kappa_rec_delta_step`
The theorem claims:
```lean
kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1
```

**Left-Hand Side:**
For `n = delta void`, the term is `recDelta void void (delta (delta void))`.
In `kappa`, this matches the first `recDelta` branch: `| .recDelta b s (.delta x)` where `x = delta void`.
```lean
  kappa (recDelta void void (delta (delta void)))
= Nat.max (Nat.max (kappa void) (kappa void)) (kappa (delta void)) + 1
= Nat.max (Nat.max 0 0) 0 + 1
= 1
```
*(Note that `kappa (delta void)` simplifies to `kappa void`, which is `0`)*

**Right-Hand Side:**
The sub-term `kappa (recDelta b s n)` for `n = delta void` is `kappa (recDelta void void (delta void))`.
This *also* matches the first `recDelta` branch where `x = void`.
```lean
  kappa (recDelta void void (delta void)) + 1
= (Nat.max (Nat.max (kappa void) (kappa void)) (kappa void) + 1) + 1
= (Nat.max (Nat.max 0 0) 0 + 1) + 1
= 1 + 1
= 2
```
The theorem ultimately claims that `1 = 2`, which is false. 

### 2. Assessing `kappa_rec_succ_drop`
The theorem claims:
```lean
kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))
```

**Left-Hand Side:**
Using the same variables, we compute `kappa` of the `app` term:
```lean
  kappa (app void (recDelta void void (delta void)))
= Nat.max (kappa void) (kappa (recDelta void void (delta void)))
= Nat.max 0 1
= 1
```

**Right-Hand Side:**
We already calculated this exact term above for the Left-Hand Side of the previous theorem.
```lean
  kappa (recDelta void void (delta (delta void)))
= 1
```
The theorem ultimately claims that `1 < 1`, which is false.
