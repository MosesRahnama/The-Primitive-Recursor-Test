The helper strategy is **sound**. Both `kappa_rec_delta_step` and `kappa_rec_succ_drop` are true statements given the definition of `kappa`, and they correctly establish that the rewrite `R_rec_succ` strictly decreases the measure `kappa`.

### Calculations

**1. Verify `kappa_rec_delta_step (b s n) : kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1`**

By the definition of `kappa`:
- `kappa (recDelta b s (delta n))` matches the `.recDelta b s (.delta n)` clause:
  ```
  kappa (recDelta b s (delta n)) = max(max(kappa b, kappa s), kappa (delta n)) + 1
                                 = max(max(kappa b, kappa s), kappa n) + 1      (since kappa (delta n) = kappa n)
  ```
- `kappa (recDelta b s n)` matches the catch‑all `.recDelta b s n` clause (because `n` is a variable, not a `.delta` constructor):
  ```
  kappa (recDelta b s n) = max(max(kappa b, kappa s), kappa n)
  ```
Therefore
```
kappa (recDelta b s (delta n)) = max(max(kappa b, kappa s), kappa n) + 1
                               = kappa (recDelta b s n) + 1
```
The equality holds for all `b, s, n : Trace`.

---

**2. Verify `kappa_rec_succ_drop (b s n) : kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))`**

Using `kappa_rec_delta_step`, the goal reduces to showing
```
kappa (app s (recDelta b s n)) < kappa (recDelta b s n) + 1
```
For natural numbers this is equivalent to
```
kappa (app s (recDelta b s n)) ≤ kappa (recDelta b s n)
```
Now compute both sides.
```
kappa (app s (recDelta b s n)) = max(kappa s, kappa (recDelta b s n))
kappa (recDelta b s n)        = max(max(kappa b, kappa s), kappa n)
```
Let `M = max(max(kappa b, kappa s), kappa n)`. Then `kappa s ≤ max(kappa b, kappa s) ≤ M`, so
```
max(kappa s, M) = M
```
Hence
```
kappa (app s (recDelta b s n)) = M = kappa (recDelta b s n)
```
Thus equality holds, giving
```
kappa (app s (recDelta b s n)) = kappa (recDelta b s n) < kappa (recDelta b s n) + 1 = kappa (recDelta b s (delta n))
```
The strict inequality always holds (a natural number is strictly less than its successor).

Both helper lemmas are unconditionally true. Consequently, the measure `kappa` strictly decreases from the left side to the right side of the `R_rec_succ` rule (`Step (recDelta b s (delta n)) (app s (recDelta b s n))`), which is exactly what is needed for a well‑founded termination argument based on `kappa`. The strategy is sound.
