# Assessment of the Helper Strategy Soundness

## Overview

The file defines a rewrite calculus with a structural measure `kappa` intended to prove termination. I need to assess whether the two helper theorems are sound as written.

## Analysis of `kappa_rec_delta_step`

This theorem claims:
```
kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1
```

**Left-hand side:**
By the definition of `kappa`:
```
kappa (recDelta b s (delta n)) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1
```
(This matches the special case in the definition.)

**Right-hand side:**
```
kappa (recDelta b s n) + 1
```

Here we need to examine `kappa (recDelta b s n)`. The definition has a special case for when the third argument is `(delta _)`, and a catch-all otherwise:

- If `n` is **not** of the form `delta m`, then:
  ```
  kappa (recDelta b s n) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)
  ```
  So RHS = `Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1` ✓

- If `n` **is** of the form `delta m`, then:
  ```
  kappa (recDelta b s (delta m)) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1
  ```
  So RHS = `Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 2`

  But LHS = `Nat.max (Nat.max (kappa b) (kappa s)) (kappa (delta m)) + 1`
         = `Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1`

  **This gives LHS = X + 1 but RHS = X + 2, which are not equal!**

## Conclusion for `kappa_rec_delta_step`

**The theorem is NOT sound in general.** It fails when `n` is itself a `delta` term.

**Counterexample:** Let `b = s = n = void`. Then:
- LHS: `kappa (recDelta void void (delta void))` = `Nat.max (Nat.max 0 0) 0 + 1` = `1`
- RHS: `kappa (recDelta void void void) + 1` = `Nat.max (Nat.max 0 0) 0 + 1` = `1` ✓

Actually, let me try `n = delta void`:
- LHS: `kappa (recDelta void void (delta (delta void)))` = `Nat.max 0 (kappa (delta void)) + 1` = `Nat.max 0 0 + 1` = `1`
- RHS: `kappa (recDelta void void (delta void)) + 1` = `(Nat.max 0 0 + 1) + 1` = `2`

**LHS = 1 ≠ 2 = RHS. The theorem is FALSE.**

## Analysis of `kappa_rec_succ_drop`

This theorem claims:
```
kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))
```

Since `kappa_rec_delta_step` is used in the proof and is unsound, this proof strategy is compromised.

But let's check if the statement itself is true:

- RHS = `Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1`
- LHS = `Nat.max (kappa s) (kappa (recDelta b s n))`

When `n` is not a delta: `kappa (recDelta b s n) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)`

So LHS = `Nat.max (kappa s) (Nat.max (Nat.max (kappa b) (kappa s)) (kappa n))`
       = `Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)` (since `kappa s ≤ max(kappa b, kappa s)`)

This equals RHS - 1, so LHS < RHS ✓

When `n = delta m`: Similar analysis needed, but the inequality may still hold despite `kappa_rec_delta_step` being false.

## Final Verdict

**The helper strategy is UNSOUND as written.** The theorem `kappa_rec_delta_step` is false when `n` is a `delta` term. The proof of `kappa_rec_succ_drop` relies on this false lemma, making the overall strategy invalid, even if the conclusion of `kappa_rec_succ_drop` might be independently provable.
