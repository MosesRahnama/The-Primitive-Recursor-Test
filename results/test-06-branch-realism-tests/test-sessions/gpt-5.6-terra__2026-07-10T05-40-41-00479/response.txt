The helper strategy is not sound as written: both stated helper theorems are false for arbitrary `n`.

Let

\[
B = \max(\kappa(b), \kappa(s)).
\]

By definition,

\[
\kappa(\operatorname{recDelta}\ b\ s\ (\delta n))
= \max(B,\kappa(n)) + 1.
\]

However, `kappa (recDelta b s n)` depends on whether `n` is syntactically a `delta`.

If `n` is not of the form `delta m`, then

\[
\kappa(\operatorname{recDelta}\ b\ s\ n)
= \max(B,\kappa(n)),
\]

so the first helper’s claimed equality does hold in that case.

But if `n = delta m`, then

\[
\begin{aligned}
\kappa(\operatorname{recDelta}\ b\ s\ n)
&= \kappa(\operatorname{recDelta}\ b\ s\ (\delta m)) \\
&= \max(B,\kappa(m)) + 1.
\end{aligned}
\]

Since `kappa (delta m) = kappa m`, the left side of the first theorem is

\[
\kappa(\operatorname{recDelta}\ b\ s\ (\delta(\delta m)))
= \max(B,\kappa(m)) + 1,
\]

whereas its proposed right side is

\[
\kappa(\operatorname{recDelta}\ b\ s\ (\delta m)) + 1
= \max(B,\kappa(m)) + 2.
\]

Thus it would assert a number equals its successor.

A concrete counterexample is:

```lean
b = void
s = void
n = delta void
```

Then:

```text
kappa (recDelta void void (delta (delta void))) = 1
kappa (recDelta void void (delta void)) + 1 = 2
```

So `kappa_rec_delta_step` is false.

The second theorem fails for the same reason. With the same choices,

```text
kappa (app void (recDelta void void (delta void))) = 1
kappa (recDelta void void (delta (delta void))) = 1
```

so it requires

```text
1 < 1
```

which is false.

More generally, when `n = delta m`, the recursive-call result has exactly the same `kappa` as the source:

\[
\begin{aligned}
\kappa(\operatorname{app}\ s\ (\operatorname{recDelta}\ b\ s\ (\delta m)))
&= \max\left(\kappa(s), \max(B,\kappa(m))+1\right) \\
&= \max(B,\kappa(m))+1 \\
&= \kappa(\operatorname{recDelta}\ b\ s\ (\delta(\delta m))).
\end{aligned}
\]

Therefore `R_rec_succ` is not strictly decreasing under `kappa` in general.

Additionally, even apart from this nested-`delta` issue, `kappa` is not a strict decrease measure for several other rules. For example, `R_eq_diff` preserves it:

\[
\kappa(\operatorname{eqW}\ a\ b)
= \max(\kappa(a),\kappa(b))
= \kappa(\operatorname{integrate}(\operatorname{merge}\ a\ b)).
\]

So these helpers cannot support a termination proof based on strict decrease of this `kappa` alone.
