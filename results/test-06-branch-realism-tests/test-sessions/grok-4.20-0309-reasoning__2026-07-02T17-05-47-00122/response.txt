The stated theorems do not hold in general.

**kappa_rec_delta_step is false.**  
Let b = s = void (so κb = κs = 0) and n = delta void (so κn = 0).  
- LHS: κ(recDelta void void (delta (delta void))) matches the (.delta _) case, so equals max(max(0, 0), 0) + 1 = 1.  
- RHS: κ(recDelta void void (delta void)) matches the (.delta _) case, so equals max(max(0, 0), 0) + 1 = 1; then 1 + 1 = 2.  
Thus 1 ≠ 2.

**kappa_rec_succ_drop is false.**  
Using the same values as above:  
- LHS of inequality: κ(app void (recDelta void void (delta void))) = max(0, 1) = 1 (inner κ uses the (.delta _) case).  
- RHS of inequality: κ(recDelta void void (delta (delta void))) = 1 (as computed above).  
Thus 1 ≮ 1. (The rw in the proof sketch fails for the same reason as the first theorem.)

These failures occur precisely when the third argument to recDelta is itself a delta (the first theorem holds, and the second gives strict decrease, in all other cases). The intended termination argument is therefore unsound.

(The counterexamples are valid by direct expansion of the given inductive definition of κ, using only the two recDelta cases and the fact that κ(delta t) = κ t.)
