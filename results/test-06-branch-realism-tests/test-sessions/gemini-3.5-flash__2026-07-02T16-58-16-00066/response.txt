The helper strategy is **unsound as written**. Both helper theorems, `kappa_rec_delta_step` and `kappa_rec_succ_drop`, are false. 

Below is the mathematical and logical support showing why these theorems fail, using a simple counterexample.

---

### Definition Analysis

Let's review the definition of `kappa` on `recDelta`:
1. `kappa (recDelta b s (delta n)) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1`
2. `kappa (recDelta b s n) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)` (when $n$ is not of the form `delta n'`)

Also, recall that:
* `kappa void = 0`
* `kappa (delta t) = kappa t`

---

### Counterexample for `kappa_rec_delta_step`

Consider the following assignment of variables:
* `b = void`
* `s = void`
* `n = delta void`

We compute both sides of `kappa_rec_delta_step` under this assignment:

#### 1. Left-Hand Side (LHS)
$$\text{LHS} = \kappa(\text{recDelta } \text{void } \text{void } (\text{delta } (\text{delta } \text{void})))$$

By the first pattern-matching rule of `kappa` for `recDelta`, where the third argument is of the form `delta X` (with $X = \text{delta } \text{void}$):
$$\text{LHS} = \text{Nat.max } (\text{Nat.max } (\kappa(\text{void}))\ (\kappa(\text{void})))\ (\kappa(\text{delta } \text{void})) + 1$$
Using the base cases $\kappa(\text{void}) = 0$ and $\kappa(\text{delta } \text{void}) = \kappa(\text{void}) = 0$:
$$\text{LHS} = \text{Nat.max } (\text{Nat.max } 0\ 0)\ 0 + 1 = 0 + 1 = 1$$

#### 2. Right-Hand Side (RHS)
$$\text{RHS} = \kappa(\text{recDelta } \text{void } \text{void } (\text{delta } \text{void})) + 1$$

For the inner term, the third argument is `delta void`, which again matches the first pattern-matching rule:
$$\kappa(\text{recDelta } \text{void } \text{void } (\text{delta } \text{void})) = \text{Nat.max } (\text{Nat.max } (\kappa(\text{void}))\ (\kappa(\text{void})))\ (\kappa(\text{void})) + 1$$
$$\kappa(\text{recDelta } \text{void } \text{void } (\text{delta } \text{void})) = \text{Nat.max } (\text{Nat.max } 0\ 0)\ 0 + 1 = 1$$

Substituting this back into the RHS:
$$\text{RHS} = 1 + 1 = 2$$

Since $\text{LHS} = 1$ and $\text{RHS} = 2$, we have $\text{LHS} \neq \text{RHS}$. Thus, the theorem **`kappa_rec_delta_step` is unsound**.

---

### Counterexample for `kappa_rec_succ_drop`

We use the same assignment:
* `b = void`
* `s = void`
* `n = delta void`

We compute both sides of the inequality $\text{LHS} < \text{RHS}$:

#### 1. Left-Hand Side (LHS)
$$\text{LHS} = \kappa(\text{app } \text{void } (\text{recDelta } \text{void } \text{void } (\text{delta } \text{void})))$$
$$\text{LHS} = \text{Nat.max } (\kappa(\text{void}))\ (\kappa(\text{recDelta } \text{void } \text{void } (\text{delta } \text{void})))$$
$$\text{LHS} = \text{Nat.max } 0\ 1 = 1$$

#### 2. Right-Hand Side (RHS)
$$\text{RHS} = \kappa(\text{recDelta } \text{void } \text{void } (\text{delta } (\text{delta } \text{void})))$$
As computed in the first part, this simplifies to:
$$\text{RHS} = 1$$

For the theorem `kappa_rec_succ_drop` to hold, we must have:
$$\text{LHS} < \text{RHS} \implies 1 < 1$$

Since $1 < 1$ is false, the theorem **`kappa_rec_succ_drop` is also unsound**.

---

### Conclusion

The helper strategy fails because the definition of `kappa` on nested `delta`s does not accumulate $+1$ for each nested layer of `delta` in the recursion trace. Instead, it collapses them because `kappa (delta n) = kappa n`. 

Consequently, when `n` is of the form `delta n'`, the step relation of `recDelta` does not strictly decrease the `kappa` measure, causing the termination helper theorems to be false.
