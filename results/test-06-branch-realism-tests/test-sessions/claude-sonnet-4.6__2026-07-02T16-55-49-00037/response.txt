## Analyzing `kappa_rec_delta_step`

The claim is:
```
kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1
```

**Left side:** By `kappa_rec_delta`:
```
kappa (recDelta b s (delta n)) = max (max (kappa b) (kappa s)) (kappa n) + 1
```

**Right side:** I need to compute `kappa (recDelta b s n)`. The definition has two cases for `recDelta`:

- Otherwise (any other form of `n`): gives `max (max (kappa b) (kappa s)) (kappa n)`

So `kappa (recDelta b s n) + 1 = max (max (kappa b) (kappa s)) (kappa n) + 1`.

This matches the left side **regardless of the form of `n`**. So **`kappa_rec_delta_step` is true**.

## Analyzing `kappa_rec_succ_drop`

The claim is:
```

```

```
kappa (app s (recDelta b s n)) < kappa (recDelta b s n) + 1
```

Which is equivalent to:
```
kappa (app s (recDelta b s n)) ≤ kappa (recDelta b s n)
```

Expanding the left side:
```
kappa (app s (recDelta b s n)) = max (kappa s) (kappa (recDelta b s n))
```

So the question is whether:
```
max (kappa s) (kappa (recDelta b s n)) ≤ kappa (recDelta b s n)
```

This requires `kappa s ≤ kappa (recDelta b s n)`.

Now, `kappa (recDelta b s n) = max (max (kappa b) (kappa s)) (kappa n)` (when `n` is not of the form `delta _`), or `max (max (kappa b) (kappa s)) (kappa n') + 1` (when `n = delta n'`).

**In either case:** `kappa (recDelta b s n) ≥ max (kappa b) (kappa s) ≥ kappa s`.

Therefore `max (kappa s) (kappa (recDelta b s n)) = kappa (recDelta b s n)`, and:
```
kappa (app s (recDelta b s n)) = kappa (recDelta b s n) ≤ kappa (recDelta b s n)
```

So `kappa (app s (recDelta b s n)) < kappa (recDelta b s n) + 1` holds. **`kappa_rec_succ_drop` is also true.**
