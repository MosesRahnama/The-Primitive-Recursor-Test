Short answer: **the helper strategy is sound** (mathematically), provided the first helper theorem is proved in the obvious way.

### Why it works

Let  
\[
M := \max(\max(\kappa b,\kappa s),\kappa n).
\]

From the definition of `kappa`:

- `kappa (recDelta b s (delta n)) = M + 1`
- `kappa (recDelta b s n) = M`  
  (because the third argument is not syntactically `delta _`, so the non-`+1` clause applies)

So:
\[
\kappa(\text{recDelta } b\, s\, (\delta n)) = \kappa(\text{recDelta } b\, s\, n) + 1.
\]
That is exactly `kappa_rec_delta_step`.

Now for `kappa_rec_succ_drop`:

\[
\kappa(\text{app } s\, (\text{recDelta } b\, s\, n))
= \max(\kappa s,\kappa(\text{recDelta } b\, s\, n))
\ge \kappa(\text{recDelta } b\, s\, n).
\]
Actually we need an upper bound:
\[
\max(\kappa s,\kappa(\text{recDelta } b\, s\, n))
\le \kappa(\text{recDelta } b\, s\, n)
\]
because \(\kappa(\text{recDelta } b\, s\, n)=\max(\max(\kappa b,\kappa s),\kappa n)\), so it is already at least \(\kappa s\). Hence
\[
\kappa(\text{app } s\, (\text{recDelta } b\, s\, n))
= \kappa(\text{recDelta } b\, s\, n).
\]
Using `kappa_rec_delta_step`,
\[
\kappa(\text{recDelta } b\, s\, (\delta n))
= \kappa(\text{recDelta } b\, s\, n)+1,
\]
so immediately
\[
\kappa(\text{app } s\, (\text{recDelta } b\, s\, n))
< \kappa(\text{recDelta } b\, s\, (\delta n)).
\]

So the intended strict decrease for `R_rec_succ` is valid.

---

One caveat (outside those two lemmas): this doesn’t mean `kappa` decreases for **all** rewrite rules (e.g. `R_eq_diff` can increase), only that this particular helper chain for the recursive-succ case is correct.
