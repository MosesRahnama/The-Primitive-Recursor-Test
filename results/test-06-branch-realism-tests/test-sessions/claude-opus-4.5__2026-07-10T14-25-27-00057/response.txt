# Assessment of the Helper Strategy Soundness

## Overview

The file defines a rewrite calculus with a structural measure `kappa` intended to prove termination. I need to assess whether the two helper theorems are sound (i.e., provable/true).

## Analysis of `kappa_rec_delta_step`

**Claim:** `kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1`

**LHS:** By the definition of `kappa`:
```
kappa (recDelta b s (delta n)) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1
```
(This uses the specific pattern match for `.recDelta b s (.delta n)`)

**RHS:** `kappa (recDelta b s n) + 1`

Here's the problem: `kappa (recDelta b s n)` depends on what `n` is:
- If `n` matches `.delta m` for some `m`, then `kappa (recDelta b s n) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1`
- Otherwise, `kappa (recDelta b s n) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)`

**Counterexample:** Let `n = delta void`.

- LHS: `kappa (recDelta b s (delta (delta void)))`
  - Pattern matches `.recDelta b s (.delta (delta void))`
  - = `Nat.max (Nat.max (kappa b) (kappa s)) (kappa (delta void)) + 1`
  - = `Nat.max (Nat.max (kappa b) (kappa s)) 0 + 1`

- RHS: `kappa (recDelta b s (delta void)) + 1`
  - Pattern matches `.recDelta b s (.delta void)`
  - = `Nat.max (Nat.max (kappa b) (kappa s)) (kappa void) + 1 + 1`
  - = `Nat.max (Nat.max (kappa b) (kappa s)) 0 + 2`

These are **not equal** (differs by 1).

**Conclusion:** `kappa_rec_delta_step` is **FALSE** in general.

## Analysis of `kappa_rec_succ_drop`

**Claim:** `kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))`

**RHS:** `Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1`

**LHS:** 
```
kappa (app s (recDelta b s n)) = Nat.max (kappa s) (kappa (recDelta b s n))
```

Again, `kappa (recDelta b s n)` depends on the form of `n`.

**Case 1:** `n` is not of form `delta m`:
- `kappa (recDelta b s n) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)`
- LHS = `Nat.max (kappa s) (Nat.max (Nat.max (kappa b) (kappa s)) (kappa n))`
      = `Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)` (since `kappa s ≤ max(kappa b, kappa s)`)
- RHS = same value + 1

This works: LHS < RHS ✓

**Case 2:** `n = delta m` for some `m`:
- `kappa (recDelta b s n) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1`
- LHS = `Nat.max (kappa s) (Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1)`
- RHS = `Nat.max (Nat.max (kappa b) (kappa s)) (kappa (delta m)) + 1`
      = `Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1`

Let `M = Nat.max (Nat.max (kappa b) (kappa s)) (kappa m)`.
- LHS = `Nat.max (kappa s) (M + 1)` = `M + 1` (since `kappa s ≤ M`)
- RHS = `M + 1`

So LHS = RHS, not LHS < RHS.

**Conclusion:** `kappa_rec_succ_drop` is **FALSE** when `n` has the form `delta m`.

## Final Verdict

**The helper strategy is UNSOUND.** Both helper theorems are false in general. The `kappa` measure does decrease for the base cases of recursion but fails to properly account for nested `delta` constructors in the recursion argument.
