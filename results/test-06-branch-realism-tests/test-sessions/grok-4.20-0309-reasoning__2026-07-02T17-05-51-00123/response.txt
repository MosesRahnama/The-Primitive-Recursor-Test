The provided helper theorems are not sound (i.e., they do not hold in general, so they cannot support a termination argument as written).

**Counterexample (for both theorems):** Let `b = void`, `s = void`, `n = delta void`. Then `kappa void = 0` (by definition), so:
- `kappa (recDelta void void (delta (delta void))) = Nat.max (Nat.max 0 0) (kappa (delta void)) + 1 = Nat.max 0 0 + 1 = 1` (by `kappa` definition, first `recDelta` case).

- Thus, `kappa (recDelta void void (delta (delta void))) = 1` but `kappa (recDelta void void (delta void)) + 1 = 2`, so `kappa_rec_delta_step` fails (`1 ≠ 2`).
