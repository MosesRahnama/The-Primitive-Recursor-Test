# Assessment of the Helper Strategy Soundness

## Overview

The file defines a rewrite calculus with a structural measure `kappa` intended to prove termination. I'll analyze whether the two helper theorems are sound.

## Analysis of `kappa_rec_delta_step`

This theorem claims:
```
kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1
```

**Left-hand side:**
By the definition of `kappa`:
```
kappa (recDelta b s (delta n)) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1
```
Note: The pattern `recDelta b s (.delta n)` matches, so `kappa` of the third argument is `kappa n` (stripping the `delta`), and we add 1.

**Right-hand side:**
```
kappa (recDelta b s n) + 1
```

For `kappa (recDelta b s n)`, we need to consider what `n` is:
- If `n` matches `.delta m` for some `m`, then `kappa (recDelta b s n) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1`
- Otherwise, `kappa (recDelta b s n) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)`

**The theorem assumes the general (non-delta) case applies to `n`**, giving:
```
RHS = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1
```

This matches the LHS **only when `n` is not of the form `delta m`**.

### Counterexample:
Let `n = delta void`, `b = void`, `s = void`.

- **LHS:** `kappa (recDelta void void (delta (delta void)))`
  - Pattern matches `.delta (delta void)`, so: `Nat.max (Nat.max 0 0) (kappa (delta void)) + 1 = Nat.max 0 0 + 1 = 1`

- **RHS:** `kappa (recDelta void void (delta void)) + 1`
  - Pattern matches `.delta void`, so: `Nat.max (Nat.max 0 0) (kappa void) + 1 + 1 = 0 + 1 + 1 = 2`

**Result: LHS = 1, RHS = 2. The theorem is FALSE.**

## Analysis of `kappa_rec_succ_drop`

This theorem claims:
```
kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n))
```

**RHS:** `Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1`

**LHS:** 
```
kappa (app s (recDelta b s n)) = Nat.max (kappa s) (kappa (recDelta b s n))
```

For the non-delta case of `n`:
```
LHS = Nat.max (kappa s) (Nat.max (Nat.max (kappa b) (kappa s)) (kappa n))
    = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)
```

So we need: `Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) < Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1`

This is true (for any natural number `x`, we have `x < x + 1`).

**However**, if `n = delta m`, then:
```
kappa (recDelta b s n) = Nat.max (Nat.max (kappa b) (kappa s)) (kappa m) + 1
```

And the inequality may still hold, but the proof strategy relies on the incorrect `kappa_rec_delta_step`.

## Conclusion

**The helper strategy is UNSOUND.**

The theorem `kappa_rec_delta_step` is false when `n` is itself of the form `delta m`. The nested pattern matching in `kappa`'s definition means that `kappa (recDelta b s n)` behaves differently depending on whether `n` matches `delta _`, but the theorem assumes it always uses the general case.

While `kappa_rec_succ_drop` might be provable directly, its stated proof strategy via `kappa_rec_delta_step` is broken due to this flaw.
