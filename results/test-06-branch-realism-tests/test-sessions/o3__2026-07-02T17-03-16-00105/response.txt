Yes – the two lemmas can really be proved from the definition of `kappa`, so the
local “helper strategy’’ embodied in them is sound.

Write  

    m := Nat.max (Nat.max (kappa b) (kappa s)) (kappa n).

1.  kappa for the two `recDelta` shapes.  
    By inspection of the definition

        kappa (recDelta b s (delta n)) = m + 1
        kappa (recDelta b s n)         = m

    therefore  

        kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1,

    and `kappa_rec_delta_step` is true by mere rewriting.

2.  Strict drop in the `R_rec_succ` rule.  
    Using the calculation above and the `kappa`-rule for `app`

        kappa (app s (recDelta b s n))
          = Nat.max (kappa s) (kappa (recDelta b s n))
          = Nat.max (kappa s) m
          = m,                    -- because m ≥ κ s by construction

    while

        kappa (recDelta b s (delta n)) = m + 1.

    Hence  

        kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n)),

    proving `kappa_rec_succ_drop`.

So both helper lemmas are correct and provable exactly as intended.

Caveat.  
If the ultimate goal is a global termination proof obtained by showing that
`kappa` strictly decreases for every rule in `Step`, then *additional work is
needed*: rules such as

    merge t t   →  t
    integrate (delta void) → void

leave `kappa` unchanged, so `kappa` alone is not a strictly-decreasing
measure for the whole calculus.  Nevertheless, for the `recDelta`/`R_rec_succ`
part the strategy implemented in the two lemmas is perfectly sound.
