**Why it terminates**

The calculus is a first‑order term‑rewrite system with constructors  

```
void, delta, integrate, merge, app, recΔ, eqW
```

and the eight rewrite rules listed in the file.  A standard well‑founded‑ranking argument suffices:

1. **Measure for `recΔ`.**  
   Let `d(t)` be the number of `delta` constructors occurring in the third argument of a `recΔ`.  
   - `R_rec_zero` removes the whole `recΔ` (the third argument is `void`, so `d = 0`).  
   - `R_rec_succ` replaces `recΔ b s (delta n)` by `app s (recΔ b s n)`.  The third argument changes from `delta n` to `n`, so `d` decreases by one.  The added `app` does not affect the ranking because the primary component (`d`) is already decreasing.

2. **Measure for the other constructors.**  
   Define a auxiliary size `|t|` (the total number of constructor occurrences in `t`).  For the remaining rules we have:

   - `R_int_delta` `integrate (delta t) → void`  reduces `|t|` (the whole sub‑term disappears).  
   - `R_merge_void_left/right` and `R_merge_cancel` all remove at least one `merge` node, therefore also reduce `|t|`.  
   - `R_eq_refl` `eqW a a → void`  removes the `eqW` node and shortens the term.  
   - `R_eq_diff` `eqW a b → integrate (merge a b)` eliminates the leading `eqW` constructor.  Although the term may grow in size, the *number of leading `eqW` symbols* drops from 1 to 0, which is a well‑founded component.

3. **Lexicographic combination.**  
   Put the three components together in a lexicographic order:

   ```
   ( #eqW at the head ,  delta‑depth of the recΔ argument ,  total size )
   ```

   Every rewrite rule decreases one of the first two components; if the first two stay equal it decreases the total size.  Since the lexicographic product of well‑founded orders is well‑founded, there cannot be an infinite descending chain.

Because each step strictly reduces this ranking, every rewrite sequence must terminate.  Hence the system is **strongly normalising**.

No additional rewrite rules, guards, hidden assumptions, or structural axioms are required; the proof uses only elementary induction on the syntax of terms, which is already available in the logical framework of Lean 4.
