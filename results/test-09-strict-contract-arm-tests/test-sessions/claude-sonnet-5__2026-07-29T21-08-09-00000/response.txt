### Step 1 — Additive failure of the naive size measure

Let `M` be node-count: `M(void)=1`, `M(f(t₁,…))=1+ΣM(tᵢ)`.

The only genuinely *duplicating* rule is

```
R_rec_succ : recΔ b s (delta n) → app s (recΔ b s n)
```

Here `s` occurs once on the left and twice on the right.

- `M(before) = M(recΔ b s (delta n)) = 2 + M(b) + M(s) + M(n)`
- `M(after)  = M(app s (recΔ b s n)) = 2 + M(b) + 2·M(s) + M(n)`

So

```
M(after) = M(before) + M(s)          (i.e. M(before) - 1 + (M(s)+1))
```

Since `M(s) ≥ 1` for **every** Trace term (there is no zero‑size term, `void` alone has `M=1`), this step **strictly increases** size on *every* application, not just some. No naive weight/size measure can certify termination of this rule — there is never a strict drop. (`R_eq_diff` duplicates nothing — `a,b` each occur once — so it is not part of this failure; only `R_rec_succ` breaks size‑based arguments.)

**CONSTRAINT CHECK:** size-based measures are blocked. A fix must not smuggle in extra rules/guards — it must instead choose a well-founded term order that tolerates duplication of an inert argument while a *distinguished* argument (`n`) strictly decreases.

### Step 2 — Proposed fix: Recursive Path Ordering (RPO)

**Key premise required:** there exists a strict precedence `≻_F` on the finite signature `{eqW, recΔ, integrate, merge, app, delta, void}` such that every rule orients as `LHS ≻_rpo RHS`, where `≻_rpo` is the standard (multiset-status) RPO built from `≻_F`. RPO's well-foundedness, monotonicity, and stability under substitution are standard rewriting-theory facts requiring only a well-founded (here: finite, hence automatically well-founded) precedence — no extra rewrite rules, guards, or object-level axioms.

**Discharging the premise — explicit precedence:**
```
eqW ≻ recΔ ≻ integrate ≻ merge ≻ app ≻ delta ≻ void
```

Verification per rule:

- `R_merge_void_left/right`, `R_merge_cancel`, `R_rec_zero`: RHS is a literal immediate subterm of LHS → holds by the **subterm property** of RPO, no precedence needed.
- `R_int_delta`, `R_eq_refl`: RHS = `void`, a nullary constant; case (b) needs only `integrate ≻ void`, `eqW ≻ void` — satisfied transitively.
- `R_eq_diff`: `eqW(A,B) ≻ merge(A,B)` via case (b) (`eqW≻merge`, and `A,B` are subterms of LHS); then `eqW(A,B) ≻ integrate(merge(A,B))` via case (b) (`eqW≻integrate`). Both hold.
- `R_rec_succ` (the duplicating rule): need `recΔ(B,S,delta N) ≻ app(S, recΔ(B,S,N))`.
  - `recΔ(B,S,delta N) ≻ S`: subterm property. ✓
  - `recΔ(B,S,delta N) ≻ recΔ(B,S,N)`: same head symbol, compare multisets `{B,S,delta N}` vs `{B,S,N}`; cancel common `B,S`, leaving `{delta N} ≻≻ {N}`, which holds since `delta N ≻ N` (subterm property). ✓
  - Then case (b) with `recΔ ≻ app` gives the result. ✓

All 8 rules are compatible with one single consistent precedence — no contradictions arise (the required inequalities `recΔ≻app`, `eqW≻integrate`, `eqW≻merge`, `integrate≻void`, `eqW≻void` are all consistent with the total order above).
