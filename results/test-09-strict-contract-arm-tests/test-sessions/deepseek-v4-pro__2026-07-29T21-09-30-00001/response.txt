**Assessment: Yes, strong normalization can be established from the calculus alone, using only the given syntax and rules, without any extra structural axioms or object‑level assumptions beyond what is derivable.**

### Reasoning (following the strict execution contract)

#### 1. The duplication step and additive failure of a naive size measure
The rule that duplicates a subterm is **R\_rec\_succ**:
```
recΔ b s (delta n)  →  app s (recΔ b s n)
```
Let `M(t)` be the number of constructors in `t`.  
- **Before**: `M(recΔ b s (delta n)) = 1 + M(b) + M(s) + 1 + M(n) = M(b) + M(s) + M(n) + 2`  
- **After**: `M(app s (recΔ b s n)) = 1 + M(s) + (1 + M(b) + M(s) + M(n)) = M(b) + 2·M(s) + M(n) + 2`  

Hence **`M(after) = M(before) + M(s)`**.  
When `M(s) ≥ 1` (i.e. `s ≠ void`), the measure does **not** drop; it increases. Thus a simple size measure fails (additive failure).

#### 2. Proposed fix – lexicographic measure
To obtain a termination proof, we strengthen the measure to a lexicographic triple:

\[
\Phi(t) = \bigl( \#\text{eqW}(t),\; \#\delta(t),\; \text{size}(t) \bigr)
\]

ordered lexicographically on \(\mathbb{N}^3\) (which is well‑founded).  

- \(\#\text{eqW}(t)\) = number of `eqW` constructors in `t`  
- \(\#\delta(t)\) = number of `delta` constructors in `t`  
- \(\text{size}(t)\) = total number of constructors  

#### 3. Key premise and verification
The premise required for the fix is:

> Every rewrite step strictly decreases \(\Phi\) lexicographically.

Verification rule by rule:

| Rule | Effect on \(\Phi\) | Decrease |
|------|-------------------|----------|
| `integrate (delta t) → void` | \(\#\delta\) decreases by 1 (the outer `delta` vanishes); \(\#\text{eqW}\) unchanged | ✓ (second component) |
| `merge void t → t` | \(\#\text{eqW}\), \(\#\delta\) unchanged; size decreases (\(1+\text{size}(t) > \text{size}(t)\)) | ✓ (third component) |
| `merge t void → t` | same as above | ✓ |
| `merge t t → t` | size decreases (\(1+2\text{size}(t) > \text{size}(t)\)) | ✓ |
| `recΔ b s void → b` | size decreases | ✓ |
| `recΔ b s (delta n) → app s (recΔ b s n)` | \(\#\delta\) decreases by 1 (outer `delta` removed); \(\#\text{eqW}\) unchanged | ✓ (second component) |
| `eqW a a → void` | \(\#\text{eqW}\) decreases by 1 | ✓ (first component) |
| `eqW a b → integrate (merge a b)` | \(\#\text{eqW}\) decreases by 1 (the `eqW` disappears) | ✓ (first component) |

In every step at least one component strictly decreases while all earlier components stay the same (or decrease). No rule creates new `eqW` or `delta` constructors, so the first two components never increase, and the size component is irrelevant when an earlier component drops.

Because the lexicographic order on \(\mathbb{N}^3\) is well‑founded, there can be no infinite reduction sequences. Therefore the rewrite system is strongly normalizing. The proof uses only the presented inductive syntax and the given rewrite rules; no external axioms or extra guards are needed.
