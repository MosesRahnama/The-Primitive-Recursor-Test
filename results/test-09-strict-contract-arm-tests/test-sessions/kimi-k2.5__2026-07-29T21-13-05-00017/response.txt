**Step 1: Identify the duplication failure in `R_rec_succ`**

Rule `R_rec_succ` duplicates the step argument `s`:
- LHS: `recΔ b s (delta n)` (contains one occurrence of `s`)
- RHS: `app s (recΔ b s n)` (contains two occurrences of `s`: one in the `app` and one in the recursive call)

Using a naive size measure `M` (counting constructors):
- `M(recΔ b s (delta n)) = 2 + M(b) + M(s) + M(n)`
- `M(app s (recΔ b s n)) = 2 + M(b) + 2·M(s) + M(n)`

Thus:
- **M(after) = M(before) - 1 + M(s)**

Since every term has `M(s) ≥ 1` (the smallest term `void` has size 1), we have `M(after) ≥ M(before)`, violating the strict decrease required for a termination ordering. When `M(s) > 1`, the measure strictly increases.

**Step 2: Proposed fix**

Define a weight function `W : Trace → ℕ` that assigns exponential weight to the recursion argument of `recΔ`:

- `W(void) = 1`
- `W(delta t) = W(t) + 1`
- `W(integrate t) = W(t) + 1`
- `W(merge t₁ t₂) = W(t₁) + W(t₂) + 1`
- `W(app t₁ t₂) = W(t₁) + W(t₂) + 1`
- `W(eqW t₁ t₂) = W(t₁) + W(t₂) + 1`
- **`W(recΔ b s n) = W(b) + W(s) · 2^{W(n)} + W(n)`**

Use the lexicographic measure `μ(t) = (N_{eqW}(t), W(t))` where `N_{eqW}(t)` counts `eqW` constructors.

**Step 3: Verify the key premise**

The critical case is `R_rec_succ`. We require:
```
W(recΔ b s (delta n)) > W(app s (recΔ b s n))
```

Compute:
- LHS: `W(b) + W(s)·2^{W(n)+1} + (W(n)+1) = W(b) + 2·W(s)·2^{W(n)} + W(n) + 1`
- RHS: `W(s) + [W(b) + W(s)·2^{W(n)} + W(n)] + 1 = W(b) + W(s)·2^{W(n)} + W(s) + W(n) + 1`

Difference:
```
LHS - RHS = W(s)·2^{W(n)} - W(s) = W(s)·(2^{W(n)} - 1)
```

**Key premise:** `W(n) ≥ 1` for all terms `n`, since `W(void) = 1` and all other constructors increase weight.
- Therefore `2^{W(n)} ≥ 2`, so `2^{W(n)} - 1 ≥ 1`.
- Since `W(s) ≥ 1`, the difference is at least `1 · 1 = 1 > 0`.
