Yes, strong normalization is derivable from the presented calculus as shown.

The key point is that the `Step` relation has no congruence rules: rewriting occurs only at the root. Therefore, after a rewrite, the next step is possible only if the resulting term itself is a root redex.

Most rules immediately produce stuck terms:

- `integrate (delta t) -> void`
- `recΔ b s (delta n) -> app s (recΔ b s n)`
- `eqW a a -> void`
- `eqW a b -> integrate (merge a b)`

The `app ...` result has no `app` rule, and `integrate (merge a b)` does not match the only `integrate` rule, which requires `integrate (delta t)`. So these reductions cannot continue.

The remaining rules reduce to a direct subterm:

- `merge void t -> t`
- `merge t void -> t`
- `merge t t -> t`
- `recΔ b s void -> b`

Those can continue only by reducing that subterm. Since terms are finite inductive trees, this gives only finite descent.

Thus every reduction sequence is finite, and no extra structural axioms or external assumptions are needed.
