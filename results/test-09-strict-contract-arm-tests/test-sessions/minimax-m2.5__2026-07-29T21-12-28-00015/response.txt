**Assessment** – Yes, the system is strongly normalising. The termination can be proved from the given rules alone by a standard lexicographic‑measure argument; no extra axioms or rewrite rules are needed.

---

### 1.  Additive failure of a naive measure  

Consider the rule  

```
R_rec_succ :  recΔ b s (delta n) → app s (recΔ b s n)
```

The second argument `s` is duplicated – it occurs once on the left and twice on the right.  
If we take the simple measure `M(t) = size(t)` (the number of constructors), then

```
M(after) = M(before) – 1 + M(s) .
```

Because `M(s) ≥ 1` for any term `s` (even `void` has size 1), we have `M(after) ≥ M(before)`.  
Thus the size measure does **not** give a strict decrease; a fix is required.

---

### 2.  Proposed fix – a lexicographic measure  

Define four components:

| Component | Definition |
|-----------|-------------|
| `C_eqW(t)` | Number of `eqW` constructors in `t`. |
| `R(t)` | Sum of the delta‑depths of all third arguments of `recΔ` in `t` (i.e. total number of `delta` constructors occurring in those arguments). |
| `D(t)` | Total number of `delta` constructors in `t`. |
| `S(t)` | Total size (number of constructors) of `t`. |

Let  

```
M(t) := ( C_eqW(t) , R(t) , D(t) , S(t) )
```

ordered lexicographically (first component most significant).

---

### 3.  Key premise – each rule decreases `M`

We check every rewrite rule:

| Rule | Effect on `(C_eqW, R, D, S)` |
|------|------------------------------|
| `R_int_delta` : `integrate (delta t) → void` | `C_eqW` unchanged, `R` unchanged, `D` – 1, `S` – ≥1 → ↓ |
| `R_merge_void_left` : `merge void t → t` | `C_eqW,R,D` unchanged, `S` – 2 → ↓ |
| `R_merge_void_right` : `merge t void → t` | same as above → ↓ |
| `R_merge_cancel` : `merge t t → t` | `C_eqW,R` unchanged, `D` – `D(t)` (if `D(t)>0`), otherwise `S` – ≥1 → ↓ |
| `R_rec_zero` : `recΔ b s void → b` | `C_eqW` unchanged, `R` does not increase (the `recΔ` with `void` contributed 0), `D` – `D(s)`, `S` – ≥2 → ↓ |
| `R_rec_succ` : `recΔ b s (delta n) → app s (recΔ b s n)` | `C_eqW` unchanged, **`R` – 1** (the outer `recΔ` loses one delta), `D` may increase but is less significant, `S` may increase but is less significant → ↓ |
| `R_eq_refl` : `eqW a a → void` | **`C_eqW` – 1**, `D` – 2·`D(a)`, `S` – ≥1 → ↓ |
| `R_eq_diff` : `eqW a b → integrate (merge a b)` | **`C_eqW` – 1**, `R,D` unchanged, `S` + 1 (less significant) → ↓ |

In every case at least one component decreases while no more‑significant component increases, so the lexicographic order guarantees `M(after) < M(before)`.

---

### 4.  Conclusion  

Because each rewrite step strictly decreases the well‑founded lexicographic tuple `M`, there is no infinite rewrite chain. Hence the calculus is **strongly normalising** without invoking any external structural axioms or additional assumptions. The proof uses only the given syntax and rewrite rules and standard termination‑proof techniques.
