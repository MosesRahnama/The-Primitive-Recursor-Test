**Assessment:** Yes, strong normalization can be established for this calculus using a lexicographic measure, despite the additive failure in the primitive recursion rule.

---

### 1. Additive Failure in `R_rec_succ`

Consider the rewrite rule for successor recursion:
```
R_rec_succ : ∀ b s n, Step (recΔ b s (delta n)) (app s (recΔ b s n))
```

Define the naive syntactic size measure `M` as the total number of constructors:
- `M(void) = 1`
- `M(delta t) = M(t) + 1`
- `M(integrate t) = M(t) + 1`
- `M(merge t1 t2) = M(t1) + M(t2) + 1`
- `M(app t1 t2) = M(t1) + M(t2) + 1`
- `M(recΔ b s n) = M(b) + M(s) + M(n) + 1`
- `M(eqW t1 t2) = M(t1) + M(t2) + 1`

For the step `recΔ b s (delta n) → app s (recΔ b s n)`:
- **Before:** `M(recΔ b s (delta n)) = M(b) + M(s) + M(n) + 1 + 1 = M(b) + M(s) + M(n) + 2`
- **After:** `M(app s (recΔ b s n)) = M(s) + [M(b) + M(s) + M(n) + 1] + 1 = M(b) + 2·M(s) + M(n) + 2`

Thus:
```
M(after) = M(before) + M(s) = M(before) - 1 + M(s) + 1
```

When `M(s) ≥ 1` (which holds for all terms), we have `M(after) ≥ M(before) + 1`, demonstrating **no strict drop**. The subterm `s` is duplicated on the right-hand side (appearing both as the first argument to `app` and preserved within the recursive call), causing the measure to increase by `M(s)`.

---

### 2. Proposed Fix: Lexicographic Measure

To establish termination, we abandon the naive size measure in favor of a **lexicographic ordering** on a triple:

**μ(t) = (E(t), R(t), S(t))**

ordered lexicographically, where:

1.  **`E(t)`** = the number of `eqW` constructors in `t` (natural number).
2.  **`R(t)`** = the multiset of heights of the third arguments of all `recΔ` redexes in `t`. The height `h(n)` is the number of nested `delta` constructors (i.e., `h(void) = 0`, `h(delta n) = h(n) + 1`). The multiset is ordered by the multiset extension of the standard ordering on ℕ.
3.  **`S(t)`** = the total syntactic size of `t` (as defined above).

**Key Premise:** Every rewrite rule strictly decreases this lexicographic measure.

---

### 3. Verification of Key Premise

We check that each rule reduces `μ(t)`:

**Rules affecting `eqW` (primary measure `E`):**
- `R_eq_refl` and `R_eq_diff` both eliminate one `eqW` constructor. Thus `E` decreases by 1, regardless of the growth in other subterms (e.g., `R_eq_diff` creates `integrate (merge a b)` which has larger syntactic size, but smaller `E`). The lexicographic priority ensures termination.
- No other rule creates new `eqW` constructors. `R_rec_succ` duplicates `s`, but any `eqW` inside `s` were already present in the original term, so `E` is non-increasing elsewhere.

**Rules affecting `recΔ` (secondary measure `R`):**
- `R_rec_zero`: Removes a `recΔ` redex with third argument `void` (height 0). The multiset `R` loses one element, strictly decreasing.
- `R_rec_succ`: Replaces a redex with third argument `delta n` (height `h+1`) with a redex with third argument `n` (height `h`). The multiset changes from `..., h+1, ...` to `..., h, ...` (plus potentially other elements from the duplicated `s`). Since `h < h+1`, and we remove `h+1` and add `h` and copies of elements from `s` (which were already present in the multiset), the multiset strictly decreases in the multiset ordering.
- Other rules (`R_int_delta`, `R_merge_*`, `R_eq_*`) may reduce inside the third argument of a `recΔ`, but they never increase the height of that argument (they may decrease it or leave it unchanged, but never transform `n` into `delta n` or a taller structure). Thus `R` is non-increasing under these rules.

**Tertiary measure `S`:**
- For rules not affecting `E` or `R` (e.g., `R_merge_void_left`, `R_merge_cancel`), the syntactic size `S` strictly decreases, ensuring local termination.

**Conclusion:** Since `E` is a natural number, `R` is a multiset of natural numbers (well-founded under multiset ordering), and `S` is a natural number, the lexicographic product is well-founded. Every step decreases `μ(t)`, therefore the system is strongly normalizing.

**No constraint blocker applies.**
