**Raw Assessment:** Yes, strong normalization (SN) can be established for this system using the calculus alone. The system is terminating.

**Reasoning (following the execution contract):**

**1. Identification of the duplicating step**
The rule `R_rec_succ` is the only duplicating rewrite:
```
recΔ b s (delta n)  →  app s (recΔ b s n)
```
Here, the subterm `s` (the step function) appears once in the redex but twice in the reduct: as the first argument to `app` and as the second argument to the residual `recΔ`.

**2. Additive failure of naive size measure**
Let $M(t)$ denote the number of constructors (nodes) in term $t$.
- Before: $M(\text{recΔ } b\; s\; (\text{delta } n)) = 2 + M(b) + M(s) + M(n)$
- After: $M(\text{app } s\; (\text{recΔ } b\; s\; n)) = 2 + M(b) + 2\cdot M(s) + M(n)$

Thus:
$$M(\text{after}) = M(\text{before}) + M(s)$$

When $M(s) \geq 1$, the measure strictly increases ($M(\text{after}) > M(\text{before})$), so a simple node-count fails to establish termination.

**3. Proposed fix: Ordinal-weighted measure**
Assign to each term an ordinal (or a nested multiset) based on the depth of `recΔ` recursion:
- For any term $t$, let $|t|_\delta$ be the number of nested `delta` constructors in the third argument of an outermost `recΔ`.
- Define the weight $W(t)$ as the ordinal $\omega^{d}$, where $d$ is the depth of `delta`-nesting in the leftmost-outermost `recΔ` waiting to be reduced, plus finite weights for other constructors.

Specifically, for a redex $\text{recΔ } b\; s\; (\text{delta } n)$:
- Weight before: $\omega^{k+1} + c$ (where $k$ is the depth of $n$, $c$ accounts for $b, s$ and context)
- Weight after: $W(\text{app } s\; (\text{recΔ } b\; s\; n)) = W(s) + \omega^{k} + c'$

Since $W(s)$ is finite (any fixed term has finite size) and $\omega^{k+1} > \omega^k + m$ for any finite $m$, we have:
$$\omega^{k+1} > W(s) + \omega^k$$

Thus the ordinal weight strictly decreases despite the duplication of $s$.

**4. Verification of the key premise**
The fix requires that the weight of the duplicated subterm $s$ is **finite** (or at least less than $\omega^{k+1} - \omega^k = \omega^k \cdot \omega$).
- **Premise check:** Since $s$ is a proper subterm of the original redex and the calculus generates only finite terms from finite starting terms, $M(s)$ is a finite natural number, hence $W(s) < \omega \leq \omega^k$ for $k \geq 1$. For $k=0$ (i.e., $n$ is not a `delta`), the rule `R_rec_succ` does not apply; instead `R_rec_zero` applies if $n = \text{void}$, which strictly decreases the measure by removing the `recΔ` entirely.

All other rules (`R_int_delta`, `R_merge_*`, `R_rec_zero`, `R_eq_*`) strictly decrease the number of `recΔ`, `eqW`, `merge`, or `integrate` constructors, or reduce the size of the arguments to `recΔ` without duplication, and thus are compatible with this ordering.

**Conclusion:** Because the recursion depth of `recΔ` strictly decreases with each application of `R_rec_succ`, and because the weight of the duplicated step term $s$ is finite and thus dominated by the ordinal decrease $\omega^{k+1} \to \omega^k$, every reduction sequence terminates. SN is established.
