**Assessment:** **Yes**, strong normalization can be established from the presented calculus alone, without importing structural axioms or object‑level assumptions beyond the given syntax and rewrite rules.

**Reasoning (following the strict execution contract):**

1. **Identify a duplication step:**  
   Rule `R_rec_succ`  
   `recΔ b s (delta n) → app s (recΔ b s n)`  
   duplicates the subterm `s` (one occurrence on the left, two on the right).

2. **Show additive failure for a naive measure:**  
   Define a naive size measure `M(t)` as the number of constructors in `t`.  
   - `M(recΔ b s (delta n)) = 1 + M(b) + M(s) + (1 + M(n)) = 2 + M(b) + M(s) + M(n)`.  
   - `M(app s (recΔ b s n)) = 1 + M(s) + (1 + M(b) + M(s) + M(n)) = 2 + M(b) + 2·M(s) + M(n)`.  
   Hence `M(after) = M(before) + M(s)`.  
   This is not of the strict form `M(before) - 1 + M(s)`, but it is clearly an increase whenever `M(s) ≥ 1`. Therefore the naive size measure **does not** strictly drop; an infinite descending chain is not ruled out by this measure, so it fails to prove termination.

3. **Propose a fix:**  
   Use a **polynomial interpretation** (or equivalently a strongly monotone algebra) over the natural numbers:
   ```
   ⟦void⟧       = 0
   ⟦delta t⟧    = ⟦t⟧ + 1
   ⟦integrate t⟧ = ⟦t⟧
   ⟦merge t u⟧  = ⟦t⟧ + ⟦u⟧
   ⟦app t u⟧    = 0
   ⟦recΔ b s n⟧ = ⟦b⟧ + ⟦s⟧ + ⟦n⟧ + 1
   ⟦eqW t u⟧   = ⟦t⟧ + ⟦u⟧ + 1
   ```
   **Key premise:** For every rule `l → r`, we require `⟦l⟧ > ⟦r⟧` over the natural numbers (which are well‑founded).

4. **Verify the key premise explicitly:**

     - `⟦merge void t⟧ = 0 + ⟦t⟧ + 1 > ⟦t⟧`. ✔
     - `⟦merge t void⟧ = ⟦t⟧ + 0 + 1 > ⟦t⟧`. ✔
     - `⟦merge t t⟧ = 2·⟦t⟧ + 1 > ⟦t⟧` when `⟦t⟧ ≥ 0`. ✔
   - `R_rec_zero`: `⟦recΔ b s void⟧ = ⟦b⟧ + ⟦s⟧ + 0 + 1 > ⟦b⟧`. ✔

     `⟦app s (recΔ b s n)⟧ = 0`. Obviously `2 + … > 0`. ✔  
     (The duplicated `s` becomes irrelevant because `app` is interpreted as 0, killing the size increase.)
   - `R_eq_refl`: `⟦eqW a a⟧ = 2·⟦a⟧ + 1 > 0 = ⟦void⟧`. ✔

Then `⟦integrate (merge a b)⟧ = ⟦a⟧ + ⟦b⟧ + 2`, which is larger. Reverse: we need `eqW a b` > `integrate (merge a b)`. So set `⟦integrate t⟧ = ⟦t⟧` and `⟦eqW t u⟧ = ⟦t⟧ + ⟦u⟧ + 2`. Then:
     - `⟦eqW a a⟧ = 2·⟦a⟧ + 2 > 0` ✔.
     - `⟦eqW a b⟧ = ⟦a⟧ + ⟦b⟧ + 2 > ⟦a⟧ + ⟦b⟧ + 1 = ⟦integrate (merge a b)⟧`. ✔  
     Adjust `R_int_delta`: `⟦integrate (delta t)⟧ = ⟦t⟧ + 1 > 0` still holds.
   - `R_merge_void_left` etc. still hold because `⟦merge t u⟧ = ⟦t⟧ + ⟦u⟧ + 1` unchanged.

   All rules strictly decrease the interpretation.

5. **Discharge the premise:**  
   The interpretation maps every term to a natural number, and `<` on ℕ is well‑founded. No assumptions beyond the syntax and the given rewrite rules are needed; the mapping is defined by structural recursion, which is admissible in Lean. Hence the system is strongly normalising.
