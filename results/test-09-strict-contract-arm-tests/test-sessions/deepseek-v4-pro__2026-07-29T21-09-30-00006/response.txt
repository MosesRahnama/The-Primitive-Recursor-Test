Strong normalization **can** be established from the given calculus alone, without any extra axioms, side conditions or hidden assumptions. One standard proof method that works is a **polynomial interpretation** over the natural numbers. No additional structural rules are required; the interpretation below uses only the information present in the syntax and the given reduction rules.

---

### 1. Additive failure of a simple size measure (as requested)
If we try the naive measure `size` (number of constructors), the critical rule  
`recΔ b s (delta n) → app s (recΔ b s n)` duplicates the subterm `s`.  
- `size(before) = size(b) + size(s) + (1 + size(n)) + 1 = size(b) + size(s) + size(n) + 2`  
- `size(after)  = size(s) + (size(b) + size(s) + size(n) + 1) + 1 = size(b) + 2·size(s) + size(n) + 2`  

Hence `size(after) = size(before) + size(s)`.  
When `size(s) ≥ 1` this is a strict *increase*, so a simple additive measure fails.

### 2. Fix: a polynomial interpretation
Define a measure `M : Trace → ℕ` by structural recursion:

- `M(void) = 0`
- `M(delta t) = M(t) + 1`
- `M(integrate t) = M(t) + 2`
- `M(merge t u) = M(t) + M(u) + 1`
- `M(app t u) = M(t) + M(u) + 1`
- `M(recΔ b s n) = (M(s) + 2) * M(n) + M(b) + 1`
- `M(eqW a b) = 2·M(a) + 2·M(b) + 4`

The interpretation is monotone (every constructor is interpreted by a polynomial with non‑negative coefficients), and `M` is a total function into the well‑founded set `(ℕ, <)`.

### 3. Verification that every rule strictly decreases `M`
We check each rule with the interpretation above (`b`, `s`, `n`, `t`, `u`, … denote `M` of the corresponding subterm).

| Rule | `M(LHS)` | `M(RHS)` | Reason for strict decrease |
|------|-----------|-----------|----------------------------|
| `integrate (delta t) → void` | `t+1+2 = t+3` | `0` | `t+3 > 0` |
| `merge void t → t` | `0 + t + 1 = t+1` | `t` | `t+1 > t` |
| `merge t void → t` | `t + 0 + 1 = t+1` | `t` | `t+1 > t` |
| `merge t t → t` | `2t+1` | `t` | `2t+1 > t` for `t ≥ 0` |
| `recΔ b s void → b` | `(s+2)·0 + b + 1 = b+1` | `b` | `b+1 > b` |
| `recΔ b s (delta n) → app s (recΔ b s n)` | `(s+2)(n+1)+b+1 = (s+2)n + s + b + 3` | `s + ((s+2)n + b + 1) + 1 = (s+2)n + s + b + 2` | difference = 1 > 0 |
| `eqW a a → void` | `2a+2a+4 = 4a+4` | `0` | `4a+4 > 0` |
| `eqW a b → integrate (merge a b)` | `2a+2b+4` | `(a+b+1)+2 = a+b+3` | `2a+2b+4 – (a+b+3) = a+b+1 ≥ 1` |

Every rewrite step strictly lowers the natural number `M`. Because `(ℕ, <)` is well‑founded, there can be no infinite reduction sequence – the system is **strongly normalising**.

---

**Key premise for the fix:** the interpretation uses multiplication `(M(s)+2) * M(n)` so that eliminating the outer `delta` on the third argument of `recΔ` outweighs the duplication of `s`. The verification above explicitly discharges this premise for all rules. Hence no external assumptions are needed.
