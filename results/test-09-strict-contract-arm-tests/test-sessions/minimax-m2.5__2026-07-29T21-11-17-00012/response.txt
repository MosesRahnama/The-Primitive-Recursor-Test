**Assessment – Yes, strong normalisation can be proved from the given rules alone.**  

Below is a concise justification that follows the required contract.

---

### 1.  Duplication in the `recΔ` rule  

Take the naïve additive measure  

\[
M(t)\;:=\;\text{total number of constructors in }t .
\]

For the rule  

\[
\text{recΔ}\;b\;s\;(\delta n)\;\longrightarrow\;\text{app}\;s\;(\text{recΔ}\;b\;s\;n)
\]

the subterm \(S:=s\) is duplicated on the right‑hand side.  
Using the additive form \(M(\text{after})=M(\text{before})-1+M(S)\) we obtain  

\[
M(\text{after})=M(\text{before})-1+M(s).
\]

If \(s\neq\text{void}\) then \(M(s)\ge 1\), so \(M(\text{after})\ge M(\text{before})\); there is **no strict drop** – the additive measure fails.

---

### 2.  Fix – a lexicographic measure  

Define  

\[
M'(t)\;:=\;\bigl(d(t),\,e(t),\,s(t)\bigr)
\]

* \(d(t)\) – number of \(\delta\) constructors in \(t\)  
* \(e(t)\) – number of \(\text{eqW}\) constructors in \(t\)  
* \(s(t)\) – total number of constructors (the original size)

The order is lexicographic: a decrease in the first component dominates any change in the second, and a decrease in the second dominates any change in the third.

---

### 3.  Verification of the key premise  

We check every rewrite rule to see that \(M'\) decreases lexicographically.

| Rule | Effect on \((d,e,s)\) |
|------|----------------------|
| \(\text{integrate}(\delta t)\to\text{void}\) | \(d\) decreases by 1 (delta removed). |
| \(\text{merge}\,\text{void}\,t\to t\) | \(d,e\) unchanged; \(s\) decreases (merge & void disappear). |
| \(\text{merge}\,t\,\text{void}\to t\) | same as above. |
| \(\text{merge}\,t\,t\to t\) | same. |
| \(\text{recΔ}\,b\,s\,\text{void}\to b\) | \(d,e\) unchanged; \(s\) decreases (recΔ & void disappear). |
| \(\text{recΔ}\,b\,s(\delta n)\to\text{app}\,s(\text{recΔ}\,b\,s\,n)\) | \(d\) decreases by 1 (the leading \(\delta\) is removed). |
| \(\text{eqW}\,a\,a\to\text{void}\) | \(e\) decreases by 1 (eqW disappears). |
| \(\text{eqW}\,a\,b\to\text{integrate}(\text{merge}\,a\,b)\) | \(e\) decreases by 1. |

In every case either \(d\) drops, or if \(d\) stays the same then \(e\) drops, or if both \(d\) and \(e\) stay the same then \(s\) drops. Hence each one‑step reduction makes \(M'\) strictly smaller in the lexicographic order.

Because the lexicographic product of well‑orderings is well‑founded, there can be no infinite rewrite sequence. Therefore the calculus is **strongly normalising**.

---

### 4.  Conclusion  

The duplication exhibited by the `recΔ` rule blocks a simple additive size‑measure, but a refined lexicographic measure (delta‑count, eqW‑count, size) restores decrease for every rule. No extra axioms, side‑conditions, or hidden assumptions are required; the proof uses only the given syntax and rewrite rules. Hence strong normalisation is provable from the calculus alone.
