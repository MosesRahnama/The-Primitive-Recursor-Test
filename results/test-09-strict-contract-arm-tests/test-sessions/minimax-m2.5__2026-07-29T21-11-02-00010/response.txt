**Raw assessment:** Yes – strong normalisation can be proved from the calculus alone, using only the syntax and the eight rewrite rules. No extra axioms or side‑conditions are required.

---

### 1.  The offending duplication (contract step)

The only rule that *duplicates* a subterm in the right‑hand side is  

```
R_rec_succ :  recΔ b s (delta n) → app s (recΔ b s n)
```

The term `s` occurs twice in the result (once as the argument of `app` and once inside the recursive call).  
If we try a purely additive measure such as the total number of constructors,
```
M(after) = M(before) – 1 + M(s)
```
because the left‑hand side loses the `delta` constructor (‑1) but gains an extra copy of `s`.  
When `M(s) ≥ 1` the inequality `M(after) < M(before)` is **not** guaranteed, so the naive additive measure fails.

---

### 2.  Fix – a lexicographic measure

Define four primitive counts for any term `t`:

* `δ(t)` – number of `delta` constructors occurring in `t`;
* `ρ(t)` – number of `recΔ` constructors in `t`;
* `ε(t)` – number of `eqW` constructors in `t`;
* `μ(t)` – number of `merge` constructors in `t`.

Set  
```
M(t) := ( δ(t) , ρ(t) , ε(t) , μ(t) )   (lexicographic order)
```
All four components are natural numbers, and lexicographic order is well‑founded.

---

### 3.  Key premise for the duplicated rule

For `R_rec_succ` we must check that `δ` strictly decreases.

*Left‑hand side:* `recΔ b s (delta n)` contains **exactly one** `delta` – the one wrapping `n`.  
*Right‑hand side:* `app s (recΔ b s n)` contains **no** `delta` in the third argument; any `delta` that may appear in `s` or `n` was already present on the left, so the total count drops by at least 1.

Hence the premise “`δ` decreases” holds for every `b, s, n`.

---

### 4.  Verification that every rule reduces `M`

| Rule | Effect on `(δ,ρ,ε,μ)` |
|------|----------------------|
| `R_int_delta` : `integrate (delta t) → void` | `δ` drops (the `delta` disappears). |
| `R_merge_void_left` : `merge void t → t` | `μ` drops (the leading `merge` is removed). |
| `R_merge_void_right` : `merge t void → t` | `μ` drops. |
| `R_merge_cancel` : `merge t t → t` | If `δ(t)>0` then `δ` drops; otherwise `μ` drops. |
| `R_rec_zero` : `recΔ b s void → b` | `ρ` drops (the `recΔ` disappears). |
| `R_rec_succ` : `recΔ b s (delta n) → app s (recΔ b s n)` | `δ` drops (the outermost `delta` is removed). |
| `R_eq_refl` : `eqW a a → void` | If `δ(a)>0` then `δ` drops; otherwise `ε` drops (the `eqW` disappears). |
| `R_eq_diff` : `eqW a b → integrate (merge a b)` | `ε` drops (the `eqW` is eliminated); the new `merge` raises `μ` **after** `ε` has decreased, so the lexicographic order is still respected. |

In every case the first non‑equal component of the 4‑tuple decreases, so the whole tuple decreases lexicographically. Consequently no infinite rewrite sequence can exist.

---

### 5.  Conclusion

The measure `M` is defined entirely in terms of the syntax of the calculus; no structural axioms or hidden assumptions are needed. Since each rewrite step strictly reduces `M`, the system is **strongly normalising**.

Thus, strong normalization can be established from the presented calculus alone.
