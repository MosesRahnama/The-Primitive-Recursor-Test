**Assessment:** Yes – strong normalisation can be proved from the given rules alone.

**Reasoning:** Define a lex‑ordered measure  

\[
M(t)=\big(e(t),\;d(t),\;|t|\big)
\]

where  

* \(e(t)\) = number of `eqW` constructors in \(t\),  
* \(d(t)\) = number of `delta` constructors in \(t\),  
* \(|t|\) = total size (number of constructors).

Each rewrite rule reduces this triple:

| Rule | Effect on \((e,d,|·|)\) |
|------|------------------------|
| `R_int_delta` | \(d\) drops (the `delta` inside `integrate` disappears) |
| `R_merge_void_left/right`, `R_merge_cancel` | \(|·|\) drops, \(e,d\) unchanged |
| `R_rec_zero` | \(|·|\) drops |
| `R_rec_succ` | \(d\) drops (the leading `delta` in the argument is removed) |
| `R_eq_refl` | \(e\) drops (and \(|·|\) drops) |
| `R_eq_diff` | \(e\) drops (the `eqW` disappears) – the increase in size is irrelevant because the first component already decreases |

Thus every one‑step reduction makes \(M\) strictly smaller in the lexicographic order, guaranteeing that no infinite reduction sequence exists. No additional axioms, structural rules, or side‑conditions are required; standard well‑founded ordering arguments suffice. Hence the system is strongly normalising.
