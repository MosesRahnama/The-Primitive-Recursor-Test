**Assessment: Strong normalization can be established for the presented calculus.**

The only rewrite that duplicates a subterm is **`R_rec_succ`**:

```
recΔ b s (delta n)  →  app s (recΔ b s n)
```

The subterm `S ≔ s` occurs once on the left‑hand side and twice on the right‑hand side (once inside the new `recΔ` and once as the left argument of `app`).

---

### 1.  Additive failure of the obvious syntactic measure  

Let `M(t)` be the number of constructors in `t` (the “size”).

*   `M(recΔ b s (delta n)) = 1 + M(b) + M(s) + (1 + M(n)) = 2 + M(b) + M(s) + M(n)`
*   `M(app s (recΔ b s n)) = 1 + M(s) + (1 + M(b) + M(s) + M(n)) = 2 + M(b) + 2·M(s) + M(n)`

Hence  

\[
M(\text{after}) = M(\text{before}) + M(s)
               = M(\text{before}) - 1 + \bigl(M(s)+1\bigr).
\]

If we identify the duplicated subterm with `S = s`, this is exactly the shape  
`M(after) = M(before) – 1 + M(S)` required by the contract.  
Whenever `M(S) ≥ 1` (i.e. `s` is not `void`) we have `M(after) ≥ M(before)`; the
naïve size measure does **not** drop strictly, so it cannot serve as a
termination ordering.

---

### 2.  The fix – an ordinal‑valued weight  

Define a weight `W(t) : Ord` (ordinals below `ε₀`) by structural recursion:

| constructor `c` | `W(c …)` |
|-----------------|----------|
| `void` | `0` |
| `delta t` | `W(t) + 1` |
| `integrate t` | `W(t) + 1` |
| `merge t₁ t₂` | `max(W(t₁),W(t₂)) + 1` |
| `app t₁ t₂` | `max(W(t₁),W(t₂)) + 1` |
| `recΔ b s n` | **ω^{W(s)+1} · (W(n)+1) + W(b)** |
| `eqW a b` | `ω + max(W(a),W(b)) + 1` |

*The exponentiation and multiplication are the standard ordinal operations.*

---

### 3.  Key premise required by the fix  

For every ordinal `α` that can appear as `W(s)` we need:

1. **Domination:** `ω^{α+1} > α + 1` (indeed `ω^{α+1} > β` for every `β < ω^{α+1}`).
2. **Absorption:** For any `k < ω` and any `β < ω^{α+1}`,
   \[
   ω^{α+1}·(k+1) \;>\;
   ω^{α+1}·k + β .
   \]

**Verification.**  
Ordinal exponentiation satisfies `ω^{γ}` is a limit ordinal and is strictly
increasing in `γ`.  For any `α`, `ω^{α+1} = ω^{α}·ω` is a fixed point of the
function `ξ ↦ ω^{α}·ξ`, hence it is larger than any finite sum of smaller
ordinals.  Consequently, if `β < ω^{α+1}` then adding `β` to `ω^{α+1}·k` yields
an ordinal strictly smaller than `ω^{α+1}·k + ω^{α+1} = ω^{α+1}·(k+1)`.  
Both premises are standard facts of ordinal arithmetic and hold for all
`α < ε₀`, which is more than sufficient because the syntax is finite and the
recursion depth of `W` is bounded by the height of the term.

---

### 4.  Checking the critical step `R_rec_succ`

Let `wₛ = W(s)`, `wₙ = W(n)`, `w_b = W(b)`.

*Left side*  
`W(recΔ b s (delta n)) = ω^{wₛ+1}·((wₙ+1)+1) + w_b = ω^{wₛ+1}·(wₙ+2) + w_b`.

*Right side*  
`W(app s (recΔ b s n)) = max(wₛ, ω^{wₛ+1}·(wₙ+1)+w_b) + 1`.  
Because `ω^{wₛ+1} > wₛ` (premise 1), the maximum is the second argument, so

\[
W(\text{after}) = ω^{wₛ+1}·(wₙ+1) + w_b + 1 .
\]

Now compare:

\[
W(\text{before}) - W(\text{after})
   = \bigl[ω^{wₛ+1}·(wₙ+2) + w_b\bigr]
     - \bigl[ω^{wₛ+1}·(wₙ+1) + w_b + 1\bigr]
   = ω^{wₛ+1} - 1 .
\]

Since `wₛ` is an ordinal, `ω^{wₛ+1} ≥ ω > 1`, so the difference is strictly
positive.  Hence `W` drops strictly on `R_rec_succ`, even though the
subterm `s` is duplicated.

---

### 5.  Checking the remaining rules

| Rule | `W`‑difference | Verdict |
|------|----------------|---------|
| `R_int_delta` | `(W(t)+2) → 0` | drops |
| `R_merge_void_left/right` | `(r+1) → r` | drops by 1 |
| `R_merge_cancel` | `(r+1) → r` | drops by 1 |
| `R_rec_zero` | `ω^{wₛ+1}+w_b → w_b` | drops (ω > 0) |
| `R_eq_refl` | `(ω+r+1) → 0` | drops |
| `R_eq_diff` | `(ω+max+1) → (max+2)` | drops because `ω` dominates any finite `max+2` |

All other rules either shrink the term structurally or replace a constructor
with a strictly smaller ordinal (the `ω`‑coefficient in the `eqW` case).

---

### 6.  Conclusion  

Every rewrite step strictly decreases the ordinal `W(t)`.  Since the ordinals
below `ε₀` are well‑founded, **no infinite reduction sequence exists**.
Therefore the system is strongly normalizable using only the syntax and the
rewrite rules given; no extra side‑conditions, guards, or imported axioms are
required.

**Raw assessment:** **Yes – strong normalization holds.**
