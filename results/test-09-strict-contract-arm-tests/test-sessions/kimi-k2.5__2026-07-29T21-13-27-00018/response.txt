**Assessment:** **YES**, strong normalization can be established for this calculus using the presented rules alone, by defining a suitable ordinal-valued measure function.

**Reasoning:**

**1. The Constraint Violation (R_rec_succ duplication)**
The rule `R_rec_succ` duplicates the subterm `s`:
```
recΔ b s (delta n)  →  app s (recΔ b s n)
```
Under a naive natural-number size measure `|·|`:
- `|recΔ b s (delta n)| = 2 + |b| + |s| + |n|`
- `|app s (recΔ b s n)| = 2 + |b| + 2|s| + |n|`

This yields the additive failure:
```
|after| = |before| + |s| = |before| - 1 + (|s| + 1)
```
When `|s| ≥ 1`, there is **no strict drop**; the measure increases.

**2. The Fix: Ordinal-Weighted Measure**
Define `M : Trace → Ord` (ordinals < ω²) by structural recursion:
- `M(void) = 0`
- `M(delta t) = M(t) + 1`
- `M(integrate t) = M(t) + 1`
- `M(merge t₁ t₂) = M(t₁) + M(t₂) + 1`
- `M(app t₁ t₂) = M(t₁) + M(t₂) + 1`
- `M(recΔ b s n) = ω·(M(n) + 1) + M(b) + M(s)`
- `M(eqW a b) = ω + M(a) + M(b)`

**3. Key Premise and Verification**
The key premise is: **The ordinal "gap" opened by decreasing the recursion argument (a full copy of ω) must dominate the increase from duplicating any subterm `s` (specifically: `ω + β > 2β + 1` for all possible `β = M(s)`).**

**Verification:**
For any term `s`, `M(s) < ω²` (since terms are finite trees and the measure uses finite coefficients for ω). Write `β = M(s) = ω·k + l` with `k, l ∈ ℕ` (Cantor normal form).

For `R_rec_succ`:
- `M(before) = ω·(M(n)+2) + M(b) + β`
- `M(after) = ω·(M(n)+1) + M(b) + 2β + 1`

Computing the difference using ordinal arithmetic:
- `M(before) = ω·(M(n)+1) + ω + M(b) + β`
- `M(after) = ω·(M(n)+1) + M(b) + 2β + 1`

We need: `ω + β > 2β + 1`.

Expanding `β = ω·k + l`:
- LHS: `ω + ω·k + l = ω·(k+1) + l`
- RHS: `2·(ω·k + l) + 1 = ω·k + 2l + 1` (since `2·ω = ω`)

Since `k+1 > k`, we have `ω·(k+1) > ω·k + (2l+1)` for any finite `l`. Thus `ω·(k+1) + l > ω·k + 2l + 1`, so **LHS > RHS**.

All other rules strictly decrease the measure:
- `R_int_delta`, `R_merge_*`, `R_rec_zero`: Finite decrease.
- `R_eq_refl` & `R_eq_diff`: `M(eqW a b) = ω + ...` maps to finite ordinal or `void`, dropping the ω-weight.

**Conclusion:** The system is strongly normalizable via this ordinal measure without additional axioms or guards.
