Raw assessment: **Yes, strong normalization can be established from the presented calculus alone.**

Reason: as written, `Step` contains only the listed root reductions and is **not context-closed**. There are no congruence rules such as “if `t → t'` then `integrate t → integrate t'`.” So reductions only happen at the top of the term.

One can define a simple natural-number measure `μ` on `Trace` by structural recursion, for example:

- `μ(void) = μ(delta _) = μ(app _ _) = 0`
- `μ(integrate (delta _)) = 1`, and `μ(integrate _) = 0` otherwise
- `μ(merge a b) = if a = b then μ(a)+1 else if a = void then μ(b)+1 else if b = void then μ(a)+1 else 0`
- `μ(recΔ b s void) = μ(b)+1`
- `μ(recΔ b s (delta _)) = 1`
- `μ(recΔ _ _ _) = 0`
- `μ(eqW _ _) = 1`

Then every `Step` rule strictly decreases `μ`:

- `integrate (delta t) → void`: `1 > 0`
- `merge void t → t`, `merge t void → t`, `merge t t → t`: left has measure `μ(t)+1` or `1`, right has measure `μ(t)`
- `recΔ b s void → b`: `μ(b)+1 > μ(b)`
- `recΔ b s (delta n) → app s (recΔ b s n)`: left has measure `1`, right has measure `0`
- `eqW a a → void`: `1 > 0`
- `eqW a b → integrate (merge a b)`: left has measure `1`, right has measure `0` because `merge a b` is not `delta _`

Thus no infinite reduction sequence can exist, since that would give an infinite descending sequence of natural numbers. No extra rewrite rules, guards, congruence assumptions, or external structural axioms are needed.
