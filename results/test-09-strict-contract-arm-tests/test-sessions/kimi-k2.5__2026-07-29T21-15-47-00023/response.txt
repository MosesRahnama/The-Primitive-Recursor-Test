**Assessment:** Yes, strong normalization can be established from the presented calculus alone.

**Reasoning:**

The system is first-order and lacks binding constructs, allowing us to attempt a structural termination measure. A standard term-size measure fails for rule `R_rec_succ` due to subterm duplication.

---

**Step 1: Identify Additive Failure (Duplication)**

In rule `R_rec_succ`:
```
recΔ b s (delta n)  →  app s (recΔ b s n)
```
The subterm **S = s** is duplicated: it appears once in the left-hand side (as the second argument to `recΔ`) and twice in the right-hand side (once as the first argument to `app`, and once preserved in the recursive call `recΔ b s n`).

Let `M(t)` be the standard syntactic size (number of constructors):
- `M(recΔ b s (delta n)) = 1 + M(b) + M(s) + 1 + M(n) = 2 + M(b) + M(s) + M(n)`
- `M(app s (recΔ b s n)) = 1 + M(s) + (1 + M(b) + M(s) + M(n)) = 2 + M(b) + 2*M(s) + M(n)`

Thus:
```
M(after) = M(before) + M(s)
```
Since `M(s) ≥ 1` for any non-trivial term, the measure does not strictly drop; it increases by the size of the duplicated subterm `s`. This violates strong normalization when `s` is large.

---

**Step 2: Proposed Fix (Weighted Measure)**

We define a well-founded measure `w : Trace → ℕ` by structural recursion:

| Constructor | Weight `w` |
|-------------|------------|
| `void` | 0 |
| `delta t` | 1 + `w(t)` |
| `integrate t` | `w(t)` |
| `merge t₁ t₂` | 1 + `w(t₁)` + `w(t₂)` |
| `app t₁ t₂` | 1 + `w(t₁)` + `w(t₂)` |
| `recΔ b s n` | **2^(w(n)+1) × (1 + w(b) + w(s))** |
| `eqW a b` | 2 + `w(a)` + `w(b)` |

---

**Step 3: Verify Key Premise for the Fix**

The critical check is for `R_rec_succ`. We must verify that the duplication of `s` is offset by the exponential decrease in the `n` position.

**Premise:** `w(recΔ b s (delta n)) > w(app s (recΔ b s n))`

**Verification:**
Let `K = 1 + w(b) + w(s)`.

- LHS: `w(recΔ b s (delta n)) = 2^(w(delta n)+1) × K = 2^(1+w(n)+1) × K = 2^(w(n)+2) × K`
- RHS: `w(app s (recΔ b s n)) = 1 + w(s) + w(recΔ b s n) = 1 + w(s) + 2^(w(n)+1) × K`

The inequality becomes:
```
2^(w(n)+2) × K  >  1 + w(s) + 2^(w(n)+1) × K
```
Subtracting the common term:
```
2^(w(n)+1) × K  >  1 + w(s)
```

This holds because:
1. `K = 1 + w(b) + w(s) ≥ 1 + w(s)`
2. `2^(w(n)+1) ≥ 2` for all `n` (since `w(n) ≥ 0`)

Therefore: `2^(w(n)+1) × K ≥ 2 × (1 + w(s)) = 2 + 2*w(s) > 1 + w(s)` for all `w(s) ≥ 0`.

The key premise is discharged.

---

**Step 4: Verify All Other Rules**

- **`R_int_delta`**: `w(integrate (delta t)) = w(delta t) = 1 + w(t) > 0 = w(void)`.
- **`R_merge_void_left/right`**: `w(merge void t) = 1 + 0 + w(t) = 1 + w(t) > w(t)`.
- **`R_merge_cancel`**: `w(merge t t) = 1 + 2*w(t) > w(t)`.
- **`R_rec_zero`**: `w(recΔ b s void) = 2^(0+1) × (1 + w(b) + w(s)) = 2 + 2*w(b) + 2*w(s) > w(b)`.
- **`R_eq_refl`**: `w(eqW a a) = 2 + 2*w(a) > 0 = w(void)`.
- **`R_eq_diff`**: `w(eqW a b) = 2 + w(a) + w(b) > 1 + w(a) + w(b) = w(merge a b) = w(integrate (merge a b))`.

All rules strictly decrease the measure `w`, which maps into the well-founded set `ℕ`. Therefore, no infinite reduction sequence exists.

**Conclusion:** The calculus is strongly normalizable without additional axioms or guards.
