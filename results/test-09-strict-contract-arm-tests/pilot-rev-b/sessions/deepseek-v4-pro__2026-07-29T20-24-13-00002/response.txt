The duplication step `R_rec_succ` copies the subterm `s`, which can cause a naive size measure to increase. We show the failure, then propose a fix that establishes strong normalization without external assumptions.

**Duplication failure**  
Take `M` = total number of constructors (size).  
For `recΔ b s (delta n) → app s (recΔ b s n)`:
- `M(before) = 2 + M(b) + M(s) + M(n)`  
- `M(after)  = 2 + M(b) + 2·M(s) + M(n)`  

Hence `M(after) = M(before) + M(s)`. Strict decrease fails when `M(s) ≥ 1`.  
(Even if we subtract 1 from the equation, the increase remains positive for nonempty `s`.)

**Fix: lexicographic measure that exploits constructor creation properties**  
Define a measure `⟨ eq_count, delta_count, size ⟩` with lexicographic order:
- `eq_count` = number of `eqW` nodes,
- `delta_count` = number of `delta` nodes,
- `size` = total nodes.

**Key premise for the fix**  
No reduction rule **ever** creates a new `eqW` node or a new `delta` node.  
*Verification by inspection of all rules:*  

| Rule | `eqW` change | `delta` change |
|------|--------------|---------------|
| `integrate(delta t) → void` | 0 | −1 |
| `merge void t → t` | 0 | 0 (or − if duplicates) |
| `merge t void → t` | 0 | 0 |
| `merge t t → t` | 0 | − (if `t` contains `delta`) |
| `recΔ b s void → b` | 0 | 0 (or less) |
| `recΔ b s (delta n) → app s (recΔ b s n)` | 0 | **−1** |
| `eqW a a → void` | **−1** | 0 (or less) |
| `eqW a b → integrate(merge a b)` (a ≠ b) | **−1** | 0 |

Every reduction either decreases `eq_count`, or (if `eq_count` unchanged) decreases `delta_count`, or (if both unchanged) decreases `size`. The duplicated `s` may increase `size`, but the `delta` node removed from the third argument of `recΔ` guarantees `delta_count` drops. Lexicographic descent then holds.

**Conclusion**  
Strong normalization **can** be established purely from the given rewrite rules, without external structural axioms. The duplication is harmless because the recursor reduces the number of `delta` constructors, which are never generated by any rule. The lexicographic measure above provides a termination proof that stays within the calculus.
