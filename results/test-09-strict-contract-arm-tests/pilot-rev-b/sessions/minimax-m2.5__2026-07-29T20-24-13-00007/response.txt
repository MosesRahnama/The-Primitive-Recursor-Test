**Raw assessment:** Yes – strong normalisation can be proved using only the given rewrite rules.

**Why it works:**  
Assign a non‑negative integer weight to each constructor (the usual “weight‑function” method). For example  

```
w(void)   = 0
w(delta)  = 3
w(app)    = 1
w(s)      = 1
w(recΔ)   = 4
w(merge)  = 1
w(integrate)=1
w(eqW)    = 5
```

(Any positive numbers that satisfy the inequalities below will do.)  
The weight of a term is the sum of the weights of the constructor symbols that occur in it.

Now check every rewrite rule:

* **R_int_delta** `integrate (delta t) → void`  
  LHS weight = w(integrate)+w(delta)+w(t) > 0 = RHS weight.

* **R_merge_void_left/right** `merge void t → t` and `merge t void → t`  
  LHS weight = w(merge)+w(t) > w(t) (since w(merge)>0).

* **R_merge_cancel** `merge t t → t`  
  LHS weight = w(merge)+2·w(t) > w(t) (again because w(merge)>0).

* **R_rec_zero** `recΔ b s void → b`  
  LHS weight = w(recΔ)+w(b)+w(s)+w(void) > w(b) (since w(recΔ),w(s)>0).

* **R_rec_succ** `recΔ b s (delta n) → app s (recΔ b s n)`  
  LHS weight = w(recΔ)+w(b)+w(s)+w(delta)+w(n).  
  RHS weight = w(app)+w(s)+w(recΔ)+w(b)+w(s)+w(n) = w(app)+w(recΔ)+w(b)+w(n)+2·w(s).  
  The difference is  

  ```
  w(delta) – w(app) – w(s)  = 3 – 1 – 1 = 1 > 0 .
  ```

  Hence the RHS is strictly lighter, despite the duplication of the `recΔ` sub‑term; the duplicated term’s argument `n` is smaller (one fewer `delta`), so the measure still decreases.

* **R_eq_refl** `eqW a a → void`  
  LHS weight = w(eqW)+2·w(a) > 0 = RHS weight.

* **R_eq_diff** `eqW a b → integrate (merge a b)`  
  LHS weight = w(eqW)+w(a)+w(b).  
  RHS weight = w(integrate)+w(merge)+w(a)+w(b).  
  Since w(eqW) > w(integrate)+w(merge) (5 > 2), the LHS is heavier.

Thus **every rewrite step reduces the total weight**. The weight is a natural number, so any infinite descending chain would be impossible; consequently the rewrite system is strongly normalising.

**Duplication handling (contract):**  
The only rule that duplicates a sub‑term is `R_rec_succ`. The additive change is  

```
M(after) = M(before) – w(delta) + w(app) .
```

Because we chose `w(delta) = 3` and `w(app) = 1` (and `w(s)=1`), the RHS is lighter: `M(after) = M(before) – 1`. The key premise required is the existence of a weight assignment that satisfies the inequality `w(delta) > w(app) + w(s)`. We have exhibited such an assignment, so the premise holds; no “constraint blocker’’ occurs.

**Conclusion:** Strong normalisation follows from the calculus alone, using a standard weight‑function (or reduction‑pair) argument, without any extra structural axioms or side conditions.
