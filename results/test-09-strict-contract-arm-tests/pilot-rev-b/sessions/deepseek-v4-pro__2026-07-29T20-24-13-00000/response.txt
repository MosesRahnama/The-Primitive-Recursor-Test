**Assessment: Yes, strong normalization can be established from the given calculus alone, without extra axioms or assumptions.**  

The system is a set of top‑level rewrite rules (no congruence), so any reduction sequence is finite because every term can only take finitely many steps. The only potential obstacle is the duplication of subterm `s` in the rule  
`recΔ b s (delta n) → app s (recΔ b s n)`, which causes a naïve size measure to increase.

---

### 1. Duplication step – additive failure

Let `M(t)` be the size (number of constructors) of term `t`.  

Before the step:  
`M(recΔ b s (delta n)) = 1 + |b| + |s| + (1 + |n|) = |b| + |s| + |n| + 2`  

After the step:  
`M(app s (recΔ b s n)) = 1 + |s| + (1 + |b| + |s| + |n|) = |b| + 2|s| + |n| + 2`  

Hence  
`M(after) = M(before) + M(s)`.  

Since `M(s) ≥ 1` for any (non‑void) `s`, the measure does **not** strictly drop; it increases.  
Thus a simple size measure fails to prove termination directly.

---

### 2. Proposed fix

Use an induction on the term size together with a case distinction:  

- If a term reduces by a rule that **strictly decreases size** (all rules except the two below), the resulting term is smaller, so by the induction hypothesis all its reduction sequences are finite.  
- For the two rules that do **not** decrease size:  

  * `eqW a b → integrate (merge a b)`  
  * `recΔ b s (delta n) → app s (recΔ b s n)`  

  the key premise is that **the right‑hand side is irreducible** (no top‑level rule applies to it). Once we check that premise, the sequence stops immediately after that step, so it remains finite regardless of the size increase.

### 3. Verifying the key premise

- **`integrate (merge a b)`** can only be reduced by `R_int_delta`, which requires an argument of the form `delta t`. The head constructor of `merge a b` is `merge`, not `delta`, hence no rule applies.  
- **`app s (recΔ b s n)`** has head constructor `app`. There is no rewrite rule for `app` in the calculus, so it is irreducible.

Both cases are normal forms; therefore the size increase cannot spawn an infinite reduction.

### 4. Conclusion

Because every reduction either moves to a strictly smaller term (where SN holds by induction) or reaches a normal form immediately, the system is strongly normalizing. No extra rewrite rules, guards, or external axioms are needed—the proof uses only the presented syntax and rules.
