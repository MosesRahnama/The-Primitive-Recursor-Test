# Proof Skeleton for Remaining Cases

Here are proof skeletons for the three remaining cases:

```lean
-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    simp [mu]
    -- Strategy: Show that the exponent omega^5 * (mu(n) + 1) in the LHS
    -- dominates all terms on the RHS
    have h_delta_large : omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + 6 
                         > mu n + mu s + 6 := by
      omega
    have h_exp_dominates : omega0 ^ (omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + 6)
                         > omega0 ^ (3 : Ordinal) * (mu s + 1) 
                           + omega0 ^ (2 : Ordinal) * (omega0 ^ (mu n + mu s + 6) + omega0 * (mu b + 1) + 2) := by
      apply Ordinal.opow_lt_opow_left omega0_pos
      exact h_delta_large
    linarith [h_exp_dominates]

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    simp [mu]
    -- Strategy: Simple positivity - both terms on RHS are positive
    have h1 : (0 : Ordinal) < mu a + mu a + 9 := by omega
    have h2 : (0 : Ordinal) < omega0 ^ (mu a + mu a + 9) := 
      Ordinal.opow_pos _ omega0_pos
    omega

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    simp [mu]
    -- Strategy: Show that omega^(mu a + mu b + 9) dominates 
    -- omega^4 * (omega^3 * (mu a + 1) + omega^2 * (mu b + 1) + 2)
    -- by comparing exponents
    have h_exp_compare : mu a + mu b + 9 > (4 : Ordinal) := by omega
    have h_base_bound : omega0 ^ (3 : Ordinal) * (mu a + 1) + omega0 ^ (2 : Ordinal) * (mu b + 1) + 2
                      < omega0 ^ (mu a + mu b + 9) := by
      calc omega0 ^ (3 : Ordinal) * (mu a + 1) + omega0 ^ (2 : Ordinal) * (mu b + 1) + 2
        _ < omega0 ^ (mu a + mu b + 4) := by
          -- The sum is bounded by a tower much smaller than omega^(mu a + mu b + 9)
          apply Ordinal.add_lt_of_lt
          apply Ordinal.opow_lt_opow_left omega0_pos
          omega
        _ < omega0 ^ (mu a + mu b + 9) := by
          apply Ordinal.opow_lt_opow_left omega0_pos
          omega
    calc omega0 ^ (4 : Ordinal) * (omega0 ^ (3 : Ordinal) * (mu a + 1) + omega0 ^ (2 : Ordinal) * (mu b + 1) + 2) + 1
      _ < omega0 ^ (4 : Ordinal) * omega0 ^ (mu a + mu b + 9) := by omega
      _ = omega0 ^ (4 + mu a + mu b + 9) := by rw [← opow_add]
      _ < omega0 ^ (mu a + mu b + 9) := by
        apply Ordinal.opow_lt_opow_left omega0_pos; omega
```

## Key Insights

1. **R_rec_succ**: The exponent on the LHS contains `omega^5 * (mu n + 1)`, which grows much faster than anything appearing in the RHS measure, making the LHS dominate.

2. **R_eq_refl**: This is straightforward—both arguments are positive ordinals, so their sum plus 9 is positive, and `omega^(positive) + 1` is positive.

3. **R_eq_diff**: The RHS exponent `mu a + mu b + 9` is much larger than the exponent 4 on the LHS, and the base term is absorbed. The ordinal arithmetic establishes that exponent comparison dominates the inequality.
