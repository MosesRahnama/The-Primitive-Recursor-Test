A complete proof cannot be given for the file as written: the `R_rec_succ` inequality is false for the current definition of `mu`. The two `eqW` cases are provable, but the recursive-successor case needs a different measure.

## Counterexample to `R_rec_succ`

Take
```lean
b := void
n := void
s := eqW void void
```
and write `Ω := omega0`. Then
\[
\mu(s)=Ω^9+1,\qquad \mu(\delta\,void)=Ω^5+1.
\]

Let
\[
F:=Ω^9+7.
\]
Because the smaller prefix is absorbed by `Ω^9`,
\[
(Ω^5+1)+(Ω^9+1)+6=Ω^9+7=F.
\]

Consequently, the source has measure
\[
\mu(\operatorname{recDelta}\ void\ s\ (\delta void))
  = Ω^F+Ω+1.
\]

The inner recursive call has the same leading exponent:
\[
\mu(\operatorname{recDelta}\ void\ s\ void)
  = Ω^F+Ω+1.
\]

For the target,
\[
\begin{aligned}
\mu(\operatorname{app}\ s\ (\operatorname{recDelta}\ void\ s\ void))
={}&Ω^3(Ω^9+2)\\
 &+Ω^2(Ω^F+Ω+2)+1.
\end{aligned}
\]
Since `2 + F = F`,
\[
Ω^2\cdot Ω^F=Ω^{2+F}=Ω^F.
\]
The first app summand is absorbed by this much larger term, giving
\[
\mu(\text{target})=Ω^F+Ω^3+Ω^2\cdot2+1,
\]
which is strictly greater than
\[
Ω^F+Ω+1=\mu(\text{source}).
\]

Thus this instance of `R_rec_succ` increases `mu`. The issue is noncommutativity of ordinal addition: in
```lean
mu n + mu s + 6
```
the contribution from `mu n` can be absorbed by a sufficiently large `mu s`.

A likely repair is to reverse the order in the recursion exponent:
```lean
omega0 ^ (mu s + mu n + 6)
```
so the source contains `mu s + mu (delta n) + 6`, or to use natural/Hessenberg sum. All rule cases would then need to be rechecked.

## Skeleton for `R_eq_refl`

This case is immediate from the final `+ 1`:

```lean
| _, _, Step.R_eq_refl a => by
    simp [mu]
    exact add_pos_right _ one_pos
```

If simplification leaves a slightly different positivity goal, the same pattern used in `R_int_delta` works:

```lean
| _, _, Step.R_eq_refl a => by
    simp [mu]
    exact Ordinal.pos_iff_ne_zero.mpr (by
      apply ne_of_gt
      exact add_pos_right _ one_pos)
```

## Skeleton for `R_eq_diff`

After unfolding, set
```lean
A := mu a
B := mu b
E := A + B + 9
```
and prove the core inequality
\[
Ω^4\bigl(Ω^3(A+1)+Ω^2(B+1)+2\bigr)<Ω^E.
\]

Distributing the left multiplication reduces the left side to
\[
Ω^7(A+1)+Ω^6(B+1)+Ω^4\cdot2.
\]

A useful auxiliary lemma is:

```lean

    omega0 ^ (k : Ordinal) * (x + 1)
      < omega0 ^ (x + (k + 1 : ℕ)) := by
  -- Prove using monotonicity of omega exponentiation,
  -- multiplication of omega powers, and principal-ordinal lemmas.
  ...
```

It gives
\[
Ω^7(A+1)<Ω^{A+8},\qquad
Ω^6(B+1)<Ω^{B+7}.
\]

The required exponent comparisons are
\[
A+8<A+B+9,\qquad
B+7<A+B+9,\qquad
5<A+B+9.
\]
Hence all three summands are below `Ω^E`. Since `Ω^E` is additively principal and `E > 0`, their finite sum is also below `Ω^E`.

The resulting Lean-shaped skeleton is:

```lean
| _, _, Step.R_eq_diff a b => by
    simp [mu]

    let A : Ordinal := mu a
    let B : Ordinal := mu b
    let E : Ordinal := A + B + 9

    have hE : 0 < E := by
      dsimp [E]
      exact add_pos_right _ (by decide)   -- or prove 0 < 9 explicitly

    have hAexp : A + 8 < E := by
      dsimp [E]
      -- Rewrite A + B + 9 as A + (B + 9).
      -- Use 8 < B + 9 and strict monotonicity in the right argument.
      ...

    have hBexp : B + 7 < E := by
      dsimp [E]
      -- First B ≤ A + B, then:
      -- B + 7 ≤ (A + B) + 7 < (A + B) + 9.
      ...

    have hconst : (5 : Ordinal) < E := by
      dsimp [E]
      -- 5 < 9 ≤ A + B + 9.
      ...

    have hA :
        omega0 ^ 7 * (A + 1) < omega0 ^ E := by
      refine lt_trans (finiteTower_mul_lt A 7) ?_
      exact opow_lt_opow_right omega0_pos hAexp
      -- Exact monotonicity lemma name may differ.

    have hB :
        omega0 ^ 6 * (B + 1) < omega0 ^ E := by
      refine lt_trans (finiteTower_mul_lt B 6) ?_
      exact opow_lt_opow_right omega0_pos hBexp

    have hsmall :
        omega0 ^ 4 * 2 < omega0 ^ E := by
      -- Bound omega^4 * 2 by omega^5, then use hconst.
      ...

    have hcore :
        omega0 ^ 4 *
            (omega0 ^ 3 * (A + 1) +
             omega0 ^ 2 * (B + 1) + 2)
          < omega0 ^ E := by
      -- Rewrite using mul_add and associativity:
      --
      -- Ω^4 * (...) =
      --   Ω^7 * (A + 1) + Ω^6 * (B + 1) + Ω^4 * 2.
      --
      -- Apply additive-principality of Ω^E repeatedly to hA, hB,
      -- and hsmall.
      ...

    change
      omega0 ^ 4 *
          (omega0 ^ 3 * (A + 1) +
           omega0 ^ 2 * (B + 1) + 1 + 1) + 1
        < omega0 ^ E + 1

    -- Normalize `(X + 1) + 1` to `X + 2`, use hcore, and preserve
    -- strictness when adding the final successor.
    simpa [A, B, E, add_assoc] using add_lt_add_right hcore 1
```

The exact names and argument order of the ordinal-principal and exponent-monotonicity lemmas may require adjustment, but this is the required arithmetic structure. No analogous skeleton can close `R_rec_succ` without first changing the measure.
