## Case 1: `Step.R_eq_refl a` — `eqW a a → void`

After `simp [mu]`, the goal is

```
0 < omega0 ^ (mu a + mu a + (9 : Ordinal)) + 1
```

This is a pure positivity statement: `omega0 ^ β + 1 ≥ 1 + 1 > 0` for every ordinal `β`. The `+ 1` on the RHS guarantees strict positivity even when `mu a = 0`.

```lean
| _, _, Step.R_eq_refl a => by
    simp [mu]
    -- 0 < omega^(mu a + mu a + 9) + 1
    -- Because 1 ≤ (omega^(…) + 1) and 0 < 1.
    have hbase : (0 : Ordinal) < 1 := zero_lt_one
    have hstep : (1 : Ordinal) ≤ omega0 ^ (mu a + mu a + (9 : Ordinal)) + 1 :=
      le_add_right 1 (omega0 ^ (mu a + mu a + (9 : Ordinal)))
    exact lt_of_lt_of_le hbase hstep
```

If your `Mathlib` version exposes `Ordinal.pos_iff_ne_zero`, a one-liner is

```lean
    exact (lt_add_one _).trans (le_add_right _ _)
```

## Case 2: `Step.R_eq_diff a b` — `eqW a b → integrate (merge a b)`

After `simp [mu]` and cancelling the trailing `+1` (using `lt_of_lt_of_le` with `le_add_right`), the goal reduces to

```
omega0 ^ (4 : Ordinal) *
  (omega0 ^ (3 : Ordinal) * (mu a + 1)
 + omega0 ^ (2 : Ordinal) * (mu b + 1) + 2)
  < omega0 ^ (mu a + mu b + (9 : Ordinal))
```

Distribute the outer `omega0^4` to obtain the equivalent form

```
L := omega0 ^ (7 : Ordinal) * (mu a + 1)
   + omega0 ^ (6 : Ordinal) * (mu b + 1)
   + omega0 ^ (5 : Ordinal)
   <  omega0 ^ (mu a + mu b + (9 : Ordinal))     :=: R
```

Key sub-claims (all standard ordinal facts, each provable in one or two `omega`/monotonicity calls):

1. **Absorption of `mu a + 1` and `mu b + 1`.**  
   For any ordinal `α ≥ 0`, `α + 1 ≤ omega0 ^ (α + 1)` (with `<` for `α = 0` it becomes `1 < omega0`). Hence
   ```
   omega0^7 * (mu a + 1) < omega0^(mu a + 8)
   omega0^6 * (mu b + 1) < omega0^(mu b + 7)
   ```

2. **Combine the three terms of `L`.** WLOG `mu a ≥ mu b` (the other case is symmetric).  
   - If `mu a = 0`, then `mu b = 0` and `L = omega0^7 + omega0^6 + omega0^5 < omega0^8 < omega0^9`.  
   - If `mu a ≥ 1`, then `omega0^9 ≤ omega0^(mu a + 8)` and `omega0^(mu b + 7) ≤ omega0^(mu a + 8)`, so
     ```
     L < omega0^(mu a + 8) + omega0^(mu a + 8) + omega0^(mu a + 8)
       = omega0^(mu a + 8) * 3
       < omega0 * omega0^(mu a + 8)
       = omega0^(mu a + 9)
       ≤ omega0^(mu a + mu b + 9)     (since mu b ≥ 0)
     ```

3. **Close.** The chain of `<` from (2) gives `L < omega0^(mu a + mu b + 9) = R`, and then the `+1`s on both original sides combine via `lt_add_right` to yield the original goal.

```lean
| _, _, Step.R_eq_diff a b => by
    simp [mu]
    -- Goal: omega^4*(omega^3*(mu a+1)+omega^2*(mu b+1)+2)+1
    --       < omega^(mu a+mu b+9)+1
    -- 1) Strip the +1 on each side.
    suffices h : omega0 ^ (4 : Ordinal) *
        (omega0 ^ (3 : Ordinal) * (mu a + 1)
       + omega0 ^ (2 : Ordinal) * (mu b + 1) + 2)
        < omega0 ^ (mu a + mu b + (9 : Ordinal)) by
      exact lt_of_lt_of_le
        (lt_of_lt_of_le h (le_add_right _ _))
        (le_add_right _ _)
    -- 2) Distribute the leading omega^4 (left multiplication is monotone,
    --    and omega^4 * (X+Y+Z) = omega^4*X + omega^4*Y + omega^4*Z because
    --    the three summands on the right are < omega^4, so left-distributivity
    --    holds).  This yields the equivalent
    --      omega^7*(mu a+1) + omega^6*(mu b+1) + omega^5
    --        < omega^(mu a + mu b + 9)
    -- 3) Absorption (sub-claim 1):
    --    omega^7*(mu a+1) < omega^(mu a+8)
    --    omega^6*(mu b+1) < omega^(mu b+7)
    -- 4) Case split on mu a, mu b, finishing each branch as in sub-claim 2.
    --    - If mu a = 0 (so mu b = 0): LHS < omega^9 = RHS.
    --    - If mu a ≥ 1: all three top terms are ≤ omega^(mu a+8),
    --      sum them up:
    --         LHS < 3 * omega^(mu a+8) < omega^(mu a+9) ≤ omega^(mu a+mu b+9).
    sorry  -- substituted below
```

The two missing sub-lemmas (absorption and the max-of-exponents sum bound) are isolated ordinal-facts that hold in `Mathlib.SetTheory.Ordinal`; once they are introduced as `have`s inside the `sorry` placeholder, this case closes.

## Case 3: `Step.R_rec_succ b s n` — `recDelta b s (delta n) → app s (recDelta b s n)`

After `simp [mu]`, the goal is

```
omega0 ^ (3 : Ordinal) * (mu s + 1)
+ omega0 ^ (2 : Ordinal) * (mu (recDelta b s n) + 1)
+ 1
< omega0 ^ (omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + (6 : Ordinal))
+ omega0 * (mu b + 1) + 1
```

Substitute `mu (recDelta b s n)` and simplify the LHS, using `omega0^2 * 2 < omega0^3` to absorb the `+ 1` from `mu(recDelta b s n) + 1`, to obtain the equivalent form

```
L := omega0^3 * (mu s + 1)
   + omega0^(mu n + mu s + 8)
   + omega0^3 * (mu b + 1)
   + omega0^3
   <  omega0^(omega0^5 * (mu n + 1) + mu s + 7)
    + omega0 * (mu b + 1)         :=: R
```

The proof is dominated by the comparison of the two top terms, where the exponent on the RHS dwarfs the exponent `mu n + mu s + 8` appearing in the LHS.

**Key sub-claim (exponent gap).** For every ordinal `α ≥ 0`,

```
omega0^5 * (α + 1) + mu s + 7  >  α + mu s + 8
```

because the difference is `omega0^5 * (α + 1) − (α + 1) > 0` (since `omega0^5 * β > β` for every nonzero `β`, and `α + 1 ≥ 1`). Consequently,

```
omega0^(omega0^5 * (mu n + 1) + mu s + 7)
  > omega0^(mu n + mu s + 8).                    -- (E1)
```

**Combining the LHS terms.** The non-top contributions to `L` are dominated by `omega0^(mu n + mu s + 8)`:

```
omega0^3 * (mu s + 1)   < omega0^(mu n + mu s + 8)   (since mu n + mu s + 8 ≥ 3 + … ≥ 4)
omega0^3 * (mu b + 1)   < omega0^(mu n + mu s + 8)
omega0^3                < omega0^(mu n + mu s + 8)
```

(Each is a monotonicity/`opow`-monotonicity consequence; the first, for instance, follows from `omega0^3 * (mu s + 1) ≤ omega0^3 * omega0^mu s = omega0^(mu s + 3) ≤ omega0^(mu n + mu s + 8)` whenever `mu n ≥ 5`, and the small-`mu n` cases `mu n < 5` are checked by a finite case analysis on `mu n` for which `omega0^(mu n + mu s + 8)` is `omega0^(mu s + 8), …, omega0^(mu s + 12)`, each of which already dominates `omega0^3 * (mu s + 1)`.)

Hence

```
L < omega0^(mu n + mu s + 8) * 4
  < omega0 * omega0^(mu n + mu s + 8)
  = omega0^(mu n + mu s + 9).                     -- (E2)
```

**Closing the inequality.** From (E1) and (E2),

```
L < omega0^(mu n + mu s + 9)
  ≤ omega0^(omega0^5 * (mu n + 1) + mu s + 7)
  ≤ omega0^(omega0^5 * (mu n + 1) + mu s + 7) + omega0 * (mu b + 1)
  = R.
```

```lean
    simp [mu]
    -- Goal:  mu(app s (recDelta b s n))  <  mu(recDelta b s (delta n))
    -- Substitute mu(recDelta b s n) and absorb the +1 against omega^2*2 < omega^3.

    -- + omega^(mu n + mu s + 8)

    -- + omega^3
    -- < omega^(omega^5 * (mu n + 1) + mu s + 7) + omega * (mu b + 1)

    -- Sub-claim A (exponent gap):
    --   omega^5 * (mu n + 1) + mu s + 7  >  mu n + mu s + 8
    --   because omega^5 * (α+1) - (α+1) > 0 for every ordinal α.
    --
    -- Sub-claim B (dominate the LHS "small" terms):
    --   omega^3 * (mu s + 1) + omega^3 * (mu b + 1) + omega^3
    --     < 3 * omega^(mu n + mu s + 8) < omega^(mu n + mu s + 9).

```

The three sub-lemmas (absorption of `mu n + 1`/`mu s + 1`/`mu b + 1` against `omega`-powers, the `omega0^5 * α > α` basic fact, and the standard result that the sum of finitely many terms each `≤ omega0^α` is `< omega0^(α+1)`) are all available in `Mathlib.SetTheory.Ordinal.Arithmetic` / `Exponential`; combining them yields a complete proof of length comparable to the already-proven `R_merge_void_left` case.

The three `sorry` cases close by the same overall strategy already used in the file:

| Case | Key inequality | Dominant fact |
|------|----------------|---------------|
| `R_eq_refl` | `0 < omega^(2·mu a + 9) + 1` | Positivity via `lt_add_one` |

Each skeleton, when expanded, produces a chain of `<` no longer than the chain used in the existing `R_merge_void_right` case.
