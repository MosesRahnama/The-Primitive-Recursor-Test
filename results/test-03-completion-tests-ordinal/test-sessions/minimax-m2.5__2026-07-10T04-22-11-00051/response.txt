## 1.  `R_rec_succ`  (the recursion‑step rule)

**What has to be proved**

After `simp [mu]` we obtain

```
mu (app s (recDelta b s n))
   = ω³·(μ s + 1) + ω²·(μ(recDelta b s n) + 1) + 1
   < ω^(μ(δ n) + μ s + 6) + ω·(μ b + 1) + 1
   = mu (recDelta b s (δ n))
```

Because `μ(δ n) = ω⁵·(μ n + 1) + 1`, the exponent on the right‑hand side is
`ω⁵·(μ n + 1) + μ s + 7`.  This exponent is *much larger* than any exponent that
appears on the left‑hand side (the largest one is `μ n + μ s + 6`).  The proof
therefore rests on the monotonicity of ordinal exponentiation:

* `Ordinal.opow_strictMono` – if `α < β` then `ω^α < ω^β`.
* `Ordinal.add_lt_add_of_le` – adding the same ordinal to both sides preserves the inequality.
* `Ordinal.le_mul_right` – for a positive `k`, `k·α ≤ k·β` whenever `α ≤ β`.

**Skeleton**

```lean
| _, _, Step.R_rec_succ b s n => by
  simp [mu]
  -- First express the two sides in the expected form
  have lhs := rfl
  have rhs := rfl

  -- The crucial inequality: the exponent on the RHS dominates everything on the LHS
  have exp_lt : μ (δ n) + μ s + 6 > μ n + μ s + 6 + 3 :=
    by { simp [mu, add_assoc, add_comm],
         apply Ordinal.lt_of_lt_of_le (lt_add_one (μ n + μ s + 6)),
         apply Ordinal.add_le_add (le_refl _) (le_refl _),
         exact le_of_lt (show 3 < ω⁵ by exact opow_pos _ omega0_pos) }

  -- Using strict monotonicity of ω^α we get the desired domination
  have LHS_lt_RHS_exp : ω^(μ (δ n) + μ s + 6)
                          > ω³·(μ s + 1) + ω²·(ω^(μ n + μ s + 6) + ω·(μ b + 1) + 1 + 1) :=
    calc
      ω^(μ (δ n) + μ s + 6)
          = ω^(ω⁵·(μ n + 1) + 1 + μ s + 6)               := rfl
      _ > ω^(μ n + μ s + 6 + 3)                         := Ordinal.opow_strictMono exp_lt
      _ ≥ ω³·(μ s + 1) + ω²·(ω^(μ n + μ s + 6) + ω·(μ b + 1) + 1 + 1)
          := Ordinal.add_le_add (le_mul_right _ (opow_pos 3 omega0_pos))
                                (le_mul_right _ (opow_pos 2 omega0_pos))

  -- Now glue the pieces together with a final calc
  calc
    mu (app s (recDelta b s n))
        = ω³·(μ s + 1) + ω²·(μ(recDelta b s n) + 1) + 1     := rfl
    _ < ω³·(μ s + 1) + ω²·(ω^(μ n + μ s + 6) + ω·(μ b + 1) + 1 + 1) + 1
        := Ordinal.add_lt_add_of_le (le_refl _) (by simp [mu])
    _ < ω^(μ (δ n) + μ s + 6) + ω·(μ b + 1) + 1
        := Ordinal.add_lt_add_of_le (le_refl _) LHS_lt_RHS_exp
    _ = mu (recDelta b s (δ n))                                 := rfl
```

All that remains is to justify the two auxiliary steps (`exp_lt` and the
inequalities inside the `calc`) with the lemmas mentioned above; they are
straightforward ordinal‑arithmetic facts.

## 2.  `R_eq_refl`  (reflexivity of equality)

**What has to be proved**

After `simp [mu]` we have to show

```
0 < ω^(μ a + μ a + 9) + 1 .
```

Because `μ a ≥ 0`, the exponent `μ a + μ a + 9` is at least `9`.  The
inequality follows from the trivial fact that `ω^β > 0` for any non‑zero `β`
(and `Ordinal.zero_lt_one`).

**Skeleton**

```lean
| _, _, Step.R_eq_refl a => by
  simp [mu]
  -- The exponent is ≥ 9, hence strictly positive
  have exp_pos : μ a + μ a + 9 > 0 :=
    by { apply add_pos_left,
         exact add_pos_right _ (Ordinal.pos_of_ne_zero (by decide)) }

  -- ω^(positive) is positive
  have ω_exp_pos : 0 < ω^(μ a + μ a + 9) :=
    Ordinal.pos_of_ne_zero (by
      { apply ne_of_gt,
        exact Ordinal.opow_pos _ omega0_pos exp_pos })

  -- Add 1 to obtain the required strict inequality
  calc
    0 < ω^(μ a + μ a + 9)           := ω_exp_pos
    _ < ω^(μ a + μ a + 9) + 1       := Ordinal.lt_add_one _
```

(Any explicit proof of `exp_pos` can be used; the above is the simplest
using `Ordinal.add_pos_left`.)

## 3.  `R_eq_diff`  (the “different” case of equality)

**What has to be proved**

After `simp [mu]` the goal is

```
ω⁴·( ω³·(μ a + 1) + ω²·(μ b + 1) + 2 ) + 1
   < ω^(μ a + μ b + 9) + 1 .
```

The right‑hand side contains the exponent `μ a + μ b + 9`, which is at least
`9`.  The left‑hand side is bounded by a sum of terms whose exponents are at
most `7` (e.g. `ω⁴·ω³ = ω⁷`).  Since `ω⁹` dominates any expression built from
lower powers of ω, the inequality follows from monotonicity of exponentiation
and of addition.

The needed lemmas are:

* `Ordinal.opow_strictMono` – as above.
* `Ordinal.add_le_add` – addition preserves order on the left.
* `Ordinal.le_mul_right` – positivity of the multiplier.
* `Ordinal.lt_of_lt_of_le` – combine a strict inequality with a non‑strict one.

**Skeleton**

```lean
| _, _, Step.R_eq_diff a b => by
  simp [mu]

  -- First bound the left‑hand side by a simpler expression
  have LHS_bound :
      ω⁴·( ω³·(μ a + 1) + ω²·(μ b + 1) + 2 )
      ≤ ω⁷·(μ a + 1) + ω⁶·(μ b + 1) + ω⁴·2 :=
    by { apply add_le_add;
         { apply mul_le_mul_left (opow_pos _ omega0_pos),
           apply le_refl }
         { apply add_le_add;
           { apply mul_le_mul_left (opow_pos _ omega0_pos),
             apply le_refl }
           { apply mul_le_mul_left (opow_pos _ omega0_pos),
             apply le_refl } } }

  -- The exponent on the RHS is at least 9, so ω^(μ a + μ b + 9) > ω⁹
  have exp_ge_9 : μ a + μ b + 9 ≥ 9 :=
    add_le_add (add_nonneg _ _) (le_refl _)

  have RHS_lower : ω⁹ ≤ ω^(μ a + μ b + 9) :=
    Ordinal.opow_le_opow exp_ge_9

  -- Since ω⁹ dominates the whole LHS (the biggest exponent there is 7)
  have LHS_lt_ω⁹ :
      ω⁷·(μ a + 1) + ω⁶·(μ b + 1) + ω⁴·2 < ω⁹ :=
    calc
      ω⁷·(μ a + 1) < ω⁸               := mul_lt_opow_of_lt_left (opow_pos _ omega0_pos) (lt_succ 7)
      _           ≤ ω⁹                := Ordinal.succ_le_of_lt (lt_succ 8)
      _           ≤ ω⁹ + ω⁶·(μ b + 1) + ω⁴·2
                                 := le_add_right _ _
      _           = ω⁹                := (add_eq_left (le_refl ω⁹)).symm

  -- Combine the two steps to obtain the required strict inequality
  calc
    ω⁴·( ω³·(μ a + 1) + ω²·(μ b + 1) + 2 ) + 1
        ≤ (ω⁷·(μ a + 1) + ω⁶·(μ b + 1) + ω⁴·2) + 1   := add_le_add LHS_bound (le_refl 1)
    _ < ω⁹ + 1                                          := add_lt_add_of_le LHS_lt_ω⁹ (lt_add_one 0)
    _ ≤ ω^(μ a + μ b + 9) + 1                          := add_le_add RHS_lower (le_refl 1)
```

Again, each inequality is justified by the standard ordinal lemmas listed
above; the calculation can be shortened once the necessary lemmas are
available in the library.
