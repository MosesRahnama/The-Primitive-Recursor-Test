-- recDelta b s (delta n)  ⟶  app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    /-
      Want   μ (app s (recDelta b s n))             <
              μ (recDelta b s (delta n))

      Unfolding both sides gives

         ω^3*(μ s+1)  +  ω^2*(μ (recΔ b s n)+1) + 1        <
         ω^(μ (delta n)+μ s+6) + ω*(μ b+1) + 1.

      The proof proceeds in three stages:

      1.  Bound the whole LHS by a single power ω^κ whose
          exponent κ is “small’’ (≤ μ n + μ s + 7).

          •  Use   μ (recΔ b s n)
                   = ω^(μ n + μ s + 6) + ω*(μ b+1) + 1
            to show
                   ω^2*(μ (recΔ …)+1) < ω^(μ n + μ s + 7).

          •  The term  ω^3*(μ s+1)  is even smaller, so  
            the complete sum is < ω^(μ n + μ s + 7).

      2.  Compare exponents.

            μ (delta n) = ω^5*(μ n+1)+1    ⩾ ω^5
            hence
            μ (delta n) + μ s + 6  >  μ n + μ s + 7.

          Therefore
                 ω^(μ n + μ s + 7) < ω^(μ (delta n)+μ s+6).

      3.  Put everything together and use monotonicity of
          addition on the right:

              LHS < ω^(μ n+μ s+7)              -- stage 1
                  < ω^(μ(delta n)+μ s+6)       -- stage 2
                  ≤ ω^(μ(delta n)+μ s+6) + ω*(μ b+1) + 1
                  = RHS.

      Each inequality is available from the library; insert the
      missing calls at the “sorry” markers.
    -/
    simp [mu]                                    -- expands both sides
    -- `have` / `have` / `calc` blocks implementing the three stages:
    -- (the actual calls to library lemmas still have to be supplied)
    have h₁ : _ < omega0 ^ (mu n + mu s + (7 : Ordinal)) := by

      sorry

      sorry

| _, _, Step.R_eq_diff a b => by
    /-
      Want   μ (integrate (merge a b))          <
              μ (eqW a b)

      LHS = ω^4 * (μ (merge a b) + 1) + 1
          = ω^4 * (ω^3*(μ a+1) + ω^2*(μ b+1) + 1 + 1) + 1

      RHS = ω^(μ a + μ b + 9) + 1.

      Strategy:

      1.  Bound the LHS by  ω^(μ a + 8):
            the factor  ω^4 · (ω^3·…) never reaches exponent μ a + 8.

      2.  Show  μ a + 8 < μ a + μ b + 9   (obvious by monotonicity).

      3.  Combine
            ω^(μ a + 8) < ω^(μ a + μ b + 9),
         then finish with `add_lt_add_right`.

      The skeleton below isolates these three tasks.

      sorry
    -- stage 2: exponent comparison
    have h₂ : (mu a + (8 : Ordinal)) < mu a + mu b + (9 : Ordinal) := by
      -- trivial arithmetic on ordinals
      sorry

    have h₃ : omega0 ^ (mu a + (8 : Ordinal))
