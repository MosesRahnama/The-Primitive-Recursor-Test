Here is a proof skeleton for the three `sorry` cases. The skeletons give the key ordinal-arithmetic facts that must be established; the actual Lean tactics (mostly `simp [mu]`, `calc`, and lemmas from `Ordinal.Arithmetic`) follow the same pattern as the already-proved cases.

---

### 1. `R_rec_succ`  (recursion “unfolding” step)

Goal  
```
mu (app s (recDelta b s n)) < mu (recDelta b s (delta n))
```

**Key observations**

* `mu (delta n) = ω⁵·(μ n + 1) + 1`, so the exponent appearing in the measure of the right-hand side is  
  ```
  μ(δ n) + μ s + 6 = ω⁵·(μ n + 1) + (μ s + 7).
  ```
  This is already ≥ ω⁵.

* The left-hand side expands to  
  ```
  ω³·(μ s + 1) + ω²·(μ(recDelta b s n) + 1) + 1,
  ```
  whose largest summand is of the form `ω²·(ω^(μ n + μ s + 6) + …)`.

* Because `ω⁵·(μ n + 1)` dominates every exponent that appears on the left-hand side, the ordinal inequality  
  ```
  ω²·(ω^(μ n + μ s + 6) + k) + m  <  ω^(ω⁵·(μ n + 1) + c)
  ```
  holds for any fixed finite constants `k,m,c`.  
  (Use the general rule `α < β → ω^α < ω^β` together with the fact that the left exponent is `< ω⁵·(μ n + 1)`.)

Skeleton steps

1. Unfold `mu` on both sides (`simp [mu]`).  
2. Show the exponent on the RHS is strictly larger than any exponent on the LHS (`opow_lt_opow_iff_right`).  
3. Conclude the whole RHS term is larger than the whole LHS term (`mul_lt_mul_of_pos_left`, `add_lt_add`, etc.).

### 2. `R_eq_refl`  (reflexive equation collapses)

Goal  
```
mu void < mu (eqW a a)        i.e.   0 < ω^(μ a + μ a + 9) + 1
```

Skeleton

1. `simp [mu]`.  
2. The right-hand side is of the form `ω^γ + 1` with `γ ≥ 9`, hence positive.  
3. Use `Ordinal.pos_iff_ne_zero` (already used in `R_int_delta`).

---

### 3. `R_eq_diff`  (non-reflexive equation expands)

Goal  
```
mu (integrate (merge a b)) < mu (eqW a b)
```

Unfolded measures

```
LHS  = ω⁴·(μ(merge a b) + 1) + 1
     = ω⁴·(ω³·(μ a + 1) + ω²·(μ b + 1) + 2) + 1
RHS  = ω^(μ a + μ b + 9) + 1
```

Key facts to prove

* The exponent `μ a + μ b + 9` satisfies  
  ```
  μ a + μ b + 9  >  4 + log_ω(ω³·(μ a + 1) + ω²·(μ b + 1) + 2).
  ```
  Concretely it is enough to show  
  ```
  ω^(μ a + μ b + 9) > ω⁴·(ω³·(μ a + 1) + ω²·(μ b + 1) + 2).
  ```
  This follows from the general rule  
  ```
  ω^α > ω^β · n   whenever   α > β   (for finite n).
  ```

* Adding the final `+ 1` on both sides preserves the inequality.

Skeleton steps

1. `simp [mu]`.  
2. Prove the exponent comparison above (use `opow_add`, `mul_lt_mul_of_pos_left`, etc.).  
3. Finish with a short `calc` or `lt_of_lt_of_le` chain, mirroring the style of `R_merge_void_left`.

---
