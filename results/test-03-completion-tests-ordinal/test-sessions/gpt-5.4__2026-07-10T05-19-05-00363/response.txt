## 1. `R_rec_succ`

Goal after `simp [mu]` is essentially:

```lean
omega0 ^ (mu n + mu s + 6) + omega0 * (mu b + 1) + 1
  |> plugged as second argument of `app`
```

more concretely:

```lean
omega0 ^ (3 : Ordinal) * (mu s + 1) +
    omega0 ^ (2 : Ordinal) *
      (omega0 ^ (mu n + mu s + 6) + omega0 * (mu b + 1) + 1 + 1) + 1
  <
omega0 ^ (omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + 6) +
    omega0 * (mu b + 1) + 1
```

### Intended ordinal comparison idea
The RHS begins with a **single leading term**
```lean
omega0 ^ (mu (delta n) + mu s + 6)
```
and
```lean
mu (delta n) = omega0^5 * (mu n + 1) + 1
```
so that exponent is enormous. It dominates the entire Cantor-normal-form size of the `app` measure, whose largest exponent is only `3` and `2`, and whose coefficient at exponent `2` contains `mu (recDelta b s n)`, itself only of the form `omega^(mu n + mu s + 6) + ...`.

So the proof should be split into two stages:

1. bound the whole LHS by something below
   ```lean
   omega0 ^ (omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + 6)
   ```
2. then conclude this is `<` RHS by positivity of the tail `omega0 * (mu b + 1) + 1`.

### Skeleton

```lean
| _, _, Step.R_rec_succ b s n => by
  simp [mu]

  let E : Ordinal := mu n + mu s + (6 : Ordinal)
  let D : Ordinal := omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + (6 : Ordinal)

  have hE_lt_D : E < D := by
    -- enough to show mu n + mu s + 6 < omega^5 * (mu n + 1) + 1 + mu s + 6
    -- first: mu n < mu n + 1
    have hn1 : mu n < mu n + 1 := lt_add_one _
    -- then: mu n + 1 ≤ omega^5 * (mu n + 1)
    have hn2 : mu n + 1 ≤ omega0 ^ (5 : Ordinal) * (mu n + 1) :=
      le_mul_right _ (opow_pos 5 omega0_pos)
    have hn3 : mu n < omega0 ^ (5 : Ordinal) * (mu n + 1) := lt_of_lt_of_le hn1 hn2
    -- now monotonicity of addition on the right
    -- derive:
    -- mu n + mu s + 6 < omega^5 * (mu n + 1) + 1 + mu s + 6
    calc
      mu n + mu s + (6 : Ordinal)
          < omega0 ^ (5 : Ordinal) * (mu n + 1) + (mu s + (6 : Ordinal)) := by
              -- use add_lt_add_right hn3 (mu s + 6)
              simpa [Ordinal.add_assoc] using add_lt_add_right hn3 (mu s + (6 : Ordinal))
      _ < omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + (6 : Ordinal) := by
              -- insert the `+ 1`
              -- first ≤ with le_add_right, then reorganize by simp [Ordinal.add_assoc]
              have : omega0 ^ (5 : Ordinal) * (mu n + 1) + (mu s + (6 : Ordinal))
                    < (omega0 ^ (5 : Ordinal) * (mu n + 1) + 1) + (mu s + (6 : Ordinal)) := by
                simpa [Ordinal.add_assoc] using
                  add_lt_add_right (lt_add_one (omega0 ^ (5 : Ordinal) * (mu n + 1))) (mu s + (6 : Ordinal))
              simpa [Ordinal.add_assoc] using this

  have hpow : omega0 ^ E < omega0 ^ D := by
    exact opow_lt_opow_right omega0 hE_lt_D
    -- if the exact lemma name differs, use the monotonicity lemma for ordinal exponentiation
    -- with base omega0 > 1.

  have hsmall1 :
      omega0 ^ (3 : Ordinal) * (mu s + 1) < omega0 ^ D := by
    -- because 3 < D, hence omega^3 * (...) < omega^D
    -- prove 3 < D first; enough since D has the huge omega^5-part
    have h3D : (3 : Ordinal) < D := by
      -- it suffices that 3 < omega^5 ≤ omega^5 * (mu n + 1) ≤ D
      -- use positivity of (mu n + 1)
      -- then monotonicity into the final sum
      sorry
    -- now use a standard bound: if k < D then omega^k * c < omega^D for positive c
    -- with c = mu s + 1 > 0
    have hspos : 0 < mu s + 1 := by
      exact add_pos_right _ one_pos
    -- invoke the corresponding lemma for CNF-leading-term comparison
    sorry

  have hsmall2 :
      omega0 ^ (2 : Ordinal) *
        (omega0 ^ E + omega0 * (mu b + 1) + 1 + 1) < omega0 ^ D := by
    -- enough to show the exponent-2 term is still below omega^D
    -- because omega^2 * (...) is bounded by omega^(E+2) or simply by some exponent < D
    -- and E < D from hE_lt_D
    have hE2D : E + (2 : Ordinal) < D := by
      -- derive from hE_lt_D since D has a huge gap
      sorry
    -- then use arithmetic: omega^2 * (omega^E + ...) < omega^(E+2) < omega^D
    -- or directly compare via a library lemma bounding multiplication by lower powers
    sorry

  have hsum :
      omega0 ^ (3 : Ordinal) * (mu s + 1) +
        omega0 ^ (2 : Ordinal) *
          (omega0 ^ E + omega0 * (mu b + 1) + 1 + 1) + 1
      < omega0 ^ D := by
    -- combine hsmall1 and hsmall2; the sum of two ordinals both < omega^D is still < omega^D
    -- when omega^D is additively principal (true for powers of omega).
    -- Use `Ordinal.IsNormal`, additive principal, or a lemma like:
    --   a < ω^D -> b < ω^D -> a + b < ω^D
    -- and then add the final `+ 1`.
    sorry

  calc
    omega0 ^ (3 : Ordinal) * (mu s + 1) +
        omega0 ^ (2 : Ordinal) *
          (omega0 ^ E + omega0 * (mu b + 1) + 1 + 1) + 1
      < omega0 ^ D := hsum
    _ < omega0 ^ D + (omega0 * (mu b + 1) + 1) := by
        exact lt_add_of_pos_right _ (add_pos_right _ one_pos)
```

### What you will likely need
Search mentally among Mathlib ordinal lemmas for variants of:

- monotonicity of addition:
  - `add_lt_add_right`
- positivity:
  - `opow_pos`
  - `add_pos_right _ one_pos`
- monotonicity/strict monotonicity of `ω^x`:
  - something like `opow_lt_opow_right`
- additive-principal closure of `ω^D`:
  - a lemma expressing that if `a < ω^D` and `b < ω^D`, then `a + b < ω^D`

This is the technically hardest case.

## 2. `R_eq_refl`

This one is easy: after `simp [mu]`, the goal is just

```lean
0 < omega0 ^ (mu a + mu a + 9) + 1
```

### Skeleton

```lean
| _, _, Step.R_eq_refl a => by
    simp [mu]
    exact Ordinal.pos_iff_ne_zero.mpr (by
      apply ne_of_gt
      exact add_pos_right _ one_pos)
```

Or even shorter, if accepted:

```lean
| _, _, Step.R_eq_refl a => by
    simp [mu]
    exact add_pos_right _ one_pos
```

depending on what `simp` leaves and whether the goal is `<` or `≠ 0` in the local state. The first version is safer and matches your `R_int_delta` style.

## 3. `R_eq_diff`

After `simp [mu]`, the goal is essentially

```lean
omega0 ^ (4 : Ordinal) *
    (omega0 ^ (3 : Ordinal) * (mu a + 1) +
      omega0 ^ (2 : Ordinal) * (mu b + 1) + 1 + 1) + 1
<
omega0 ^ (mu a + mu b + 9) + 1
```

### Intended comparison idea
The whole LHS is bounded by something of exponent at most `7` plus lower stuff:

- `ω^4 * (ω^3 * ...) = ω^(4+3) * ... = ω^7 * ...`
- `ω^4 * (ω^2 * ...) = ω^6 * ...`
- `ω^4 * 2 = ω^4 * 2`

So the largest exponent occurring on the LHS is at most `7`.

By contrast, RHS is `ω^(mu a + mu b + 9) + 1`, and
```lean
mu a + mu b + 9
```
is always at least `9`, hence strictly bigger than `7`. Therefore `ω^(...)` on the RHS dominates the whole LHS.

### Skeleton

```lean
| _, _, Step.R_eq_diff a b => by
    simp [mu]

    let E : Ordinal := mu a + mu b + (9 : Ordinal)

    have h7E : (7 : Ordinal) < E := by
      -- since 7 < 9 ≤ mu a + mu b + 9
      calc
        (7 : Ordinal) < 9 := by norm_num
        _ ≤ mu a + mu b + (9 : Ordinal) := by
          -- use that 9 ≤ x + 9
          simpa [Ordinal.add_assoc] using le_add_left (9 : Ordinal) (mu a + mu b)

    have hω7_lt : omega0 ^ (7 : Ordinal) < omega0 ^ E := by
      exact opow_lt_opow_right omega0 h7E

    have hleft_bound :
      omega0 ^ (4 : Ordinal) *
        (omega0 ^ (3 : Ordinal) * (mu a + 1) +
          omega0 ^ (2 : Ordinal) * (mu b + 1) + 1 + 1)
      < omega0 ^ E := by
      -- expand/bound by exponent analysis:
      -- ω^4 * (ω^3 * (mu a + 1) + ...) ≤ ω^7 * (mu a + 1) + ...
      -- hence < ω^E because 7 < E.
      --
      -- One way is to first show the parenthesized term is < ω^4,
      -- but that is false in general because of coefficients.
      -- Better: compare each summand after left multiplication by ω^4.
      --
      -- Use distributive/associative ordinal arithmetic lemmas as available:
      --   ω^4 * (ω^3 * (mu a + 1)) = ω^7 * (mu a + 1)
      -- and similarly the other terms become exponents 6 and 4.
      --
      -- Then show each of those is < ω^E and combine using additive-principal closure.
      have hA :
        omega0 ^ (4 : Ordinal) * (omega0 ^ (3 : Ordinal) * (mu a + 1)) < omega0 ^ E := by
        -- rewrite to ω^7 * (mu a + 1)
        -- then use 7 < E
        sorry
      have hB :
        omega0 ^ (4 : Ordinal) * (omega0 ^ (2 : Ordinal) * (mu b + 1)) < omega0 ^ E := by
        -- exponent 6 < E
        sorry
      have hC :
        omega0 ^ (4 : Ordinal) * (1 + 1) < omega0 ^ E := by
        -- exponent 4 < E
        sorry
      -- combine hA, hB, hC into the whole bound
      sorry

    calc
      omega0 ^ (4 : Ordinal) *
          (omega0 ^ (3 : Ordinal) * (mu a + 1) +
            omega0 ^ (2 : Ordinal) * (mu b + 1) + 1 + 1) + 1
        < omega0 ^ E + 1 := by
            exact add_lt_add_right hleft_bound 1
      _ = omega0 ^ (mu a + mu b + (9 : Ordinal)) + 1 := rfl
```

### Simpler fallback proof pattern
If direct algebraic rewriting is awkward, use a stronger but more abstract intermediate lemma:

> For any ordinal `x`, `omega0 ^ 4 * x < omega0 ^ E` whenever `x < omega0 ^ (E - 4)`.

Then prove the inside term is `< ω^(mu a + mu b + 5)` or just `< ω^5` if possible. But with arbitrary coefficients `mu a + 1`, `mu b + 1`, a fixed `< ω^5` bound is not available. So the exponent-by-summand decomposition above is the more realistic route.

## Practical advice on finishing in Lean

The two hard cases (`R_rec_succ`, `R_eq_diff`) are fundamentally about **Cantor normal form dominance**:

- terms with all exponents `< E` are `< ω^E`
- finite sums of such terms remain `< ω^E`
- if `α < β`, then `ω^α < ω^β`

So the useful library facts to look for, without searching outside the file, are likely around:

- strict monotonicity of `opow`
- positivity of `ω^k`
- additive closure / principal ordinals for `ω^E`
- arithmetic identities:
  - `ω^a * ω^b = ω^(a+b)`
  - reassociation of multiplication
  - distributive-ish inequalities sufficient for upper bounds

If exact theorem names differ, the proof shape can still be implemented by replacing each `sorry` with the corresponding local lemma invocations.

## Short version of the three replacements

### `R_eq_refl`
Use exactly the same positivity pattern as `R_int_delta`.

### `R_rec_succ`
1. Set `E := mu n + mu s + 6`, `D := mu (delta n) + mu s + 6`.
2. Prove `E < D`.
3. Deduce `ω^E < ω^D`.
4. Show each summand in `mu (app s (recDelta b s n))` is `< ω^D`.
5. Conclude the whole LHS is `< ω^D < ω^D + ω*(mu b+1) + 1`.

### `R_eq_diff`
1. Set `E := mu a + mu b + 9`.
2. Prove `7 < E`.
3. Bound the left side by a sum of terms of exponents `7`, `6`, and `4`.
4. Show each is `< ω^E`.
5. Combine to get the whole LHS `< ω^E`, hence `< ω^E + 1`.
