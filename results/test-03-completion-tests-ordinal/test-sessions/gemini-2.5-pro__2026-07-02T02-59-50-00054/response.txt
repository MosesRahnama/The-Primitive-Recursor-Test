Here is a proof skeleton for the three `sorry` cases. The proofs rely on standard properties of ordinal arithmetic, particularly the behavior of addition, multiplication, and exponentiation with `omega0` (`ω`).

### Skeleton for `Step.R_rec_succ`

The goal is to show `mu(app s (recDelta b s n)) < mu(recDelta b s (delta n))`.
The left-hand side (LHS) has a `mu` term of `omega0 ^ (mu(delta n) + ...)`, while the right-hand side (RHS) has terms whose sizes are based on `mu(recDelta b s n)`, which has an exponent of `mu n + ...`. The core of the proof is that the exponent on the LHS, which contains `mu(delta n) = omega0^5 * (mu n + 1) + 1`, is vastly larger than any exponent appearing on the RHS.

```lean
-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    simp [mu]
    -- Goal: omega^3*(mu s+1) + omega^2*(omega^(mu n+mu s+6) + omega*(mu b+1)+1+1)+1
    --     < omega^(omega^5*(mu n+1)+1 + mu s+6) + omega*(mu b+1)+1

    -- Let's define abbreviations for the exponents to make it clearer.
    let lhs_exp_base := omega0 ^ (mu n + mu s + 6) + omega0 * (mu b + 1) + 1
    let rhs_exp := mu (delta n) + mu s + 6
    -- The inequality is:
    --   omega0^3*(mu s+1) + omega0^2*(lhs_exp_base+1)+1 < omega0^rhs_exp + omega0*(mu b+1)+1

    -- We will show that the RHS is dominated by a term much smaller than the leading term
    -- of the LHS. A common strategy is to find a simple upper bound for the RHS.

    -- 1. Find an upper bound for `mu(recDelta b s n) + 1`.
    --    Let E_rec = mu n + mu s + 6.
    --    mu(recDelta b s n) = omega0^E_rec + omega0*(mu b+1) + 1.
    --    Since E_rec >= 6 > 1, we have omega0*(mu b+1)+1 < omega0^E_rec.
    have h_bound_rec_part : omega0 * (mu b + 1) + 1 < omega0 ^ (mu n + mu s + 6) := sorry
    --    Therefore, mu(recDelta b s n) < omega0^E_rec + omega0^E_rec = omega0^E_rec * 2.
    have h_bound_rec : mu (recDelta b s n) < omega0 ^ (mu n + mu s + 6) * 2 := sorry
    --    And so mu(recDelta b s n) + 1 < omega0^E_rec * 3.
    have h_bound_rec_plus_one : mu (recDelta b s n) + 1 < omega0 ^ (mu n + mu s + 6) * 3 := sorry

    -- 2. Find an upper bound for the whole RHS `mu(app s (recDelta b s n))`.
    --    mu(app...) = omega0^3*(mu s+1) + omega0^2*(mu(rec...)+1) + 1
    --    Since mu s + 1 < omega0^(mu n + mu s + 6), we can bound the whole expression.
    have h_bound_s : mu s + 1 < omega0 ^ (mu n + mu s + 6) := sorry
    --    RHS < omega0^3*omega0^E_rec + omega0^2*(omega0^E_rec*3) + 1
    --        = omega0^(E_rec+3) + omega0^(E_rec+2)*3 + 1
    --    This sum is less than omega0^(E_rec+4).
    have h_rhs_lt : mu (app s (recDelta b s n)) < omega0 ^ (mu n + mu s + 10) := sorry

    -- 3. Show this upper bound is less than the LHS `mu(recDelta b s (delta n))`.
    --    LHS = omega0^(omega0^5*(mu n+1)+1 + mu s+6) + ...
    --    It's enough to show the upper bound is less than the leading term of the LHS.
    --    Goal: omega0^(mu n + mu s + 10) < omega0^(omega0^5*(mu n+1) + mu s + 7)
    apply lt_of_lt_of_le h_rhs_lt
    apply le_trans (add_le_add_right (opow_le_opow_of_le omega0_ge_one _) _) (le_add_right _ _)
    --    This reduces to comparing exponents.
    apply opow_lt_opow_iff_of_one_lt.mpr
    · exact one_lt_omega0
    --    Goal: mu n + mu s + 10 < omega0^5*(mu n+1) + mu s + 7
    --    Cancel `mu s` from both sides.
    apply (add_lt_add_iff_left (mu s)).mpr
    --    Goal: mu n + 10 < omega0^5*(mu n+1) + 7
    --    This is true because `mu n + 10 < omega0*(mu n+1)`, a standard result.
    have h_final_exp : mu n + 10 < omega0 ^ 5 * (mu n + 1) + 7 := sorry
    exact h_final_exp
```

### Skeleton for `Step.R_eq_refl`

The goal is to show `mu(void) < mu(eqW a a)`. This is a straightforward positivity argument, as `mu(void)` is 0 and `mu(eqW a a)` is manifestly greater than 0.

```lean
-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    simp [mu]
    -- Goal: 0 < omega0 ^ (mu a + mu a + 9) + 1
    -- This follows from two facts:
    -- 1. For any ordinal e, omega0^e > 0 (since omega0 > 1).
    -- 2. Adding 1 to a positive ordinal yields a strictly greater ordinal.
    have h_opow_pos : 0 < omega0 ^ (mu a + mu a + 9) := by
      -- Use the lemma that o^e > 0 if o > 1.
      apply opow_pos_of_one_lt
      exact one_lt_omega0
    -- Now show that adding 1 preserves positivity.
    calc
      0 < omega0 ^ (mu a + mu a + 9) := h_opow_pos
      _ < omega0 ^ (mu a + mu a + 9) + 1 := lt_add_one _
```

### Skeleton for `Step.R_eq_diff`

The goal is to show `mu(integrate (merge a b)) < mu(eqW a b)`.
The LHS has `mu(eqW a b) = omega0^(mu a + mu b + 9) + 1`. The RHS expands to a sum of terms involving `omega0` to small powers like 4, 3, and 2. The core of the proof is that the exponent `mu a + mu b + 9` on the LHS is large enough to dominate the entire RHS expression. The proof strategy involves finding an upper bound for the RHS and showing it is smaller than the leading term of the LHS. A small complication arises if `mu a` or `mu b` is zero, which slightly weakens the bounds, so we may need a case split.

```lean
-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    simp [mu]
    -- Goal: omega^4 * (omega^3*(mu a+1) + omega^2*(mu b+1) + 2) + 1
    --     < omega^(mu a + mu b + 9) + 1

    -- Cancel the "+ 1" on both sides.
    apply add_lt_add_iff_right.mpr
    -- New Goal: omega^4 * (omega^3*(mu a+1) + omega^2*(mu b+1) + 2)
    --         < omega^(mu a + mu b + 9)

    -- Let A = mu a and B = mu b.
    let A := mu a
    let B := mu b

    -- To prove this, we bound the LHS.
    -- The main idea is that X + Y < omega^(max(log X, log Y) + 1).
    -- We have omega^3*(A+1) < omega^(A+4) and omega^2*(B+1) < omega^(B+3).
    have h_bound_A : omega0 ^ 3 * (A + 1) < omega0 ^ (A + 4) := sorry
    have h_bound_B : omega0 ^ 2 * (B + 1) < omega0 ^ (B + 3) := sorry

    -- The term in parenthesis is bounded by a power of omega whose exponent
    -- is based on max(A+4, B+3).
    have h_bound_sum : omega0 ^ 3 * (A + 1) + omega0 ^ 2 * (B + 1) + 2 <
                       omega0 ^ (max (A + 4) (B + 3) + 1) := sorry

    -- Therefore, the whole LHS is bounded.
    have h_bound_lhs : omega0 ^ 4 * (omega0 ^ 3 * (A + 1) + omega0 ^ 2 * (B + 1) + 2) <
                       omega0 ^ (max (A + 4) (B + 3) + 5) := sorry
    apply lt_of_lt_of_le h_bound_lhs
    apply opow_le_opow_of_le omega0_ge_one
    
    -- The problem reduces to comparing exponents.
    -- Goal: max (A + 4) (B + 3) + 5 < A + B + 9
    -- We can prove this by cases on whether A+4 > B+3.

    by_cases h_max : (A + 4) ≤ (B + 3)
    · -- Case 1: B is larger or comparable to A.
      -- Goal: (B + 3) + 5 < A + B + 9  ==>  B + 8 < A + B + 9
      rw [max_le_iff] at h_max
      simp only [h_max.2, le_refl, max_eq_right]
      -- This simplifies to 8 < A + 9, which is always true.
      have h_A_ge_zero : 0 ≤ A := Ordinal.zero_le A
      have h_goal : 8 < A + 9 := sorry -- by adding 8 to 0 <= A+1
      exact h_goal
    · -- Case 2: A is larger than B.
      -- Goal: (A + 4) + 5 < A + B + 9  ==>  A + 9 < A + B + 9
      simp only [not_le] at h_max
      simp only [max_eq_left (le_of_lt h_max)]
      -- This simplifies to 0 < B.
      apply (add_lt_add_iff_left (A + 9)).mpr
      -- This holds unless B = 0. We need a special argument for mu b = 0.
      by_cases hB_zero : B = 0
      · -- If B = 0, our general bound was too loose. We need a tighter one.
        -- Let's restart the proof for this specific sub-case.
        -- Goal: omega^7 * (A+2) < omega^(A+9), which holds.
        sorry
      · -- If B > 0, then 0 < B holds.
        exact Ordinal.pos_iff_ne_zero.mpr hB_zero
```
