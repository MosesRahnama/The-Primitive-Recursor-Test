**Key observations for completing the proofs:**

1.  **`R_eq_diff`**: The inequality `mu(merge a b) + 1 < omega^(mu a + mu b + 5)` relies on the fact that `omega^3 * (mu a + 1) < omega^(mu a + 4)` (and similarly for `b`). This follows from `mul_lt_opow_succ` and the observation that for any ordinal `alpha`, `alpha + 1 <= omega^alpha` when `alpha >= 1` (and the finite cases are routine).

2.  **`R_rec_succ`**: The critical insight is that `mu(delta n) = omega^5 * (mu n + 1) + 1` creates a "gap" of size `omega^5` in the exponent tower. This dominates the fixed exponents (`3` and `2`) appearing in `mu(app ...)` and also dominates `mu(recDelta b s n)`, which only reaches height `mu n + mu s + 6`. Thus `omega^X` absorbs both summands of the left-hand side.
