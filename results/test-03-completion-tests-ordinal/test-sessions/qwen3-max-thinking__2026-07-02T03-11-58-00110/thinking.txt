```lean
    _ < omega0^(mu a + mu b + 9) := h9
    _ < omega0^(mu a + mu b + 9) + 1 := lt_add_one _
    _ = mu (eqW a b) := by rfl
```

Note: In R_eq_diff, the step for h9 uses a sorry for the limit ordinal property. In practice, one would use a lemma like `add_lt_of_lt_limit` if available, or prove it. But for the skeleton, we leave it as sorry.
