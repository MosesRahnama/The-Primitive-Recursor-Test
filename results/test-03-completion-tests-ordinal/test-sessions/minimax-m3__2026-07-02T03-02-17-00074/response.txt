# Proof Skeleton for the Three Remaining Cases

I'll give a per-case strategy, the key ordinal-arithmetic lemmas, and a Lean-style sketch.

---

## 1. `R_eq_refl`:  `eqW a a → void`

After `simp [mu]` the goal is the bare positivity

```
0 < omega0 ^ (mu a + mu a + 9) + 1
```

`x + 1` is always positive for any ordinal `x`, so the same tactic chain used for `R_int_delta` works verbatim.

```lean
| _, _, Step.R_eq_refl a => by
    simp [mu]
    exact Ordinal.pos_iff_ne_zero.mpr (by
      apply ne_of_gt
      exact add_pos_right _ one_pos)
```

No exponent arithmetic is needed — the RHS is the successor of any ordinal.

---

## 2. `R_eq_diff`:  `eqW a b → integrate (merge a b)`

After `simp [mu]` and using `mu (merge a b) = omega0^3*(mu a+1) + omega0^2*(mu b+1) + 1`, the goal becomes

```
omega0^4 * (omega0^3*(mu a+1) + omega0^2*(mu b+1) + 2) + 1
   < omega0 ^ (mu a + mu b + 9) + 1
```

### Strategy

Factor out the `+ 1` on each side (it only makes the inequality harder on the LHS), then absorb the `omega0^4` into the exponent on the RHS:

```
omega0^4 * M  ≤  omega0^4 * omega0^(mu a + mu b + 5)  =  omega0^(mu a + mu b + 9)
```

where `M := omega0^3*(mu a+1) + omega0^2*(mu b+1) + 2`. This reduces the case to a single supporting lemma.

### Supporting lemma (the only non-trivial part)

```lean
lemma mu_merge_lt (a b : Trace) :
    omega0^3 * (mu a + 1) + omega0^2 * (mu b + 1) + 2
      < omega0 ^ (mu a + mu b + 5) := by
  -- (a) omega0^3 * (mu a + 1) ≤ omega0^(mu a + 4)
  --     from  mu a + 1 ≤ omega0^(mu a + 1)  (since  α + 1 ≤ ω^(α+1) for α ≥ 0)
  --     and   omega0^3 * omega0^(mu a+1) = omega0^(mu a+4)  (opow_add)
  -- (b) symmetrically, omega0^2 * (mu b + 1) ≤ omega0^(mu b + 3)
  -- (c) For α,β ≥ 1:  omega0^α + omega0^β < omega0^(max(α,β) + 1)
  --     and since  mu a+4, mu b+3 ≤ mu a + mu b + 5  (because mu a, mu b ≥ 0),
  --     conclude M < omega0^(mu a + mu b + 5).
  sorry
```

### Putting it together

```lean
| _, _, Step.R_eq_diff a b => by
    simp [mu]
    suffices h : omega0^4 * (omega0^3 * (mu a + 1)
                              + omega0^2 * (mu b + 1) + 2)
                  < omega0 ^ (mu a + mu b + 9) by
      exact add_lt_add_right h 1
    have hM := mu_merge_lt a b
    calc omega0^4 * (omega0^3 * (mu a + 1) + omega0^2 * (mu b + 1) + 2)
        < omega0^4 * omega0 ^ (mu a + mu b + 5) :=
            mul_lt_mul_of_pos_left hM (opow_pos 4 omega0_pos)
      _ = omega0 ^ (mu a + mu b + 9) := by
            rw [← Ordinal.opow_add]; congr 1; ring_nf
```

The equality step uses `Ordinal.opow_add : omega^(α+β) = omega^α * omega^β` (valid for `0 < omega0`) plus the fact that `4 + (mu a + mu b + 5) = mu a + mu b + 9`.

## 3. `R_rec_succ`:  `recDelta b s (delta n) → app s (recDelta b s n)`

After `simp [mu]` the goal is

```
omega0^3*(mu s+1) + omega0^2*(mu(recDelta b s n) + 1) + 1
   < omega0^(omega0^5*(mu n+1) + 1 + mu s + 6) + omega0*(mu b+1) + 1
```

Substituting `mu(recDelta b s n) = omega0^(mu n + mu s + 6) + omega0*(mu b+1) + 1` and using
`omega0^2 * omega0^α = omega0^(2+α)`, `omega0^2 * omega0 * x = omega0^3 * x`, the LHS becomes

```
omega0^3*(mu s+1) + omega0^(mu n + mu s + 8) + omega0^3*(mu b+1) + omega0^2*2 + 1
```

### Strategy

The RHS's leading term has exponent
`E := omega0^5 * (mu n + 1) + 1 + mu s + 6`, which is "Veblen-huge":
`E ≥ omega0^5` already dominates every term on the LHS. So bound the entire LHS by `omega0^E`, then add the residual `omega0*(mu b+1) + 1`.

### Supporting lemmas

```lean
-- (i)  mu n + mu s + 8  <  E     (a "linear-vs-tower" inequality)
lemma exp_dominates : mu n + mu s + 8
                       < omega0^5 * (mu n + 1) + 1 + mu s + 6 := by
  -- omega0^5 * (mu n+1)  ≥  omega0^5  ≥  mu n + 7  for any mu n
  -- (uses opow_le_opow_right on omega0^5 ≥ ... and omega0^5 * 1 ≥ mu n + 7)
  sorry

-- (ii) if a < b then omega0^a < omega0^b   (opow strict-monotone on the right)
-- (iii) for any x with x < omega0^E, also  omega0^k * x < omega0^E   when k + 1 ≤ ...
--      (use mul_lt_mul_of_pos_left with the bound x < omega0^(E-k))
```

The dominant sub-step is the absorption of the LHS into `omega0^E`:

```lean
have hLHS : omega0^3 * (mu s + 1) + omega0^(mu n + mu s + 8)
              + omega0^3 * (mu b + 1) + omega0^2 * 2 + 1
            < omega0 ^ E := by
  have hE_pos : 0 < E := by positivity
  -- bound the "big" term first
  have h1 : omega0^(mu n + mu s + 8) < omega0^E :=
    Ordinal.opow_lt_opow_right omega0_pos exp_dominates
  -- bound the three "small" polynomial terms individually by omega0^E
  have h2 : omega0^3 * (mu s + 1) < omega0^E := by
    -- mu s + 1 ≤ omega0^(mu s)  (le_opow_self variant)
    -- omega0^3 * omega0^(mu s) = omega0^(mu s + 3) ≤ omega0^E
    sorry
  have h3 : omega0^3 * (mu b + 1) < omega0^E := by sorry
  have h4 : omega0^2 * 2 + 1 < omega0^E := by
    -- 2*omega0^2 + 1 ≤ omega0^3 ≤ omega0^E   (E ≥ omega0^5 ≥ 3 for mu n ≥ 0)
    sorry
  -- sum of < ω^E is < ω^E (use the sub-additivity of < under the largest summand,
  --  i.e. for ordinals x,y with x,y < ω^E, also x+y < ω^E since ω^E is additively principal)
  sorry
```

### Putting it together

```lean
| _, _, Step.R_rec_succ b s n => by
    simp [mu]
    -- LHS < omega0^E   (just established)
    have hLHS : _ < omega0 ^ (omega0^5 * (mu n + 1) + 1 + mu s + 6) := by
      sorry  -- main arithmetic
    -- Then absorb the residual omega0*(mu b+1) term on the RHS
    calc _ 
        < omega0 ^ (omega0^5 * (mu n + 1) + 1 + mu s + 6) := hLHS
      _ ≤ omega0 ^ (omega0^5 * (mu n + 1) + 1 + mu s + 6)
          + omega0 * (mu b + 1) := le_add_left _ _
      _ ≤ omega0 ^ (omega0^5 * (mu n + 1) + 1 + mu s + 6)
          + omega0 * (mu b + 1) + 1 := le_add_right _ _
```

## Summary of the ordinal arithmetic toolkit needed

All three cases (with the prover cases) ultimately use only a small library:

| Fact | Use |
|---|---|
| `opow_pos n omega0_pos : 0 < omega0^n` | proved cases |
| `le_mul_right a h : a ≤ b * a`  for `0 < b` | proved cases |
| `opow_add : a^(b+c) = a^b * a^c`  for `0 < a` | R_eq_diff, R_rec_succ |
| `opow_lt_opow_right : a < b → omega^a < omega^b` | R_rec_succ |
| `mul_lt_mul_of_pos_left : a < b → c * a < c * b`  for `0 < c` | R_eq_diff |
| `add_lt_add_right : a < b → a + c < b + c` | R_eq_diff, R_rec_succ |
| `α + 1 ≤ ω^α`  for `α ≥ 0` (a `le_opow_self` variant) | the supporting lemmas |
| `ω^α + ω^β < ω^γ` when `α,β < γ` (or `α,β ≤ γ-1` with at least one strict) | the supporting lemmas |

The first five are already in Mathlib's `Ordinal` namespace and are used in the existing proofs; the last two are small one-line consequences of `opow_lt_opow_right` and the Cantor-Bendixson style absorption lemmas already in `Mathlib.SetTheory.Ordinal.Principal`, and isolating them as named lemmas is the cleanest way to discharge the `sorry`s without re-proving ordinal arithmetic inline.
