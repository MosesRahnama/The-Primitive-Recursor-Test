**Proof skeletons for the three missing cases**

We provide high‑level reasoning and the key ordinal arithmetic comparisons needed to fill the `sorry` blocks in the `mu_decreases` theorem.  Each skeleton can be expanded into a full Lean proof using the indicated lemmas.

---

### 1. `R_rec_succ` – `recDelta b s (delta n) ⟶ app s (recDelta b s n)`

**Goal**  
`mu (app s (recDelta b s n)) < mu (recDelta b s (delta n))`

**Expanded measures**  

- `mu(recDelta b s (delta n)) = ω⁽ᵐᵘ⁽ᵈᵉˡᵗᵃ ⁿ⁾ + ᵐᵘ ˢ + ⁶⁾ + ω·(mu b + 1) + 1`  
  with `mu(delta n) = ω⁵·(mu n + 1) + 1`.

- `mu(app s (recDelta b s n)) = ω³·(mu s + 1) + ω²·(mu(recDelta b s n) + 1) + 1`  
  where `mu(recDelta b s n) = ω⁽ᵐᵘ ⁿ + ᵐᵘ ˢ + ⁶⁾ + ω·(mu b + 1) + 1`.

**Key comparison**  

The leading term of the left‑hand side is  
`ω²·(ω⁽ᵐᵘ ⁿ + ᵐᵘ ˢ + ⁶⁾) = ω⁽ᵐᵘ ⁿ + ᵐᵘ ˢ + ⁸⁾`.

All other terms are smaller than this (they have lower exponent or finite coefficients).

The exponent of the dominating term on the right‑hand side is  
`X := mu(delta n) + mu s + 6 = ω⁵·(mu n + 1) + 1 + mu s + 6 = ω⁵·(mu n + 1) + mu s + 7`.

We need to show `mu n + mu s + 8 < X`.  
This follows from `mu n + 2 < mu(delta n)`, i.e. `mu n + 2 < ω⁵·(mu n + 1) + 1`.  
Because `ω⁵ ≥ 1`, we have `ω⁵·(mu n + 1) ≥ mu n + 1`, and adding `1` gives `ω⁵·(mu n + 1) + 1 ≥ mu n + 2`.  
Strictness holds because `ω⁵·(mu n + 1)` is infinite whenever `mu n` is finite and is strictly greater than `mu n+1` for any `mu n` (even `mu n = 0` yields `ω⁵ > 1`).

Thus `mu n + mu s + 8 < X`, and by `opow_lt_opow_right` we obtain  
`ω⁽ᵐᵘ ⁿ + ᵐᵘ ˢ + ⁸⁾ < ω^X`.

Now the entire left‑hand side is a **finite sum** of ordinals each strictly less than `ω^X`.  
Since `ω^X` is an **additive principal** ordinal (a power of `ω`, see `Ordinal.add_principal`), any finite sum of ordinals less than `ω^X` is again less than `ω^X`.  
Consequently, the left‑hand side is `< ω^X`.

Finally, the right‑hand side is `ω^X + (ω·(mu b+1) + 1)`, which is `≥ ω^X`.  
Hence `LHS < RHS`, as required.

**Lemmas to use**  
`opow_pos`, `opow_lt_opow_right`, `add_lt_add`, `lt_of_lt_of_le`, `le_mul_right`, `Ordinal.add_principal` (or explicit bounding via `opow_lt_opow_right` on each summand).

### 2. `R_eq_refl` – `eqW a a ⟶ void`

**Goal**  
`mu void < mu (eqW a a)`, i.e. `0 < ω⁽²·ᵐᵘ ᵃ + ⁹⁾ + 1`.

**Proof**  

`omega0^α` is strictly positive for every ordinal `α` (lemma `opow_pos`).  
Therefore `omega0^(mu a + mu a + 9) > 0`.  
Adding `1` yields `ω⁽²·ᵐᵘ ᵃ + ⁹⁾ + 1 > 0`.  
With `simp [mu]` this is immediate:

```lean4
have hpos := opow_pos (mu a + mu a + (9 : Ordinal)) omega0_pos
-- hpos : 0 < omega0 ^ (mu a + mu a + 9)
simpa [mu] using add_pos_of_pos_of_nonneg hpos (by norm_num)
```

### 3. `R_eq_diff` – `eqW a b ⟶ integrate (merge a b)`

**Goal**  
`mu (integrate (merge a b)) < mu (eqW a b)`

**Expanded measures**  

- `mu(eqW a b) = ω⁽ᵐᵘ ᵃ + ᵐᵘ ᵇ + ⁹⁾ + 1`
- `mu(integrate (merge a b)) = ω⁴·(mu(merge a b) + 1) + 1`
  with `mu(merge a b) = ω³·(mu a + 1) + ω²·(mu b + 1) + 1`.

Hence `mu(integrate (merge a b))` expands to  
`ω⁴·( ω³·(mu a+1) + ω²·(mu b+1) + 2 ) + 1`  
= `ω⁷·(mu a+1) + ω⁶·(mu b+1) + ω⁴·2 + 1`.

**Key comparison**  

We show the whole left‑hand side is `< ω⁽ᵐᵘ ᵃ + ᵐᵘ ᵇ + ⁹⁾`.  
Because the right‑hand side is `ω⁽ᵐᵘ ᵃ + ᵐᵘ ᵇ + ⁹⁾ + 1`, this proves the inequality.

**Bounding each term**  

- `ω⁷·(mu a+1) ≤ ω⁷·ω⁽ᵐᵘ ᵃ⁺¹⁾ = ω⁽ᵐᵘ ᵃ + ⁸⁾` (using `mu a+1 ≤ ω⁽ᵐᵘ ᵃ⁺¹⁾`, which holds because `ω^α ≥ α` for any `α`).  
  Then `omega⁽ᵐᵘ ᵃ + ⁸⁾ < omega⁽ᵐᵘ ᵃ + ᵐᵘ ᵇ + ⁹⁾` because `mu a + 8 < mu a + mu b + 9` (since `mu b ≥ 0` implies `8 < mu b + 9`).  
  Hence `ω⁷·(mu a+1) < ω⁽ᵐᵘ ᵃ + ᵐᵘ ᵇ + ⁹⁾`.

- `ω⁶·(mu b+1)` is bounded in the same way:  
  `ω⁶·(mu b+1) ≤ ω⁶·ω⁽ᵐᵘ ᵇ⁺¹⁾ = ω⁽ᵐᵘ ᵇ + ⁷⁾` and `mu b + 7 < mu a + mu b + 9` (since `mu a ≥ 0`).  
  Thus `ω⁶·(mu b+1) < ω⁽ᵐᵘ ᵃ + ᵐᵘ ᵇ + ⁹⁾`.

- The constant term `ω⁴·2 + 1` is finite with respect to `ω⁽ᵐᵘ ᵃ + ᵐᵘ ᵇ + ⁹⁾` when `mu a + mu b + 9 ≥ 1` (which is always true).  
  For instance, `omega⁴·2 < omega⁹ ≤ ω⁽ᵐᵘ ᵃ + ᵐᵘ ᵇ + ⁹⁾` (since the exponent is at least 9).

Since the three parts are all `< ω⁽ᵐᵘ ᵃ + ᵐᵘ ᵇ + ⁹⁾`, their sum (the left‑hand side) is also `< ω⁽ᵐᵘ ᵃ + ᵐᵘ ᵇ + ⁹⁾` because `ω⁽ᵐᵘ ᵃ + ᵐᵘ ᵇ + ⁹⁾` is additive principal.  
Thus `LHS < ω⁽ᵐᵘ ᵃ + ᵐᵘ ᵇ + ⁹⁾ ≤ RHS`, completing the proof.

**Lemmas to use**  
`opow_lt_opow_right`, `opow_pos`, `le_mul_right`, `add_lt_add`, `lt_of_lt_of_le`, `Ordinal.add_principal` (or explicit bounding via repeated `opow_lt`), plus the elementary inequality `α ≤ ω^α`.
