To complete the remaining three cases (`R_rec_succ`, `R_eq_refl`, and `R_eq_diff`), we must perform ordinal arithmetic. Since ordinal addition and multiplication are non-commutative, a direct algebraic expansion can be difficult. 

The most robust strategy is to **use coarse upper bounds** (bounding expressions by larger powers of $\omega_0$) to simplify the terms before applying monotonicity of exponentiation.

Below is a detailed proof skeleton and strategy for each of the three remaining cases.

---

### 1. Case `R_eq_refl` (eqW a a → void)

This is the simplest case. Since $\mu(\text{void}) = 0$, we only need to show that the RHS is strictly positive. Any ordinal of the form $\alpha + 1$ is strictly positive.

#### Proof Skeleton:
```lean
-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    simp [mu]
    -- Since any ordinal of the form X + 1 is strictly positive:
    exact Ordinal.pos_iff_ne_zero.mpr (by
      apply ne_of_gt
      exact add_pos_right _ one_pos)
```

### 2. Case `R_eq_diff` (eqW a b → integrate (merge a b))

We need to show:
$$\mu(\text{integrate}(\text{merge } a\ b)) < \mu(\text{eqW } a\ b)$$
Unfolding the definition of $\mu$, this requires proving:
$$\omega_0^4 \cdot (\omega_0^3 \cdot (\mu(a) + 1) + \omega_0^2 \cdot (\mu(b) + 1) + 2) + 1 < \omega_0^{\mu(a) + \mu(b) + 9} + 1$$

#### Mathematical Strategy:
1. **Bound the Inner Terms**: 
   - Since $\mu(a) + 1 < \omega_0^{\mu(a)+1}$, we have $\omega_0^3 \cdot (\mu(a) + 1) < \omega_0^{\mu(a) + 4} \le \omega_0^{\mu(a) + \mu(b) + 4}$.
   - Similarly, $\omega_0^2 \cdot (\mu(b) + 1) < \omega_0^{\mu(b) + 3} \le \omega_0^{\mu(a) + \mu(b) + 3}$.
   - Summing these up with the constant $+2$, we can bound the entire inner parenthesis by $\omega_0^{\mu(a) + \mu(b) + 5}$.
2. **Apply Left-Multiplication**: 
   - Left-multiplying by $\omega_0^4$ gives: $\omega_0^4 \cdot \omega_0^{\mu(a) + \mu(b) + 5} = \omega_0^{4 + \mu(a) + \mu(b) + 5}$.
3. **Handle Non-Commutativity**:
   - For any ordinal $x$ and finite $c$, we have $c + x \le x + c$. 
   - Thus, $4 + \mu(a) + \mu(b) + 5 \le \mu(a) + \mu(b) + 9$.
   - This yields the desired strict upper bound.

#### Proof Skeleton:
```lean
-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    simp [mu]
    -- Step 1: Establish coarse upper bounds for individual components of merge
    have h_a : omega0 ^ (3 : Ordinal) * (mu a + 1) < omega0 ^ (mu a + mu b + 4) := sorry
    have h_b : omega0 ^ (2 : Ordinal) * (mu b + 1) < omega0 ^ (mu a + mu b + 3) := sorry
    
    -- Step 2: Combine to bound the inner sum of the integrate-merge term
    have h_inner : omega0 ^ (3 : Ordinal) * (mu a + 1) + omega0 ^ (2 : Ordinal) * (mu b + 1) + 2 
                   < omega0 ^ (mu a + mu b + 5) := sorry

    -- Step 3: Apply left-multiplication by omega^4
    have h_mult : omega0 ^ (4 : Ordinal) * (omega0 ^ (3 : Ordinal) * (mu a + 1) + omega0 ^ (2 : Ordinal) * (mu b + 1) + 2)
                  < omega0 ^ (4 + (mu a + mu b + 5)) := sorry

    -- Step 4: Resolve the non-commutative exponent addition
    have h_exp : 4 + (mu a + mu b + 5) ≤ mu a + mu b + 9 := sorry
    have h_final_bound : omega0 ^ (4 + (mu a + mu b + 5)) ≤ omega0 ^ (mu a + mu b + 9) := sorry

    -- Step 5: Put it all together using calc
    calc omega0 ^ (4 : Ordinal) * (omega0 ^ (3 : Ordinal) * (mu a + 1) + omega0 ^ (2 : Ordinal) * (mu b + 1) + 1 + 1) + 1
      _ < omega0 ^ (4 + (mu a + mu b + 5)) + 1 := by sorry
      _ ≤ omega0 ^ (mu a + mu b + 9) + 1       := by sorry
```

### 3. Case `R_rec_succ` (recDelta b s (delta n) → app s (recDelta b s n))

We need to show:
$$\mu(\text{app } s\ (\text{recDelta } b\ s\ n)) < \mu(\text{recDelta } b\ s\ (\text{delta } n))$$
Unfolding the definition of $\mu$, this requires proving:
$$\omega_0^3 \cdot (\mu(s) + 1) + \omega_0^2 \cdot (\omega_0^{\mu(n) + \mu(s) + 6} + \omega_0 \cdot (\mu(b) + 1) + 2) + 1 < \omega_0^{\mu(\text{delta } n) + \mu(s) + 6} + \omega_0 \cdot (\mu(b) + 1) + 1$$

#### Mathematical Strategy:
- The RHS contains a massive tower exponent $\mu(\text{delta } n) + \mu(s) + 6 = \omega_0^5 \cdot (\mu(n) + 1) + \mu(s) + 7$.
- The LHS contains a smaller exponent $\mu(n) + \mu(s) + 6$.
- When the LHS is multiplied by $\omega_0^2$, the term containing $\mu(b)$ becomes $\omega_0^3 \cdot (\mu(b) + 1)$, while in the RHS it is only $\omega_0 \cdot (\mu(b) + 1)$.
- Because $\mu(b)$ is arbitrary and can absorb the other terms if it is very large, we must leverage the fact that $\omega_0^2 \cdot (\omega_0^X + Y) = \omega_0^{2+X} + \omega_0^2 \cdot Y$ for limit ordinals $X$. This allows us to separate the recursion step from the term $b$ and show that the tower term $\omega_0^{\omega_0^5 \cdots}$ strictly dominates the rest of the expression.

#### Proof Skeleton:
```lean
-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    simp [mu]
    -- Step 1: Isolate the giant exponent on the RHS
    let exp_RHS := omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + 6
    
    -- Step 2: Distribute the omega^2 multiplication across the LHS limit ordinal term
    have h_distrib : omega0 ^ (2 : Ordinal) * (omega0 ^ (mu n + mu s + 6) + omega0 * (mu b + 1) + 2)
                     = omega0 ^ (mu n + mu s + 8) + omega0 ^ (3 : Ordinal) * (mu b + 1) + 2 * omega0 ^ (2 : Ordinal) := sorry

    -- Step 3: Show that the exponent exp_RHS strictly dominates all s and n terms in LHS
    have h_dom : omega0 ^ (3 : Ordinal) * (mu s + 1) + omega0 ^ (mu n + mu s + 8) < omega0 ^ exp_RHS := sorry

    -- Step 4: Re-assemble and apply monotonicity to show LHS < RHS
    sorry
```
