# Proof Skeleton for Remaining Cases

Based on the structure and patterns from the proved cases, here are proof skeletons for the three `sorry` cases:

## Case 1: `R_rec_succ` (recDelta b s (delta n) --> app s (recDelta b s n))

```lean
| _, _, Step.R_rec_succ b s n => by
    simp [mu]
    -- Key insight: omega^5 * (mu n + 1) dominates mu(n) + mu(s) + 6
    -- so omega^(omega^5 * (mu n + 1) + 1 + mu s + 6 + ...) 
    -- dominates the omega^3 and omega^2 terms on RHS
    
    -- Step 1: Show that the exponent on LHS is large
    have h_exp_large : omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + 6 
                     > mu n + mu s + 6 := by omega
    
    -- Step 2: Use monotonicity of exponentiation
    have h_exp_mono : omega0 ^ (mu n + mu s + 6) 
                    < omega0 ^ (omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + 6) := by
      apply opow_lt_opow_left omega0_pos h_exp_large
    
    -- Step 3: Show this dominates the RHS
    calc omega0 ^ (3 : Ordinal) * (mu s + 1) 
         + omega0 ^ (2 : Ordinal) * (omega0 ^ (mu n + mu s + 6) + omega0 * (mu b + 1) + 1 + 1) + 1
      _ < omega0 ^ (omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + 6) 
         + omega0 * (mu b + 1) + 1 := by
      sorry  -- Ordinal arithmetic: higher exponent dominates lower poly terms
```

## Case 2: `R_eq_refl` (eqW a a --> void)

```lean
| _, _, Step.R_eq_refl a => by
    simp [mu]
    -- Straightforward positivity: 0 < omega^(2*mu(a) + 9) + 1
    
    -- Step 1: Show the exponent is positive
    have h_exp_pos : (0 : Ordinal) < mu a + mu a + 9 := by omega
    
    -- Step 2: omega^(positive) is positive
    have h_omega_pow : (0 : Ordinal) < omega0 ^ (mu a + mu a + 9) := by
      apply opow_pos omega0_pos
    
    -- Step 3: Adding 1 preserves positivity
    exact Ordinal.add_pos_right _ h_omega_pow
```

## Case 3: `R_eq_diff` (eqW a b --> integrate (merge a b))

```lean
| _, _, Step.R_eq_diff a b => by
    simp [mu]
    -- mu(LHS) = omega^4 * (omega^3 * (mu a + 1) + omega^2 * (mu b + 1) + 2) + 1
    -- mu(RHS) = omega^(mu a + mu b + 9) + 1
    -- Need: LHS < RHS
    
    -- Step 1: The exponent on RHS dominates all polynomial terms on LHS
    have h_exp_large : mu a + mu b + 9 > 4 := by omega
    
    -- Step 2: omega^k grows faster than polynomial in lower-order terms
    have h_dominates : omega0 ^ (4 : Ordinal) * (omega0 ^ (3 : Ordinal) * (mu a + 1) 
                                                  + omega0 ^ (2 : Ordinal) * (mu b + 1) + 2)
                     < omega0 ^ (mu a + mu b + 9) := by
      -- Key: omega^(mu a + mu b + 9) > omega^4 * anything with smaller exponents
      apply Ordinal.lt_of_lt_of_le
      · apply opow_lt_opow_left omega0_pos h_exp_large
      · sorry  -- ordinal arithmetic showing the polynomial is bounded by the high exponent
    
    -- Step 3: Conclude the full inequality
    calc omega0 ^ (4 : Ordinal) * (omega0 ^ (3 : Ordinal) * (mu a + 1) 
                                   + omega0 ^ (2 : Ordinal) * (mu b + 1) + 2) + 1
      _ < omega0 ^ (mu a + mu b + 9) + 1 := by
      apply Ordinal.add_lt_add_right h_dominates
```

These skeletons follow the pattern established in the proved cases: identify the dominating term, use ordinal monotonicity lemmas (`opow_lt_opow_left`, `le_mul_right`, `lt_of_lt_of_le`), and build up the inequality chain using `calc`.
