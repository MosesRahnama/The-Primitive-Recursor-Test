# Proof Skeleton for Remaining Cases

Based on the structure of the file and the patterns established in the proved cases, here is a proof skeleton for the three `sorry` cases:

```lean
-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    simp [mu]
    -- Strategy: Show that omega^(omega^5 * (mu n + 1) + 1 + mu s + 6) dominates
    -- the RHS which has exponent only mu(n) + mu(s) + 6
    have h_delta_large : omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + 6 
                         > mu n + mu s + 6 := by
      -- omega^5 * (mu n + 1) is vastly larger than mu n
      have : omega0 ^ (5 : Ordinal) * (mu n + 1) > mu n + mu s := by
        have h1 : mu n < mu n + 1 := lt_add_one _
        have h2 : mu n + 1 ≤ omega0 ^ (5 : Ordinal) * (mu n + 1) :=
          le_mul_right _ (opow_pos 5 omega0_pos)
        omega
      omega
    have h_lhs_exp : omega0 ^ (omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + 6) 
                     > omega0 ^ (mu n + mu s + 6) := by
      apply opow_lt_opow_left omega0_pos
      exact h_delta_large
    -- This dominates all terms on the RHS
    calc mu (app s (recDelta b s n))
      _ = omega0 ^ (3 : Ordinal) * (mu s + 1) + omega0 ^ (2 : Ordinal) * (mu (recDelta b s n) + 1) + 1 := by simp [mu]
      _ ≤ omega0 ^ (3 : Ordinal) * (mu s + 1) + omega0 ^ (2 : Ordinal) * omega0 ^ (mu n + mu s + 6) + 1 := by
          gcongr
          omega
      _ < omega0 ^ (omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + 6) + omega0 * (mu b + 1) + 1 := by
          -- The exponent on LHS is much smaller than on RHS
          have : omega0 ^ (3 : Ordinal) * (mu s + 1) + omega0 ^ (2 : Ordinal) * omega0 ^ (mu n + mu s + 6) + 1 
                  < omega0 ^ (mu n + mu s + 6 + 1) := by omega
          have : omega0 ^ (mu n + mu s + 6 + 1) 
                  < omega0 ^ (omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + 6) := by
            apply opow_lt_opow_left omega0_pos
            exact h_delta_large
          omega
      _ = mu (recDelta b s (delta n)) := by simp [mu]

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    simp [mu]
    -- Show: 0 < omega^(mu a + mu a + 9) + 1

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    simp [mu]
    -- Strategy: Show that omega^(mu a + mu b + 9) dominates all terms on LHS
    -- mu(integrate (merge a b)) = omega^4 * (omega^3 * (mu a + 1) + omega^2 * (mu b + 1) + 2) + 1
    -- We need this < omega^(mu a + mu b + 9) + 1
    have h_exp_ineq : (4 : Ordinal) < mu a + mu b + (9 : Ordinal) := by omega
    have h_rhs_exp : omega0 ^ (4 : Ordinal) * (omega0 ^ (3 : Ordinal) * (mu a + 1) + omega0 ^ (2 : Ordinal) * (mu b + 1) + 2)
                     < omega0 ^ (mu a + mu b + 9) := by
      have : omega0 ^ (3 : Ordinal) * (mu a + 1) + omega0 ^ (2 : Ordinal) * (mu b + 1) + 2 
              < omega0 ^ (mu a + mu b + 5) := by omega
      have : omega0 ^ (4 : Ordinal) * omega0 ^ (mu a + mu b + 5) 
              = omega0 ^ (mu a + mu b + (9 : Ordinal)) := by ring
      calc omega0 ^ (4 : Ordinal) * (omega0 ^ (3 : Ordinal) * (mu a + 1) + omega0 ^ (2 : Ordinal) * (mu b + 1) + 2)
        _ < omega0 ^ (4 : Ordinal) * omega0 ^ (mu a + mu b + 5) := by omega
        _ = omega0 ^ (mu a + mu b + 9) := by ring
    calc mu (integrate (merge a b))
      _ = omega0 ^ (4 : Ordinal) * (mu (merge a b) + 1) + 1 := by simp [mu]
      _ < omega0 ^ (mu a + mu b + 9) + 1 := by omega
      _ = mu (eqW a b) := by simp [mu]
```

The skeleton follows these key patterns:
1. **R_rec_succ**: Uses the fact that `omega^5 * (mu n + 1)` in the exponent of the LHS vastly exceeds the simpler exponent `mu n + mu s + 6` on the RHS
2. **R_eq_refl**: Simple positivity of ordinal exponentiation
3. **R_eq_diff**: Shows that exponent 4 is dominated by `mu a + mu b + 9`, making the RHS larger
