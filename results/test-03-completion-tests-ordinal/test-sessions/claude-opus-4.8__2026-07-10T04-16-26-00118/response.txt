# Proof Skeletons for the Three Remaining Cases

Below are proof skeletons for the three `sorry` cases. I'll present each with the key lemmas needed and a structured approach.

## Case 2: `R_eq_refl` (easiest — pure positivity)

This one is the simplest. After `simp [mu]`, the goal is essentially `0 < omega0 ^ (...) + 1`.

```lean
| _, _, Step.R_eq_refl a => by
    simp [mu]
    -- Goal (roughly): 0 < omega0 ^ (mu a + mu a + 9) + 1
    exact Ordinal.pos_iff_ne_zero.mpr (by
      apply ne_of_gt
      exact add_pos_right _ one_pos)
    -- Alternatively, if simp normalizes the goal to `0 < _`:
    -- exact add_pos_right _ one_pos
    -- or:  exact lt_of_lt_of_le one_pos (le_add_left _ _)  -- adjust as needed
```

**Note:** Inspect the exact post-`simp` goal. If `simp` closes the `+ 1` positivity itself, this may already be discharged. The robust fallback is `positivity`-style reasoning: `Ordinal.pos_iff_ne_zero.mpr (ne_of_gt (add_pos_right _ one_pos))`.

## Case 3: `R_eq_diff` (exponent domination, single ordinal)

Here we compare `omega0 ^ 4 * (M + 1) + 1` against `omega0 ^ (mu a + mu b + 9) + 1`, where `M = mu(merge a b)`. Strategy: reduce to comparing the `omega0 ^ (...)` heads via strict monotonicity of `opow` in the exponent.

```lean
| _, _, Step.R_eq_diff a b => by
    simp [mu]
    -- Let E := mu a + mu b + 9  (the RHS exponent)
    -- Let M := omega0^3*(mu a+1) + omega0^2*(mu b+1) + 1  (= mu (merge a b))
    -- Goal: omega0^4 * (M + 1) + 1 < omega0^(E) + 1

    -- KEY LEMMA A: omega0^4 * (M + 1) < omega0 ^ E, so the +1's are dominated.
    -- To get this, bound the LHS by a single power of omega0 with a smaller exponent.

    -- Step 1: M < omega0 ^ 4  (since M is a sum of omega0^3,omega0^2 blocks).
    --   Actually we need M+1 to be absorbed. Show:
    --   omega0^4 * (M + 1) < omega0 ^ (4 + (something ≤ E)).
    -- Use: omega0^4 * (M+1) ≤ omega0^4 * omega0^k = omega0^(4+k)
    --   whenever M+1 ≤ omega0^k for suitable k.

    -- Concretely: M + 1 < omega0 ^ (mu a + mu b + 4)  (heuristic: 3+... dominated)
    --   because omega0^3*(mu a+1) ≤ omega0^(mu a + 3) etc.

    have hM : (omega0 ^ (3:Ordinal) * (mu a + 1)
               + omega0 ^ (2:Ordinal) * (mu b + 1) + 1) + 1
              < omega0 ^ (mu a + mu b + 4) := by
      sorry  -- bound each block: omega0^3*(mu a+1) ≤ omega0^(mu a+3), etc.
             -- use mul_le_of_le_opow / opow_add and add-absorption of lower terms

    -- Step 2: multiply by omega0^4 and use opow_add
    have hmul : omega0 ^ (4:Ordinal) * (mu (merge a b) + 1)
                < omega0 ^ (4 + (mu a + mu b + 4)) := by
      calc omega0 ^ (4:Ordinal) * (mu (merge a b) + 1)
          _ < omega0 ^ (4:Ordinal) * omega0 ^ (mu a + mu b + 4) := by
                apply (Ordinal.mul_lt_mul_iff_left (opow_pos 4 omega0_pos)).mpr
                exact hM
        _ = omega0 ^ (4 + (mu a + mu b + 4)) := (opow_add omega0 _ _).symm

    -- Step 3: 4 + (mu a + mu b + 4) < mu a + mu b + 9  is FALSE additively,
    --   but ordinal addition is left-absorbing: for infinite mu a,
    --   4 + (mu a + mu b + 4) = mu a + mu b + 4 (natural absorption).
    --   Then mu a + mu b + 4 < mu a + mu b + 9.  Handle the finite/zero cases too.
    have hexp : (4 : Ordinal) + (mu a + mu b + 4) ≤ mu a + mu b + 9 := by
      sorry  -- rewrite via add_assoc and use `Ordinal.add_le_add_right`;
             -- if needed case on whether mu a is 0/finite, but the ≤ 9 slack covers 4+4=8 ≤ 9

    -- Step 4: chain everything and re-absorb the +1's
    have hpow : omega0 ^ (4 + (mu a + mu b + 4)) ≤ omega0 ^ (mu a + mu b + 9) :=
      opow_le_opow_right omega0_pos hexp
    calc omega0 ^ (4:Ordinal) * (mu (merge a b) + 1) + 1
        _ < omega0 ^ (mu a + mu b + 9) := by
              -- LHS < omega0^(...) since a power of omega0 is a limit/principal ordinal,
              -- so adding 1 to something strictly below it stays below.
              sorry  -- use `Principal.add` for additive-principality of omega0^e,
                     -- i.e. x + 1 < omega0^e when x < omega0^e (Ordinal.principal_add_omega0_opow)
      _ ≤ omega0 ^ (mu a + mu b + 9) + 1 := le_add_right _ _
```

**Key mathlib lemmas to locate:**
- `opow_add : a ^ (b + c) = a ^ b * a ^ c`
- `opow_le_opow_right : 0 < a → b ≤ c → a ^ b ≤ a ^ c`
- `mul_lt_mul_iff_left` (left-cancellative strict monotonicity for positive left factor)
- **Additive principality:** `omega0 ^ e` is additively principal, so `x < omega0^e → x + 1 < omega0^e`. Search `Ordinal.principal_add_omega0_opow` or `Principal.add_lt` / `principal_add_iff_add_lt_ne_self`. This is the crux for absorbing the trailing `+ 1`.

## Case 1: `R_rec_succ` (hardest — exponent dominates a compound RHS)

Here `mu(delta n) = omega0^5 * (mu n + 1) + 1` sits inside the LHS exponent, and it must dominate the RHS which is `omega0^3*(mu s+1) + omega0^2*(mu(recDelta b s n)+1) + 1`.

```lean
| _, _, Step.R_rec_succ b s n => by
    simp [mu]
    -- LHS  = omega0 ^ (mu (delta n) + mu s + 6) + omega0 * (mu b + 1) + 1
    --      = omega0 ^ ((omega0^5*(mu n+1)+1) + mu s + 6) + ...
    -- RHS  = omega0^3*(mu s+1)
    --        + omega0^2*((omega0^(mu n+mu s+6) + omega0*(mu b+1) + 1) + 1) + 1
    --
    -- Abbreviations:
    set En := mu n + mu s + 6 with hEn         -- inner rec exponent
    set L  := (omega0^5*(mu n+1) + 1) + mu s + 6 with hL   -- LHS exponent

    -- MASTER STRATEGY: show RHS < omega0 ^ L  (a single power dominates all of RHS),
    -- then RHS < omega0^L ≤ LHS by le_add_right, absorbing lower-order LHS terms.

    -- Step A: bound the inner recDelta measure by a power with exponent < L.
    --   omega0^En + omega0*(mu b+1) + 1  <  omega0 ^ (En + 1)   (principality/absorption)
    have hinner : omega0 ^ En + omega0 * (mu b + 1) + 1 < omega0 ^ (En + 1) := by
      sorry  -- omega0^(En+1) = omega0^En * omega0 is additively-principal and
             -- strictly above omega0^En + (finite-ish tail). Use opow_add + principality.

    -- Step B: bound each RHS block by a single power:
    --   omega0^3*(mu s+1) < omega0^(mu s + 4)
    --   omega0^2*(X+1)    < omega0^2 * omega0^(En+1) = omega0^(En+3)   where X = inner
    -- Combine: RHS < omega0 ^ (max exponent + 1) ≤ omega0 ^ Q for some Q we control.
    have hRHS : (omega0^(3:Ordinal)*(mu s+1)
                 + omega0^(2:Ordinal)*((omega0^En + omega0*(mu b+1) + 1) + 1) + 1)
                < omega0 ^ (En + 4) := by
      sorry  -- bound blocks via opow_add and re-absorb lower terms into omega0^(En+4)

    -- Step C: the crucial exponent comparison En + 4 < L.
    --   L = (omega0^5*(mu n+1) + 1) + mu s + 6.
    --   En + 4 = mu n + mu s + 10.
    --   Since omega0^5*(mu n+1) ≥ omega0^5 ≫ mu n, and left-absorption gives
    --   L = omega0^5*(mu n+1) + (1 + mu s + 6)  with head omega0^5*(...) dominating.
    --   Hence mu n + mu s + 10 < omega0^5*(mu n+1) + ... = L.
    have hexp : En + 4 < L := by
      -- unfold En, L
      simp only [hEn, hL]
      -- Show mu n + mu s + 10 < omega0^5*(mu n+1) + 1 + mu s + 6.
      -- Head domination: omega0^5*(mu n+1) ≥ omega0^5 > any finite + mu n + mu s tail
      -- when combined additively. Prove via:
      --   mu n + mu s + 10 < omega0^5 ≤ omega0^5*(mu n+1) ≤ L
      have h1 : mu n + mu s + 10 < omega0 ^ (5:Ordinal) := by
        sorry  -- mu n, mu s < omega0^5 (structural: every mu t < omega0^5?);
               -- if not provable directly, instead show < omega0^5*(mu n+1):
               -- mu n + mu s + 10 ≤ omega0^5*(mu n+1) by absorption since
               -- omega0^5*(mu n+1) ≥ omega0^5*(mu n+1) has head omega0^5.
      have h2 : omega0 ^ (5:Ordinal) ≤ omega0^(5:Ordinal)*(mu n+1) :=
        le_mul_right _ (by exact_mod_cast Nat.succ_pos 0)  -- 0 < mu n + 1
      have h3 : omega0^(5:Ordinal)*(mu n+1)
                ≤ omega0^(5:Ordinal)*(mu n+1) + 1 + mu s + 6 := by
        refine le_trans (le_add_right _ _) ?_
        refine le_trans (le_add_right _ _) ?_
        exact le_add_right _ _
      exact lt_of_lt_of_le (lt_of_lt_of_le h1 h2) h3

    -- Step D: assemble.
    have hpow : omega0 ^ (En + 4) ≤ omega0 ^ L := opow_le_opow_right omega0_pos (le_of_lt hexp)
    calc (omega0^(3:Ordinal)*(mu s+1)
           + omega0^(2:Ordinal)*((omega0^En + omega0*(mu b+1) + 1) + 1) + 1)
        _ < omega0 ^ (En + 4) := hRHS
      _ ≤ omega0 ^ L := hpow
      _ ≤ omega0 ^ L + omega0 * (mu b + 1) + 1 := by
            refine le_trans (le_add_right _ _) (le_add_right _ _)
```

## Summary of the Reusable Lemma Toolkit

Locate/confirm these before filling `sorry`s:

| Purpose | Candidate lemma |
|---|---|
| Split exponent product | `opow_add : a^(b+c) = a^b * a^c` |
| Monotone in exponent (≤) | `opow_le_opow_right : 0 < a → b ≤ c → a^b ≤ a^c` |
| Strict monotone in exponent | `opow_lt_opow_right` / `opow_lt_opow_iff_right` |
| Left mul strict-mono | `mul_lt_mul_iff_left` (pos left factor) |
| **Additive principality** (absorb `+1`, `+ lower`) | `Ordinal.principal_add_omega0_opow`, `Principal.add_lt`, `principal_add_iff_add_left_eq_self` |
| Base positivity | `omega0_pos`, `opow_pos` |
| Trivial bounds | `le_add_right`, `le_add_left`, `le_mul_right`, `lt_add_one` |

**Most important gap:** all three cases hinge on the fact that a power `omega0 ^ e` is **additively principal** — i.e. sums of strictly-smaller ordinals (including trailing `+1`s and lower `omega0^k` blocks) stay strictly below it. Establishing one reusable helper:

```lean
have absorb : ∀ (x : Ordinal) (e : Ordinal), 0 < e → x < omega0 ^ e → x + 1 < omega0 ^ e := ...
```

(built from principality of `omega0^e`) will discharge the trailing-`+1` obligations uniformly across cases 1 and 3.
