For the `R_rec_succ` and `R_eq_diff` cases, completing the proofs from first principles in mathlib requires lengthy manipulations of ordinal arithmetic operations. The skeletons below decompose the remaining goals into smaller sub-goals using `have` statements to demonstrate the strict domination of the exponents, which isolates the "careful ordinal arithmetic" into specific `sorry` blocks.

| _, _, Step.R_rec_succ b s n => by
    simp [mu]

    have h_exp : mu n + mu s + (6 : Ordinal) < omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + (6 : Ordinal) := by sorry

    have h_dom : omega0 ^ (3 : Ordinal) * (mu s + 1) + omega0 ^ (2 : Ordinal) * (omega0 ^ (mu n + mu s + (6 : Ordinal)) + omega0 * (mu b + 1) + 1 + 1) < omega0 ^ (omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + (6 : Ordinal)) := by sorry

    have h_lt : omega0 ^ (3 : Ordinal) * (mu s + 1) + omega0 ^ (2 : Ordinal) * (omega0 ^ (mu n + mu s + (6 : Ordinal)) + omega0 * (mu b + 1) + 1 + 1) + 1 < omega0 ^ (omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + (6 : Ordinal)) + omega0 * (mu b + 1) + 1 := by sorry
