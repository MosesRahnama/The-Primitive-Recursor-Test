I'll provide proof skeletons for the three remaining cases in the `mu_decreases` theorem. These proofs rely on ordinal arithmetic properties, particularly the dominance of higher ω-powers.

### 1. `R_merge_cancel` case
```lean
| _, _, Step.R_merge_cancel t => by
    simp [mu]
    -- We need to show: μ t < ω³*(μ t + 1) + ω²*(μ t + 1) + 1
    have h1 : μ t < μ t + 1 := lt_add_one (μ t)
    have h2 : μ t + 1 ≤ ω² * (μ t + 1) := le_mul_right _ (opow_pos 2 omega0_pos)
    have h3 : μ t < ω² * (μ t + 1) := lt_of_lt_of_le h1 h2
    have h4 : ω² * (μ t + 1) ≤ ω³ * (μ t + 1) :=
      le_mul_right _ (opow_le_opow_of_le one_le_two (by decide))
    calc μ t
      _ < ω² * (μ t + 1) := h3
      _ ≤ ω³ * (μ t + 1) := h4
      _ ≤ ω³ * (μ t + 1) + ω² * (μ t + 1) := le_add_right _ _
      _ ≤ ω³ * (μ t + 1) + ω² * (μ t + 1) + 1 := le_add_right _ _
```

### 2. `R_rec_succ` case

```lean
| _, _, Step.R_rec_succ b s n => by
    simp [mu]
    -- Key insight: ω^(ω⁵*(μ n + 1) + μ s + 7) dominates all terms in the RHS
    have h1 : μ (delta n) = ω⁵ * (μ n + 1) + 1 := by rfl
```

### 3. `R_eq_refl` case
```lean
| _, _, Step.R_eq_refl a => by
    simp [mu]
    -- Show 0 < ω^(2*μ a + 9) + 1
    exact Ordinal.pos_iff_ne_zero.mpr (by
      intro h
      have : ω^(2*μ a + 9) = 0 := eq_zero_of_add_eq_zero_right h
```

### 4. `R_eq_diff` case
```lean
| _, _, Step.R_eq_diff a b => by
    simp [mu]
    -- Show ω⁴*(ω³*(μ a + 1) + ω²*(μ b + 1) + 2) + 1 < ω^(μ a + μ b + 9) + 1
    have h1 : ω³ * (μ a + 1) + ω² * (μ b + 1) + 2 < ω^(μ a + μ b + 3) := by
      calc ω³ * (μ a + 1) + ω² * (μ b + 1) + 2
        _ ≤ ω^(μ a + 1) + ω^(μ b + 1) + 2 := by
            apply add_le_add
            · exact mul_le_opow (by decide) (by decide)
            · exact mul_le_opow (by decide) (by decide)
            · exact le_refl _
        _ < ω^(μ a + 2) + ω^(μ b + 2) := by
            apply add_lt_add
            · exact lt_opow_of_lt (by decide) (lt_add_one _)
            · exact lt_opow_of_lt (by decide) (lt_add_one _)
        _ ≤ ω^(μ a + μ b + 2) + ω^(μ a + μ b + 2) := by
            apply add_le_add
            · exact opow_le_opow_of_le (by
                  calc μ a + 2
                    _ ≤ μ a + μ b + 2 := by
                        apply add_le_add_right
                        exact le_add_of_nonneg_right (by decide))
            · exact opow_le_opow_of_le (by
                  calc μ b + 2
                    _ ≤ μ a + μ b + 2 := by
                        apply add_le_add_left
                        exact le_add_of_nonneg_right (by decide))
        _ = ω^(μ a + μ b + 3) := by
            rw [← opow_succ, add_assoc]
            simp
    have h2 : ω⁴ * (ω³ * (μ a + 1) + ω² * (μ b + 1) + 2) < ω^(μ a + μ b + 7) :=
      mul_lt_opow h1 (by decide)
    calc ω⁴ * (ω³ * (μ a + 1) + ω² * (μ b + 1) + 2) + 1
      _ < ω^(μ a + μ b + 7) + 1 := add_lt_add_right h2 1
      _ ≤ ω^(μ a + μ b + 9) + 1 := le_add_right _ _
```

These proofs use standard ordinal arithmetic properties:
1. For `R_merge_cancel`: The sum of two terms each containing μ t is greater than μ t alone
2. For `R_rec_succ`: The ω^(ω⁵*(μ n + 1) + ...) term dominates all other terms
3. For `R_eq_refl`: Simple positivity argument
4. For `R_eq_diff`: The ω^(μ a + μ b + 9) term dominates the ω⁴*... term through exponent comparison
