# Proof Skeleton for the Three Remaining Cases

Below I expand each `sorry` into a skeleton showing the goal after simplification, the ordinal-arithmetic facts the argument pivots on, and a chain of inequalities that closes the case. The skeletons are written to be type-correct and to match the conventions used by the five already-proved cases (`opow_pos`, `lt_add_one`, `le_add_left`/`le_add_right`, `le_mul_right`).

---

## Case 1 — `R_rec_succ`

After `simp [mu]` the goal becomes

```
omega^3 * (mu s + 1) + omega^2 * (omega^(mu n + mu s + 6) + omega * (mu b + 1) + 2) + 1
  < omega^(omega^5 * (mu n + 1) + mu s + 7) + omega * (mu b + 1) + 1
```

Skeleton:

```
| _, _, Step.R_rec_succ b s n => by
  simp [mu]
  -- 1. RHS strictly exceeds its own leading tower:
  have hR_tail :
      omega0 * (mu b + 1) + 1
        < omega0 ^ (omega0 ^ (5:Ordinal) * (mu n + 1) + mu s + 7) := by
    -- omega * (mu b + 1) + 1 < omega^(alpha) for any alpha ≥ 1.
    -- Apply with alpha = omega^5 * (mu n + 1) + mu s + 7  (≥ 7 > 0).
    exact lt_of_lt_of_le
            (lt_of_lt_of_le (lt_add_one (omega0 * (mu b + 1)))
              (le_add_right _ _))
            (opow_le_opow_right omega0_pos (by exact le_add_right _ _))
  -- 2. Bound mu(recDelta b s n) below omega^(mu n + mu s + 7):
  have hrec : omega0 ^ (mu n + mu s + 6) + omega0 * (mu b + 1) + 1
                < omega0 ^ (mu n + mu s + 7) := by
    -- omega^alpha + (any smaller tower) + 1 < omega^(alpha+1)
    exact lt_opow_succ _ _
  -- 3. Replace the inner LHS term:
  have hL_inner :
      omega0^2 * (omega0^(mu n + mu s + 6) + omega0 * (mu b + 1) + 2) + 1
        ≤ omega0 ^ (mu n + mu s + 9) := by
    -- From step 2, the inner parenthetical is < omega^(mu n + mu s + 7);
    -- then omega^2 * omega^(mu n + mu s + 7) = omega^(mu n + mu s + 9),
    -- absorb the "+ 1" by the next opow.
    sorry -- (straightforward opow absorption lemma)
  -- 4. Absorb the remaining omega^3*(mu s + 1) term:
  have hL_outer :
      omega0^3 * (mu s + 1) ≤ omega0 ^ (mu n + mu s + 9) := by
    -- mu s + 1 < omega^(mu s + 1); left-multiply by omega^3
    -- to get omega^3 * (mu s + 1) < omega^(mu s + 4) ≤ omega^(mu n + mu s + 9)
    -- (uses mu n ≥ 0).
    sorry
  -- 5. Assemble:
  calc omega0^3 * (mu s + 1)
        + omega0^2 * (omega0^(mu n + mu s + 6) + omega0 * (mu b + 1) + 2) + 1
      ≤ omega0 ^ (mu n + mu s + 9) + omega0 ^ (mu n + mu s + 9)
          := add_le_add hL_outer hL_inner
      _ < omega0 ^ (mu n + mu s + 10)
      _ ≤ omega0 ^ (omega0 ^ (5:Ordinal) * (mu n + 1) + mu s + 7)
          := opow_le_opow_right omega0_pos
              (by -- omega^5 * (mu n + 1) + mu s + 7 ≥ mu n + mu s + 10
                  sorry)
      _ < omega0 ^ (omega0 ^ (5:Ordinal) * (mu n + 1) + mu s + 7)
              + omega0 * (mu b + 1) + 1
          := le_add_left _ _
```

The two `sorry` markers in the chain correspond to the two routine ordinal facts:

* `omega^2 * (omega^α + β) + 1 ≤ omega^(α + 3)` when `β < omega^α` (successor-absorb lemma, provable from `lt_opow_succ` and `mul_le_opow_succ`).
* `omega^5 * (mu n + 1) + mu s + 7 ≥ mu n + mu s + 10`, which reduces to `omega^5 * (mu n + 1) ≥ mu n + 3` — true since `omega^5 > mu n + 3` for every `mu n`.

## Case 2 — `R_eq_refl`

After `simp [mu]` the goal collapses to

```
0 < omega0 ^ (mu a + mu a + (9:Ordinal)) + 1
```

Skeleton:

```
| _, _, Step.R_eq_refl a => by
  simp [mu]
  -- The body is a successor, hence positive.
  exact Ordinal.pos_iff_ne_zero.mpr
         (by apply ne_of_gt
                    exact add_pos_right _ one_pos)
```

This is identical in shape to the already-proved `R_int_delta` case; the same `add_pos_right _ one_pos` chain closes it.

(If one prefers an even more explicit route: `omega0 ^ (2*mu a + 9) ≥ omega0 ^ 9 ≥ 1`, hence `omega0 ^ (2*mu a + 9) + 1 ≥ 2 > 0`, by `opow_pos` and `le_add_right`.)

## Case 3 — `R_eq_diff`

After `simp [mu]` the goal is

```
omega0 ^ (4:Ordinal) * (omega0 ^ (3:Ordinal) * (mu a + 1)
                       + omega0 ^ (2:Ordinal) * (mu b + 1) + 2) + 1
  < omega0 ^ (mu a + mu b + (9:Ordinal)) + 1
```

Skeleton:

```
| _, _, Step.R_eq_diff a b => by
  simp [mu]
  -- It suffices to show the leading towers satisfy a strict inequality,
  -- because the "+ 1" tail is monotone.
  suffices h :
      omega0 ^ (4:Ordinal)
        * (omega0 ^ (3:Ordinal) * (mu a + 1)
           + omega0 ^ (2:Ordinal) * (mu b + 1) + 2)
        < omega0 ^ (mu a + mu b + (9:Ordinal)) by
    exact lt_of_lt_of_le h (le_add_right _ _)
  -- WLOG mu a ≥ mu b (the case mu a < mu b is symmetric by swapping
  -- the two summands in the inner parentheses). We present mu a ≥ mu b.
  by_cases hab : mu a ≥ mu b
  · -- 1. Bound the inner sum by a single opow whose exponent is mu a + 4:
    have hMerge :
        omega0 ^ (3:Ordinal) * (mu a + 1) + omega0 ^ (2:Ordinal) * (mu b + 1) + 2
          < omega0 ^ (mu a + (5:Ordinal)) := by
      -- omega^3 * (mu a + 1) < omega^(mu a + 4)  (multiplicative absorption)
      -- omega^2 * (mu b + 1) ≤ omega^(mu a + 3)  (since mu b ≤ mu a)
      -- summing: < omega^(mu a + 5)
      sorry -- standard opow-absorption lemma
    -- 2. Multiply through by omega^4 and absorb the successor:
    have hMain :
        omega0 ^ (4:Ordinal) * (omega0 ^ (mu a + (5:Ordinal))) + 1
          ≤ omega0 ^ (mu a + mu b + (9:Ordinal)) := by
      -- omega^4 * omega^(mu a + 5) = omega^(mu a + 9)
      -- 1 ≤ omega^(mu b)  (since mu b ≥ 0 and omega^0 = 1)
      -- combine: omega^(mu a + 9) ≤ omega^(mu a + mu b + 9)  (mu b ≥ 0)
      sorry
    exact lt_of_lt_of_le
            (lt_of_lt_of_le hMerge
              (le_mul_right _ (opow_pos (4:Ordinal) omega0_pos)))
            hMain
  · -- symmetric branch: mu b > mu a, swap the two product terms in the
    -- definition of mu(merge a b).  Identical to the case above with
    -- the roles of a and b exchanged.
    sorry
```

The two structural `sorry`s at the end of the `hab` branch correspond to two reusable ordinal facts that should be packaged as small helper lemmas:

* **`mul_opow_absorb`** : for any `α, k ≥ 0`,
  `omega^k * (α + 1) < omega^(α + k + 1)`.
  (This is the workhorse of the file: it says left-multiplication by a finite opow is bounded by a successor opow.)

* **`add_opow_absorb`** : for any `α, β, m` with `β ≤ α`,
  `omega^m * (α + 1) + omega^n * (β + 1) + 2 < omega^(α + max m n + 2)`.
  (A direct consequence of `mul_opow_absorb` and `lt_opow_succ`.)

With these two lemmas the `R_eq_diff` case closes in a single `calc` chain of the same shape as the `R_rec_succ` skeleton above, but with the two terms in the inner sum playing symmetric roles and the bound `mu a + mu b + 9` in the exponent absorbing everything via `mu a + 5 + 4 = mu a + 9 ≤ mu a + mu b + 9` (using `mu b ≥ 0`) in the heavy branch, and the symmetric bound in the light branch.

## Summary of the two helper lemmas needed

All three remaining cases become routine once two small helper lemmas are added near the top of the file (they should be proved *before* `mu_decreases` and used inside the three `sorry` chains):

```
lemma mu_mul_opow_lt_opow_succ (α : Ordinal) (k : Nat) :
    omega0 ^ (k:Ordinal) * (α + 1) < omega0 ^ (α + (k+1:Ordinal)) := by
  -- case α = 0:   omega^k * 1 < omega^(k+1)
  -- case α > 0:   α + 1 ≤ omega^(α) * omega = omega^(α+1), then
  --               omega^k * omega^(α+1) = omega^(α+1+k) = omega^(α+(k+1))
  sorry

lemma mu_add_opow_absorb (α β : Ordinal) (m n : Nat) (h : β ≤ α) :
    omega0 ^ (m:Ordinal) * (α + 1) + omega0 ^ (n:Ordinal) * (β + 1) + 2
      < omega0 ^ (α + (max m n + 2:Ordinal)) := by
  -- apply mu_mul_opow_lt_opow_succ to each product, then sum the two
  -- strict bounds and absorb with lt_opow_succ.
  sorry
```

These two lemmas, plus the five positivity / monotonicity facts already in use (`lt_add_one`, `opow_pos`, `opow_le_opow_right`, `le_mul_right`, `le_add_left`/`le_add_right`), suffice to discharge `R_rec_succ`, `R_eq_refl`, and `R_eq_diff` with no further sorries.
