### 1) `R_rec_succ` skeleton

```lean
| _, _, Step.R_rec_succ b s n => by
  simp [mu]
  /-
    Goal shape after simp:

      omega0 ^ (3:Ordinal) * (mu s + 1)
        + omega0 ^ (2:Ordinal) * ( (omega0 ^ (mu n + mu s + 6) + omega0 * (mu b + 1) + 1) + 1 )
        + 1
      <
      omega0 ^ ( (omega0 ^ (5:Ordinal) * (mu n + 1) + 1) + mu s + 6 )
        + omega0 * (mu b + 1) + 1

    Strategy:
    1) Bound LHS by something of form < omega0 ^ E where
         E := (omega0^5*(mu n+1)+1)+mu s+6.
    2) Then use omega0^E ≤ omega0^E + omega0*(mu b+1)+1.
  -/
  let E : Ordinal := (omega0 ^ (5 : Ordinal) * (mu n + 1) + 1) + mu s + 6

  have hEpos : 0 < omega0 ^ E := opow_pos _ omega0_pos

  -- Key arithmetic lemma you will want here:
  -- every summand on the LHS is < omega0^E, hence whole LHS < omega0^E.
  have hL : omega0 ^ (3 : Ordinal) * (mu s + 1)
              + omega0 ^ (2 : Ordinal) *
                  (omega0 ^ (mu n + mu s + 6) + omega0 * (mu b + 1) + 1 + 1) + 1
            < omega0 ^ E := by
    -- skeleton:
    -- * show mu n + mu s + 6 < E (because E has leading omega^5*(mu n+1))
    -- * derive omega0^(mu n+mu s+6) < omega0^E via opow_lt_opow_right omega0_pos ...
    -- * absorb polynomial terms (ω^3*, ω^2*, +1) below ω^E
    -- This is the only nontrivial ordinal-comparison block.
    sorry

  calc
    omega0 ^ (3 : Ordinal) * (mu s + 1)
      + omega0 ^ (2 : Ordinal) *
          (omega0 ^ (mu n + mu s + 6) + omega0 * (mu b + 1) + 1 + 1) + 1
      < omega0 ^ E := hL
    _ ≤ omega0 ^ E + (omega0 * (mu b + 1) + 1) := by
          exact le_add_right _ _
```

### 3) `R_eq_diff` skeleton

```lean
| _, _, Step.R_eq_diff a b => by
  simp [mu]
  /-
    Need:

      omega0 ^ (4:Ordinal) *
        (omega0 ^ (3:Ordinal) * (mu a + 1) + omega0 ^ (2:Ordinal) * (mu b + 1) + 1 + 1) + 1
      <
      omega0 ^ (mu a + mu b + 9) + 1

    Strategy:
    1) Show the big product term is < omega0^(mu a + mu b + 9).
    2) Then finish by monotonicity of (+1) on the right / le_add_right.
  -/
  let F : Ordinal := mu a + mu b + 9

  have hMain :
      omega0 ^ (4 : Ordinal) *
        (omega0 ^ (3 : Ordinal) * (mu a + 1)
          + omega0 ^ (2 : Ordinal) * (mu b + 1) + 1 + 1)
      < omega0 ^ F := by
    -- skeleton:
    -- * first show the parenthesized part is bounded by some ω^K with K < F-4 style bound
    -- * then ω^4 * ω^K = ω^(4+K) < ω^F
    -- * use that F = mu a + mu b + 9 is intentionally oversized.
    sorry

  calc
    omega0 ^ (4 : Ordinal) *
      (omega0 ^ (3 : Ordinal) * (mu a + 1)
        + omega0 ^ (2 : Ordinal) * (mu b + 1) + 1 + 1) + 1
      ≤ omega0 ^ F + 1 := by
          exact add_le_add_right (le_of_lt hMain) 1
    _ = omega0 ^ (mu a + mu b + 9) + 1 := by rfl
```

## What auxiliary lemmas you’ll likely need

To actually discharge the two hard `sorry`s (`R_rec_succ`, `R_eq_diff`), you’ll probably want small local lemmas of this pattern:

- monotonicity of `ω^x` in exponent (`x < y → ω^x < ω^y`)
- positivity of `ω^k`
- “adding positive tail makes things bigger”: `x ≤ x + y`
- bounding polynomial-in-ω terms below a higher pure power.

If mathlib names are awkward, proving tiny custom helper lemmas in-place with `calc` + existing inequalities is usually easiest.
