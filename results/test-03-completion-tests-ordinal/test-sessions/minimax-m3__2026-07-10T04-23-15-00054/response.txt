## Skeleton for the three open cases

The measure `mu` is engineered so that every kernel rule sends the "expanded" shape strictly below the "contracted" shape in Cantor-normal-form order. All three open cases are instances of one master pattern:

> after distributing `mu` across the right-hand side, each summand of the right-hand side has a strictly smaller CNF leading exponent than some summand of the left-hand side, and the left-hand side's "big tower" summand is a limit ordinal, so the entire right-hand side lands below it.

The three cases differ only in which summand of the left-hand side does the dominating and how much distribution/rewriting is needed before the comparison is visible. I work through them in order of difficulty, beginning with the easy positivity case and ending with `R_rec_succ` (the one that requires the most care).

---

### 0. Lemmas you will need (most are already in Mathlib)

```lean
-- Strict left-monotonicity of right addition.
add_lt_add_iff_right :  a + c < b + c ↔ a < b        -- Mathlib: Ordinal.add_lt_add_iff_right
add_le_add_iff_right :  a + c ≤ b + c ↔ a ≤ b

-- Monotonicity / strict monotonicity of right multiplication.
le_mul_right           :  0 < a → a ≤ a * b          -- "le_mul_right _ ha"
mul_le_mul_right       :  0 < a → b ≤ c → b * a ≤ c * a

-- Monotonicity / strict monotonicity of ordinal exponentiation in the *right* argument.
opow_le_opow_right     :  0 < a → b ≤ c → a ^ b ≤ a ^ c
opow_lt_opow_right     :  0 < a → b < c → a ^ b < a ^c

-- omega is positive / greater than 1.
omega0_pos / one_lt_omega0 : (0 : Ordinal) < omega0, (1 : Ordinal) < omega0
opow_pos              :  0 < a → 0 < a ^ b

-- omega^a is a limit ordinal whenever a > 0  → lets us absorb finite sums.
isLimit_opow          :  0 < a → (omega0 ^ a).IsLimit

-- For limit L, x < L and y < L implies x + y < L  (sometimes stated via IsLimit).
IsLimit.add_lt        :  L.IsLimit → x < L → y < L → x + y < L

-- Right multiplication by a positive ordinal with right coefficient > 1 is strictly increasing.
-- (Specifically the inequality we will need: alpha < omega^β * alpha for alpha > 0, beta > 0
--  and alpha a successor.  This is the one "bespoke" fact the proof genuinely needs.)
lt_mul_of_one_lt_left :  0 < a → 1 < b → a < b * a
-- (or proved ad hoc — see the per-case argument below)
```

### Case A — `Step.R_eq_refl a`  (the easy one)

**Goal:** `0 < omega^(2 * mu a + 9) + 1`.

**Strategy:** `omega^(2 * mu a + 9) + 1` is a successor ordinal, hence strictly positive. No distributive work or exponent comparison is needed.

**Skeleton:**
```lean
| _, _, Step.R_eq_refl a => by
    simp [mu]
    -- Goal: 0 < omega^(2 * mu a + 9) + 1
    exact add_pos_right _ one_pos        -- or: `exact one_pos.trans (le_add_right _ _)`
```

---

### Case B — `Step.R_eq_diff a b`

**Goal:** `mu(integrate (merge a b)) < mu(eqW a b)`, i.e.

```
omega^4 * (omega^3 * (mu a + 1) + omega^2 * (mu b + 1) + 1 + 1) + 1
  < omega^(mu a + mu b + 9) + 1.
```

**Step 1 — Drop the trailing `+1` on both sides.**
Both sides are successors, so the inequality is equivalent to:

```
omega^4 * (omega^3*(mu a+1) + omega^2*(mu b+1) + 2) < omega^(mu a + mu b + 9).
```

**Step 2 — Distribute the outer `omega^4`.**
Using `mul_add` and `mul_one`:

```
LHS = omega^7 * (mu a + 1)
    + omega^6 * (mu b + 1)
    + omega^4 * 2
```

This is the only ordinal-arithmetic step where the bookkeeping is non-trivial (in particular, `omega^4 * 2 = omega^4 + omega^4`, *not* `omega^8`); do it with `Ordinal.mul_add` and `Ordinal.mul_one` (then `ring_nf` to handle the natural-number `2`).

**Step 3 — Bound each summand by the RHS.**

| Summand | CNF leading exponent | Bound | Why it is < RHS |
|---|---|---|---|
| `omega^7 * (mu a + 1)` | `≤ mu a + 7` | `< omega^(mu a + 8)` | `mu a + 8 < mu a + mu b + 9` (since `0 ≤ mu b`) |
| `omega^6 * (mu b + 1)` | `≤ mu b + 6` | `< omega^(mu b + 7)` | `≤ omega^(mu a + mu b + 7)` < `omega^(mu a + mu b + 9)` |
| `omega^4 * 2` | `= 4` | `omega^4` | `< omega^(mu a + mu b + 9)` since `4 < mu a + mu b + 9` |

Each bound is a one- or two-line application of `opow_lt_opow_right` after establishing the corresponding exponent inequality with `add_lt_add_iff_right` / `le_add_left`.

**Step 4 — Absorb via the limit property of the RHS.**
The RHS is `omega^(mu a + mu b + 9)`, which is a limit ordinal because the exponent `mu a + mu b + 9 ≥ 9 > 0`. By `IsLimit.add_lt` (applied twice), the sum of the three summands is still `< omega^(mu a + mu b + 9)`.

**Skeleton:**
```lean
| _, _, Step.R_eq_diff a b => by
    simp [mu]
    -- Drop the trailing +1 on both sides (both are successors).
    -- Equivalently: rw [show (omega0^4*X + 2) + 1 = (omega0^4*X + 1) + 1 from rfl,
    --                  show omega0^(mu a + mu b + 9) + 1 = omega0^(mu a + mu b + 9) + 1 from rfl]
    -- and use add_right_cancel_iff / add_lt_add_iff_right on the +1
    have step1 : omega0^(4:Ordinal) * (omega0^3*(mu a+1) + omega0^2*(mu b+1) + 2)
                < omega0^(mu a + mu b + 9) := by
      -- distribute
      have hdist :
          omega0^(4:Ordinal) * (omega0^3*(mu a+1) + omega0^2*(mu b+1) + 2)
          = omega0^(7:Ordinal) * (mu a + 1)
          + omega0^(6:Ordinal) * (mu b + 1)
          + omega0^(4:Ordinal) * 2 := by
        rw [Ordinal.mul_add, Ordinal.mul_add]
        ring_nf; sorry   -- close the resulting finite-arithmetic goals
      rw [hdist]
      -- bound each summand:
      have h1 : omega0^(7:Ordinal) * (mu a + 1) < omega0^(mu a + mu b + 9) := by
        -- (omega^7)*(mu a+1) ≤ omega^(mu a + 8) via le_mul_right and opow_le_opow_right,
        -- then opow_lt_opow_right since (mu a + 8) < (mu a + mu b + 9) (mu b ≥ 0).
        sorry
      have h2 : omega0^(6:Ordinal) * (mu b + 1) < omega0^(mu a + mu b + 9) := by
        sorry
      have h3 : omega0^(4:Ordinal) * (2:Ordinal) < omega0^(mu a + mu b + 9) := by
        sorry
      -- absorb:  omega^E is a limit ordinal for E > 0
      exact (Ordinal.isLimit_opow _
              (Ordinal.add_pos_right _ (Ordinal.add_pos_right _ one_pos)))
              .add_lt h1 (Ordinal.add_lt_add_iff_left.mpr
                ((Ordinal.isLimit_opow _ _).add_lt h2 h3))
    exact step1.trans (le_add_right _ _)
```

The point is that the only non-mechanical steps are the three summand bounds; everything else is `IsLimit.add_lt` chaining.

### Case C — `Step.R_rec_succ b s n`  (the only subtle one)

**Goal:** `mu(app s (recDelta b s n)) < mu(recDelta b s (delta n))`, i.e.

```
omega^3*(mu s+1) + omega^2*(omega^(mu n+mu s+6) + omega*(mu b+1) + 1 + 1) + 1
  < omega^(omega^5*(mu n+1) + 1 + mu s + 6) + omega*(mu b+1) + 1
```

**Step 1 — Throw away the additive tail of the LHS.** Set
```
E1 := omega^5 * (mu n + 1) + mu s + 7
E2 := mu n + mu s + 6
```
The LHS is `omega^E1 + omega*(mu b+1) + 1`, so by `le_add_right` it suffices to show the RHS is `< omega^E1`.

**Step 2 — Distribute the RHS.**
```
RHS = omega^3*(mu s+1) + omega^2*(omega^E2 + omega*(mu b+1) + 2) + 1
    = omega^3*(mu s+1) + omega^(E2+2) + omega^3*(mu b+1) + omega^2*2 + 1
```
(distribute with `Ordinal.mul_add`; again `omega^2 * 2 = omega^2 + omega^2`.)

**Step 3 — Compare the leading exponent `E2+2` with `E1`.**
```
E2 + 2 = (mu n + 1) + mu s + 7
E1     = omega^5 * (mu n + 1) + mu s + 7
```
By `add_lt_add_iff_right`, the inequality `E2+2 < E1` reduces to the *key sub-lemma*:

> **Sub-lemma.** `(mu n + 1 : Ordinal) < omega^5 * (mu n + 1)`.

**Ad-hoc proof of the sub-lemma** (no fancy CNF needed):
```
(mu n + 1) < (mu n + 1) + 1       -- lt_add_one
(mu n + 1) + 1 = mu n + 2         -- Ordinal.add_assoc then add 1
mu n + 2 ≤ mu n + omega0^5        -- le_add_right (since 2 ≤ omega0^5)
mu n + omega0^5 ≤ omega0^5 * mu n + omega0^5  -- le_mul_right (since mu n ≤ omega^5*mu n)
              = omega0^5 * (mu n + 1)          -- Ordinal.mul_add
```
The only ordinal-arithmetic fact used is that `2 ≤ omega^5` and that `alpha ≤ omega^5 * alpha` for any ordinal `alpha`. (`alpha ≤ omega^5 * alpha` is `le_mul_right _ (opow_pos _ omega0_pos) : a ≤ a * b` for `b > 0`.) This avoids the trap that `omega * omega^omega = omega^omega` would otherwise cause.

From the sub-lemma, `opow_lt_opow_right omega0 (sub_lemma')` (where `sub_lemma' : E2+2 < E1`) gives `omega^(E2+2) < omega^E1`.

**Step 4 — Show the "subleading" tail is `< omega^E1` and absorb.**
Set
```
S := omega^3*(mu s+1) + omega^3*(mu b+1) + omega^2*2 + 1
```
Each summand of `S` has CNF leading exponent `≤ max(mu s, mu b) + 3 ≤ mu s + mu b + 3 < E1` (because `E1 = omega^5*(mu n+1) + mu s + 7` and the subleading part is a sum, dominated by the leading `omega^5*(mu n+1)` which is much larger than any finite-exponent tower). So each summand is `< omega^E1`. By two applications of `IsLimit.add_lt` to the limit ordinal `omega^E1`, the whole `S < omega^E1`.

**Step 5 — Conclude.** `omega^(E2+2) + S < omega^E1` by `IsLimit.add_lt`.

**Skeleton:**
```lean
| _, _, Step.R_rec_succ b s n => by
    simp [mu]
    set E1 : Ordinal := omega0^(5:Ordinal) * (mu n + 1) + 1 + mu s + (6:Ordinal)
    set E2 : Ordinal := mu n + mu s + (6:Ordinal)
    -- LHS = omega^E1 + omega*(mu b+1) + 1 ; suffices to bound RHS by omega^E1
    suffices h : omega0^(3:Ordinal) * (mu s + 1)
                + omega0^(2:Ordinal) * (omega0^E2 + omega0 * (mu b + 1) + 2) + 1
                < omega0^E1 by
      exact h.trans (le_add_right _ _)
    -- distribute the outer omega^2 on the (omega^E2 + omega*(mu b+1) + 2)
    have hdist : omega0^(2:Ordinal) * (omega0^E2 + omega0*(mu b+1) + 2)
                = omega0^(E2 + (2:Ordinal))
                + omega0^(3:Ordinal) * (mu b+1)
                + omega0^(2:Ordinal) * 2 := by
      rw [Ordinal.mul_add]; ring_nf; sorry
    rw [hdist]
    -- now we have omega^3*(mu s+1) + omega^(E2+2) + omega^3*(mu b+1) + omega^2*2 + 1 < omega^E1
    -- show E2 + 2 < E1  (sub-lemma)
    have hE : E2 + (2:Ordinal) < E1 := by
      have hk : (mu n + 1 : Ordinal) < omega0^(5:Ordinal) * (mu n + 1) := by
        -- chain: (mu n+1) < (mu n+1)+1 = mu n+2 ≤ mu n+omega^5 ≤ omega^5*mu n+omega^5
        -- = omega^5 * (mu n+1)
        have h1 : (mu n + 1) < (mu n + 1) + 1 := Ordinal.lt_add_one _
        have h2 : (mu n + 1) + 1 = mu n + (2:Ordinal) := by
          rw [Ordinal.add_assoc]; rfl
        have h3 : mu n + (2:Ordinal) ≤ mu n + omega0^(5:Ordinal) :=
          Ordinal.add_le_add_iff_right.mpr (one_le_iff_ne_zero.mp
            (Ordinal.opow_pos _ omega0_pos))   -- 2 ≠ 0
        have h4 : mu n + omega0^(5:Ordinal) ≤ omega0^(5:Ordinal) * mu n + omega0^(5:Ordinal) :=
          Ordinal.add_le_add_iff_right.mpr
            (Ordinal.le_mul_right _ (Ordinal.opow_pos _ omega0_pos))
        have h5 : omega0^(5:Ordinal) * mu n + omega0^(5:Ordinal)
                = omega0^(5:Ordinal) * (mu n + 1) := by
          rw [← Ordinal.mul_add]
        exact h1.trans (h2.trans (h3.trans (h4.trans h5.le)))
      --  E2 + 2 = (mu n+1) + mu s + 7 ;  E1 = omega^5*(mu n+1) + mu s + 7
      rw [show E2 + (2:Ordinal) = (mu n + 1) + mu s + (7:Ordinal) from rfl,
          show E1 = omega0^(5:Ordinal) * (mu n + 1) + mu s + (7:Ordinal) from rfl]
      exact Ordinal.add_lt_add_iff_right.mpr hk
    -- absorb the leading summand
    have hLead : omega0^(E2 + (2:Ordinal)) < omega0^E1 :=
      Ordinal.opow_lt_opow_right omega0 hE
    -- bound the subleading tail
    have hS : omega0^(3:Ordinal) * (mu s + 1)
            + omega0^(3:Ordinal) * (mu b + 1)
            + omega0^(2:Ordinal) * (2:Ordinal) + (1:Ordinal) < omega0^E1 := by
      -- each of the four summands has CNF leading exponent strictly less than E1
      sorry   -- four near-identical applications of opow_lt_opow_right,
              -- then two uses of IsLimit.add_lt
    -- combine: omega^(E2+2) + S < omega^E1
    exact (Ordinal.isLimit_opow E1
            (Ordinal.add_pos_right _ (Ordinal.add_pos_right _ one_pos)))
            .add_lt hLead hS
```

### Why this works (high-level sanity check)

The three rules all fall out of the same inequality template:

> `omega^α * X + omega^β * Y + small   <   omega^γ`

where `α, β < γ` and `omega^γ` is a limit ordinal. The measure is built so that

* `R_eq_refl` gives `γ = 9` (a tiny but positive power of ω — positivity is trivial);
* `R_eq_diff` gives `γ = mu a + mu b + 9` dominating `α = 7` and `β = 6` since `mu a, mu b ≥ 0`;
* `R_rec_succ` gives `γ = omega^5*(mu n+1) + mu s + 7` dominating `α = (mu n + 1) + mu s + 8 = E2+2` thanks to `omega^5*(mu n+1) > mu n+1`.

The three open sorry's are exactly the three places where the proof reduces to the limit-absorption lemma, the sub-lemma `(mu n+1) < omega^5 * (mu n+1)`, and the exponent inequality `E2+2 < E1` — all of which are short ordinal-arithmetic calculations once the supporting `IsLimit` and `opow_lt_opow_right` machinery is in scope.
