# Proof Skeleton for Remaining Cases

Here's a proof skeleton for completing the three `sorry` cases:

```lean
-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    simp [mu]
    -- Strategy: Show that omega^(omega^5 * (mu n + 1) + 1 + mu s + 6) 
    -- dominates omega^3 * (mu s + 1) + omega^2 * (...)
    --
    -- Key steps:
    -- 1. Recognize that mu(delta n) = omega^5 * (mu n + 1) + 1
    -- 2. Show that omega^5 * (mu n + 1) >> mu n + mu s + 6
    -- 3. Use opow_lt_opow_left to show exponent dominance
    -- 4. Conclude that the LHS of the step strictly decreases
    
    have h_delta : mu (delta n) = omega0 ^ 5 * (mu n + 1) + 1 := rfl
    have h_exp_large : mu n + mu s + 6 < omega0 ^ 5 * (mu n + 1) + 1 := by
      -- omega^5 * (mu n + 1) grows much faster than any finite sum involving mu n
      sorry
    have h_opow_lt : omega0 ^ (mu n + mu s + 6) < omega0 ^ (omega0 ^ 5 * (mu n + 1) + 1) := by
      exact opow_lt_opow_left omega0_pos h_exp_large
    sorry

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    simp [mu]
    -- Strategy: Simple positivity argument
    -- 0 < omega^(2*mu a + 9) + 1 follows from ordinal properties
    
    have h1 : (0 : Ordinal) < 2 * mu a + 9 := by
      omega
    have h2 : omega0 ^ (2 * mu a + 9) > 0 := opow_pos omega0_pos _
    have h3 : omega0 ^ (2 * mu a + 9) + 1 > 0 := by omega
    exact h3

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    simp [mu]
    -- Strategy: Show omega^4 * (...) + 1 < omega^(mu a + mu b + 9) + 1
    -- by showing the exponent on the RHS dominates the LHS
    --
    -- Key insight: mu a + mu b + 9 is sufficiently large compared to 
    -- the structure of omega^3 * (mu a + 1) + omega^2 * (mu b + 1) + 2
    
    have h_lhs_bound : omega0 ^ (4 : Ordinal) * 
        (omega0 ^ (3 : Ordinal) * (mu a + 1) + omega0 ^ (2 : Ordinal) * (mu b + 1) + 2) + 1 
        < omega0 ^ (mu a + mu b + 9) + 1 := by
      -- The exponent mu a + mu b + 9 on RHS is much larger than 4,
      -- so omega^(...) on RHS dominates the LHS entirely
      have h_exp_large : (4 : Ordinal) < mu a + mu b + 9 := by omega
      have h_base_large : omega0 ^ (4 : Ordinal) * _ < omega0 ^ (mu a + mu b + 9) := by
        -- Use that omega^n grows faster than any polynomial in smaller terms
        sorry
      omega
    exact h_lhs_bound
```

## Key Proof Techniques Needed:

1. **R_rec_succ**: Exploit that `omega^5 * (mu n + 1)` in the exponent of the RHS vastly dominates the `mu n + mu s + 6` exponent of the LHS.

2. **R_eq_refl**: Straightforward—use `omega` tactic or basic ordinal positivity lemmas since `omega^(2*mu a + 9) + 1 > 0`.

3. **R_eq_diff**: Show that `mu a + mu b + 9` is a sufficiently large exponent that `omega^(mu a + mu b + 9)` dominates `omega^4 * (...)`. The critical lemmas are `opow_lt_opow_left` and monotonicity of ordinal exponentiation.
