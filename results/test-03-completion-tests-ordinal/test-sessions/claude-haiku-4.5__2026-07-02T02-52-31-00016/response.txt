    --    because omega^5 * (mu n + 1) >> mu n + mu s + 6
    -- 2. Therefore omega^(omega^5 * (mu n + 1) + ...) >> omega^(mu n + mu s + 6) + ...
    -- 3. So LHS >> omega^3 * (...) + omega^2 * (omega^(...) + ...)

    calc omega0 ^ (mu (delta n) + mu s + 6) + omega0 * (mu b + 1) + 1
      _ = omega0 ^ (omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + 6)

      _ > omega0 ^ (3 : Ordinal) * (mu s + 1)

| _, _, Step.R_eq_refl a => by

| _, _, Step.R_eq_diff a b => by
    simp [mu]
    -- Strategy: Show omega^4 * (omega^3 * (mu a + 1) + omega^2 * (mu b + 1) + 2) + 1
    --         < omega^(mu a + mu b + 9) + 1

## Key Proof Ideas:

1. **R_rec_succ**: The exponent in `recDelta` contains `omega^5 * (mu n + 1)`, which grows much faster than `mu n + mu s + 6`. This exponential gap ensures `recDelta`'s measure dominates the expanded `app s (recDelta b s n)`.

2. **R_eq_refl**: Direct positivity since `omega^(...)` terms are positive.

3. **R_eq_diff**: The exponent `mu a + mu b + 9` in `eqW` is large enough (≥ 9 > 4) that `omega^(mu a + mu b + 9)` vastly exceeds `omega^4 * (...)`, using ordinal exponential properties like `opow_lt_opow_left`.

The `sorry` placeholders mark where standard ordinal arithmetic lemmas (like dominance properties of exponentials) would complete the proofs.
