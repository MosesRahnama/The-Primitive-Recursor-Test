# Proof Skeletons for the Three Remaining Cases

Below are structured proof skeletons. I keep them faithful to the measure definitions and the ordinal lemmas already used elsewhere in the file (`opow_pos`, `le_mul_right`, `le_add_left/right`, `lt_of_lt_of_le`, `add_pos_right`, etc.).

## Case 1: `R_eq_refl` (easiest — pure positivity)

Goal after `simp [mu]`: `0 < omega0 ^ (mu a + mu a + 9) + 1`.

```lean
| _, _, Step.R_eq_refl a => by
    simp [mu]
    -- Goal: 0 < omega0 ^ (mu a + mu a + 9) + 1
    exact Ordinal.pos_iff_ne_zero.mpr (by
      apply ne_of_gt
      exact add_pos_right _ one_pos)
```

**Skeleton rationale:** This mirrors the `R_int_delta` case exactly. The RHS is of the form `X + 1`, and `add_pos_right _ one_pos` gives `0 < X + 1`. If `simp` normalizes the exponent differently, fall back to:
```lean
    exact Ordinal.pos_iff_ne_zero.mpr (Ordinal.succ_ne_zero _ ∘ ...)
    -- or simply:  exact lt_of_lt_of_le one_pos (le_add_left _ _)
```

## Case 2: `R_eq_diff` (dominate via exponent comparison)

Goal: `omega0^4 * (mu(merge a b) + 1) + 1 < omega0^(mu a + mu b + 9) + 1`.

**Strategy:** Reduce `+ 1 < + 1` to a strict inequality on the main parts, then show the LHS is `< omega0^(mu a + mu b + 9)` because the LHS is a "small" term below a single omega-power whose exponent strictly exceeds the LHS's leading exponent.

```lean
| _, _, Step.R_eq_diff a b => by
    simp only [mu]
    -- Abbreviations
    set A := mu a
    set B := mu b
    -- Step 1: reduce  X + 1 < Y + 1  to  X < Y
    rw [add_lt_add_iff_right]   -- may need: Ordinal.add_lt_add_iff_right
    -- Now goal: omega0^4 * (merge-body + 1) < omega0^(A + B + 9)
    -- Step 2: bound the LHS by a single omega-power omega0^E with E < A+B+9.
    -- The whole LHS lives below omega0^(A+B+9) since that exponent dominates
    -- the leading exponent 4 (constant) and the internal exponents 3,2.
    have hlead : (4 : Ordinal) < A + B + 9 := by
      -- 4 < 9 ≤ A + B + 9
      calc (4 : Ordinal) < 9 := by norm_num
        _ ≤ A + B + 9 := le_add_left _ _
    -- Step 3: any ordinal of the form omega0^4 * (c) with c < omega0-power
    -- is < omega0^(A+B+9).  Use that omega0^(A+B+9) is a principal/limit
    -- ordinal absorbing lower powers.
    -- Key lemma pattern:  omega0^4 * k < omega0^(A+B+9)
    -- provided k < omega0^(A+B+9 - 4)-ish; simpler: bound via mul_lt_opow.
    sorry
```

**Recommended concrete completion for Step 3.** Use the principality of `omega0`-powers under multiplication/addition. The cleanest path:

```lean
    -- Let E := A + B + 9.
    have key : omega0 ^ (4 : Ordinal) * (mu (merge a b) + 1) < omega0 ^ (A + B + 9) := by
      -- omega0^E is additively & multiplicatively principal (E ≠ 0).
      -- Bound the multiplicand: mu(merge a b) + 1 < omega0^E.
      have hmul : mu (merge a b) + 1 < omega0 ^ (A + B + 9) := by
        -- mu(merge a b) itself is < omega0^E since its leading power is 3 < E
        sorry
      -- Then omega0^4 * (small) < omega0^E because 4 < E and small < omega0^E,
      -- using Ordinal.mul_lt_opow / Principal.mul with base omega0^E.
      calc omega0 ^ (4 : Ordinal) * (mu (merge a b) + 1)
          < omega0 ^ (4 : Ordinal) * omega0 ^ (A + B + 9) :=
            (mul_lt_mul_iff_of_pos_left (opow_pos 4 omega0_pos)).mpr hmul
        _ = omega0 ^ ((4 : Ordinal) + (A + B + 9)) := by rw [← opow_add]
        _ = omega0 ^ (A + B + 9) := by
            -- 4 + (A+B+9) = A+B+9 requires A+B+9 to absorb 4 on the left,
            -- which holds since A+B+9 ≥ omega0 (its exponent ≥ 1 gives a limit).
            sorry
    exact key
```

Note the last equality is the delicate point: `(4 : Ordinal) + (A+B+9) = A+B+9` requires `A+B+9` to be `≥ omega0` (a limit absorbing finite left-addends), which holds because `omega0^(A+B+9)`... — actually you want left-absorption of the *finite* `4` into an ordinal `≥ omega0`. Since `A + B + 9 ≥ 9`, and `4 + n` for finite parts is fine, but to fully absorb you need `A+B+9` infinite. If `A = B = 0` it is `9` (finite), so `4 + 9 = 13 ≠ 9`. **Therefore prefer the direct `hmul` bounding route** without the `opow_add` rewrite:

```lean
    -- Preferred: bound LHS directly using that omega0^E dominates omega0^4 * k
    -- when 4 < E, via  omega0^4 * k < omega0^(4) * omega0 = omega0^5 ≤ omega0^E ... 
    -- Instead use: omega0^4 * (mu(merge a b)+1) < omega0^E directly by
    --   omega0^4 * c ≤ omega0^4 * omega0^d = omega0^(4+d) and choose d with 4+d ≤ E.
```

The robust choice is to pick `d` with `(4 : Ordinal) + d = A + B + 9` (possible since `A+B+9 ≥ 4`), giving `omega0^4 * omega0^d = omega0^(A+B+9)`, and bound `mu(merge a b)+1 < omega0^d` using `4 ≤ ...`. Structure:

```lean
    obtain ⟨d, hd⟩ : ∃ d, (4 : Ordinal) + d = A + B + 9 :=
      ⟨_, Ordinal.add_sub_cancel_of_le (by ... : (4:Ordinal) ≤ A+B+9)⟩
```

## Case 3: `R_rec_succ` (the hard one — exponent tower domination)

Goal reduces to showing
```
omega0^3*(mu s+1) + omega0^2*(mu(recDelta b s n)+1) + 1
  < omega0^(mu(delta n) + mu s + 6) + omega0*(mu b+1) + 1
```
where `mu(delta n) = omega0^5*(mu n+1)+1`, so the RHS leading exponent is `omega0^5*(mu n+1)+1 + mu s + 6`.

```lean
| _, _, Step.R_rec_succ b s n => by
    simp only [mu]
    set N := mu n; set S := mu s; set Bb := mu b
    -- RHS leading power exponent
    set Erhs := omega0 ^ (5 : Ordinal) * (N + 1) + 1 + S + 6 with hErhs
    -- LHS is entirely below omega0^Erhs.
    -- Strategy:
    --   1. Bound whole LHS by a single power omega0^F with F < Erhs.
    --   2. Conclude LHS < omega0^Erhs ≤ RHS.

    -- Step A: The LHS's largest internal exponent is inside
    --   omega0^2 * (omega0^(N+S+6) + ...), i.e. exponent 2 + (N+S+6).
    -- We must show that exponent < Erhs.
    have hexp : (2 : Ordinal) + (N + S + 6) < omega0 ^ (5 : Ordinal) * (N + 1) + 1 + S + 6 := by
      -- LHS ≈ N + S + 8 (finite shifts of N,S),
      -- RHS ≈ omega0^5*(N+1) + S + 7, and omega0^5*(N+1) ≫ N.
      -- Use omega0^5*(N+1) ≥ omega0^5 > N and monotonicity.
      sorry

    -- Step B: bound whole LHS < omega0^Erhs
    have hLHS : omega0 ^ (3 : Ordinal) * (S + 1)
                + omega0 ^ (2 : Ordinal) *
                    (omega0 ^ (N + S + 6) + omega0 * (Bb + 1) + 1 + 1) + 1
                < omega0 ^ Erhs := by
      -- omega0^Erhs is additively principal (Erhs ≠ 0), so it suffices
      -- that each summand is < omega0^Erhs. Bound each:
      --   omega0^3*(S+1)          < omega0^Erhs   (since 3 < Erhs)
      --   omega0^2*(inner)        < omega0^Erhs   (via hexp)
      --   1                        < omega0^Erhs
      sorry

    -- Step C: reduce  X + 1 < Y + 1  and use hLHS ≤ RHS body
    calc _ < omega0 ^ Erhs := by
              -- peel the trailing +1 with add_lt_add_iff_right, then hLHS
              sorry
         _ ≤ omega0 ^ Erhs + omega0 * (Bb + 1) := le_add_right _ _
         _ ≤ omega0 ^ Erhs + omega0 * (Bb + 1) + 1 := le_add_right _ _
```

### Supporting lemmas you will want (state once, reuse)

```lean
-- A finite power times a bounded factor stays below a bigger power.
lemma opow_mul_lt_opow_of_lt {c d k : Ordinal}
    (hcd : c < d) (hk : k < omega0 ^ d) (hd : 0 < d) :
    omega0 ^ c * k < omega0 ^ d := by
  sorry  -- via Principal.mul_omega0 / opow_add / mul_lt_mul

-- Sum of finitely many terms each < omega0^E (E ≠ 0) is < omega0^E.
lemma add_lt_opow_of_all_lt {E x y : Ordinal}
    (hE : E ≠ 0) (hx : x < omega0 ^ E) (hy : y < omega0 ^ E) :
    x + y < omega0 ^ E := by
  have := principal_add_omega0_opow E   -- omega0^E additively principal
  exact this hx hy
```

**Key facts driving the whole argument:**
- `omega0 ^ E` is **additively principal** for `E ≠ 0` (`principal_add_omega0_opow`), so a finite sum of things below it stays below it.
- `omega0 ^ E` is **multiplicatively principal**, absorbing left multiplications by smaller powers.
- Exponent domination `hexp`: `omega0^5*(N+1)` dwarfs any expression that is finite-shift-linear in `N, S`. Prove via `N < omega0^5 ≤ omega0^5*(N+1)` and left-add absorption into the limit ordinal.

### General remarks on getting these to compile
- After `simp only [mu]`, inspect the *exact* associativity/normal form of `+` and `*` the goal takes; the `calc`/`rw` steps must match it. Use `ring_nf`-free manual reassociation via `add_assoc`/`mul_assoc` if `simp` regroups.
- Prefer `Ordinal.add_lt_add_iff_right` to strip trailing `+ 1`, and `mul_lt_mul_iff_of_pos_left` (with `opow_pos`) for the multiplicative steps.
- For exponent-absorption equalities, use `Ordinal.add_absorp` / left-absorption lemmas rather than `opow_add` when the summands are finite vs. limit.
