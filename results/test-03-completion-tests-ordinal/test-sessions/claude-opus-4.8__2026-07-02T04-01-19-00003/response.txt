# Proof Skeletons for the Three Remaining Cases

Below are proof skeletons for the three `sorry` cases. I'll present them in order of increasing difficulty, providing the key lemmas and structural steps needed for each.

## Case 1: `R_eq_refl` (easiest — pure positivity)

After `simp [mu]`, the goal reduces to showing `0 < omega0 ^ (mu a + mu a + 9) + 1` (or a similar form; `simp` may collapse `mu a + mu a`). This is pure positivity.

```lean
| _, _, Step.R_eq_refl a => by
    simp [mu]
    -- Goal: 0 < omega0 ^ (mu a + mu a + 9) + 1  (or a simp-normal variant)
    -- Strategy: the whole expression is a successor / has a positive summand.
    apply Ordinal.pos_iff_ne_zero.mpr
    apply ne_of_gt
    -- The +1 gives positivity directly:
    exact add_pos_right _ one_pos
    -- Alternative if simp leaves a bare `omega0 ^ _`:
    --   exact opow_pos _ omega0_pos
    -- Alternative if simp normalizes to a clean successor:
    --   exact Ordinal.pos_iff_ne_zero.mpr (by positivity)  -- (if positivity handles it)
```

**Note:** Inspect the exact `simp`-normal form. If `simp` fully closes the goal, delete the tactic block after `simp [mu]`. If it leaves `0 < X + 1`, `add_pos_right _ one_pos` finishes it.

## Case 2: `R_eq_diff` (moderate — exponent comparison)

**Key idea:** The LHS `mu (integrate (merge a b)) = omega0^4 * (M + 1) + 1` where `M = mu(merge a b)` is *strictly below* `omega0^(mu a + mu b + 9)` because the RHS exponent `mu a + mu b + 9` dominates any finite tower over `omega0^3, omega0^4`.

**Central lemma to establish:** any term of the form `omega0^4 * (k + 1) + 1` with `k < omega0^(mu a + mu b + 9)` (in a controlled sense) is bounded by `omega0^(mu a + mu b + 9)`, using that `omega0^e` is a *principal* (additively-and-multiplicatively closed) ordinal for `e ≥ ...`.

```lean
| _, _, Step.R_eq_diff a b => by
    simp [mu]
    -- Let E := mu a + mu b + 9   (the big exponent)
    -- Goal (pre-simp): omega0^4 * (omega0^3*(mu a+1) + omega0^2*(mu b+1) + 1 + 1) + 1
    --                  < omega0^E + 1
    set A := mu a with hA
    set B := mu b with hB
    -- Step 1: name the merge measure
    set M : Ordinal := omega0 ^ (3:Ordinal) * (A + 1)
                     + omega0 ^ (2:Ordinal) * (B + 1) + 1 with hM
    -- Step 2: show M < omega0 ^ (A + B + 9)
    have hM_lt : M < omega0 ^ (A + B + 9) := by
      -- Bound each summand of M below omega0^(A+B+9).
      -- Use that A+B+9 ≥ 4 ≥ 3, 2, and that omega0^e is principal for +.
      -- Key facts:
      --   • omega0^3 * (A+1) < omega0^(A+B+9)   since 3 + (exp of (A+1)) < A+B+9
      --   • omega0^2 * (B+1) < omega0^(A+B+9)
      --   • use Ordinal.principal_add_omega0_opow / add_lt_of_lt_omega0_opow style lemmas
      sorry
    -- Step 3: show omega0^4 * (M + 1) < omega0 ^ (A + B + 9)
    have hLHS_body : omega0 ^ (4:Ordinal) * (M + 1) < omega0 ^ (A + B + 9) := by
      -- Since M < omega0^(A+B+9) and A+B+9 ≥ 4:
      --   omega0^4 * (M+1) ≤ omega0^4 * omega0^(A+B+9) = omega0^(4 + (A+B+9))
      -- but we actually want strict < omega0^(A+B+9).  Use a stronger form:
      --   because omega0^(A+B+9) is *multiplicatively* principal and closed,
      --   any omega0^4 * (successor bounded by it) stays below.
      -- Concretely: use `Ordinal.mul_lt_opow` / `Principal.mul` lemmas with
      --   the fact that the *exponent* A+B+9 strictly dominates 4 + logs.
      sorry
    -- Step 4: absorb the trailing +1 on the LHS and conclude.
    calc omega0 ^ (4:Ordinal) * (M + 1) + 1
        ≤ omega0 ^ (A + B + 9) := by
          -- omega0^(A+B+9) is a limit ordinal, so successor of anything below stays below/≤
          apply Order.add_one_le_of_lt  -- or `Order.succ_le_of_lt` after rewriting +1 as succ
          exact hLHS_body
      _ < omega0 ^ (A + B + 9) + 1 := lt_add_one _
```

**Lemmas likely needed for Steps 2–3:**
- `Ordinal.opow_le_opow_right omega0_pos (h : e₁ ≤ e₂)` for monotonicity of the base tower.
- `Ordinal.principal_add_omega0_opow` (or `Ordinal.add_absorp` / `Ordinal.mul_lt_opow_succ`) to bound sums/products beneath a single `omega0^e`.
- The fact `omega0 ^ e` is a limit ordinal (`Ordinal.opow_limit` / `isLimit`) so `x < omega0^e → x + 1 ≤ omega0^e`.

## Case 3: `R_rec_succ` (hardest — exponent tower domination)

**Key idea:** The LHS lives inside `omega0^(mu(delta n) + mu s + 6)` whose exponent contains `omega0^5 * (mu n + 1)`. The RHS is a finite polynomial in `omega0^3, omega0^2` over `omega0^(mu n + mu s + 6)`. Since the exponent of the LHS *strictly exceeds* everything appearing in the RHS, the LHS dominates.

```lean
| _, _, Step.R_rec_succ b s n => by
    simp [mu]
    set N := mu n with hN
    set S := mu s with hS
    set Bb := mu b with hBb
    -- Big exponent on the LHS:  D := mu(delta n) + S + 6
    --                            = (omega0^5 * (N+1) + 1) + S + 6
    set D : Ordinal := (omega0 ^ (5:Ordinal) * (N + 1) + 1) + S + 6 with hD
    -- Small exponent appearing on the RHS:  e := N + S + 6
    set e : Ordinal := N + S + 6 with he
    -- Step 1: strict exponent domination  e < D
    have h_exp : e < D := by
      -- D = omega0^5*(N+1) + (1 + S + 6);  e = N + S + 6.
      -- Since omega0^5*(N+1) ≥ omega0^5 > N (and dominates the linear part),
      -- we get N + S + 6 < omega0^5*(N+1) + ... = D.
      -- Use: N < omega0^5 * (N+1)  (via le_mul_right + opow_pos), then add S+6.
      sorry
    -- Step 2: the LHS core omega0^D dominates the entire RHS.
    -- RHS = omega0^3*(S+1) + omega0^2*(RD + 1) + 1
    --   where RD = mu(recDelta b s n) = omega0^e + omega0*(Bb+1) + 1.
    set RD : Ordinal := omega0 ^ e + omega0 * (Bb + 1) + 1 with hRD
    set RHS : Ordinal :=
        omega0 ^ (3:Ordinal) * (S + 1)
      + omega0 ^ (2:Ordinal) * (RD + 1) + 1 with hRHS
    -- Show RHS < omega0^D.  Every summand is below omega0^D because:
    --   • omega0^2 * (RD+1) is bounded by omega0^(e+3) < omega0^D  (since e < D, +3 still < D)
    --   • omega0^3*(S+1) < omega0^D
    --   • omega0^D is additively principal (limit), so the sum stays below.
    have h_RHS_lt : RHS < omega0 ^ D := by
      -- Sub-lemma A: RD < omega0^(e+1)  (since omega0^e dominates the linear tail)
      have hRD_lt : RD < omega0 ^ (e + 1) := by
        -- omega0^e + omega0*(Bb+1) + 1 < omega0^e * omega0 = omega0^(e+1)
        sorry
      -- Sub-lemma B: omega0^2 * (RD+1) < omega0^D
      have hB_lt : omega0 ^ (2:Ordinal) * (RD + 1) < omega0 ^ D := by
        -- ≤ omega0^2 * omega0^(e+1) = omega0^(e+3) < omega0^D  (needs e+3 < D)
        -- get e+3 < D from h_exp by strengthening Step 1 to `e + 3 < D` if needed
        sorry
      -- Sub-lemma C: omega0^3 * (S+1) < omega0^D
      have hC_lt : omega0 ^ (3:Ordinal) * (S + 1) < omega0 ^ D := by
        sorry
      -- Combine using additive principality of omega0^D (it is a limit ordinal):
      -- x < omega0^D → y < omega0^D → x + y < omega0^D
      have hlim : (omega0 ^ D).IsLimit := by
        apply Ordinal.opow_isLimit_of_omega_le  -- or `Ordinal.isLimit_opow` variant
        sorry
      -- add up hC_lt, hB_lt, and the trailing +1
      sorry
    -- Step 3: fold omega0^D into the actual LHS (which has extra +omega0*(Bb+1)+1 tail
    --   OUTSIDE the exponent — note the LHS is omega0^D + omega0*(Bb+1) + 1),
    --   and conclude RHS < LHS.
    -- LHS = omega0^D + omega0*(Bb+1) + 1  ≥  omega0^D  > RHS.
    calc RHS
        < omega0 ^ D := h_RHS_lt
      _ ≤ omega0 ^ D + omega0 * (Bb + 1) + 1 := by
          apply le_add_right  -- add the nonneg tail
```

**Lemmas likely needed for Case 3:**
- `Ordinal.opow_lt_opow_right` / `opow_lt_opow_iff_right` (strict monotone in exponent for base `> 1`) to turn `e < D` into `omega0^e < omega0^D` and to bound `omega0^(e+3) < omega0^D`.
- `Ordinal.mul_lt_opow` or `Ordinal.opow_add` (`omega0^a * omega0^b = omega0^(a+b)`) to collapse products of towers.
- `Ordinal.add_lt_of_lt` for a limit ordinal (additive principality of `omega0^D`).
- `le_mul_right`, `opow_pos`, `lt_add_one` as in the proved cases.

## General Advice

1. **Inspect the actual `simp [mu]` normal form** for each case first — `simp` may reorder `+`, collapse `0 + x`, or rewrite `omega0^5` differently. Adjust the `set`/`calc` targets accordingly.
2. **The recurring pattern** is: *bound each additive summand below a single `omega0^e`, then use that `omega0^e` is additively principal (a limit ordinal) to combine them.* Factor this into one helper lemma if you may edit the file later:
   ```lean
   lemma sum_lt_opow {x y e : Ordinal} (he : (omega0^e).IsLimit)
       (hx : x < omega0^e) (hy : y < omega0^e) : x + y < omega0^e
   ```
3. **The strict exponent gap** (`e < D`, driven by `omega0^5 * (N+1)`) is the crux of `R_rec_succ`; everything else is bookkeeping to reduce products/sums of lower towers under `omega0^D`.
