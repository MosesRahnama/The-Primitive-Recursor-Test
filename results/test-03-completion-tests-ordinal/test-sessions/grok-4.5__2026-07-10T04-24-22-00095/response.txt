## Proof Skeleton for the Three Remaining Cases

The three open cases are `R_rec_succ`, `R_eq_refl`, and `R_eq_diff`. Below are self-contained skeletons that fit the existing `theorem mu_decreases` pattern. They rely only on Mathlib ordinal lemmas already imported (or re-exportable from the same modules).

---

### 1. `R_eq_refl` (routine positivity)

```lean
-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
  simp [mu]
  -- Goal: 0 < ω^(μ a + μ a + 9) + 1
  exact Ordinal.pos_iff_ne_zero.mpr (by
    apply ne_of_gt
    exact add_pos_right _ one_pos)
```

This is identical in structure to the already-proved `R_int_delta` case.

---

### 2. `R_eq_diff` (polynomial-vs-exponential domination)

```lean
-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
  simp [mu]
  -- Goal:
  --   ω⁴ * (ω³*(μa+1) + ω²*(μb+1) + 2) + 1
  --     < ω^(μa + μb + 9) + 1
  -- Equivalent (add_lt_add_iff_right, cancel +1):
  --   ω⁴ * (ω³*(μa+1) + ω²*(μb+1) + 2) < ω^(μa + μb + 9)

  set μa := mu a
  set μb := mu b

  -- Step A: bound the merge-measure strictly
  --   ω³*(μa+1) + ω²*(μb+1) + 2
  --     < ω³ * ((μa+1) + (μb+1) + 1)
  --     ≤ ω³ * (μa + μb + 3)
  have h_inner :
      omega0^(3:Ordinal)*(μa+1) + omega0^(2:Ordinal)*(μb+1) + 2
        < omega0^(3:Ordinal) * (μa + μb + 3) := by
    -- (i) ω² < ω³ ⇒ ω²*(μb+1) < ω³*(μb+1)
    have h1 : omega0^(2:Ordinal)*(μb+1) < omega0^(3:Ordinal)*(μb+1) := by
      apply mul_lt_mul_of_pos_right
      · exact opow_lt_opow_iff_right one_lt_omega0 |>.mpr (by norm_num)
      · exact Ordinal.pos_iff_ne_zero.mpr (by simp)
    -- (ii) 2 < ω³
    have h2 : (2:Ordinal) < omega0^(3:Ordinal) := by
      calc (2:Ordinal) < omega0 := nat_lt_omega0 2
        _ ≤ omega0^(3:Ordinal) := opow_le_self_of_le_right one_le_omega0 (by norm_num)
    -- (iii) assemble with add_lt_add / le_of_lt
    -- use: x + y + z < x' + y' + z' when x≤x', y<y', z<z' (with care for non-strict)
    calc omega0^3*(μa+1) + omega0^2*(μb+1) + 2
      _ < omega0^3*(μa+1) + omega0^3*(μb+1) + omega0^3 := by
            -- apply add_lt_add_of_le_of_lt etc.
            sorry -- short calc using h1, h2
      _ = omega0^3 * ((μa+1) + (μb+1) + 1) := by
            rw [← mul_add, ← mul_add]
      _ ≤ omega0^3 * (μa + μb + 3) := by
            -- (μa+1)+(μb+1)+1 ≤ μa+μb+3
            -- because 1+μb ≤ μb+1
            apply mul_le_mul_left'
            calc (μa+1)+(μb+1)+1
              _ = μa + (1+μb) + 1 + 0 + 1 := by ac_rfl -- or ring-like reassoc
              _ ≤ μa + (μb+1) + 2 := by
                    apply add_le_add_right
                    exact add_le_add_left (by
                      -- 1+μb ≤ μb+1
                      cases' lt_or_le μb omega0 with h h
                      · -- finite: commute
                        sorry
                      · -- infinite: 1+μb = μb ≤ μb+1
                        sorry) _
              _ = μa + μb + 3 := by abel -- or simp [add_assoc]

  -- Step B: multiply by ω⁴
  have h_scaled :
      omega0^(4:Ordinal) *
        (omega0^3*(μa+1) + omega0^2*(μb+1) + 2)
        < omega0^(4:Ordinal) * (omega0^3 * (μa+μb+3)) :=
    mul_lt_mul_of_pos_left h_inner (opow_pos 4 omega0_pos)

  -- Step C: simplify left to ω⁷ · (μa+μb+3)
  have h_pow : omega0^4 * (omega0^3 * (μa+μb+3))
                = omega0^(7:Ordinal) * (μa+μb+3) := by
    rw [← mul_assoc, ← opow_add]; norm_num

  -- Step D: ω⁷ · θ < ω^(θ+6) where θ = μa+μb+3 ≥ 3
  --         (θ+6 = μa+μb+9)
  have h_exp : omega0^(7:Ordinal) * (μa+μb+3)
                < omega0^(μa+μb+9) := by
    set θ := μa + μb + 3
    -- two regimes
    by_cases hθ : θ < omega0
    · -- θ finite, θ ≥ 3 ⇒ θ+6 ≥ 9 > 7
      -- ω⁷·θ < ω⁷·ω = ω⁸ < ω⁹ ≤ ω^(θ+6)
      have : θ ≤ (θ:ℕ) := by sorry -- coerce
      calc omega0^7 * θ
        _ < omega0^7 * omega0 := mul_lt_mul_of_pos_left
              (lt_of_lt_of_le hθ (le_refl _)) (opow_pos _ omega0_pos)
        _ = omega0^8 := by rw [← opow_one_right, ← opow_add]; norm_num
        _ < omega0^9 := opow_lt_opow_iff_right one_lt_omega0 |>.mpr (by norm_num)
        _ ≤ omega0^(θ+6) := opow_le_opow_right omega0_pos (by
              -- 9 ≤ θ+6 since θ ≥ 3
              sorry)
    · -- θ ≥ ω ⇒ 7+θ = θ
      -- ω⁷·θ ≤ ω⁷·ω^θ = ω^(7+θ) = ω^θ < ω^(θ+6)
      have hθ' : omega0 ≤ θ := le_of_not_lt hθ
      calc omega0^7 * θ
        _ ≤ omega0^7 * omega0^θ := mul_le_mul_left' (le_opow_self _ _) _
        _ = omega0^(7+θ) := (opow_mul_opow_eq_opow_add _ _ _).symm
        _ = omega0^θ := by
              -- 7+θ = θ because θ ≥ ω
              rw [add_eq_right.mpr]; exact le_trans (nat_lt_omega0 7).le hθ'
        _ < omega0^(θ+6) :=
              opow_lt_opow_iff_right one_lt_omega0 |>.mpr (lt_add_of_pos_right _ (by norm_num))

  -- Step E: chain
  calc omega0^4 * (omega0^3*(μa+1) + omega0^2*(μb+1) + 2)
    _ < omega0^7 * (μa+μb+3) := h_pow ▸ h_scaled
    _ < omega0^(μa+μb+9)     := h_exp
  -- finally +1 on both sides (monotonicity of (+1))
```

**Key design check.** The exponent offset `+9` is exactly large enough: after collecting `ω⁷ · (μa+μb+3)` one still has six finite “degrees of freedom” left (`θ+6`), which covers both the finite and the infinite regimes for `θ`.

### 3. `R_rec_succ` (exponent tower domination)

```lean
-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
  simp [mu]
  -- Goal (after simp):
  --   ω³*(μs+1) + ω²*( ω^(μn+μs+6) + ω*(μb+1) + 2 ) + 1
  --     < ω^(ω⁵*(μn+1) + 1 + μs + 6) + ω*(μb+1) + 1
  -- i.e.
  --   ω³*(μs+1) + ω²*( ω^(μn+μs+6) + ω*(μb+1) + 2 ) + 1
  --     < ω^(ω⁵*(μn+1) + μs + 7) + ω*(μb+1) + 1

  set μn := mu n; set μs := mu s; set μb := mu b

  -- ── Step A: the crucial exponent inequality ──────────────────
  have h_exp : μn + μs + 8 < omega0^(5:Ordinal)*(μn+1) + μs + 7 := by
    -- Core domination: μn + k < ω⁵*(μn+1) for any finite k
    have h_core : μn + 8 < omega0^(5:Ordinal)*(μn+1) := by
      calc μn + 8
        _ < μn + omega0 := (add_lt_add_iff_left _).mpr (nat_lt_omega0 8)
        _ ≤ omega0 * (μn + 1) := by
              -- μn + ω ≤ ω·(μn+1) = ω·μn + ω
              -- standard bound: α + ω ≤ ω·(α+1)
              sorry -- Mathlib: le_mul_of_one_le / omega0_le_opow / ...
        _ ≤ omega0^5 * (μn + 1) :=
              mul_le_mul_right' (opow_le_opow_right omega0_pos (by norm_num)) _
    -- Now lift across + μs, then absorb the finite +7
    -- Two sub-cases on whether μs is finite give a clean proof:
    by_cases hμs : μs < omega0
    · -- μs finite ⇒ μn+μs+8 = (μn+8)+μs (finite addition commutes)
      -- and β := ω⁵*(μn+1) is a limit ⇒ (μn+8)+μs < β ≤ β+μs+7
      have : μn + μs + 8 = (μn + 8) + μs := by
        -- finite reassociation / commutativity
        sorry
      rw [this]
      calc (μn + 8) + μs
        _ < omega0^5*(μn+1) := by
              -- α < β limit, n finite ⇒ α+n < β
              sorry -- use h_core + limit character of ω⁵·_
        _ ≤ omega0^5*(μn+1) + μs + 7 := le_self_add
    · -- μs ≥ ω
      -- L = μn + μs + 8 = (μn + (μs+7)) + 1
      -- R = ω⁵*(μn+1) + (μs+7)
      -- show μn + (μs+7) < ω⁵*(μn+1) + (μs+7) by CNF /
      -- additive absorption under a multiple of ω⁵, then +1 still < R? 
      -- cleaner: L ≤ ω⁵*(μn+1) + μs + 8 = R+1 and L ≠ R+1
      -- because the left-most CNF term of R has degree ≥5 while
      -- the difference would require a pure finite carry that cannot match.
      sorry
      -- (alternative: prove the stronger
      --    μn + μs + 9 ≤ ω⁵*(μn+1) + μs + 7
      --  by writing both sides in CNF and comparing leading terms;
      --  the ω⁵·(μn+1) term on the right always dominates μn.)

  -- ── Step B: the dominant power on the RHS ───────────────────
  have h_pow_lt :
      omega0^(μn + μs + 8)
        < omega0^(omega0^5*(μn+1) + μs + 7) :=
    (opow_lt_opow_iff_right one_lt_omega0).mpr h_exp

  -- ── Step C: expand and bound every summand of the LHS ───────
  -- LHS = ω³*(μs+1)
  --     + ω² * ω^(μn+μs+6)          -- = ω^(μn+μs+8)
  --     + ω² * (ω*(μb+1) + 2)
  --     + 1
  --   = ω³*(μs+1) + ω^(μn+μs+8) + ω³*(μb+1) + ω²*2 + 1

  have h_term1 : omega0^3 * (μs + 1)
                  < omega0^(omega0^5*(μn+1) + μs + 7) := by
    -- ω³*(μs+1) ≤ ω³ * ω^(μs+1) = ω^(μs+4) < ω^(… + μs + 7)
    sorry

  have h_term2 : omega0^(μn + μs + 8)
                  < omega0^(omega0^5*(μn+1) + μs + 7) := h_pow_lt

  have h_term3 : omega0^3 * (μb + 1)
                  < omega0^(omega0^5*(μn+1) + μs + 7) := by
    -- same style as h_term1
    sorry

  have h_term4 : (omega0^2 * 2 + 1 : Ordinal)
                  < omega0^(omega0^5*(μn+1) + μs + 7) := by
    -- finite / low power < any ω^(≥1)
    sorry

  -- ── Step D: sum of four terms each < ω^Θ  (Θ ≥ 1) is still < ω^Θ
  -- because ω^Θ is additively principal for Θ ≥ 1
  have h_sum :
      omega0^3*(μs+1) + omega0^(μn+μs+8)
        + omega0^3*(μb+1) + (omega0^2*2 + 1)
        < omega0^(omega0^5*(μn+1) + μs + 7) := by
    -- repeated use of principal_add_omega0_opow / add_lt_of_lt / ...
    sorry

  -- ── Step E: finish
  -- LHS ≤ the sum above (by re-association of the expanded form)
  -- and RHS = ω^Θ + ω*(μb+1) + 1 ≥ ω^Θ
  calc
    _ ≤ omega0^3*(μs+1) + omega0^(μn+μs+8)
          + omega0^3*(μb+1) + omega0^2*2 + 1 := by
            -- expand ω²*(ω^(…)+ω*(μb+1)+2) via mul_add
            sorry
    _ < omega0^(omega0^5*(μn+1) + μs + 7) := h_sum
    _ ≤ omega0^(omega0^5*(μn+1) + μs + 7) + omega0*(μb+1) + 1 :=
          le_self_add
```

**Why the measure works.**  
`μ(delta n) = ω⁵·(μn+1)+1` injects an `ω⁵` factor into the *exponent* of the `recDelta` measure. Consequently the RHS exponent is at least `ω⁵·(μn+1) + μs + 7`, which strictly dominates the largest exponent that can appear on the LHS (`μn+μs+8`). Additive principality of `ω^Θ` then collapses the whole polynomial of lower-order terms.

---

### Summary of the three skeletons

| Case | Main idea | Critical lemma / fact |
|------|-----------|------------------------|
| `R_eq_refl` | positivity of `ω^_ + 1` | `add_pos_right`, same as `R_int_delta` |
| `R_eq_diff` | `ω⁴·(merge poly) < ω^(μa+μb+9)` | `ω⁷·θ < ω^(θ+6)` for `θ≥3` (case split `θ<ω` / `θ≥ω`) |
| `R_rec_succ` | LHS poly of degree `μn+μs+8` vs RHS tower `ω^(ω⁵·(μn+1)+…)` | `μn+μs+8 < ω⁵·(μn+1)+μs+7` + additive principality of `ω^Θ` |

All three proofs stay inside the already-imported Mathlib ordinal API (`opow_lt_opow_iff_right`, `mul_lt_mul_of_pos_*`, `nat_lt_omega0`, `principal` facts, `le_self_add`, etc.) and do not require any change to `mu` or to the five already-completed cases.
