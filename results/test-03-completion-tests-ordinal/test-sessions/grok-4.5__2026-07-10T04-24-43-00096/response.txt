## Proof skeleton for the three remaining cases

The three open cases are `R_rec_succ`, `R_eq_refl`, and `R_eq_diff`. Below is a skeleton that matches the existing style of `mu_decreases` (local `have`s, `calc`, Mathlib ordinal lemmas) and isolates the non-trivial arithmetic into named subgoals.

---

### Shared lemmas you will want

```lean
-- Additive principality of ω-powers (Mathlib)
-- principal_add_omega0_opow : ∀ o, Principal (· + ·) (omega0 ^ o)
-- Principal.add_lt : Principal (·+·) p → a < p → b < p → a + b < p

-- Strict monotonicity of right addition
-- add_lt_add_right : a < b → a + c < b + c

-- Power / multiplication
-- opow_add : omega0 ^ (a + b) = omega0 ^ a * omega0 ^ b
-- le_opow_self' : 1 < b → a ≤ b ^ a
-- (also: a < omega0 ^ a for all a, via lt_opow_self_of_one_lt / zero cases)

-- Useful elementary facts
-- lt_add_one, le_mul_right, opow_pos, omega0_pos, one_pos
-- mul_add (left distributivity)
```

### Case `R_eq_refl` (easiest)

Goal after `simp [mu]`:
```
0 < omega0 ^ (mu a + mu a + 9) + 1
```

Skeleton (mirrors the already-proved `R_int_delta` case):

```lean
| _, _, Step.R_eq_refl a => by
  simp [mu]
  -- 0 < ω^(…) + 1 by positivity of the right summand
  exact Ordinal.pos_iff_ne_zero.mpr (by
    apply ne_of_gt
    exact add_pos_right _ one_pos)
  -- alternative one-liners:
  -- exact lt_of_lt_of_le one_pos (le_add_left _ _)
  -- exact add_pos_of_nonneg_of_pos bot_le one_pos
```

No ordinal-arithmetic subtlety; pure positivity.

### Case `R_eq_diff`

Goal after `simp [mu]`:
```
omega0 ^ 4 * (mu (merge a b) + 1) + 1
  < omega0 ^ (mu a + mu b + 9) + 1
```
i.e.
```
ω⁴ · (ω³(μa+1) + ω²(μb+1) + 2) + 1
  < ω^(μa+μb+9) + 1
```

Skeleton:

```lean
| _, _, Step.R_eq_diff a b => by
  simp [mu]
  -- Reduce "+ 1" on both sides
  refine add_lt_add_right ?_ 1
  -- Goal: ω⁴ * (ω³(μa+1) + ω²(μb+1) + 2) < ω^(μa+μb+9)

  -- (1) Expand by left distributivity + ω-power arithmetic
  have h_expand :
      omega0 ^ 4 *
        (omega0 ^ 3 * (mu a + 1) + omega0 ^ 2 * (mu b + 1) + 2) =
      omega0 ^ 7 * (mu a + 1) +
      omega0 ^ 6 * (mu b + 1) +
      omega0 ^ 4 * 2 := by
    rw [mul_add, mul_add]
    congr 1
    · -- ω⁴ * (ω³ * (μa+1)) = ω⁷ * (μa+1)
      rw [← mul_assoc, ← opow_add]
      norm_cast  -- 4+3 = 7
    · -- ω⁴ * (ω² * (μb+1)) = ω⁶ * (μb+1)
      rw [← mul_assoc, ← opow_add]
      norm_cast  -- 4+2 = 6
  rw [h_expand]

  -- (2) Target power is additively principal
  have hprin : Principal (· + ·) (omega0 ^ (mu a + mu b + 9)) :=
    principal_add_omega0_opow _

  -- (3) Bound each summand strictly below ω^(μa+μb+9)
  have b1 : omega0 ^ 7 * (mu a + 1) < omega0 ^ (mu a + mu b + 9) := by
    -- μa+1 < ω^(μa+1)  (strict)
    have hlt : mu a + 1 < omega0 ^ (mu a + 1) := by
      -- use lt_opow_self_of_one_lt omega0_gt_one, handle 0 if needed
      sorry
    have hmul :
        omega0 ^ 7 * (mu a + 1) < omega0 ^ 7 * omega0 ^ (mu a + 1) :=
      (mul_lt_mul_iff_of_pos_left (opow_pos _ omega0_pos)).mpr hlt
    -- ω⁷ * ω^(μa+1) = ω^(7 + μa + 1)
    have hpow :
        omega0 ^ 7 * omega0 ^ (mu a + 1) = omega0 ^ (7 + mu a + 1) := by
      rw [← opow_add]; congr 1
      -- 7 + (μa + 1) = 7 + μa + 1
      abel
    rw [hpow] at hmul
    -- 7 + μa + 1 ≤ μa + 8  (finite: equal; infinite: 7+μa collapses)
    have hle_exp : 7 + mu a + 1 ≤ mu a + 8 := by
      -- case split on mu a < ω vs ≥ ω, or use a small calc
      sorry
    -- μa + 8 < μa + μb + 9  (since 8 < μb + 9)
    have hlt_exp : mu a + 8 < mu a + mu b + 9 := by
      apply add_lt_add_left
      have : (8 : Ordinal) < mu b + 9 :=
        lt_of_lt_of_le (by norm_cast : (8 : Ordinal) < 9)
          (le_add_left _ _)
      -- actually: 8 < μb + 9 always
      exact lt_of_lt_of_le (by decide : (8 : Ordinal) < 9)
        (le_self_add.trans (add_le_add_right (Ordinal.zero_le _) _))
      -- cleaner: exact lt_add_of_pos_right _ (by norm_num : (0:Ordinal) < 1) … 
      sorry
    -- chain: ω^(7+μa+1) ≤ ω^(μa+8) < ω^(μa+μb+9)
    have : omega0 ^ (7 + mu a + 1) ≤ omega0 ^ (mu a + 8) :=
      opow_le_opow_right omega0_pos hle_exp
    have : omega0 ^ (mu a + 8) < omega0 ^ (mu a + mu b + 9) :=
      (opow_lt_opow_iff_right omega0_gt_one).mpr hlt_exp
    exact hmul.trans_le (this.trans_lt ‹_› |>.le) |>.trans_lt ‹_›
    -- tidy with calc once the two exp facts are in place

  have b2 : omega0 ^ 6 * (mu b + 1) < omega0 ^ (mu a + mu b + 9) := by
    -- same pattern: μb+1 < ω^(μb+1)
    -- ⇒ ω⁶*(μb+1) < ω^(6+μb+1) ≤ ω^(μb+7) < ω^(μa+μb+9)
    -- key: μb + 7 < μb + 9 ≤ μa + μb + 9
    sorry

  have b3 : omega0 ^ 4 * 2 < omega0 ^ (mu a + mu b + 9) := by
    -- 4 < μa+μb+9 (since RHS ≥ 9), so ω⁴*2 < ω⁵ ≤ ω^(μa+μb+9)
    have h4 : (4 : Ordinal) < mu a + mu b + 9 := by
      calc (4 : Ordinal)
        _ < 9 := by norm_cast
        _ ≤ mu a + mu b + 9 := le_add_left _ _
    -- then ω⁴ < ω^(μa+μb+9), and multiply by 2 still below the next power
    sorry

  -- (4) Sum of three terms each < principal ordinal
  have sum12 :
      omega0 ^ 7 * (mu a + 1) + omega0 ^ 6 * (mu b + 1)
        < omega0 ^ (mu a + mu b + 9) :=
    hprin.add_lt b1 b2
  exact hprin.add_lt sum12 b3
```

**Design note.** The `+ 9` in `mu (eqW …)` is exactly the slack that absorbs the fixed `ω⁷`, `ω⁶`, `ω⁴` coefficients after expansion of `integrate (merge …)`. The critical comparison is always of the form
```
fixed + μx + c  <  μa + μb + 9
```
which holds because the constant on the left is smaller than `9` and the missing variable is ≥ 0.

### Case `R_rec_succ` (hardest)

Goal after `simp [mu]`:
```
mu (app s (recDelta b s n)) < mu (recDelta b s (delta n))
```
i.e.
```
ω³(μs+1) + ω²(μ(rec)+1) + 1
  <  ω^(μ(δ n) + μs + 6) + ω(μb+1) + 1
```
where
```
μ(δ n) = ω⁵(μn+1) + 1
μ(rec) = ω^(μn+μs+6) + ω(μb+1) + 1
```
so the source exponent is
```
exp := μ(δ n) + μs + 6 = ω⁵(μn+1) + μs + 7
```

Skeleton:

```lean
| _, _, Step.R_rec_succ b s n => by
  simp [mu]
  -- After simp the goal is literally
  --   ω³(μs+1) + ω²( (ω^(μn+μs+6) + ω(μb+1) + 1) + 1 ) + 1
  --     <  ω^( (ω⁵(μn+1)+1) + μs + 6 ) + ω(μb+1) + 1

  -- ── Step A: name the dominant exponent ──────────────────────────
  set exp : Ordinal :=
    mu (delta n) + mu s + 6 with hexp
  -- After unfolding mu(delta n):
  have exp_simp :
      exp = omega0 ^ 5 * (mu n + 1) + mu s + 7 := by
    simp [exp, mu]
    -- (ω⁵(μn+1) + 1) + μs + 6 = ω⁵(μn+1) + μs + 7
    abel

  -- ── Step B: it is enough to beat the pure ω^exp summand ─────────
  -- If LHS < ω^exp then LHS < ω^exp + ω(μb+1) + 1 = RHS
  have enough :
      omega0 ^ 3 * (mu s + 1)
        + omega0 ^ 2 * (mu (recDelta b s n) + 1) + 1
        < omega0 ^ exp →
      omega0 ^ 3 * (mu s + 1)
        + omega0 ^ 2 * (mu (recDelta b s n) + 1) + 1
        < omega0 ^ exp + omega0 * (mu b + 1) + 1 := by
    intro h
    exact lt_of_lt_of_le h (le_add_right _ _)

  apply enough
  -- Goal now: ω³(μs+1) + ω²(μ(rec)+1) + 1 < ω^exp

  -- ── Step C: expand μ(rec) + 1 ───────────────────────────────────
  have hrec :
      mu (recDelta b s n) + 1 =
        omega0 ^ (mu n + mu s + 6) + omega0 * (mu b + 1) + 2 := by
    simp [mu]; abel

  -- ── Step D: distribute ω² ───────────────────────────────────────
  have hdist :
      omega0 ^ 2 * (mu (recDelta b s n) + 1) =
        omega0 ^ (mu n + mu s + 8)
        + omega0 ^ 3 * (mu b + 1)
        + omega0 ^ 2 * 2 := by
    rw [hrec, mul_add, mul_add]
    congr 1
    · -- ω² * ω^(μn+μs+6) = ω^(μn+μs+8)
      rw [← opow_add]
      congr 1
      -- 2 + (μn+μs+6) = μn+μs+8
      abel
    · -- ω² * (ω · (μb+1)) = ω³ · (μb+1)
      rw [← mul_assoc, ← opow_one omega0, ← opow_add]
      norm_cast  -- 2+1 = 3
  -- rewrite the goal with hdist
  -- Goal becomes:
  --   ω³(μs+1) + ω^(μn+μs+8) + ω³(μb+1) + 2·ω² + 1  <  ω^exp

  -- ── Step E: additive principality ───────────────────────────────
  have hprin : Principal (· + ·) (omega0 ^ exp) :=
    principal_add_omega0_opow _

  -- ── Step F: four (or five) component bounds ─────────────────────
  -- F1. The critical exponent comparison
  have exp_lt :
      mu n + mu s + 8 < exp := by
    -- exp = ω⁵(μn+1) + μs + 7
    rw [exp_simp]
    -- μn + μs + 8 = (μn + 1) + μs + 7
    -- and μn + 1 < ω⁵ · (μn + 1)  (strict, since ω⁵ ≥ 2)
    have hμn : mu n + 1 < omega0 ^ 5 * (mu n + 1) := by
      have h1 : (1 : Ordinal) < omega0 ^ 5 := by
        -- ω⁵ ≥ ω > 1
        exact one_lt_omega0.trans_le (le_opow_self' omega0_gt_one _)
      -- α < c·α for c > 1, α ≥ 1; or: c·α ≥ 2·α = α+α ≥ α+1 > α
      sorry
    -- right-addition preserves strict inequality
    have : (mu n + 1) + (mu s + 7)
            < omega0 ^ 5 * (mu n + 1) + (mu s + 7) :=
      add_lt_add_right hμn _
    -- rearrange both sides to the desired shapes
    convert this using 1 <;> abel

  have b_main :
      omega0 ^ (mu n + mu s + 8) < omega0 ^ exp :=
    (opow_lt_opow_iff_right omega0_gt_one).mpr exp_lt

  -- F2. ω³(μs+1) < ω^exp
  have b_s : omega0 ^ 3 * (mu s + 1) < omega0 ^ exp := by
    -- μs+1 < ω^(μs+1) ⇒ ω³(μs+1) < ω^(3+μs+1) ≤ ω^(μs+4)
    -- and μs+4 < exp = ω⁵(μn+1)+μs+7
    -- (because 4 < ω⁵(μn+1)+7, then right-add μs… careful with order;
    --  better: μs+4 < μs + (ω⁵(μn+1)+7) ≤ ω⁵(μn+1)+μs+7 after
    --  showing μs + γ = γ + μs or using absorption when γ ≥ ω)
    sorry

  -- F3. ω³(μb+1) < ω^exp   (same pattern as b_s)
  have b_b : omega0 ^ 3 * (mu b + 1) < omega0 ^ exp := by
    sorry

  -- F4. 2·ω² + 1 < ω^exp   (trivial: degree 2 ≪ exp ≥ ω⁵ ≥ ω)
  have b_fin :
      omega0 ^ 2 * 2 + 1 < omega0 ^ exp := by
    sorry

  -- ── Step G: reassemble with principality ────────────────────────
  -- (order of summands must match the goal after hdist;
  --  use add_assoc / add_comm only where valid, or apply hprin.add_lt
  --  iteratively left-to-right)
  have s1 := hprin.add_lt b_s b_main
  have s2 := hprin.add_lt s1 b_b
  exact hprin.add_lt s2 b_fin
```

**Why the measure works here.**  
`delta` is assigned base `ω⁵`, so the source exponent contains the term `ω⁵·(μn+1)`. That single term strictly dominates the “recursive” exponent `μn+μs+6` that appears inside `μ(rec)` (and therefore after multiplication by `ω²` becomes `μn+μs+8`). All other summands of the `app` measure have fixed finite degree (`3` or `2`) and are absorbed by the same principal ordinal `ω^exp`. The `+6` / `+7` offsets are just bookkeeping so that the inequalities stay strict after the `+1`s introduced by the measure definition.

### Assembly checklist

| Case | Main idea | Key comparison |
|---|---|---|
| `R_eq_refl` | positivity of `ω^_ + 1` | none |
| `R_eq_diff` | expand `ω⁴·(merge…)`; each CNF term has degree `< μa+μb+9` | `μa+8 < μa+μb+9`, `μb+7 < μa+μb+9` |
| `R_rec_succ` | LHS `< ω^exp` with `exp = ω⁵(μn+1)+μs+7`; RHS absorbs `ω^exp` | `μn+μs+8 < ω⁵(μn+1)+μs+7` |

Once the three `sorry`s are filled along the skeletons above, `mu_decreases` is complete and `strong_normalization` follows unchanged via `Subrelation.wf` + `InvImage.wf`.
