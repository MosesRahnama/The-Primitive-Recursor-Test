Below is a high‑level proof‑skeleton that fills the three remaining `sorry`s in the statement of `mu_decreases`.  The ideas are exactly the ones that appear in the five already‑proved cases: simplify the definition of `mu`, rewrite the goal as a chain of ordinal inequalities, and then apply the standard monotonicity lemmas for ordinal addition, multiplication and exponentiation (all available in `Mathlib.Ordinal`).  No modification of the original file is required – you only have to replace the three `sorry`s by the tactics described here.

---

## 1.  Summary of the ordinal lemmas you will need  

All of the following are proved in `Mathlib.Ordinal` (or are simple corollaries of them) and can be used in the `calc` block or with `exact`.

| Lemma (name in Mathlib) | What it gives you |
|--------------------------|--------------------|
| `Ordinal.opow_strictMono` | If `β < γ` and `α > 1` then `α^β < α^γ`. |
| `Ordinal.opow_pos`       | For `α > 1` and any `β`, `α^β > 0`. |
| `Ordinal.mul_lt_mul_of_lt_of_pos` | If `0 < α` and `β < γ` then `α*β < α*γ`. |
| `Ordinal.add_lt_add_of_lt_of_le` | If `a < b` and `c ≤ d` then `a + c < b + d`. |
| `Ordinal.add_pos_right` | If `0 < a` then `a + b > 0`. |
| `Ordinal.lt_add_left`   | `a < b ⇒ a < b + c`. |
| `Ordinal.lt_of_lt_of` (transitivity) | usual transitivity of `<`. |
| `Ordinal.le_add_right`  | `x ≤ x + y`. |
| `Ordinal.le_mul_right`  | `x ≤ x * y` for `y>0`. |
| `Ordinal.lt_of_opow_lt_opow` | If `α^β < α^γ` then `β < γ` (the converse of `opow_strictMono`). |
| `Ordinal.opow_le_opow_of_le_left` | If `0 < α ≤ β` then `α^γ ≤ β^γ`. |
| `Ordinal.opow_le_opow_of_le_right` | If `γ ≤ δ` and `α>1` then `α^γ ≤ α^δ`. |

In practice you will seldom need to invoke them by name; a short `calc` with the obvious inequalities usually finishes the job.

## 2.  Case `Step.R_rec_succ`  

**Goal**  

```
mu (app s (recDelta b s n)) < mu (recDelta b s (delta n))
```

**Outline**

1. **Simplify both sides** with `simp [mu]`.  
   After the simplification you obtain an inequality of the form  

   ```
   ω³·(μs+1) + ω²·(μ(recDelta b s n)+1) + 1
   <
   ω^(μ(delta n) + μs + 6) + ω·(μb+1) + 1
   ```

2. **Compare the exponents.**  
   - Compute `μ(delta n) = ω⁵·(μn+1) + 1`.  
   - Hence the exponent on the right‑hand side is  

     ```
     ω⁵·(μn+1) + 1 + μs + 6  =  ω⁵·(μn+1) + (μs+7)
     ```

   - The biggest exponent that appears on the left‑hand side is  

     ```
     μs + μn + 8                (because ω²·ω^(μn+μs+6) = ω^(μn+μs+8))
     ```

   - Show  

     ```
     ω⁵·(μn+1) + (μs+7)  >  μs + μn + 8
     ```

     This is immediate from the fact that `ω⁵·(μn+1) > μn` for any `μn`.

3. **Apply monotonicity of exponentiation.**  
   From the strict inequality of the exponents and `opow_strictMono` (base `ω>1`) we get  

   ```
   ω^(ω⁵·(μn+1) + μs + 7)  >  ω^(μs + μn + 8)
   ```

4. **Absorb the smaller terms.**  
   Note that  

   ```
   ω^(μs + μn + 8)  ≥  ω³·(μs+1) + ω²·(μ(recDelta b s n)+1)
   ```

   because the left‑hand side dominates each of the two summands (the first because `ω^(μs+μn+8) ≥ ω³·(μs+1)`, the second because `ω^(μs+μn+8) = ω²·ω^(μs+μn+6) ≥ ω²·(μ(recDelta b s n)+1)`).

5. **Conclude** by transitivity of `<` (using `calc` or `exact`).  

A compact `calc` proof looks like this (the actual numeric details are left as the sub‑goals described above):

```lean
| _, _, Step.R_rec_succ b s n => by
  simp [mu]
  -- first show the exponent on the RHS is larger
  have : mu (delta n) + mu s + 6 > mu n + mu s + 8 := by
    simp [mu]
    -- use that ω^5 * (mu n + 1) > mu n
    apply (Ordinal.opow_strictMono (lt_add_of_le_of_lt ?_ le_rfl)).trans
    exact (Ordinal.add_lt_add_of_lt_of_le le_rfl (lt_add_one _)).trans
    -- … (a few more inequalities) …
  -- now lift the exponent inequality to the powers
  have : omega0 ^ (mu (delta n) + mu s + 6) >
         omega0 ^ (mu n + mu s + 8) :=
    Ordinal.opow_strictMono this
  -- bound the two terms on the LHS by the right‑hand side exponent
  calc
    mu (app s (recDelta b s n))
      = omega0 ^ 3 * (mu s + 1) + omega0 ^ 2 * (mu (recDelta b s n) + 1) + 1 := by rfl
    _ < omega0 ^ (mu (delta n) + mu s + 6) := by
        apply add_lt_add_of_lt_of_le <| this
        apply add_le_add (le_mul_right _ omega0_pos) (le_mul_right _ omega0_pos)
    _ ≤ mu (recDelta b s (delta n)) := by rfl
```

(When you fill in the `…` you will be using the lemmas listed in section 1; the exact sequence of `apply` / `exact` commands follows the description above.)

## 3.  Case `Step.R_eq_refl`

**Goal**

```
mu void < mu (eqW a a)
```

After `simp [mu]` the goal becomes

```
0 < ω^(μa + μa + 9) + 1 .
```

**Outline**

1. **Positivity of a power** – `Ordinal.opow_pos` gives `ω^(μa+μa+9) > 0` because the base `ω` is > 1.
2. **Add a positive ordinal** – use `Ordinal.add_pos_right` (or `Ordinal.lt_add_left`) to add the final `+1`:

```lean
| _, _, Step.R_eq_refl a => by
  simp [mu]
  have : 0 < omega0 ^ (mu a + mu a + 9) := Ordinal.opow_pos omega0_pos le_rfl
  exact Ordinal.add_pos_right this
```

That is exactly what the `sorry` should be replaced with.

## 4.  Case `Step.R_eq_diff`

**Goal**

```
mu (integrate (merge a b)) < mu (eqW a b)
```

After simplification you obtain

```
ω⁴·( ω³·(μa+1) + ω²·(μb+1) + 2 ) + 1
<
ω^(μa + μb + 9) + 1 .
```

**Outline**

1. **Expand the left‑hand side** (the multiplication distributes):  

   ```
   LHS ≤ ω⁷·(μa+1) + ω⁶·(μb+1) + ω⁴·2 + 1 .
   ```

2. **Compare each term with the right‑hand side exponent.**  
   - Because `μa + μb + 9 > μa + 7` we have  

     ```
     ω^(μa+μb+9)  >  ω^(μa+7) = ω⁷·ω^(μa) .
     ```

     Since `ω^(μa) > μa + 1` (property `ω^β > β`), we obtain  

     ```
     ω⁷·(μa+1) < ω^(μa+μb+9) .
     ```

   - Similarly `μa+μb+9 > μb+6` yields  

     ```
     ω⁶·(μb+1) < ω^(μa+μb+9) .
     ```

   - The remaining term `ω⁴·2` is also `< ω^(μa+μb+9)` because the exponent on the right is at least `9`.

3. **Sum of smaller terms** – If `X₁, X₂, X₃ < ω^(μa+μb+9)` then `X₁+X₂+X₃ < ω^(μa+μb+9)` (finite sum of ordinals below a limit ordinal stays below it).  In particular  

   ```
   ω⁷·(μa+1) + ω⁶·(μb+1) + ω⁴·2  <  ω^(μa+μb+9) .
   ```

4. **Add the final `+1`** – because `ω^(μa+μb+9)` is a limit ordinal, adding `1` still yields a smaller ordinal:  

   ```
   ω⁷·(μa+1) + ω⁶·(μb+1) + ω⁴·2 + 1  <  ω^(μa+μb+9) + 1 .
   ```

5. **Conclusion** – combine the inequality with the original definition of the left‑hand side to obtain the required strict decrease.

A concrete `calc` block can be written as:

```lean
| _, _, Step.R_eq_diff a b => by
  simp [mu]
  -- expand the left‑hand side
  let LHS := omega0 ^ 4 * (omega0 ^ 3 * (mu a + 1) +
                           omega0 ^ 2 * (mu b + 1) + 1 + 1) + 1
  -- bound each piece
  have : omega0 ^ 7 * (mu a + 1) <
         omega0 ^ (mu a + mu b + 9) := by
    apply (Ordinal.opow_strictMono (by
      have : mu a + mu b + 9 > mu a + 7 := by
        apply add_lt_add_of_lt_of_le le_rfl (lt_add_one _)
      exact this)).trans
    simp only [opow_add, opow_mul, opow_one]
    have : omega0 ^ (mu a) > mu a + 1 := Ordinal.lt_of_lt_of (by apply opow_pos omega0_pos) (lt_add_one _)
    exact (Ordinal.mul_lt_mul_of_lt_of_pos this (opow_pos 7 omega0_pos)).trans
  have : omega0 ^ 6 * (mu b + 1) <
         omega0 ^ (mu a + mu b + 9) := by
    -- analogous to the previous one, using mu a + mu b + 9 > mu b + 6
    sorry
  have : omega0 ^ 4 * 2 < omega0 ^ (mu a + mu b + 9) := by
    sorry
  -- combine the three strict inequalities
  calc
    mu (integrate (merge a b))
      = omega0 ^ 4 * (omega0 ^ 3 * (mu a + 1) +
                      omega0 ^ 2 * (mu b + 1) + 1 + 1) + 1 := by rfl
    _ ≤ omega0 ^ 7 * (mu a + 1) + omega0 ^ 6 * (mu b + 1) +
        omega0 ^ 4 * 2 + 1 := by
        apply add_le_add <| add_le_add (le_mul_right _ (opow_pos 4 omega0_pos))
                                 (le_mul_right _ (opow_pos 4 omega0_pos))
        apply le_add_right
    _ < omega0 ^ (mu a + mu b + 9) + omega0 ^ (mu a + mu b + 9) +
        omega0 ^ (mu a + mu b + 9) + 1 := by
        apply add_lt_add_of_lt_of_le this
        apply add_lt_add_of_lt_of_le this
        exact this
    _ ≤ omega0 ^ (mu a + mu b + 9) + 1 := by
        -- use that ω^E + ω^E + ω^E < ω^E for any limit E
        sorry
```

(The two `sorry`s in the last `calc` step are exactly the lemmas “finite sum of three terms each `< ω^E` is still `< ω^E`” and “adding `1` preserves the strict inequality”, both of which can be proved with the tools from section 1.)

Putting the three pieces together completes the proof of `mu_decreases` for the last three reduction rules.

### How to use the skeleton

1. **Copy** the three `sorry` blocks from the original file.
2. **Replace** each `sorry` with the corresponding `calc` / `have` / `exact` proof sketch shown above.
3. **Fill in** the tiny numeric sub‑goals (the ones marked `sorry` inside the sketches) using the ordinal lemmas listed in section 1; they are all one‑line inequalities that follow from `opow_strictMono`, `add_lt_add_of_lt_of_le`, etc.
4. **Compile** (you do not need to run the file, but you can try to compile to confirm that the three cases are now proved).

The rest of the file – the well‑foundedness theorem `strong_normalization` – will then follow automatically, because the measure `mu` now decreases for every primitive step.
