  simp [mu]
  -- Goal shape after simp:
  -- ω^3*(mu s + 1) + ω^2*(ω^(mu n + mu s + 6) + ω*(mu b + 1) + 1 + 1) + 1
  -- < ω^(mu (delta n) + mu s + 6) + ω*(mu b + 1) + 1
  --
  -- with mu (delta n) = ω^5*(mu n + 1) + 1.

  -- 1) Show the app-measure is bounded by one ω-power with exponent
  --    strictly below (mu (delta n) + mu s + 6).
  have hExp :
      (mu n + mu s + (6 : Ordinal)) < (mu (delta n) + mu s + (6 : Ordinal)) := by
    -- enough to show mu n < mu (delta n), then monotonicity of (+ mu s + 6)
    have hnd : mu n < mu (delta n) := by
      -- same pattern as earlier: mu n < mu n+1 ≤ ω^5*(mu n+1) < ... +1
      have h1 : mu n < mu n + 1 := lt_add_one (mu n)
      have h2 : mu n + 1 ≤ omega0 ^ (5 : Ordinal) * (mu n + 1) :=
        le_mul_right _ (opow_pos 5 omega0_pos)
      have h3 : mu n < omega0 ^ (5 : Ordinal) * (mu n + 1) := lt_of_lt_of_le h1 h2
      -- then into +1
      exact lt_of_lt_of_le h3 (le_add_right _ _)
    -- transport across right-addition
    exact add_lt_add_right hnd _

  have hPow :
      omega0 ^ (mu n + mu s + (6 : Ordinal))
        < omega0 ^ (mu (delta n) + mu s + (6 : Ordinal)) := by
    exact opow_lt_opow_right omega0 hExp  -- or corresponding monotonic lemma in your Mathlib

  --    (Use standard “lower-order terms are absorbed” lemmas.)

    -- skeleton: repeatedly use
    --   * terms like ω^3 * ... , ω^2 * ... are < ω^(big exponent)
    --   * hPow for the recursive ω^(mu n + mu s + 6) component
    --   * add/succ absorption below principal term

    omega0 ^ (3 : Ordinal) * (mu s + 1)
      + omega0 ^ (2 : Ordinal) * (omega0 ^ (mu n + mu s + (6 : Ordinal)) + omega0 * (mu b + 1) + 1 + 1) + 1

## Practical tip

For the two hard branches (`rec_succ`, `eq_diff`), the missing ingredients are usually a handful of lemmas of the form:

- monotonicity/strict monotonicity of `ω^x` in exponent,
- `a < b → a + c < b + c`,
- bounds sending lower-rank polynomial terms under a bigger principal `ω^E`,
- positivity of `ω^k`.

If exact lemma names differ, keep this structure and swap in local `have` proofs with `calc` + `lt_of_lt_of_le` as you already did in earlier branches.
