Here is a proof skeleton for the three remaining cases. The ideas rely on the monotonicity properties of ordinal exponentation, the fact that `ω^γ` is an additive principal ordinal for any `γ > 0`, and elementary bounds on the exponents. The missing cases are `R_rec_succ`, `R_eq_refl`, and `R_eq_diff`.

---

### 1. `Step.R_rec_succ b s n`

We need  
`mu (app s (recDelta b s n)) < mu (recDelta b s (delta n))`.

Set  
`A := mu n`, `B := mu s`, `C := mu b`.

Compute:

```
mu (recDelta b s (delta n))
= ω^{ mu(delta n) + mu s + 6 } + ω * (mu b + 1) + 1
= ω^{ (ω^5·(A+1) + 1) + B + 6 } + ω·(C+1) + 1
= ω^{ ω^5·(A+1) + B + 7 } + ω·(C+1) + 1

mu (app s (recDelta b s n))
= ω^3·(B+1) + ω^2·(mu(recDelta b s n) + 1) + 1
= ω^3·(B+1) + ω^2·( ω^{A+B+6} + ω·(C+1) + 1 + 1 ) + 1
= ω^3·(B+1) + ω^{A+B+8} + ω^3·(C+1) + ω^2·2 + 1 .
```

Now observe:

* `ω^3·(B+1) ≤ ω^{3+B} ≤ ω^{A+B+8}` because `A ≥ 0`.
* `ω^3·(C+1) ≤ ω^{A+B+8}` similarly.
* `ω^2·2 < ω^{A+B+8}` (since `A+B+8 ≥ 8 > 2`).

Thus the left‑hand side is bounded above by a finite sum of copies of `ω^{A+B+8}`; concretely  
`mu (app …) ≤ ω^{A+B+8} · 5` (where the constant 5 can be replaced by any natural number).

Because `ω^{A+B+8} · 5 < ω^{A+B+8} · ω = ω^{A+B+9}`, it suffices to show  
`ω^{A+B+9} < ω^{ ω^5·(A+1) + B + 7 }`.

Since `ω > 1`, the strict monotonicity of `ω^·` gives this inequality exactly when  
`A+B+9 < ω^5·(A+1) + B + 7  ⇔  A+2 < ω^5·(A+1)`.

The right‑hand side `ω^5·(A+1)` is obtained by multiplying `ω^5 (> 1)` with `A+1 (> 0)`. For ordinals, `α>1` and `β>0` imply `α·β > β`. Hence `ω^5·(A+1) > A+1 ≥ A+2 ?` Actually `A+2 ≤ (A+1)+1` and `ω^5·(A+1) ≥ (A+1)+1` holds because `ω^5·(A+1) ≥ A+1` and if equality were possible we would have `A+1` a fixed point of `ω^5·`, impossible for `ω^5 > 1`. A quick way: `ω^5·(A+1) ≥ (A+1)·2 = A·2+2 ≥ A+2`. So the exponent inequality holds strictly.

Therefore `mu (app …) < ω^{ ω^5·(A+1) + B + 7 } ≤ mu (recDelta … (delta n))` (the last because `mu` adds non‑negative ordinals to the huge power). The final strict inequality follows.

*Key lemmas:*  
`Ordinal.one_pos`, `Ordinal.opow_lt_opow_of_exponent_lt` (requires base > 1), `Ordinal.mul_lt_mul_of_pos_left`/`right`, `Ordinal.add_lt_add`, and the property `a>1 ∧ b>0 → a·b > b`.

---

### 2. `Step.R_eq_refl a`

We need `mu void < mu (eqW a a)`.

`mu void = 0`, `mu (eqW a a) = ω^{ mu a + mu a + 9 } + 1`.  
Both sides simplify with `simp [mu]`. The goal becomes `0 < ω^{ … } + 1`.

This is immediate because `ω^{ … } ≥ 0` and `1 > 0` implies their sum is positive:  
`exact add_pos_of_nonneg_of_pos (zero_le _) one_pos`.

*Key lemmas:* `Ordinal.zero_le`, `Ordinal.one_pos`, `Ordinal.add_pos_of_nonneg_of_pos`.

---

### 3. `Step.R_eq_diff a b`

We need `mu (integrate (merge a b)) < mu (eqW a b)`.

Again set `A := mu a`, `B := mu b`.

```
mu (eqW a b)                = ω^{A+B+9} + 1

mu (integrate (merge a b))  = ω^4·(mu(merge a b) + 1) + 1
                             = ω^4·( ω^3·(A+1) + ω^2·(B+1) + 2 ) + 1
                             = ω^7·(A+1) + ω^6·(B+1) + ω^4·2 + 1 .
```

The right‑hand side `ω^{A+B+9}` is an **additive principal ordinal**: for any `x,y < ω^{A+B+9}` we have `x+y < ω^{A+B+9}`.  
(This is a standard fact: `ω^γ` is additive principal for every `γ > 0`.)  
There is a lemma `Ordinal.principal_add_iff` or `Ordinal.opow_is_add_principal` in `Mathlib.SetTheory.Ordinal.Principal`.

Therefore it suffices to prove that each summand of the left‑hand side is strictly below `ω^{A+B+9}`:

* `ω^7·(A+1) < ω^{A+B+9}`  
  Because `7 < A+B+9` (obvious) and `A+1 < ω^{A+B+9}` (since `A+1 ≤ ω^{A+1} < ω^{A+B+9}` – the last strict inequality uses `A+1 < A+B+9` and the fact that `ω` power is strictly monotone in the exponent when the exponent is non‑zero? Actually if `A+1` is zero? A is mu of a term, so it might be 0, then `A+1=1`, still `1 < ω^{B+9}`. So it’s true). The product of two ordinals each below `ω^{γ}` is again below `ω^{γ}` when `γ` is a limit ordinal, but we can avoid product rules by a direct estimate:  
  `ω^7·(A+1) ≤ ω^7 · ω^{A+1} = ω^{A+8} < ω^{A+B+9}` (since `B+9 ≥ 9 > 8`). This uses `x+1 ≤ ω^{x+1}` (true for all ordinals) and `ω^δ` monotonicity.

* `ω^6·(B+1) < ω^{A+B+9}` by the same argument, leading to `ω^{B+7} < ω^{A+B+9}`.

* `ω^4·2 < ω^{A+B+9}` because `4 < A+B+9` and the constant `2` is smaller than any infinite power.

* `1 < ω^{A+B+9}`.

Thus each term is ` < ω^{A+B+9}`, and by additivity the sum `ω^7·(A+1) + … + 1` is also ` < ω^{A+B+9}`.  
Adding `+1` on the right side (since `mu(eqW …) = ω^{…}+1`) does not affect the strict inequality, so the final goal holds.

*Key lemmas:* `Ordinal.opow_lt_opow_of_exponent_lt`, `Ordinal.lt_of_lt_of_le`, `Ordinal.add_lt_omega_opow` (or the additive principal property), `Ordinal.mul_add`, `Ordinal.add_assoc`, and again `Ordinal.one_pos`.
