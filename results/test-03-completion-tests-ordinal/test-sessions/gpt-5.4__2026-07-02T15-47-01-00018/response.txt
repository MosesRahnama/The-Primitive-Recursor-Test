Below is a proof skeleton for the three remaining cases. I am not editing the file; this is a suggested shape for how to complete them in-place.

The key idea in all three cases is:

- for `R_eq_refl`, just use positivity of `ω^(...) + 1`;
- for `R_rec_succ`, first prove the exponent on the recursive-call side is strictly smaller than the exponent coming from `delta n`, then lift that through monotonicity of `ω^_`, then dominate the lower-order `ω^3` / `ω^2` terms by the huge leading `ω^(...)`;
- for `R_eq_diff`, similarly show the “polynomial in ω” coming from `integrate (merge a b)` is bounded by some `ω^k` with small finite `k` relative to the exponent `mu a + mu b + 9`, then conclude it is below `ω^(mu a + mu b + 9)`.


If `simp [mu]` leaves the goal as `0 < omega0 ^ (mu a + mu a + 9) + 1`, the above is the direct analogue of the first proved case.

## 2. `R_rec_succ`

This is the hardest case. The intended strategy is:

1. Expand both sides with `simp [mu]`.
2. Let
   ```lean
   Esmall : Ordinal := mu n + mu s + 6
   Ebig   : Ordinal := omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + 6
   ```
   so the goal becomes roughly
   ```lean
   omega0 ^ (3:Ordinal) * (mu s + 1)
     + omega0 ^ (2:Ordinal) * (omega0 ^ Esmall + omega0 * (mu b + 1) + 1 + 1) + 1
     <
   omega0 ^ Ebig + omega0 * (mu b + 1) + 1
   ```
3. Prove `Esmall < Ebig`.
   This should come from:
   - `mu n < mu n + 1`;
   - `mu n + 1 ≤ omega0 ^ 5 * (mu n + 1)` via `le_mul_right _ (opow_pos 5 omega0_pos)`;
   - hence `mu n + mu s + 6 < omega0 ^ 5 * (mu n + 1) + 1 + mu s + 6`.
4. From `Esmall < Ebig`, obtain
   ```lean
   hpow : omega0 ^ Esmall < omega0 ^ Ebig
   ```
   via strict monotonicity of `a ↦ omega0 ^ a`. In mathlib this is usually some lemma of the form `opow_lt_opow` / `opow_right_strictMono` / monotonicity on exponents for base `1 < omega0`. You’ll need to locate the exact lemma by elaboration, but this is the right proof shape.
5. Show the entire left side is bounded by something `< omega0 ^ Ebig`.
   The high-level reason is that the left side is a finite sum of terms all of strictly smaller Cantor rank than `omega0 ^ Ebig`. Concretely:
   - `omega0 ^ 3 * (mu s + 1) < omega0 ^ Ebig` because `3 < Ebig`;
   - `omega0 ^ 2 * (omega0 ^ Esmall + omega0 * (mu b + 1) + 2) < omega0 ^ Ebig` because multiplying by `ω^2` only raises exponent by `2`, so this remains below `ω^(Esmall + finite)`, hence below `ω^Ebig`;
   - adding `1` still stays below `omega0 ^ Ebig`.
6. Finally conclude
   ```lean
   LHS < omega0 ^ Ebig ≤ omega0 ^ Ebig + omega0 * (mu b + 1) + 1
   ```
   by `lt_of_lt_of_le` and `le_add_right`.

A skeleton block:

### What you’ll likely need from mathlib
Expect to use lemmas of these kinds:

- positivity/nonzero:
  - `omega0_pos`
  - `one_pos`
  - `add_pos_right`
  - `Ordinal.pos_iff_ne_zero`
- monotonicity of addition:
  - `add_lt_add_right`
  - `add_lt_add_left`
  - `le_add_right`
  - `le_add_left`
- monotonicity / strict monotonicity of `ω^_`:
  - some lemma like `opow_lt_opow`, `opow_right_strictMono`, or monotonicity under `1 < omega0`
- comparison of lower-order Cantor terms with a larger principal term:
  - often easiest via exponent comparison and standard lemmas about `ω^a * c < ω^b` when `a < b` and `c ≠ 0`.

If elaboration complains, the proof should be broken into even more local claims about:
- `omega0 ^ 3 < omega0 ^ Ebig`,
- `omega0 ^ Esmall * omega0 ^ 2 = omega0 ^ (Esmall + 2)`,
- `Esmall + 2 < Ebig`.

That is often the cleanest route.

## 3. `R_eq_diff`

This case is conceptually similar but simpler than `R_rec_succ`.

After `simp [mu]`, the goal is essentially:

```lean
omega0 ^ (4 : Ordinal) *
    (omega0 ^ (3 : Ordinal) * (mu a + 1) +
      omega0 ^ (2 : Ordinal) * (mu b + 1) + 1 + 1) + 1
  <
omega0 ^ (mu a + mu b + 9) + 1
```

Strategy:

1. It suffices to show
   ```lean
   omega0 ^ 4 * (...) < omega0 ^ (mu a + mu b + 9)
   ```
   then add `1` on both sides.
2. Bound the parenthesized term by something of the form `omega0 ^ (mu a + mu b + 8)` or lower.
   Since the inner term is built from exponents `3` and `2`, multiplying by `ω^4` raises those only to `7` and `6`, both comfortably below exponent `mu a + mu b + 9`.
3. Show `(4 : Ordinal) < mu a + mu b + 9`, `(7 : Ordinal) < mu a + mu b + 9`, etc., by finite arithmetic and positivity of the tail `+ 9`.
4. Conclude the whole left side is below `ω^(mu a + mu b + 9)`, hence below `ω^(mu a + mu b + 9) + 1`.

A proof skeleton:

```lean
| _, _, Step.R_eq_diff a b => by
    simp [mu]
    let E : Ordinal := mu a + mu b + (9 : Ordinal)

    have hEpos : 0 < E := by
      dsimp [E]
      exact add_pos_right _ (by decide)

    have hinner :
      omega0 ^ (4 : Ordinal) *
          (omega0 ^ (3 : Ordinal) * (mu a + 1) +
            omega0 ^ (2 : Ordinal) * (mu b + 1) + 1 + 1)
      < omega0 ^ E := by
      -- show each contribution has exponent < E:
      have h7 : (7 : Ordinal) < E := by
        dsimp [E]
        -- since 7 < 9 <= mu a + mu b + 9
        sorry
      have h6 : (6 : Ordinal) < E := by
        dsimp [E]
        sorry
      have h4 : (4 : Ordinal) < E := by
        dsimp [E]
        sorry

      -- Then use ordinal arithmetic:
      -- ω^4 * (ω^3 * (mu a + 1)) = ω^(4+3) * (mu a + 1) = ω^7 * ...
      -- ω^4 * (ω^2 * (mu b + 1)) = ω^6 * ...
      -- ω^4 * 2 is still below ω^E
      --
      -- Establish each piece < ω^E, then the sum < ω^E.
      sorry

    -- now compare `... + 1` with `omega0 ^ E + 1`
    exact add_lt_add_right hinner 1
```

If `add_lt_add_right` is not the exact lemma name for ordinals in this context, use:

```lean
calc
  omega0 ^ (4 : Ordinal) * (...) + 1
    < omega0 ^ E + 1 := by
        exact add_lt_add_right hinner 1
  _ = mu (eqW a b) := by simp [mu, E]
```

or just let `simp [E, mu]` finish the second line.

# Practical advice for finishing in Lean

The two difficult cases are not about the idea, but about finding the exact ordinal lemmas already present in mathlib. The likely bottleneck is strict monotonicity of `omega0 ^ _` and “finite/lower exponent terms are below a larger principal term”.

A robust way to proceed in Lean is to introduce more intermediate lemmas inside the proof:

- `have hEbig_ge_7 : (7 : Ordinal) < Ebig := ...`
- `have hpow3 : omega0 ^ (3 : Ordinal) < omega0 ^ Ebig := ...`
- `have hpowSmall : omega0 ^ Esmall * omega0 ^ (2 : Ordinal) = omega0 ^ (Esmall + 2) := ...`
- `have hsmall2 : Esmall + 2 < Ebig := ...`
- `have hprincipal : omega0 ^ (Esmall + 2) < omega0 ^ Ebig := ...`

Then rewrite products of powers into one power and compare exponents.

So the completion plan is:

- `R_eq_refl`: one-line positivity proof.
- `R_rec_succ`: compare exponents `Esmall < Ebig`, lift to powers, dominate lower-order sum.
- `R_eq_diff`: show the `integrate-merge` ordinal is a finite `ω`-polynomial of degree at most `7`, while `eqW` has principal term `ω^(mu a + mu b + 9)`.
