Below are proof skeletons for the three remaining `sorry` cases. The key tool is a small family of ordinal-arithmetic facts:

- `opow_pos b omega0_pos`     — `0 < ω^b` for any `b`
- `lt_add_one a`              — `a < a + 1`
- `le_add_right a b`          — `a ≤ a + b`
- `opow_le_opow_right` / `opow_lt_opow_right` — `α ≤ β → ω^α ≤ ω^β` (and strict) when the base is `ω`; in Mathlib these are the same statement because `ω^α` is monotone in `α` and `0 < ω`. Use `omega0_pos` to flip the inequality when needed.
- "Absorption" lemma: if `α < ω^β` then `ω^n * α < ω^(n + β + 1)`. This is proved by writing `α ≤ ω^β`, so `ω^n * α ≤ ω^n * ω^β = ω^(n+β)`, and then `ω^(n+β) < ω^(n+β+1)` by strict monotonicity.

The three cases are handled in increasing difficulty.

---

## 1. `R_eq_refl` — `mu void < mu (eqW a a)`

After `simp [mu]` the goal is

```
0 < ω^(mu a + mu a + 9) + 1
```

`ω^α > 0` for every ordinal `α` (use `opow_pos` with `omega0_pos`), and a positive ordinal plus 1 is still positive. The cleanest completion mirrors the `R_int_delta` case:

```lean
| _, _, Step.R_eq_refl a => by
    simp [mu]
    -- ω^α > 0 for any α (since ω > 0), hence ω^(2*mu a + 9) + 1 > 0.
    exact Ordinal.pos_iff_ne_zero.mpr (by
      apply ne_of_gt
      exact add_pos_right (opow_pos _ omega0_pos))
```

If `add_pos_right` is not in scope, an equivalent is

```lean
    have hpow : (0 : Ordinal) < omega0 ^ (mu a + mu a + (9 : Ordinal)) :=
      opow_pos _ omega0_pos
    exact hpow.trans (lt_add_one _)
```

---

## 2. `R_rec_succ` — `mu (app s (recDelta b s n)) < mu (recDelta b s (delta n))`

After `simp [mu]` the goal is

```
ω^3 * (mu s + 1) + ω^2 * (mu (recDelta b s n) + 1) + 1
  < ω^(ω^5 * (mu n + 1) + 1 + mu s + 6) + ω * (mu b + 1) + 1
```

The RHS carries an `ω` raised to the colossal exponent `ω^5 * (mu n + 1) + 1 + mu s + 6`. The plan is to bound the entire LHS by `ω^(mu n + mu s + 10)`, which is still vastly smaller.

**Key sub-lemmas (each is `sorry` material):**

1. `mu (recDelta b s n) < ω^(mu n + mu s + 7)`  
   Proof: `mu (recDelta b s n) = ω^(mu n + mu s + 6) + ω * (mu b + 1) + 1`. Each non-leading summand is `< ω^(mu n + mu s + 6)` (the `+1` is `≤ ω^0 ≤ ω^α`; `ω * (mu b + 1) < ω^(mu n + mu s + 6)` requires `mu n + mu s + 6 ≥ 2`, which is true for any `n, s`). Hence the whole sum is `< ω^(mu n + mu s + 6) * ω = ω^(mu n + mu s + 7)`.

2. **Absorption:** for any `α < ω^β` and natural `n`, `ω^n * α < ω^(n + β + 1)`. (Take `α ≤ ω^β`, multiply by `ω^n`, then add 1 to the exponent.)

3. `mu s + 1 ≤ ω^(mu s + 1)` (because `α + 1 ≤ ω^(α+1)` for every `α`), and similarly `(mu n + 1) ≤ ω^(mu n + 1)`.

4. `opow_lt_opow_right` for the final exponent comparison, plus the basic fact `omega^5 * (mu n + 1) + 1 + mu s + 6 > mu n + mu s + 10`, which holds because `omega^5 * (mu n + 1) ≥ omega^5 > 10 + mu s − 1 − mu n` (and the inequality is strict in ordinals because all summands are positive).

**Skeleton:**

```lean
| _, _, Step.R_rec_succ b s n => by
    simp [mu]
    -- Goal:  ω^3 * (mu s + 1) + ω^2 * (mu (recDelta b s n) + 1) + 1
    --      < ω^(ω^5*(mu n+1) + 1 + mu s + 6) + ω * (mu b + 1) + 1
    --
    -- (1) Bound the recursive term.
    have hrec : mu (recDelta b s n)
                < omega0 ^ (mu n + mu s + (7 : Ordinal)) := by
      sorry  -- absorption on the three summands of mu (recDelta …)

    -- (2) ω^2 * (mu (recDelta b s n) + 1) ≤ ω^(mu n + mu s + 9)
    have h1 : omega0 ^ (2 : Ordinal) * (mu (recDelta b s n) + 1)
              ≤ omega0 ^ (mu n + mu s + (9 : Ordinal)) := by
      sorry  -- absorption: lemma (2) with n = 2, β = mu n + mu s + 7

    -- (3) ω^3 * (mu s + 1) ≤ ω^(mu s + 4) ≤ ω^(mu n + mu s + 9)
    have h2 : omega0 ^ (3 : Ordinal) * (mu s + 1)
              ≤ omega0 ^ (mu n + mu s + (9 : Ordinal)) := by
      sorry  -- first inequality is absorption with β = mu s + 1;
            -- the second is opow_le_opow_right using 0 ≤ mu n

    -- (4) Combine and use that adding 1 to a strict bound is still strict.
    have hLHS : omega0 ^ (3 : Ordinal) * (mu s + 1)
                + omega0 ^ (2 : Ordinal) * (mu (recDelta b s n) + 1) + 1
                < omega0 ^ (mu n + mu s + (9 : Ordinal)) * 2 + 1 := by
      sorry  -- apply h1, h2, plus `1 ≤ ω^α` for any α (opow_pos gives ≥1)

    -- (5) Final step:  ω^(mu n + mu s + 10) ≤ RHS
    --     (the +1 on the LHS is absorbed by strict monotonicity of opow).
    have hRHS_main : omega0 ^ (mu n + mu s + (10 : Ordinal))
                     ≤ omega0 ^ (omega0 ^ (5 : Ordinal) * (mu n + 1)
                                 + (1 : Ordinal) + mu s + (6 : Ordinal)) := by
      sorry  -- opow_le_opow_right once we have
            --   mu n + mu s + 10 ≤ ω^5*(mu n+1) + 1 + mu s + 6
            -- i.e. mu n + 4 ≤ ω^5*(mu n+1), which is true since
            -- ω^5*(mu n+1) ≥ ω^5 > mu n + 4 for any ordinal mu n.

    -- (6) Stitch the chain together.
    calc omega0 ^ (3 : Ordinal) * (mu s + 1)
          + omega0 ^ (2 : Ordinal) * (mu (recDelta b s n) + 1) + 1
        < omega0 ^ (mu n + mu s + (9 : Ordinal)) * 2 + 1        := hLHS
      _ ≤ omega0 ^ (mu n + mu s + (10 : Ordinal)) + 1            := by sorry
      _ ≤ omega0 ^ (omega0 ^ (5 : Ordinal) * (mu n + 1)
                    + (1 : Ordinal) + mu s + (6 : Ordinal)) + 1  := by
          sorry  -- opow_le_opow_right applied to hRHS_main
      _ ≤ omega0 ^ (omega0 ^ (5 : Ordinal) * (mu n + 1)
                    + (1 : Ordinal) + mu s + (6 : Ordinal))
          + omega0 * (mu b + 1) + 1                              := by
          sorry  -- le_add_left / le_add_right
```

The two `sorry` lines in (6) are routine `le_add_left` / `le_add_right` rewrites. The non-trivial content is entirely in sub-lemmas (1)–(5), each of which is a self-contained ordinal-arithmetic statement.

---

## 3. `R_eq_diff` — `mu (integrate (merge a b)) < mu (eqW a b)`

After `simp [mu]` the goal is

```
ω^4 * (ω^3 * (mu a + 1) + ω^2 * (mu b + 1) + 2) + 1
  < ω^(mu a + mu b + 9) + 1
```

**Strategy.** Bound the inner sum `S := ω^3 * (mu a + 1) + ω^2 * (mu b + 1) + 2` by `ω^(mu a + mu b + 4)`. Then `ω^4 * S + 1 < ω^4 * ω^(mu a + mu b + 4) + 1 = ω^(mu a + mu b + 8) + 1 < ω^(mu a + mu b + 9) + 1`.

**Key sub-lemmas:**

1. `mu a + 1 ≤ ω^(mu a + 1)` and `mu b + 1 ≤ ω^(mu b + 1)`. (Each is the trivial `α + 1 ≤ ω^(α+1)`, because `ω^(α+1)` is a limit ordinal strictly above `α + 1`.)

2. **Absorption (same as before):** for `α < ω^β` and natural `n`, `ω^n * α < ω^(n + β + 1)`. Applied with `α = mu a + 1`, `β = mu a + 1`, `n = 3`: `ω^3 * (mu a + 1) < ω^(mu a + 4 + 1) = ω^(mu a + 5)`. Tightening to `≤ ω^(mu a + 4)` is also easy (use `α + 1 ≤ ω^(α+1)` gives `α ≤ ω^α`, then multiply). Similarly `ω^2 * (mu b + 1) < ω^(mu b + 4)`.

3. `2 < ω^3`, and (since `mu a + mu b + 3 ≥ 3`) `ω^3 ≤ ω^(mu a + mu b + 3)`.

4. `opow_le_opow_right` for collapsing `ω^(mu a + 4) + ω^(mu b + 3) + ω^(mu a + mu b + 3) ≤ ω^(mu a + mu b + 4) * 3 < ω^(mu a + mu b + 5)`. (Use `β ≤ γ → ω^β ≤ ω^γ` for `β = mu a + 4, mu b + 3` vs `γ = mu a + mu b + 4`, the latter holding because `mu a + 4 ≤ mu a + mu b + 4` and `mu b + 3 ≤ mu a + mu b + 4` — both since `mu a, mu b ≥ 0`.)

5. Final strict step: `ω^(mu a + mu b + 8) < ω^(mu a + mu b + 9)` by `opow_lt_opow_right` (using `8 < 9` as naturals lifting to ordinals).

**Skeleton:**

```lean
| _, _, Step.R_eq_diff a b => by
    simp [mu]
    -- Goal: ω^4 * (ω^3*(mu a+1) + ω^2*(mu b+1) + 2) + 1
    --      < ω^(mu a + mu b + 9) + 1
    --
    -- (1) Each summand of the inner S = ω^3*(mu a+1) + ω^2*(mu b+1) + 2
    --     is bounded by ω^(mu a + mu b + 4).
    have ha : omega0 ^ (3 : Ordinal) * (mu a + 1)
              ≤ omega0 ^ (mu a + (4 : Ordinal)) := by
      sorry  -- absorption: (mu a+1) ≤ ω^(mu a+1) and n = 3
    have hb : omega0 ^ (2 : Ordinal) * (mu b + 1)
              ≤ omega0 ^ (mu b + (3 : Ordinal)) := by
      sorry  -- absorption: (mu b+1) ≤ ω^(mu b+1) and n = 2
    have h2 : (2 : Ordinal) < omega0 ^ (3 : Ordinal) := by sorry
    have h2' : omega0 ^ (3 : Ordinal) ≤ omega0 ^ (mu a + mu b + (3 : Ordinal)) := by
      sorry  -- opow_le_opow_right, since 3 ≤ mu a + mu b + 3

    -- (2) Bound the inner sum.
    have hinner : omega0 ^ (3 : Ordinal) * (mu a + 1)
                  + omega0 ^ (2 : Ordinal) * (mu b + 1) + (2 : Ordinal)
                  ≤ omega0 ^ (mu a + mu b + (4 : Ordinal)) * (3 : Ordinal) := by
      sorry  -- combine ha, hb, h2, h2' using le_add of three pieces,
            -- and the absorption omega^(mu a+4), omega^(mu b+3), omega^(mu a+mu b+3)
            -- are all ≤ omega^(mu a + mu b + 4)

    -- (3) Absorb the *3 by going up one ordinal.
    have hinner' : omega0 ^ (3 : Ordinal) * (mu a + 1)
                   + omega0 ^ (2 : Ordinal) * (mu b + 1) + (2 : Ordinal)
                   < omega0 ^ (mu a + mu b + (5 : Ordinal)) := by
      sorry  -- hinner followed by omega^(α)*3 < omega^(α+1) (multiplication by ω)

    -- (4) Multiply by ω^4.
    have hLHS : omega0 ^ (4 : Ordinal)
                * (omega0 ^ (3 : Ordinal) * (mu a + 1)
                   + omega0 ^ (2 : Ordinal) * (mu b + 1) + (2 : Ordinal)) + 1
                < omega0 ^ (mu a + mu b + (9 : Ordinal)) + 1 := by
      sorry  -- hinner' then ω^4 * ω^(mu a+mu b+5) = ω^(mu a+mu b+9),
            -- then strict monotonicity: ω^(mu a+mu b+8) < ω^(mu a+mu b+9),
            -- finally `+1` on each side (and the strict inequality carries
            -- through because the inner strict step dominates the +1).
```

After these four sub-lemmas, the last line follows by a short `calc` block; alternatively one closes with `exact hLHS`.

## Common auxiliary lemmas to extract

To keep the three cases tidy, factor the recurring ordinal facts into a small `private lemma` block (each is a one-line proof once the API lemmas above are available):

- `lemma mu_succ_eqn (b s n) : mu (recDelta b s n) < ω^(mu n + mu s + 7)` — used by `R_rec_succ`.
- `lemma opow_mul_absorb {n : ℕ} {α β : Ordinal} (hα : α < ω^β) : ω^n * α < ω^(n + β + 1)` — used in both `R_rec_succ` and `R_eq_diff`.
- `lemma alpha_le_opow_alpha (α : Ordinal) : α + 1 ≤ ω^(α + 1)` — used everywhere.

With those three in place the three `sorry` cases reduce to short `calc` chains of length 3–6, each line justified by one of the three lemmas above combined with `opow_le_opow_right` / `opow_lt_opow_right` / `lt_add_one` / `le_add_right`.
