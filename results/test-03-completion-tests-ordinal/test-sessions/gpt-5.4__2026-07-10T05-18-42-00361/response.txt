## 1. `R_rec_succ`

Goal after `simp [mu]` is essentially:

```lean
omega0 ^ (3 : Ordinal) * (mu s + 1) +
    omega0 ^ (2 : Ordinal) *
      (omega0 ^ (mu n + mu s + 6) + omega0 * (mu b + 1) + 1 + 1) + 1
  <
omega0 ^ (omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + 6) +
    omega0 * (mu b + 1) + 1
```

### Intended strategy

Show the whole left side is bounded by something of the form

```lean
< omega0 ^ (omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + 6)
```

and then conclude by positivity of the tail on the RHS.

The key ordinal fact is:

- the exponent
  ```lean
  mu n + mu s + 6
  ```
  is strictly less than
  ```lean
  omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + 6
  ```
  because `mu n < omega0^5 * (mu n + 1)` and adding on the right preserves enough order here;
- hence
  ```lean
  omega0 ^ (mu n + mu s + 6)
    < omega0 ^ (omega0 ^ 5 * (mu n + 1) + 1 + mu s + 6)
  ```
  by monotonicity/strict monotonicity of `Ordinal.opow` in the exponent base `omega0 > 1`.

Then absorb the `omega^3 * ...` and `omega^2 * (...)` terms into the same principal bound.

### Skeleton

```lean
| _, _, Step.R_rec_succ b s n => by
    simp [mu]

    let E : Ordinal := mu n + mu s + (6 : Ordinal)
    let F : Ordinal := omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + (6 : Ordinal)

    have hmn : mu n < omega0 ^ (5 : Ordinal) * (mu n + 1) := by
      have h1 : mu n < mu n + 1 := lt_add_one (mu n)
      have h2 : mu n + 1 ≤ omega0 ^ (5 : Ordinal) * (mu n + 1) :=
        le_mul_right _ (opow_pos 5 omega0_pos)
      exact lt_of_lt_of_le h1 h2

    have hE_lt_F : E < F := by
      -- rewrite E = mu n + (mu s + 6), F = (omega^5 * (mu n + 1)) + (1 + mu s + 6)
      -- use hmn and monotonicity of addition on the right
      -- likely:
      --   exact add_lt_add_right (add_lt_add_right hmn _) _
      sorry

    have hpow : omega0 ^ E < omega0 ^ F := by
      -- use strict monotonicity of exponentiation with base omega0
      -- a lemma of the form `opow_lt_opow_right` / `opow_lt_opow` should be applicable
      sorry

    have hs_term :
      omega0 ^ (3 : Ordinal) * (mu s + 1) < omega0 ^ F := by
      -- enough to show 3 < F, then ω^3 * (...) < ω^F
      -- one route: first show
      --   omega0 ^ (3 : Ordinal) * (mu s + 1) < omega0 ^ (4 : Ordinal) * (mu s + 1)
      -- and then that this is ≤ omega0 ^ F because 4 ≤ F
      -- easier: prove directly by showing the leading exponent 3 is below F
      sorry

    have hrec_term :
      omega0 ^ (2 : Ordinal) *
          (omega0 ^ E + omega0 * (mu b + 1) + 1 + 1)
        < omega0 ^ F := by
      -- first dominate the parenthesized term by some multiple/sum below ω^F
      -- use hpow : ω^E < ω^F and the fact that the smaller summands
      --   ω*(mu b+1), 1, 1
      -- are all < ω^F as well
      -- then multiplying by ω^2 still stays below ω^F because F is far larger than 2
      sorry

    have hsum :
      omega0 ^ (3 : Ordinal) * (mu s + 1) +
          omega0 ^ (2 : Ordinal) *
            (omega0 ^ E + omega0 * (mu b + 1) + 1 + 1) + 1
        < omega0 ^ F := by
      -- combine hs_term and hrec_term; since ω^F is additive principal,
      -- sum of two ordinals < ω^F is still < ω^F, and then +1 remains < ω^F
      -- this is exactly where a principal-ordinal lemma from `Ordinal.Principal` is meant to be used
      sorry

    calc
      omega0 ^ (3 : Ordinal) * (mu s + 1) +
          omega0 ^ (2 : Ordinal) *
            (omega0 ^ E + omega0 * (mu b + 1) + 1 + 1) + 1
        < omega0 ^ F := hsum
      _ ≤ omega0 ^ F + (omega0 * (mu b + 1) + 1) := by
            exact le_add_right _ _
```

### What lemmas to look for in Mathlib

Search mentally in `Ordinal` for lemmas with names like:

- `lt_add_one`
- `le_mul_right`
- `opow_pos`
- monotonicity of `opow` in the exponent:
  - something like `opow_le_opow_right`
  - something like `opow_lt_opow_right`
- additive-principal closure lemmas from `Ordinal.Principal`, e.g. if `a,b < ω^F` then `a+b < ω^F`

This case is the one that really wants the “`ω^F` is additively principal” API.

## 2. `R_eq_refl`

This one is easy and should mirror `R_int_delta`.

After `simp [mu]`, goal is:

```lean
0 < omega0 ^ (mu a + mu a + 9) + 1
```

### Skeleton

```lean
| _, _, Step.R_eq_refl a => by
    simp [mu]
    exact Ordinal.pos_iff_ne_zero.mpr (by
      apply ne_of_gt
      exact add_pos_right _ one_pos)
```

You can also use `simpa [mu] using add_pos_right (omega0 ^ (mu a + mu a + (9 : Ordinal))) one_pos`

## 3. `R_eq_diff`

After `simp [mu]`, the goal is essentially:

```lean
omega0 ^ (4 : Ordinal) *
    (omega0 ^ (3 : Ordinal) * (mu a + 1) +
      omega0 ^ (2 : Ordinal) * (mu b + 1) + 1 + 1) + 1
  <
omega0 ^ (mu a + mu b + 9) + 1
```

### Intended strategy

As in the previous difficult case, show

```lean
omega0 ^ (4 : Ordinal) *
    (omega0 ^ (3 : Ordinal) * (mu a + 1) +
      omega0 ^ (2 : Ordinal) * (mu b + 1) + 1 + 1)
  < omega0 ^ (mu a + mu b + 9)
```

and then conclude by `+ 1`.

The conceptual reason is:
- the left side is bounded by something around exponent `7` plus lower noise;
- the right side has exponent `mu a + mu b + 9`, which is certainly at least `9`, hence much larger than `7`.

So you want a small chain:
1. show the inside of the parentheses is `< omega0 ^ (mu a + mu b + 8)` (or any exponent `< mu a + mu b + 9`);
2. multiplying by `omega0^4` shifts exponent by `4`, still staying below `mu a + mu b + 9`;
3. then `+1` is still below RHS.

### Skeleton

```lean
| _, _, Step.R_eq_diff a b => by
    simp [mu]

    let G : Ordinal := mu a + mu b + (9 : Ordinal)

    have h9 : (9 : Ordinal) ≤ G := by
      -- since G = mu a + mu b + 9
      exact le_add_left _ _   -- or build via repeated `le_add_right`; exact shape may vary
    have h4_lt_G : (4 : Ordinal) < G := by
      -- derive from 4 < 9 ≤ G
      exact lt_of_lt_of_le (by decide) h9   -- if numeral comparison on ordinals simplifies
      -- otherwise prove 4 < 9 explicitly by simp

    have ha_term :
      omega0 ^ (3 : Ordinal) * (mu a + 1) < omega0 ^ G := by
      -- because 3 < G
      -- use same pattern as earlier: mu a + 1 ≤ ω^(something) * (mu a+1),
      -- then ω^3 * (...) is still below ω^G when 3 < G
      sorry

    have hb_term :
      omega0 ^ (2 : Ordinal) * (mu b + 1) < omega0 ^ G := by
      -- same idea, since 2 < G
      sorry

    have hone : (1 : Ordinal) < omega0 ^ G := by
      -- enough that ω^G is positive and nonzero; in fact 1 ≤ ω^G for any G
      -- and strictness because ω^G ≠ 1 once G > 0
      sorry

    have hinside :
      omega0 ^ (3 : Ordinal) * (mu a + 1) +
          omega0 ^ (2 : Ordinal) * (mu b + 1) + 1 + 1
        < omega0 ^ G := by
      -- combine ha_term, hb_term, hone using additive-principal closure of ω^G
      sorry

    have hmain :
      omega0 ^ (4 : Ordinal) *
          (omega0 ^ (3 : Ordinal) * (mu a + 1) +
            omega0 ^ (2 : Ordinal) * (mu b + 1) + 1 + 1)
        < omega0 ^ G := by
      -- again use that multiplying something below ω^G by ω^4 stays below ω^G
      -- because 4 < G and ω^G is closed under such smaller left-multiplications
      sorry

    calc
      omega0 ^ (4 : Ordinal) *
          (omega0 ^ (3 : Ordinal) * (mu a + 1) +
            omega0 ^ (2 : Ordinal) * (mu b + 1) + 1 + 1) + 1
        < omega0 ^ G := by
            -- from hmain and closure under +1 below ω^G
            sorry
      _ ≤ omega0 ^ G + 1 := le_add_right _ _
```

### A more concrete alternative route

If the principal-ordinal closure lemmas are awkward to find, another common trick is to prove a stronger but simpler upper bound:

```lean
omega0 ^ (4 : Ordinal) *
    (omega0 ^ (3 : Ordinal) * (mu a + 1) +
      omega0 ^ (2 : Ordinal) * (mu b + 1) + 1 + 1)
≤ omega0 ^ (8 : Ordinal) * ((mu a + 1) + (mu b + 1) + 2)
```

and then show

```lean
omega0 ^ (8 : Ordinal) * ((mu a + 1) + (mu b + 1) + 2) < omega0 ^ (mu a + mu b + 9)
```

because `8 < mu a + mu b + 9`. This avoids some nested-principal reasoning, at the price of more algebraic reshuffling.

## Short version of the three completions

If you want the minimal practical guidance:

- `R_eq_refl`: copy the proof of `R_int_delta` exactly.
- `R_rec_succ`: define the two exponents `E` and `F`; prove `E < F`; deduce `ω^E < ω^F`; then use additive-principal closure of `ω^F` to bound both summands on the LHS below `ω^F`.
- `R_eq_diff`: let `G := mu a + mu b + 9`; show every component of the expanded integrate/merge measure is `< ω^G`; then use principal closure to conclude the whole LHS `< ω^G < ω^G + 1`.
