# Proof Skeleton for the Three Remaining Cases

Below is a skeleton with the key lemmas and structure needed for each `sorry`. I focus on the ordinal-arithmetic backbone and the Mathlib lemmas that should discharge each step.

## Case 1: `R_eq_refl` (easiest — pure positivity)

After `simp [mu]`, the goal is `0 < omega0 ^ (mu a + mu a + 9) + 1` (up to how `simp` normalizes `mu a + mu a`).

```lean
| _, _, Step.R_eq_refl a => by
    simp [mu]
    -- Goal: 0 < omega0 ^ (...) + 1
    exact Ordinal.pos_iff_ne_zero.mpr (by
      apply ne_of_gt
      exact add_pos_right _ one_pos)
    -- Alternative if `simp` closes the opow to something else:
    --   exact lt_of_lt_of_le one_pos (le_add_left _ _)
    --   or simply:  positivity-style: `exact Ordinal.add_one_pos.mpr ...`
```

**Fallback**, if `simp` leaves `0 < X + 1` directly:
```lean
    exact Order.lt_add_one_iff.mpr (Ordinal.zero_le _) -- gives 0 ≤ ... hence 0 < ...+1
```
or just `exact add_pos_right _ one_pos` after establishing `0 ≤ omega0 ^ _`.

## Key Reusable Lemma (needed for Cases 2 & 3)

Both hard cases reduce to comparing ordinals of the form
`(finite tower) < omega0 ^ (large exponent)`.
The central tool is **strict monotonicity of `opow` in the exponent** combined with the **absorption fact** that any ordinal built from `omega0 ^ k * c + ...` with bounded `k` is `< omega0 ^ (k+1)`.

Draft these helper lemmas before the theorem (or inline as `have`s):

```lean
-- Anything of the form omega0^k * c + r with r < omega0^k is < omega0^(k+1)
-- provided c is finite-ish; but here we use the cleaner exponent-domination route.

-- Domination: if e1 < e2 then omega0^e1 * (n:finite) + smaller < omega0^e2
have opow_lt_opow_of_exp :
    ∀ {e1 e2 : Ordinal}, e1 < e2 → omega0 ^ e1 < omega0 ^ e2 := by
  intro e1 e2 h
  exact opow_lt_opow_right one_lt_omega0 h
```

The workhorse from Mathlib is `opow_lt_opow_right` (or `Ordinal.opow_lt_opow_iff_right`) with base `omega0 > 1`.

## Case 2: `R_eq_diff`

Goal (post-`simp [mu]`), morally:
```
omega0^4 * (omega0^3*(mu a+1) + omega0^2*(mu b+1) + 1 + 1) + 1
  < omega0^(mu a + mu b + 9) + 1
```

**Strategy**: bound the LHS by a single `omega0`-power with an exponent strictly below `mu a + mu b + 9`.

```lean
| _, _, Step.R_eq_diff a b => by
    simp [mu]
    -- Step A: name the merge-measure
    set M := omega0 ^ (3:Ordinal) * (mu a + 1)
              + omega0 ^ (2:Ordinal) * (mu b + 1) + 1 with hM
    -- Step B: bound M below a clean power.
    --   M < omega0 ^ (mu a + mu b + 4)   (its top block is omega0^3*(mu a+1))
    have hM_lt : M < omega0 ^ (mu a + mu b + 4) := by
      -- omega0^3*(mu a+1) < omega0^(3 + mu a + ...) etc.
      -- Use: each summand omega0^k * c < omega0^(k + c'), and the sum of
      -- ordinals below a limit power is below it (additive principality).
      sorry_placeholder_A
    -- Step C: lift through omega0^4 * (M+1)
    --   omega0^4 * (M+1) < omega0^(4 + (mu a + mu b + 4)) = omega0^(mu a + mu b + 8)
    have hLHS : omega0 ^ (4:Ordinal) * (M + 1)
                  < omega0 ^ (mu a + mu b + 8) := by
      -- omega0^4 * X < omega0^(4 + e) when X < omega0^e:
      --   mul_lt_of_lt_opow / omega0^a * omega0^b = omega0^(a+b)
      have := opow_add omega0 4 (mu a + mu b + 4)   -- omega0^(4+e)=omega0^4*omega0^e
      sorry_placeholder_B
    -- Step D: absorb the trailing +1 and compare exponents 8 < 9.
    have hexp : mu a + mu b + 8 < mu a + mu b + 9 := by
      exact add_lt_add_left (by norm_num) _
    calc omega0 ^ (4:Ordinal) * (M + 1) + 1
        ≤ omega0 ^ (mu a + mu b + 8) + 1 := by
            exact add_le_add_right (le_of_lt hLHS) 1
      _ < omega0 ^ (mu a + mu b + 9)     := by
            -- omega0^smaller + 1 < omega0^larger, since omega0^larger is a limit
            -- (principal for addition) strictly above omega0^smaller + 1.
            sorry_placeholder_C
      _ ≤ omega0 ^ (mu a + mu b + 9) + 1 := le_add_right _ _
```

**Lemmas to fill the placeholders**:
- `sorry_placeholder_A`: use additive principality of `omega0 ^ e` (`Ordinal.principal_add_omega0_opow` / `principal_add_opow`) plus `omega0^k * (c+1) < omega0^(k + c + 1)` obtained from `opow_add` and `mul_lt_of_lt`. Bound each summand's exponent by `mu a + mu b + 4`.
- `sorry_placeholder_B`: `opow_add omega0 4 e` rewrites `omega0^(4+e) = omega0^4 * omega0^e`; then `mul_lt_mul_left'` / `Ordinal.mul_lt_mul_of_pos_left` with `M+1 < omega0^e` (from `hM_lt` and `lt_add_one` absorption, using that a limit power has no immediate successor issue). Note `4 + e = mu a + mu b + 8` needs `add_assoc`/`add_comm` normalization — do this with `ring_nf`-style ordinal rewriting or explicit `add_assoc`.
- `sorry_placeholder_C`: `omega0 ^ (mu a + mu b + 9)` is additively principal and a limit, so `omega0^s + 1 < omega0^b` when `s < b`. Use `Ordinal.principal_add_omega0_opow` giving closure, plus `lt_of_lt_of_le (add_lt ...) (opow_le_opow_right ...)`, or directly `Ordinal.add_lt_omega0_opow`-style lemma if available.

## Case 3: `R_rec_succ` (hardest)

Goal:
```
omega0^3*(mu s+1) + omega0^2*(mu(recDelta b s n)+1) + 1
  < omega0^(mu(delta n) + mu s + 6) + omega0*(mu b+1) + 1
```
where `mu(delta n) = omega0^5*(mu n+1) + 1` and
`mu(recDelta b s n) = omega0^(mu n + mu s + 6) + omega0*(mu b+1) + 1`.

**Key inequality**: The RHS exponent `E := omega0^5*(mu n+1)+1 + mu s + 6` dominates everything, because it contains `omega0^5*(mu n+1)`, which is far above the RHS-inner exponent `mu n + mu s + 6` used inside the LHS's `recDelta` subterm.

```lean
| _, _, Step.R_rec_succ b s n => by
    simp [mu]
    -- Abbreviations
    set R := omega0 ^ (mu n + mu s + 6) + omega0 * (mu b + 1) + 1 with hR
      -- = mu (recDelta b s n)
    set E := omega0 ^ (5:Ordinal) * (mu n + 1) + 1 + mu s + 6 with hE
      -- = exponent on RHS
    -- Step A: bound the whole LHS by a single power omega0^F with F < E.
    --   LHS top block is omega0^3*(mu s+1); the omega0^2*(R+1) block has
    --   R < omega0^(mu n + mu s + 7), so omega0^2*(R+1) < omega0^(mu n+mu s+9).
    have hR_lt : R < omega0 ^ (mu n + mu s + 7) := by
      -- same additive-principality argument as Case 2 Step A
      sorry_placeholder_A3
    have hLHS_lt : omega0 ^ (3:Ordinal) * (mu s + 1)
                    + omega0 ^ (2:Ordinal) * (R + 1) + 1
                   < omega0 ^ (mu n + mu s + 10) := by
      -- combine: omega0^2*(R+1) < omega0^(2 + (mu n+mu s+7)) = omega0^(mu n+mu s+9)
      -- and omega0^3*(mu s+1) < omega0^(mu n+mu s+9) as well; sum stays below +10
      sorry_placeholder_B3
    -- Step B: the RHS exponent E dominates: mu n + mu s + 10 < E, because
    --   E ≥ omega0^5*(mu n+1) ≥ omega0^5 > mu n + mu s + 10  (finite offset).
    have hexp_lt : mu n + mu s + 10 < E := by
      -- omega0^5*(mu n+1) is a limit ordinal ≥ omega0^5, dwarfing the additive
      -- term mu n + mu s + 10. Use omega0-power growth + add absorption.
      sorry_placeholder_C3
    -- Step C: conclude
    calc omega0 ^ (3:Ordinal) * (mu s + 1)
              + omega0 ^ (2:Ordinal) * (R + 1) + 1
        < omega0 ^ (mu n + mu s + 10)          := hLHS_lt
      _ < omega0 ^ E                            := opow_lt_opow_right one_lt_omega0 hexp_lt
      _ ≤ omega0 ^ E + omega0 * (mu b + 1) + 1 := by
            exact le_add_right _ _   -- may need two `le_add_right` / `add_assoc`
```

**Lemmas for placeholders**:
- `sorry_placeholder_A3` / `B3`: identical machinery to Case 2 — additive principality (`Ordinal.principal_add_omega0_opow`), `opow_add` to split `omega0^(k+e)=omega0^k*omega0^e`, and `Ordinal.mul_lt_mul_of_pos_left`.
- `sorry_placeholder_C3`: the crucial domination. Show `omega0^5 ≤ omega0^5*(mu n+1) ≤ E` and `mu n + mu s + 10 < omega0^5` since any finite-plus-`mu` sum stays below the limit `omega0^5` — actually you need `mu n + mu s + 10 < omega0^5*(mu n+1)`. Use: `mu n < omega0^5*(mu n+1)` (from `lt_mul_right`/`le_mul_right`), and additive absorption of the finite `+ mu s + 10` into the limit ordinal via `Ordinal.add_absorp` or repeated `add_lt_of_lt` with principality.

## Summary of Mathlib lemmas you will most rely on

| Purpose | Lemma |
|---|---|
| Base `omega0 > 1` | `one_lt_omega0` |
| Exponent monotonicity | `opow_lt_opow_right`, `opow_le_opow_right` |
| Split powers | `opow_add` |
| Multiply strict-mono | `Ordinal.mul_lt_mul_of_pos_left`, `mul_le_mul_left'` |
| `x ≤ c * x` | `le_mul_right` (with `opow_pos`/`omega0_pos`) |
| Additive principality of `omega0^e` | `Ordinal.principal_add_omega0_opow` / `principal_add_opow` |
| Absorb small additive tail | `Ordinal.add_absorp`, `add_lt_add_left` |
| Positivity | `Ordinal.pos_iff_ne_zero`, `add_pos_right`, `opow_pos` |

The `sorry_placeholder_*` names are stand-ins — replace each with the corresponding `have`-proof using the table above.
