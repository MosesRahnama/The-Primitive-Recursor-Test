# Proof Skeleton for the Remaining Three Cases

Below I give a strategy sketch for each `sorry`. The shape mirrors the existing proved cases: a `simp [mu]` unfolding, followed by ordinal-arithmetic steps using `opow_lt_opow_*`, `mul_le_mul_*`, and `lt_of_lt_of_le`.

---

## Case 1 — `R_rec_succ b s n`

**Goal:** `mu (app s (recDelta b s n)) < mu (recDelta b s (delta n))`

After `simp [mu]`, the inequality is

```
omega^3 * (mu s + 1) + omega^2 * (omega^(mu n + mu s + 6) + omega * (mu b + 1) + 2) + 1
  < omega^(omega^5 * (mu n + 1) + mu s + 7) + omega * (mu b + 1) + 1
```

**Skeleton:**

```lean
| _, _, Step.R_rec_succ b s n => by
    simp [mu]
    -- Step 1. drop the trailing +1 on both sides (lt_add_right _ one_pos)
    have h_add : omega^3 * (mu s + 1)
                 + omega^2 * (omega^(mu n + mu s + 6) + omega * (mu b + 1) + 2)
                 < omega^(omega^5 * (mu n + 1) + mu s + 7) + omega * (mu b + 1) := by
      -- Step 2. absorb the omega^3*(mu s+1) and omega^2*omega*... = omega^3*... terms
      --         into the LHS using monotonicity of left-multiplication by omega^2:
      --   omega^3*(mu s+1) ≤ omega^2 * (omega^(mu n + mu s + 6) + omega*(mu b+1) + 2)
      -- because omega^(mu n + mu s + 6) ≥ omega ≥ 1 dominates everything.
      -- So LHS ≤ omega^2 * (omega^(mu n + mu s + 6) + omega*(mu b+1) + 2) * 2
      --        = omega^2 * omega * 2 * (omega^(mu n + mu s + 6) + omega*(mu b+1) + 2)
      --        (using right-distributivity: alpha * (beta+gamma) = alpha*beta + alpha*gamma)
      --        ≤ omega^3 * (omega^(mu n + mu s + 6) + omega*(mu b+1) + 2) * omega
      --        = omega^3 * omega^(mu n + mu s + 6 + 1) + ...
      --        ≤ omega^(mu n + mu s + 8)  (after packing everything under one tower)
      sorry
    exact lt_of_lt_of_le h_add (le_add_right _ _)
```

The crux is the **key lemma**:

> If `γ = mu n ≥ 0` then `omega^5 * (γ + 1) > γ + 1`, so
> `omega^5 * (γ + 1) + mu s + 7 > mu n + mu s + 8`.

This is `omega^5 * (γ + 1) = omega^5 * (γ+1) ≥ 2*(γ+1) > γ+1` (since `omega^5 ≥ 2` and `2*(γ+1) = (γ+1)+(γ+1) > γ+1` for `γ+1 > 0`). Hence the LHS, whose largest CNF exponent is `mu n + mu s + 8`, is dominated by the RHS whose top term alone is `omega^(omega^5*(mu n+1) + mu s + 7)`. Apply `Ordinal.opow_lt_opow_right` (which needs `0 < base` and `alpha < beta` for `omega^alpha < omega^beta`) at the leading term and then `lt_of_lt_of_le` over the rest.

## Case 2 — `R_eq_refl a`

**Goal:** `0 < omega^(mu a + mu a + 9) + 1`

**Skeleton:**

```lean
| _, _, Step.R_eq_refl a => by
    simp [mu]
    -- omega^α > 0 for every α, then +1 keeps it positive
    exact Ordinal.pos_iff_ne_zero.mpr
      (Ordinal.ne_zero_of_lt
        (lt_add_right (opow_pos _ omega0_pos) one_pos))
    -- or more directly:
    -- exact (opow_pos _ omega0_pos).trans (lt_add_right _ one_pos)
```

This is a one-liner positivity argument and matches the proof style of `R_int_delta`.

## Case 3 — `R_eq_diff a b`

**Goal:** `mu (integrate (merge a b)) < mu (eqW a b)`, i.e.

```
omega^4 * (omega^3 * (mu a + 1) + omega^2 * (mu b + 1) + 2) + 1
  < omega^(mu a + mu b + 9) + 1
```

**Skeleton:**

```lean
| _, _, Step.R_eq_diff a b => by
    simp [mu]
    -- Step 1. drop the +1 (le_add_right / lt_add_right)
    suffices h : omega^4 * (omega^3 * (mu a + 1) + omega^2 * (mu b + 1) + 2)
                 < omega^(mu a + mu b + 9) by
      exact lt_of_lt_of_le h (le_add_right _ _)
    -- Step 2. right-distribute omega^4 (Ordinal.mul_add):
    --   LHS = omega^7 * (mu a + 1) + omega^6 * (mu b + 1) + omega^4 * 2
    simp_rw [show ∀ x y z, omega0^4 * (x + y + z)
                       = omega0^4*x + omega0^4*y + omega0^4*z from by intros; ring_nf]
    -- (or, more simply, use Ordinal.mul_add twice and then add_assoc)
    -- Step 3. crush each summand under a single tower with coefficient (mu a + mu b + 3):
    --   omega^7 * (mu a + 1) ≤ omega^7 * (mu a + mu b + 3)
    --   omega^6 * (mu b + 1) ≤ omega^7 * (mu a + mu b + 3)   (since 6 < 7 and mu a+1 ≥ 1)
    --   omega^4 * 2           ≤ omega^7 * (mu a + mu b + 3)
    have h1 : omega^7 * (mu a + 1) ≤ omega^7 * (mu a + mu b + 3) :=
      mul_le_mul_left _ (le_add_right _ _)
    have h2 : omega^6 * (mu b + 1) ≤ omega^7 * (mu a + mu b + 3) := by
      refine le_trans (mul_le_mul_right _ (le_mul_right _ (opow_pos 6 omega0_pos))) ?_
      -- omega^6 ≤ omega^7 and (mu b+1) ≤ (mu a+mu b+3)
      sorry
    have h3 : omega^4 * (2 : Ordinal) ≤ omega^7 * (mu a + mu b + 3) := by
      refine le_trans (le_mul_right _ (Nat.cast_pos.2 (by omega))) ?_
      sorry
    -- Step 4. combine, then use the Key Lemma (omega^8 * f < omega^(f + 8))
    have hLHS : omega^4 * (omega^3 * (mu a + 1) + omega^2 * (mu b + 1) + 2)
                ≤ omega^7 * (mu a + mu b + 3) := by linarith
    have hKey : omega^7 * (mu a + mu b + 3) < omega^(mu a + mu b + 9) := by
      -- The CNF leading exponent of omega^7 * (mu a + mu b + 3) is
      --   7 + (leading exponent of mu a + mu b + 3)
      -- and the leading exponent of mu a + mu b + 3 is at most
      --   (leading exponent of mu a + mu b)  ≤  mu a + mu b.
      -- So the LHS leading exponent is at most mu a + mu b + 7,
      -- strictly less than the RHS exponent mu a + mu b + 9.
      -- This is the lemma:
      --   ∀ f : Ordinal, omega^7 * f < omega^(f + 9)   (when f ≥ 1)
      -- which is proved by opow_lt_opow_right using 7 + log_omega(f) < f + 9
      -- (since log_omega(f) ≤ f, with strict inequality for f ≥ 1,
      -- and the case f = 0 is trivial because omega^7 * 0 = 0 < 1 = omega^9).
      sorry
    exact lt_of_le_of_lt hLHS hKey
```

The **key lemma** invoked in `hKey` is

> For any ordinal `f`, `omega^7 * f ≤ omega^7 * omega^f = omega^(f+7) < omega^(f+9)`.

Two sub-lemmas are needed:

1. `omega^7 * f ≤ omega^(f + 7)` — this is `mul_le_opow` style: the leading term of `omega^7 * f` has exponent `7 + log_omega(f) ≤ 7 + f`, so the product is `≤ omega^(7+f)`. (Mathlib has `Ordinal.opow_mul_opow`/`Ordinal.mul_opow` style lemmas; the proof is by induction on the CNF of `f`.)
2. `omega^(f+7) < omega^(f+9)` — direct application of `Ordinal.opow_lt_opow_right` (with `omega0_pos` for the base), needing `f + 7 < f + 9`, which is `lt_add_right` of `Ordinal.lt_one_iff_ne_zero.mpr …` style.

---

## Summary of the strategy in one sentence

The three remaining cases reduce to the **single ordinal fact** `omega^n * f < omega^(f + n + k)` for `k ≥ 2`, which holds because the CNF leading exponent of the LHS is `n + log_omega(f) ≤ n + f < f + n + k`. This is the workhorse that the three skeletons allude to, and it lines up with the design comments at the top of the file: the `+9` in the `eqW` exponent, the `+6` in `recDelta`, and the base `omega^5` for `delta` are all chosen so that this fact delivers the strict decrease for every rule.
