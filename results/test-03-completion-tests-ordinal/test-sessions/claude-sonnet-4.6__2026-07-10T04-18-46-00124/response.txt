The key insights are:
- **`R_eq_refl`**: `omega^(2*mu(a)+9) + 1 > 0` follows from `add_pos_right` with `one_pos`
- **`R_rec_succ`**: The LHS exponent `omega^5*(mu n+1) + 1 + mu s + 6` strictly exceeds `mu n + mu s + 6` because `mu n < omega^5*(mu n+1)`, so the ordinal power comparison goes through via `opow_lt_opow_right`
- **`R_eq_diff`**: The exponent `mu a + mu b + 9` dominates `4 + log_omega(merge expansion)` because the merge's ordinal value is bounded below `omega^(mu a + mu b + 5)`
