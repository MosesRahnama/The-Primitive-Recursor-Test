# Proof Skeleton for Remaining Cases

Here is a proof skeleton for the three `sorry` cases. Each skeleton identifies the key ordinal-arithmetic facts needed.

---

## 1. `R_rec_succ` (recursion successor step)

**Goal:** Show
```
mu (app s (recDelta b s n)) < mu (recDelta b s (delta n))
```

**Key facts to establish:**
- `mu (delta n) = ω⁵·(μ n + 1) + 1`
- The LHS measure expands to  
  `ω³·(μ s + 1) + ω²·(μ(recDelta b s n) + 1) + 1`
- The RHS measure expands to  
  `ω^(μ(delta n) + μ s + 6) + ω·(μ b + 1) + 1`
  `= ω^(ω⁵·(μ n + 1) + 1 + μ s + 6) + …`
- **Dominance argument:** The exponent `ω⁵·(μ n + 1) + …` on the RHS is strictly larger than any polynomial expression in `μ(recDelta b s n)` (whose leading term is `ω^(μ n + μ s + 6)`). Use the rule `ω^α < ω^β` whenever `α < β`, together with `a + b < ω^γ` when `a,b < ω^γ`.

**Skeleton tactic outline:**
```lean
simp [mu]
-- 1. show the exponent on RHS > any exponent appearing on LHS
have hexp : mu (delta n) + mu s + 6 > mu n + mu s + 6 := …
-- 2. apply opow_lt_opow_iff_right (or similar) to get ω^… dominance
-- 3. absorb the remaining lower-order terms with add_lt_of_lt
```

---

## 2. `R_eq_refl` (reflexive equality)

**Goal:** Show `0 < μ(eqW a a)`.

**Key facts:**
- `μ(eqW a a) = ω^(μ a + μ a + 9) + 1`
- Any ordinal power `ω^γ` with `γ ≥ 0` is positive; adding 1 preserves positivity.

**Skeleton:**
```lean
simp [mu]
apply Ordinal.add_pos_right
exact Ordinal.opow_pos _ omega0_pos   -- ω^(2·μ a + 9) > 0
```

---

## 3. `R_eq_diff` (non-reflexive equality)

**Goal:** Show
```
mu (integrate (merge a b)) < mu (eqW a b)
```

**Key facts to establish:**
- `μ(merge a b) = ω³·(μ a + 1) + ω²·(μ b + 1) + 1`
- Hence LHS = `ω⁴·(μ(merge a b) + 1) + 1`
- RHS = `ω^(μ a + μ b + 9) + 1`
- **Dominance:** The exponent `μ a + μ b + 9` is at least 9, while the LHS is bounded by a fixed-height tower `ω⁴·(ω³·x + ω²·y + C)`. Show
  ```
  ω⁴·(ω³·(μ a + 1) + ω²·(μ b + 1) + 2) + 1 < ω^(μ a + μ b + 9)
  ```
  by proving the exponent on the right is large enough that `ω^(μ a + μ b + 9)` absorbs the entire left-hand side (use `mul_lt_of_lt` and `add_lt_of_lt` repeatedly, or the general fact that `ω^α` eventually dominates any polynomial in smaller ordinals).

**Skeleton tactic outline:**
```lean
simp [mu]
-- 1. bound the argument of ω⁴ on the LHS
have hbound : mu (merge a b) + 1 < ω^(mu a + mu b + 9 - 4) := …
-- 2. then ω⁴ * (that) < ω^(mu a + mu b + 9)
exact (Ordinal.mul_lt_of_lt (Ordinal.opow_pos 4 omega0_pos) hbound)
```

---

These skeletons rely only on the ordinal library lemmas already imported (`opow_pos`, `opow_lt_opow_iff_right`, `mul_lt_of_lt`, `add_lt_of_lt`, `lt_add_one`, etc.) and the concrete exponents chosen in the definition of `mu`.
