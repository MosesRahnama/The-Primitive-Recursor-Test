## Overview

All three remaining cases share the same basic shape of argument that is already used in the five finished cases: expand `mu` on both sides using the rewriting-rule structure, then show the left side is dominated by (a piece of) the right side using

* `opow_add : a ^ (x + y) = a ^ x * a ^ y`
* `mul_add : a * (x + y) = a * x + a * y` (left‑distributivity, the only distributivity law that holds for `Ordinal`)
* monotonicity lemmas `add_le_add_left/right`, `add_lt_add_left/right`, `le_add_left`, `le_add_right`
* `opow_le_opow_right`, `opow_lt_opow_right` (monotonicity of `b ^ ·` for `1 < b`)
* additive principality of towers: `principal_add_omega0_opow : Principal (· + ·) (omega0 ^ e)`, used to combine several terms each `< omega0 ^ e` into a sum still `< omega0 ^ e`.

Since a lot of the work is "some ordinal `x` is dominated by `omega0 ^ (x+1)`", it is worth factoring that out once:

```lean
/-- Every ordinal is strictly below the next power-tower level.
    Standard fact, proved by transfinite induction on `x`. -/
theorem self_lt_opow_succ (x : Ordinal) : x < omega0 ^ (x + 1) := by
  induction x using Ordinal.limitRecOn with
  | H1 =>
      simpa using opow_pos (0 + 1) omega0_pos
  | H2 y ih =>
      -- y < omega0 ^ (y+1)  ⇒  y+1 ≤ omega0 ^ (y+1) < omega0 ^ (y+1) * omega0 = omega0 ^ (y+1+1)
      have h1 : y + 1 ≤ omega0 ^ (y + 1) := ih
      have h2 : omega0 ^ (y + 1) < omega0 ^ (y + 1) * omega0 :=
        (lt_mul_iff_one_lt_right (opow_pos _ omega0_pos)).mpr (by
          exact_mod_cast (by norm_num : (1:Ordinal) < omega0) )
      have h3 : omega0 ^ (y + 1) * omega0 = omega0 ^ (y + 1 + 1) := by
        rw [← opow_add]
      -- combine
      calc y + 1 ≤ omega0 ^ (y+1)             := h1
        _ < omega0 ^ (y+1) * omega0           := h2
        _ = omega0 ^ (y + 1 + 1)              := h3
  | H3 y hy ih =>
      -- limit case: omega0^(y+1) is continuous in y, and y = sup of smaller ordinals
      sorry  -- routine continuity-of-opow-at-limits argument
```

This lemma is what lets us turn "`X` is a polynomial expression in `A`" into "`X < omega0 ^ (A + k)`".

## `R_eq_diff`

Set `A := mu a`, `B := mu b`. Expanding:

```
mu (integrate (merge a b))
  = omega0^4 * (mu (merge a b) + 1) + 1
  = omega0^4 * (omega0^3*(A+1) + omega0^2*(B+1) + 2) + 1
  = omega0^7*(A+1) + omega0^6*(B+1) + omega0^4*2 + 1        -- via mul_add, opow_add, mul_assoc

mu (eqW a b) = omega0 ^ (A + B + 9) + 1
```

so it suffices to dominate the three summands by `omega0 ^ (A+B+9)` and use additive principality.

```lean
| _, _, Step.R_eq_diff a b => by
    simp only [mu]
    set A := mu a
    set B := mu b
    -- 1. algebraic expansion of the LHS
    have expand :
        omega0 ^ (4:Ordinal) *
          (omega0 ^ (3:Ordinal) * (A + 1) + omega0 ^ (2:Ordinal) * (B + 1) + 1 + 1)
        = omega0 ^ (7:Ordinal) * (A + 1) + omega0 ^ (6:Ordinal) * (B + 1)
            + omega0 ^ (4:Ordinal) * 2 := by
      have e1 : (1:Ordinal) + 1 = 2 := by norm_num
      rw [e1, mul_add, mul_add, ← mul_assoc, ← mul_assoc, ← opow_add, ← opow_add]

    -- 2. each summand is dominated by omega0 ^ (A+B+9)
    have hA : omega0 ^ (7:Ordinal) * (A + 1) < omega0 ^ (A + B + 9) := by
      have h1 : A + 1 ≤ omega0 ^ (A + 1) := (self_lt_opow_succ A).le
      have h2 : omega0 ^ (7:Ordinal) * (A + 1) ≤ omega0 ^ (7 + (A + 1)) := by
        calc omega0 ^ (7:Ordinal) * (A + 1)
            ≤ omega0 ^ (7:Ordinal) * omega0 ^ (A + 1) := by
              exact mul_le_mul_left' h1 _
          _ = omega0 ^ (7 + (A + 1)) := by rw [← opow_add]
      have h3 : (7:Ordinal) + (A + 1) < A + B + 9 := by
        have h8 : (8:Ordinal) ≤ B + 8 := le_add_left _ _
        have h9 : (8:Ordinal) < B + 9 := lt_of_le_of_lt h8 (add_lt_add_left (by norm_num) _)
        have := add_lt_add_left h9 A
        simpa [add_assoc] using this
      exact lt_of_le_of_lt h2 (opow_lt_opow_right (by norm_num) h3)

    have hB : omega0 ^ (6:Ordinal) * (B + 1) < omega0 ^ (A + B + 9) := by
      have h1 : B + 1 ≤ omega0 ^ (B + 1) := (self_lt_opow_succ B).le
      have h2 : omega0 ^ (6:Ordinal) * (B + 1) ≤ omega0 ^ (6 + (B + 1)) := by
        calc omega0 ^ (6:Ordinal) * (B + 1)
            ≤ omega0 ^ (6:Ordinal) * omega0 ^ (B + 1) := mul_le_mul_left' h1 _
          _ = omega0 ^ (6 + (B + 1)) := by rw [← opow_add]
      have h3 : (6:Ordinal) + (B + 1) < A + B + 9 := by
        have hB' : B ≤ A + B := le_add_left _ _
        have s1 : B + 7 ≤ (A + B) + 7 := add_le_add_right hB' _
        have s2 : (A + B) + 7 < (A + B) + 9 := add_lt_add_left (by norm_num) _
        have : B + 7 < A + B + 9 := lt_of_le_of_lt s1 (by simpa [add_assoc] using s2)
        simpa [add_assoc] using this
      exact lt_of_le_of_lt h2 (opow_lt_opow_right (by norm_num) h3)

    have hC : omega0 ^ (4:Ordinal) * 2 < omega0 ^ (A + B + 9) := by
      have h1 : omega0 ^ (4:Ordinal) * 2 < omega0 ^ (5:Ordinal) := by
        calc omega0 ^ (4:Ordinal) * 2
            < omega0 ^ (4:Ordinal) * omega0 := by
              exact mul_lt_mul_left' (by norm_num) _
          _ = omega0 ^ (5:Ordinal) := by
              rw [show (5:Ordinal) = 4 + 1 by norm_num, opow_add, opow_one]
      have h2 : (5:Ordinal) < A + B + 9 := by
        have : (0:Ordinal) ≤ A + B := Ordinal.zero_le _
        have := add_lt_add_right (lt_of_le_of_lt this (by norm_num : (0:Ordinal) < 9)) 0
        -- 5 < 9 ≤ A+B+9
        have h9 : (9:Ordinal) ≤ A + B + 9 := le_add_left _ _
        exact lt_of_lt_of_le (by norm_num) h9
      exact h1.trans (opow_lt_opow_right (by norm_num) h2)

    -- 3. combine via additive principality of omega0^(A+B+9)
    have hsum := (principal_add_omega0_opow (A + B + 9)) hA hB
    have hfinal := (principal_add_omega0_opow (A + B + 9)) hsum hC

    -- 4. rewrite the goal and finish
    show omega0 ^ (4:Ordinal) * (mu (merge a b) + 1) + 1 < omega0 ^ (A + B + 9) + 1
    simp only [mu]
    rw [expand]
    exact add_lt_add_right hfinal 1
```

## `R_rec_succ`

Write `N := mu n`, `S := mu s`, `B := mu b`, `R := mu (recDelta b s n)`. The rule gives

```
mu (app s (recDelta b s n))
  = omega0^3*(S+1) + omega0^2*(R+1) + 1

mu (recDelta b s (delta n))
  = omega0 ^ (E) + omega0*(B+1) + 1,   where E := omega0^5*(N+1) + 1 + S + 6
```

The intended argument (matching the file's comment) is: the exponent `omega0^5*(N+1)` produced by `mu (delta n)` is astronomically larger than `N`, and should dominate everything on the left after expanding `R`. Expanding as in the `eq_diff` case,

```
omega0^2*(R+1) = omega0^(N+S+8) + omega0^3*(B+1) + omega0^2*2
```

so the whole left side reduces to bounding

```
omega0^3*(S+1) + omega0^(N+S+8) + omega0^3*(B+1) + omega0^2*2 + 1  <  omega0^E + omega0*(B+1) + 1.
```

The `omega0^(N+S+8)` term is easily dominated by `omega0^E` (since `N+S+8 < E`, because `omega0^5*(N+1) ≥ omega0^5 > 8` swallows the `+8`). This is the routine part and follows the same pattern as `eq_diff`:

```lean
have hExp : N + S + 8 < E := by
  have h5 : (8:Ordinal) < omega0 ^ (5:Ordinal) := by
    calc (8:Ordinal) < omega0 := by norm_num
      _ = omega0 ^ (1:Ordinal) := (opow_one _).symm
      _ ≤ omega0 ^ (5:Ordinal) := opow_le_opow_right (by norm_num) (by norm_num)
  -- N + S + 8 < N + S + omega0^5*(N+1) ≤ omega0^5*(N+1) + 1 + S + 6 = E
  sorry
```

The genuinely delicate part is the two terms `omega0^3*(S+1)` and `omega0^3*(B+1)`, which come from wrapping `R` (and `s`) one extra level inside `app`. On the *left* they occur with coefficient `omega0^3`, while on the *right* the corresponding contributions of `S` and `B` are only present as *additive summands inside the exponent* (`S` via `E`) or with the smaller coefficient `omega0^1` (`B` via `omega0*(B+1)`). Closing this gap requires showing

```lean
have hCoeff :
    omega0 ^ (3:Ordinal) * (S + 1) + omega0 ^ (3:Ordinal) * (B + 1)
      < omega0 ^ E + omega0 * (B + 1) := by
  sorry  -- ** the crux inequality; see remark below **
```

```lean
| _, _, Step.R_rec_succ b s n => by
    simp only [mu]
    set N := mu n
    set S := mu s
    set B := mu b
    set E : Ordinal := omega0 ^ (5:Ordinal) * (N + 1) + 1 + S + 6 with hE_def
    have expand :
        omega0 ^ (2:Ordinal) *
            (omega0 ^ (N + S + 6) + omega0 * (B + 1) + 1 + 1)
          = omega0 ^ (N + S + 8) + omega0 ^ (3:Ordinal) * (B + 1)
              + omega0 ^ (2:Ordinal) * 2 := by
      have e1 : (1:Ordinal) + 1 = 2 := by norm_num
      rw [e1, mul_add, mul_add, ← mul_assoc, ← mul_assoc, ← opow_add, ← opow_add]
      norm_num
    have hExp : N + S + 8 < E := by
      sorry  -- routine: omega0^5*(N+1) alone exceeds "8", as in eq_diff's hA/hB pattern
    have hCoeff :
        omega0 ^ (3:Ordinal) * (S + 1) + omega0 ^ (3:Ordinal) * (B + 1)
          + omega0 ^ (2:Ordinal) * 2
          < omega0 ^ E + omega0 * (B + 1) := by
      sorry  -- ** crux step, see remark **
    -- assemble
    show omega0 ^ (3:Ordinal) * (S + 1)
           + omega0 ^ (2:Ordinal) * (omega0 ^ (N + S + 6) + omega0 * (B + 1) + 1 + 1) + 1
         < omega0 ^ E + omega0 * (B + 1) + 1
    rw [expand]
    have step1 :
        omega0 ^ (3:Ordinal) * (S + 1) + (omega0 ^ (N + S + 8)
            + omega0 ^ (3:Ordinal) * (B + 1) + omega0 ^ (2:Ordinal) * 2)
          < omega0 ^ E + omega0 * (B + 1) := by
      sorry -- combine hExp and hCoeff via principal_add_omega0_opow / associativity
    exact add_lt_add_right step1 1
```

**Remark (honesty about the crux step).** Unlike `eq_diff`, here `S` and `B` are *free* subterms independent of `N`: nothing forces `mu s` or `mu b` to be small relative to `omega0^5*(mu n+1)`. The reduction wraps the recursive call one extra `app`-level deep, which re-multiplies the `B`- and `S`-contributions by an extra factor of `omega0^2` relative to what appears on the right-hand side. Closing `hCoeff` in full generality therefore needs either

* an auxiliary invariant bounding `mu s`, `mu b` in terms of `mu n` for well-typed `recDelta` terms, or
* a strengthening of `mu`'s `recDelta`/`app` clauses (e.g. carrying the `omega0*(mu b+1)+1` tail *inside* the exponent, or giving `recDelta`'s tail the same `omega0^3`/`omega0^2` weighting that `app` will apply to it),

so that the coefficient of `B` (and `S`) cannot increase across the step. Whichever fix is chosen, the surrounding skeleton above (the `expand`/`hExp`/`hCoeff`/`step1` structure, using `mul_add`, `opow_add`, `principal_add_omega0_opow`, and the same monotonicity lemmas as in `eq_diff`) is exactly what completes the case once `hCoeff` is established for the corrected/strengthened measure.
