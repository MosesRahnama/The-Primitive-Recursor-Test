The three open cases are `R_rec_succ`, `R_eq_refl`, and `R_eq_diff`. (`R_merge_cancel` and `R_rec_zero` already have complete proofs in the file.) Below is a proof skeleton for each remaining case: the target inequality after `simp [mu]`, the intermediate ordinal bounds that close the gap, and the Mathlib facts that justify each step.

### 1. `Step.R_eq_refl` (routine positivity)

After `simp [mu]` the goal is
```text
0 < ω^(mu a + mu a + 9) + 1
```
Skeleton:
```lean
| _, _, Step.R_eq_refl a => by
  simp [mu]
  exact add_pos_right _ one_pos
```
(Equivalently: `Ordinal.pos_iff_ne_zero.mpr (ne_of_gt (add_pos_right _ one_pos))`.)  
No non-trivial ordinal arithmetic is required; the `+ 1` makes the whole expression strictly positive.

---

### 2. `Step.R_eq_diff` (exponent dominates a fixed finite power)

After `simp [mu]` the goal is
```text
ω^4 * (mu (merge a b) + 1) + 1
  < ω^(mu a + mu b + 9) + 1
```
Because successor is strictly monotone it is enough to show
```text
ω^4 * (mu (merge a b) + 1) < ω^(mu a + mu b + 9).
```

**Step A – expand and bound the merge.**  
```text
mu (merge a b) + 1
  = ω^3*(mu a + 1) + ω^2*(mu b + 1) + 2
  ≤ ω^3*(mu a + 1) + ω^3*(mu b + 1) + ω^3     -- ω² ≤ ω³, 2 ≤ ω³
  = ω^3 * (mu a + mu b + 3)
```
(uses `opow_le_opow_right`, `mul_le_mul_right`, `add_le_add`, `le_mul_of_one_le_left` / `omega0_pos`).

**Step B – multiply by the outer ω⁴.**  
```text
ω^4 * (mu (merge a b) + 1)
  ≤ ω^4 * ω^3 * (mu a + mu b + 3)
  = ω^7 * (mu a + mu b + 3)
```
(uses `opow_add` / `ω^4 * ω^3 = ω^7`).

**Step C – uniform domination lemma.**  
Let `γ := mu a + mu b`. Prove the key fact
```text
∀ γ, ω^7 * (γ + 3) < ω^(γ + 9).
```
Proof of the lemma (no case-split on finiteness needed):
```text
γ + 3 < ω^(γ + 1)          -- any ordinal ξ satisfies ξ < ω^(ξ+1);
                             -- ω^(γ+1) is additively principal, so closed under +3
⇒ ω^7 * (γ + 3) < ω^7 * ω^(γ + 1)
                 = ω^(7 + (γ + 1))
                 = ω^(8 + γ)
```
and
```text
8 + γ ≤ γ + 8 < γ + 9     -- n + α ≤ α + n for finite n; then α + 8 < α + 9
⇒ ω^(8 + γ) ≤ ω^(γ + 8) < ω^(γ + 9).
```
(Left-multiplication by `ω^7 > 0` is strictly monotone; `opow_lt_opow_iff_right omega0_lt_omega1` gives the last strict inequality.)

**Step D – assemble.**  
```text
ω^4 * (mu (merge a b) + 1)
  ≤ ω^7 * (γ + 3)
  < ω^(γ + 9)
  = ω^(mu a + mu b + 9).
```
Adding `+ 1` to both sides finishes the goal.

### 3. `Step.R_rec_succ` (the exponential tower on the source dominates)

After `simp [mu]` one must prove
```text
mu (app s (recDelta b s n))
  < mu (recDelta b s (delta n)).
```
Write the two sides explicitly:

*Source* (right-hand side of the inequality):
```text
E  := mu (delta n) + mu s + 6
    = ω^5*(mu n + 1) + mu s + 7
src := ω^E + ω*(mu b + 1) + 1
```

*Target* (left-hand side):
```text
e   := mu n + mu s + 6
rec := ω^e + ω*(mu b + 1) + 1
tgt := ω^3*(mu s + 1)
     + ω^2*(rec + 1)
     + 1
    = ω^3*(mu s + 1)
     + ω^(2 + e)
     + ω^3*(mu b + 1)
     + ω²*2
     + 1
```
(the expansion of `ω² * (rec + 1)` uses `mul_add` and `ω² * ω^e = ω^(2+e)`, `ω² * ω = ω³`).

**Step A – bound every summand of `tgt` by a single power of `ω` that is still far below `E`.**  
It is enough to show
```text
tgt < ω^E
```
because `ω^E ≤ src`.  Since `ω^E` is additively principal (exponent `E ≥ 7 > 0`), it suffices to prove each of the five summands is `< ω^E`:

1. `ω^3 * (mu s + 1) < ω^E`  
   because `mu s + 1 < ω^(mu s + 1)` and `3 + (mu s + 1) ≤ mu s + 4 < E`  
   (the last inequality holds by the concrete shape of `E = ω^5*(mu n + 1) + mu s + 7`).

2. `ω^(2 + e) < ω^E`  
   because `2 + e = 2 + mu n + mu s + 6 ≤ mu n + mu s + 8`  
   and `mu n + mu s + 8 < ω^5*(mu n + 1) + mu s + 7 = E`  
   (the `ω^5*(mu n + 1)` term strictly dominates the linear `mu n`).

3. `ω^3 * (mu b + 1) < ω^E`  
   – **this is the delicate point**.  
   The bound holds *provided* `mu b + 1 < ω^(E - 3)`, i.e. when the additive `μ b` term does not already exceed the exponential tower built from `n` and `s`.  
   If the measure is used only on terms in which `b` is “small” relative to the recursion counter, the inequality goes through exactly as for (1).  
   In the fully general case the present measure may fail (a very large `b` makes the coefficient `ω³` on the target larger than the coefficient `ω` on the source).  A robust repair is to move `mu b` into the exponent as well, e.g.
   ```text
   mu (recDelta b s n) = ω^(mu n + mu s + mu b + 6) + 1
   ```
   or to use a multiplicative form
   ```text
   ω^(mu n) * (mu s + 1) + mu b.
   ```
   With either repair the same domination argument works uniformly.

4. `ω² * 2 < ω^E` and `1 < ω^E` are immediate (`E ≥ 7`).

**Step B – conclude.**  
All five summands `< ω^E` ⇒ their sum `tgt < ω^E ≤ src`.

**Lean-level skeleton (assuming the measure is left unchanged and one accepts the side-condition on `mu b`, or after the repair above):**
```lean
| _, _, Step.R_rec_succ b s n => by
  simp [mu]
  -- introduce abbreviations E, e, \ldots
  set e : Ordinal := mu n + mu s + 6
  set E : Ordinal := omega0 ^ 5 * (mu n + 1) + mu s + 7
  have E_def : mu (delta n) + mu s + 6 = E := by simp [mu]; abel
  -- show each summand of the target < ω^E
  have h1 : omega0 ^ 3 * (mu s + 1) < omega0 ^ E := \ldots
  have h2 : omega0 ^ (2 + e) < omega0 ^ E := \ldots
  have h3 : omega0 ^ 3 * (mu b + 1) < omega0 ^ E := \ldots  -- needs repair or side-condition
  have h4 : omega0 ^ 2 * 2 < omega0 ^ E := \ldots
  have h5 : (1 : Ordinal) < omega0 ^ E := \ldots
  -- reassemble by additive principality of ω^E
  have tgt_lt : \ldots < omega0 ^ E :=
    calc \ldots ≤ (sum of the five terms) := le_of_eq (by ring/abel)
         _    < omega0 ^ E               := add_lt_of_lt (opow_isAddPrincipal \ldots) h1 (add_lt_of_lt \ldots h2 \ldots)
  -- finally tgt < ω^E ≤ src
  exact lt_of_lt_of_le tgt_lt (le_add_right _ _)
```

### Summary of the three skeletons

| Case            | Core obligation after `simp [mu]`                              | Main lemma needed                                      |
|-----------------|----------------------------------------------------------------|--------------------------------------------------------|
| `R_eq_refl`     | `0 < ω^(2·mu a + 9) + 1`                                      | `add_pos_right _ one_pos`                              |
| `R_eq_diff`     | `ω^4·(mu(merge a b)+1) < ω^(mu a+mu b+9)`                     | `ω^7·(γ+3) < ω^(γ+9)` (uniform, via `γ+3 < ω^(γ+1)`) |
| `R_rec_succ`    | `ω^3·(μs+1) + ω²·(rec+1) + 1 < ω^E + ω·(μb+1) + 1`            | each summand `< ω^E`; may require adjusting `mu` for the `μb` term |

The first two cases are complete with the arguments above. The third case follows the same style of exponent-domination once the interaction of the additive `mu b` coefficient with the `ω²` coming from `app` is secured (either by a side-condition or by a minor strengthening of the definition of `mu` on `recDelta`).
