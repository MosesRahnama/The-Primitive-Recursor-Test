## Proof skeletons for the three remaining cases

The five completed cases already illustrate the basic pattern: `simp [mu]`, then chain `lt_add_one` / `le_mul_right` / `opow_pos` / `le_add_left` / `le_add_right` (and cancellation of a trailing `+ 1`). The three open cases follow the same style; only `R_rec_succ` and `R_eq_diff` need non-trivial ordinal arithmetic.

### 1. `R_eq_refl` — positivity (routine)

**Goal after `simp [mu]`:**
```text
0 < omega0 ^ (mu a + mu a + 9) + 1
```

**Skeleton:**
```lean
| _, _, Step.R_eq_refl a => by
  simp [mu]
  -- omega0 ^ _ + 1 is always strictly positive
  exact Ordinal.pos_iff_ne_zero.mpr (by
    apply ne_of_gt
    exact add_pos_right _ one_pos)
```

(Identical shape to the already-proved `R_int_delta` case.)

### 2. `R_eq_diff` — exponent on `eqW` dominates `integrate ∘ merge`

**Goal after `simp [mu]`:**
```text
omega0 ^ 4 * (omega0 ^ 3 * (mu a + 1) + omega0 ^ 2 * (mu b + 1) + 2) + 1
  < omega0 ^ (mu a + mu b + 9) + 1
```

**Skeleton:**
```lean
| _, _, Step.R_eq_diff a b => by
  simp [mu]
  -- Cancel trailing +1 (successor is strictly monotone / injective)
  apply Order.add_lt_add_right  -- or: show the bodies are < and lift
  -- Reduced goal:
  --   ω⁴ * (ω³*(μa+1) + ω²*(μb+1) + 2) < ω^(μa+μb+9)
  --
  -- Expand LHS by left-distributivity:
  --   = ω⁷*(μa+1) + ω⁶*(μb+1) + ω⁴*2
  --
  -- Claim: each summand is < ω^(μa+μb+9).
  -- Then use that ω^δ is additively principal:
  --   x < ω^δ → y < ω^δ → x + y < ω^δ  (twice).

  -- Subclaim 1: ω⁷ * (μa + 1) < ω^(μa + μb + 9)
  --   μa + 1 < ω^(μa + 1)          (always strict for the successor power)
  --   ⇒ ω⁷*(μa+1) < ω⁷ * ω^(μa+1) = ω^(7 + μa + 1)
  --   and 7 + μa + 1 ≤ μa + 8 < μa + μb + 9
  --   (since 8 < 9 + μb), so ω^(7+μa+1) ≤ ω^(μa+8) < ω^(μa+μb+9).

  -- Subclaim 2: ω⁶ * (μb + 1) < ω^(μa + μb + 9)
  --   same pattern: < ω^(6 + μb + 1) ≤ ω^(μb + 7) < ω^(μa + μb + 9).

  -- Subclaim 3: ω⁴ * 2 < ω^(μa + μb + 9)
  --   ω⁴ * 2 < ω⁵ ≤ ω⁹ ≤ ω^(μa+μb+9).

  -- Assemble with additive principality of ω^(μa+μb+9).
  sorry -- fill with the three subclaims + principal sum
```

Useful Mathlib facts: `opow_add`, `opow_lt_opow_right_iff` / `opow_le_opow_right`, `mul_lt_mul_of_pos_left`, `omega0_pos`, `add_lt_add_right`, and that `ω^δ` is additively closed (`Ordinal.principal_add_opow_omega0` or equivalent).

### 3. `R_rec_succ` — `delta` in the recursion counter lifts the exponent

**Goal after `simp [mu]`:**
```text
omega0 ^ 3 * (mu s + 1)
  + omega0 ^ 2 * (omega0 ^ (mu n + mu s + 6)
                  + omega0 * (mu b + 1) + 2) + 1
  < omega0 ^ (mu (delta n) + mu s + 6)
      + omega0 * (mu b + 1) + 1
```
with `mu (delta n) = omega0 ^ 5 * (mu n + 1) + 1`.

**Skeleton:**
```lean
| _, _, Step.R_rec_succ b s n => by
  simp [mu]
  -- Let
  --   δ  := μ(delta n) + μs + 6
  --       = ω⁵*(μn+1) + 1 + μs + 6
  --       = ω⁵*(μn+1) + μs + 7
  --   ρ  := ω^(μn + μs + 6) + ω*(μb+1) + 1     -- μ(recDelta b s n)
  --
  -- LHS = ω³*(μs+1) + ω²*(ρ + 1) + 1
  -- RHS = ω^δ + ω*(μb+1) + 1
  --
  -- Strategy: show LHS < ω^δ + ω*(μb+1) + 1 by showing
  -- LHS ≤ (something strictly below RHS).

  -- Step A — expand ω²*(ρ + 1):
  --   ρ + 1 = ω^(μn+μs+6) + ω*(μb+1) + 2
  --   ω²*(ρ + 1)
  --     = ω² * ω^(μn+μs+6) + ω²*ω*(μb+1) + ω²*2
  --     = ω^(2 + μn + μs + 6) + ω³*(μb+1) + 2*ω²
  --   (opow_add: ω² * ω^α = ω^(2+α))

  -- Step B — key exponent comparison (delta dominates):
  --   Claim: 2 + μn + μs + 6 < δ = μ(delta n) + μs + 6
  --   Reduced (right-add strictly monotone) to:
  --     2 + μn < μ(delta n) = ω⁵*(μn+1) + 1
  --   Proof sketch:
  --     ω⁵ ≥ 2 ⇒ ω⁵*(μn+1) ≥ 2*(μn+1) ≥ μn+2
  --     and the inequality is strict (ω⁵ > 2, or 2*(μn+1) > μn+2 for μn ≥ 1),
  --     hence ω⁵*(μn+1) + 1 > μn + 2.

  -- Step C — bound every summand of LHS by a piece of RHS:
  --   C1. ω^(2+μn+μs+6) < ω^δ                 (from Step B + opow strict mono)
  --   C2. ω³*(μs+1)        < ω^δ                 (μs+1 ≪ ω^δ; same style as eq_diff)
  --   C3. 2*ω² + 1         < ω^δ                 (finite / small power)
  --   C4. Treat the μb-carrying term carefully:
  --       ω³*(μb+1)  vs  ω^δ + ω*(μb+1)
  --       Split on whether ω³*(μb+1) ≤ ω^δ or not:
  --         • if ≤, absorb into ω^δ (strictly below RHS);
  --         • if >, use CNF / additive absorption so that
  --           ω^δ + ω*(μb+1) still dominates the expanded LHS
  --           (or reorganize: show full LHS < RHS by comparing
  --           CNF leading terms, using that δ contains ω⁵*(μn+1)).
  --
  --   Alternatively (cleaner if it goes through): show the whole
  --   LHS < ω^δ + ω*(μb+1) + 1 by
  --     LHS ≤ ω³*(μs+1) + ω^(2+μn+μs+6) + ω³*(μb+1) + 2*ω² + 1
  --         < ω^δ + ω*(μb+1) + 1
  --   packing the non-μb terms into ω^δ via additive principality,
  --   and comparing μb-coefficients with the ω¹ term on the RHS
  --   only after confirming the measure coefficients are compatible.

  -- Step D — conclude with add_lt_add / calc.
  sorry -- discharge C1–C4 with opow_add, opow_lt_opow_right, principal_add
```

**Key lemmas to reach for:**
- `Ordinal.opow_add` — `ω^(a+b) = ω^a * ω^b`
- Right-strict monotonicity of `+` and of `ω^·`
- `le_mul_right` / `mul_le_mul_left` with `omega0_pos` / `opow_pos`
- Additive principality of powers of `ω`
- `lt_add_one`, `add_lt_add_right`, `le_add_left` / `le_add_right`

### Summary of proof obligations

| Case | Core obligation | Difficulty |
|------|-----------------|------------|
| `R_eq_refl` | `0 < ω^(…) + 1` | Trivial (copy `R_int_delta`) |
| `R_eq_diff` | `ω⁴·(ω³·(μa+1)+ω²·(μb+1)+2) < ω^(μa+μb+9)` via three summands each `< ω^(…)` + additive principality | Medium |
| `R_rec_succ` | Expanded `app` measure `< ω^(μ(δ n)+μs+6) + ω·(μb+1) + 1`, using `μ(δ n) = ω⁵·(μn+1)+1` to lift the exponent past `2 + μn + μs + 6`, then absorb lower-order / `μb` terms | Hardest (detailed CNF / case split on which term dominates) |

Once these three bodies replace the `sorry`s, `mu_decreases` is complete and `strong_normalization` follows unchanged from the existing `Subrelation.wf` + `InvImage.wf` argument.
