Below is a **proof‑skeleton** for the three `sorry` branches of `mu_decreases`.  
Each skeleton expands the definition of `mu`, isolates the dominant ordinal term, and then uses the standard monotonicity lemmas from the `Ordinal` library (e.g. `Ordinal.opow_lt_opow_of_lt`, `Ordinal.add_lt_add`, `Ordinal.mul_lt_mul`, `Ordinal.lt_opow_self`, `Ordinal.pos_opow`, etc.) to obtain the required strict inequality.

The idea is the same in all three cases:

1. **Expand** `mu` for the left‑hand side (the term we are reducing) and for the right‑hand side (the reduct).  
2. **Identify the biggest ordinal tower** in the RHS – it is always a power of ω whose exponent is strictly larger than any exponent that appears on the LHS.  
3. **Compare term‑by‑term** using the monotonicity lemmas, or bound each LHS term by a smaller power of ω and then sum them up – the sum is still strictly smaller than the single large RHS term.

### 1. `R_rec_succ`  –  `recDelta b s (delta n) → app s (recDelta b s n)`

```lean
| _, _, Step.R_rec_succ b s n => by
  simp [mu]
  -- LHS = μ(app s (recDelta b s n))
  --      = ω³·(μ s + 1) + ω²·(μ(recDelta b s n) + 1) + 1
  -- RHS = μ(recDelta b s (delta n))
  --      = ω^(μ(delta n) + μ s + 6) + ω·(μ b + 1) + 1
  --      = ω^( ω⁵·(μ n + 1) + 1 + μ s + 6 ) + ω·(μ b + 1) + 1
  --      = ω^( ω⁵·(μ n + 1) + μ s + 7 ) + ω·(μ b + 1) + 1

  -- The dominant term on the RHS is ω^( ω⁵·(μ n + 1) + μ s + 7 ).
  -- Since ω⁵·(μ n + 1) + 1 > μ n + μ s + 6, we have
  --   ω^( ω⁵·(μ n + 1) + μ s + 7 )  >  ω^( μ n + μ s + 6 ).
  -- Now compare the remaining pieces:
  --   • ω³·(μ s + 1) ≤ ω^( μ s + 3 )  < RHS (because μ s + 3 ≤ ω⁵·(μ n + 1) + μ s + 7 )
  --   • ω²·(μ(recDelta b s n) + 1) = ω²·( ω^(μ n + μ s + 6) + ω·(μ b + 1) + 1 + 1 )
  --     ≤ ω^( μ n + μ s + 6 + 2 )   < RHS (exponent μ n + μ s + 8 is still < ω⁵·(μ n + 1)+ μ s + 7)
  --   • The final “+1” is harmless.

  -- Conclude by adding the three strict inequalities (use `Ordinal.add_lt_add` repeatedly).
  sorry
```

*Key lemmas to insert:*  

- `Ordinal.opow_lt_opow_of_lt` (monotonicity of `ω^` in the exponent).  
- `Ordinal.mul_lt_mul` (for the finite coefficients in front of the ω‑powers).  
- `Ordinal.add_lt_add` (to glue the three pieces together).

### 2. `R_eq_refl`  –  `eqW a a → void`

```lean
| _, _, Step.R_eq_refl a => by
  simp [mu]
  -- Goal: 0 < ω^( μ a + μ a + 9 ) + 1
  -- Since μ a + μ a + 9 > 0, the term ω^( μ a + μ a + 9 ) is positive.
  -- Use `Ordinal.pos_opow` (or `Ordinal.zero_lt_opow`) to obtain
  --   0 < ω^( μ a + μ a + 9 ).
  -- Adding the final “+1” preserves the strict inequality.

  exact Ordinal.zero_lt_of (Ordinal.pos_opow (Ordinal.add_pos (add_pos (mu a) (mu a)) (by norm_num)))
  sorry
```

*Key lemmas:*  

- `Ordinal.pos_opow` (if `α > 0` then `ω^α > 0`).  
- `Ordinal.zero_lt_of` (if `0 < β` then `0 < β + 1`).

### 3. `R_eq_diff`  –  `eqW a b → integrate (merge a b)`

```lean
| _, _, Step.R_eq_diff a b => by
  simp [mu]
  -- LHS = μ(integrate (merge a b))
  --      = ω⁴·( μ(merge a b) + 1 ) + 1
  --      = ω⁴·( ω³·(μ a + 1) + ω²·(μ b + 1) + 1 + 1 ) + 1
  --      = ω⁴·( ω³·(μ a + 1) + ω²·(μ b + 1) + 2 ) + 1
  --
  -- RHS = μ(eqW a b) = ω^( μ a + μ b + 9 ) + 1

  -- Bound each term on the LHS by a smaller power of ω^( μ a + μ b + 9 ):
  --   • ω⁴·ω³·(μ a + 1) = ω⁷·(μ a + 1)
  --     Since μ a + 1 < ω^(μ a + 1) (by `Ordinal.lt_opow_self`),
  --     ω⁷·(μ a + 1) ≤ ω⁷·ω^(μ a + 1) = ω^(7 + μ a + 1) = ω^(μ a + 8).
  --     Because μ b ≥ 0, we have μ a + 8 ≤ μ a + μ b + 9,
  --     hence ω^(μ a + 8) ≤ ω^(μ a + μ b + 9).
  --
  --   • ω⁴·ω²·(μ b + 1) = ω⁶·(μ b + 1) ≤ ω^(μ b + 7) ≤ ω^(μ a + μ b + 9).
  --
  --   • ω⁴·2 < ω⁵ ≤ ω^(μ a + μ b + 9)  (again using μ a + μ b + 9 ≥ 5).

  -- Adding the three strict inequalities gives
  --   LHS ≤ ω^(μ a + μ b + 9) + ω^(μ a + μ b + 9) + ω^(μ a + μ b + 9)
  --       < ω^(μ a + μ b + 9) + 1   (the extra “+1” on the RHS dominates).
  -- Hence μ(integrate (merge a b)) < μ(eqW a b).

  sorry
```

*Key lemmas:*  

- `Ordinal.lt_opow_self` – for any `β>0`, `β < ω^β`.  
- `Ordinal.opow_monotonic` – if `γ ≤ δ` then `ω^γ ≤ ω^δ`.  
- `Ordinal.mul_lt_mul` (for the finite coefficients).  
- `Ordinal.add_lt_add` (to combine the three bounds).

### How to turn the skeletons into a full proof

1. **Compute the ordinals** with `simp [mu]` (the file already does this).  
2. **Introduce the key inequalities** using the lemmas listed above.  
3. **Chain the inequalities** with `calc` (or with repeated `apply ordinal.add_lt_add`).  
4. **Close each goal** with `exact` or `refine` once the required strict inequality is in the goal state.

The three `sorry`s become `exact` (or a short `apply …`) statements once the appropriate ordinal lemmas are in place. The structure above mirrors the existing proofs in the file (e.g. the `R_int_delta` case) and should fit cleanly into the surrounding code without any further modifications.
