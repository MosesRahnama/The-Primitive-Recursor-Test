The three open cases of `mu_decreases` are `R_rec_succ`, `R_eq_refl`, and `R_eq_diff`. Below is a proof skeleton for each. The skeletons follow the same style as the five completed cases (local `have`s for elementary comparisons, then a `calc` block). They rely only on the standard Mathlib ordinal API already imported (`opow_pos`, `le_mul_right`, `lt_add_one`, `add_pos_right`, left-multiplication monotonicity, `ω^a · ω^b = ω^(a+b)`, and that `ω^γ` (`γ ≥ 1`) is additively principal).

### 2. `Step.R_eq_diff` (absorb `integrate (merge _ _)`)

Goal after `simp [mu]`:
```text
ω^4 * (μ(merge a b) + 1) + 1
  < ω^(mu a + mu b + 9) + 1
```
i.e. (writing `μa = mu a`, `μb = mu b`)
```text
ω^4 * (ω^3*(μa+1) + ω^2*(μb+1) + 2) + 1
  < ω^(μa + μb + 9) + 1
```

Expanding the LHS by left-distributivity:
```text
ω^7 * (μa+1) + ω^6 * (μb+1) + 2*ω^4 + 1
```

Skeleton:

```lean
| _, _, Step.R_eq_diff a b => by
  simp [mu]
  -- Denote the target exponent
  set E := mu a + mu b + (9 : Ordinal) with hE
  -- It is enough to show the expanded LHS is < ω^E
  -- (then +1 on both sides preserves the inequality).
  have h_principal : ∀ {x y : Ordinal}, x < ω^E → y < ω^E → x + y < ω^E := by
    intro x y hx hy
    -- ω^E (E ≥ 9 ≥ 1) is additively principal
    exact prop_principal (opow_is_add_principal omega0_ne_zero (by
      rw [hE]; exact (Nat.cast_le.mpr (by norm_num : (1:ℕ) ≤ 9)).trans
        (Ordinal.le_add_left _ _)) ) hx hy
    -- (or use the Mathlib lemma `opow_add_lt_opow_of_lt` / principal API)

  -- Bound each summand of the expanded LHS by ω^E
  have b1 : ω0^(7:Ordinal) * (mu a + 1) < ω0^E := by
    -- μa+1 < ω^(μa+1)  (strict, any ordinal)
    -- ⇒ ω^7*(μa+1) < ω^7 * ω^(μa+1) = ω^(μa+8)
    -- ⇒ ω^(μa+8) ≤ ω^(μa+μb+8) < ω^(μa+μb+9) = ω^E
    have h_lt : mu a + 1 < ω0^(mu a + 1) := by
      -- standard fact: ∀ α, α < ω^α; apply to α = μa+1, or prove by
      -- lt_opow_self / self_lt_opow if available, else via CNF or induction on Trace
      sorry -- short lemma
    have : ω0^(7:Ordinal) * (mu a + 1)
            < ω0^(7:Ordinal) * (ω0^(mu a + 1)) :=
      (mul_lt_mul_iff_left (opow_pos 7 omega0_pos)).mpr h_lt
    -- ω^7 * ω^(μa+1) = ω^(7+μa+1) = ω^(μa+8)
    rw [← opow_add] at this
    -- μa+8 < μa+μb+9 = E
    have h_exp : (mu a + 8 : Ordinal) < E := by
      rw [hE]
      -- μa + 8 < μa + (μb + 9) because 8 < μb + 9 (μb ≥ 0)
      sorry -- arithmetic: lt_add_of_pos_right / add_lt_add_left
    exact lt_trans this (opow_lt_opow_iff_right omega0_lt_omega1 |>.mpr h_exp)
      -- (adjust to the precise Mathlib lemma name for strict mono of ω^(-))

  have b2 : ω0^(6:Ordinal) * (mu b + 1) < ω0^E := by
    -- symmetric argument with roles of a/b swapped, exponent μb+7 < E
    sorry

  have b3 : (2 : Ordinal) * ω0^(4:Ordinal) < ω0^E := by
    -- 2*ω^4 = ω^4 * 2 < ω^4 * ω = ω^5 ≤ ω^9 ≤ ω^E
    sorry

  have b4 : (1 : Ordinal) < ω0^E :=
    one_lt_omega0.trans_le (opow_le_opow_right omega0_pos (by
      rw [hE]; exact Ordinal.le_add_left _ _))

  -- Sum the four bounds via repeated application of h_principal
  have : ω0^(7:Ordinal)*(mu a+1) + ω0^(6:Ordinal)*(mu b+1)
           + 2*ω0^(4:Ordinal) + 1 < ω0^E := by
    sorry -- chain of h_principal

  -- Conclude: LHS + 0 < ω^E + 1, and the “+1” on the original goal is free
  calc
    ω0^(4:Ordinal) * (ω0^(3:Ordinal)*(mu a+1) + ω0^(2:Ordinal)*(mu b+1) + 2) + 1
        = ω0^(7:Ordinal)*(mu a+1) + ω0^(6:Ordinal)*(mu b+1) + 2*ω0^(4:Ordinal) + 1 := by
            -- expand with mul_add / opow_add
            sorry
    _ < ω0^E + 1 := by
            exact lt_add_of_lt_add_right this (by rfl)  -- or lt_of_lt_of_le this (le_add_right _ _)
```

(The only real work is the four elementary bounds `b1`–`b4` and the algebraic expansion; each is a few lines of `opow_add` / `mul_lt_mul_iff_left`.)

### 3. `Step.R_rec_succ` (the delicate case)

Goal after `simp [mu]`:
```text
ω^3*(μs+1) + ω^2*(ω^(μn+μs+6) + ω*(μb+1) + 2) + 1
  <  ω^(μ(delta n) + μs + 6) + ω*(μb+1) + 1
```
where `μ(delta n) = ω^5*(μn+1) + 1`, so the big exponent on the right is
```text
E ≔ ω^5*(μn+1) + μs + 7
```
and the goal is
```text
RHS  <  ω^E + ω*(μb+1) + 1.
```

Expand the left-hand side (using `ω^a · ω^b = ω^(a+b)` and left-distributivity):
```text
RHS = ω^3*(μs+1)
    + ω^(μn+μs+8)
    + ω^3*(μb+1)
    + 2*ω^2
    + 1
```

Skeleton:

```lean
| _, _, Step.R_rec_succ b s n => by
  simp [mu]
  -- Abbreviations
  set μn := mu n
  set μs := mu s
  set μb := mu b
  set E  := ω0^(5:Ordinal)*(μn+1) + μs + (7:Ordinal) with hE
  -- Goal is now:
  --   ω^3*(μs+1) + ω^2*(ω^(μn+μs+6) + ω*(μb+1) + 2) + 1
  --     < ω^E + ω*(μb+1) + 1

  -- Step A: expand the LHS
  have h_expand :
      ω0^(3:Ordinal)*(μs+1)
        + ω0^(2:Ordinal)*(ω0^(μn+μs+6) + ω0*(μb+1) + 2) + 1
      = ω0^(3:Ordinal)*(μs+1)
        + ω0^(μn+μs+8)
        + ω0^(3:Ordinal)*(μb+1)
        + (2:Ordinal)*ω0^(2:Ordinal) + 1 := by
    -- ω^2 * ω^(μn+μs+6) = ω^(2+μn+μs+6) = ω^(μn+μs+8)
    -- ω^2 * (ω*(μb+1))   = ω^3*(μb+1)
    -- ω^2 * 2             = 2*ω^2
    sorry  -- pure rewriting with opow_add / mul_add / mul_assoc

  rw [h_expand]

  -- Step B: show every summand that does NOT contain μb is < ω^E
  have small_s : ω0^(3:Ordinal)*(μs+1) < ω0^E := by
    -- μs+1 < ω^(μs+1) ⇒ ω^3*(μs+1) < ω^(μs+4) ≤ ω^(μs+7) ≤ ω^E
    sorry

  have small_exp : ω0^(μn + μs + 8) < ω0^E := by
    -- need μn+μs+8 < E = ω^5*(μn+1) + μs + 7
    -- key comparison: μn < ω^5*(μn+1)  (because μn < μn+1 ≤ ω^5*(μn+1))
    -- then finish by case-split / CNF / add_lt_add_of_lt_of_le
    have h1 : μn < ω0^(5:Ordinal)*(μn+1) :=
      lt_of_lt_of_le (lt_add_one μn) (le_mul_right _ (opow_pos 5 omega0_pos))
    sorry  -- lift h1 through “+ μs + 8” versus “+ μs + 7”

  have small_const : (2:Ordinal)*ω0^(2:Ordinal) + 1 < ω0^E := by
    -- 2*ω^2 + 1 < ω^5 ≤ ω^E
    sorry

  -- Step C: treat the coefficient of μb
  --   We must show
  --     ω^3*(μb+1) + (small terms)  <  ω^E + ω*(μb+1) + 1.
  -- Split on the relative size of ω^3*(μb+1) and ω^E.

  by_cases hbig : ω0^(3:Ordinal)*(μb+1) < ω0^E
  · -- All four pieces of the expanded LHS are < ω^E,
    -- and ω^E is additively principal, so their sum is < ω^E ≤ RHS.
    have : ω0^(3:Ordinal)*(μs+1) + ω0^(μn+μs+8)
             + ω0^(3:Ordinal)*(μb+1)
             + (2:Ordinal)*ω0^(2:Ordinal) + 1
           < ω0^E := by
      -- repeated application of additive principality of ω^E
      sorry
    exact lt_of_lt_of_le this (le_add_right _ _)

  · -- ¬ (ω^3*(μb+1) < ω^E), i.e. ω^E ≤ ω^3*(μb+1).
    -- In this regime the ω*(μb+1) term on the true RHS is
    -- still dominated by ω^3*(μb+1), so we need a sharper
    -- comparison that keeps the μb-coefficients on both sides.
    --
    -- Write both sides in “μb-leading” form:
    --   LHS_exp ≤ ω^3*(μb+1) + P     (P collects terms independent of b)
    --   true RHS = ω^E + ω*(μb+1) + 1
    --            ≥ ω*(μb+1) + 1
    -- and use that for large enough μb the difference
    --   ω^3*(μb+1) - ω*(μb+1)
    -- is absorbed only if the measure coefficients were chosen
    -- so that the left coefficient ≤ the right coefficient
    -- (here they are not: ω^3 ≰ ω).  Consequently a direct
    -- proof with the present definition of `mu` does not go
    -- through for arbitrary `b`.
    --
    -- Practical ways to finish inside the given development:
    --   (i)  strengthen the coefficient of (mu b+1) in the
    --        `recDelta` clause of `mu` from `ω * _` to at least
    --        `ω^4 * _` (or put `mu b` into the exponent), then
    --        the same expansion works uniformly; or
    --   (ii) prove the inequality only after observing that
    --        every value in the image of `mu` has a restricted
    --        Cantor-normal form that restores the comparison.
    -- Both are outside a pure “skeleton”; the skeleton stops here
    -- with the case split and the two proof obligations above.
    sorry
```

**Remark on Step C.**  
A fully closed proof of `R_rec_succ` with the *exact* definition of `mu` given in the file is obstructed: after expansion the left-hand side carries a factor `ω³·(μb+1)` while the right-hand side carries only `ω·(μb+1)`. When `μb` is larger than the big exponent `E` (possible because `eqW` produces values `ω^(…)+1` of arbitrary height) the inequality fails for concrete closed terms. The skeleton therefore isolates the comparison that must be discharged and records the two standard repairs (raise the coefficient of `mu b` inside `recDelta`, or exploit a tighter characterisation of the image of `mu`). All other algebraic steps are routine and match the style of the five already-proved cases.
