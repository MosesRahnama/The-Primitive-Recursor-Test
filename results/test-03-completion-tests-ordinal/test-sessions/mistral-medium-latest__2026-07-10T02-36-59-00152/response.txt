Here's a proof skeleton for completing the remaining three cases (`R_rec_succ`, `R_eq_refl`, and `R_eq_diff`) in the `mu_decreases` theorem:

```lean
-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    simp [mu]
    -- We need to show:
    -- omega^3 * (mu s + 1) + omega^2 * (omega^(mu n + mu s + 6) + omega * (mu b + 1) + 2) + 1
    -- < omega^(omega^5 * (mu n + 1) + 1 + mu s + 6) + omega * (mu b + 1) + 1
    have h1 : mu n + 1 ≤ omega^5 * (mu n + 1) :=
      le_mul_right _ (opow_pos 5 omega0_pos)
    have h2 : mu n + mu s + 6 < omega^5 * (mu n + 1) + 1 + mu s + 6 := by
      calc mu n + mu s + 6
        _ ≤ mu n + 1 + mu s + 6 := by omega
        _ ≤ omega^5 * (mu n + 1) + 1 + mu s + 6 := add_le_add_right h1 _
    -- The exponent on LHS is strictly smaller than exponent on RHS
    have h3 : omega0 ^ (mu n + mu s + 6) < omega0 ^ (omega0 ^ 5 * (mu n + 1) + 1 + mu s + 6) :=
      opow_lt_opow_right omega0_pos (by omega) h2
    -- Now show the full inequality by comparing dominant terms
    sorry

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    simp [mu]
    -- We need to show: 0 < omega^(2 * mu a + 9) + 1
    apply Ordinal.pos_iff_ne_zero.mpr
    apply ne_of_gt
    apply add_pos_right
    exact opow_pos _ omega0_pos

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    simp [mu]
    -- We need to show:
    -- omega^4 * (omega^3 * (mu a + 1) + omega^2 * (mu b + 1) + 2) + 1
    -- < omega^(mu a + mu b + 9) + 1
    have h1 : mu a + mu b + 9 > 4 := by
      calc mu a + mu b + 9
        _ ≥ 0 + 0 + 9 := by omega
        _ > 4 := by norm_num
    have h2 : omega0 ^ 4 < omega0 ^ (mu a + mu b + 9) :=
      opow_lt_opow_right omega0_pos (by omega) h1
    -- The RHS has a strictly larger exponent than any term on LHS
    have h3 : omega0 ^ 4 * (omega0 ^ 3 * (mu a + 1) + omega0 ^ 2 * (mu b + 1) + 2) <
              omega0 ^ (mu a + mu b + 9) := by
      calc omega0 ^ 4 * (omega0 ^ 3 * (mu a + 1) + omega0 ^ 2 * (mu b + 1) + 2)
        _ ≤ omega0 ^ 4 * (omega0 ^ 4) := by
          have : omega0 ^ 3 * (mu a + 1) + omega0 ^ 2 * (mu b + 1) + 2 ≤ omega0 ^ 4 := by
            sorry -- Need to show this bound
          exact mul_le_mul_left' this _
        _ = omega0 ^ (4 + 4) := by rw [← opow_add]
        _ < omega0 ^ (mu a + mu b + 9) := by
          apply opow_lt_opow_right omega0_pos
          · omega
          · omega
    calc omega0 ^ 4 * (omega0 ^ 3 * (mu a + 1) + omega0 ^ 2 * (mu b + 1) + 2) + 1
      _ < omega0 ^ (mu a + mu b + 9) := h3
      _ ≤ omega0 ^ (mu a + mu b + 9) + 1 := le_add_right _ _
```

Key insights for each case:

1. **R_rec_succ**: The exponent in the LHS's dominant term (from `recDelta`) is `mu n + mu s + 6`, while the RHS has exponent `omega^5 * (mu n + 1) + 1 + mu s + 6`. The `omega^5` term ensures the RHS exponent is strictly larger.

2. **R_eq_refl**: This is straightforward positivity since `omega^(2*mu a + 9) + 1` is clearly positive.

3. **R_eq_diff**: The RHS has exponent `mu a + mu b + 9` which is strictly larger than 4 (the exponent in the LHS's dominant term `omega^4 * ...`). The key is showing that the entire LHS expression is bounded by `omega^4 * omega^4 = omega^8`, which is still less than `omega^(mu a + mu b + 9)` when `mu a + mu b + 9 > 8` (which holds since `mu a, mu b ≥ 0`).

The remaining `sorry` in `R_eq_diff` would need to establish that `omega^3 * (mu a + 1) + omega^2 * (mu b + 1) + 2 ≤ omega^4`, which follows from the fact that `omega^4` dominates all lower omega powers.
