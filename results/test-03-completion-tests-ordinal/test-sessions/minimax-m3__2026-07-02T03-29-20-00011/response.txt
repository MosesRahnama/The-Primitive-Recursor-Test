# Proof Skeleton for the Three Remaining Cases

Below I sketch how each `sorry` should be discharged. The structure mirrors the proven cases: rewrite with `simp [mu]`, then bound the LHS by a single $\omega$-tower of height strictly less than the dominant exponent on the RHS, and finally chain the inequalities.

---

## Case `R_eq_refl` : `eqW a a → void`

**Goal after `simp [mu]`:** show `0 < omega^(mu a + mu a + 9) + 1`.

**Skeleton.** This is pure positivity:

```lean
exact Ordinal.pos_iff_ne_zero.mpr (by
  apply ne_of_gt
  exact add_pos_right _ one_pos)
```

This is exactly the same idiom as the proven `R_int_delta` case: the expression is a successor, hence non-zero, hence positive.

---

## Case `R_rec_succ` : `recDelta b s (delta n) → app s (recDelta b s n)`

**After `simp [mu]`, the goal is**

```
omega^3 * (mu s + 1) + omega^2 * (omega^(mu n + mu s + 6) + omega * (mu b + 1) + 2) + 1
  < omega^(omega^5 * (mu n + 1) + mu s + 7) + omega * (mu b + 1) + 1
```

**Strategy.** Show the entire LHS is strictly less than the *first* term of the RHS, namely
`M := omega^(omega^5 * (mu n + 1) + mu s + 7)`. Then `LHS < M ≤ M + omega*(mu b+1) + 1 = RHS`.

**Key inequality.** Every term on the LHS is bounded above by $\omega^{\mu n + \mu s + 8}$ (up to a finite coefficient), and

$$\mu n + \mu s + 9 \;<\; \omega^{5}\cdot(\mu n + 1) + \mu s + 7$$

because $\omega^{5}\cdot(\mu n+1) > \mu n + 2$ for every $\mu n$ (since $\omega^{5}\ge 1$ and $\mu n + 1 \ge 1$; for $\mu n = 0$ this is $\omega^5 > 2$, and for $\mu n > 0$ the multiplicative factor $\mu n+1$ already exceeds $\mu n+2$ once the ordinal is infinite, and exceeds it after a single step for finite ones).

**Term-by-term bound (LHS ≤ 5 · ω^(μn+μs+8)):**

1. `omega^3 * (mu s + 1) ≤ omega^(mu s + 3) ≤ omega^(mu n + mu s + 8)` since `mu n ≥ 0` and $3 \le \mu n + 8$.
2. `omega^2 * omega^(mu n + mu s + 6) = omega^(mu n + mu s + 8)`.
3. `omega^2 * (omega * (mu b + 1)) = omega^3 * (mu b + 1) ≤ omega^(mu b + 3) ≤ omega^(mu n + mu s + 8)` (using `mu n ≥ 0` and `mu s ≥ 0`).
4. `omega^2 * 2 ≤ omega^3 ≤ omega^(mu n + mu s + 8)`.
5. The trailing `+ 1` is bounded by `omega^(mu n + mu s + 8)` whenever the exponent is ≥ 0 (always true; for exponent 0, `1 ≤ 1`).

So LHS ≤ `5 * omega^(mu n + mu s + 8)`, and `5 * omega^α < omega^(α+1) ≤ omega^(α+2)` for every $\alpha$, giving
LHS < `omega^(mu n + mu s + 9) < omega^(omega^5 * (mu n + 1) + mu s + 7) ≤ RHS`.

**Skeleton.**

```lean
| _, _, Step.R_rec_succ b s n => by
  simp [mu]
  -- 1. Establish the per-term bounds listed above, each via
  --    `le_opow_succ / opow_le_opow_right` plus `Ordinal.lt_add_one` style lemmas.
  -- 2. Sum them: LHS ≤ 5 · ω^(μn+μs+8).
  -- 3. Use `Ordinal.lt_mul_of_lt` style: 5·ω^α < ω·ω^α = ω^(α+1).
  -- 4. Use `opow_lt_opow_right omega0_pos` with the strict inequality
  --    `mu n + mu s + 9 < omega^5 * (mu n + 1) + mu s + 7`
  --    (it follows from `mu n + 1 ≤ omega^5 * (mu n + 1)`, true since
  --    `omega^5 ≥ 1`).
  -- 5. Conclude LHS < RHS via `le_add_left`/`le_add_right` on the trailing
  --    `omega * (mu b + 1) + 1`.
  sorry
```

## Case `R_eq_diff` : `eqW a b → integrate (merge a b)`

**After `simp [mu]`, the goal is**

```
omega^4 * (omega^3 * (mu a + 1) + omega^2 * (mu b + 1) + 2) + 1
  < omega^(mu a + mu b + 9) + 1
```

**Strategy.** Bound the LHS above by $\omega^{\mu a + \mu b + 8}\cdot 3$, which is strictly less than $\omega^{\mu a + \mu b + 9}$.

**Key inequality.** For any ordinals $\alpha, \beta$:

- $\omega^{7}\cdot(\mu a + 1) \le \omega^{7 + \mu a}$ (using $(\mu a + 1) \le \omega^{\mu a}$, true for $\mu a = 0$ as equality and for $\mu a \ge 1$ by ordinal monotonicity $\mu a + 1 \le \omega^{\mu a}$).
- $\omega^{6}\cdot(\mu b + 1) \le \omega^{6 + \mu b}$.
- $2 \cdot \omega^4 + 1 \le \omega^5$.
- The trailing `+ 1` (from the outer `omega^4 * ... + 1`) is absorbed since each summand is already a limit/successor of sufficiently high tower.

**Summing.** LHS ≤ $\omega^{7+\mu a} + \omega^{6+\mu b} + \omega^5 + 1$, and since $\mu a, \mu b \ge 0$ each exponent is at most $\mu a + \mu b + 7$, so

$$\text{LHS} \;\le\; 3 \cdot \omega^{\mu a + \mu b + 7}.$$

Finally $3 \cdot \omega^{\alpha} < \omega^{\alpha+1} \le \omega^{\alpha+2}$ for every $\alpha$ (because $3 < \omega$), giving

$$\text{LHS} \;<\; \omega^{\mu a + \mu b + 9} \;<\; \omega^{\mu a + \mu b + 9} + 1 \;=\; \text{RHS}.$$

**Skeleton.**

```lean
| _, _, Step.R_eq_diff a b => by
  simp [mu]
  -- 1. Bound each summand of the LHS:
  --      omega^4 * omega^3 * (mu a + 1) ≤ omega^(7 + mu a)
  --      omega^4 * omega^2 * (mu b + 1) ≤ omega^(6 + mu b)
  --      omega^4 * 2                ≤ omega^5
  --      trailing +1                ≤ omega^0 ≤ omega^5
  --    Use `Ordinal.opow_add`, `mul_assoc`, then
  --    `(mu a + 1) ≤ omega^mu a` (`Ordinal.le_opow_self` plus add)
  --    and `opow_le_opow_right` to push the factor into the exponent.
  -- 2. Combine: LHS ≤ omega^(7 + mu a) + omega^(6 + mu b) + omega^5 + 1
  --             ≤ 3 · omega^(mu a + mu b + 7),
  --    using `7 + mu a ≤ mu a + mu b + 7` and similarly for the other
  --    two (since `mu b ≥ 0` and `5 ≤ mu a + mu b + 7`).
  -- 3. Use `Ordinal.lt_mul_of_lt_zero_or_lt` style: 3·ω^α < ω^(α+1) < ω^(α+2).
  -- 4. Apply `opow_lt_opow_right omega0_pos` to the exponent inequality
  --    `mu a + mu b + 9 ≤ mu a + mu b + 9` (reflexive) — actually conclude
  --    LHS < omega^(mu a + mu b + 9) ≤ RHS via `le_add_right _ _`.
  sorry
```

## Summary of the Three Sub-arguments

| Case | LHS upper bound | RHS lower bound | Strict gap |
|---|---|---|---|
| `R_eq_refl` | (LHS is `0`) | `omega^(2μa+9) + 1 ≥ 1` | trivial positivity |
| `R_rec_succ` | $\le 5\cdot\omega^{\mu n+\mu s+8}$ | $\ge \omega^{\omega^5(\mu n+1)+\mu s+7}$ | $\mu n + 9 < \omega^5(\mu n+1) + 7$ |
| `R_eq_diff` | $\le 3\cdot\omega^{\mu a+\mu b+7}$ | $\ge \omega^{\mu a+\mu b+9}$ | coefficient $3 < \omega$ |

The shared technique is: (i) `simp [mu]` to expose the raw ordinal arithmetic, (ii) bound the LHS by a *single* $\omega$-tower with a small finite coefficient using `(μ+1) ≤ ω^μ` and `opow_le_opow_right`, (iii) absorb the finite coefficient via `c · ω^α < ω^(α+1)`, and (iv) use `opow_lt_opow_right omega0_pos` on an exponent inequality that follows from the design choices in `mu` (the `+ 5` on `delta`, the `+ 9` on `eqW`).
