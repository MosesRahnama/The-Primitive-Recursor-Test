## 2. `R_rec_succ`

This is the hardest one. After `simp [mu]`, the goal should be of the shape

```lean
⊢ omega0 ^ (mu n + mu s + 6) + omega0 * (mu b + 1) + 1
   |> plugged into `app`
   < omega0 ^ (mu (delta n) + mu s + 6) + omega0 * (mu b + 1) + 1
```

More concretely, after expanding `mu`, the target is morally:

```lean
omega0 ^ 3 * (mu s + 1)
  + omega0 ^ 2 * (omega0 ^ (mu n + mu s + 6) + omega0 * (mu b + 1) + 1 + 1)
  + 1
<
omega0 ^ (omega0 ^ 5 * (mu n + 1) + 1 + mu s + 6)
  + omega0 * (mu b + 1) + 1
```

The intended strategy is:

1. Let
   ```lean
   α := mu n + mu s + 6
   β := omega0 ^ 5 * (mu n + 1) + 1 + mu s + 6
   ```
2. Prove `α < β`.
   - Since `mu n < mu n + 1`
   - and `mu n + 1 ≤ omega0 ^ 5 * (mu n + 1)` by `le_mul_right _ (opow_pos 5 omega0_pos)`
   - hence `mu n < omega0 ^ 5 * (mu n + 1)`
   - then `mu n + mu s + 6 < omega0 ^ 5 * (mu n + 1) + 1 + mu s + 6`
     by monotonicity of addition.
3. Lift to
   ```lean
   omega0 ^ α < omega0 ^ β
   ```
   using strict monotonicity of `opow` in the exponent for base `omega0` (`Ordinal.opow_lt_opow_iff_right` or a monotonicity lemma such as `opow_lt_opow_right` / `StrictMono` form, depending on mathlib names).
4. Bound each summand on the LHS by `omega0 ^ β`:
   - `omega0 ^ 3 * (mu s + 1) < omega0 ^ β`
   - `omega0 ^ 2 * (omega0 ^ α + omega0 * (mu b + 1) + 1 + 1) < omega0 ^ β`
   
   The easiest proof skeleton is not to fully normalize those products, but to use a “principal term dominates lower-rank finite tower” lemma if available. If not, the proof will likely need helper inequalities such as:
   - `3 < β`
   - `α + 2 < β`
   - therefore `omega0 ^ 3 * (mu s + 1) < omega0 ^ β`
   - and `omega0 ^ 2 * (...) ≤ omega0 ^ (α + 2) < omega0 ^ β`
   
   This uses standard ordinal facts:
   - `omega^p * c < omega^(p+1)` for positive `c`
   - `omega^2 * omega^α = omega^(2 + α)` / `omega^(α+2)` depending on convention/order
   - and then exponent comparison.

Because exact lemma names are uncertain, the best completion is to insert a local `have hdom : ...` for the principal domination and then finish by transitivity.

## 3. `R_eq_diff`

After `simp [mu]`, the goal is essentially

```lean
omega0 ^ 4 * (omega0 ^ 3 * (mu a + 1) + omega0 ^ 2 * (mu b + 1) + 1 + 1) + 1
<
omega0 ^ (mu a + mu b + 9) + 1
```

Strategy:

1. Let `γ := mu a + mu b + 9`.
2. Show the entire left side before `+1` is `< omega0 ^ γ`.
   This should follow because:
   - `omega0 ^ 3 * (mu a + 1) + omega0 ^ 2 * (mu b + 1) + 2 < omega0 ^ (mu a + mu b + 5)` (or some smaller exponent)
   - multiplying by `omega0 ^ 4` puts it below `omega0 ^ (mu a + mu b + 9)`
3. Then conclude
   ```lean
   X + 1 < omega0 ^ γ + 1
   ```
   using `add_lt_add_right`.

A very standard route is to first prove the inner merge measure is below `omega0 ^ (mu a + mu b + 5)` (or just any exponent strictly below `γ - 4`), then multiply by `omega0 ^ 4`.

      -- Typical ingredients:
      --   `mu a < mu a + 1 ≤ omega0^? * (mu a + 1)`
      --   `mu b < mu b + 1 ≤ omega0^? * (mu b + 1)`

      --
      -- Depending on available lemmas, you may:
