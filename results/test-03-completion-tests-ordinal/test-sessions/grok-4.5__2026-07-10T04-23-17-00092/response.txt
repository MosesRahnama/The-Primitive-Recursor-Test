## Proof Skeleton for the Three Remaining Cases

Below is a case-by-case skeleton that completes `mu_decreases`. The three open rules are `R_eq_refl`, `R_eq_diff`, and `R_rec_succ`. The first is a positivity fact; the other two are pure ordinal comparisons that exploit the tower heights built into `mu`.

---

### 1. `R_eq_refl` — `eqW a a → void`

**Goal after `simp [mu]`:**
```
0 < ω^(μ a + μ a + 9) + 1
```

**Skeleton:**
```lean
| _, _, Step.R_eq_refl a => by
  simp [mu]
  -- identical pattern to R_int_delta
  exact Ordinal.pos_iff_ne_zero.mpr (by
    apply ne_of_gt
    exact add_pos_right _ one_pos)
```

`add_pos_right _ one_pos` gives `0 < x + 1` for any ordinal `x`, and `ω^_ + 1` is of that form.

---

### 2. `R_eq_diff` — `eqW a b → integrate (merge a b)`

**Goal after `simp [mu]`:**
```
ω⁴ · (ω³ · (μa+1) + ω² · (μb+1) + 2) + 1
  <  ω^(μa + μb + 9) + 1
```
Equivalently (right-add of `1` is strictly monotone):
```
ω⁴ · (ω³ · (μa+1) + ω² · (μb+1) + 2)  <  ω^(μa + μb + 9)
```

**Skeleton:**
```lean
| _, _, Step.R_eq_diff a b => by
  simp [mu]
  -- Step A: cancel the trailing +1 on both sides
  apply (Order.add_lt_add_iff_left 1).mp   -- or: show main parts, then add_lt_add_right
  -- Prefer the direct form:
  --   apply Ordinal.add_lt_add_iff_right.mpr  -- depending on Mathlib spelling
  -- Cleaner: prove the body inequality, then use add_lt_add_right one_pos / lt_add...

  -- Expand LHS by left-distributivity:
  --   ω⁴ · (ω³(μa+1) + ω²(μb+1) + 2)
  --     = ω⁷ · (μa+1) + ω⁶ · (μb+1) + ω⁴ · 2
  have h_distrib :
      omega0 ^ (4 : Ordinal)
        * (omega0 ^ (3 : Ordinal) * (mu a + 1)
           + omega0 ^ (2 : Ordinal) * (mu b + 1) + 2)
      = omega0 ^ (7 : Ordinal) * (mu a + 1)
        + omega0 ^ (6 : Ordinal) * (mu b + 1)
        + omega0 ^ (4 : Ordinal) * 2 := by
    -- mul_add, mul_add, ← opow_add (4+3=7, 4+2=6)
    sorry -- routine algebra

  rw [h_distrib]
  -- Goal: ω⁷(μa+1) + ω⁶(μb+1) + ω⁴·2  <  ω^(μa+μb+9)

  -- Step B: bound each summand strictly below the target power
  have t1 : omega0 ^ (7 : Ordinal) * (mu a + 1)
            < omega0 ^ (mu a + mu b + (9 : Ordinal)) := by
    -- reduce to ω⁷ · (μa+1) < ω^(μa+9) ≤ ω^(μa+μb+9)
    have h_exp : mu a + (9 : Ordinal) ≤ mu a + mu b + 9 := by
      -- μb ≥ 0
      sorry
    refine lt_of_lt_of_le ?_ (opow_le_opow_right omega0_pos h_exp)
    -- Claim: ∀ α, ω⁷ · (α+1) < ω^(α+9)
    -- · α = 0: ω⁷ < ω⁹
    -- · α finite: ω⁷ · (n+1) < ω⁸ ≤ ω^(n+9)
    -- · α ≥ ω: α+1 ≤ α·2, so
    --     ω⁷·(α+1) ≤ ω⁷·α·2 ≤ (ω⁷·ω^α)·2 = ω^(7+α)·2
    --     and 7+α = α (α ≥ ω), so ω^α · 2 < ω^α · ω = ω^(α+1) ≤ ω^(α+9)
    sorry

  have t2 : omega0 ^ (6 : Ordinal) * (mu b + 1)
            < omega0 ^ (mu a + mu b + (9 : Ordinal)) := by
    -- symmetric: ω⁶ · (μb+1) < ω^(μb+8) ≤ ω^(μa+μb+9)
    sorry

  have t3 : omega0 ^ (4 : Ordinal) * 2
            < omega0 ^ (mu a + mu b + (9 : Ordinal)) := by
    -- ω⁴ · 2 < ω⁵ < ω⁹ ≤ ω^(μa+μb+9)
    sorry

  -- Step C: sum of three terms each < ω^γ, and ω^γ (γ ≥ 1) is additively principal
  -- (available via Mathlib.SetTheory.Ordinal.Principal)
  have hγ : (0 : Ordinal) < mu a + mu b + 9 := by
    -- ≥ 9
    sorry
  -- principal_add: α,β < ω^γ → α+β < ω^γ
  have sum12 :
      omega0 ^ (7 : Ordinal) * (mu a + 1)
        + omega0 ^ (6 : Ordinal) * (mu b + 1)
      < omega0 ^ (mu a + mu b + (9 : Ordinal)) :=
    principal_add_iff_add_lt.mp
      (opow_principal_add omega0_pos (by -- γ > 0
        sorry)) t1 t2   -- adjust to actual Mathlib API
  exact principal_add_iff_add_lt.mp
    (opow_principal_add omega0_pos (by sorry)) sum12 t3
```

**Design note.** The constant `+9` in `mu (eqW …)` is exactly large enough that every CNF term produced by `integrate (merge …)` (highest power `ω⁷`) sits strictly below `ω^(μa+μb+9)`. Additive principality of `ω^γ` then closes the sum.

### 3. `R_rec_succ` — `recDelta b s (delta n) → app s (recDelta b s n)`

**Goal after `simp [mu]`:**
```
ω³ · (μs+1) + ω² · (μ(recDelta b s n) + 1) + 1
  <  ω^(μ(delta n) + μs + 6) + ω · (μb+1) + 1
```
Unfolding definitions:
```
LHS = ω³(μs+1) + ω² · (ω^(μn+μs+6) + ω(μb+1) + 2) + 1
RHS = ω^(ω⁵(μn+1) + 1 + μs + 6) + ω(μb+1) + 1
    = ω^(ω⁵(μn+1) + μs + 7) + ω(μb+1) + 1
```

**Skeleton:**
```lean
| _, _, Step.R_rec_succ b s n => by
  simp [mu]
  -- Notation for the two big exponents
  set eL : Ordinal := (2 : Ordinal) + (mu n + mu s + 6)   -- will appear from ω²·ω^(…)
  set eR : Ordinal := omega0 ^ (5 : Ordinal) * (mu n + 1) + mu s + 7

  -- Step A: expand LHS by distributivity
  --   ω² · (ω^(μn+μs+6) + ω(μb+1) + 2)
  --     = ω² · ω^(μn+μs+6) + ω² · ω · (μb+1) + ω² · 2
  --     = ω^(2+(μn+μs+6)) + ω³ · (μb+1) + ω² · 2
  have h_lhs :
      omega0 ^ (3 : Ordinal) * (mu s + 1)
        + omega0 ^ (2 : Ordinal)
            * (omega0 ^ (mu n + mu s + (6 : Ordinal))
               + omega0 * (mu b + 1) + 2)
        + 1
      = omega0 ^ (3 : Ordinal) * (mu s + 1)
        + omega0 ^ eL
        + omega0 ^ (3 : Ordinal) * (mu b + 1)
        + omega0 ^ (2 : Ordinal) * 2
        + 1 := by
    -- mul_add ×2, ← opow_add (ω²·ω^α = ω^(2+α)), ω²·ω = ω³
    sorry

  -- RHS stays:
  --   ω^eR + ω(μb+1) + 1

  -- Step B: show the exponent jump  eL < eR
  -- This is the heart of the measure design (delta gets ω⁵).
  have h_exp : eL < eR := by
    -- eL = 2 + (μn + μs + 6)
    -- eR = ω⁵(μn+1) + μs + 7
    -- Key fact: μn < ω⁵ · (μn+1)
    have h_n : mu n < omega0 ^ (5 : Ordinal) * (mu n + 1) := by
      have : mu n < mu n + 1 := lt_add_one _
      have : mu n + 1 ≤ omega0 ^ (5 : Ordinal) * (mu n + 1) :=
        le_mul_right _ (opow_pos _ omega0_pos)
      exact lt_of_lt_of_le ‹_› ‹_›
    -- right-add μs (strictly monotone): μn + μs < ω⁵(μn+1) + μs
    have h_ns : mu n + mu s
                < omega0 ^ (5 : Ordinal) * (mu n + 1) + mu s :=
      (Order.add_lt_add_iff_right (mu s)).mpr h_n
    -- then +6 vs +7, and 2+α ≤ α+2 for finite 2:
    --   2 + (μn+μs+6) ≤ (μn+μs+6) + 2
    --                 < (μn+μs+6) + 3
    --                 ≤ (ω⁵(μn+1) + μs) + 7   (using h_ns and room in +7)
    -- Fill with lt_of_le_of_lt / add_lt_add_right / nat cast facts.
    sorry

  -- Step C: every LHS summand < ω^eR  (hence < RHS)
  -- Because ω^eR is additively principal (eR ≥ 7 > 0):
  have pR : Principal (· + ·) (omega0 ^ eR) :=
    opow_principal_add omega0_pos (by
      -- eR > 0
      sorry)

  have u1 : omega0 ^ (3 : Ordinal) * (mu s + 1) < omega0 ^ eR := by
    -- ω³ · (μs+1) < ω^(μs+5) ≤ ω^eR  (eR ≥ μs+7)
    sorry
  have u2 : omega0 ^ eL < omega0 ^ eR :=
    opow_lt_opow_iff_right omega0_pos |>.mpr h_exp
  have u3 : omega0 ^ (3 : Ordinal) * (mu b + 1) < omega0 ^ eR := by
    -- ω³ · (μb+1) < ω^(μb+5) < eR-powered term
    -- (eR ≥ ω⁵ ≥ ω⁵, absorbs any fixed tower over μb via the same argument as eq_diff)
    sorry
  have u4 : omega0 ^ (2 : Ordinal) * 2 < omega0 ^ eR := by
    -- ω²·2 < ω³ < ω^eR
    sorry

  -- Step D: sum the four positive terms + 1, all < ω^eR ≤ RHS
  --   u1 + u2 + u3 + u4 + 1 < ω^eR + ω(μb+1) + 1   (even the weaker bound without the ω(μb+1) works)
  -- Use repeated principal_add (or a fold), then
  --   lt_of_lt_of_le (sum < ω^eR) (le_add_right _ _)
  -- and finally add_lt_add_right for the trailing +1 if needed.
  sorry
```

**Design note.** Placing `μ(delta n) = ω⁵(μn+1)+1` into the *exponent* of `recDelta` is what creates `eR ≫ eL`. Once the leading powers satisfy `eL < eR`, additive principality of `ω^eR` swallows the lower-order `app` coefficients (`ω³`, `ω²`, constants).
