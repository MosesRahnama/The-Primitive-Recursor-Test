A good way to finish the file is to **avoid doing the two large ordinal arguments inline**.  Package the needed ordinal estimates as local/helper lemmas, then the remaining rule cases become short.

Below is a proof skeleton you can use.  I am not claiming the exact Mathlib lemma names are all correct; the point is the structure and the intermediate estimates you want.

```lean
/-! Suggested helper lemmas for the hard ordinal estimates.

These should be proved once using:
  * monotonicity of ordinal addition/multiplication/opow,
  * positivity of `omega0`,
  * additively-principal behaviour of `omega0 ^ ξ`,
  * the fact that finite towers such as `ω^3`, `ω^4`, `ω^5`
    are strictly below the large exponents used in `recDelta`/`eqW`.
-/

private lemma eqDiff_bound (A B : Ordinal) :
    omega0 ^ (4 : Ordinal) *
        (omega0 ^ (3 : Ordinal) * (A + 1)
          + omega0 ^ (2 : Ordinal) * (B + 1)
          + 1 + 1)
      + 1
    <
    omega0 ^ (A + B + (9 : Ordinal)) + 1 := by
  /-
  Intended proof outline.

  Let E := A + B + 9.

  1. Show the merge payload is below `ω ^ (A + B + 5)`:

        omega0^3 * (A + 1) < omega0 ^ (A + B + 5)
        omega0^2 * (B + 1) < omega0 ^ (A + B + 5)
        1 + 1              < omega0 ^ (A + B + 5)

     Then use additively-principal closure of `omega0 ^ (A + B + 5)` under
     finite/additive sums.

  2. Multiply by `omega0^4`:

        omega0^4 * inner < omega0 ^ (4 + (A + B + 5))

  3. Use ordinal arithmetic:

        4 + (A + B + 5) ≤ A + B + 9

     hence

        omega0^4 * inner < omega0 ^ (A + B + 9)

  4. Conclude by adding the final `+ 1`:

        X < omega0 ^ E
        ----------------
        X + 1 < omega0 ^ E + 1

  -/
  sorry


private lemma recSucc_bound (B S N : Ordinal) :
    omega0 ^ (3 : Ordinal) * (S + 1)
      + omega0 ^ (2 : Ordinal) *
          (omega0 ^ (N + S + (6 : Ordinal))
            + omega0 * (B + 1)
            + 1 + 1)
      + 1
    <
    omega0 ^
        (omega0 ^ (5 : Ordinal) * (N + 1)
          + 1 + S + (6 : Ordinal))
      + omega0 * (B + 1)
      + 1 := by
  /-
  Intended proof outline.

  Put

      C := N + S + 6
      D := omega0^5 * (N + 1) + 1 + S + 6

  The goal is:

      μ(app s (recDelta b s n)) < ω^D + ω * (B + 1) + 1

  where

      μ(recDelta b s n) = ω^C + ω * (B + 1) + 1.

  Expand/estimate the app measure:

      ω^3 * (S + 1)
        + ω^2 * (ω^C + ω * (B + 1) + 1 + 1)
        + 1

  The low-order terms are bounded by `ω^D`:

      ω^3 * (S + 1) < ω^D
      ω^2 * ω^C     = ω^(2 + C) < ω^D
      ω^2 * 2       < ω^D

  because the exponent `D` contains the large component

      omega0^5 * (N + 1)

  and therefore dominates `S`, `N + S + 6`, and all finite shifts.

  The only delicate part is the `B`-dependent tail:

      ω^2 * (ω * (B + 1)) = ω^3 * (B + 1)

  This is absorbed by the source tail

      ω * (B + 1)

  once the leading `ω^D` term is present.  A useful auxiliary estimate is:

      omega0^3 * (B + 1)
        < omega0^D + omega0 * (B + 1)

  for `D ≥ omega0^5`.

  Combining these estimates with additive-principal closure of `ω^D`
  gives the strict bound

      ω^3 * (S + 1)
        + ω^2 * (ω^C + ω * (B + 1) + 1 + 1)
      < ω^D + ω * (B + 1)

  and then adding the final `+ 1` gives the desired result.

  -/
  sorry
```

Then the three missing cases can be completed as follows.

```lean
-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    simp [mu]
    -- After `simp [mu]`, the goal is exactly the ordinal estimate
    -- specialized to `B = mu b`, `S = mu s`, `N = mu n`.
    exact recSucc_bound (mu b) (mu s) (mu n)

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    simp [mu]
    -- Goal is:
    --   0 < omega0 ^ (mu a + mu a + 9) + 1
    -- This follows immediately because the right side has a final `+ 1`.
    exact Ordinal.pos_iff_ne_zero.mpr (by
      apply ne_of_gt
      exact add_pos_right _ one_pos)

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    simp [mu]
    -- After simplification this is exactly `eqDiff_bound`.
    exact eqDiff_bound (mu a) (mu b)
```

So the completion strategy is:

1. Prove the easy `eq_refl` case directly by positivity.
2. Add one helper lemma for the `eq_diff` ordinal domination estimate.
3. Add one helper lemma for the `rec_succ` ordinal domination estimate.
4. In the actual rule cases, reduce with `simp [mu]` and apply those helpers.
