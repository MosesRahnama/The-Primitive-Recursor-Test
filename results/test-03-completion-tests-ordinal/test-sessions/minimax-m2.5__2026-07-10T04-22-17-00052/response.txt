Below is a compact **proof‑skeleton** for the three remaining cases of `mu_decreases`.  
The idea is the same as in the already‑finished cases: we compare the two
ordinals term‑by‑term, use the monotonicity of ordinal addition,
multiplication and exponentiation (the base `ω₀` is a limit ordinal > 1), and
the obvious bounds that come from the definition of `mu`.  The skeletons are
written in the same “calc‑style” that the file already uses, so they can be
copied straight into the three `sorry` holes.

## 1.  `R_rec_succ`  –  `recDelta b s (delta n)  ⟹  app s (recDelta b s n)`

```lean
| _, _, Step.R_rec_succ b s n => by
  -- mu(app s (recDelta b s n))  <  mu(recDelta b s (delta n))
  simp [mu]

  /- The left‑hand side (the reductum) is

       LHS = ω³·(μs+1) + ω²·(μ(recDelta b s n)+1) + 1

     The right‑hand side (the contractum) is

       RHS = ω^( μ(delta n) + μs + 6 ) + ω·(μb+1) + 1

     where  μ(delta n) = ω⁵·(μn+1) + 1.
  -/

  -- 1.  Bound μ(recDelta b s n) from above
  have μ_rec : μ (recDelta b s n) ≤
               ω^(μ n + μ s + 6) + ω·(μ b + 1) := by
    -- This is exactly the definition of μ on a recDelta‑term
    simp [mu]

  -- 2.  Show that the exponent of the RHS is strictly larger than
  --     the biggest exponent that appears on the LHS.
  --     The crucial inequality is
  --     μ(delta n) + μs + 6  >  μs + ( μ(recDelta b s n) + 3 )
  have exp_ineq :
      μ (delta n) + μ s + (6 : Ordinal) >
      μ s + (μ (recDelta b s n) + (3 : Ordinal)) := by
    -- Use the shape of μ(delta n) and the bound for μ(recDelta)
    have : μ (delta n) = ω0 ^ (5 : Ordinal) * (μ n + 1) + 1 := rfl
    have := μ_rec
    -- Because ω⁵·(μn+1) dominates any term of the form μn+μs+6,
    -- we obtain the strict inequality after a short ordinal‑arithmetics
    -- routine (the goal follows from ordinal strict monotonicity of ^).
    apply Ordinal.lt_of_lt_of_le
      (Ordinal.opow_strictMono (lt_add_one _))
    · -- Show   ω⁵·(μn+1)  >  μn + μs + 6   (true for all n,s)
      have : ω0 ^ (5 : Ordinal) > (μ n + μ s + 6) := by
        apply Ordinal.opow_strictMono (Ordinal.lt_of_lt_of_le _)
        · exactOrdinal.lt_omega0  -- ω₀ > any natural number
        · linarith
      exact this
    · rfl

  -- 3.  Use the strict monotonicity of exponentiation to compare the
  --     leading ω‑powers.
  have ω_exp_strict : ω0 ^ (μ (delta n) + μ s + 6) >
                      ω0 ^ (μ s + (μ (recDelta b s n) + 3)) :=
    Ordinal.opow_strictMono exp_ineq

  -- 4.  Put everything together in a calc‑chain.
  calc μ (app s (recDelta b s n))
    _ = ω0 ^ 3 * (μ s + 1) + ω0 ^ 2 * (μ (recDelta b s n) + 1) + 1
      := rfl
    _ < ω0 ^ (μ (delta n) + μ s + 6) + ω0 * (μ b + 1) + 1
      := by
        -- The first term is dominated by the big ω‑power from step 3,
        -- the second term is ≤ ω·(μb+1) and the +1 is harmless.
        apply Ordinal.lt_of_lt_of_le ω_exp_strict
        apply Ordinal.add_lt_add_right
        · exact Ordinal.lt_add_one _
        · rfl
```

The key point is that the exponent on the RHS contains `ω⁵·(μn+1)` (coming from
`mu(delta n)`), which is astronomically larger than anything that can appear
in the exponent on the LHS, so the strict inequality follows from the
monotonicity of ordinal exponentiation.

## 2.  `R_eq_refl`  –  `eqW a a  ⟹  void`

```lean
| _, _, Step.R_eq_refl a => by
  simp [mu]
  -- Goal: 0 < ω^(μa + μa + 9) + 1
  -- The exponent is at least 9, hence non‑zero.
  have : μ a + μ a + (9 : Ordinal) ≠ 0 := by
    -- μ a is an ordinal, so μ a + μ a ≥ 0; adding 9 gives a non‑zero ordinal.
    apply Ordinal.add_ne_zero_of_ne_zero
    · exact Ordinal.add_ne_zero_of_ne_zero (Ordinal.zero_ne_add _)
    · decide   -- 9 ≠ 0
  -- ω^positive > 0
  have ω_pos : 0 < ω0 ^ (μ a + μ a + 9) := by
    apply Ordinal.opow_pos
    · exact omega0_pos
    · exact this
  -- Add the trailing +1
  exact Ordinal.add_pos_right (ω0 ^ (μ a + μ a + 9)) one_pos
```

The proof is a straightforward positivity argument: any positive exponent
produces a strictly positive ordinal, and adding 1 preserves strict
positivity.

## 3.  `R_eq_diff`  –  `eqW a b  ⟹  integrate (merge a b)`

```lean
| _, _, Step.R_eq_diff a b => by
  simp [mu]
  -- Let A = μ a, B = μ b for readability.
  -- LHS = μ(integrate (merge a b))
  --     = ω⁴·( ω³·(A+1) + ω²·(B+1) + 1 + 1 ) + 1
  -- RHS = μ(eqW a b) = ω^(A + B + 9) + 1
  -- We must show LHS < RHS.

  -- 1.  Bound the inner term of the LHS by something that still fits
  --     under the big exponent on the RHS.
  have inner_le : ω³·(A+1) + ω²·(B+1) + (2 : Ordinal) ≤
                  ω0 ^ (max A B + 4) := by
    -- Both ω³·(A+1) and ω²·(B+1) are ≤ ω^(max A B + 3)
    -- Adding the small constant 2 does not change the class.
    apply Ordinal.le_add_right
    apply Ordinal.le_mul_right
    · exact opow_pos (max A B + 3) omega0_pos

  -- 2.  Since 4 + (max A B + 4)  ≤  A + B + 9   (the RHS exponent)
  --     we get a strict inequality after one more step of monotonicity.
  have exp_ineq : (4 : Ordinal) + (max A B + 4) < A + B + 9 := by
    have : max A B ≤ A + B := Ordinal.le_add_right _ _
    linarith

  -- 3.  Apply the strict monotonicity of exponentiation:
  --     ω^(4 + (max A B + 4))  <  ω^(A + B + 9)
  have ω_strict : ω0 ^ (4 + (max A B + 4)) <
                  ω0 ^ (A + B + 9) :=
    Ordinal.opow_strictMono exp_ineq

  -- 4.  Now compare the whole LHS with the RHS.
  calc μ (integrate (merge a b))
    _ = ω0 ^ 4 * (ω0 ^ 3 * (A + 1) + ω0 ^ 2 * (B + 1) + 1 + 1) + 1
      := rfl
    _ ≤ ω0 ^ 4 * ω0 ^ (max A B + 4) + 1
      := by
        -- use the bound from step 1
        apply Ordinal.mul_le_mul_left
        · exact inner_le
    _ < ω0 ^ (A + B + 9) + 1
      := by
        -- combine step 3 with the fact that +1 is harmless
        apply Ordinal.lt_of_lt_of_le ω_strict
        apply Ordinal.add_le_add_right
        rfl
```

The intuition is that the RHS carries a tower‑exponent `A+B+9` that is far
larger than any combination of the smaller exponents (3, 2, 4) that appear on
the LHS, so the inequality follows from the monotonicity of ordinal
exponentiation.
