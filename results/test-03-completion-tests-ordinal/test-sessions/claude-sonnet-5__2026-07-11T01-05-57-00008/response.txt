Below is a proof skeleton for the three remaining cases (`R_rec_succ`, `R_eq_refl`, `R_eq_diff`). It follows the same style as the completed cases: the ordinal arithmetic is broken into small `have`-lemmas (mostly provable directly from standard `Ordinal` monotonicity facts already used elsewhere in the file, e.g. `le_mul_right`, `opow_pos`, `le_add_left/right`, `opow_le_opow_right`, `opow_lt_opow_right`, `Ordinal.opow_add`), assembled by a final `calc`. Genuinely delicate absorption facts about `omega0`-towers are isolated into named auxiliary lemmas so that they can be filled in one at a time without disturbing the overall shape of the proof.

```lean
-- ── Remaining cases (skeleton) ────────────────────────────────

-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    simp [mu]
    -- Names for the two sides after unfolding `mu`:
    --   LHS exponent  E1 := mu (delta n) + mu s + 6
    --               = (omega0^5 * (mu n + 1) + 1) + mu s + 6
    --   RHS content   uses mu (recDelta b s n)
    --               = omega0 ^ (mu n + mu s + 6) + omega0 * (mu b + 1) + 1
    --
    -- Strategy: E1 strictly dominates (as an ordinal) the exponent
    -- `2` appearing in `omega0^2 * (mu (recDelta b s n) + 1)` together with
    -- everything else on the RHS, because E1 already contains a summand
    -- `omega0^5 * (mu n + 1)` which is far larger than
    -- `mu n + mu s + 6` (the RHS's own top exponent) plus any finite
    -- additive slack coming from `omega0^3`, `omega0^2`.
    --
    -- Step 1: the RHS exponent is strictly below the LHS exponent.
    have hExp : mu n + mu s + 6 < mu (delta n) + mu s + 6 := by
      have : mu n < mu (delta n) := by
        simp [mu]
        have h1 : mu n < mu n + 1 := lt_add_one _
        have h2 : mu n + 1 ≤ omega0 ^ (5 : Ordinal) * (mu n + 1) :=
          le_mul_right _ (opow_pos 5 omega0_pos)
        exact lt_of_lt_of_le h1 (le_trans h2 (le_add_right _ _))
      exact add_lt_add_right (add_lt_add_right this _) _
    -- Step 2: turn the exponent gap into an opow gap.
    have hOpow : omega0 ^ (mu n + mu s + 6) < omega0 ^ (mu (delta n) + mu s + 6) :=
      (opow_lt_opow_right one_lt_omega0 hExp)   -- fill in exact lemma name/args
    -- Step 3: `omega0 ^ (mu (delta n) + mu s + 6)` absorbs *all* finite
    -- multiples/additive pieces coming from `omega0^3 * (mu s+1)`,
    -- `omega0^2 * (…)`, `omega0 * (mu b + 1)`, and the trailing `+1`'s,
    -- since those are each `< omega0 ^ (mu (delta n) + mu s + 6)` and the
    -- opow tower is closed under a bounded number of additions of smaller
    -- ordinals (principal additive result for `omega0^_`).
    have hAbsorb :
        omega0 ^ (3 : Ordinal) * (mu s + 1)
          + omega0 ^ (2 : Ordinal) *
              (omega0 ^ (mu n + mu s + 6) + omega0 * (mu b + 1) + 1 + 1) + 1
        < omega0 ^ (mu (delta n) + mu s + 6) + omega0 * (mu b + 1) + 1 := by
      sorry  -- absorption lemma: combine hOpow with `Ordinal.principal_add_omega0_opow`
             -- (or a direct opow_add / mul_lt_opow argument) to dominate
             -- the finite stack of `+`/`*` on the LHS.
    -- Step 4: conclude.
    simpa [mu] using hAbsorb

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    simp [mu]
    -- Goal: 0 < omega0 ^ (mu a + mu a + 9) + 1
    -- identical shape to the `R_int_delta` case.
    exact Ordinal.pos_iff_ne_zero.mpr (by
      apply ne_of_gt
      exact add_pos_right _ one_pos)

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    simp [mu]
    -- Goal (after unfolding `mu`):
    --   omega0^4 * (omega0^3*(mu a+1) + omega0^2*(mu b+1) + 1 + 1) + 1
    --     < omega0 ^ (mu a + mu b + 9) + 1
    --
    -- It suffices to bound the content of the `omega0^4 * (...)` term by
    -- `omega0 ^ (mu a + mu b + 4)`, since then
    --   omega0^4 * omega0^(mu a + mu b + 4) = omega0 ^ (mu a + mu b + 8)
    --     < omega0 ^ (mu a + mu b + 9).
    have hInner :
        omega0 ^ (3 : Ordinal) * (mu a + 1) + omega0 ^ (2 : Ordinal) * (mu b + 1) + 1 + 1
          ≤ omega0 ^ (mu a + mu b + 4) := by
      -- Two sub-bounds, each an instance of "small exponent + small
      -- coefficient is absorbed by a larger tower", proved the same way
      -- as in the completed `merge`/`app` cases via `le_mul_right`,
      -- `opow_pos`, and monotonicity of `opow` in the exponent.
      have hA : omega0 ^ (3 : Ordinal) * (mu a + 1) ≤ omega0 ^ (mu a + 3) := by
        sorry  -- mu a + 1 ≤ omega0 ^ (mu a + 1) type fact, then opow_add + mul monotonicity
      have hB : omega0 ^ (2 : Ordinal) * (mu b + 1) ≤ omega0 ^ (mu b + 2) := by
        sorry  -- symmetric to hA
      have hSum : omega0 ^ (mu a + 3) + omega0 ^ (mu b + 2) + 1 + 1
          ≤ omega0 ^ (mu a + mu b + 4) := by
        sorry  -- absorption of two smaller opow-towers (plus finite slack)
               -- into one larger tower with exponent `mu a + mu b + 4`
      calc omega0 ^ (3 : Ordinal) * (mu a + 1) + omega0 ^ (2 : Ordinal) * (mu b + 1) + 1 + 1
          ≤ omega0 ^ (mu a + 3) + omega0 ^ (mu b + 2) + 1 + 1 :=
            add_le_add_right (add_le_add_right (add_le_add hA hB) _) _
        _ ≤ omega0 ^ (mu a + mu b + 4) := hSum
    have hOuter :
        omega0 ^ (4 : Ordinal) * (omega0 ^ (mu a + mu b + 4)) < omega0 ^ (mu a + mu b + 9) := by
      -- `omega0^4 * omega0^(mu a + mu b + 4) = omega0^(mu a + mu b + 8)`
      -- via `Ordinal.opow_add`, then strict opow monotonicity in the
      -- exponent (`8 < 9`).
      sorry
    calc
      omega0 ^ (4 : Ordinal)
          * (omega0 ^ (3 : Ordinal) * (mu a + 1) + omega0 ^ (2 : Ordinal) * (mu b + 1) + 1 + 1)
          + 1
        ≤ omega0 ^ (4 : Ordinal) * omega0 ^ (mu a + mu b + 4) + 1 :=
          add_le_add_right (mul_le_mul_left' hInner _) _
      _ < omega0 ^ (mu a + mu b + 9) + 1 :=
          add_lt_add_right hOuter 1
```

Notes on filling in the `sorry`s (the genuinely technical steps):

- `hAbsorb` / `hSum` / `hOuter` all reduce to a single recurring fact about ordinal exponentials: if `e₁ < e₂` then `omega0 ^ e₂` absorbs any finite sum of terms of the form `omega0 ^ e₁ * k` or smaller (this is essentially `Ordinal.principal_add_omega0_opow` / the fact that `omega0 ^ e` is additively principal, combined with `Ordinal.opow_add` to merge exponents when multiplying towers).
- `hA`, `hB` reduce to the basic fact `x + 1 ≤ omega0 ^ (x + 1)`, provable by induction on `x` (or directly from `Ordinal.right_le_opow`-style lemmas), then composed with `opow_add : omega0 ^ (x + k) = omega0 ^ x * omega0 ^ k` and `le_mul_right`.
- Once these three lemmas are proved as standalone facts, they can be reused verbatim in `R_rec_succ` and `R_eq_diff`, since both ultimately reduce to "a bounded stack of `omega0^k * (small)` terms is dominated by one larger `omega0^(bigger exponent)`".
