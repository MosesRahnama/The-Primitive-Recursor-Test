Here are proof skeletons for the three remaining cases.  Each follows the same pattern as the already-completed cases: isolate the dominant power of `omega0`, show that every summand of the right-hand side is strictly below that power, and then sum them using the fact that non-trivial powers of `omega` are additively principal.

| _, _, Step.R_rec_succ b s n => by
  simp [mu]
  -- The left summand of the recDelta measure dominates the whole RHS.
  have h : omega0 ^ (3 : Ordinal) * (mu s + 1)
          + omega0 ^ (2 : Ordinal) * (mu (recDelta b s n) + 1)
          + 1
          < omega0 ^ (mu (delta n) + mu s + (6 : Ordinal)) := by
    have h1 : omega0 ^ (3 : Ordinal) * (mu s + 1)
              < omega0 ^ (mu (delta n) + mu s + (6 : Ordinal)) := by
      have hs : mu s + 1 < omega0 ^ (mu s + 1) := by
        apply lt_of_lt_of_le (lt_add_one (mu s))
        exact le_opow_self omega0_pos (mu s + 1)
      have h11 : omega0 ^ (3 : Ordinal) * (mu s + 1)
                 < omega0 ^ (3 : Ordinal) * omega0 ^ (mu s + 1) := by
        apply mul_lt_mul_of_pos_left hs (opow_pos 3 omega0_pos)
      have h12 : omega0 ^ (3 : Ordinal) * omega0 ^ (mu s + 1)
                 = omega0 ^ ((3 : Ordinal) + (mu s + 1)) := by
        rw [← opow_add]
      have h13 : (3 : Ordinal) + (mu s + 1) < mu (delta n) + mu s + (6 : Ordinal) := by
        -- 3 + (mu s + 1) ≤ mu s + 4 < mu s + 7 ≤ mu(delta n) + mu s + 6
        -- because mu(delta n) = omega^5*(mu n + 1) + 1 ≥ 1.
        sorry
      have h14 : omega0 ^ ((3 : Ordinal) + (mu s + 1))
                 < omega0 ^ (mu (delta n) + mu s + (6 : Ordinal)) := by
        apply opow_lt_opow_right omega0_one_lt_omega0 h13
      rw [h12] at h11
      exact lt_trans h11 h14

              < omega0 ^ (mu (delta n) + mu s + (6 : Ordinal)) := by
      -- Expand mu(recDelta b s n).  Its leading term is omega^(mu n + mu s + 6).
      -- Multiplying by omega^2 yields at most omega^(mu n + mu s + 6) (when the
      -- exponent is infinite) or omega^(finite+2); in all cases it is below
      -- omega^(mu(delta n) + mu s + 6) because mu n < mu(delta n).

      simp

    -- (additively indecomposable), so the sum of three smaller ordinals is smaller.
    sorry

        + omega0 * (mu b + 1) + 1 := by
      apply le_trans (le_add_right _ _) (le_add_right _ _)

| _, _, Step.R_eq_refl a => by

**Notes on the remaining `sorry` gaps:**

1. **The ordinal inequalities of the form** `7 + mu a + 1 < mu a + mu b + 9` **etc.** are pure ordinal arithmetic: for any `α, β` we have `n + α + 1 ≤ α + (n+1) < α + (n+2) ≤ α + β + (n+2)` when `β ≥ 0`.  A few lines with `add_lt_add_right`, `lt_add_of_pos_right`, and `opow_lt_opow_right` close them.

2. **The “additively principal” bundling** (`sorry` at the end of the two `have h : ...` blocks) is the standard fact that `ω^γ` with `γ > 0` is closed under addition: if `x < ω^γ` and `y < ω^γ` then `x + y < ω^γ`.  In Mathlib this is available via `Ordinal.isPrincipalAdd_opow`; applying it to `h1`, `h2` (and `h3`) finishes the goal in each case.
