## 2.  `R_eq_refl`  –  equality‑reflexivity  

```
| _, _, Step.R_eq_refl a => by
  simp [mu]
  -- Goal: 0 < ω^(μ a + μ a + 9) + 1
  -- The exponent μ a + μ a + 9 is a non‑zero natural number,
  -- hence its ω‑power is positive.
  have h : 0 < mu a + mu a + 9 := by
    apply add_pos <|> linarith   -- μ a ≥ 0 ⇒ sum ≥ 9 > 0
  have h' : 0 < omega0 ^ (mu a + mu a + 9) := by
    exact opow_pos (mu a + mu a + 9) omega0_pos
  -- Finally 0 < ω^(…) + 1 follows from ordinal.zero_lt_succ
  exact ordinal.zero_lt_succ.mpr (add_pos h' one_pos)
```

All that is needed here is the positivity of the exponent and the fact that `ω^α + 1` is always a successor ordinal.

```
| _, _, Step.R_eq_diff a b => by

  set α := mu a with ha
  set β := mu b with hb

  -- LHS = ω^4 * ( ω^3*(α+1) + ω^2*(β+1) + 2 ) + 1
  -- RHS = ω^(α+β+9) + 1

  -- The exponent on the RHS is at least 9, i.e. > 4.
  have h_big : α + β + 9 > 4 := by linarith   -- α,β ≥ 0

  --   ω^3*(α+1) + ω^2*(β+1) + 2  ≤  ω^(α+β+5)

    -- Adding the two yields ≤ ω^(max(α+3, β+2)) ≤ ω^(α+β+5) because both
    --   α+3 ≤ α+β+5 and β+2 ≤ α+β+5.

  -- Multiplying the inequality by ω^4 (which is monotone) gives
  --   ω^4 * ( … ) ≤ ω^4 * ω^(α+β+5) = ω^(α+β+9)
  have h_mul : ω0 ^ 4 * ( ω0 ^ 3 * (α + 1) + ω0 ^ 2 * (β + 1) + 2 ) ≤
              omega0 ^ (α + β + 9) := by
    apply mul_le_mul_left
    · exact opow_pos 4 omega0_pos
    · exact h_inner

  -- Finally strip the trailing +1 from both sides (they are equal on both
  -- sides and do not affect the strict inequality).
  exact calc
    _ = ω0 ^ 4 * ( ω0 ^ 3 * (α + 1) + ω0 ^ 2 * (β + 1) + 2 ) + 1   -- LHS
      _ < ω0 ^ (α + β + 9) + 1                                    -- h_mul
      _ = _                                                      -- RHS
```

monotonicity of multiplication (`mul_le_mul_left`) and of exponentiation
(`opow_strictMono`) together with the obvious bound `α+β+5 ≥ 3,2`.

### How to finish the three cases  

1. **R_rec_succ** – Prove the exponent strictness `α+β+6 < ω^5·(α+1)+β+7` and then
   chain the inequalities as shown in the `calc` block.  The required lemmas
   are `ordinal.opow_strictMono`, `ordinal.add_le_add`, `ordinal.mul_le_mul_left`,
   and the simple bound `ω^5·x > x`.

2. **R_eq_refl** – Use `ordinal.opow_pos` together with `ordinal.add_pos` (or
   `ordinal.zero_lt_succ`) to obtain `0 < ω^(2·μ a + 9) + 1`.

3. **R_eq_diff** – Show `α+β+9 > 4`, bound the inner term by `ω^(α+β+5)`,
   multiply by `ω^4`, and compare with the RHS.  The needed lemmas are the
   same monotonicity lemmas as above.
