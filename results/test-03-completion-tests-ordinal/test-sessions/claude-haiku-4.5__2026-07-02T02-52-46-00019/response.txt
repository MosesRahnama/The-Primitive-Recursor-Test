# Proof Skeleton for Remaining Cases

Here's a skeleton for completing the three `sorry` cases:

```lean
-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    simp [mu]
    -- Strategy: Show that the exponent omega^5 * (mu(n) + 1) in the LHS 
    -- dominates the entire RHS
    have h_n_tower : omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + 6 
                     > mu n + mu s + 6 := by
      -- omega^5 * (mu(n) + 1) grows much faster than mu(n)
      sorry
    have h_lhs_exp : omega0 ^ (omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + 6)
                     > omega0 ^ (3 : Ordinal) * (mu s + 1) 
                     + omega0 ^ (2 : Ordinal) * (omega0 ^ (mu n + mu s + 6) + omega0 * (mu b + 1) + 1 + 1) + 1 := by
      -- Exponentiation is monotone in the exponent for omega base
      sorry
    calc mu b + 1 < omega0 * (mu b + 1)                           := sorry
      _ < omega0 ^ (mu n + mu s + 6) + omega0 * (mu b + 1)        := sorry
      _ < omega0 ^ (omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + 6)
                   + omega0 * (mu b + 1)                          := sorry
      _ < omega0 ^ (omega0 ^ (5 : Ordinal) * (mu n + 1) + 1 + mu s + 6)
                   + omega0 * (mu b + 1) + 1                      := sorry
      _ < omega0 ^ (3 : Ordinal) * (mu s + 1)
          + omega0 ^ (2 : Ordinal) * (omega0 ^ (mu n + mu s + 6) + omega0 * (mu b + 1) + 1 + 1) + 1 := h_lhs_exp

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    simp [mu]
    -- Simple positivity: 0 < omega^(mu(a) + mu(a) + 9) + 1
    have h_pos : 0 < omega0 ^ (mu a + mu a + (9 : Ordinal)) := by
      apply opow_pos
      exact omega0_pos
    omega

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    simp [mu]
    -- Strategy: Show that omega^(mu(a) + mu(b) + 9) dominates
    -- omega^4 * (omega^3 * (mu(a) + 1) + omega^2 * (mu(b) + 1) + 2)
    have h_merge_bound : omega0 ^ (3 : Ordinal) * (mu a + 1) + omega0 ^ (2 : Ordinal) * (mu b + 1) + 2
                         < omega0 ^ (mu a + mu b + (9 : Ordinal)) := by
      -- The omega^3 term is bounded by omega^(mu(a) + 9)
      -- The omega^2 term is bounded by omega^(mu(b) + 9)
      -- Adding them stays below omega^(mu(a) + mu(b) + 9)
      sorry
    have h_integrate_bound : omega0 ^ (4 : Ordinal) * (omega0 ^ (3 : Ordinal) * (mu a + 1) 
                             + omega0 ^ (2 : Ordinal) * (mu b + 1) + 2)
                             < omega0 ^ (mu a + mu b + (9 : Ordinal)) := by
      calc omega0 ^ (4 : Ordinal) * (omega0 ^ (3 : Ordinal) * (mu a + 1) 
                                     + omega0 ^ (2 : Ordinal) * (mu b + 1) + 2)
         < omega0 ^ (4 : Ordinal) * omega0 ^ (mu a + mu b + (9 : Ordinal))
         := by apply mul_lt_mul_of_pos_left h_merge_bound; sorry
         _ = omega0 ^ (4 : Ordinal + mu a + mu b + (9 : Ordinal))
         := by rw [← opow_add]
         _ < omega0 ^ (mu a + mu b + (9 : Ordinal))
         := by sorry  -- 4 + mu(a) + mu(b) + 9 vs mu(a) + mu(b) + 9 requires care
    calc omega0 ^ (4 : Ordinal) * (omega0 ^ (3 : Ordinal) * (mu a + 1)
                                   + omega0 ^ (2 : Ordinal) * (mu b + 1) + 2) + 1
       < omega0 ^ (mu a + mu b + (9 : Ordinal)) + 1 := by omega
```

**Key strategies:**
- **R_rec_succ**: Use tower monotonicity; `omega^5 * (mu n + 1)` in the exponent dominates all RHS terms
- **R_eq_refl**: Direct positivity (omega base is positive)
- **R_eq_diff**: Show `omega^(mu a + mu b + 9)` dominates the `omega^4 * (...)` term; the main challenge is ordinal exponent comparison
