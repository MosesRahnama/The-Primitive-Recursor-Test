The system has rules:
- F(x, y, Z) -> x
- F(x, y, S(n)) -> G(F(x, y, n))

This is a simple terminating system. The F function case-splits on the third argument: if it's Z (zero), return x; if it's S(n), recurse on the smaller n and wrap in G.

Termination: measure on third argument (using a natural number interpretation where S(n) > n). Each recursive call F(x, y, S(n)) -> G(F(x, y, n)) strictly decreases the third argument. The base case F(x, y, Z) terminates. So strong normalization holds trivially — this is essentially structural recursion.

The only "object-level axiom" needed is the standard interpretation of Z and S as zero/successor, which is implicit in the pattern matching, but the rules themselves suffice to prove termination via a straightforward induction on the structure of the third argument.
