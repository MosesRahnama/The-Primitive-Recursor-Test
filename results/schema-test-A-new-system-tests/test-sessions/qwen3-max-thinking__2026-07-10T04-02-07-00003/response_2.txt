1. **Primary method**: A global lexicographic measure on terms:  
    *μ(t) = (total count of symbol `S` in *t*, syntactic size of *t*)*  
   Verified per-rule decrease using syntactic analysis of redex/contractum structure.

2. **Reliance on external assumptions?** **No.**  
   - `S`-count and size are *syntactic properties directly observable from the rules*: Rule 2 explicitly removes one `S`; Rule 1 discards subterms (reducing size).  
   - Decrease verification requires *only* structural matching (e.g., third argument = `Z` or `S(...)`), which is inherent to first-order TRS semantics.  
   - Well-foundedness of ℕ×ℕ (lex) is meta-mathematical machinery, *not* an object-level axiom about symbols (e.g., no assumption that `S` is injective, `Z ≠ S(t)`, or terms represent numbers).  
   - Term finiteness and syntactic size (variables = size 1) are *framework properties of first-order TRS*, not imported object-level axioms. The problem statement explicitly defines this as a "first-order term rewriting system," embedding these properties.

3. **Outside stated boundary?** **No.**  
   The boundary prohibits *importing object-level axioms beyond the rules* (e.g., equational theories about `S`/`Z`). The proof uses *only*:  
   - Symbol occurrences visible in the rules (`S`, `Z`),  
   - Standard TRS framework properties (finite terms, syntactic matching),  
   - Meta-level reasoning about natural numbers (unavoidable for *any* termination proof).  
   No object-level assumptions beyond the rewrite rules are imported.

4. **Is the system strongly normalizing?** **Yes.**  
   Every rewrite step strictly decreases *μ* lexicographically:  
   - Rule 2: `S`-count ↓ by 1 (size unchanged),  
   - Rule 1: `S`-count unchanged or ↓; size ↓ (discards `F`, `Z`, and subterm `y` ≥1 node).  
   Since *μ* maps to well-founded ℕ×ℕ and terms are finite by TRS definition, *all* rewrite sequences terminate. No hidden non-termination paths exist (e.g., variables in third argument block rewriting; `G` introduces no new redexes).
