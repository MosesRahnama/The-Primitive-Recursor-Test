### Proof of Strong Normalization

We can prove termination using two standard, self-contained methods:

#### Method 1: Multiset Path Ordering (MPO)
We can define a Multiset Path Ordering ($>_{mpo}$) with the precedence $F > G$. 

1. **Rule 1:** `F(x, y, Z) -> x`
   * Under MPO, $F(x, y, Z) >_{mpo} x$ holds because $x$ is a strict subterm of the left-hand side.
   
2. **Rule 2:** `F(x, y, S(n)) -> G(F(x, y, n))`
   * Since $F > G$, to show $F(x, y, S(n)) >_{mpo} G(F(x, y, n))$ we must show that $F(x, y, S(n)) >_{mpo} F(x, y, n)$.
   * By the definition of MPO, $F(x, y, S(n)) >_{mpo} F(x, y, n)$ reduces to comparing their arguments as multisets: $\{x, y, S(n)\} >_{mul} \{x, y, n\}$.
   * After removing the common elements $x$ and $y$, we compare $\{S(n)\} >_{mul} \{n\}$, which holds because $S(n) >_{mpo} n$ (since $n$ is a strict subterm of $S(n)$).

Both rules are strictly oriented, which proves that the system is strongly normalizing.

#### Method 2: Polynomial Interpretation
Alternatively, we can map terms to the well-founded domain of natural numbers $(\mathbb{N}, >)$ using a strictly monotonic polynomial interpretation $[\cdot]$:

* $[Z] = 0$
* $[S(t)] = [t] + 1$
* $[G(t)] = [t]$
* $[F(t_1, t_2, t_3)] = [t_1] + [t_2] + [t_3] + 1$

We check both rules to ensure the left-hand side is strictly greater than the right-hand side for all variables in $\mathbb{N}$:

1. **Rule 1:** `F(x, y, Z) -> x`
   $$\begin{aligned}
   [F(x, y, Z)] &= x + y + [Z] + 1 \\
   &= x + y + 1
   \end{aligned}$$
   Since $y \ge 0$, we have $x + y + 1 > x$. Thus, $[LHS] > [RHS]$.

2. **Rule 2:** `F(x, y, S(n)) -> G(F(x, y, n))`
   $$\begin{aligned}
   [F(x, y, S(n))] &= x + y + (n + 1) + 1 \\
   &= x + y + n + 2
   \end{aligned}$$
   $$\begin{aligned}
   [G(F(x, y, n))] &= [F(x, y, n)] \\
   &= x + y + n + 1
   \end{aligned}$$
   Since $x + y + n + 2 > x + y + n + 1$, we have $[LHS] > [RHS]$.

Since all functions are interpreted as strictly monotonic polynomials on the natural numbers and every reduction step strictly decreases the value, infinite rewrite sequences are impossible. Thus, the system is strongly normalizing.
