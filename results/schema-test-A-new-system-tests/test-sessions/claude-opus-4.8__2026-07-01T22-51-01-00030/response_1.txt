# Assessment

**Yes, strong normalization can be established from the rewrite system alone.**

## Reasoning

The system has two rules:
1. `F(x, y, Z) -> x`
2. `F(x, y, S(n)) -> G(F(x, y, n))`

**Key structural observation:** In rule 2, the recursive call `F(x, y, n)` occurs with `n` as a strict subterm of `S(n)`. The rewrite strictly decreases the third argument's `S`-structure while introducing only a `G` wrapper (which contains no `F` symbol that could re-trigger a rewrite in a growing way).

**A simple measure argument suffices.** Define a weight/interpretation that is monotone and strictly decreasing under both rules:

Let each term be interpreted over the naturals with:
- `[Z] = 1`
- `[S(t)] = [t] + 1`
- `[G(t)] = [t]`
- `[F(t₁, t₂, t₃)] = [t₁] + [t₃]` (or more carefully, a lexicographic/polynomial interpretation)

Checking the rules under a polynomial interpretation, e.g.:
- `[F(x,y,z)] = x + 2z`, `[G(z)] = z + 1`, `[S(z)] = z + 1`, `[Z] = 0` (constants ≥ 0):

Rule 1: `[F(x,y,Z)] = x + 0 = x` vs `[x] = x`. Need strict decrease; adjust so `[F(x,y,z)] = x + 2z + 1 > x`. ✓

Rule 2: `[F(x,y,S(n))] = x + 2(n+1) + 1 = x + 2n + 3` vs `[G(F(x,y,n))] = (x + 2n + 1) + 1 = x + 2n + 2`. Strict decrease `x+2n+3 > x+2n+2`. ✓

Both rules strictly decrease under this monotone polynomial interpretation over ℕ, which is a well-founded ordering. Since the interpretation is monotone in all argument positions, it is a **reduction ordering**, giving termination.

## Why no external axioms are needed

- There is **no critical overlap** between the rules causing non-terminating loops.
- The recursion in rule 2 is **structurally decreasing** on the third argument (`S(n) → n`), and the introduced `G` is a passive constructor that cannot regenerate an `F` redex.
- The termination certificate (the polynomial interpretation above) is derived purely from the syntactic form of the rules. No structural induction principles, no imported object-level assumptions, and no additional term-structure axioms are required — the well-foundedness comes from the standard ordering on ℕ used in the interpretation, which is part of the standard termination-proving machinery, not an object-level assumption about the system.

**Conclusion:** Strong normalization follows directly from the given rules via a monotone polynomial interpretation (or equivalently a simple structural measure on the third argument), with no need to import anything beyond what the rules present.
