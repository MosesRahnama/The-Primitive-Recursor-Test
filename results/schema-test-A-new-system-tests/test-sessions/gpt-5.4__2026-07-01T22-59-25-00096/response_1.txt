Yes — strong normalization can be established from the rewrite system alone.

Reasoning, briefly:

- The only recursive rule is  
  `F(x, y, S(n)) -> G(F(x, y, n))`.
- This strictly decreases the third argument of `F` from `S(n)` to `n`.
- The base case is  
  `F(x, y, Z) -> x`,
  which removes the `F` entirely.
- There are no rewrite rules for `G`, `S`, or `Z`, and no rule rewrites variables or introduces a larger third argument again.

So every rewrite sequence starting from a term with an `F` can only peel off finitely many `S` constructors before reaching `Z`, after which no further `F`-rewrite is possible. Since no cycle or self-reproduction at equal/greater size is present, infinite reductions cannot be generated.

Caveat: this conclusion is for the presented first-order TRS itself. If one allowed arbitrary non-normalizing substitutions for variables from some external system, that would be extra structure not present here. Under ordinary TRS reading, the system is strongly normalizing.
