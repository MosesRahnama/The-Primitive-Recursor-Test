Yes — from the rewrite rules alone, strong normalization can be established.

Reasoning, briefly:
- The only recursive rule is  
  `F(x, y, S(n)) -> G(F(x, y, n))`.
- This strictly decreases the third argument of `F` from `S(n)` to `n`.
- The base case  
  `F(x, y, Z) -> x`
  stops the recursion.
- There are no rewrite rules for `G`, `S`, or `Z`, so they cannot generate new redexes that would restart or extend the recursion indefinitely.

A simple measure is: count the number of `S` constructors in the third argument of every reducible `F`. Each rewrite of an `F(..., S(n))` reduces that count by 1, and eventually one reaches `F(..., Z)`, which rewrites to `x`. Since no rule increases this measure or creates a cycle, there cannot be an infinite rewrite sequence.

So the system is strongly normalizing on its own.
