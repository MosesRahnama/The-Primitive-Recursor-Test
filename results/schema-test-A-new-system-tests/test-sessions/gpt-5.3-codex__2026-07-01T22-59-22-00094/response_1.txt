Yes — **strong normalization can be established from these rules alone**.

Reason (briefly): the only recursive rewrite is

- `F(x, y, S(n)) -> G(F(x, y, n))`

which strictly decreases the third argument of `F` from `S(n)` to `n`.  
The base case

- `F(x, y, Z) -> x`

stops that recursion. There are **no rules rewriting `G(...)`**, and no rule introduces a larger third argument again. So every rewrite sequence starting from a finite term can only peel off finitely many `S` constructors, then terminate.

A simple measure like “number of `S` constructors in third arguments of reducible `F`-redexes” decreases to zero, so infinite reductions are impossible.
