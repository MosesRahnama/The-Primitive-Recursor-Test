The system has two rules:
- F(x, y, Z) -> x
- F(x, y, S(n)) -> G(F(x, y, n))

Variables: x, y, n. No rule mentions G on the left-hand side. So G only appears on right-hand sides, never on left-hand sides. Therefore G is a constructor (a free symbol) - no rewrite rule can be applied to G(...).

Strong normalization: every reduction sequence terminates.

Starting from F(x, y, S(n)) - this reduces to G(F(x, y, n)). The inner F(x, y, n) can be reduced if n is Z (giving x) or another S (giving G(F(...))). The outer G cannot be reduced.

So consider a term like F(x, y, S(S(S(...S(Z))...))). The reductions will eventually produce G(G(G(...G(x)...))). Each step reduces the S-argument. The reduction sequence is bounded by the number of S constructors, so it terminates.

For any term, we can define a measure. The termination is clear: F(x,y,Z) terminates in 1 step, F(x,y,S(n)) reduces to G(F(x,y,n)) which is a smaller F-application (in terms of the size of the third argument), and G has no rules.

So yes, strong normalization can be established from the rules alone. The rewrite system is strongly normalizing.
