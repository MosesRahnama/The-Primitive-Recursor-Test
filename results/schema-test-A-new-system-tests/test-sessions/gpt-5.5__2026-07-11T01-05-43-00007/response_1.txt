Yes. Strong normalization can be established from the presented rewrite system alone.

Reasoning: the only potentially recursive rule is

```text
F(x, y, S(n)) -> G(F(x, y, n))
```

This decreases the third argument of `F` from `S(n)` to `n`. Although it adds a `G` wrapper, there is no rule for reducing or eliminating `G`, and no rule that reconstructs a larger `S`-argument for `F`. The base rule

```text
F(x, y, Z) -> x
```

terminates immediately.

A standard syntactic termination argument suffices, for example using a recursive path ordering with precedence such as

```text
F > G
S > ...
```

or a custom measure counting the depth of `S` in the third argument of reducible `F`-terms. Each use of the second rule strictly decreases that depth for the relevant `F`, and the first rule removes an `F`-redex entirely.

So, without assuming any extra arithmetic axioms for `Z`/`S`, structural equations, or object-level semantics, the TRS is strongly normalizing.
