## Assessment

**Yes — strong normalization can be established from the presented system alone.**

## Reasoning

The system has two rules:

```
F(x, y, Z)    -> x
F(x, y, S(n)) -> G(F(x, y, n))
```

**Key observation:** The third argument of `F` strictly controls recursion, and it strictly decreases in the recursive rule.

Consider any term. The only rewrite rules apply to `F`-redexes. Look at what happens in each rule:

1. `F(x, y, Z) -> x`: The redex is *eliminated* entirely; the result `x` is a subterm of the redex, containing no new `F` symbol introduced by the rule.
2. `F(x, y, S(n)) -> G(F(x, y, n))`: The `F` on the left is reproduced on the right, but its third argument shrinks from `S(n)` to `n` — one `S` layer is peeled off — and a `G` (a symbol not on any left-hand side) is wrapped around it.

**Termination argument (multiset / structural measure):**

Assign to each `F`-subterm a weight equal to the size (number of `S`/`Z` constructor symbols) of its third argument. Take the multiset of these weights over all `F`-occurrences in a term.

- Rule 2 replaces an `F` with third argument `S(n)` by an `F` with third argument `n`: this strictly decreases that occurrence's measure (removes one `S`), and introduces no new `F`. The surrounding `G` is inert (never a redex root and appears on no left-hand side).
- Rule 1 removes an `F`-occurrence altogether and introduces no `F`.

In both cases the multiset of third-argument sizes strictly decreases under the well-founded multiset ordering over ℕ. Substitutions cannot increase this measure in a way that breaks it: the third argument `S(n)`/`Z`/`n` positions match constructor patterns, and rewriting only ever reduces the constructor depth there.

Since:
- there is no variable binding,
- `G` is a free constructor (never a defined symbol / never the root of a redex, so it cannot regenerate work),
- no rule increases the constructor-depth of any `F`'s third argument,

every reduction strictly decreases a well-founded measure. Hence **no infinite reduction sequence exists → strong normalization holds.**

This is derivable purely from the shown rules — the needed facts (well-foundedness of ℕ / multisets, structural decrease of `S(n) → n`) are consequences of the rule shapes themselves, not imported object-level axioms.

**A standard tool confirms this cheaply:** even a simple lexicographic path ordering or polynomial interpretation (e.g. `[F](x,y,z) = x + y + z + 1`, `[S](z) = z+1`, `[G](z) = z`, `[Z] = 0`) orients both rules strictly, giving termination without any external assumptions.
