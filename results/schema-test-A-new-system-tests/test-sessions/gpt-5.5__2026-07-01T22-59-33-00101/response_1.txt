Yes — strong normalization/termination can be established from the presented first-order rewrite system alone.

Reasoning: the only recursive rule is

```txt
F(x, y, S(n)) -> G(F(x, y, n))
```

It strips one outer `S` from the third argument of `F` and wraps the result in `G`. Since there are no rewrite rules for `G`, the added `G` does not create a new way to continue expanding forever. Rewriting may still proceed inside `G`, but the recursive `F` call has a strictly smaller third argument.

A standard syntactic termination order proves this directly. For example, use a lexicographic path order with precedence

```txt
F > G
```

and the usual subterm property, so `S(n) > n`. Then:

```txt
F(x, y, Z) -> x
```

decreases because `x` is a subterm of the left-hand side.

And:

```txt
F(x, y, S(n)) -> G(F(x, y, n))
```

decreases because the root symbol `F` is greater than `G`, and also

```txt
F(x, y, S(n)) > F(x, y, n)
```

since the third argument decreases from `S(n)` to `n`.

Thus the rules are oriented by a well-founded reduction order, so there is no infinite rewrite sequence over finite first-order terms. No structural axioms, semantic assumptions about naturals, or external object-level equations are needed.
