Yes — **strong normalization can be established from these rules alone**.

Reason (briefly):  
The only recursive step is

\[
F(x,y,S(n)) \to G(F(x,y,n)),
\]

which strictly decreases the third argument of `F` from `S(n)` to `n`. So each such rewrite reduces the number of surrounding `S` constructors by 1. When that argument reaches `Z`, the base rule applies:

\[
F(x,y,Z) \to x,
\]

and no further `F`-rule applies. `G(...)` has no rewrite rules, so it cannot create new redexes or restart recursion. Thus there is no infinite rewrite sequence.

So from the presented TRS itself, SN holds.
