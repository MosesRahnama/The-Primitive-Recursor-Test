**Yes**

A multiset measure on term sizes works: collect the size of the third argument of every F-subterm occurrence (size is ordinary syntactic term size). Each rule application strictly decreases this multiset under the multiset extension of > on naturals:

- For F(x, y, Z) → x the redex contributes size(Z); it is removed from the multiset. Any enclosing F whose third-argument size included the redex has that size decreased (size(F(...)) > size(x)). All other F-occurrences are unchanged, so the multiset decreases.
- For F(x, y, S(n)) → G(F(x, y, n)) the redex contributes size(S(n)); this is replaced by size(n) (strictly smaller by 1). If the redex occurs inside another F's third argument, that outer size is unchanged (both sides have identical size 2 + |x| + |y| + |n|). All other contributions are identical, so the multiset decreases.

The multiset order is well-founded on finite terms, so no infinite reduction sequence exists. The argument uses only the shapes of the two given rules, the syntax of terms, and the fact that no other rules are present; nothing about Z/S being constructors, no typing, no external induction principle, and no equational axioms beyond the rewrite relation itself is required.
