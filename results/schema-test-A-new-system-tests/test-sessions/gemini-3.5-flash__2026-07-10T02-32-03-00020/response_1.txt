We can prove termination using standard, well-known techniques such as the **Lexicographic Path Ordering (LPO)** or a **Polynomial Interpretation**.

By defining a precedence relation on the function symbols where $F \succ G$, we can show that both rules strictly decrease under LPO ($\succ_{lpo}$):

1. **Rule 1:** `F(x, y, Z) -> x`

2. **Rule 2:** `F(x, y, S(n)) -> G(F(x, y, n))`
   * $F(x, y, S(n)) \succ_{lpo} G(F(x, y, n))$ holds because:
     * $F \succ G$, and
     * $F(x, y, S(n)) \succ_{lpo} F(x, y, n)$, which is true because the arguments lexicographically decrease ($S(n) \succ_{lpo} n$ by the subterm property).

### Proof via Polynomial Interpretation
Alternatively, we can define a polynomial interpretation over the natural numbers $\mathbb{N}_{\ge 1}$ as follows:
* $[Z] = 1$
* $[S](n) = n + 1$
* $[G](x) = x$
* $[F](x, y, n) = x + y + n$

Applying this mapping to the rules:
1. **Rule 1:** $[F(x, y, Z)] = x + y + 1 > x$ (strictly decreasing for all $y \ge 1$)
2. **Rule 2:** $[F(x, y, S(n))] = x + y + n + 1 > [G(F(x, y, n))] = x + y + n$ (strictly decreasing)

Since the interpretations of all function symbols are monotonic and well-founded, the system is strongly normalizing.
