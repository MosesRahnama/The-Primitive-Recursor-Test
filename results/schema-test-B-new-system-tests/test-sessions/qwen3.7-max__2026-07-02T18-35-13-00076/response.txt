# Analysis of Termination Proof Methods

## System Analysis

The TRS has two rules:
1. `F(x, y, Z) → x`
2. `F(x, y, S(n)) → G(y, F(x, y, n))`

F recurses on its third argument (a Peano natural number), stripping one `S` per step until reaching `Z`.

---

## Method-by-Method Evaluation

### (A) LPO with precedence F > G > S > Z

**Rule 1:** `F(x, y, Z) → x` — `x` is a proper subterm of the LHS, so `F(x,y,Z) >_lpo x` by the subterm condition. ✓

**Rule 2:** `F(x, y, S(n)) → G(y, F(x, y, n))` — Since `F > G`, LPO requires `F(x,y,S(n)) >_lpo y` (holds: subterm) and `F(x,y,S(n)) >_lpo F(x,y,n)`. For the latter, same head symbol `F` triggers lexicographic comparison: `(x, y, S(n)) >_lex (x, y, n)` because `x=x`, `y=y`, and `S(n) >_lpo n` (subterm). The side condition `F(x,y,S(n)) >_lpo t_i` for each argument `t_i ∈ {x, y, n}` also holds since all are variables occurring in the LHS. ✓

**Succeeds:** Yes. **Within boundary:** Yes.

---

### (B) Nonlinear polynomial interpretation

- `[F(x,y,Z)] = x + (y+1)(0+1) = x + y + 1 > x` since `y + 1 ≥ 1`. ✓
- `[F(x,y,S(n))] = x + (y+1)(n+2)`
- `[G(y, F(x,y,n))] = y + x + (y+1)(n+1)`
- Difference: `(y+1)(n+2) − y − (y+1)(n+1) = (y+1) − y = 1 > 0`. ✓

Monotonicity holds since all partial derivatives are strictly positive over ℕ.

**Succeeds:** Yes. **Within boundary:** Yes.

---

### (C) MPO with precedence F > G > S > Z

**Rule 1:** Same as LPO. ✓

**Rule 2:** Since `F > G`, MPO requires `F(x,y,S(n)) >_mpo y` (subterm) and `F(x,y,S(n)) >_mpo F(x,y,n)`. For the latter, same head `F` triggers multiset comparison: `{x, y, S(n)} >_mul {x, y, n}`. Choosing `X = {S(n)}`, `Y = {n}`, we need `S(n) >_mpo n`, which holds by the subterm condition. The side conditions `F(x,y,S(n)) >_mpo t_i` for `t_i ∈ {x, y, n}` all hold. ✓

**Succeeds:** Yes. **Within boundary:** Yes.

---

### (D) Dependency pairs with subterm criterion

The only defined symbol is `F`. The only dependency pair generated is:
`F♯(x, y, S(n)) → F♯(x, y, n)`

Projection `π(F♯) = 3` gives:
- `π(LHS) = S(n)`
- `π(RHS) = n`
- `S(n) ⊳ n` (proper subterm) ✓

The subterm criterion removes all dependency pairs, leaving `P = ∅`. No infinite chains are possible.

**Succeeds:** Yes. **Within boundary:** Yes.

---

### (E) Exponential interpretation

- `[F(x,y,Z)] = (x+y+2)^1 = x + y + 2 > x` since `y + 2 ≥ 2`. ✓
- `[F(x,y,S(n))] = (x+y+2)^{n+2}`
- `[G(y, F(x,y,n))] = y + (x+y+2)^{n+1}`
- Let `b = x + y + 2 ≥ 2`. Difference: `b^{n+2} − b^{n+1} − y = b^{n+1}(b−1) − y`.
  Since `b−1 = x+y+1 ≥ y+1` and `b^{n+1} ≥ 2`, we get `b^{n+1}(b−1) ≥ 2(y+1) = 2y+2 > y`. ✓

Monotonicity holds: all partial derivatives are strictly positive over ℕ.

**Succeeds:** Yes. **Within boundary:** Yes.

---

## Conclusion

**All five methods (A), (B), (C), (D), and (E) satisfy both conditions.** Each successfully proves termination of the system, and each operates purely from the rewrite rules without importing external structural axioms or object-level assumptions.
