# Analysis of Each Method

## (A) LPO with precedence F > G > S > Z

**Termination proof:**
- `F(x, y, Z) → x`: F > x in the quasi-precedence (function symbol > variable), and x is a subterm variable of F(x, y, Z). ✓
- `F(x, y, S(n)) → G(y, F(x, y, n))`: F > G in the precedence, and F(x, y, S(n)) > y (y is a subterm variable) and F(x, y, S(n)) > F(x, y, n) (by case 1: F(x,y,S(n)) > n since n is a subterm variable). ✓

**Benchmark:** Purely order-based, uses only the given rules. **Within boundary.**

**Succeeds: Yes.**

## (B) Nonlinear polynomial interpretation over N

**Termination proof:** The polynomial f(x,y,n) = x + (y+1)(n+1) is strictly monotone in each argument (∂/∂x=1, ∂/∂y=n+1, ∂/∂n=y+1, all positive on N). Then:
- f(x,y,0) = x + y + 1 > x. ✓
- f(x,y,n+1) − g(y, f(x,y,n)) = [x + (y+1)(n+2)] − [y + x + (y+1)(n+1)] = 1 > 0. ✓

**Benchmark:** Standard polynomial-interpretation machinery over N. **Within boundary.**

**Succeeds: Yes.**

## (C) MPO with precedence F > G > S > Z, all multiset

**Termination proof:**
- `F(x, y, Z) → x`: F is a defined symbol. x is a subterm variable. ✓
- `F(x, y, S(n)) → G(y, F(x, y, n))`: F is a defined symbol, so F(x,y,S(n)) > ti for each ti.
  - > y: y is a subterm variable. ✓
  - > F(x, y, n): F = F in precedence, multiset status. {x, y, S(n)} >M {x, y, n} because S(n) > n (n is a subterm variable of S(n), and S > n). ✓

**Benchmark:** Purely order-based. **Within boundary.**

**Succeeds: Yes.**

## (D) Dependency pairs with subterm criterion (third-argument projection)

**Termination proof:** G has no rules, so it is not a defined symbol. The only DP is:
`F#(x, y, S(n)) → F#(x, y, n)`
The right-hand side F#(x,y,n) is a strict subterm of the left-hand side F#(x,y,S(n)). Projecting to the third argument gives π(LHS) = S(n) > π(RHS) = n in the subterm order, so the chain is decreasing.

**Benchmark:** The DP framework is applied directly to the given rules; no external structure about F, G, S, Z is assumed. **Within boundary.**

**Succeeds: Yes.**

## (E) Exponential interpretation over N

**Termination proof:** Each polynomial is strictly monotone in every argument on N.
- f(x,y,0) = (x+y+2) > x. ✓
- f(x,y,n+1) − g(y, f(x,y,n)) = (x+y+2)^(n+1) · (x+y+1) − y. For x, y, n ∈ N, the left factor is at least (x+y+2) ≥ 2 and the right factor at least 1, so the product is at least (x+y+2)(x+y+1) = u² + 3u + 2 ≥ y + 2 for all u = x+y ≥ 0. Hence strictly positive. ✓

**Benchmark:** Same general framework as (B); standard well-founded monotone N-algebra. **Within boundary.**

**Succeeds: Yes.**
