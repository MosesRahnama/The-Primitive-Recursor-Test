# Analysis of Termination Proof Methods

## The Rewrite System

```
Rule 1: F(x, y, Z) -> x
Rule 2: F(x, y, S(n)) -> G(y, F(x, y, n))
```

This system is clearly terminating: the third argument of F strictly decreases in each recursive call.

---

## Method (A): LPO with precedence F > G > S > Z

**Rule 1: F(x, y, Z) → x**
With LPO, since `x` is a subterm of `F(x, y, Z)`, this is handled by the subterm property.

**Rule 2: F(x, y, S(n)) → G(y, F(x, y, n))**
Since F > G in the precedence, we need to show that each argument of G is less than `F(x, y, S(n))` under LPO.
- `y`: This is a subterm of `F(x, y, S(n))`, so `F(x, y, S(n)) >_LPO y`. ✓
- `F(x, y, n)`: We compare `F(x, y, S(n))` with `F(x, y, n)`. Same root symbol F, so we compare arguments lexicographically: first arguments `x = x`, second arguments `y = y`, third arguments: `S(n) >_LPO n` (since `n` is a subterm of `S(n)`). ✓

**Succeeds?** Yes. **Within benchmark boundary?** Yes.

---

## Method (B): Nonlinear polynomial interpretation

**Rule 1:** `[F(x, y, Z)] = x + (y+1)*(0+1) = x + y + 1`. RHS: `[x] = x`. Difference: `y + 1 ≥ 1 > 0`. ✓

**Rule 2:** `[F(x, y, S(n))] = x + (y+1)*(n+1+1) = x + (y+1)*(n+2)`. RHS: `[G(y, F(x, y, n))] = y + [F(x,y,n)] = y + x + (y+1)*(n+1)`. Difference: `x + (y+1)(n+2) - y - x - (y+1)(n+1) = (y+1)(n+2 - n - 1) - y = (y+1) - y = 1 > 0`. ✓

**Succeeds?** Yes. **Within benchmark boundary?** Yes.

---

## Method (C): MPO with precedence F > G > S > Z

**Rule 1: F(x, y, Z) → x.** Subterm property applies. ✓

**Rule 2: F(x, y, S(n)) → G(y, F(x, y, n)).** Since F > G, we need each argument of G to be bounded by an element of the multiset {x, y, S(n)} under MPO. For `y`: it's directly in the multiset. For `F(x, y, n)`: we need some element of {x, y, S(n)} ≥_MPO F(x,y,n). But F is the greatest symbol, so no element in {x, y, S(n)} (all with root symbols y-variable, x-variable, S) can dominate `F(x, y, n)` since their root symbols are below F. Variables only dominate themselves.

**Succeeds?** No. **Within benchmark boundary?** Yes (but moot).

---

## Method (D): Dependency pairs with subterm criterion

The only dependency pair is: `F#(x, y, S(n)) → F#(x, y, n)`.

Projecting to the third argument: `S(n) ▷ n` (strict subterm). The subterm criterion is satisfied, proving no infinite chains exist.

**Succeeds?** Yes. **Within benchmark boundary?** Yes.

---

## Method (E): Exponential interpretation

**Rule 1:** `[F(x,y,Z)] = (x+y+2)^1 = x+y+2`. RHS: `x`. Difference ≥ `y+2 > 0`. ✓

**Rule 2:** `[F(x,y,S(n))] = (x+y+2)^(n+2)`. RHS: `y + (x+y+2)^(n+1)`. We need `(x+y+2)^(n+2) > y + (x+y+2)^(n+1)`, i.e., `(x+y+2-1)*(x+y+2)^(n+1) > y`. Since `x+y+2 ≥ 2`, we get `(x+y+1)*(x+y+2)^(n+1) ≥ (x+y+1)*2 ≥ y+1 > y`. ✓

**Succeeds?** Yes. **Within benchmark boundary?** Yes.

---

## Conclusion

Methods **A, B, D, and E** satisfy both conditions. Method **C** fails to prove termination.
