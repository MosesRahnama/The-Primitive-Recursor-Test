# Analysis of the Term Rewriting System

## The System

```
F(x, y, Z)     → x
F(x, y, S(n))  → G(y, F(x, y, n))
```

The function F recurses on its third argument (a natural number encoded as Z/S). Each recursive call strictly decreases that argument, so the system is terminating.

---

## Method-by-Method Evaluation

### (A) LPO with precedence F > G > S > Z

**Rule 1:** `F(x, y, Z) → x`
`x` is a proper subterm of the LHS, so `F(x,y,Z) >_{lpo} x` holds by the subterm property.

**Rule 2:** `F(x, y, S(n)) → G(y, F(x, y, n))`
Since `F > G`, we must show the LHS dominates each argument of the RHS:
- `F(x,y,S(n)) > y` — subterm, holds.
- `F(x,y,S(n)) > F(x,y,n)` — same head symbol `F`, so compare lexicographically:
  - Position 1: `x = x`
  - Position 2: `y = y`
  - Position 3: `S(n) >_{lpo} n` — holds because `n` is a proper subterm of `S(n)`.
  - Subterm checks (`LHS > x, y, n`): all hold since each is a subterm.

**Result:** Succeeds. Stays within boundary.

---

### (B) Nonlinear polynomial interpretation

`[F(x,y,n)] = x + (y+1)(n+1)`, `[S(n)] = n+1`, `[G(a,b)] = a+b`, `[Z] = 0`

**Rule 1:** `x + (y+1)(0+1) = x + y + 1 > x` since `y + 1 ≥ 1`.

**Rule 2:**
- LHS: `x + (y+1)(n+2) = x + yn + 2y + n + 2`
- RHS: `y + x + (y+1)(n+1) = x + yn + 2y + n + 1`
- Difference: `LHS − RHS = 1 > 0`.

Monotonicity holds in all arguments (all partial derivatives/coefficients are strictly positive over ℕ).

**Result:** Succeeds. Stays within boundary.

---

### (C) MPO with precedence F > G > S > Z, multiset argument comparison

**Rule 1:** Same as LPO — subterm property.

**Rule 2:** Since `F > G`, we need `F(x,y,S(n)) > F(x,y,n)` via multiset comparison:
- Compare `{x, y, S(n)}` vs `{x, y, n}`.
- Remove `S(n)`, replace with `n`; require `S(n) >_{mpo} n` — holds by subterm property.
- Subterm checks on RHS arguments all pass.

**Result:** Succeeds. Stays within boundary.

---

### (D) Dependency pairs with subterm criterion, projecting to 3rd argument of F

**Dependency pairs:** The only defined root symbol on an RHS is `F` in Rule 2, yielding one DP:

```
F#(x, y, S(n)) → F#(x, y, n)
```

(Rule 1's RHS is a variable, producing no DP.)

**Subterm criterion** with projection `π(F#) = 3`:
- `π(LHS) = S(n)`
- `π(RHS) = n`
- `S(n) ▷ n` (proper subterm) — the criterion is satisfied.

The single DP is removed, leaving an empty DP problem, which trivially proves termination. (Additionally, no chain edges exist since `F(x,y,n)` can never rewrite to a term with `F` at the root.)

**Result:** Succeeds. Stays within boundary.

---

### (E) Exponential interpretation

`[F(x,y,n)] = (x+y+2)^{n+1}`, `[S(n)] = n+1`, `[G(a,b)] = a+b`, `[Z] = 0`

**Rule 1:** `(x+y+2)^1 = x+y+2 > x` since `y+2 ≥ 2`.

**Rule 2:** Let `B = x+y+2 ≥ 2`.
- LHS: `B^{n+2} = B · B^{n+1}`
- RHS: `y + B^{n+1}`
- `LHS − RHS = (B−1)·B^{n+1} − y`
- Since `B ≥ y+2`, we get `B−1 ≥ y+1` and `B^{n+1} ≥ 2`, so:
  `(B−1)·B^{n+1} ≥ 2(y+1) = 2y+2 > y`.

Monotonicity holds: the base `B ≥ 2 > 1` ensures monotonicity in `n`; partial derivatives w.r.t. `x` and `y` are `(n+1)·B^n > 0`.

**Result:** Succeeds. Stays within boundary.
