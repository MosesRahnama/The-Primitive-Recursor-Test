## Quick justification per method

### (A) LPO
Rules:
- `F(x,y,Z) -> x` : `F(x,y,Z) > x` by subterm/variable occurrence.
- `F(x,y,S(n)) -> G(y,F(x,y,n))` :
  - `F(x,y,S(n)) > y`
  - `F(x,y,S(n)) > F(x,y,n)` since same root `F` and `S(n) > n`
  - with `F > G`, conclude `F(x,y,S(n)) > G(y,F(x,y,n))`

So **A succeeds**.

Boundary: the proof relies on the **chosen precedence** `F > G > S > Z`, which is an external global ordering choice, so **outside**.

---

### (B) Polynomial interpretation
Given:
- `[F(x,y,n)] = x + (y+1)(n+1)`
- `[S(n)] = n+1`
- `[G(a,b)] = a+b`
- `[Z] = 0`

Check rules:

1. `F(x,y,Z) -> x`
   - LHS = `x + (y+1)(0+1) = x+y+1 > x`

2. `F(x,y,S(n)) -> G(y,F(x,y,n))`
   - LHS = `x + (y+1)(n+2)`
   - RHS = `y + x + (y+1)(n+1)`
   - Difference = `1`

So **B succeeds**.

Boundary: it uses a **specific imported arithmetic interpretation over** `N`, so **outside**.

---

### (C) MPO
- `F(x,y,Z) -> x` works by subterm/variable occurrence.
- For `F(x,y,S(n)) -> G(y,F(x,y,n))`:
  - `F(x,y,S(n)) > y`
  - `F(x,y,S(n)) > F(x,y,n)` because with multiset status,
    `{x,y,S(n)} >mul {x,y,n}` via `S(n) > n`
  - with `F > G`, conclude the full rule

So **C succeeds**.

Boundary: again relies on an externally selected **precedence**, so **outside**.

---

### (D) Dependency pairs + subterm criterion
Only recursive call is in the second rule, yielding the dependency pair:
- `F#(x,y,S(n)) -> F#(x,y,n)`

Project to the third argument:
- left projection = `S(n)`
- right projection = `n`

And `S(n)` is a proper superterm of `n`, so the subterm criterion applies. Hence the DP problem is chain-free, so termination follows.

So **D succeeds**.

Boundary: under your **narrow** notion, I would count this as **inside** the boundary, because it uses the structural decrease already visible in the given rule rather than importing an external precedence/algebra.  
(If one treated every projection function as an arbitrary global choice, this would become borderline; under your instruction, the natural reading is **inside**.)

---

### (E) Exponential interpretation
Given:
- `[F(x,y,n)] = (x+y+2)^(n+1)`
- `[S(n)] = n+1`
- `[G(a,b)] = a+b`
- `[Z] = 0`

Check rules:

1. `F(x,y,Z) -> x`
   - LHS = `(x+y+2)^1 = x+y+2 > x`

2. `F(x,y,S(n)) -> G(y,F(x,y,n))`
   - LHS = `(x+y+2)^(n+2)`
   - RHS = `y + (x+y+2)^(n+1)`
   - Difference:
     \[
     (x+y+2)^{n+1}(x+y+1) - y \ge 1
     \]
   so strict decrease holds.

So **E succeeds**.

Boundary: it imports a **specific exponential arithmetic interpretation**, so **outside**.
