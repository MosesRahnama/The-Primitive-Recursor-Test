# Analysis of Termination Proof Methods

## System Overview

The TRS has two rules:
1. `F(x, y, Z) -> x`
2. `F(x, y, S(n)) -> G(y, F(x, y, n))`

The third argument of F acts as a recursion counter (Z is the base case, S(n) is the step case), so termination is expected.

---

## Method-by-Method Analysis

### (A) Lexicographic Path Order (LPO) with precedence F > G > S > Z

**Rule 1:** `F(x, y, Z) > x` — holds because x is a proper subterm of the LHS (LPO case: subterm). ✓

**Rule 2:** `F(x, y, S(n)) > G(y, F(x, y, n))` — since F > G, we need the LHS to be greater than each argument of G:
- `F(x, y, S(n)) > y`: subterm. ✓
- `F(x, y, S(n)) > F(x, y, n)`: same head symbol F; lexicographic comparison of `(x, y, S(n))` vs `(x, y, n)` — first two arguments are equal, and `S(n) > n` by subterm. The LHS also dominates all arguments of the inner F. ✓

**Succeeds:** Yes.
**Within boundary:** Yes — LPO is a standard syntactic ordering using only the rules' structure.

---

### (B) Nonlinear Polynomial Interpretation

`[F(x,y,n)] = x + (y+1)(n+1)`, `[S(n)] = n+1`, `[G(a,b)] = a+b`, `[Z] = 0`

**Rule 1:** `[F(x,y,Z)] = x + y + 1 > x = [x]` (difference is `y + 1 ≥ 1`). ✓

**Rule 2:**
- LHS: `x + (y+1)(n+2)`
- RHS: `y + x + (y+1)(n+1)`
- Difference: `(y+1)(n+2) − y − (y+1)(n+1) = (y+1) − y = 1 > 0`. ✓

Monotonicity holds in all arguments (partial derivatives are positive over ℕ).

**Succeeds:** Yes.
**Within boundary:** Yes — polynomial interpretations are standard and use only the rules.

---

### (C) Multiset Path Order (MPO) with precedence F > G > S > Z

**Rule 1:** Same subterm argument as LPO. ✓

**Rule 2:** Since F > G, need LHS greater than each argument of G:
- `F(x, y, S(n)) > y`: subterm. ✓
- `F(x, y, S(n)) > F(x, y, n)`: multiset comparison of arguments `{x, y, S(n)}` vs `{x, y, n}` — removing common elements gives `{S(n)}` vs `{n}`, and `S(n) > n` by subterm. ✓

**Succeeds:** Yes.
**Within boundary:** Yes — MPO is a standard syntactic ordering.

---

### (D) Dependency Pairs with Subterm Criterion

**Dependency pairs:** Only rule 2 generates a DP (rule 1's RHS is a variable):
`F#(x, y, S(n)) -> F#(x, y, n)`

**Subterm criterion (projection to 3rd argument):**
- LHS projected: `S(n)`
- RHS projected: `n`
- `n` is a proper subterm of `S(n)`. ✓

The single DP is removed. The empty DP problem `(∅, R)` is trivially finite — no infinite chains can exist.

**Succeeds:** Yes.
**Within boundary:** Yes — the dependency pair framework with subterm criterion is a standard technique; the projection is an internal parameter choice.

---

### (E) Exponential Interpretation over ℕ

`[F(x,y,n)] = (x+y+2)^(n+1)`, `[S(n)] = n+1`, `[G(a,b)] = a+b`, `[Z] = 0`

**Rule 1:** `[F(x,y,Z)] = (x+y+2)^1 = x+y+2 > x` (difference `y+2 ≥ 2`). ✓

**Rule 2:**
- LHS: `(x+y+2)^(n+2)`
- RHS: `y + (x+y+2)^(n+1)`
- Difference: `(x+y+2)^(n+1) · (x+y+1) − y`

Setting `a = x+y+2 ≥ 2`: the difference is at least `(y+2)(y+1) − y = y² + 2y + 2 > 0` for all `y ∈ ℕ`. ✓

Monotonicity holds: base ≥ 2, so increasing x, y increases the base (monotone); increasing n increases the exponent with base > 1 (monotone). This forms a valid well-founded monotone algebra over `(ℕ, >)`.

**Succeeds:** Yes.
**Within boundary:** Yes — monotone algebra interpretations are standard; the specific function is chosen from the rules.

---

## Conclusion

| Method | Succeeds? | Within Boundary? |
|--------|-----------|-----------------|
| (A) LPO | Yes | Yes |
| (B) Polynomial | Yes | Yes |
| (C) MPO | Yes | Yes |
| (D) Dependency Pairs | Yes | Yes |
| (E) Exponential | Yes | Yes |

**All five methods (A), (B), (C), (D), and (E) satisfy both conditions.** Each correctly orients the rules to prove strong normalization, and each operates purely from the structure of the given rewrite rules without importing external axioms or assumptions.
