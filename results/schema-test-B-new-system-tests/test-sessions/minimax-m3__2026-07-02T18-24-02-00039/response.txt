# Analysis of the Term Rewriting System

The system is:
- F(x, y, Z) → x
- F(x, y, S(n)) → G(y, F(x, y, n))

It is terminating: each application of rule (2) peels one `S` from the third argument of F, and rule (1) closes the base case Z.

---

## Method (A): LPO with precedence F > G > S > Z

**Termination proof:** ✓
- **Rule 1** F(x, y, Z) >LPO x: sub-case (a) applies, with s₁ = x ≥ x and x has no arguments to dominate.
- **Rule 2** F(x, y, S(n)) >LPO G(y, F(x, y, n)): sub-case (b) applies (F > G), with F(x,y,S(n)) > y via s₂ = y, and F(x,y,S(n)) >LPO F(x,y,n) via sub-case (c) — same root, lexicographic comparison succeeds because S(n) > n (n is a strict subterm of S(n)).

**Boundary:** ✓ LPO uses only the (well-founded) precedence and the recursive term structure.

---

## Method (B): Nonlinear polynomial interpretation over N

**Termination proof:** ✓
- **Rule 1**: [F(x,y,Z)] = x + (y+1)(0+1) = x + y + 1 > x (since y + 1 ≥ 1).
- **Rule 2**: [F(x,y,S(n))] = x + (y+1)(n+2); [G(y,F(x,y,n))] = y + x + (y+1)(n+1). Difference = (y+1) − y = 1 > 0.

**Boundary:** ✓ The interpretation is verified directly against the rules; only the standard well-founded order on N is used as a meta-theoretic tool.

---

## Method (C): Multiset Path Order with F > G > S > Z

**Termination proof:** ✓
- **Rule 1** F(x, y, Z) >MPO x: sub-case (a) applies (s₁ = x ≥ x, multiset {x,y,Z} >mul ∅).
- **Rule 2** F(x, y, S(n)) >MPO G(y, F(x,y,n)): F > G, multiset {x, y, S(n)} ≥mul {y, F(x,y,n)} because x ≥ F(x,y,n) (x is a strict subterm of F(x,y,n)) and y ≥ y.

**Boundary:** ✓ Only the multiset extension of the precedence is used.

---

## Method (D): Dependency pairs with subterm criterion, projecting to the third argument of F

**Termination proof:** ✓

The defined symbols are F and G (roots of left-hand sides); S, Z are constructors.

**Dependency pairs:**
- DP1: F#(x, y, S(n)) → F#(x, y, n)  (from the inner F in rule 2's RHS)
- DP2: F#(x, y, S(n)) → G#(y, F(x, y, n))  (from the G in rule 2's RHS)

**Analysis:**
- DP1 is covered by the subterm criterion: ignoring #, F(x,y,n) is a strict subterm of F(x,y,S(n)) via the third argument (S(n) → n). This matches the stated projection.
- DP2 chains to G#, but G has no defining rules, so G# has no outgoing DPs — the chain terminates minimally.

The DP dependency graph contains no cycles requiring further argument, and the subterm criterion disposes of the recursive F# → F# chain.

**Boundary:** ✓ Entirely syntactic; uses only the rules and the standard DP/subterm-criterion infrastructure.

---

## Method (E): Exponential interpretation over N

**Termination proof:** ✓
- **Rule 1**: [F(x,y,Z)] = (x+y+2)¹ = x+y+2 > x (since y+2 ≥ 2).
- **Rule 2**: [F(x,y,S(n))] = (x+y+2)^(n+2); [G(y,F(x,y,n))] = y + (x+y+2)^(n+1). Difference = (x+y+2)^(n+1)·(y+1) − y ≥ 2(y+1) − y = y+2 ≥ 2 > 0.

**Boundary:** ✓ The interpretation is verified directly against the rules; only the well-foundedness of N is used externally.

## Summary

| Method | Proves termination? | Within boundary? |
|--------|---------------------|------------------|
| (A) LPO                 | ✓ | ✓ |
| (B) Nonlinear poly. int.| ✓ | ✓ |
| (C) MPO                 | ✓ | ✓ |
| (D) DP + subterm        | ✓ | ✓ |
| (E) Exponential int.    | ✓ | ✓ |

**All five methods (A, B, C, D, E) satisfy both conditions.** Each one establishes strong normalization of the system using only the two rules as given, together with standard well-founded meta-theoretic tools (a finite precedence for the path orders, the natural-number order for the interpretations, and the syntactic dependency-pair framework). None of them requires structural axioms or object-level assumptions beyond what the rules themselves provide.
