| Method | Proves termination? | Within the stated boundary? | Reason |
|---|---:|---:|---|
| (A) LPO with \(F>G>S>Z\) | Yes | No | The rules orient under the stated LPO. In particular, \(F(x,y,S(n)) >_{\mathrm{LPO}} G(y,F(x,y,n))\): \(F>G\), the left side is above \(y\), and it is above \(F(x,y,n)\) by the lexicographic decrease \(S(n)>n\). However, the proof relies on an externally imposed global symbol precedence, which is not part of the rewrite system. |
| (B) Nonlinear polynomial interpretation | Yes | Yes | Both rules strictly decrease in the displayed interpretation. For the second rule, the left-hand value exceeds the right-hand value by exactly \(1\). This is a checked semantic certificate over \(\mathbb N\), not an added object-level axiom about the terms. |
| (C) MPO with \(F>G>S>Z\) | Yes | No | The second rule is oriented because \(F>G\), the left side dominates \(y\), and \(F(x,y,S(n)) >_{\mathrm{MPO}} F(x,y,n)\) via the multiset replacement of \(S(n)\) by its proper subterm \(n\). But, as with (A), the argument depends on the imported global precedence. |
| (D) Dependency pairs with third-argument projection | Yes | Yes | The relevant dependency pair is \(F^\#(x,y,S(n)) \to F^\#(x,y,n)\). Projection to the third argument gives \(S(n) \triangleright n\), a strict subterm decrease. This projection is directly supported by the sole recursive call in the given rule, rather than requiring a global precedence or external structural axiom. |
| (E) Exponential interpretation | Yes | Yes | Let \(a=x+y+2\ge 2\). The first rule gives \(a>x\). For the second rule, the left side is \(a^{n+2}\), while the right side is \(y+a^{n+1}\); since \(a^{n+2}=a^{n+1}a\) and \(a-1=x+y+1>y\), the left side is strictly larger. This is again a metatheoretic interpretation certificate, not an assumption that the object symbols intrinsically denote arithmetic successor or exponentiation. |
