# Analysis of Termination Proof Methods

## System Recap

**Rules:**
1. `F(x, y, Z) -> x`
2. `F(x, y, S(n)) -> G(y, F(x, y, n))`

The system recurses on the third argument of `F`, stripping `S` constructors until `Z` is reached.

---

## Method (A): LPO with F > G > S > Z

**Rule 1:** `F(x, y, Z) > x` — `x` is a subterm of the LHS (1st argument). ✓

**Rule 2:** `F(x, y, S(n)) > G(y, F(x, y, n))` — Since `F > G`, we need:
- `F(x, y, S(n)) > y` — `y` is a subterm. ✓
- `F(x, y, S(n)) > F(x, y, n)` — Same root `F`, lexicographic comparison: `(x, y, S(n)) >_lex (x, y, n)` because `x=x`, `y=y`, and `S(n) > n` (since `n` is a subterm of `S(n)`). ✓
- `F(x,y,S(n))` dominates each argument `x, y, n` of the recursive call. ✓

**Result:** Succeeds. Within boundary (standard syntactic order, no imported axioms).

---

## Method (B): Polynomial Interpretation

`[F(x,y,n)] = x + (y+1)(n+1)`, `[S(n)] = n+1`, `[G(a,b)] = a+b`, `[Z] = 0`

**Rule 1:** `[F(x,y,Z)] = x + y + 1 > x = [x]` since `y + 1 ≥ 1 > 0`. ✓

**Rule 2:** `[F(x,y,S(n))] = x + (y+1)(n+2)` vs `[G(y,F(x,y,n))] = y + x + (y+1)(n+1)`.
Difference: `(y+1)(n+2) − (y+1)(n+1) − y = (y+1) − y = 1 > 0`. ✓

Monotonicity holds for all symbols (all partial derivatives positive over ℕ).

**Result:** Succeeds. Within boundary.

---

## Method (C): MPO with F > G > S > Z

**Rule 1:** Same as LPO. ✓

**Rule 2:** `F(x, y, S(n)) > G(y, F(x, y, n))` — Since `F > G`, we need:
- `F(x,y,S(n)) > y` ✓
- `F(x,y,S(n)) > F(x,y,n)` — Same root `F`, multiset comparison: `{x, y, S(n)} >_mul {x, y, n}`. After cancelling common elements `x, y`, we need `S(n) > n`. ✓
- Subterm conditions on arguments. ✓

**Result:** Succeeds. Within boundary.

---

## Method (D): Dependency Pairs with Subterm Criterion (3rd-argument projection)

The sole dependency pair is: `F#(x, y, S(n)) -> F#(x, y, n)`

Projecting to the 3rd argument of `F` means `π(F) = π(F#) = 3`.

For the subterm criterion to be sound in full rewriting, we need **both**:
1. **DP oriented:** `π(F#(x,y,S(n))) = S(n) ▷ n = π(F#(x,y,n))` ✓
2. **Usable rules weakly decreasing:** For Rule 1 `F(x,y,Z) -> x`, we need `π(F(x,y,Z)) ▷_eq π(x)`, i.e., `Z ▷_eq x`. This **fails** — `Z` and `x` are unrelated terms.

Since Rule 1 is a usable rule for full rewriting (variables can be instantiated to any term, so all rules are usable), the required compatibility condition is violated. The subterm ordering on the projected 3rd argument is not preserved across rewrite steps between DP applications (e.g., `F(a, b, Z) -> a` can replace the 3rd argument with an unrelated term).

**Result:** Does **not** succeed.

---

## Method (E): Exponential Interpretation

`[F(x,y,n)] = (x+y+2)^(n+1)`, `[S(n)] = n+1`, `[G(a,b)] = a+b`, `[Z] = 0`

**Rule 1:** `[F(x,y,Z)] = x+y+2 > x` since `y+2 ≥ 2 > 0`. ✓

**Rule 2:** Let `b = x+y+2 ≥ 2`. Need `b^(n+2) > y + b^(n+1)`.
Difference: `b^(n+1)(b−1) = b^(n+1)(x+y+1) ≥ 1·(y+1) > y`. ✓

Monotonicity holds: base `≥ 2` and exponent `≥ 1` ensure strict increase in each argument.

**Result:** Succeeds. Within boundary.

---

## Summary

| Method | Succeeds? | Within Boundary? |
|--------|-----------|------------------|
| (A) LPO | Yes | Yes |
| (B) Polynomial | Yes | Yes |
| (C) MPO | Yes | Yes |
| (D) DP + subterm | **No** | — |
| (E) Exponential | Yes | Yes |

**Methods satisfying both conditions: (A), (B), (C), and (E).**
