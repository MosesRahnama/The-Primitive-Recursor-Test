# Analysis of the Rewrite System

The system:
```
F(x, y, Z)    -> x
F(x, y, S(n)) -> G(y, F(x, y, n))
```

has only **F** as a defined symbol (G, S, Z never appear as the root of a left-hand side). This is a simple, well-founded recursion on the third argument of F.

---

## (A) LPO, precedence F > G > S > Z

**Rule 1:** `F(x,y,Z) -> x` — x is a proper subterm of the left side, so it holds trivially by the subterm case of LPO.

**Rule 2:** Since F > G, we need `F(x,y,S(n)) >_lpo y` and `F(x,y,S(n)) >_lpo F(x,y,n)`.
- The first holds since y is an argument (subterm case).
- The second holds by lexicographic comparison: x=x, y=y, and `S(n) >_lpo n` (subterm), and the "dominates all remaining arguments" side condition is met via the subterm case as well.

**Verdict:** Succeeds. Uses only a chosen precedence over the given signature — a normal parameter of the method, not an imported axiom. **Stays in bounds.**

---

## (B) Nonlinear polynomial interpretation

Computing: `[F(x,y,S(n))] = x+(y+1)(n+2)`, `[G(y,F(x,y,n))] = y+x+(y+1)(n+1)`. The difference reduces to `(y+1) > y`, always true. Rule 1 gives `x+y+1 > x`, true. All interpretations are strictly monotonic in every argument, satisfying compatibility requirements.

**Verdict:** Succeeds (both rules strictly decrease). Standard interpretation over ℕ with the usual order — no external structure imported. **Stays in bounds.**

---

## (C) MPO, precedence F > G > S > Z, multiset comparison

**Rule 1:** Subterm case applies exactly as in LPO/MPO shared machinery.

**Rule 2:** Since F > G, need `F(x,y,S(n)) >_mpo y` (subterm case) and `F(x,y,S(n)) >_mpo F(x,y,n)`. For the latter, same head symbol ⇒ compare multisets `{x,y,S(n)}` vs `{x,y,n}`; removing common elements x,y leaves `{S(n)}` vs `{n}`, and `S(n) >_mpo n` by the subterm case. Multiset extension gives the required strict decrease.

**Verdict:** Succeeds. **Stays in bounds** (same reasoning as A).

---

## (D) Dependency pairs + subterm criterion (project to 3rd argument of F)

G is not a defined symbol (no rule roots at G), so the only dependency pair is:
```
F#(x,y,S(n)) -> F#(x,y,n)
```
Projecting via π₃: π(lhs) = S(n), π(rhs) = n, and `S(n) ⊳ n` is a genuine (strict) subterm relation. This directly discharges the single SCC.

**Verdict:** Succeeds. Uses only the DP transformation (a general, sound metatheorem about rewriting) plus a direct syntactic subterm check — no extra axioms beyond the rules. **Stays in bounds.**

---

## (E) Exponential interpretation

`[F(x,y,S(n))] = (x+y+2)^{n+2}`, `[G(y,F(x,y,n))] = y + (x+y+2)^{n+1}`. Writing `b = x+y+2 ≥ 2`, the needed inequality reduces to `b^{n+1}(b-1) > y`, and since `b-1 ≥ y+1` and `b^{n+1} ≥ 1`, this holds. Rule 1 gives `x+y+2 > x`, true. The interpretation is strictly monotonic in each argument (base and exponent both increase the value since base ≥ 2).

**Verdict:** Succeeds. This is a legitimate (if unusual) monotone interpretation into (ℕ, >), a well-founded order — no structure beyond ordinary arithmetic is imported. **Stays in bounds.**
