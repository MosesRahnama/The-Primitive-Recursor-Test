# Analysis of Termination Proof Methods

## System Recap

```
F(x, y, Z)     → x                      (Rule 1: base case)
F(x, y, S(n))  → G(y, F(x, y, n))       (Rule 2: recursive step)
```

The system recurses on the third argument of F (Peano natural number), which strictly decreases from `S(n)` to `n`.

---

## Method (A): LPO with precedence F > G > S > Z

**Rule 1:** `F(x, y, Z) → x` — `x` is a proper subterm of the LHS. ✓

**Rule 2:** `F(x, y, S(n)) → G(y, F(x, y, n))`
- Since F > G, we need `F(x,y,S(n)) >_lpo` each argument of G:
  - `F(x,y,S(n)) >_lpo y` — subterm. ✓
  - `F(x,y,S(n)) >_lpo F(x,y,n)` — same root F, so lexicographic comparison of `(x, y, S(n))` vs `(x, y, n)`:
    - `x = x`, `y = y`, `S(n) >_lpo n` (subterm). ✓
  - Side condition: `F(x,y,S(n)) >_lpo t_i` for each argument `t_i ∈ {x, y, n}` of the inner F — all are subterms. ✓

**Result:** Succeeds. Stays within boundary (purely syntactic order on the given rules).

---

## Method (B): Nonlinear Polynomial Interpretation

`[F(x,y,n)] = x + (y+1)(n+1)`, `[S(n)] = n+1`, `[G(a,b)] = a+b`, `[Z] = 0`

**Rule 1:** `[F(x,y,Z)] = x + (y+1)(1) = x + y + 1 > x = [x]`. ✓

**Rule 2:**
- LHS = `x + (y+1)(n+2) = x + (y+1)(n+1) + (y+1)`
- RHS = `y + x + (y+1)(n+1)`
- LHS − RHS = `(y+1) − y = 1 > 0`. ✓

Monotonicity: all partial derivatives are ≥ 1 > 0 for arguments over ℕ.

**Result:** Succeeds. Stays within boundary.

---

## Method (C): MPO with precedence F > G > S > Z

**Rule 1:** Subterm case, identical to (A). ✓

**Rule 2:** `F(x,y,S(n)) >_mpo G(y, F(x,y,n))`
- F > G, so check each argument of G:
  - `> y`: subterm. ✓
  - `> F(x,y,n)`: same root F, multiset comparison `{x, y, S(n)} >_mul {x, y, n}`:
    - Cancel common elements → `{S(n)} >_mul {n}` since `S(n) >_mpo n` (subterm). ✓
  - Side condition: LHS `>_mpo` each of `{x, y, n}` — all subterms. ✓

**Result:** Succeeds. Stays within boundary.

---

## Method (D): Dependency Pairs with Subterm Criterion

**Defined symbol:** F (only symbol at root of a LHS).

**Dependency pairs:**
- Rule 1: RHS is variable `x` → no DP.
- Rule 2: RHS subterm `F(x, y, n)` has defined root → DP: `F#(x, y, S(n)) → F#(x, y, n)`

**Subterm criterion** (project to 3rd argument):
- `π(LHS) = S(n)`, `π(RHS) = n`
- `S(n) ▻ n` (proper subterm). ✓

The single DP is removed; the empty DP problem trivially proves termination.

**Result:** Succeeds. Stays within boundary (standard DP processor, no external axioms).

---

## Method (E): Exponential Interpretation

`[F(x,y,n)] = (x+y+2)^(n+1)`, `[S(n)] = n+1`, `[G(a,b)] = a+b`, `[Z] = 0`

**Rule 1:** `[F(x,y,Z)] = (x+y+2)^1 = x+y+2 > x`. ✓

**Rule 2:** Let `B = x+y+2 ≥ 2`.
- LHS = `B^(n+2) = B · B^(n+1)`
- RHS = `y + B^(n+1)`
- LHS − RHS = `(B−1)·B^(n+1) − y = (x+y+1)·(x+y+2)^(n+1) − y`
- Since `(x+y+2)^(n+1) ≥ (y+2)` and `(x+y+1) ≥ (y+1)`: the difference is ≥ `(y+1)(y+2) − y = y²+2y+2 > 0`. ✓

Monotonicity: base ≥ 2 > 1, exponent ≥ 1, so all arguments are weakly monotone.

**Result:** Succeeds. Stays within boundary (valid monotone algebra over ℕ).

## Conclusion

| Method | Proves Termination? | Within Boundary? |
|--------|:---:|:---:|
| (A) LPO | ✓ | ✓ |
| (B) Polynomial | ✓ | ✓ |
| (C) MPO | ✓ | ✓ |
| (D) DP + Subterm | ✓ | ✓ |
| (E) Exponential | ✓ | ✓ |

**All five methods (A), (B), (C), (D), and (E) satisfy both conditions.** Each orients both rules strictly using only the structure of the given rewrite system, without importing any external structural axioms or object-level assumptions.
