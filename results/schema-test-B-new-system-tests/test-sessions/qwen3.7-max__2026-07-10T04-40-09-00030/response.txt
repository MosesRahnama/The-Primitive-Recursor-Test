# Analysis of Termination Proof Methods

## System Under Analysis
```
Rules:
  (1) F(x, y, Z) → x
  (2) F(x, y, S(n)) → G(y, F(x, y, n))
```

---

## Method (A): LPO with precedence F > G > S > Z

**Termination proof:**

- **Rule 1:** `F(x, y, Z) → x`. Since `x` is a variable and a proper subterm of the LHS, `F(x,y,Z) >_lpo x` holds directly (subterm case). ✓
- **Rule 2:** `F(x, y, S(n)) → G(y, F(x, y, n))`. Since `F > G`, we need the LHS to dominate each argument of `G`:
  - `F(x,y,S(n)) >_lpo y`: subterm case. ✓
  - `F(x,y,S(n)) >_lpo F(x, y, n)`: same root symbol, so lexicographic comparison of arguments: `x = x`, `y = y`, and `S(n) >_lpo n` (subterm case). The lexicographic condition is satisfied. The LHS also dominates each argument of the RHS's `F`. ✓

**Boundary check:** LPO operates purely on rule structure and a symbol precedence. No external axioms imported. ✓

**Result: Succeeds.**

---

## Method (B): Nonlinear Polynomial Interpretation

Interpretation: `[F(x,y,n)] = x + (y+1)(n+1)`, `[S(n)] = n+1`, `[G(a,b)] = a+b`, `[Z] = 0`

**Termination proof:**

- **Rule 1:** `[F(x,y,Z)] = x + (y+1)(1) = x + y + 1`. Need `x + y + 1 > x`, i.e., `y + 1 > 0`. Holds for all `y ∈ ℕ`. ✓
- **Rule 2:** `[F(x,y,S(n))] = x + (y+1)(n+2)`. RHS: `[G(y, F(x,y,n))] = y + x + (y+1)(n+1)`. Difference: `(y+1)(n+2) − (y+1)(n+1) − y = (y+1) − y = 1 > 0`. ✓
- **Monotonicity:** `[F]` is monotone in all three arguments since partial derivatives are positive over ℕ. ✓

**Boundary check:** Standard polynomial interpretation; no external axioms. ✓

**Result: Succeeds.**

## Method (C): MPO with precedence F > G > S > Z

**Termination proof:**

- **Rule 1:** `F(x,y,Z) → x`. Subterm case: `x` is a direct argument. ✓
- **Rule 2:** `F(x,y,S(n)) → G(y, F(x,y,n))`. Since `F > G`, check LHS dominates each argument of `G`:
  - `F(x,y,S(n)) >_mpo y`: subterm case. ✓
  - `F(x,y,S(n)) >_mpo F(x,y,n)`: same root, multiset comparison `{x, y, S(n)} >_mul {x, y, n}`. Remove common elements `x, y`; need `{S(n)} >_mul {n}`, which holds since `S(n) >_mpo n` (subterm case). The LHS also dominates each argument `x, y, n` of the inner `F`. ✓

**Boundary check:** MPO is a purely structural method. No external axioms. ✓

**Result: Succeeds.**

---

## Method (D): Dependency Pairs with Subterm Criterion

**Termination proof:**

- **Dependency pairs:** The only defined symbol (LHS root) is `F`. The only subterm of an RHS with a defined root is `F(x, y, n)` in Rule 2. This yields one DP:
  ```
  F#(x, y, S(n)) → F#(x, y, n)
  ```
- **Subterm criterion** with projection `π(F#) = 3`:
  - `π(LHS) = S(n)`
  - `π(RHS) = n`
  - `n` is a proper subterm of `S(n)`. The DP is removed. ✓
- The resulting DP problem has `P = ∅`, which is trivially finite. ✓

**Boundary check:** Dependency pairs with subterm criterion operate purely on rule structure. No external axioms. ✓

**Result: Succeeds.**

## Method (E): Exponential Interpretation

Interpretation: `[F(x,y,n)] = (x+y+2)^(n+1)`, `[S(n)] = n+1`, `[G(a,b)] = a+b`, `[Z] = 0`

**Termination proof:**

- **Rule 1:** `[F(x,y,Z)] = (x+y+2)^1 = x + y + 2 > x`. Holds since `y + 2 ≥ 2 > 0`. ✓
- **Rule 2:** LHS `= (x+y+2)^(n+2)`. RHS `= y + (x+y+2)^(n+1)`. Difference:
  ```
  (x+y+2)^(n+2) − (x+y+2)^(n+1) = (x+y+2)^(n+1) · (x+y+1)
  ```
  Since `x+y+2 ≥ 2` and `n ≥ 0`: `(x+y+2)^(n+1) ≥ y+2`. And `x+y+1 ≥ 1`. So the difference `≥ (y+2)·1 = y+2 > y`. ✓
- **Monotonicity:** Base `x+y+2 ≥ 2 > 1` ensures monotonicity in `n`; exponent `n+1 ≥ 1` ensures monotonicity in `x` and `y`. ✓

**Boundary check:** This is a monotone algebra over `(ℕ, >)`. No structural axioms or object-level assumptions are imported—it is a semantic interpretation function derived solely from the rules. ✓

**Result: Succeeds.**
