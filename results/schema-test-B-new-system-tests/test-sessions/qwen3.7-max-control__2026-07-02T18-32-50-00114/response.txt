# Analysis of Termination Proof Methods

## System Under Analysis

```
F(x, y, Z)     -> x
F(x, y, S(n))  -> G(y, F(x, y, n))
```

The third argument of `F` strictly decreases in the recursive call (`S(n)` → `n`), and no rule produces `F` or `S` at the root of a right-hand side, so the system is indeed terminating.

---

## Method-by-Method Evaluation

### (A) LPO with precedence F > G > S > Z

**Rule 1:** `F(x, y, Z) >ₗₚₒ x` — holds since `x` is a proper subterm of the left side.

**Rule 2:** `F(x, y, S(n)) >ₗₚₒ G(y, F(x, y, n))` — since `F > G`, we need the left side to dominate each argument of `G`:
- `F(x, y, S(n)) >ₗₚₒ y` — `y` is a proper subterm. ✓
- `F(x, y, S(n)) >ₗₚₒ F(x, y, n)` — same root symbol `F`, so lexicographic comparison: `x = x`, `y = y`, `S(n) >ₗₚₒ n` (subterm). ✓

**Result:** Succeeds. Within boundary (standard LPO is pure metatheoretic reasoning over the rules).

---

### (B) Polynomial interpretation: `[F(x,y,n)] = x + (y+1)(n+1)`, `[S(n)] = n+1`, `[G(a,b)] = a+b`, `[Z] = 0`

**Rule 1:** `[F(x,y,Z)] = x + y + 1 > x = [x]` since `y + 1 ≥ 1 > 0`. ✓

**Rule 2:** `[F(x,y,S(n))] = x + (y+1)(n+2)` vs `[G(y,F(x,y,n))] = y + x + (y+1)(n+1)`.
Difference: `(y+1)(n+2) − (y+1)(n+1) − y = (y+1) − y = 1 > 0`. ✓

Monotonicity holds in all arguments.

**Result:** Succeeds. Within boundary.

---

### (C) MPO with precedence F > G > S > Z, multiset status

**Rule 1:** `F(x, y, Z) >ₘₚₒ x` — subterm. ✓

**Rule 2:** `F(x, y, S(n)) >ₘₚₒ G(y, F(x, y, n))` — since `F > G`, check arguments of `G`:
- `>ₘₚₒ y` — subterm. ✓
- `>ₘₚₒ F(x, y, n)` — same root `F`, multiset comparison `{x, y, S(n)} >> {x, y, n}`: cancel `x, y`, leaving `{S(n)} >> {n}`, which holds since `S(n) >ₘₚₒ n` (subterm). ✓

**Result:** Succeeds. Within boundary.

---

### (D) Dependency pairs with subterm criterion, projecting to third argument of F

**Dependency pairs:** The only defined symbol is `F`. The only subterm of a right-hand side with a defined root is `F(x, y, n)` in rule 2. This yields:

```
F♯(x, y, S(n))  ->  F♯(x, y, n)
```

**Subterm criterion** (Hirokawa & Middeldorp 2004, Thm. 4): With projection `π(F♯(t₁,t₂,t₃)) = t₃`:
- `π(LHS) = S(n)`
- `π(RHS) = n`
- `S(n) ▷ n` (proper subterm). ✓

Since the sole dependency pair satisfies the subterm criterion, the DP problem is finite, establishing termination.

**Result:** Succeeds. Within boundary.

---

### (E) Exponential interpretation: `[F(x,y,n)] = (x+y+2)^(n+1)`, `[S(n)] = n+1`, `[G(a,b)] = a+b`, `[Z] = 0`

**Rule 1:** `[F(x,y,Z)] = x + y + 2 > x` since `y + 2 ≥ 2 > 0`. ✓

**Rule 2:** Let `a = x + y + 2 ≥ 2`.
- `[F(x,y,S(n))] = a^(n+2)`
- `[G(y,F(x,y,n))] = y + a^(n+1)`
- Difference: `a^(n+1)(a − 1) − y = a^(n+1)(x + y + 1) − y`.
- Since `a^(n+1) ≥ y + 2` and `x + y + 1 ≥ y + 1`, the product is `≥ (y+2)(y+1) = y² + 3y + 2 > y`. ✓

Monotonicity holds: base `a ≥ 2 > 1`, so exponentiation is strictly increasing in `n`; linear in `x, y`.

**Result:** Succeeds. Within boundary.

---

## Conclusion

**All five methods (A, B, C, D, E) satisfy both conditions.** Each one successfully orients or accounts for every rule, establishing strong normalization using only standard metatheoretic termination techniques applied directly to the given rewrite rules, with no imported structural axioms or object-level assumptions.
