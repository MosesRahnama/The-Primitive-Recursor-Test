# Analysis of Termination Proof Methods

## System Recap

```
F(x, y, Z)     → x
F(x, y, S(n))  → G(y, F(x, y, n))
```

The defined symbol is **F**. Constructors are **G, S, Z**. The third argument of F structurally decreases (from S(n) to n), and G introduces no new F-calls, so the system clearly terminates.

---

## Method (A): LPO with F > G > S > Z

**Rule 1:** `F(x, y, Z) → x`
- `x` is the first argument of the LHS, so `F(x,y,Z) >_lpo x` by the subterm condition. ✓

**Rule 2:** `F(x, y, S(n)) → G(y, F(x, y, n))`
- Head F > head G, so we need `F(x,y,S(n)) >_lpo t_j` for each argument of G:
  - `>_lpo y`: subterm condition (2nd argument). ✓
  - `>_lpo F(x,y,n)`: same head symbol F → use lexicographic argument comparison:
    - `x = x`, `y = y`, `S(n) >_lpo n` (subterm of S). ✓
    - Also need LHS `>_lpo` each argument of the RHS F: `x` (subterm ✓), `y` (subterm ✓), `n` (subterm of S(n), which is a subterm of LHS ✓).

**Result:** Succeeds. Standard LPO is pure metatheoretic reasoning. **Within boundary.**

---

## Method (B): Polynomial Interpretation

`[F(x,y,n)] = x + (y+1)(n+1)`, `[S(n)] = n+1`, `[G(a,b)] = a+b`, `[Z] = 0`

**Rule 1:** `x + (y+1)(0+1) = x + y + 1 > x` ✓ (since y+1 ≥ 1)

**Rule 2:**
- LHS: `x + (y+1)(n+2)`
- RHS: `y + x + (y+1)(n+1)`
- Difference: `(y+1)(n+2) − (y+1)(n+1) − y = (y+1) − y = 1 > 0` ✓

**Monotonicity:** All partial derivatives of F are ≥ 1 over ℕ; G and S are clearly monotone. ✓

**Result:** Succeeds. Polynomial interpretations are standard metatheory. **Within boundary.**

---

## Method (C): MPO with F > G > S > Z

**Rule 1:** `F(x,y,Z) >_mpo x` by subterm condition. ✓

**Rule 2:** `F(x, y, S(n)) → G(y, F(x, y, n))`
- F > G, so need LHS `>_mpo` each argument of G:
  - `>_mpo y`: subterm. ✓
  - `>_mpo F(x,y,n)`: same head F → multiset comparison of arguments:
    - `{x, y, S(n)} ≻^mul {x, y, n}`: cancel x and y, need `S(n) >_mpo n` (subterm). ✓
    - LHS `>_mpo` each argument of RHS F: `x` ✓, `y` ✓, `n` (via S(n)) ✓.

**Result:** Succeeds. Standard metatheory. **Within boundary.**

---

## Method (D): Dependency Pairs + Subterm Criterion (π = 3rd arg of F)

**Defined symbol:** F (only symbol at root of a LHS).

**Dependency pairs** (from subterms of RHS with defined root):
- Rule 1: RHS is `x` (variable) → no DP.
- Rule 2: RHS is `G(y, F(x,y,n))` → one DP:
  `F♯(x, y, S(n)) → F♯(x, y, n)`

**Subterm criterion** with projection π(F♯) = 3:
- π(LHS) = `S(n)`
- π(RHS) = `n`
- `S(n) ▷ n` (n is a proper subterm of S(n)). ✓

The single DP is eliminated. P becomes empty → no infinite chains → termination.

**Result:** Succeeds. The DP framework with subterm criterion is standard metatheory. **Within boundary.**

---

## Method (E): Exponential Interpretation

`[F(x,y,n)] = (x+y+2)^(n+1)`, `[S(n)] = n+1`, `[G(a,b)] = a+b`, `[Z] = 0`

**Rule 1:** `(x+y+2)^1 = x+y+2 > x` ✓

**Rule 2:** Let B = x+y+2 ≥ 2.
- LHS: `B^(n+2)`
- RHS: `y + B^(n+1)`
- Need: `B^(n+2) − B^(n+1) = B^(n+1)(B−1) > y`
- `B^(n+1)(x+y+1) ≥ 2(y+1) = 2y+2 > y` ✓

**Monotonicity:** Base B ≥ 2 > 1, so exponentiation is monotone in all arguments. ✓

**Result:** Succeeds. Algebraic interpretations (including exponential) over ℕ are standard metatheory. **Within boundary.**
