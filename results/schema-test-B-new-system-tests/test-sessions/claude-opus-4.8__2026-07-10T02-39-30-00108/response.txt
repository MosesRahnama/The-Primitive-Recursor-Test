## (E) Exponential: [F(x,y,n)] = (x+y+2)^(n+1), [S(n)]=n+1, [G(a,b)]=a+b, [Z]=0

**Rule 1:** LHS = [F(x,y,Z)] = (x+y+2)^(0+1) = x+y+2. [x] = x. Need x+y+2 > x ✓.

**Rule 2:** LHS = [F(x,y,S(n))] = (x+y+2)^(n+2).
RHS = [G(y, F(x,y,n))] = y + (x+y+2)^(n+1).

LHS − RHS = b·b^(n+1) − b^(n+1) − y = (b−1)b^(n+1) − y.
Since b ≥ 2, (b−1) ≥ 1 and b^(n+1) ≥ b = x+y+2 > y. So (b−1)b^(n+1) ≥ b^(n+1) > y.
Thus LHS − RHS > 0. ✓

Both rules strictly decrease. **Succeeds.** All interpretations fitted to the rules only. ✓✓
