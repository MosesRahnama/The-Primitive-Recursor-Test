## Why each succeeds

### (A) LPO
- Rule 1: \(F(x,y,Z) \to x\) is fine since the lhs contains \(x\) as a subterm.
- Rule 2: \(F(x,y,S(n)) \to G(y, F(x,y,n))\)
  - \(F(x,y,S(n)) > F(x,y,n)\) because the third argument decreases \(S(n) > n\).
  - \(F > G\), and the lhs is bigger than both arguments of the rhs.
- So **A succeeds**.

### (B) Polynomial interpretation
Given
\[
[F(x,y,n)] = x + (y+1)(n+1),\quad [S(n)] = n+1,\quad [G(a,b)] = a+b,\quad [Z]=0.
\]

- Rule 1:
  \[
  [F(x,y,Z)] = x + (y+1)(1) = x+y+1 > x.
  \]
- Rule 2:
  \[
  [F(x,y,S(n))] = x + (y+1)(n+2),
  \]
  \[
  [G(y,F(x,y,n))] = y + x + (y+1)(n+1).
  \]
  Difference:
  \[
  x+(y+1)(n+2) - \bigl(y+x+(y+1)(n+1)\bigr)=1.
  \]
So **B succeeds**.

### (C) MPO
- Rule 1 is easy by subterm/property of the lhs.
- Rule 2:
  - With multiset comparison, \(\{x,y,S(n)\} >_{\text{mul}} \{x,y,n\}\) since \(S(n) > n\).
  - Hence \(F(x,y,S(n)) > F(x,y,n)\).
  - Since \(F > G\), the rhs root \(G\) is below the lhs root.
So **C succeeds**.

### (D) Dependency pairs + subterm criterion
The only defined symbol is \(F\), so the only DP is:
\[
F^\#(x,y,S(n)) \to F^\#(x,y,n).
\]
Project to the 3rd argument:
- lhs projection: \(S(n)\)
- rhs projection: \(n\)

And \(S(n)\) is a proper superterm of \(n\). Thus the SCC is chain-free by the subterm criterion. So **D succeeds**.

### (E) Exponential interpretation
Let
\[
[F(x,y,n)] = (x+y+2)^{n+1},\quad [S(n)]=n+1,\quad [G(a,b)] = a+b,\quad [Z]=0.
\]

- Rule 1:
  \[
  [F(x,y,Z)] = (x+y+2)^1 = x+y+2 > x.
  \]
- Rule 2: let \(b=x+y+2\ge 2\). Then
  \[
  [F(x,y,S(n))] = b^{n+2},
  \]
  \[
  [G(y,F(x,y,n))] = y + b^{n+1}.
  \]
  Need \(b^{n+2} > y + b^{n+1}\), i.e.
  \[
  (b-1)b^{n+1} > y.
  \]
  Since \(b-1 = x+y+1 > y\) and \(b^{n+1}\ge 1\), this holds.
So **E succeeds**.

## Boundary judgment

Using your **narrow** instruction:

- **A, C**: outside, because they depend on an externally chosen global precedence.
- **B, E**: outside, because they depend on externally chosen interpretations over \(\mathbb N\).
- **D**: inside, because it uses the actual recursive descent already visible in the rule \(S(n) \to n\), rather than importing a separate global algebra or precedence.

**(D) only.**
