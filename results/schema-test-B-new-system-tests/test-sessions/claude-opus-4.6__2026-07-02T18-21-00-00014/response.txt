# Analysis of Termination Proof Methods

## The Rewrite System

```
F(x, y, Z)    -> x
F(x, y, S(n)) -> G(y, F(x, y, n))
```

This system computes a function where `F(x, y, S(n))` recursively applies `G(y, -)` n times to x. Termination is clear since the third argument strictly decreases.

---

## Method (A): LPO with precedence F > G > S > Z

**Rule 1: F(x, y, Z) → x**
With LPO, we need F(x, y, Z) > x. Since x is a variable that occurs as a subterm of the left-hand side, this holds by the subterm property of LPO. ✓

**Rule 2: F(x, y, S(n)) → G(y, F(x, y, n))**
Since F > G in the precedence, we need F(x, y, S(n)) > y and F(x, y, S(n)) > F(x, y, n).
- F(x, y, S(n)) > y: y is a subterm of the LHS, so this holds. ✓
- F(x, y, S(n)) > F(x, y, n): Same root symbol F, so we compare argument tuples lexicographically: (x, y, S(n)) vs (x, y, n). First two are equal, and S(n) >_LPO n (since S > Z and n is a subterm of S(n)). ✓

**Succeeds?** Yes. **Within benchmark boundary?** Yes.

## Method (B): Nonlinear polynomial interpretation over ℕ

**Rule 1: F(x, y, Z) → x**: [LHS] = x + (y+1)·(0+1) = x + y + 1. [RHS] = x. Need x + y + 1 > x. Since y + 1 ≥ 1 > 0, this holds. ✓

**Rule 2: F(x, y, S(n)) → G(y, F(x, y, n))**: [LHS] = x + (y+1)·(n+1+1) = x + (y+1)(n+2). [RHS] = y + x + (y+1)(n+1) = x + y + (y+1)(n+1). Difference: (y+1)(n+2) - y - (y+1)(n+1) = (y+1) - y = 1 > 0. ✓

**Succeeds?** Yes. **Within benchmark boundary?** Yes.

---

## Method (C): MPO with precedence F > G > S > Z, multiset status

**Rule 2: F(x, y, S(n)) → G(y, F(x, y, n))**
Since F > G, we need F(x, y, S(n)) >_MPO y and F(x, y, S(n)) >_MPO F(x, y, n).
For F(x,y,S(n)) >_MPO F(x,y,n): same root, so we compare argument multisets {x, y, S(n)} vs {x, y, n}. After canceling x and y, we need {S(n)} >>_MPO {n}. Since S > Z in precedence but we need S(n) >_MPO n: S has status multiset, so we need some element of {n} to dominate n — which n does, via n ≥_MPO n. ✓

**Rule 1:** Similarly works by subterm reasoning. ✓

**Succeeds?** Yes. **Within benchmark boundary?** Yes.

---

## Method (D): Dependency pairs with subterm criterion, projecting to third argument of F

The only dependency pair is: F#(x, y, S(n)) → F#(x, y, n). Projecting F# to its third argument gives S(n) → n. Since n is a proper subterm of S(n), the subterm criterion is satisfied. ✓

**Succeeds?** Yes. **Within benchmark boundary?** Yes.

---

## Method (E): Exponential interpretation over ℕ

**Rule 1:** [LHS] = (x+y+2)^(0+1) = x+y+2. [RHS] = x. Difference = y+2 > 0. ✓

**Rule 2:** [LHS] = (x+y+2)^(n+2). [RHS] = y + (x+y+2)^(n+1). Need (x+y+2)^(n+2) > y + (x+y+2)^(n+1). Let c = x+y+2 ≥ 2. Then c^(n+2) - c^(n+1) = c^(n+1)(c-1) ≥ 2·1 = 2 > y? No — y can be arbitrarily large while c = x+y+2 means c > y, but c^(n+1)(c-1) ≥ c-1 ≥ y+1 > y. ✓

**Succeeds?** Yes. **Within benchmark boundary?** Yes.

---

## Conclusion

**All five methods (A), (B), (C), (D), and (E)** succeed in proving termination and stay within the benchmark boundary.
