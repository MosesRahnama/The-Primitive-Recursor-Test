# Analysis of Proposed Proof Methods

## System Under Analysis

```
F(x, y, Z) -> x
F(x, y, S(n)) -> G(y, F(x, y, n))
```

The system recurses on the third argument of `F`, peeling off one `S` at each step and accumulating a `G(y, ...)` wrapper.

---

## Method (A): LPO with precedence F > G > S > Z

**Termination proof:**

- **Rule 1:** `F(x, y, Z) >_lpo x` — holds by the subterm condition (first argument `x ≥_lpo x`).
- **Rule 2:** `F(x, y, S(n)) >_lpo G(y, F(x, y, n))` — since `F > G`, condition 1 of LPO requires `F(x,y,S(n)) >_lpo y` (holds by subterm) and `F(x,y,S(n)) >_lpo F(x,y,n)`. The latter uses condition 2 (same root `F`): all RHS arguments are subterms of the LHS, and the lexicographic comparison `(x, y, S(n)) >^lex (x, y, n)` reduces to `S(n) >_lpo n`, which holds by the subterm condition.

**Benchmark boundary:** LPO uses only the rewrite rules and a precedence on function symbols. No external axioms.

**Result: Satisfies both conditions. ✓**

---

## Method (B): Nonlinear polynomial interpretation

**Termination proof:**

- **Rule 1:** `[F(x,y,Z)] = x + (y+1)(0+1) = x + y + 1 > x` — holds since `y + 1 ≥ 1 > 0`.
- **Rule 2:** `[F(x,y,S(n))] = x + (y+1)(n+2)` versus `[G(y,F(x,y,n))] = y + x + (y+1)(n+1)`. Difference: `(y+1)(n+2) − y − (y+1)(n+1) = (y+1) − y = 1 > 0`.

Monotonicity holds: partial derivatives are all strictly positive over ℕ. All interpretations map ℕᵏ → ℕ.

**Benchmark boundary:** Polynomial interpretations are derived solely from the rule structure. No external axioms.

**Result: Satisfies both conditions. ✓**

## Method (C): MPO with precedence F > G > S > Z

**Termination proof:**

- **Rule 1:** `F(x, y, Z) >_mpo x` — subterm condition.
- **Rule 2:** `F(x, y, S(n)) >_mpo G(y, F(x, y, n))` — since `F > G`, condition 1 requires `F(x,y,S(n)) >_mpo y` (subterm) and `F(x,y,S(n)) >_mpo F(x,y,n)`. For the latter (same root `F`), all RHS arguments `{x, y, n}` are subterms of the LHS, and the multiset comparison `{x, y, S(n)} >^mul {x, y, n}` holds because `S(n) >_mpo n` (subterm) replaces `n`.

**Benchmark boundary:** MPO is a purely syntactic order on the given rules. No external axioms.

**Result: Satisfies both conditions. ✓**

## Method (D): Dependency pairs with subterm criterion

**Termination proof:**

The only defined symbol is `F`. Computing dependency pairs:

- Rule 1 (`F(x,y,Z) → x`): RHS is a variable — no DP.
- Rule 2 (`F(x,y,S(n)) → G(y, F(x,y,n))`): the subterm `F(x,y,n)` has defined root `F`, yielding the single DP:
  **`F#(x, y, S(n)) → F#(x, y, n)`**

Applying the subterm criterion with projection π to the third argument:
- `π(LHS) = S(n)`
- `π(RHS) = n`
- `S(n) ▷ n` (proper superterm, since `n` is a proper subterm of `S(n)`)

By the subterm criterion (Hirokawa & Middeldorp, 2004), this DP is removed, leaving `P' = ∅`. An empty DP set is trivially finite, proving termination.

**Benchmark boundary:** The DP framework and subterm criterion derive everything from the given rules. No external axioms.

**Result: Satisfies both conditions. ✓**

## Method (E): Exponential interpretation

**Termination proof:**

- **Rule 1:** `[F(x,y,Z)] = (x+y+2)^1 = x+y+2 > x` — holds since `y+2 ≥ 2 > 0`.
- **Rule 2:** `[F(x,y,S(n))] = (x+y+2)^(n+2)` versus `[G(y,F(x,y,n))] = y + (x+y+2)^(n+1)`. Let `b = x+y+2 ≥ 2`. Then `b^(n+2) − b^(n+1) − y = b^(n+1)(b−1) − y`. Since `b−1 = x+y+1 ≥ y+1` and `b^(n+1) ≥ 2`, we get `b^(n+1)(b−1) ≥ 2(y+1) = 2y+2 > y`.

Monotonicity: base `b ≥ 2 > 1` ensures the exponential is strictly increasing in all arguments. All functions map ℕᵏ → ℕ.

**Benchmark boundary:** The exponential interpretation is a mathematical mapping derived from the rules. No external axioms.

**Result: Satisfies both conditions. ✓**
