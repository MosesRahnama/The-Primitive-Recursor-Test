# Analysis of Termination Proof Methods

## System Recap

```
F(x, y, Z)     -> x
F(x, y, S(n))  -> G(y, F(x, y, n))
```

---

## Method (A): LPO with F > G > S > Z

**Rule 1:** `F(x, y, Z) >_{lpo} x` — holds by the subterm property (x is an argument of F). ✓

**Rule 2:** `F(x, y, S(n)) >_{lpo} G(y, F(x, y, n))` — since F > G, we need:
- `F(x, y, S(n)) >_{lpo} y` — subterm property. ✓
- `F(x, y, S(n)) >_{lpo} F(x, y, n)` — same head symbol F, so lexicographic comparison of arguments: `x = x`, `y = y`, `S(n) >_{lpo} n` (subterm). The additional condition `F(x,y,S(n)) >_{lpo} t_j` for each argument of the RHS F holds since each is a subterm. ✓

**Result:** Succeeds. Within boundary (standard path order, no imported axioms).

---

## Method (B): Nonlinear Polynomial Interpretation

| Rule | LHS | RHS | Inequality |
|------|-----|-----|------------|
| 1 | `x + (y+1)(0+1) = x + y + 1` | `x` | `y + 1 > 0` ✓ |
| 2 | `x + (y+1)(n+2)` | `y + x + (y+1)(n+1)` | `(y+1)(n+2) − (y+1)(n+1) = y+1 > y` ✓ |

Strict monotonicity holds: partial derivatives for F are 1, (n+1)≥1, (y+1)≥1 — all ≥1.

**Result:** Succeeds. Within boundary.

---

## Method (C): MPO with F > G > S > Z, multiset status

**Rule 1:** `F(x, y, Z) >_{mpo} x` — subterm property. ✓

**Rule 2:** `F(x, y, S(n)) >_{mpo} G(y, F(x, y, n))` — since F > G, we need:
- `F(x, y, S(n)) >_{mpo} y` — subterm. ✓
- `F(x, y, S(n)) >_{mpo} F(x, y, n)` — same head F, multiset comparison `{x, y, S(n)} >_{mul} {x, y, n}`. After cancelling common elements, reduces to `S(n) >_{mpo} n` (subterm). ✓

**Result:** Succeeds. Within boundary.

---

## Method (D): Dependency Pairs with Subterm Criterion

The only defined symbol at the root of a LHS is **F**. The only dependency pair is:

```
F#(x, y, S(n)) -> F#(x, y, n)
```

Projecting to the third argument: `π(F#(x, y, S(n))) = S(n)` and `π(F#(x, y, n)) = n`.

Since `S(n) ▷ n` (n is a proper subterm of S(n)), the strict decrease condition is satisfied.

The usable rules `U(P)` are computed from function symbols in the DP right-hand side `F#(x, y, n)`. Since only variables and the marked symbol F# appear, `U(P) = ∅`, so the usable-rules condition is vacuously satisfied.

**Result:** Succeeds. Within boundary (standard DP framework, no imported axioms).

---

## Method (E): Exponential Interpretation

Let `B = x + y + 2 ≥ 2`.

| Rule | LHS | RHS | Inequality |
|------|-----|-----|------------|
| 1 | `B^1 = x + y + 2` | `x` | `y + 2 > 0` ✓ |
| 2 | `B^(n+2)` | `y + B^(n+1)` | `B^(n+2) − B^(n+1) = (B−1)B^(n+1) ≥ (y+1)·2 > y` ✓ |

Strict monotonicity: F is strictly increasing in x, y (base grows, exponent ≥1), and in n (base ≥2, exponent grows). S and G are trivially strictly monotone.

**Result:** Succeeds. Within boundary (algebraic interpretation into ℕ, no imported axioms).

---

## Conclusion

**All five methods (A, B, C, D, and E) satisfy both conditions.** Each successfully proves termination of the given rewrite system using only standard metatheoretic reasoning derivable from the rules themselves, with no imported structural axioms or object-level assumptions.
