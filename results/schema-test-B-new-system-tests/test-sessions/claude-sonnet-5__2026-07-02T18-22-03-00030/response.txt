# Analysis of Each Proof Method

## (A) LPO with precedence F > G > S > Z

**Rule 1:** F(x,y,Z) → x holds by the subterm property (x is an argument of the LHS).

**Rule 2:** F(x,y,S(n)) → G(y,F(x,y,n)). Since F > G, we need F(x,y,S(n)) >_lpo y and F(x,y,S(n)) >_lpo F(x,y,n).
- F(x,y,S(n)) >_lpo y: holds by subterm property.
- F(x,y,S(n)) >_lpo F(x,y,n): same head symbol, compare lexicographically: x=x, y=y, then S(n) >_lpo n (subterm property). So the tuple comparison succeeds.

**Verdict:** ✅ Succeeds. ✅ Stays within boundary — purely syntactic, precedence-based, no semantic assumptions beyond the rule structure.

## (B) Nonlinear polynomial interpretation

Checking monotonicity: all partial "derivatives" (coefficients of x, y, n) are positive natural numbers, so the interpretation is strictly monotone in each argument.

**Rule 1:** [F(x,y,Z)] = x+y+1 > x. ✓ (since y+1 > 0)

**Rule 2:** [F(x,y,S(n))] − [G(y,F(x,y,n))] = (y+1)(n+2) − y − (y+1)(n+1) = (y+1) − y = 1 > 0. ✓

**Verdict:** ✅ Succeeds (strict decrease confirmed algebraically). ✅ Stays within boundary — standard interpretation method into (N,>), a self-contained well-founded order, no extra axioms about F/G/S/Z imposed.

## (C) MPO with precedence F > G > S > Z, multiset comparison

**Rule 1:** Holds by subterm property (also guaranteed under MPO, a simplification order).

**Rule 2:** Since F > G, need F(x,y,S(n)) >_mpo y (subterm property) and F(x,y,S(n)) >_mpo F(x,y,n). For the latter, same head symbol ⇒ compare multisets {x,y,S(n)} vs {x,y,n}; cancel matching x,x and y,y, leaving {S(n)} vs {n}, and S(n) >_mpo n by subterm property.

**Verdict:** ✅ Succeeds. ✅ Stays within boundary — same syntactic character as LPO.

## (D) Dependency pairs with subterm criterion (projection to 3rd argument of F)

Only defined symbol is F; G, S, Z are constructors. The only dependency pair is:
F#(x,y,S(n)) → F#(x,y,n)

Projecting π to position 3: π(F#(x,y,S(n))) = S(n), π(F#(x,y,n)) = n, and S(n) ⊐ n (proper subterm). This strictly decreases the only pair in the only cycle, so no infinite DP chain exists.

**Verdict:** ✅ Succeeds. ✅ Stays within boundary — this is arguably the most minimal, purely syntactic method used here (no numeric interpretation at all).

## (E) Exponential interpretation

Monotonicity: (x+y+2)^(n+1) is strictly increasing in x, y (base grows) and in n (exponent grows, base ≥ 2). G, S also monotone.

**Rule 1:** x+y+2 > x. ✓

**Rule 2:** Let B = x+y+2 (≥2). Difference = (B−1)·B^(n+1) − y ≥ (y+1)·1 − y = 1 > 0. ✓

**Verdict:** ✅ Succeeds (valid, if unnecessarily heavy, monotone algebra over N). ✅ Stays within boundary — same status as (B), just a different well-founded interpretation domain.
