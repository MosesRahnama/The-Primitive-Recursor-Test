## The Rewrite System

- R1: F(x, y, Z) → x
- R2: F(x, y, S(n)) → G(y, F(x, y, n))

The third argument of F decreases (S(n) → n), and G is non-recursive. Termination is intuitively clear.

---

## Method A: LPO with F > G > S > Z

**R1:** F(x, y, Z) →_LPO x. LPO requires the right-hand side to be a proper subterm or strictly smaller. x is a subterm of F(x, y, Z), so x <_LPO F(x, y, Z). ✓

**R2:** F(x, y, S(n)) →_LPO G(y, F(x, y, n)). Since F > G, we need all arguments of G to be strictly less than F(x, y, S(n)). 
- y is a subterm of F(x, y, S(n)) ✓
- F(x, y, n): same head F, compare lex: x=x, y=y, then n vs S(n). Since n is a subterm of S(n), n <_LPO S(n) ✓, so F(x, y, n) <_LPO F(x, y, S(n)) ✓

**A succeeds. Within boundary.** ✓✓

## Method B: Polynomial interpretation

**R1:** [F(x,y,Z)] = x + (y+1)(0+1) = x + y + 1 > x = [x]. ✓

**R2:** [F(x,y,S(n))] = x + (y+1)(n+2). [G(y, F(x,y,n))] = y + x + (y+1)(n+1) = x + y + (y+1)(n+1).

Difference: x+(y+1)(n+2) − (x+y+(y+1)(n+1)) = (y+1)(n+2)−y−(y+1)(n+1) = (y+1) − y = 1 > 0. ✓

**B succeeds. Within boundary.** ✓✓

## Method C: MPO with all arguments as multisets

**R2:** F(x, y, S(n)) → G(y, F(x, y, n)). Since F > G, MPO requires each argument of G to be strictly less than F(x, y, S(n)) under MPO.
- y <_MPO F(x, y, S(n)) (subterm) ✓
- F(x, y, n): same head F, compare argument multisets {x, y, n} vs {x, y, S(n)}. Need {x,y,n} <_mul {x,y,S(n)}. After canceling x,y: {n} vs {S(n)}. Need n <_MPO S(n). Since S > Z (and n is a variable), n is not necessarily smaller than S(n) under MPO — variables have no fixed position. MPO requires S(n) to have n as a strict subterm, but MPO on terms with variables: S(n) >_MPO n since S(n) has head S and n is a strict subterm. ✓

Actually MPO (like LPO) treats variables, and since n is a subterm of S(n), n <_MPO S(n). So {n} <_mul {S(n)}. ✓

**C succeeds. Within boundary.** ✓✓

## Method D: Dependency pairs with subterm criterion

The only dependency pair from R2 is: F#(x, y, S(n)) → F#(x, y, n).

Projecting to the third argument: π(F#(x, y, S(n))) = S(n), π(F#(x, y, n)) = n. Since n is a strict subterm of S(n), the subterm criterion applies directly. ✓

**D succeeds. Within boundary.** ✓✓

## Method E: Exponential interpretation

**R1:** [F(x,y,Z)] = (x+y+2)^1 = x+y+2. [x] = x. Need x+y+2 > x, i.e., y+2 > 0. ✓ (over N)

**R2:** [F(x,y,S(n))] = (x+y+2)^(n+2). [G(y,F(x,y,n))] = y + (x+y+2)^(n+1).

Need (x+y+2)^(n+2) > y + (x+y+2)^(n+1). Let c = x+y+2 ≥ 2. Need c^(n+2) > y + c^(n+1), i.e., c^(n+1)(c−1) > y. With x,y,n ranging over all naturals, y can be arbitrarily large while c−1 = x+y+1 ≥ y+1, so c^(n+1)(c−1) ≥ 1·(y+1) > y. ✓

**E succeeds. Within boundary.** ✓✓
