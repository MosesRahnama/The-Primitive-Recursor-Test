# Analysis of the Rewrite System

```
F(x, y, Z)    -> x
F(x, y, S(n)) -> G(y, F(x, y, n))
```

This is a simple primitive-recursion-style system: the only "hard" rule is the second one, which recurses on the third argument of `F`. All five methods target exactly this recursive structure.

---

## (A) LPO, precedence F > G > S > Z

**Rule 1** `F(x,y,Z) -> x`: holds by the subterm property (x is an argument of the LHS).

**Rule 2** `F(x,y,S(n)) -> G(y,F(x,y,n))`: Since F > G, we need `F(x,y,S(n)) >_lpo y` (subterm property) and `F(x,y,S(n)) >_lpo F(x,y,n)`. The latter compares equal heads lexicographically: `(x,y,S(n)) >_lex (x,y,n)` since `S(n) >_lpo n` by the subterm property, and the auxiliary domination condition (`s >_lpo t_j` for each argument of the smaller term) is satisfied since each `t_j ∈ {x,y,n}` is dominated via the subterm case.

**Verdict:** Succeeds. Only uses a precedence over the given symbols — a standard, self-contained technique. **Within boundary.**

---

## (B) Nonlinear polynomial interpretation

Checking strict decrease:
- Rule 1: `x + y + 1 > x` — always true.
- Rule 2: `x+(y+1)(n+2) > y + x + (y+1)(n+1)` reduces to `(y+1) > y` — always true.

All symbols are weakly (in fact strictly) monotonic in each argument, satisfying the requirements of the interpretation method.

**Verdict:** Succeeds. Standard reduction-pair/algebra technique, no external axioms imported. **Within boundary.**

---

## (C) MPO, precedence F > G > S > Z, multiset status

**Rule 1**: holds via subterm property, as in LPO.

**Rule 2**: Need `F(x,y,S(n)) >_mpo F(x,y,n)` (same head, multiset comparison) and `>_mpo y`. Cancel common elements `x,y` from `{x,y,S(n)}` vs `{x,y,n}`, leaving `{S(n)}` vs `{n}`; since `S(n) ▷ n`, the multiset order holds, giving domination, and the case F > G then applies to conclude the full comparison.

**Verdict:** Succeeds. Same self-contained precedence/order machinery as LPO. **Within boundary.**

---

## (D) Dependency pairs + subterm criterion, projection π(F#) = 3rd argument

The only defined symbol is `F`; rule 1 yields no dependency pair (RHS has no defined-symbol call); rule 2 yields the single DP:

`F#(x,y,S(n)) -> F#(x,y,n)`

Projecting to the 3rd argument: `π(LHS) = S(n)`, `π(RHS) = n`, and `S(n) ▷ n` strictly. This is the only DP (forming its own trivial SCC), so the subterm criterion removes it entirely, leaving no cycles.

**Verdict:** Succeeds. Purely syntactic construction from the given rules (marking symbols, forming DPs, subterm relation) — no external assumptions. **Within boundary.**

---

## (E) Exponential interpretation

- Rule 1: `(x+y+2) > x`, i.e. `y+2>0` — always true.
- Rule 2: Setting `b = x+y+2 ≥ 2`, need `b^{n+2} > y + b^{n+1}`, i.e. `b^{n+1}(b-1) > y`. Since `y ≤ b-2`, it suffices that `b^{n+1}(b-1) > b-2`; already at `n=0` this is `b(b-1) > b-2 ⟺ (b-1)^2+1>0`, always true, and the left side only grows with `n`.

All symbols are strictly monotonic in each argument (base ≥ 2 ensures monotonicity in the exponent and in the base).

**Verdict:** Succeeds. This is still an instance of the general monotone-algebra/interpretation method (just using an exponential rather than polynomial function) — no axioms beyond choosing an interpretation into a well-founded ordered domain, which is intrinsic to the technique itself. **Within boundary.**

---

# Summary

| Method | Proves termination? | Stays within boundary? |
|---|---|---|
| A (LPO) | Yes | Yes |
| B (nonlinear polynomial) | Yes | Yes |
| C (MPO) | Yes | Yes |
| D (DP + subterm criterion) | Yes | Yes |
| E (exponential interpretation) | Yes | Yes |

**Conclusion:** All five methods, A–E, successfully establish strong normalization of the given system, and each does so using only structure intrinsic to the rules themselves (chosen precedences, chosen interpretations, or syntactically derived dependency pairs) — none imports arbitrary global structural axioms beyond the standard, sound application of its technique. Hence **all five methods (A, B, C, D, E)** satisfy both conditions.
