# Analysis of Termination Proof Methods

## The Rewrite System

```
Rule 1: F(x, y, Z) -> x
Rule 2: F(x, y, S(n)) -> G(y, F(x, y, n))
```

This is a primitive-recursive style iteration: F iterates G on y, n times, starting from x.

---

## Method A: LPO with precedence F > G > S > Z

**Rule 1: F(x, y, Z) → x**
Since x is a subterm of F(x, y, Z), this is handled by the subterm property of LPO. ✓

**Rule 2: F(x, y, S(n)) → G(y, F(x, y, n))**
Since F > G, we need F(x, y, S(n)) >_LPO y and F(x, y, S(n)) >_LPO F(x, y, n).

- F(x, y, S(n)) >_LPO F(x, y, n): Same root symbol F, so we compare argument tuples lexicographically (left to right by default). First arguments are equal (x), second arguments are equal (y), third: S(n) >_LPO n since S > n's variable... actually n is a subterm of S(n), so S(n) >_LPO n. ✓
- F(x, y, S(n)) >_LPO y: y is a subterm of F(x, y, S(n)). ✓

**Succeeds: Yes. Within boundary: Yes.**

---

## Method B: Nonlinear Polynomial Interpretation

**Rule 1: F(x, y, Z) → x**
[F(x,y,Z)] = x + (y+1)*(0+1) = x + y + 1. [RHS] = x.
x + y + 1 > x ✓ (since y + 1 ≥ 1)

**Rule 2: F(x, y, S(n)) → G(y, F(x, y, n))**
[LHS] = x + (y+1)*(n+1+1) = x + (y+1)*(n+2)
[RHS] = [G(y, F(x,y,n))] = y + [F(x,y,n)] = y + x + (y+1)*(n+1)

Difference: x + (y+1)(n+2) - y - x - (y+1)(n+1) = (y+1)[(n+2)-(n+1)] - y = (y+1) - y = 1 > 0. ✓

**Succeeds: Yes. Within boundary: Yes.**

---

## Method C: MPO with precedence F > G > S > Z

**Rule 2: F(x, y, S(n)) → G(y, F(x, y, n))**
Since F > G, we need F(x, y, S(n)) >_MPO every argument of G. For F(x, y, S(n)) >_MPO y: y is a subterm argument of F, so this holds. For F(x, y, S(n)) >_MPO F(x, y, n): same root, so we compare argument multisets: {x, y, S(n)} vs {x, y, n}. Removing common elements: {S(n)} vs {n}. Since S > n (subterm), S(n) >_MPO n. ✓

**Rule 1:** x is a subterm. ✓

**Succeeds: Yes. Within boundary: Yes.**

---

## Method D: Dependency Pairs with Subterm Criterion

The dependency pairs (capitalized root for DP):
- F#(x, y, S(n)) → F#(x, y, n)

Projecting F# to its third argument: S(n) ▷ n (proper subterm). The subterm criterion applies: the projected argument strictly decreases. No infinite chains possible. ✓

**Succeeds: Yes. Within boundary: Yes.**

---

## Method E: Exponential Interpretation

**Rule 1:** [F(x,y,Z)] = (x+y+2)^1 = x+y+2. [RHS] = x. Need x+y+2 > x. ✓

**Rule 2:** [LHS] = (x+y+2)^(n+2). [RHS] = y + (x+y+2)^(n+1).
(x+y+2)^(n+2) = (x+y+2)·(x+y+2)^(n+1) ≥ 2·(x+y+2)^(n+1) > y + (x+y+2)^(n+1) when (x+y+2)^(n+1) > y. Since x+y+2 ≥ 2, (x+y+2)^(n+1) ≥ 2 > 0... actually we need (x+y+1)·(x+y+2)^(n+1) > y. Since (x+y+2)^(n+1) ≥ y+2 > y. ✓

**Succeeds: Yes. Within boundary: Yes.**

---

## Conclusion

**All five methods (A, B, C, D, E)** succeed in proving termination and remain within the benchmark boundary.
