# Analysis of Termination Proof Methods

## System Under Analysis

```
F(x, y, Z)     → x
F(x, y, S(n))  → G(y, F(x, y, n))
```

The third argument of F acts as a natural number (built from Z and S) that strictly decreases with each recursive call.

---

## Method (A): LPO with precedence F > G > S > Z

**Termination proof:**

- **Rule 1:** `F(x, y, Z) >_lpo x` — x is the first argument (subterm condition). ✓
- **Rule 2:** `F(x, y, S(n)) >_lpo G(y, F(x, y, n))` — Root F > G in precedence, so we need `F(x,y,S(n)) >_lpo` each argument of G:
  - `>_lpo y`: y is the 2nd argument (subterm). ✓
  - `>_lpo F(x, y, n)`: same root F, lexicographic comparison of arguments:
    - x = x, y = y, S(n) >_lpo n (subterm). ✓
    - `F(x,y,S(n)) >_lpo` each argument x, y, n of the RHS F (all subterms). ✓

**Result:** Succeeds. Stays within boundary (standard path ordering, no imported axioms).

---

## Method (B): Nonlinear Polynomial Interpretation

**Termination proof:**

- **Rule 1:** `[F(x,y,Z)] = x + (y+1)(0+1) = x + y + 1 > x` since y+1 ≥ 1. ✓
- **Rule 2:**
  - `[F(x,y,S(n))] = x + (y+1)(n+2) = x + yn + 2y + n + 2`
  - `[G(y, F(x,y,n))] = y + x + (y+1)(n+1) = x + yn + 2y + n + 1`
  - Difference: **1 > 0**. ✓
- **Monotonicity:** All partial differences are strictly positive over ℕ (e.g., ∂F/∂x = 1, ∂F/∂y = n+1 ≥ 1, ∂F/∂n = y+1 ≥ 1). ✓

**Result:** Succeeds. Stays within boundary (standard polynomial interpretation).

---

## Method (C): MPO with precedence F > G > S > Z

**Termination proof:**

- **Rule 1:** `F(x, y, Z) >_mpo x` — subterm condition. ✓
- **Rule 2:** `F(x, y, S(n)) >_mpo G(y, F(x, y, n))` — F > G, so check each argument of G:
  - `>_mpo y`: subterm. ✓
  - `>_mpo F(x, y, n)`: same root F, multiset comparison of arguments:
    - `{x, y, S(n)} ≫_mpo {x, y, n}`: remove matching x, y; need `S(n) >_mpo n` (subterm). ✓
    - `F(x,y,S(n)) >_mpo` each argument x, y, n (all subterms). ✓

**Result:** Succeeds. Stays within boundary (standard path ordering).

---

## Method (D): Dependency Pairs with Subterm Criterion

**Termination proof:**

The only defined root symbol is F. The single dependency pair is:

```
F♯(x, y, S(n)) → F♯(x, y, n)
```

Projecting to the 3rd argument (π(F♯) = 3):
- π(LHS) = S(n)
- π(RHS) = n
- **S(n) ▷ n** (proper superterm). ✓

By the subterm criterion, no infinite DP chain can exist (the projected terms would form an infinite strictly decreasing sequence in the well-founded subterm ordering, which is impossible).

**Result:** Succeeds. Stays within boundary (standard DP framework technique).

---

## Method (E): Exponential Interpretation

**Termination proof:**

- **Rule 1:** `[F(x,y,Z)] = (x+y+2)^1 = x + y + 2 > x` since y+2 ≥ 2. ✓
- **Rule 2:** Let B = x + y + 2 ≥ 2.
  - `[F(x,y,S(n))] = B^(n+2) = B · B^(n+1)`
  - `[G(y, F(x,y,n))] = y + B^(n+1)`
  - Need `B · B^(n+1) > y + B^(n+1)`, i.e., `(B−1) · B^(n+1) > y`.
  - Since B−1 = x+y+1 ≥ y+1 and B^(n+1) ≥ 2: **(y+1)·2 = 2y+2 > y**. ✓
- **Monotonicity:** F increases strictly in each argument over ℕ (base ≥ 2, exponent ≥ 1). G and S are trivially monotone. ✓

**Result:** Succeeds. Stays within boundary (valid monotone algebra; choosing exponentiation is a metatheoretic parameter choice, not an imported structural axiom).
