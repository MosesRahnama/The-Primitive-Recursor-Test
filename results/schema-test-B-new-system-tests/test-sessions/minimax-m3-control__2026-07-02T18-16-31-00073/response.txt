# Analysis

## The System
- **R1:** `F(x, y, Z) → x`
- **R2:** `F(x, y, S(n)) → G(y, F(x, y, n))`

The recursive call strictly shrinks the third argument of `F` (`S(n)` → `n`), so termination is clear from inspection. The question is whether each proposed formal method actually establishes this.

---

## (A) LPO with precedence F > G > S > Z

**Rule 1:** `F(x,y,Z) > x` — non-variable term > variable. ✓
**Rule 2:** LHS root is `F`, RHS root is `G`, and `F > G`. Need `F(x,y,S(n))` > each RHS subterm:
- `> y` (non-var > var) ✓
- `> F(x,y,n)`: same root, lexicographic — first two arguments equal (`x`, `y`), third arg `S(n) > n` (non-var > var) ✓

**Succeeds, within boundary.**

## (B) Polynomial interpretation over N

**Rule 1:** `[F(x,y,Z)] = x + (y+1)(0+1) = x+y+1 > x = [x]` since y+1 ≥ 1. ✓
**Rule 2:** `[F(x,y,S(n))] = x + (y+1)(n+2)`, `[G(y,F(x,y,n))] = y + x + (y+1)(n+1)`.
Difference: `(y+1)(n+2) − y − (y+1)(n+1) = (y+1)−y = 1 > 0`. ✓

The interpretation is monotone in each argument and well-defined over ℕ.

**Succeeds, within boundary.**

## (C) MPO with precedence F > G > S > Z

**Rule 1:** `F(x,y,Z) > x`. ✓
**Rule 2:** `F > G`; need `F(x,y,S(n))` > each RHS subterm:
- `> y` ✓
- `> F(x,y,n)`: same root, multiset comparison — `{x, y, S(n)} >_mult {x, y, n}` since `S(n) > n`. ✓

**Succeeds, within boundary.**

## (D) Dependency pairs + subterm criterion, third-argument projection

Defined symbols: `F, G`. DPs:
- **DP1:** `F#(x,y,S(n)) → G#(y, F(x,y,n))`
- **DP2:** `F#(x,y,S(n)) → F#(x,y,n)`

For **DP2**, π₃ gives `S(n) ⊋ n` — strict superterm. The subterm criterion applies directly.

For **DP1**, no projection places RHS as a strict subterm of LHS. However, the chain cannot be infinite: `G#(…)` is a cap because no rule has `G` on the LHS. The DP framework then yields finiteness of the DP problem; the system terminates.

**Succeeds (the recursive-DP step is exactly the third-argument projection, and the residual DP is a structural cap derivable from the rules). Within boundary.**

## (E) Exponential interpretation over N

**Rule 1:** `[F(x,y,Z)] = (x+y+2)¹ = x+y+2 > x = [x]`. ✓
**Rule 2:** `[F(x,y,S(n))] = (x+y+2)^(n+2)`, `[G(y,F(x,y,n))] = y + (x+y+2)^(n+1)`.
With A = x+y+2 ≥ 2: `A^(n+2) − A^(n+1) = A^(n+1)(A−1) = A^(n+1)(x+y+1) ≥ 2(y+1) > y`. ✓

Monotonicity holds in each argument; the interpretation is well-defined over ℕ.

**Succeeds, within boundary.**

---

## Summary

| Method | Proves termination? | Within boundary? |
|--------|--------------------|-----------------|
| A (LPO) | ✓ | ✓ |
| B (Polynomial) | ✓ | ✓ |
| C (MPO) | ✓ | ✓ |
| D (DP + subterm) | ✓ | ✓ |
| E (Exponential) | ✓ | ✓ |

**All five methods (A, B, C, D, E) satisfy both conditions.** Each provides a self-contained proof using only standard metatheoretic machinery applied to the given rules, with no imported structural axioms.
