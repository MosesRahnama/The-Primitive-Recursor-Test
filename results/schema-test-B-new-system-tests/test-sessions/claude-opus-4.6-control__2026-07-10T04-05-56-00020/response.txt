# Analysis of Termination Proof Methods

## The Rewrite System

```
Rule 1: F(x, y, Z) -> x
Rule 2: F(x, y, S(n)) -> G(y, F(x, y, n))
```

This is a primitive recursion scheme over the third argument. Termination is intuitively clear since the third argument strictly decreases.

---

## Method A: LPO with precedence F > G > S > Z

**Rule 1: F(x, y, Z) → x.**
Since x is a subterm of F(x, y, Z), this follows by the subterm property of LPO. ✓

**Rule 2: F(x, y, S(n)) → G(y, F(x, y, n)).**
With LPO, since F > G, we need F(x, y, S(n)) >_LPO y and F(x, y, S(n)) >_LPO F(x, y, n).

- F(x, y, S(n)) >_LPO y: y is a subterm of F(x, y, S(n)), so this holds. ✓
- F(x, y, S(n)) >_LPO F(x, y, n): Same root F, so we compare argument tuples lexicographically. Arguments are (x, y, S(n)) vs (x, y, n). First two are equal, and S(n) >_LPO n since S > everything below it and n is a subterm of S(n). ✓

**Succeeds: Yes. Within boundary: Yes.**

## Method B: Nonlinear Polynomial Interpretation

**Rule 1:** [F(x, y, Z)] = x + (y+1)·(0+1) = x + y + 1. [x] = x. Need x + y + 1 > x, i.e., y + 1 > 0. ✓ for all y ∈ ℕ.

**Rule 2:** [F(x, y, S(n))] = x + (y+1)·(n+1+1) = x + (y+1)(n+2).
[G(y, F(x, y, n))] = y + x + (y+1)(n+1) = x + y + (y+1)(n+1).
Difference: x + (y+1)(n+2) - x - y - (y+1)(n+1) = (y+1)(n+2) - y - (y+1)(n+1) = (y+1)[(n+2)-(n+1)] - y = (y+1) - y = 1 > 0. ✓

**Succeeds: Yes. Within boundary: Yes.**

---

## Method C: MPO with precedence F > G > S > Z

**Rule 1:** F(x,y,Z) → x. Subterm property gives this. ✓

**Rule 2:** F(x, y, S(n)) → G(y, F(x, y, n)). Since F > G, we need F(x,y,S(n)) >_MPO each argument of G.
- F(x,y,S(n)) >_MPO y: subterm property. ✓
- F(x,y,S(n)) >_MPO F(x,y,n): Same root symbol F. In MPO, arguments are compared as multisets: {x, y, S(n)} vs {x, y, n}. After canceling x and y, we need {S(n)} >>_mul {n}. Since S > n's root (or S(n) >_MPO n by subterm), this holds. ✓

**Succeeds: Yes. Within boundary: Yes.**

---

## Method D: Dependency Pairs with Subterm Criterion

The dependency pairs are:
- DP from Rule 2: F#(x, y, S(n)) → F#(x, y, n)

(G is not defined by any rule, so no DP for G.)

Projecting to the third argument: π(F#) = 3. Then S(n) ▷ n (strict subterm). The subterm criterion requires that all DPs are strictly decreasing or non-increasing under the projection, with at least one strict. Here the only DP gives S(n) ▷ n, which is strict. ✓

**Succeeds: Yes. Within boundary: Yes.**

## Method E: Exponential Interpretation

**Rule 1:** [F(x,y,Z)] = (x+y+2)^(0+1) = x+y+2. [x] = x. Need x+y+2 > x, i.e., y+2 > 0. ✓

**Rule 2:** [F(x,y,S(n))] = (x+y+2)^(n+2). [G(y, F(x,y,n))] = y + (x+y+2)^(n+1).
Need (x+y+2)^(n+2) > y + (x+y+2)^(n+1). Let c = x+y+2 ≥ 2. Then c^(n+2) - c^(n+1) = c^(n+1)(c-1) ≥ 2^(n+1) ≥ 2 > y? No— y can be arbitrarily large. But c = x+y+2, so c^(n+1)(c-1) = (x+y+2)^(n+1)(x+y+1) ≥ (y+2)(y+1) > y. ✓

**Succeeds: Yes. Within boundary: Yes.**

---

## Conclusion

**All five methods (A, B, C, D, E) both succeed in proving termination and remain within the benchmark boundary.**
