# Analysis of Termination Proof Methods

## System Recap
```
F(x, y, Z)    -> x
F(x, y, S(n)) -> G(y, F(x, y, n))
```

This is a simple primitive-recursive schema (F "unfolds" S(n) applications of G), and it is amenable to essentially every standard termination technique.

---

## (A) LPO, precedence F > G > S > Z

**Rule 1:** `x` is a proper subterm of `F(x,y,Z)` → oriented trivially by the subterm property.

**Rule 2:** Since F ≻ G, it suffices to show `F(x,y,S(n))` dominates each argument of `G(y,F(x,y,n))`:
- dominates `y` (subterm property);
- dominates `F(x,y,n)` — same head symbol, so compare lexicographically: `(x,y,S(n)) >_lex (x,y,n)` since `S(n) > n` (subterm property).

Both rules orient. **Succeeds.**
**Boundary:** Purely syntactic (precedence + subterm structure of the given signature). **Stays within boundary.**

---

## (B) Nonlinear polynomial interpretation

Rule 1: `[F(x,y,Z)] = x+y+1 > x = [x]` for all `x,y ≥ 0`. ✓
Rule 2: `[LHS] - [RHS] = (y+1)(n+2) - y - (y+1)(n+1) = 1 > 0`. ✓
All interpretations are (weakly/strictly) monotone in every argument.

**Succeeds** (rigid arithmetic check confirms strict decrease on both rules).
**Boundary:** Standard semantic technique using only the given signature; no extra rules/axioms assumed. **Stays within boundary.**

---

## (C) MPO, precedence F > G > S > Z, multiset comparison

**Rule 1:** trivial (subterm).
**Rule 2:** F ≻ G reduces to checking `F(x,y,S(n))` dominates `y` and `F(x,y,n)`; the latter (same head F) reduces to multiset comparison `{x,y,S(n)} >> {x,y,n}`, which holds after cancelling the common `x,y` and comparing `S(n) > n`.

**Succeeds.**
**Boundary:** Same syntactic apparatus as LPO, just multiset instead of lexicographic status — no external axioms. **Stays within boundary.**

---

## (D) Dependency pairs + subterm criterion (projection to 3rd argument of F)

Only defined symbol is F (G, S, Z are constructors here). Rule 1 yields no DP (RHS has no defined-symbol subterm). Rule 2 yields the single DP:
```
F#(x,y,S(n)) -> F#(x,y,n)
```
Projecting to argument 3: `π(l)=S(n)`, `π(r)=n`, and `S(n) ⊐ n` (proper subterm) — this is exactly what the subterm criterion requires to eliminate the only cycle in the dependency graph.

**Succeeds.**
**Boundary:** The subterm criterion is a self-contained syntactic device (marked symbols + subterm order); it needs no usable-rules argument here and imports nothing beyond the rule structure. **Stays within boundary.**

---

## (E) Exponential interpretation

Rule 1: `[LHS]=(x+y+2)^1=x+y+2 > x`. ✓
Rule 2: with `k=x+y+2≥2`,
`[LHS]-[RHS] = (k-1)k^{n+1} - y ≥ (k-1)k - (k-2) = (k-1)^2+1 > 0` for all valid `x,y,n`.
Monotonicity in each argument holds (base ≥ 2, exponent/base increasing).

**Succeeds** (verified explicitly, though it is a needlessly heavy tool for this simple system).
**Boundary:** Still just a semantic interpretation of the given symbols into (N, >); no external structural assumption is introduced. **Stays within boundary.**

## Conclusion

All five methods **A, B, C, D, and E** succeed in proving termination of the given system, and all of them do so using only structure intrinsic to the rules (precedences, subterm relations, or monotone interpretations over the given signature) — none imports axioms or assumptions beyond what the rewrite system itself provides. Hence **all five methods (A–E) satisfy both conditions.**
