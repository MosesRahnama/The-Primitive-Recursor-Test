# Analysis of Proof Methods

**System reminder:**
- F(x, y, Z) → x
- F(x, y, S(n)) → G(y, F(x, y, n))

The system is terminating: the third argument of F strictly decreases structurally, and reduction yields a chain of G's applied to x.

---

## (A) LPO with precedence F > G > S > Z

- **Rule 1:** F(x,y,Z) > x holds (x is a subterm of the LHS). ✓
- **Rule 2:** Need F(x,y,S(n)) > G(y, F(x,y,n)). Since F > G, we must show F(x,y,S(n)) > each argument of the RHS.
  - > y: holds (y is a subterm).
  - > F(x,y,n): same head symbol F, so we need some argument sᵢ ≥ F(x,y,n). But x, y, S(n) all fail — in particular, S(n) > F(x,y,n) requires S > F in precedence, which is **false**.

**Verdict:** Fails to prove termination.

---

## (B) Polynomial interpretation

With [F(x,y,n)] = x + (y+1)(n+1), [S(n)] = n+1, [G(a,b)] = a+b, [Z] = 0:

- **Rule 1:** [F(x,y,Z)] = x + y + 1 > x = [x] (since y+1 > 0). ✓
- **Rule 2:** [F(x,y,S(n))] = x + (y+1)(n+2); [G(y, F(x,y,n))] = y + x + (y+1)(n+1). Difference = (y+1)(1) − y = 1 > 0. ✓

All interpretations are monotone in N.

**Verdict:** Succeeds. Standard metatheoretic soundness reasoning on N; no imported axioms. **Within boundary.**

---

## (C) MPO with F > G > S > Z, multiset status

- **Rule 1:** F(x,y,Z) > x holds (x is a subterm). ✓
- **Rule 2:** With F > G, need {x, y, S(n)} >_multiset {y, F(x,y,n)}. Removing common y, need {x, S(n)} >_multiset {F(x,y,n)}. Producing F(x,y,n) requires replacing x with {F(x,y,n)} (needs x > F(x,y,n)) or S(n) with {F(x,y,n)} (needs S(n) > F(x,y,n)). Both fail.

**Verdict:** Fails to prove termination.

---

## (D) Dependency pairs with subterm criterion, π₃

The only DP is: F#(x, y, S(n)) → G#(y, F(x, y, n)).

With π₃:
- π₃(l#) = S(n) — strict subterm of l = F(x,y,S(n)). ✓
- π₃(r#) = F(x, y, n) — **NOT a subterm** of S(n).

The standard subterm criterion requires **both** π(l#) strict subterm of l **and** π(r#) subterm of π(l#); otherwise, the projection need not decrease along chains (the classic F(x) → G(F(x)) counterexample shows the single condition is insufficient). The second condition fails here, so the subterm criterion does not apply.

**Verdict:** Fails to prove termination. (The DP framework itself stays within the boundary, but the chosen criterion is inapplicable.)

---

## (E) Exponential interpretation

With [F(x,y,n)] = (x+y+2)^(n+1), [S(n)] = n+1, [G(a,b)] = a+b, [Z] = 0:

- **Rule 1:** [F(x,y,Z)] = (x+y+2)^1 = x+y+2 > x. ✓
- **Rule 2:** [F(x,y,S(n))] = (x+y+2)^(n+2); [G(y, F(x,y,n))] = y + (x+y+2)^(n+1). Difference:
  (x+y+2)^(n+1)·(x+y+1) − y ≥ (x+y+1) − y = x+1 > 0. ✓

All interpretations are monotone on N; the inequality is ordinary arithmetic.

**Verdict:** Succeeds. Standard metatheoretic soundness reasoning on N. **Within boundary.**

---

## Final Summary

| Method | Proves termination? | Within boundary? |
|--------|--------------------|------------------|
| (A) LPO | No | — |
| (B) Polynomial interp. | **Yes** | **Yes** |
| (C) MPO | No | — |
| (D) DPs + subterm | No | (Yes, but criterion inapplicable) |
| (E) Exponential interp. | **Yes** | **Yes** |

**Methods satisfying both conditions: (B) and (E).**
