# Analysis

## The System
```
F(x, y, Z) → x
F(x, y, S(n)) → G(y, F(x, y, n))
```

This is the well-known fold/unfold pattern: each application of the second rule peels off one `S` and wraps a `G`, eventually reaching `Z` and reducing to `x`. Termination is straightforward — the structural recursion on the third argument terminates.

---

## Method (A): LPO with precedence F > G > S > Z

- **Rule 1:** F(x,y,Z) > x. F > x holds because x is a variable (variables are minimal in LPO). ✓
- **Rule 2:** F(x,y,S(n)) > G(y, F(x,y,n)). Since F > G in precedence, it suffices that F(x,y,S(n)) > y (variable, ✓) and F(x,y,S(n)) > F(x,y,n). For the same-symbol case: F(x,y,S(n)) > x, y, n all hold (variables), and the multiset {x, y, S(n)} dominates {x, y, n} since S(n) > n. ✓

**Result: Succeeds ✓, within boundary ✓**

---

## Method (B): Nonlinear polynomial interpretation

- **Rule 1:** [F(x,y,Z)] = x + (y+1)·1 = x+y+1. Strictly > [x] = x iff y+1 > 0, true for y ∈ ℕ. ✓
- **Rule 2:** LHS = x + (y+1)(n+2). RHS = y + x + (y+1)(n+1) = x + y + (y+1)(n+1).  
  Difference: (y+1)(n+2) − [y + (y+1)(n+1)] = (y+1)n + 2(y+1) − y − (y+1)n − (y+1) = y+1 > 0. ✓

**Result: Succeeds ✓, within boundary ✓**

---

## Method (C): MPO with precedence F > G > S > Z, multiset status

- **Rule 1:** F(x,y,Z) > x. Variable case. ✓
- **Rule 2:** F > G in precedence, so we need F(x,y,S(n)) > y and F(x,y,S(n)) > F(x,y,n). The latter is the same-symbol multiset rule: {x, y, S(n)} > {x, y, n} because S(n) > n (S > n since n is a variable; actually we need S(n) > n in MPO, which holds because n is a variable, so the LHS term S(n) > n, and from the multiset {S(n)} > {n}). ✓

**Result: Succeeds ✓, within boundary ✓**

---

## Method (D): Dependency pairs with subterm criterion, 3rd-argument projection

The only DP (F is the sole defined symbol — G never appears at LHS root) is:
```
F#(x, y, S(n)) → F#(x, y, n)
```
With projection π = 3: π(LHS) = S(n), π(RHS) = n. Since n is a **strict syntactic subterm** of S(n), the subterm criterion is satisfied: every DP step strictly shrinks the third argument, and the subterm relation is well-founded on first-order terms. The single chain terminates in one step (the next F# would have its third argument already in non-S form, blocking the DP). ✓

**Result: Succeeds ✓, within boundary ✓**

---

## Method (E): Exponential interpretation

- **Rule 1:** [F(x,y,Z)] = (x+y+2)¹ = x+y+2 > x iff y+2 > 0, true for y ∈ ℕ. ✓
- **Rule 2:** LHS = (x+y+2)^(n+2). RHS = y + (x+y+2)^(n+1).  
  Let u = x+y+1 ≥ 1. Then LHS − RHS = (u+1)^(n+1)[(u+1) − 1] − y = (u+1)^(n+1)·u − y ≥ u − y = x+1 > 0. ✓

**Result: Succeeds ✓, within boundary ✓**

---

## Boundary Check

Each method (A–E) is a standard first-order termination technique that analyzes the rules directly using only ordinary metatheoretic reasoning (precedences, polynomial/interpretation algebra on ℕ, multiset/well-founded subterm orders). None of them imports arbitrary global structural axioms or object-level assumptions not derivable from the rules. All five stay within the original benchmark boundary.
