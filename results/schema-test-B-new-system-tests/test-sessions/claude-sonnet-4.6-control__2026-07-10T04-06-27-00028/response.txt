## Method A: LPO with F > G > S > Z

**R1:** F(x, y, Z) →_LPO x. The right-hand side x is a subterm of the left-hand side, so LPO handles this trivially. ✓

**R2:** F(x, y, S(n)) →_LPO G(y, F(x, y, n)).
- The root F > G, so we need each argument of G to be strictly less than F(x, y, S(n)) under LPO.
- y is a subterm of the left side: ✓
- F(x, y, n): same root F, so compare arguments lexicographically. First args equal (x=x), second equal (y=y), third: need S(n) >_LPO n. Since S > n is not valid (n is a variable, not headed by anything ≤ S)... but S(n) >_LPO n because n is a proper subterm of S(n). ✓

**Both rules verified. Method A succeeds.** Within boundary (uses only the given rules). ✓

## Method B: Polynomial interpretation

**R1:** [F(x,y,Z)] = x + (y+1)(0+1) = x + y + 1. [x] = x. Need x + y + 1 > x, i.e., y + 1 > 0. ✓ (over N)

**R2:** [F(x,y,S(n))] = x + (y+1)(n+2). [G(y, F(x,y,n))] = y + x + (y+1)(n+1) = x + y + (y+1)(n+1).
Need x + (y+1)(n+2) > x + y + (y+1)(n+1).
Difference: (y+1)(n+2) - y - (y+1)(n+1) = (y+1)(n+2) - (y+1)(n+1) - y = (y+1) - y = 1 > 0. ✓

**Both rules verified. Method B succeeds.** Within boundary. ✓

## Method E: Exponential interpretation

**R1:** [F(x,y,Z)] = (x+y+2)^1 = x+y+2. [x] = x. Need x+y+2 > x, i.e., y+2 > 0. ✓
