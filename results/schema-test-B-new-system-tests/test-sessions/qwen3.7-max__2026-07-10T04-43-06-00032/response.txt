# Analysis of Termination Proof Methods

## System Overview

The TRS has two rules:
1. `F(x, y, Z) -> x`
2. `F(x, y, S(n)) -> G(y, F(x, y, n))`

The third argument of `F` acts as a unary natural number (Peano-style). Each recursive call strips one `S`, so the system clearly terminates.

---

## Method-by-Method Analysis

### (A) LPO with precedence F > G > S > Z

**Rule 1:** `F(x, y, Z) >_lpo x` — holds by the subterm case (x is the first argument). ✓

**Rule 2:** `F(x, y, S(n)) >_lpo G(y, F(x, y, n))`
- Since F > G in precedence, we need `s >_lpo y` and `s >_lpo F(x, y, n)`.
- `s >_lpo y`: subterm case. ✓
- `s >_lpo F(x, y, n)`: same-head case. Lexicographic comparison of arguments: `x = x`, `y = y`, `S(n) >_lpo n` (subterm). Side conditions `s >_lpo x, y, n` all hold by subterm. ✓

**Result:** Succeeds. Stays within boundary (purely syntactic order on terms). ✓

---

### (B) Nonlinear polynomial interpretation

| Rule | LHS | RHS | Difference |
|------|-----|-----|------------|
| 1 | x + y + 1 | x | y + 1 ≥ 1 > 0 ✓ |
| 2 | x + (y+1)(n+2) | y + x + (y+1)(n+1) | (y+1) − y = 1 > 0 ✓ |

All interpretation functions are strictly monotone in every argument over ℕ (partial derivatives are all positive). The domain (ℕ, >) is well-founded.

**Result:** Succeeds. Stays within boundary (semantic algebra over ℕ, no imported axioms). ✓

---

### (C) MPO with precedence F > G > S > Z

**Rule 1:** `F(x, y, Z) >_mpo x` — subterm case. ✓

**Rule 2:** `F(x, y, S(n)) >_mpo G(y, F(x, y, n))`
- F > G, so we need `s >_mpo y` (subterm ✓) and `s >_mpo F(x, y, n)`.
- Same-head case with multiset comparison: `{x, y, S(n)} >> {x, y, n}` reduces to `{S(n)} >> {n}`, which holds since `S(n) >_mpo n` by subterm. Side conditions `s >_mpo x, y, n` all hold by subterm. ✓

**Result:** Succeeds. Stays within boundary. ✓

---

### (D) Dependency pairs with subterm criterion

The only defined symbol is F. The rules yield a single dependency pair:

`F#(x, y, S(n)) -> F#(x, y, n)`

Projecting to the third argument of F#:
- LHS projected: `S(n)`
- RHS projected: `n`
- `S(n) ⊳ n` (proper subterm relation)

Since the sole DP strictly decreases under the projection, the subterm criterion removes it. The DP set becomes empty, establishing finiteness.

**Result:** Succeeds. Stays within boundary (syntactic DP framework, no external axioms). ✓

---

### (E) Exponential interpretation

| Rule | LHS | RHS |
|------|-----|-----|
| 1 | x + y + 2 | x |
| 2 | B^(n+2) | y + B^(n+1), where B = x+y+2 ≥ 2 |

**Rule 1:** x + y + 2 > x since y + 2 > 0. ✓

**Rule 2:** B^(n+2) − y − B^(n+1) = B^(n+1)(B − 1) − y = (x+y+2)^(n+1)(x+y+1) − y.
Since (x+y+2)^(n+1) ≥ x+y+2, the expression is ≥ (x+y+2)(x+y+1) − y = (x+y)² + 3x + 2y + 2 ≥ 2 > 0. ✓

All functions are strictly monotone over ℕ (base ≥ 2 > 1 ensures monotonicity in the exponent; linearity in x, y ensures monotonicity in those arguments). Well-foundedness of (ℕ, >) is standard.

**Result:** Succeeds. Stays within boundary (semantic algebra, no imported axioms). ✓

---

## Conclusion

**All five methods (A, B, C, D, E) satisfy both conditions.** Each one successfully orients or eliminates all rules/pairs, establishing strong normalization using only the given rewrite rules, without importing any structural axioms or object-level assumptions.
