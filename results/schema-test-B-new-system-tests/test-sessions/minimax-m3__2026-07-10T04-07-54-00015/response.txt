# Analysis of Termination Proof Methods

The system is clearly terminating: in `F(x, y, S(n)) → G(y, F(x, y, n))`, the third argument strictly shrinks (from `S(n)` to `n`).

## (A) LPO with precedence F > G > S > Z

**Rule 1**: `F(x, y, Z) >_lpo x` — the variable `x` appears strictly inside `F(x, y, Z)`. ✓
**Rule 2**: `F(x, y, S(n)) >_lpo G(y, F(x, y, n))` — since F > G, we need `F(x,y,S(n)) >_lpo y` (variable occurrence) and `F(x,y,S(n)) >_lpo F(x,y,n)` (lexicographic: equal on first two args, then `S(n) >_lpo n` by variable occurrence). ✓

**Succeeds: yes. Stays within boundary: yes.**

## (B) Nonlinear Polynomial Interpretation

`[F(x,y,Z)] = x + y + 1 > x` since `y + 1 > 0` for `y ∈ ℕ`. ✓
`[F(x,y,S(n))] - [G(y, F(x,y,n))] = (x + (y+1)(n+2)) - (y + x + (y+1)(n+1)) = (y+1) - y = 1 > 0`. ✓

The polynomial is weakly monotone in all three arguments (slopes `1`, `n+1`, `y+1`, all ≥ 0).

**Succeeds: yes. Stays within boundary: yes.**

## (C) Multiset Path Order with F > G > S > Z

**Rule 1**: `F(x, y, Z) >_mpo x` by variable occurrence. ✓
**Rule 2**: `F(x, y, S(n)) >_mpo G(y, F(x, y, n))` requires F > G (✓) and `F(x,y,S(n)) >_mpo y` (variable occurrence ✓). For the same-head case `F(x,y,S(n)) >_mpo F(x,y,n)`, the multiset `{x, y, S(n)}` dominates `{x, y, n}` by replacing `S(n)` with `n` (where `S(n) >_mpo n`). ✓

**Succeeds: yes. Stays within boundary: yes.**

## (D) Dependency Pairs with Subterm Criterion, Third-Argument Projection

The only DP is `F#(x, y, S(n)) → F#(x, y, n)` (G is not a defined symbol, so no DP is generated for the `G(...)` subterm).

Under the projection `π(F#) = [3]`: the projected pair becomes `S(n) → n`. Since `n` is a strict subterm of `S(n)`, we have `S(n) >_subterm n`, and the strict subterm order is well-founded. The argument-filter + subterm relation gives a valid reduction pair, so the DP chain terminates.

**Succeeds: yes. Stays within boundary: yes.**

## (E) Exponential Interpretation over ℕ

**Rule 1**: `[F(x,y,Z)] = (x+y+2)^1 = x+y+2 > x` since `y+2 > 0`. ✓
**Rule 2**: 
`[F(x,y,S(n))] = (x+y+2)^(n+2)`
`[G(y, F(x,y,n))] = y + (x+y+2)^(n+1)`
Difference: `(x+y+2)^(n+1)·(x+y+2) − y − (x+y+2)^(n+1) = (x+y+2)^(n+1)·(x+y+1) − y ≥ (y+2)(y+1) − y = y² + 2y + 2 > 0`. ✓

The interpretation is weakly monotone in each argument.

**Succeeds: yes. Stays within boundary: yes.**
