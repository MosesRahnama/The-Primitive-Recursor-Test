# Analysis of Each Proof Method

## Method (A): LPO with precedence F > G > S > Z

**Rule 1:** `F(x, y, Z) → x`. Since `s₁ = x ≥ x`, we have `F(x,y,Z) > x`. ✓

**Rule 2:** `F(x, y, S(n)) → G(y, F(x,y,n))`. We have `F > G`. Need `F(x,y,S(n)) > y` (✓ via `s₂ = y`) and `F(x,y,S(n)) > F(x,y,n)`. Comparing arguments lexicographically: positions 1, 2 are equal; at position 3, `S(n) > n` (via subterm rule). ✓

**Succeeds.** Stays within boundary (purely syntactic over the rules).

## Method (B): Polynomial interpretation over N

**Rule 1:** `⟦F(x,y,Z)⟧ = x + y + 1 > x = ⟦x⟧` (since y ≥ 0). ✓

**Rule 2:** `⟦F(x,y,S(n))⟧ = x + (y+1)(n+2)`. `⟦G(y,F(x,y,n))⟧ = y + x + (y+1)(n+1)`. The difference is `(y+1)(n+2) − y − (y+1)(n+1) = (y+1) − y = 1 > 0`. ✓

**Succeeds.** Stays within boundary.

## Method (C): MPO with precedence F > G > S > Z

**Rule 1:** `F(x,y,Z) > x` via `s₁ = x`. ✓

**Rule 2:** `F > G` ✓, but the multiset comparison `{x, y, S(n)} >_mult {y, F(x,y,n)}` requires that for the term `F(x,y,n)` on the right, some term on the left strictly dominates it in MPO. The candidates are `x`, `y` (variables, hence smaller than any function symbol) and `S(n)` (top symbol `S` has lower precedence than `F`, so `S(n) <_MPO F(x,y,n)` since `S(n)` is not a subterm of `F(x,y,n)`). **No element dominates `F(x,y,n)`.** ✗

**Fails.** Even setting aside the boundary, the method does not establish termination.

## Method (D): Dependency pairs with subterm criterion, projecting to position 3

The only defined symbol with a recursive rule is `F`. The unique dependency pair is:

`F#(x, y, S(n)) → F#(x, y, n)`

(Projecting to position 3:) at the projected position, `l[3] = S(n)` and `r[3] = n`, and `n` is a **strict subterm** of `S(n)`. The component-wise subterm criterion with projection is satisfied, so the DP is removed. With no remaining DPs, termination follows.

**Succeeds.** Stays within boundary (the DPs are derived mechanically from the rules; the criterion is a standard component of the DP framework).

## Method (E): Exponential interpretation over N

**Rule 1:** `⟦F(x,y,Z)⟧ = (x+y+2)¹ = x+y+2 > x = ⟦x⟧`. ✓

**Rule 2:** `⟦F(x,y,S(n))⟧ = (x+y+2)^(n+2)`. `⟦G(y,F(x,y,n))⟧ = y + (x+y+2)^(n+1)`.

Let `A = (x+y+2)^(n+1) ≥ 2`. The difference is:
`A·(x+y+2) − y − A = A·(x+y+1) − y ≥ A·1 − y = A − y ≥ 2 − y`.

If `y = 0`: `A − 0 = A ≥ 2 > 0`. If `y ≥ 1`: `A·(x+y+1) ≥ 2·(0+2) = 4 > y`. In all cases, strict decrease. ✓

**Succeeds.** Stays within boundary.

---

## Summary

| Method | Proves termination? | Within boundary? |
|--------|--------------------|------------------|
| A (LPO)               | **Yes** | **Yes** |
| B (Polynomial interp.)| **Yes** | **Yes** |
| C (MPO)               | **No**  | —      |
| D (DP + subterm proj.)| **Yes** | **Yes** |
| E (Exponential interp.) | **Yes** | **Yes** |

**Methods A, B, D, and E** satisfy both conditions. Method C fails to prove termination — the MPO cannot orient the second rule because the recursive call `F(x, y, n)` is not strictly below any argument of `F(x, y, S(n))` in the MPO.
