# Analysis of the TRS and Proof Methods

The system computes a left-fold over a unary counter, with `F(x,y,Z) → x` as the base case and `F(x,y,S(n)) → G(y, F(x,y,n))` recursing on `n`. It is clearly terminating, but the question is which of the listed methods actually establish this.

## (A) Lexicographic Path Order — F > G > S > Z

**Succeeds.** Check both rules:
- `F(x,y,Z) > x`: `x` is a strict subterm of `F(x,y,Z)` (variable case in LPO). ✓
- `F(x,y,S(n)) > G(y, F(x,y,n))`: `F > G` in prec, and we need `F > y` (subterm) and `F > F(x,y,n)` (lex on arguments: `x=x, y=y, S(n)>n` since `n` occurs in `S(n)`). ✓

**Within boundary.** LPO is a standard, sound metatheoretic ordering. ✓

## (B) Polynomial Interpretation over ℕ

**Succeeds.** With `[F(x,y,n)] = x + (y+1)(n+1)`:
- Rule 1: `[F(x,y,Z)] = x + y + 1 > x = [x]`. ✓
- Rule 2: `[F(x,y,S(n))] − [G(y, F(x,y,n))] = (y+1)(n+2) − y − (y+1)(n+1) = (y+1) − y = 1 > 0`. ✓

**Within boundary.** Polynomial interpretations are ordinary termination techniques. ✓

## (C) Multiset Path Order — F > G > S > Z

**Fails.** For `F(x,y,S(n)) → G(y, F(x,y,n))`, since `F > G` the multiset case requires
`{x, y, S(n)} >_mult {y, F(x,y,n)}`.
Matching `y`→`y` is fine, but matching `F(x,y,n)` requires some LHS argument `a ≥ F(x,y,n)` in MPO:
- `x ≥ F(x,y,n)`? No — `F(x,y,n)` is not a subterm of variable `x`.
- `y ≥ F(x,y,n)`? No.
- `S(n) ≥ F(x,y,n)`? Heads differ with `S <_F F`; subterm case fails since `F(x,y,n)` is not a subterm of `S(n)`.

The multiset comparison fails, so the second rule is not handled. **No precedence ordering rescues this** — the LHS's structural elements cannot dominate the RHS's `F(x,y,n)` because `F` outranks `S`.

**Within boundary** as a technique, but the proof attempt fails.

## (D) Dependency Pairs + Subterm Criterion, Projecting to 3rd Argument of F

**Succeeds.** The relevant DP is
`F#(x,y,S(n)) → G#(y, F(x,y,n))`.

Projecting the LHS to its 3rd argument gives `S(n)`. The RHS contains the recursive call `F(x,y,n)`, whose 3rd argument is `n`. Since `n` is a strict subterm of `S(n)`, the projection decreases along any chain. Concretely, the criterion "some subterm of `r` lies strictly below `π(l)`" is satisfied with `π(l) = S(n)` and the subterm `n ⊂ G#(y, F(x,y,n))`. This rules out infinite `(P, R)`‑chains by the well-foundedness of the strict subterm relation.

**Within boundary.** The DP framework and subterm/subterm‑projection criterion are standard, derivable metatheory, not imported axioms. ✓

## (E) Exponential Interpretation over ℕ

**Succeeds.** With `[F(x,y,n)] = (x+y+2)^(n+1)`:
- Rule 1: `[F(x,y,Z)] = x+y+2 > x`. ✓
- Rule 2: `[F(x,y,S(n))] − [G(y, F(x,y,n))] = (x+y+2)^(n+1)·(x+y+1) − y ≥ (x+y+1)(x+y+2) − y`, which for `x, y, n ≥ 0` is at least `2 > 0`. ✓

**Within boundary.** This is a standard monotone interpretation over ℕ. ✓
