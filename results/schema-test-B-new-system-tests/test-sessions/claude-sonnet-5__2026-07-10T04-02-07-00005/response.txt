# Analysis of Each Proof Method

**The system** implements simple recursion on the third argument of `F`, with `x` and `y` carried unchanged. This is a very simple structurally-recursive definition, so it is worth checking each method carefully rather than assuming failure.

---

## (A) LPO, precedence F > G > S > Z

*Rule 1:* `F(x,y,Z) -> x`. Since `x` is a direct argument of the LHS, this is an instance of the subterm property — holds automatically.

*Rule 2:* `F(x,y,S(n)) -> G(y,F(x,y,n))`. Since `F > G`, it suffices that `F(x,y,S(n)) >_lpo y` (subterm case) and `F(x,y,S(n)) >_lpo F(x,y,n)`. For the latter, same head symbol ⇒ compare lexicographically: `x=x`, `y=y`, `S(n) > n` (subterm). This gives the needed strict decrease.

**(1) Succeeds.** **(2) Stays within boundary** — purely syntactic, uses only precedence and subterm structure derivable from the rules.

---

## (B) Nonlinear polynomial interpretation

Checking both rules symbolically:
- Rule 1: `x+(y+1) > x` ⇔ `y+1>0` — always true.
- Rule 2: `x+(y+1)(n+2)` vs `y+x+(y+1)(n+1)` — difference simplifies to exactly `1 > 0` for all `x,y,n`.

Both strict inequalities hold for all naturals; the interpretation is monotone.

**(1) Succeeds.** **(2) Stays within boundary** — standard monotone algebra over ℕ, nothing beyond the given signature/rules is assumed.

---

## (C) MPO, precedence F > G > S > Z, multiset comparison

Subterm case for Rule 1 is identical to LPO (clause (b) is shared by LPO/MPO). For Rule 2, comparing multisets `{x,y,S(n)}` vs `{x,y,n}`: remove `S(n)`, add `n`, and `S(n) > n` justifies the multiset-order requirement (matched elements `x,x`, `y,y` cancel).

**(1) Succeeds** (multiset comparison degenerates favorably here since only one argument changes). **(2) Stays within boundary** — same syntactic justification as (A).

---

## (D) Dependency pairs + subterm criterion (projection to 3rd argument)

Only defined symbol is `F`; the only DP is:
`F#(x,y,S(n)) -> F#(x,y,n)`.

Projecting to argument 3: `π(lhs)=S(n)`, `π(rhs)=n`, and `S(n) ⊳ n` (proper subterm). This is the only SCC, and it is oriented strictly, so the DP problem is finite.

**(1) Succeeds.** **(2) Stays within boundary** — the subterm criterion is a purely syntactic check on term positions; no reduction pair/interpretation beyond the rule structure is needed.

---

## (E) Exponential interpretation

Let `k = x+y+2 ≥ 2`.
- Rule 1: `x+y+2 > x` — trivial.
- Rule 2: need `k^(n+2) > y + k^(n+1)`, i.e. `k^(n+1)(k-1) > y`. Since `k-1 = x+y+1 ≥ y+1` and `k^(n+1)≥1`, we get `k^(n+1)(k-1) ≥ y+1 > y`.

All monotonicity conditions hold (base ≥2, so increasing any argument strictly increases the value).

**(1) Succeeds.** **(2) Stays within boundary** — still a well-founded, monotone interpretation over ℕ using ordinary arithmetic; no external assumptions imported.
