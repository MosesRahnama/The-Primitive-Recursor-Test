# Analysis of the Rewrite System

The system computes `F(x, y, Sⁿ(Z)) = n·y + x`, with recursion strictly decreasing in the third argument of `F`.

## Method (A): LPO with F > G > S > Z

**Fails on Rule 2.** Orienting `F(x, y, S(n)) → G(y, F(x, y, n))` requires `F(x,y,S(n)) > F(x,y,n)`. Since both have head `F`, LPO falls back to comparing argument multisets `{x, y, S(n)}` vs `{x, y, n}`. No single element of the LHS multiset dominates all elements of the RHS multiset:
- `x`, `y`: are variables, hence `< F(x,y,n)`.
- `S(n)`: does not contain `x` or `y` as subterms, so `S(n) ≯ x` and `S(n) ≯ y`.

LPO cannot orient the rule. **Method A fails.**

## Method (B): Nonlinear Polynomial Interpretation

Check both rules over ℕ with `[Z]=0`, `[S(n)]=n+1`, `[G(a,b)]=a+b`, `[F(x,y,n)]=x+(y+1)(n+1)`:

- **Rule 1:** `[F(x,y,Z)] = x+(y+1)(1) = x+y+1 > x = [x]`. ✓
- **Rule 2:** `[F(x,y,S(n))] = x+(y+1)(n+2)` vs `[G(y,F(x,y,n))] = y + x + (y+1)(n+1)`. Difference is `(y+1)(n+2) − y − (y+1)(n+1) = (y+1) − y = 1 > 0`. ✓

Monotonicity is clear. **Method B succeeds and stays within the boundary** — only standard arithmetic over ℕ is used.

## Method (C): MPO with F > G > S > Z, all arguments as multisets

For first-order terms, MPO with all-multiset status is identical to multiset LPO. The same obstruction as in (A) applies: `F(x,y,S(n))` and `F(x,y,n)` have identical heads, and no single argument of the LHS dominates `F(x,y,n)` under multiset comparison. **Method C fails.**

## Method (D): Dependency Pairs + Subterm Criterion (project to 3rd arg of F)

The relevant dependency pair is:
$$F^\#(x, y, S(n)) \to F^\#(x, y, n)$$

Applying the projection `π₃` (third argument):
- `π₃(LHS) = S(n)`
- `π₃(RHS) = n`

Since `n` is a **strict subterm** of `S(n)`, the subterm criterion is satisfied. The DP chain is immediately covered, establishing termination. **Method D succeeds and stays within the boundary** — the subterm criterion is a general derived technique of the DP framework, not an extra object-level assumption.

## Method (E): Exponential Interpretation

Let `a = x+y+2`. With `[Z]=0`, `[S(n)]=n+1`, `[G(a,b)]=a+b`, `[F(x,y,n)]=a^(n+1)`:

- **Rule 1:** `[F(x,y,Z)] = a^1 = x+y+2 > x`. ✓
- **Rule 2:** `[F(x,y,S(n))] = a^(n+2) = a^(n+1)·a` vs `[G(y,F(x,y,n))] = y + a^(n+1)`. The difference is
  $$a^{n+1}(a-1) - y = a^{n+1}(x+y+1) - y.$$
  Setting `m = x+y`, this is `(m+2)^(n+1)·(m+1) − y ≥ (m+2)(m+1) − y ≥ m² + 3m + 2 − m = m² + 2m + 2 > 0`. ✓

Monotonicity holds. **Method E succeeds and stays within the boundary.**
