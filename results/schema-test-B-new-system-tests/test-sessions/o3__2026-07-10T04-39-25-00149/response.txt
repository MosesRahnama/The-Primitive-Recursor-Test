  2. F(x,y,S(n))     → G(y, F(x,y,n))

(A) LPO with precedence F > G > S > Z  
• Rule 1: F(x,y,Z) is a proper super-term of x ⇒ satisfied.  
• Rule 2: root symbols F > G.  
  – Need F(x,y,S(n)) > y   (function term > variable) ✓  
  – Need F(x,y,S(n)) > F(x,y,n).  Same root, compare lexicographically:
    S(n) > n because S(n) is a function term containing n ⇒ ✓  
  ⇒ Both rules oriented, LPO terminates.  
• Uses no extra axioms. ✔  
Result: succeeds, within boundary.

(B) Non-linear polynomial interpretation over ℕ
