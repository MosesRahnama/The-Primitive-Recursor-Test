- Rule 1: `F(x, y, Z) -> x`
- Rule 2: `F(x, y, S(n)) -> G(y, F(x, y, n))`

## Method (A): LPO with precedence F > G > S > Z

**Rule 1:** `F(x,y,Z) > x`. The RHS is a proper subterm of the LHS, so LPO holds.

**Rule 2:** `F(x,y,S(n)) > G(y, F(x,y,n))`. Since F > G, we need LHS to dominate each argument of G:
- `F(x,y,S(n)) > y`: yes, y is a subterm.
- `F(x,y,S(n)) > F(x,y,n)`: compare F=F lexicographically. Args (x,y,S(n)) vs (x,y,n): first two equal, then need `S(n) > n` under LPO — yes, since n is a subterm of S(n).

Both hold. **Succeeds.** Stays within boundary (LPO uses only the given signature and a precedence).

## Method (B): Polynomial interpretation

`[F(x,y,n)] = x + (y+1)(n+1)`, `[S(n)] = n+1`, `[G(a,b)] = a+b`, `[Z]=0`.

**Rule 1:** LHS = `x + (y+1)(0+1) = x + y + 1`. RHS = `x`. Need `x+y+1 > x`: yes (strict).

**Rule 2:** LHS = `x + (y+1)(S(n)+1) = x + (y+1)(n+2)`.
RHS = `[G(y, F(x,y,n))] = y + [F(x,y,n)] = y + x + (y+1)(n+1)`.
Difference LHS − RHS = `(y+1)(n+2) − (y+1)(n+1) − y = (y+1) − y = 1 > 0`. Strict.

Both rules strictly decrease. **Succeeds.** Stays within boundary (standard interpretation over N).

## Method (C): MPO with precedence F > G > S > Z

**Rule 1:** RHS `x` is a subterm of LHS: holds.

**Rule 2:** `F(x,y,S(n)) > G(y, F(x,y,n))` with F > G. Need LHS to dominate each arg of G:
- `F(x,y,S(n)) > y`: subterm, yes.
- `F(x,y,S(n)) > F(x,y,n)`: same head F, compare arguments **as multisets** (MPO). Multiset {x,y,S(n)} vs {x,y,n}. Remove common x,y; compare {S(n)} vs {n}. Need `S(n) > n`: yes (n subterm). So the multiset comparison succeeds.

Both hold. **Succeeds.** Stays within boundary. (Note: MPO works here since the difference reduces cleanly, though MPO is generally weaker than LPO for lexicographic structure — here it still applies.)

## Method (D): Dependency pairs with subterm criterion

Dependency pairs (only Rule 2 has a defined symbol nested):
- `F#(x,y,S(n)) -> F#(x,y,n)` (from the F inside G).

(The G call is not a DP since G is not defined by any rule — G is a constructor here.)

Subterm criterion: projection π picking argument 3 of F#. Then π(F#(x,y,S(n))) = S(n), π(F#(x,y,n)) = n. We need `S(n) ▷ n` (proper subterm): yes, n is a proper subterm of S(n).

The single DP is strictly decreasing under the projection, and the cycle is handled. **Succeeds.** Stays within boundary (DP framework derives everything from the rules).

## Method (E): Exponential interpretation

`[F(x,y,n)] = (x+y+2)^(n+1)`, `[S(n)]=n+1`, `[G(a,b)]=a+b`, `[Z]=0`.

**Rule 1:** LHS = `(x+y+2)^1 = x+y+2`. RHS = `x`. Need `x+y+2 > x`: yes.

**Rule 2:** LHS = `(x+y+2)^(S(n)+1) = (x+y+2)^(n+2)`.
RHS = `y + (x+y+2)^(n+1)`.
Let `B = x+y+2 ≥ 2`. LHS = `B^(n+2) = B·B^(n+1)`. RHS = `y + B^(n+1)`.
LHS − RHS = `B·B^(n+1) − B^(n+1) − y = (B−1)B^(n+1) − y`.
Since `B−1 = x+y+1 ≥ y+1` and `B^(n+1) ≥ 2`, we get `(B−1)B^(n+1) ≥ (y+1)·2 = 2y+2 > y`. Strict.

Both rules strictly decrease. **Succeeds.** Stays within boundary (interpretation over N, monotone with B ≥ 2).
