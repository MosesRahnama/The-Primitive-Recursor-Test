# Analysis of Termination Methods for the System

The system:
```
F(x, y, Z) -> x
F(x, y, S(n)) -> G(y, F(x, y, n))
```
is intuitively terminating because the recursion in F always reduces the third argument (S(n) → n), while no recursion is introduced into the first two arguments.

---

## (A) LPO with precedence F > G > S > Z

**Rule 1**: `F(x,y,Z) >LPO x` — the first argument is x, so x ≥ x. ✓

**Rule 2**: `F(x,y,S(n)) >LPO G(y, F(x,y,n))`. Since F > G, it suffices that F(x,y,S(n)) >LPO each tⱼ:
- vs. y: second argument y ≥ y. ✓
- vs. F(x,y,n): same head; the only difference is S(n) vs. n, and S(n) >LPO n (n is a subterm of S(n)). ✓

1. **Succeeds**: yes. 2. **Within boundary**: yes — purely syntactic on the rules.

## (B) Polynomial interpretation over N

Compute LHS − RHS:
- Rule 1: `(x + (y+1)·1) − x = y + 1 > 0`. ✓
- Rule 2: `[F(x,y,S(n))] = x + (y+1)(n+2)`; `[G(y,F(x,y,n))] = y + x + (y+1)(n+1)`. Difference = `(y+1) − y = 1 > 0`. ✓

All interpretations are monotone in N.

1. **Succeeds**: yes. 2. **Within boundary**: yes.

## (C) MPO with precedence F > G > S > Z, multiset status

**Rule 1**: `F(x,y,Z) >MPO x` — subterm clause (x is an argument). ✓

**Rule 2**: `F(x,y,S(n)) >MPO G(y,F(x,y,n))`. F > G, so need F(x,y,S(n)) >MPO each RHS subterm:
- vs. y: subterm. ✓
- vs. F(x,y,n): same head, multiset {x,y,S(n)} ≻ᵐ {x,y,n} requires S(n) >MPO n (subterm). ✓

1. **Succeeds**: yes. 2. **Within boundary**: yes.

## (D) Dependency pairs + subterm criterion (project to third argument)

Dependency pair (from rule 2's defined-symbol subterm):
```
F(x, y, S(n)) -> F(x, y, n)
```

Projecting to π₃: π₃(LHS) = S(n), π₃(RHS) = n. The term n is a **strict subterm** of S(n), so the subterm criterion is satisfied.

1. **Succeeds**: yes. 2. **Within boundary**: yes — the DP method analyzes the rules directly.

## (E) Exponential interpretation over N

Let a = x + y + 2 (note a ≥ 2 in N). Compute LHS − RHS:
- Rule 1: `(x+y+2)¹ − x = y + 2 > 0`. ✓
- Rule 2: `a^(n+2) − (y + a^(n+1)) = a^(n+1)(a − 1) − y = a^(n+1)(x+y+1) − y`.
  Since a^(n+1) ≥ 2^(n+1) ≥ 1 and (x+y+1) ≥ 1, we have a^(n+1)(x+y+1) ≥ a^(n+1) ≥ y+2 > y (using a ≥ y+2). ✓

All functions are monotone in N.

1. **Succeeds**: yes. 2. **Within boundary**: yes.

## Conclusion

**All five methods (A, B, C, D, E) satisfy both conditions.** Each method establishes strong normalization of the system using only the two given rewrite rules and standard, well-founded termination proof techniques, without importing any external structural axioms or object-level assumptions.
