# Analysis of the Five Termination Methods

**System:**
```
F(x, y, Z)    -> x
F(x, y, S(n)) -> G(y, F(x, y, n))
```

---

## (A) LPO, precedence F > G > S > Z

**Rule 1:** `x` is a subterm of the LHS — holds trivially.

**Rule 2:** Since F > G, need `F(x,y,S(n)) >_lpo y` (subterm, ✓) and `F(x,y,S(n)) >_lpo F(x,y,n)`. Same head symbol ⇒ compare argument tuples lexicographically: `x=x`, `y=y`, then `S(n) >_lpo n` (subterm, ✓).

**1. Succeeds.** **2. Stays in bounds** — LPO uses only the precedence (an arbitrary order on the finite symbol set) and the syntactic subterm relation. No structure beyond the rules/signature is needed.

---

## (B) Nonlinear polynomial interpretation

Computing both rules:
- Rule 1: `x+(y+1) > x` ⇔ `y+1>0` ✓
- Rule 2: `x+(y+1)(n+2) > y + x+(y+1)(n+1)` reduces to `(y+1) > y` ✓

**1. Succeeds** (the inequalities are valid and the algebra is monotone).
**2. Exceeds the boundary** — this proof is not obtainable from the rewrite rules themselves; it imports the arithmetic of `(ℕ,+,·,>)` (distributivity, monotonicity of `+`/`·`, well-foundedness of `>` on ℕ) as external structure. Z and S are never claimed by the rules to denote numbers with these arithmetic properties.

---

## (C) MPO, precedence F > G > S > Z, multiset status

**Rule 1:** subterm property — holds.

**Rule 2:** F > G ⇒ need `F(x,y,S(n))` to dominate every argument of `G(y,F(x,y,n))`:
- vs `y`: subterm ✓
- vs `F(x,y,n)`: same symbol ⇒ multiset comparison `{x,y,S(n)} >_mul {x,y,n}`; canceling the identical `x,y`, left with `S(n) > n` ✓

**1. Succeeds.** **2. Stays in bounds** — purely syntactic (precedence + subterm relation + multiset extension), nothing beyond term structure is used.

---

## (D) Dependency pairs + subterm criterion (3rd argument)

Only defined-symbol subterm on a RHS is `F(x,y,n)`, giving the single dependency pair:
```
F#(x,y,S(n)) -> F#(x,y,n)
```
Projection π(third arg): `π(l#) = S(n)`, `π(r#) = n`, and `S(n) ⊳ n` (strict subterm).

**1. Succeeds** — this strict decrease closes the only SCC, and no other dependency pairs exist (G is not defined).
**2. Stays in bounds** — the DP construction and the subterm criterion use only the rules (to identify defined symbols/dependency pairs) and the syntactic subterm relation ⊵. No semantic domain is imported.

---

## (E) Exponential interpretation

Let `b = x+y+2 ≥ 2`.
- Rule 1: `x+y+2 > x` ✓
- Rule 2: `b^(n+2) > y + b^(n+1)` ⇔ `b^(n+1)(b-1) > y` ⇔ `b^(n+1)(x+y+1) > y`, which holds since `b^(n+1) ≥ 2` and `x+y+1 ≥ y+1`.

**1. Succeeds** — the inequalities check out and the interpretation is monotone.
**2. Exceeds the boundary** — even more emphatically than (B), this imports not just arithmetic but exponentiation and its monotonicity/growth properties over ℕ, none of which are derivable from the given rules; it presupposes a rich external algebraic model.

---

## Summary Table

| Method | (1) Proves termination? | (2) Stays within boundary? |
|---|---|---|
| A (LPO) | Yes | Yes |
| B (nonlinear polynomial) | Yes | **No** (imports ℕ-arithmetic axioms) |
| C (MPO) | Yes | Yes |
| D (DP + subterm criterion) | Yes | Yes |
| E (exponential) | Yes | **No** (imports exponential arithmetic) |

## Conclusion

**Methods A, C, and D** satisfy both conditions: they succeed in proving termination and do so using only structural/syntactic properties (precedence orders, subterm relations) derivable directly from the given rules. **Methods B and E**, while mathematically valid termination arguments, rely on importing the arithmetic structure of ℕ (ordinary or exponential arithmetic) as an external well-founded algebra — structure not present in or derivable from the rewrite system itself — and therefore fall outside the stated benchmark boundary.
