# Analysis of Termination Proof Methods

## Method A: LPO with precedence F > G > S > Z

**Rule 1:** F(x,y,Z) → x. Since x is a direct argument of the LHS, F(x,y,Z) >_lpo x holds by the subterm property of LPO.

**Rule 2:** F(x,y,S(n)) → G(y, F(x,y,n)). Since F > G, we need F(x,y,S(n)) >_lpo y and F(x,y,S(n)) >_lpo F(x,y,n).
- F(x,y,S(n)) >_lpo y holds by subterm property (y is a direct argument).
- For F(x,y,S(n)) >_lpo F(x,y,n): same head symbol, so compare lexicographically (x,y,S(n)) vs (x,y,n). First two components are equal; third requires S(n) >_lpo n, which holds by the subterm property.

**Verdict:** ✅ Succeeds. ✅ Within boundary (precedence is stated explicitly and verified directly against the rules; no external axioms invoked).

## Method B: Nonlinear polynomial interpretation

**Rule 1:** [F(x,y,Z)] = x + (y+1)(1) = x + y + 1 > x. ✓ (holds for all y ≥ 0)

**Rule 2:** [F(x,y,S(n))] = x + (y+1)(n+2), and [G(y,F(x,y,n))] = y + x + (y+1)(n+1).
Difference: (y+1)(n+2) − (y+1)(n+1) − y = (y+1) − y = 1 > 0. ✓

All base functions are (weakly/strictly) monotonic in every argument, satisfying the compatibility requirements for a valid polynomial interpretation.

**Verdict:** ✅ Succeeds. ✅ Within boundary (interpretation fully specified, verified algebraically from the rules alone).

## Method C: MPO with all-multiset status

**Rule 1:** Holds trivially by the subterm-selection clause of the recursive path order (x is s₁).

**Rule 2:** Since F > G, need F(x,y,S(n)) >_mpo y (holds, subterm) and F(x,y,S(n)) >_mpo F(x,y,n) (same head ⇒ multiset comparison: {x,y,S(n)} vs {x,y,n}; cancel common x,y, leaving {S(n)} vs {n}; since S(n) > n, the multiset order holds).

**Verdict:** ✅ Succeeds. ✅ Within boundary (same reasoning as A/C — precedence and status fixed explicitly, verified directly against the rules).

## Method D: Dependency pairs + subterm criterion

Only defined symbol is F (G has no rules). The only dependency pair generated is:

  F#(x,y,S(n)) → F#(x,y,n)

Projecting π to the third argument: π(LHS) = S(n), π(RHS) = n. Since n is a proper subterm of S(n), we get strict decrease (⊳) on the only cycle. By the subterm criterion theorem, this DP problem is finite, and since it is the only cycle, the original TRS is terminating.

**Verdict:** ✅ Succeeds. ✅ Within boundary (DP set derived mechanically from the given rules; projection is stated explicitly and validated by the subterm relation on ground terms).

## Method E: Exponential interpretation

**Rule 1:** [F(x,y,Z)] = (x+y+2)¹ = x+y+2 > x. ✓

**Rule 2:** [F(x,y,S(n))] = (x+y+2)^(n+2), [G(y,F(x,y,n))] = y + (x+y+2)^(n+1).
Need (x+y+2)^(n+2) − (x+y+2)^(n+1) > y, i.e. (x+y+2)^(n+1)·(x+y+1) > y. Since (x+y+2)^(n+1) ≥ 2 and (x+y+1) ≥ 1, the LHS grows at least quadratically in y while RHS is linear — the inequality holds for all x,y,n ∈ ℕ. All components are monotonic in each argument.

**Verdict:** ✅ Succeeds. ✅ Within boundary (fully specified interpretation over ℕ, verified directly from the rules; exponential functions are standard, well-founded, monotone algebraic objects, not external structural axioms).

| A (LPO) | Yes | Yes |
| B (Polynomial) | Yes | Yes |

**Conclusion:** All five methods — **A, B, C, D, and E** — succeed in proving strong normalization of the given system, and each does so using only parameters (precedence, interpretation, or projection) that are explicitly stated and checked directly against the given rules, without appeal to any external structural axioms or unstated object-level assumptions. Hence **all five methods satisfy both conditions**.
