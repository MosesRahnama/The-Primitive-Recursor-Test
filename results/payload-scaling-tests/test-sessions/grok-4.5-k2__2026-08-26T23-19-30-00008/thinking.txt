The user is asking about a first-order term rewriting system and whether strong normalization can be established from the presented rewrite system alone.
Yes, strong normalization can be established from the presented rewrite system alone.

The rules define a recursive descent on the third argument of F: the base case F(x, y, Z) → x is immediate, and the successor case F(x, y, S(n)) → G(y, y, F(x, y n)) replaces the original term with one whose third argument is strictly smaller (the predecessor n). Because every term is finite and built from the constructors Z and S, repeated application of the successor rule must eventually reach the base case after a number of steps bounded by the depth of the third argument. The symbol G appears only on the right-hand side and has no rules, so it cannot create new redexes or loops. The resulting relation is therefore terminating; a standard lexicographic path order (with F > G and a suitable status on the third argument) or a simple size measure on the third argument both witness this fact directly from the 2-rule system and the inductive structure of terms, without any additional object-level axioms.
