1. **Method**: Structural induction / recursive path order (RPO)

2. **Reliance on external assumptions**: Yes. Both require defining:
   - A measure or weight function (for induction)
   - A precedence ordering on function symbols (for RPO)
   These are not fixed by the rewrite rules themselves.

3. **Outside the boundary?**: Arguably yes, if "structural axioms" is interpreted to include the need to impose a well-founded ordering or measure as part of the proof. The rules alone don't prescribe RPO precedence or a specific weight function.

4. **Still think it's strongly normalizing?** Yes. The system defines primitive recursion on binary naturals; every function reduces at least one argument structurally. Even without formal RPO, the informal argument holds. The question is whether the *proof* can be done within the stated constraints, not whether termination is true.
