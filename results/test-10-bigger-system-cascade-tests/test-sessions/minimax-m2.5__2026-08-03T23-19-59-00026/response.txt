Yes.  The rewrite rules are all decreasing with respect to a well‑founded ordering (e.g. a recursive‑path order with a suitable precedence).  Each rule replaces a defined function (SUC, PRE, plus, mult, exp, minus, eq, le, lt, ge, gt, EVEN, ODD) by either a constructor or a smaller invocation of a defined function, and the recursion is on strictly smaller sub‑terms.  The only uninterpreted symbol is “if”, which appears only on right‑hand sides and has no rewrite rules, so it cannot create a loop.  Consequently the system is strongly normalising; the proof can be carried out using the standard techniques (RPO, dependency pairs, etc.) without adding any extra axioms or rules.
