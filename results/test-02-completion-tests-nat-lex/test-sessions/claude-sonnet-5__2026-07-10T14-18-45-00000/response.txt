# Proof Skeleton for the Remaining `measure_decreases` Cases

Below are the five remaining cases. Each follows the same two‑lemma pattern already established (`drop_left` for a strict `kappa` decrease, `drop_right` for a `kappa` tie together with a strict `mu` decrease), with `simp` unfolding the relevant equations and `omega` closing the resulting (in)equalities (including the `Nat.max` reasoning, which `omega` handles directly).

```lean
-- integrate (delta t) --> void
-- kappa (integrate (delta t)) = kappa t, kappa void = 0.
-- Split on whether kappa t is zero (tie, use mu) or positive (strict kappa drop).
| _, _, Step.R_int_delta t => by
    rcases Nat.eq_zero_or_pos (kappa t) with h0 | hpos
    · have hk : kappa void = kappa (integrate (delta t)) := by
        simp [kappa]; omega
      have hmu : mu void < mu (integrate (delta t)) := by
        simp [mu]; omega
      exact drop_right hmu hk
    · have hk : kappa void < kappa (integrate (delta t)) := by
        simp [kappa]; omega
      exact drop_left hk

-- recDelta b s void --> b
-- kappa (recDelta b s void) = max (kappa b) (kappa s).
-- Split on whether kappa s <= kappa b (tie on kappa b, use mu) or kappa b < kappa s (strict kappa drop).
| _, _, Step.R_rec_zero b s => by
    rcases le_or_lt (kappa s) (kappa b) with hle | hlt
    · have hk : kappa b = kappa (recDelta b s void) := by
        simp [kappa]; omega
      have hmu : mu b < mu (recDelta b s void) := by
        simp [mu]; omega
      exact drop_right hmu hk
    · have hk : kappa b < kappa (recDelta b s void) := by
        simp [kappa]; omega
      exact drop_left hk

-- recDelta b s (delta n) --> app s (recDelta b s n)
-- The behaviour of kappa depends on whether n itself is delta-wrapped:
--   * if n is NOT of the form `delta _`, the "+1" bonus of kappa disappears
--     after the step, giving a strict kappa decrease;
--   * if n IS of the form `delta n'`, the new recDelta node still starts
--     with an outer delta, so kappa ties, and the decrease must come from mu.
| _, _, Step.R_rec_succ b s n => by
    match n with
    | delta n' =>
        have hk : kappa (recDelta b s (delta (delta n'))) =
                  kappa (app s (recDelta b s (delta n'))) := by
          simp [kappa]; omega
        have hmu : mu (app s (recDelta b s (delta n'))) <
                   mu (recDelta b s (delta (delta n'))) := by
          simp [mu]; omega
        exact drop_right hmu hk.symm
    | void =>
        have hk : kappa (app s (recDelta b s void)) <
                  kappa (recDelta b s (delta void)) := by
          simp [kappa]; omega
        exact drop_left hk
    | integrate n' =>
        have hk : kappa (app s (recDelta b s (integrate n'))) <
                  kappa (recDelta b s (delta (integrate n'))) := by
          simp [kappa]; omega
        exact drop_left hk
    | merge n1 n2 =>
        have hk : kappa (app s (recDelta b s (merge n1 n2))) <
                  kappa (recDelta b s (delta (merge n1 n2))) := by
          simp [kappa]; omega
        exact drop_left hk
    | app n1 n2 =>
        have hk : kappa (app s (recDelta b s (app n1 n2))) <
                  kappa (recDelta b s (delta (app n1 n2))) := by
          simp [kappa]; omega
        exact drop_left hk
    | recDelta n1 n2 n3 =>
        have hk : kappa (app s (recDelta b s (recDelta n1 n2 n3))) <
                  kappa (recDelta b s (delta (recDelta n1 n2 n3))) := by
          simp [kappa]; omega
        exact drop_left hk
    | eqW n1 n2 =>
        have hk : kappa (app s (recDelta b s (eqW n1 n2))) <
                  kappa (recDelta b s (delta (eqW n1 n2))) := by
          simp [kappa]; omega
        exact drop_left hk

-- eqW a a --> void
-- kappa (eqW a a) = kappa a, kappa void = 0: same shape as R_int_delta.
| _, _, Step.R_eq_refl a => by
    rcases Nat.eq_zero_or_pos (kappa a) with h0 | hpos
    · have hk : kappa void = kappa (eqW a a) := by
        simp [kappa]; omega
      have hmu : mu void < mu (eqW a a) := by
        simp [mu]; omega
      exact drop_right hmu hk
    · have hk : kappa void < kappa (eqW a a) := by
        simp [kappa]; omega
      exact drop_left hk

-- eqW a b --> integrate (merge a b)
-- kappa ties exactly: both sides equal max (kappa a) (kappa b).
-- mu strictly drops by exactly 1: (4 + mu a + mu b) --> (1 + (2 + mu a + mu b)).
| _, _, Step.R_eq_diff a b => by
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by
      simp [kappa]
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by
      simp [mu]; omega
    exact drop_right hmu hk
```

## Notes on the structure

- **`R_int_delta`, `R_eq_refl`** share the same shape: the target is `void` (measure `(0,0)`), and the source's `kappa` equals some sub-term's `kappa`, which may be zero (→ tie, use `mu`) or positive (→ strict `kappa` drop). Hence the `rcases Nat.eq_zero_or_pos` split.

- **`R_rec_zero`** is analogous but the relevant quantity is `max (kappa b) (kappa s)` instead of a single `kappa`; the split is on `le_or_lt (kappa s) (kappa b)` to determine whether the max collapses to `kappa b` (tie) or strictly exceeds it (`kappa` drop).

- **`R_eq_diff`** is the cleanest case: no branching is needed since `kappa` is *exactly* preserved (`eqW a b` and `merge a b` share the same `max (kappa a) (kappa b)` formula) and `mu` decreases by a fixed constant (`4 + mu a + mu b` vs `3 + mu a + mu b`).

- **`R_rec_succ`** is the most delicate: it requires a full case split on the constructor of `n` because `kappa`'s definition treats `recDelta _ _ (delta _)` specially. All non‑`delta` shapes of `n` yield a strict `kappa` decrease (`drop_left`); the `delta n'` shape ties `kappa` and needs `mu` to close the gap (`drop_right`), each verified via `simp [kappa]`/`simp [mu]` unfolding followed by `omega`.

Each `have` goal reduces, after `simp` unfolds the recursive equations for `kappa`/`mu` on the concrete constructors involved, to a pure linear‑arithmetic statement over `Nat.max`/`+`, which `omega` is expected to discharge directly (Lean's `omega` handles `Nat.max`/`Nat.min` via internal case splitting).
