The file is not provable as stated: the `R_rec_succ` case does not strictly decrease the stated measure.

For example, instantiate `b := void`, `s := void`, and `n := delta void`. Then

```lean
a := recDelta void void (delta void)
b := app void (recDelta void void (delta void))
```

satisfy `Step a b`, but

```lean
kappa a = 1
mu a    = 3

kappa b = 1
mu b    = 4
```

Hence the lexicographic measure increases in the second component, so

```lean
¬ LexOrder (measure b) (measure a)
```

for this rule instance.

The other four remaining cases have proof skeletons of the following form:

```lean
-- integrate (delta t) --> void
| _, _, Step.R_int_delta t => by
    by_cases hκ : kappa t = 0
    · apply drop_right
      · simp [mu]
        omega
      · simp [kappa, hκ]
    · apply drop_left
      · simp [kappa]
        exact Nat.pos_of_ne_zero hκ
```

```lean
-- recDelta b s void --> b
| _, _, Step.R_rec_zero b s => by
    let K := Nat.max (Nat.max (kappa b) (kappa s)) 0
    by_cases hκ : kappa b = Nat.max (Nat.max (kappa b) (kappa s)) 0
    · apply drop_right
      · simp [mu]
        omega
      · simp [kappa, hκ]
    · have hle :
          kappa b ≤ Nat.max (Nat.max (kappa b) (kappa s)) 0 :=
        Nat.le_max_left _ _
      have hlt :
          kappa b < Nat.max (Nat.max (kappa b) (kappa s)) 0 :=
        lt_of_le_of_ne hle hκ
      apply drop_left
      · simpa [kappa] using hlt
```

```lean
-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    by_cases hκ : kappa a = 0
    · apply drop_right
      · simp [mu]
        omega
      · simp [kappa, hκ]
    · apply drop_left
      · simp [kappa]
        exact Nat.pos_of_ne_zero hκ
```

```lean
-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    have hmu :
        mu (integrate (merge a b)) < mu (eqW a b) := by
      simp [mu]
      omega
    have hκ :
        kappa (integrate (merge a b)) = kappa (eqW a b) := by
      simp [kappa]
    exact drop_right hmu hκ
```

For `R_rec_succ`, a branch such as

```lean
| _, _, Step.R_rec_succ b s n => by
    cases n with
    | void => ...
    | delta n => ...
    | integrate n => ...
    | merge a b => ...
    | app a b => ...
    | recDelta b s n => ...
    | eqW a b => ...
```

will encounter an unprovable `delta` branch, because that branch gives the counterexample above. A different measure or a modified rewrite rule is required before `measure_decreases` can be completed.
