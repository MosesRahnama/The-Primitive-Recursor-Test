Four cases can be completed, but `R_rec_succ` cannot: the stated measure does not strictly decrease for all instances.

```lean
-- integrate (delta t) --> void
| _, _, Step.R_int_delta t => by
    by_cases hk0 : kappa t = 0
    · have hmu : mu void < mu (integrate (delta t)) := by
        simp [mu]
      have hk : kappa void = kappa (integrate (delta t)) := by
        simp [kappa, hk0]
      exact drop_right hmu hk
    · have hk : kappa void < kappa (integrate (delta t)) := by
        simp [kappa]
        exact Nat.pos_of_ne_zero hk0
      exact drop_left hk

-- recDelta b s void --> b
| _, _, Step.R_rec_zero b s => by
    have hle : kappa b ≤ kappa (recDelta b s void) := by
      simp [kappa]
    rcases lt_or_eq_of_le hle with hk | hk
    · exact drop_left hk
    · have hmu : mu b < mu (recDelta b s void) := by
        simp [mu]
        omega
      exact drop_right hmu hk

-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    -- No proof exists with the current definitions.
    sorry

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    by_cases hk0 : kappa a = 0
    · have hmu : mu void < mu (eqW a a) := by
        simp [mu]
        omega
      have hk : kappa void = kappa (eqW a a) := by
        simp [kappa, hk0]
      exact drop_right hmu hk
    · have hk : kappa void < kappa (eqW a a) := by
        simp [kappa]
        exact Nat.pos_of_ne_zero hk0
      exact drop_left hk

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by
      simp [mu]
      omega
    have hk :
        kappa (integrate (merge a b)) = kappa (eqW a b) := by
      simp [kappa]
    exact drop_right hmu hk
```

The obstruction in `R_rec_succ` appears when `n` itself is delta-wrapped. For example, take:

```lean
b = void
s = void
n = delta void
```

Then the rule is

```lean
recDelta void void (delta (delta void))
  -->
app void (recDelta void void (delta void))
```

The measures are:

```text
source: (kappa, mu) = (1, 3)
target: (kappa, mu) = (1, 4)
```

Thus `kappa` ties while `mu` increases, so

```lean
LexOrder (measure target) (measure source)
```

is false. Consequently, `measure_decreases` and therefore the supplied proof of `strong_normalization` cannot be completed without changing the measure, restricting `R_rec_succ`, or using a different well-founded argument.
