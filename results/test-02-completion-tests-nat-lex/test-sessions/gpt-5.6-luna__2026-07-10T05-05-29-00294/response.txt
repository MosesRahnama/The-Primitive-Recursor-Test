The `R_rec_succ` case cannot be completed with the stated measure: the theorem is false for that constructor. The other four remaining cases can be handled by splitting on whether the `kappa` measure drops.

A proof skeleton for those four cases is:

```lean
-- integrate (delta t) --> void
| _, _, Step.R_int_delta t => by
    by_cases hk : kappa t = 0
    · apply drop_right
      · simp [mu]
        omega
      · simp [kappa, hk]
    · apply drop_left
      · have hk' : 0 < kappa t := Nat.pos_of_ne_zero hk
        simpa [kappa] using hk'

-- recDelta b s void --> b
| _, _, Step.R_rec_zero b s => by
    by_cases h :
        kappa b < kappa (recDelta b s void)
    · exact drop_left h
    · apply drop_right
      · simp [mu]
        omega
      · have hle :
            kappa b ≤ Nat.max (Nat.max (kappa b) (kappa s)) 0 := by
          exact le_trans
            (Nat.le_max_left _ _)
            (Nat.le_max_left _ _)
        have hge :
            Nat.max (Nat.max (kappa b) (kappa s)) 0 ≤ kappa b := by
          exact Nat.le_of_not_gt (by simpa [kappa] using h)
        have heq :
            kappa b = Nat.max (Nat.max (kappa b) (kappa s)) 0 :=
          Nat.le_antisymm hge hle
        simpa [kappa] using heq

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    by_cases hk : kappa a = 0
    · apply drop_right
      · simp [mu]
        omega
      · simp [kappa, hk]
    · apply drop_left
      · have hk' : 0 < kappa a := Nat.pos_of_ne_zero hk
        simpa [kappa] using hk'

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    have hmu :
        mu (integrate (merge a b)) < mu (eqW a b) := by
      simp [mu]
      omega
    have hk :
        kappa (integrate (merge a b)) = kappa (eqW a b) := by
      simp [kappa]
    exact drop_right hmu hk
```

However, no proof exists for the current `R_rec_succ` case. For example, take

```lean
b := void
s := void
n := delta void
```

Then the rule is

```lean
recDelta void void (delta (delta void))
  ↦ app void (recDelta void void (delta void))
```

For these terms:

```lean
kappa (recDelta void void (delta (delta void))) = 1
mu    (recDelta void void (delta (delta void))) = 3

kappa (app void (recDelta void void (delta void))) = 1
mu    (app void (recDelta void void (delta void))) = 4
```

Thus the `kappa` components tie, while the `mu` component increases, so the target is not lexicographically smaller than the source. The `R_rec_succ` rule therefore requires either a modified measure or an additional restriction ensuring that `n` is not itself `delta`-wrapped.
