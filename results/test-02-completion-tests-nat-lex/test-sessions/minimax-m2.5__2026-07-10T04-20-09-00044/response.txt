Below is the proof skeleton for the five remaining cases in the `measure_decreases` theorem. Each case follows the same pattern: compute the measures of the left-hand and right-hand sides, compare kappa and mu, and apply `drop_left` or `drop_right` to establish lexicographic decrease.

### Case 1: `R_int_delta t`
```
| _, _, Step.R_int_delta t => by
    have hk : kappa (integrate (delta t)) = kappa t := by simp
    have hmu : mu (integrate (delta t)) = 1 + mu t := by simp
    cases hk : kappa t
    case zero =>
      have hk' : kappa (integrate (delta t)) = 0 := by simp [hk]
      have hmu' : 0 < 1 + mu t := by simp
      exact drop_right hmu' hk'
    case succ k =>
      have hk' : 0 < Nat.suc k := by simp
      exact drop_left hk'
```
**Explanation**: We compare `measure (integrate (delta t)) = (kappa t, 1 + mu t)` with `measure void = (0, 0)`. If `kappa t = 0`, then kappa ties and mu decreases; otherwise kappa decreases.

### Case 2: `R_rec_zero b s`
```
| _, _, Step.R_rec_zero b s => by
    have hk := kappa_recDelta b s void
    have hmu := mu_recDelta b s void
    by_cases h : kappa b < kappa s
    case inl h =>
      have hk' : kappa (recDelta b s void) = kappa s := by simp [hk, h]
      have hk'' : kappa b < kappa (recDelta b s void) := by simp [hk']
      exact drop_left hk''
    case inr h =>
      have H := Classical.not_lt.mp h
      have hk' : kappa (recDelta b s void) = kappa b := by simp [hk, Nat.max_eq_left H]
      have hmu' : mu b < 3 + mu b + mu s := by simp
      exact drop_right hmu' hk'
```
**Explanation**: We compare `measure (recDelta b s void) = (max(kappa b, kappa s), 3 + mu b + mu s)` with `measure b = (kappa b, mu b)`. If `kappa b < kappa s`, then kappa decreases; otherwise kappa ties and mu decreases.

### Case 3: `R_rec_succ b s n`
```
| _, _, Step.R_rec_succ b s n => by
    have hk_left : kappa (recDelta b s (delta n)) = Nat.max (kappa b) (Nat.max (kappa s) (kappa n)) + 1 := by simp
    have hk_right : kappa (app s (recDelta b s n)) = Nat.max (kappa b) (Nat.max (kappa s) (kappa n)) := by simp
    have hk : kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n)) := by simp
    exact drop_left hk
```
**Explanation**: We compare `measure (recDelta b s (delta n)) = (max(kappa b, kappa s, kappa n) + 1, 3 + mu b + mu s + mu n)` with `measure (app s (recDelta b s n)) = (max(kappa b, kappa s, kappa n), 1 + mu s + mu (recDelta b s n))`. Here kappa strictly decreases by 1, so we use `drop_left`.

### Case 4: `R_eq_refl a`

```
| _, _, Step.R_eq_refl a => by

    have hmu : mu (eqW a a) = 4 + 2 * mu a := by simp

```
**Explanation**: We compare `measure (eqW a a) = (kappa a, 4 + 2 * mu a)` with `measure void = (0, 0)`. If `kappa a = 0`, then kappa ties and mu decreases; otherwise kappa decreases.

### Case 5: `R_eq_diff a b`
```
| _, _, Step.R_eq_diff a b => by
    have hk : kappa (eqW a b) = Nat.max (kappa a) (kappa b) := by simp
    have hk' : kappa (integrate (merge a b)) = Nat.max (kappa a) (kappa b) := by simp [kappa_integrate, kappa_merge]
    have hk'' : kappa (integrate (merge a b)) = kappa (eqW a b) := by simp [hk, hk']
    have hmu : mu (integrate (merge a b)) = 3 + mu a + mu b := by simp [mu_integrate, mu_merge]
    have hmu' : mu (eqW a b) = 4 + mu a + mu b := by simp
    have hmu'' : mu (integrate (merge a b)) < mu (eqW a b) := by simp [hmu, hmu']
    exact drop_right hmu'' hk''
```
**Explanation**: We compare `measure (eqW a b) = (max(kappa a, kappa b), 4 + mu a + mu b)` with `measure (integrate (merge a b)) = (max(kappa a, kappa b), 3 + mu a + mu b)`. Here kappa ties and mu decreases by 1, so we use `drop_right`.

These proofs ensure that each reduction rule strictly decreases the lexicographic measure `(kappa, mu)`, thus establishing strong normalization.
