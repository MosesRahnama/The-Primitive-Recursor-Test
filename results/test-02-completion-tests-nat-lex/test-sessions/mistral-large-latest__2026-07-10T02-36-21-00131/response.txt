I'll provide proof skeletons for the remaining five cases in the `measure_decreases` theorem. Each case needs to show that the lexicographic measure decreases when applying the corresponding reduction rule.

### 1. R_int_delta case
```lean
| _, _, Step.R_int_delta t => by
    have hk : kappa void < kappa (integrate (delta t)) := by
      simp [kappa]; omega
    exact drop_left hk
```

### 2. R_rec_zero case
```lean
| _, _, Step.R_rec_zero b s => by
    have hmu : mu b < mu (recDelta b s void) := by
      simp [mu]; omega
    have hk : kappa b = kappa (recDelta b s void) := by
      simp [kappa]
    exact drop_right hmu hk
```

### 3. R_rec_succ case
```lean
| _, _, Step.R_rec_succ b s n => by
    have hk : kappa (app s (recDelta b s n)) = kappa (recDelta b s (delta n)) := by
      simp [kappa]; omega
    have hmu : mu (app s (recDelta b s n)) < mu (recDelta b s (delta n)) := by
      simp [mu]; omega
    exact drop_right hmu hk
```

### 4. R_eq_refl case
```lean
| _, _, Step.R_eq_refl a => by
    have hk : kappa void < kappa (eqW a a) := by
      simp [kappa]; omega
    exact drop_left hk
```

### 5. R_eq_diff case
```lean
| _, _, Step.R_eq_diff a b => by
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by
      simp [kappa]
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by
      simp [mu]; omega
    exact drop_right hmu hk
```

Each proof follows the same pattern:
1. For cases where κ decreases, we use `drop_left`
2. For cases where κ stays the same but μ decreases, we use `drop_right`
3. We use the simp lemmas to simplify the expressions and omega to handle the arithmetic comparisons

The key is to show that either:
- The κ measure strictly decreases (left component of the lex order), or
- The κ measure stays the same while the μ measure strictly decreases (right component of the lex order)
