# Proof Skeleton for Remaining Cases

Based on the structure of the three proved cases and the measures defined, here are the proof skeletons for the five remaining cases:

```lean
-- integrate (delta t) --> void
| _, _, Step.R_int_delta t => by
    have hk : kappa void < kappa (integrate (delta t)) := by simp [kappa]
    exact drop_left hk

-- recDelta b s void --> b
| _, _, Step.R_rec_zero b s => by
    have hk : kappa b < kappa (recDelta b s void) := by simp [kappa]; omega
    exact drop_left hk

-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    have hk : kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n)) := by
      simp [kappa]; omega
    exact drop_left hk

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    have hk : kappa void < kappa (eqW a a) := by simp [kappa]; omega
    exact drop_left hk

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    have hk : kappa (integrate (merge a b)) < kappa (eqW a b) := by
      simp [kappa]; omega
    exact drop_left hk
```

## Key observations:

1. **R_int_delta**: Delta is transparent in `kappa`, so `kappa(integrate(delta t)) = kappa(t)`, but wrapping in `integrate` doesn't change `kappa`. However, `void` has `kappa 0`, making the drop work.

2. **R_rec_zero**: The third argument transitions from `void` (kappa 0) to being removed entirely, dropping kappa by the max computation.

3. **R_rec_succ**: Kappa drops by 1 because `delta` is transparent in `kappa`, converting the `+1` in the definition to a strict inequality.

4. **R_eq_refl**: Both arguments are identical, so `max(k,k) = k`, and `void` has kappa 0.

5. **R_eq_diff**: The `integrate` wrapper is transparent in `kappa`, preserving the `max(kappa a, kappa b)` value, but `void` is smaller.

All five cases use `drop_left` (kappa strictly decreases) rather than `drop_right`, which aligns with the measure design where `kappa` is the primary discriminator.
