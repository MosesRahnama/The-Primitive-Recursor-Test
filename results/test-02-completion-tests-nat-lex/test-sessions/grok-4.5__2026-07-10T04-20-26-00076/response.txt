The three completed cases all follow the same pattern: establish a strict `mu` drop, prove a `kappa` tie, then finish with `drop_right`. The five remaining root rules split into three groups under the same `(kappa, mu)` lex measure.

```lean
-- ── Remaining cases ───────────────────────────────────────────

-- integrate (delta t) --> void
--   kappa :  0  ≟  kappa t          (tie or strict drop)
--   mu    :  0  <  1 + mu t         (always)
| _, _, Step.R_int_delta t => by
    have hmu : mu void < mu (integrate (delta t)) := by simp [mu]
    by_cases h : kappa t = 0
    · -- kappa ties at 0
      exact drop_right hmu (by simp [kappa, h])
    · -- kappa drops
      exact drop_left (by simp [kappa]; exact Nat.pos_of_ne_zero h)

-- recDelta b s void --> b
--   kappa :  kappa b  ≤  max(kappa b, kappa s)   (tie or strict drop)
--   mu    :  mu b  <  3 + mu b + mu s            (always)
| _, _, Step.R_rec_zero b s => by
    have hmu : mu b < mu (recDelta b s void) := by simp [mu]; omega
    have hle : kappa b ≤ kappa (recDelta b s void) := by
      simp only [kappa]
      exact le_trans (le_max_left _ _) (le_max_left _ _)
    by_cases h : kappa b = kappa (recDelta b s void)
    · exact drop_right hmu h
    · exact drop_left (lt_of_le_of_ne hle h)

-- recDelta b s (delta n) --> app s (recDelta b s n)
--   Designed so that the +1 in kappa on a delta-wrapped recDelta
--   produces a strict kappa drop (mu may increase; lex still falls).
--   Proof obligation:
--     max (kappa s) (kappa (recDelta b s n))
--       <  max (max (kappa b) (kappa s)) (kappa n) + 1
| _, _, Step.R_rec_succ b s n => by
    apply drop_left
    -- Unfold both sides of the desired inequality
    change
      Nat.max (kappa s) (kappa (recDelta b s n))
        < Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1
    -- Case-split on the shape of n (the simp lemma kappa_rec_delta
    -- only fires when the third argument is definitionally `delta _`)
    cases n with
    | delta m =>
        -- kappa (recDelta b s (delta m))
        --   = max(max(kb,ks), kappa m) + 1
        -- which equals the RHS, so the inequality becomes
        --   max(ks, RHS) < RHS, i.e. needs ks < RHS (true) but
        --   max(ks,RHS) = RHS, so the goal is RHS < RHS — false.
        -- Under the *current* definition of kappa this sub-case does
        -- not go through; a full-height numeral measure (or an
        -- equivalent adjustment of kappa) is required.
        sorry
    | void =>
        -- third argument is not delta-wrapped:
        -- kappa (recDelta b s void) = max(max(kb,ks), 0) = max(kb,ks)
        -- goal reduces to max(ks, max(kb,ks)) < max(kb,ks) + 1
        simp only [kappa]
        omega
    | integrate t =>
        simp only [kappa]; omega
    | merge a b' =>
        simp only [kappa]; omega
    | app a b' =>
        simp only [kappa]; omega
    | recDelta b' s' n' =>
        simp only [kappa]; omega
    | eqW a b' =>
        simp only [kappa]; omega

-- eqW a a --> void
--   kappa :  0  ≟  kappa a          (tie or strict drop)
--   mu    :  0  <  4 + 2·mu a       (always)
| _, _, Step.R_eq_refl a => by
    have hmu : mu void < mu (eqW a a) := by simp [mu]
    by_cases h : kappa a = 0
    · exact drop_right hmu (by simp [kappa, h])
    · exact drop_left (by simp [kappa]; exact Nat.pos_of_ne_zero h)

-- eqW a b --> integrate (merge a b)
--   kappa :  max(ka,kb) = max(ka,kb)   (always ties)
--   mu    :  3 + mua + mub  <  4 + mua + mub   (always)
| _, _, Step.R_eq_diff a b => by
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by
      simp [mu]; omega
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by
      simp [kappa]
    exact drop_right hmu hk
```

**Summary of the skeleton**

| Rule | `kappa` behaviour | Finishing lemma |
|------|-------------------|-----------------|
| `R_int_delta` | tie or drop | `by_cases` → `drop_right` / `drop_left` |
| `R_rec_zero` | tie or drop | `by_cases` → `drop_right` / `drop_left` |
| `R_rec_succ` | intended strict drop | `drop_left` (needs a full-height fix for nested `delta`) |
| `R_eq_refl` | tie or drop | `by_cases` → `drop_right` / `drop_left` |
| `R_eq_diff` | always ties | `drop_right` |

The three mixed cases (`R_int_delta`, `R_rec_zero`, `R_eq_refl`) are completed by the same `by_cases` on whether `kappa` is preserved; when it is, `mu` supplies the strict decrease. `R_eq_diff` is the clean twin of the already-proved merge rules. `R_rec_succ` is the only rule whose `kappa` decrease is not unconditional under the given definition; the skeleton isolates the precise inequality that must be shown and the case split required to show it.
