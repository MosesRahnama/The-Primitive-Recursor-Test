**Proof skeleton for the five remaining cases**

```lean
-- 1. integrate (delta t) --> void
--    kappa: either drops (if kappa t > 0) or ties at 0
--    mu: always drops by at least 1
| _, _, Step.R_int_delta t => by
    by_cases hκ : kappa t > 0
    · exact drop_left (by simp [kappa]; omega)
    · have hμ : mu void < mu (integrate (delta t)) := by simp [mu]; omega
      have hk : kappa void = kappa (integrate (delta t)) := by simp [kappa]; omega
      exact drop_right hμ hk

-- 2. recDelta b s void --> b
--    kappa: drops when kappa s > 0, otherwise ties
--    mu: drops by 3 + mu s
| _, _, Step.R_rec_zero b s => by
    by_cases hκ : kappa s > 0
    · exact drop_left (by simp [kappa]; omega)
    · have hμ : mu b < mu (recDelta b s void) := by simp [mu]; omega
      have hk : kappa b = kappa (recDelta b s void) := by simp [kappa]; omega
      exact drop_right hμ hk

-- 3. recDelta b s (delta n) --> app s (recDelta b s n)
--    kappa: strictly decreases by 1 (the +1 in the recDelta-delta clause disappears)
| _, _, Step.R_rec_succ b s n => by
    have hκ : kappa (app s (recDelta b s n)) <
              kappa (recDelta b s (delta n)) := by
      simp [kappa]
      -- M = max (max κb κs) κn ; left = M+1, right = M
      have : max (kappa s) (Nat.max (Nat.max (kappa b) (kappa s)) (kappa n))
           = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) := by
        apply Nat.max_eq_right; apply Nat.le_max_left
      rw [this]; omega
    exact drop_left hκ

-- 4. eqW a a --> void
--    kappa: drops when kappa a > 0, otherwise ties at 0
--    mu: drops by 4 + 2·mu a
| _, _, Step.R_eq_refl a => by
    by_cases hκ : kappa a > 0
    · exact drop_left (by simp [kappa]; omega)
    · have hμ : mu void < mu (eqW a a) := by simp [mu]; omega
      have hk : kappa void = kappa (eqW a a) := by simp [kappa]; omega
      exact drop_right hμ hk

-- 5. eqW a b --> integrate (merge a b)
--    kappa: identical (both sides take max(κa,κb))
--    mu: drops by 1
| _, _, Step.R_eq_diff a b => by
    have hμ : mu (integrate (merge a b)) < mu (eqW a b) := by simp [mu]; omega
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by simp [kappa]
    exact drop_right hμ hk
```

Each case follows the same pattern used in the three already-proved rules: decide whether `kappa` decreases (use `drop_left`) or stays equal (use `drop_right` with a `mu` decrease). The only non-trivial reasoning is the `R_rec_succ` case, where the `+1` in the `kappa` definition for a `delta`-wrapped third argument disappears on the right-hand side.
