# Proof Skeleton for Remaining Cases

Looking at the Lean 4 file, I need to analyze each remaining case and determine the appropriate proof strategy based on the `kappa` and `mu` measures.

## Analysis of Each Case

### Case 1: `R_int_delta` — `integrate (delta t) --> void`

- **LHS**: `integrate (delta t)` has `kappa = kappa t` and `mu = 1 + mu t`
- **RHS**: `void` has `kappa = 0` and `mu = 0`
- **Strategy**: `mu` strictly decreases (from `1 + mu t` to `0`), and we need to handle `kappa`. Since `kappa void = 0 ≤ kappa t`, we either have `kappa` dropping or tying at 0.

```lean
| _, _, Step.R_int_delta t => by
    have hmu : mu void < mu (integrate (delta t)) := by simp [mu]; omega
    have hk  : kappa void ≤ kappa (integrate (delta t)) := by simp [kappa]; omega
    cases Nat.lt_or_eq_of_le hk with
    | inl hlt => exact drop_left hlt
    | inr heq => exact drop_right hmu heq
```

### Case 2: `R_rec_zero` — `recDelta b s void --> b`

- **LHS**: `recDelta b s void` has `kappa = max (max (kappa b) (kappa s)) 0` and `mu = 3 + mu b + mu s + 0`
- **RHS**: `b` has `kappa = kappa b` and `mu = mu b`
- **Strategy**: `kappa` ties or drops, `mu` strictly drops by at least `3 + mu s`.

```lean
| _, _, Step.R_rec_zero b s => by
    have hmu : mu b < mu (recDelta b s void) := by simp [mu]; omega
    have hk  : kappa b ≤ kappa (recDelta b s void) := by simp [kappa]; omega
    cases Nat.lt_or_eq_of_le hk with
    | inl hlt => exact drop_left hlt
    | inr heq => exact drop_right hmu heq
```

### Case 3: `R_rec_succ` — `recDelta b s (delta n) --> app s (recDelta b s n)`

- **LHS**: `kappa = max (max (kappa b) (kappa s)) (kappa n) + 1`
- **RHS**: `app s (recDelta b s n)` has `kappa = max (kappa s) (max (max (kappa b) (kappa s)) (kappa n))`
- **Strategy**: `kappa` strictly drops (the `+1` is removed).

```lean
| _, _, Step.R_rec_succ b s n => by
    have hk : kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n)) := by
      simp [kappa]
      omega
    exact drop_left hk
```

### Case 4: `R_eq_refl` — `eqW a a --> void`

```lean
| _, _, Step.R_eq_refl a => by
```

### Case 5: `R_eq_diff` — `eqW a b --> integrate (merge a b)`

- **LHS**: `eqW a b` has `kappa = max (kappa a) (kappa b)` and `mu = 4 + mu a + mu b`
- **RHS**: `integrate (merge a b)` has `kappa = max (kappa a) (kappa b)` and `mu = 1 + 2 + mu a + mu b = 3 + mu a + mu b`
- **Strategy**: `kappa` ties exactly, `mu` drops by 1.

```lean
| _, _, Step.R_eq_diff a b => by
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by simp [mu]; omega
    have hk  : kappa (integrate (merge a b)) = kappa (eqW a b) := by simp [kappa]
    exact drop_right hmu hk
```
