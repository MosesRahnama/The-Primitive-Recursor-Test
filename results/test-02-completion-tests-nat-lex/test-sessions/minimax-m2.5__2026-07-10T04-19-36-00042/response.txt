We complete the proof of `measure_decreases` for the remaining five reduction rules by applying the helper lemmas `drop_left` and `drop_right`. The key is to analyze how `kappa` and `mu` change in each case.

### Case 1: `R_int_delta t` — `integrate (delta t) → void`
- **Idea**: If `kappa t > 0`, then `kappa` strictly decreases. If `kappa t = 0`, then `kappa` stays the same but `mu` strictly decreases (since `mu(integrate(delta t)) = 1 + mu t ≥ 1`).
- **Proof skeleton**:
  ```lean
  | _, _, Step.R_int_delta t => by
      have hk : kappa void = 0 := by simp
      have hk' : kappa (integrate (delta t)) = kappa t := by simp
      by_cases h : kappa t = 0
      · rw [h] at hk hk'
        have hmu : mu void < mu (integrate (delta t)) := by simp [mu]; omega
        exact drop_right hmu hk
      · have hklt : kappa void < kappa (integrate (delta t)) := by simp [h, hk, hk']; omega
        exact drop_left hklt
  ```

### Case 2: `R_rec_zero b s` — `recDelta b s void → b`
- **Idea**: If `kappa b < kappa s`, then `kappa` strictly decreases. Otherwise, `kappa b ≥ kappa s`, so `kappa` stays the same but `mu` strictly decreases (since `mu(recDelta b s void) = 3 + mu b + mu s > mu b`).
- **Proof skeleton**:
  ```lean
  | _, _, Step.R_rec_zero b s => by
      have hk : kappa (recDelta b s void) = Nat.max (kappa b) (kappa s) := by simp
      have hmu : mu (recDelta b s void) = 3 + mu b + mu s := by simp
      by_cases h : kappa b < kappa s
      · have hklt : kappa b < kappa (recDelta b s void) := by simp [h, hk]
        exact drop_left hklt
      · have hkeq : kappa b = kappa (recDelta b s void) := by simp [hk, h]
        have hmulte : mu b < mu (recDelta b s void) := by simp [hmu]; omega
        exact drop_right hmulte hkeq
  ```

### Case 3: `R_rec_succ b s n` — `recDelta b s (delta n) → app s (recDelta b s n)`
- **Idea**: `kappa` strictly decreases by exactly 1 (since the target’s `kappa` lacks the `+1` from the source’s delta wrapper).
- **Proof skeleton**:
  ```lean
  | _, _, Step.R_rec_succ b s n => by
      have hklt : kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n)) := by simp
      exact drop_left hklt
  ```

### Case 4: `R_eq_refl a` — `eqW a a → void`
- **Idea**: Same structure as case 1. If `kappa a > 0`, `kappa` decreases; otherwise, `mu` decreases.
- **Proof skeleton**:
  ```lean
  | _, _, Step.R_eq_refl a => by
      have hk : kappa void = 0 := by simp
      have hk' : kappa (eqW a a) = kappa a := by simp
      by_cases h : kappa a = 0
      · rw [h] at hk hk'
        have hmu : mu void < mu (eqW a a) := by simp [mu]; omega
        exact drop_right hmu hk
      · have hklt : kappa void < kappa (eqW a a) := by simp [h, hk, hk']; omega
        exact drop_left hklt
  ```

### Case 5: `R_eq_diff a b` — `eqW a b → integrate (merge a b)`
- **Idea**: `kappa` stays the same, while `mu` strictly decreases (since `mu(integrate(merge a b)) = 3 + mu a + mu b` and `mu(eqW a b) = 4 + mu a + mu b`).
- **Proof skeleton**:
  ```lean
  | _, _, Step.R_eq_diff a b => by
      have hkeq : kappa (eqW a b) = kappa (integrate (merge a b)) := by simp
      have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by simp [mu]; omega
      exact drop_right hmu hkeq
  ```

These skeletons can be inserted into the `measure_decreases` proof to replace the `sorry` markers, completing the strong normalization proof.
