A complete skeleton for all five `sorry`s cannot exist for the file exactly as written: the `R_rec_succ` case is not a lexicographic decrease for the given `kappa, mu`.

The other four cases can be filled along these lines:

```lean
-- integrate (delta t) --> void
| _, _, Step.R_int_delta t => by
    by_cases hk0 : kappa t = 0
    · have hmu : mu void < mu (integrate (delta t)) := by
        simp [mu]
      have hk : kappa void = kappa (integrate (delta t)) := by
        simp [kappa, hk0]
      exact drop_right hmu hk
    · have hklt : kappa void < kappa (integrate (delta t)) := by
        have : 0 < kappa t := Nat.pos_of_ne_zero hk0
        simpa [kappa] using this
      exact drop_left hklt

-- recDelta b s void --> b
| _, _, Step.R_rec_zero b s => by
    have hmu : mu b < mu (recDelta b s void) := by
      simp [mu]
      omega
    have hle : kappa b ≤ kappa (recDelta b s void) := by
      have h1 : kappa b ≤ Nat.max (kappa b) (kappa s) :=
        Nat.le_max_left _ _
      have h2 :
          Nat.max (kappa b) (kappa s) ≤
            Nat.max (Nat.max (kappa b) (kappa s)) (kappa void) :=
        Nat.le_max_left _ _
      simpa [kappa] using Nat.le_trans h1 h2
    by_cases hk : kappa b = kappa (recDelta b s void)
    · exact drop_right hmu hk
    · exact drop_left (Nat.lt_of_le_of_ne hle hk)

-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    -- This case is not provable with the current measure.
    -- See explanation below.
    sorry

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    by_cases hk0 : kappa a = 0
    · have hmu : mu void < mu (eqW a a) := by
        simp [mu]
        omega
      have hk : kappa void = kappa (eqW a a) := by
        simp [kappa, hk0]
      exact drop_right hmu hk
    · have hklt : kappa void < kappa (eqW a a) := by
        have : 0 < kappa a := Nat.pos_of_ne_zero hk0
        simpa [kappa] using this
      exact drop_left hklt

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by
      simp [mu]
      omega
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by
      simp [kappa]
    exact drop_right hmu hk
```

The obstruction is the `R_rec_succ` rule. For example, take

```lean
b = void
s = void
n = delta void
```

Then the step is

```lean
Step
  (recDelta void void (delta (delta void)))
  (app void (recDelta void void (delta void)))
```

by `Step.R_rec_succ void void (delta void)`.

But the measures are:

```lean
measure (recDelta void void (delta (delta void))) = (1, 3)
measure (app void (recDelta void void (delta void))) = (1, 4)
```

So `kappa` ties and `mu` increases. Therefore

```lean
LexOrder
  (measure (app void (recDelta void void (delta void))))
  (measure (recDelta void void (delta (delta void))))
```

is false.

Thus the theorem

```lean
theorem measure_decreases :
  forall {a b : Trace}, Step a b -> LexOrder (measure b) (measure a)
```

cannot be completed without changing either the measure or the rewrite rule.
