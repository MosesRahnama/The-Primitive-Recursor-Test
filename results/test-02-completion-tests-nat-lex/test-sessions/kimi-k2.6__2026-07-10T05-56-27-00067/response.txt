Here is a complete tactic skeleton for the five remaining `sorry` cases.

```tactics
-- integrate (delta t) --> void
| _, _, Step.R_int_delta t => by
    have hmu : mu void < mu (integrate (delta t)) := by simp [mu]; omega
    by_cases h : kappa void < kappa (integrate (delta t))
    · exact drop_left h
    · have hk_eq : kappa void = kappa (integrate (delta t)) := by
        simp [kappa] at h ⊢
        omega
      exact drop_right hmu hk_eq

-- recDelta b s void --> b
| _, _, Step.R_rec_zero b s => by
    have hmu : mu b < mu (recDelta b s void) := by simp [mu]; omega
    by_cases h : kappa b < kappa (recDelta b s void)
    · exact drop_left h
    · have hk_eq : kappa b = kappa (recDelta b s void) := by
        simp [kappa, Nat.max_zero_right] at h ⊢
        have h_le : kappa b ≤ Nat.max (kappa b) (kappa s) := Nat.le_max_left (kappa b) (kappa s)
        have h_ge : Nat.max (kappa b) (kappa s) ≤ kappa b := by omega
        omega
      exact drop_right hmu hk_eq

-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    have hk : kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n)) := by
      simp [kappa]
      have h : kappa s ≤ Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) := by
        trans
        · exact Nat.le_max_right (kappa b) (kappa s)
        · exact Nat.le_max_left (Nat.max (kappa b) (kappa s)) (kappa n)
      rw [Nat.max_eq_left h]
      omega
    exact drop_left hk

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    have hmu : mu void < mu (eqW a a) := by simp [mu]; omega
    by_cases h : kappa void < kappa (eqW a a)
    · exact drop_left h
    · have hk_eq : kappa void = kappa (eqW a a) := by
        simp [kappa, Nat.max_self] at h ⊢
        omega
      exact drop_right hmu hk_eq

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by simp [mu]; omega
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by simp [kappa]
    exact drop_right hmu hk
```

**Why this works**

* **R_int_delta / R_eq_refl:** `mu` drops by a fixed positive amount, while `kappa` is monotonic (it does not increase). If `kappa` stays equal we use `drop_right`; if it decreases we use `drop_left`.
* **R_rec_zero:** `mu` drops by at least 3. After simplifying `kappa void = 0`, the target `kappa` becomes `max (kappa b) (kappa s)`. Either this is strictly larger than `kappa b` (`drop_left`), or it equals `kappa b` (`drop_right`).
* **R_rec_succ:** This is the only rule where `kappa` *strictly* decreases. The `+1` in the `recDelta`–`delta` clause disappears on the right-hand side, while the surrounding `max` collapses to the same inner maximum; hence `drop_left` applies directly.
* **R_eq_diff:** `kappa` is identical on both sides (`max (kappa a) (kappa b)`), but `mu` drops from `4 + mu a + mu b` to `3 + mu a + mu b`, so `drop_right` finishes the goal.
