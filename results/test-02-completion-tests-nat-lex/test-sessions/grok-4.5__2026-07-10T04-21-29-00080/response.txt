## Proof skeleton for the five remaining cases

The three completed cases all follow the same pattern: exhibit a strict `mu` drop together with a `kappa` tie, then apply `drop_right`. The five remaining rules need a slightly richer pattern because `kappa` may either drop or stay equal. The skeleton below keeps the same style (`drop_left` / `drop_right` + `simp`/`omega`) and only adds a `by_cases` (or an equivalent `Nat.eq_zero_or_pos`) when the two measures interact.

```lean
-- integrate (delta t) --> void
-- kappa :  0  ≟  kappa t     (tie  ⇔  kappa t = 0)
-- mu    :  0  <  1 + mu t    (always)
| _, _, Step.R_int_delta t => by
    have hmu : mu void < mu (integrate (delta t)) := by simp [mu]
    by_cases h : kappa t = 0
    · -- kappa ties
      have hk : kappa void = kappa (integrate (delta t)) := by simp [kappa, h]
      exact drop_right hmu hk
    · -- kappa drops
      have hk : kappa void < kappa (integrate (delta t)) := by simp [kappa]; omega
      exact drop_left hk

-- recDelta b s void --> b
-- kappa :  kappa b  ≟  max (max (kappa b) (kappa s)) 0
--         (tie  ⇔  kappa s ≤ kappa b)
-- mu    :  mu b  <  3 + mu b + mu s     (always)
| _, _, Step.R_rec_zero b s => by
    have hmu : mu b < mu (recDelta b s void) := by simp [mu]
    by_cases h : kappa b = kappa (recDelta b s void)
    · exact drop_right hmu h
    · -- the inequality kappa b ≤ kappa (recDelta …) is definitional,
      -- so ≠ immediately gives <
      have hk : kappa b < kappa (recDelta b s void) := by
        simp [kappa] at h ⊢
        omega
      exact drop_left hk

-- recDelta b s (delta n) --> app s (recDelta b s n)
-- kappa source = max (max (kappa b) (kappa s)) (kappa n) + 1
-- kappa target = max (kappa s) (kappa (recDelta b s n))
--
-- · when n is not of the form `delta _`,
--     kappa (recDelta b s n) = max (max …) (kappa n)
--     so target kappa = max (max …) (kappa n)  <  source kappa
-- · when n = delta m the two kappas become equal and one must
--   fall back to mu; that sub-case needs an extra local argument
--   (or a refined measure) – left as a nested case-split.
| _, _, Step.R_rec_succ b s n => by
    cases n with
    | delta m =>
        -- kappa ties; supply a mu argument (or refine the global measure)
        have hmu : mu (app s (recDelta b s (delta m)))
                   < mu (recDelta b s (delta (delta m))) := by
          simp [mu]; omega   -- may need a tighter measure
        have hk : kappa (app s (recDelta b s (delta m)))
                  = kappa (recDelta b s (delta (delta m))) := by
          simp [kappa]
        exact drop_right hmu hk
    | void =>
        apply drop_left; simp [kappa]; omega
    | integrate t =>
        apply drop_left; simp [kappa]; omega
    | merge a b' =>
        apply drop_left; simp [kappa]; omega
    | app a b' =>
        apply drop_left; simp [kappa]; omega
    | recDelta b' s' n' =>
        apply drop_left; simp [kappa]; omega
    | eqW a b' =>
        apply drop_left; simp [kappa]; omega

-- eqW a a --> void
-- kappa :  0  ≟  kappa a     (tie  ⇔  kappa a = 0)
-- mu    :  0  <  4 + 2·mu a  (always)
| _, _, Step.R_eq_refl a => by
    have hmu : mu void < mu (eqW a a) := by simp [mu]
    by_cases h : kappa a = 0
    · have hk : kappa void = kappa (eqW a a) := by simp [kappa, h]
      exact drop_right hmu hk
    · have hk : kappa void < kappa (eqW a a) := by simp [kappa]; omega
      exact drop_left hk

-- eqW a b --> integrate (merge a b)
-- kappa always ties:  max (kappa a) (kappa b) = max (kappa a) (kappa b)
-- mu    always drops by 1:  3 + mu a + mu b  <  4 + mu a + mu b
| _, _, Step.R_eq_diff a b => by
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by
      simp [mu]; omega
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by
      simp [kappa]
    exact drop_right hmu hk
```

### How the skeleton is meant to be read

| Rule | `kappa` behaviour | `mu` behaviour | Combinator |
|------|-------------------|----------------|------------|
| `R_int_delta` | may drop or tie | always ↓ | `by_cases` + `drop_left`/`drop_right` |
| `R_rec_zero` | may drop or tie | always ↓ | `by_cases` + `drop_left`/`drop_right` |
| `R_rec_succ` | drops on a non-`delta` predecessor; ties on a nested `delta` | (see note) | `cases n` then `drop_left` / `drop_right` |
| `R_eq_refl` | may drop or tie | always ↓ | `by_cases` + `drop_left`/`drop_right` |
| `R_eq_diff` | always ties | always ↓ | plain `drop_right` |

The only delicate point is the nested-`delta` branch of `R_rec_succ`. With the measure as written, both components of `(kappa,mu)` fail to decrease on that branch, so either

* a local strengthening of `mu` (e.g. give `app` a smaller weight, or count a “pending-recursor” component), or  
* an appeal to a different well-founded order  

is required before that single sub-goal can be closed. All other branches are completed exactly by the code above.
