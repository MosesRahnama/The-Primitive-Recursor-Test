Here is the completed proof skeleton for the remaining five cases. The proofs leverage the existing `drop_left` and `drop_right` lemmas, using `by_cases` to handle situations where the primary measure `kappa` might tie (requiring the secondary measure `mu` to show strict decrease) or strictly decrease.

```lean
-- ── Remaining cases ───────────────────────────────────────────

-- integrate (delta t) --> void
| _, _, Step.R_int_delta t => by
    by_cases h : kappa t = 0
    · -- If kappa t = 0, kappa ties, so we show mu strictly decreases.
      have hk : kappa void = kappa (integrate (delta t)) := by simp [kappa, h]
      have hmu : mu void < mu (integrate (delta t)) := by simp [mu]; omega
      exact drop_right hmu hk
    · -- If kappa t > 0, kappa strictly decreases.
      have hk : kappa void < kappa (integrate (delta t)) := by
        simp only [kappa_void, kappa_integrate, kappa_delta]
        omega
      exact drop_left hk

-- recDelta b s void --> b
| _, _, Step.R_rec_zero b s => by
    by_cases h : kappa b < kappa (recDelta b s void)
    · -- If kappa strictly decreases, we are done.
      exact drop_left h
    · -- Otherwise, kappa ties (since kappa b <= kappa (recDelta ...) is always true).
      have hk : kappa b = kappa (recDelta b s void) := by
        simp only [kappa] at h ⊢
        omega
      have hmu : mu b < mu (recDelta b s void) := by simp [mu]; omega
      exact drop_right hmu hk

-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    -- Here, the +1 in the kappa definition for delta-wrapped recDelta guarantees a strict drop.
    have hk : kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n)) := by
      simp only [kappa_app, kappa_rec_delta, kappa]
      -- Establish that kappa s is bounded by the max expression
      have h_le : kappa s ≤ max (max (kappa b) (kappa s)) (kappa n) := by omega
      -- Simplify the nested max
      rw [max_eq_right h_le]
      omega
    exact drop_left hk

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    by_cases h : kappa a = 0
    · -- If kappa a = 0, kappa ties, so we show mu strictly decreases.
      have hk : kappa void = kappa (eqW a a) := by simp [kappa, h]
      have hmu : mu void < mu (eqW a a) := by simp [mu]; omega
      exact drop_right hmu hk
    · -- If kappa a > 0, kappa strictly decreases.
      have hk : kappa void < kappa (eqW a a) := by
        simp only [kappa_void, kappa_eqW]
        omega
      exact drop_left hk

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    -- kappa is exactly preserved because max(kappa a, kappa b) is structurally identical.
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by simp [kappa]
    -- mu strictly decreases because the eqW weight (4) is greater than integrate+merge weights (1+2=3).
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by simp [mu]; omega
    exact drop_right hmu hk
```

### Key insights applied in the skeleton:
1. **`R_int_delta` & `R_eq_refl`**: The target is `void`, which has `kappa = 0`. Since the source's `kappa` could also be `0`, we split on whether the source's `kappa` is `0`. If it is, `kappa` ties and we rely on `mu` dropping. If it's `> 0`, `kappa` strictly drops.
2. **`R_rec_zero`**: The target is `b`. The source's `kappa` is `max (kappa b) (kappa s)`. We split on whether `kappa b` is strictly less than this max. If not, they must be equal, and we fall back to `mu` dropping.
3. **`R_rec_succ`**: The source has a `delta`-wrapped third argument, which explicitly adds `+ 1` to its `kappa` measure. The target unwraps the `delta` and shifts to an `app` node, meaning the target's `kappa` is strictly bounded by the source's `kappa` minus 1. Thus, `kappa` strictly decreases unconditionally.
4. **`R_eq_diff`**: Both sides evaluate to the exact same `kappa` (`max (kappa a) (kappa b)`). The proof strictly relies on the secondary measure `mu` dropping (the `eqW` constructor weight of `4` is strictly greater than the combined `integrate` + `merge` weight of `1 + 2 = 3`).
