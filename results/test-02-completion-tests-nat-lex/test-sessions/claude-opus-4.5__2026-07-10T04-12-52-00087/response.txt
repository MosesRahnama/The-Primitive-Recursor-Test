# Proof Skeleton for Remaining Cases

Based on the structure of the existing proofs and the definitions of `kappa` and `mu`, here's the proof skeleton for the five remaining cases:

## Case 1: `R_int_delta` - `integrate (delta t) --> void`

```lean
| _, _, Step.R_int_delta t => by
    -- kappa: kappa void = 0 ≤ kappa (integrate (delta t)) = kappa t
    -- mu: mu void = 0 < 1 + mu t = mu (integrate (delta t))
    have hmu : mu void < mu (integrate (delta t)) := by simp [mu]
    have hk  : kappa void ≤ kappa (integrate (delta t)) := by simp [kappa]; omega
    -- Either kappa drops strictly, or it ties (both 0 when kappa t = 0) and mu drops
    by_cases hkz : kappa t = 0
    · have hkeq : kappa void = kappa (integrate (delta t)) := by simp [kappa, hkz]
      exact drop_right hmu hkeq
    · have hklt : kappa void < kappa (integrate (delta t)) := by simp [kappa]; omega
      exact drop_left hklt
```

## Case 2: `R_rec_zero` - `recDelta b s void --> b`

```lean
| _, _, Step.R_rec_zero b s => by
    -- kappa: kappa b ≤ max(max(kappa b, kappa s), 0) = max(kappa b, kappa s)
    -- mu: mu b < 3 + mu b + mu s + 0 = mu (recDelta b s void)
    have hmu : mu b < mu (recDelta b s void) := by simp [mu]; omega
    have hk  : kappa b ≤ kappa (recDelta b s void) := by simp [kappa]; omega
    by_cases hkeq : kappa b = kappa (recDelta b s void)
    · exact drop_right hmu hkeq
    · have hklt : kappa b < kappa (recDelta b s void) := by omega
      exact drop_left hklt
```

## Case 3: `R_rec_succ` - `recDelta b s (delta n) --> app s (recDelta b s n)`

```lean
| _, _, Step.R_rec_succ b s n => by
    -- Key insight: kappa drops strictly because the delta wrapper is removed
    -- LHS kappa: max(max(kappa b, kappa s), kappa n) + 1
    -- RHS kappa: max(kappa s, kappa (recDelta b s n)) = max(kappa s, max(max(kappa b, kappa s), kappa n))
    --          = max(max(kappa b, kappa s), kappa n)
    -- So kappa drops by 1
    have hklt : kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n)) := by
      simp only [kappa_rec_delta, kappa_app]
      -- kappa (recDelta b s n) depends on whether n matches (delta _)
      -- In general: max(kappa s, kappa (recDelta b s n)) < max(max(kappa b, kappa s), kappa n) + 1
      omega
    exact drop_left hklt
```

## Case 4: `R_eq_refl` - `eqW a a --> void`

```lean
| _, _, Step.R_eq_refl a => by
    -- kappa: kappa void = 0, kappa (eqW a a) = max(kappa a, kappa a) = kappa a
    -- mu: mu void = 0 < 4 + mu a + mu a = mu (eqW a a)
    have hmu : mu void < mu (eqW a a) := by simp [mu]; omega
    by_cases hkz : kappa a = 0
    · have hkeq : kappa void = kappa (eqW a a) := by simp [kappa, hkz]
      exact drop_right hmu hkeq
    · have hklt : kappa void < kappa (eqW a a) := by simp [kappa]; omega
      exact drop_left hklt
```

## Case 5: `R_eq_diff` - `eqW a b --> integrate (merge a b)`

```lean
| _, _, Step.R_eq_diff a b => by
    -- kappa ties: kappa (integrate (merge a b)) = max(kappa a, kappa b) = kappa (eqW a b)
    -- mu drops: 1 + 2 + mu a + mu b = 3 + mu a + mu b < 4 + mu a + mu b
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by simp [mu]; omega
    have hk  : kappa (integrate (merge a b)) = kappa (eqW a b) := by simp [kappa]
    exact drop_right hmu hk
```
