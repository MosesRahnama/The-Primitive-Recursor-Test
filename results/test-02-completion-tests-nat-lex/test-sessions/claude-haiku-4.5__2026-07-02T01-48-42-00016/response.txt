# Proof Skeleton for Remaining Cases

Here's a proof skeleton for the five remaining cases in the `measure_decreases` theorem:

```lean
-- integrate (delta t) --> void
| _, _, Step.R_int_delta t => by
    have hk : kappa void < kappa (integrate (delta t)) := by simp [kappa]
    exact drop_left hk

-- recDelta b s void --> b
| _, _, Step.R_rec_zero b s => by
    have hk : kappa b < kappa (recDelta b s void) := by simp [kappa]; omega
    exact drop_left hk

-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    have hk : kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n)) := by 
      simp [kappa]; omega
    exact drop_left hk

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    have hk : kappa void < kappa (eqW a a) := by simp [kappa]; omega
    exact drop_left hk

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by simp [mu]; omega
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by simp [kappa]
    exact drop_right hmu hk
```

**Key observations:**

1. **Cases R_int_delta, R_rec_zero, R_rec_succ, R_eq_refl** use `drop_left` because `kappa` strictly decreases (the delta-wrapping transparency property makes kappa drop when delta layers are eliminated).

2. **Case R_eq_diff** uses `drop_right` because kappa is preserved (both sides have `max(kappa a, kappa b)`) but mu strictly decreases (4 + 2·size becomes 1 + 2·size).

3. All proofs use `simp` to unfold definitions and `omega` to discharge arithmetic inequalities.
