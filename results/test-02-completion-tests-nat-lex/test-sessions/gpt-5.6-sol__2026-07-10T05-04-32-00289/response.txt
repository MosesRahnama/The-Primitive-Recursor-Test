A complete proof cannot be given for the file as written: the `R_rec_succ` case does not always decrease `(kappa, mu)`. The other four cases have the following proof skeletons.

```lean
-- integrate (delta t) --> void
| _, _, Step.R_int_delta t => by
    by_cases hk : kappa t = 0
    · have hmu : mu void < mu (integrate (delta t)) := by
        simp [mu]
      have hk' : kappa void = kappa (integrate (delta t)) := by
        simp [kappa, hk]
      exact drop_right hmu hk'
    · have hpos : 0 < kappa t := Nat.pos_of_ne_zero hk
      apply drop_left
      simpa [kappa] using hpos

-- recDelta b s void --> b
| _, _, Step.R_rec_zero b s => by
    have hle : kappa b ≤ kappa (recDelta b s void) := by
      simp [kappa]
    by_cases hk : kappa b = kappa (recDelta b s void)
    · have hmu : mu b < mu (recDelta b s void) := by
        simp [mu]
        omega
      exact drop_right hmu hk
    · have hlt : kappa b < kappa (recDelta b s void) := by
        omega
      exact drop_left hlt

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    by_cases hk : kappa a = 0
    · have hmu : mu void < mu (eqW a a) := by
        simp [mu]
      have hk' : kappa void = kappa (eqW a a) := by
        simp [kappa, hk]
      exact drop_right hmu hk'
    · have hpos : 0 < kappa a := Nat.pos_of_ne_zero hk
      apply drop_left
      simpa [kappa] using hpos

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    have hmu :
        mu (integrate (merge a b)) < mu (eqW a b) := by
      simp [mu]
      omega
    have hk :
        kappa (integrate (merge a b)) = kappa (eqW a b) := by
      simp [kappa]
    exact drop_right hmu hk
```

The remaining `R_rec_succ` obligation is false. Take

```lean
b := void
s := void
n := delta void
```

Then the rule gives

```lean
Step
  (recDelta void void (delta (delta void)))
  (app void (recDelta void void (delta void)))
```

but the measures are

```lean
measure (recDelta void void (delta (delta void))) = (1, 3)
measure (app void (recDelta void void (delta void))) = (1, 4)
```

Thus `kappa` ties while `mu` increases, so

```lean
LexOrder
  (measure (app void (recDelta void void (delta void))))
  (measure (recDelta void void (delta (delta void))))
```

is false.

The issue is that `kappa` adds only one for `recDelta _ _ (delta n)`, regardless of whether `n` is itself delta-wrapped. On the right-hand side, `recDelta b s n` retains that same increment when `n = delta m`.

Consequently, `measure_decreases` and hence the displayed final proof cannot be completed without changing a definition or the rewrite rule. A typical repair would make `kappa` account for all leading `delta` constructors in the recursion argument (or make `delta` increase `kappa`), after which `R_rec_succ` can decrease in the first lexicographic component.
