**Proof skeleton for the five remaining cases**

```lean
-- integrate (delta t) --> void
-- kappa may drop or tie; mu always drops by 1 + mu t
| _, _, Step.R_int_delta t => by
    cases Nat.lt_or_eq_of_le (Nat.zero_le (kappa t)) with
    | inl hk => exact drop_left (by simp [kappa, hk])
    | inr hk =>
        have hmu : mu void < mu (integrate (delta t)) := by simp [mu]
        exact drop_right hmu (by simp [kappa, hk])

-- recDelta b s void --> b
-- mu drops by 3 + mu s; kappa may drop or tie
| _, _, Step.R_rec_zero b s => by
    cases Nat.lt_or_eq_of_le (Nat.zero_le (Nat.max (kappa b) (kappa s))) with
    | inl hk => exact drop_left (by simp [kappa, hk])
    | inr hk =>
        have hmu : mu b < mu (recDelta b s void) := by simp [mu]; omega
        exact drop_right hmu (by simp [kappa, hk])

-- recDelta b s (delta n) --> app s (recDelta b s n)
-- kappa drops by exactly 1 (recDelta's +1 disappears)
| _, _, Step.R_rec_succ b s n => by
    have hk : kappa (app s (recDelta b s n)) <
              kappa (recDelta b s (delta n)) := by
      simp [kappa]; omega
    exact drop_left hk

-- eqW a a --> void
-- mu drops by 4 + 2*mu a; kappa may drop or tie
| _, _, Step.R_eq_refl a => by
    cases Nat.lt_or_eq_of_le (Nat.zero_le (kappa a)) with
    | inl hk => exact drop_left (by simp [kappa, hk])
    | inr hk =>
        have hmu : mu void < mu (eqW a a) := by simp [mu]; omega
        exact drop_right hmu (by simp [kappa, hk])

-- eqW a b --> integrate (merge a b)
-- kappa ties; mu drops by 1
| _, _, Step.R_eq_diff a b => by
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by simp [mu]
    have hk  : kappa (integrate (merge a b)) = kappa (eqW a b) := by simp [kappa]
    exact drop_right hmu hk
```

Each case follows the same two-branch pattern used in the already-proved merge rules: either a strict `kappa` decrease (use `drop_left`) or a `kappa` tie with a strict `mu` decrease (use `drop_right`). The `omega` tactic is used only where the arithmetic is a simple linear inequality already implied by the definitions of `kappa`/`mu`.
