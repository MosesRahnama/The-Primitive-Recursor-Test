The remaining five cases of `measure_decreases` follow the same pattern as the three already proved: establish either a strict drop in `kappa` (then apply `drop_left`) or a tie in `kappa` together with a strict drop in `mu` (then apply `drop_right`).  Four of the five cases go through with a short case-split on whether `kappa` ties; the fifth (`R_rec_succ`) needs an additional structural case-split on the third argument of `recDelta` because that is what determines whether `kappa` drops.

```lean
-- integrate (delta t) --> void
-- κ may drop (to 0) or tie; μ always drops by 1+μ t
| _, _, Step.R_int_delta t => by
    have hmu : mu void < mu (integrate (delta t)) := by simp [mu]
    by_cases h : kappa t = 0
    · -- κ ties at 0
      have hk : kappa void = kappa (integrate (delta t)) := by simp [kappa, h]
      exact drop_right hmu hk
    · -- κ drops
      have hk : kappa void < kappa (integrate (delta t)) := by
        simp [kappa]; omega
      exact drop_left hk

-- recDelta b s void --> b
-- κ_L = max(κ b, κ s); κ may drop or tie; μ always drops by 3+μ s
| _, _, Step.R_rec_zero b s => by
    have hmu : mu b < mu (recDelta b s void) := by simp [mu]; omega
    by_cases h : kappa b ≥ kappa s
    · -- κ ties (max(κb,κs) = κb)
      have hk : kappa b = kappa (recDelta b s void) := by
        simp [kappa]; omega
      exact drop_right hmu hk
    · -- κ drops
      have hk : kappa b < kappa (recDelta b s void) := by
        simp [kappa]; omega
      exact drop_left hk

-- recDelta b s (delta n) --> app s (recDelta b s n)
-- μ always *increases*; therefore the only hope is a strict drop in κ.
-- κ drops precisely when n is not itself headed by delta;
-- when n = delta _ the two κ values are equal (and the measure fails).
| _, _, Step.R_rec_succ b s n => by
    cases n with
    | delta m =>
        -- κ ties, μ increases – LexOrder does not hold
        -- (counter-example: b=s=void, n=delta void)
        sorry
    | void | integrate _ | merge _ _ | app _ _ | recDelta _ _ _ | eqW _ _ =>
        -- third argument is not delta-headed, so
        -- κ(recDelta b s n) = max(max(κb,κs),κn)
        -- and therefore κ_R = max(κs, that) = that = κ_L - 1
        have hk : kappa (app s (recDelta b s n))
                  < kappa (recDelta b s (delta n)) := by
          simp [kappa]
          -- after simp the goal is essentially
          -- max (κ s) (max (max (κ b) (κ s)) (κ n))
          --   < max (max (κ b) (κ s)) (κ n) + 1
          omega
        exact drop_left hk

-- eqW a a --> void
-- same shape as R_int_delta: κ may drop to 0 or tie; μ always drops
| _, _, Step.R_eq_refl a => by
    have hmu : mu void < mu (eqW a a) := by simp [mu]; omega
    by_cases h : kappa a = 0
    · have hk : kappa void = kappa (eqW a a) := by simp [kappa, h]
      exact drop_right hmu hk
    · have hk : kappa void < kappa (eqW a a) := by
        simp [kappa]; omega
      exact drop_left hk

-- eqW a b --> integrate (merge a b)
-- κ always ties (both sides = max(κa,κb)); μ drops by 1
| _, _, Step.R_eq_diff a b => by
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by
      simp [mu]; omega
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by
      simp [kappa]
    exact drop_right hmu hk
```

(The only `sorry` that remains is the nested-delta subcase of `R_rec_succ`; under the given definitions of `kappa`/`mu` that subcase simply does not decrease the lexicographic measure.  A repaired `kappa` that adds `+1` for every delta layer – i.e. `kappa (recDelta b s (delta n)) = kappa (recDelta b s n) + 1` – would make the same skeleton go through without the inner case-split.)
