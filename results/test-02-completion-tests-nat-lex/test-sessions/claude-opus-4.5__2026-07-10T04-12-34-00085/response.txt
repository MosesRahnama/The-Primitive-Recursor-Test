# Proof Skeleton for Remaining Cases

Looking at the measures and the reduction rules, I can analyze what needs to be proved for each remaining case:

## Case 1: `R_int_delta` - `integrate (delta t) --> void`

**Analysis:**
- LHS: `integrate (delta t)` has `kappa = kappa t`, `mu = 1 + mu t`
- RHS: `void` has `kappa = 0`, `mu = 0`

**Strategy:** The mu strictly decreases (from `1 + mu t` to `0`), and kappa either decreases or ties (depending on `t`). We can use either `drop_left` if `kappa t > 0`, or `drop_right` if `kappa t = 0`. Actually, since `0 ≤ kappa t` always holds and `mu` strictly drops, we need to handle both components. The cleanest approach: show mu drops and kappa is `≤`, then case split or use that `0 < 1 + mu t` always.

```lean
| _, _, Step.R_int_delta t => by
    -- kappa void = 0, kappa (integrate (delta t)) = kappa t
    -- mu void = 0, mu (integrate (delta t)) = 1 + mu t
    -- Since 0 < 1 + mu t, mu strictly decreases
    -- Need: either kappa drops, or kappa ties and mu drops
    -- Case split on whether kappa t = 0
    by_cases hk : kappa t = 0
    · -- kappa ties at 0, mu drops
      have hmu : mu void < mu (integrate (delta t)) := by simp [mu]; omega
      have hkeq : kappa void = kappa (integrate (delta t)) := by simp [kappa, hk]
      exact drop_right hmu hkeq
    · -- kappa drops (kappa t > 0)
      have hklt : kappa void < kappa (integrate (delta t)) := by simp [kappa]; omega
      exact drop_left hklt
```

## Case 2: `R_rec_zero` - `recDelta b s void --> b`

**Analysis:**
- LHS: `recDelta b s void` has `kappa = max (max (kappa b) (kappa s)) 0 = max (kappa b) (kappa s)`, `mu = 3 + mu b + mu s + 0`
- RHS: `b` has `kappa = kappa b`, `mu = mu b`

```lean
| _, _, Step.R_rec_zero b s => by
    -- mu drops: mu b < 3 + mu b + mu s + mu void = 3 + mu b + mu s
    -- kappa: kappa b ≤ max (kappa b) (kappa s) = kappa (recDelta b s void)
    have hmu : mu b < mu (recDelta b s void) := by simp [mu]; omega
    have hk : kappa b ≤ kappa (recDelta b s void) := by simp [kappa]; exact Nat.le_max_left _ _
    -- Need kappa b = kappa (recDelta b s void) to use drop_right, or < to use drop_left
    by_cases hkeq : kappa b = kappa (recDelta b s void)
    · exact drop_right hmu hkeq
    · exact drop_left (Nat.lt_of_le_of_ne hk hkeq)
```

## Case 3: `R_rec_succ` - `recDelta b s (delta n) --> app s (recDelta b s n)`

**Analysis:**
- LHS: `kappa = max (max (kappa b) (kappa s)) (kappa n) + 1`
- RHS: `app s (recDelta b s n)` has `kappa = max (kappa s) (kappa (recDelta b s n))`

The key insight: `kappa (recDelta b s n) ≤ max (max (kappa b) (kappa s)) (kappa n)` (no +1 unless n is delta-wrapped), so RHS kappa < LHS kappa.

```lean
| _, _, Step.R_rec_succ b s n => by
    -- kappa strictly decreases because we unwrap one delta
    have hk : kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n)) := by
      simp [kappa]
      -- Need to show max (kappa s) (kappa (recDelta b s n)) < max (max (kappa b) (kappa s)) (kappa n) + 1
      omega  -- or manual case analysis on recDelta pattern
    exact drop_left hk
```

## Case 4: `R_eq_refl` - `eqW a a --> void`

```lean
| _, _, Step.R_eq_refl a => by
    by_cases hk : kappa a = 0
    · have hmu : mu void < mu (eqW a a) := by simp [mu]; omega
      have hkeq : kappa void = kappa (eqW a a) := by simp [kappa, hk]
      exact drop_right hmu hkeq
    · have hklt : kappa void < kappa (eqW a a) := by simp [kappa]; omega
      exact drop_left hklt
```

## Case 5: `R_eq_diff` - `eqW a b --> integrate (merge a b)`

```lean
| _, _, Step.R_eq_diff a b => by

    -- mu drops: 1 + 2 + mu a + mu b = 3 + mu a + mu b < 4 + mu a + mu b
```
