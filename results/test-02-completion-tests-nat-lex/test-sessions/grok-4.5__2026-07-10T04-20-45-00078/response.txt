The five remaining cases follow the same `drop_left` / `drop_right` pattern as the three completed ones. Below is a proof skeleton for each. Four cases go through with the given measure; the fifth (`R_rec_succ`) does **not** — the measure is not strictly decreasing on that rule when the third argument of `recDelta` is itself `delta`-headed (nested numerals). The skeleton for that case records the intended case split and the obstruction.

```lean
-- ── Remaining cases ───────────────────────────────────────────

-- integrate (delta t) --> void
-- kappa_LHS = kappa t,  kappa_RHS = 0
-- mu_LHS    = 1 + mu t, mu_RHS    = 0
-- Either kappa drops (kappa t > 0) or kappa ties and mu drops.
| _, _, Step.R_int_delta t => by
    by_cases h : kappa t = 0
    · -- kappa ties at 0; mu drops
      have hmu : mu void < mu (integrate (delta t)) := by simp [mu]
      have hk  : kappa void = kappa (integrate (delta t)) := by simp [kappa, h]
      exact drop_right hmu hk
    · -- kappa drops
      have hk : kappa void < kappa (integrate (delta t)) := by
        simp [kappa]; exact Nat.pos_of_ne_zero h
      exact drop_left hk

-- recDelta b s void --> b
-- kappa_LHS = max(max(kb, ks), 0) = max(kb, ks)
-- kappa_RHS = kb
-- mu always drops by ≥ 3; kappa drops or ties according to ks ≰ kb.
| _, _, Step.R_rec_zero b s => by
    have hmu : mu b < mu (recDelta b s void) := by simp [mu]; omega
    -- second equation of kappa (void is not delta-headed)
    have krec : kappa (recDelta b s void)
                  = Nat.max (Nat.max (kappa b) (kappa s)) (kappa void) := rfl
    by_cases h : kappa b < Nat.max (kappa b) (kappa s)
    · -- kappa strictly decreases
      have hk : kappa b < kappa (recDelta b s void) := by
        simp only [krec, kappa_void]; omega
      exact drop_left hk
    · -- kappa ties; mu drops
      have hk : kappa b = kappa (recDelta b s void) := by
        simp only [krec, kappa_void]; omega
      exact drop_right hmu hk

-- recDelta b s (delta n) --> app s (recDelta b s n)
-- kappa_LHS = max(max(kb, ks), kappa n) + 1   (first equation of kappa)
--
-- Subcase n not delta-headed:
--   kappa(recDelta b s n) = max(max(kb,ks), kappa n) = kappa_LHS - 1
--   ⇒ kappa_RHS = max(ks, kappa_LHS - 1) < kappa_LHS   → drop_left
--
-- Subcase n = delta m:
--   kappa(recDelta b s n) = max(max(kb,ks), kappa m) + 1 = kappa_LHS
--   ⇒ kappa_RHS = max(ks, kappa_LHS) = kappa_LHS        → kappa ties
--   but mu_RHS = 4 + μb + 2·μs + μn
--       mu_LHS = 3 + μb + μs + μn
--   so mu_RHS > mu_LHS.  Lexicographic measure *increases*.
--   The claim measure_decreases is false for this rule instance.
--
-- Skeleton (cannot be completed with the present measure):
| _, _, Step.R_rec_succ b s n => by
    -- Intended argument: show kappa always drops, then drop_left.
    -- That holds only when n is not delta-headed.
    -- When n is delta-headed the kappa components are equal and mu rises,
    -- so neither drop_left nor drop_right applies.
    sorry

    --  argument of recDelta, e.g. replace transparency of delta by
    --  a dedicated succ-height so that peeling one delta always
    --  lowers kappa.  Then the proof becomes a uniform drop_left.)

-- eqW a a --> void
-- kappa_LHS = kappa a,  kappa_RHS = 0
-- mu_LHS    = 4 + 2·mu a, mu_RHS = 0
-- Same shape as R_int_delta.
| _, _, Step.R_eq_refl a => by
    by_cases h : kappa a = 0
    · have hmu : mu void < mu (eqW a a) := by simp [mu]; omega
      have hk  : kappa void = kappa (eqW a a) := by simp [kappa, h]
      exact drop_right hmu hk
    · have hk : kappa void < kappa (eqW a a) := by
        simp [kappa]; exact Nat.pos_of_ne_zero h
      exact drop_left hk

-- eqW a b --> integrate (merge a b)
-- kappa ties: both sides equal max(ka, kb)
-- mu drops by 1:  (1 + 2 + μa + μb) < (4 + μa + μb)
| _, _, Step.R_eq_diff a b => by

      simp [mu]; omega
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by
      simp [kappa]
    exact drop_right hmu hk
```

**Summary**

| Rule | kappa behaviour | mu behaviour | Tactic |
|------|-----------------|--------------|--------|
| `R_int_delta` | drops or ties | always drops | `by_cases` on `kappa t = 0` |
| `R_rec_zero` | drops or ties | always drops | `by_cases` on `kb < max(kb,ks)` |
| `R_rec_succ` | drops only if `n` not `delta`-headed; **ties + mu rises** otherwise | — | **blocked** by present measure |
| `R_eq_refl` | drops or ties | always drops | `by_cases` on `kappa a = 0` |
| `R_eq_diff` | always ties | always drops by 1 | direct `drop_right` |

The three already-proved merge rules and the four cases above (excluding `R_rec_succ`) are all that the current `(kappa, mu)` lex measure can justify. Completing `R_rec_succ` requires a revised `kappa` that strictly decreases whenever a `delta` is peeled from the third argument of `recDelta`.
