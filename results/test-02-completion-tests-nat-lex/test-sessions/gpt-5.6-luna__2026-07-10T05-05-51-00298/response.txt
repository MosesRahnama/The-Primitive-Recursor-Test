No complete proof skeleton exists for this file as written. The `R_rec_succ` case does not strictly decrease the declared measure.

Take

```lean
q := recDelta void void (delta void)
n := delta q
```

and instantiate `R_rec_succ` with `b := void`, `s := void`, and this `n`. Then the step is

```lean
recDelta void void (delta n)
  ↦ app void (recDelta void void n)
```

The measures are:

```lean
kappa (recDelta void void (delta n)) = 2
mu    (recDelta void void (delta n)) = 6

kappa (app void (recDelta void void n)) = 2
mu    (app void (recDelta void void n)) = 7
```

Thus the two `kappa` values tie, but the `mu` value increases. Consequently,

```lean
¬ LexOrder
    (measure (app void (recDelta void void n)))
    (measure (recDelta void void (delta n)))
```

so the required `R_rec_succ` proof is false.

The other four remaining cases can be handled by the intended pattern:

```lean
| _, _, Step.R_int_delta t => by
    by_cases hκ : 0 < kappa t
    · apply drop_left
      simpa [kappa] using hκ
    · have hκ0 : kappa t = 0 := by omega
      apply drop_right
      · simp [mu]
      · simp [kappa, hκ0]

| _, _, Step.R_rec_zero b s => by
    by_cases hκ : kappa b < kappa (recDelta b s void)
    · exact drop_left hκ
    · apply drop_right
      · simp [mu]
        omega
      · simp [kappa] at hκ ⊢
        omega

| _, _, Step.R_eq_refl a => by
    by_cases hκ : 0 < kappa (eqW a a)
    · apply drop_left
      simpa using hκ
    · have hκ0 : kappa a = 0 := by
        simp [kappa] at hκ ⊢
        omega
      apply drop_right
      · simp [mu, hκ0]
      · simp [kappa, hκ0]

| _, _, Step.R_eq_diff a b => by
    apply drop_right
    · simp [mu]
      omega
    · simp [kappa]
```

But the `R_rec_succ` branch cannot be completed without changing either the measure or that rewrite rule.
