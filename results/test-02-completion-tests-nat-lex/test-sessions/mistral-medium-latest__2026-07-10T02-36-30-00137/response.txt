Here's a proof skeleton for completing the remaining five cases in the `measure_decreases` theorem:

```lean
-- integrate (delta t) --> void
| _, _, Step.R_int_delta t => by
    have hmu : mu void < mu (integrate (delta t)) := by simp [mu]
    have hk  : kappa void = kappa (integrate (delta t)) := by simp [kappa]
    exact drop_right hmu hk

-- recDelta b s void --> b
| _, _, Step.R_rec_zero b s => by
    have hmu : mu b < mu (recDelta b s void) := by simp [mu]; omega
    have hk  : kappa b = kappa (recDelta b s void) := by simp [kappa]
    exact drop_right hmu hk

-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    have hk : kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n)) := by
      simp [kappa]
      omega
    exact drop_left hk

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    have hmu : mu void < mu (eqW a a) := by simp [mu]
    have hk  : kappa void = kappa (eqW a a) := by simp [kappa]
    exact drop_right hmu hk

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by
      simp [mu]
      omega
    have hk  : kappa (integrate (merge a b)) = kappa (eqW a b) := by
      simp [kappa]
    exact drop_right hmu hk
```

The proof strategy for each case follows this pattern:
1. For cases where kappa decreases (like `R_rec_succ`), we use `drop_left` with a proof that kappa strictly decreases
2. For cases where kappa stays the same but mu decreases (all other cases), we:
   - Prove `mu b < mu a` using `simp [mu]` and `omega` for arithmetic
   - Prove `kappa b = kappa a` using `simp [kappa]`
   - Apply `drop_right` with these two facts

The `omega` tactic is particularly useful for handling the arithmetic inequalities that arise from the recursive definitions of `mu` and `kappa`.
