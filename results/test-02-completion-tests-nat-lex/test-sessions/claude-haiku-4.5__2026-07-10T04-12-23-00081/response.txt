# Proof Skeleton for Remaining Cases

Here's a structured approach for each of the five remaining cases:

```lean
-- integrate (delta t) --> void
| _, _, Step.R_int_delta t => by
    -- kappa: kappa(void) = 0, kappa(integrate(delta t)) = kappa(delta t) = kappa t
    -- Need: 0 < kappa t, which fails for t = void
    -- Strategy: Use drop_left with kappa strictly decreasing
    have hk : kappa void < kappa (integrate (delta t)) := by simp [kappa]; omega
    exact drop_left hk

-- recDelta b s void --> b
| _, _, Step.R_rec_zero b s => by
    -- kappa: kappa(b) vs kappa(recDelta b s void)
    --        = max(max(kappa b, kappa s), kappa void)
    --        = max(kappa b, kappa s)
    -- mu: mu(b) vs mu(recDelta b s void)
    --     = 3 + mu b + mu s + mu void
    -- Strategy: Use drop_right, showing kappa ties and mu strictly decreases
    have hk : kappa b = kappa (recDelta b s void) := by simp [kappa]; omega
    have hmu : mu b < mu (recDelta b s void) := by simp [mu]; omega
    exact drop_right hmu hk

-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    -- kappa: kappa(app s (recDelta b s n))
    --        = max(kappa s, kappa(recDelta b s n))
    --        = max(kappa s, max(max(kappa b, kappa s), kappa n))
    --        = max(kappa b, kappa s, kappa n)
    -- kappa(recDelta b s (delta n))
    --        = max(max(kappa b, kappa s), kappa n) + 1
    -- kappa strictly decreases by 1
    have hk : kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n)) := by
      simp [kappa]; omega
    exact drop_left hk

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    -- kappa: kappa(void) = 0, kappa(eqW a a) = max(kappa a, kappa a) = kappa a
    -- Need: 0 < kappa a, which fails in general
    -- Strategy: Use drop_left with kappa strictly decreasing
    have hk : kappa void < kappa (eqW a a) := by simp [kappa]; omega
    exact drop_left hk

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    -- kappa: kappa(integrate(merge a b)) = kappa(merge a b) = max(kappa a, kappa b)
    -- kappa(eqW a b) = max(kappa a, kappa b)
    -- kappa ties!
    -- mu: mu(integrate(merge a b)) = 1 + mu(merge a b) = 1 + 2 + mu a + mu b = 3 + mu a + mu b
    -- mu(eqW a b) = 4 + mu a + mu b
    -- mu strictly decreases by 1
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by simp [kappa]
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by simp [mu]; omega
    exact drop_right hmu hk
```

**Key insights:**
- **Cases with kappa drop** (R_int_delta, R_rec_succ, R_eq_refl): Use `drop_left` exploiting the strict decrease in kappa
- **Cases with kappa tie** (R_rec_zero, R_eq_diff): Use `drop_right` with kappa equality and mu strictly decreasing
- All omega tactics rely on the simp lemmas to unfold measure definitions and perform arithmetic verification
