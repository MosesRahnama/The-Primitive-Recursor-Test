## Proof skeleton for the five remaining cases

The three already-proved merge rules all follow the same pattern: **kappa ties, mu drops**, hence `drop_right`. The remaining rules split into three patterns:

| Rule | kappa behaviour | mu behaviour | tactic pattern |
|---|---|---|---|
| `R_eq_diff` | always ties | always drops | `drop_right` |
| `R_int_delta`, `R_rec_zero`, `R_eq_refl` | may drop or tie | always drops | `by_cases` on the kappa comparison, then `drop_left` / `drop_right` |
| `R_rec_succ` | intended to drop (the source carries an explicit `+ 1`) | may rise | `drop_left` |

---

### 1. `R_int_delta` — `integrate (delta t) → void`

```lean
-- integrate (delta t) --> void
-- measure void = (0, 0)
-- measure (integrate (delta t)) = (kappa t, 1 + mu t)
-- mu always drops; kappa drops iff kappa t > 0
| _, _, Step.R_int_delta t => by
    have hmu : mu void < mu (integrate (delta t)) := by
      simp [mu]; omega
    by_cases h : kappa t = 0
    · -- kappa ties at 0, mu drops
      apply drop_right hmu
      simp [kappa, h]
    · -- kappa strictly drops
      apply drop_left
      simp [kappa]; omega
```

---

### 2. `R_rec_zero` — `recDelta b s void → b`

```lean
-- recDelta b s void --> b
-- kappa (recDelta b s void) = max (max (kappa b) (kappa s)) 0
--                           = max (kappa b) (kappa s)   (Nat)
-- so kappa b ≤ kappa source, with equality iff kappa s ≤ kappa b
-- mu always drops (by at least 3)
| _, _, Step.R_rec_zero b s => by
    have hmu : mu b < mu (recDelta b s void) := by
      simp [mu]; omega
    by_cases h : kappa s ≤ kappa b
    · -- kappa ties: max(kb, ks) = kb
      apply drop_right hmu
      simp [kappa]; omega
    · -- kappa drops: kb < max(kb, ks)
      apply drop_left
      simp [kappa]; omega
```

---

### 3. `R_rec_succ` — `recDelta b s (delta n) → app s (recDelta b s n)`

```lean
-- recDelta b s (delta n) --> app s (recDelta b s n)
-- kappa source = max (max (kappa b) (kappa s)) (kappa n) + 1
-- kappa target = max (kappa s) (kappa (recDelta b s n))
-- Strategy: show kappa target < kappa source, then drop_left.
--
-- Key bound needed:
--   kappa (recDelta b s n) ≤ max (max (kappa b) (kappa s)) (kappa n)
-- which holds whenever the third argument is NOT headed by `delta`.
-- (If n = delta m the bound fails and kappa merely ties; the present
--  measure then does not decrease — see remark below.)
| _, _, Step.R_rec_succ b s n => by
    apply drop_left
    -- Goal: kappa (app s (recDelta b s n))
    --     < kappa (recDelta b s (delta n))
    simp only [kappa_app, kappa_rec_delta]
    -- Goal: max (kappa s) (kappa (recDelta b s n))
    --     < max (max (kappa b) (kappa s)) (kappa n) + 1
    have hks : kappa s ≤ Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) := by
      omega
    have hrec : kappa (recDelta b s n)
                  ≤ Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) := by
      -- discharge by cases on the shape of n
      cases n with
      | void          => simp [kappa]; omega
      | delta m       =>
          -- bound fails: kappa gets an extra +1
          -- (nested-delta edge case; see remark)
          simp [kappa]; omega   -- ← will not close
      | integrate t   => simp [kappa]; omega
      | merge a b'    => simp [kappa]; omega
      | app a b'      => simp [kappa]; omega
      | recDelta b' s' n' => simp [kappa]; omega
      | eqW a b'      => simp [kappa]; omega
    -- max of two quantities each ≤ K is ≤ K, hence < K+1
    omega
```

**Remark on nested deltas.**  
If `n = delta m`, then
```
kappa (recDelta b s n) = max(max(kb,ks), kappa m) + 1
                       = max(max(kb,ks), kappa n) + 1
```
so kappa *ties*, while
```
mu (app s (recDelta b s n)) = 4 + μb + 2μs + μn
mu (recDelta b s (delta n)) = 3 + μb + μs + μn
```
so mu *increases*. The lexicographic pair therefore does not decrease on that instance. A measure that counts the full leading-delta depth of the third argument of `recDelta` (instead of a single `+ 1`) would restore a uniform kappa drop; with the measure as written the nested-delta subcase is a genuine gap.

### 4. `R_eq_refl` — `eqW a a → void`

```lean
-- eqW a a --> void
-- measure void = (0, 0)
-- measure (eqW a a) = (kappa a, 4 + 2 * mu a)
-- same pattern as R_int_delta
| _, _, Step.R_eq_refl a => by
    have hmu : mu void < mu (eqW a a) := by
      simp [mu]; omega
    by_cases h : kappa a = 0
    · apply drop_right hmu
      simp [kappa, h]
    · apply drop_left
      simp [kappa]; omega
```

---

### 5. `R_eq_diff` — `eqW a b → integrate (merge a b)`

```lean
-- eqW a b --> integrate (merge a b)
-- kappa (integrate (merge a b)) = max (kappa a) (kappa b)
--                               = kappa (eqW a b)          (always ties)
-- mu:  3 + μa + μb  <  4 + μa + μb                        (drops by 1)
| _, _, Step.R_eq_diff a b => by
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by
      simp [mu]; omega
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by
      simp [kappa]
    exact drop_right hmu hk
```

---

### Summary of the skeleton

```lean
theorem measure_decreases : forall {a b : Trace}, Step a b -> LexOrder (measure b) (measure a)
-- proved
| _, _, Step.R_merge_void_left  t     => by ...  -- drop_right
| _, _, Step.R_merge_void_right t     => by ...  -- drop_right
| _, _, Step.R_merge_cancel     t     => by ...  -- drop_right
-- remaining
| _, _, Step.R_int_delta        t     => by by_cases (kappa t = 0) <;> drop_right / drop_left
| _, _, Step.R_rec_zero         b s   => by by_cases (kappa s ≤ kappa b) <;> drop_right / drop_left
| _, _, Step.R_rec_succ         b s n => by drop_left  (kappa source has +1; bound kappa of result)
| _, _, Step.R_eq_refl          a     => by by_cases (kappa a = 0) <;> drop_right / drop_left
| _, _, Step.R_eq_diff          a b   => by drop_right  (kappa ties, mu drops by 1)
```

Four of the five cases are unconditional with the given measure. Completing `R_rec_succ` for arbitrary `n` requires either strengthening `kappa` so that it counts the full leading-delta spine of the third argument of `recDelta`, or accepting an auxiliary well-founded order that can absorb the nested-delta residual.
