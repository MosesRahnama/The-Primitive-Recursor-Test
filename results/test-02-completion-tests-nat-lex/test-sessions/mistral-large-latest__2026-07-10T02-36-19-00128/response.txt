Here are the proof skeletons for the remaining five cases in the `measure_decreases` theorem. Each case follows the same pattern: analyze how the measure changes and use either `drop_left` (when kappa decreases) or `drop_right` (when kappa stays the same but mu decreases).

### 1. `R_int_delta` case
```lean
| _, _, Step.R_int_delta t => by
    have hk : kappa void < kappa (integrate (delta t)) := by
      simp [kappa]; omega
    exact drop_left hk
```

### 2. `R_rec_zero` case
```lean
| _, _, Step.R_rec_zero b s => by
    have hmu : mu b < mu (recDelta b s void) := by
      simp [mu]; omega
    have hk : kappa b = kappa (recDelta b s void) := by
      simp [kappa]
    exact drop_right hmu hk
```

### 3. `R_rec_succ` case
```lean
| _, _, Step.R_rec_succ b s n => by
    have hk : kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n)) := by
      simp [kappa]
      have h1 : kappa (recDelta b s n) ≤ Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) := by
        simp [kappa]
      omega
    exact drop_left hk
```

### 4. `R_eq_refl` case
```lean
| _, _, Step.R_eq_refl a => by
    have hk : kappa void < kappa (eqW a a) := by
      simp [kappa]; omega
    exact drop_left hk
```

### 5. `R_eq_diff` case
```lean
| _, _, Step.R_eq_diff a b => by
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by
      simp [mu]; omega
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by
      simp [kappa]
    exact drop_right hmu hk
```

### Explanation:
1. **`R_int_delta`**: The `kappa` measure decreases from `kappa t` to `0`, so we use `drop_left`.
2. **`R_rec_zero`**: The `kappa` measure stays the same (since `void` doesn't contribute to recursion depth), but `mu` decreases by `3 + mu s`, so we use `drop_right`.
3. **`R_rec_succ`**: The `kappa` measure decreases by 1 (since we remove a `delta` wrapper from the third argument of `recDelta`), so we use `drop_left`.
4. **`R_eq_refl`**: The `kappa` measure decreases from `max(kappa a, kappa a)` to `0`, so we use `drop_left`.
5. **`R_eq_diff`**: The `kappa` measure stays the same (since `integrate` and `merge` don't affect `kappa`), but `mu` decreases by `4 + mu a + mu b - (1 + 2 + mu a + mu b) = 1`, so we use `drop_right`.

Each proof uses `simp` to unfold the definitions of `kappa` and `mu`, and `omega` to handle arithmetic inequalities. The `drop_left` and `drop_right` lemmas are used to construct the lexicographic order proof.
