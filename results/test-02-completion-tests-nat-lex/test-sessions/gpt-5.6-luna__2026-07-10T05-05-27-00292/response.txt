No proof skeleton exists for all five cases with the stated measure. The `R_rec_succ` case is false: the lexicographic measure does not always decrease.

For example, instantiate

```lean
b := void
s := void
n := delta void
```

Then the rewrite is

```lean
Step
  (recDelta void void (delta (delta void)))
  (app void (recDelta void void (delta void)))
```

The measures are:

```lean
kappa (recDelta void void (delta (delta void))) = 1
mu    (recDelta void void (delta (delta void))) = 3

kappa (app void (recDelta void void (delta void))) = 1
mu    (app void (recDelta void void (delta void))) = 4
```

Thus the kappa components tie, but the target has a larger mu component. Consequently,

```lean
¬ LexOrder
    (measure (app void (recDelta void void (delta void))))
    (measure (recDelta void void (delta (delta void))))
```

so the required conclusion in the `R_rec_succ` branch is unprovable.

The intended skeleton for the other four cases can be completed along these lines:

```lean
-- integrate (delta t) --> void
| _, _, Step.R_int_delta t => by
    by_cases hk : kappa t = 0
    · apply drop_right
      · simp [mu]
        omega
      · simp [kappa, hk]
    · apply drop_left
      simp [kappa]
      omega

-- recDelta b s void --> b
| _, _, Step.R_rec_zero b s => by
    have hle :
        kappa b ≤ kappa (recDelta b s void) := by
      simp [kappa]
      exact le_trans
        (Nat.le_max_left _ _)
        (Nat.le_max_left _ _)
    by_cases hlt : kappa b < kappa (recDelta b s void)
    · exact drop_left hlt
    · have hk : kappa b = kappa (recDelta b s void) := by
        omega
      apply drop_right
      · simp [mu]
        omega
      · exact hk

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    by_cases hk : kappa a = 0
    · apply drop_right
      · simp [mu]
        omega
      · simp [kappa, hk]
    · apply drop_left
      simp [kappa]
      omega

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    apply drop_right
    · simp [mu]
      omega
    · simp [kappa]
```

However, the `R_rec_succ` branch cannot be filled without changing the measure, changing the rule, or weakening the theorem.
