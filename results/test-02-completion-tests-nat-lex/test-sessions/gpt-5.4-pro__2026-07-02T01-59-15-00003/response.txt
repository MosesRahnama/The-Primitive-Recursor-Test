Here’s a workable skeleton for the five remaining branches.

The first, second, fourth, and fifth can be completed directly.  
The `R_rec_succ` branch is different: with the current definitions of `kappa` and `mu`, the statement is actually false in the subcase `n = delta n'`, so that branch cannot be closed without changing the measure.

## 1. `integrate (delta t) --> void`

```lean
| _, _, Step.R_int_delta t => by
    by_cases ht : kappa t = 0
    · have hmu : mu void < mu (integrate (delta t)) := by
        simp [mu]
      have hk : kappa void = kappa (integrate (delta t)) := by
        simpa [kappa] using ht.symm
      exact drop_right hmu hk
    · have hk : kappa void < kappa (integrate (delta t)) := by
        have hpos : 0 < kappa t := Nat.pos_of_ne_zero ht
        simpa [kappa] using hpos
      exact drop_left hk
```

## 2. `recDelta b s void --> b`

```lean
| _, _, Step.R_rec_zero b s => by
    have hmu : mu b < mu (recDelta b s void) := by
      simp [mu]
      omega
    by_cases hs : kappa s ≤ kappa b
    · have hk : kappa b = kappa (recDelta b s void) := by
        simp [kappa, Nat.max_eq_left hs]
      exact drop_right hmu hk
    · have hs' : kappa b < kappa s := Nat.lt_of_not_ge hs
      have hk : kappa b < kappa (recDelta b s void) := by
        simpa [kappa] using
          lt_of_lt_of_le hs' (Nat.le_max_right (kappa b) (kappa s))
      exact drop_left hk
```

## 3. `recDelta b s (delta n) --> app s (recDelta b s n)`

This is the problematic one.

A useful skeleton is to split on the shape of `n`:

```lean
| _, _, Step.R_rec_succ b s n => by
    cases n with
    | void =>
        have hsle :
            kappa s ≤ Nat.max (Nat.max (kappa b) (kappa s)) (kappa void) := by
          exact le_trans (Nat.le_max_right _ _) (Nat.le_max_left _ _)
        have hk :
            kappa (app s (recDelta b s void)) <
              kappa (recDelta b s (delta void)) := by
          simp [kappa, Nat.max_eq_right hsle]
        exact drop_left hk

    | integrate n' =>
        have hsle :
            kappa s ≤ Nat.max (Nat.max (kappa b) (kappa s)) (kappa (integrate n')) := by
          exact le_trans (Nat.le_max_right _ _) (Nat.le_max_left _ _)
        have hk :
            kappa (app s (recDelta b s (integrate n'))) <
              kappa (recDelta b s (delta (integrate n'))) := by
          simp [kappa, Nat.max_eq_right hsle]
        exact drop_left hk

    | merge n₁ n₂ =>
        have hsle :
            kappa s ≤ Nat.max (Nat.max (kappa b) (kappa s)) (kappa (merge n₁ n₂)) := by
          exact le_trans (Nat.le_max_right _ _) (Nat.le_max_left _ _)
        have hk :
            kappa (app s (recDelta b s (merge n₁ n₂))) <
              kappa (recDelta b s (delta (merge n₁ n₂))) := by
          simp [kappa, Nat.max_eq_right hsle]
        exact drop_left hk

    | app n₁ n₂ =>
        have hsle :
            kappa s ≤ Nat.max (Nat.max (kappa b) (kappa s)) (kappa (app n₁ n₂)) := by
          exact le_trans (Nat.le_max_right _ _) (Nat.le_max_left _ _)
        have hk :
            kappa (app s (recDelta b s (app n₁ n₂))) <
              kappa (recDelta b s (delta (app n₁ n₂))) := by
          simp [kappa, Nat.max_eq_right hsle]
        exact drop_left hk

    | recDelta b' s' n' =>
        have hsle :
            kappa s ≤ Nat.max (Nat.max (kappa b) (kappa s)) (kappa (recDelta b' s' n')) := by
          exact le_trans (Nat.le_max_right _ _) (Nat.le_max_left _ _)
        have hk :
            kappa (app s (recDelta b s (recDelta b' s' n'))) <
              kappa (recDelta b s (delta (recDelta b' s' n'))) := by
          simp [kappa, Nat.max_eq_right hsle]
        exact drop_left hk

    | eqW a c =>
        have hsle :
            kappa s ≤ Nat.max (Nat.max (kappa b) (kappa s)) (kappa (eqW a c)) := by
          exact le_trans (Nat.le_max_right _ _) (Nat.le_max_left _ _)
        have hk :
            kappa (app s (recDelta b s (eqW a c))) <
              kappa (recDelta b s (delta (eqW a c))) := by
          simp [kappa, Nat.max_eq_right hsle]
        exact drop_left hk

    | delta n' =>
        -- blocked with the current measure
        -- Here the kappas tie, and mu actually increases.
        --
        -- Concretely, with K := max (max (kappa b) (kappa s)) (kappa n'),
        --
        --   kappa (recDelta b s (delta (delta n'))) = K + 1
        --   kappa (app s (recDelta b s (delta n'))) = K + 1
        --
        -- but
        --
        --   mu (recDelta b s (delta (delta n'))) = 3 + mu b + mu s + mu n'
        --   mu (app s (recDelta b s (delta n'))) = 4 + mu b + 2 * mu s + mu n'
        --
        -- so the right-hand side is not lexicographically smaller.
        --
        -- Example: b = void, s = void, n' = void gives
        --   measure lhs = (1, 3), measure rhs = (1, 4).
        --
        -- So this branch cannot be completed unless the measure is strengthened.
        sorry
```

So: the non-`delta` subcases of `R_rec_succ` follow the same `drop_left` pattern; the `delta` subcase is a genuine obstruction.

## 4. `eqW a a --> void`

```lean
| _, _, Step.R_eq_refl a => by
    by_cases ha : kappa a = 0
    · have hmu : mu void < mu (eqW a a) := by
        simp [mu]
        omega
      have hk : kappa void = kappa (eqW a a) := by
        simpa [kappa] using ha.symm
      exact drop_right hmu hk
    · have hk : kappa void < kappa (eqW a a) := by
        have hpos : 0 < kappa a := Nat.pos_of_ne_zero ha
        simpa [kappa] using hpos
      exact drop_left hk
```

## 5. `eqW a b --> integrate (merge a b)`

```lean
| _, _, Step.R_eq_diff a b => by
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by
      simp [mu]
      omega
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by
      simp [kappa]
    exact drop_right hmu hk
```

## Bottom line

- These four branches should go through with only minor `simp` adjustments:
  - `R_int_delta`
  - `R_rec_zero`
  - `R_eq_refl`
  - `R_eq_diff`

- `R_rec_succ` is not just “hard”; it fails for the current `(kappa, mu)` measure in the `n = delta _` subcase.

If you want, I can also suggest a revised measure that would make the `R_rec_succ` case provable.
