A few important remarks about this skeleton:

1. **`R_int_delta`** and **`R_eq_diff`** are straightforward:
   - `kappa` is preserved,
   - `mu` strictly drops,
   - so `drop_right` applies directly.

2. **`R_rec_succ`** should use **`drop_left`**:
   - source has `... + 1` in `kappa`,
   - target’s `kappa` collapses to the same max without the `+1`,
   - so strict `kappa` decrease is immediate.

3. **`R_eq_refl`** cannot always be proved by `drop_right`, because
   `kappa (eqW a a) = kappa a`, which is not generally `0`.
   So a natural skeleton is:
   - if `kappa a = 0`, use `drop_right`;
   - otherwise `0 < kappa a`, hence `kappa void < kappa (eqW a a)`, so use `drop_left`.

4. **`R_rec_zero`** is the problematic one with the current measure:
   - source `kappa` is `max (max (kappa b) (kappa s)) 0`,
   - target `kappa` is `kappa b`,
   - this is **not** always equal, and not always strictly smaller by enough to force a lex drop in a uniform way via `drop_right`.
   - In fact, if `kappa s > kappa b`, then source `kappa` is bigger and `drop_left` would work; if `kappa s ≤ kappa b`, then `kappa` ties and `mu` drops, so `drop_right` works.
   - So this case needs a **case split on `kappa s ≤ kappa b` vs `kappa b < kappa s`**.

A more precise skeleton for `R_rec_zero` is:

```lean
| _, _, Step.R_rec_zero b s => by
    by_cases hs : kappa s ≤ kappa b
    · have hk : kappa b = kappa (recDelta b s void) := by
        simp [kappa]
        have hmax : Nat.max (kappa b) (kappa s) = kappa b := Nat.max_eq_left hs
        simp [hmax]
      have hmu : mu b < mu (recDelta b s void) := by
        simp [mu]
        omega
      exact drop_right hmu hk
    · have hs' : kappa b < kappa s := Nat.lt_of_not_ge hs
      have hk : kappa b < kappa (recDelta b s void) := by
        simp [kappa]
        have hmax : Nat.max (kappa b) (kappa s) = kappa s := Nat.max_eq_right (Nat.le_of_lt hs')
        simp [hmax]
        exact hs'
      exact drop_left hk
```

So the only genuinely delicate cases are `R_rec_zero` and `R_eq_refl`; the others are routine.
