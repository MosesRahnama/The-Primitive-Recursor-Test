The four cases other than `R_rec_succ` can be completed with the following proof skeletons:

```lean
-- integrate (delta t) --> void
| _, _, Step.R_int_delta t => by
    by_cases hκ : kappa t = 0
    · have hmu : mu void < mu (integrate (delta t)) := by
        simp [mu]
        omega
      have hk : kappa void = kappa (integrate (delta t)) := by
        simp [kappa, hκ]
      exact drop_right hmu hk
    · have hκ' : kappa void < kappa (integrate (delta t)) := by
        simpa [kappa] using Nat.pos_of_ne_zero hκ
      exact drop_left hκ'

-- recDelta b s void --> b
| _, _, Step.R_rec_zero b s => by
    by_cases hk : kappa b = kappa (recDelta b s void)
    · have hmu : mu b < mu (recDelta b s void) := by
        simp [mu]
        omega
      exact drop_right hmu hk
    · have hle : kappa b ≤ kappa (recDelta b s void) := by
        simp [kappa]
        omega
      have hlt : kappa b < kappa (recDelta b s void) := by
        omega
      exact drop_left hlt

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    by_cases hκ : kappa a = 0
    · have hmu : mu void < mu (eqW a a) := by
        simp [mu]
        omega
      have hk : kappa void = kappa (eqW a a) := by
        simp [kappa, hκ]
      exact drop_right hmu hk
    · have hκ' : kappa void < kappa (eqW a a) := by
        simpa [kappa] using Nat.pos_of_ne_zero hκ
      exact drop_left hκ'

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by
      simp [mu]
      omega
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by
      simp [kappa]
    exact drop_right hmu hk
```

However, the `R_rec_succ` case cannot be proved from the stated measure, because the claimed theorem is false for that rule.

For example, take `b = void`, `s = void`, and `n = delta void`. Then:

```lean
a := recDelta void void (delta (delta void))
b := app void (recDelta void void (delta void))
```

and the rule gives `Step a b`. But the measures are:

```lean
kappa a = 1
mu a    = 3

kappa b = 1
mu b    = 4
```

Thus `measure b` is not lexicographically smaller than `measure a`: the `kappa` values tie, while `mu b > mu a`.

Consequently, no proof term for

```lean
| _, _, Step.R_rec_succ b s n => by
    ...
```

exists without changing either the measure, the rule, or the statement of `measure_decreases`.
