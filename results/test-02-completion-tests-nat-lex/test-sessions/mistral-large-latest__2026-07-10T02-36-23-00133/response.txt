I'll provide proof skeletons for the remaining five cases in the `measure_decreases` theorem. Each case needs to show that the lexicographic measure decreases when applying the corresponding reduction rule.

### 1. R_int_delta case
```lean
| _, _, Step.R_int_delta t => by
    have hk : kappa void < kappa (integrate (delta t)) := by
      simp [kappa]; apply Nat.zero_lt_succ
    exact drop_left hk
```

### 2. R_rec_zero case
```lean
| _, _, Step.R_rec_zero b s => by
    have hmu : mu b < mu (recDelta b s void) := by
      simp [mu]; omega
    have hk : kappa b = kappa (recDelta b s void) := by
      simp [kappa]
    exact drop_right hmu hk
```

### 3. R_rec_succ case
```lean
| _, _, Step.R_rec_succ b s n => by
    have hk : kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n)) := by
      simp [kappa]
      have h1 : kappa (recDelta b s n) ≤ Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) := by
        simp [kappa]; omega
      have h2 : Nat.max (kappa s) (kappa (recDelta b s n)) < Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1 := by
        apply Nat.lt_succ_of_le
        apply Nat.max_le_max (Nat.le_max_left _ _) (Nat.le_max_right _ _)
      exact h2
    exact drop_left hk
```

### 4. R_eq_refl case
```lean
| _, _, Step.R_eq_refl a => by
    have hk : kappa void < kappa (eqW a a) := by
      simp [kappa]; apply Nat.zero_lt_succ
    exact drop_left hk
```

### 5. R_eq_diff case
```lean
| _, _, Step.R_eq_diff a b => by
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by
      simp [mu]
      have h : 1 + (2 + mu a + mu b) < 4 + mu a + mu b := by omega
      exact h
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by
      simp [kappa]
    exact drop_right hmu hk
```

Each proof follows the same pattern:
1. For cases where kappa decreases, we use `drop_left`
2. For cases where kappa stays the same but mu decreases, we use `drop_right`
3. We use the simp lemmas to simplify the measure calculations
4. We use omega for simple arithmetic proofs when needed

The key is to analyze how each reduction rule affects both the kappa (recursion depth) and mu (structural size) measures.
