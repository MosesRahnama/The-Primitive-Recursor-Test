Below is a concise proof‑skeleton for the five remaining `Step` cases.  Each case follows the same pattern used for the three already‑proved rules: compute the two components of the measure \((\kappa,\mu)\) for the left‑hand side (LHS) and right‑hand side (RHS), then show either a strict drop in \(\kappa\) (using `drop_left`) or a tie in \(\kappa\) together with a strict drop in \(\mu\) (using `drop_right`).  The natural‑number inequalities are discharged with `omega`.

```lean
-- integrate (delta t) --> void
| _, _, Step.R_int_delta t => by
  -- κ(void) = 0, κ(integrate (delta t)) = κ t
  -- μ(void) = 0, μ(integrate (delta t)) = 1 + μ t
  by_cases hk : kappa t = 0
  · -- case κ t = 0 : κ ties, μ drops
    have hmu : mu void < mu (integrate (delta t)) := by simp [mu, hk]; omega
    have hk' : kappa void = kappa (integrate (delta t)) := by simp [kappa, hk]
    exact drop_right hmu hk'
  · -- case κ t > 0 : κ drops
    have hk' : kappa void < kappa (integrate (delta t)) := by simp [kappa, hk]; omega
    exact drop_left hk'

-- recDelta b s void --> b
| _, _, Step.R_rec_zero b s => by
  -- κ(b) versus κ(recDelta b s void) = max(κ b, κ s)
  by_cases hk : kappa s > kappa b
  · have hk' : kappa b < kappa (recDelta b s void) := by simp [kappa, hk]; omega
    exact drop_left hk'
  · have hk' : kappa b = kappa (recDelta b s void) := by simp [kappa, hk]; omega
    have hmu : mu b < mu (recDelta b s void) := by simp [mu]; omega
    exact drop_right hmu hk'

-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
  -- κ(app s (recDelta b s n)) = max(κ b, κ s, κ n)
  -- κ(recDelta b s (delta n)) = max(κ b, κ s, κ n) + 1
  have hk : kappa (app s (recDelta b s n))
            < kappa (recDelta b s (delta n)) := by
    simp [kappa]
    omega
  exact drop_left hk

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
  -- Similar to the R_int_delta case
  by_cases hk : kappa a = 0
  · have hmu : mu void < mu (eqW a a) := by simp [mu, hk]; omega
    have hk' : kappa void = kappa (eqW a a) := by simp [kappa, hk]
    exact drop_right hmu hk'
  · have hk' : kappa void < kappa (eqW a a) := by simp [kappa, hk]; omega
    exact drop_left hk'

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
  -- κ(integrate (merge a b)) = κ(eqW a b)
  have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by simp [kappa]
  -- μ(integrate (merge a b)) = 3 + μ a + μ b  <  4 + μ a + μ b = μ(eqW a b)
  have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by simp [mu]; omega
  exact drop_right hmu hk
```

These outlines can be filled in directly in the `measure_decreases` proof in place of the `sorry` markers.  The key ideas are:

* **R_int_delta** and **R_eq_refl** – either κ drops (if the argument’s κ is non‑zero) or, when κ ties, μ drops because the LHS adds a positive constant (1 or 4) to the size of the argument.
* **R_rec_zero** – compare κ(b) with max(κ b, κ s).  If κ s > κ b then κ drops; otherwise κ ties and μ drops (the LHS adds at least 3).
* **R_rec_succ** – the RHS’s κ is exactly one less than the LHS’s κ (the “+1” in the definition of κ for a delta‑wrapped third argument), so κ drops outright.
* **R_eq_diff** – κ is unchanged, but μ drops by 1 (the LHS adds 4 while the RHS adds 1 + 2).

All cases are therefore handled by the existing lemmas `drop_left` and `drop_right`.
