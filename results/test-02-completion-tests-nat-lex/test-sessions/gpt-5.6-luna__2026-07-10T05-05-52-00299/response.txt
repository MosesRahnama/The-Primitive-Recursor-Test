The `R_rec_succ` case cannot be completed with the definitions as written: `measure_decreases` is false.

For example, take `b = s = n = void` after choosing the rule instance with `n := delta void`:

```lean
Step.R_rec_succ void void (delta void) :
  Step (recDelta void void (delta (delta void)))
       (app void (recDelta void void (delta void)))
```

The measures are:

```lean
kappa (recDelta void void (delta (delta void))) = 1
mu    (recDelta void void (delta (delta void))) = 3

kappa (app void (recDelta void void (delta void))) = 1
mu    (app void (recDelta void void (delta void))) = 4
```

Thus the κ-components tie, but the μ-component increases, so the required lexicographic decrease does not hold.

The other four cases admit proofs of the following shape:

```lean
-- integrate (delta t) --> void
| _, _, Step.R_int_delta t => by
    by_cases hk : kappa t = 0
    · apply drop_right
      · simp [mu]
        omega
      · simp [kappa, hk]
    · apply drop_left
      simp [kappa]
      omega

-- recDelta b s void --> b
| _, _, Step.R_rec_zero b s => by
    by_cases h : kappa b = kappa (recDelta b s void)
    · apply drop_right
      · simp [mu]
        omega
      · exact h
    · apply drop_left
      have hle : kappa b ≤ kappa (recDelta b s void) := by
        simpa [kappa] using
          (le_trans
            (Nat.le_max_left (kappa b) (kappa s))
            (Nat.le_max_left (Nat.max (kappa b) (kappa s)) 0))
      exact lt_of_le_of_ne hle h

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    by_cases hk : kappa a = 0
    · apply drop_right
      · simp [mu]
        omega
      · simp [kappa, hk]
    · apply drop_left
      simp [kappa]
      omega

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    apply drop_right
    · simp [mu]
      omega
    · simp [kappa]
```

To make the full theorem provable, the recursion measure or the `R_rec_succ` rule needs to be adjusted. In particular, because `delta` is transparent to `kappa`, nested `delta` arguments make the source and recursive target have equal κ while the target has larger μ.
