I'll provide proof skeletons for the remaining five cases in the `measure_decreases` theorem. Each case needs to show that the lexicographic measure decreases according to the `(kappa, mu)` pair.

### 1. R_int_delta case
```lean
| _, _, Step.R_int_delta t => by
    have hk : kappa void < kappa (integrate (delta t)) := by
      simp [kappa]; omega
    exact drop_left hk
```

### 2. R_rec_zero case
```lean
| _, _, Step.R_rec_zero b s => by
    have hmu : mu b < mu (recDelta b s void) := by
      simp [mu]; omega
    have hk : kappa b = kappa (recDelta b s void) := by
      simp [kappa]
    exact drop_right hmu hk
```

### 3. R_rec_succ case
```lean
| _, _, Step.R_rec_succ b s n => by
    have hk : kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n)) := by
      simp [kappa]
      have h1 : kappa (recDelta b s n) ≤ Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) := by
        simp [kappa]
      omega
    exact drop_left hk
```

### 4. R_eq_refl case
```lean
| _, _, Step.R_eq_refl a => by
    have hk : kappa void < kappa (eqW a a) := by
      simp [kappa]; omega
    exact drop_left hk
```

### 5. R_eq_diff case
```lean
| _, _, Step.R_eq_diff a b => by
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by
      simp [kappa]
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by
      simp [mu]
      have h1 : mu (merge a b) = 2 + mu a + mu b := by simp [mu]
      omega
    exact drop_right hmu hk
```

Each proof follows the same pattern:
1. First try to show that `kappa` decreases (using `drop_left`)
2. If `kappa` doesn't decrease, show that it stays the same and `mu` decreases (using `drop_right`)
3. Use the simp lemmas and omega for arithmetic reasoning

The key is to analyze how each reduction rule affects both components of the measure. For recursive cases like `R_rec_succ`, we need to carefully compare the measures of the left and right sides.
