Here's a proof skeleton for completing the remaining five cases in the `measure_decreases` theorem. The approach follows the same pattern as the proved cases: show that either `kappa` strictly decreases, or it stays the same while `mu` strictly decreases, then apply the appropriate `drop_left` or `drop_right` lemma.

```lean
-- integrate (delta t) --> void
| _, _, Step.R_int_delta t => by
    have hk : kappa void < kappa (integrate (delta t)) := by
      simp [kappa]
    exact drop_left hk

-- recDelta b s void --> b
| _, _, Step.R_rec_zero b s => by
    have hmu : mu b < mu (recDelta b s void) := by
      simp [mu]
      omega
    have hk : kappa b = kappa (recDelta b s void) := by
      simp [kappa]
    exact drop_right hmu hk

-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    have hk : kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n)) := by
      simp [kappa]
      omega
    exact drop_left hk

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    have hk : kappa void < kappa (eqW a a) := by
      simp [kappa]
      omega
    exact drop_left hk

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by
      simp [mu]
      omega
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by
      simp [kappa]
    exact drop_right hmu hk
```

Key observations for each case:
1. **R_int_delta**: `kappa` drops from `kappa t` to 0 (since `void` has `kappa = 0`), so we use `drop_left`.
2. **R_rec_zero**: `kappa` stays the same (both sides have `max (kappa b) (kappa s)`), but `mu` drops from `3 + mu b + mu s + 0` to `mu b`, so we use `drop_right`.
3. **R_rec_succ**: `kappa` drops by 1 (from `max (max (kappa b) (kappa s)) (kappa n) + 1` to `max (kappa s) (max (kappa b) (kappa n))`), so we use `drop_left`.
4. **R_eq_refl**: `kappa` drops from `max (kappa a) (kappa a)` to 0, so we use `drop_left`.
5. **R_eq_diff**: `kappa` stays the same (both sides have `max (kappa a) (kappa b)`), but `mu` drops from `4 + mu a + mu b` to `1 + 2 + mu a + mu b`, so we use `drop_right`.

The `omega` tactic is used to handle arithmetic goals involving natural numbers, which is sufficient for these cases. The `simp` tactic unfolds the definitions of `kappa` and `mu` to expose the underlying arithmetic.
