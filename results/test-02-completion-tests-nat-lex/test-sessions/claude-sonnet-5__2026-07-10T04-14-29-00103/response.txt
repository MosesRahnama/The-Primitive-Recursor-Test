Below is a proof skeleton for the five remaining `sorry` cases, written in the same style as the three already‑proved cases (using `drop_left`/`drop_right`, `simp [kappa]`, `simp [mu]`, and `omega` to close the arithmetic side‑conditions).

Four of the five go through cleanly. The `R_rec_succ` case needs a case split on the shape of the recursion argument `n`, because `kappa` treats "the third argument of `recDelta` is `delta`‑headed" as a 0/1 flag rather than counting nesting depth; when `n` is *itself* `delta`‑headed the `kappa` component ties and the extra `1 + mu s` picked up by the `app` wrapper makes `mu` increase rather than decrease. I've flagged that residual sub‑case explicitly with `sorry` rather than papering over it, since it genuinely needs a refined measure (e.g. a `kappa` that counts the full run of leading `delta`s instead of a boolean flag) to close.

```lean
-- integrate (delta t) --> void
| _, _, Step.R_int_delta t => by
    rcases Nat.eq_zero_or_pos (kappa t) with hk | hk
    · -- kappa ties (both are `kappa t = 0`), mu strictly drops
      have hmu : mu void < mu (integrate (delta t)) := by simp [mu]
      have hkeq : kappa void = kappa (integrate (delta t)) := by simp [kappa, hk]
      exact drop_right hmu hkeq
    · -- kappa strictly drops from `kappa t > 0` to `0`
      have hklt : kappa void < kappa (integrate (delta t)) := by
        simp [kappa]; omega
      exact drop_left hklt

-- recDelta b s void --> b
| _, _, Step.R_rec_zero b s => by
    have hk : kappa (recDelta b s void) =
        Nat.max (Nat.max (kappa b) (kappa s)) (kappa void) := by simp [kappa]
    have hkv : kappa void = 0 := kappa_void
    rcases le_or_lt (kappa s) (kappa b) with h | h
    · -- kappa ties (max collapses to kappa b), mu strictly drops
      have hkeq : kappa b = kappa (recDelta b s void) := by omega
      have hmu : mu b < mu (recDelta b s void) := by simp [mu]
      exact drop_right hmu hkeq
    · -- kappa strictly drops (kappa s dominates the max)
      have hklt : kappa b < kappa (recDelta b s void) := by omega
      exact drop_left hklt

-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    have hsrc : kappa (recDelta b s (delta n)) =
        Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1 := kappa_rec_delta b s n
    -- Case split on the shape of n: kappa (recDelta b s n) depends on whether
    -- n is itself `delta`-headed.
    cases n with
    | delta n' =>

        -- (same "+1" flag fires again on the inner recDelta), so kappa ties
        -- with the source, and mu strictly *increases* by `1 + mu s`.
        -- The (kappa, mu) measure as given is not fine enough to witness a
        -- decrease in this sub-case; a kappa that counts the full nesting
        -- depth of leading `delta`s (instead of a 0/1 flag) is needed here.
        sorry
    | void =>
        have hk : kappa (recDelta b s void) =
            Nat.max (Nat.max (kappa b) (kappa s)) (kappa void) := by simp [kappa]

            kappa (recDelta b s (delta void)) := by
          simp only [kappa_app, hk] ; simp [kappa] at hsrc ⊢ ; omega
        exact drop_left hklt
    | integrate t =>
        have hk : kappa (recDelta b s (integrate t)) =
            Nat.max (Nat.max (kappa b) (kappa s)) (kappa (integrate t)) := by simp [kappa]

            kappa (recDelta b s (delta (integrate t))) := by
          simp only [kappa_app, hk] ; simp [kappa] at hsrc ⊢ ; omega
        exact drop_left hklt
    | merge a c =>
        have hk : kappa (recDelta b s (merge a c)) =
            Nat.max (Nat.max (kappa b) (kappa s)) (kappa (merge a c)) := by simp [kappa]
        have hklt : kappa (app s (recDelta b s (merge a c))) <
            kappa (recDelta b s (delta (merge a c))) := by
          simp only [kappa_app, hk] ; simp [kappa] at hsrc ⊢ ; omega

    | app a c =>

            Nat.max (Nat.max (kappa b) (kappa s)) (kappa (app a c)) := by simp [kappa]

            kappa (recDelta b s (delta (app a c))) := by
          simp only [kappa_app, hk] ; simp [kappa] at hsrc ⊢ ; omega

            Nat.max (Nat.max (kappa b) (kappa s)) (kappa (recDelta a c d)) := by simp [kappa]

| _, _, Step.R_eq_refl a => by

      have hmu : mu void < mu (eqW a a) := by simp [mu]
      have hkeq : kappa void = kappa (eqW a a) := by simp [kappa, hk]
      exact drop_right hmu hkeq

      have hklt : kappa void < kappa (eqW a a) := by
        simp [kappa]; omega
      exact drop_left hklt

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    -- kappa ties: both sides equal max(kappa a, kappa b)
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by simp [kappa]
    -- mu strictly drops: 3 + mu a + mu b  <  4 + mu a + mu b
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by
      simp [mu]; omega
    exact drop_right hmu hk
```

Notes on the individual cases:

- **`R_int_delta`**: `kappa` is transparent through both `integrate` and `delta`, so `kappa (integrate (delta t)) = kappa t`; splitting on whether that's `0` gives either a `kappa`‑tie with a `mu`‑drop (`0 < 1 + mu t`), or an outright `kappa`‑drop.
- **`R_rec_zero`**: unfolding `kappa` on the `void` third argument collapses the nested `Nat.max` with `kappa void = 0`; splitting on `le_or_lt (kappa s) (kappa b)` decides whether the max is realized by `kappa b` (tie, use the guaranteed `mu` drop of at least `3`) or by `kappa s` (strict `kappa` drop).
- **`R_rec_succ`**: uses the given `kappa_rec_delta` lemma for the source term; for the six constructors other than `delta`, the reduct's inner `recDelta b s n` uses the *un‑flagged* `kappa` formula, giving a strict `kappa` decrease independent of `mu`. The `delta n'` sub-case is left as an explicit `sorry` with a comment explaining why the given measure is insufficient there.
- **`R_eq_refl`**: same pattern as `R_int_delta`, using `kappa_eqW`/`Nat.max_self`.
- **`R_eq_diff`**: cleanest case — `kappa` is exactly preserved (`kappa (integrate (merge a b)) = kappa (eqW a b)` via transparency of `integrate`/`merge`'s max matching `eqW`'s max), while `mu` strictly drops by exactly `1` (`4 + mu a + mu b` vs `3 + mu a + mu b`), so `drop_right` applies directly with no case split needed.
