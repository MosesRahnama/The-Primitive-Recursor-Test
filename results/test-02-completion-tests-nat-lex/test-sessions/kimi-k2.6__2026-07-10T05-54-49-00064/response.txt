Here is a proof skeleton for the five remaining rule cases. Each follows the established pattern: show that the first component `kappa` drops (using `drop_left`), or else that `kappa` ties and the second component `mu` drops (using `drop_right`). For the cases where `kappa` may or may not drop depending on the subterms, a `by_cases` on the relevant `kappa` equality/inequality is used.

```lean
-- integrate (delta t) --> void
| _, _, Step.R_int_delta t => by
    by_cases h : kappa t = 0
    · -- kappa ties (both sides are 0)
      have hk : kappa void = kappa (integrate (delta t)) := by simp [h]
      have hmu : mu void < mu (integrate (delta t)) := by simp [mu]; omega
      exact drop_right hmu hk
    · -- kappa strictly decreases: 0 < kappa t
      have hk : kappa void < kappa (integrate (delta t)) := by simp; omega
      exact drop_left hk

-- recDelta b s void --> b
| _, _, Step.R_rec_zero b s => by
    by_cases h : kappa b < kappa s
    · -- max(kappa b, kappa s) = kappa s, so kappa drops
      have hk : kappa b < kappa (recDelta b s void) := by
        simp [kappa]
        omega
      exact drop_left hk
    · -- kappa s ≤ kappa b, so max(kappa b, kappa s) = kappa b and kappa ties
      have h' : kappa s ≤ kappa b := by omega
      have hk : kappa b = kappa (recDelta b s void) := by
        simp [kappa, Nat.max_eq_left h', Nat.max_eq_left (show 0 ≤ kappa b by omega)]
      have hmu : mu b < mu (recDelta b s void) := by simp [mu]; omega
      exact drop_right hmu hk

-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    have hk : kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n)) := by
      simp [kappa]
      sorry
    exact drop_left hk

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    by_cases h : kappa a = 0
    · -- kappa ties (both sides are 0)
      have hk : kappa void = kappa (eqW a a) := by simp [h]
      have hmu : mu void < mu (eqW a a) := by simp [mu]; omega
      exact drop_right hmu hk
    · -- kappa strictly decreases: 0 < kappa a
      have hk : kappa void < kappa (eqW a a) := by simp; omega
      exact drop_left hk

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by simp [kappa]
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by simp [mu]; omega
    exact drop_right hmu hk
```

**Notes on the remaining arithmetic goals:**

*   **`R_int_delta`** and **`R_eq_refl`**: The `by_cases` splits into a trivial `drop_right` via `mu` (the right-hand side is `void`, so `mu = 0`) and a `drop_left` via `kappa` where `omega` closes the strict inequality because `kappa` is a natural number and we have the negation of equality with `0`.
*   **`R_rec_zero`**: The `by_cases` uses the definition of `kappa` on `recDelta`. When `kappa s > kappa b`, the outer `Nat.max` evaluates to `kappa s` and `kappa` strictly decreases. Otherwise `kappa s ≤ kappa b`, the max ties on `kappa b`, and `mu` drops because `recDelta` carries a constant weight of `3` plus `mu s`.
*   **`R_eq_diff`**: `kappa` is exactly preserved (`max (kappa a) (kappa b)` on both sides), while `mu` drops by `1` because `eqW` has weight `4` but `integrate (merge a b)` has weight `1 + 2 = 3`.
*   **`R_rec_succ`**: The only remaining `sorry` is the strict inequality on `kappa`. The simp-expanded goal will relate `Nat.max (kappa s) (kappa (recDelta b s n))` to `Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1`; the proof must show the left-hand side is strictly smaller (which holds for the fragment where the third argument loses its outer `delta` wrapper and `kappa` is computed on the resulting smaller term).
