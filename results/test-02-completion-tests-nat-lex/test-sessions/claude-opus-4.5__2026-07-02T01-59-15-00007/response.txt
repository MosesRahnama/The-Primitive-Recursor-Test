# Proof Skeleton for Remaining Cases

Looking at the five remaining cases, I need to analyze each rule to determine whether `kappa` drops strictly (use `drop_left`) or `kappa` ties and `mu` drops strictly (use `drop_right`).

## Analysis of Each Case

### Case 1: `R_int_delta` - `integrate (delta t) --> void`
- **kappa**: `kappa (integrate (delta t)) = kappa (delta t) = kappa t`, and `kappa void = 0`
- **mu**: `mu (integrate (delta t)) = 1 + mu (delta t) = 1 + mu t`, and `mu void = 0`
- Since `kappa t` could be non-zero, we can't guarantee `kappa` ties. However, `mu void = 0 < 1 + mu t` always holds, and we need `kappa void ≤ kappa t` which is `0 ≤ kappa t` (always true). But for `drop_right` we need equality. Actually, if `kappa t > 0`, then `kappa` drops (use `drop_left`). If `kappa t = 0`, then `kappa` ties and `mu` drops.
- Better approach: Show `measure void < measure (integrate (delta t))` using that either kappa drops or mu drops with kappa equal.

### Case 2: `R_rec_zero` - `recDelta b s void --> b`
- **kappa**: `kappa (recDelta b s void) = max (max (kappa b) (kappa s)) (kappa void) = max (max (kappa b) (kappa s)) 0 = max (kappa b) (kappa s)`
- `kappa b ≤ max (kappa b) (kappa s)`, so kappa doesn't increase
- **mu**: `mu (recDelta b s void) = 3 + mu b + mu s + 0 = 3 + mu b + mu s`, and `mu b < 3 + mu b + mu s`

### Case 3: `R_rec_succ` - `recDelta b s (delta n) --> app s (recDelta b s n)`
- **kappa LHS**: `max (max (kappa b) (kappa s)) (kappa n) + 1`
- **kappa RHS**: `max (kappa s) (kappa (recDelta b s n))`
- The key insight is that `recDelta b s n` (where `n` is not wrapped in `delta` at the top) has kappa = `max (max (kappa b) (kappa s)) (kappa n)`, so kappa drops by 1.

### Case 4: `R_eq_refl` - `eqW a a --> void`
- **kappa**: `kappa (eqW a a) = max (kappa a) (kappa a) = kappa a`, and `kappa void = 0`
- **mu**: `mu (eqW a a) = 4 + 2*(mu a)`, and `mu void = 0`

### Case 5: `R_eq_diff` - `eqW a b --> integrate (merge a b)`
- **kappa**: Both sides have `max (kappa a) (kappa b)` - they tie
- **mu**: `mu (eqW a b) = 4 + mu a + mu b`, `mu (integrate (merge a b)) = 1 + 2 + mu a + mu b = 3 + mu a + mu b`
- mu drops by 1

## Proof Skeleton

```lean
-- integrate (delta t) --> void
| _, _, Step.R_int_delta t => by
    have hmu : mu void < mu (integrate (delta t)) := by simp [mu]; omega
    cases Nat.eq_or_lt_of_le (Nat.zero_le (kappa t)) with
    | inl hk => exact drop_right hmu (by simp [kappa]; omega)
    | inr hk => exact drop_left (by simp [kappa]; omega)

-- recDelta b s void --> b
| _, _, Step.R_rec_zero b s => by
    have hmu : mu b < mu (recDelta b s void) := by simp [mu]; omega
    have hk : kappa b = kappa (recDelta b s void) ∨ kappa b < kappa (recDelta b s void) := by
      simp [kappa]; omega
    cases hk with
    | inl hk => exact drop_right hmu hk
    | inr hk => exact drop_left hk

-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    have hk : kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n)) := by
      simp [kappa]
      omega
    exact drop_left hk

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    have hmu : mu void < mu (eqW a a) := by simp [mu]; omega
    cases Nat.eq_or_lt_of_le (Nat.zero_le (kappa a)) with
    | inl hk => exact drop_right hmu (by simp [kappa]; omega)
    | inr hk => exact drop_left (by simp [kappa]; omega)

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by simp [mu]; omega
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by simp [kappa]
    exact drop_right hmu hk
```
