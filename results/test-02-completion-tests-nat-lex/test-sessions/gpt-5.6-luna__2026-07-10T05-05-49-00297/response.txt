A complete proof cannot be supplied for the file as written: the `R_rec_succ` case is false for the stated measure.

For example, instantiate `b = s = void` and `n = delta void`. The rule gives

```lean
Step
  (recDelta void void (delta (delta void)))
  (app void (recDelta void void (delta void)))
```

but the measures are

```lean
measure (recDelta void void (delta (delta void))) = (1, 3)
measure (app void (recDelta void void (delta void))) = (1, 4)
```

Thus the required conclusion would be `Prod.Lex (1, 4) (1, 3)`, which is false: the first components tie, while `4 < 3` is false.
