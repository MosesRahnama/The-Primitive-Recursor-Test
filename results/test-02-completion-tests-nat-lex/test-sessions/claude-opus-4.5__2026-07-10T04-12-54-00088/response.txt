# Proof Skeleton for Remaining Cases

I'll analyze each remaining case and provide the proof skeleton based on the measure definitions.

## Analysis of Each Case

### 1. `R_int_delta`: `integrate (delta t) --> void`
- **kappa**: `kappa (integrate (delta t)) = kappa (delta t) = kappa t`, while `kappa void = 0`
- **mu**: `mu (integrate (delta t)) = 1 + mu (delta t) = 1 + mu t`, while `mu void = 0`
- **Strategy**: mu drops strictly (from `1 + mu t` to `0`), kappa either drops or ties (depending on t)

### 2. `R_rec_zero`: `recDelta b s void --> b`
- **kappa**: LHS = `max (max (kappa b) (kappa s)) (kappa void) = max (max (kappa b) (kappa s)) 0 = max (kappa b) (kappa s)`, RHS = `kappa b`
- **mu**: LHS = `3 + mu b + mu s + 0`, RHS = `mu b`
- **Strategy**: mu drops strictly (by at least 3), need to show kappa ties or drops

### 3. `R_rec_succ`: `recDelta b s (delta n) --> app s (recDelta b s n)`
- **kappa**: LHS = `max (max (kappa b) (kappa s)) (kappa n) + 1` (note: third arg is `delta n`)
- RHS = `max (kappa s) (kappa (recDelta b s n))`
- Since `n` is not wrapped in `delta` at the recursive call, kappa of `recDelta b s n` doesn't get the +1
- **Strategy**: kappa drops strictly

### 4. `R_eq_refl`: `eqW a a --> void`
- **kappa**: LHS = `max (kappa a) (kappa a) = kappa a`, RHS = `0`
- **mu**: LHS = `4 + mu a + mu a`, RHS = `0`
- **Strategy**: mu drops strictly

### 5. `R_eq_diff`: `eqW a b --> integrate (merge a b)`
- **kappa**: LHS = `max (kappa a) (kappa b)`, RHS = `kappa (integrate (merge a b)) = max (kappa a) (kappa b)`
- **mu**: LHS = `4 + mu a + mu b`, RHS = `1 + (2 + mu a + mu b) = 3 + mu a + mu b`
- **Strategy**: kappa ties, mu drops by 1

## Proof Skeleton

```lean
-- integrate (delta t) --> void
| _, _, Step.R_int_delta t => by
    have hmu : mu void < mu (integrate (delta t)) := by simp [mu]; omega
    apply drop_right hmu
    simp [kappa]

-- recDelta b s void --> b
| _, _, Step.R_rec_zero b s => by
    have hmu : mu b < mu (recDelta b s void) := by simp [mu]; omega
    have hk : kappa b = kappa (recDelta b s void) := by simp [kappa]
    exact drop_right hmu hk

-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    have hk : kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n)) := by
      simp [kappa]
      -- Need to show max (kappa s) (kappa (recDelta b s n)) < max (max (kappa b) (kappa s)) (kappa n) + 1
      -- The key insight: recDelta b s n (where n is not delta-wrapped) has kappa = max (max (kappa b) (kappa s)) (kappa n)
      -- So RHS ≤ max (max (kappa b) (kappa s)) (kappa n) < LHS
      omega
    exact drop_left hk

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    have hmu : mu void < mu (eqW a a) := by simp [mu]; omega
    apply drop_right hmu
    simp [kappa]

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by simp [mu]; omega
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by simp [kappa]
    exact drop_right hmu hk
```
