# Proof Skeleton for Remaining Cases

Here is a proof skeleton for the five remaining cases:

```lean
-- integrate (delta t) --> void
| _, _, Step.R_int_delta t => by
    -- kappa: integrate (delta t) = kappa t, void = 0, so kappa drops
    -- mu: integrate (delta t) = 1 + mu t, void = 0, so mu also drops
    -- Use drop_left since kappa strictly decreases
    have hk : kappa void < kappa (integrate (delta t)) := by simp [kappa]
    exact drop_left hk

-- recDelta b s void --> b
| _, _, Step.R_rec_zero b s => by
    -- kappa: recDelta b s void = max(max(kb, ks), 0) = max(kb, ks)
    --        vs b = kb, so kappa drops when ks > kb or ties when ks ≤ kb
    -- mu: recDelta b s void = 3 + mu b + mu s + 0, vs b = mu b, so mu drops by (3 + mu s)
    -- Use drop_right since mu strictly decreases and kappa ties or drops
    have hmu : mu b < mu (recDelta b s void) := by simp [mu]; omega
    have hk : kappa b = kappa (recDelta b s void) := by simp [kappa]; omega
    exact drop_right hmu hk

-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    -- kappa: recDelta b s (delta n) = max(max(kb, ks), kn) + 1
    --        app s (recDelta b s n) = max(ks, max(max(kb, ks), kn))
    --                                = max(ks, kb, ks, kn) = max(kb, ks, kn)
    -- So kappa drops by 1
    have hk : kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n)) := by
      simp [kappa]; omega
    exact drop_left hk

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    -- kappa: eqW a a = max(ka, ka) = ka, void = 0, so kappa drops
    -- mu: eqW a a = 4 + mu a + mu a = 4 + 2*mu a, void = 0, so mu drops
    have hk : kappa void < kappa (eqW a a) := by simp [kappa]; omega
    exact drop_left hk

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    -- kappa: eqW a b = max(ka, kb)
    --        integrate (merge a b) = kappa (merge a b) = max(ka, kb)
    -- kappa ties; check mu
    -- mu: eqW a b = 4 + mu a + mu b
    --     integrate (merge a b) = 1 + (2 + mu a + mu b) = 3 + mu a + mu b
    -- So mu drops by 1
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by simp [mu]; omega
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by simp [kappa]
    exact drop_right hmu hk
```

The skeleton uses:
- **`drop_left`** when kappa strictly decreases (rules with delta unwrapping or integration)
- **`drop_right`** when kappa ties but mu strictly decreases (rules that reduce size while preserving depth)
- Simple `simp` and `omega` tactics to discharge arithmetic goals about measure values
