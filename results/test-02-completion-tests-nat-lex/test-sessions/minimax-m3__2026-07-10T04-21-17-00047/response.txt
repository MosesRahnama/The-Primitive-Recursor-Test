Below are the proof skeletons for the five remaining cases. The strategy follows the same pattern as the proved merge cases: pick a coordinate (κ or μ) whose comparison yields a strict lexicographic decrease, and use `drop_left` or `drop_right`.

---

### `R_int_delta` : `integrate (delta t) → void`

Here κ is preserved (`kappa (integrate (delta t)) = kappa t`) and μ collapses to 0. The proof is a case split on whether `kappa t = 0` or not.

```lean
| _, _, Step.R_int_delta t => by
    -- Two sub-cases depending on whether κ of t is zero.
    by_cases hk : kappa t = 0
    · -- κ ties at 0; use μ which strictly decreases.
      have hmu : mu void < mu (integrate (delta t)) := by
        simp [mu]               -- mu (integrate (delta t)) = 1 + mu t ≥ 1
        omega
      have hk' : kappa void = kappa (integrate (delta t)) := by
        simp [kappa, hk]
      exact drop_right hmu hk'
    · -- κ strictly decreases to 0.
      have hk' : kappa void < kappa (integrate (delta t)) := by
        simp [kappa]; omega
      exact drop_left hk'
```

---

### `R_rec_zero` : `recDelta b s void → b`

`kappa (recDelta b s void) = max (kappa b) (kappa s)`. So:

* If `kappa b < kappa s` then κ strictly decreases.
* Otherwise `kappa b ≥ kappa s` so κ ties and μ strictly decreases (`3 + mu b + mu s > mu b`).

```lean
| _, _, Step.R_rec_zero b s => by
    by_cases hk : kappa b < kappa s
    · -- Left coordinate strictly decreases.
      have hk' : kappa b < kappa (recDelta b s void) := by
        simp [kappa]; exact hk
      exact drop_left hk'
    · -- Push the negation into the form `kappa b ≥ kappa s`.
      have hk' : kappa b = kappa (recDelta b s void) := by
        simp [kappa]; omega
      have hmu : mu b < mu (recDelta b s void) := by
        simp [mu]; omega
      exact drop_right hmu hk'
```

---

### `R_rec_succ` : `recDelta b s (delta n) → app s (recDelta b s n)`

Let `M = max (max (kappa b) (kappa s)) (kappa n)`.

* `kappa (recDelta b s (delta n)) = M + 1`.
* `kappa (app s (recDelta b s n)) = max (kappa s) M = M`  (because `M ≥ kappa s`).

So κ strictly decreases by exactly 1 — `drop_left` suffices.

```lean
| _, _, Step.R_rec_succ b s n => by
    -- After unfolding, left κ = M + 1, right κ = max (kappa s) M = M.
    -- Crucial fact: M ≥ kappa s, so max kappa s M = M.
    have hk : kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n)) := by
      simp [kappa]
      -- goal reduces to  max (kappa s) (max (max (kappa b) (kappa s)) (kappa n))
      --                < max (max (kappa b) (kappa s)) (kappa n) + 1
      -- which is immediate from the enclosing max dominating the inner.
      sorry
    exact drop_left hk
```

The inner `sorry` is a one-line `omega` once the term is rewritten — it follows from `max a M ≤ M` and the strict `+1` on the larger side.

---

### `R_eq_refl` : `eqW a a → void`

Identical structure to `R_int_delta`: κ is preserved, μ strictly decreases when κ ties at 0.

```lean
| _, _, Step.R_eq_refl a => by
    by_cases hk : kappa a = 0
    · have hmu : mu void < mu (eqW a a) := by
        simp [mu]; omega
      have hk' : kappa void = kappa (eqW a a) := by
        simp [kappa, hk]
      exact drop_right hmu hk'
    · have hk' : kappa void < kappa (eqW a a) := by
        simp [kappa]; omega
      exact drop_left hk'
```

---

### `R_eq_diff` : `eqW a b → integrate (merge a b)`

κ ties at `max (kappa a) (kappa b)`, and μ drops from `4 + mu a + mu b` to `3 + mu a + mu b`.

```lean
| _, _, Step.R_eq_diff a b => by
    have hk  : kappa (integrate (merge a b)) = kappa (eqW a b) := by
      simp [kappa]
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by
      simp [mu]; omega
    exact drop_right hmu hk
```

---

### Summary of the (κ, μ) lex strategy

| Rule | κ behavior | μ behavior | Branch |
|------|-----------|-----------|--------|
| `R_int_delta`  | preserved (= `kappa t`) | collapses to 0 | case split on `kappa t = 0` |
| `R_rec_zero`   | ties iff `kappa b ≥ kappa s` | drops by `3 + mu s` | case split on `kappa b < kappa s` |
| `R_rec_succ`   | drops by 1 (the `+1` flips sign) | n/a | `drop_left` |
| `R_eq_refl`    | preserved (= `kappa a`) | collapses to 0 | case split on `kappa a = 0` |
| `R_eq_diff`    | ties | drops by 1 | `drop_right` |

Every `sorry` reduces (after `simp` on `kappa`/`mu`) to either a `max` monotonicity fact solved by `omega`, or a `by_cases` followed by the same.
