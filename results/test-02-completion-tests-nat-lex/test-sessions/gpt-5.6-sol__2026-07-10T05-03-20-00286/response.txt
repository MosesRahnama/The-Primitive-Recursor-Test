The theorem cannot be completed as stated: the `R_rec_succ` case does not always decrease the given lexicographic measure. The other four cases have the following proof skeletons.

```lean
-- integrate (delta t) --> void
| _, _, Step.R_int_delta t => by
    by_cases h : kappa t = 0
    · have hmu : mu void < mu (integrate (delta t)) := by
        simp [mu]
      have hk : kappa void = kappa (integrate (delta t)) := by
        simp [kappa, h]
      exact drop_right hmu hk
    · have hp : 0 < kappa t := Nat.pos_of_ne_zero h
      apply drop_left
      simpa [kappa] using hp

-- recDelta b s void --> b
| _, _, Step.R_rec_zero b s => by
    have hle : kappa b ≤ kappa (recDelta b s void) := by
      change kappa b ≤ Nat.max (Nat.max (kappa b) (kappa s)) 0
      exact
        le_trans
          (Nat.le_max_left (kappa b) (kappa s))
          (Nat.le_max_left (Nat.max (kappa b) (kappa s)) 0)
    by_cases hk : kappa b = kappa (recDelta b s void)
    · have hmu : mu b < mu (recDelta b s void) := by
        simp [mu]
        omega
      exact drop_right hmu hk
    · have hlt : kappa b < kappa (recDelta b s void) := by
        omega
      exact drop_left hlt

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    by_cases h : kappa a = 0
    · have hmu : mu void < mu (eqW a a) := by
        simp [mu]
        omega
      have hk : kappa void = kappa (eqW a a) := by
        simp [kappa, h]
      exact drop_right hmu hk
    · have hp : 0 < kappa a := Nat.pos_of_ne_zero h
      apply drop_left
      simpa [kappa] using hp

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    have hmu :
        mu (integrate (merge a b)) < mu (eqW a b) := by
      simp [mu]
      omega
    have hk :
        kappa (integrate (merge a b)) = kappa (eqW a b) := by
      simp [kappa]
    exact drop_right hmu hk
```

The remaining recursion case is impossible:

```lean
-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    -- Not provable with the current measures.
```

Take

```lean
b := void
s := void
n := delta void
```

Then the step is

```lean
recDelta void void (delta (delta void))
  -->
app void (recDelta void void (delta void))
```

Its measures are:

```text
measure (recDelta void void (delta (delta void)))       = (1, 3)
measure (app void (recDelta void void (delta void)))    = (1, 4)
```

Thus `kappa` ties while `mu` increases:

```text
kappa source = 1 = kappa target
mu source    = 3 < 4 = mu target
```

Consequently,

```lean
LexOrder (measure target) (measure source)
```

is false. A completion requires changing the measure—typically making the recursion component count all leading `delta` constructors in the third argument—or restricting/changing `R_rec_succ`. Without such a change, both `measure_decreases` and the presented proof of `strong_normalization` cannot be completed.
