We need to fill five remaining cases of `measure_decreases`. Each case follows the same pattern: compute the lexicographic measures `(kappa x, mu x)` for both sides of the step, then show either a strict decrease in the first component (using `drop_left`) or a tie in the first component with a strict decrease in the second (using `drop_right`). All arithmetic can be handled by `simp` with the provided lemma and `omega`.

Below is a proof skeleton for each case.

---

### 1. `R_int_delta t` : `integrate (delta t) ⟶ void`
- **Compute measures**:  
  `measure void = (0,0)` and `measure (integrate (delta t)) = (kappa t, 1 + mu t)` (by `simp`).
- **Case distinction** on `kappa t`.  
  - If `kappa t > 0`, then `0 < kappa t` → left strict decrease. Apply `drop_left` with `h`:`0 < kappa t` (from `Nat.zero_lt_of_ne_zero` or `by omega`).  
  - If `kappa t = 0`, then kappas tie and `0 < 1 + mu t` holds trivially. Apply `drop_right` with `hmu`:`0 < 1 + mu t` (from `omega`) and `hk`:`kappa t = 0` (which makes the kappa equality after `simp`).

### 2. `R_rec_zero b s` : `recDelta b s void ⟶ b`
- **Compute measures**:  
  `measure (recDelta b s void) = (Nat.max (kappa b) (kappa s), 3 + mu b + mu s)`  
  `measure b = (kappa b, mu b)`.
- **Case distinction** on `kappa b` versus `kappa s`.  
  - If `kappa s ≤ kappa b`:  
    Then `Nat.max (kappa b) (kappa s) = kappa b` (ties).  
    Right component: `mu b < 3 + mu b + mu s` always true (`omega`).  
    Apply `drop_right` with `hmu` (the inequality) and `hk` (the equality of maxima, by `Nat.max_eq_left`).
  - If `kappa b < κ s` (i.e., `¬ κ s ≤ κ b`):  
    Then `Nat.max (kappa b) (kappa s) = kappa s > kappa b`.  
    So left strict decrease holds. Apply `drop_left` with `h`:`kappa b < Nat.max (kappa b) (kappa s)` (by rewriting the max to `kappa s` using `Nat.max_eq_right (by omega)`).

### 3. `R_rec_succ b s n` : `recDelta b s (delta n) ⟶ app s (recDelta b s n)`
- **Compute kappas** (mu is irrelevant here):  
  `kappa LHS = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n) + 1` (because third argument is `delta n`)  
  `kappa RHS = Nat.max (Nat.max (kappa b) (kappa s)) (kappa n)` (since `app` and `recDelta` without `delta` give the maximum).  
- Clearly `kappa RHS = M` and `kappa LHS = M + 1`, so `kappa RHS < kappa LHS`.  
- **Apply `drop_left`** directly with `h` : `kappa RHS < kappa LHS` (provable by `simp` and `omega`).

### 4. `R_eq_refl a` : `eqW a a ⟶ void`
- **Analogous to case 1**:  
  `measure void = (0,0)` and `measure (eqW a a) = (kappa a, 4 + 2*mu a)`.
- **Case split** on `kappa a`.  
  - If `kappa a > 0`: left strict decrease, `drop_left`.  
  - If `kappa a = 0`: kappas tie, right strict decrease `0 < 4 + 2*mu a`, `drop_right`.  

### 5. `R_eq_diff a b` : `eqW a b ⟶ integrate (merge a b)`
- **Compute measures**:  
  LHS: `(Nat.max (kappa a) (kappa b), 4 + mu a + mu b)`  
  RHS: `(Nat.max (kappa a) (kappa b), 3 + mu a + mu b)` (since `kappa` of `merge` is max, `integrate` preserves it; `mu` from `merge` gives `2+mu a+mu b`, plus `1` from `integrate`).
- Kappas are equal, mu RHS = `3+μa+μb` < `4+μa+μb` = mu LHS.  
- **Apply `drop_right`** with `hmu` (from `omega`) and `hk` (by `simp`).

---

All cases use the existing helper lemmas `drop_left` and `drop_right`. The required arithmetic is straightforward and can be dispatched with `simp` and `omega`.
