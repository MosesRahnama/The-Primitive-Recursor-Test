# Proof Skeleton for Remaining Cases

Here is a proof skeleton for the five remaining cases:

```lean
-- integrate (delta t) --> void
| _, _, Step.R_int_delta t => by
    have hk : kappa void < kappa (integrate (delta t)) := by simp [kappa]
    exact drop_left hk

-- recDelta b s void --> b
| _, _, Step.R_rec_zero b s => by
    have hk : kappa b < kappa (recDelta b s void) := by simp [kappa]; omega
    exact drop_left hk

-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    have hk : kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n)) := by
      simp [kappa]; omega
    exact drop_left hk

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    have hk : kappa void < kappa (eqW a a) := by simp [kappa]; omega
    exact drop_left hk

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by simp [mu]; omega
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by simp [kappa]
    exact drop_right hmu hk
```

**Key insights for each case:**

1. **R_int_delta**: Delta is transparent to kappa, so `kappa(integrate(delta t))` preserves kappa through both layers → decrease via `drop_left`
2. **R_rec_zero**: Without delta wrapping on the third argument, kappa decreases → `drop_left`
3. **R_rec_succ**: The delta wrapper adds +1 to kappa (per definition), which is lost in the reduct → `drop_left`
4. **R_eq_refl**: Kappa of the recursive argument `a` is strictly smaller than the max of two equal arguments → `drop_left`
5. **R_eq_diff**: Kappa is preserved (both sides have max), but mu decreases from `4 + 2·mu(a) + 2·mu(b)` to `1 + 2 + mu(a) + mu(b)` → `drop_right`
