I'll provide proof skeletons for the remaining five cases in the `measure_decreases` theorem. Each case will follow the pattern of showing either a strict decrease in `kappa` (using `drop_left`) or a tie in `kappa` with a strict decrease in `mu` (using `drop_right`).

### 1. R_int_delta case
```lean
| _, _, Step.R_int_delta t => by
    have hk : kappa void < kappa (integrate (delta t)) := by
      simp [kappa]; omega
    exact drop_left hk
```

### 2. R_rec_zero case
```lean
| _, _, Step.R_rec_zero b s => by
    have hmu : mu b < mu (recDelta b s void) := by
      simp [mu]; omega
    have hk : kappa b = kappa (recDelta b s void) := by
      simp [kappa]
    exact drop_right hmu hk
```

### 3. R_rec_succ case
```lean
| _, _, Step.R_rec_succ b s n => by
    have hk : kappa (app s (recDelta b s n)) = kappa (recDelta b s (delta n)) := by
      simp [kappa]
    have hmu : mu (app s (recDelta b s n)) < mu (recDelta b s (delta n)) := by
      simp [mu]
      have : mu (recDelta b s n) + 1 ≤ mu (recDelta b s (delta n)) := by
        simp [mu]; omega
      omega
    exact drop_right hmu hk
```

### 4. R_eq_refl case
```lean
| _, _, Step.R_eq_refl a => by
    have hk : kappa void < kappa (eqW a a) := by
      simp [kappa]; omega
    exact drop_left hk
```

### 5. R_eq_diff case
```lean
| _, _, Step.R_eq_diff a b => by
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by
      simp [kappa]
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by
      simp [mu]
      have : 1 + (2 + mu a + mu b) < 4 + mu a + mu b := by omega
      exact this
    exact drop_right hmu hk
```

Each proof follows the same pattern:
1. First try to show `kappa` decreases (using `drop_left`)
2. If `kappa` doesn't decrease, show it stays the same and `mu` decreases (using `drop_right`)
3. Use the simp lemmas to simplify the expressions
4. Use `omega` for arithmetic reasoning when needed

The key is to understand how each reduction rule affects both measures:
- `R_int_delta`: `kappa` decreases because we're removing an `integrate` wrapper
- `R_rec_zero`: `mu` decreases because we're removing the `recDelta` constructor
- `R_rec_succ`: `kappa` stays the same but `mu` decreases (the +1 from `delta` is offset by the `app` constructor)
- `R_eq_refl`: `kappa` decreases because we're removing the `eqW` constructor
- `R_eq_diff`: `kappa` stays the same but `mu` decreases (4 → 1 + 2)
