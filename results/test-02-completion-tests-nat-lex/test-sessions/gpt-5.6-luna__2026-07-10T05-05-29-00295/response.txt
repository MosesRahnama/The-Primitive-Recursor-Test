The remaining cases cannot all be completed as stated: the `R_rec_succ` case is false for the given measure.

A proof skeleton for the four valid remaining cases is:

```lean
-- integrate (delta t) --> void
| _, _, Step.R_int_delta t => by
    by_cases hk : 0 < kappa t
    · apply drop_left
      simpa [kappa] using hk
    · apply drop_right
      · simp [mu]
        omega
      · simp [kappa]
        omega

-- recDelta b s void --> b
| _, _, Step.R_rec_zero b s => by
    by_cases hk : kappa b < kappa (recDelta b s void)
    · exact drop_left hk
    · apply drop_right
      · simp [mu]
        omega
      · simp [kappa]
        omega

-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    -- This case is not provable with the stated `kappa` and `mu`.
    sorry

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    by_cases hk : 0 < kappa a
    · apply drop_left
      simpa [kappa] using hk
    · apply drop_right
      · simp [mu]
        omega
      · simp [kappa]
        omega

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    apply drop_right
    · simp [mu]
      omega
    · simp [kappa]
```

The obstruction is exposed by taking `b = void`, `s = void`, and `n = delta void`. Then:

```lean
recDelta void void (delta (delta void))
```

reduces to

```lean
app void (recDelta void void (delta void))
```

and both sides have the same `kappa`:

```lean
kappa (recDelta void void (delta (delta void))) = 1
kappa (app void (recDelta void void (delta void))) = 1
```

but the `mu` values are:

```lean
mu (recDelta void void (delta (delta void))) = 3
mu (app void (recDelta void void (delta void))) = 4
```

Thus the target lexicographic decrease is false. The `R_rec_succ` rule or one of the measures must be changed before the full theorem can be proved.
