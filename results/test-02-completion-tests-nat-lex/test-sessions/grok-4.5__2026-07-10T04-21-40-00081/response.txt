## Proof skeleton for the five remaining cases

The three completed merge cases all follow the same pattern: prove a strict `mu` decrease, prove a `kappa` tie, then apply `drop_right`. The remaining rules need a mix of `drop_left` / `drop_right`, sometimes with a case split on whether `kappa` falls or ties. Below is a drop-in skeleton in the same style as the existing proofs. (Comments record the arithmetic that the tactics are discharging.)

```lean
-- ── Remaining cases ───────────────────────────────────────────

-- integrate (delta t) --> void
-- κ:  0  ≟  κ t          (drop if κ t > 0, tie if κ t = 0)
-- μ:  0  <  1 + μ t      (always)
| _, _, Step.R_int_delta t => by
    have hmu : mu void < mu (integrate (delta t)) := by simp [mu]
    by_cases h : kappa t = 0
    · -- κ ties at 0
      have hk : kappa void = kappa (integrate (delta t)) := by simp [kappa, h]
      exact drop_right hmu hk
    · -- κ drops
      have hk : kappa void < kappa (integrate (delta t)) := by simp [kappa]; omega
      exact drop_left hk

-- recDelta b s void --> b
-- κ:  κ b  ≟  max(κ b, κ s)   (drop if κ s > κ b, tie otherwise)
-- μ:  μ b  <  3 + μ b + μ s   (always)
| _, _, Step.R_rec_zero b s => by
    have hmu : mu b < mu (recDelta b s void) := by simp [mu]; omega
    -- third arg is void (not δ-wrapped) ⇒ second equation of κ
    have hk_lhs : kappa (recDelta b s void) = Nat.max (kappa b) (kappa s) := by
      -- κ(recDelta b s void) = max(max(κ b, κ s), κ void) = max(κ b, κ s)
      change Nat.max (Nat.max (kappa b) (kappa s)) (kappa void) = _
      simp [kappa]
    by_cases h : kappa s ≤ kappa b
    · -- κ ties
      have hk : kappa b = kappa (recDelta b s void) := by
        rw [hk_lhs, Nat.max_eq_left h]
      exact drop_right hmu hk
    · -- κ drops
      have hk : kappa b < kappa (recDelta b s void) := by
        rw [hk_lhs]; exact Nat.lt_max_of_lt_right (lt_of_not_ge h)
      exact drop_left hk

-- recDelta b s (delta n) --> app s (recDelta b s n)
-- Intended: κ drops by 1 because the outer +1 on the δ-wrapped
-- third argument is peeled off.
--
--   κ LHS = max(max(κ b, κ s), κ n) + 1
--   κ RHS = max(κ s, κ(recDelta b s n))
--
-- When n is *not* itself δ-wrapped, κ(recDelta b s n) =
-- max(max(κ b, κ s), κ n), so κ RHS ≤ that quantity and is
-- therefore strictly below κ LHS → drop_left.
-- When n *is* δ-wrapped the two κ values tie and μ actually
-- *increases*, so the current (κ, μ) measure does not decrease.
-- A complete proof therefore needs either
--   (a) a case-split on n together with a refined measure, or
--   (b) a different combinatorial argument for the δ/δ subcase.
-- Skeleton for the non-δ branch (the δ branch is the obstruction):
| _, _, Step.R_rec_succ b s n => by
    -- Goal: LexOrder (measure (app s (recDelta b s n)))
    --                  (measure (recDelta b s (delta n)))
    apply drop_left
    -- κ (app s (recDelta b s n)) < κ (recDelta b s (delta n))
    simp only [kappa_app, kappa_rec_delta]
    -- remains: max (κ s) (κ (recDelta b s n))
    --        < max (max (κ b) (κ s)) (κ n) + 1
    -- Discharge by cases on the shape of n:
    cases n with
    | delta m =>
        -- κ ties and μ rises — measure does not decrease as defined.
        -- Place-holder: refine the measure (e.g. count full δ-tower
        -- height in the third argument of recDelta) or switch to a
        -- different well-founded order for this rule.
        sorry
    | void =>
        -- κ (recDelta b s void) = max(κ b, κ s)
        -- RHS = max(κ s, max(κ b, κ s)) = max(κ b, κ s)
        -- LHS = max(κ b, κ s) + 1  → strict drop
        simp [kappa]; omega
    | integrate t =>
        simp [kappa]; omega
    | merge a b' =>
        simp [kappa]; omega
    | app a b' =>
        simp [kappa]; omega
    | recDelta b' s' n' =>
        simp [kappa]; omega
    | eqW a b' =>
        simp [kappa]; omega

-- eqW a a --> void
-- κ:  0  ≟  κ a          (drop if κ a > 0, tie if κ a = 0)
-- μ:  0  <  4 + 2·μ a    (always)
| _, _, Step.R_eq_refl a => by
    have hmu : mu void < mu (eqW a a) := by simp [mu]; omega
    by_cases h : kappa a = 0
    · have hk : kappa void = kappa (eqW a a) := by simp [kappa, h]
      exact drop_right hmu hk
    · have hk : kappa void < kappa (eqW a a) := by simp [kappa]; omega
      exact drop_left hk

-- eqW a b --> integrate (merge a b)
-- κ:  max(κ a, κ b) = max(κ a, κ b)     (always ties)
-- μ:  3 + μ a + μ b  <  4 + μ a + μ b   (always drops by 1)
| _, _, Step.R_eq_diff a b => by
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by
      simp [mu]; omega
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by
      simp [kappa]
    exact drop_right hmu hk
```

### Summary of the decrease argument per rule

| Rule | κ behaviour | μ behaviour | Combinator |
|------|-------------|-------------|------------|
| `R_int_delta` | drop or tie | always ↓ | `by_cases` + `drop_left`/`drop_right` |
| `R_rec_zero` | drop or tie | always ↓ | `by_cases` + `drop_left`/`drop_right` |
| `R_rec_succ` | drops when 3rd arg is not δ; **ties (and μ↑) when it is** | — | `drop_left` on non-δ branches; **measure gap on δ/δ** |
| `R_eq_refl` | drop or tie | always ↓ | `by_cases` + `drop_left`/`drop_right` |
| `R_eq_diff` | always ties | always ↓ by 1 | `drop_right` |

### Note on `R_rec_succ`

With the given definitions,

- `κ (recDelta b s (delta (delta m))) = max(max(κ b, κ s), κ m) + 1`
- `κ (app s (recDelta b s (delta m))) = max(κ s, max(max(κ b, κ s), κ m) + 1)`  
  which is the **same** value, while
- `μ` goes from `3 + μ b + μ s + μ m` to `4 + μ b + 2·μ s + μ m` (strictly larger).

So `LexOrder (measure RHS) (measure LHS)` fails on that instance. Four of the five sorries close with the skeleton above; finishing `R_rec_succ` requires a refined measure (for example, making `kappa` count the full height of the δ-tower in the third argument of `recDelta`) rather than a pure tactic proof over the current `(kappa, mu)`.
