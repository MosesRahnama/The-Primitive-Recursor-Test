Here is a proof skeleton you can drop into the five remaining branches.

Four of the five cases have a straightforward lex-decrease proof with the current `(kappa, mu)` measure. The `R_rec_succ` case is different: the natural proof works for all non-`delta` predecessors, but the `n = delta n'` subcase appears genuinely incompatible with the current measure.

## 1. Branches that should go through

```lean
-- integrate (delta t) --> void
| _, _, Step.R_int_delta t => by
    by_cases h : kappa t = 0
    · have hmu : mu void < mu (integrate (delta t)) := by
        simp [mu]
      have hk : kappa void = kappa (integrate (delta t)) := by
        simp [kappa, h]
      exact drop_right hmu hk
    · have hpos : 0 < kappa t := Nat.pos_of_ne_zero h
      have hk : kappa void < kappa (integrate (delta t)) := by
        simpa [kappa] using hpos
      exact drop_left hk

-- recDelta b s void --> b
| _, _, Step.R_rec_zero b s => by
    by_cases h : kappa s ≤ kappa b
    · have hmu : mu b < mu (recDelta b s void) := by
        simp [mu]
        omega
      have hk : kappa b = kappa (recDelta b s void) := by
        simp [kappa, Nat.max_eq_left h]
      exact drop_right hmu hk
    · have hs : kappa b < kappa s := Nat.lt_of_not_ge h
      have hk : kappa b < kappa (recDelta b s void) := by
        have hle :
            kappa s ≤ Nat.max (Nat.max (kappa b) (kappa s)) (kappa void) := by
          exact le_trans (Nat.le_max_right _ _) (Nat.le_max_left _ _)
        simpa [kappa] using lt_of_lt_of_le hs hle
      exact drop_left hk

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    by_cases h : kappa a = 0
    · have hmu : mu void < mu (eqW a a) := by
        simp [mu]
      have hk : kappa void = kappa (eqW a a) := by
        simp [kappa, h]
      exact drop_right hmu hk
    · have hpos : 0 < kappa a := Nat.pos_of_ne_zero h
      have hk : kappa void < kappa (eqW a a) := by
        simpa [kappa] using hpos
      exact drop_left hk

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by
      simp [mu]
      omega
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by
      simp [kappa]
    exact drop_right hmu hk
```

## 2. `R_rec_succ`: skeleton plus the obstruction

A natural start is:

```lean
-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    cases n with
    | void =>
        have hks_le :
            kappa s ≤ Nat.max (Nat.max (kappa b) (kappa s)) (kappa void) := by
          exact le_trans (Nat.le_max_right _ _) (Nat.le_max_left _ _)
        have hk :
            kappa (app s (recDelta b s void)) <
              kappa (recDelta b s (delta void)) := by
          simp [kappa, Nat.max_eq_right hks_le]
          exact Nat.lt_succ_self _
        exact drop_left hk

    | integrate t =>
        have hks_le :
            kappa s ≤ Nat.max (Nat.max (kappa b) (kappa s)) (kappa (integrate t)) := by
          exact le_trans (Nat.le_max_right _ _) (Nat.le_max_left _ _)
        have hk :
            kappa (app s (recDelta b s (integrate t))) <
              kappa (recDelta b s (delta (integrate t))) := by
          simp [kappa, Nat.max_eq_right hks_le]
          exact Nat.lt_succ_self _
        exact drop_left hk

    | merge a c =>
        have hks_le :
            kappa s ≤ Nat.max (Nat.max (kappa b) (kappa s)) (kappa (merge a c)) := by
          exact le_trans (Nat.le_max_right _ _) (Nat.le_max_left _ _)
        have hk :
            kappa (app s (recDelta b s (merge a c))) <
              kappa (recDelta b s (delta (merge a c))) := by
          simp [kappa, Nat.max_eq_right hks_le]
          exact Nat.lt_succ_self _
        exact drop_left hk

    | app a c =>
        have hks_le :
            kappa s ≤ Nat.max (Nat.max (kappa b) (kappa s)) (kappa (app a c)) := by
          exact le_trans (Nat.le_max_right _ _) (Nat.le_max_left _ _)
        have hk :
            kappa (app s (recDelta b s (app a c))) <
              kappa (recDelta b s (delta (app a c))) := by
          simp [kappa, Nat.max_eq_right hks_le]
          exact Nat.lt_succ_self _
        exact drop_left hk

    | recDelta b' s' n' =>
        have hks_le :
            kappa s ≤ Nat.max (Nat.max (kappa b) (kappa s)) (kappa (recDelta b' s' n')) := by
          exact le_trans (Nat.le_max_right _ _) (Nat.le_max_left _ _)
        have hk :
            kappa (app s (recDelta b s (recDelta b' s' n'))) <
              kappa (recDelta b s (delta (recDelta b' s' n'))) := by
          simp [kappa, Nat.max_eq_right hks_le]
          exact Nat.lt_succ_self _
        exact drop_left hk

    | eqW a c =>
        have hks_le :
            kappa s ≤ Nat.max (Nat.max (kappa b) (kappa s)) (kappa (eqW a c)) := by
          exact le_trans (Nat.le_max_right _ _) (Nat.le_max_left _ _)
        have hk :
            kappa (app s (recDelta b s (eqW a c))) <
              kappa (recDelta b s (delta (eqW a c))) := by
          simp [kappa, Nat.max_eq_right hks_le]
          exact Nat.lt_succ_self _
        exact drop_left hk

    | delta n' =>
        -- This is the problematic subcase.
        --
        -- After simplification, if
        --   M := Nat.max (Nat.max (kappa b) (kappa s)) (kappa n'),
        -- then:
        --
        --   kappa (recDelta b s (delta (delta n'))) = M + 1
        --   kappa (app s (recDelta b s (delta n'))) = M + 1
        --
        -- so `drop_left` is impossible.
        --
        -- Also:
        --
        --   mu (recDelta b s (delta (delta n'))) = 3 + mu b + mu s + mu n'
        --   mu (app s (recDelta b s (delta n'))) = 4 + mu b + 2 * mu s + mu n'
        --
        -- hence the target `mu` is larger, so `drop_right` is impossible too.
        --
        -- So this branch likely cannot be completed with the current
        -- `measure := (kappa, mu)`; the measure itself needs adjustment.
        sorry
```

## 3. Why `R_rec_succ` is the blocker

The issue is not just a missing trick; it looks like a real counterexample to `measure_decreases` as currently stated.

Take `b = void`, `s = void`, `n = delta void`. Then:

- source: `recDelta void void (delta (delta void))`
- target: `app void (recDelta void void (delta void))`

Their measures are:

- `measure source = (1, 3)`
- `measure target = (1, 4)`

So `LexOrder (measure target) (measure source)` is false.

## 4. Practical takeaway

So:

- the four branches above should be the right skeletons;
- the `R_rec_succ` proof naturally proceeds by `cases n`;
- but the `delta` subcase seems unprovable with the present definitions.

If you want, I can also suggest a minimal measure redesign that would make `R_rec_succ` decrease while leaving the rest of the file structurally similar.
