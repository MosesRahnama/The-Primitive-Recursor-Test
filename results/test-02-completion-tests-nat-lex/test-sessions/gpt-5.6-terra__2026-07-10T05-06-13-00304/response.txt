The `R_rec_succ` case cannot be completed with the stated measure: `measure_decreases` is false for that rule. The other four remaining cases can follow the same `drop_left` / `drop_right` pattern.

```lean
-- integrate (delta t) --> void
| _, _, Step.R_int_delta t => by
    by_cases h : kappa t = 0
    · apply drop_right
      · simp [mu]
      · simp [kappa, h]
    · apply drop_left
      simpa [kappa] using Nat.pos_of_ne_zero h

-- recDelta b s void --> b
| _, _, Step.R_rec_zero b s => by
    by_cases h : kappa s ≤ kappa b
    · apply drop_right
      · simp [mu]
        omega
      · simp [kappa, Nat.max_eq_left h]
    · have hlt : kappa b < kappa s := Nat.lt_of_not_ge h
      apply drop_left
      simp [kappa, Nat.max_eq_right (Nat.le_of_lt hlt), hlt]

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    by_cases h : kappa a = 0
    · apply drop_right
      · simp [mu]
      · simp [kappa, h]
    · apply drop_left
      simpa [kappa] using Nat.pos_of_ne_zero h

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    apply drop_right
    · simp [mu]
      omega
    · simp [kappa]
```

The obstruction in the successor-recursion rule is that the recursive argument `n` is allowed to itself be a `delta` term. Take:

```lean
b = void
s = void
n = delta void
```

Then the rule instance is:

```lean
recDelta void void (delta (delta void))
  -->
app void (recDelta void void (delta void))
```

For this instance, the measures reduce to:

```lean
measure (recDelta void void (delta (delta void))) = (1, 3)
measure (app void (recDelta void void (delta void))) = (1, 4)
```

So the proposed right-hand side is lexicographically *larger*, not smaller:

```lean
¬ LexOrder (1, 4) (1, 3)
```

Concretely:

* the source has `kappa = 1`, since its third argument is delta-wrapped;
* the target also has `kappa = 1`, because its inner `recDelta` still has a delta-wrapped third argument;
* the target has larger `mu`, since wrapping the recursive call in `app` adds `1`.

Therefore no Lean proof of the remaining `R_rec_succ` hole exists under the current definitions, and consequently the theorem `measure_decreases` as written cannot be completed. A repair would require changing the measure, restricting the successor rule, or using a different termination argument rather than this `(kappa, mu)` lexicographic measure.
