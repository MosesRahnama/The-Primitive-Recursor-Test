As written, the five remaining cases cannot all be completed: the `R_rec_succ` case is false for the current measure. Four of the five cases have straightforward lexicographic-decrease proofs, but `recDelta b s (delta n) → app s (recDelta b s n)` fails when `n` itself is a `delta`.

Here is the skeleton for the four provable cases:

```lean
-- integrate (delta t) --> void
| _, _, Step.R_int_delta t => by
    have hk_le : kappa void ≤ kappa (integrate (delta t)) := by
      simp
    rcases Nat.lt_or_eq_of_le hk_le with hk | hk
    · exact drop_left hk
    · have hmu : mu void < mu (integrate (delta t)) := by
        simp [mu]
      exact drop_right hmu hk

-- recDelta b s void --> b
| _, _, Step.R_rec_zero b s => by
    have hk_le : kappa b ≤ kappa (recDelta b s void) := by
      -- kappa source is max (max (kappa b) (kappa s)) 0
      exact Nat.le_trans
        (Nat.le_max_left (kappa b) (kappa s))
        (Nat.le_max_left (Nat.max (kappa b) (kappa s)) 0)
    rcases Nat.lt_or_eq_of_le hk_le with hk | hk
    · exact drop_left hk
    · have hmu : mu b < mu (recDelta b s void) := by
        simp [mu]
        omega
      exact drop_right hmu hk

-- eqW a a --> void
| _, _, Step.R_eq_refl a => by
    have hk_le : kappa void ≤ kappa (eqW a a) := by
      simp
    rcases Nat.lt_or_eq_of_le hk_le with hk | hk
    · exact drop_left hk
    · have hmu : mu void < mu (eqW a a) := by
        simp [mu]
      exact drop_right hmu hk

-- eqW a b --> integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by
      simp [mu]
      omega
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by
      simp [kappa]
    exact drop_right hmu hk
```

The problematic case is:

```lean
-- recDelta b s (delta n) --> app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    sorry
```

This cannot be proved with the current definitions. For example, take:

```lean
b = void
s = void
n = delta void
```

Then the rule gives:

```lean
Step
  (recDelta void void (delta (delta void)))
  (app void (recDelta void void (delta void)))
```

But the measures are:

```lean
measure (recDelta void void (delta (delta void))) = (1, 3)
measure (app void (recDelta void void (delta void))) = (1, 4)
```

So the `kappa` components are equal, while `mu` increases from `3` to `4`. Therefore

```lean
LexOrder (measure target) (measure source)
```

is false in this case. Thus `measure_decreases` is not provable as stated unless either the measure or the `R_rec_succ` rule is changed/restricted.
