Below is a compact “skeleton” that replaces every remaining `sorry` with a brief, self-contained argument.  Every case is reduced to the two generic lemmas
```
drop_left   :  kappa b < kappa a →  LexOrder (measure b) (measure a)
drop_right  :  mu b    < mu a
               kappa b = kappa a →  LexOrder (measure b) (measure a)
```
so each rule only has to supply

 • a strict `kappa` drop, or  
 • a strict `mu` drop together with a `kappa` tie,  
with a small case split whenever both situations may occur.

```lean
-- integrate (delta t)  ⟶  void
| _, _, Step.R_int_delta t => by
    -- kappa may drop (usual case) or tie (when kappa t = 0)
    have hμ  : mu void < mu (integrate (delta t)) := by simp [mu]
    have hκₗ : kappa void ≤ kappa (integrate (delta t)) := by simp [kappa]
    have hκ := lt_or_eq_of_le hκₗ
    cases hκ with
    | inl hk => exact drop_left hk
    | inr hk => exact drop_right hμ hk

-- recDelta b s void  ⟶  b
| _, _, Step.R_rec_zero b s => by
    -- again: either kappa drops or ties
    have hμ  : mu b < mu (recDelta b s void) := by
      simp [mu]; omega
    have hκₗ : kappa b ≤ kappa (recDelta b s void) := by simp [kappa]
    cases (lt_or_eq_of_le hκₗ) with
    | inl hk => exact drop_left hk
    | inr hk => exact drop_right hμ hk

-- recDelta b s (delta n)  ⟶  app s (recDelta b s n)
| _, _, Step.R_rec_succ b s n => by
    -- +1 in the source kappa gives an immediate drop
    have hk : kappa (app s (recDelta b s n))
            < kappa (recDelta b s (delta n)) := by
      simp [kappa_app, kappa_rec_delta]
    exact drop_left hk

-- eqW a a  ⟶  void
| _, _, Step.R_eq_refl a => by
    have hμ  : mu void < mu (eqW a a) := by
      simp [mu]; omega
    have hκₗ : kappa void ≤ kappa (eqW a a) := by simp [kappa]
    cases (lt_or_eq_of_le hκₗ) with
    | inl hk => exact drop_left hk
    | inr hk => exact drop_right hμ hk

-- eqW a b  ⟶  integrate (merge a b)
| _, _, Step.R_eq_diff a b => by
    have hμ : mu (integrate (merge a b)) < mu (eqW a b) := by
      simp [mu]; omega
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by
      simp [kappa]
    exact drop_right hμ hk
```

The arithmetic inequalities are handled with `simp` plus the already-used `omega` tactic (as in the earlier `merge` proofs).  No new ideas are required: each new rule is dispatched by the same lexicographic-measure scheme already exemplified in the completed `merge` cases.
