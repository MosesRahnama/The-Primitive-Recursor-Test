Here is a proof skeleton for the remaining cases.

Four of the five are straightforward drop-ins. The `R_rec_succ` case is different: with the current `kappa`/`mu`, its `n = delta _` subcase appears genuinely impossible, so I’m giving the natural case split skeleton and pointing out the obstruction.

| _, _, Step.R_int_delta t => by
    by_cases hk0 : kappa t = 0
    · have hmu : mu void < mu (integrate (delta t)) := by
        simp [mu]
      have hk : kappa void = kappa (integrate (delta t)) := by
        simp [kappa, hk0]
      exact drop_right hmu hk
    · have hpos : 0 < kappa t := Nat.pos_of_ne_zero hk0
      have hk : kappa void < kappa (integrate (delta t)) := by

| _, _, Step.R_eq_diff a b => by

    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by

    exact drop_right hmu hk

Short summary:

- `R_int_delta` and `R_eq_refl`: split on whether `kappa` is zero; use `drop_left` if positive, otherwise `drop_right`.
- `R_rec_zero`: split on whether `kappa s ≤ kappa b`; if yes, `kappa` ties and `mu` drops; if not, `kappa` drops.
- `R_eq_diff`: `kappa` ties, `mu` drops by 1.
- `R_rec_succ`: all non-`delta` `n` branches can use `drop_left`; the `n = delta _` branch reveals a real mismatch in the current measure.
