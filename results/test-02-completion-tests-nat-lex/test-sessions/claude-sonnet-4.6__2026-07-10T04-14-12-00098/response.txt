1. **R_int_delta**: `integrate (delta t) → void`. `kappa void = 0`, `kappa (integrate (delta t)) = kappa t`. `mu void = 0`, `mu (integrate (delta t)) = 1 + mu t`. Need to handle whether `kappa t = 0` or not — actually `kappa (integrate (delta t)) = kappa t` and `kappa void = 0`. 3. **R_rec_succ**: `recDelta b s (delta n) → app s (recDelta b s n)`. Kappa of LHS = `max(max(kappa b)(kappa s))(kappa n) + 1`, kappa of RHS = `max(kappa s)(max(max(kappa b)(kappa s))(kappa n))` = `max(max(kappa b)(kappa s))(kappa n)`. So kappa strictly drops by 1.

4. **R_eq_refl**: `eqW a a → void`. `kappa void = 0 ≤ kappa (eqW a a)`. If kappa drops, done; if kappa ties (both 0), mu drops.
