Looking at the partial proof, I need to analyze each remaining rule and determine whether `kappa` drops (use `drop_left`) or `kappa` ties and `mu` drops (use `drop_right`).

## Case 1: `R_int_delta` - `integrate (delta t) --> void`

- **LHS kappa**: `kappa (integrate (delta t)) = kappa (delta t) = kappa t`
- **RHS kappa**: `kappa void = 0`
- **LHS mu**: `mu (integrate (delta t)) = 1 + mu (delta t) = 1 + mu t`
- **RHS mu**: `mu void = 0`

Since `kappa void = 0 ≤ kappa t`, we have `kappa` ties or drops. If `kappa t = 0`, then kappa ties and mu drops. If `kappa t > 0`, kappa drops. Either way, we can use `drop_right` when they tie, but more generally mu strictly drops from `1 + mu t` to `0`.

```lean
| _, _, Step.R_int_delta t => by
    have hmu : mu void < mu (integrate (delta t)) := by simp [mu]; omega
    have hk  : kappa void ≤ kappa (integrate (delta t)) := by simp [kappa]; omega
    by_cases h : kappa t = 0
    · exact drop_right hmu (by simp [kappa, h])
    · exact drop_left (by simp [kappa]; omega)
```

## Case 2: `R_rec_zero` - `recDelta b s void --> b`

- **LHS kappa**: `kappa (recDelta b s void) = max (max (kappa b) (kappa s)) (kappa void) = max (max (kappa b) (kappa s)) 0 = max (kappa b) (kappa s)`
- **RHS kappa**: `kappa b`
- **LHS mu**: `3 + mu b + mu s + 0 = 3 + mu b + mu s`
- **RHS mu**: `mu b`

Kappa of RHS `≤` kappa of LHS (since `kappa b ≤ max (kappa b) (kappa s)`), and mu strictly drops.

```lean
| _, _, Step.R_rec_zero b s => by
    have hmu : mu b < mu (recDelta b s void) := by simp [mu]; omega
    have hk  : kappa b ≤ kappa (recDelta b s void) := by simp [kappa]; exact Nat.le_max_left _ _
    by_cases h : kappa b = kappa (recDelta b s void)
    · exact drop_right hmu h
    · exact drop_left (Nat.lt_of_le_of_ne hk h)
```

## Case 3: `R_rec_succ` - `recDelta b s (delta n) --> app s (recDelta b s n)`

- **LHS kappa**: `max (max (kappa b) (kappa s)) (kappa n) + 1`
- **RHS kappa**: `max (kappa s) (kappa (recDelta b s n)) = max (kappa s) (max (max (kappa b) (kappa s)) (kappa n))`

The key insight is that `kappa` of RHS equals `max (max (kappa b) (kappa s)) (kappa n)`, which is strictly less than LHS (which has `+1`).

```lean
| _, _, Step.R_rec_succ b s n => by
    have hk : kappa (app s (recDelta b s n)) < kappa (recDelta b s (delta n)) := by
      simp [kappa]
      omega
    exact drop_left hk
```

## Case 4: `R_eq_refl` - `eqW a a --> void`

- **LHS kappa**: `max (kappa a) (kappa a) = kappa a`
- **RHS kappa**: `0`

| _, _, Step.R_eq_refl a => by

## Case 5: `R_eq_diff` - `eqW a b --> integrate (merge a b)`

| _, _, Step.R_eq_diff a b => by
