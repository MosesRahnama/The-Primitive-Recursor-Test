I'll provide proof skeletons for the remaining five cases in the `measure_decreases` theorem. Each case needs to show that the lexicographic measure decreases when applying the corresponding reduction rule.

### 1. R_int_delta case

```lean
| _, _, Step.R_int_delta t => by
    have hk : kappa void < kappa (integrate (delta t)) := by
      simp [kappa]
      apply Nat.zero_lt_succ
    exact drop_left hk
```

### 2. R_rec_zero case
```lean
| _, _, Step.R_rec_zero b s => by
    have hmu : mu b < mu (recDelta b s void) := by
      simp [mu]
      omega
    have hk : kappa b = kappa (recDelta b s void) := by
      simp [kappa]
    exact drop_right hmu hk
```

### 3. R_rec_succ case

```lean
| _, _, Step.R_rec_succ b s n => by

    exact drop_left hk
```

### 4. R_eq_refl case
```lean
| _, _, Step.R_eq_refl a => by
    have hk : kappa void < kappa (eqW a a) := by
      simp [kappa]
      apply Nat.zero_lt_succ

      apply Nat.zero_lt_succ
      apply Nat.zero_lt_succ
    exact drop_left hk
```

### 5. R_eq_diff case
```lean
| _, _, Step.R_eq_diff a b => by
    have hmu : mu (integrate (merge a b)) < mu (eqW a b) := by
      simp [mu]
      omega
    have hk : kappa (integrate (merge a b)) = kappa (eqW a b) := by
      simp [kappa]
    exact drop_right hmu hk
```

Each proof follows the same pattern:
1. For cases where κ decreases, we use `drop_left` with a proof that κ strictly decreases
2. For cases where κ stays the same but μ decreases, we use `drop_right` with proofs that κ is equal and μ strictly decreases

The proofs use the simp lemmas provided in the file and basic arithmetic properties of natural numbers. The `omega` tactic is used in some cases to handle simple arithmetic inequalities.
