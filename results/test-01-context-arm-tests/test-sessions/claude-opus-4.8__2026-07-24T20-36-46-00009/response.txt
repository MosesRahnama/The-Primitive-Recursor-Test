## Assessment

**No — strong normalization cannot be established for this `Step` system.** In fact the system is *not* strongly normalizing: there is an infinite reduction sequence, so no proof of SN is possible from the calculus alone (or with any sound method).

## Reasoning

The culprit is the interaction of two rules with no side conditions:

- `R_eq_diff : ∀ a b, Step (eqW a b) (integrate (merge a b))`
- `R_eq_refl : ∀ a, Step (eqW a a) void`

The `R_eq_diff` rule fires for **any** `a b`, including the case `a = b`. It is unguarded — there is no side condition requiring `a ≠ b`, and rewrite relations here are not confluence/priority-ordered, so both `R_eq_refl` and `R_eq_diff` are simultaneously available on `eqW a a`.

Now consider what `R_eq_diff` produces and try to build a loop. The obvious hope for divergence would be a term that reproduces an `eqW` redex of the same or larger form. Examine the outputs:

- `eqW a b → integrate (merge a b)` strictly grows the term (adds `integrate` and `merge`), but the result `integrate (merge a b)` has no `eqW` at the head anymore.

However, divergence does not require regenerating `eqW` specifically — it only requires *some* infinite chain. Consider whether any single term admits an infinite path. Trace the structure:

- `integrate` only reduces via `R_int_delta`, which requires its argument to be `delta _`, and it terminates to `void`.
- `merge`, `recΔ`, `app`, `delta` reductions all strictly decrease structural size or transform into strictly smaller/finite forms.
- The only rule that **increases** term size is `R_eq_diff`.

But `R_eq_diff` can only fire on an `eqW` node, and it *consumes* that `eqW` node (replacing it by `integrate (merge …)`). Since each `Trace` term contains only finitely many `eqW` subterms, and no rule ever *creates* a new `eqW` node from non-`eqW` material, the total number of `eqW`-firings along any reduction is bounded by the count of `eqW` occurrences in the starting term.

So one must weigh this correctly. Define a measure combining:
1. the number of `eqW` nodes (strictly decreased by both eq-rules, unchanged or decreased by all others), and
2. ordinary term size for everything else.

Since `R_eq_diff` is the only size-increasing rule and it strictly reduces the `eqW` count, and no rule increases the `eqW` count, a lexicographic measure `(eqW-count, size)` (or a polynomial interpretation weighting `eqW` heavily) strictly decreases at every step.

## Corrected conclusion

On careful inspection, the size-increasing `R_eq_diff` is bounded by the strictly-decreasing `eqW`-count, so the danger of nontermination is neutralized. **Strong normalization *is* establishable from the calculus alone**, via a lexicographic / weighted-interpretation argument:

- Assign each rule a measure `μ(t) = (number of eqW subterms, structural size)`.
- Every rule either decreases the `eqW` count (both `eqW` rules) or leaves it unchanged while strictly decreasing structural size (all other rules — each removes a constructor and never introduces `eqW`).
- This lexicographic pair is well-founded, so `Step` is strongly normalizing.

This uses only the given syntax and rules, with no added guards, side conditions, or extra axioms.
