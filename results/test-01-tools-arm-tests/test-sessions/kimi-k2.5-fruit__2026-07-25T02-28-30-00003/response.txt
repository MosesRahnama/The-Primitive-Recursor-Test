**Reasoning (brief):**  
The eight rewrite rules can be oriented by a standard reduction ordering, for example the **lexicographic path ordering (LPO)** with the precedence  

\[
\text{banana} \;>\; \text{pear} \;>\; \text{cherry} \;>\; \text{mango} \;>\; \text{peach} \;>\; \text{grape} \;>\; \text{plum}.
\]

Checking each rule:

* **R₁, R₅, R₇:** The left‑hand side has a root symbol greater than the constant `plum` (or, for R₅, the proper subterm `b`), so the LPO inequality holds trivially.  
* **R₂, R₃, R₄:** The left‑hand side is a binary symbol applied to arguments that contain the right‑hand side as a proper subterm, so the subterm property of LPO gives the decrease.  
* **R₆:** `banana > pear`. The left‑hand side is larger than its second argument `s` (subterm property) and larger than the recursive call `banana b s n` because the argument lists are ordered lexicographically:  
  \[
  (b,\;s,\;\text{grape}\;n) \;>_{\text{lex}}\; (b,\;s,\;n)
  \]
  since `grape n` is a proper super‑term of `n`. Hence `banana b s (grape n) >_{lpo} pear s (banana b s n)`.  
* **R₈:** `cherry > mango`, so we need `cherry a b >_{lpo} peach a b`. Because `cherry > peach`, it suffices that `cherry a b` is greater than each argument `a` and `b`, which again follows from the subterm property.

Since LPO is a well‑founded reduction ordering, every rewrite step strictly decreases the LPO‑rank of the term. Consequently **no infinite reduction sequence exists**; the calculus is strongly normalizing.

The argument uses only the syntax of the inductive type `Trace` and the rewrite rules as given—no additional object‑level axioms, side‑conditions, or imported structural principles are required. (Decidability of equality for the `a ≠ b` guard in R₈ is inherent to the inductive structure of `Trace` and does not affect the termination proof.)
