**Raw assessment: yes — strong normalization can be established from the presented calculus alone**, at least for the `Step` relation as written, and also for its standard contextual/compatible closure if that is what is intended by “rewrite calculus.”

No structural/object-level axioms, guards, side conditions, or extra rewrite rules are needed. A standard syntactic termination proof by a well-founded measure suffices.

One possible ranking into natural numbers is:

\[
\begin{aligned}
\llbracket void \rrbracket &= 0 \\
\llbracket delta\ t \rrbracket &= \llbracket t \rrbracket + 1 \\
\llbracket integrate\ t \rrbracket &= \llbracket t \rrbracket + 1 \\
\llbracket merge\ a\ b \rrbracket &= \llbracket a \rrbracket + \llbracket b \rrbracket + 1 \\
\llbracket app\ a\ b \rrbracket &= \llbracket a \rrbracket + \llbracket b \rrbracket + 1 \\
\llbracket recΔ\ b\ s\ n \rrbracket
&= \llbracket b \rrbracket + (\llbracket n \rrbracket + 1)(\llbracket s \rrbracket + 2) + 1 \\
\llbracket eqW\ a\ b \rrbracket
&= 2\llbracket a \rrbracket + 2\llbracket b \rrbracket + 3
\end{aligned}
\]

Each rewrite rule strictly decreases this measure:

- `integrate (delta t) → void` decreases.
- `merge void t → t`, `merge t void → t`, and `merge t t → t` decrease.
- `recΔ b s void → b` decreases.
- `recΔ b s (delta n) → app s (recΔ b s n)` decreases by exactly `1` under the measure above.
- `eqW a a → void` decreases.
- `eqW a b → integrate (merge a b)` decreases, since  
  \[
  2a + 2b + 3 > a + b + 2.
  \]

All constructors are monotone with respect to this measure, so if one also takes the usual contextual closure of `Step`, reduction inside a subterm still strictly decreases the whole term’s measure. Since natural numbers are well-founded, there can be no infinite rewrite sequence.

So **strong normalization is available purely syntactically**.

Caveat: this does **not** show confluence or determinism. In fact, the overlap between

```lean
R_eq_refl : Step (eqW a a) void
R_eq_diff : Step (eqW a b) (integrate (merge a b))
```

means `eqW a a` has two possible reductions. For example, `eqW void void` can reduce to either `void` or `integrate (merge void void)`, and those do not obviously join under the rules as given. But nondeterminism/nonconfluence does not prevent strong normalization.

So the answer is: **yes, strong normalization can be proved from the given calculus alone; what fails is not termination but stronger properties such as confluence unless additional structure is supplied.**
