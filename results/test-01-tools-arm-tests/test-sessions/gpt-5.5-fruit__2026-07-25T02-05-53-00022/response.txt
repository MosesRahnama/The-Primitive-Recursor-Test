**Raw assessment: yes.** Strong normalization can be established from the presented calculus alone, without adding structural axioms, extra rewrite rules, guards, or object-level assumptions.

A direct proof is by a well-founded measure / polynomial interpretation into natural numbers. Define a measure `μ : Trace → Nat` by:

```text
μ(plum)          = 0
μ(grape t)       = μ(t) + 1
μ(mango t)       = μ(t)
μ(peach a b)     = μ(a) + μ(b) + 1
μ(pear a b)      = μ(a) + μ(b)
μ(banana b s n)  = μ(b) + (μ(n) + 1) * (μ(s) + 1)
μ(cherry a b)    = μ(a) + μ(b) + 2
```

Then every given rewrite rule strictly decreases `μ`.

For example:

- `mango (grape t) → plum`

```text
μ(mango (grape t)) = μ(t) + 1 > 0 = μ(plum)
```

- `peach plum t → t`

```text
μ(peach plum t) = 0 + μ(t) + 1 > μ(t)
```

- `banana b s plum → b`

```text
μ(banana b s plum) = μ(b) + (0 + 1) * (μ(s) + 1) > μ(b)
```

- The only size-increasing-looking rule is:

```text
banana b s (grape n) → pear s (banana b s n)
```

but under the above measure:

```text
μ(banana b s (grape n))
= μ(b) + (μ(n) + 2) * (μ(s) + 1)

μ(pear s (banana b s n))
= μ(s) + μ(b) + (μ(n) + 1) * (μ(s) + 1)
```

The left side exceeds the right side by exactly `1`.

- For `cherry_diff`:

```text
cherry a b → mango (peach a b)
```

regardless of the inequality premise,

```text
μ(cherry a b) = μ(a) + μ(b) + 2
> μ(a) + μ(b) + 1
= μ(mango (peach a b))
```

So the `a ≠ b` premise is not needed for termination; it is merely part of the rewrite rule.

Because natural-number descent is well-founded, there cannot be an infinite sequence of `Step` reductions.

Moreover, if one interprets this as a usual first-order rewrite system closed under contexts, the same argument still works: each constructor interpretation is monotone/strictly compatible with decrease in its arguments, so a rewrite inside a subterm also strictly decreases the whole term’s measure.

So within the stated boundary: **yes, strong normalization is provable from the given syntax and rules alone.**
