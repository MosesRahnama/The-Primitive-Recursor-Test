### Method 1: Monotonic Polynomial Interpretation
We can establish strong normalization by mapping every constructor to a strictly monotonic polynomial over the strictly positive integers ($\mathbb{N}_{\ge 1}$). Consider the following interpretation mapping:

* $[\text{void}] = 1$
* $[\text{delta}](t) = t + 1$
* $[\text{integrate}](t) = t$
* $[\text{merge}](a, b) = a + b$
* $[\text{app}](a, b) = a + b$
* $[\text{rec}\Delta](b, s, n) = b + s \times n + n$
* $[\text{eqW}](a, b) = a + b + 1$

By evaluating the left-hand side (LHS) and right-hand side (RHS) of every rule in your calculus under this interpretation, we observe a strict mathematical decrease ($LHS > RHS$) in every single case:

1. **`integrate (delta t) -> void`**
   $LHS: t + 1 \quad>\quad RHS: 1$
2. **`merge void t -> t`**
   $LHS: 1 + t \quad>\quad RHS: t$
3. **`merge t void -> t`**
   $LHS: t + 1 \quad>\quad RHS: t$
4. **`merge t t -> t`**
   $LHS: 2t \quad>\quad RHS: t$ *(since $t \ge 1$)*
5. **`recΔ b s void -> b`**
   $LHS: b + s(1) + 1 = b + s + 1 \quad>\quad RHS: b$
6. **`recΔ b s (delta n) -> app s (recΔ b s n)`**
   $LHS: b + s(n + 1) + (n + 1) = b + sn + s + n + 1$
   $RHS: s + (b + sn + n) = b + sn + s + n$

8. **`eqW a b -> integrate (merge a b)`**
   $LHS: a + b + 1 \quad>\quad RHS: a + b$

Because every constituent polynomial is strictly monotonic for variables $\ge 1$, *any* rewrite step (even inside an unstated congruence context) strictly decreases the integer weight of the whole term. Since there are no infinitely descending chains of positive integers, an infinite rewrite sequence is mathematically impossible.
