## Assessment: **Yes — strong normalization can be established from the calculus alone.**

**Method:** the standard *monotone‑algebra / polynomial‑interpretation* technique for first‑order term rewriting systems. Interpret every `Trace` term as a natural number via a function $f$ defined by structural recursion on the constructors:

$$f(\text{void}) = 1,\quad f(\text{delta}(t)) = f(t)+1,\quad f(\text{integrate}(t)) = f(t)+1$$
$$f(\text{merge}(a,b)) = f(a)+f(b)+1,\quad f(\text{app}(a,b)) = f(a)+f(b)+1$$
$$f(\text{eqW}(a,b)) = f(a)+f(b)+3,\quad f(\text{recΔ}(b,s,n)) = f(b) + (f(s)+1)\cdot 3^{f(n)}$$

Every clause of $f$ is **strictly monotone** in each argument, so replacing a subterm with a $<_{\mathbb N}$‑smaller‑interpretation subterm strictly decreases the interpretation of the whole enclosing term — this is exactly what lifts a root‑level rule into a genuine compatible order over *all* contexts, which is what "Step" closed under subterms requires for a termination argument.

Checking the eight rules gives $f(\text{lhs}) - f(\text{rhs})$ equal to:

| Rule | Difference |
|---|---|
| `R_int_delta` | $t+1$ |
| `R_merge_void_left/right` | $2$ |
| `R_merge_cancel` | $t+1$ |
| `R_rec_zero` | $3S+3$ |
| `R_rec_succ` | $(2\cdot3^{N}-1)(S+1)$ |
| `R_eq_refl` | $2x+2$ |
| `R_eq_diff` | $1$ |

All of these are **strictly positive** for all natural‑number values of the free variables (verified symbolically, including the factorization $(2\cdot3^N-1)(S+1)\ge 1$ for the trickiest case, `R_rec_succ`, where the step function `s` is duplicated on the right‑hand side). Since $(\mathbb N,>)$ is well‑founded, no rule application — in any context — can ever increase $f$, and every application strictly decreases it. Hence there is no infinite `Step`‑reduction sequence from any `Trace`, i.e. the system is strongly normalizing.

**Why the "duplication" of `s` and of `a`,`b` does not threaten this:** the naive worry is that `R_rec_succ` copies `s` (recΔ(b,s,delta n) → app(s, recΔ(b,s,n))) and could cause unbounded growth. A plain additive size measure indeed fails to decrease here. But no rule in the system ever *introduces* a fresh `delta` constructor — every `delta` appearing after a step already existed as a subterm of the redex — so the recursion index in `recΔ` only ever shrinks structurally, never regenerates. Choosing an interpretation where the recursion index contributes *exponentially* (the $3^{f(n)}$ factor) rather than additively exactly compensates for the duplication of `s`, giving a strict decrease regardless of how large `s` is. This is the same phenomenon that makes primitive recursion (Gödel's System T style recursors) strongly normalizing despite duplicating the step function, and it required no new rule, guard, or side condition — only an interpretation built from the existing constructors.

**Note on confluence, not relevant to SN:** the rules `R_eq_refl` and `R_eq_diff` overlap on `eqW(a,a)`, giving two different one‑step reducts (`void` vs. `integrate(merge(a,a))`). This is a failure of confluence, but strong normalization only requires that *every* reduction path is finite, which the interpretation above guarantees for both branches (indeed both differences, $2x+2$ and $1$, are positive).

**Conclusion:** the eight rules, taken exactly as given, admit a well‑founded monotone interpretation into $(\mathbb N,>)$ under which every rule strictly decreases; this suffices to prove strong normalization purely from the syntax and rewrite rules presented, without invoking any external structural axiom, extra rule, guard, or side condition.
