**Assessment: yes.** Strong normalization is establishable from the presented calculus alone. No extra object-level axioms, semantic assumptions, guards, or added rewrite rules appear necessary.

A direct termination proof is available by a well-founded interpretation into natural numbers. Define a measure `μ : Trace → Nat` such as:

```lean
μ plum = 0
μ (grape t) = μ t + 1
μ (mango t) = μ t + 1
μ (peach a b) = μ a + μ b + 1
μ (pear a b) = μ a + μ b + 1
μ (banana b s n) = μ b + (μ n + 1) * (μ s + 2)
μ (cherry a b) = μ a + μ b + 3
```

Then every rewrite rule strictly decreases `μ`.

Key checks:

- `mango (grape t) → plum`

  ```text
  μ = μ t + 2 > 0
  ```

- `peach plum t → t`

  ```text
  μ = μ t + 1 > μ t
  ```

- `peach t plum → t`

  ```text
  μ = μ t + 1 > μ t
  ```

- `peach t t → t`

  ```text
  μ = 2 * μ t + 1 > μ t
  ```

- `banana b s plum → b`

  ```text
  μ = μ b + μ s + 2 > μ b
  ```

- `banana b s (grape n) → pear s (banana b s n)`

  Left side:

  ```text
  μ b + (μ n + 2) * (μ s + 2)
  ```

  Right side:

  ```text
  μ s + [μ b + (μ n + 1) * (μ s + 2)] + 1
  ```

  The left exceeds the right by exactly `1`.

- `cherry a a → plum`

  ```text
  2 * μ a + 3 > 0
  ```

- `cherry a b → mango (peach a b)`

  ```text
  μ left  = μ a + μ b + 3
  μ right = μ a + μ b + 2
  ```

  The disequality premise is irrelevant for termination; the measure decreases regardless.

Because every `Step x y` gives `μ x > μ y`, and `>` on natural numbers is well-founded, there can be no infinite rewrite sequence. Thus the system is strongly normalizing for the `Step` relation as presented.

If one later defined the usual compatible/contextual closure of `Step`, the same measure also works, because all constructors above are strictly monotone in their recursive arguments under this interpretation. But for the file exactly as shown, no such closure is even part of the calculus, so the root-step termination proof is already sufficient.
