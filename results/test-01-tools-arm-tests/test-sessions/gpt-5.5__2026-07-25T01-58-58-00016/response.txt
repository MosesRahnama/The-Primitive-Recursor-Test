**Raw assessment: yes — strong normalization can be established from the presented calculus alone**, assuming the rewrite relation is either exactly the `Step` relation shown or its ordinary first-order contextual closure.

A standard termination proof is available by orienting all rules with a well-founded simplification order, e.g. recursive path ordering / lexicographic path ordering, using a precedence such as:

```text
recΔ  >  eqW  >  integrate  >  merge  >  app  >  delta  >  void
```

with lexicographic status for `recΔ`.

The key points are:

- `integrate (delta t) → void` strictly decreases by root-symbol precedence.
- `merge void t → t`, `merge t void → t`, and `merge t t → t` decrease by the subterm property.
- `recΔ b s void → b` decreases by the subterm property.
- `recΔ b s (delta n) → app s (recΔ b s n)` is orientable because:
  - `recΔ` is above `app`;
  - the recursive call has strictly smaller third argument, since `delta n > n`;
  - `s` is already a subterm of the left side.
- `eqW a a → void` decreases by precedence/subterm ordering.
- `eqW a b → integrate (merge a b)` is orientable because `eqW` is above `integrate` and `merge`, and the arguments `a`, `b` are subterms of the left side.

Such an ordering is stable under substitution and contexts, so it proves termination/strong normalization of the induced first-order rewrite system without adding guards, side conditions, structural axioms, or object-level assumptions.

One caveat: the system is **not confluent/deterministic** as written, because `eqW a a` matches both

```lean
R_eq_refl : eqW a a → void
R_eq_diff : eqW a a → integrate (merge a a)
```

But that overlap does **not** threaten strong normalization. It only means different finite reduction paths may exist.

So the concise judgment is: **yes, SN is provable from the given rules alone; the unguarded equality-difference rule may break confluence, but not termination.**
