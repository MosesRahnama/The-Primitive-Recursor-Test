The rewrite system can be shown to terminate by a standard simplification ordering (e.g., a polynomial interpretation or a lexicographic path ordering) that does not require any extra rewrite rules, guards, or hidden axioms.

### Why it terminates

1. **No hidden generation of “grape”.**  
   The right‑hand side of every rule uses only the constructors `plum`, `mango`, `peach`, `pear`, `banana` and `cherry`. No rule creates a `grape`. Consequently the total number of `grape` symbols in a term is a non‑increasing measure, and it strictly decreases on the two rules that match `grape` (`R_mango_grape` and `R_apple_orange`). After finitely many steps all `grape`s are eliminated.

2. **Ordering the remaining rules.**  
   Once grapes are gone, the only rules that can fire are those that either
   * delete a leading symbol (all `peach` rules, `R_banana_zero`, `R_cherry_refl`), or
   * replace `cherry` by a strictly smaller term in a well‑founded sense.

   To handle the one rule that syntactically increases size –  
   `cherry a b → mango (peach a b)` when `a≠b` – we give `cherry` a weight that dominates the right‑hand side.  A concrete polynomial interpretation over ℕ is:

   | constructor | interpretation |
   |-------------|----------------|
   | `plum`      | 1 |
   | `grape(x)`  | 1 + x |
   | `mango(x)`  | 1 + x |
   | `peach(x,y)`| 1 + x + y |
   | `pear(x,y)` | 1                     (ignores its arguments) |
   | `banana(x,y,z)`| 1 + x + y + z |
   | `cherry(x,y)`| 3 + 2·x + 2·y |

   With this assignment every left‑hand side is strictly larger than the corresponding right‑hand side:
   * `mango(grape t) = 2+t > 1 = plum`.
   * `peach(plum,t) = 2+t > t`, and similarly for the other peach rules.
   * `banana(b,s,plum) = 2+b+s > b`.
   * `banana(b,s,grape n) = 2+b+s+n > 1 = pear(s, banana b s n)`.
   * `cherry(a,a) = 3+4a > 1`.
   * `cherry(a,b) = 3+2a+2b > 2+a+b = mango(peach a b)`.

   All interpretation functions are monotone (coefficients are non‑negative), and the ordering on ℕ is well‑founded, so no infinite rewrite sequence exists.

3. **Alternative view (LPO).**  
   The same result is obtained with a lexicographic path ordering using the precedence  
   `cherry > mango > peach > banana > pear > grape > plum`.  
   Each rule orients because:
   * `cherry` dominates `mango` (which dominates `plum`);
   * `banana` dominates `pear`, and in the critical rule `banana b s (grape n) → pear s (banana b s n)` the lexicographic comparison of the arguments reduces the third argument from `grape n` to the proper subterm `n`;
   * the `peach` rules delete a proper subterm;
   * `grape` never appears on a right‑hand side, so its presence strictly decreases.

Since a well‑ founded measure (either the polynomial weight or the LPO) decreases on every step, **every reduction sequence terminates**. No additional structural axioms or object‑level assumptions are needed; the termination proof uses only the syntax and the rewrite rules as given.
