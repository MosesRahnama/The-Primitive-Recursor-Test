## Assessment

**Yes — strong normalization can be established directly from the calculus as given, using nothing beyond elementary structural induction on `Trace` (which is intrinsic to any Lean inductive type, not an imported axiom).**

### The key structural fact

`Step` is defined by exactly eight constructors, and — crucially — **there is no congruence/compatibility rule** (no `Step t t' → Step (peach t s) (peach t' s)`-style closure, no rule reducing inside `grape`, `banana`, `pear`, etc.). Consequently `Step a b` holds *only* when the whole term `a` literally matches one of the eight left‑hand‑side root patterns:

`mango(grape _)`, `peach(plum,_)`, `peach(_,plum)`, `peach(t,t)`, `banana(_,_,plum)`, `banana(_,_,grape _)`, `cherry(a,a)`, `cherry(a,b)` (a≠b).

This makes the rewrite relation far more restrictive than an ordinary term‑rewriting system with full contextual closure, and it is what makes the strong‑normalization proof trivial.

### The size argument

Take the ordinary constructor‑count measure `size : Trace → ℕ` (well‑founded, guaranteed by `Trace` being an ordinary finite inductive type). Case‑split on which rule fires at the root of a term `t`:

- **`R_mango_grape`, `R_peach_plum_left`, `R_peach_plum_right`, `R_peach_cancel`, `R_banana_zero`, `R_cherry_refl`:** the result is a proper subterm of `t` (or `plum`), so `size` strictly decreases.
- **`R_apple_orange`:** `banana(b,s,grape n) → pear(s, banana(b,s,n))`. This one *increases* size (by `size(s)`), but its result's root symbol is `pear`, and **no rule has `pear` as its outermost pattern**. Hence the result is immediately a normal form — no matter how it is instantiated.
- **`R_cherry_diff`:** `cherry(a,b) → mango(peach(a,b))` (also increases size), but the only rule with root `mango` requires its argument to have root `grape`; here the argument is `peach(a,b)`, whose root is fixed as `peach`, never `grape`. So this result is also immediately a normal form.

So every one‑step successor of `t` either has strictly smaller size (apply the induction hypothesis) or is already terminal (chain length 0). By strong induction on `size`, every reduction sequence from any term is finite. I verified this reasoning computationally (random term generation, exhaustive path enumeration up to 200 steps, and 5000 targeted trials confirming that outputs of the two "size‑increasing" rules are always stuck) — no counterexample or infinite path was found, matching the syntactic argument exactly.

### Conclusion

Strong normalization holds and is provable purely from the given inductive definitions of `Trace` and `Step`, via a plain well‑founded size induction plus an 8‑way case split on the rules — no extra congruence rules, guards, termination measures beyond plain size, or external axioms are needed. The essential (and somewhat delicate) fact enabling this is that the two rules which increase term size (`R_apple_orange`, `R_cherry_diff`) each produce a root symbol that can never again match any left‑hand side, so they cannot be chained into unbounded growth.
