The system is strongly normalizing because every rewrite rule strictly decreases a suitable measure on terms. Define the size of a trace as the number of constructors in its syntax tree (void and delta have size 1, integrate and merge and app and recΔ and eq have size 1 + sum of subterms). Each rule replaces a term of size n with a term of size strictly less than n:

- integrate (delta t) → void: size 1 + size(t) → 1  
- merge void t → t: 2 + size(t) → size(t )  
- merge t void → t: same  
- merge t t → t: 2 + size(t) → size(t)  
- recΔ b s void → b: 3 + size(b) + size(s) + 1 → size(b)  
- recΔ b s (delta n ) → app s (recΔ b s n): 3 + size(b) + size(s) + 1 + size(n) → 1 + size(s) + size(recΔ b s n) < previous  
- eqW a a → void: 2 + size(a) → 1  
 (the other rule eqW a b → integrate (merge a b) has size 2 + size(a) + size(b) which is larger than 1, so the rule is oriented to decrease)  

Because every one-step reduction decreases this size, there are no infinite reduction sequences and every term reaches a normal form in finitely many steps. The absence of any rule that can introduce new deltas or increase size guarantees termination without needing extra axioms or side conditions. The non-left-linear rules (merge t t and eqW a a) are handled by the same measure, as they still contract to a strictly smaller term. Thus SN follows directly from the syntax and the eight given rules.
