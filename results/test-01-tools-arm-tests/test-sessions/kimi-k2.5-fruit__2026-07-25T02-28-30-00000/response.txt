**Assessment: Yes**, strong normalization can be established from the presented calculus alone.

**Reasoning:**

The system is strongly normalizing because all rewrite rules are either size-decreasing or implement a well-founded primitive recursion schema. A termination proof can be constructed using a well-founded measure based on multisets of natural numbers, without importing external axioms.

1.  **Simple rules (R1–R5, R7):** These strictly decrease the number of constructors (term size). For example, `mango (grape t)` (size ≥2) becomes `plum` (size 0); `peach` eliminates a binary constructor; `banana b s plum` drops two constructors.

2.  **Non-recursive size-increasing rule (R8):** `cherry a b → mango (peach a b)` (when `a ≠ b`) increases size by 1, but the result `mango (peach a b)` is a normal form (no left-hand side matches `mango` with a non-`grape` argument, and `peach` requires `plum` or identical arguments). Thus it cannot participate in an infinite loop.

3.  **Primitive recursive rule (R6):** The critical rule is  
    `banana b s (grape n) → pear s (banana b s n)`.  
    This duplicates the second argument `s`, which prevents a simple size measure from decreasing. However, this is exactly the structure of primitive recursion (Gödel's **T**). The rule consumes one `grape` constructor from the third argument. 

    To formalize termination, define for any term `t` the multiset `M(t)` of the "grape-depths" of all active `banana` redexes (subterms of the form `banana b s (grape^k u)` where `u` is not `grape`, with associated integer `k`; include `0` for `banana b s plum`).
    - Applying **R6** to a redex with depth `k+1` removes that redex and inserts a new one with depth `k` (inside the `pear` wrapper), strictly decreasing the multiset in the multiset ordering.
    - Applying **R5** removes a redex (depth 0).
    - Other rules either decrease the size of subterms (and thus cannot increase any grape-depths) or create only normal forms (R8).
    - Reducing a subterm inside the third argument of a `banana` can convert an inactive `banana` (non-redex) into an active one, but this strictly decreases the size of that third argument, which can happen only finitely many times before it becomes `plum` or `grape`.

    Since the multiset ordering is well-founded, and no rule can increase the grape-depth of any `banana` redex, **R6** can be applied only finitely many times. Combined with the fact that all other rules are size-decreasing or halt immediately, every reduction sequence must terminate.

Thus, the system is strongly normalizing by structural analysis of the rewrite rules alone.
