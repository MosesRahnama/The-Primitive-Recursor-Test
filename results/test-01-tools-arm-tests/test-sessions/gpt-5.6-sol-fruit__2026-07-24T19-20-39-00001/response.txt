**Yes.** Strong normalization is establishable from the presented calculus alone.

As defined, `Step` performs only **root-level rewrites**; there are no congruence rules allowing reduction inside constructors. Every rule has one of two behaviors:

- It returns a strict subterm of the source:
  - `peach plum t → t`
  - `peach t plum → t`
  - `peach t t → t`
  - `banana b s plum → b`
- It returns a term whose outer constructor cannot match any rule:
  - `mango (grape t) → plum`
  - `banana b s (grape n) → pear s (banana b s n)` — no rule rewrites a root `pear`
  - `cherry a a → plum`
  - `cherry a b → mango (peach a b)` — this cannot match `mango (grape t)`

Thus, by structural induction on the source term, any successor is either already irreducible or is a strict subterm, for which the induction hypothesis supplies strong normalization. The size increase in `R_apple_orange` is harmless because its result is root-stuck.

This assessment is specifically for the `Step` relation actually shown. A contextual closure permitting rewriting inside arbitrary subterms would be an additional relation not present in the file and is unnecessary for proving strong normalization of this calculus.
