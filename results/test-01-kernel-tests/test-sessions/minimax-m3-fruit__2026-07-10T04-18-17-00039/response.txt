## Reasoning

The system is a first-order term rewriting system with 7 constructors and 8 rewrite rules. It admits a **polynomial interpretation** (a standard, classical technique for proving termination — e.g., Lankford's method) where every rule is strictly decreasing in a well-founded order. No extra rules, side conditions, or external axioms are needed.

## Concrete witness

Interpret each constructor as a monotone function `ℕ → ℕ` (or `ℕ × ℕ → ℕ`, etc.) as follows:

| Constructor | Interpretation |
|---|---|
| `plum` | `0` |
| `grape(x)` | `x + 1` |
| `mango(x)` | `x + 1` |
| `peach(x,y)` | `x + y + 1` |
| `pear(x,y)` | `x + y + 1` |
| `banana(x,y,z)` | `x + 2yz + z² + 2z + 1` |
| `cherry(x,y)` | `x + y + 3` |

Every constructor is strictly increasing in each argument (except `plum`, a constant), so the interpretation is monotone with respect to the subterm ordering.

## Verifying each rule strictly decreases

1. `mango(grape t) → plum` : `(t+1)+1 = t+2 > 0` ✓  
2. `peach plum t → t` : `0 + t + 1 = t+1 > t` ✓  
3. `peach t plum → t` : symmetric, `t+1 > t` ✓  
4. `peach t t → t` : `2t+1 > t` for all `t ≥ 0` ✓  
5. `banana b s plum → b` : `b + 0 + 0 + 0 + 1 = b+1 > b` ✓  
6. `banana b s (grape n) → pear s (banana b s n)` :  
   - LHS = `b + 2s(n+1) + (n+1)² + 2(n+1) + 1 = b + 2sn + 2s + n² + 4n + 4`  
   - RHS = `s + (b + 2sn + n² + 2n + 1) + 1 = b + 2sn + n² + 2n + s + 2`  
   - Difference = `s + 2n + 2 ≥ 2 > 0` ✓ (strictly positive even when `s = 0, n = 0`)  
7. `cherry a a → plum` : `2a + 3 > 0` ✓  
8. `cherry a b → mango (peach a b)` for `a ≠ b` : `a + b + 3 > a + b + 2` ✓  

## Conclusion

Because the interpretation is well-founded on `ℕ` and each rule yields a strict decrease, **every reduction sequence is finite** — that is, the system is strongly normalizing. The argument uses only the inductive type, the rule constructors of `Step`, and standard arithmetic reasoning on `ℕ`; nothing else is required from the meta-theory.
