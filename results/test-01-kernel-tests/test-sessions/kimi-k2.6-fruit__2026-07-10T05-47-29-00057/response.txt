**Yes, strong normalization can be established from the calculus alone.**

The system is a finitely branching, first-order rewrite system with no variable binding. Strong normalization follows directly by exhibiting a strictly monotone interpretation into the well-founded set **ℕ** (a standard monotone-algebra termination argument). Assign to each constructor a function on natural numbers as follows:

- `plum` ↦ 1
- `grape(x)` ↦ x + 2
- `mango(x)` ↦ x + 1
- `peach(x,y)` ↦ max(x,y) + 1
- `pear(x,y)` ↦ x + y + 1
- `banana(x,y,z)` ↦ x + (y + 1)·z
- `cherry(x,y)` ↦ max(x,y) + 3

Each of these is strictly monotone in every argument, and one checks that for every rewrite rule the left-hand side evaluates to a strictly larger number than the right-hand side:

1. `mango(grape t)` ↦ |t|+3 > 1 = `plum`.
2. `peach plum t` ↦ |t|+1 > |t|.
3. `peach t plum` ↦ |t|+1 > |t|.
4. `peach t t` ↦ |t|+1 > |t|.
5. `banana b s plum` ↦ |b|+|s|+1 > |b|.
6. `banana b s (grape n)` ↦ |b|+(|s|+1)(|n|+2) = |b|+(|s|+1)|n|+2|s|+2  
   > |s|+|b|+(|s|+1)|n|+1 = `pear s (banana b s n)`.  
   The multiplicative interpretation on the third argument absorbs the duplication of `s`.
7. `cherry a a` ↦ |a|+3 > 1 = `plum`.
8. `cherry a b` (with a≠b) ↦ max(|a|,|b|)+3 > max(|a|,|b|)+2 = `mango (peach a b)`.

Because every step strictly decreases the natural-number value of the term, no infinite reduction sequence exists. No additional axioms, side conditions, or imported lemmas are required—only the syntax and the rewrite rules as given.
