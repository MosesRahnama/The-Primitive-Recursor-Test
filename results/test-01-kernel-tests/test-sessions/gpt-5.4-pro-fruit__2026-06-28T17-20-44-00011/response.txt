Yes — as written, strong normalization should be establishable from this calculus alone.

Two reasons:

1. **For `Step` exactly as defined in the Lean file**, rewriting is only at the root; there are no congruence/context rules. In that literal reading, termination is very straightforward: most rules go directly to a normal form or to a strict subterm, and the only “expanding” rule  
   `banana b s (grape n) → pear s (banana b s n)`  
   lands under a `pear`, and there is no rule with `pear` at the top, so it cannot keep firing at the root.

2. **Even if one reads it as the usual first-order TRS generated by those rules under contexts**, it still looks strongly normalizing. A standard polynomial interpretation over `ℕ` orients all rules strictly, for example:
   - `plum ↦ 0`
   - `grape x ↦ x + 1`
   - `mango x ↦ x + 1`
   - `peach x y ↦ x + y + 1`
   - `pear x y ↦ x + y + 1`
   - `banana b s n ↦ b + (n + 1)(s + 2)`
   - `cherry a b ↦ a + b + 3`

   Then every rewrite rule strictly decreases the measure, including the non-obvious one:
   \[
   \llbracket banana\ b\ s\ (grape\ n)\rrbracket
   = b + (n+2)(s+2)
   > s + \bigl(b + (n+1)(s+2)\bigr) + 1
   = \llbracket pear\ s\ (banana\ b\ s\ n)\rrbracket.
   \]

So my raw assessment is: **yes, strong normalization can be proved from the presented rules alone, without adding extra rewrite rules, guards, side conditions, or object-level axioms.**
