## Assessment: **Yes — strong normalization can be established from the calculus alone.**

### Proof Method: Polynomial Interpretation

A polynomial interpretation over the natural numbers (with the standard well-founded order `>`) suffices. Define the interpretation `⟦·⟧` as follows:

| Constructor | Interpretation |
|---|---|
| `void` | `1` |
| `delta(t)` | `⟦t⟧ + 2` |
| `integrate(t)` | `⟦t⟧ + 1` |
| `merge(a, b)` | `⟦a⟧ + ⟦b⟧` |
| `app(a, b)` | `⟦a⟧ + ⟦b⟧` |
| `recΔ(b, s, n)` | `⟦n⟧ · ⟦s⟧ + ⟦b⟧ + ⟦n⟧` |
| `eqW(a, b)` | `⟦a⟧ + ⟦b⟧ + 2` |

All interpretations are ≥ 1, and every constructor is **monotone** in each argument (multiplication is by a factor ≥ 1), so the compatible closure (reduction under contexts) is compatible with the ordering.

### Verification of Each Rule

1. **`integrate(delta(t)) → void`**: LHS = `⟦t⟧ + 3` ≥ 4 > 1 = RHS. ✓
2. **`merge(void, t) → t`**: LHS = `1 + ⟦t⟧` > `⟦t⟧` = RHS. ✓
3. **`merge(t, void) → t`**: Same as (2). ✓
4. **`merge(t, t) → t`**: LHS = `2·⟦t⟧` > `⟦t⟧` = RHS (since `⟦t⟧ ≥ 1`). ✓
5. **`recΔ(b, s, void) → b`**: LHS = `⟦s⟧ + ⟦b⟧ + 1` > `⟦b⟧` = RHS. ✓
6. **`recΔ(b, s, delta(n)) → app(s, recΔ(b, s, n))`**:
   - LHS = `(⟦n⟧+2)·⟦s⟧ + ⟦b⟧ + ⟦n⟧ + 2`
   - RHS = `⟦s⟧ + ⟦n⟧·⟦s⟧ + ⟦b⟧ + ⟦n⟧`
   - LHS − RHS = `⟦s⟧ + 2` ≥ 3 > 0. ✓
7. **`eqW(a, a) → void`**: LHS = `2·⟦a⟧ + 2` ≥ 4 > 1 = RHS. ✓
8. **`eqW(a, b) → integrate(merge(a, b))`**:
   - LHS = `⟦a⟧ + ⟦b⟧ + 2`
   - RHS = `⟦a⟧ + ⟦b⟧ + 1`
   - LHS − RHS = 1 > 0. ✓

### Conclusion

Every rewrite step (at any position in a term, via monotonicity) strictly decreases the natural-number interpretation. Since `>` on ℕ is well-founded, no infinite reduction sequence exists. The system is **strongly normalizing**, and this is established purely from the given syntax and rules — no external axioms, guards, or side conditions are needed.

The key design feature that makes this work is that rule 6 (`recΔ` unfolding), which duplicates `s`, is guarded by `delta` in the third argument. The interpretation charges `delta` a weight of +2, which pays for the duplication of `s` (costing `⟦s⟧`) while still leaving a strict decrease.
