## Assessment: Yes, strong normalization is provable from the calculus alone.

**Method:** A polynomial interpretation (standard in term rewriting) assigns a non‑negative integer weight to every term, strictly decreasing on every `Step`.

### Weight function W : Trace → ℕ

```
W(plum)            = 0
W(grape  t)        = 1 + W(t)
W(mango  t)        = 1 + W(t)
W(peach  s t)      = 1 + W(s) + W(t)
W(pear   s t)      = W(t)
W(banana b s t)    = 1 + W(b) + 2·W(s) + W(t)
W(cherry a b)      = 3 + W(a) + W(b)
```

All functions are monotone in each argument, so W is a morphism of the term algebra.

### Verification: W(LHS) − W(RHS) on every rule

| Rule | LHS weight | RHS weight | Δ |
|---|---|---|---|
| R_mango_grape | 2 + W(t) | 0 | 2 |
| R_peach_plum_left | 1 + W(t) | W(t) | 1 |
| R_peach_plum_right | 1 + W(t) | W(t) | 1 |
| R_peach_cancel | 1 + 2W(t) | W(t) | 1+W(t) |
| R_banana_zero | 1+W(b)+2W(s) | W(b) | 1+2W(s) |
| R_apple_orange | 2+W(b)+2W(s)+W(n) | 1+W(b)+2W(s)+W(n) | 1 |
| R_cherry_refl | 3+2W(a) | 0 | 3+2W(a) |
| R_cherry_diff | 3+W(a)+W(b) | 2+W(a)+W(b) | 1 |

Every rule strictly decreases W. Contextual closure (reducing a subterm) also strictly decreases W because each constructor's weight function is monotone in every argument and uses only non‑negative coefficients.

### Conclusion

Since W is a non‑negative integer and every one‑step reduction strictly decreases it, no infinite reduction sequence exists. Hence the system is **strongly normalizing (SN)**, established purely from the syntax and the eight given rewrite rules — no extra axioms, side conditions, or rewrite rules are needed.

The single delicate rule is `R_apple_orange` (the only rule whose right‑hand side is not a strict syntactic subterm); it is handled by absorbing the `pear` wrapper into the weight via W(pear s t) = W(t), while the grape "peels off" contribute the constant 1 that makes the difference positive.
