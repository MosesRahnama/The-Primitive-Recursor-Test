## Assessment: Yes, strong normalization can be established.

### Proof via Polynomial Interpretation

Define an interpretation `f : Trace → ℕ⁺` as follows:

| Term | Interpretation |
|---|---|
| `void` | `1` |
| `delta t` | `2·f(t) + 1` |
| `integrate t` | `f(t) + 1` |
| `merge t₁ t₂` | `f(t₁) + f(t₂) + 1` |
| `app t₁ t₂` | `f(t₁) + f(t₂) + 1` |
| `eqW a b` | `f(a) + f(b) + 3` |
| `recΔ b s n` | `f(b) + (f(s) + 1)·f(n) + 1` |

**Monotonicity.** Every constructor is strictly increasing in each argument. The only non-trivial case is `recΔ` in its third argument `n`: since `f(s)+1 ≥ 2 > 0`, the expression `(f(s)+1)·f(n)` is strictly increasing in `f(n)`. This guarantees that rewriting in any subterm propagates to a strict decrease at the root.

**Every rule strictly decreases `f`.** The interesting cases:

- **Rule 6** (`recΔ b s (delta n) → app s (recΔ b s n)`):
  ```
  f(LHS) = f(b) + (f(s)+1)·(2·f(n)+1) + 1
         = f(b) + 2·f(s)·f(n) + 2·f(n) + f(s) + 2
  f(RHS) = f(s) + f(b) + (f(s)+1)·f(n) + 1 + 1
         = f(b) + f(s)·f(n) + f(n) + f(s) + 2
  f(LHS) − f(RHS) = f(n)·(f(s) + 1) ≥ 2 > 0  ✓
  ```
  The key insight: `delta` is interpreted multiplicatively (`2·f(t)+1`), so consuming one `delta` layer releases enough "budget" to pay for duplicating `s`.

- **Rule 8** (`eqW a b → integrate (merge a b)`):
  ```
  f(LHS) = f(a) + f(b) + 3
  f(RHS) = f(a) + f(b) + 1 + 1 + 1 = f(a) + f(b) + 2
  f(LHS) − f(RHS) = 1 > 0  ✓
  ```
  The constant `+3` on `eqW` (rather than `+1`) absorbs the one-step size increase from introducing `integrate` and `merge`.

- **Rule 5** (`recΔ b s void → b`): decrease is `f(s) + 2 ≥ 3 > 0`. ✓
- **Rules 1–4, 7**: straightforward size decreases. ✓

Since `f` maps into `ℕ⁺` (which is well-founded under `>`), is monotone in every context, and strictly decreases on every rewrite step at any position, no infinite reduction sequence exists. The system is **strongly normalizing**.
