Raw reason: a direct well-founded measure exists using only the given syntax and rules, so no extra structural axioms or object-level assumptions are needed.

A convenient polynomial interpretation into `ℕ` is:

- `μ(void) = 0`
- `μ(delta t) = μ(t) + 1`
- `μ(integrate t) = μ(t) + 1`
- `μ(merge a b) = μ(a) + μ(b) + 1`
- `μ(app f x) = μ(f) + μ(x) + 1`
- `μ(eqW a b) = μ(a) + μ(b) + 3`
- `μ(recΔ b s n) = μ(b) + (μ(s) + 2) * (μ(n) + 1)`

Then every rewrite rule strictly decreases `μ`:

- `integrate (delta t) → void`:
  `μ = μ(t)+2 > 0`
- `merge void t → t`, `merge t void → t`:
  `μ = μ(t)+1 > μ(t)`
- `merge t t → t`:
  `2μ(t)+1 > μ(t)`
- `recΔ b s void → b`:
  `μ(b)+(μ(s)+2) > μ(b)`
- `recΔ b s (delta n) → app s (recΔ b s n)`:
  left minus right is exactly `1`
- `eqW a a → void`:
  `2μ(a)+3 > 0`
- `eqW a b → integrate (merge a b)`:
  `μ(a)+μ(b)+3 > μ(a)+μ(b)+2`

Since `ℕ` is well-founded, no infinite reduction sequence exists.

So: **strong normalization is establishable from this calculus alone**.
