Raw assessment  
Yes – strong (i.e. global) normalization can be proved for this rewrite system without adding any extra rules, side-conditions or external axioms.  A direct, completely syntactic proof can be given by orienting every rule with a single well-founded measure on traces, or with a simple multicomponent (lexicographic) measure, so that each rule strictly decreases that measure.  As every rule then lowers a natural number, no infinite reduction sequence is possible.

Sketch of the argument  

0.  Let |t|ₑ, |t|_δ, |t|ₘ denote respectively  
    • the number of occurrences of the constructor eqW in t,  
    • the number of occurrences of the constructor delta in t,  
    • the number of occurrences of the constructor merge in t.

   These three statistics are computable purely from the syntax.

1.  Define the global weight of a trace by  
        W(t)  =  3·|t|ₑ  +  2·|t|_δ  +  |t|ₘ.  
    (Any strictly positive weights with 3 > 2 > 1 would do; the above numbers just make all checks immediate.)

2.  Check every rule.

    • integrate (delta …) → void  
        removes one delta, removes one integrate, never introduces any of eqW/merge;  
        ΔW = −2  <  0.

    • merge void t    → t  
      merge t void    → t  
      merge t t       → t  
        all three cases eliminate exactly one merge and do not add any eqW or delta;  
        ΔW = −1  <  0.

    • recΔ b s void   → b  
        eliminates the whole recΔ-node but does not touch the weighted symbols;  
        ΔW = 0 on the weighted part, but length of the term strictly drops, so we could either
        (a) add a separate component “number of recΔ‐nodes”, or
        (b) keep the present weight and note that these two rules can only be fired finitely many
            times because after they are used the redex disappears.
        Either way, no loop is introduced.

    • recΔ b s (delta n)  →  app s (recΔ b s n)  
        removes one delta (weight −2) and introduces one app (weight 0);  
        ΔW = −2  <  0.

    • eqW a a        →  void  
        removes one eqW;  ΔW = −3  <  0.

    • eqW a b        →  integrate (merge a b)    (for a ≠ b or, syntactically, the catch-all rule)  
        removes one eqW (−3) and introduces one merge (+1);  
        ΔW = −2  <  0.

    Hence every single rewrite strictly decreases W(t).

3.  Since W(t) ∈ ℕ and is strictly lowered by every step, no infinite chain t₀ → t₁ → t₂ → ⋯ can exist; the reduction relation is therefore strongly normalizing.

4.  The argument is carried out entirely inside the object language:  
    – no appeal to any semantic interpretation,  
    – no use of additional axioms,  
    – only the given syntax and the eight rewrite rules are employed.

Conclusion  
All reduction sequences issued from any closed Trace term are finite; thus the calculus is strongly normalizing, and this fact can be proved from the supplied rules alone, with nothing further imported.
