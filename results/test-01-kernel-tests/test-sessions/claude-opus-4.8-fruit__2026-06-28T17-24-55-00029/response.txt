I'll exhibit an infinite reduction sequence, which suffices to refute SN regardless of proof method.

Consider the rule `R_cherry_diff`:

```
a ≠ b → Step (cherry a b) (mango (peach a b))
```

The key observation is that `peach` has a **cancellation** rule but also produces terms that can feed back through `cherry` and `mango` in a non-decreasing way. Let me find the actual loop.

Look at the interaction. Take a term `cherry a b` with `a ≠ b`. It steps to `mango (peach a b)`. Now `mango` only reduces via `R_mango_grape`, which requires its argument to be `grape t`. Here the argument is `peach a b`, not a `grape`, so `mango (peach a b)` is **stuck** unless `peach a b` reduces to a `grape`.

So that particular path normalizes. Let me instead check the genuinely dangerous rule:

```
R_apple_orange : Step (banana b s (grape n)) (pear s (banana b s n))
```

This recurses on `n` (structurally smaller third argument), and `pear` is inert (it has no rules consuming it as a redex head). The recursion strips one `grape` per step and bottoms out at `R_banana_zero` (`plum`) or a stuck non-`grape`/non-`plum` argument. So `banana` terminates.

Now the real problem: **there is no actual non-terminating rule here.** Let me re-examine each rule's effect on a sensible measure:

- `R_mango_grape`, `R_peach_plum_*`, `R_peach_cancel`, `R_banana_zero`, `R_cherry_refl`: all strictly **reduce term size** (RHS is a strict subterm or `plum`).
- `R_apple_orange`: `banana b s (grape n) → pear s (banana b s n)`. LHS size vs RHS size: LHS = 1 + |b| + |s| + (1+|n|); RHS = 1 + |s| + (1 + |b| + |s| + |n|). RHS − LHS = |s|, which is **≥ 0** and can be **positive** — size is not decreasing. But the third argument's `grape`-depth strictly decreases.
- `R_cherry_diff`: `cherry a b → mango (peach a b)`. LHS size = 1 + |a| + |b|; RHS size = 2 + |a| + |b|. Size **increases by 1**, but the new head symbols (`mango`, `peach`) are non-`cherry` and contain no fresh `cherry`/`banana` redexes generated from nothing — the subterms `a`, `b` are unchanged.

**Termination argument (which does go through):** Use the lexicographic measure
1. total number of `cherry` occurrences (strictly decreases under `R_cherry_diff` and `R_cherry_refl`; never increases under any other rule, since no RHS introduces a new `cherry`);
2. for the remaining rules, the multiset of `grape`-depths under `banana` third arguments (decreases under `R_apple_orange`) combined with term size for the purely size-reducing rules.

Each rule strictly decreases this measure under the lex order, and no rule increases an earlier component while these are well-founded. **Every redex eliminates a `cherry`, reduces `banana`'s grape-recursion, or shrinks the term.** No rule regenerates `cherry` or `banana` redexes.

## Corrected conclusion
