# Raw Assessment

**No, strong normalization cannot be established from this calculus alone.**

## Reasoning

The system contains a **non-terminating cycle**:

1. Consider the term `t = eqW void void`
2. By `R_eq_refl`: `eqW void void → void`
3. Now consider `u = eqW (delta void) (delta void)`
4. By `R_eq_refl`: `eqW (delta void) (delta void) → void`

However, the critical issue is with **`recΔ`**:

- `recΔ b s (delta n) → app s (recΔ b s n)` (by `R_rec_succ`)

If we have `recΔ b s (delta (delta (delta ...)))` (an infinite delta chain), the rewrite system will:
- Apply `R_rec_succ` to produce `app s (recΔ b s (delta (...)))`
- Apply `R_rec_succ` again to produce `app s (app s (recΔ b s (...)))`
- Continue indefinitely

**There is no rule that eliminates or bounds the accumulation of `app` applications**, and there is no structural termination metric that decreases under the rewrites. The system allows unbounded recursion depth without a base case guarantee in all reduction paths.

The base case `R_rec_zero` only fires on `void`, but there is nothing preventing infinite derivations on non-void structures. Standard techniques (lexicographic ordering on term structure, size-based metrics) fail because `R_rec_succ` increases the nesting of `app` without corresponding decreases elsewhere.

**Conclusion:** Without additional guards (e.g., restricted application domains, well-founded annotations, or explicit termination premises), strong normalization is not derivable from the presented rules alone.
