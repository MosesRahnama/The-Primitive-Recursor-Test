## Assessment: **Yes**, strong normalization is provable from the presented calculus alone.

The system is a first-order rewrite system with no binding, no contexts, and no overlap between the eight left-hand sides. Every term has at most one redex, so each reduction sequence is a deterministic chain. Showing SN reduces to exhibiting a well-founded measure `M : Trace → ℕ` that strictly decreases at every step.

### A suitable measure

Define `M : Trace → ℕ` structurally:

```
M(plum)              = 0
M(grape t)           = 1 + M(t)
M(mango t)           = M(t)                (* no contribution *)
M(peach t s)         = 1 + M(t) + M(s)
M(pear t s)          = 0                   (* pear is never a redex *)
M(banana b s n)      = 1 + M(b) + M(s) + M(n)
M(cherry a b)        = M(a) + M(b) + 2
```

A trivial structural induction gives `M(t) ≥ 0` for every term.

### Verification on every rule

| Rule | LHS value | RHS value | Decrease |
|------|-----------|-----------|----------|
| `R_mango_grape` | `M(grape t) = 1+M(t)` | `M(plum) = 0` | ✓ |
| `R_peach_plum_left` | `1+0+M(t)` | `M(t)` | ✓ |
| `R_peach_plum_right` | `1+M(t)+0` | `M(t)` | ✓ |
| `R_peach_cancel` | `1+2M(t)` | `M(t)` | ✓ |
| `R_banana_zero` | `1+M(b)+M(s)+0` | `M(b)` | ✓ |
| `R_apple_orange` | `1+M(b)+M(s)+1+M(n) = 2+M(b)+M(s)+M(n)` | `0 + 1+M(b)+M(s)+M(n) = 1+M(b)+M(s)+M(n)` | ✓ (drops by 1, the trick being `M(pear _ _) = 0`) |
| `R_cherry_refl` | `2M(a)+2` | `0` | ✓ |
| `R_cherry_diff` | `M(a)+M(b)+2` | `M(peach a b) = 1+M(a)+M(b)` | ✓ (drops by 1) |

The crucial point: rule 6 (`R_apple_orange`) appears to inflate size, but assigning `M(pear _ _) = 0` makes the cost of the wrapping `pear` zero; the only thing that grows is the "spine" of grapes being peeled, and that growth is offset by `M(mango _)` also being a no-op (used in rule 8).

### Conclusion

For every `(t, t')` with `Step t t'`, we have `M(t') < M(t)`. Since `ℕ` with the usual order is well-founded, no infinite reduction chain can exist. The proof uses only the inductive definition of `Trace`, the eight constructors of `Step`, and standard (constructive) well-foundedness of `ℕ` — no extra rewrite rules, side conditions, or external axioms are required.
