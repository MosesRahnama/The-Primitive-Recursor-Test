## Assessment: Strong Normalization is Establishable

**Yes**, strong normalization can be established from the presented calculus alone using standard proof methods.

### Reasoning

The system is a first-order term rewriting system with no variable binding. Strong normalization can be proven via a **lexicographic path ordering** or, more directly, a **polynomial interpretation** mapping terms to natural numbers that strictly decreases with each rewrite step.

Here's a sketch of a suitable interpretation `‖·‖ : Trace → ℕ`:

```
‖plum‖ = 1
‖grape t‖ = ‖t‖ + 2
‖mango t‖ = ‖t‖ + 1
‖peach t₁ t₂‖ = ‖t₁‖ + ‖t₂‖ + 1
‖pear t₁ t₂‖ = ‖t₁‖ + ‖t₂‖
‖banana b s n‖ = (‖b‖ + ‖s‖) · ‖n‖ + ‖b‖ + 1
‖cherry a b‖ = ‖a‖ + ‖b‖ + 3
```

**Verification of strict decrease for each rule:**

1. **R_mango_grape**: `‖mango (grape t)‖ = ‖t‖ + 3 > 1 = ‖plum‖` ✓

2. **R_peach_plum_left**: `‖peach plum t‖ = 1 + ‖t‖ + 1 = ‖t‖ + 2 > ‖t‖` ✓

3. **R_peach_plum_right**: `‖peach t plum‖ = ‖t‖ + 1 + 1 = ‖t‖ + 2 > ‖t‖` ✓

4. **R_peach_cancel**: `‖peach t t‖ = 2‖t‖ + 1 > ‖t‖` (since `‖t‖ ≥ 1`) ✓

5. **R_banana_zero**: `‖banana b s plum‖ = (‖b‖ + ‖s‖)·1 + ‖b‖ + 1 = 2‖b‖ + ‖s‖ + 1 > ‖b‖` ✓

6. **R_apple_orange** (banana/grape): 
   - LHS: `(‖b‖ + ‖s‖)·(‖n‖ + 2) + ‖b‖ + 1`
   - RHS: `‖s‖ + (‖b‖ + ‖s‖)·‖n‖ + ‖b‖ + 1`
   - Difference: `(‖b‖ + ‖s‖)·2 - ‖s‖ = 2‖b‖ + ‖s‖ > 0` ✓

7. **R_cherry_refl**: `‖cherry a a‖ = 2‖a‖ + 3 > 1 = ‖plum‖` ✓

8. **R_cherry_diff**: 
   - LHS: `‖a‖ + ‖b‖ + 3`
   - RHS: `‖mango (peach a b)‖ = ‖a‖ + ‖b‖ + 2`
   - Strictly decreases by 1 ✓

Since every rule strictly decreases a well-founded measure (natural numbers under `<`), and this interpretation extends to contexts by monotonicity of the constructors, **strong normalization holds**.

No external axioms, guards, or additional assumptions beyond the given syntax and rules are required.
