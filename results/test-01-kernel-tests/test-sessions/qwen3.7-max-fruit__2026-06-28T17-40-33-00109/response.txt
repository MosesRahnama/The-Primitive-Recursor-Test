## Assessment

**Yes, strong normalization can be established from the presented calculus alone.**

## Reasoning

The standard method of **polynomial interpretation** over the positive integers suffices. Define the interpretation ⟦·⟧ as follows:

| Constructor | Interpretation |
|---|---|
| `plum` | `1` |
| `grape(x)` | `x + 1` |
| `mango(x)` | `x + 1` |
| `peach(x, y)` | `x + y + 1` |
| `pear(x, y)` | `x + y` |
| `banana(x, y, z)` | `x + y·z + z + 1` |
| `cherry(x, y)` | `x + y + 3` |

**Well-definedness:** Every term maps to an integer ≥ 1, and every constructor is strictly monotone in all arguments over ℕ⁺ (e.g., `banana` has partial derivatives 1, z ≥ 1, and y + 1 ≥ 2).

**Every rule strictly decreases the interpretation:**

1. **`mango (grape t) → plum`**: (t+1)+1 = t+2 > 1 ✓
2. **`peach plum t → t`**: 1+t+1 = t+2 > t ✓
3. **`peach t plum → t`**: t+1+1 = t+2 > t ✓
4. **`peach t t → t`**: 2t+1 > t ✓
5. **`banana b s plum → b`**: b+s·1+1+1 = b+s+2 > b ✓
6. **`banana b s (grape n) → pear s (banana b s n)`**:
   - LHS = b + s(n+1) + (n+1) + 1 = b + sn + s + n + 2
   - RHS = s + (b + sn + n + 1) = b + sn + s + n + 1
   - LHS − RHS = **1** > 0 ✓
7. **`cherry a a → plum`**: 2a+3 > 1 ✓
8. **`cherry a b → mango (peach a b)`**:
   - LHS = a+b+3
   - RHS = (a+b+1)+1 = a+b+2
   - LHS − RHS = **1** > 0 ✓

Since the interpretation maps into ℕ⁺ (well-founded under >), is compatible with all contexts (by strict monotonicity), and strictly decreases at every rewrite step, no infinite reduction sequence can exist. Strong normalization follows directly—no extra rules, guards, side conditions, or external axioms are needed.

The critical design choice is the multiplicative term `y·z` in the `banana` interpretation, which absorbs the duplication of `s` in rule 6, and the elevated constant (+3) on `cherry`, which absorbs the `mango(peach …)` expansion in rule 8.
