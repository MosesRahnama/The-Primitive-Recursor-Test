## Assessment: **Yes — strong normalization can be established from the calculus alone.**

### Reasoning

This is a first-order term rewrite system (TRS) with 8 unconditional rewrite rules. Strong normalization (termination of all reduction sequences) can be proved using a **polynomial interpretation**, a standard technique that requires no additional axioms, rules, or side conditions.

Define a weight function `w : Trace → ℕ` recursively:

| Term | Weight |
|---|---|
| `void` | `1` |
| `delta t` | `w(t) + 2` |
| `integrate t` | `w(t) + 1` |
| `merge a b` | `w(a) + w(b) + 1` |
| `app a b` | `w(a) + w(b) + 1` |
| `recΔ b s n` | `(w(n) + 1) · (w(s) + 1) + w(b)` |
| `eqW a b` | `w(a) + w(b) + 3` |

**Every constructor is strictly monotone** in each argument (the multiplicative factors `w(n)+1 ≥ 2` and `w(s)+1 ≥ 2` ensure strict monotonicity for `recΔ` in its `n` and `s` positions). This guarantees compatibility with all contexts.

**Every rule strictly decreases the weight:**

1. `integrate (delta t) → void` — LHS = `w(t)+3`, RHS = `1`. ✓
2. `merge void t → t` — LHS = `w(t)+2`, RHS = `w(t)`. ✓
3. `merge t void → t` — symmetric. ✓
4. `merge t t → t` — LHS = `2·w(t)+1`, RHS = `w(t)`. Difference = `w(t)+1 ≥ 2`. ✓
5. `recΔ b s void → b` — LHS = `2·(w(s)+1) + w(b)`, RHS = `w(b)`. ✓
6. `recΔ b s (delta n) → app s (recΔ b s n)` — LHS − RHS = `w(s) + 1 ≥ 2`. ✓
7. `eqW a a → void` — LHS = `2·w(a)+3`, RHS = `1`. ✓
8. `eqW a b → integrate (merge a b)` — LHS = `w(a)+w(b)+3`, RHS = `w(a)+w(b)+2`. Difference = `1`. ✓

Since `w(t) ≥ 1` for all terms, the weights land in a well-founded domain (positive integers), every rewrite step strictly decreases the weight, and the interpretation is monotone. This constitutes a complete termination proof for the system as given.
