## Assessment: Yes, strong normalization can be established.

### Reasoning

The system is strongly normalizing, provable via a **polynomial interpretation** — a standard termination proof technique that requires no added rules, guards, or assumptions.

Define a weight function `⟦·⟧` from terms to positive integers:

| Term | Weight |
|---|---|
| `void` | `1` |
| `delta t` | `2 + ⟦t⟧` |
| `integrate t` | `1 + ⟦t⟧` |
| `merge t₁ t₂` | `1 + ⟦t₁⟧ + ⟦t₂⟧` |
| `app t₁ t₂` | `2 + ⟦t₁⟧ + ⟦t₂⟧` |
| `recΔ b s n` | `(1 + ⟦s⟧) · ⟦n⟧ + ⟦b⟧` |
| `eqW a b` | `3 + ⟦a⟧ + ⟦b⟧` |

This function is strictly monotone in every subterm position, so rewriting at any depth decreases the weight. Checking each rule:

1. **`integrate (delta t) → void`**: `3 + ⟦t⟧ > 1` ✓
2. **`merge void t → t`**: `2 + ⟦t⟧ > ⟦t⟧` ✓
3. **`merge t void → t`**: same ✓
4. **`merge t t → t`**: `1 + 2⟦t⟧ > ⟦t⟧` ✓
5. **`recΔ b s void → b`**: `1 + ⟦s⟧ + ⟦b⟧ > ⟦b⟧` ✓
6. **`recΔ b s (delta n) → app s (recΔ b s n)`**: LHS − RHS = `⟦s⟧ ≥ 1 > 0` ✓
7. **`eqW a a → void`**: `3 + 2⟦a⟧ > 1` ✓
8. **`eqW a b → integrate (merge a b)`**: `3 + ⟦a⟧ + ⟦b⟧ > 2 + ⟦a⟧ + ⟦b⟧` ✓

Every rule strictly decreases the weight at the root, and monotonicity ensures this lifts to rewriting in any context. Since the weights are positive integers (a well-founded set), no infinite reduction sequence exists.

**Key design insight**: The multiplicative structure `(1 + ⟦s⟧) · ⟦n⟧` in `recΔ` absorbs the duplication of `s` in rule 6 (each step consumes one `delta` from the decreasing third argument), while the extra additive constant on `eqW` (weight 3 vs. combined `integrate`+`merge` weight 2) absorbs the size increase in rule 8.
