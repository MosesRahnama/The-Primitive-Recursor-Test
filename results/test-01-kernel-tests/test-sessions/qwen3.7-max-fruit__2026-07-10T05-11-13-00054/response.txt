### Proof via Polynomial Interpretation

Strong normalization is provable using a standard polynomial interpretation over $\mathbb{N}$. Assign each constructor the following interpretation:

| Constructor | Interpretation |
|---|---|
| `plum` | $1$ |
| `grape(x)` | $x + 1$ |
| `mango(x)` | $x + 1$ |
| `peach(x, y)` | $x + y + 1$ |
| `pear(x, y)` | $x + y + 1$ |
| `banana(x, y, z)` | $(y + 3)(z^2 + 1) + x + z$ |
| `cherry(x, y)` | $x + y + 3$ |

**Strict monotonicity** holds for every constructor in every argument. The critical case is `banana`: the partial derivative w.r.t. $y$ is $z^2 + 1 \geq 1 > 0$, and w.r.t. $z$ is $2(y+3)z + 1 \geq 1 > 0$.

**Every rule strictly decreases the interpretation** (for all variable assignments over $\mathbb{N}$):

| Rule | LHS $-$ RHS |
|---|---|
| `mango(grape t) → plum` | $(t+2) - 1 = t + 1 > 0$ |
| `peach plum t → t` | $(t+2) - t = 2 > 0$ |
| `peach t plum → t` | $(t+2) - t = 2 > 0$ |
| `peach t t → t` | $(2t+1) - t = t + 1 > 0$ |
| `banana b s plum → b` | $(2s + b + 7) - b = 2s + 7 > 0$ |
| `banana b s (grape n) → pear s (banana b s n)` | $n(2s + 6) + 3 \geq 3 > 0$ |
| `cherry a a → plum` | $(2a+3) - 1 = 2a + 2 > 0$ |
| `cherry a b → mango(peach a b)` | $(a+b+3) - (a+b+2) = 1 > 0$ |

The key difficulty is **rule 6** (`banana b s (grape n) → pear s (banana b s n)`), which duplicates `s` and can increase the term size and the total number of `grape`/`banana` constructors. The quadratic factor $z^2$ in `banana`'s interpretation absorbs this duplication: the LHS evaluates at $z = n+1$ while the RHS embeds `banana` at $z = n$, and the difference $(y+3)((n+1)^2 + 1) - [(y+3)(n^2+1) + y + 1] = n(2y+6) + 3$ is always positive.

Since all constructors are strictly monotone and every rewrite rule (including its contextual closure) strictly decreases the interpretation into $\mathbb{N}$, no infinite reduction sequence can exist. **The system is strongly normalizing.**
