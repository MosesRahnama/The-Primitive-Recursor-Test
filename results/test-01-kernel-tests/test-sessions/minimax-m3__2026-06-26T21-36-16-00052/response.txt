## Assessment: **Yes**, strong normalization can be established from the calculus alone, using a standard polynomial-interpretation / natural-number measure. No extra rewrite rules, guards, or hidden assumptions are required.

## Reasoning

Because the `Step` rules in the file form a (left-linear) first-order TRS with no free variables, a single recursive function `μ : Trace → ℕ` that strictly decreases under every rule gives SN immediately, since `ℕ` is well-founded. Such a measure exists:

```
μ(void)              = 0
μ(delta t)           = μ(t) + 1
μ(integrate t)       = μ(t)
μ(merge t1 t2)       = μ(t1) + μ(t2) + 1
μ(app t1 t2)         = μ(t1) + μ(t2) + 1
μ(recΔ b s n)        = (δcount(n) + 1) · (μ(s) + μ(b) + 2)
μ(eqW a b)           = μ(a) + μ(b) + 2
```

where `δcount` is the number of leading `delta`s (with `δcount(void) = 0` and `δcount(_)=0` for any non-`delta` head). All cases are well-defined by structural recursion on the term.

### Verification against every rule

Let `X = μ(s)`, `Y = μ(b)` for brevity. Writing `L → R` as `μ(L) > μ(R)`:

1. `integrate (delta t) → void` : `μ(t)+1 > 0` ✓
2. `merge void t → t` : `μ(t)+1 > μ(t)` ✓
3. `merge t void → t` : `μ(t)+1 > μ(t)` ✓
4. `merge t t → t` : `2μ(t)+1 > μ(t)` ✓
5. `recΔ b s void → b` : `(X+Y+2) > Y` since `X+2 > 0` ✓
6. `recΔ b s (delta n) → app s (recΔ b s n)` :

   LHS = `(δcount(n)+2)(X+Y+2)`,
   RHS = `X + (δcount(n)+1)(X+Y+2) + 1`,
   LHS − RHS = `Y + 1 > 0` ✓

7. `eqW a a → void` : `2μ(a)+2 > 0` ✓
8. `eqW a b → integrate (merge a b)` : `μ(a)+μ(b)+2 > μ(a)+μ(b)+1` ✓

Every rule strictly decreases `μ`. There is no overlap issue to resolve for SN (only for confluence, and SN does not require confluence). Hence any reduction sequence is finite, so the system is strongly normalizing.

### Where the trickiness sits — and why it is resolved

The only rule that is not "size-decreasing in the obvious sense" is the recursor:

```
recΔ b s (delta n)  ⟶  app s (recΔ b s n)
```

The RHS is structurally larger (an extra `app` and an extra `s`), so a plain size measure fails. The fix is to give `recΔ` a measure that depends on `δcount(n)` — the recursion counter — and the trick `μ(recΔ b s n) = (δcount(n)+1)(μ(s)+μ(b)+2)` is the smallest natural-number weighting that simultaneously:

* forces `recΔ b s void → b` to drop (factor `1` vs. `Y`),
* forces the rec-step to drop by exactly `μ(b)+1`, which is strictly positive regardless of `s` (including the awkward case `s = void`),
* leaves all the other rules decreasing in the same measure.

This is the classical "weight the recursor by the size of the structural argument" trick; nothing about the system forces one to strengthen it, add side conditions, or import anything beyond the syntax and rules shown.
