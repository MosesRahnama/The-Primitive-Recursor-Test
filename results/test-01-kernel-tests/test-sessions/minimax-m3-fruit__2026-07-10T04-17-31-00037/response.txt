## Assessment

**Yes.** Strong normalization of this system can be established from the rules alone, using a standard polynomial interpretation. No extra axioms, guards, or side conditions beyond the side condition `a ≠ b` already present in `R_cherry_diff` are required.

### Why a naive size measure fails

A simple constructor-counting size doesn't work, because two rules can increase size:

- `R_apple_orange`: `banana b s (grape n) → pear s (banana b s n)` — the right-hand side re‑emits `s` inside the surviving banana, growing the term.
- `R_cherry_diff`: `cherry a b → mango (peach a b)` — replaces one binary constructor with two.

So you need a weighted interpretation, not raw size.

### A working polynomial interpretation

Assign to each constructor a polynomial in the interpretation of its arguments (values in ℕ, all coefficients non‑negative):

| symbol | arity | interpretation |
|---|---|---|
| `plum` | 0 | `0` |
| `grape(x)` | 1 | `x + 1` |
| `mango(x)` | 1 | `x + 1` |
| `peach(x,y)` | 2 | `x + y + 1` |
| `pear(x,y)` | 2 | `y + 1` |
| `banana(x,y,z)` | 3 | `2x + 3y + 2z + 1` |
| `cherry(x,y)` | 2 | `x + y + 3` |

Now check each rule `⟦LHS⟧ > ⟦RHS⟧`:

1. `mango(grape t) → plum`: `⟦t⟧+2 > 0` ✓
2. `peach plum t → t`: `⟦t⟧+1 > ⟦t⟧` ✓
3. `peach t plum → t`: `⟦t⟧+1 > ⟦t⟧` ✓
4. `peach t t → t`: `2⟦t⟧+1 > ⟦t⟧` ✓
5. `banana b s plum → b`: `2⟦b⟧+3⟦s⟧+1 > ⟦b⟧` ✓
6. `banana b s (grape n) → pear s (banana b s n)`: `2⟦b⟧+3⟦s⟧+2⟦n⟧+3 > (2⟦b⟧+3⟦s⟧+2⟦n⟧+1)+1` (difference = 1) ✓
   (The trick: `pear` is interpreted as `y+1`, ignoring the first argument. This neutralises the duplication of `s`.)
7. `cherry a a → plum`: `2⟦a⟧+3 > 0` ✓
8. `cherry a b → mango (peach a b)` (a≠b): `⟦a⟧+⟦b⟧+3 > ⟦a⟧+⟦b⟧+2` ✓ (no need to use the `a≠b` premise; the additive constant 3 makes it strict unconditionally)

### Consequence

Every rule strictly decreases a value in the well‑founded order `(ℕ, >)`. Hence any reduction sequence from a term `t` has length strictly less than `⟦t⟧`, so it must terminate. This is a meta‑level argument (a standard polynomial‑order proof), not an addition to the object calculus; it uses only the rewrite rules as given.

**Conclusion:** the system is strongly normalising on the basis of the presented rules alone.
