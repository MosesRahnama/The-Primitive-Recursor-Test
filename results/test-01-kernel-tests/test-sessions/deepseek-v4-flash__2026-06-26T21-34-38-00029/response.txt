Yes. Strong normalization can be established using only the given syntax and rewrite rules, without adding any extra axioms or side conditions.  

**Reasoning**  
The rewrite relation `Step` is defined directly by a finite set of patterns, with *no closure under contexts* (reduction is allowed only at the root of a term). For each rule we examine the head constructor of the right‑hand side:  

- `R_int_delta`, `R_eq_refl` → `void` (no rule for `void`)  
- `R_merge_void_left`, `R_merge_void_right`, `R_merge_cancel` → the subterm `t` (size strictly smaller than the left‑hand side)  
- `R_rec_zero` → the subterm `b` (size strictly smaller)  
- `R_rec_succ` → `app s (recΔ b s n)` (head `app`, which has no rewrite rule)  
- `R_eq_diff` → `integrate (merge a b)` (head `integrate`, but its argument is `merge a b`, which is not `delta …`; no rule applies)  

Thus any reduction step either:  
1. replaces a term by a proper subterm (all cases except `R_rec_succ`), which strictly reduces the number of constructors, or  
2. produces a term whose head constructor is `app` or `integrate` with a non‑`delta` argument, which is immediately a normal form because no rule matches.  

Consequently, every reduction sequence is finite: the only way to have more than one step is when a rule of type (1) yields a term that itself matches a rule at the root, but that term is a subterm of the original, so the size decreases. There is no possibility of an infinite descending chain because the term structure is finite and each step either reduces size or ends the reduction. Therefore the system is strongly normalizing.
