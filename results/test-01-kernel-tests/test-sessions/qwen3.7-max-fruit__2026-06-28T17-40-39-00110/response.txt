## Assessment: **Yes — strong normalization is provable from the calculus alone.**

### Proof via Polynomial Interpretation

Strong normalization can be established by exhibiting a **monotone polynomial interpretation** into the positive integers such that every rewrite rule strictly decreases the interpretation. Define ⟦·⟧ recursively:

| Constructor | Interpretation |
|---|---|
| `plum` | `1` |
| `grape(t)` | `⟦t⟧ + 1` |
| `mango(t)` | `⟦t⟧ + 1` |
| `peach(a, b)` | `⟦a⟧ + ⟦b⟧ + 1` |
| `pear(a, b)` | `⟦a⟧ + ⟦b⟧` |
| `banana(b, s, n)` | `⟦b⟧ + ⟦s⟧·(⟦n⟧ + 1) + ⟦n⟧ + 1` |
| `cherry(a, b)` | `2·(⟦a⟧ + ⟦b⟧) + 3` |

All constructors are strictly monotone in each argument, and every term evaluates to a value ≥ 1.

### Verification of each rule (LHS − RHS)

1. **`mango(grape t) → plum`**: LHS = ⟦t⟧ + 2, RHS = 1. Diff ≥ 2. ✓
2. **`peach plum t → t`**: LHS = ⟦t⟧ + 2, RHS = ⟦t⟧. Diff = 2. ✓
3. **`peach t plum → t`**: Symmetric. Diff = 2. ✓
4. **`peach t t → t`**: LHS = 2⟦t⟧ + 1, RHS = ⟦t⟧. Diff = ⟦t⟧ + 1 ≥ 2. ✓
5. **`banana b s plum → b`**: LHS = ⟦b⟧ + 2⟦s⟧ + 2, RHS = ⟦b⟧. Diff = 2⟦s⟧ + 2 ≥ 4. ✓
6. **`banana b s (grape n) → pear s (banana b s n)`**:
   - LHS = ⟦b⟧ + ⟦s⟧(⟦n⟧+2) + ⟦n⟧ + 2
   - RHS = ⟦s⟧ + ⟦b⟧ + ⟦s⟧(⟦n⟧+1) + ⟦n⟧ + 1
   - Diff = ⟦s⟧·1 − ⟦s⟧ + 1 = **1**. ✓
7. **`cherry a a → plum`**: LHS = 4⟦a⟧ + 3, RHS = 1. Diff ≥ 6. ✓
8. **`cherry a b → mango(peach a b)`** (a ≠ b):
   - LHS = 2(⟦a⟧+⟦b⟧) + 3
   - RHS = ⟦a⟧ + ⟦b⟧ + 2
   - Diff = ⟦a⟧ + ⟦b⟧ + 1 ≥ 3. ✓

### Why this suffices

Every rule strictly decreases the measure, and monotonicity of every constructor guarantees that rewriting at any depth (compatible closure) also strictly decreases the measure. Since the measure maps into ℕ⁺, which is well-founded under `>`, **no infinite reduction sequence exists**. No external axioms, guards, or additional rules are needed — the proof uses only the syntax and rewrite rules as given.
