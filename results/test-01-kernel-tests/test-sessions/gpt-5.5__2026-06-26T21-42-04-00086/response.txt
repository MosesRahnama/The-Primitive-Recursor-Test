Yes. Strong normalization can be established from the presented oriented rules alone.

A simple polynomial interpretation into `Nat` gives a termination measure. For example define:

```text
⟦void⟧              = 0
⟦delta t⟧           = ⟦t⟧ + 1
⟦integrate t⟧       = ⟦t⟧ + 1
⟦merge a b⟧         = ⟦a⟧ + ⟦b⟧ + 1
⟦app a b⟧           = ⟦a⟧ + ⟦b⟧
⟦recΔ b s n⟧        = ⟦b⟧ + ⟦s⟧ + ⟦n⟧ * (⟦s⟧ + 1) + 1
⟦eqW a b⟧           = ⟦a⟧ + ⟦b⟧ + 3
```

Then every displayed rewrite rule strictly decreases this measure:

```text
integrate (delta t)        ↦ void
t + 2                      > 0

merge void t               ↦ t
t + 1                      > t

merge t void               ↦ t
t + 1                      > t

merge t t                  ↦ t
2t + 1                     > t

recΔ b s void              ↦ b
b + s + 1                  > b

recΔ b s (delta n)         ↦ app s (recΔ b s n)
b + 2s + n(s+1) + 2        > b + 2s + n(s+1) + 1

eqW a a                    ↦ void
2a + 3                     > 0

eqW a b                    ↦ integrate (merge a b)
a + b + 3                  > a + b + 2
```

The interpretation is also strictly monotone in subterms, so the same argument works for the ordinary contextual closure of these rewrite rules, if that is what is meant by rewriting.

The rule

```lean
R_eq_diff : ∀ a b, Step (eqW a b) (integrate (merge a b))
```

has no disequality side condition, so it overlaps with `R_eq_refl`; that may affect confluence, but not termination. Likewise `R_rec_succ` can increase syntactic size because it duplicates `s`, but the above measure still decreases.

So, within the boundary of the given syntax and oriented rewrite rules, and without adding associativity/commutativity, quotienting, inverse rules, guards, or object-level axioms, strong normalization is establishable.
