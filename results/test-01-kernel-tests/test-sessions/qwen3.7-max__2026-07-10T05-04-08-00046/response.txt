## Assessment: **Yes, strong normalization can be established.**

### Proof via Polynomial Interpretation

The system is strongly normalizing. This can be proven by exhibiting a **monotone polynomial interpretation** into the positive integers that strictly decreases with every rewrite step.

Define the interpretation `⟦·⟧` as:

| Term | Interpretation |
|---|---|
| `void` | `1` |
| `delta t` | `⟦t⟧ + 1` |
| `integrate t` | `⟦t⟧ + 1` |
| `merge t₁ t₂` | `⟦t₁⟧ + ⟦t₂⟧ + 1` |
| `app t₁ t₂` | `⟦t₁⟧ + ⟦t₂⟧ + 1` |
| `eqW t₁ t₂` | `⟦t₁⟧ + ⟦t₂⟧ + 3` |
| `recΔ b s t` | `⟦b⟧ + ⟦s⟧ · ⟦t⟧² + ⟦t⟧ + 1` |

Every term maps to an integer ≥ 1. Monotonicity holds because every argument position contributes with a positive coefficient (for `recΔ`'s third argument, the derivative `2·⟦s⟧·⟦t⟧ + 1 ≥ 3 > 0`).

### Verification of all rules

Let `B = ⟦b⟧, S = ⟦s⟧, N = ⟦n⟧, A = ⟦a⟧`. All are ≥ 1.

| Rule | LHS | RHS | Difference |
|---|---|---|---|
| `integrate (delta t) → void` | `⟦t⟧ + 2` | `1` | `⟦t⟧ + 1 ≥ 2` |
| `merge void t → t` | `⟦t⟧ + 2` | `⟦t⟧` | `2` |
| `merge t void → t` | `⟦t⟧ + 2` | `⟦t⟧` | `2` |
| `merge t t → t` | `2⟦t⟧ + 1` | `⟦t⟧` | `⟦t⟧ + 1 ≥ 2` |
| `recΔ b s void → b` | `B + S + 2` | `B` | `S + 2 ≥ 3` |
| **`recΔ b s (delta n) → app s (recΔ b s n)`** | `B + S(N+1)² + N + 2` | `B + S·N² + S + N + 2` | **`2SN ≥ 2`** |
| `eqW a a → void` | `2A + 3` | `1` | `2A + 2 ≥ 4` |
| `eqW a b → integrate (merge a b)` | `A + B + 3` | `A + B + 2` | `1` |

The critical rule is `R_rec_succ` (rule 6), which duplicates `s`. The quadratic dependence `⟦s⟧·⟦t⟧²` absorbs this: expanding `S(N+1)² − SN² = S(2N+1)`, and subtracting the remaining RHS terms `S + N + 2 − (N + 2)` leaves exactly `2SN`, which is strictly positive.

### Conclusion

Since every rule strictly decreases a monotone interpretation into the well-founded domain ℕ₊, no infinite rewrite sequence can exist. Strong normalization follows from the calculus alone with no additional axioms, side conditions, or guards.
