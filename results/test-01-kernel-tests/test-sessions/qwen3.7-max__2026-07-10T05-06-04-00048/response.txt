## Assessment: **Yes, strong normalization can be established.**

### Method: Polynomial Interpretation over ℕ₊

A polynomial interpretation assigns each term a positive integer such that every rewrite rule strictly decreases the value, and every constructor is (strictly) monotone in each argument. This directly implies strong normalization (even under the compatible closure / reduction in arbitrary contexts), since there are no infinite descending chains in ℕ.

### Interpretation

| Constructor | Interpretation |
|---|---|
| `void` | `1` |
| `delta(t)` | `⟦t⟧ + 1` |
| `integrate(t)` | `⟦t⟧` |
| `merge(t₁, t₂)` | `⟦t₁⟧ + ⟦t₂⟧` |
| `app(t₁, t₂)` | `⟦t₁⟧ + ⟦t₂⟧` |
| `recΔ(b, s, n)` | `⟦b⟧ + ⟦s⟧·⟦n⟧ + ⟦n⟧` |
| `eqW(a, b)` | `⟦a⟧ + ⟦b⟧ + 1` |

All constructors are strictly monotone in every argument (for `recΔ`: partial derivatives are 1, n≥1, and s+1≥2 respectively).

### Rule-by-rule verification (all variables ≥ 1)

1. **`integrate (delta t) → void`**: LHS = `⟦t⟧+1 ≥ 2`, RHS = `1`. ✓
2. **`merge void t → t`**: LHS = `1+⟦t⟧`, RHS = `⟦t⟧`. ✓
3. **`merge t void → t`**: same as 2. ✓
4. **`merge t t → t`**: LHS = `2·⟦t⟧`, RHS = `⟦t⟧`. Strict since `⟦t⟧ ≥ 1`. ✓
5. **`recΔ b s void → b`**: LHS = `⟦b⟧+⟦s⟧+1`, RHS = `⟦b⟧`. Strict since `⟦s⟧ ≥ 1`. ✓
6. **`recΔ b s (delta n) → app s (recΔ b s n)`**:
   - LHS = `⟦b⟧ + ⟦s⟧·(⟦n⟧+1) + (⟦n⟧+1)` = `⟦b⟧ + ⟦s⟧·⟦n⟧ + ⟦s⟧ + ⟦n⟧ + 1`
   - RHS = `⟦s⟧ + ⟦b⟧ + ⟦s⟧·⟦n⟧ + ⟦n⟧`
   - Difference = **1** > 0. ✓
7. **`eqW a a → void`**: LHS = `2·⟦a⟧+1 ≥ 3`, RHS = `1`. ✓
8. **`eqW a b → integrate (merge a b)`**: LHS = `⟦a⟧+⟦b⟧+1`, RHS = `⟦a⟧+⟦b⟧`. Difference = **1** > 0. ✓

### Key observations

- **Rule 6** is the only rule that duplicates a subterm (`s`), which is why the multiplicative term `⟦s⟧·⟦n⟧` in the interpretation of `recΔ` is needed. Each step strips one `delta` (decreasing `⟦n⟧` by 1), which "pays" for the duplication of `s` with a surplus of exactly 1.
- **Rule 8** increases the term's syntactic size but the interpretation accounts for it via the `+1` in `eqW`'s weight.
- The overlap between rules 7 and 8 (when `a = b`) is harmless: both strictly decrease the measure.

No extra axioms, guards, side conditions, or structural assumptions are required.
