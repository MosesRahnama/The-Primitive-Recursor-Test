**Reasoning:**  
The eight rewrite rules are all “size‑decreasing” under a suitable monotone polynomial interpretation into the natural numbers, defined by structural recursion on `Trace`:

* `|plum| = 2`
* `|grape t| = |t| + 1`
* `|mango t| = |t| + 1`
* `|peach t₁ t₂| = |t₁| + |t₂| + 1`
* `|pear t₁ t₂| = |t₁| + |t₂|`
* `|banana t₁ t₂ t₃| = |t₁| · |t₂| · |t₃|`
* `|cherry t₁ t₂| = |t₁| + |t₂| + 4`

Because every constructor has positive coefficient, this map is strictly monotone in every argument, so any reduction inside a context lowers the overall value.  One checks directly that for each rule `l → r` we have `|l| > |r|`:

* `mango (grape t) → plum`: `|t| + 2 > 2`
* `peach plum t → t`: `|t| + 3 > |t|`
* `peach t plum → t`: `|t| + 3 > |t|`
* `peach t t → t`: `2|t| + 1 > |t|`
* `banana b s plum → b`: `2·|b|·|s| > |b|`
* `banana b s (grape n) → pear s (banana b s n)`:  
  `|b|·|s|·(|n|+1) = |s|·(|b|·|n| + |b|) > |s|·(|b|·|n| + 1)` because `|b| ≥ 2`
* `cherry a a → plum`: `2|a| + 4 > 2`
* `cherry a b → mango (peach a b)`: `|a|+|b|+4 > |a|+|b|+2`

Since `<` on `ℕ` is well‑founded, no infinite `Step` sequence exists.  The side condition `a ≠ b` is irrelevant for termination: the unconditional version of the rule is already decreasing.
