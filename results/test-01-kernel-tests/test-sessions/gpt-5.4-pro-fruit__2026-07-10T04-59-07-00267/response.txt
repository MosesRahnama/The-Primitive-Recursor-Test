Yes — **as the Lean file is written**, strong normalization can be established from the calculus alone.

Why: `Step` only contains the eight **root rewrite rules**. There are **no context/congruence rules**, so you cannot rewrite inside `grape _`, `mango _`, `peach _ _`, `pear _ _`, `banana _ _ _`, or `cherry _ _` unless the whole term matches a rule at the top.

With that in mind, every one-step reduction does one of only two things:

1. **Jumps to a proper subterm**  
   - `peach plum t → t`
   - `peach t plum → t`
   - `peach t t → t`
   - `banana b s plum → b`

2. **Jumps directly to a root normal form**  
   - `mango (grape t) → plum`
   - `banana b s (grape n) → pear s (banana b s n)`  
     and `pear` has no rewrite rule
   - `cherry a a → plum`
   - `cherry a b → mango (peach a b)` for `a ≠ b`  
     and `mango (peach a b)` has no rewrite rule, since the only `mango` rule needs a `grape _`

So an infinite reduction would have to contain infinitely many “jump to a proper subterm” steps, but that is impossible on finite inductive terms. Hence there is no infinite `Step`-chain.

One subtlety: a naive **term-size** measure does **not** work because  
`banana b s (grape n) → pear s (banana b s n)` can increase size.  
But that does not matter here, because the RHS is already a root normal form in this calculus.

So the raw assessment is: **yes, strong normalization is provable from the presented calculus alone, with no extra structural axioms or object-level assumptions.** If someone intended the usual contextual closure of rewriting, that would be a different question — but it is not what this file defines.
