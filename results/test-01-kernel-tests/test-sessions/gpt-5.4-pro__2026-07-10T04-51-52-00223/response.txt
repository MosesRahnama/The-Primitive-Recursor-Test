Yes.

A direct strong-normalization proof is available from the rules as given, with no extra axioms or side conditions. The nontrivial point is that `R_rec_succ` can increase raw term size, so a plain “term size decreases” argument does **not** work. But a standard polynomial interpretation does.

One suitable interpretation into `ℕ` is:

- `⟦void⟧ = 0`
- `⟦delta t⟧ = ⟦t⟧ + 1`
- `⟦integrate t⟧ = ⟦t⟧`
- `⟦merge t u⟧ = ⟦t⟧ + ⟦u⟧ + 1`
- `⟦app t u⟧ = ⟦t⟧ + ⟦u⟧`
- `⟦eqW t u⟧ = ⟦t⟧ + ⟦u⟧ + 2`
- `⟦recΔ b s n⟧ = ⟦b⟧ + (⟦n⟧ + 1)(⟦s⟧ + 1) + 1`

Then every rewrite rule strictly decreases this measure. For example:

- `integrate (delta t) → void`:
  `⟦t⟧ + 1 > 0`
- `merge void t → t`, `merge t void → t`, `merge t t → t`:
  all strictly decrease
- `recΔ b s void → b`:
  `⟦b⟧ + ⟦s⟧ + 2 > ⟦b⟧`
- `recΔ b s (delta n) → app s (recΔ b s n)`:
  the left side exceeds the right by exactly `1`
- `eqW a a → void` and `eqW a b → integrate (merge a b)`:
  both strictly decrease

So there is a well-founded descending measure for every step. Hence there can be no infinite reduction sequence.

One caveat only for terminology: if you mean the literal `Step` relation exactly as written, it is only root reduction, and termination is even easier. But the stronger, standard first-order TRS reading with closure under contexts is also covered by the interpretation above.

So the raw assessment is: **yes, strong normalization is provable from this calculus alone.** Non-confluence may still be present (because `eqW a a` matches both equality rules), but that does not affect strong normalization.
