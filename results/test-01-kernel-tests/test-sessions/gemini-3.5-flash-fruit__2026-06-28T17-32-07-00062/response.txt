* Without congruence rules, rewrites can only occur at the root of the term.
* Because the right-hand sides of the rules do not construct new root-level redexes in a cyclic manner, any sequence of root-level reductions must terminate in at most a few steps. Thus, strong normalization is trivially provable for the literal relation `Step`.

### 2. Standard Term Rewriting Interpretation (With Congruence/Context Rules)
Even if we assume the standard closure under contexts (i.e., allowing rewrites inside subterms), the system remains strongly normalizing. This can be formally proven using a standard **Lexicographic Path Ordering (LPO)** with the following precedence on the constructors:

$$\text{cherry} \succ \text{mango} \succ \text{peach}$$
$$\text{banana} \succ \text{pear}$$
$$\text{banana} \succ \text{grape} \succ \text{plum}$$

Under this precedence, every rewrite rule strictly decreases the term:
* **Projections/Reductions** (`R_peach_plum_left`, `R_peach_plum_right`, `R_peach_cancel`, `R_banana_zero`, `R_cherry_refl`): These rules project to a strict subterm or a smaller constant, which strictly decreases the term under any path ordering.
* **`R_mango_grape`**: `mango (grape t)` reduces to the constant `plum`, which is smaller in the precedence.
* **`R_apple_orange`**: `banana b s (grape n) → pear s (banana b s n)`

* **`R_cherry_diff`**: `cherry a b → mango (peach a b)`
  * Since $\text{cherry} \succ \text{mango}$ and $\text{cherry} \succ \text{peach}$, and the arguments $a, b$ are retained, this is a strict decrease.

Because the LPO is a well-founded strict partial order on terms that is compatible with contexts, the existence of this compatible ordering guarantees that no infinite reduction sequences can exist.
