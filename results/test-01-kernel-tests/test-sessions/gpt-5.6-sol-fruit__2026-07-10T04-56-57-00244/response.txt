Yes. Strong normalization can be established from the given syntax and rules alone.

A strictly monotone interpretation into `Nat` suffices. For example:

- `⟦plum⟧ = 0`
- `⟦grape t⟧ = ⟦t⟧ + 1`
- `⟦mango t⟧ = ⟦t⟧ + 1`
- `⟦peach a b⟧ = ⟦a⟧ + ⟦b⟧ + 1`
- `⟦pear a b⟧ = ⟦a⟧ + ⟦b⟧ + 1`
- `⟦banana b s n⟧ = ⟦b⟧ + (2⟦n⟧ + 1)(⟦s⟧ + 1)`
- `⟦cherry a b⟧ = 2⟦a⟧ + 2⟦b⟧ + 3`

Every displayed rewrite strictly decreases this measure. In particular, the apparently size-increasing banana rule decreases by `⟦s⟧ + 1`. The `cherry_diff` side condition is not needed for the decrease argument.

Since `<` on natural numbers is well-founded, there can be no infinite rewrite sequence. This proves normalization for `Step` as presented and would also support the usual contextual closure because the interpretations are strictly monotone. No additional rewrite rules, structural axioms, or object-level assumptions are required.
