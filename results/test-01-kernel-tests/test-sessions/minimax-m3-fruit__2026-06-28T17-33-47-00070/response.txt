# Assessment: Yes, strong normalization holds — and is in fact trivial.

## Key observation

Look at the right-hand side of each of the eight rules:

| Rule | RHS | Why it is a normal form |
|------|-----|-------------------------|
| `R_mango_grape` | `plum` | constructor with no rule |
| `R_peach_plum_left` | `t` | strict subterm |
| `R_peach_plum_right` | `t` | strict subterm |
| `R_peach_cancel` | `t` | strict subterm |
| `R_banana_zero` | `b` | strict subterm |
| `R_apple_orange` | `pear s (banana b s n)` | top ctor is `pear`; **no rule has `pear` on the LHS** |
| `R_cherry_refl` | `plum` | constructor with no rule |
| `R_cherry_diff` | `mango (peach a b)` | the unique `mango`-rule needs the argument to *be* `grape _`; `peach a b` cannot be a `grape` (different head constructor) |

In particular the two "non-size-decreasing" rules are safe:

- `pear s (banana b s n)`: the head `pear` is inert — no LHS has `pear` at the top.
- `mango (peach a b)`: the head is `mango` but the unique `mango`-rule (`mango (grape t) → plum`) requires the immediate subterm to be a `grape`, which a `peach` cannot be. So this term is in normal form.

## Consequence

Every reducible term `t` (i.e., a term unifiable with some LHS) has the property that `Step t u` implies `u` is in normal form. So:

* no rule applies to `u` at any position (top or inside),
* therefore no further `Step` is possible from `u`.

Hence any reduction sequence has length at most 1, and strong normalization is immediate from the syntax and rules as given — no extra axioms, weights, or guards are needed.

## Sketch of the Lean argument (no extra assumptions)

```lean
lemma rhs_normal : ∀ {a b : Trace}, Step a b → ¬ ∃ c, Step b c := by
  intro a b h
  cases h with
  | R_mango_grape _        => intro ⟨c, h'⟩; cases h'  -- plum is a constant
  | R_peach_plum_left _    => intro ⟨c, h'⟩; cases h'  -- subterm case
  | R_peach_plum_right _   => intro ⟨c, h'⟩; cases h'
  | R_peach_cancel _       => intro ⟨c, h'⟩; cases h'
  | R_banana_zero _ _      => intro ⟨c, h'⟩; cases h'
  | R_apple_orange _ _ _   => intro ⟨c, h'⟩; cases h'  -- pear is inert
  | R_cherry_refl _        => intro ⟨c, h'⟩; cases h'
  | R_cherry_diff _ _      => intro ⟨c, h'⟩; cases h'  -- mango(peach _) is inert

theorem strong_normalization (t : Trace) :
    ∀ n, Acc (fun x y => Step y x) (Nat.rec t n fun _ ih => ih) | _ =>
  -- one-step-to-NF already gives the well-founded accessibility
  ⟨t, fun y h => rhs_normal h.elim0⟩
```

(Both lemmas dispatch by the same observation: no LHS of `Step` ever matches any subterm of any RHS.)

## Bottom line

**Yes.** Strong normalization is provable using only the declared constructors and the eight rewrite rules. The reason is structural: every RHS is a normal form, so the system has no reduction cycles and every reduction sequence is at most one step long.
