Yes.

A direct termination proof can be given from the rules alone, with no extra object-level axioms. A simple way is a polynomial interpretation into `ℕ`:

- `μ(plum) = 0`
- `μ(grape t) = μ(t) + 1`
- `μ(mango t) = μ(t) + 1`
- `μ(peach x y) = μ(x) + μ(y) + 1`
- `μ(pear x y) = μ(x) + μ(y) + 1`
- `μ(cherry a b) = μ(a) + μ(b) + 3`
- `μ(banana b s n) = μ(b) + (μ(n) + 2) * (μ(s) + 2)`

Then every rewrite rule strictly decreases `μ`:

- `mango (grape t) → plum`:
  `μ = μ(t)+2 > 0`
- `peach plum t → t`, `peach t plum → t`, `peach t t → t`:
  all obvious from `+1`
- `banana b s plum → b`:
  `μ(lhs) = μ(b) + 2*(μ(s)+2) > μ(b)`
- `banana b s (grape n) → pear s (banana b s n)`:
  `μ(lhs) = μ(b) + (μ(n)+3)(μ(s)+2)`
  while
  `μ(rhs) = μ(s) + 1 + μ(b) + (μ(n)+2)(μ(s)+2)`,
  and the difference is exactly `1`
- `cherry a a → plum`:
  `2μ(a)+3 > 0`
- `cherry a b → mango (peach a b)`:
  `μ(lhs)=μ(a)+μ(b)+3 > μ(a)+μ(b)+2 = μ(rhs)`

So there is a strict descent in `ℕ` on every step, hence no infinite reduction sequence.

One nuance: as written, `Step` is only the root-step relation, with no congruence/context closure built in. For that exact relation, strong normalization is therefore certainly provable. In fact, the same interpretation is monotone, so it also proves termination even under the usual contextual reading of the rewrite rules. No extra structural axioms or hidden assumptions are needed.
