### Reasoning

The system as presented is **not strongly normalizing** due to a critical issue with rule `R_eq_diff`:

```lean
| R_eq_diff : ∀ a b, Step (eqW a b) (integrate (merge a b))
```

This rule applies to **any** `a` and `b`, including when `a = b`. Combined with `R_eq_refl`:

```lean
| R_eq_refl : ∀ a, Step (eqW a a) void
```

When `a = b`, the term `eqW a a` has **two possible reducts**:
1. Via `R_eq_refl`: `eqW a a → void`
2. Via `R_eq_diff`: `eqW a a → integrate (merge a a)`

This creates non-confluence, but more critically for normalization, consider what happens when we follow the `R_eq_diff` path starting from `eqW void void`:

```
eqW void void 
→ integrate (merge void void)    [by R_eq_diff]
→ integrate void                  [by R_merge_cancel]
```

This particular path terminates. However, the deeper problem is that **there is no guard preventing `R_eq_diff` from applying when `a = b`**, making the reduction relation non-deterministic in a way that could allow divergent reduction strategies in more complex terms.

More fundamentally, even if we interpret the rules as intended (with `R_eq_diff` applying only when `a ≠ b`), the system lacks a well-founded measure that decreases across all rules. Specifically:

- `R_rec_succ` transforms `recΔ b s (delta n)` into `app s (recΔ b s n)`, which duplicates `s` and `b` implicitly through the recursive structure
- There's no size discipline ensuring the arguments decrease in a compatible way

The `recΔ` constructor combined with `delta` essentially encodes a primitive recursion scheme, but without a well-founded ordering on the third argument that's respected by all rules, strong normalization proofs via standard methods (polynomial interpretations, recursive path orderings, reducibility candidates) cannot succeed without additional assumptions about term structure or reduction strategy.

**Conclusion**: The calculus as stated either admits non-terminating reduction sequences (if `R_eq_diff` is unrestricted) or requires unstated side conditions to even be coherent, violating the boundary of the question.
