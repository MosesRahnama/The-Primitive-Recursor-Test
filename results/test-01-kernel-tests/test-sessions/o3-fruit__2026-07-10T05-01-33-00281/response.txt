Yes – strong normalisation for the relation  Step  as it is given in the file can be proved within the calculus itself, without importing any extra axioms or side conditions.

Sketch of the argument  
1.  Step–rules are root-rules only.  A term can be rewritten exactly when its outermost constructor matches the left–hand side of one of the eight rules; there is no inductively-defined closure under arbitrary contexts in the file.

2.  For every rule except R_apple_orange the right–hand side is a strict structural sub-term of the left–hand side, so any natural size–measure (number of constructors, height, etc.) strictly decreases.

3.  Rule R_apple_orange (the only one that may enlarge the term)
      banana b s (grape n) ⟶ pear s (banana b s n)
   replaces the outer symbol banana by pear.  Since there is no rule whose left-hand side starts with pear, the resulting term is a normal form.  Consequently that rule can fire at most once in any reduction sequence.

4.  Hence every reduction sequence has length ≤ 1 when it ends with R_apple_orange and is strictly size-decreasing otherwise, so there is no infinite sequence of  Step  reductions.

Because we can give a well-founded measure (for instance
      μ(t) := 1 if t is of the form banana _ _ (grape _),  
              otherwise the number of constructors in t)
that strictly decreases with every  Step, the relation is strongly normalising.

No additional rewrite rules, semantic conditions, or external axioms are needed; the proof can be carried out inside Lean using only the inductive definitions already present.
