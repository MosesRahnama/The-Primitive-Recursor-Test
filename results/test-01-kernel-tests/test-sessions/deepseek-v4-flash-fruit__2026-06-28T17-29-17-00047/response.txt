Yes. Strong normalization can be proved from the presented calculus alone, using only the given syntax and rewrite rules. A standard method is to define a well-founded measure (e.g., a polynomial interpretation into the natural numbers) that strictly decreases for every rule. Such a measure can be defined by recursion on the structure of `Trace` (for instance, assign weights to constructors so that the left-hand side of each rule is larger than the right-hand side). Because the rewrite relation is only defined at the top level (no congruence rules), the existence of such a measure implies that every reduction sequence is finite. No external axioms, structural assumptions, or additional rules are needed; the proof uses only induction on terms and basic arithmetic, both of which are available within Lean's type theory.
