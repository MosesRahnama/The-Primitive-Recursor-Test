### Proof by Lexicographic Path Ordering (LPO)

We can prove strong normalization using a standard **Lexicographic Path Ordering (LPO)**, which is a well-founded reduction order on terms. 

To define the LPO, we choose the following precedence on the constructors:
$$\text{eqW} \succ \text{integrate} \succ \text{merge} \succ \text{void}$$
$$\text{rec}\Delta \succ \text{app} \succ \text{void}$$

For the ternary constructor $\text{rec}\Delta(b, s, n)$, we define a lexicographic status that prioritizes the **third argument** (the recursion index $n$) over the first two.

Using this LPO, we show that every rewrite rule $l \to r$ in the calculus strictly decreases ($l \succ_{\text{lpo}} r$):

1. **`R_int_delta`**: $\text{integrate}(\text{delta}(t)) \succ_{\text{lpo}} \text{void}$
   * Holds because $\text{integrate} \succ \text{void}$.

2. **`R_merge_void_left` / `R_merge_void_right` / `R_merge_cancel`**:

   * $\text{merge}(t, \text{void}) \succ_{\text{lpo}} t$
   * $\text{merge}(t, t) \succ_{\text{lpo}} t$
   * These all hold immediately by the subterm property of LPO.

3. **`R_rec_zero`**: $\text{rec}\Delta(b, s, \text{void}) \succ_{\text{lpo}} b$
   * Holds by the subterm property.

4. **`R_rec_succ`**: $\text{rec}\Delta(b, s, \text{delta}(n)) \succ_{\text{lpo}} \text{app}(s, \text{rec}\Delta(b, s, n))$
   * Since $\text{rec}\Delta \succ \text{app}$, we need to show:
     * $\text{rec}\Delta(b, s, \text{delta}(n)) \succ_{\text{lpo}} s$ (holds by subterm property)

   * Comparing the arguments of $\text{rec}\Delta$ under the status prioritizing the 3rd argument, we compare $\text{delta}(n)$ and $n$. Since $\text{delta}(n) \succ_{\text{lpo}} n$ by the subterm property, this step strictly decreases.

5. **`R_eq_refl`**: $\text{eqW}(a, a) \succ_{\text{lpo}} \text{void}$
   * Holds because $\text{eqW} \succ \text{void}$.

6. **`R_eq_diff`**: $\text{eqW}(a, b) \succ_{\text{lpo}} \text{integrate}(\text{merge}(a, b))$
   * Since $\text{eqW} \succ \text{integrate}$, this reduces to showing $\text{eqW}(a, b) \succ_{\text{lpo}} \text{merge}(a, b)$.
   * Since $\text{eqW} \succ \text{merge}$, this reduces to showing $\text{eqW}(a, b) \succ_{\text{lpo}} a$ and $\text{eqW}(a, b) \succ_{\text{lpo}} b$, both of which hold by the subterm property.
