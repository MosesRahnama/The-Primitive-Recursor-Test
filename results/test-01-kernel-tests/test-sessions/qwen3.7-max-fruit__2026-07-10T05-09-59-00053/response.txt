### Proof via Polynomial Interpretation

A standard polynomial interpretation over ℕ (with base values ≥ 2) suffices. Define:

| Constructor | Interpretation |
|---|---|
| `plum` | `2` |
| `grape(t)` | `⟦t⟧ + 1` |
| `mango(t)` | `⟦t⟧ + 1` |
| `peach(a, b)` | `⟦a⟧ + ⟦b⟧ + 1` |
| `pear(a, b)` | `⟦a⟧ + ⟦b⟧ + 1` |
| `banana(a, b, c)` | `⟦a⟧ + ⟦b⟧² · (⟦c⟧ + 1)` |
| `cherry(a, b)` | `⟦a⟧ + ⟦b⟧ + 3` |

All interpretation functions are strictly monotone in each argument over the domain {n ∈ ℕ | n ≥ 2}.

### Verification of strict decrease for every rule

1. **R_mango_grape**: `⟦t⟧ + 2 > 2` ✓
2. **R_peach_plum_left**: `⟦t⟧ + 3 > ⟦t⟧` ✓
3. **R_peach_plum_right**: `⟦t⟧ + 3 > ⟦t⟧` ✓
4. **R_peach_cancel**: `2⟦t⟧ + 1 > ⟦t⟧` ✓
5. **R_banana_zero**: `⟦b⟧ + 3⟦s⟧² > ⟦b⟧` ✓
6. **R_apple_orange** (the critical duplicating rule):
   - LHS: `⟦b⟧ + ⟦s⟧²·(⟦n⟧ + 2)`
   - RHS: `⟦s⟧ + ⟦b⟧ + ⟦s⟧²·(⟦n⟧ + 1) + 1`
   - Difference simplifies to **`⟦s⟧² − ⟦s⟧ − 1`**, which is `≥ 1 > 0` for all `⟦s⟧ ≥ 2`. ✓
7. **R_cherry_refl**: `2⟦a⟧ + 3 > 2` ✓
8. **R_cherry_diff**: `⟦a⟧ + ⟦b⟧ + 3 > ⟦a⟧ + ⟦b⟧ + 2` ✓

### Reasoning

The only rule that duplicates a subterm is `R_apple_orange`, which copies `s` while stripping one `grape` from the third argument of `banana`. The quadratic dependence `⟦b⟧² · (⟦c⟧ + 1)` in the interpretation of `banana` ensures that removing one `grape` from `c` (decreasing `⟦c⟧` by 1) releases `⟦s⟧²` units of measure, which more than pays for the duplicated `s` (costing `⟦s⟧ + 1` units) since `⟦s⟧² − ⟦s⟧ − 1 > 0`.

Since every rule strictly decreases a well-founded measure (natural numbers under `>`), no infinite reduction sequence exists. This proof requires no additional rules, side conditions, or object-level axioms—only standard arithmetic properties of ℕ used at the meta-level.
