Raw assessment: **strong normalization can be established from the rules shown, without adding any extra object-level axioms, guards, or side conditions**.

Two readings:

1. **Literal reading of the Lean file**: `Step` is only the root-step relation defined by those constructors. Under that reading, termination is essentially immediate.

2. **Usual TRS reading (rules usable in any context)**: it is still strongly normalizing. A standard **polynomial interpretation over `ℕ`** strictly decreases on every rule.

One workable interpretation is:

- `|void| = 0`
- `|delta t| = |t| + 1`
- `|integrate t| = |t| + 1`
- `|merge a b| = |a| + |b| + 1`
- `|app a b| = |a| + |b|`
- `|eqW a b| = |a| + |b| + 3`
- `|recΔ b s n| = (|n| + 1) * (|s| + 1) + |b| + 1`

Then each rule strictly decreases:

- `integrate (delta t)` : `|t|+2 > 0`
- `merge void t` : `|t|+1 > |t|`
- `merge t void` : `|t|+1 > |t|`
- `merge t t` : `2|t|+1 > |t|`
- `recΔ b s void` : `|s|+|b|+2 > |b|`
- `recΔ b s (delta n)` :
  `(|n|+2)(|s|+1)+|b|+1 > |s| + ((|n|+1)(|s|+1)+|b|+1)`
- `eqW a a` : `2|a|+3 > 0`
- `eqW a b` : `|a|+|b|+3 > |a|+|b|+2 = |integrate (merge a b)|`

Since this is a monotone interpretation into the well-founded order on `ℕ`, infinite reductions are impossible.

One caveat: the system is **not orthogonal/confluent**, because `eqW a a` matches both `R_eq_refl` and `R_eq_diff`. But that affects confluence, **not** strong normalization.

So within the boundary you set: **yes, SN is provable from the presented calculus alone**.
