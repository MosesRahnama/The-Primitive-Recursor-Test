**Yes – strong normalisation can be proved using only the given syntax and rewrite rules.**

A standard way is to introduce a numeric “weight’’ for every term that decreases at every rewrite step.  
For example, assign the following non‑negative integers to the constructors (the exact values are not important, any numbers satisfying the constraints below work):

```
w(plum)      = 0
w(grape)    = 0        (with a coefficient 1 for the argument)
w(mango)    = 1
w(peach)    = 1
w(banana)   = 1
w(pear)     = 0
w(cherry)   = 2
```

and give each argument a coefficient:

* grape x  → 0 + 1·w(x)
* mango x  → 1 + 0·w(x)
* peach x y → 1 + 1·w(x) + 1·w(y)
* banana x y z → 1 + 1·w(x) + 0·w(y) + 1·w(z)
* pear x y → 0 + 0·w(x) + 0·w(y)
* cherry x y → 2 + 1·w(x) + 1·w(y)

Define `weight(t)` recursively by this interpretation.  
A straightforward induction on the structure of the terms shows that for each of the eight rewrite rules

```
Step LHS RHS  ⇒  weight(LHS) > weight(RHS)
```

holds (the inequalities are exactly the linear constraints listed above; they are all satisfied by the chosen numbers).  

Because the weight of a term is a natural number and strictly decreases at every rewrite step, any rewrite sequence must be finite.  This is precisely strong normalisation.

The proof uses only the inductive definitions of `Trace` and `Step` and elementary arithmetic; no additional axioms, rewrite rules, or side‑conditions are required.
