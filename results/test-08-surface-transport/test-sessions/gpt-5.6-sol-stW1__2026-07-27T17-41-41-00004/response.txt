**Verdict:** The equations are sufficient to establish that left-to-right rewriting has no infinite computation on unary numeral inputs. However, they are **not** sufficient to establish that all the displayed symbols define total functions returning unary naturals on all inputs.

The distinction matters because `p Z` and `fac Z` have no defining equations, and every positive factorial computation eventually reaches `fac Z`.

### Termination of rewriting

Write \(\lvert S^n Z\rvert=n\).

- `plus x Z = x` stops immediately.
- `plus x (S y) = S (plus x y)` decreases the number of `S` constructors in the second argument by one. Hence `plus` terminates on all numeral inputs.

- `times Z y = Z` and `times x Z = Z` stop immediately. Their overlap at `times Z Z` is harmless since both yield `Z`.
- `times (S x) y = plus (times x y) y` decreases the number of `S` constructors in the first argument. There are therefore finitely many `times` steps, and every introduced `plus` call terminates by the preceding argument.

- `p (S Z) = Z` is a base case.
- `p (S (S x)) = S (p (S x))` decreases by one the number of `S` constructors in the argument of the recursive `p` call. Thus, for \(n\geq1\),
  \[
  p(S^n Z)\;\longrightarrow^*\;S^{n-1}Z.
  \]
  The input `p Z` has no applicable equation and is stuck, rather than divergent.

- For \(n\geq1\),
  \[
  fac(S^n Z)
  \longrightarrow
  times(fac(p(S^n Z)),S^n Z)
  \longrightarrow^*
  times(fac(S^{n-1}Z),S^n Z).
  \]
  Thus each recursive `fac` occurrence has a numeral argument with one fewer `S`. After finitely many such steps the computation reaches `fac Z`, where no equation applies. Consequently there is no infinite reduction.

This argument uses only the finite constructor shape of the input terms and the displayed equations; it does not require an additional arithmetic axiom.

### Limitation

The equations do **not** show total evaluation to a unary natural:

- `p Z` is undefined.
- `fac Z` is undefined.
- Indeed, `fac (S Z)` reaches
  ```text
  times (fac Z) (S Z)
  ```
  which is stuck: neither `times Z y`, `times x Z`, nor `times (S x) y` matches it.
- The same obstruction propagates to every positive factorial input.

So the raw assessment is:

- **Yes** for strong normalization/no infinite left-to-right rewriting on unary numeral inputs.
- **No** if “termination as functions on all inputs” means that every input evaluates to a unary-natural result. That stronger claim cannot be obtained without adding at least the missing base behavior, which the stated boundary forbids.
