**Verdict:** Yes—if “termination” means that the defining equations are oriented left-to-right as rewrite rules and that no infinite reduction starts from a function applied to finite unary numerals. This can be proved from the syntax and equations alone.

However, these equations do **not** define a total numeral-valued factorial: `fac Z` has no defining equation, so factorial computations eventually become stuck rather than return a unary numeral.

### Termination argument

Write \(\lvert S^n Z\rvert=n\). Induction here is only meta-level induction on finite constructor syntax; it imports no object-level arithmetic axiom.

- **`plus`**
  - `plus x Z = x` removes the `plus` call.
  - `plus x (S y) = S (plus x y)` decreases the number of `S` constructors in the second argument.
  
  Hence `plus` terminates on unary-natural arguments.

- **`times`**
  - `times Z y = Z` removes the call.
  - `times x Z = Z` removes the call.
  - `times (S x) y = plus (times x y) y` decreases the first argument from `S x` to `x`. The newly introduced `plus` call terminates by the preceding argument.

  The overlap at `times (S x) Z` causes no problem: choosing the second rule terminates immediately, while choosing the third rule decreases the first argument and then uses terminating `plus`. Thus every choice terminates.

- **`p`**
  - `p (S Z) = Z` removes the call.
  - `p (S (S x)) = S (p (S x))` decreases the number of leading `S` constructors beneath `p`.

  Consequently, for every constructor numeral \(x\), the equations derive
  \[
  p(Sx)\;\longrightarrow^*\;x.
  \]
  This is a derived reduction fact, not an added equation.

- **`fac`**
  - The only rule is
    \[
    fac(Sx)\to times(fac(p(Sx)))(Sx).
    \]
    For a numeral \(x\), the recursive argument satisfies
    \[
    p(Sx)\to^*x,
    \]
    so the recursive `fac` call has numeral rank one less than the original argument. Rewriting may apply the `fac` rule before all internal `p` reductions finish, but this does not invalidate the decrease: assigning
    \[
    |Z|=0,\qquad |S t|=|t|+1,\qquad |p(t)|=\max(|t|-1,0)
    \]
    makes both `p` equations preserve the assigned value, while every `fac` contraction changes the rank of its unique recursive `fac` call from \(|Sx|=|x|+1\) to
    \[
    |p(Sx)|=|x|.
    \]
    Thus only finitely many `fac` contractions are possible. Between them, only the already terminating `p`, `times`, and `plus` reductions occur.

There is no rule for `fac Z`, so it is already a normal form. For example:
\[
fac(SZ)\to times(fac(p(SZ)))(SZ)
\to times(fac Z)(SZ),
\]
which is stuck because `fac Z` does not reduce and no `times` rule matches that first argument.

Therefore:

- **Rewrite termination on all finite unary-natural inputs:** yes.
- **Total evaluation to a unary-natural result:** no, because `fac Z` is undefined.
- **If equations were allowed in both directions rather than oriented as defining rewrite rules:** termination would of course fail, but that is not the standard reading of recursive defining equations.
