## Verdict: **Yes**, termination is establishable for all four functions using only structural recursion / well-founded induction on the size of unary naturals (the "number of `S` constructors", call it `|Z|=0`, `|S t|=|t|+1`). No extra axioms are needed beyond the given equations and the fact that closed terms in `Z`/`S` are inductively built (standard structural induction for `Z`,`S`).

---

### 1. `plus x y` — recursion on the second argument

```
plus x Z     = x
plus x (S y) = S (plus x y)
```

Every equation either is a base case (`Z`) or makes a recursive call `plus x y` where the second argument `y` is a syntactic subterm of `S y`, so `|y| < |S y|`. By structural induction on the second argument, `plus` terminates for all `x, y`.

### 2. `times x y` — recursion on the first argument

```
times Z y     = Z
times x Z     = Z
times (S x) y = plus (times x y) y
```

The two base equations (`Z y` and `x Z`) terminate immediately (no recursive call — note `plus`, used in the body of the third equation, was already shown terminating above, so its use doesn't threaten termination of `times`). The only recursive equation calls `times x y` from `times (S x) y`, with `|x| < |S x|`. By structural induction on the first argument, `times` terminates for all `x, y`. (The overlapping instance `times Z Z` is covered consistently by either equation, causing no non-termination issue — at worst nondeterminism, not looping.)

### 3. `p` — recursion on the argument itself

```
p (S (S x)) = S (p (S x))
p (S Z)     = Z
```

The recursive call is `p (S x)` from `p (S (S x))`, and `|S x| < |S (S x)|`. By structural induction on the argument (equivalently, induction on the number of leading `S`'s), `p` terminates on every input of the form `S t`. There is no equation for `p Z`; that case simply has no applicable rule, so evaluation halts immediately (a stuck term is not a non-terminating computation) — this case introduces no termination obligation.

### 4. `fac` — recursion on the argument, using termination of `p`

```
fac (S x) = times (fac (p (S x))) (S x)
```

Two things must be checked:

- **Well-definedness/termination of the inner call `p (S x)`:** shown in (3), for arbitrary `x` this reduces to a normal form in finitely many steps (structural recursion on the `S`-depth of `x`).
- **Value of that normal form:** by straightforward computation from the two `p`-equations, one shows by induction on `x` that `p (S x)` reduces exactly to `x`:
  - Base: `p (S Z) = Z`, matching `x = Z`.
  - Step: `p (S (S x)) = S (p (S x)) = S x` by the induction hypothesis `p (S x) = x`.

  So the argument of the outer recursive call, `p (S x)`, is (after termination of `p`) syntactically/semantically `x`, a proper structural subterm of `S x`: `|x| < |S x|`.

- **Recursive call `fac (p (S x))` = `fac x` (after reduction), with `|x| < |S x|`.** By structural induction on the argument of `fac`, using the already-established termination of `p` (to know the argument-reduction step itself terminates) and of `times` (used in the outer combination, already shown terminating), `fac` terminates for every input of the form `S x`.

There is no equation for `fac Z`; as with `p`, this is simply a case with no applicable rule — evaluation halts, which is termination (not an infinite computation), and creates no separate proof obligation.

### Summary

All recursive calls in every equation strictly decrease a well-founded measure (the number of `S`-constructors) on the designated recursion argument:

- `plus`: decreases on 2nd argument.
- `times`: decreases on 1st argument (relying only on the already-proved terminating `plus`).
- `p`: decreases on its argument.
- `fac`: decreases on its argument, via the terminating auxiliary computation `p (S x) = x` and the terminating `times`.

Since unary naturals built from `Z`/`S` are well-founded under the subterm order, ordinary structural induction (mathematical induction on the natural number encoded by the term) suffices to prove termination of each function on all inputs, using only the equations given — no additional guards, side conditions, or externally imported axioms are required.
