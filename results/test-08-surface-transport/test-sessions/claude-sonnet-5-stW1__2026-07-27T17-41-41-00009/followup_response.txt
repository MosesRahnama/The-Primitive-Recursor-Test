# Why I picked this method

**The core reason: the argument structure of each function told me exactly what measure to use, and unary naturals make size literally *count* the recursion.**

For `plus` and `p`, the recursive call sits directly on a syntactic subterm of the pattern-matched argument (`y` inside `S y`; `S x` inside `S (S x)`). This is the textbook case for **structural/subterm induction** — the decrease isn't something I have to prove by calculation, it's given for free by the shape of the pattern match. Choosing anything fancier (e.g. an explicit well-founded relation, or converting to a numeric measure) would have been unnecessary machinery for what's already syntactically obvious. I used the simplest tool that fits the evidence.

For `times`, the same observation applies to the *first* argument only — the second argument is inert. I picked structural induction on `x` alone (ignoring `y`) because that's precisely the variable that shrinks; trying to build a joint measure on both arguments would have been overkill and would have obscured that `y` never needs to decrease.

**For `fac`, plain structural induction doesn't literally apply**, because the recursive call is `fac (p (S x))`, not `fac x'` for some syntactic subterm `x'` of `S x`. This is the interesting case, and it's why I switched strategy:

1. I first checked whether `p (S x)` is *provably* a subterm of `x` in every case — it isn't purely syntactically (the equations build `p (S x)` via peeling of `S`s, not by direct subterm extraction), so naive structural recursion doesn't transparently apply to `fac`.
2. Since termination proofs must reduce to *some* well-founded decrease, and term size (`|·|`) is a natural number, the natural fallback is a **derived measure**: prove a lemma that `|p (S x)| ≤ |x|`, itself by structural induction on `p`'s own equations (staying inside the given rules — no new axioms). This converts an opaque recursive call into a genuine, provable strict decrease in a well-founded order (natural number size), letting me invoke ordinary induction on ℕ.
3. This is a standard technique — "measure functions" or "size-decrease lemmas" — precisely because `fac`'s recursion is *not* directly structural but is *provably* well-founded once you understand what `p` does. I didn't want to just assert "`p` decreases things" as an axiom; I wanted to derive it from the equations themselves, since the prompt disallows importing extra assumptions.

**Why not other methods?**
- *Lexicographic or multiset orders*: unnecessary — there's only one argument changing in each function, so a single scalar measure suffices everywhere. Introducing multi-argument orders would add complexity with no benefit.
- *Semantic/domain-theoretic denotational arguments*: overkill for finite first-order recursion on an inductive type; structural methods are strictly simpler and equally rigorous here.
- *Assuming termination as an axiom or invoking recursion-schemes as primitive*: this would violate the "no extra axioms beyond the equations" constraint — I needed the decrease to be *derived*, not postulated, which is exactly what the `p`-lemma does.

In short: I used the weakest/simplest sufficient method for each equation — direct subterm recursion where the syntax already guarantees it (`plus`, `times`, `p`), and a derived numeric measure exactly where syntax alone is insufficient (`fac`) — so that every termination claim is justified strictly from the given equations and basic well-foundedness of ℕ, with no unjustified leaps.
