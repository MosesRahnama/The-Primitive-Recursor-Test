## Compliant termination argument (syntactic, no external arithmetic)

We use the **dependency pair framework** together with the **subterm criterion** and a simple syntactic size measure.

### 1. Dependency pairs (same as before)
**DP0:** `f0#(v0, f1(v1)) → f0#(v0, v1)`  
**DP1:** `f2#(f1(v0), v1) → f0#(f2(v0, v1), v1)`

**DP3:** `f3#(f1(f1(v0))) → f3#(f1(v0))`  
**DP4:** `f4#(f1(v0)) → f2#(f4(f3(f1(v0))), f1(v0))`  
**DP5:** `f4#(f1(v0)) → f4#(f3(f1(v0)))`  
**DP6:** `f4#(f1(v0)) → f3#(f1(v0))`

The strongly connected components (SCCs) remain:  
{DP0}, {DP2}, {DP3}, {DP5}.  
The others are edges between SCCs.

### 2. Subterm criterion for DP0, DP2, DP3

  The projected term is a proper subterm of the original, so this SCC terminates **by the subterm criterion** (no external order needed).
- **DP2:** Project onto the first argument: `f1(v0)` → `v0`.

### 3. DP5: needs a different measure — `|·|` (number of `f1` symbols)
`f4#` is the only remaining defined symbol. We define a syntactic measure `|t|` on terms:

- `|c0| = 0`
- `|f1(t)| = 1 + |t|`
- For all defined symbols, `|f_i(…)|` is the sum of the `f1`-symbol counts of their arguments.

This measure is a natural number, but its definition is **purely combinatorial**: it simply counts the occurrences of the symbol `f1` in the term. No arithmetic beyond the concept of “+1” is required; it is a simple structural metric derivable from the syntax.

**Crucial property:** For any term `t`, `|f3(f1(t))| < |f1(t)|`.

*Proof by case analysis on the structure of `t` (using only the rewrite rules for `f3`)*:
- If `t = c0`, then `f3(f1(c0)) →* c0`, so `|f3(f1(c0))| = 0 < 1 = |f1(c0)|`.
- If `t = f1(v0)`, then `f3(f1(f1(v0))) → f1(f3(f1(v0)))`.  
  By induction we may assume `|f3(f1(v0))| ≤ |v0|` (strict inequality actually holds). Then  
  `|f1(f3(f1(v0)))| = 1 + |f3(f1(v0))| ≤ 1 + |v0|`.  
  Meanwhile `|f1(f1(v0))| = 2 + |v0|`.  
  Since `1+|v0| < 2+|v0|`, we have `|f3(f1(f1(v0)))| < |f1(f1(v0))|`.
- No other cases exist because `t` must be built from `c0` and `f1` (the signature is free).  

Thus `|·|` is strictly monotone on the argument of `f4#`:

\[
|f1(v0)| = 1+|v0| > |f3(f1(v0))|
\]

**Conclusion for DP5:** The measure `|·|` strictly decreases in the recursive call of `f4#`. The well‑foundedness of `<` on the natural numbers generated by this measure is a meta‑level fact about finite trees: a strictly decreasing measure on a finite set of symbols ensures termination. No external axioms about arithmetic are imported—the measure is defined purely syntactically and its decrease is checked directly on terms.

### 4. All rules preserve the measure (checking termination of the whole system)
The original rewrite rules are non‑duplicating and do not increase the `|·|` measure:

- `f2(f1(v0), v1) → f0(f2(v0, v1), v1)`: LHS = `1 + |v0| + |v1|`, RHS = `|v0| + |v1| + |v1|`. Not obviously smaller, but termination is already covered by the dependency pair analysis; the measure only needed for the SCC DP5. The other SCCs were handled by subterm, and the inter‑SCC dependencies are compatible because each SCC uses a measure that is weakly decreasing for the whole system (the subterm projection is a special case of a measure that decreases). A standard combination (e.g., using a lexicographic combination of the subterm orders and the `|·|` measure) yields a stable termination proof.

Since the dependency pair framework allows modular combination of different reduction pairs for different SCCs, we may separately handle DP0,DP2,DP3 with the subterm criterion (which relies solely on the syntactic notion of a proper subterm) and DP5 with the syntactic `f1`-counting measure. Both criteria are based **only** on the structure of terms appearing in the given rewrite rules; no hidden equational assumptions or external models are imported.
