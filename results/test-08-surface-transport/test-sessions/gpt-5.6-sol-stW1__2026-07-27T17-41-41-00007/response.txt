## Verdict

**Yes—under the standard left-to-right rewrite interpretation, every computation starting from unary numeral inputs terminates:** there is no infinite reduction sequence.

However, **termination must not be confused with totality or successful evaluation to a numeral**. In particular, there is no equation for `fac Z`, so `fac Z` is a stuck normal form, and every positive factorial computation eventually contains that stuck call. Thus these equations do **not** define a total numeral-valued factorial function.

The proof uses only metalevel induction on the finite syntax of unary numerals, not an imported object-level induction axiom.

## Termination argument

Write \(\bar n=S^n Z\).

### `plus`

The rules are

```text
plus x Z     → x
plus x (S y) → S (plus x y)
```

Each use of the second rule removes one `S` from the second argument. Hence `plus a \bar n` takes at most \(n+1\) root steps, apart from reductions already present inside `a`. No rule increases the recursive second argument.

### `times`

The rules are

```text
times Z y     → Z
times x Z     → Z
times (S x) y → plus (times x y) y
```

For numeral arguments, the third rule removes one `S` from the first argument. The introduced `plus` call terminates by the preceding argument because its second argument is the unchanged numeral `y`.

The overlap at `times (S x) Z` causes no problem:

- using `times x Z → Z` terminates immediately;
- using the successor rule gives
  `plus (times x Z) Z`, after which either the `plus` or inner `times` rule reduces, and the computation terminates.

Likewise, the two rules applicable to `times Z Z` both produce `Z`.

More generally, this also shows that `times a \bar n` terminates whenever `a` itself has only finite reductions: reductions inside `a` are finite, and any exposed successor case decreases its constructor depth.

### `p`

The rules are

```text
p (S (S x)) → S (p (S x))
p (S Z)     → Z
```

Each use of the first rule decreases the number of `S` constructors inside the argument of the recursive `p` call by one. The second rule ends the recursion. In particular, directly from these rules,

\[
p(S\bar n)\to^*\bar n.
\]

This is proved syntactically:

- \(p(SZ)\to Z\);
- if \(p(S\bar n)\to^*\bar n\), then
  \[
  p(S(S\bar n))\to S(p(S\bar n))\to^*S\bar n.
  \]

`p Z` has no applicable rule, so it is stuck rather than divergent.

### `fac`

The sole rule is

```text
fac (S x) → times (fac (p (S x))) (S x)
```

For a numeral \(\bar n\),

\[
fac(S\bar n)
\to
times(fac(p(S\bar n)),S\bar n)
\to^*
times(fac(\bar n),S\bar n).
\]

Thus every newly exposed recursive `fac` call has one fewer `S` in its numeral argument. By metalevel induction on \(n\), this descent can happen only finitely many times. The surrounding `p`, `times`, and `plus` reductions terminate by the preceding arguments.

At the bottom, the computation reaches `fac Z`. Since no rule has `fac Z` on its left-hand side, it stops there. For example,

```text
fac (S Z)
→ times (fac (p (S Z))) (S Z)
→ times (fac Z) (S Z)
```

and the final term is stuck.

## Boundary of the result

Therefore:

- **Rewrite termination/no infinite computation:** established from the displayed rules alone.
- **Total evaluation to unary naturals:** not established and in fact false for these rules, because `fac Z` has no defining equation.
- No extra equation such as `fac Z = S Z` has been assumed.
