## Method A: LPO with F > G > S > Z

**R1:** F(x, y, Z) → x. LPO requires the RHS to be a subterm or strictly smaller. x is a proper subterm of the LHS ✓

**R2:** F(x, y, S(n)) → G(y, F(x, y, n)). With F > G, we need all arguments of G to be strictly less than the LHS. G(y, F(x,y,n)): y is a subterm ✓; F(x,y,n) — need F(x,y,S(n)) >_LPO F(x,y,n). Since F=F, compare lexicographically: x=x, y=y, S(n) >_LPO n (since S > n by subterm/status) ✓. So F(x,y,S(n)) >_LPO F(x,y,n) ✓. Then F(x,y,S(n)) >_LPO G(y, F(x,y,n)) since F > G and both arguments of G are strictly less than the LHS ✓.

**Condition 1: Succeeds ✓**
**Condition 2:** LPO is derived purely from the signature and rules — no external axioms needed ✓

## Method B: Polynomial Interpretation

**R2:** [F(x,y,S(n))] = x + (n+1) + 1 = x+n+2. [G(y, F(x,y,n))] = [F(x,y,n)] = x+n+1. So x+n+2 > x+n+1 ✓

**Condition 1: Succeeds ✓**

## Method C: KBO with uniform weight w=1

KBO requires the weight function to satisfy w(f) ≥ 0 and for unary symbols w(f)+w(x) ≥ w(x). Additionally, the variable condition: every variable in the RHS must appear at least as often in the LHS.

**R2:** F(x, y, S(n)) → G(y, F(x, y, n)). Check variable balance: x appears once each side ✓, y once each side ✓, n: LHS has n (inside S(n)), RHS has n ✓. Weight comparison: LHS weight = w(F)+w(S)+w(x)+w(y)+w(n) = 1+1+1+1+1=5 (treating variables as weight 1 per variable). Actually standard KBO: weight of term = sum of symbol weights + variable weights. LHS: w(F)+w(S)+w(Z... wait, third arg is S(n)): w(F)+w(x)+w(y)+w(S)+w(n)=5. RHS: w(G)+w(y)+w(F)+w(x)+w(y)+w(n)=1+1+1+1+1+1=6.

LHS weight 5 < RHS weight 6. **KBO fails** — weight does not decrease.

**Condition 1: Fails ✗**
