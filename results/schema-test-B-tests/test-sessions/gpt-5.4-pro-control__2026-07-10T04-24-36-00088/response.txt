## Quick justifications

### A) LPO
- Rule 1: \(F(x,y,Z) > x\) by subterm property.
- Rule 2: \(F(x,y,S(n)) > G(y,F(x,y,n))\) since \(F > G\), and
  - \(F(x,y,S(n)) > y\),
  - \(F(x,y,S(n)) > F(x,y,n)\) because \(S(n) > n\).
- So **termination proof succeeds**.

Boundary: the chosen precedence is a **global external choice**, so **outside**.

---

### B) Polynomial interpretation
Given:
- \([F(x,y,n)] = x+n+1\)
- \([S(n)] = n+1\)
- \([G(a,b)] = b\)
- \([Z]=0\)

At the rule roots:
- \(F(x,y,Z)\): \(x+1 > x\)
- \(F(x,y,S(n))\): \(x+n+2 > x+n+1\)

But this does **not** yield a valid direct termination proof for the whole TRS, because the interpretation ignores some arguments:
- \(F\) ignores its 2nd argument,
- \(G\) ignores its 1st argument.

So a rewrite inside those positions need not decrease. Example:
\[
F(Z,\;F(Z,Z,Z),\;Z) \to F(Z,Z,Z)
\]
Both sides interpret to \(1\). Hence the proposed interpretation does **not** give a global strictly decreasing reduction order.

Boundary: imported global semantic assignment, so **outside**.

---

### C) KBO
Rule 2 is enough to kill it:
\[
F(x,y,S(n)) \to G(y,F(x,y,n))
\]
In KBO, variable occurrences on the left must dominate those on the right. But:
- \(y\) occurs **once** on the left,
- \(y\) occurs **twice** on the right.

So KBO cannot orient this rule. With standard positive variable weight, the RHS is also heavier under uniform symbol weights.

Thus **fails**. Boundary: global weights/precedence, so **outside**.

---

### D) Dependency pairs + subterm criterion
Only recursive call is in rule 2, so the DP set is:
\[
F^\#(x,y,S(n)) \to F^\#(x,y,n)
\]
Project to the 3rd argument:
- left projection: \(S(n)\)
- right projection: \(n\)

Since \(S(n)\) is a proper superterm of \(n\), the subterm criterion applies, so there is **no infinite DP chain**. Hence the TRS is terminating.

Boundary: this is still based on the recursive structure visible in the rules themselves, so **within**.

---

### E) Direct measure \(\mu\)
As stated:
- \(\mu(F(x,y,n)) = \mathrm{depth}_S(n)+1\)
- \(\mu(G(a,b))=\mu(b)\)
- \(\mu(x)=0\)

This does **not** strictly decrease on every rewrite step.

A direct counterexample:
\[
F(F(Z,Z,S(Z)),\;Z,\;Z) \to F(Z,Z,S(Z))
\]
Then:
- \(\mu(\text{lhs}) = \mathrm{depth}_S(Z)+1 = 1\)
- \(\mu(\text{rhs}) = \mathrm{depth}_S(S(Z))+1 = 2\)

So the measure can **increase**. Also, rewrites inside ignored contexts are not tracked.

Boundary: yes, because it is a direct measure extracted from the recursive argument, not an imported global structure.

---
