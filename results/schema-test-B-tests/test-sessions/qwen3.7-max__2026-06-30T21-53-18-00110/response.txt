# Analysis of the Term Rewriting System and Proof Methods

## The TRS

```
F(x, y, Z)     → x                        (Rule 1)
F(x, y, S(n))  → G(y, F(x, y, n))         (Rule 2)
```

Defined symbol: **F** (only symbol at the root of a left-hand side).
Constructors/other: **G, S, Z**.

---

## Method-by-Method Analysis

### (A) Lexicographic Path Order with F > G > S > Z

**Does it succeed?** **Yes.**

- **Rule 1:** `F(x, y, Z) >_{lpo} x` holds because `x` is a proper subterm of the left side (LPO subterm property).
- **Rule 2:** `F(x, y, S(n)) >_{lpo} G(y, F(x, y, n))`. Since `F > G` in the precedence, LPO requires `F(x,y,S(n)) >_{lpo} t_j` for every argument of `G`:
  - `>_{lpo} y`: `y` is a subterm of the LHS. ✓
  - `>_{lpo} F(x, y, n)`: Same root symbol `F`, so compare arguments lexicographically:
    - `x = x`, `y = y`, then `S(n) >_{lpo} n` (subterm property). ✓
    - Additionally need LHS `>_{lpo}` each argument of the RHS's `F`: `x`, `y`, `n` are all subterms of the LHS. ✓

Since LPO is a simplification order (closed under contexts and substitutions), this proves termination.

**Within benchmark boundary?** **Yes.** LPO is a purely syntactic method requiring only the rules themselves and a precedence—no imported axioms.

---

### (B) Polynomial Interpretation: [F]=x+n+1, [S]=n+1, [G]=b, [Z]=0

**Does it succeed?** **No.**

The rule checks `[l] > [r]` do hold:
- Rule 1: `x + 0 + 1 = x+1 > x`. ✓
- Rule 2: `x + (n+1) + 1 = x+n+2 > x+n+1`. ✓

**However**, the interpretation of `F` is `[F](x,y,n) = x + n + 1`, which has coefficient **0** for the second argument `y`. This violates the **monotonicity requirement** of polynomial interpretations: `[F]` must be strictly monotone in every argument.

This is not a mere formality. Consider the term `s = F(a, F(x, y, S(n)), S(c))` and the rewrite of the inner redex:

```
s = F(a, F(x, y, S(n)), S(c))   →   F(a, G(y, F(x, y, n)), S(c)) = t
```

Evaluating: `[s] = a + (c+1) + 1 = a+c+2` and `[t] = a + (c+1) + 1 = a+c+2`. The measure does **not** decrease (`[s] = [t]`), so the interpretation fails to be a valid termination proof.

**Within benchmark boundary?** Yes (the technique itself is standard), but it **fails to prove termination**.

---

### (C) Knuth-Bendix Order with uniform weights w(F)=w(G)=w(S)=w(Z)=1

**Does it succeed?** **No.**

KBO requires the **variable condition**: for every rule `l → r` and every variable `v`, the number of occurrences of `v` in `l` must be ≥ its occurrences in `r`.

In Rule 2: `F(x, y, S(n)) → G(y, F(x, y, n))`
- `y` appears **1 time** on the LHS, but **2 times** on the RHS (once in `G(y,…)` and once in `F(…,y,…)`).

This is a hard structural violation that **no choice of weights or precedence can overcome**. KBO is inapplicable to this system.

**Within benchmark boundary?** Yes, but it **fails**.

---

### (D) Dependency Pairs with Subterm Criterion (projection to 3rd argument of F)

**Does it succeed?** **Yes.**

**Step 1 — Generate dependency pairs.** Only Rule 2 produces a DP (the subterm `F(x,y,n)` of the RHS has defined root `F`):

```
F#(x, y, S(n))  →  F#(x, y, n)
```

**Step 2 — Apply the subterm criterion** (Hirokawa & Middeldorp, 2004) with projection `π(F#) = 3`:

- `π(LHS) = S(n)`
- `π(RHS) = n`

Since `n` is a **proper subterm** of `S(n)`, the criterion is satisfied. The single DP is removed, leaving an empty DP problem `(∅, R)`, which is trivially finite—proving termination.

**Within benchmark boundary?** **Yes.** The dependency pair framework and subterm criterion are standard, self-contained termination techniques requiring only the rewrite rules.

---

### (E) Direct Descent Measure: μ(F(x,y,n))=depth_S(n)+1, μ(G(a,b))=μ(b), μ(var)=0

**Does it succeed?** **No.**

The measure decreases for root-level rewrites:
- Rule 1: `μ(F(x,y,Z)) = 1 > 0 = μ(x)`. ✓
- Rule 2: `μ(F(x,y,S(n))) = depth_S(n)+2 > depth_S(n)+1 = μ(G(y,F(x,y,n)))`. ✓

However, the claim is that **every** rewrite step (including under contexts) strictly decreases μ. This is false. Consider:

```
s = F(G(a, F(x, y, S(n))), y', Z)
    ↓  (rewrite inner F)
t = F(G(a, G(y, F(x, y, n))), y', Z)
```

- `μ(s) = depth_S(Z) + 1 = 0 + 1 = 1` (outer F's 3rd arg is Z)
- `μ(t) = depth_S(Z) + 1 = 0 + 1 = 1`

The measure **does not decrease** (`μ(s) = μ(t)`), because the rewrite happened inside the first argument of the outer `F`, but μ only inspects the third argument. The stated argument is unsound.

**Within benchmark boundary?** Yes, but it **fails**.

---

## Conclusion

| Method | Succeeds? | Within Boundary? | Both? |
|--------|-----------|------------------|-------|
| (A) LPO | ✅ Yes | ✅ Yes | ✅ |
| (B) Poly. interp. | ❌ No (non-monotone in y) | ✅ Yes | ❌ |
| (C) KBO | ❌ No (variable condition) | ✅ Yes | ❌ |
| (D) Dep. pairs + subterm | ✅ Yes | ✅ Yes | ✅ |
| (E) Direct measure | ❌ No (counterexample) | ✅ Yes | ❌ |

**Methods satisfying both conditions: (A) and (D).**
