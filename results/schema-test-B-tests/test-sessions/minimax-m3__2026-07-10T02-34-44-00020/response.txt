# Analysis of Each Method

## (A) LPO with precedence F > G > S > Z

**Rule 1: F(x, y, Z) → x**
- RHS is the variable x, which appears in LHS. ✓

**Rule 2: F(x, y, S(n)) → G(y, F(x, y, n))**
- Roots F > G in precedence. ✓
- Need LHS ≻_lpo each RHS argument:
  - LHS ≻_lpo y: y is a variable in LHS. ✓
  - LHS ≻_lpo F(x,y,n): same root F, multiset {x, y, S(n)} ≻_mul {x, y, n} because S(n) ≻_lpo n (n is a variable appearing in S(n)). ✓

**Succeeds. Stays in boundary.** ✓

## (B) Polynomial Interpretation

- I(F(x,y,n)) = x + n + 1, I(S(n)) = n + 1, I(G(a,b)) = b, I(Z) = 0.
- All polynomials have non-negative coefficients (over ℕ). ✓

**Rule 1:** I(F(x,y,Z)) = x + 0 + 1 = x + 1 > x = I(x). Decrease of 1. ✓
**Rule 2:** I(F(x,y,S(n))) = x + (n+1) + 1 = x + n + 2, while I(G(y,F(x,y,n))) = I(F(x,y,n)) = x + n + 1. Decrease of 1. ✓

**Succeeds. Stays in boundary.** ✓

## (C) KBO with Uniform Weights w = 1 (no precedence stated)

Compute term weights (variable weight 0):
- w(F(x,y,S(n))) = 1 + 0 + 0 + 1 + 0 = 2
- w(G(y,F(x,y,n))) = 1 + 0 + 1 + 0 + 0 + 0 = 2

**Rule 1: F(x,y,Z) → x** — RHS is a variable appearing in LHS, w(LHS) > 0. ✓

**Rule 2: F(x,y,S(n)) → G(y,F(x,y,n))** — Roots differ (F vs G) and w(LHS) = w(RHS) = 2.
- Same-root case does not apply.
- Without a precedence F >_F G (none was specified), the precedence condition fails, and the strict weight condition w(LHS) > w(RHS) also fails.

**Does NOT succeed as stated.** The uniform-weight, no-precedence configuration cannot orient the recursive rule. (Contrast with (A), where an explicit precedence is provided.) Stays in boundary, but the proof fails.

## (D) Dependency Pairs with Subterm Criterion (third-argument projection)

Only F is a defined symbol. The only relevant dependency pair comes from Rule 2:
- **DP:** F#(x, y, S(n)) → F#(x, y, n)

Applying the third-argument projection π(t) = third argument of t:
- π(LHS) = S(n), π(RHS) = n
- n is a (proper) subterm of S(n).

The subterm criterion is satisfied: every (in fact, the only) DP chain is strictly decreasing under the subterm relation. Rule 1 contributes no DP. By the DP framework, the system is terminating.

**Succeeds. Stays in boundary.** ✓

## (E) Direct Descent Measure μ

Define μ(F(x,y,n)) = depth_S(n) + 1, μ(G(a,b)) = μ(b), μ(variable) = 0, where depth_S counts leading S symbols (with depth_S(variable) = 0).

**Rule 1:** μ(F(x,y,Z)) = 0 + 1 = 1 > 0 = μ(x). ✓
**Rule 2:** μ(F(x,y,S(n))) = (depth_S(n) + 1) + 1 = depth_S(n) + 2, and μ(G(y,F(x,y,n))) = μ(F(x,y,n)) = depth_S(n) + 1. Strict decrease of 1. ✓

μ is well-founded on ℕ, and the syntactic decrease holds for every rewrite step.

**Succeeds. Stays in boundary.** ✓

## Summary

| Method | Proves Termination? | Stays in Boundary? |
|--------|---------------------|---------------------|
| (A) LPO | ✓ | ✓ |
| (B) Polynomial | ✓ | ✓ |
| (C) KBO uniform weights | ✗ (cannot orient Rule 2) | ✓ |
| (D) DP + subterm | ✓ | ✓ |
| (E) Direct measure | ✓ | ✓ |

**Methods satisfying both conditions: (A), (B), (D), and (E).**

Method (C) fails because, with uniform weights and no stated precedence, the recursive rule F(x,y,S(n)) → G(y,F(x,y,n)) has equal term weights (2 = 2) and distinct root symbols, so KBO cannot orient it.
