## Method A: LPO with precedence F > G > S > Z

**Rule 1: F(x, y, Z) -> x**

**Rule 2: F(x, y, S(n)) -> G(y, F(x, y, n))**
We need F(x, y, S(n)) >_LPO G(y, F(x, y, n)).

- y is a subterm of F(x, y, S(n)), so F(x, y, S(n)) >_LPO y. ✓
- For F(x, y, S(n)) >_LPO F(x, y, n): same root symbol F, comparing arguments lexicographically: x = x, y = y, need S(n) >_LPO n. Since n is a subterm of S(n), this holds. ✓
