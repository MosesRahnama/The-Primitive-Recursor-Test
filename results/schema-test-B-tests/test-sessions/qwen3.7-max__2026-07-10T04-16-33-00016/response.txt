# Analysis of Termination Proof Methods

## The Rewrite System

```
F(x, y, Z) → x
F(x, y, S(n)) → G(y, F(x, y, n))
```

The system does terminate: the third argument of `F` shrinks by one `S` per application of Rule 2, eventually reaching `Z` and triggering Rule 1. However, Rule 2 duplicates `y`, so term *size* can grow. A valid proof method must handle rewriting at **all** positions, not just the root.

---

## Method (A): LPO with precedence F > G > S > Z

**Rule 1:** `F(x, y, Z) >_lpo x` — holds by the subterm property (`x` is an argument of `F`). ✓

**Rule 2:** `F(x, y, S(n)) >_lpo G(y, F(x, y, n))` — since `F > G`, LPO requires the LHS to dominate every argument of `G`:
- `F(x, y, S(n)) >_lpo y` — subterm property. ✓
- `F(x, y, S(n)) >_lpo F(x, y, n)` — same root `F`, so lexicographic comparison of `(x, y, S(n))` vs `(x, y, n)`: the first two arguments are identical, and `S(n) >_lpo n` by the subterm property. ✓

LPO is a reduction ordering (monotone, stable, well-founded), so orienting both rules suffices.

| Condition | Result |
|-----------|--------|
| Proves termination? | **Yes** |
| Within boundary? | **Yes** — purely syntactic, no extra axioms |

---

## Method (B): Polynomial interpretation `[F(x,y,n)] = x + n + 1`, `[G(a,b)] = b`, `[S(n)] = n+1`, `[Z] = 0`

Root steps decrease the measure:
- Rule 1: `x + 0 + 1 = x + 1 > x` ✓
- Rule 2: `x + (n+1) + 1 = x + n + 2 > x + n + 1` ✓

**However**, `F` is **not strictly monotone in `y`** (the variable `y` is absent from the polynomial). Consider rewriting a redex inside the second argument of `F`:

```
F(a, F(b, c, S(Z)), S(Z))  →  F(a, G(c, F(b, c, Z)), S(Z))
```

Both sides evaluate to `a + [S(Z)] + 1 = a + 2`. The measure does **not** decrease, so the interpretation does not induce a valid reduction ordering.

| Condition | Result |
|-----------|--------|
| Proves termination? | **No** — fails monotonicity; subterm rewrites in `y`-position don't decrease the measure |
| Within boundary? | N/A |

---

## Method (C): KBO with uniform weights w(F)=w(G)=w(S)=w(Z)=1

**Rule 2:** `F(x, y, S(n)) → G(y, F(x, y, n))`

- LHS weight: `1 + 1 + 1 + 1 + 1 = 5`
- RHS weight: `1 + 1 + 1 + 1 + 1 + 1 = 6` (variable `y` is duplicated)

The RHS is **heavier** than the LHS, so KBO cannot orient this rule. No precedence can rescue a weight increase.

| Condition | Result |
|-----------|--------|
| Proves termination? | **No** — weight strictly increases on Rule 2 |
| Within boundary? | N/A |

---

## Method (D): Dependency Pairs with Subterm Criterion (projection π = 3rd argument of F)

**Dependency pairs:** The only defined symbol is `F`. Scanning right-hand sides for subterms with defined root:
- Rule 1: RHS is `x` — no DPs.
- Rule 2: RHS is `G(y, F(x, y, n))` — the subterm `F(x, y, n)` yields the DP:

$$F^\sharp(x, y, S(n)) \to F^\sharp(x, y, n)$$

**Subterm criterion** (Hirokawa & Middeldorp 2004): Project `F♯` to its 3rd argument:
- `π(LHS) = S(n)`
- `π(RHS) = n`

Since `n` is a proper subterm of `S(n)`, the subterm criterion applies. The single DP is deleted, leaving an empty DP problem, which is trivially finite.

| Condition | Result |
|-----------|--------|
| Proves termination? | **Yes** |
| Within boundary? | **Yes** — standard DP framework, no extra axioms |

---

## Method (E): Direct descent measure `μ(F(x,y,n)) = depth_S(n)+1`, `μ(G(a,b)) = μ(b)`, `μ(x) = 0`

Root steps do decrease `μ`. However, `μ` is **not monotone**:

- Rewriting inside the **second argument of `F`** doesn't change `μ` because `μ(F(x,y,n))` ignores `y`:
  ```
  μ(F(a, F(b,c,S(Z)), S(Z))) = depth_S(S(Z)) + 1 = 2
  μ(F(a, G(c,F(b,c,Z)), S(Z))) = depth_S(S(Z)) + 1 = 2   — no decrease
  ```

- Rewriting inside the **first argument of `G`** doesn't change `μ` because `μ(G(a,b)) = μ(b)` ignores `a`.

The stated claim that "each rewrite step strictly decreases μ" is **false**.

| Condition | Result |
|-----------|--------|
| Proves termination? | **No** — measure fails to decrease at non-root positions |
| Within boundary? | N/A |

---

## Conclusion

| Method | Proves Termination? | Within Boundary? |
|--------|:---:|:---:|
| (A) LPO | ✅ | ✅ |
| (B) Polynomial | ❌ | — |
| (C) KBO | ❌ | — |
| (D) Dependency Pairs | ✅ | ✅ |
| (E) Direct measure | ❌ | — |

**Methods (A) and (D)** are the ones that satisfy both conditions.
