# Analysis of Proposed Proof Methods

## The Rewrite System

```
Rule 1: F(x, y, Z)    -> x
Rule 2: F(x, y, S(n)) -> G(y, F(x, y, n))
```

This system computes a form of iterated application of G to x, controlled by the third argument. Termination is driven by the decreasing third argument.

---

## Method (A): LPO with precedence F > G > S > Z

**Rule 1: F(x, y, Z) → x**
Since x is a subterm of F(x, y, Z), this is handled by the subterm property of LPO. ✓

**Rule 2: F(x, y, S(n)) → G(y, F(x, y, n))**
With F > G, we need F(x, y, S(n)) >_LPO each argument of G:
- F(x, y, S(n)) >_LPO y: yes, y is a subterm of the left-hand side.
- F(x, y, S(n)) >_LPO F(x, y, n): same root F, compare arguments lexicographically. First two arguments are equal (x, y). Third: S(n) >_LPO n since n is a subterm of S(n). ✓

**Succeeds?** Yes.
**Within boundary?** Yes — LPO is a standard metatheoretic tool applied directly to the given rules.

---

## Method (B): Polynomial interpretation over ℕ

```
[F(x,y,n)] = x + n + 1
[G(a,b)]   = b
[Z]        = 0
[S(n)]     = n + 1
```

**Rule 1: F(x, y, Z) → x**: [LHS] = x + 0 + 1 = x + 1 > x = [RHS]. ✓

**Rule 2: F(x, y, S(n)) → G(y, F(x, y, n))**:
- [LHS] = x + (n + 1) + 1 = x + n + 2
- [RHS] = [G(y, F(x,y,n))] = [F(x,y,n)] = x + n + 1
- x + n + 2 > x + n + 1. ✓

We must verify monotonicity and well-definedness. [G(a,b)] = b: this is weakly monotone in both arguments (monotone in b, weakly in a — but for polynomial interpretations we need **weak** monotonicity in all arguments, which [G] = b satisfies since it's non-decreasing in a (trivially) and in b). All interpretations map to ℕ. ✓

**Succeeds?** Yes.
**Within boundary?** Yes — standard polynomial interpretation applied to the given rules.

---

## Method (C): KBO with uniform weights w = 1

**Weight calculation:**
- w(F(x,y,n)) = 1 + w(x) + w(y) + w(n)
- w(G(a,b)) = 1 + w(a) + w(b)

**Rule 2: F(x, y, S(n)) → G(y, F(x, y, n))**:
- w(LHS) = 1 + w(x) + w(y) + 1 + w(n) = 3 + w(x) + w(y) + w(n)
- w(RHS) = 1 + w(y) + 1 + w(x) + w(y) + w(n) = 3 + w(x) + 2·w(y) + w(n)

For KBO, we need w(LHS) ≥ w(RHS). But w(RHS) - w(LHS) = w(y) ≥ 0, and w(y) > 0 when y is not empty. The variable y appears once on the left but twice on the right, violating the variable condition of KBO (every variable must appear at least as many times on the left as on the right). Variable y appears 1 time on LHS, 2 times on RHS. ✗

**Succeeds?** No.
**Within boundary?** N/A (fails).

---

## Method (D): Dependency pairs with subterm criterion, projecting to third argument of F

The dependency pairs are:
- DP from Rule 2: F#(x, y, S(n)) → F#(x, y, n)

Projecting F# to its third argument: S(n) ▷ n (proper subterm). The subterm criterion is satisfied. ✓

**Succeeds?** Yes.
**Within boundary?** Yes — dependency pair framework with subterm criterion is a standard metatheoretic method applied to the given rules.

---

## Method (E): Direct descent measure

The measure μ is defined on terms syntactically, but this is not a standard termination proof method with established soundness. The definition conflates the measure of a term with its reduct structure. Specifically, μ(G(a,b)) = μ(b) makes the measure depend on the inner structure recursively, but this is essentially recapitulating the polynomial interpretation [G]=b informally. While the reasoning is **correct in substance**, it is essentially an informal restatement of a polynomial interpretation. As stated, it does work: each step strictly decreases μ, and μ is bounded below by 0.

**Succeeds?** Yes.
**Within boundary?** Yes.

---

## Conclusion

**Methods (A), (B), (D), and (E)** satisfy both conditions (they succeed in proving termination and stay within the benchmark boundary).

**Method (C)** fails to prove termination.
