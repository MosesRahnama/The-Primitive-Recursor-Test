## The Rewrite System

- R1: F(x, y, Z) → x
- R2: F(x, y, S(n)) → G(y, F(x, y, n))

The third argument of F decreases (S(n) → n), and G simply wraps its second argument.

---

## Method A: LPO with F > G > S > Z

**R1: F(x, y, Z) → x**
x is a subterm of the left side, so LPO handles this (subterm property). ✓

**R2: F(x, y, S(n)) → G(y, F(x, y, n))**
Need F(x,y,S(n)) >_LPO G(y, F(x,y,n)).
- F > G, so we need each argument of G to be strictly less than F(x,y,S(n)).
- y is a subterm of LHS ✓
- F(x,y,n): F = F, so compare lex: x=x, y=y, then S(n) vs n. Since S(n) >_LPO n ✓

**Succeeds. Within boundary? Yes** — LPO is a purely syntactic, rule-derived method. ✓

---

## Method B: Polynomial interpretation

**R1:** [F(x,y,Z)] = x + 0 + 1 = x+1 > x = [x] ✓

**R2:** [F(x,y,S(n))] = x + (n+1) + 1 = x+n+2
[G(y, F(x,y,n))] = [F(x,y,n)] = x+n+1
x+n+2 > x+n+1 ✓

**Succeeds. Within boundary? Yes** — polynomial interpretations are standard termination machinery applied to the given rules alone. ✓

---

## Method C: KBO with uniform weight w = 1

**KBO requirement:** For a rule l → r, we need w(l) ≥ w(r), and the variable condition (each variable in r appears at least as often in l).

**R1: F(x, y, Z) → x**
- w(LHS) = 1+1+1+1 = 4 (F,x,y,Z), w(RHS) = 1. Weight condition: 4 > 1 ✓
- Variable condition: x appears in LHS ✓ (y is not in RHS, that's fine)

**R2: F(x, y, S(n)) → G(y, F(x, y, n))**
- w(LHS) = 1+1+1+1+1 = 5 (F,x,y,S,n)
- w(RHS) = 1+1+1+1+1+1 = 6 (G,y,F,x,y,n) — y appears twice on RHS but once on LHS!

Variable condition **fails**: y occurs once in LHS but twice in RHS. KBO requires each variable in r to occur no more times than in l.

**Fails.** ✗

---

## Method D: Dependency pairs with subterm criterion, projecting to third argument of F

The dependency pairs from R2: F(x,y,S(n)) → F(x,y,n) (the recursive call inside G).

The subterm criterion: π(F) = 3 (third argument). We need the third argument of the left DP to be a strict superterm of the third argument of the right DP.

Third argument of F(x,y,S(n)) is S(n); third argument of F(x,y,n) is n. S(n) ⊋ n ✓ (strict subterm).

**Succeeds. Within boundary? Yes** — dependency pairs and subterm criterion operate purely on the given rules. ✓

## Method E: Direct descent measure

**R1: F(x,y,Z) → x**
mu(F(x,y,Z)) = depth_S(Z)+1 = 0+1 = 1. mu(x) = 0. 1 > 0 ✓

**R2: F(x,y,S(n)) → G(y, F(x,y,n))**
mu(F(x,y,S(n))) = depth_S(S(n))+1 = (depth_S(n)+1)+1
mu(G(y,F(x,y,n))) = mu(F(x,y,n)) = depth_S(n)+1
So depth_S(n)+2 > depth_S(n)+1 ✓

**Succeeds. Within boundary? Yes** — the measure is defined directly from the structure of the rules. ✓
