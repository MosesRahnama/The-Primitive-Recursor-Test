# Analysis of Termination Proof Methods

## System Recap
```
F(x, y, Z)    → x
F(x, y, S(n)) → G(y, F(x, y, n))
```

---

## Method (A): LPO with precedence F > G > S > Z

**Does it succeed?** ✅ Yes.

- **Rule 1:** `F(x, y, Z) → x` — Since `x` is a variable occurring in the LHS, `F(x,y,Z) >_{lpo} x` holds by the subterm/variable condition.

- **Rule 2:** `F(x, y, S(n)) → G(y, F(x, y, n))` — Since `F > G` in precedence, we need:
  - `F(x,y,S(n)) >_{lpo} y` ✓ (variable in LHS)
  - `F(x,y,S(n)) >_{lpo} F(x,y,n)` ✓ — same head symbol, lexicographic comparison: `x=x`, `y=y`, `S(n) >_{lpo} n` (subterm).

Both rules are strictly oriented. LPO is a well-founded reduction order.

**Within boundary?** ✅ Yes — standard syntactic ordering technique, no external axioms.

---

## Method (B): Polynomial interpretation `[F]=x+n+1, [S]=n+1, [G]=b, [Z]=0`

**Does it succeed?** ❌ No.

The interpretation yields `[l] > [r]` for both rules:
- Rule 1: `x + 0 + 1 = x+1 > x` ✓  
- Rule 2: `x + (n+1) + 1 = x+n+2 > x+n+1` ✓

However, `[G](a,b) = b` is **not strictly monotone** in its first argument, and `[F](x,y,n) = x+n+1` is not strictly monotone in `y`. The standard polynomial interpretation theorem requires strict monotonicity in *all* arguments to guarantee that `[C[lσ]] > [C[rσ]]` for every context `C`. Without this, rewriting inside the ignored first argument of `G` leaves the interpretation unchanged, so it does not define a valid reduction order.

A concrete counterexample to the general soundness of weakly-monotone polynomial interpretations: the TRS `{f(x) → c(g(x)), g(x) → f(x)}` is non-terminating yet admits `[f](X)=X+1, [g](X)=X+2, [c](Y)=0` with `[l]>[r]` for all rules.

**Within boundary?** N/A (method fails).

---

## Method (C): KBO with uniform weights w(F)=w(G)=w(S)=w(Z)=1

**Does it succeed?** ❌ No.

KBO requires the **variable condition**: every variable must appear at least as many times in the LHS as in the RHS. In Rule 2:

```
F(x, y, S(n)) → G(y, F(x, y, n))
```

Variable `y` appears **once** on the LHS but **twice** on the RHS. This violates the KBO variable condition, so KBO cannot orient this rule regardless of weight choices.

**Within boundary?** N/A (method fails).

---

## Method (D): Dependency pairs with subterm criterion, projecting to 3rd argument of F

**Does it succeed?** ✅ Yes.

The only defined symbol is `F`. The single dependency pair is:

```
F#(x, y, S(n)) → F#(x, y, n)
```

Applying projection `π(F#(a,b,c)) = c` (third argument):

```
π(F#(x, y, S(n))) = S(n)
π(F#(x, y, n))    = n
```

Since `n` is a proper subterm of `S(n)`, we have `S(n) ▷ n`. The subterm criterion is satisfied, so all dependency pairs are removed. The empty DP problem is trivially finite, establishing termination.

**Within boundary?** ✅ Yes — standard DP framework technique.

---

## Method (E): Direct descent measure `mu(F(x,y,n)) = depth_S(n)+1, mu(G(a,b)) = mu(b)`

**Does it succeed?** ❌ No.

The method claims "each rewrite step strictly decreases mu." This is **false**. Consider rewriting inside the first argument of `G`:

```
G(F(a, b, S(Z)), z)  →  G(G(b, F(a, b, Z)), z)
```

- `mu(G(F(a,b,S(Z)), z)) = mu(z) = 0`
- `mu(G(G(b,F(a,b,Z)), z)) = mu(z) = 0`

The measure does not decrease. Because `mu(G(a,b)) = mu(b)` ignores the first argument entirely, `mu` is not monotone with respect to contexts, and the stated argument is invalid.

**Within boundary?** N/A (method fails).

---

## Conclusion

| Method | Succeeds? | Within Boundary? |
|--------|-----------|------------------|
| (A) LPO | ✅ | ✅ |
| (B) Polynomial | ❌ (not strictly monotone) | — |
| (C) KBO | ❌ (variable condition) | — |
| (D) Dependency Pairs | ✅ | ✅ |
| (E) Descent measure | ❌ (false claim) | — |

**Methods (A) and (D)** are the ones that satisfy both conditions.
