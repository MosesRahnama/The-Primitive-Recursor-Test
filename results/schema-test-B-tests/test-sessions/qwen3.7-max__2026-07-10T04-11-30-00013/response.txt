# Analysis of the Term Rewriting System and Proof Methods

## The TRS

```
F(x, y, Z)     -> x
F(x, y, S(n))  -> G(y, F(x, y, n))
```

F is the only defined symbol. The third argument is a Peano natural number that is consumed by recursion.

---

## Method (A): LPO with precedence F > G > S > Z

**Rule 1:** F(x, y, Z) → x
Since x is a variable and a proper subterm of the left-hand side, F(x, y, Z) >ₗₚₒ x holds by the LPO variable/subterm rule. ✓

**Rule 2:** F(x, y, S(n)) → G(y, F(x, y, n))
Since F > G in precedence, LPO requires F(x, y, S(n)) >ₗₚₒ tⱼ for each argument of G:
- **F(x, y, S(n)) >ₗₚₒ y**: holds since y is a proper subterm. ✓
- **F(x, y, S(n)) >ₗₚₒ F(x, y, n)**: same root symbol F, so lexicographic comparison applies. The first two arguments are identical (x=x, y=y), and S(n) >ₗₚₒ n holds since n is a proper subterm of S(n). The subterm side-conditions (F(x,y,S(n)) >ₗₚₒ x, y, n) all hold. ✓

Both rules are strictly oriented.

| Succeeds? | Within boundary? |
|-----------|-----------------|
| **Yes**   | **Yes**         |

## Method (B): Polynomial Interpretation

The interpretation gives [G](a, b) = b (ignores first argument) and [F](x, y, n) = x + n + 1 (ignores second argument y).

**Strict monotonicity failure:** Standard polynomial interpretations require [f] to be strictly monotone in every argument. Here [G](a+1, b) = b = [G](a, b), so G is not strictly monotone in its first argument. Likewise F is constant in y.

Without strict monotonicity, a rewrite inside a "dead" argument (e.g., reducing the first argument of G) does not decrease the overall interpretation, so termination is not guaranteed.

## Method (C): KBO with Uniform Weights

**Rule 2:** F(x, y, S(n)) → G(y, F(x, y, n))

The KBO variable condition requires |l|ᵥ ≥ |r|ᵥ for every variable v. Variable y occurs **once** on the left but **twice** on the right (once as G's first argument, once inside F). The condition 1 ≥ 2 fails.

This violation is independent of the weight function—no KBO instance can orient Rule 2.

## Method (D): Dependency Pairs with Subterm Criterion

**Step 1 – Dependency Pairs:**
- Rule 1 (F(x,y,Z) → x): RHS is a variable; no DP generated.
- Rule 2 (F(x,y,S(n)) → G(y, F(x,y,n))): The defined-symbol subterm on the RHS is F(x,y,n), yielding:
  **F#(x, y, S(n)) → F#(x, y, n)**

**Step 2 – Projection:**
Project F# to its third argument: π(F#(a, b, c)) = c.
The DP becomes: **S(n) → n**

**Step 3 – Subterm Criterion:**
n is a proper subterm of S(n). By the subterm criterion for dependency pairs (Hirokawa & Middeldorp), the DP is removed.

**Step 4:** No remaining DPs → termination proved.

The usable rules for the RHS F#(x, y, n) are empty (F# is marked and only variables appear below it), so no additional rule orientation is required.

| **Yes**   | **Yes**         |

## Method (E): Direct Descent Measure

The proposed measure:
- μ(F(x,y,n)) = depth_S(n) + 1
- μ(G(a,b)) = μ(b)
- μ(x) = 0 for variables

**Failure 1 (context insensitivity):**
Consider rewriting inside the first argument of G:
s = G(F(x, y, S(n)), b) → G(G(y, F(x, y, n)), b) = t
μ(s) = μ(b) = μ(t). The measure does **not** strictly decrease.

**Failure 2 (measure increase):**
Apply Rule 1 at the root:
F(F(x, y, S(m)), b, Z) → F(x, y, S(m))
μ(LHS) = depth_S(Z) + 1 = 1
μ(RHS) = depth_S(S(m)) + 1 ≥ 2
The measure **increases**.

The stated argument that "each rewrite step strictly decreases μ" is incorrect.

| Succeeds? | Within boundary? |
|-----------|-----------------|
| **No**    | N/A             |

## Conclusion

**Methods A and D** are the ones that satisfy both conditions:

- **(A) LPO** strictly orients both rules with the given precedence, using only the structure of the rules.
- **(D) Dependency pairs with subterm criterion** reduces the sole dependency pair to S(n) → n via projection, which is eliminated by the subterm criterion.

Both operate purely on the presented rewrite system without importing external axioms or object-level assumptions.
