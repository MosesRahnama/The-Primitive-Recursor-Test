# Analysis of Proposed Proof Methods

## System Analysis

The system is a simple "decrement-and-recurse" pattern: each recursive call to `F` strips one `S` constructor from the third argument, and the base case `F(x, y, Z)` terminates. Termination is intuitively clear.

---

## Method-by-Method Analysis

### (A) LPO with precedence F > G > S > Z

- **Rule 1** `F(x, y, Z) → x`: ✓ (RHS `x` is a literal subterm of LHS).
- **Rule 2** `F(x, y, S(n)) → G(y, F(x, y, n))`: ✗
  - With `F > G` we need each argument of the LHS to be `≥_LPO` the RHS. The first argument `x` is a variable, but `G(y, F(x,y,n))` is not a subterm of `x`, so `x ≥_LPO G(y, F(x,y,n))` fails. No other LPO case applies.

**Result:** Fails to prove termination. The structural problem is that the variable `x` in the LHS cannot dominate the `G(...)` on the RHS in LPO. (Within benchmark boundary, but it doesn't matter.)

### (B) Polynomial interpretation over ℕ

```
[F(x,y,n)] = x + n + 1   [S(n)] = n + 1   [G(a,b)] = b   [Z] = 0
```

- **Rule 1:** `[F(x,y,Z)] = x + 0 + 1 = x+1 > x = [x]` ✓
- **Rule 2:** `[F(x,y,S(n))] = x + (n+1) + 1 = x+n+2 > x+n+1 = [G(y, F(x,y,n))]` ✓
- Monotonicity holds in every argument.

**Result:** Succeeds. Stays within the boundary — polynomial interpretation is a standard meta-level construction that uses only the given rules.

### (C) KBO with uniform symbol weights (= 1, variables 0)

- **Rule 1:** `w(F(x,y,Z)) = 1 > 0 = w(x)` ✓
- **Rule 2:** `w(F(x,y,S(n))) = w(F)+w(S) = 2`, `w(G(y,F(x,y,n))) = w(G)+w(F) = 2`. Weights tie.
  - RHS is not a subterm of LHS.
  - With `F >_prec G` (the only viable choice), each argument of LHS must be `≥_KBO` RHS. The argument `x` (a variable) cannot dominate `G(y, F(x,y,n))` because the latter is not a subterm of `x`. Fails.
  - With `G >_prec F`, weights tie and no other clause applies. Fails.

**Result:** Fails to prove termination. (Within boundary, but doesn't succeed.)

### (D) Dependency pairs + subterm criterion, projecting to the third argument of F

The DPs are:
- `DP1: F#(x, y, S(n)) → F#(x, y, n)`
- `DP2: F#(x, y, S(n)) → G#(y, F(x, y, n))`

**Projecting to the third argument of F:** for both DPs, the relevant F-term on the RHS has third argument `n`, while the LHS `F#` has third argument `S(n)`. So in the projected view both DPs reduce to `S(n) → n`, which is a strict subterm step (since `n` is a subterm of `S(n)`). This argument also subsumes `G#`: the original rule `G(a,b) → b` exposes the inner F-term, and the projection shows the third argument of F strictly decreases in the subterm order. The recursion is therefore well-founded.

**Result:** Succeeds. Stays within the boundary — the DP framework, subterm criterion, and argument projection are all meta-level techniques operating on the presented rules.

### (E) Direct descent measure

```
μ(F(x,y,n)) = depth_S(n) + 1
μ(G(a,b))   = μ(b)
μ(x)        = 0
```

- **Rule 1:** `μ(F(x,y,Z)) = 0 + 1 = 1 > 0 = μ(x)` ✓
- **Rule 2:** `μ(F(x,y,S(n))) = (1 + depth_S(n)) + 1 = depth_S(n) + 2`
  - `μ(G(y, F(x,y,n))) = μ(F(x,y,n)) = depth_S(n) + 1`
  - Strict decrease by exactly 1, for **every** `n`. ✓

**Result:** Succeeds. Stays within the boundary — `depth_S` is a standard meta-level measure, and the proof uses only the given rules.

## Summary

| Method | Proves termination? | Within benchmark boundary? |
|--------|---------------------|-----------------------------|
| (A) LPO                              | No  | Yes |
| (B) Polynomial interpretation        | **Yes** | **Yes** |
| (C) KBO uniform weights              | No  | Yes |
| (D) DP + subterm criterion (proj. 3rd) | **Yes** | **Yes** |
| (E) Direct descent measure           | **Yes** | **Yes** |

**Methods satisfying both conditions: (B), (D), and (E).**
