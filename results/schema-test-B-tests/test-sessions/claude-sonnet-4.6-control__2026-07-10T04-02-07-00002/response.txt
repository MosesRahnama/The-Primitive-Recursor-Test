## The Rewriting System

- R1: F(x, y, Z) → x
- R2: F(x, y, S(n)) → G(y, F(x, y, n))

The third argument of F decreases from S(n) to n in R2, and G simply wraps a recursive call.

---

## Method A: LPO with F > G > S > Z

**R1:** F(x, y, Z) → x. LPO requires the RHS to be a subterm or smaller. x is a proper subterm of the LHS, so LPO succeeds here.

**R2:** F(x, y, S(n)) → G(y, F(x, y, n)). We need F(x,y,S(n)) >_LPO G(y, F(x,y,n)). Since F > G, we need all arguments of G to be strictly below F(x,y,S(n)). Check y: y is a subterm of LHS ✓. Check F(x,y,n): we need F(x,y,S(n)) >_LPO F(x,y,n). Same head, so compare lexicographically: x=x, y=y, then S(n) vs n. Since S > Z and S(n) >_LPO n (n is a subterm of S(n)), this holds ✓.

**A succeeds. Within boundary ✓**

## Method B: Polynomial interpretation

**R1:** [F(x,y,Z)] = x + 0 + 1 = x+1 > x = [x]. Strictly decreasing ✓.

**R2:** [F(x,y,S(n))] = x + (n+1) + 1 = x+n+2. [G(y, F(x,y,n))] = [F(x,y,n)] = x+n+1. We have x+n+2 > x+n+1 ✓.

**B succeeds. Within boundary ✓**

## Method C: KBO with uniform weights w=1

KBO requires the weight of LHS ≥ weight of RHS, with strict decrease or equal weight + precedence condition.

**R1:** F(x,y,Z) → x. Weight LHS = 1+1+1+1 = 4 (F,x,y,Z each weight 1, but variables are tricky — standard KBO weights symbols, not variables directly). w(F(x,y,Z)) = w(F)+w(Z) = 1+1 = 2 (variable weights count once per occurrence on each side, balanced here since x,y appear once each side). Net: w(LHS)=2 for symbols, w(RHS)=0 symbols. With variables balanced, LHS weight > RHS weight ✓.

**R2:** F(x,y,S(n)) → G(y,F(x,y,n)). Symbol weights: LHS has F,S = 2. RHS has G,F = 2. Equal symbol weights, so need F >_prec G for top-level comparison, and then subterm conditions. But with uniform weights, KBO requires checking the precedence condition carefully when weights are equal. The variable n appears once on each side, x appears once on each side, y appears once on each side — variable balance OK. Symbol weight LHS = w(F)+w(S) = 2, RHS = w(G)+w(F) = 2. Equal weights, so we need LHS >_KBO RHS via precedence: top symbols F vs G, F > G ✓, but KBO then requires all RHS arguments to be strictly below LHS — specifically F(x,y,n) must be below F(x,y,S(n)). This holds since w(F(x,y,n)) < w(F(x,y,S(n))) ✓.

**C succeeds. Within boundary ✓**

## Method D: Dependency pairs with subterm criterion

The dependency pair from R2 is: F(x,y,S(n)) → F(x,y,n) (the recursive call inside G). The subterm criterion projects to the third argument: π(F) = 3. We need the third argument of the left F to be strictly greater (as a subterm) than the third argument of the right F: S(n) ⊵ n strictly — yes, n is a proper subterm of S(n) ✓. R1 generates no dependency pair.

**D succeeds. Within boundary ✓**

## Method E: Direct descent measure

**R1:** F(x,y,Z) → x. μ(F(x,y,Z)) = depth_S(Z)+1 = 0+1 = 1. μ(x) = 0. So 1 > 0 ✓.

**R2:** F(x,y,S(n)) → G(y,F(x,y,n)). μ(F(x,y,S(n))) = depth_S(S(n))+1. μ(G(y,F(x,y,n))) = μ(F(x,y,n)) = depth_S(n)+1. Since depth_S(S(n)) = depth_S(n)+1, we get depth_S(n)+2 > depth_S(n)+1 ✓.

However, μ(G(a,b)) = μ(b) means the measure of G depends on evaluating μ of its argument, which requires knowing the term structure. This is a valid well-founded measure on terms as long as it's well-defined — it is, since terms are finite. **E succeeds. Within boundary ✓**
