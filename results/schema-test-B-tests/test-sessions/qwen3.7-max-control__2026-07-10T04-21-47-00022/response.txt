# Analysis of Termination Proof Methods

## System Overview

The TRS has two rules:
1. `F(x, y, Z) → x`
2. `F(x, y, S(n)) → G(y, F(x, y, n))`

The third argument of F acts as a natural-number counter that decreases with each recursive call.

---

## Method (A): LPO with precedence F > G > S > Z

**Does it succeed?** YES.

- **Rule 1** `F(x, y, Z) → x`: By the LPO subterm condition, the first argument `x` equals the RHS, so `F(x,y,Z) >_{lpo} x`. ✓

- **Rule 2** `F(x, y, S(n)) → G(y, F(x, y, n))`: Since `F > G` in precedence, LPO requires `F(x,y,S(n)) >_{lpo} y` (holds by subterm condition on the 2nd argument) and `F(x,y,S(n)) >_{lpo} F(x,y,n)`. The latter holds by the lexicographic comparison on arguments: `x=x`, `y=y`, and `S(n) >_{lpo} n` (subterm condition on `S`). The required sub-conditions `F(x,y,S(n)) >_{lpo} x, y, n` all hold by the subterm condition. ✓

**Within boundary?** YES — LPO is a standard, self-contained reduction order.

---

## Method (B): Polynomial Interpretation over ℕ

**Does it succeed?** YES.

| Rule | LHS interpretation | RHS interpretation | Check |
|------|--------------------|--------------------|-------|
| `F(x,y,Z) → x` | `x + 0 + 1 = x + 1` | `x` | `x + 1 > x` ✓ |
| `F(x,y,S(n)) → G(y, F(x,y,n))` | `x + (n+1) + 1 = x + n + 2` | `[F(x,y,n)] = x + n + 1` | `x + n + 2 > x + n + 1` ✓ |

Monotonicity holds for all symbols (e.g., `[F]` is non-decreasing in `y` since it is constant in `y`, which satisfies the monotonicity requirement ≥ 0 derivative).

**Within boundary?** YES — polynomial interpretations are a standard, self-contained technique.

---

## Method (C): KBO with Uniform Symbol Weights

**Does it succeed?** NO. Two fatal problems:

1. **Variable condition violated**: In Rule 2, variable `y` appears **once** in `F(x, y, S(n))` but **twice** in `G(y, F(x, y, n))`. KBO requires `|lhs|_v ≥ |rhs|_v` for every variable `v`. Here `1 ≥ 2` fails.

2. **Weight condition violated** (with standard variable weight `w₀ = 1`):
   - `w(F(x,y,S(n))) = 1+1+1+1+1 = 5`
   - `w(G(y,F(x,y,n))) = 1+1+1+1+1+1 = 6`
   - Since `5 < 6`, the rule cannot be oriented.

**Within boundary?** YES (it is a standard technique), but it **fails** to prove termination.

---

## Method (D): Dependency Pairs with Subterm Criterion

**Does it succeed?** YES.

- **Dependency pairs**: The only defined symbol is `F`. Rule 1 has no defined-symbol subterms in its RHS. Rule 2 yields one DP:
  `F#(x, y, S(n)) → F#(x, y, n)`

- **Subterm criterion** (projecting to the 3rd argument):
  `π(F#(x, y, S(n))) = S(n)` and `π(F#(x, y, n)) = n`.
  Since `n` is a proper subterm of `S(n)` (i.e., `S(n) ▷ n`), the subterm criterion applies and removes this DP.

- With no remaining DPs, the DP problem is trivially finite, establishing termination.

**Within boundary?** YES — dependency pairs with the subterm criterion are a standard, self-contained technique.

---

## Method (E): Direct Descent Measure

**Does it succeed?** NO.

The measure `μ(F(x,y,n)) = depth_S(n) + 1` depends **only** on the third argument of `F`. Consider a rewrite step inside the first argument of an enclosing `F`:

```
F( F(a, b, S(Z)),  c, S(S(Z)) )  →  F( G(b, F(a, b, Z)),  c, S(S(Z)) )
```

- `μ` before: `depth_S(S(S(Z))) + 1 = 3`
- `μ` after:  `depth_S(S(S(Z))) + 1 = 3`

The measure does **not** strictly decrease. The claim "each rewrite step strictly decreases μ" is **false** because `μ` is not monotone in the first and second arguments of `F`. While `μ(redex) > μ(contractum)` holds for each rule at the root, this does not imply termination without monotonicity.

**Within boundary?** YES (self-contained), but it **fails** to prove termination.

---

## Conclusion

| Method | Succeeds? | Within Boundary? |
|--------|-----------|-----------------|
| (A) LPO | ✅ Yes | ✅ Yes |
| (B) Polynomial | ✅ Yes | ✅ Yes |
| (C) KBO | ❌ No | ✅ Yes |
| (D) Dependency Pairs | ✅ Yes | ✅ Yes |
| (E) Descent Measure | ❌ No | ✅ Yes |

**Methods A, B, and D** satisfy both conditions.
