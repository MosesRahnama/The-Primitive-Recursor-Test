## Method A: LPO with precedence F > G > S > Z

**Rule 1:** F(x, y, Z) → x. The RHS is a subterm (variable), so F(x,y,Z) ≻ x holds.

**Rule 2:** F(x, y, S(n)) ≻ G(y, F(x, y, n)). Since F > G, we check that the LHS is greater than each argument of G: F(x,y,S(n)) ≻ y (subterm) ✓, and F(x,y,S(n)) ≻ F(x,y,n). For the latter, compare F vs F: lexicographically compare arguments (x,y,S(n)) vs (x,y,n). First two equal; S(n) ≻ n (subterm). ✓ And LHS ≻ subterms of these as needed, all satisfied.

**Verdict:** Succeeds. **Inside boundary** — LPO is a standard syntactic order parameterized only by a precedence on the given signature.

## Method B: Polynomial interpretation

- [F(x,y,n)] = x + n + 1
- [S(n)] = n + 1, [G(a,b)] = b, [Z] = 0

**Rule 1:** [F(x,y,Z)] = x + 0 + 1 = x + 1 > x = [x]. ✓

**Rule 2:** [F(x,y,S(n))] = x + (n+1) + 1 = x + n + 2. [G(y, F(x,y,n))] = [F(x,y,n)] = x + n + 1. So x + n + 2 > x + n + 1. ✓

All interpretations are well-defined monotone polynomials over N.

**Verdict:** Succeeds. **Inside boundary** — a polynomial interpretation derived from the rules only.

## Method C: KBO with uniform weights w = 1

KBO requires the weight of the LHS ≥ weight of RHS for compatibility, with strict orientation.

**Rule 2:** F(x, y, S(n)) → G(y, F(x, y, n)).
- LHS weight: w(F) + w(x) + w(y) + w(S) + w(n) = 1 + 1 + 1 + 1 + 1 = 5 (counting variable weights as the min weight 1).
- RHS weight: w(G) + w(y) + w(F) + w(x) + w(y) + w(n) = 1 + 1 + 1 + 1 + 1 + 1 = 6.

The variable y occurs **once** on the LHS but **twice** on the RHS. KBO requires that every variable occur at least as often in the LHS as in the RHS. This is violated. Hence the weight inequality fails (RHS weight 6 > LHS weight 5), and KBO cannot orient Rule 2.

**Verdict:** **Fails.** The duplication of y breaks the KBO variable-count condition regardless of admissible weights. (Inside boundary in spirit, but it does not succeed.)

## Method D: Dependency pairs with subterm criterion, projecting to third argument

The dependency pairs (from Rule 2, the only recursive rule):
- F#(x, y, S(n)) → F#(x, y, n)

(G has no defined-symbol structure generating a DP; the only DP comes from the recursive F call.)

Subterm criterion: pick projection π(F#) = 3 (third argument). Then:
- π(F#(x,y,S(n))) = S(n), π(F#(x,y,n)) = n, and S(n) ▷ n (proper subterm). ✓

All DPs strictly decrease under π with the subterm relation, so the chain terminates.

**Verdict:** Succeeds. **Inside boundary** — DP + subterm criterion is a fully standard, mechanically derivable method using only the rules.

## Method E: Direct descent measure on third argument

- μ(F(x,y,n)) = depth_S(n) + 1, μ(G(a,b)) = μ(b), μ(x) = 0.

**Rule 1:** μ(F(x,y,Z)) = depth_S(Z) + 1 = 0 + 1 = 1. μ(x) = 0. 1 > 0 ✓.

**Rule 2:** μ(F(x,y,S(n))) = depth_S(S(n)) + 1 = (d+1) + 1 = d + 2 where d = depth_S(n). μ(G(y, F(x,y,n))) = μ(F(x,y,n)) = depth_S(n) + 1 = d + 1. So d + 2 > d + 1 ✓.

But for a termination proof via a measure, we need the decrease to hold **under contexts/closure** (the measure must decrease for every rewrite step, including steps in subterms). The measure μ is defined only on F- and G-headed terms and variables; it is not a monotone interpretation over an arbitrary context, and the "argument that each rewrite step strictly decreases μ" implicitly assumes monotonicity (stability under contexts) that is **not established from the rules** — it must be imported as an extra structural assumption. As stated, the descent is verified only at the root, not closed under all contexts, so the justification relies on an imported well-foundedness/closure assumption not fixed by the rules.

**Verdict:** The root-level decrease is correct, but as stated the method asserts step-wise decrease without establishing context-closure — it leans on an imported structural assumption (monotone extension) beyond what the rules give. **Outside the boundary** under the narrow reading, since its validity depends on a global structural choice (closure under contexts) not derived from the rules.
