# Analysis of the Rewrite System and Proof Methods

## The System
```
F(x, y, Z)  →  x
F(x, y, S(n))  →  G(y, F(x, y, n))
```

Note that `G` has no defining rule, so it is a constructor; the only defined symbol is `F`. Recursion on `F` is driven by the third argument, with the base case `Z`.

---

## Method A — LPO with precedence F > G > S > Z

**Rule 1:** `F(x, y, Z) → x`. The RHS `x` is a variable that occurs in the LHS. LPO accepts this. ✓

**Rule 2:** `F(x, y, S(n)) → G(y, F(x, y, n))`. The RHS root is `G`, with `F >_prec G`. We need `s >_lpo` every strict subterm of the RHS, i.e., `s >_lpo y` (a variable in `s`, ✓) and `s >_lpo F(x, y, n)`. Comparing `F(x, y, S(n))` with `F(x, y, n)` lexicographically: `x = x`, `y = y`, and `S(n) >_lpo n` (variable `n` occurs in `S(n)`). ✓

**Verdict:** Succeeds. Uses only the stated precedence on the given terms. **In boundary.**

## Method B — Polynomial Interpretation over ℕ

```
[F(x,y,n)] = x + n + 1,   [G(a,b)] = b,   [S(n)] = n + 1,   [Z] = 0
```

All interpretations are monotone in their arguments. ✓

- Rule 1: `[F(x,y,Z)] = x + 0 + 1 = x + 1 > x = [x]`. ✓
- Rule 2: `[F(x,y,S(n))] = x + (n+1) + 1 = x + n + 2` vs. `[G(y, F(x,y,n))] = [F(x,y,n)] = x + n + 1`. Strict decrease. ✓

**Verdict:** Succeeds. Polynomial interpretation is a standard generic tool over ℕ; it imposes no extra structural axioms on the rewrite system. **In boundary.**

## Method C — KBO with uniform weights w(·) = 1

- Rule 1: `w(F(x,y,Z)) = 1+1+1 = 3 > 0 = w(x)`. ✓ (Also, the variable `x` appears in the LHS.)
- Rule 2: `w(F(x,y,S(n))) = 1+1+1+1 = 4` vs. `w(G(y, F(x,y,n))) = 1+0+1+0+0 = 2`. Strict weight decrease. ✓ All RHS variables (`x, y, n`) appear in the LHS. ✓

Because weight strictly decreases, no precedence/status comparison is even needed.

**Verdict:** Succeeds. **In boundary.**

## Method D — Dependency Pairs + Subterm Criterion (projected to 3rd arg of F)

Since only `F` is defined (no rule for `G`), there is exactly one DP:

```
F#(x, y, S(n)) → F#(x, y, n)
```

Project both sides to the third argument of `F`: LHS gives `S(n)`, RHS gives `n`. The term `n` is a strict subterm of `S(n)`, so the subterm criterion under the third-argument filter applies. ✓

(Note: there is no DP for `G`, since `G` has no rules — it is a sink, so no chain can re-enter from `G` either.)

**Verdict:** Succeeds. **In boundary.**

## Method E — Direct Descent Measure

```
mu(F(x,y,n)) = depth_S(n) + 1
mu(G(a,b))   = mu(b)
mu(x)        = 0   (for variables)
```

- Rule 1: `mu(F(x,y,Z)) = 0 + 1 = 1 > 0 = mu(x)`. ✓
- Rule 2: `mu(F(x,y,S(n))) = (1 + depth_S(n)) + 1 = depth_S(n) + 2` vs. `mu(G(y, F(x,y,n))) = mu(F(x,y,n)) = depth_S(n) + 1`. Strict decrease. ✓

`depth_S` is a purely syntactic notion (counting leading `S` symbols), so this stays internal to the term algebra.

**Verdict:** Succeeds. **In boundary.**

## Summary

| Method | Proves termination? | Stays within the stated boundary? |
|--------|---------------------|-----------------------------------|
| A (LPO)         | Yes | Yes |
| B (Poly interp) | Yes | Yes |
| C (KBO)         | Yes | Yes |

**Conclusion:** All five methods (A, B, C, D, E) succeed in proving strong normalization of the system **and** all five stay within the benchmark boundary — each is a generic termination technique applied to the rewrite rules as given, with no imported structural axioms or object-level assumptions.
