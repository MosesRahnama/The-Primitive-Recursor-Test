# Analysis of Each Proof Method

## (A) LPO with precedence F > G > S > Z

**Success?** Yes.

- Rule 1: `F(x,y,Z) -> x` holds trivially by the subterm property of LPO.
- Rule 2: `F(x,y,S(n)) -> G(y,F(x,y,n))`. Since F > G, we need `F(x,y,S(n)) > y` and `F(x,y,S(n)) > F(x,y,n)`.
  - `F(x,y,S(n)) > y` holds by the subterm property.
  - `F(x,y,S(n)) > F(x,y,n)`: same head symbol, so compare argument tuples lexicographically. The first two arguments are syntactically identical; at the third position `S(n) > n` holds by the subterm property. The domination condition `F(x,y,S(n)) > x, y, n` holds trivially (again subterm property, using `S(n) ▷ n`).

Both rules are oriented, so LPO succeeds.

**Boundary?** Yes — LPO is a purely syntactic order defined from term structure and a symbol precedence; nothing beyond the rules/signature is used.

## (B) Polynomial interpretation

**Success?** Yes.

- Rule 1: `[F(x,y,Z)] = x+0+1 = x+1 > x = [x]`. ✓
- Rule 2: `[F(x,y,S(n))] = x+(n+1)+1 = x+n+2`, and `[G(y,F(x,y,n))] = [F(x,y,n)] = x+n+1`. Since `x+n+2 > x+n+1` for all natural numbers, the inequality holds. ✓

All interpretations are weakly monotonic (constant dependencies are trivially monotonic), so this is a valid reduction order and both rules strictly decrease.

**Boundary?** Yes — this is a standard algebraic interpretation into (ℕ, >), a routine termination technique using only the given signature/rules.

## (C) KBO with uniform weight 1

**Success?** No.

- Rule 1: weight(LHS) = 4, weight(RHS) = 1. OK (4 > 1).
- Rule 2: weight(`F(x,y,S(n))`) = 1+1+1+(1+1) = 5. Weight(`G(y,F(x,y,n))`) = 1+1+(1+1+1+1) = 6.

Since **6 > 5**, the weight condition required by KBO (weight of LHS ≥ weight of RHS) is **violated** for rule 2. This specific weight assignment cannot orient the second rule, so KBO as stated fails.

**Boundary?** Moot — since the method does not succeed, the boundary question does not apply favorably; no illicit assumptions are used, but the technique simply fails.

## (D) Dependency pairs + subterm criterion (projection to 3rd argument of F)

**Success?** Yes.

- G is not a defined symbol (no rules define it), so the only dependency pair arising from rule 2 is:
  `F#(x,y,S(n)) -> F#(x,y,n)`
- Rule 1 produces no dependency pair (RHS is a variable).
- Using projection `π(F#(x,y,n)) = n`: `π(LHS) = S(n)`, `π(RHS) = n`, and `n` is a strict subterm of `S(n)`.

This satisfies the subterm criterion for the single cycle in the dependency graph, so there are no infinite DP chains, and termination follows.

**Boundary?** Yes — DP with subterm criterion is a standard, purely syntactic technique derived directly from the rule set; no extra axioms are needed.

## (E) Direct descent measure

**Success?** No — the argument as stated is flawed.

The claim "each rewrite step strictly decreases μ" is checked only for *root-level* applications of the two rules. But rewriting is closed under arbitrary contexts and substitutions: `x` and `y` in `F(x,y,n)` can themselves be instantiated with complex terms (including nested `F`'s), and μ as defined **ignores changes in the first two arguments of F (and the first argument of G)**.

Concrete counterexample: let
`t = F( F(a,b,S(Z)), y, Z )`.
Since μ(F(...,...,Z)) = 1 regardless of the first two arguments, we get μ(t) = 1. Rewriting the *inner* redex `F(a,b,S(Z)) -> G(b,F(a,b,Z))` yields
`t' = F( G(b,F(a,b,Z)), y, Z )`, and again μ(t') = 1.

So this legitimate rewrite step does **not** decrease μ at all, contradicting the claim that "each rewrite step strictly decreases μ." The measure lacks the monotonicity/context-compatibility property required of a genuine reduction order, so the argument does not establish strong normalization as stated.

**Boundary?** Also problematic — to repair the argument one would need to either restrict to outermost rewriting (an extra, unstated strategy assumption not licensed by the rules alone) or redefine μ so it is context-monotonic (a different method). As presented, the method both fails to prove termination and implicitly relies on an unstated assumption (that only the shown redex positions need be checked), exceeding what is justified by the rules alone.
