Then we require that for each DP l^# -> r^#, proj(l) ▷ proj(r) (i.e., proj(l) contains proj(r) as a strict subterm). If that holds, then there is no infinite chain.

Alternatively, the subterm criterion can be used to delete DPs: if for a DP, the right projection is a proper subterm of the left projection, then that DP can be removed.
