# Analysis of Each Method

## The System Recap

Only two rules; F is the sole defined symbol, and S, Z, G are constructors. Every rewrite step is rooted at F, and rule 2's recursive call replaces the third argument S(n) with the strictly smaller n. The system is clearly terminating.

---

### (A) LPO with precedence F > G > S > Z

- **Rule 1:** F(x,y,Z) ≻_lpo x. The variable x is a subterm of F(x,y,Z). ✓
- **Rule 2:** F(x,y,S(n)) ≻_lpo G(y, F(x,y,n)). Since F >_prec G, it suffices to show F(x,y,S(n)) ≻_lpo y and ≻_lpo F(x,y,n). The first is a subterm. The second uses multiset status: {x, y, S(n)} ≻_mul {x, y, n} because S(n) ≻_lpo n (n is a subterm of S(n)). ✓

**Succeeds; within the boundary.** The LPO is applied purely to the two given rules with a finite precedence — no structural import.

---

### (B) Polynomial Interpretation over ℕ

Check strict decrease:
- Rule 1: [F(x,y,Z)] = x + 0 + 1 = x+1 > x = [x]. ✓
- Rule 2: [F(x,y,S(n))] = x + (n+1) + 1 = x+n+2 > x+n+1 = [F(x,y,n)] = [G(y, F(x,y,n))]. ✓

All interpretations are weakly monotone (non-negative coefficients). The well-foundedness of (ℕ, >) is ordinary metatheory.

**Succeeds; within the boundary.**

---

### (C) KBO with Uniform Weights w(F)=w(G)=w(S)=w(Z)=1

Compute weights (variables contribute 0):
- Rule 1: |F(x,y,Z)|_w = 1+1 = 2 > 0 = |x|_w. ✓
- Rule 2: |F(x,y,S(n))|_w = 1+1 = 2. |G(y, F(x,y,n))|_w = 1+1 = **2** (the F inside counts!). The weights are **equal**.

With equal weights and different root symbols (F vs. G), no precedence condition (whether F >_prec G or G >_prec F) can rescue the orientation: the KBO requires the LHS root to dominate the RHS root either by strict weight or by strict precedence *combined with dominance on arguments*. A variable x on the LHS cannot dominate the G-term on the RHS. The rule cannot be oriented.

**Fails.** The method does not prove termination.

---

### (D) Dependency Pairs with Subterm Criterion, Projecting to the Third Argument of F

The only DP is F(x,y,S(n)) → F(x,y,n) (the constructor G in the RHS of rule 2 is discarded under argument filter π(F) = {3}).

The projected DP becomes S(n) → n, where n is a strict subterm of S(n). The subterm relation on the term algebra is well-founded (standard metatheory), so the DP chain is finite. By the soundness of argument filtering in the DP framework, the original system terminates.

**Succeeds; within the boundary.** The projection is a structural choice driven by the rule's own recursive structure; well-foundedness of subterm is ordinary metatheory.

---

### (E) Direct Descent Measure μ

Define depth_S(n) as the number of S symbols on the spine of the third argument of F (0 for variables, Z, or non-S roots). Then:

- Rule 1: μ(F(x,y,Z)) = 0 + 1 = 1 > 0 = μ(x). ✓
- Rule 2: μ(F(x,y,S(n))) = depth_S(n) + 2 > depth_S(n) + 1 = μ(F(x,y,n)) = μ(G(y, F(x,y,n))). ✓

Every step strictly decreases a ℕ-valued measure; well-foundedness of (ℕ, >) gives termination.

**Succeeds; within the boundary.** μ is defined over the term algebra using only the recursive structure visible in the rules; no external structural axiom is invoked.

---

## Summary

| Method | Proves termination? | Within benchmark boundary? |
|--------|---------------------|----------------------------|
| A (LPO)            | Yes | Yes |
| B (Poly interp.)   | Yes | Yes |
| C (KBO uniform)    | **No** (rule 2 unorientable) | — |
| D (DP + subterm + projection) | Yes | Yes |
| E (Direct μ)       | Yes | Yes |

**Methods satisfying both conditions: A, B, D, and E.**
