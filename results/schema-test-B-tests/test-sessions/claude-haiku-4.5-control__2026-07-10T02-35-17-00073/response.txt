## **(A) Lexicographic Path Order (LPO) with precedence F > G > S > Z**

**Does it succeed?**

For Rule 1: `F(x, y, Z) → x`
- LPO compares F(x, y, Z) with x. Since F is the top symbol and x is a variable, and F > any symbol in x, this holds by the variable criterion. ✓

For Rule 2: `F(x, y, S(n)) → G(y, F(x, y, n))`
- LPO compares F(x, y, S(n)) with G(y, F(x, y, n)).
- F > G by precedence, so we need F(x, y, S(n)) >_LPO each argument of G.
- Does F(x, y, S(n)) >_LPO y? Yes (F is the top symbol of the left side, y is a variable). ✓
- Does F(x, y, S(n)) >_LPO F(x, y, n)? 
  - By LPO, since the top symbols are equal, we compare argument sequences lexicographically.
  - Arguments of both are (x, y, S(n)) vs (x, y, n).
  - First two arguments are identical; comparing S(n) vs n: S > any symbol in n, so S(n) >_LPO n. ✓

LPO succeeds. ✓

**Within boundary?**

LPO is a standard, metatheoretic proof technique that derives its soundness from general properties of term orderings and recursion. The precedence F > G > S > Z is fixed by the method statement itself—it is not an arbitrary external structural axiom imported from outside. The method uses only standard ordering machinery.

Yes, within boundary. ✓

## **(E) Direct descent measure**

**Does it succeed?**

Measure:
- mu(F(x,y,n)) = depth_S(n) + 1 (depth of nesting of S symbols in n, plus 1)
- mu(G(a,b)) = mu(b)
- mu(x) = 0 for variables
- [Z = 0, S(n) has depth_S = 1 + depth_S(n)]

For Rule 1: `F(x, y, Z) → x`
- mu(F(x, y, Z)) = depth_S(Z) + 1 = 0 + 1 = 1
- mu(x) = 0
- Is 1 > 0? Yes. ✓

For Rule 2: `F(x, y, S(n)) → G(y, F(x, y, n))`
- mu(F(x, y, S(n))) = depth_S(S(n)) + 1 = (1 + depth_S(n)) + 1 = depth_S(n) + 2
- mu(G(y, F(x, y, n))) = mu(F(x, y, n)) = depth_S(n) + 1
- Is depth_S(n) + 2 > depth_S(n) + 1? Yes. ✓

The measure succeeds. ✓

**Within boundary?**
