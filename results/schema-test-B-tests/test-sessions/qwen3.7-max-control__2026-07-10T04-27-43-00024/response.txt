# Analysis of Termination Proof Methods

## System Overview

The rules are:
1. `F(x, y, Z) → x`
2. `F(x, y, S(n)) → G(y, F(x, y, n))`

The third argument of `F` acts as a natural number (Peano-style), decreasing with each application of rule 2 until it reaches `Z`, where rule 1 eliminates `F`.

---

## Method A: LPO with precedence F > G > S > Z

**Does it succeed?** Yes.

- **Rule 1:** `F(x, y, Z) >_{LPO} x` — holds by the subterm property (x is an argument of F).
- **Rule 2:** `F(x, y, S(n)) >_{LPO} G(y, F(x, y, n))` — since `F > G` in the precedence, we need `F(x, y, S(n)) >_{LPO}` each argument of `G`:
  - `>_{LPO} y`: holds by subterm property.
  - `>_{LPO} F(x, y, n)`: same root symbol `F`, so compare lexicographically. Arguments `x = x`, `y = y`, and `S(n) >_{LPO} n` (subterm property). We also verify `F(x, y, S(n)) >_{LPO} t_j` for each argument `t_j ∈ {x, y, n}` of the RHS, all of which hold by the subterm property.

Both rules are strictly oriented. LPO is a well-founded reduction order.

**Within boundary?** Yes — LPO is a standard metatheoretic technique using only the given rules and a symbol precedence.

---

## Method B: Polynomial interpretation over ℕ

**Does it succeed?** No.

Checking the rules:
- Rule 1: `[F(x,y,Z)] = x + 0 + 1 = x + 1 > x = [x]` ✓
- Rule 2: `[F(x,y,S(n))] = x + n + 2 > x + n + 1 = [G(y, F(x,y,n))]` ✓

However, `[G(a,b)] = b` is **not strictly monotone** in its first argument: `[G(a₁, b)] = b = [G(a₂, b)]` regardless of `a₁, a₂`. Consequently, the induced order is **not closed under contexts**. For example:

```
G(F(x,y,S(n)), c) → G(G(y,F(x,y,n)), c)
```
yields `[LHS] = c = [RHS]` — no strict decrease. The interpretation does not constitute a valid reduction order.

**Within boundary?** N/A (fails condition 1).

---

## Method C: KBO with uniform weights w(F)=w(G)=w(S)=w(Z)=1

**Does it succeed?** No.

KBO requires the **variable condition**: every variable must occur at least as many times in the LHS as in the RHS. For Rule 2:

| Variable | Occurrences in LHS | Occurrences in RHS |
|----------|--------------------|--------------------|
| x        | 1                  | 1                  |
| y        | 1                  | **2**              |
| n        | 1                  | 1                  |

Variable `y` appears **once** in `F(x, y, S(n))` but **twice** in `G(y, F(x, y, n))`. This violates the variable condition (`1 < 2`), so KBO cannot orient Rule 2 regardless of weights or precedence.

**Within boundary?** N/A (fails condition 1).

---

## Method D: Dependency pairs with subterm criterion

**Does it succeed?** Yes.

**DP construction:** The only defined symbol is `F` (root of LHS). Examining RHS subterms with defined roots:
- Rule 1: `x` — variable, no DP.
- Rule 2: `G(y, F(x, y, n))` — `G` is not defined; `F(x, y, n)` yields the single DP:

> `F#(x, y, S(n)) → F#(x, y, n)`

**Subterm criterion** with projection `π(F#) = 3` (third argument):
- `π(F#(x, y, S(n))) = S(n)`
- `π(F#(x, y, n)) = n`
- `S(n) ▷ n` (proper subterm) ✓

The subterm criterion (Hirokawa & Middeldorp) states that if `π(s) ▷ π(t)` for all DPs, the DP problem is finite. The criterion is satisfied, so the system terminates.

**Within boundary?** Yes — dependency pairs and the subterm criterion are standard metatheoretic techniques using only the given rules.

---

## Method E: Direct descent measure

**Does it succeed?** No.

The measure claims `μ` strictly decreases for every rewrite step. This is **false** even at the root. Consider Rule 1 applied to:

```
F(F(a, b, S(S(Z))), y, Z) → F(a, b, S(S(Z)))
```

- `μ(F(F(a,b,S(S(Z))), y, Z)) = depth_S(Z) + 1 = 1`
- `μ(F(a, b, S(S(Z)))) = depth_S(S(S(Z))) + 1 = 3`

The measure **increases** from 1 to 3. Additionally, rewriting inside the first argument of `G` leaves `μ` unchanged (since `μ(G(a,b)) = μ(b)` ignores the first argument). The stated argument is incorrect.

**Within boundary?** N/A (fails condition 1).
