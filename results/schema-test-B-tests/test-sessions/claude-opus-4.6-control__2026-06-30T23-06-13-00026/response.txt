# Analysis of Proposed Proof Methods

## The Rewrite System

```
Rule 1: F(x, y, Z)    -> x
Rule 2: F(x, y, S(n)) -> G(y, F(x, y, n))
```

This is a classic primitive-recursion-style system where the third argument decreases structurally.

---

## Method (A): LPO with precedence F > G > S > Z

**Rule 1: F(x, y, Z) → x**
With LPO, we need F(x, y, Z) > x. Since x is a subterm of F(x, y, Z), this holds by the subterm property. ✓

**Rule 2: F(x, y, S(n)) → G(y, F(x, y, n))**
With LPO and F > G, we need F(x, y, S(n)) > G(y, F(x, y, n)). Since F > G, it suffices to show F(x, y, S(n)) > y and F(x, y, S(n)) > F(x, y, n). The first holds by the subterm property (y is a subterm). For the second, we compare F(x, y, S(n)) vs F(x, y, n): same head symbol, lexicographically comparing arguments — first two are equal, and S(n) >_LPO n by the subterm property. ✓

**Does it succeed?** Yes.
**Within boundary?** Yes — LPO is a standard metatheoretic technique applied directly to the given rules.

---

## Method (B): Polynomial interpretation over ℕ

```
[F(x,y,n)] = x + n + 1
[G(a,b)] = b
[Z] = 0
[S(n)] = n + 1
```

**Rule 1: F(x, y, Z) → x**
LHS: x + 0 + 1 = x + 1. RHS: x. We need x + 1 > x. ✓

**Rule 2: F(x, y, S(n)) → G(y, F(x, y, n))**
LHS: x + (n + 1) + 1 = x + n + 2.
RHS: [G(y, F(x, y, n))] = [F(x, y, n)] = x + n + 1.
We need x + n + 2 > x + n + 1. ✓

We must also verify monotonicity and that all interpretations map ℕ^k → ℕ. All polynomials have non-negative coefficients and are weakly monotone. ✓

**Does it succeed?** Yes.
**Within boundary?** Yes — standard polynomial interpretation applied to the given rules.

---

## Method (C): KBO with uniform weights w = 1

**Rule 2: F(x, y, S(n)) → G(y, F(x, y, n))**
KBO first checks weight. LHS weight: w(F) + w(x) + w(y) + w(S) + w(n) — but variable weights contribute their count. The weight of LHS = 1(F) + 1(S) + variables {x, y, n} each with weight w₀ (the variable weight, which for uniform weight 1 is typically 1). So weight(LHS) = 2 + 3w₀.
Weight of RHS: 1(G) + 1(F) + variables {y, x, y, n}. Weight = 2 + (x: w₀) + (y: 2w₀) + (n: w₀) = 2 + 4w₀.

The variable y appears once on LHS but twice on RHS, so weight(RHS) = 2 + 4w₀ > 2 + 3w₀ = weight(LHS). The RHS is **heavier**, so KBO fails.

**Does it succeed?** No.
**Within boundary?** N/A (it fails).

## Method (D): Dependency pairs with subterm criterion

The dependency pairs are:
- DP from Rule 2: F#(x, y, S(n)) → F#(x, y, n)

Projecting to the third argument: S(n) ≻ n by the proper subterm relation. The subterm criterion is satisfied. ✓

**Does it succeed?** Yes.
**Within boundary?** Yes — standard dependency pair framework applied to the given rules.

## Method (E): Direct descent measure

The proposed measure μ(F(x, y, n)) = depth_S(n) + 1, μ(G(a, b)) = μ(b).

**Rule 2: F(x, y, S(n)) → G(y, F(x, y, n))**
LHS: depth_S(S(n)) + 1. RHS: μ(G(y, F(x, y, n))) = μ(F(x, y, n)) = depth_S(n) + 1. This is strictly less. ✓

**Rule 1: F(x, y, Z) → x**
LHS: μ = depth_S(Z) + 1 = 1. RHS: μ(x) = 0. Strict decrease. ✓

However, this "measure" is not well-defined on arbitrary terms in rewriting contexts — it conflates term-level and meta-level reasoning and doesn't properly handle all contexts (it's essentially an ad hoc semantic argument rather than a recognized termination framework). Nevertheless, the core reasoning is sound and stays within the boundary.

**Does it succeed?** Yes (the argument is essentially correct, though informal).
**Within boundary?** Yes.

---

## Conclusion

**Methods A, B, D, and E** satisfy both conditions (successful proof, within boundary).
**Method C** fails to prove termination.
