# Analysis of Termination Proof Methods

## System Recap

```
Rules:
  (1) F(x, y, Z)   → x
  (2) F(x, y, S(n)) → G(y, F(x, y, n))
```

Note that Rule 2 duplicates variable `y` (appears once on the LHS, twice on the RHS).

---

## Method (A): LPO with precedence F > G > S > Z

**Rule 1:** F(x, y, Z) >\_lpo x — holds because x is a proper subterm of the LHS.

**Rule 2:** F(x, y, S(n)) >\_lpo G(y, F(x, y, n))
Since F > G in precedence, LPO requires the LHS to be strictly greater than each argument of G:
- F(x, y, S(n)) >\_lpo y — holds (y is a subterm).
- F(x, y, S(n)) >\_lpo F(x, y, n) — same root symbol F, so compare arguments lexicographically:
  - x = x, y = y, then S(n) >\_lpo n (n is a proper subterm of S(n)). ✓
  - Side conditions: LHS >\_lpo x, y, n — all hold since each is a subterm.

LPO is a well-founded reduction order closed under contexts and substitutions.

**Result: Succeeds. Within boundary** (standard metatheoretic technique; the precedence is a proof parameter, not an imported axiom).

---

## Method (B): Polynomial Interpretation

`[F(x,y,n)] = x + n + 1` has coefficient 0 for `y`, so F is **not strictly monotone** in its second argument. Consider the valid rewrite step:

```
F(a, F(b, c, S(d)), e) → F(a, G(c, F(b, c, d)), e)
```

Both sides evaluate to `a + e + 1`. The measure does not strictly decrease. The interpretation is not closed under contexts, so it does not constitute a valid reduction order.

**Result: Fails.**

---

## Method (C): KBO with Uniform Weights

Rule 2: F(x, y, S(n)) → G(y, F(x, y, n))

- **Variable condition:** `y` occurs once on the LHS but **twice** on the RHS (once as argument of G, once inside F). KBO requires |LHS|\_v ≥ |RHS|\_v for every variable v. This is violated: 1 < 2.
- **Weight:** Even ignoring the variable condition, with variable weight w₀ = 1: w(LHS) = 5, w(RHS) = 6. The LHS is lighter, so KBO cannot orient this rule.

**Result: Fails.**

---

## Method (D): Dependency Pairs with Subterm Criterion

The sole dependency pair is:

```
F#(x, y, S(n)) → F#(x, y, n)
```

Projecting to the third argument gives π(F#(x, y, S(n))) = S(n). The subterm criterion requires F#(x, y, n) to be a subterm of S(n). The subterms of S(n) are {S(n), n}; F#(x, y, n) is neither. The criterion does not apply.

Attempting argument filtering first (e.g., π(F) = 3) makes Rule 1 into `Z → x`, violating the variable condition. No valid filtering enables the subterm criterion here.

**Result: Fails.**

---

## Method (E): Direct Descent Measure

```
mu(F(x,y,n)) = depth_S(n) + 1
mu(G(a,b))   = mu(b)
mu(x)        = 0
```

Root steps decrease mu correctly. However, mu depends **only** on the third argument of F. Consider a rewrite in the first argument:

```
F(F(a, b, Z), c, d) → F(a, c, d)
```

mu(LHS) = depth\_S(d) + 1 = mu(RHS). The measure does **not** strictly decrease. The same problem occurs for rewrites in the second or third argument position of an outer F when depth\_S does not change.

**Result: Fails.**

---

## Conclusion

| Method | Proves Termination? | Within Boundary? |
|--------|---------------------|------------------|
| (A)    | Yes                 | Yes              |
| (B)    | No                  | —                |
| (C)    | No                  | —                |
| (D)    | No                  | —                |
| (E)    | No                  | —                |

**Only Method (A) satisfies both conditions.**
