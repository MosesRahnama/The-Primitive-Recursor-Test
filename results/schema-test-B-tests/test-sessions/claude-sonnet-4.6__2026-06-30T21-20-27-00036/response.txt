## The Rewrite System

```
F(x, y, Z) → x
F(x, y, S(n)) → G(y, F(x, y, n))
```

Termination hinges on the third argument of F decreasing (S(n) → n), but the right-hand side of rule 2 contains G wrapping F, so the root symbol changes.

---

## Method A: LPO with F > G > S > Z

**Rule 1:** F(x, y, Z) → x. LPO requires the RHS to be a subterm or recursively smaller. x is a proper subterm of the LHS. ✓

**Rule 2:** F(x, y, S(n)) → G(y, F(x, y, n)). With F > G, LPO checks G(y, F(x,y,n)) < F(x,y,S(n)). Since F > G, we need each argument of G to be strictly less than F(x,y,S(n)). y is a subterm ✓; F(x,y,n) < F(x,y,S(n)) by LPO since the arguments are lex-compared and n < S(n) (as S > Z and n is a subterm of S(n)... actually n is a variable). LPO compares F(x,y,n) vs F(x,y,S(n)): same root, lex comparison reaches third argument: n vs S(n). Is n <_LPO S(n)? Yes, n is a proper subterm of S(n). ✓

**Both conditions satisfied.** ✓

## Method B: Polynomial interpretation

**Rule 1:** [F(x,y,Z)] = x + 0 + 1 = x + 1 > x = [x]. ✓

**Rule 2:** [F(x,y,S(n))] = x + (n+1) + 1 = x + n + 2. [G(y, F(x,y,n))] = [F(x,y,n)] = x + n + 1. So x + n + 2 > x + n + 1. ✓

The interpretation uses only values derivable from the rules themselves (no external axioms). **Both conditions satisfied.** ✓

---

## Method C: KBO with uniform weights w = 1

**Rule 2:** F(x, y, S(n)) → G(y, F(x, y, n)). Weight of LHS: w(F) + w(S) + w(n) + w(x) + w(y) = 1+1+1+1+1 = 5 (counting variables as weight 1). Weight of RHS: w(G) + w(y) + w(F) + w(x) + w(y) + w(n) = 1+1+1+1+1+1 = 6. RHS weight (6) > LHS weight (5). **KBO fails.** ✗

---

## Method D: Dependency pairs with subterm criterion

The dependency pairs from rule 2 are: F(x,y,S(n)) → F(x,y,n) (the recursive call inside G). Projecting to the third argument: π(F(x,y,S(n))) = S(n), π(F(x,y,n)) = n. Since n is a proper subterm of S(n), the subterm criterion applies directly. **Both conditions satisfied.** ✓

---

## Method E: Direct descent measure

μ(F(x,y,S(n))) = depth_S(S(n)) + 1. After rule 2, we get G(y, F(x,y,n)), and μ(G(y,F(x,y,n))) = μ(F(x,y,n)) = depth_S(n) + 1 < depth_S(S(n)) + 1. ✓ For rule 1, F(x,y,Z) → x, and μ(x) = 0 < 1 = μ(F(x,y,Z)). ✓

However, defining μ on G as μ(G(a,b)) = μ(b) requires knowing b's structure, and extending μ to all terms involves assumptions about how G-headed terms reduce — this leans on structural reasoning about derivable reductions rather than a purely syntactic interpretation of the rules. This is borderline, but the measure is definable from the rules alone. **Both conditions arguably satisfied.** ✓
