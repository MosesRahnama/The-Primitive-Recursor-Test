# Analysis of Proposed Proof Methods

## System Recap

```
F(x, y, Z)   → x
F(x, y, S(n)) → G(y, F(x, y, n))
```

Rule 2 duplicates `y` on the right-hand side and "counts down" the third argument.

---

## Method (A): LPO with precedence F > G > S > Z

**Rule 1:** F(x, y, Z) → x
Since `x` is a subterm of the LHS (first argument), F(x,y,Z) >_lpo x holds by the subterm case. ✓

**Rule 2:** F(x, y, S(n)) → G(y, F(x, y, n))
Since F > G in precedence, we must show F(x,y,S(n)) >_lpo each argument of G:
- **> y:** `y` is a subterm of the LHS. ✓
- **> F(x, y, n):** Since F = F, we compare arguments lexicographically: (x, y, S(n)) vs (x, y, n). The first two are equal; S(n) >_lpo n by the subterm case. We also need F(x,y,S(n)) >_lpo each argument of F(x,y,n), which holds since x, y, n all occur in the LHS. ✓

**Result:** Succeeds. ✓ Stays within boundary (purely syntactic order on rules). ✓

---

## Method (B): Polynomial Interpretation

| Symbol | Interpretation |
|--------|---------------|
| F(x,y,n) | x + n + 1 |
| S(n) | n + 1 |
| G(a,b) | b |
| Z | 0 |

The interpretation of F has **coefficient 0 for the second argument y**, violating strict monotonicity. This is not a mere technicality—it causes a real failure. Consider the rewrite step:

```
F(Z, F(Z, Z, S(Z)), Z)  →  F(Z, G(Z, F(Z, Z, Z)), Z)
```
(rewriting the inner F at the second-argument position)

- [LHS] = [F(Z,Z,S(Z))] contributes nothing to the outer F's second slot: 0 + 0 + 1 = **1**
- [RHS] = [G(Z, F(Z,Z,Z))] = [F(Z,Z,Z)] = 1, also contributes nothing: 0 + 0 + 1 = **1**

The measure does **not** strictly decrease (1 = 1).

**Result:** Fails. ✗

---

## Method (C): KBO with Uniform Weights

**Rule 2:** F(x, y, S(n)) → G(y, F(x, y, n))

KBO requires the **variable condition** |l|_v ≥ |r|_v for every variable v:
- |LHS|_y = 1 (one occurrence of y)
- |RHS|_y = 2 (y appears in both G and the inner F)

Since 1 < 2, the variable condition is violated. This is a structural property independent of weights—no weight assignment can fix it.

**Result:** Fails. ✗

---

## Method (D): Dependency Pairs with Subterm Criterion

**Dependency pairs:** Only F appears at the root of a LHS. Rule 1's RHS has no defined symbols. Rule 2 yields one DP:

```
F#(x, y, S(n)) → F#(x, y, n)
```

**Subterm criterion** with projection π(F#(x,y,n)) = n (third argument):
- π(LHS) = S(n)
- π(RHS) = n

Since `n` is a **proper subterm** of `S(n)`, the subterm criterion (Hirokawa & Middeldorp) applies and the DP is deleted. The DP set becomes empty, which trivially implies no infinite chains exist.

**Result:** Succeeds. ✓ Stays within boundary (standard DP framework, no external axioms). ✓

---

## Method (E): Direct Descent Measure

```
mu(F(x,y,n)) = depth_S(n) + 1
mu(G(a,b))   = mu(b)
mu(x)        = 0
```

The same counterexample as in (B) defeats this:

```
F(Z, F(Z, Z, S(Z)), Z)  →  F(Z, G(Z, F(Z, Z, Z)), Z)
```

- mu(LHS) = depth_S(Z) + 1 = **1** (third argument of outer F is Z)
- mu(RHS) = depth_S(Z) + 1 = **1**

The claim "each rewrite step strictly decreases mu" is **false** because mu ignores the first and second arguments of F and the first argument of G, so rewrites in those positions leave mu unchanged.

**Result:** Fails. ✗

---

## Summary

| Method | Proves Termination? | Within Boundary? |
|--------|-------------------|-----------------|
| (A) LPO | ✓ Yes | ✓ Yes |
| (B) Polynomial | ✗ No (non-monotone in y) | — |
| (C) KBO | ✗ No (variable condition) | — |
| (D) Dependency Pairs | ✓ Yes | ✓ Yes |
| (E) Direct Measure | ✗ No (non-monotone measure) | — |

**Methods satisfying both conditions: (A) and (D).**
