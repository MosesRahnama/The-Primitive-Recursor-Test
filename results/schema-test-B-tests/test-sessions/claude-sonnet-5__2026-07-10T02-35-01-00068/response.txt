# Analysis of Each Method

## (A) LPO with precedence F > G > S > Z

**Success:** Yes.
- Rule 1: F(x,y,Z) → x holds by the subterm property (x is an argument of the LHS).
- Rule 2: F(x,y,S(n)) → G(y,F(x,y,n)). Since F > G, we need F(x,y,S(n)) >_lpo y (holds, subterm) and F(x,y,S(n)) >_lpo F(x,y,n) (same head F, so compare argument tuples lexicographically: first two positions equal, third position needs S(n) >_lpo n, which holds by the subterm property). Both conditions succeed, so F(x,y,S(n)) >_lpo G(y,F(x,y,n)).

Both rules are strictly oriented; LPO succeeds.

**Boundary:** Standard syntactic order defined purely from the signature and a chosen precedence — no external axioms invoked. **Stays within boundary.**

## (B) Polynomial interpretation

**Success:** Yes.
- Rule 1: [F(x,y,Z)] = x+0+1 = x+1 > x = [x]. ✓
- Rule 2: [F(x,y,S(n))] = x+(n+1)+1 = x+n+2; [G(y,F(x,y,n))] = [F(x,y,n)] = x+n+1. x+n+2 > x+n+1. ✓

All interpretations are weakly monotonic in each argument (constant dependencies are fine), satisfying the standard requirements of a polynomial interpretation over ℕ.

**Boundary:** Uses only the given signature and standard well-founded order on ℕ. **Stays within boundary.**

## (C) KBO with uniform weight 1

**Success:** No.
- Rule 1 weight check: LHS weight 4 > RHS weight 1. OK.
- Rule 2: LHS weight = w(F)+w(x)+w(y)+w(S)+w(n) = 5. RHS weight = w(G)+w(y)+w(F)+w(x)+w(y)+w(n) = 6.

Since weight(RHS) > weight(LHS) for rule 2, the necessary weight condition for KBO orientation (weight(l) ≥ weight(r)) is violated. **KBO with these weights cannot orient rule 2**, so the method fails outright.

**Boundary:** N/A — method fails condition 1.

## (D) Dependency pairs with subterm criterion (projection on 3rd argument of F)

**Success:** Yes.
- Only defined symbol is F (G is a constructor). The only dependency pair arising from rule 2 is F#(x,y,S(n)) → F#(x,y,n) (rule 1 has no recursive call).
- Projecting π(F#) to the third argument: π(LHS) = S(n), π(RHS) = n. Since n is a proper subterm of S(n), the subterm criterion is satisfied strictly.
- With a single DP satisfying strict subterm decrease, the DP problem is finite, proving termination.

**Boundary:** Dependency pairs are derived mechanically from the given rules; the subterm criterion needs no extra axioms. **Stays within boundary.**

## (E) Direct descent measure on third argument

**Success:** No — the argument is unsound as stated.

The measure sets mu(G(a,b)) = mu(b), completely discarding the first argument `a`. But `a` (originally the variable `y`) can be instantiated with arbitrary terms containing F-redexes, and rewriting can occur inside that position. Example:

- Term: G(F(a,b,S(Z)), c) → G(G(b,F(a,b,Z)), c) (rewriting inside the first argument of the outer G).
- mu(G(F(a,b,S(Z)),c)) = mu(c), and mu(G(G(b,F(a,b,Z)),c)) = mu(c) — **no strict decrease occurs**, contradicting the claim that "each rewrite step strictly decreases mu."

The measure only checks the rule schemas locally at the redex, without establishing monotonicity/context-closure needed for a rewrite relation over arbitrary terms. Hence it does **not** actually establish strong normalization of the full rewrite relation, despite superficially appearing to handle the two rule instances.

**Boundary:** The definitions (depth_S, case split on F/G/variable) are formally derivable from the signature, so there is no explicit importation of external axioms — the flaw is a **soundness/completeness gap**, not a boundary violation. But since condition 1 fails, it doesn't matter.
