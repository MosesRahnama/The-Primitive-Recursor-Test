# Analysis of Termination Proof Methods

## System Recap

```
F(x, y, Z)     -> x
F(x, y, S(n))  -> G(y, F(x, y, n))
```

---

## Method (A): LPO with precedence F > G > S > Z

**Does it succeed?** **Yes.**

- **Rule 1:** `F(x, y, Z) >_lpo x` — holds by the subterm rule (lpo1), since `x` is a direct argument of the LHS.
- **Rule 2:** `F(x, y, S(n)) >_lpo G(y, F(x, y, n))` — since `F > G` in the precedence, LPO case (lpo2) requires the LHS to be strictly greater than each argument of `G`:
  - `F(x, y, S(n)) >_lpo y` — holds by subterm.
  - `F(x, y, S(n)) >_lpo F(x, y, n)` — same head symbol `F`, so lexicographic comparison applies: `x = x`, `y = y`, and `S(n) >_lpo n` (by subterm, since `n` is a subterm of `S(n)`). The side condition `F(x,y,S(n)) >_lpo t_j` for each argument `x, y, n` of the RHS `F` also holds by the subterm property.

Both rules are oriented. ✓

**Within boundary?** Yes. LPO is a standard, self-contained termination technique operating purely on the given rules.

---

## Method (B): Polynomial interpretation over ℕ

**Does it succeed?** **Yes.**

- **Rule 1:** `[F(x, y, Z)] = x + 0 + 1 = x + 1 > x = [x]` — holds (1 > 0). ✓
- **Rule 2:** `[F(x, y, S(n))] = x + (n+1) + 1 = x + n + 2`. `[G(y, F(x, y, n))] = [F(x, y, n)] = x + n + 1`. Since `x + n + 2 > x + n + 1` for all `x, n ∈ ℕ`. ✓

All polynomials have non-negative coefficients (weak monotonicity is satisfied). Both rules are strictly oriented. ✓

**Within boundary?** Yes. Polynomial interpretation is a standard termination technique requiring no external axioms.

---

## Method (C): KBO with uniform weights w(F) = w(G) = w(S) = w(Z) = 1

**Does it succeed?** **No.**

KBO requires the **variable condition**: for every variable `v`, the number of occurrences of `v` in the LHS must be ≥ the number of occurrences in the RHS.

For Rule 2: `F(x, y, S(n)) -> G(y, F(x, y, n))`
- Variable `y` appears **1 time** on the LHS and **2 times** on the RHS (once in `G(y, …)` and once inside `F(x, y, n)`).

This violates `|LHS|_y ≥ |RHS|_y`. No choice of precedence or weights can fix this fundamental violation—substituting a heavy term for `y` will always make the RHS heavier. ✗

**Within boundary?** N/A (method fails).

---

## Method (D): Dependency pairs with subterm criterion, projecting to the third argument of F

**Does it succeed?** **No.**

The single dependency pair is:
```
F♯(x, y, S(n)) -> F♯(x, y, n)
```

The basic subterm criterion requires `F♯(x, y, n)` to be a proper subterm of `F♯(x, y, S(n))`. It is **not**—the third argument changes from `S(n)` to `n`, but `F♯(x, y, n)` as a whole is not a subterm of `F♯(x, y, S(n))`.

The projection-based variant (argument filtering `π(F♯) = π(F) = 3`) yields `π(LHS) = S(n) ▷ n = π(RHS)`, satisfying the DP condition. However, the subterm criterion with argument filterings additionally requires **rule compatibility**: `π(l) ⊵ π(r)` for all rules `l → r`.

- **Rule 1** with `π(F) = 3`: `π(F(x, y, Z)) = Z`, but `π(x) = x`. We need `Z ⊵ x`, which is **false** since `x` is not a subterm of the constant `Z`.

No argument filtering simultaneously satisfies the DP condition and the rule conditions. The method is therefore incomplete as stated. ✗

**Within boundary?** N/A (method fails).

---

## Method (E): Direct descent measure on the third argument

**Does it succeed?** **No.**

The measure `μ(F(x,y,n)) = depth_S(n) + 1` depends **only on the third argument** of `F`. This means rewriting inside the first or second argument of `F` does not change `μ`.

**Counterexample step:**
```
F(F(a, b, S(m)), y, S(n))  →  F(G(b, F(a, b, m)), y, S(n))
```
(rewriting the inner redex `F(a, b, S(m))` at position 1)

- `μ(LHS) = depth_S(S(n)) + 1`
- `μ(RHS) = depth_S(S(n)) + 1`

The measure is **equal**, not strictly decreasing. The claim that "each rewrite step strictly decreases μ" is false. `μ` is not monotone in the first argument of `F`, so it cannot serve as a standalone termination measure. ✗

**Within boundary?** N/A (method fails).
