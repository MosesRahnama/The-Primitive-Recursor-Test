Actually, I recall now that the subterm criterion IS valid without conditions on R, but only for MINIMAL chains. Let me re-read the theorem.

Theorem (Hirokawa & Middeldorp, 2004): Let (P, R) be a DP problem. If there exists an argument filtering π such that π(s) ▷ π(t) for all s -> t in P, then there is no infinite MINIMAL (P, R)-chain.

The proof goes as follows:
Suppose there is an infinite minimal chain: s1σ1 -> t1σ1 ->*_R s2σ2 -> t2σ2 ->*_R ...

We have π(siσi) ▷ π(tiσi).
We also have tiσi ->*_R si+1σi+1.
Now, the key insight: since the chain is minimal, we can show that π(tiσi) ⊵ π(si+1σi+1).

Why? Because in a minimal chain, the R-rewrites from tiσi to si+1σi+1 only happen at positions below the "cap" of ti. And if π only selects arguments that are not affected by these rewrites, then π(tiσi) ⊵ π(si+1σi+1).
