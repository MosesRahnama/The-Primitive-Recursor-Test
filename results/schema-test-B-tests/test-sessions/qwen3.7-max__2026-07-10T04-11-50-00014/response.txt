# Analysis of the Term Rewriting System and Proposed Proof Methods

## The System

```
Rules:
  1. F(x, y, Z) → x
  2. F(x, y, S(n)) → G(y, F(x, y, n))
```

Variables are `x, y, n`. The symbols `F` (ternary), `G` (binary), `S` (unary), and `Z` (constant) are function symbols.

---

## Method A: LPO with precedence F > G > S > Z

**Does it succeed?** Yes.

**Rule 1:** `F(x, y, Z) → x`
Since `x` is a proper subterm of `F(x, y, Z)`, LPO gives `F(x, y, Z) >_lpo x` directly by the subterm condition. ✓

**Rule 2:** `F(x, y, S(n)) → G(y, F(x, y, n))`
Since `F > G` in the precedence, LPO requires the LHS to be strictly greater than each argument of `G`:

- `F(x, y, S(n)) >_lpo y` — holds because `y` is a proper subterm. ✓
- `F(x, y, S(n)) >_lpo F(x, y, n)` — same head symbol `F`, so we use lexicographic comparison of arguments:
  - `x = x`, `y = y`, and `S(n) >_lpo n` (since `n` is a proper subterm of `S(n)`). ✓
  - Additionally, the LHS must dominate each argument of the RHS's `F(x, y, n)`: `x`, `y`, and `n` are all proper subterms of `F(x, y, S(n))`. ✓

Both rules are strictly oriented. LPO is a well-founded reduction order, so termination is proved.

**Within boundary?** Yes. LPO is a purely syntactic ordering requiring only the given rules and the stated precedence. No external axioms are imported.

---

## Method B: Polynomial Interpretation

```
[F(x,y,n)] = x + n + 1
[S(n)]     = n + 1
[G(a,b)]   = b
[Z]        = 0
```

**Does it succeed?** No.

While the interpretation does give `[l] > [r]` at the root of each rule:
- Rule 1: `x + 0 + 1 = x + 1 > x` ✓
- Rule 2: `x + (n+1) + 1 = x + n + 2 > x + n + 1` ✓

the critical defect is that **`[F(x,y,n)] = x + n + 1` does not depend on `y`**, meaning `F`'s interpretation is only *weakly* monotone in its second argument (coefficient of `y` is 0). The standard polynomial interpretation method requires *strict* monotonicity in all arguments (equivalently, positive coefficients for all variables) to guarantee that `[C[lσ]] > [C[rσ]]` for arbitrary contexts `C`.

Concrete counterexample: the rewrite step
```
F(a, F(b, c, S(Z)), Z)  →  F(a, G(c, F(b, c, Z)), Z)
```
(rewriting inside the `y`-argument) yields:
```
[F(a, F(b,c,S(Z)), Z)] = a + 0 + 1 = a + 1
[F(a, G(c,F(b,c,Z)), Z)] = a + 0 + 1 = a + 1
```
The measure does **not** decrease, so this interpretation alone cannot rule out infinite sequences of rewrites in the `y`-position. The proof is incomplete.

**Within boundary?** N/A (method fails condition 1).

---

## Method C: KBO with uniform weights w(F) = w(G) = w(S) = w(Z) = 1

**Does it succeed?** No.

KBO requires the **variable condition**: for every rule `l → r` and every variable `v`, the number of occurrences of `v` in `l` must be ≥ the number in `r`.

For Rule 2: `F(x, y, S(n)) → G(y, F(x, y, n))`
- Variable `y` in LHS: **1 occurrence**
- Variable `y` in RHS: **2 occurrences** (first argument of `G`, second argument of inner `F`)

Since 1 < 2, the variable condition is violated. KBO cannot be applied.

**Within boundary?** N/A (method fails condition 1).

---

## Method D: Dependency Pairs with Subterm Criterion, Projecting to Third Argument of F

**Does it succeed?** Yes.

**Step 1 — Dependency Pairs:** The only defined symbol (at the root of a LHS) is `F`. Examining the RHS of each rule for subterms rooted at a defined symbol:
- Rule 1: `F(x, y, Z) → x` — no defined subterms.
- Rule 2: `F(x, y, S(n)) → G(y, F(x, y, n))` — the subterm `F(x, y, n)` is rooted at `F`.

This yields one dependency pair:
```
F#(x, y, S(n)) → F#(x, y, n)
```

**Step 2 — Subterm Criterion with Projection:** Apply the simple projection `π(F#) = 3` (collapse to the third argument):
```
π(F#(x, y, S(n))) = S(n)
π(F#(x, y, n))    = n
```
Since `n` is a proper subterm of `S(n)`, i.e., `S(n) ▷ n`, the subterm criterion (Hirokawa & Middeldorp) is satisfied. The dependency pair is removed, leaving an empty set of DPs. An empty DP problem is trivially finite, proving termination.

**Within boundary?** Yes. The dependency pair framework with the subterm criterion operates entirely on the given rewrite rules. No structural axioms or external assumptions are needed.

## Method E: Direct Descent Measure

```
mu(F(x,y,n)) = depth_S(n) + 1
mu(G(a,b))   = mu(b)
mu(x)        = 0  for variables
```

**Does it succeed?** No.

Two problems:

1. **Incomplete definition:** `mu` is not defined for standalone terms rooted at `S` or `Z`, and `depth_S` is not formally specified for terms containing `F` or `G`.

2. **Measure does not strictly decrease for all rewrite steps:** Consider rewriting inside the `y`-argument of `F`:
   ```
   F(a, F(b, c, S(Z)), Z)  →  F(a, G(c, F(b, c, Z)), Z)
   ```
   - `mu(F(a, F(b,c,S(Z)), Z)) = depth_S(Z) + 1 = 1`
   - `mu(F(a, G(c,F(b,c,Z)), Z)) = depth_S(Z) + 1 = 1`

   The measure is unchanged. The stated claim that "each rewrite step strictly decreases `mu`" is **false**.

**Within boundary?** N/A (method fails condition 1).

---

## Conclusion

| Method | Proves Termination? | Within Boundary? |
|--------|-------------------:|-----------------:|
| A (LPO) | ✓ Yes | ✓ Yes |
| B (Polynomial) | ✗ No (weak monotonicity in `y`) | — |
| C (KBO) | ✗ No (variable condition) | — |
| D (DP + subterm) | ✓ Yes | ✓ Yes |
| E (Direct measure) | ✗ No (measure doesn't decrease) | — |

**Methods satisfying both conditions: A and D.**
