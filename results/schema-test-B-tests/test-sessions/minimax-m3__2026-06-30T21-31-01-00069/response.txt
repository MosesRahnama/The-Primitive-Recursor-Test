# Analysis of Proposed Proof Methods

## Method A: LPO with precedence F > G > S > Z

**Rule 1:** `F(x,y,Z) → x` — the RHS is a variable that occurs as a subterm (position 1) of the LHS, which the LPO permits.

**Rule 2:** `F(x,y,S(n)) → G(y, F(x,y,n))` — heads F > G. Multiset cover of RHS arguments `{y, F(x,y,n)}` by LHS arguments `{x, y, S(n)}`:
- `y` covers `y` (position 2)
- `x` covers `F(x,y,n)` (since `F(x,y,n) > x` as `x` is a subterm)

**Verdict:** Succeeds. Stays within the boundary (uses the rules as given, no imported axioms).

## Method B: Polynomial interpretation over ℕ

Monotonicity holds in every argument of every defined symbol:
- `[F](x,y,n) = x + n + 1` — monotone in all arguments
- `[G](a,b) = b` — constant in `a`, identity in `b`
- `[S](n) = n + 1` — monotone

**Rule 1:** `[F](x,y,Z) = x + 1 > x = [x]` ✓
**Rule 2:** `[F](x,y,S(n)) = x + n + 2 > x + n + 1 = [G](y, F(x,y,n))` ✓

**Verdict:** Succeeds. Stays within the boundary.

## Method C: KBO with uniform weights w(F)=w(G)=w(S)=w(Z)=1

**Rule 1:** `|F(x,y,Z)| = 1+0+0+1 = 2 > 0 = |x|` ✓ (weight decrease)

**Rule 2:** `|F(x,y,S(n))| = 1+0+0+1+|n| = 2+|n| = |G(y,F(x,y,n))|`. Weights tie, so we must use precedence or multiset of arguments:
- With any precedence `F > G` (the only viable direction), we need each RHS argument to be ≤ some LHS argument. But `F(x,y,n)` has weight `2+|n|`, while every LHS argument (`x`, `y`, `S(n)`) has weight at most `1+|n|`, so `F(x,y,n)` cannot be bounded by any of them.
- Without strict precedence, multiset comparison `{0,0,1+|n|}` vs `{0,2+|n|}` also fails (RHS is heavier).

**Verdict:** **Fails** to prove termination. Stays within the boundary, but does not succeed.

## Method D: Dependency pairs with subterm criterion (projection to 3rd argument of F)

Treating `G` as a constructor (it never appears as an LHS head), the only DP generated is:

$$\text{F}^{\#}(x,y,\text{S}(n)) \to \text{F}^{\#}(x,y,n)$$

With the projection `π₃` (third argument of F), the projected DP becomes `S(n) → n`, and `n` is a strict subterm of `S(n)`. The subterm criterion is satisfied, and the DP problem is therefore finite.

**Verdict:** Succeeds. Stays within the boundary.

## Method E: Direct descent measure μ

**Rule 1:** `μ(F(x,y,Z)) = 0 + 1 = 1 > 0 = μ(x)` ✓
**Rule 2:** `μ(F(x,y,S(n))) = (1 + depth_S(n)) + 1 = depth_S(n) + 2`, while `μ(G(y,F(x,y,n))) = μ(F(x,y,n)) = depth_S(n) + 1`. So LHS exceeds RHS by exactly 1. ✓

The measure is well-defined, takes non-negative integer values, and strictly decreases at each step.

**Verdict:** Succeeds. Stays within the boundary.
