# Analysis of Termination Proof Methods

## System Summary

```
F(x, y, Z)     → x
F(x, y, S(n))  → G(y, F(x, y, n))
```

The third argument of F acts as a unary-natural-number counter (Sⁿ(Z)) that decreases with each recursive call.

---

## Method (A): LPO with F > G > S > Z

**Condition 1 — Succeeds? Yes.**

- **Rule 1:** F(x, y, Z) → x. Since x is the first argument of F, we get F(x,y,Z) >\_lpo x by the subterm case. ✓
- **Rule 2:** F(x, y, S(n)) → G(y, F(x, y, n)). Root F > G in precedence, so we must show F(x,y,S(n)) >\_lpo each argument of G:
  - >\_lpo y: y is the 2nd argument (subterm case). ✓
  - >\_lpo F(x, y, n): same root F, so use lexicographic comparison of (x, y, S(n)) vs (x, y, n). First two arguments are equal; S(n) >\_lpo n by the subterm case. We also need F(x,y,S(n)) >\_lpo each argument of the inner F (x, y, n), all satisfied by subterm/transitivity. ✓

**Condition 2 — Within boundary? Yes.** LPO is a purely syntactic ordering derived from the rules alone.

---

## Method (B): Polynomial Interpretation

**Condition 1 — Succeeds? No.**

The interpretation [F(x,y,n)] = x + n + 1 **ignores the second argument y entirely**, violating the strict monotonicity requirement for polynomial interpretations. Concretely, consider the valid rewrite step:

```
F(a, F(d, e, Z), c)  →  F(a, d, c)
```

Both sides evaluate to a + c + 1 under the interpretation — no strict decrease. The ordering is not closed under contexts, so it does not constitute a valid reduction order.

**Condition 2 — N/A (method fails).**

---

## Method (C): KBO with Uniform Weights w = 1

**Condition 1 — Succeeds? No.**

For Rule 2: F(x, y, S(n)) → G(y, F(x, y, n)):

- **Variable condition fails:** y appears once on the LHS but **twice** on the RHS (|y|\_LHS = 1 < |y|\_RHS = 2).
- **Weight condition fails:** w(LHS) = 5, w(RHS) = 6. The right-hand side is strictly heavier.

KBO cannot orient this rule.

**Condition 2 — N/A (method fails).**

---

## Method (D): Dependency Pairs + Subterm Criterion (project to 3rd arg)

**Condition 1 — Succeeds? Yes.**

The only defined symbol is F. Computing dependency pairs from the rules:

- Rule 1 produces no DP (RHS is a variable).
- Rule 2 yields one DP: **F#(x, y, S(n)) → F#(x, y, n)**

Applying projection π(F#) = 3:

| | Projected term |
|---|---|
| LHS: F#(x, y, S(n)) | S(n) |
| RHS: F#(x, y, n) | n |

Since n is a **proper subterm** of S(n), the subterm criterion removes this DP. The DP set becomes empty, so no infinite chain can exist. Termination is proved.

**Condition 2 — Within boundary? Yes.** Dependency pairs with the subterm criterion operate entirely on the given rules.

---

## Method (E): Direct Descent Measure μ

**Condition 1 — Succeeds? No.**

Consider Rule 1 applied with x instantiated to a complex term, e.g., x = F(a, b, S(S(Z))):

```
F(F(a,b,S(S(Z))), y, Z)  →  F(a, b, S(S(Z)))
```

- μ(LHS) = depth\_S(Z) + 1 = **1**
- μ(RHS) = depth\_S(S(S(Z))) + 1 = **3**

The measure **increases** from 1 to 3. The definition μ(F(x,y,n)) = depth\_S(n) + 1 ignores x entirely, so replacing F(…Z) with a deep x causes a blow-up. The claimed strict decrease does not hold.

**Condition 2 — N/A (method fails).**

---

## Conclusion

| Method | Proves termination? | Within boundary? |
|--------|---------------------|------------------|
| (A) LPO | ✅ Yes | ✅ Yes |
| (B) Polynomial | ❌ No | — |
| (C) KBO | ❌ No | — |
| (D) Dependency Pairs | ✅ Yes | ✅ Yes |
| (E) Descent measure | ❌ No | — |

**Methods (A) and (D) satisfy both conditions.**
