# Analysis of Termination Proof Methods

## System Recap
- **Rule 1:** F(x, y, Z) → x
- **Rule 2:** F(x, y, S(n)) → G(y, F(x, y, n))

The third argument of F acts as a structural counter: Rule 2 peels off one S and creates a nested call; Rule 1 is the base case. The system clearly terminates.

---

## Method A: LPO with F > G > S > Z

**Rule 1:** F(x, y, Z) >_{lpo} x. Since x is the first argument of the LHS, this holds by the subterm clause (lpo1). ✓

**Rule 2:** F(x, y, S(n)) >_{lpo} G(y, F(x, y, n)).
- Root F > root G in precedence, so we use clause (lpo2), requiring the LHS to be strictly greater than each argument of G:
  - **vs. y:** Holds by subterm clause (y is the 2nd argument of LHS). ✓
  - **vs. F(x, y, n):** Both sides have root F, so we use the lexicographic clause (lpo3):
    - Arguments compared lexicographically: x = x, y = y, S(n) >_{lpo} n (subterm clause on S). ✓
    - LHS must dominate each argument of the RHS's F: x, y, n — all hold by subterm. ✓

**Result:** Both rules oriented. LPO is a standard reduction order requiring no external axioms.

|-----------|-----------------|
| **Yes**   | **Yes**         |

## Method B: Polynomial Interpretation

Interpretation: [F(x,y,n)] = x + n + 1, [S(n)] = n + 1, [G(a,b)] = b, [Z] = 0.

**Rule orientation** works arithmetically:
- Rule 1: x + 0 + 1 = x + 1 > x ✓
- Rule 2: x + n + 2 > x + n + 1 ✓

**Critical flaw — not monotone in y:** [F(x, y, n)] = x + n + 1 ignores y entirely. Consider rewriting inside the second argument of F:

> F(a, **F(b, c, S(d))**, Z) → F(a, **G(c, F(b, c, d))**, Z)

Both sides evaluate to a + 0 + 1 = a + 1. The measure does **not** strictly decrease. The induced ordering is not closed under contexts, so it is not a valid reduction order.

|-----------|-----------------|
| **No**    | N/A             |

## Method C: KBO with Uniform Weights w = 1

**Rule 2:** F(x, y, S(n)) → G(y, F(x, y, n))

- **Variable condition violated:** y occurs **once** in the LHS but **twice** in the RHS. KBO requires every variable to appear at least as many times in the LHS as in the RHS.
- **Weight comparison fails regardless:** |LHS| = 1+1+1+1+1 = 5, |RHS| = 1+1+1+1+1+1 = 6. The RHS is heavier.

No precedence or variable-weight adjustment can fix the variable-duplication violation.

|-----------|-----------------|
| **No**    | N/A             |

## Method D: Dependency Pairs with Subterm Criterion

**Dependency pairs:** Only Rule 2 generates a DP (Rule 1's RHS is a variable, producing none):
> F♯(x, y, S(n)) → F♯(x, y, n)

**Subterm criterion** with projection π(F♯) = 3rd argument:
- π(LHS) = S(n)
- π(RHS) = n
- n ⊲ S(n) — the projected RHS is a proper subterm of the projected LHS. ✓

By the subterm criterion theorem (Hirokawa & Middeldorp), this DP can be removed, leaving an empty DP set. The problem (∅, R) is trivially finite, so the TRS terminates. This is a purely metatheoretic argument from the rules alone.

|-----------|-----------------|
| **Yes**   | **Yes**         |

## Method E: Direct Descent Measure

Proposed measure: μ(F(x,y,n)) = depth_S(n) + 1, μ(G(a,b)) = μ(b), μ(variables) = 0.

**Root rewrites** decrease μ:
- Rule 1: μ(F(x,y,Z)) = 1 > 0 = μ(x) ✓
- Rule 2: μ(F(x,y,S(n))) = depth_S(n) + 2 > depth_S(n) + 1 = μ(G(y, F(x,y,n))) ✓

**Fatal flaw — not context-compatible:** μ(F(x,y,n)) depends *only* on the third argument. Rewriting inside the second argument of F yields no decrease:

> F(a, **F(b, c, S(d))**, Z) → F(a, **G(c, F(b, c, d))**, Z)

Both sides give μ = depth_S(Z) + 1 = 1. The claim that "each rewrite step strictly decreases μ" is **false**.

|-----------|-----------------|
| **No**    | N/A             |

---

## Conclusion

**Methods A and D** satisfy both conditions: they successfully prove termination and stay within the benchmark boundary (relying only on standard metatheoretic reasoning from the given rules, with no imported structural axioms).
