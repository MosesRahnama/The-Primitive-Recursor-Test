- Rule 2: F > G, so we compare lhs with each rhs argument: lhs > y (variable) and lhs > F(x,y,n). For the latter, same head, lexicographic: S(n) > n (variable), so lhs > F(x,y,n). Thus both rules oriented. LPO is a reduction order, so termination proved.
- Boundary: purely syntactic order, inside.

(B) Polynomial interpretation.
- [F(x,y,Z)] = x+1 > x = [x].
- [F(x,y,S(n))] = x+n+2 > x+n+1 = [G(y,F(x,y,n))].
- However, the interpretation is not monotone in the first argument of G (coefficient 0). Thus not closed under contexts. Counterexample: rewrite inside first arg of G: G(F(x,y,S(n)), z) -> G(G(y,F(x,y,n)), z). Both sides have interpretation [z], so no strict decrease. Hence fails as a general termination proof.
- Boundary: uses imported structure N, but polynomial interpretations are standard metatheoretic technique, so inside.

(C) KBO with uniform weights.
- Rule 1 oriented by weight (2 > 0).
- Rule 2: both sides have weight 2. KBO requires a precedence to break ties between different head symbols with equal weight. The method does not provide a precedence (and uniform weights alone do not give one). Without a precedence, F and G are incomparable or equally ranked, so the rule cannot be oriented. Hence fails.
- Boundary: standard syntactic order, inside.

(D) Dependency pairs with subterm criterion, projecting to third arg of F.
- The only dependency pair is F#(x,y,S(n)) -> F#(x,y,n).
- Projecting to third argument gives lhs projection S(n) and rhs projection n. Since S(n) is a strict superterm of n, the subterm criterion applies. No infinite chain possible. Termination proved.
- Boundary: purely syntactic DP framework, inside.

(E) Direct descent measure.
- mu(F(x,y,n)) = depth_S(n)+1, mu(G(a,b)) = mu(b), mu(var)=0.
- For a root step, mu decreases.
- But rewriting can occur inside the first argument of G or the first/second argument of F, positions ignored by mu. E.g., G(F(x,y,S(n)), z) -> G(G(y,F(x,y,n)), z): mu = mu(z) before and after, so no strict decrease. F(F(x,y,S(n)), v, w) -> F(G(y,F(x,y,n)), v, w): mu depends on w only, unchanged. Thus the claim that every rewrite step strictly decreases mu is false.
- Boundary: recursive measure is metatheoretic, inside.

Thus methods satisfying both: (A) and (D).
