## The Rewriting System

- R1: F(x, y, Z) → x
- R2: F(x, y, S(n)) → G(y, F(x, y, n))

The third argument of F decreases by one S-layer each recursive call, so termination is intuitively clear.

---

## Method A: LPO with F > G > S > Z

**R1:** F(x, y, Z) →_lpo x. LPO requires the RHS to be a subterm or strictly smaller. x is a proper subterm of the LHS, so ✓.

**R2:** F(x, y, S(n)) →_lpo G(y, F(x, y, n)). Check G(y, F(x,y,n)) < F(x,y,S(n)) under LPO with F > G. Since F > G, we need each argument of G to be strictly less than F(x,y,S(n)). y is a subterm ✓. F(x,y,n): compare with F(x,y,S(n)) — same root, lex comparison gives x=x, y=y, then n vs S(n), and n <_lpo S(n) ✓. So F(x,y,n) <_lpo F(x,y,S(n)) ✓.

**Result: Succeeds. Within boundary.**

## Method B: Polynomial interpretation

**R1:** [F(x,y,Z)] = x + 0 + 1 = x+1 > x = [x] ✓

**R2:** [F(x,y,S(n))] = x + (n+1) + 1 = x+n+2. [G(y, F(x,y,n))] = [F(x,y,n)] = x+n+1. Indeed x+n+2 > x+n+1 ✓.

Both rules strictly decrease the interpretation.

**Result: Succeeds. Within boundary.**

## Method C: KBO with uniform weights w=1

KBO requires the weight function to satisfy: for every rule, either weight decreases, or weight is equal and the rule is compatible with the precedence in a specific way.

**R1:** F(x,y,Z) → x. Weight LHS = 1+1+1+1 = 4 (F,x,y,Z each count as 1 for ground, but x,y are variables). Variable weight rule: each variable on RHS must appear on LHS (✓), and w(LHS) must be ≥ w(RHS). w(LHS)=w(F)+w(Z)+(variable contributions). For KBO with w=1 for all symbols: w(F(x,y,Z))=1+1=2 (non-variable symbols F,Z) plus variable occurrences. w(x)=variable weight. Standard KBO: w(F(x,y,Z))=w(F)+w(Z) + w_var(x)+w_var(y). If variable weight=1, LHS weight=4, RHS weight=1. Strictly decreases ✓.

**R2:** w(F(x,y,S(n)))= w(F)+w(S)+variable weights = 1+1+wx+wy+wn = 2+3=5. w(G(y,F(x,y,n)))=w(G)+w(F)+wy+wx+wy+wn=1+1+1+1+1+1=6. **LHS weight 5 < RHS weight 6.** KBO fails since weight does not decrease and equal-weight case requires precedence condition which can't save a weight increase.

**Result: Fails.**

## Method D: Dependency pairs with subterm criterion

The dependency pair from R2 is: F(x,y,S(n)) → F(x,y,n) (the recursive call). The subterm criterion projects F to its third argument: π(F)=3. Then we need S(n) ▷ n (strict subterm), which holds. The DP problem is solved.

R1 yields no dependency pair.

**Result: Succeeds. Within boundary.**

## Method E: Direct descent measure

mu(F(x,y,n)) = depth_S(n)+1, mu(G(a,b))=mu(b), mu(x)=0 for variables.

**R1:** F(x,y,Z)→x. mu(LHS)=0+1=1, mu(x)=0. 1>0 ✓.

**R2:** F(x,y,S(n))→G(y,F(x,y,n)). mu(LHS)=depth_S(S(n))+1=(depth_S(n)+1)+1. mu(G(y,F(x,y,n)))=mu(F(x,y,n))=depth_S(n)+1. Strictly greater ✓.

**Result: Succeeds. Within boundary.**
