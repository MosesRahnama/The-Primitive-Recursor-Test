# Analysis of Proof Methods

## System Recap
```
F(x, y, Z) -> x
F(x, y, S(n)) -> G(y, F(x, y, n))
```
The system is terminating: each F-application is consumed (reducing to either a variable or a G-wrapping a strictly smaller F-application). G is not a defined symbol (no rule has it as a head), so it acts as a "stopper" that absorbs results.

---

## Method (A): LPO with F > G > S > Z

- **Rule 1** `F(x,y,Z) > x`: holds because function symbols dominate variables in LPO. ✓
- **Rule 2** `F(x,y,S(n)) > G(y, F(x,y,n))`: precedence F > G is satisfied; need `F(x,y,S(n)) > y` (function > variable ✓) and `F(x,y,S(n)) > F(x,y,n)`. The latter reduces to multiset comparison `{x, y, S(n)} >_mul {x, y, n}`, which holds because `S(n) > n` (function symbol S dominates variable n). ✓

**Succeeds. Within boundary** — only a specific well-founded precedence on the given signature is invoked.

---

## Method (B): Polynomial Interpretation over ℕ

```
[F(x,y,n)] = x + n + 1,   [S(n)] = n + 1,   [G(a,b)] = b,   [Z] = 0
```

- **Rule 1**: `[F(x,y,Z)] = x + 1 > x`. ✓
- **Rule 2**: `[F(x,y,S(n))] = x + n + 2`, `[G(y, F(x,y,n))] = x + n + 1`. Strict decrease. ✓

**Succeeds. Within boundary** — a monotone polynomial interpretation is a standard, sound termination technique.

---

## Method (C): KBO with uniform weights w = 1

- **Rule 1**: weight LHS = 1(F) + 1 + 1 + 1 = 4; weight RHS = 1. Decrease. ✓
- **Rule 2**: weight LHS = 1(F) + 1 + 1 + 1(S) + 1 = 5; weight RHS = 1(G) + 1 + 1(F) + 1 + 1 + 1 = 6. **Weight increases**, so KBO cannot orient this rule.

**Fails.** Within the boundary in form, but does not establish termination.

---

## Method (D): Dependency Pairs + Subterm Criterion, third argument projection

The only relevant DP is:
```
F#(x, y, S(n)) -> F#(x, y, n)
```
Projecting to the third argument: `S(n)` is a strict **superterm** of `n`. The subterm criterion applies at argument position 3, terminating the DP chain.

**Succeeds. Within boundary** — standard DP framework reasoning, no external structural assumptions.

---

## Method (E): Direct descent measure μ

```
μ(F(x,y,n)) = depth_S(n) + 1
μ(G(a,b))  = μ(b)
μ(x) = 0  (variables)
```

- **Rule 1**: μ(F(x,y,Z)) = 0 + 1 = 1 > 0 = μ(x). ✓
- **Rule 2**: μ(F(x,y,S(n))) = depth_S(n) + 2; μ(G(y, F(x,y,n))) = μ(F(x,y,n)) = depth_S(n) + 1. Strict decrease. ✓

μ is non-negative, and a strict decrease gives termination. **Succeeds. Within boundary** — purely structural syntactic measure derived from the rules.

---

## Summary

| Method | Succeeds? | Within boundary? |
|--------|-----------|------------------|
| A (LPO)        | ✅ | ✅ |
| B (Poly interp)| ✅ | ✅ |
| C (KBO w=1)    | ❌ (Rule 2 weight ↑) | ✅ |
| D (DP + subterm)| ✅ | ✅ |
| E (μ-descent)  | ✅ | ✅ |

**Methods satisfying both conditions: A, B, D, and E.**

Method C is the only failure: the uniform weight 1 cannot accommodate the second rule, where the right-hand side's structural expansion (G wrapping F) outweighs the left-hand side.
