### A. LPO

With precedence \(F>G>S>Z\):

- \(F(x,y,Z) >_{\mathrm{LPO}} x\) by the subterm property.
- For the second rule, the left side dominates both arguments of the right-side \(G\):
  - \(F(x,y,S(n)) > y\);
  - \(F(x,y,S(n)) > F(x,y,n)\), since the first two arguments agree and \(S(n)>n\).

Thus both rules are strictly oriented. This is a purely syntactic termination order and adds no object-level assumptions.

### B. Polynomial interpretation

Both rules decrease at their roots:

\[
[F(x,y,Z)]=x+1>x,
\]

and

\[
[F(x,y,S(n))]=x+n+2>x+n+1
 =[G(y,F(x,y,n))].
\]

However, \(G(a,b)=b\) ignores its first argument, so the induced strict order is not strictly monotone in every context. For example,

\[
G(F(x,y,Z),z)\to G(x,z)
\]

has the same interpretation \(z\) on both sides. Therefore this interpretation is not a reduction order proving full termination. Using \(\mathbb N\) as a meta-level interpretation does not itself introduce an object-level assumption, so it remains within the benchmark boundary.

### C. KBO

The second rule violates KBO’s variable condition. The left side contains one occurrence of \(y\), while the right side contains two:

\[
F(x,y,S(n))
\to
G(y,F(x,y,n)).
\]

Consequently, no KBO with the stated uniform weights can orient that rule from left to right. The method is nevertheless purely syntactic and stays within the boundary.

### D. Dependency pairs

The only dependency pair is

\[
F^\#(x,y,S(n))\to F^\#(x,y,n).
\]

Projecting onto the third argument gives

\[
S(n)\mathrel{\triangleright}n,
\]

a strict proper-subterm decrease. Hence the dependency-pair problem is finite by the subterm criterion. This uses only the presented rewrite system.

### E. Direct measure

The claimed “every rewrite step strictly decreases” property is false for unrestricted rewriting. For example, rewriting inside the ignored first argument of \(G\) gives

\[
G(F(x,y,Z),z)\to G(x,z),
\]

but both sides have measure \(\mu(z)=0\).

There is also a substitution problem with the first rule: although the schematic variable \(x\) is assigned measure \(0\), an instance of \(x\) can be an arbitrarily complex term with positive measure. Thus checking only the schematic root rule does not establish decrease under substitution.

Making this argument work would require extra restrictions—such as treating variables as irreducible, restricting the third argument to numeral-like terms, or considering only root recursion—which are not supplied by the TRS and would leave the stated benchmark boundary.
