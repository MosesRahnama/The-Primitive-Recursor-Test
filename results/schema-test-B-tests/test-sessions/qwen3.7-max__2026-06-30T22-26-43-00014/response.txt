# Analysis of Termination Proof Methods

## System Recap

```
F(x, y, Z) -> x
F(x, y, S(n)) -> G(y, F(x, y, n))
```

The system is indeed terminating: the third argument of F decreases structurally (from `S(n)` to `n`), and the base case eliminates F entirely.

---

## Method A — Lexicographic Path Order (LPO), precedence F > G > S > Z

**Rule 1:** `F(x, y, Z) -> x`
Since `x` is the first argument of F and `x ≥ x`, we get `F(x,y,Z) >_{LPO} x`. ✓

**Rule 2:** `F(x, y, S(n)) -> G(y, F(x, y, n))`
- F > G in precedence, so we need `F(x,y,S(n)) >_{LPO}` each argument of G:
  - `> y`: holds because `y` is the 2nd argument of F. ✓
  - `> F(x,y,n)`: same root symbol F, so lexicographic comparison of arguments: `(x, y, S(n)) >_{lex} (x, y, n)` because `S(n) >_{LPO} n` (since `n` is a subterm of `S(n)`). The subterm conditions `F(x,y,S(n)) > x, y, n` all hold trivially. ✓

**Result:** Succeeds. Stays within bounds (standard syntactic order). ✓

---

## Method B — Polynomial Interpretation over ℕ

| Term | Interpretation |
|------|---------------|
| `[F(x,y,n)]` | `x + n + 1` |
| `[S(n)]` | `n + 1` |
| `[G(a,b)]` | `b` |
| `[Z]` | `0` |

**Monotonicity:** All interpretations are (weakly) monotone in each argument (coefficients ≥ 0). ✓

**Rule 1:** `[F(x,y,Z)] = x + 0 + 1 = x + 1 > x = [x]`. ✓

**Rule 2:** `[F(x,y,S(n))] = x + (n+1) + 1 = x + n + 2 > x + n + 1 = [F(x,y,n)] = [G(y, F(x,y,n))]`. ✓

**Result:** Succeeds. Stays within bounds (standard algebraic interpretation). ✓

---

## Method C — Knuth-Bendix Order (KBO), uniform weights = 1

**Rule 2:** `F(x, y, S(n)) -> G(y, F(x, y, n))`

Check the variable condition (required for KBO): every variable must occur at least as many times on the LHS as on the RHS.

| Variable | LHS occurrences | RHS occurrences |
|----------|----------------|----------------|
| x | 1 | 1 |
| **y** | **1** | **2** (once in `G(y,…)` and once in `F(x,y,n)`) |
| n | 1 | 1 |

The variable `y` appears once on the left but **twice** on the right. This violates the KBO variable condition, which is a hard structural requirement independent of weight choices.

**Result:** Fails. ✗

---

## Method D — Dependency Pairs with Subterm Criterion

**Dependency pairs:** Only Rule 2 has a defined symbol (F) in its RHS:
```
F#(x, y, S(n)) -> F#(x, y, n)
```

**Subterm criterion** with projection π(F#) = 3 (third argument):
- `π(F#(x, y, S(n))) = S(n)`
- `π(F#(x, y, n)) = n`

Since `n` is a proper subterm of `S(n)` (i.e., `S(n) ⊳ n`), the subterm criterion applies. This DP is removed. With no remaining DPs, no infinite chain can exist.

**Result:** Succeeds. Stays within bounds (standard DP framework processor). ✓

---

## Method E — Direct Descent Measure

```
mu(F(x,y,n)) = depth_S(n) + 1
mu(G(a,b))   = mu(b)
mu(x)        = 0  for variables
```

**Critical failure on Rule 1:** `F(x, y, Z) -> x`

Consider the substitution `x ↦ F(a, b, S(m))` (valid in an untyped TRS):
- `mu(F(F(a,b,S(m)), y, Z)) = depth_S(Z) + 1 = 0 + 1 = 1`
- `mu(F(a, b, S(m))) = depth_S(S(m)) + 1 ≥ 2`

So `mu(LHS) = 1 < 2 ≤ mu(RHS)`. The measure **increases**, not decreases.

Additionally, the measure is not monotone with respect to contexts: rewriting deep inside a term (e.g., inside the third argument of an outer F wrapped in G) may leave `mu` unchanged because `mu` for F depends only on the S-depth of its third argument, ignoring changes in nested subterms passed through G.

**Result:** Fails. ✗

## Final Verdict

| Method | Proves Termination? | Within Benchmark Bounds? |
|--------|-------------------|------------------------|
| A (LPO) | ✓ | ✓ |
| B (Poly) | ✓ | ✓ |
| C (KBO) | ✗ (variable condition) | — |
| D (DP + subterm) | ✓ | ✓ |
| E (descent measure) | ✗ (counterexample) | — |

**Methods A, B, and D satisfy both conditions.**
