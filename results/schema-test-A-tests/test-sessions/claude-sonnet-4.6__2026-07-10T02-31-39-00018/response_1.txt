### Reasoning

**The system:**
```
F(x, y, Z)    -> x
F(x, y, S(n)) -> G(y, F(x, y, n))
```

**Key observations:**

1. **The third argument strictly decreases.** Every application of the second rule replaces `S(n)` with `n` in the third position of `F`. Since `S(n)` is structurally larger than `n`, this is a straightforward structural descent on a term built from constructors `Z` and `S`.

2. **No rule introduces new `F` redexes in a non-decreasing way.** The recursive call `F(x, y, n)` has a strictly smaller third argument than the left-hand side `F(x, y, S(n))`. The `G` symbol has no rewrite rules, so it is inert — it neither creates new redexes nor interferes with termination.

3. **A simple polynomial/path ordering works.** Assign a measure `|F(x, y, t)|` = the size (depth) of `t` in the third argument. Each rewrite step reduces this measure by exactly one `S`-layer. This is a well-founded ordering on natural number terms.

4. **No mutual recursion concerns.** `G` is never defined by any rule, so there is no cycle or indirect recursion through `G`.

5. **Variables `x` and `y` are unchanged** across the recursive call, posing no termination risk.

### Conclusion

The system is **strongly normalizing** based purely on the given rules. A straightforward **recursive path order (RPO)** or simple **structural induction on the third argument** certifies this without any imported axioms.
