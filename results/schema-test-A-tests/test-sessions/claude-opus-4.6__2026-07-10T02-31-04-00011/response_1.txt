# Assessment: Strong Normalization **Can** Be Established

## Conclusion

**Yes**, strong normalization of this system can be established from the presented rewrite rules alone.

## Reasoning

The system has two rules:

1. `F(x, y, Z) → x`
2. `F(x, y, S(n)) → G(y, F(x, y, n))`

**Key observations:**

1. **The third argument of F strictly decreases:** In rule (2), `F(x, y, S(n))` on the left has `S(n)` as the third argument, while `F(x, y, n)` on the right has `n` — a strict subterm. This is a structural recursion on the third argument.

2. **No new redexes of increasing complexity are created:** The right-hand side of rule (2) introduces `G(y, ...)`, but `G` has no rewrite rules — it is a constructor/free symbol. So `G` terms are never reducible and cannot trigger further rewrites on their own.

3. **No self-feeding recursion:** The only recursive call `F(x, y, n)` has strictly smaller third argument. The variables `x` and `y` are simply passed through unchanged, and `y` appears under `G` which is inert.

4. **Simple termination argument via a well-founded ordering:** We can use a standard recursive path ordering (RPO) or simply a lexicographic path ordering with precedence `F > G, S, Z`. Under RPO:
   - Rule (1): `F(x, y, Z) → x` — the right-hand side `x` is a subterm of the left-hand side. ✓
   - Rule (2): `F(x, y, S(n)) → G(y, F(x, y, n))` — since `F > G` in the precedence, `F(x, y, S(n))` dominates `G(...)`. We need `F(x, y, S(n)) > y` (yes, `y` is a subterm) and `F(x, y, S(n)) > F(x, y, n)` (yes, since `S(n) ▷ n` gives us the subterm decrease in the third argument). ✓

This is a textbook example of primitive recursion (essentially computing iterated application of G with y, applied n times to x), and it terminates by any standard termination criterion (RPO, polynomial interpretation, dependency pairs, etc.).
