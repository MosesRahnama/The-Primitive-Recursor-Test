Yes — **strong normalization can be established from these rules alone**.

Reason (brief): every rewrite step on `F(x,y,S(n))` replaces it by `G(y, F(x,y,n))`, i.e. it strictly decreases the third argument of `F` from `S(n)` to `n`. The only redex-creating rule for `F` is this one, and it can be applied only finitely many times until the third argument becomes `Z`, where `F(x,y,Z) -> x` terminates that chain.  

`G` has no rewrite rules, so it cannot generate further reductions. Thus there is no possible infinite rewrite sequence from any term. So the TRS is strongly normalizing.
