Yes — **strong normalization can be established from these rules alone**.

Reason (briefly): define a simple measure on terms based on the third argument of `F`:

- Let `μ(F(a,b,t)) = sizeNat(t)` where `sizeNat(Z)=0`, `sizeNat(S(n))=1+sizeNat(n)`.
- Other symbols (`G`, variables) do not increase this measure in a problematic way.

Now check rules:

1. `F(x,y,Z) -> x`  
   The `F` disappears entirely, so the measure for that redex drops to 0 (strict decrease).

2. `F(x,y,S(n)) -> G(y, F(x,y,n))`  
   The recursive `F` now has third argument `n` instead of `S(n)`, so `sizeNat` decreases by 1.

Crucially, there is **no rule with `G` on the left**, so `G` cannot trigger further growth/rewrite loops by itself. Any rewrite sequence must come from reducing `F`-redexes, and each such step strictly decreases the natural-number depth in the third argument of that `F`. Hence no infinite reduction is possible.

So the TRS is strongly normalizing without additional axioms.
