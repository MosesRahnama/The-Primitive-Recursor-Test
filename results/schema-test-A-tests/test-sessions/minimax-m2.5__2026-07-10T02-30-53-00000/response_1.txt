**Assessment:** Yes – the system is strongly normalising.

**Reasoning:**  
The only rule that can be applied repeatedly is  

```
F(x, y, S(n)) → G(y, F(x, y, n))
```

Each use of this rule removes one occurrence of the constructor `S` from the third argument of `F`.  The first rule  

```
F(x, y, Z) → x
```

then eliminates the remaining `F` once the third argument has been reduced to `Z`.  Thus the number of `S`‑symbols in the third argument of any `F`‑subterm strictly decreases with every rewrite step, and it cannot increase (there is no rule that introduces a new `S`).  Consequently any reduction sequence can contain at most “initial number of S’s + 1” steps, guaranteeing termination.  The argument relies only on the syntactic form of the two rules and requires no extra structural or object‑level axioms.
