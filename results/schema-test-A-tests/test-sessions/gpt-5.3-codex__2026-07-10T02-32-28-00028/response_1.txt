Yes — **strong normalization can be established from these rules alone**.

Reason (briefly): define a simple well-founded measure on terms that strictly decreases with every rewrite.  
A convenient one is the number of `S` constructors in the **third argument of each `F`**, summed over all `F` occurrences.

- Rule 1: `F(x,y,Z) -> x` removes one `F` redex outright, so the measure decreases.
- Rule 2: `F(x,y,S(n)) -> G(y, F(x,y,n))` replaces an `F` whose third argument has one more `S` by an `F` with one fewer `S` in that position; no new `S` is introduced there. So the measure decreases by 1.

Since this measure is a natural number and strictly decreases on every step, infinite rewrite sequences are impossible. Hence the TRS is strongly normalizing.
