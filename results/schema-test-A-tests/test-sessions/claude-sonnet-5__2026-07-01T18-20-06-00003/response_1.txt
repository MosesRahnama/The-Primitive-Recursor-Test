**Termination argument via Recursive Path Order (RPO):**

Fix the precedence `F > G` and use the standard (subterm-monotonic, well-founded) RPO argument with lexicographic comparison on `F`'s arguments.

- Rule 1: `F(x,y,Z) -> x`. RHS is a proper subterm of LHS ⇒ immediate RPO strict decrease.

- Rule 2: `F(x,y,S(n)) -> G(y, F(x,y,n))`.
  Since `F > G` in precedence, it suffices to show the LHS dominates *each* argument of the RHS:
  - `F(x,y,S(n)) ▷ y` — trivially, as `y` is a subterm of the LHS.
  - `F(x,y,S(n)) ▷ F(x,y,n)` — both terms are headed by `F`; compare argument tuples lexicographically: `x = x`, `y = y`, and `S(n) ▷ n` (subterm relation, since `n` occurs inside `S(n)`). This gives strict decrease at the first differing position, so `F(x,y,S(n)) >_{rpo} F(x,y,n)`.

  Hence `F(x,y,S(n)) >_{rpo} G(y,F(x,y,n))` by the standard RPO composition rule (LHS dominates all immediate subterms of RHS, head symbol of LHS has higher precedence).

Both rules are oriented by RPO, which is a well-founded, monotonic, stable order — this is a general-purpose termination technique applicable directly to *any* first-order TRS satisfying the signature/precedence conditions, not an extra "structural axiom" specific to this system. It relies only on:
- the subterm property (a term is bigger than its own subterms), and
- closure under contexts/substitutions (monotonicity),

both of which are basic consequences of how rewriting is defined for the given rules — nothing beyond the rewrite system itself is imported.

The system is a simple recursor over the naturals (`Z`, `S`) with an inert combinator `G`; it is captured cleanly by RPO with `F > G`, giving strong normalization **directly and only from the presented rules**, with no need for extra axioms or semantic assumptions.
