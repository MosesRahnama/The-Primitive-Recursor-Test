### Reasoning

The system can be proven strongly normalizing using the **Recursive Path Ordering (RPO)** with a simple precedence and lexicographic status.

**Precedence:** F > G  (other symbols need no particular ordering)
**Status:** Lexicographic comparison (left-to-right) for F.

**Rule 1:** `F(x, y, Z) -> x`
This is trivially oriented by RPO because `x` is a proper subterm of `F(x, y, Z)`, and RPO has the subterm property.

**Rule 2:** `F(x, y, S(n)) -> G(y, F(x, y, n))`
We need `F(x, y, S(n)) >_rpo G(y, F(x, y, n))`. Since `F > G` in the precedence, RPO requires the left-hand side to be strictly greater than each argument of `G`:

1. **`F(x, y, S(n)) >_rpo y`** — holds because `y` is a proper subterm.
2. **`F(x, y, S(n)) >_rpo F(x, y, n)`** — same head symbol `F`, so we compare arguments lexicographically:
   - 1st: `x` vs `x` — equal, advance.
   - 2nd: `y` vs `y` — equal, advance.
   - 3rd: `S(n)` vs `n` — `S(n) >_rpo n` holds by the subterm property.

   The subterm conditions on the arguments of the right-hand `F` (`x`, `y`, `n`) are all satisfied since each is a proper subterm of `F(x, y, S(n))`.

Both rules are strictly oriented by RPO. Since RPO is a well-founded reduction ordering (closed under contexts and substitutions), no infinite rewrite sequence is possible regardless of the starting term or reduction strategy. Therefore, **the system is strongly normalizing**, and this is provable entirely from the given rules without any external axioms.
