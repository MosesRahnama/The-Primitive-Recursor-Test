# Assessment: Strong Normalization **Can** Be Established

## Conclusion

**Yes**, strong normalization of this system can be established from the presented rewrite rules alone.

## Reasoning

The system consists of two rules:

1. `F(x, y, Z) → x`
2. `F(x, y, S(n)) → G(y, F(x, y, n))`

**Key observations:**

1. **The function symbol `G` has no rewrite rules.** It is a constructor — it appears on the right-hand side but never as a root symbol on the left-hand side of any rule. So `G(...)` terms are in normal form once their arguments are.

2. **The only defined symbol is `F`.** All rewriting activity involves reducing `F`-rooted terms.

3. **Structural decrease in the third argument.** In rule (2), the third argument decreases from `S(n)` to `n`. The first two arguments `x` and `y` are passed unchanged. The right-hand side `G(y, F(x, y, n))` contains exactly one recursive `F`-call with a strictly smaller third argument.

4. **Simple polynomial interpretation / recursive path ordering.** We can use a straightforward termination argument:
   - Assign a measure based on the size of the third argument of `F`. Specifically, let `|Z| = 0` and `|S(n)| = |n| + 1`.
   - The number of `F`-symbols in any term is bounded, and each rewrite step either eliminates an `F` (rule 1) or replaces `F(x, y, S(n))` with a term where the only `F` has a strictly smaller third argument (rule 2).
   - More formally, this is easily handled by **Lexicographic Path Order (LPO)** or **Knuth-Bendix Order (KBO)** with precedence `F > G, S, Z`. Under LPO with `F` greatest, both rules orient correctly since rule (1) returns a subterm, and rule (2) has `F` on the left dominating `G` on the right, with the recursive `F`-call having a strictly smaller third argument.

5. **No hidden non-termination.** There are no mutually recursive defined symbols, no rules for `G`, and no increase in the third argument anywhere. The substitution instances of `x` and `y` are irrelevant to termination since they are never inspected or expanded by the rules — they are simply passed through or placed under the constructor `G`.

This system is essentially computing iterated application of `G(y, ·)` — it computes something like `G(y, G(y, ... G(y, x)...))` with `n` applications of `G(y, ·)`. It is clearly terminating and any standard automated termination prover would confirm this instantly.
