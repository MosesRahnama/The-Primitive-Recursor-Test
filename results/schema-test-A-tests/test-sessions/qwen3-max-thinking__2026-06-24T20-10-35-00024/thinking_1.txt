So the pair (S_count, F_count) goes from (1,1) to (0,1), which is a decrease in the first component. Good.

Another example for rule 1: F(x,y,Z) -> x. Suppose x is a variable, y is a variable. Original term: F(x,y,Z) has S_count=0 (no S), F_count=1. After reduction: x, which has S_count=0, F_count=0. After reduction: x, which has S_count=0 (assuming x has no S), F_count=0. So (1,1) -> (0,0), decrease in first component.

Now, what if x contains S or F? For rule 1: F(x,y,Z) with x = S(b). Original: S_count = count_S(x) + count_S(y) + count_S(Z) = 1 + count_S(y) + 0. F_count = 1 + F_count(x) + F_count(y) = 1 + 0 + F_count(y) (since S(b) has no F). After reduction: term is x = S(b), so S_count = 1, F_count = 0. Change in S_count: new S_count = 1, old S_count = 1 + count_S(y). So if count_S(y) > 0, then old S_count > 1, so new S_count < old S_count. If count_S(y)=0, old S_count=1, new S_count=1, so S_count unchanged. Change in F_count: old F_count = 1 + F_count(y), new F_count = 0. So F_count decreases by 1 + F_count(y) >=1. So in the case count_S(y)=0, S_count unchanged, F_count decreases. So the pair decreases lexicographically.

Similarly for rule 2 with x containing symbols: the change calculations we did earlier were based on the counts in the subterms, and they hold regardless of what x,y,n are, because we are counting the entire subterm. The key is that the measure is defined on the whole term, and the reduction of the redex changes the counts exactly as computed, and the context (outside the redex) remains unchanged, so the total measure of the whole term changes by the same amount as the redex's measure change. Therefore, for any reduction step anywhere in the term, the global measure (total S count, total F count) decreases lexicographically.

Moreover, this measure is computable from the term syntax alone, and the decrease is guaranteed by the structure of the rules. No additional axioms are needed. We do not need to assume that G is a constructor or that S and Z form a datatype; we only use the fact that S and F are distinct function symbols whose occurrences we can count. The rules explicitly show that in rule 2, the left-hand side has an S that is not present in the right-hand side in the same position (it is peeled off), and in rule 1, the left-hand side has a Z and possibly other symbols that are removed.

Therefore, strong normalization (termination) can be established from the presented rewrite system alone. The proof sketch is the lexicographic combination of the counts of S and F symbols.

But wait: is there any caveat? What about the symbol G? In rule 2, we introduce a G. Does G contain S or F? No, G is a different function symbol. In our measure, we are only counting S and F. The introduction of G does not affect the S or F counts directly, except that in rule 2, we remove one S and possibly change the F count as computed. The G symbol itself is not counted in our measure, which is fine because we don't need to count it; the measure only needs to decrease. The presence of G does not introduce new S or F symbols (unless the arguments to G contain them, but those arguments are y and the new F term, and we already accounted for their counts in the change calculation). In the change calculation for rule 2, we computed the exact change in S and F counts, and it is negative for S count (decrease by 1) and the F count change is F_count(y), but since the S count decreases, the lexicographic order ensures decrease regardless of F count change. So even if F count increases due to y containing F, the first component decrease dominates.

Therefore, the system is terminating, and this can be proven using a simple measure that relies only on the syntax of the terms and the given rules. No external axioms are required.
