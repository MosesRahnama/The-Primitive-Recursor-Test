# Assessment: Strong Normalization **Can** Be Established

## Conclusion

**Yes**, strong normalization of this system can be established from the presented rewrite rules alone.

## Reasoning

The system has two rules:

1. `F(x, y, Z) → x`
2. `F(x, y, S(n)) → G(y, F(x, y, n))`

**Key observations:**

### Termination Argument via Structural Decrease

The only defined symbol is `F` (and `G` is a constructor — it appears nowhere on the left-hand side of any rule, so it is never rewritten). The recursive structure is straightforward:

- In rule (1), the right-hand side `x` is a subterm of the left-hand side, so the term strictly shrinks (no `F` remains).
- In rule (2), the right-hand side `G(y, F(x, y, n))` contains exactly one recursive call `F(x, y, n)`, where the third argument has decreased from `S(n)` to `n`.

The third argument of `F` is a Peano-style natural number built from `Z` and `S`. Each application of rule (2) strictly decreases this argument in the subterm ordering on naturals, and rule (1) is the base case. The first two arguments `x` and `y` are unchanged and merely passed through.

### Formal Proof Method

This can be established by a simple **polynomial interpretation** or **recursive path ordering (RPO)**:

- **Polynomial interpretation:** Assign `[Z] = 0`, `[S(n)] = n + 1`, `[G(a, b)] = a + b + 1`, `[F(x, y, n)] = (n+1)·(x + y + 1)`. One can verify both rules strictly decrease the interpretation. (Or even simpler interpretations work.)

- **Lexicographic path ordering (LPO):** With precedence `F > G > S > Z`, rule (1) is trivially decreasing (RHS is a subterm), and rule (2) decreases because the recursive `F` call has a smaller third argument (`n < S(n)` in the subterm ordering), and `G` has lower precedence than `F`.

### No External Axioms Needed

Since `G` is purely a constructor (no rules apply to it), there are no hidden reduction paths. The system is non-overlapping, and the termination argument depends only on the structure of the two given rules. No additional structural axioms or object-level assumptions are required.
