Yes — under standard first-order rewriting on finite terms, strong normalization can be established from these rules alone.

Brief reason: the TRS admits a direct well-founded termination interpretation, so no extra object-level axioms are needed. For example, use the polynomial interpretation into naturals

- ⟦Z⟧ = 0
- ⟦S(t)⟧ = ⟦t⟧ + 1
- ⟦G(a,b)⟧ = ⟦a⟧ + ⟦b⟧
- ⟦F(a,b,c)⟧ = (⟦c⟧ + 1)(⟦a⟧ + ⟦b⟧ + 1)

Then both rules strictly decrease:

1. `F(x,y,Z) -> x`
   - ⟦lhs⟧ = (0+1)(X+Y+1) = X+Y+1 > X = ⟦rhs⟧

2. `F(x,y,S(n)) -> G(y, F(x,y,n))`
   - ⟦lhs⟧ = (N+2)(X+Y+1)
   - ⟦rhs⟧ = Y + (N+1)(X+Y+1)
   - difference = X + 1 > 0

So every rewrite step strictly decreases a natural-number measure. Hence there cannot be any infinite rewrite sequence: the system is strongly normalizing.

Intuitively, the recursive `F` call peels one `S` from the third argument, and although `y` is duplicated into `G`, that duplication does not block termination because the global interpretation still strictly decreases.
