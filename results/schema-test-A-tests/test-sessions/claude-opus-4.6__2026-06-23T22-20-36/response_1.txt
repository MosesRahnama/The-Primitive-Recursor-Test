# Assessment: Strong Normalization **Can** Be Established

## Conclusion

**Yes**, strong normalization of this system can be established from the presented rewrite rules alone.

## Reasoning

The system consists of two rules:

1. `F(x, y, Z) → x`
2. `F(x, y, S(n)) → G(y, F(x, y, n))`

**Key observations:**

1. **The function symbol `G` has no rewrite rules.** It is a constructor — it appears on the right-hand side but never as a root symbol on the left-hand side of any rule. So `G(...)` terms are in normal form once their arguments are in normal form.

2. **Termination argument via a simple measure:** Consider the third argument of `F`. In rule (1), `F(x, y, Z)` eliminates the `F` entirely. In rule (2), `F(x, y, S(n))` rewrites to `G(y, F(x, y, n))`, where the third argument decreases from `S(n)` to `n` — strictly smaller in the natural number structure.

3. **Formal termination proof:** We can use a **recursive path ordering (RPO)** or even a simple **polynomial interpretation**. For example:
   - Let `[Z] = 0`, `[S(n)] = [n] + 1`, `[G(a, b)] = [a] + [b]`, `[F(x, y, n)] = ([x] + [y] + 1) · ([n] + 1)`.
   - Rule 1: `[F(x, y, Z)] = ([x] + [y] + 1) · 1 = [x] + [y] + 1 > [x]` ✓
   - Rule 2: `[F(x, y, S(n))] = ([x] + [y] + 1) · ([n] + 2)` vs `[G(y, F(x, y, n))] = [y] + ([x] + [y] + 1) · ([n] + 1)` = `[y] + ([x] + [y] + 1)·([n] + 1)`. The difference is `([x] + [y] + 1) · ([n] + 2) - [y] - ([x] + [y] + 1)·([n] + 1) = ([x] + [y] + 1) - [y] = [x] + 1 > 0` ✓

   Both rules strictly decrease the interpretation, confirming termination.

4. **No problematic features:** There is no mutual recursion, no non-terminating interactions, and no rules that could increase term complexity. The system is clearly terminating.

**Strong normalization holds**, provable purely from the given rules using standard termination methods (e.g., polynomial interpretation).
