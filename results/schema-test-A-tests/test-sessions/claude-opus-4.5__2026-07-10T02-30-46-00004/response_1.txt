This system is strongly normalizing, and this can be proven using standard termination techniques without importing any external axioms.

- In rule 1: `F(x, y, Z)` reduces to `x`, eliminating the `F` symbol entirely

**Formal justification:**

- **Lexicographic path ordering (LPO)** or **recursive path ordering (RPO)** with precedence `F > G`

- Rule 2: `[F(x, y, S(n))] = [n] + 2 > [n] + 1 = [G(y, F(x, y, n))]` ✓

Both rules strictly decrease the interpretation, establishing termination.

**Conclusion:** The system is self-contained and strongly normalizing by straightforward well-founded induction on the structure of the third argument of `F`.
