Yes, strong normalization can be established from the given rewrite system alone. The system has two rules:

- `F(x, y, Z) -> x`
- `F(x, y, S(n)) -> G(y, F(x, y, n))`

The key observation is that each application of the second rule strictly reduces the total number of `S` symbols in the term (it removes the outermost `S` from the third argument of the redex). Rule applications of the first rule do not increase the number of `S` symbols and strictly decrease the overall term size (since they replace an `F`-term by its first argument, a proper subterm). Therefore, any reduction sequence can contain only finitely many applications of the second rule (bounded by the initial number of `S` symbols), and after that only finitely many applications of the first rule (since each reduces size). This gives a well‑founded termination argument purely from the syntax, without needing any external axioms.
