# Assessment: Strong Normalization **Can** Be Established

## Conclusion

**Yes**, strong normalization of this system can be established from the presented rewrite rules alone.

## Reasoning

The system consists of two rules:

1. `F(x, y, Z) → x`
2. `F(x, y, S(n)) → G(y, F(x, y, n))`

**Key observations:**

### Termination Argument via a Reduction Order

We can use a simple **structural/recursive argument** on the third argument of `F`:

- In Rule 1, the right-hand side `x` is a strict subterm of `F(x, y, Z)`, so the term clearly decreases in complexity.
- In Rule 2, the right-hand side is `G(y, F(x, y, n))`. The only redex-capable symbol on the right-hand side is `F(x, y, n)`, where `n` is strictly smaller than `S(n)`. The symbol `G` is a **constructor** — it does not appear as the left-hand side of any rewrite rule, so it introduces no new redexes.

Since `G` is not a defined symbol (no rules have `G` at the root on the left-hand side), any `G(...)` term is in normal form with respect to the root, and we only need to normalize its arguments. The argument `y` is unchanged (no growth of redexes), and `F(x, y, n)` has a strictly smaller third argument.

### Formal justification

A **lexicographic path order (LPO)** or even a simple **polynomial interpretation** suffices:

- **Polynomial interpretation:** Let `[Z] = 0`, `[S(n)] = [n] + 1`, `[G(a, b)] = [a] + [b] + 1`, `[F(x, y, n)] = ([y] + 2) * (n + 1) + [x]` (or similar). One can verify:
  - `[F(x, y, Z)] = ([y] + 2) · 1 + [x] = [y] + 2 + [x] > [x]` ✓
  - `[F(x, y, S(n))] = ([y] + 2)(n + 2) + [x]` vs `[G(y, F(x, y, n))] = [y] + 1 + ([y] + 2)(n + 1) + [x] = [y] + 1 + [x] + ([y] + 2)(n + 1)`. The difference is `([y] + 2)(n + 2) - ([y] + 2)(n+1) - [y] - 1 = [y] + 2 - [y] - 1 = 1 > 0` ✓

Both rules are strictly decreasing under this interpretation, proving strong normalization.

### No external axioms needed

The termination proof relies solely on the structure of the two given rules and a straightforward well-founded order. No additional structural axioms or object-level assumptions are required.
