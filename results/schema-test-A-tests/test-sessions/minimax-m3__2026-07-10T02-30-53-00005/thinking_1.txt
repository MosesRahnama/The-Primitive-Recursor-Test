Let me try: M(t) = (# F symbols in t, # S symbols in t). Lexicographic.

Rule 1: F(x,y,Z) -> x. #F decreases by 1 (the F is removed). #S: was 0 in pattern, now S-count(x). #S could increase. But #F decreased, so M decreases (lex order, #F first).

Rule 2: F(x,y,S(n)) -> G(y, F(x,y,n)). #F: was 1 + f(x) + f(y) + f(n), now 0 + f(y) + 1 + f(x) + f(y) + f(n) = 1 + f(x) + 2f(y) + f(n). #F can increase! #S: was 1 + S(x) + S(y) + S(n), now S(y) + S(x) + 0 + S(n) = S(x) + S(y) + S(n). #S decreased by 1.

So lex order on (#F, #S) doesn't work for rule 2 since #F can increase.

Let me try (#S, #F) lex.

Rule 1: #S could go either way (was 0+S(x)+S(y), now S(x)). If S(y) > 0, #S decreases. If S(y) = 0, #S stays. #F decreases by 1. So lex (#S, #F): #S stays or decreases, and #F decreases. So lex decreases (since #S doesn't increase and #F decreases — wait, lex compares #S first; if #S stays the same, then #F decreasing means lex decreases; if #S decreases, lex decreases). 

Wait, lex (#S, #F): smaller is "less". If #S decreases, then (a, b) < (a', b') with a < a' regardless of b. If #S stays, then need b < b'. In rule 1, #S: from S(x) + S(y) to S(x). Difference is -S(y). If S(y) > 0, #S decreases. If S(y) = 0, #S stays. In the latter case, #F: was 1 + f(x) + f(y) + 0 = 1 + f(x) + f(y), now f(x). Difference: -1 - f(y). #F decreases by 1 + f(y) ≥ 1.

So in all cases for rule 1, lex (#S, #F) decreases. 

Rule 2: #S: was S(x) + S(y) + 1 + S(n), now S(y) + S(x) + 0 + S(n) = S(x) + S(y) + S(n). Difference: -1. #S decreases by 1.

So in rule 2, #S decreases by 1, so lex (#S, #F) decreases regardless of #F. 

So lex (#S, #F) is a well-founded measure that strictly decreases with each rewrite. This proves strong normalization!

Wait, let me double-check rule 1. LHS: F(x, y, Z). #S in this term (with substitution): S(x) + S(y) + 0 (Z has no S) = S(x) + S(y). RHS: x. #S: S(x). So #S(LHS) - #S(RHS) = S(y) ≥ 0. #S doesn't increase.

#L(F(x, y, Z)) = 1 + f(x) + f(y) + 0 = 1 + f(x) + f(y). #F(x) = f(x). #F(LHS) - #F(RHS) = 1 + f(y) ≥ 1. #F decreases by at least 1.

So in rule 1: #S doesn't increase, #F decreases. Lex (#S, #F) decreases. ✓

Rule 2: LHS = F(x, y, S(n)). #S = S(x) + S(y) + 1 + S(n). RHS = G(y, F(x, y, n)). #S = S(y) + S(x) + S(n) (G has no S, F(x,y,n) has no top-level S). #S(LHS) - #S(RHS) = 1. #S decreases by 1.

So #S decreases strictly. ✓

Great, so the measure (#S, #F) with lex ordering shows strong normalization.

Therefore, yes, strong normalization can be established from the rules alone.
